Lua היא שפת הסקריפטים השנייה של [סביבת העבודה סקריפט](topic:craftscript). בחרו ב-**Lua** בתיבת השפה שמעל לעורך (קובץ `.lua` נפתח ב-Lua מעצמו). Lua ו-CraftScript חולקות את אותם משתנים ואותן פונקציות מובנות, כך שסקריפט Lua יכול להשתמש במה שסקריפט CraftScript יצר, וגם להפך.

## העיקרים

```
-- כל פונקציה מובנית נמצאת בטבלה cs
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- מתחיל מ-1, כמו ב-CraftScript
print(K(1, 1), #K)             -- איבר; מספר האיברים

-- סביבת העבודה: אותם משתנים שכל סקריפט רואה
ws.total = K(1, 1) * 2
print(ws.total)

-- כמה תוצאות מפונקציה אחת
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` קורא לכל פונקציה מובנית ומחזיר את התוצאה הראשונה שלה; `cs.call(name, n, …)` מחזיר `n` תוצאות.
- `cs.tensor({1, 2, 3})` יוצר שורה, ו-`cs.tensor({{1, 2}, {3, 4}})` יוצר מטריצה.
- מערכים, מטריצות דלילות, רשתות ושדות הם ערכים עם מתודות: `t(i, j)` או `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (שחלוף), `t:totable()`. `+ - * / ^` פועלים כמו ב-CraftScript (`*` הוא מכפלת מטריצות); `t:times(u)` מכפיל איבר-איבר.
- מספר שהוא מערך 1×1 מגיע כמספר Lua רגיל.
- `ws.name` קורא וכותב לסביבת העבודה המשותפת. משתנים גלובליים שהסקריפט משאיר אחריו נכנסים אליה גם כשהוא מסתיים.
- `print(…)` כותב לקונסולה; `cs.show(f)`, `cs.plot(y)` ופונקציות התצוגה האחרות פועלות כמו ב-CraftScript.

## קריאה לספריית הניתוח

הפונקציות של [ספריית הניתוח](topic:craftscript-library) (הלשונית ספרייה) והפונקציות ש-CraftScript של החלק מגדירות, מגיעות גם הן דרך `cs`:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- שתי תוצאות
```

הן נמצאות לפני תחילת הסקריפט, לכן יש לכתוב את השם בתוך הסקריפט: `cs.static_tet(` או `cs.call('static_tet', …)`. שם שמורכב בזמן הריצה מגיע רק לפונקציות המובנות. מבנה שנבנה עם `cs.struct({ … })` הוא מבנה של CraftScript, ורשימה של Lua של מבנים כאלה (`{ cs.struct(…), … }`) היא תא, וזה מה שההגדרות של הספרייה מצפות לו. אם משהו משתבש בתוך פונקציה של הספרייה, ההודעה מציינת את הפונקציה ואת השורה שלה, ומצביעה על השורה שלכם שקראה לה.

## מה כבוי

סקריפטים אינם יכולים להגיע לקבצים, לרשת או לעמוד: `io`, `os` (למעט השעון), `require`, `dofile`, `loadfile` ו-`debug` הוסרו. השתמשו ב{{ui:פתיחה}} של סביבת העבודה ובמשתנים כדי להביא נתונים פנימה. תקציב הצעדים וה{{ui:עצירה}} פועלים כמו ב-CraftScript.
