Python היא שפת הסקריפטים השלישית של [סביבת העבודה סקריפט](topic:craftscript). בחרו ב-**Python** בתיבת השפה שמעל לעורך (קובץ `.py` נפתח ב-Python מעצמו). Python, Lua ו-CraftScript חולקות את אותם משתנים ואותן פונקציות מובנות, כך שסקריפט Python יכול להשתמש במה שסקריפט CraftScript יצר, וגם להפך.

ההרצה הראשונה בביקור טוענת את Python עצמו (CPython 3.14, כ-7 MB) מהאתר הזה, וזה לוקח כמה שניות. Python אינו חלק מ{{ui:שמירה לשימוש לא מקוון}} עדיין: הריצו קודם סקריפט Python אחד בזמן שאתם מחוברים.

## Python מבודד

סקריפטים של Python מבודדים כמו סקריפטים של CraftScript ו-Lua: הם מגיעים לחלק, למשתנים ולפונקציות המובנות, ולא לשום דבר נוסף. כל הרצה היא Python חדש בארגז חול משלו, עם עץ קבצים קטן בזיכרון (ספריית התקן שלו ותיקיית `/tmp` שנעלמת אחרי ההרצה). הוא אינו יכול להגיע לרשת, לקבצים שלכם או לשאר העמוד, בדפדפן ובשורת הפקודה כאחד. סקריפט מאדם אחר עדיין יכול לצרוך הרבה זמן או זיכרון: {{ui:עצירה}} מסיים אותו.

## העיקרים

```
A = cs.magic(3)              # כל פונקציה מובנית היא cs.<name>
B = A @ A.T                  # @ הוא מכפלת מטריצות, .T השחלוף
C = A * 2 + 1                # + - * / ** פועלים איבר-איבר, כמו ב-numpy
print(A[0, 1], A[-1, -1])    # מ-0; מספר שלילי סופר מהסוף
row = A[1]                   # אינדקס אחד על מטריצה: שורה
big = A[A > 4]               # מסכה לוגית בוחרת איברים
A[0, 0] = -5                 # הצבה לתוך מערך
V, D = cs.call('eig', 2, A)  # כמה תוצאות: cs.call(name, כמה, …)
```

- מערך 1 × 1 מגיע כמספר רגיל; מערכים אחרים, מטריצות דלילות, רשתות, שדות ומודלים הם **ערכים**.
- לערך יש `shape` (tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (מספר השורות שלו), ו-`float()`, `int()` ו-`bool()` לאיבר בודד.
- השוואות (`<`, `==` וכו') פועלות איבר-איבר, כמו ב-numpy: הן נותנות ערך לוגי.
- רשימות של מספרים שמועברות לפונקציה מובנית הופכות למערכים: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` יוצר מטריצה.
- מילון הופך למבנה (struct), ורשימה של דברים מעורבים הופכת לתא, ולהפך.

כל משתנה גלובלי שהסקריפט יוצר (מספר, ערך, מילון, רשימה…) נכנס ללשונית **משתנים** בסיום ההרצה, גם אחרי שגיאה. שמות שמתחילים ב-`_`, פונקציות, מחלקות ומודולים נשארים ב-Python. `ws.name` קורא או מגדיר משתנה ישירות, ו-`ws_names()` מציג את הרשימה.

`print(…)` כותב לקונסולה. `display(…)` (או `cs.display`) מציג רשת, שדה או גרף, כמו ב-CraftScript.

## קריאה לספריית הניתוח

פונקציות הספרייה נקראות כמו המובנות: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. כתבו את השם בסקריפט כמו שהוא: PartCraft מוצא את פונקציות הספרייה שסקריפט משתמש בהן לפני שהוא רץ.

## עדיין לא קיים

- numpy, scipy וחבילות אחרות: רק ספריית התקן של Python (`math`, `json`, `itertools`, `decimal`, `statistics`…) קיימת כאן, בלי חלקי החלונות, הטרמינל והמסד-נתונים (`tkinter`, `curses`, `sqlite3`).
- שקעים (sockets) וכל דבר אחר שיגיע החוצה: ל-Python אין כאן רשת.
- `time.sleep` מחזיר מיד.
- קיפול בעורך, וקריאה לפונקציית Python מסקריפט CraftScript.
- הרצה בודקת את תקציב ההוראות ואת {{ui:עצירה}} כל 1000 שורות; חישוב ארוך בתוך פונקציה מובנית אחת מסתיים קודם.
