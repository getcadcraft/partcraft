CraftScript היא שפת מטריצות שנכתבה כך שתיקרא כמו MATLAB, ולכן רוב הקודים הנומריים הקלאסיים (קוד אופטימיזציית הטופולוגיה בן 88 השורות, למשל) רצים עם שינויים קטנים בלבד. היא רצה ב[סביבת העבודה סקריפט](topic:craftscript) ומשורת הפקודה.

## ערכים

| סוג | דוגמה | הערות |
|---|---|---|
| מספר, מערך | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | כל מספר הוא מערך (בגודל 1×1). המערכים נשמרים עמודה אחר עמודה, עד 8 ממדים |
| לוגי | `A > 2`, `true` | מערכים של אמת ושקר; אפשר להשתמש בהם כאינדקסים |
| טקסט | `'beam'`, `"beam"` | |
| מטריצה דלילה | `sparse(i, j, v, n, n)` | למטריצות קשיחות |
| רשת, שדה, מודל | `hexGrid(…)`, `part()`, `load('part.stl')` | מה ש-`show` מציג |
| מבנה (struct) | `s.E = 210e3` | שדות בעלי שם |
| תא (cell) | `c = {1, 'two', [3 4]}` | רשימה של ערכים מכל סוג |
| ידית פונקציה | `f = @(x) x.^2` | |

## מערכים ואינדקס

- טווחים: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- האינדקס מתחיל מ-1: `A(2, 3)`, `v(end)`, `A(:, 1)` (עמודה שלמה), `A(:)` (הכול כעמודה אחת), `v(v > 0)` (אינדקס לוגי).
- הצבה מעבר לסוף מגדילה את המערך, כמו ב-MATLAB: `v(10) = 1`.

## אופרטורים

- `+ - * / \ ^` הן פעולות מטריצה (`A \ b` פותר); `.* ./ .^` פועלים איבר-איבר. `'` מבצע שחלוף.
- השוואות `== ~= < <= > >=`; לוגיקה `& | ~` (איבר-איבר) ו-`&& ||` (קיצור מעגל).

## בקרת זרימה ופונקציות

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

הפונקציות נכתבות בסקריפט אחרי הפקודות שלו, או בלשונית סקריפט משלהן שנקראת על שם הפונקציה:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

שם מחפשים לפי הסדר הבא: משתנה, סקריפט בחלק הזה בעל אותו שם, פונקציית ספרייה, ופונקציה מובנית.

## הדפסה, הערות, פלט

- הצהרה בלי `;` מדפיסה את ערכה; `;` משתיק אותה.
- `%` מתחיל הערה; `%{` ו-`%}` בשורות משלהן מסמנים הערה לשורות שביניהן.
- `disp(x)`, `fprintf('%g\n', x)` ו-`display(x)` מדפיסים לקונסולה.

## שגיאות ומגבלות

- שגיאות מתארות במילים פשוטות מה השתבש, ומציינות את השורה (ואת שרשרת הקריאות לפונקציות).
- לכל הרצה יש תקציב צעדים (ב**אפשרויות הרצה** בחלונית); לולאה אינסופית נעצרת עם הודעה, או בלחיצה על {{ui:עצירה}}.
- מערך מכיל עד 134 מיליון ערכים.

## שלא כמו MATLAB

- פקודות גרף מקבלות את האפשרויות שלהן בתוך הקריאה: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` ודומיהן מתקבלות ואינן עושות דבר.
- `input` ו-`keyboard` אינם נתמכים: סקריפט לא יכול לעצור ולשאול שאלה.
- אין toolboxes; יש את [ספריית הניתוח](topic:craftscript-library) והפונקציות המובנות.
