ניתוח בסביבת העבודה סקריפט הוא כמה סקריפטים קצרים שמעבירים זה לזה משתנים. התחילו מ[פונקציית ספרייה](topic:craftscript-library) קרובה למה שאתם צריכים, צרו ממנה עותק ושנו אותו; או בנו מאפס, כמפורט להלן.

## 1. רשת

```
model = part();                  % החלק שאתם מדמים, כמודל
m = tetmesh(model, 4);           % טטרהדרים בגודל של כ-4 mm
show(m)
```

בדקו את הרשת בתצוגה לפני שתמשיכו: {{key:F}} מתאים אותה, וסמל העין ב**מוצגים** מסתיר את החלק.

## 2. הרכבה ופתרון

כתבו את לולאת האלמנטים בסקריפט (היא נקראת כמו בספר הלימוד), והשאירו את החלקים הכבדים לפונקציות המובנות: מטריצות אלמנטים, הרכבה דלילה משלשות, ופותר הגרדיאנט הצמוד עם מכשיר קדם. פונקציית ספרייה כמו `static_tet` (לאחר שהספרייה כוללת אותה) היא דוגמה שלמה להעתקה.

## 3. הצגת התוצאה

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % ערך אחד לכל צומת
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- אפשר להקליד את טווח המקרא, או להחזיר אותו ל{{ui:אוטומטי}}.
- לחצו על הרשת כדי לקרוא את הערכים בצומת.
- גרף ששומר על אותו `'id'` מתעדכן במקומו, לכן הדפיסו וציירו בתוך הלולאה כדי לראות את ההתכנסות.

## 4. בדיקה

השוו למשהו שאתם יודעים: סטיית הקצה של זיז מול PL³/3EI, לוח עם חור מול מקדם ריכוז המאמץ שלו, התגובות מול העומסים. כתבו את הבדיקה כסקריפט נפרד, כדי שתרוץ שוב אחרי כל שינוי:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. שמירה

- כל שלב יכול להיות לשונית סקריפט נפרדת: הן חולקות משתנים, לכן הריצו אותן זו אחר זו.
- הסקריפטים נשמרים בתוך החלק. סמנו **לשמור את המשתנים עם החלק** בלשונית {{ui:משתנים}} כדי לשמור גם את התוצאות (עד 32 MB).
- {{ui:שמירה}} בקבוצת הסקריפט מורידה סקריפט כדי לשתף אותו; {{ui:פתיחה}} מביאה סקריפט פנימה.
