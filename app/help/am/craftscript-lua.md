Lua የ[የስክሪፕት የስራ ቦታ](topic:craftscript) ሁለተኛ ቋንቋ ነው። **Lua**ን ከአርታኢው በላይ ባለው የቋንቋ ሳጥን ይምረጡ (`.lua` ፋይል በራሱ በLua ይከፈታል)። Lua እና CraftScript ተመሳሳይ ተለዋዋጮች እና አብሮ የተሰሩ ተግባራት ይጋራሉ፣ ስለዚህ የLua ስክሪፕት የCraftScript ስክሪፕት የሰራውን ሊጠቀም ይችላል፣ እና በተቃራኒው።

## መሰረታዊ ነገሮች

```
-- ሁሉም አብሮ የተሰራ ተግባር በcs ሰንጠረዥ ውስጥ ነው
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- ከ1 የሚጀምር፣ እንደ CraftScript
print(K(1, 1), #K)             -- አንድ ኤለመንት፤ የኤለመንቶች ብዛት

-- የስራ ቦታው: ሁሉም ስክሪፕት የሚያየው ተመሳሳይ ተለዋዋጮች
ws.total = K(1, 1) * 2
print(ws.total)

-- ከአንድ ተግባር ብዙ ውጤቶች
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` ማንኛውንም አብሮ የተሰራ ተግባር ይጠራል እና የመጀመሪያ ውጤቱን ይመልሳል፤ `cs.call(name, n, …)` `n` ውጤቶችን ይመልሳል።
- `cs.tensor({1, 2, 3})` ረድፍ ይሰራል፣ `cs.tensor({{1, 2}, {3, 4}})` ማትሪክስ ይሰራል።
- አደራደሮች፣ sparse ማትሪክሶች፣ ሜሾች እና ፊልዶች ዘዴ ያላቸው እሴቶች ናቸው: `t(i, j)` ወይም `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (ትራንስፖዝ), `t:totable()`። `+ - * / ^` በCraftScript ያሉትን ያመለክታሉ (`*` የማትሪክስ ውጤት ነው)፤ `t:times(u)` ኤለመንት በኤለመንት ያባዛል።
- 1×1 አደራደር እንደ ተራ የLua ቁጥር ይደርሳል።
- `ws.name` የተጋራውን የስራ ቦታ ያነባል እና ይጽፋል። ስክሪፕትዎ የሚተዋቸው ግሎባል ተለዋዋጮችም ሲያልቅ እዚያ ይገባሉ።
- `print(…)` ወደ ኮንሶሉ ይጽፋል፤ `cs.show(f)`, `cs.plot(y)` እና ሌሎች የማሳያ ተግባራት በCraftScript እንደሚሰሩ ይሰራሉ።

## የትንተና ቤተ-መጻሕፍትን መጥራት

የትንተና ቤተ-መጻሕፍቱ ተግባራት (የቤተ-መጻሕፍት ትሩ) እና የክፍልዎ የራሳቸው ስክሪፕቶች የሚገልጹዋቸው የCraftScript ተግባራት በ`cs` በኩልም ይደረሳሉ:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- two outputs
```

እነሱ ስክሪፕቱ ከመጀመሩ በፊት ይገኛሉ፣ ስለዚህ ስሙን በስክሪፕቱ ውስጥ ይጻፉ: `cs.static_tet(` ወይም `cs.call('static_tet', …)`። ስክሪፕቱ በሚሰራበት ጊዜ የሚሰራ ስም ወደ አብሮ የተሰሩ ተግባራት ብቻ ይደርሳል። `cs.struct({ … })` የሚሰራ struct የCraftScript struct ነው፣ እና የLua ዝርዝር ከእነሱ (`{ cs.struct(…), … }`) cell ነው፣ ይህም የቤተ-መጻሕፍቱ ቅንብሮች የሚፈልጉት ነው። በቤተ-መጻሕፍት ተግባር ውስጥ የሆነ ችግር ከተፈጠረ መልዕክቱ ተግባሩን እና መስመሩን ይጠቅሳል፣ እና ያንን ያጠራውን የእርስዎን መስመር ይጠቁማል።

## የተዘጉ

ስክሪፕቶች ፋይሎችን፣ ኔትወርክን ወይም ገጹን መድረስ አይችሉም: `io`, `os` (ሰዓቱን ካልቆጠረ በስተቀር), `require`, `dofile`, `loadfile` እና `debug` ተወግደዋል። ዳታ ለማስገባት የስክሪፕት የስራ ቦታውን ክፈት እና ተለዋዋጮቹን ይጠቀሙ። የእርምጃ በጀቱ እና አቁም ለCraftScript እንደሚሰሩት ይሰራሉ።
