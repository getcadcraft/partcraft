## የሚያደርጉት

**የአካሉን ሁሉንም መጠኖች በአንድ ጊዜ** ያስረክባሉ፦ እያንዳንዱ ውቅር አንድ STEP፣ IFC እና DWG ፋይል እና ሥዕል ይኖረዋል፣ እያንዳንዱ ምን እንደሆነ የሚናገር ሰንጠረዥ፣ እና ሁሉንም በአንድ ገጽ ላይ የሚያስቀምጥ የቤተ-መጻሕፍት ንጥል።

መጀመሪያ **ውቅሮች** ያሉት አካል ያስፈልግዎታል (ይመልከቱ [ውቅሮችና የንድፍ ሰንጠረዦች](topic:design-tables))። ባህሪን የሚያጠፋ ውቅር፣ ለምሳሌ ቀዳዳ ያለውና የሌለው ሳህን፣ የራሱ ልዩነት ይሆናል።

## ደረጃዎች

1. አካሉን ይክፈቱ። በ{{ui:መለኪያዎች}} ትር ላይ **ውቅሮች**ን ይፈልጉ።
2. {{ui:የልዩነቶች ጥቅል…}} ን ይጫኑ።
3. የሚገነቡትን ውቅሮች (ሁሉም ምልክት ተደርጎባቸዋል) እና የሚጻፉትን ፋይሎች ምልክት ያድርጉ፦ STEP፣ IFC፣ DWG፣ ቅድመ-እይታ እና የቤተ-መጻሕፍት ንጥሉ።
4. {{ui:ጥቅሉን ስራ}} ን ይጫኑ። የሁኔታ መስመሩ ልዩነቶቹ ሲገነቡ ይቆጥራል፤ አካልዎ አይቀየርም።
5. አንድ ዚፕ ይወርዳል፦ `<part> variants.zip`።

## ማወቅ ጠቃሚ ነገሮች

- **STEP** ትክክለኛ kernel በግንባታዎ ላይ ሲበራ ትክክለኛ ነው። ያለሱ STEP በፋሴት (ጠፍጣፋ ሦስት ማዕዘኖች) ነው፤ README ይህንን ይናገራል።
- **DWG** የ3D ሞዴል ሳይሆን የሥዕል ሉህ ነው። መስመሮቹ ከmesh ይመጣሉ፤ ስለዚህ ጠማማ ጠርዝ ብዙ አጭር መስመሮች ነው።
- **የቤተ-መጻሕፍት ንጥሉ** ለእያንዳንዱ ልዩነት አንድ አካልና አንድ አሻራ ይይዛል፣ በቤተ-መጻሕፍቱ የራሱ ዘንጎች፦ Z ወደ ላይ፣ ፊቱ ወደ −Y፣ እና የማስገቢያ ነጥቡ ከታች በኋለኛው መሃል። እቅዱ የእያንዳንዱ ልዩነት ዙሪያ አራት ማዕዘን ነው። ንጥሉ በ8 MB የተገደበ ነው፤ ስለዚህ በጣም ከባድ ልዩነት በመጠኑ ልክ ሳጥን ይሆናል፣ README ስንቱ እንደሆነ ይናገራል።
- የአካሉ ንቁ ውቅር የንጥሉ ነባሪ ልዩነት ነው።
- ፖርቶች (ለቧንቧና ለቱቦ የግንኙነት ነጥቦች) ከPartCraft አይዘጋጁም።

## ልዩነቶቹን በቤተ-መጻሕፍት ገጽ ላይ ያስቀምጡ

`<part>.item.json` ን በጣቢያው ላይ በ**ቤተ-መጻሕፍት › ስቀል** ይጫኑ። ምድቡን፣ ፈቃዱንና የክሬዲት መስመርዎን ይምረጡ፤ ከዚያ ከልዩነቶቹ ጋር የቤተ-መጻሕፍት ንጥል ይሆናል። በBimCraft ውስጥ ሲያስቀምጡት የትኛው ልዩነት እንደሆነ ይጠይቃል፣ **ቀይር** ሌሎቹን ያቀርባል። ጎብኚዎች አማራጭ የሚመርጡበት፣ 3D የሚያዩበትና ልዩነት የሚያወርዱበት ገጽ ለአሁኑ **ለሠራተኞች ቅድመ-እይታ** ብቻ ነው፦ ለህዝብ ገና ክፍት አይደለም።

## ከትእዛዝ መስመር

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` ውቅሮቹን ይሰይማል፣ `--formats` ከ`step`፣ `ifc`፣ `dwg`፣ `preview` ማንኛውንም፣ `--no-item` የቤተ-መጻሕፍት ንጥሉን ያስቀራል። አቃፊ፣ ዚፕ ወይም ሁለቱንም ይጽፋል፤ ልዩነት መገንባት ካልቻለ 1 ብሎ ይወጣል። ይመልከቱ [ስክሪፕቶችና የትእዛዝ መስመር](topic:scripts-and-cli)።
