የምህንድስና መሣሪያዎቹ (ጀነሬተሮች፣ የምህንድስና ቤተ-መጻሕፍት፣ ፍተሻዎች እና የመረጃ ፋይሎች) **የአስተዳዳሪ መብት አይፈልጉም** እና **ጫኚ አይፈልጉም**። የሚጽፉት እዚህ የተዘረዘረውን ብቻ ነው፣ ሌላ ምንም አይጽፉም።

| ምን | የት ተቀምጧል |
|---|---|
| ክፍሎችዎ፣ ከተፈጠሩት አካሎቻቸው፣ የመረጃ ሉሆቻቸው እና ፍተሻዎቻቸው | እርስዎ ያስቀመጡት የክፍል ፋይል (`.partcraft.json`)፣ ያስቀመጡበት ቦታ። |
| ከፋይሎች የከፈቷቸው ጀነሬተሮች | በመተግበሪያው የራሱ ማከማቻ፦ በድር ገጽ ውስጥ የአሳሹ የአካባቢ ማከማቻ፣ እና በተንቀሳቃሽ Studio ውስጥ ከፕሮግራሙ ቀጥሎ ያለው `data` አቃፊ። ከፍተኛው 20። |
| ቅንብሮች (የቮክሰል መጠኖች፣ የሶልቨር ክሮች፣ አቀማመጡ) | ተመሳሳዩ የመተግበሪያ ማከማቻ። |
| የመረጃ ሉሆች፣ መስኮች፣ ሜሾች | እርስዎ በሚያስቀምጡበት ቦታ ብቻ፦ ውርዱ እርስዎ በመረጡት ቦታ ይሄዳል። |

መሣሪያዎቹ **የራሳቸው የኔትወርክ ጥሪ የላቸውም**፦ የሚላኩት ጀነሬተሮች በመተግበሪያው አቃፊ ውስጥ ያሉ ፋይሎች ናቸው፣ ቤተ-መጻሕፍቱ እና ፍተሻዎቹ ኮምፒውተርዎ ላይ፣ ኔትወርክ መድረስ በማይችል ዎርከር ውስጥ ይሰራሉ፣ የምህንድስና መረጃው (የውሃ እና የአየር ባህሪያት፣ ቁሳቁሶች) በመተግበሪያው ውስጥ ነው። ከፋይል የከፈቱት ጀነሬተር በኮምፒውተርዎ ላይ ይነበባል እና ወደየትም አይሄድም።

## ተንቀሳቃሽ የWindows ዚፕ እና Linux

ተንቀሳቃሽ Studio ለWindows ቅንብሮቹን፣ መሸጎጫዎቹን እና ተጨማሪዎቹን ከፕሮግራሙ ቀጥሎ ባለ `data` አቃፊ ውስጥ ያስቀምጣል። የLinux AppImage ከራሱ ቀጥሎ `portable` የሚባል ፋይል ካለ ቅንብሮቹን ከራሱ ቀጥሎ ያስቀምጣል፤ ያ ፋይል ከሌለ ግን የቤትዎን አቃፊ ይጠቀማል። ተንቀሳቃሽ የMac ቅጽ የለም፦ ሲስተሙ ከወረደ መተግበሪያ ራሱ ቀጥሎ እንዳይጽፍ ይከለክለዋል። የሼሉ የራሱ ተንቀሳቃሽ ማስታወሻዎች (`Studio` እገዛ) ፕሮግራሙ የሚጽፈውን ይዘረዝራሉ።

## የአስተናጋጅ መዳረሻ

እዚህ ምንም **የአስተናጋጅ መዳረሻ** አይጠይቅም። አታሚዎች፣ ተከታታይ ማሽኖች እና USB መሣሪያዎች የተለዩ ናቸው፦ ስራ ሲፈልጋቸው ይጠይቃሉ፣ ለእያንዳንዱ መሣሪያ አንድ ጊዜ፣ እና ጀነሬተሮቹ ወይም ፍተሻዎቹ ምንም አይነኩም።
