በስክሪፕት የስራ ቦታ ያለ ትንተና ተለዋዋጮችን እርስ በርስ የሚሰጡ ጥቂት አጫጭር ስክሪፕቶች ናቸው። ከቅርብ የ[ቤተ-መጻሕፍት](topic:craftscript-library) ተግባር ጀምረው ቅጂ ያድርጉ እና ይቀይሩት፤ ወይም ከታች እንደተገለጸው ቀስ በቀስ ይገንቡት።

## 1. ሜሽ

```
model = part();                  % የምትሞዴሉት ክፍል፣ እንደ ሞዴል
m = tetmesh(model, 4);           % ~4 mm ስፋት ያላቸው tetrahedra
show(m)
```

ከመቀጠልዎ በፊት ሜሹን በእይታው ያረጋግጡ: {{key:F}} ያስማማዋል፣ እና በ**የሚታዩት** ውስጥ ያለው {{ui:ዓይን}} ክፍሉን ይደብቀዋል።

## 2. መሰብሰብ እና መፍታት

የኤለመንት ዑደቱን በስክሪፕቱ ውስጥ ይጻፉ (እንደ መማሪያ መጽሐፍ ያነባል)፣ እና ከባዱን ክፍል ለአብሮ የተሰሩ ተግባራት ይተዉ: ኤለመንት ማትሪክስ፣ ከtriplets የሚሰበሰብ sparse መሰብሰብ፣ እና ከpreconditioner ጋር conjugate gradient ሶልቨር። እንደ `static_tet` ያለ የቤተ-መጻሕፍት ተግባር (ቤተ-መጻሕፍቱ ሲኖረው) ለመቅዳት የተሟላ ምሳሌ ነው።

## 3. ውጤቱን አሳይ

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % በኖድ አንድ እሴት
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- የማብራሪያው ክልል ሊጻፍ ወይም ወደ {{ui:ራስ-ሰር}} ሊመለስ ይችላል።
- በኖድ ላይ ያሉ እሴቶችን ለማንበብ ሜሹን ጠቅ ያድርጉ።
- ተመሳሳይ `'id'` የያዘ ፕሎት በቦታው ይዘምናል፤ ስለዚህ እንዴት እንደሚገጣጠም ለማየት በዑደቱ ውስጥ ያትሙ እና ፕሎት ያድርጉ።

## 4. ያረጋግጡት

የሚታወቅ ነገር ጋር ያወዳድሩ: የካንቲሊቨር የጫፍ መታጠፍ ከ PL³/3EI ጋር፣ ቀዳዳ ያለው ሳህን ከጭንቀት ማጎሪያ ፋክተሩ ጋር፣ ምላሾቹ ከጭነቶቹ ጋር። ፍተሻውን እንደ የራሱ ስክሪፕት ይጻፉት፣ ከእያንዳንዱ ለውጥ በኋላ እንደገና እንዲሰራ:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. ያስቀምጡት

- እያንዳንዱ ደረጃ የራሱ የስክሪፕት ትር ሊሆን ይችላል: ተለዋዋጮችን ይጋራሉ፣ ስለዚህ አንድ በአንድ አስኪዷቸው።
- ስክሪፕቶች በክፍሉ ውስጥ ይቀመጣሉ። ውጤቶቹንም ለማቆየት በ**ተለዋዋጮች** ትሩ ላይ **ተለዋዋጮቹን ከክፍሉ ጋር አስቀምጥ** ይምረጡ (እስከ 32 MB)።
- በስክሪፕት ቡድኑ ውስጥ ያለው {{ui:አስቀምጥ}} ስክሪፕት ያወርዳል ለማጋራት፤ {{ui:ክፈት}} አንዱን ያመጣል።
