ተመሳሳዩ የመሳሪያ መንገድ ለተለያዩ መቆጣጠሪያዎች በተለያየ መንገድ መጻፍ አለበት: የመስመር ቁጥሮች ወይም ምንም፣ `M6` ወይም ቆም ማለት፣ `G28` ወይም `G53`፣ `M30` ወይም `M2`። **ፖስት** እንዴት እንደሚጻፍ የሚናገር አጭር ጽሑፍ ነው። የPartCraft ሦስቱ አብረው የተሰሩ ፖስቶች (Fanuc-style፣ GRBL እና LinuxCNC) በዚህ ቅርጸት ተጽፈዋል፣ ስለዚህ የራስዎ ፖስት ከእነሱ አንዱን በመቅዳት ሊጀምር ይችላል።

ከመቁረጥዎ በፊት ውጤቱን በማሽንዎ የራሱ ሲሙሌተር ያረጋግጡ፣ እና መጀመሪያ ከእቃው በላይ በአየር ላይ ያሩጡት። አብረው የተሰሩ ፖስቶች ይህ ቅርጸት ከመኖሩ በፊት የጻፉትን በትክክል ይጽፋሉ (ፈተናዎቹ በመቶዎች በሚቆጠሩ ፕሮግራሞች ላይ ውጤታቸውን ባይት በባይት ያወዳድራሉ)፣ ነገር ግን እዚህ የተባለው ምንም በማሽንዎ ላይ አልተረጋገጠም፣ እና የቀየሩት ፖስት የእርስዎ ነው፣ የማረጋገጡም ኃላፊነት የእርስዎ ነው።

## አንድ ፖስት መስራት

በ**ማምረት** ውስጥ፣ በ**ፖስት** ስር:

- በአብረው በተሰራ መቆጣጠሪያ ላይ {{ui:ፖስት አርትዕ…}} የእርስዎን **የራስዎን ቅጂ** ይከፍታል። በራስዎ ፖስት ላይ ያ ፖስቱን ይከፍታል።
- {{ui:አዲስ ፖስት…}} በሁሉም ክስተቶች ያሉበት ትንሽ ባዶ ፖስት ይጀምራል።
- {{ui:የፖስት ፋይል አስመጣ…}} `.cpost` የጽሑፍ ፋይል ያነባል (በአርታኢው ውስጥ **እንደ ፋይል አስቀምጥ…** የሚያገኙት ፋይል)።

አርታኢው ጽሑፉን፣ ጽሑፉ ማንበብ እንደሚችል የሚናገርና የተሳሳተውን መስመር የሚያሳይ መስመር፣ እና ሲተይቡ ፖስቱ የሚጽፈውን G-code ያሳያል። **ቅድመ-እይታ በ** ሁሉንም ክስተቶች የሚያሮጥ ትንሽ ናሙና ፕሮግራም ወይም የዚህን ክፍል ራሱ ፕሮግራም ይመርጣል። {{ui:አስቀምጥ}} ፖስቱን በክፍሉ ፋይል ውስጥ ያስቀምጣል (እስከ 20 ፖስቶች) እና እንደ መቆጣጠሪያ ይመርጠዋል። ፖስቶች ከክፍሉ ጋር አብረው ይጓዛሉ፤ በሌላ ክፍል ለመጠቀም እንደ ፋይል ያስቀምጡትና እዚያ ያስመጡት።

## ፖስት ምን ይመስላል

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` የሚጀምሩ መስመሮችና ባዶ መስመሮች ችላ ይባላሉ። ከላይ ቅንብሮቹ ይመጣሉ፤ ከዚያ ለእያንዳንዱ ክስተት አንድ `on <event>` ብሎክ ይመጣል፣ በ`end` ይዘጋል። ያስቀሩት ክስተት ምንም አይጽፍም።

| ቅንብር | ትርጉም |
|---|---|
| `post <id>` | የፖስቱ መለያ: ፊደሎች፣ ቁጥሮች፣ `-` እና `_` |
| `name <text>` | በመቆጣጠሪያዎች ዝርዝር ውስጥ የሚታየው |
| `extension <ext>` | የፋይል ቅጥያ: nc፣ ngc፣ tap … |
| `line-numbers 10` / `off` | በእያንዳንዱ `emit` መስመር ላይ `N10`፣ `N20` … ወይም ምንም |
| `decimal-point yes` / `no` | `10` ፈንታ `10.`። አስተያየቶች ነጥብ አይይዙም |
| `canned-cycles yes` / `no` | `no`: ቀዳዳዎች የሚወክሉት G0/G1 እንቅስቃሴዎች ሆነው ይጻፋሉ |
| `modal <group> <words>` | የቡድኑ ቃላት (`modal motion G0 G1 G2 G3`) ሲለወጡ ብቻ ይጻፋሉ |

## ክስተቶች

ለአንድ ፕሮግራም በዚህ ቅደም ተከተል ይሄዳሉ: `start`፤ ከዚያ ለእያንዳንዱ ኦፕሬሽን `operation`፣ `tool-change` (መሳሪያው ሲቀየር)፣ `spindle` (ፍጥነቱ ሲቀየር)፣ `approach` (ወደ መጀመሪያው ነጥብ የሚደረገው እንቅስቃሴ፣ ከመጀመሪያው ፈጣን እንቅስቃሴ በፊት)፣ `coolant-on`፣ ከዚያም እንቅስቃሴዎቹ እንደ `rapid`፣ `feed` እና `arc`፣ እያንዳንዱ ቋሚ ዑደት እንደ `cycle-start`፣ ለእያንዳንዱ ቀዳዳ አንድ `cycle-hole` እና `cycle-end`፤ በመጨረሻ `end`።

እያንዳንዱ ክስተት የራሱን እንቅስቃሴ ዓይነት ተለዋዋጮች መጠቀም ይችላል፣ በ`{name}` ተጽፈው: የፕሮግራሙ (`name`፣ `program`፣ `setup.axis`፣ `setup.origin`፣ `setup.coolant`)፣ የእቃው (`stock.kind`፣ `stock.d`፣ `stock.sx`፣ `stock.sy`፣ `stock.sz`፣ `stock.minx` … `stock.maxz`)፣ የመሳሪያው (`tool.number`፣ `tool.desc`፣ `tool.kind`፣ `tool.d`፣ `tool.flutes`፣ `tool.fluteLen`)፣ የኦፕሬሽኑ (`op.name`፣ `op.type`)፣ `rpm`፣ የእንቅስቃሴው ነጥብ (`x`፣ `y`፣ `z`፣ `f`፣ እና `moved`: አንድ ዘንግ ሲቀየር እውነት)፣ ቅስቶች (`arc.g` 2 ወይም 3፣ `arc.i`፣ `arc.j`፣ `arc.cx`፣ `arc.cy`) እና ቀዳዳዎች (`hole.x`፣ `hole.y`፣ `hole.z`፣ `hole.r`፣ `hole.q`፣ `hole.return`፣ `hole.first`፣ `cycle.kind`፣ `cycle.init`፣ `feed`)። የአርታኢው **ክስተቶችና ተለዋዋጮች** ዝርዝር የትኛው ክስተት የትኛውን እንደሚያይ ያሳያል። ማንበብና ማዘጋጀት የሚችሏቸው ሁኔታዎች: `cool`፣ `offset`፣ እና `at.x`፣ `at.y`፣ `at.z`፣ `at.f` (የመጨረሻ የተጻፉ እሴቶች)።

## መግለጫዎች

| መግለጫ | ምን ያደርጋል |
|---|---|
| `raw TEXT` | መስመር ልክ እንደተተየበ (የመስመር ቁጥር የለም) |
| `comment TEXT` | `(TEXT)`፣ ASCII ያልሆኑ ፊደሎችና ቅንፎች ተወግደው |
| `emit WORD WORD …` | የቃላት መስመር፤ ባዶ የሚወጡ ቃላት ይቀራሉ፤ ቃል ከሌለ መስመር የለም |
| `word WORD …` | በመገንባት ላይ ላለው መስመር ቃላት ጨምር፤ ባዶ `emit` መስመሩን ይዘጋል |
| `if EXPR` … `else` … `end` | ሁኔታዎች: `a == b`፣ `a != b`፣ `not a`፣ `a and b`፣ `a or b`፣ `a??b` (a፣ ካልሆነ b) |
| `for tool in tools` … `end` | ፕሮግራሙ ለሚጠቀምበት እያንዳንዱ መሳሪያ አንድ ጊዜ |
| `set NAME EXPR` | እሴት አስታውስ (`set offset tool.number`) |
| `reset NAME …` | ሞዳል ቃላትን እርሳ (ቡድን፣ `Z` የመሰለ የአድራሻ ፊደል፣ ወይም `at.z`) |
| `do rapid X Y Z` | ለአንድ ነጥብ የ`rapid` ክስተቱን አሂድ |

ቃል በተተየበ ጽሑፍ ከ`{variable|filter}` ቀዳዳዎች ጋር ነው። ማጣሪያዎቹ `upper`፣ `lower`፣ `pad:N` (በዜሮ መሙላት)፣ `cut:N` (የመጀመሪያዎቹ N ፊደሎች)፣ `safe` (ለአስተያየት ደህና ASCII) እና `int` ናቸው። በ`~` የሚያልቅ ቃል **ሞዳል** ነው: ከመጨረሻ የተጻፈው ሲለይ ብቻ ይጻፋል (`G1~`፣ `X{x}~`)። በ`~!` የሚያልቅ ቃል ሁልጊዜ ይጻፋል፣ አሁንም ይታወሳል። ተለዋዋጭ ያልሆነ ስም ተራ ጽሑፍ ነው (`G81`፣ `mist`)። ቁጥሮች ወደ 0.001 mm ተጠጋግተው ያለ ተከታይ ዜሮዎች ይጻፋሉ።

## ፖስት ማድረግ የማይችለው

ፖስት እንቅስቃሴዎቹ እንዴት እንደሚጻፉ ብቻ ይወስናል፣ ከዚያ በላይ አይደለም። የመሳሪያ መንገዱን ሊቀይር፣ ኦፕሬሽኖችን ሊያስተካክል፣ ቅስትን ሊከፋፍል፣ ዘንግ ሊጨምር፣ የማሽንዎን የጉዞ ክልል ወይም ኪነማቲክስ ሊያውቅ፣ ወይም በመጋጠሚያዎች ላይ ስሌት ሊያደርግ አይችልም (`+` የለም)። ፕሮቢንግ፣ የመሳሪያ ዕድሜ እና ንዑስ ፕሮግራም ዑደቶች፣ የ4ኛና 5ኛ ዘንግ ውጤት እና የላዝ ኮዶች አልተገነቡም። ከሌላ ፕሮግራም የመጣ `.cps`-style የፖስት ፋይል ሊጫን አይችልም: ይህ የተለየ፣ ቀለል ያለ ቅርጸት ነው።
