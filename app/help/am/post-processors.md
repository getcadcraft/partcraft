ተመሳሳይ የመሣሪያ መንገድ ለተለያዩ ቁጥጥሮች በተለየ መንገድ መጻፍ አለበት: የመስመር ቁጥሮች ወይም የሉም፣ `M6` ወይም ቆም ማለት፣ `G28` ወይም `G53`፣ `M30` ወይም `M2`። **ፖስት** እንዴት እንደሚሆን የሚናገር አጭር ጽሑፍ ነው። የPartCraft ሦስቱ አብሮ የተሰሩ ፖስቶች (Fanuc መሰል፣ GRBL እና LinuxCNC) በዚህ ቅርጸት የተጻፉ ናቸው፣ ስለዚህ የራስዎ ፖስት ከአንዱ ቅጂ ሊጀምር ይችላል።

ውጤቱን ከመቁረጥዎ በፊት በማሽንዎ የራሱ ማስመሰያ ያረጋግጡ፣ እና በመጀመሪያ ከጥሬ ዕቃው በላይ በአየር ላይ ያሂዱት። አብሮ የተሰሩ ፖስቶች ከዚህ ቅርጸት በፊት ይጽፉ የነበረውን በትክክል ይጽፋሉ (ፈተናዎቹ ውጤታቸውን በመቶዎች ፕሮግራሞች ላይ በባይት-በባይት ያወዳድራሉ)፣ ነገር ግን እዚህ ምንም በማሽንዎ ላይ አልተረጋገጠም፣ እና የቀየሩት ፖስት የእርስዎ ነው ማረጋገጥ ያለብዎት።

## አንድ ፖስት ይስሩ

በማምረት ውስጥ፣ በ**ፖስት** ስር:

- {{ui:ፖስት አርትዕ…}} በአብሮ በተሰራ ቁጥጥር ላይ **የእርስዎን የራስዎን ቅጂ** ይከፍታል። በእርስዎ የራስዎ ፖስት ላይ ያ ፖስት ይከፈታል።
- {{ui:አዲስ ፖስት…}} በሁሉም ክስተቶች ያለው አነስተኛ ባዶ ፖስት ይጀምራል።
- {{ui:የፖስት ፋይል አስመጣ…}} የ`.cpost` የጽሑፍ ፋይል ያነባል (ከአርታኢው **እንደ ፋይል አስቀምጥ…** የሚያገኙት ፋይል)።

አርታኢው ጽሑፉን፣ ፖስቱ ማንበብ እንደሚችል (እና የትኛው መስመር እንደተሳሳተ) የሚናገር መስመር፣ እና ፖስቱ የሚጽፈውን G-code ሲተይቡ ያሳያል። **ቅድመ-እይታ በ** አነስተኛ ናሙና ፕሮግራም ይመርጣል ሁሉንም ክስተቶች የሚያሂድ፣ ወይም የዚህ ክፍል የራሱ ፕሮግራም። {{ui:አስቀምጥ}} ፖስቱን በክፍሉ ፋይል ውስጥ ይይዛል (እስከ 20 ፖስቶች) እና እንደ ቁጥጥር ይመርጠዋል። ፖስቶች ከክፍሉ ጋር ይጓዛሉ፤ በሌላ ክፍል ለመጠቀም እንደ ፋይል ያስቀምጡ እና እዚያ ያስመጡ።

## ፖስት ምን ይመስላል

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` የሚጀምሩ መስመሮች እና ባዶ መስመሮች ችላ ይባላሉ። በላይ ላይ ቅንብሮቹ ይመጣሉ፤ ከዚያ ለእያንዳንዱ ክስተት `on <event>` ብሎክ፣ በ`end` የሚዘጋ። የተዉት ክስተት ምንም አይጽፍም።

| ቅንብር | ትርጉም |
|---|---|
| `post <id>` | የፖስቱ መለያ: ፊደላት፣ ቁጥሮች፣ `-` እና `_` |
| `name <text>` | በቁጥጥር ዝርዝሩ ውስጥ የሚታየው |
| `extension <ext>` | የፋይል ቅጥያው: nc፣ ngc፣ tap … |
| `line-numbers 10` / `off` | `N10`፣ `N20` … በእያንዳንዱ `emit` መስመር ላይ፣ ወይም ምንም |
| `decimal-point yes` / `no` | `10.` ከ`10` ይልቅ (አስተያየቶች ነጥብ በጭራሽ አይይዙም) |
| `canned-cycles yes` / `no` | `no`: ቀዳዳዎች የሚወክሉት G0/G1 እንቅስቃሴዎች ሆነው ይጻፋሉ |
| `modal <group> <words>` | የቡድን ቃላት (`modal motion G0 G1 G2 G3`) የሚጻፉት ሲለወጡ ብቻ |

## ክስተቶች

ለአንድ ፕሮግራም በዚህ ቅደም ተከተል ይሰራሉ: `start`፤ ከዚያ ለእያንዳንዱ ኦፕሬሽን `operation`፣ `tool-change` (መሣሪያው ሲቀየር)፣ `spindle` (ፍጥነቱ ሲቀየር)፣ `approach` (ወደ መጀመሪያው ነጥብ የሚደረገው እንቅስቃሴ፣ ከመጀመሪያው ፈጣን ጉዞ በፊት)፣ `coolant-on`፣ ከዚያም እንቅስቃሴዎቹ እንደ `rapid`፣ `feed` እና `arc`፣ እና እያንዳንዱ ቋሚ ዑደት እንደ `cycle-start`፣ ለእያንዳንዱ ቀዳዳ አንድ `cycle-hole` እና `cycle-end`፤ በመጨረሻ `end`።

ተጨማሪ ክስተቶች፣ ከሦስት ዘንጎች ባሻገር ለሚሄደው (ያለ ክስተት ፖስቱ እንዲህ ያለውን ፕሮግራም ውድቅ ያደርጋል እና የጎደለውን ክስተት ይጠቅሳል):

| ክስተት | መቼ | ተለዋዋጮቹ |
|---|---|---|
| `index` | ከአንድ ኦፕሬሽን በፊት የመሣሪያ አቅጣጫው ከመጨረሻው የተለየ ሲሆን፣ እና በሮታሪ ዘንጎች ባለ ማሽን ላይ ከመጀመሪያው ኦፕሬሽን በፊት | `rot.a`, `rot.b`, `rot.c` (የሚሄዱባቸው ቦታዎች፤ ማሽኑ የሌለው ዘንግ ባዶ)፣ `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | የኦፕሬሽን እንቅስቃሴዎች ሮታሪ ዘንጎቹ በሚቆርጡበት ጊዜ የሚንቀሳቀሱበት | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (ፊዱ የተገላቢጦሽ ጊዜ መሆን ሲገባው አዎ)፣ `invf` (1/ደቂቃ) |
| `rotary-end` | ከእንደዚህ ያለ ኦፕሬሽን በኋላ | |
| `probe-move` | ፕሮቡ ሲነካ የሚቆም እንቅስቃሴ | `x`, `y`, `z`, `f`, `probe.n` (1 እስከ 4), `probe.axis` (x, y ወይም z), `probe.k` (1, 2 ወይም 3) |
| `probe-set` | ከአንድ ፕሮብ ዑደት ንክኪዎች በኋላ | `probe.kind` (`"z"`, `"x"`, `"y"` ወይም `centre`), `probe.action` (`set` ወይም `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | በላቲ ላይ የክር እንቅስቃሴ | `x`, `z`, `thread.lead` |

ለእያንዳንዱ ክስተት፦ `kin` (none, a, b, ac, bc)፣ `rotary` እና `tcp` (yes ወይም no፣ ከማዋቀር ማሽኑ)፣ `pivot.x`, `pivot.y`, `pivot.z`፣ የኦፕሬሽኑ `op.tilt` እና `op.turn`፣ እና በላቲ ላይ `spin.mode` (css ወይም rpm)፣ `spin.css`፣ `spin.max` እና `tool.nose`። ባዶ እሴት ያለው የፊደል ቃል፣ ለምሳሌ `A{rot.a}` ያለ A ዘንግ ባለ ማሽን ላይ፣ ከመስመሩ ይቀራል። በጥቅስ ምልክቶች መካከል እንደ ጽሑፍ x፣ y እና z ያወዳድሩ (`if probe.kind == "z"`)፤ ያለ ጥቅስ የእንቅስቃሴው መጋጠሚያዎች ናቸው።

በፖስቱ አናት ላይ ሁለት መስመሮች ላቲ-ፖስት ያደርጉታል: `machine lathe` (ከዚያ X እና Z ብቻ ይጽፋል፣ እና የወፍጮ ዱካዎችን ውድቅ ያደርጋል፣ የወፍጮ ፖስት የማዞሪያ ዱካዎችን እንደሚያደርገው) እና `lathe-x diameter` ወይም `lathe-x radius`።

እያንዳንዱ ክስተት የራሱን አይነት እንቅስቃሴ ተለዋዋጮች መጠቀም ይችላል፣ በ`{name}` የተጻፈ፦ ፕሮግራሙ (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`)፣ ጥሬ ዕቃው (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`)፣ መሣሪያው (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`)፣ ኦፕሬሽኑ (`op.name`, `op.type`)፣ `rpm`፣ የእንቅስቃሴው ነጥብ (`x`, `y`, `z`, `f`፣ እና `moved`: አንድ ዘንግ ሲቀየር እውነት)፣ ቅስቶች (`arc.g` 2 ወይም 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) እና ቀዳዳዎች (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`)። የአርታኢው **ክስተቶች እና ተለዋዋጮች** ዝርዝር የትኛው ክስተት የትኛውን እንደሚያይ ያሳያል። የሚነበቡ እና የሚዘጋጁ ሁኔታዎች: `cool`, `offset`, እና `at.x`, `at.y`, `at.z`, `at.f` (የመጨረሻዎቹ የተጻፉ እሴቶች)።

| `comment TEXT` | `(TEXT)` ከASCII ያልሆኑ እና ቅንፎች ተወስደው |
| `emit WORD WORD …` | የቃላት መስመር፤ ባዶ የሚሆኑ ቃላት ይቀራሉ፤ ቃል ከሌለ መስመር የለም |
| `word WORD …` | ቃላትን ወደ እየተገነባ ላለው መስመር ጨምር፤ ባዶ `emit` መስመሩን ይዘጋል |
| `if EXPR` … `else` … `end` | ሁኔታዎች: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a፣ አለበለዚያ b) |
| `for tool in tools` … `end` | ፕሮግራሙ ለሚጠቀምበት እያንዳንዱ መሣሪያ አንድ ጊዜ |
| `set NAME EXPR` | እሴት አስታውስ (`set offset tool.number`) |
| `reset NAME …` | ሞዳል ቃላትን እርሳ (ቡድን፣ እንደ `Z` ያለ የአድራሻ ፊደል፣ ወይም `at.z`) |
| `do rapid X Y Z` | ለአንድ ነጥብ `rapid` ክስተቱን አሂድ |

ቃል በተተየበ ጽሑፍ ከ`{variable|filter}` ቀዳዳዎች ጋር ነው። ማጣሪያዎቹ `upper`, `lower`, `pad:N` (ዜሮ መሙላት), `cut:N` (የመጀመሪያዎቹ N ፊደላት), `safe` (ለአስተያየት ደህንነቱ የተጠበቀ ASCII) እና `int` ናቸው። በ`~` የሚያልቅ ቃል **ሞዳል** ነው: ከመጨረሻው ከተጻፈው የሚለየው ሲሆን ብቻ ይጻፋል (`G1~`, `X{x}~`)። በ`~!` የሚያልቅ ቃል በእያንዳንዱ ጊዜ ይጻፋል እና አሁንም ይታወሳል። ተለዋዋጭ ያልሆነ ስም ተራ ጽሑፍ ነው (`G81`, `mist`)። ቁጥሮች ወደ 0.001 mm ይዞራሉ እና ያለ ተከታይ ዜሮዎች ይጻፋሉ።

## ፖስቱ ምን ማድረግ አይችልም

የእንቅስቃሴዎቹን እንዴት እንደሚጻፉ ብቻ ይወስናል፣ ከዚያ በላይ አይደለም። የመሣሪያ መንገዱን መቀየር፣ ኦፕሬሽኖችን ማዘዝ፣ ቅስትን መክፈል፣ ዘንግ ማከል፣ የማሽኑን ጉዞ ወይም ኪነማቲክስ ማወቅ፣ ወይም በመጋጠሚያዎች ላይ ሂሳብ ማድረግ አይችልም (`+` የለም)። የሮታሪ ቦታዎቹ እራሳቸው ከማዋቀር ውስጥ ከተገለጸው ማሽን ይመጣሉ፣ ከፖስቱ አይደለም፤ ፖስት ምልክታቸውን ወይም ፊደሎቻቸውን መቀየር ይችላል፣ ኪነማቲክሱን አይደለም። የመሣሪያ ዕድሜ እና ንዑስ-ፕሮግራም ዑደቶች አልተሰሩም። ከሌላ ፕሮግራም የ`.cps`-መሰል ፖስት ፋይል መጫን አይቻልም: ይህ የተለየ፣ ቀላል ቅርጸት ነው።
