ቅንብሮቹን ለመክፈት በመተግበሪያው አሞሌ ላይ ያለውን ማርሽ ወይም {{key:Mod+,}} ይጫኑ። የመጀመሪያው ትር {{ui:PartCraft}} የዚህ መተግበሪያ ቅንብሮችን ይይዛል፤ {{ui:General}} ሁሉም የCadCraft መተግበሪያዎች የሚጋሩትን (ገጽታ፣ መሣሪያ አሞሌ፣ ፓነሎች) ይይዛል። የPartCraft ቅንብሮች በመተግበሪያው ውስጥ ብቻ ይኖራሉ፦ እዚህ ይለውጧቸዋል፣ ይህ አሳሽ ያስታውሳቸዋል። {{ui:Reset PartCraft settings}} ሁሉንም ወደ መጀመሪያው ይመልሳል።

## እይታውን ማዞር

- **የግራ አዝራር** (መጀመሪያ)፦ ክፍሉን ለማዞር በግራ አዝራሩ ይጎትቱ፤ ለመንሸራተት በቀኝ ወይም መካከለኛ አዝራር ይጎትቱ።
- **መካከለኛ አዝራር**፦ ክፍሉን ለማዞር ጎማውን ተጭነው ይጎትቱ፤ ለመንሸራተት {{key:Shift}} (ወይም {{key:Ctrl}}፣ ወይም ⌘) ይዘው በመካከለኛ አዝራሩ፣ ወይም በቀኝ አዝራሩ ይጎትቱ። የግራ አዝራሩ ፊቶችን፣ ጠርዞችን እና ፕላኖችን ብቻ ይመርጣል፣ ስለዚህ ትንሽ የሚንቀሳቀስ ጠቅታ ክፍሉን በጭራሽ አያዞርም። ብዙ CAD ፕሮግራሞች በዚህ መንገድ ይሰራሉ።

ጎማው በሁለቱም መንገድ ጠቋሚው ላይ ያጉላል። በስኬች ውስጥ፣ ቀኝ እና መካከለኛ አዝራሮች እንደ በፊቱ ይንሸራተታሉ።

## ማሸብለል፦ የመዳፊት ጎማ ወይም ትራክፓድ

- **ራሱ ይገምት** (መጀመሪያ)፦ PartCraft ማሸብለሉን ይከታተላል። ትራክፓድ እንደሚልከው ወደ ጎን ወይም ጥሩ ማሸብለል ክፍሉን ያዞራል፤ ሙሉ የጎማ ጠቅታዎች ያጉላሉ።
- **የመዳፊት ጎማ**፦ ማሸብለል ሁልጊዜ ወደ ጠቋሚው ያጉላል።
- **ትራክፓድ**፦ ክፍሉን ለማዞር በሁለት ጣቶች ያንሸራትቱ፣ ለመንሸራተት {{key:Shift}} ይያዙ እና ያንሸራትቱ፣ ለማጉላት ቆንጥጠው ያንሸራትቱ። በስኬች ውስጥ ሁለት ጣት ማንሸራተት ስኬቹን ያንሸራትታል።

ቆንጥጦ ማጉላት በሁሉም ምርጫዎች ይሰራል። "ራሱ ይገምት" ለመዳፊትዎ ወይም ለትራክፓድዎ ከተሳሳተ፣ ያለዎትን ይምረጡ። ተጨማሪ በ[ትራክፓድ፣ ንክኪ እና ትናንሽ ስክሪኖች](topic:trackpad-and-touch)።

## ስኬች፦ በመሳል ጊዜ ግንኙነቶችን ጨምር

**በመሳል ጊዜ ግንኙነቶችን ጨምር** (በመጀመሪያ በርቷል)፦ ወደ ነጥብ የሚጣበቅ ጠቅታ አዲሱን ነጥብ ከእሱ ጋር ተጣብቆ ያደርገዋል፣ በኩርባ ላይ ጠቅታ ነጥቡን በዚያ ኩርባ ላይ ያደርገዋል፣ እና በቅርብ ደረጃ ወይም ቀጥ ብሎ የተሳለ መስመር አግድም ወይም ቀጥ ይሆናል። [ግንኙነቶች እና ልኬቶች](topic:relations-dimensions) ይመልከቱ።

ጂኦሜትሪን ከሌላ ጂኦሜትሪ ጋር ሳያያይዙ በአቅራቢያ ማስቀመጥ ሲፈልጉ ያጥፉት። ጠቋሚው አሁንም ወደ ነጥቦች እና ኩርባዎች ይጣበቃል፣ ነገር ግን ምንም አይያያዝም፦ በሰንሰለት የተሳሉ መስመሮች ጫፎቻቸውን አይጋሩም፣ ስለዚህ መጎተት ሊለያያቸው ይችላል። የሚፈልጓቸውን ግንኙነቶች ከቀኝ ፓነል እራስዎ ይጨምሩ። የተዘጋ መገለጫ ጫፎቹ ሲገናኙ አሁንም ይወጣል።

## ስኬች፦ በመሳል ጊዜ ልኬት ስጥ

**በመሳል ጊዜ ልኬት ስጥ** (በመጀመሪያ በርቷል)፦ መስመር፣ አራት ማዕዘን፣ ክብ ወይም ቅስት በሚሳልበት ጊዜ ቁጥር መጻፍ ከጠቋሚው ጎን ያለውን የመጠን ሳጥን ይሞላል ({{key:Tab}} ወደ ቀጣዩ ሳጥን ይሄዳል)፣ {{key:Enter}} ቅርጹን በዚያ መጠን ይስላል፣ ለተጻፈው እያንዳንዱ መጠን የሚመራ ልኬት ይዞ። ሲጠፋ፣ በሚስሉበት ጊዜ ቁጥር መጻፍ ምንም አያደርግም፣ ቅርጾች በጠቅታ ብቻ ይሳላሉ። [መጠኑን በመሳል ጊዜ ይጻፉ](topic:sketch-basics#type-the-size-as-you-draw) ይመልከቱ።

## የማዕዘን አመልካች

በ3D እይታው ጥግ ላይ የሚታየው፦ **የእይታ ኩብ** (በመጀመሪያ፤ ከላይ በቀኝ — ፊት፣ ጠርዝ ወይም ጥግ ጠቅ ያድርጉ ከዚያ ለመመልከት፣ ለማዞር ይጎትቱት፣ የኮምፓስ ቀለበቱን ይጎትቱ ሞዴሉን ለማዞር)፣ **የዘንግ አዶ** (ከታች ግራ ያለ ትንሽ X፣ Y፣ Z ምልክት ከእይታው ጋር የሚዞር፦ X ቀይ፣ Y አረንጓዴ፣ Z ሰማያዊ) ወይም **ምንም**። ከእነዚህ ሁለቱም አንዳቸውም በስኬች ሲሳሉ ወይም በስዕል ሉህ ላይ አይታዩም። [የእይታ ኩብ](topic:view-cube) ይመልከቱ።

## የሶልቨር ክሮች

የማስመሰል ሶልቨሮች ስንት ክሮች መጠቀም እንደሚችሉ። **ራስ-ሰር** (መጀመሪያ) ከኮምፒውተሩ ሎጂካዊ ፕሮሰሰሮች አንዱን ያነሰ ይወስዳል (ከ16 ያልበለጠ)፣ ስለዚህ ጥናት በሚፈታ ጊዜ ገጹ ምላሽ ይሰጣል፤ ወይም ቁጥር ይምረጡ። ትላልቅ ቮክሰል ጥናቶች፣ ባክሊንግ፣ በጊዜ ሂደት ውጥረት እና ፍሰት በብዙ ክሮች ፈጣን ይፈታሉ (በ4 ክሮች ለ80,000 ኩቦች በእኛ ልኬቶች ~2× ገደማ፣ በስራ ፈት ኮምፒውተር ላይ ይበልጣል)፤ ከ20,000 ያነሱ ያልታወቁ ያላቸው ሞዴሎች በአንድ ክር ይቆያሉ፣ ምክንያቱም ክሮችን መጀመር ከሚያድኑት ይበልጣል። ከብዙ ክሮች የሚገኝ መፍትሄ ከአንድ ክር ጋር ተመሳሳይ መልስ ይሰጣል (እስከ ማጠጋጋት፤ ድምሮቹ በተለያየ ቅደም ተከተል ስለሚጨመሩ)። የእያንዳንዱ ጥናት ውጤቶች **N ክሮች** ወይም **1 ክር** ከምክንያቱ ጋር በ**ሶልቨር** ስር ያሳያሉ።

ክሮች ገጹ **cross-origin isolated** እንዲሆን ይፈልጋሉ (አሳሹ ሰራተኞች ማህደረ ትውስታን የሚጋሩት ያን ጊዜ ብቻ ነው)። የላብ ገጹ እንደዚያ ነው፤ ካልሆነ ቅንብሩ ይነግራል ("This page is not cross-origin isolated, so solvers run on one thread whatever is chosen here.") እና እያንዳንዱ መፍትሄ አንድ ክር ይጠቀማል። ሌላው ሁሉ እንደዚሁ ይሰራል፣ መልሶቹም ተመሳሳይ ናቸው።

የላሚናር ፍሰት ጥናቶችም ክሮቹን ይጠቀማሉ (ለ54,000 የፈሳሽ ሴሎች በ4 ክሮች ~2.5× ገደማ፣ እስከ መጨረሻው አሃዝ ተመሳሳይ መልስ)። የኳድራቲክ ቴትራሄድሮን ሶልቨር እና የሙቀት ማስተላለፍ በአንድ ክር ይሰራሉ፦ በሙከራ ኮምፒውተራችን ላይ በክር ማድረግ ቀርፋፋ ሆኖ ተገኝቷል (ሶልቨሮቻቸው በማህደረ ትውስታ ፍጥነት እና ሊከፈል በማይችል ደረጃ የተገደቡ ናቸው)።

### በገዛ የድር አገልጋይዎ ላይ

PartCraftን ከራስዎ አገልጋይ የሚያሄዱ ከሆነ፣ እንደተገለገለ ይሰራል። ለሶልቨር ክሮች፣ አገልጋዩ ለPartCraft ገጽ ሁለት ራስጌዎችን እንዲልክ ያድርጉ፦

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

በApache፣ በአቃፊው `.htaccess` ውስጥ (mod_headers ያስፈልጋል)፦

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

በnginx፣ PartCraftን በሚያገለግለው `location` ውስጥ፦

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

ገጹን እንደገና ይጫኑ፦ ቅንብሮች › የሶልቨር ክሮች ከኮምፒውተርዎ ቁጥር ጋር **ራስ-ሰር** ያቀርባል። ሁለተኛው ራስጌ ገጹ ከሌላ ጣቢያ የሚጭነውን እና የማይፈቅድለትን አሳሹ አይቀበልም፤ ይህ PartCraft ለብቻው ለሚሰራ ጥሩ ነው (ሁሉንም ከራሱ አቃፊ ይጭናል)።
