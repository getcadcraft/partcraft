Python የ[የስክሪፕት የስራ ቦታ](topic:craftscript) ሶስተኛ ቋንቋ ነው። **Python**ን ከአርታኢው በላይ ባለው የቋንቋ ሳጥን ይምረጡ (`.py` ፋይል በራሱ በPython ይከፈታል)። Python፣ Lua እና CraftScript ተመሳሳይ ተለዋዋጮች እና አብሮ የተሰሩ ተግባራት ይጋራሉ፣ ስለዚህ የPython ስክሪፕት የCraftScript ስክሪፕት የሰራውን ሊጠቀም ይችላል፣ እና በተቃራኒው።

በዚህ ጉብኝት የመጀመሪያው የPython ሩጫ Python ራሱን (CPython 3.14፣ ወደ 7 MB) ከዚህ ጣቢያ ይጭናል፤ ይህም ጥቂት ሰከንዶች ይወስዳል። Python ገና የ{{ui:ከመስመር ውጭ አስቀምጥ}} አካል አይደለም: መጀመሪያ አንድ የPython ስክሪፕት በመስመር ላይ ያሂዱ።

## Python ታሽጓል

የPython ስክሪፕቶች እንደ CraftScript እና Lua ስክሪፕቶች ታሽገዋል: ክፍሉን፣ ተለዋዋጮቹን እና አብሮ የተሰሩ ተግባራትን ብቻ ይደርሳሉ፣ ሌላ አይደርሱም። እያንዳንዱ ሩጫ በራሱ ሳንድቦክስ ውስጥ አዲስ Python ነው፣ በማህደረ ትውስታ ውስጥ ትንሽ የፋይል ዛፍ ያለው (መደበኛ ቤተ-መጻሕፍቱ እና ከሩጫው በኋላ የሚጠፋ `/tmp` ፎልደር)። ወደ ኔትወርክ፣ ወደ ፋይሎችዎ ወይም ወደ ቀሪው ገጽ መድረስ አይችልም፤ በአሳሹም ሆነ በትዕዛዝ መስመር ላይ። ከሌላ ሰው የመጣ ስክሪፕት አሁንም ብዙ ጊዜ ወይም ማህደረ ትውስታ ሊወስድ ይችላል: {{ui:አቁም}} ያቆመዋል።

## መሰረታዊ ነገሮች

```
A = cs.magic(3)              # አብሮ የተሰራ ተግባር ሁሉ cs.<name> ነው
B = A @ A.T                  # @ የማትሪክስ ውጤት ነው፣ .T ትራንስፖዝ
C = A * 2 + 1                # + - * / ** ኤለመንት በኤለመንት ናቸው፣ እንደ numpy
print(A[0, 1], A[-1, -1])    # ከ0 ይጀምራል፤ አሉታዊ ከመጨረሻ ይቆጥራል
row = A[1]                   # በማትሪክስ ላይ አንድ ኢንዴክስ: ረድፍ
big = A[A > 4]               # ሎጂካዊ ማስክ ኤለመንቶችን ይመርጣል
A[0, 0] = -5                 # ወደ አደራደር መመደብ
V, D = cs.call('eig', 2, A)  # ብዙ ውጤቶች: cs.call(name, ስንት, …)
```

- 1 × 1 አደራደር እንደ ተራ ቁጥር ይደርሳል፤ ሌሎች አደራደሮች፣ sparse ማትሪክሶች፣ ሜሾች፣ ፊልዶች እና ሞዴሎች **Values** ናቸው።
- Value `shape` (tuple)፣ `T`፣ `type`፣ `numel()`፣ `copy()`፣ `tolist()`፣ `len()` (ረድፎቹ)፣ እና ለአንድ ኤለመንት `float()`፣ `int()` እና `bool()` አሉት።
- ንጽጽሮች (`<`, `==`, …) እንደ numpy ኤለመንት በኤለመንት ናቸው፤ ሎጂካዊ Value ይሰጣሉ።
- ቁጥሮች ዝርዝር ለአብሮ የተሰራ ተግባር ሲሰጡ አደራደር ይሆናሉ: `cs.sum([1, 2, 3])`። `cs.tensor([[1, 2], [3, 4]])` ማትሪክስ ይሰራል።
- dict struct ይሆናል፣ የተደባለቁ ነገሮች ዝርዝር cell ይሆናል፣ እና ወደ ኋላም።

ስክሪፕትዎ የሚሰራው እያንዳንዱ ግሎባል (ቁጥር፣ Value፣ dict፣ ዝርዝር…) ሩጫው ሲያልቅ በ**ተለዋዋጮች** ትር ውስጥ ይገባል፣ ስህተት ቢኖርም። `_` የሚጀምሩ ስሞች፣ ተግባራት፣ ክፍሎች እና ሞጁሎች በPython ይቀራሉ። `ws.name` ተለዋዋጭን በቀጥታ ያነባል ወይም ያዘጋጃል፣ እና `ws_names()` ይዘረዝራቸዋል።

`print(…)` ወደ ኮንሶሉ ይጽፋል። `display(…)` (ወይም `cs.display`) ሜሽ፣ ፊልድ ወይም ፕሎት ያሳያል፣ እንደ CraftScript።

## የትንተና ቤተ-መጻሕፍትን መጥራት

የቤተ-መጻሕፍት ተግባራት እንደ አብሮ የተሰሩ ይጠራሉ: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`። ስሙን በስክሪፕቱ ውስጥ እንዳለ ይጻፉ: PartCraft ስክሪፕቱ ከመሄዱ በፊት የሚጠቀምባቸውን የቤተ-መጻሕፍት ተግባራት ያገኛል።

## ገና አልተካተተም

- numpy፣ scipy እና ሌሎች ፓኬጆች: የPython የራሱ መደበኛ ቤተ-መጻሕፍት ብቻ (`math`, `json`, `itertools`, `decimal`, `statistics`…) እዚህ አለ፣ ያለ መስኮት፣ ተርሚናል እና ዳታቤዝ ክፍሎቹ (`tkinter`, `curses`, `sqlite3`)።
- Sockets እና ወደ ውጭ የሚደርስ ማንኛውም ነገር: Python እዚህ ኔትወርክ የለውም።
- `time.sleep` ወዲያውኑ ይመለሳል።
- በአርታኢው ውስጥ መታጠፍ፣ እና ከCraftScript ስክሪፕት የPython ተግባርን መጥራት።
- ሩጫው የመመሪያ በጀቱን እና አቁም ን በየ1000 መስመሮች ይፈትሻል፤ በአንድ አብሮ የተሰራ ተግባር ውስጥ ያለ ረጅም ስሌት መጀመሪያ ይጨርሳል።
