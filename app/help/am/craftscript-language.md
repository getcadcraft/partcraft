CraftScript ማትሪክስ ላይ የተመሠረተ ቋንቋ ነው፤ MATLAB ን ለማንበብ እንዲቀል ተደርጎ የተጻፈ ነው። ስለዚህ አብዛኛዎቹ ክላሲክ የቁጥር ኮዶች (ለምሳሌ ባለ 88 መስመሩ የቶፖሎጂ ማመቻቸት ኮድ) በትንሽ ለውጦች ብቻ ይሰራሉ። በ[የስክሪፕት የስራ ቦታ](topic:craftscript) ውስጥ እና ከትዕዛዝ መስመር ይሰራል።

## እሴቶች

| ዓይነት | ምሳሌ | ማስታወሻ |
|---|---|---|
| ቁጥር፣ አደራደር | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ሁሉም ቁጥር አደራደር ነው (1×1 አደራደር)። አደራደሮች በአምድ-በአምድ ይቀመጣሉ፣ እስከ 8 ልኬቶች |
| ሎጂካል | `A > 2`, `true` | የእውነት/ሐሰት አደራደሮች፤ እንደ ኢንዴክስ ያገለግላሉ |
| ጽሑፍ | `'beam'`, `"beam"` | |
| Sparse ማትሪክስ | `sparse(i, j, v, n, n)` | ለጥንካሬ ማትሪክስ |
| ሜሽ፣ ፊልድ፣ ሞዴል | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` የሚስለው |
| Struct | `s.E = 210e3` | የተሰየሙ መስኮች |
| Cell | `c = {1, 'two', [3 4]}` | የማንኛውም እሴቶች ዝርዝር |
| የተግባር መያዣ | `f = @(x) x.^2` | |

## አደራደሮች እና ኢንዴክስ ማድረግ

- ክልሎች: `1:5`, `0:0.1:1`። `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`።
- ኢንዴክስ ማድረግ ከ1 ይጀምራል: `A(2, 3)`, `v(end)`, `A(:, 1)` (ሙሉ አምድ), `A(:)` (ሁሉንም እንደ አንድ አምድ), `v(v > 0)` (ሎጂካዊ ኢንዴክስ)።
- ከመጨረሻው ውጭ መመደብ አደራደሩን ያሰፋዋል፣ እንደ MATLAB: `v(10) = 1`።

## ኦፐሬተሮች

- `+ - * / \ ^` የማትሪክስ ክዋኔዎች ናቸው (`A \ b` ይፈታል)፤ `.* ./ .^` ኤለመንት በኤለመንት ይሰራሉ። `'` ትራንስፖዝ ያደርጋል።
- ንጽጽሮች `== ~= < <= > >=`፤ ሎጂክ `& | ~` (ኤለመንት በኤለመንት) እና `&& ||` (አጭር ዙር)።

## የቁጥጥር ፍሰት እና ተግባራት

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ተግባራት በስክሪፕቱ ውስጥ ከትዕዛዞቹ በኋላ፣ ወይም በራሳቸው የስክሪፕት ትር ውስጥ በተግባሩ ስም ይቀመጣሉ:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ስም የሚፈለገው በዚህ ቅደም ተከተል ነው: ተለዋዋጭ፣ በዚህ ክፍል ውስጥ ያ ስም ያለው ስክሪፕት፣ የቤተ-መጻሕፍት ተግባር፣ አብሮ የተሰራ ተግባር።

## Echo፣ አስተያየቶች፣ ውጤት

- ከ`;` ውጭ ያለ መግለጫ እሴቱን ያትማል፤ `;` ጸጥ ያደርገዋል።
- `%` አስተያየት ይጀምራል፤ `%{` እና `%}` በራሳቸው መስመሮች ላይ ያሉ መስመሮችን ያግዳሉ።
- `disp(x)`፣ `fprintf('%g\n', x)` እና `display(x)` ወደ ኮንሶሉ ያትማሉ።

## ስህተቶች እና ገደቦች

- ስህተቶች ምን እንደተፈጠረ በቀላል ቃላት ይናገራሉ፣ እና መስመሩን (እና የተግባር ጥሪዎች ሰንሰለትን) ያሳያሉ።
- እያንዳንዱ ሩጫ የእርምጃ በጀት አለው (በፓነሉ ውስጥ ያሉ የሩጫ አማራጮች)። ማለቂያ የሌለው ዑደት በመልዕክት ይቆማል፣ ወይም አቁም ን ይጫኑ።
- አደራደሮች እያንዳንዳቸው እስከ 134 ሚሊዮን እሴቶችን ይይዛሉ።

## ከMATLAB የተለየ

- የፕሎት ትዕዛዞች አማራጮቻቸውን በጥሪው ውስጥ ያስቀምጣሉ: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`። `figure`, `hold`, `axis`, `title(…)` እና መሰል ተቀባይነት አላቸው እና ምንም አያደርጉም።
- `input` እና `keyboard` አይደገፉም: ስክሪፕት ጥያቄ ለመጠየቅ መቆም አይችልም።
- ቱልቦክሶች የሉም፤ [የትንተና ቤተ-መጻሕፍት](topic:craftscript-library) እና አብሮ የተሰሩ ተግባራት ብቻ ናቸው ያሉት።
