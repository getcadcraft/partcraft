CraftScript एक मैट्रिक्स भाषा है जो MATLAB जैसी पढ़ी जाए, इसलिए ज़्यादातर पारंपरिक संख्यात्मक कोड (उदाहरण के लिए 88-पंक्ति वाला टोपोलॉजी ऑप्टिमाइज़ेशन कोड) थोड़े-से बदलावों के साथ चल जाते हैं। यह [स्क्रिप्ट वर्कस्पेस](topic:craftscript) में और कमांड लाइन से चलती है।

## मान

| प्रकार | उदाहरण | टिप्पणियाँ |
|---|---|---|
| संख्या, ऐरे | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | हर संख्या एक ऐरे है (1×1 वाला)। ऐरे कॉलम-दर-कॉलम संग्रहीत होते हैं, 8 आयाम तक |
| लॉजिकल | `A > 2`, `true` | सही/गलत के ऐरे; इंडेक्स के रूप में इस्तेमाल हो सकते हैं |
| टेक्स्ट | `'beam'`, `"beam"` | |
| स्पार्स मैट्रिक्स | `sparse(i, j, v, n, n)` | कठोरता मैट्रिक्स के लिए |
| मेश, फ़ील्ड, मॉडल | `hexGrid(…)`, `part()`, `load('part.stl')` | जो `show` दिखाता है |
| स्ट्रक्चर | `s.E = 210e3` | नामित फ़ील्ड |
| सेल | `c = {1, 'two', [3 4]}` | किसी भी मान की सूची |
| फ़ंक्शन हैंडल | `f = @(x) x.^2` | |

## ऐरे और इंडेक्सिंग

- रेंज: `1:5`, `0:0.1:1`। `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`।
- इंडेक्सिंग 1 से शुरू होती है: `A(2, 3)`, `v(end)`, `A(:, 1)` (पूरा कॉलम), `A(:)` (सब कुछ एक कॉलम में), `v(v > 0)` (लॉजिकल इंडेक्सिंग)।
- आख़िरी से आगे असाइन करने पर ऐरे बढ़ जाता है, MATLAB की तरह: `v(10) = 1`।

## ऑपरेटर

- `+ - * / \ ^` मैट्रिक्स संक्रियाएँ हैं (`A \ b` हल करता है); `.* ./ .^` एक-एक एलिमेंट पर काम करते हैं। `'` ट्रांसपोज़ करता है।
- तुलना `== ~= < <= > >=`; लॉजिक `& | ~` (एक-एक एलिमेंट पर) और `&& ||` (शॉर्ट-सर्किट)।

## नियंत्रण प्रवाह और फ़ंक्शन

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

फ़ंक्शन स्क्रिप्ट में उसके कमांड के बाद रखे जाते हैं, या फ़ंक्शन के नाम वाले अपने अलग स्क्रिप्ट टैब में:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

किसी नाम को इस क्रम में खोजा जाता है: एक वेरिएबल, इस पार्ट में उसी नाम की एक स्क्रिप्ट, एक लाइब्रेरी फ़ंक्शन, एक अंतर्निर्मित फ़ंक्शन।

## इको, टिप्पणियाँ, आउटपुट

- बिना `;` वाला स्टेटमेंट अपना मान प्रिंट करता है; `;` उसे शांत रखता है।
- `%` से टिप्पणी शुरू होती है; अपनी-अपनी लाइन पर `%{` और `%}` उनके बीच की लाइनों को टिप्पणी बना देते हैं।
- `disp(x)`, `fprintf('%g\n', x)` और `display(x)` कंसोल पर प्रिंट करते हैं।

## त्रुटियाँ और सीमाएँ

- त्रुटियाँ सरल शब्दों में बताती हैं कि क्या गलत हुआ, और लाइन (और फ़ंक्शन कॉल की श्रृंखला) भी देती हैं।
- हर रन का एक स्टेप बजट होता है (पैनल में Run options देखें); अनंत लूप एक संदेश के साथ रुकता है, या आप {{ui:Stop}} दबा सकते हैं।
- हर ऐरे में 134 मिलियन मान तक हो सकते हैं।

## MATLAB से अलग

- प्लॉट कमांड अपने विकल्प कॉल के अंदर रखते हैं: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`। `figure`, `hold`, `axis`, `title(…)` और ऐसे ही फ़ंक्शन स्वीकार होते हैं और कुछ नहीं करते।
- `input` और `keyboard` समर्थित नहीं हैं: स्क्रिप्ट रुककर कोई सवाल नहीं पूछ सकती।
- कोई टूलबॉक्स नहीं है; [विश्लेषण लाइब्रेरी](topic:craftscript-library) और अंतर्निर्मित फ़ंक्शन ही उपलब्ध हैं।
