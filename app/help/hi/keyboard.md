पैनल के किसी बॉक्स में टाइप करते समय कीज़ कुछ नहीं करतीं, सिवाय {{key:Mod+S}} और {{key:Mod+O}} के, जो हमेशा काम करती हैं। अक्षर कीज़ बिना मॉडिफ़ायर के काम करती हैं.

ब्राउज़र में कीज़ और फ़ंक्शन कीज़ के बिना कीबोर्ड के बारे में आम नोट्स: [कीज़, माउस और ट्रैकपैड](common:keys).

## हर जगह

| कीज़ | क्रिया |
|---|---|
| {{key:Mod+S}} | पार्ट सहेजें (असेंबली में: असेंबली)। पहले खुला स्केच बंद करता है |
| {{key:Mod+O}} | पार्ट या असेंबली फ़ाइल खोलें (यदि बिना सहेजे बदलाव हैं तो पहले पूछता है) |
| {{key:Mod+Z}} | पूर्ववत करें |
| {{key:Mod+Y}} या {{key:Mod+Shift+Z}} | फिर से करें |
| {{key:F1}} | यह सहायता खोलें या बंद करें (ऐप बार में {{ui:सहायता}} भी)। {{key:Esc}} से भी यह बंद होती है। कई लैपटॉप और Mac कीबोर्ड पर Fn दबाए रखें |
| {{key:Ctrl+Shift+F}} | स्क्रीन मोड: सामान्य, पूर्ण स्क्रीन, बार छिपाकर पूर्ण स्क्रीन। Mac पर भी Control, ⌘ नहीं |
| {{key:Esc}} | पूर्ण स्क्रीन से बाहर निकलें (पूर्ण स्क्रीन में होने पर) |
| {{key:Mod+,}} | सेटिंग्स, जिसमें PartCraft टैब भी है (देखें [PartCraft सेटिंग्स](topic:settings)) |

पैनल के संख्या बॉक्स में {{key:Mod+Z}} ब्राउज़र का अपना टेक्स्ट पूर्ववत करना है। स्केच डाइमेंशन के ऊपर वाले संख्या बॉक्स में यह PartCraft में पूर्ववत करता है.

## कॉपी, पेस्ट और डुप्लिकेट बनाना

ये उसी पर काम करती हैं जिसमें आप काम कर रहे हैं: खुले स्केच में चुनी गई ज्यामिति, हिस्ट्री में चुनी गई फ़ीचर, या असेंबली में चुना गया पार्ट। विवरण [कॉपी, पेस्ट और डुप्लिकेट बनाना](topic:copy-paste) में।

| कीज़ | क्रिया |
|---|---|
| {{key:Mod+C}} | चुनी हुई चीज़ कॉपी करें |
| {{key:Mod+X}} | काटें: पहले कॉपी, फिर मिटाएँ |
| {{key:Mod+V}} | चिपकाएँ। स्केच में कॉपी पॉइंटर के साथ चलती है: जहाँ जाना है वहाँ क्लिक करें |
| {{key:Mod+Shift+V}} | उसी जगह चिपकाएँ: वही निर्देशांक (असेंबली में, वही जगह) |
| {{key:Mod+D}} | डुप्लिकेट बनाएँ: एक चरण में कॉपी और चिपकाना, क्लिपबोर्ड अछूता रहता है |
| {{key:Mod+A}} | सभी चुनें (स्केच में) |
| {{key:Esc}} | चयन हटाएँ (और पॉइंटर के साथ चलने वाला पेस्ट रद्द करें) |

संख्या बॉक्स में ये कीज़ सामान्य रूप से टेक्स्ट कॉपी और पेस्ट करती हैं। पैनल में चुना गया टेक्स्ट ब्राउज़र कॉपी करता है.

## पार्ट पर (कोई स्केच खुला नहीं)

| कीज़ | क्रिया |
|---|---|
| {{key:S}} | चुने गए तल या समतल फ़ेस पर स्केच करें; कुछ न चुना हो तो क्लिक करके जगह चुनें |
| {{key:F}} | पार्ट को व्यू में फ़िट करें |
| {{key:M}} | मापें, हर वर्कस्पेस और असेंबली में; {{key:Esc}} चुने गए बिंदु साफ़ करता है, {{key:Esc}} फिर से इसे बंद करता है (देखें [दूरी, कोण और द्रव्यमान मापें](topic:measure)) |
| {{key:X}} | सेक्शन व्यू चालू या बंद करें, हर वर्कस्पेस और असेंबली में; {{key:Esc}} इसे बंद करता है (देखें [सेक्शन व्यू से अंदर देखें](topic:section-view)) |
| {{key:Delete}} | चुनी हुई फ़ीचर हटाएँ (यदि उसे दूसरे भी इस्तेमाल करते हैं तो पूछता है) |
| {{key:0}} … {{key:9}}, {{key:.}} | फ़ीचर चुनी होने पर: उसकी मुख्य संख्या लिखें (एक्सट्रूड की गहराई, होल का व्यास, पैटर्न की गिनती, फ़िलेट की त्रिज्या …), फिर {{key:Enter}}। {{key:Esc}} पुरानी संख्या रखता है |
| {{key:Backspace}} | चुनी हुई फ़ीचर हटाएँ, जब कोई चुनी हो |
| {{key:Esc}} | स्केच तल चुनना बंद करें, या चयन साफ़ करें ({{key:Shift}} से चुने गए एज या फ़ेस सहित) |

## 3D व्यू में

पहले व्यू में क्लिक करें ताकि कीबोर्ड फ़ोकस उसके पास आए।

| कीज़ | क्रिया |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | व्यू को 15 डिग्री घुमाएँ |
| {{key:Shift+Left}} और बाकी तीर | पैन करें |
| {{key:Plus}} या {{key:=}} | ज़ूम इन |
| {{key:Minus}} | ज़ूम आउट |

| माउस | क्रिया |
|---|---|
| बायाँ बटन दबाकर खींचें | व्यू घुमाएँ (ऑर्बिट) |
| दायाँ या बीच का बटन दबाकर खींचें | पैन करें |
| बायाँ बटन खींचते समय {{key:Shift}}, {{key:Ctrl}} या ⌘ दबाए रखें | पैन करें |
| व्हील घुमाएँ | पॉइंटर पर ज़ूम (आपसे दूर घुमाने पर ज़ूम इन) |
| ट्रैकपैड पर दो उंगलियों का स्वाइप | व्यू घुमाएँ; {{key:Shift}} के साथ पैन करें। पिंच से ज़ूम। यह [PartCraft सेटिंग्स](topic:settings) में **स्क्रॉलिंग** से तय होता है |

[PartCraft सेटिंग्स](topic:settings) में **व्यू घुमाना: बीच का बटन** चालू होने पर बीच का बटन व्यू घुमाता है, बीच के बटन या दाएँ बटन के साथ {{key:Shift}} पैन करता है, और बायाँ बटन केवल चुनता है.
| क्लिक | फ़ेस चुनें (वह पूरा हाइलाइट होता है), एज या तल चुनें |
| {{key:Shift}}+क्लिक एज या फ़ेस पर | कई एज या फ़ेस इकट्ठा करें |
| खाली जगह पर क्लिक करें | चयन साफ़ करें |

## फ़िलेट, चैम्फ़र या शेल के लिए एज या फ़ेस चुनते समय


| कीज़ या माउस | क्रिया |
|---|---|
| एज या फ़ेस पर क्लिक करें | उसे जोड़ें, या यदि पहले से है तो हटाएँ |
| {{key:Esc}} या {{key:Enter}} | चुनना समाप्त करें ({{ui:हो गया}} की तरह ही) |
| {{key:F}} | फ़िट करें |
| तीर कीज़, व्यू फ़ोकस में होने पर | घुमाएँ; {{key:Shift}} के साथ पैन करें |

| माउस | क्रिया |
|---|---|

| खाली जगह पर खींचें (चुनें) | विंडो: पूरी तरह अंदर की हर चीज़ चुनता है |
| बिंदु, लाइन या वृत्त की एज खींचें (चुनें) | उसे हिलाएँ; संबंध बने रहते हैं |
| डाइमेंशन की संख्या खींचें (चुनें) | लेबल हिलाएँ |
| डाइमेंशन पर डबल-क्लिक करें | उसका मान बदलें |

| दायाँ या बीच का बटन दबाकर खींचें | पैन करें |
| व्हील घुमाएँ | पॉइंटर पर ज़ूम |

| {{key:Mod+Shift+[}} / {{key:Mod+Shift+]}} | कर्सर वाला ब्लॉक फ़ोल्ड / अनफ़ोल्ड करें (function, if, for, while … end) |
| {{key:Mod+Space}} | आप जो नाम टाइप कर रहे हैं उसके सुझाव दिखाएँ (दो अक्षर के बाद भी खुलता है); {{key:Up}} / {{key:Down}} से चुनें, {{key:Enter}} या {{key:Tab}} से एक लें, {{key:Esc}} बंद करता है |
| कंसोल के नीचे की पंक्ति में {{key:Enter}} | वह एक स्टेटमेंट चलाएँ; {{key:Up}} और {{key:Down}} से पहले के स्टेटमेंट वापस लाएँ |

## ब्राउज़र जो शॉर्टकट ले सकता है

- Safari में {{key:Mod+Y}} हिस्ट्री खोल सकता है: फिर से करने के लिए {{key:Mod+Shift+Z}} इस्तेमाल करें।
- {{key:Mod+D}} ब्राउज़र की बुकमार्क कीज़ है: ऐप फ़ोकस में होने पर PartCraft इसे लेता है, और बॉक्स में टाइप करते समय इसे छोड़ देता है।
- {{key:F11}} और {{key:Mod+Plus}} / {{key:Mod+Minus}} ब्राउज़र की पूर्ण स्क्रीन और पेज ज़ूम हैं, PartCraft के नहीं। पूर्ण स्क्रीन के लिए {{key:Ctrl+Shift+F}} और मॉडल के लिए व्हील इस्तेमाल करें।
- कई लैपटॉप और Mac पर फ़ंक्शन कीज़ के लिए Fn कुंजी चाहिए: सहायता के लिए Fn+{{key:F1}} दबाएँ, या {{ui:सहायता}} बटन इस्तेमाल करें।

टच और ट्रैकपैड इशारे: [ट्रैकपैड, टच और छोटी स्क्रीन](topic:trackpad-and-touch).

## हिलाने का विकल्प कहाँ है

हिलाने का विकल्प फ़ीचर समूह के {{ui:और}} मेन्यू में {{ui:बॉडी हिलाएँ}} के रूप में है, उस {{ui:हिलाना}} बॉक्स में जहाँ आप ΔX, ΔY और ΔZ लिखते हैं, और पार्ट पर {{ui:हिलाने के लिए खींचें}} तीरों के रूप में।
