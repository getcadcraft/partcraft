Python स्क्रिप्ट [स्क्रिप्ट वर्कस्पेस](topic:craftscript) की तीसरी भाषा है। एडिटर के ऊपर भाषा बॉक्स में **Python** चुनें (`.py` फ़ाइल अपने-आप Python में खुलती है)। Python, Lua और CraftScript एक ही वेरिएबल और एक ही अंतर्निर्मित फ़ंक्शन साझा करते हैं, इसलिए एक Python स्क्रिप्ट वह इस्तेमाल कर सकती है जो CraftScript स्क्रिप्ट ने बनाया, और इसका उल्टा भी।

किसी विज़िट में पहली Python रन Python स्वयं (CPython 3.14, लगभग 7 MB) इस साइट से लोड करता है, जिसमें कुछ सेकंड लगते हैं। Python अभी {{ui:ऑफ़लाइन के लिए सहेजें}} का हिस्सा नहीं है: पहले ऑनलाइन रहते हुए एक Python स्क्रिप्ट चला लें।

## Python सीलबंद है

Python स्क्रिप्ट CraftScript और Lua स्क्रिप्ट की तरह सीलबंद हैं: वे पार्ट, वेरिएबल और अंतर्निर्मित फ़ंक्शन तक पहुँचती हैं, और कुछ नहीं। हर रन एक नया Python होता है, अपने सैंडबॉक्स में, मेमोरी में एक छोटे फ़ाइल-ट्री के साथ (उसकी स्टैंडर्ड लाइब्रेरी और एक `/tmp` फ़ोल्डर, जो रन के बाद मिट जाता है)। यह नेटवर्क, आपकी फ़ाइलों या पेज के बाकी हिस्से तक नहीं पहुँच सकता, ब्राउज़र में और कमांड लाइन पर दोनों जगह। किसी और की स्क्रिप्ट फिर भी बहुत समय या मेमोरी ले सकती है: {{ui:रोकें}} उसे खत्म करता है।

## मूल बातें

```
A = cs.magic(3)              # हर अंतर्निर्मित फ़ंक्शन cs.<name> है
B = A @ A.T                  # @ मैट्रिक्स गुणन है, .T ट्रांसपोज़
C = A * 2 + 1                # + - * / ** एक-एक एलिमेंट पर हैं, numpy की तरह
print(A[0, 1], A[-1, -1])    # 0-आधारित; ऋणात्मक अंत से गिनता है
row = A[1]                   # मैट्रिक्स पर एक इंडेक्स: एक पंक्ति
big = A[A > 4]               # एक लॉजिकल मास्क एलिमेंट चुनता है
A[0, 0] = -5                 # ऐरे में असाइन करना
V, D = cs.call('eig', 2, A)  # कई परिणाम: cs.call(name, कितने, …)
```

- 1 × 1 ऐरे एक साधारण संख्या के रूप में आता है; बाकी ऐरे, स्पार्स मैट्रिक्स, मेश, फ़ील्ड और मॉडल **Values** हैं।
- एक Value में `shape` (ट्यूपल), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (उसकी पंक्तियाँ), और एक एलिमेंट के लिए `float()`, `int()` और `bool()` होते हैं।
- तुलना (`<`, `==`, …) numpy की तरह एक-एक एलिमेंट पर होती है: ये एक लॉजिकल Value देते हैं।
- अंतर्निर्मित फ़ंक्शन को पास की गई संख्याओं की सूचियाँ ऐरे बन जाती हैं: `cs.sum([1, 2, 3])`। `cs.tensor([[1, 2], [3, 4]])` एक मैट्रिक्स बनाता है।
- एक dict एक स्ट्रक्चर बनता है, और मिश्रित चीज़ों की सूची एक सेल, और फिर वापस भी।

आपकी स्क्रिप्ट जो भी ग्लोबल बनाती है (एक संख्या, एक Value, एक dict, एक list…), वह रन खत्म होने पर **वेरिएबल** टैब में पहुँचती है, भले ही बीच में कोई त्रुटि हुई हो। `_` से शुरू होने वाले नाम, फ़ंक्शन, क्लास और मॉड्यूल Python के भीतर ही रहते हैं। `ws.name` किसी वेरिएबल को सीधे पढ़ता या सेट करता है, और `ws_names()` उन्हें सूचीबद्ध करता है।

`print(…)` कंसोल पर लिखता है। `display(…)` (या `cs.display`) एक मेश, फ़ील्ड या प्लॉट दिखाता है, CraftScript की तरह।

## विश्लेषण लाइब्रेरी बुलाएँ

लाइब्रेरी फ़ंक्शन अंतर्निर्मित फ़ंक्शनों की तरह बुलाए जाते हैं: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`। नाम स्क्रिप्ट में ठीक वैसे ही लिखें: PartCraft चलने से पहले ढूँढ लेता है कि स्क्रिप्ट कौन-से लाइब्रेरी फ़ंक्शन इस्तेमाल करती है।

## अभी नहीं है

- numpy, scipy और अन्य पैकेज: यहाँ केवल Python की अपनी स्टैंडर्ड लाइब्रेरी है (`math`, `json`, `itertools`, `decimal`, `statistics`…), उसके विंडो, टर्मिनल और डेटाबेस वाले हिस्सों (`tkinter`, `curses`, `sqlite3`) के बिना।
- सॉकेट और बाहर पहुँचने वाली कोई भी चीज़: यहाँ Python के पास नेटवर्क नहीं है।
- `time.sleep` तुरंत लौट आता है।
- एडिटर में फ़ोल्डिंग, और CraftScript स्क्रिप्ट से Python फ़ंक्शन बुलाना।
- रन हर 1000 लाइनों पर निर्देश-बजट और Stop की जाँच करता है; एक अंतर्निर्मित फ़ंक्शन के अंदर की लंबी गणना पहले पूरी होती है।
