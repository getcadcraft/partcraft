何か動かないときは、まず画面下部の**ステータスバー**を確認してください。PartCraft は、拒否した理由や、次に必要な操作を表示します。失敗したフィーチャーには、右パネルの上部と、履歴の行にポインターを合わせたときにもメッセージが表示されます。

## アプリが起動しない

### 「このブラウザーでは 3D を表示できません（WebGL がオフまたは未対応のため、PartCraft をここで実行できません）。」

**原因:** ブラウザーで 3D グラフィックス（WebGL）がオフになっているか、ブロックされているか、グラフィックスドライバーで対応していません。

**対処:**

:::chromium
`chrome://settings/system`（Edge では `edge://settings/system`）を開き、「利用可能な場合はハードウェア アクセラレーションを使用する」をオンにしてから、ブラウザーを再起動します。すでにオンの場合は、`chrome://gpu` で WebGL の状態を確認し、グラフィックスドライバーを更新してください。
:::

:::firefox
`about:support` を開き、グラフィックスの WebGL を確認します。ブロックされている場合は、グラフィックスドライバーを更新してください。`about:config` で `webgl.disabled` が `false` である必要があります。
:::

:::safari
現在の Safari では、WebGL は常にオンです。macOS を更新してください（Safari は macOS と一緒に更新されます）。それでも失敗する場合は、同じ Mac で Chrome または Firefox を試し、グラフィックスハードウェアが原因かどうかを切り分けてください。
:::

リモートデスクトップや一部の仮想マシンには WebGL がありません。実際のコンピューターで試してください。

### 「ソリッドカーネルを読み込めませんでした: …」

**原因:** ジオメトリカーネル（WebAssembly プログラム）を取得または開始できませんでした。多くの場合、アプリの読み込み中に接続が切れた、会社のポリシーやブラウザーのセキュリティ設定で WebAssembly がオフになっている、またはブラウザーが非常に古い、のいずれかです。

**対処:** オンラインのままページを再読み込みしてください。それでも失敗する場合は、別の最新ブラウザーを試してください。Firefox では、`about:config` の `javascript.options.wasm` が `true` である必要があります。オフラインの場合、アプリとそのカーネルは、接続が切れる前にアプリバーに**オフライン対応**と表示されていた場合にのみ読み込まれます（オンラインで {{ui:オフライン用に保存}} を実行します。[オフラインでの作業](common:offline)を参照してください）。

### オフラインボタンに「保存できませんでした」または「オフラインで利用できません」と表示される

**保存できませんでした**: 一部のファイルをダウンロードできませんでした。オンラインでクリックして、もう一度試してください。低速または従量制の接続では、2 回目の試行が必要な場合があります。**オフラインで利用できません**: このブラウザーウィンドウでは、オフラインのコピーを保持できません（プライベートウィンドウや、一部の管理されたコンピューターではブロックされます）。通常のウィンドウを使うか、タブを開いたままにしてください。

### PartCraft はオフラインですが、古くなっています

オンラインのときに**オフライン対応**をクリックし、{{ui:もう一度保存(最新バージョンを取得)}} を選びます。

### 「スイープ: まだ作成されていません。厳密カーネルが必要ですが、このバージョンの PartCraft にはありません。」

完全なメッセージは「<名前>: まだ作成されていません。厳密カーネルが必要ですが、このバージョンの PartCraft にはありません。ヘルプ › まだ作成されていない機能 で、代わりの方法を確認できます。」です。スイープ、ロフト、リブ、板金のフランジ、サーフェスのフィーチャー、結合、ボディの移動、ボディの尺度変更、パスパターンを選んだとき、またその他の厳密カーネルでしか作れない機能で表示されます。ブラウザーや部品に問題があるわけではありません。このバージョンの PartCraft は、すべての部品をメッシュカーネルで作成します。代わりの方法は [まだ作成されていない機能](topic:not-built-yet) を、カーネルについては [メッシュカーネル](topic:solid-kernels) を参照してください。

### 「ソリッドカーネルを読み込み中…」が消えない

低速な接続では、少し待ってください。カーネルと 3D ライブラリは、初回に読み込まれるためダウンロードされます。その後、再読み込みしてください。ページ自体にエラーが表示される場合は、上記を参照してください。

## キーを押しても何も起きない

- 入力欄にカーソルがあるときは、キーは動作しません。3D ビューをクリックするか、入力後に {{key:Esc}} を押してください（または {{key:Tab}} で抜けます）。
- 矢印キーと {{key:Plus}}/{{key:Minus}} は、ビューをクリックした後にのみ、ビューを回転・ズームします。
- ダイアログが開いています。先にそれに応答してください。
- スケッチ内では {{key:F}} はフィレットツールであり、全体表示ではありません。{{ui:全体表示}} ボタンを使ってください。

## ツールバーのボタンがグレーになっている

- スケッチを開いている間は、フィーチャーのボタンがグレーになります。先にスケッチを閉じてください。
- スケッチツールはスケッチの中でのみ動作します。
- {{ui:元に戻す}} と {{ui:やり直し}} は、元に戻す、またはやり直す操作がないときにグレーになります。
- {{ui:アセンブリ}} には、ソリッドのある部品が必要です。{{ui:ジョイント}} には、アセンブリに 2 つの部品が必要です。{{ui:部品を編集}} には、部品が選択されている必要があります。
- {{ui:STEP AP242（厳密ソリッド）}} と {{ui:STEP AP214（厳密ソリッド）}} は、アセンブリではグレーになります。各部品を個別に書き出してください。別のプログラムが厳密ファイルを拒否する場合は、{{ui:STEP AP214（厳密ソリッド）}} を試し、次に {{ui:STEP（ファセット、メッシュカーネル）}} を試してください。そのうえで、{{ui:ヘルプ}} › {{ui:問題を報告}} からお知らせください。
- {{ui:スイープ}}、{{ui:ロフト}}、およびその他の厳密カーネルを必要とするフィーチャーは、グレーにはなりません。クリックはできますが、ツールチップは「まだ作成されていません（厳密カーネルが必要）」で終わり、クリックするとステータスバーにその旨が表示されます。[まだ作成されていない機能](topic:not-built-yet)を参照してください。
- {{ui:図面}} にはソリッドのある部品が必要で、スケッチを開いている間はグレーになります。
- {{ui:エクスポート}} の項目は、アセンブリではグレーになります。アセンブリはまだ書き出せません。閉じるか、部品を編集してから書き出してください。

## スケッチの問題

### スケッチで関係を追加できない

「この選択には関係を適用できません。項目を 1 つか 2 つ選択してください（Shift+クリックで追加）。」 その関係には、別の選択が必要です。各関係に必要なものは、[スケッチの関係と寸法](topic:sketch-relations)を参照してください。

### 「過剰定義: … は同時に満たせません。元に戻すか、どれか 1 つを削除してください。」

**原因:** 新しい関係または寸法が、既存の関係または寸法と矛盾しています。スケッチは動いていません。

**対処:** {{key:Mod+Z}} を押すか、右パネルの一覧で赤い項目の 1 つを削除します（その横の**削除**を選びます）。

### 「過剰定義: … はすでに導かれています。削除してください。」

**原因:** この関係は何も追加しません。他の関係によって、すでに決まっています（たとえば、長方形の 2 辺の平行、またはすでに固定されている寸法）。このビルドには従動寸法はありません。

**対処:** 削除してください。フィーチャーは警告付きで作成されます。

### 「これらの項目は一緒に寸法を付けられません。」

たとえば、点と円を選びました。代わりに、円の中心点に寸法を付けてください。

### 「フィレットには、ちょうど 2 本の線が交わる角が必要です。」/「その半径は、これらの線には大きすぎます。」

2 本の実線の角の点を正確にクリックしてください。短い方の線が許す大きさより小さい半径を使ってください。

### ドラッグすると図形が元に戻る

そのドラッグは関係または寸法を壊すため、PartCraft は図形を元の位置に戻します。動かせるのは、青色（未定義）の図形だけです。

### 「このスケッチは開けません: Extrude2 が必要ですが、失敗しています。」

スケッチは、作成されていないフィーチャーの面の上にあります。先にそのフィーチャーを修正するか、抑制を解除するか、ロールフォワードしてください。

## 選択の問題

- 「その面は曲面です。スケッチ用に平面を選んでください。」 スケッチには平面が必要です。基準平面にスケッチを描き、寸法でスケッチの位置を決めてください。
- 面に「選択時に固定」と表示される: その面はスケッチのエッジで作られたものではないため（たとえば、パターンコピーの面）、その面上のスケッチは、部品が変わっても動きません。
- エッジは選びにくいです。ズームしてください。ポインターがちょうどエッジの上にあるときは、エッジが隣の面より優先されます。

**保存したファイルが見当たらない。** 保存はダウンロードです。ブラウザーのダウンロードフォルダーを探すか、ブラウザーのツールバーからダウンロードの一覧を開いてください。[ファイルの保存先](common:your-files)を参照してください。

## 図面の問題

| メッセージ | 対処 |
|---|---|
| 「先にソリッドを作成してから、その図面を作成してください。」 | 先に部品を作成します |
| 「シートに詳細図の場所がありません。詳細図を小さくするか、ビューを 1 つ削除してください。」 | **詳細の半径**または**詳細の縮尺**を小さくするか、断面を削除します |
| 「詳細図は、正面、上面、右面、または断面ビューから取られます。」 | それらのビューのいずれかをクリックします |
| 「ビューの 1 つをクリックしてください。」 | クリックした場所が空白の用紙上だった |
| 「位置には、少なくとも 1 つの基準参照が必要です。」 など、フレームのメッセージ | パネルが求める基準を設定するか、別の特性を選びます |
| 「図面のビューを作成できませんでした: …」 | 最後の変更を元に戻します。繰り返す場合は、保存し、再読み込みしてから、部品を開き直してください |

## アセンブリの問題

| メッセージ | 対処 |
|---|---|
| 「先にソリッドを作成してから、アセンブリに入れてください。」 | 部品にまだソリッドがありません |
| 「先に 2 つ目の部品を入れてください（コピーを追加、挿入、または 編集 › 複製）。」 | ジョイントには 2 つの部品が必要です |
| 「別の部品の面を選んでください。」 | ジョイントの両方の面は、異なる部品の上にある必要があります |
| 「その面は曲面です。平面を選んでください …」 | ジョイントは平面から始まります。穴や回転軸には、**中心を指定**を使います |
| 「Bracket2 は固定された部品につながっていないため、置いた位置のままになります。」 | 配置済みの部品に対して、その部品からジョイントを追加してください |
| 「Revolute3 は閉じられないループを作ります: 2.000 mm ずれています。ループのジョイントの面、オフセット、制限を確認してください。」 | 部品をすべて接合できません。長さ、各ジョイントが使う面、オフセット（面どうしを重ねた部品は奥行きが一致している必要があります）、制限を確認するか、ループのジョイントを 1 つ削除します |
| 「このジョイントが使う面は Bracket からなくなりました。」/「このジョイントが使う軸は Bracket からなくなりました。」 | 部品が編集されました。ジョイントを削除して、作り直してください |
| 「軸が面に沿っているため、ジョイントの中心を設定できません。」 | 面と交わる軸を選ぶか、「面自体の原点」を選びます |
| 「アセンブリには少なくとも 1 つの部品が必要です。代わりに閉じてください。」 | {{ui:閉じる}} を使います |

**部品はつながっていますが、位置が違います。** ジョイントの両側の**中心を指定**を、揃えたい穴または回転軸に設定し、その後で**角度 (°)** と**オフセット (mm)** を調整します。

## 遅い

- モデリング中は**曲線**を標準または粗めに設定し、書き出す前に細かめに切り替えてください。
- 大きなパターンの数（数百個のコピー）は、変更のたびに再構築に時間がかかります。他のフィーチャーの作業中は、パターンを抑制してください。
- 干渉チェックと動作チェックは、すべての部品の組を比較するため、大きなアセンブリでは時間がかかります。
- 他の重いタブを閉じてください。PartCraft は、お使いのコンピューターのプロセッサーとグラフィックスで動作します。

## それでも解決しない

まずファイルを保存（{{key:Mod+S}}）してから、ページを再読み込みして開き直してください。フィーチャーが依然として失敗する場合は、そのフィーチャーを選び、メッセージを読んで、{{key:Mod+Z}} で最後の正常な状態まで戻してみてください。
