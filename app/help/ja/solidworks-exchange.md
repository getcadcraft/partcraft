PartCraftは、ほかの誰も読めないファイル形式を使わずに、SolidWorksとの間でパーツを双方向にやり取りします:

- **送り出し:** SolidWorksが実行して、パーツ自体をフィーチャーごとに作成するマクロ(`.swb`、プレーンテキスト)です。スケッチ、拘束、寸法、グローバル変数、方程式が含まれます。ライブのフィーチャーツリーを持つネイティブのパーツが得られ、静的なソリッドではありません。
- **戻す:** SolidWorks内で実行するマクロが、パーツのフィーチャーと方程式を`.cadcraft-sw.json`ファイルに書き出します。そのファイルをPartCraftで開く機能は、このバージョンではまだ作成されていません(厳密カーネルが必要です)。

:::warning
これらはまだSolidWorksでテストされていません。SolidWorksはライセンスのあるWindowsでのみ動作し、PartCraftではこれらのマクロを実行したことがありません。マクロはSolidWorks APIのドキュメントから作成され、ここでは構造のみ確認しています。問題が報告される可能性があります。マクロが書き出すログに、失敗した手順が示されます。
:::

PartCraftは`.sldprt`ファイルを書き出せません。この形式は非公開です。ネイティブのパーツを得る方法は、マクロです。

## パーツをマクロとして送る

1. パーツを開きます。
2. {{ui:エクスポート}}を選び、次に{{ui:SolidWorks用マクロ (.swb)}}を選びます。PartCraftは`<part>.swb`をダウンロードします。ステータスバーに「厳密カーネルなしで作成されました」と表示されます。
3. ダイアログに、マクロが作成するフィーチャー、グローバル変数、方程式の数が表示され、対象外のものが一覧表示されます。このバージョンでは、マクロと一緒にSTEPは出力されません。必要な場合は、{{ui:エクスポート}}を選び、次に{{ui:STEP（ファセット、メッシュカーネル）}}を選びます。
4. SolidWorksで、**Tools > Macro > Run**を選び、`.swb`ファイルを選択して完了するまで待ちます。既定のパーツテンプレートから新しいパーツが作られ、単位をミリメートルに設定して、すべてのフィーチャーを作成します。
5. 最後にメッセージが表示され、完了した手順の数、失敗した数、PartCraftのボディと一致した数が示されます。完全なログ`<part> macro log.txt`は、マクロの隣に書き出されます。

マクロが作成する内容:

| PartCraft | 新しいパーツ内 |
|---|---|
| 正面、上面、右面の平面上のスケッチ | その平面上のスケッチ。線分、円弧、円、点、拘束、寸法を含みます(`k7`のように、PartCraftと同じ名前が付きます) |
| 面上のスケッチ | 同じ面上のスケッチ。面上の点で選択されます |
| 固定平面上のスケッチ | 3点を通る基準平面と、その上のスケッチ |
| 押し出し、切り抜き(指定距離、全貫通、中間平面、両方向、テーパー) | ボス押し出しまたは切り抜き押し出し |
| 回転、回転切り抜き | 同じ中心線を軸にした回転 |
| 穴(通常、座ぐり、皿穴、ねじ穴) | 独自のスケッチを持つ1つまたは2つの切り抜き(ねじ穴は下穴として作られ、ねじ山はありません) |
| 直線パターンと円形パターン、ミラー | 直線パターン、円形パターン、ミラー(フィーチャーまたはボディ) |
| フィレット、面取り、シェル | 同じエッジと面に対するフィレット、面取り、シェル。点で選択されます |
| パラメーターと方程式 | 名前を変更した寸法に対するグローバル変数と方程式 |
| 抑制されたフィーチャー、ロールバックバー | 同じ方法で抑制されます。ロールバックバーは同じ位置に置かれます |

各ソリッドのフィーチャーの後、マクロはボディのボリュームと寸法をPartCraftのものと比較します。異なる場合は、そのフィーチャーの方向を1回反転させて再度チェックします。それでも改善しない場合は元に戻し、ログに"Check"と書き出します。

### 対象外のもの

ダイアログとマクロの先頭に、引き継がれなかったものがすべて理由とともに一覧表示されます。現時点では次が該当します: インポートしたソリッド(代わりにSTEPを挿入してください)、スイープ、ロフト、抜き勾配、基準軸と基準点、「次まで」の終了条件、一部の輪郭だけの押し出し、およびそれらに依存するもの。スプラインは、通過する点を通る曲線になります。このバージョンには厳密カーネルがないため、面上のスケッチや、エッジや面を選択するフィーチャーも対象外になります。

## 名前付きSTEPを送る

このバージョンではまだ作成されていません: {{ui:SolidWorks 用の STEP（名前付き、AP214）}}には厳密カーネルが必要で、選択すると「SolidWorks 用の STEP: まだ作成されていません。…」と表示されます。厳密カーネルがあれば、ファイルにはパーツの名前、ミリメートル単位、パーツの色が含まれ、SolidWorksがパーツを表示するのと同じように、Y軸が上向きになります(通常の{{ui:STEP AP214（厳密ソリッド）}}の書き出しではZ軸が上向きになります)。名前では、アクセント付きの文字はアクセントを除いて書き出され、ASCII以外のその他の文字は`_`になります。

## パーツを戻す

PartCraftでファイルを開く(手順3)機能は、このバージョンではまだ作成されていません。「SolidWorksの書き出しを開く: まだ作成されていません。…」と表示されます。CadCraftの製図アプリでは、引き続きファイルを開き、そのスケッチを取り込めます。

1. {{ui:ファイル}} > {{ui:エクスポート}} > {{ui:部品を戻すためのエクスポートマクロ (.swb)}}を選び、`CadCraftExport.swb`をダウンロードして、パーツの隣に置きます。
2. SolidWorksでパーツを開き、**Tools > Macro > Run**を選んで`CadCraftExport.swb`を選択します。パーツの隣に`<part>.cadcraft-sw.json`を書き出し、パーツ自体は変更しません。
3. PartCraftで{{ui:開く}}を選んでそのファイルを選ぶか、3Dビューにドロップします。
4. 厳密カーネルがあれば、PartCraftはパーツをフィーチャーごとに再構築し、その結果を表示します。たとえば「SolidWorksから5件中5件のフィーチャーを引き継ぎました(Flange.SLDPRT)」、引き継げなかった各フィーチャー(「引き継がれませんでした: Sweep1 (Sweep).」)、およびボリュームがSolidWorksの書き出したものと一致するかどうかが示されます。
5. {{ui:保存}}を選び、PartCraftのパーツとして保存します。

スケッチは、基準平面上にある場合は基準平面に、対応する平らな面がパーツにある場合はその面に(そのため後の編集に追従します)、それ以外の場合は固定平面に配置されます。フィレット、面取り、シェルのエッジと面は、点から見つけられ、名前付きの参照として保持されます。グローバル変数はパラメーターになります(スペースを含む名前にはアンダースコアが付きます: 「Bolt count」は`Bolt_count`になります)。方程式は同じ寸法に対する方程式になります。推測は行われません。対応するものがないものは一覧表示されます。

CadCraftの製図アプリも同じファイルを開き、そのスケッチを取り込みます。

:::note
形式は、ミリメートルと度を使ったプレーンJSONの`cadcraft-sw-export`バージョン1です。新しいマクロで作成されたファイル、または有効でないファイルは、理由とともに拒否されます。
:::
