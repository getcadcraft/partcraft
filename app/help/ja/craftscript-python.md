[スクリプトワークスペース](topic:craftscript) の 3 番目の言語が Python です。エディター上の言語ボックスで **Python** を選びます（`.py` ファイルは自動的に Python で開きます）。Python、Lua、CraftScript は同じ変数と同じ組み込み関数を共有するので、Python スクリプトは CraftScript スクリプトが作ったものを使えますし、その逆も可能です。

訪問ごとの最初の Python 実行では、Python 本体（CPython 3.14、約 7 MB）をこのサイトから読み込みます。数秒かかります。Python はまだ {{ui:オフライン用に保存}} の対象ではありません。先にオンラインの状態で Python スクリプトを 1 つ実行してください。

## Python は隔離されています

Python スクリプトは、CraftScript や Lua のスクリプトと同じく隔離されています。届くのはパーツ、変数、組み込み関数だけです。実行のたびに、メモリ上の小さなファイルツリー（標準ライブラリと、実行後に消える `/tmp` フォルダー）を持つ新しい Python が、独自のサンドボックスで起動します。ネットワーク、あなたのファイル、ページの他の部分には到達できません。ブラウザーでもコマンドラインでも同じです。他人のスクリプトは、依然として多くの時間やメモリを使うことがあります。その場合は {{ui:停止}} で終了させてください。

## 基本

```
A = cs.magic(3)              # 組み込み関数はすべて cs.<名前>
B = A @ A.T                  # @ は行列積、.T は転置
C = A * 2 + 1                # + - * / ** は numpy と同じく要素ごと
print(A[0, 1], A[-1, -1])    # 0 始まり。負の数は末尾から数える
row = A[1]                   # 行列への 1 つの添字: 行
big = A[A > 4]               # 論理マスクで要素を選ぶ
A[0, 0] = -5                 # 配列への代入
V, D = cs.call('eig', 2, A)  # 複数の結果: cs.call(名前, 個数, …)
```

- 1 × 1 の配列は普通の数値として渡されます。それ以外の配列、疎行列、メッシュ、フィールド、モデルは**値**です。
- 値は `shape`（タプル）、`T`、`type`、`numel()`、`copy()`、`tolist()`、`len()`（行数）を持ち、1 つの要素に対しては `float()`、`int()`、`bool()` を持ちます。
- 比較（`<`、`==` など）は numpy と同じく要素ごとで、論理値の値を返します。
- 組み込み関数に渡された数値のリストは配列になります: `cs.sum([1, 2, 3])`。`cs.tensor([[1, 2], [3, 4]])` は行列を作ります。
- 辞書は構造体に、混在したもののリストはセルになり、その逆も可能です。

スクリプトが作るすべてのグローバル（数値、値、辞書、リストなど）は、エラーの後でも、実行が終わると**変数**タブに入ります。`_` で始まる名前、関数、クラス、モジュールは Python 内に残ります。`ws.name` は変数を直接読み書きし、`ws_names()` は変数の一覧を返します。

`print(…)` はコンソールに書き出します。`display(…)`（または `cs.display`）は、CraftScript と同じようにメッシュ、フィールド、プロットを表示します。

## 解析ライブラリを呼び出す

ライブラリ関数は組み込み関数と同じように呼び出します: `cs.box_mesh(20, 10, 10, 5, 'hex')`、`cs.call('modal_tet', 2, …)`。名前はスクリプト内にそのままの形で書いてください。PartCraft は、実行前にスクリプトが使うライブラリ関数を見つけます。

## まだ対応していない機能

- numpy、scipy、その他のパッケージ: Python 標準ライブラリだけ（`math`、`json`、`itertools`、`decimal`、`statistics` など）が使えます。ウィンドウ、ターミナル、データベースの部分（`tkinter`、`curses`、`sqlite3`）はありません。
- ソケットその他の外部に届く機能: ここでは Python からネットワークに到達できません。
- `time.sleep` はすぐに戻ります。
- エディター内の折りたたみ、および Python 関数を CraftScript スクリプトから呼び出すこと。
- 実行中は 1000 行ごとに命令上限と停止を確認します。1 つの組み込み関数の中で行われる長い計算は、先に完了します。
