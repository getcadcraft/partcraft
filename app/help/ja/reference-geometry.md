参照ジオメトリは、フィーチャーを作成するための足場です。面がない場所でスケッチするための**平面**、回転やパターンの基準となる**軸**、押し出しを止めるための**点**です。それ自体の材料はありません。平面は表示では薄い色の正方形、軸は破線、点は小さな十字で表示されます。3つすべてが履歴に加わり、上流で寸法を変更すると、作成元に従って変わります。

これらは、フィーチャーグループの{{ui:その他}}メニューにあります: {{ui:平面}}、{{ui:軸}}、{{ui:点}}。

## 平面を作成する

1. 開始点にするため、平らな面、または履歴の基準平面をクリックします (任意)。
2. {{ui:その他}} を選択し、次に {{ui:平面}} を選択します。最初は、選んだ面 (または上面) から部品サイズの 20 %離れたオフセット平面として始まります。
3. 右パネルで **種類** と参照を選びます:

| 種類 | 参照 | 数値 |
|---|---|---|
| 平面または面からのオフセット | **基準平面** | **距離 (mm)**、反対側にする場合は負の値 |
| 角度付き、エッジまたは軸を通る | **基準平面**、**回転軸** (ワールド軸、軸フィーチャー、または選んだ直線エッジ) | **角度 (°)** |
| 3点を通る | **点 1**、**点 2**、**点 3** | — |
| 2つの間の中間平面 | **1つ目の平面**、**2つ目の平面** (平行: 中間、交差: 角を二等分する平面) | — |
| 円柱に接する | **円柱** (円柱面)、**近い点** (どちら側か) | — |
| エッジに直角、点で | **エッジ**、**指定点** (平面はエッジ上で最も近い点を通り、指定点も通る) | — |
| エッジと点を通る | **直線エッジ** (または軸)、**通過点** | — |
| エッジの中点で直角 | **エッジ** (その中点で直角)、またはエッジがない場合 **点 1** と **点 2** (2点の中間の平面) | — |

各参照には **選択** ボタンがあります。それを選び、表示内でクリックします。平面の欄には、基準平面、参照平面、または平らな面を指定できます。点の欄には、エッジの端 (その端の近くをクリック)、点フィーチャー、または面上の位置を指定できます。エッジの欄にはエッジを指定します。{{key:Esc}} で選択を取り消します。**法線を反転** を選ぶと平面が裏返り、その上のスケッチの向きが変わります。

このバージョンでは、エッジまたは円柱面を必要とする欄 (円柱に接する、およびエッジの欄) は「まだ作成されていません」と表示されます。代わりに点または軸を使用してください。

## 平面にスケッチする

平面を選択し (履歴で、または表示の正方形をクリックして)、{{ui:スケッチ}} を選ぶか、そのパネルの **この平面にスケッチ** を選択します。スケッチは平面に従います。平面の距離を変更すると、スケッチとその上のすべてのフィーチャーも移動します。

## 軸と点

- {{ui:軸}}: 2点を通る、円柱または円錐の軸、2つの平面が交わる位置、直線エッジに沿って (または円形エッジの軸)、点を通る面に直角。
- {{ui:点}}: 座標、頂点またはスケッチ点、円形エッジの中心、および「オブジェクト間」の点:

| 点の種類 | 参照 |
|---|---|
| エッジの中点 (または2点の中間) | **エッジ** (長さの中点、円弧や曲線にも対応)、またはエッジがない場合は **点 1** と **点 2** |
| エッジまたは軸が面または平面と交わる位置 | **エッジ** (直線または曲線) または軸、および **交差する平面** (平面または平らな面)、または **または面** (平らな面または円柱)。円は平面と2回交わり、直線は円柱を2回通ります。2つ目は **もう一方の交点** で指定します |
| 3つの平面が交わる位置 | **1つ目**、**2つ目**、**3つ目の平面** (平面または平らな面) |

参照が合わない場合は、それぞれ簡単なメッセージで失敗します。例: 平面に平行な線、円柱を外れる線、平面に届かないエッジ、1点で交わらない3つの平面、平面を定めるはずの線上にある点。

他のフィーチャーでも使用できます:

| 使用先 | 方法 |
|---|---|
| 回転 | **軸**: 一覧から軸フィーチャーを選びます (スケッチの平面内にある必要があります) |
| 円形パターン | **軸**: 軸フィーチャー |
| 直線パターン | **方向**: 軸フィーチャー、または平面 (その法線) |
| ミラー | **ミラー平面**: 参照平面 |
| 押し出し | **終了**: 面または平面まで、頂点まで (点フィーチャー)。このバージョンではまだ作成されていません (厳密カーネルが必要です) |
| 抜き勾配 | **中立平面** |

## 参照がなくなったとき

もう存在しない面から作られた平面は、それを示すメッセージで失敗します。例: 「配置先の面はExtrude1からなくなっています。」 別の面へ移動されることは決してありません。その上のスケッチとフィーチャーは、新しい参照を選ぶまで「未作成」と表示されます。部品のそれ以外の部分は変わりません。

:::note
このバージョンでは、すべての部品をメッシュカーネルで作成します。このカーネルでは、基準平面、押し出しまたは回転で作られた平らな面、スケッチ点、座標、その他の参照フィーチャーから、平面、軸、点を作成できます。エッジ、エッジの端、または曲面を必要とするものには、厳密カーネルが必要です。このバージョンではまだ作成されていません (「この立体の面またはエッジを使用しており、厳密カーネルでのみ検出できます。このバージョンではまだ作成されていません。」)。
:::
