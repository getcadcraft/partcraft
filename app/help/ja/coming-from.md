SolidWorks で部品を設計している場合、PartCraft の考え方の多くは馴染みがあるでしょう: 正面、上面、右面の平面上のスケッチ、拘束とスマート寸法、ロールバックバー付きのフィーチャー履歴、合致で配置されたアセンブリ。ただし、操作への到達方法は一部異なり、この最初のビルドでは機能が少なくなっています。このページでは、これらの習慣の対応関係と、驚きやすい点を説明します。

## 習慣の対応

| 使い慣れた操作 | PartCraft では |
|---|---|
| 左側のデザインツリー | 左側の履歴: 平面が先に、続いてフィーチャー、そのフィーチャーで使うスケッチはその下にインデントされて表示されます |
| 正面、上面、右面の平面 | 同じ 3 つで、原点を通ります。正面は XY 平面、上面は XZ、右面は YZ です。Y が上向きです |
| 平面または面上にスケッチし、確認コーナーで終了 | 選択した平面または平らな面で {{ui:スケッチ}} ({{key:S}})。{{ui:終了}} または {{key:Esc}} で閉じます |
| スマート寸法 | {{ui:寸法}} ({{key:D}})。1 つまたは 2 つの要素をクリックし、次に数値を配置する位置をクリックします。配置した位置によって、水平、垂直、または平行寸法が決まります |
| プロパティパネルで拘束を追加 | 要素を選択し、右パネルの拘束ボタン (一致、水平、平行、接線、等しい など) |
| スケッチ中の自動拘束 | スナップにより、一致、点が曲線上、水平、垂直の拘束が追加されます |
| 青 / 黒 / 赤のスケッチ色 | 同じ考え方です。青は不足定義、黒は完全定義、赤は過剰定義です。チップには残りの自由度が表示されます |
| 回転用の中心線 | {{ui:中心線}} ({{key:N}})。{{ui:回転}} は、別の軸を選ばない限り最初の中心線を使います |
| スケッチのフィレット | スケッチの {{ui:フィレット}} ({{key:F}}): 角をクリックし、半径を入力します |
| 作成線のトグル | {{ui:補助ジオメトリ}} ({{key:Q}}) |
| 押し出しボス | {{ui:押し出し}}: 指定距離、中間平面、面まで / 次まで / 頂点まで、面からのオフセット、反対方向、テーパー、1 つの輪郭 (**領域を選択**) |
| 押し出しカット | {{ui:切り取り}}: 最初は全貫通です。ポケットにするには指定距離に切り替えます |
| 回転ボス / カット | {{ui:回転}} / {{ui:その他}} › {{ui:回転カット}} |
| 参照平面 / 軸 / 点 | {{ui:その他}} › {{ui:平面}}、{{ui:軸}}、{{ui:点}} ([参照平面、軸、点](topic:reference-geometry) を参照) |
| スイープまたはロフトのボス / カット、抜き勾配 | 平らな面に対する {{ui:その他}} › {{ui:抜き勾配}} ([スイープ、ロフト、抜き勾配](topic:sweep-loft-draft) を参照)。{{ui:スイープ}} と {{ui:ロフト}} は、このバージョンではまだ作成されていません (厳密カーネルが必要なため) |
| 穴ウィザード | 独立したスケッチ点ごとに {{ui:穴}}: 単純、座ぐり、皿穴 (90° / 82°)、ISO メートルねじ M2 から M24 のタップ穴、貫通または止まり穴 |
| 直線 / 円形パターン、ミラー | {{ui:直線}}、{{ui:円形}}、{{ui:ミラー}} (フィーチャーまたはボディ全体) |
| エッジのフィレットと面取り | {{ui:フィレット}} / {{ui:面取り}}: エッジをクリックし、{{key:Shift}}+クリックで追加してからボタンを選択します。半径は 1 つ。等距離、2 距離、または距離と角度の面取りがあります。このバージョンでは、2 つの平らな面の間にある直線エッジのみ対応し、角で交わる丸みは、なめらかにつながらず斜めに切り取られます。曲線エッジの丸めや面取りは、スケッチで行ってください ({{ui:フィレット}} をスケッチ内で、{{key:F}}) |
| シェル | {{ui:シェル}}: 開く平らな面をクリックしてからボタンを選択します。壁厚は 1 つ |
| STEP ファイルを開く | {{ui:開く}}: 三角形として読み込まれ、立体のボディとして作業を続けられます ([STEP ファイルを開く](topic:import-step) を参照) |
| フィーチャーを編集してから OK | フィーチャーをクリックし、右側の数値を変更します。入力中に再構築されます。OK もキャンセルもありません。{{key:Mod+Z}} を使います |
| スケッチを編集 | 履歴でスケッチをダブルクリック |
| 再構築 | すべての変更後に自動的に実行されます。再構築のキーはありません |
| 抑制 / 抑制解除 | 右パネルの {{ui:抑制}} / {{ui:抑制解除}} |
| ロールバックバーのドラッグ | フィーチャーの {{ui:ここまでロールバック}}。「ロールバックバー · 先へ進める」をクリックして戻ります |
| ツリーでフィーチャーをドラッグして並べ替え | {{ui:上に移動}} / {{ui:下に移動}}、または {{key:Alt+Up}} / {{key:Alt+Down}}。依存関係が壊れる場合は、理由とともに拒否されます |
| モデル上でダブルクリックして寸法を編集 | フィーチャーを選択します。そのスケッチの寸法は右パネルに一覧表示されます |
| 合致: 一致、同心、距離、角度 | {{ui:ジョイント}} ({{key:J}}): 各部品の平らな面を選択します。ジョイントは面どうしを合わせます。軸に対する **中心の位置** は同心と同じ、**オフセット** は距離と同じ、**角度** は角度と同じ働きをします |
| 固定コンポーネント | 最初の部品が固定されます。{{ui:固定部品にする}} で変更できます |
| コンポーネントの挿入 | {{ui:コピーを追加}}、{{ui:複製}} (別のコピー)、または {{ui:挿入}} (部品ファイルから) |
| アセンブリで部品を編集 | {{ui:部品を編集}}、次に {{ui:戻る}} |
| 干渉検出 | {{ui:干渉チェック}} |
| 動きを見るためにコンポーネントを動かす | 回転またはスライダージョイントの角度またはオフセットのスライダーをドラッグします。{{ui:動きの中で干渉がないか確認}} で掃引します。ジョイントのない部品は **手で移動** (ドラッグする矢印、または値の入力) |
| 計測 / 検査 | {{ui:表示}} の後、{{ui:計測}} ({{key:M}}): 距離、角度、半径、面積。{{ui:質量特性}} |
| 分解図、部品表 | アセンブリで何も選択していない状態で、右パネルの **分解図** と **部品表** |
| 質量特性 | **部品** ボックス: 面の多い立体の体積、表面積、サイズ (丸い部品では少し小さく出ます)。質量はありません。まだ材料を設定していないためです |
| 保存、STEP として保存 | {{ui:保存}} は `.partcraft.json` をダウンロードします。{{ui:エクスポート}} では、STL、3MF、厳密 STEP (AP242 または AP214)、面の多い STEP、DXF、PDF 図面を書き出せます |
| 部品から図面を作成 | {{ui:図面}}: 3 つのビュー、等角投影、1 つの断面、1 つの詳細図、基準、幾何公差の枠、仕上げ記号を含む自動 A3 シートです。全体の寸法のみが記入されます |
| 中ボタンドラッグで回転 | ここでは **左ドラッグ** で回転します。中または右ドラッグでパンします。ホイールはポインター位置でズームします |
| ビューの向き、法線方向 | {{ui:表示}} メニュー。選択した面、平面、またはスケッチには {{ui:法線方向から表示}} |
| 全体表示 (F) | {{key:F}}、または {{ui:全体表示}} (スケッチ内では {{key:F}} はフィレットツールです) |
| 右クリックメニュー | なし。右ドラッグでパンします。スケッチでは右クリックで線の連続を終了します |

:::tip
SolidWorks の操作に慣れている場合は、{{ui:設定}} › {{ui:PartCraft}} › {{ui:メニュー、キー、マウス}} で {{ui:フィーチャーツリー}} のメニュースタイルを選んでください。フィーチャー、スケッチ、サーフェス、評価、図面、アセンブリ、表示のタブを持つリボンが表示され、中ボタンで回転し、{{key:Shift}} と中ボタンでパンし、左ボタンは選択のみになります。[メニュー、キー、マウス](topic:menus-keys-and-mouse) を参照してください。
:::

## 違いで戸惑いやすい点

**スケッチ全体が輪郭です。** 押し出しと回転は、スケッチ内のすべての閉ループを使います。フィーチャーに対して、スケッチの領域や輪郭を 1 つだけ選択することはできません。フィーチャーごとに 1 つのスケッチを使用してください。

**フィーチャーが使うスケッチ。** フィーチャーは、直前に閉じたスケッチ、または履歴で選択されているスケッチを使います。何も選択されていない場合は、どのフィーチャーもまだ使っていない最新のスケッチを使います。間違ったスケッチが使われた場合は、正しいスケッチを選択してからフィーチャーを選び直してください。

**変更は入力中に適用されます。** OK とキャンセルのあるフィーチャーダイアログはありません。数値を入力するたびにすぐに再構築されます。元に戻すには {{key:Mod+Z}} を使います。元に戻す一覧には、スケッチの編集、フィーチャー、設定がすべて含まれます。

**過剰定義は放置されません。** 従属 (参照) 寸法はありません。他の拘束ですでに決まっている寸法は、過剰定義として報告されます (「既に決まっています。削除してください。」)。矛盾する寸法は形状を変えず、赤くなります。どちらかを削除するか、元に戻してください。

**スイープとロフトはまだ作成されていません。フィレット、面取り、シェル、抜き勾配には制限があります。** このバージョンの PartCraft は、すべての部品をメッシュカーネルで作成します。ステータスバーのチップには常に「Mesh kernel」と表示されます。フィレットと面取りは、2 つの平らな面の間にある直線エッジでのみ動作し、丸みが角で交わる場合は、ブレンドされずに斜めに切り取られます。シェルは開き、抜き勾配は平らな面のみを傾けられます。厳密カーネルが必要な機能は選択できますが、選択すると「まだ作成されていません」と表示されます。[メッシュカーネル](topic:solid-kernels) と [まだ作成されていない機能](topic:not-built-yet) を参照してください。

**2 つのフィレットボタン。** スケッチでは、{{ui:フィレット}} ({{key:F}}) がスケッチの角を丸めます。部品では、フィーチャーグループの {{ui:フィレット}} が立体のエッジを丸めます (このバージョンでは、2 つの平らな面の間の直線エッジのみです)。このバージョンにはスイープもロフトもありません。[まだ作成されていない機能](topic:not-built-yet) を参照してください。

**穴には独立した点が必要です。** {{ui:穴}} は、点ツールで作成された点に穴を開けます。円の中心や線の端点は対象になりません。

**貫通全体はカットにのみ使えます。** ボスには深さが必要です。「頂点まで / 面まで / 次まで」という終了条件はまだありません。

**立体は面の多いメッシュです。** メッシュカーネルは、丸い面を平らな面の集まりで作成するため、表示、体積、STL と 3MF の書き出しはすべて面の多い形状になります。部品パネルの **曲線** で、より細かくできます。厳密な STEP の書き出しは対象外で、丸い面を真の曲面で書き出します。

**単位はミリメートルのみです。** まだインチの設定はありません。インチの寸法を入力するときは、25.4 を掛けてください。

**Y が上向きです。** 正面平面はユーザーの方を向き、上面は部品を上から見下ろすように表示されます。しかし、世界の上方向の軸は Y です。STL、3MF、厳密 STEP の書き出しは Z 上向きに変換され、面の多い STEP は Y 上向きのままです。

**合致は面であり、ジオメトリのペアではありません。** ジョイントは常に、2 つの平らな面を面どうしで合わせることから始まります。穴に入るピンの場合は、穴の周りの平らな面とピンの段付き部分を選択し、**中心の位置** を穴の軸とピンの回転軸に設定します。ジョイントで到達しない部品は、挿入された位置のままになり、ドラッグすることはできません。ループ内のジョイントは解かれません。

**保存はダウンロードです。** 上書きし続けるファイルはありません。保存するたびに、ダウンロードフォルダーに新しいファイルが作成されます。最初に部品に名前を付け、ファイルはプロジェクトフォルダーに保管してください。

**右クリックメニューやコマンドマネージャーのタブはありません。** すべてはツールバーと右パネルにあり、ツールバーは作業内容によって変わります。スケッチツールはスケッチ内でのみ、アセンブリツールはアセンブリ内でのみ表示されます。

**スケッチ内のキーは 1 文字です。** {{key:L}}、{{key:R}}、{{key:C}}、{{key:A}}、{{key:P}}、{{key:N}}、{{key:F}}、{{key:D}}、{{key:Q}}、{{key:S}} は、修飾キーなしでツールを選択します。[キーとマウス](topic:keyboard) を参照してください。
