## 学習内容

AIアシスタント（または自分で作成したスクリプト）に、開いている部品を確認させ、パラメーターを変更させ、スクリプトを実行させてエクスポートさせる方法と、どこまで操作を許可するかを決める方法を説明します。

PartCraftは独自のAIを持たず、どこにもデータを送信しません。アシスタントは自分で用意します。Model Context Protocol（MCP）に対応したプログラムであれば何でも使えます。PartCraftはそれにツールを提供するだけで、どのツールを使わせるかは選べます。

## 有効にする

1. {{ui:設定}}（アプリバーの歯車、または {{key:Mod+,}}）を開き、{{ui:PartCraft}} タブに移動します。
2. {{ui:アシスタント}}の下にある **AIアシスタントとスクリプトにPartCraftの使用を許可する** にチェックを入れます。チェックを入れるまでは無効です。
3. 許可する操作を選びます。**読み取り** は最初からオンになっています。他の操作は必要なときだけオンにします。
4. フォルダーへのエクスポートや保存を許可するには、**使用できるフォルダー** の下にある {{ui:フォルダーを追加…}} を選び、Studioのダイアログでフォルダーを選択します。

アシスタントは、お使いのコンピューター上の **CadCraft Studio** を経由して接続します。Studioには、アシスタントに貼り付けるアドレスとトークンが表示されます。ブラウザータブでは、アシスタントへの接続を開けません。

## アシスタントに依頼できること

| ツール | 権限 | 内容 |
|---|---|---|
| `part_describe`, `features_list` | 読み取り | 特徴を順番に、構築できたものと失敗したものとともに、マテリアル、ソリッドの体積とサイズ |
| `params_list` | 読み取り | パラメーターと、数式で駆動できるすべての数値、その値 |
| `mass_properties` | 読み取り | 体積、面積、重心、その周りの慣性。マテリアルがある場合は質量 |
| `param_set` | 編集 | パラメーターまたは特徴の数値を設定し、再構築します。1回の手順で元に戻せます |
| `script_run` | 編集 | {{ui:スクリプト}}ワークスペースと同じ方法で、CraftScript、Lua、Python のスクリプトを実行します。隔離されており、ファイルもネットワークも使えません。部品は変更されません |
| `part_export` | エクスポート | STL、3MF、STEP、OpenUSD（.usdz、.usda、.usdc）を、{{ui:ファイル}} › {{ui:エクスポート}} が書き出すのと同じ形式で書き出します |
| `link_push` | 編集 | 別のプログラムからリンクされたモデルを更新します（[.3dmモデルを常に最新に保つ](topic:live-3dm-link)を参照） |
| `link_status` | 読み取り | リンクされたモデルがまだあるかどうか、最後に更新された日時を示します |
| `part_save` | 保存 | PartCraftの{{ui:保存}}と同じ操作を行います |
| `illustrate_export` | エクスポート | {{ui:イラスト}}ワークスペースのマニュアルを、ビューのPDFまたはSVGの線画、インタラクティブ3Dファイル、またはPDFかウェブページの{{ui:手順書}}として書き出します。書き出しは、ワークスペースの{{ui:エクスポート}}と{{ui:手順書}}のメニューと同じ方法で行われます（[マニュアル](topic:illustrate)を参照） |

:::note
このビルドはメッシュカーネルを使用しています。体積は三角形から求められるため（真の曲面ソリッドよりわずかに小さくなります）、STEPは厳密な曲面の代わりに三角形を使ってファセット形式で書き出されます。
:::

## 利用者が管理

- **すべての変更は1回の取り消し操作になります**。アシスタント向けのラベルが付き、例えば「Assistant: set l = 45」のように表示されます。{{key:Mod+Z}} を押すと元に戻ります。
- **接続状態が分かります**。接続中は、アプリバーのボタンにアシスタントの名前が表示されます。そのボタンをクリックすると、許可されている操作を確認したり、**切断** したりできます。
- **アクティビティ**。{{ui:設定}} › {{ui:PartCraft}} › {{ui:アシスタント}} › {{ui:アクティビティ}} で、すべての呼び出しを一覧表示します。{{ui:ログを保存}} で写しを保存できます。
- **フォルダー**。アシスタントが読み書きできるのは、追加したフォルダー内のファイルだけです。{{ui:削除}} を押すと、そのフォルダーの許可は直ちに取り消されます。

## PartCraftを開かずに使う

アシスタント用のCadCraftファイルサーバー（`npx @getcadcraft/mcp`）と `cadcraft` コマンドラインは、ウィンドウを開かずに、PartCraft自身のコードとメッシュカーネルで `.partcraft.json` の部品を開きます。同じ読み取りツール、パラメーターの設定、CraftScriptのスクリプト、エクスポート（OpenUSDを含む）、保存が行えます。`cadcraft convert bracket.partcraft.json bracket.stl` は、コマンドラインから部品を構築して書き出します。マニュアル（`.partcraft-manual.json`）も同様にエクスポートできます。`illustrate_export`、または `cadcraft convert linkage.partcraft-manual.json linkage.pdf` を使います（手順書にする場合は `--instructions` を追加します）。

## うまくいかない場合

- **「needs the edit permission」**: {{ui:アシスタント}}の下で **編集** にチェックを入れてから、もう一度依頼します。
- **「driven by the equation」**: その数値は別のパラメーターに従って変化します。代わりにアシスタントにそのパラメーターを設定するよう依頼してください。
- **アシスタントの変更が間違っていた場合**: {{key:Mod+Z}} を押します。
