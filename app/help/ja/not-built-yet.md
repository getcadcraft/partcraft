PartCraft は初期のビルドです。このページには、このビルドで対応していない機能と、現時点での代替手段を記載します。探す時間を無駄にしないためのページです。ここに記載された項目には、予定日はありません。

## 厳密カーネルが必要

このバージョンでは、すべての部品をメッシュカーネル ([メッシュカーネル](topic:solid-kernels) を参照) で作成します。以下のすべては厳密なジオメトリカーネルを必要としますが、このバージョンにはまだありません。これらの機能で保存された部品も開けます。機能は履歴に残り、未作成と表示され、保存時にも保持されます。

| まだ作成されていません | 現時点での代替手段 |
|---|---|
| 丸い辺への {{ui:Fillet}} と {{ui:Chamfer}}。辺に沿って半径が変わるフィレット。交わる箇所で丸みを滑らかに混ぜること (メッシュカーネルでは面取りのように処理されます) | フィレットと面取りは、平らな面どうしを結ぶ直線の辺で動作します。ほかの角は、押し出しの前にスケッチで丸めてください ({{ui:Fillet}} をスケッチで使用、{{key:F}}) |
| 曲面を開く {{ui:Shell}}。肉厚の異なる壁 | 平らな面を開きます。壁を厚くする必要がある箇所は、押し出しで材料を追加してください |

| 複数のボディ: {{ui:Combine}}、{{ui:Move body}}、{{ui:Scale body}}、{{ui:Path pattern}}、新しいボディを作成するフィーチャー | 1 つのソリッド。パターンとミラーはフィーチャーをコピーします |
| 厳密カーネルでしか見つけられない面上のスケッチ、平面、軸、点 (フィレットで作られた面、穴の壁、読み込んだソリッドの面) | 基準平面、参照平面、押し出しと回転の平らな面にスケッチします |

| 図面ビューの真の円弧 | ビューと断面ビューは、ファセットから描画されます |
| 厳密な体積、面積、距離 | {{ui:Measure}} は、ファセット化されたソリッドの数値を示します。丸い部品では少し小さめになります。より細かい **曲線** 設定で、より近い値になります |
