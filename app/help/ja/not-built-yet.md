PartCraft は初期版です。このページでは、まだ対応していない機能と、現時点での代わりの方法を一覧にしています。探す手間を省くためです。ここに記載の機能に予定日はありません。

## 正確なカーネルが必要な機能

このバージョンは、すべてのパーツをメッシュカーネルで作成します（[メッシュカーネル](topic:solid-kernels)を参照）。以下のすべてには正確な形状カーネルが必要ですが、このバージョンにはまだありません。これらの機能を使って保存されたパーツも開けます。フィーチャーは履歴に残り、未作成とマークされ、保存時にも保持されます。

| まだ作成されていない機能 | 現時点での代わりの方法 |
|---|---|
| 丸いエッジへの{{ui:フィレット}}と{{ui:面取り}}; 半径がエッジに沿って変化するフィレット; 交わる箇所で滑らかに混ざり合う丸み（メッシュカーネルではミター処理されます） | フィレットと面取りは、平らな面の間の直線エッジで動作します。ほかの角は、押し出す前にスケッチで丸めてください（スケッチ内の{{ui:フィレット}}、{{key:F}}） |
| 曲面を開く{{ui:シェル}}; 壁の厚さが異なるシェル | 平らな面を開きます。壁を厚くしたい箇所は、押し出しで材料を追加してください |
| 曲面への{{ui:スイープ}}、{{ui:ロフト}}、{{ui:抜き勾配}}; 面、次の面、または頂点までの押し出し; テーパー押し出し | 押し出しまたは回転を、必要に応じて段階的に行います。測定した深さまで押し出してください |
| {{ui:リブ}}、{{ui:ベースフランジ}}、{{ui:エッジフランジ}}、および展開図 | 板またはリブの断面を押し出してください |
| サーフェス: {{ui:フォーム}}をパーツに仕上げる、{{ui:パッチ}}、{{ui:ロフトサーフェス}}、{{ui:ゴルドンサーフェス}}、{{ui:縫い合わせ}}、{{ui:肉厚付け}}、{{ui:サーフェスのオフセット}}、{{ui:サーフェスの延長}}、{{ui:サーフェスのトリム}} | 利用できません |
| 複数のボディ: {{ui:結合}}、{{ui:ボディを移動}}、{{ui:ボディを尺度変更}}、{{ui:パスパターン}}、新しいボディを作成するフィーチャー | 1つのソリッド。パターンとミラーはフィーチャーをコピーします |
| 正確なカーネルでしか見つけられない面上のスケッチ、平面、軸、点（フィレットで作られた面、穴の壁、読み込んだソリッドの面） | 基準平面、参照平面、押し出しと回転の平らな面にスケッチします |
| ジェネレーティブデザインの結果をパーツとして開く、またはパーツに追加する（読み込んだソリッドになります） | 結果を STL または STEP としてダウンロードしてください |
| 開いた STEP ファイルの曲面を正確な曲面として編集すること; STEP ファイルのスプライン、スイープ、回転の面の正確な STEP; スプラインの側面、モデル化されたねじ、STL / OBJ / 3MF のボディとアセンブリ; ほかのパーツモデラー向けの STEP | {{ui:開く}}は STEP を三角形として読み込み、書き出し用にファイルの平らな面、円筒、円錐、球、トーラスを保持します（[STEP ファイルを開く](topic:import-step)）。{{ui:エクスポート}} › {{ui:STEP AP242（厳密ソリッド）}}は、解析的な面をすべて正確に書き出し、それらはファセットとして保持します（[エクスポート](topic:export-files#for-other-cad-programs-step)）。別のパーツモデラー向けのマクロは、引き続き書き出します |
| 図面ビューの正確な円弧 | ビューと断面ビューは、ファセットから描かれます |
| 正確な体積、面積、距離 | {{ui:計測}}はファセットのソリッドの数値を出します。丸い部分では少し低めです。より細かい**曲線**の設定で、より近い値になります |

以下の表の一部の行では、これらの機能のいずれかを、別の目的の代わりとして提案しています。その提案は、正確なカーネルが戻ってから有効になります。

| 結果を、編集可能な（滑らかでパラメトリックな）ソリッドとして | STL、ファセットの STEP、または結果を読み込んだファセットのソリッドとして持つパーツ |
