PartCraft はお使いのコンピューター上のファイルを扱います。パーツをアップロードすることはなく、アカウントやクラウドストレージも使用しません。クラウド保存はまだ利用できません。

## PartCraft で開けるファイル

| ファイル | 拡張子 | 方法 |
|---|---|---|
| PartCraft パーツ | `.partcraft.json` | {{ui:開く}}、{{key:Mod+O}}、または 3D ビューにドロップ |
| PartCraft アセンブリ | `.partcraft-asm.json` | 同じ。PartCraft がどの種類かを判断します |
| STEP ソリッド | `.step`、`.stp` | 三角形で読み込まれるソリッドボディ: [STEP ファイルを開いて作業を続ける](topic:import-step) |

STL、OBJ、3MF のメッシュもソリッドボディとして開けます ([STL、OBJ、3MF を開く](topic:open-meshes))。`.3dm` ファイルも同様です ([.3dm モデルを開く](topic:open-3dm-files))。DXF、IGES、他のプログラムのネイティブなパーツファイルは開けません ([まだ作成されていないもの](topic:not-built-yet) を参照)。

開くときのルール:

- パーツやアセンブリのファイル名は `.json` で終わる必要があり、ファイルは 50 MB 未満である必要があります。
- 何かを表示する前に、ファイルが検査されます。壊れているファイルや編集されたファイルは、「PartCraft のファイルではありません。」など、わかりやすい理由とともに拒否されます。
- 新しい PartCraft で保存されたファイルは拒否されます: 「このファイルは新しい PartCraft で保存されています (ファイルバージョン 3)。このバージョンはバージョン 2 まで読み込めます。」古いファイルは開けます。
- 画面上のパーツに保存されていない変更がある場合、PartCraft は先に確認します: {{ui:キャンセル}}、{{ui:変更を破棄}}、{{ui:先に保存}}。

## 保存

{{ui:保存}} または {{key:Mod+S}} で、画面上の内容を保存します:

- パーツの場合: `<パーツ名>.partcraft.json`。完全な履歴 (スケッチ、拘束、寸法、フィーチャー、ロールバックの位置)、図面シートの断面、詳細図、GD&T の注記、以前のビルドで読み込んだ STEP ソリッドの全テキストを含みます。このバージョンで作成できないフィーチャーは、変更されずに保存されます。ソリッド自体は保存されません。ファイルを開くときに、PartCraft が履歴から再構築します。
- アセンブリの場合: `<アセンブリ名>.partcraft-asm.json`。**すべてのパーツを内部に含みます**。1 つのファイルにアセンブリ全体が含まれるため、それだけを送信できます。

保存は **ダウンロード** です。お使いのブラウザーがファイルをダウンロード フォルダーに保存します。または、保存場所を尋ねるよう設定している場合は、保存場所を確認する画面が表示されます。もう一度保存すると新しいダウンロードが作られます。ブラウザーは古いファイルを置き換えず、`Part1 (1).partcraft.json` のような名前を付けることがあります。ファイルの名前変更や移動は、{{pick:mac=Finder|windows=エクスプローラー|linux=お使いのファイルマネージャー}} でお好きなように行えます。

パーツ名の中にある、英字、数字、スペース、`_`、`.`、`-` 以外の文字は、ファイル名では `_` に置き換えられます。

:::tip
多くのブラウザーには、各ダウンロードの保存場所を尋ねる設定があります。毎回「名前を付けて保存」を選びたい場合はオンにしてください。Chrome と Edge では設定のダウンロードにあります。Firefox では一般の「ファイルとアプリケーション」にあります。Safari では一般の「ファイルのダウンロード先」にあります。
:::

ダウンロードの保存先と、ファイルを安全に保つ方法について詳しくは、[ファイルの保存場所](common:your-files) を参照してください。

## エクスポート

{{ui:エクスポート}} メニューは、他の形式で書き出します。それぞれダウンロードとなり、パーツ名が付けられます。

| メニュー項目 | ファイル | 内容 |
|---|---|---|
| {{ui:STL（3Dプリント用）}} | `<名前>.stl` | ソリッドの三角形によるバイナリ STL。ミリメートル、**Z 軸が上** |
| {{ui:3MF（3Dプリント用）}} | `<名前>.3mf` | ソリッドを 1 つのオブジェクトとして含む 3MF。ミリメートル、**Z 軸が上** |
| {{ui:STEP AP242（厳密ソリッド）}} | `<名前>.step` | 1 つの正確なソリッド。ミリメートル、Z 軸が上。丸い面は真の円柱、円錐、球、トーラス。他の CAD や CAM プログラム用の STEP |
| {{ui:STEP AP214（厳密ソリッド）}} | `<名前>.step` | 同じ正確なソリッドを旧 AP214 スキーマで |
| {{ui:STEP（ファセット、メッシュカーネル）}} | `<名前>.step` | メッシュから作られた平らな面のソリッド: **丸い曲面は多数の小さな平らなファセット**。ミリメートル、PartCraft 独自の軸 (Y 軸が上)。正確なファイルを拒否するプログラム用 |
| {{ui:スケッチまたは平らな面の DXF}} | `<名前> - <スケッチ>.dxf` または `<名前> - face.dxf` | DXF R12。スケッチの場合: 線分、円弧、円、点をスケッチ独自の座標で、レイヤー PROFILE、CONSTRUCTION、POINTS に配置。選択した平らな面の場合: 閉じたポリラインとしての輪郭 (丸いエッジはファセット) |
| {{ui:図面 (PDF): 図、断面、詳細図、幾何公差}} | `<名前> - drawing.pdf` | A3 の図面シート: 3 つのビュー、等角投影、設定されていれば断面と詳細図、全体の寸法、GD&T 記号、表題欄 |

:::note
{{ui:STEP AP242（厳密ソリッド）}} は、穴、ボス、フィレット、円錐、球、トーラスを真の曲面で書き出すため、他のプログラムは穴を円柱として選択できます。**曲線** の設定はこれを変更しません。スプラインの側面、モデル化されたねじ、読み込んだメッシュには正確な曲面がなく、同じソリッド内で平らなファセットのままになります。その数はステータスバーに表示されます。{{ui:STEP（ファセット、メッシュカーネル）}} は、すべての丸い面をファセットとして書き出します。
:::

- エクスポートは、画面上のパーツが対象です。アセンブリではエクスポートがオフになっています。アセンブリのエクスポートはまだありません。
- STL、3MF、ファセット STEP、面 DXF は常にファセットで構成されます。**曲線** の設定 (何も選択されていない状態で右パネルにあります) で、1 周あたり 32 から 256 面の細かさを設定できます。なめらかに印刷したい場合は、STL や 3MF をエクスポートする前に、細かい または非常に細かい を選んでください。
- PDF 図面は、閲覧ソフトに組み込まれた Helvetica フォントを使用します。表示できない文字は「?」と印刷されます。

手順については、[3D プリント、STEP、DXF 用のエクスポート](topic:export-files) と [図面シートの作成](topic:drawing-pdf) を参照してください。

## 保存されていない作業

- PartCraft は、変更の少し後に、開いているパーツやアセンブリの回復用コピーをこのブラウザーに保持します。そのため、クラッシュしたときやタブを閉じたときも失われません。次に PartCraft を開くと「作業内容を復元しますか?」と尋ねます。これは保存ではありません。作業を残すにはファイルに保存してください。[保存されていない作業を復元する](common:recover) を参照してください。
- 保存されていない変更があるままタブを閉じたり再読み込みしたりすると、ブラウザーが「サイトを離れますか?」と尋ねます。これはブラウザー自身の確認画面で、PartCraft では文言を変更できません。
- {{ui:新規}}、{{ui:開く}}、アセンブリを閉じる操作では、保存されていない変更を破棄する前に確認が表示されます。

## オンラインとオフライン

すべての処理はお使いのコンピューター上で行われます。メッシュカーネル (WebAssembly プログラム) はアプリと一緒にダウンロードされ、ジオメトリをローカルで作成します。ファイルはディスクから読み書きされます。パーツのデータがネットワークを通ることはありません。[メッシュカーネル](topic:solid-kernels) を参照してください。

接続がまったくない状態で作業するには、オンラインのときに PartCraft をオフラインで使えるように保存します。アプリバーの {{ui:オフライン用に保存}} を選び、「40 / 212 を保存中」のようにカウントが進むのを待ち、**オフライン準備完了** と表示されるまで待ちます。保存されたコピーには、3D ライブラリとメッシュカーネルが含まれるため、その後はモデリング、保存、すべてのエクスポート、図面がすべてオフラインで動作します。**保存できませんでした** と表示された場合は、オンラインの状態でクリックして再試行してください。**オフラインで利用できません** と表示された場合は、このブラウザーウィンドウがコピーを保持できないことを意味します (プライベートウィンドウや、一部の管理されたコンピューター)。コピーが保存されていれば、**オフライン準備完了** をクリックすると、{{ui:もう一度保存(最新バージョンを取得)}} と {{ui:オフライン用コピーを削除}} が表示されます。詳しくは [オフラインでの作業](common:offline) を参照してください。

:::online
オンラインです。オフライン用に保存していなくても、PartCraft が読み込まれ、ステータスバーのチップに「メッシュカーネル」と表示されれば、接続が切れても作業を続けられます。接続が戻るまで、このページを再読み込みしないでください。
:::

:::offline
オフラインです。PartCraft がすでに開いている場合は、作業を続けられます。保存とエクスポートも動作します。アプリバーに **オフライン準備完了** と表示されていれば、PartCraft は接続なしでも最初から開けます。そうでなければ、このタブを再読み込みしないでください。
:::

## ブラウザーによる違い

- **ダウンロード。** 各ブラウザーには独自のダウンロード フォルダーと、保存場所を尋ねる方法があります。ブラウザーがこのサイトにファイルのダウンロードを許可するか尋ねてきた場合は、許可してください。許可しないと、保存もエクスポートもできません。
- **ファイルのドラッグ アンド ドロップ** でビューに配置する操作は、Chrome、Edge、Firefox、Safari で動作します。
- **スマートフォンやタブレットからのファイル。** iPhone と iPad では、「開く」を選ぶと「ファイル」アプリが表示されます。保存したファイルは「ファイル」の「ダウンロード」に保存されます。Android では、ダウンロード フォルダーに保存されます。

ブラウザーやオペレーティングシステムによって、ファイルの内容が変わることはありません。
