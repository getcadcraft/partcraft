モデルの形状の作成は、モデリングしている場所で続け、加工、確認、文書化はここで行います。他のプログラムで変更するたびに、PartCraft で読み込んだ本体が 1 つ置き換えられ、その後にあるフィーチャーが新しい形状で再構築されます。

:::note
このリンクには、同じコンピューターに **CadCraft Studio** が必要です。ブラウザーのタブでは接続できません。データはインターネットを経由しません。スクリプトは、このコンピューター自身のアドレスで Studio と、トークンを使って通信します。
:::

:::warning
このリンクは、スクリプトのファイル書き出し機能と、他のプログラムの代わりになるものでテストされています。Rhino や Grasshopper 本体ではまだテストされていません。そこで何か失敗した場合は、表示されたメッセージを教えてください。
:::

## 設定する

1. Studio で PartCraft を開きます。{{ui:設定}} › {{ui:PartCraft}} › {{ui:アシスタント}} で **AI アシスタントとスクリプトに PartCraft の使用を許可する** にチェックを入れ、次に **編集** を押します。
2. Studio で {{ui:アシスタントを接続}} を選びます。下に貼り付けるアドレスとトークンが表示されます。
3. スクリプトをダウンロードします: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)。

## Rhino から

1. Rhino のスクリプトエディターで `cadcraft_link.py` を実行します（Rhino 8 では Python 3）。
2. 初回は、アドレスとトークンを貼り付けます。これらは `.cadcraft-link.json` に保存されます（ホームフォルダー内。モデルには保存されません）。Studio は起動するたびに新しいトークンを作るため、その場合はスクリプトが再度尋ねます。

もう一度スクリプトを実行すると停止します。

## Grasshopper から

最初に Rhino でスクリプトを一度実行し、アドレスとトークンを保存しておきます。

1. スクリプトコンポーネント（Python 3）を追加し、`cadcraft_link.py` の全体を貼り付けます。
2. 次の入力を与えます: `G`（ジオメトリ。リストアクセス付き）、`N`（名前。任意）、`On`（ブール値のトグル）、`Target`（任意。`model` または `part`。両方のアプリが開いている場合）。
3. `On` を true にします。

計算のたびに `G` が送られ、前回このコンポーネントが送ったものが置き換えられます。

## 仕組み

- **1 つの本体。** モデル内で見えるものはすべて、[.3dm ファイルを開く](topic:open-3dm-files) ときと同じように、1 つの読み込みフィーチャーになります。
- **閉じている必要があります。** PartCraft は小さな穴と平らな開口を埋めます。その数は他のプログラムにも伝えられます。モデルがまだ閉じていない場合、PartCraft は前の本体を保持し、ステータスバーにその旨を表示します。次に閉じる変更で本体が更新されます。
- **作業を終えてください。** スケッチまたは図面では、更新は拒否され、後で再試行されます。モデルに戻ると反映されます。
- **元に戻す。** 2 秒以内の更新は、1 回の元に戻す操作にまとめられます。
- **保存。** パーツファイルはリンクを保持します。ファイルを開き直したあとは、スクリプトを再度実行してください。同じフィーチャーが更新されます。

**一方向のみです。** ここでの変更は、他のプログラムには戻りません。

## うまくいかないとき

- **「ModelCraft または PartCraft のウィンドウで許可されていません」:** 設定の手順 1 を行ってください。
- **「Studio がトークンを拒否しました」:** Studio が再起動しています。新しいトークンをコピーして、スクリプトを再度実行してください。Grasshopper の場合は、先に Rhino で実行してください。
- **「CadCraft Studio に接続できません」:** Studio が実行されていないか、アドレスが変わっています。
