すべてのソリッドは、平面上の平らな図であるスケッチから始まります。このチュートリアルでは描画ツールを扱います。拘束と寸法でスケッチを固定する方法は[スケッチを完全に定義する](topic:relations-dimensions)を参照してください。

## スケッチを開始する

基準平面、またはパーツの任意の平らな面にスケッチできます。

1. スケッチする場所を選びます:
   - 基準平面: 履歴の**正面平面**、**上面平面**、**右面平面**をクリックするか、ビューで平面をクリックします。
   - 平らな面: ビューで面をクリックします。面全体がハイライト表示されます。
2. ツールバーの{{ui:スケッチ}}を選ぶか、{{key:S}}キーを押します。(面を選択している場合は、右側のパネルで{{ui:この面にスケッチ}}も選べます。平面を選択している場合は{{ui:この上にスケッチ}}を選べます。)

ビューが平面に対して正面を向き、ツールバーにスケッチツールが表示され、線分ツールがすぐに使える状態になります。何も選択せずに{{ui:スケッチ}}を押すと、基準平面が表示され、ステータスバーに「スケッチする平面または平らな面をクリックしてください。Escで停止します。」と表示されます。

:::note
曲面にはスケッチを置けません。「その面は曲面です。スケッチする平らな面または平面を選んでください。」と表示されます。
:::

**面上のスケッチはその面に追従します。** 面がスケッチの辺または押し出しの端面で作られている場合、フィーチャーが変わると新しいスケッチも移動します(深いポケットは、その底面のスケッチも一緒に移動させます)。パネルに面が「選択した位置に固定」と表示されている場合は、スケッチは現在の面の位置に留まります。

## 描画ツール

各ツールにはツールバーのボタンとキーがあります。同じボタンをもう一度選ぶか、{{key:S}}キーを押すか、{{key:Esc}}キーを押すと、選択に戻ります。

| ツール | キー | 描き方 |
|---|---|---|
| {{ui:線分}} | {{key:L}} | 始点をクリックし、次の点を順にクリックします。線分は端から端までつながります。連結を終了するには、{{key:Esc}}、{{key:Enter}}、右クリック、またはダブルクリックします。既存の点をクリックしても終了します |
| {{ui:長方形}} | {{key:R}} | 1つの隅をクリックし、反対側の隅をクリックします。角でつながった4本の線分(水平2本、垂直2本)ができます |
| {{ui:円}} | {{key:C}} | 中心をクリックし、円周上の点をクリックします |
| {{ui:円弧}} | {{key:A}} | 中心、始点、終点の順にクリックします。円弧は、中心の周りをポインターを動かした向きに描かれます |
| {{ui:点}} | {{key:P}} | クリックします。単独の点は{{ui:穴}}の穴の中心を示します |
| {{ui:中心線}} | {{key:N}} | 線分と同様に、1区間ずつ描きます。破線で描かれ、補助ジオメトリであり、回転の軸や基準として使います |
| {{ui:フィレット}} | {{key:F}} | 2本の線が交わる角をクリックし、半径を入力して{{key:Enter}}を押します |
| {{ui:スプライン}} | {{key:B}} | 曲線が通る点をクリックします。{{key:Enter}}で終了し、最初の点をクリックすると閉じます。[スプライン、トリム、オフセットその他のスケッチツール](topic:sketch-tools)を参照してください |
| {{ui:トリム}} | {{key:T}} | 取り除く曲線の部分をクリックします。最も近い交点までが対象になります |
| {{ui:寸法}} | {{key:D}} | [スケッチを完全に定義する](topic:relations-dimensions)を参照してください |

描いている間、ポインターの横の小さなボックスに、長さ、サイズ、直径、または半径が表示されます。

### 描きながらサイズを入力する

線分、長方形、円、円弧の最初のクリックの後は、クリックする代わりにサイズを入力できます。数値を入力すると、ポインターの横のボックスが開き、その数値が入ります:

| ツール | 入力欄({{key:Tab}}で次の欄へ移動) | {{key:Enter}}を押したときの動作 |
|---|---|---|
| {{ui:線分}}、{{ui:中心線}} | 長さ、次にスケッチのX軸からの角度(°) | 線分は指定の長さで、ポインターの方向または入力した角度で描かれます。連結はその端から続きます |
| {{ui:長方形}} | 幅、次に高さ | 長方形は最初の隅からポインターの方向に描かれます。入力しなかったサイズはポインターの位置から決まります |
| {{ui:円}} | 直径 | 指定した直径で円が描かれます |
| {{ui:円弧}} | 中心の後に半径、次に始点の後に円弧の角度(°) | 始点は中心から指定の距離に置かれます。その後、ポインターを動かした向きに、指定の角度だけ円弧が描かれます |

入力したサイズはそれぞれ、同じ操作で**駆動寸法**になるため、スケッチは寸法どおりに作られます。{{key:Mod+Z}}を押すと、形状とその寸法がまとめて取り消されます。{{key:Enter}}ではなくクリックした場合は、入力した値を保持し、残りはクリック位置から決まります。{{key:Esc}}でボックスを閉じると、ポインターの操作に戻ります。

クリックだけで描きたい場合は、{{ui:設定}} › {{ui:PartCraft}} › **描きながら寸法を付ける**をオフにします。[PartCraftの設定](topic:settings)を参照してください。

スケッチツールの末尾にある{{ui:その他}}には、制御点スプライン、延長、オフセット、ミラー、ポリゴン、スロット、スケッチパターン、エッジを投影が含まれます。[スプライン、トリム、オフセットその他のスケッチツール](topic:sketch-tools)を参照してください。

### スナップ

スナップは拘束を自動で追加するため、スケッチは移動しても接続されたままになります:

- **端点または原点**にスナップすると、小さな正方形が表示されます。新しい点はその点と一致させられます。
- **線分、円、または円弧**にスナップすると、小さな十字が表示されます。新しい点はその曲線上に置かれます。
- 水平または垂直から3度以内の線分は、水平または垂直にスナップされ、水平または垂直の拘束が付きます。ラベルに「H」または「V」が表示されます。

スナップを避けるには、ズームインして、点や曲線から離れた位置をクリックします。

## 角を丸める

1. {{key:F}}キーを押すか、{{ui:フィレット}}を選びます。
2. 2本の線分が交わる角の点をクリックします。
3. 推奨半径が入ったボックスが開きます。半径を入力して{{key:Enter}}を押します。

両方の線分はトリムされ、半径寸法の付いた接線円弧でつながれます。表示される可能性のあるメッセージ: 「フィレットには、ちょうど2本の線が交わる角が必要です。」、「この半径は、これらの線には大きすぎます。」

:::tip
スケッチのフィレットはプロファイルの角を丸めるため、押し出し後は縦のエッジが丸くなります。ソリッド自体のエッジ(たとえば板の上端のエッジ)を丸めるには、代わりにパーツの{{ui:フィレット}}フィーチャーを使います。[丸め、面取り、シェル](topic:fillet-chamfer-shell)を参照してください。スケッチでは、ツールバーの{{ui:フィレット}}がスケッチツールです。パーツでは、フィーチャーになります。
:::

## 補助ジオメトリ

補助ジオメトリの線分、円、円弧は、グレーの破線で表示されます。スケッチを導くためのもので、押し出しや回転の対象になるプロファイルには含まれません。

1. 線分、円、または円弧を選択します。
2. {{key:Q}}キーを押すか、{{ui:補助ジオメトリ}}を選びます。もう一度押すと元に戻ります。

## 選択、ドラッグ、削除

選択するには{{key:S}}キーを押します(または、ツールが有効でなくなるまで{{key:Esc}}を押します)。

- 点、線分、円、円弧、拘束記号、または寸法をクリックして選択します。{{key:Shift}}+クリックで選択に追加、または選択から外します。WindowsとLinuxでは{{key:Ctrl}}+クリックで同じことができます。Macでは⌘+クリックです。
- 何もない場所でドラッグすると窓選択の枠が描かれ、枠の中に完全に含まれるものがすべて選択されます。
- 点または線分をドラッグして移動します。ソルバーは移動中もすべての拘束と寸法を保つため、自由な形状だけが動きます。円の縁をドラッグすると、半径を変えられます。
- 寸法の数値をドラッグすると、ラベルを移動できます。
- {{key:Delete}}または{{key:Backspace}}を押すか、右側のパネルで{{ui:削除}}を選ぶと、選択したものが削除されます。形状を削除すると、その形状の拘束も削除されます。

## スケッチ内でのズームとパン

- ホイールを回すと、ポインターの位置を中心にズームします。
- 中ボタンまたは右ボタンでドラッグすると、パンします。
- ツールバーまたは右側のパネルの{{ui:全体表示}}は、スケッチをビューに合わせて表示します。スケッチでは{{key:F}}キーはフィレットツールで、全体表示ではありません。

## スケッチを閉じる

ツールバーの{{ui:終了}}、または右側のパネルの{{ui:スケッチを終了}}を選ぶか、スケッチが閉じるまで{{key:Esc}}を押します。{{key:Esc}}を押すたびに、まず進行中の操作が取り消され、次に選択ツールに戻り、次に選択が解除されます。その次の{{key:Esc}}でスケッチが閉じます。

スケッチは選択されたままになるため、次の{{ui:押し出し}}または{{ui:回転}}で使われます。

## 適切なプロファイルとは

{{ui:押し出し}}と{{ui:回転}}は、スケッチのうち補助ジオメトリ以外の実線の線分、円、円弧、スプラインのすべての閉じたループを使います。ループの内側のループは穴になります。

- 各端点は、必ずほかの端点1つと一致しなければなりません。「プロファイルが開いています: (12.5, 40) の端点はどこにも接続されていません。」のように、問題の位置が示されます。
- 3つ以上の端点が1点で交わってはいけません: 「プロファイルが(0, 20)で分岐しています: 2つを超える端点が交わっています。」
- 点と補助ジオメトリは、プロファイルでは無視されます。

## 写真からスケッチ

**フィーチャー › {{ui:その他}} › 写真からスケッチ…**(またはフィーチャーツリーのリボンにあるスケッチグループ)は、平らな地面に置かれた平らなパーツの写真(輪郭と穴)、またはペン描きの図を、線分、円弧、円のスケッチにトレースします。寸法の基準として長さを1つ(幅、高さ、または最長辺)指定し、プレビューで検出された内容を確認して、**スケッチを作成**を選びます。同じ元に戻す操作の中で押し出すこともできます。トレースはこのコンピューター上で行われます。角の半径は約5%の誤差に収まり、1〜2ピクセルの細部は失われます。斜めから撮影した写真や、パーツ全体に影が落ちている写真は補正されません。パーツを正面から、均一な照明で撮影してください。
