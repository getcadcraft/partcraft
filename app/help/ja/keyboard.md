パネル内のボックスに入力している間は、キーは動作しません。ただし {{key:Mod+S}} と {{key:Mod+O}} は常に動作します。文字キーは修飾キーなしで動作します。

ブラウザーでのキーの一般的な注意点や、ファンクションキーのないキーボードについては、[キー、マウス、トラックパッド](common:keys) を参照してください。

## すべての場所

| キー | 操作 |
|---|---|
| {{key:Mod+S}} | パーツを保存します（アセンブリ内ではアセンブリを保存）。開いているスケッチがあれば、先に閉じます |
| {{key:Mod+O}} | パーツまたはアセンブリのファイルを開きます（保存されていない変更がある場合は先に確認します） |
| {{key:Mod+Z}} | 元に戻す |
| {{key:Mod+Y}} または {{key:Mod+Shift+Z}} | やり直し |
| {{key:F1}} | このヘルプを開く、または閉じます（アプリバーの {{ui:ヘルプ}} と同じです）。{{key:Esc}} でも閉じられます。多くのノートパソコンや Mac のキーボードでは Fn を押しながら使います |
| {{key:Ctrl+Shift+F}} | 画面モードを切り替えます: 通常、全画面、バーを隠した全画面。Mac でも Control を使い、⌘ は使いません |
| {{key:Esc}} | 全画面を終了します（全画面表示中のみ） |
| {{key:Mod+,}} | 設定。PartCraft タブを含みます（[PartCraft の設定](topic:settings) を参照） |

パネル内の数値ボックスでは、{{key:Mod+Z}} はブラウザー自身のテキストの元に戻すになります。スケッチ寸法の上にある数値ボックスでは、PartCraft で元に戻します。

## コピー、貼り付け、複製

これらは作業中のものに作用します。開いているスケッチで選択した図形、履歴で選択したフィーチャー、またはアセンブリで選択したパーツです。詳しくは [コピー、貼り付け、複製](topic:copy-paste) を参照してください。

| キー | 操作 |
|---|---|
| {{key:Mod+C}} | 選択をコピー |
| {{key:Mod+X}} | 切り取り: コピーしてから削除 |
| {{key:Mod+V}} | 貼り付け。スケッチでは、コピーはポインターに追従します。置きたい場所をクリックしてください |
| {{key:Mod+Shift+V}} | 同じ位置に貼り付け: 同じ座標に貼り付けます（アセンブリでは同じ場所） |
| {{key:Mod+D}} | 複製: コピーと貼り付けを 1 回の操作で行い、クリップボードは変更しません |
| {{key:Mod+A}} | すべて選択（スケッチ内） |
| {{key:Esc}} | 選択解除（ポインターに追従する貼り付けも取り消します） |

数値ボックス内では、これらのキーは通常どおりテキストをコピーおよび貼り付けします。パネル内で選択したテキストは、ブラウザーがコピーします。

## パーツ上（スケッチを開いていないとき）

| キー | 操作 |
|---|---|
| {{key:S}} | 選択した平面または平らな面にスケッチします。何も選んでいない場合は、クリックして場所を指定します |
| {{key:F}} | パーツをビューに合わせます |
| {{key:M}} | 計測。すべてのワークスペースとアセンブリで使えます。{{key:Esc}} で選択をクリアし、もう一度 {{key:Esc}} で閉じます（[距離、角度、質量を計測](topic:measure) を参照） |
| {{key:X}} | 断面ビューのオン／オフ。すべてのワークスペースとアセンブリで使えます。{{key:Esc}} で閉じます（[断面ビューで内部を表示](topic:section-view) を参照） |
| {{key:Delete}} | 選択したフィーチャーを削除します（他で使われている場合は確認します） |
| {{key:0}} … {{key:9}}, {{key:.}} | フィーチャーを選択した状態で、その主な数値（押し出しの深さ、穴の直径、パターンの数、フィレットの半径など）を入力し、{{key:Enter}} を押します。{{key:Esc}} で元の値を保持します |
| {{key:Backspace}} | フィーチャーが選択されているとき、そのフィーチャーを削除します |
| {{key:Esc}} | スケッチ平面の選択を中止するか、選択をクリアします（{{key:Shift}} で選んだエッジや面を含みます） |

## 3D ビュー内

先にビューをクリックして、キーボードのフォーカスを与えてください。

| キー | 操作 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | ビューを 15 度回転します |
| {{key:Shift+Left}} などの矢印 | パン |
| {{key:Plus}} または {{key:=}} | ズームイン |
| {{key:Minus}} | ズームアウト |

| マウス | 操作 |
|---|---|
| 左ボタンでドラッグ | ビューを回転（軌道回転） |
| 右ボタンまたは中ボタンでドラッグ | パン |
| 左ボタンでドラッグしながら {{key:Shift}}、{{key:Ctrl}}、または ⌘ を押す | パン |
| ホイールを回す | ポインターの位置でズーム（手前に回すとズームイン） |
| トラックパッドで 2 本指スワイプ | ビューを回転します。{{key:Shift}} を押しながらならパン。ピンチでズームします。[PartCraft の設定](topic:settings) の **スクロール** で設定します |

[PartCraft の設定](topic:settings) で **ビューの回転: 中ボタン** を選ぶと、中ボタンでビューを回転し、{{key:Shift}} と中ボタン、または右ボタンでパンします。左ボタンは選択だけに使われます。
| クリック | 面（面全体がハイライトされます）、エッジ、または平面を選択 |
| {{key:Shift}}+エッジまたは面をクリック | 複数のエッジまたは面を集めます |
| 何もない場所をクリック | 選択をクリア |

## フィレット、面取り、シェルのためにエッジや面を選択中

| キーまたはマウス | 操作 |
|---|---|
| エッジまたは面をクリック | 追加します。すでに含まれていれば外します |
| {{key:Esc}} または {{key:Enter}} | 選択を完了（{{ui:完了}} と同じです） |
| {{key:F}} | ビューに合わせる |
| 矢印キー（ビューにフォーカスがあるとき） | 回転。{{key:Shift}} を押すとパン |

## 図面シート上

| キー | 操作 |
|---|---|
| {{key:F}} | シートをビューに合わせる |
| {{key:Plus}} / {{key:Minus}} | ズーム（シートにフォーカスがあるとき） |
| {{key:Shift+Left}} などの矢印 | パン（シートにフォーカスがあるとき） |
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 選択した幾何公差記号を 1 mm 動かす |
| {{key:Delete}} または {{key:Backspace}} | 選択した記号を削除 |
| {{key:Esc}} | 記号の配置を中止。それ以外は選択を解除。さらにそれ以外はモデルに戻ります |

| マウス | 操作 |
|---|---|
| データム、公差枠、仕上げ、詳細のいずれかを選んだ状態で、ビュー上をクリック | その位置に配置します（最も近い線にスナップします） |
| 記号をクリック | 選択 |
| 記号をドラッグ | 移動（引出線は同じ点に残ります） |
| ホイールを回す | ポインターの位置でズーム |
| 右ボタンまたは中ボタンでドラッグ | パン |

| キー | 操作 |
|---|---|
| {{key:L}} | 線分 |
| {{key:R}} | 長方形 |
| {{key:C}} | 円 |
| {{key:A}} | 円弧（中心、始点、終点） |
| {{key:P}} | 点 |
| {{key:N}} | 中心線 |
| {{key:F}} | 角をフィレット |
| {{key:D}} | 寸法 |
| {{key:B}} | スプライン（フィット点） |
| {{key:T}} | トリム |
| {{key:E}} | 延長 |
| {{key:O}} | オフセット（オフセット中に {{key:B}} を押すと両側） |
| {{key:M}} | 鏡像 |
| {{key:S}} | 選択 |
| {{key:Q}} | 選択した曲線を補助ジオメトリに切り替え、また戻します |
| {{key:Enter}} | 線分のチェーンまたはスプラインを終了 |
| {{key:Delete}} または {{key:Backspace}} | 選択を削除 |
| {{key:Mod+A}} | スケッチ内のすべてを選択 |
| {{key:Mod+C}} / {{key:Mod+X}} / {{key:Mod+V}} | 図形のコピー、切り取り、貼り付け（貼り付けはポインターに追従します） |
| {{key:Mod+Shift+V}} | 同じ座標に貼り付け |
| {{key:Mod+D}} | 選択を複製し、クリックして配置 |
| {{key:Esc}} | 1 段階戻ります: 数値ボックスまたは貼り付けを取り消す、線分のチェーンを終了する、選択ツールに戻る、選択をクリアする、最後にスケッチを閉じる |

| マウス | 操作 |
|---|---|
| クリック | 作図ツールで点を配置。選択ツールで選択 |
| {{key:Shift}}+クリック | 選択に追加、または選択から外す（Windows と Linux では {{key:Ctrl}}+クリック、Mac では ⌘+クリックでも同じ） |
| 何もない場所でドラッグ（選択）| 窓選択: 完全に内側にあるものをすべて選択 |
| 点、線、円のエッジをドラッグ（選択）| 移動。拘束は保たれます |
| 寸法の数値をドラッグ（選択）| ラベルを移動 |
| 寸法をダブルクリック | 値を変更 |
| 線を描いている間にダブルクリックまたは右クリック | チェーンを終了 |
| 右ボタンまたは中ボタンでドラッグ | パン |
| ホイールを回す | ポインターの位置でズーム |

### 数値ボックス内

| キー | 操作 |
|---|---|
| {{key:Enter}} | 値を適用 |
| {{key:Esc}} | 変更せずに閉じる |

数値ボックスの外をクリックしても、値が適用されます。

|---|---|
| {{key:Tab}} | リストに移動 |
| {{key:Up}} / {{key:Down}} | 行の間を移動 |
| {{key:Enter}} または {{key:Space}} | 行を選択 |

| {{key:F2}} | 行内でフィーチャーの主な数値を変更。{{key:Enter}} で設定、{{key:Esc}} で元の値を保持 |

|---|---|
| クリック | 平面またはフィーチャーを選択 |

| キー | 操作 |
|---|---|
| {{key:J}} | ジョイントを開始。次に 2 つのパーツそれぞれの平らな面をクリック |
| {{key:F}} | ビューに合わせる |
| {{key:Esc}} | 開始したジョイントをキャンセル、または選択をクリア |
| {{key:Delete}} | 選択したパーツまたはジョイントを取り除く |
| {{key:Backspace}} | 選択したパーツまたはジョイントを取り除く |
| {{key:Mod+Z}} / {{key:Mod+Y}} | アセンブリ独自のリスト内で元に戻す／やり直し |
| {{key:Mod+D}} | 選択したパーツを複製（同じパーツを他のパーツの横に配置） |
| {{key:Mod+C}}、次に {{key:Mod+V}} または {{key:Mod+Shift+V}} | パーツをコピーし、他のパーツの横、または同じ位置に貼り付け |

ビュー内のマウス操作は、上の「3D ビュー内」と同じです。パーツをクリックすると選択します。リストでパーツをダブルクリックすると編集します。

## スクリプトワークスペース内

| キー | 操作 |
|---|---|
| {{key:F5}} | スクリプトを実行（エディター、パネル、ビューのどこからでも） |
| {{key:Mod+Enter}} | 選択した行、またはカーソルのある行を実行 |
| {{key:Tab}} / {{key:Shift+Tab}} | 選択した行をインデント／インデント解除。キーボードでエディターを離れるには、{{key:Esc}} を押してから {{key:Tab}} を押します |
| {{key:Mod+/}} | 選択した行をコメントアウト、またはコメントを戻す |
| {{key:Mod+F}} / {{key:Mod+H}} | スクリプト内で検索／検索と置換。{{key:Enter}} または {{key:F3}} で次の一致、{{key:Shift+Enter}} または {{key:Shift+F3}} で前の一致、{{key:Esc}} で閉じます |
| {{key:Mod+Shift+[}} / {{key:Mod+Shift+]}} | カーソルのあるブロック（function、if、for、while … end）を折りたたむ／展開する |

詳しくは [スクリプトを書いて実行](topic:craftscript) を参照してください。

## ブラウザーが処理する可能性のあるショートカット

- {{key:Mod+Y}} は Safari では履歴を開くことがあります。やり直しには {{key:Mod+Shift+Z}} を使ってください。
- {{key:Mod+D}} はブラウザーのブックマークのキーです。PartCraft はアプリにフォーカスがある間それを使い、ボックスに入力中は触れません。
- {{key:F11}} と {{key:Mod+Plus}} / {{key:Mod+Minus}} はブラウザーの全画面とページのズームで、PartCraft のものではありません。全画面には {{key:Ctrl+Shift+F}}、モデルのズームにはホイールを使ってください。
- 多くのノートパソコンや Mac のファンクションキーでは Fn キーが必要です。ヘルプを開くには Fn+{{key:F1}} を押すか、{{ui:ヘルプ}} ボタンを使ってください。

タッチとトラックパッドのジェスチャーについては、[トラックパッド、タッチ、小さな画面](topic:trackpad-and-touch) を参照してください。

## 移動の場所

移動は、フィーチャー グループの {{ui:その他}} メニューにある {{ui:ボディを移動}} にあります。ΔX、ΔY、ΔZ を入力する {{ui:移動}} ボックスにもあり、パーツ上の {{ui:ドラッグで移動}} の矢印としても使えます。
