:::note
**このバージョンではまだ作成されていません。** 複数のボディを扱うには厳密なジオメトリカーネルが必要ですが、このバージョンの PartCraft にはありません。すべての部品はメッシュカーネルで作成されます。代わりにする方法は [まだ作成されていない機能](topic:not-built-yet) を参照してください。このページの残りの部分は、厳密カーネルを使った場合の動作を説明しています。
:::

部品は複数の立体を持つことができます。個々の独立した立体は **ボディ** です。ほとんどのフィーチャーは、接触するすべてのボディに対して追加または切り取りを行います。このページのツールは、選択したボディ全体を操作します。これらは、フィーチャーグループの {{ui:その他}} メニューにあります: {{ui:結合}}、{{ui:ボディを移動}}、{{ui:ボディを尺度変更}}、{{ui:パスパターン}}。これらはすべて厳密カーネル (OpenCascade) が必要です。

## 独立したボディを作成

押し出しまたは回転の右パネルで、**操作** を **新しいボディ** に設定します (スイープとロフトにもあります)。新しい立体は、他の立体と重なっていても別々のままになります。**交差** は、新しい形状と既存の形状の重なり部分だけを残します。

ボディは、そのボディを作成したフィーチャーにちなんで名前が付きます: 「Extrude2」。コピーは、元のボディとコピーしたフィーチャーにちなんで名前が付きます: 「Extrude2, copy 1 of Move1」。上流の寸法を変更しても名前は変わらないため、そのボディを使うフィーチャーは引き続きボディを見つけられます。ボディが 2 つ以上ある場合、部品パネル (何もない場所をクリック) に、ボディの一覧とその体積が表示されます。

## ボディの名前変更または非表示

ビュー内の何もない場所をクリックすると部品パネルが表示されます。ボディの一覧 (部品にボディが 2 つ以上ある場合に表示) には、各行に名前ボックスと {{ui:非表示}} ボタンがあります。

- **名前変更:** 名前ボックスに新しい名前を入力し、{{key:Enter}} を押すか、別の場所をクリックします。結合、ボディを移動、パターンなど、すべてのパネルでこの名前が使われます。ボックスを空にすると、ボディを作成したフィーチャーの名前に戻ります。
- **非表示:** 行の {{ui:非表示}} をクリックします。ボディはビューから消え、クリックはそのボディを通過するため、その後ろの面を選択できます。{{ui:表示}} で再表示され、{{ui:すべて表示}} で非表示のボディがすべて再表示されます。

非表示は表示だけを変更します。非表示のボディも引き続き作成され、体積や計測に含まれ、STL、3MF、STEP の書き出しにも保存されます。名前と非表示のボディは部品ファイルに保存され、各変更は {{ui:元に戻す}} の 1 回分になります。

## ボディを結合

1. {{key:Shift}}+クリックで、**対象ボディ** の面を選択し、次に各 **ツールボディ** の面を選択します。
2. {{ui:その他}} を選び、続けて {{ui:結合}} を選びます。
3. 右パネルで **操作** を選びます:

| 操作 | 結果 |
|---|---|
| 結合 | 対象とツールが 1 つのボディになります |
| 切り取り | 対象からツールが取り除かれます |
| 交差 | 対象とすべてのツールが共有する部分だけが残ります |

**対象ボディ** は、名前をそのまま保持するボディです。**ツールボディ** にチェックを付けるか外すか、**ビューで選択** を使ってその面をクリックします。**ツールボディを保持** を選ぶと、ツールも元の位置に残ります (金型とその中子に便利です)。ツールボディが以前の結合ですでに使われている場合、パネルは別のボディを選ぶのではなく、その旨を表示します。

## ボディの移動またはコピー

1. {{ui:その他}} を選び、続けて {{ui:ボディを移動}} を選びます。最新のボディにチェックが付いています。移動するボディにチェックを付けます。
2. **移動** の種類を選びます:

| 移動 | 設定内容 |
|---|---|
| 平行移動 | ミリメートル単位の **ΔX**、**ΔY**、**ΔZ** |
| 2 点間 | **開始** と **終了**: エッジの端、点フィーチャー、または面上の点の近くをクリックします |
| 軸周りの回転 | **軸** (X、Y、Z、軸フィーチャー、または **選択**: 直線エッジ、円、円筒) と **角度 (°)** |
| 面を面または平面に位置合わせ | **移動する面** (ボディの平らな面)、**合わせ先** (平らな面または平面) |

位置合わせでは、ボディの面が相手の面に重なるように回転させ、その後、その面の法線方向にのみ滑らせます。**同じ向き** を選ぶと、向きが逆になります。**コピー** は元のボディを残し、移動したコピーを新しいボディとして追加します。

## ボディの尺度変更

1. {{ui:その他}} を選び、続けて {{ui:ボディを尺度変更}} を選び、ボディにチェックを付けます。
2. **尺度** を入力するか、**均一** のチェックを外して **X 方向の尺度**、**Y 方向の尺度**、**Z 方向の尺度** を入力します (ワールド軸に沿って)。
3. **基準** は位置が変わらない点です。ボディのボックスの中心、または選択した点です。

均一な尺度変更は正確です。不均一な尺度変更では円が楕円に変わります。円筒は楕円筒になり、解析的な曲面では表せないため、曲面は B スプライン曲面になります。その誤差は正確な形状から 0.0000004 mm 以内に収まります。平面と直線のエッジは正確なままです。パネルには、どの方法が使われたかが表示されます。倍率は 0 より大きい値が必要です (代わりに {{ui:ミラー}} を使ってください)。

## パスに沿ってコピー

1. 履歴でコピーするフィーチャーを選択します。何も選択しない場合は、最新のボディをコピーします。
2. {{ui:その他}} を選び、続けて {{ui:パスパターン}} を選びます。使われていない最新のスケッチがパスとして使われます。
3. 右パネルで次を設定します:

| 設定 | 内容 |
|---|---|
| **コピー** | ボディ (各コピーが新しいボディになります) または フィーチャー (元と同様に結合または切り取られます) |
| **パス** | スケッチにチェックを付けるか、**モデルのエッジを選択**。各部分は端どうしでつながっている必要があります |
| **個数** | 元のボディを含めた合計数 |
| **間隔** | 等間隔 (開いたパスの終点まで、または閉じたパスの全周に配置) または指定距離 |
| **向き** | パスに沿う (各コピーがパスに合わせて回転) または 固定 (コピーは平行を保ちます) |
| **進行方向を反転** | パスを逆方向に進みます |

コピーは、パスが元のボディに最も近い位置から始まり、曲線に沿った長さで間隔が決められます。

{{ui:直線}} パターンと {{ui:円形}} パターンでも、ボディをコピーできます。パネルで **ボディをコピー** にチェックを付け、ボディを選択します。各コピーは新しいボディになります。

## 制限

- ボディには厳密カーネルが必要です。メッシュカーネルでは 1 つの立体のみを保持し、その旨を表示します。
- 不均一な尺度変更では、曲面は (上記のとおり) 近似の B スプラインになります。正確な円筒や円錐にはなりません。オフセット曲面は、まだこの方法で尺度変更できません。
- ねじれた 3D 曲線に沿う場合、コピーはねじれずに移動します。平らなパスでは、回転は正確です。
- 結合は立体にのみ使えます。サーフェスボディは {{ui:縫い合わせ}} で結合します。

点や平面を「オブジェクトの間」に作成する方法は [参照平面、軸、点](topic:reference-geometry) を、パターンとミラーについては [パターンとミラーのフィーチャー](topic:patterns-mirror) を参照してください。
