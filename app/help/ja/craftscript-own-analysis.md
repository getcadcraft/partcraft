スクリプトワークスペースでの解析は、互いに変数を受け渡す数本の短いスクリプトです。必要な内容に近い[ライブラリ](topic:craftscript-library)の関数から始め、コピーを作成して変更してください。または、以下のように一から組み立てることもできます。

## 1. メッシュ

```
model = part();                  % モデル化しているパーツを、モデルとして取得
m = tetmesh(model, 4);           % 約 4 mm の四面体
show(m)
```

次に進む前に、ビューでメッシュを確認してください。{{key:F}} で全体を表示でき、**表示中**の目のアイコンでパーツを非表示にできます。

## 2. 組み立てて解く

要素のループはスクリプト内に書きます（教科書どおりに読めます）。重い部分は組み込み関数に任せてください: 要素行列、三つ組からの疎な組み立て、前処理付きの共役勾配ソルバーです。`static_tet` のようなライブラリ関数（ライブラリに含まれていれば）は、そのままコピーできる完全な例です。

## 3. 結果を表示する

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % 節点ごとに 1 つの値
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- 凡例の範囲は直接入力するか、{{ui:自動}} に戻せます。
- メッシュをクリックすると、節点の値が読み取れます。
- 同じ `'id'` を保持するプロットはその場で更新されるので、ループ内で print と plot を使えば収束を追えます。

## 4. 確認する

既知のものと比べてください。例えば、片持ち梁の先端のたわみを PL³/3EI と、穴のある板をその応力集中係数と、反力を荷重と比較します。確認は独自のスクリプトとして書き、変更のたびに再実行されるようにしてください:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. 保存する

- 各手順は独自のスクリプトタブにできます。変数を共有するので、順番に実行してください。
- スクリプトはパーツに保存されます。結果も保存するには、**変数**タブで**変数をパーツと一緒に保存**にチェックを入れてください（最大 32 MB）。
- スクリプトグループの {{ui:保存}} は、共有のためにスクリプトをダウンロードします。{{ui:開く}} で読み込みます。
