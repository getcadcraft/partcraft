加工ワークスペースは、パーツを工具経路に変換し、Gコードとして書き出します。ほとんどの工程は**2.5軸**のフライス加工です。工具は垂直に保たれ、壁はまっすぐ下に、床は平らに切削されます。**3D荒取り**と**残り加工**は、曲面のあるパーツを3Dで荒取りします（[3D荒取りと残り加工](topic:rough-3d)）。**平行**と**スカラップ**は、それを仕上げます（[3D仕上げ](topic:finish-3d)）。回転軸のある機械では、どの工程でも工具を傾けられ、2つの工程では切削中に回転軸が動きます（[4軸・5軸加工](topic:multi-axis)）。旋盤用の工程（[旋盤での旋削](topic:turning)）と、タッチプローブ用の工程（[プロービング](topic:probing)）もあります。メッシュカーネルがパーツに与える名前付きの面を対象に動作します（[メッシュカーネル](topic:solid-kernels)を参照）。

試験版のビルドです。すべてのプログラムは、お使いの制御装置自身のシミュレーターで確認し、まず素材の上の空中で実行してください。

## セットアップ

1. ワークスペースの切り替えで**加工**を選び、{{ui:新規セットアップ}}を選びます。
2. **セットアップ**タブで次を選びます:
   - **工具軸 (+Z)**: 工具がパーツへ向く方向。既定値はワールドの +Y（PartCraft の上方向）です。この場合、機械の X はワールドの X、機械の Y はワールドの −Z になります。
   - **ワーク原点 (G54)**: 素材の角または中心、上面または下面、モデルの上面中心、またはモデルの原点。
   - **素材**: 直方体または円筒。モデルに（側面、上面、下面の）オフセットを加えたもの、または固定サイズ。
   - **材料**（開始時の送りと速度を設定）、**ポスト**（制御装置）、機械の最大主軸回転数、早送り速度と工具交換時間、クーラント、プログラム番号。

## ツール

**ツール**タブにはライブラリがあります。フラット、ボール、コーナーRのエンドミル、ドリル、面取りカッター、正面フライスがあり、それぞれに T 番号、直径、刃数、刃長があります（該当する場合は、コーナー半径、先端角、面取り角も加えます）。

作成したツールは、ブラウザーに保存できるほか、ファイルとして別のコンピューターへ移動できます。[ツールライブラリ](topic:tool-library)を参照してください。

主軸回転数と送りは材料から算出されます: n = 1000 × 切削速度 / (π × 直径)、送り = n × 刃数 × 1刃あたりの送り量（ドリルの場合: n × 1回転あたりの送り）。数値は公開されている範囲から取った控えめな開始値であり、お使いの機械に合わせて調整したものではありません。工具メーカーの切削速度、1刃あたりの送り量、回転数（rpm）、または送りを入力すると、これらを上書きできます。速度が機械の最大値を超える場合は、その値に保たれ、送りはそれに従って1刃あたりの送り量を維持します。

## 工程の追加

ツールバーの各ボタンは工程を追加します。形状が必要な工程では、選択を開始します。ビューで面またはエッジをクリックし（再度クリックすると選択を外せます）、その後 {{ui:選択を完了}} または {{key:Esc}} を押します。

| 工程 | 選択 | 動作 |
|---|---|---|
| {{ui:面}} | なし | 素材全体の上を、縁を越えて、モデルの上面まで、ジグザグのパスで切削します |
| {{ui:ポケット}} | 平らな床面、丸穴、または閉じたエッジの連なり | 各切り込みごとに、内側から外側へのオフセットパスで領域を除去します。アイランド（床の内側で立ち上がっている面）は残します。周囲が開いている床（外側に高い箇所がない）は、素材の縁まで除去します |
| {{ui:アダプティブ}} | ポケットと同じ | 同じ領域を、それぞれ一定の幅（**径方向の切り込み**、直径の一部）を切削するパスで除去します。そのため、コーナーでもカッターは全幅の溝を切りません。ヘリカルで切り込み、各レベルで壁を仕上げます。切り込み幅が狭いほど、より深い切り込みと高い送りが可能になります |
| {{ui:輪郭}} | 平らな面（その外形）、丸い面、またはエッジ | 工具半径だけオフセットした外形に沿って切削します。外側でも内側でも可能で、進入と退出の円弧、必要に応じてタブを付けられます |
| {{ui:ドリル}} | 穴（穴の壁または縁をクリック） | 固定サイクルで各穴を加工します: ペック (G83)、ドリル (G81)、またはチップブレーク (G73)。直径を指定すると、その寸法の穴をすべて加工します |
| {{ui:面取り}} | 面の外形またはエッジ | 面取りカッターをエッジに沿って動かし、設定した幅で切削します |
| {{ui:平行}} | なし（モデル全体） | 任意の角度の平行線で3D仕上げを行い、ボール、コーナーR、またはフラットのエンドミルで曲面に沿って加工します。[3D仕上げ](topic:finish-3d)を参照してください |
| {{ui:スカラップ}} | なし（モデル全体） | 曲面上で一定の距離ごとのパスにより3D仕上げを行い、パス間の山が指定した高さになります |

リストで工程を選択すると、工具、高さ（逃げ、退避、送り高さ、上面、底面）、切り込み量、ステップオーバー、仕上げ代、仕上げパス、進入（ヘリカル、ランプ、プランジ）、ダウンカット、タブ、サイクルを変更できます。{{ui:上へ}}と{{ui:下へ}}で順序を変え、{{ui:抑制}}で工程を除外し、{{ui:削除}}で削除します。すべての変更は元に戻す履歴に残り、パーツファイルに保存されます。

ポケットのステップオーバーは工具径の半分以下です。そのため、床面のすべての点は、いずれかのパスから工具半径以内にあります。内側のコーナーには、工具の半径が残ります。

**アダプティブ荒取り**は、カッターの径方向の切り込みをほぼ一定の値に保ちます。直径の 0.15 の切り込みは、約 46° の切り込み角に相当します（素材の中でカッターの刃先が描く円弧）。対照的に、オフセットのポケットは、最初のパスで全幅を切削し、内側のすべてのコーナーでさらに回り込みます。パスの間では、工具は切削していない空間を移動するときに下がったままになり、そのほかの場所では空間で上下に動きます。パスは領域上の細かい格子で計算されます（セルは工具半径の約12分の1）。そのため、切り込みは設定値よりセル1つ分ほど広くなることがあります。壁は正確に仕上げられます。広く開いた領域では、短い移動が多い長いプログラムになります。

## シミュレーション

工具経路は、変更のたびに作り直されます（パーツも同様です）。{{ui:シミュレーション}}では、プログラム全体の後に残る素材も表示されます。パネルには次が表示されます:

- **サイクルタイム**: 送り移動は送り速度で、早送りはセットアップの早送り速度による直線として、さらに工具交換時間を加えて計算します。実際の機械は加速するため、より時間がかかります。
- **食い込み**: 工具がパーツの表面より 0.02 mm 以上深く入った箇所。ビューでは赤い印で表示されます。
- **パーツに残る素材**。

素材は上面の高さマップ（Zマップ）なので、アンダーカットは表示できません。**再生**をドラッグすると、プログラムに沿って工具が動きます。ビューでは、送り移動は実線、早送りは破線で表示され、工程ごとに色が異なります。

**シミュレーションした素材を表示**をオンにすると、素材はモデルと比較して、セルごとに色分けされます。モデル上にある箇所は**緑**（0.02 mm 以内）、工具がモデルに食い込んだ箇所は**赤**、モデル上に素材が残っている箇所は、薄い皮なら**黄**、それより多ければ**橙**、1 mm 以上では未切削の素材の**灰**へと変わります。色は変更のたびに、パネルの数値と同じ高さマップから作り直されるため、緑と赤は「食い込み」の行と一致します。面取りは意図的にモデルに切り込むため、そのエッジに沿って赤く表示されます。

## Gコードのポスト

**ポスト**の下で制御装置を選び、{{ui:Gコードをダウンロード}}を押します（またはツールバーの{{ui:ポストプロセッサー}}）:

| 制御装置 | ファイル | 備考 |
|---|---|---|
| Fanuc風 ISO | .nc | %、O番号、行番号、G43 H 付きの T M6、固定サイクル |
| GRBL | .nc | 工具交換装置と固定サイクルはありません。工具交換は M0 で一時停止し、穴あけは通常の移動として書き出されます |
| LinuxCNC | .ngc | G43 H 付きの T M6、固定サイクル、M2 |
| Fanuc風旋盤 | .nc | 旋削プログラム用: X は直径、1回転あたりの送り、G50 の制限の下で G96、G32 のねじ切り |
| LinuxCNC旋盤 | .ngc | 旋削プログラム用: G7 の直径、G95、G96、G33 のねじ切り。原点復帰の移動は書き出しません |
| 独自 | 任意 | 自分で作成または変更したポスト: {{ui:ポストを編集…}}、{{ui:新規ポスト…}}、{{ui:ポストファイルをインポート…}} |

すべてのファイルは、プログラム、素材、ワーク原点、工具に関するコメントから始まります。座標はミリメートルで、小数点以下 3 桁です。{{ui:工具経路 CSV}}と{{ui:工具経路 JSON}}は、移動そのものを書き出します。

**切削の前に、お使いの機械自身のシミュレーターで出力を確認し、まず素材の上の空中で実行してください。**内蔵の3種のポストは、制御装置の公開された動作に従う出発点です。特定の機械で検証されたものではありません。変更したポストの検証は、お客様ご自身で行う必要があります。作成方法: [ポストプロセッサー](topic:post-processors)。

## 加工用の正確なSTEP

**工程**タブのGコードボタンの下にある{{ui:厳密なSTEP（作業座標）}}は、`<part>-work.step` をダウンロードします。これは、このセットアップのワーク原点を原点とし、Z を工具軸に沿わせた、正確なソリッドとしてのパーツです（穴とボスは正確な円筒、そのエッジは正確な円）。これらは Gコードが使う座標なので、工場独自のCAMプログラムや検査ツールは、モデルを動かさずにプログラムに合わせられます。ファイルにはパーツだけが含まれ、素材と工具経路は含まれません。

{{ui:エクスポート}} › {{ui:STEP AP242（厳密ソリッド）}}は、同じソリッドをパーツ自身の位置（Z が上）で書き出します。[印刷、STEP、DXF のエクスポート](topic:export-files#for-other-cad-programs-step)を参照してください。

## 制限事項

- ポケット、輪郭、穴あけ、面取りは2.5軸です。曲面のあるパーツは、専用の工程で3Dに荒取り・仕上げされます（[3D荒取りと残り加工](topic:rough-3d)、[3D仕上げ](topic:finish-3d)）。アダプティブ荒取りは2Dです（平らな床面）。
- 傾いた工具、5軸と4軸の仕上げ、旋削、プロービングはありますが、それぞれに固有の制限があり、**いずれも機械で実行されたことはありません**。[4軸・5軸加工](topic:multi-axis)、[旋盤での旋削](topic:turning)、[プロービング](topic:probing)を参照してください。
- ホルダーとシャンクは衝突チェックされません。切り込みが刃長より深い場合は警告が表示されます。
- 送りと速度は開始値です。ポストは編集できるテキストですが、移動の書き方を決めるだけです。工具経路を変更したり、軸を追加したり、お使いの機械を把握したりすることはできません（[ポストプロセッサー](topic:post-processors)で、できないことを一覧で確認できます）。

## プログラムを機械に送信する

デスクトップ版の CadCraft Studio で、Studio に機械が設定されている場合、**Gコードをダウンロード**の横に**機械に送信…**が表示され、同じプログラムをネットワーク上の機械にアップロードします。PartCraft から開始されることはありません。安全が確認できてから、機械側で開始してください。ブラウザーではボタンは表示されません（Webページはネットワーク上の機械に接続できないためです）。代わりにプログラムをダウンロードしてください。
