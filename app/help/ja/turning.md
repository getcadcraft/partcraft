加工には、旋盤用の工程が7つあります。どのパーツにも使えます。切削されるのは、素材の中心のまわりで回転したときにパーツが作る**外形**です。そのため、丸くないパーツは、それを支える丸い形状まで削られます。

**ここに記載の内容は、どれも旋盤で実行したことはありません。** 経路はテストによって形状と照合されています。2つの旋盤用ポストは、制御装置の公開されたコードに従います。まず、お使いの制御装置自身のシミュレーターで、そして空中でプログラムを検証してください。

## セットアップ

**セットアップ**タブで:

- **工具軸**は主軸の軸、つまり旋盤の Z です。パーツの前面は +Z にあり、チャックは反対側の端を保持します。
- **素材**: {{ui:円筒}}（棒材）を選びます。上面のオフセットは、正面削りで除去される量です。
- **ワーク原点**: 素材の上面中心またはモデルの上面中心を選ぶと、Z0 が前面に置かれます。通常の位置です。
- **制御装置**: {{ui:Fanuc風旋盤 (.nc)}}または{{ui:LinuxCNC旋盤 (.ngc)}}。フライス用ポストは旋削プログラムを受け付けず、その旨を表示します。
- **主軸の最大回転数**: 周速が保たれる上限。

加工ツールバーの{{ui:その他}}には、7つの旋削工程が**工程**タブの上部に一覧表示されます。最初に追加した工程は、専用の工具を持ち込みます。**旋削インサート**（ノーズR、インサート角、切刃角）または**溝入れブレード**（幅、コーナー半径、到達する深さ）です。**ツール**タブで変更してください。送りは1回転あたりで、速度は m/min の周速で、直径が変わっても制御装置が保ちます。速度を固定したい場合は、ツールに個別の回転数を指定してください。

## 工程

| 工程 | 動作 |
|---|---|
| {{ui:面}} | 棒材の前面を、1回に切り込み量ずつ、外側から中心を少し過ぎるまでパーツまで削ります。 |
| {{ui:荒削り}} | Z に沿って**切り込み量**の間隔でパスし、外形と**仕上げ代**の位置まで削ります。その後、外形に沿って1回たどり、段差を取り除きます。2つの肩の間の谷には、切り込み量1つ分のプランジで進入します。 |
| {{ui:仕上げ}} | 工具の送りの一部の速度で、外形に沿って1回のパス。 |
| {{ui:溝入れ}} | ブレードを並べて、残っている素材の限界を超えて切削できる箇所に、その都度プランジします。旋削インサートが届かなかった溝です。**Z の開始 / 終了** で範囲を絞ります。 |
| {{ui:突切り}} | 背面のすぐ後ろで、中心を少し過ぎるまでパーツを切り離します。ペックを設定した場合は、ペックで切削します。 |
| {{ui:ねじ}} | 外径ねじ: 外径、ピッチ、長さ、パス数。深さ 0 は 0.6134 × ピッチ（60° ねじ）を意味します。各パスは同じ面積の切りくずを取ります。スプリングパスは最後のパスを繰り返します。 |
| {{ui:ドリル}} | 中心線上で、指定の深さまでドリルで穴あけします。ペックを使用します。 |

## 工具をパーツに接触させない方法

インサートは、その形状のまま扱われます。ノーズの円と、その後ろの後端の直線です。後端の直線の角度は、180° から切刃角とインサート角を引いたものです。この形状を、Z に沿った各点で外形の上に下ろし、その静止位置が経路になります。そのため:

- **ノーズRはすでに経路に含まれています。** ポストは `G41` や `G42` を書き出しません。座標は、工具のプログラム上の点（ノーズを囲む正方形の角）です。
- インサートは、**その後端より急な壁には追従できません**。肩の後ろの溝は残され、仕上げ工程は、届かなかった外形の量を表示します。{{ui:溝入れ}}工程がそれを切削します。
- 素材は、切削のたびに Z に沿って追跡されます。そのため、荒削りは空中を切削せず、溝入れは残った箇所を見つけ、各工程は除去した体積と、パーツに食い込んだかどうかを表示します。

## 制限事項

- **外径旋削のみ**: 中ぐりバー、内側の溝やねじ、端面の溝はありません。
- 主軸は1つで、パーツは −Z で保持されます。サブスピンドル、ライブツール、C 軸や Y 軸、振れ止め（スティディレスト）や心押し台の移動はありません。
- 経路は直線移動です。曲線は公差内の短い直線として書き出されます（`G2`/`G3` はありません）。荒削りとねじ切りは、パスごとに書き出されます（`G71` や `G76` のサイクルはありません）。
- ねじ切りは直線のパスで、最後は直線で抜きます。ねじには逃げ溝を設けてください。ねじは素材の表示には含まれません。
- センターでの穴あけは、素材モデルを変更しません。
- ホルダー、タレット、チャックはチェックされません。工具をチャックのつめから離すには、**Z で停止**を設定してください。
- 送りと速度は、フライスの場合と同様に開始値です。
