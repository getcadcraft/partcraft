同じツールパスでも、制御装置によって書き方が異なります。行番号の有無、`M6` か一時停止か、`G28` か `G53` か、`M30` か `M2` か、といった違いです。**ポスト**は、それをどう書くかを示す短いテキストです。PartCraft の組み込みポスト 3 種（Fanuc 系、GRBL、LinuxCNC）もこの形式で書かれているため、自分のポストは組み込みのいずれかをコピーして作成できます。

切削の前に、お使いの機械のシミュレーターで出力を確認してください。また、まずは素材の上の空中で実行してください。組み込みポストは、この形式が作られる前と同じ出力を書き出します（テストでは数百のプログラムの出力をバイト単位で比較しています）。ただし、ここにある内容がお使いの機械で検証されたわけではありません。変更したポストは、ご自身で検証する必要があります。

## ポストを作成する

加工の**ポスト**の下で:

- 組み込みの制御装置で{{ui:ポストを編集…}}を選択すると、そのコピーが開きます。自分で作成したポストで選択すると、そのポストが開きます。
- {{ui:新規ポスト…}}を選択すると、すべてのイベントを含む小さな空のポストが作成されます。
- {{ui:ポストファイルをインポート…}}を選択すると、`.cpost` テキストファイル（エディターの **ファイルとして保存…** で得られるファイル）を読み込みます。

エディターには、テキスト、読み取れるかどうかを示す行（誤りがある場合はその行）、入力中に書き出される G コードが表示されます。**プレビュー対象** では、すべてのイベントを実行する小さなサンプルプログラム、またはこのパーツ自身のプログラムを選択できます。{{ui:保存}}を選択すると、ポストはパーツのファイルに保存され（最大 20 件）、制御装置として選ばれます。ポストはパーツと一緒に移動します。別のパーツで使うには、ファイルとして保存し、そのパーツでインポートしてください。

## ポストの構成

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` で始まる行と空行は無視されます。先頭に設定を書き、続けてイベントごとに `on <event>` ブロックを 1つずつ書きます。ブロックは `end` で閉じます。省略したイベントは何も書き出しません。

| 設定 | 意味 |
|---|---|
| `post <id>` | ポストの ID。英字、数字、`-`、`_` |
| `name <text>` | 制御装置の一覧に表示される名前 |
| `extension <ext>` | ファイルの拡張子（nc、ngc、tap など） |
| `line-numbers 10` / `off` | 各 `emit` 行に `N10`、`N20` … を付けるか、なし |
| `decimal-point yes` / `no` | `10` の代わりに `10.`（コメントには小数点を付けません） |
| `canned-cycles yes` / `no` | `no` の場合、穴は対応する G0/G1 の移動として書き出されます |
| `modal <group> <words>` | グループの単語（`modal motion G0 G1 G2 G3`）。値が変わったときだけ書き出されます |

## イベント

1つのプログラムは、次の順に実行されます。`start` の後、各工程について `operation` が実行されます。工具が変わるとき `tool-change`、速度が変わるとき `spindle`、最初の点への移動（最初の早送りの前）として `approach`、そして `coolant-on` が実行されます。続いて移動が `rapid`、`feed`、`arc` として実行されます。各固定サイクルは `cycle-start`、穴ごとの `cycle-hole`、`cycle-end` として実行されます。最後に `end` が実行されます。

各イベントは、そのイベントの種類の移動に応じた変数を `{name}` の形で使用できます。プログラム（`name`、`program`、`setup.axis`、`setup.origin`、`setup.coolant`）、素材（`stock.kind`、`stock.d`、`stock.sx`、`stock.sy`、`stock.sz`、`stock.minx` … `stock.maxz`）、工具（`tool.number`、`tool.desc`、`tool.kind`、`tool.d`、`tool.flutes`、`tool.fluteLen`）、工程（`op.name`、`op.type`）、`rpm`、移動の点（`x`、`y`、`z`、`f`、そして軸が変わったときに true になる `moved`）、円弧（`arc.g` の 2 または 3、`arc.i`、`arc.j`、`arc.cx`、`arc.cy`）、穴（`hole.x`、`hole.y`、`hole.z`、`hole.r`、`hole.q`、`hole.return`、`hole.first`、`cycle.kind`、`cycle.init`、`feed`）です。エディターの**イベントと変数**の一覧に、どのイベントでどの変数が使えるかが表示されます。読み取りと設定ができる状態は `cool`、`offset`、および `at.x`、`at.y`、`at.z`、`at.f`（最後に書き出された値）です。

## ステートメント

| ステートメント | 働き |
|---|---|
| `raw TEXT` | 入力どおりの行（行番号なし） |
| `comment TEXT` | `(TEXT)`。ASCII 以外の文字と括弧は取り除かれます |
| `emit WORD WORD …` | 単語の並ぶ行。空になった単語は省かれ、単語がなければ行は書き出されません |
| `word WORD …` | 作成中の行に単語を追加します。単独の `emit` で行を終えます |
| `if EXPR` … `else` … `end` | 条件: `a == b`、`a != b`、`not a`、`a and b`、`a or b`、`a??b`（a、なければ b） |
| `for tool in tools` … `end` | プログラムが使う工具ごとに 1回ずつ実行されます |
| `set NAME EXPR` | 値を記憶します（`set offset tool.number`） |
| `reset NAME …` | モーダルの単語を忘れます（グループ、`Z` のようなアドレス文字、または `at.z`） |
| `do rapid X Y Z` | 点について `rapid` イベントを実行します |

単語は、`{variable|filter}` の穴を含む入力テキストです。フィルターは `upper`、`lower`、`pad:N`（ゼロ埋め）、`cut:N`（先頭 N 文字）、`safe`（コメントに安全な ASCII）、`int` です。末尾に `~` が付く単語は**モーダル**で、最後に書き出した内容と異なる場合にだけ書き出されます（`G1~`、`X{x}~`）。末尾が `~!` の単語は、毎回書き出され、かつ記憶されます。変数ではない名前は、そのままの文字列として扱われます（`G81`、`mist`）。数値は 0.001 mm 単位に丸められ、末尾の 0 は書き出されません。

## ポストでできないこと

ポストが決めるのは移動の書き方だけです。ツールパスを変更する、工程の順序を変える、円弧を分割する、軸を追加する、機械の移動範囲や運動学を知る、座標の計算を行う（`+` はありません）ことはできません。プロービング、工具寿命とサブプログラムのサイクル、4 軸と 5 軸の出力、旋盤のコードは作成されていません。他のプログラムの `.cps` 形式のポストファイルは読み込めません。本形式は別のもので、より単純です。
