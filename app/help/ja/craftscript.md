**プレビュー。** スクリプティングは PartCraft 0.3 で新しく追加されたプレビュー版の機能です。言語、ライブラリ、スクリプトの保存方法は変わることがあり、今書いたスクリプトは後で少し修正が必要になることがあります。問題があれば知らせてください。

スクリプトワークスペースでは、パーツの横で独自の計算を実行できます: 小さな合計、解析全体、または [解析ライブラリ](topic:craftscript-library) のスクリプトです。スクリプトは **CraftScript**（MATLAB によく似た行列言語。[CraftScript の言語](topic:craftscript-language) を参照）、**Lua**（[Lua のスクリプト](topic:craftscript-lua) を参照）、または **Python**（[Python のスクリプト](topic:craftscript-python) を参照）で書けます。

ツールバー左側の**ワークスペース**ボックスで **スクリプト** を選びます。パーツは変更されません。右パネルがスクリプトパネルになります（通常より広くなります。端をドラッグして幅を変えるか、{{ui:⋯}} メニューから 2 台目の画面に移動できます。[パネルの配置](common:arrange-panels) を参照）。

## モデリング中にスクリプトを書く

Design ワークスペースを離れずにスクリプトを書けます。デザインでは、右パネルの {{ui:スクリプト}} タブに、同じエディター、コンソール、変数、ライブラリがあり、同じスクリプトが使えます。フィーチャーツリーとビューは引き続き動作します: フィーチャーをクリックして選択し、スケッチをダブルクリックして編集し、ビューを回転させてから、{{ui:スクリプト}} タブに戻って {{key:F5}} を押します。

スクリプトが何を**表示**するか（メッシュ、フィールド、プロット、表）は、デザインでモデルの上には描かれません。コンソールにその旨が表示され、すべてはスクリプトワークスペースに切り替えたときに表示されます。

{{ui:別ウィンドウに分離}} は {{ui:実行}} の横にあり、パネル全体を独自のウィンドウに移します。例えば 2 台目の画面に置けば、エディターと全体のビューを並べられます。{{ui:メインウィンドウに戻す}} で再びドッキングします。[パネルの配置](common:arrange-panels) を参照してください。

## 最初のスクリプトを実行する

1. エディターに入力します。例えば:

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. {{key:F5}} を押します（または {{ui:実行}}）。エディターの下のコンソールに、スクリプトが出力した内容と「… s で完了」が表示されます。プロットは、3D ビューの下にある**サブディスプレイ**に表示されます。
3. セミコロンのない行は、MATLAB と同じく値を表示します: `a = 3` は `a = 3` と表示し、`a = 3;` は何も表示しません。
4. スクリプトの一部だけを実行するには、行を選んで {{key:Mod+Enter}} を押します（{{ui:選択範囲}}）。何も選択していなければ、カーソルのある行を実行します。
5. コンソールの下端（`>>` の後）の行は、{{key:Enter}} を押すたびに 1 つの文を実行します。{{key:Up}} と {{key:Down}} で前の行を呼び出せます。

## 検索、折りたたみ、補完

- **検索と置換。** {{key:Mod+F}}（置換も行うなら {{key:Mod+H}}）を押します。コードの上にバーが開きます。検索する語を入力すると一致箇所が光り、件数で現在位置が分かります。ボックスの横のボタンは、大文字と小文字の区別（**Aa**）、単語単位の検索（**W**）、正規表現（**.\***。置換では `$1` で最初のグループに一致した内容を戻せます）を切り替えます。{{ui:置換}} は現在の一致箇所を置き換え、{{ui:すべて}} はすべての一致箇所を 1 回の {{key:Mod+Z}} の操作として置き換えます。
- **折りたたみ。** 行番号の横の ▾ をクリックするか、`function`、`if`、`for`、`while`、`switch`、`try` の行（Lua では `function`、`do`、`if`、`repeat`）にカーソルを置いて {{key:Mod+Shift+[}} を押すと、その内側の行をしまえます。行には、しまわれた行数が表示されます。▸ または {{key:Mod+Shift+]}} で再び開きます。折りたたみは行を隠すだけです。実行、保存、コピー、行番号はすべての行を数え続けます。折りたたまれた行に入力すると、先に開きます。
- **補完。** 名前の最初の 2 文字を入力するか、{{key:Mod+Space}} を押します。変数、言語の関数（引数付き）、キーワード、そのスクリプトですでに使われている名前の一覧が表示されます。矢印で選び、{{key:Enter}} または {{key:Tab}} で決定します。

## 問題が起きたとき

- エラーは問題と行を示します。その行はエディターで赤く表示され、コンソールの**行 n** からその行へ移動できます。
- 終わらないループは {{ui:停止}}（ツールバーまたはパネル）で止めます。スクリプトはすぐに止まり、変数は、その実行の前の値を保持します。
- 実行ごとにステップ上限もあります（既定では 20 億ステップ。パネルの**実行オプション**で変更できます）。上限を超えた実行はメッセージとともに停止します。

## 変数は、スクリプトからスクリプトへ引き継がれます

スクリプトが作るすべての最上位の変数は、**変数**タブ（名前、型、サイズ、最小値と最大値）に入り、どちらの言語からでも次のスクリプトのために残ります。そのため、あるスクリプトでメッシュを作り、次で解き、3 つ目でプロットできます。

- 変数をクリックして表示します。メッシュ、フィールド、モデルは 3D ビューに、配列は表として（ベクトルなら折れ線グラフ、行列ならカラーマップも）サブディスプレイに表示されます。
- {{ui:JSON として保存}}、{{ui:CSV として保存}}（数値の表）、{{ui:HDF5 として保存}} でダウンロードします。{{ui:削除}} で削除し、{{ui:すべてクリア}} でワークスペースを空にします。
- **変数をパーツと一緒に保存**にチェックを入れると、パーツファイルに保存されます（最大 32 MB。それより大きいものは、この訪問の間だけ残ります）。そのようなパーツを開くと、パネルが変数の読み込みを提案します。

## メッシュ、フィールド、プロット

- `show(m)` はメッシュを描きます。`show(f)` は、凡例付きでそのメッシュにフィールドの色を付けます。ビューの左上にある**表示中**の一覧で、各項目を非表示（目のアイコン {{ui:目のアイコン}}）または削除でき、パーツ自体の表示も切り替えられます。凡例の下で範囲（**開始**、**終了**）を入力するか、{{ui:自動}} を押します。ベクトルや応力のフィールドでは、表示する成分も選べます。
- `show(f, 'deform', u, 'scale', 50)` は、変位フィールド `u` で動かされたメッシュを 50 倍に拡大して描きます（`scale` を省略すると、モデルの大きさの約 8 % になります）。
- 表示されたメッシュをクリックすると、最も近い節点、要素、そこでのフィールドの値がサブディスプレイ（**選択点**）に表示されます。
- `plot`、`imagesc`、`table` は、サブディスプレイに折れ線グラフ、2 次元配列のカラーマップ、表を表示します。同じ `'id'`（またはタイトル）を持つ以前のプロットは置き換えられるので、ループで 1 つの収束プロットを更新できます。`'append', true` を指定すると曲線を追加します。{{ui:クリア}} でサブディスプレイを空にし、矢印でしまえます。
- 2 つ以上のプロットがあるときは、{{ui:並べて表示}} で（新しい方から 6 つ）一度にすべて表示します。表またはピクチャのタブをクリックすると、そのひとつだけが再び表示されます。
- すべてのプロットの下には、{{ui:PNG}}、{{ui:SVG}}、{{ui:CSV}} があります。PNG と SVG は、テーマにかかわらず用紙の色で白い背景に出力します（PNG は 1600 × 1000 ピクセル、SVG はぼやけずに拡大縮小します）。CSV は数値をすべての桁で保持します。曲線が x を共有する場合は、x の列と曲線ごとの列が 1 つずつ。そうでない場合は、点ごとに 1 行で、曲線の名前を付けます。
- {{key:F}} または {{ui:全体表示}} で、ビューを表示中のものに合わせます。

## ファイル

- スクリプトグループの {{ui:開く}}（またはビューやパネルにファイルをドロップ）: `.craft`、`.lua`、`.py` ファイルは新しいスクリプトとして開きます（実行はしません）。データファイル（STL、OBJ、CSV、JSON、NPY、HDF5）は、ファイル名の下で変数に読み込まれます。
- スクリプトグループの {{ui:保存}} は、現在のスクリプトをファイルとしてダウンロードします。
- スクリプトグループの {{ui:新規}}（またはタブ横の {{ui:+}}）で別のスクリプトを始めます。タブをダブルクリックすると名前を変更できます。その {{ui:×}} で削除できます（元に戻せます）。

## パーツのパラメーターを読む

スクリプトは、パーツのパラメーター（[パラメーターでパーツを駆動する](topic:parameters) を参照）を名前で読み取ります:

```
w = param('width');     % 1 つのパラメーターの値。mm（または度、または単なる数値）
p = params();           % すべて、構造体として: p.width, p.height
```

Lua と Python では `cs.param('width')` と `cs.params()` です。スクリプトはパラメーターを読み取るだけです。変更は {{ui:パラメーター}} タブで行ってください。スクリプトのタブの下に、`param('…')` で読み取っているパラメーターの一覧が表示され、パーツにないものにはマークが付きます。{{ui:パラメーター}} タブには、それぞれのパラメーターの下にスクリプトが一覧されます。スクリプトの実行中に組み立てられる名前（例: `param(name)`）は一覧されません。

## スクリプトはパーツに保存されます

タブ内のすべてのスクリプトはパーツに保存されるので、ファイルグループの {{ui:保存}} で一緒に保存され、スクリプトへの変更は元に戻せます。パーツを開いても、そのスクリプトは**実行されません**。コンソールには含まれるスクリプトの数が表示され、{{ui:実行}} を押したときだけ実行されます。他人のパーツには、どんなスクリプトでも含まれている可能性があるので、実行する前に必ず内容を読んでください。スクリプトは、このコンピューター上でバックグラウンドで、ネットワークアクセスなしに実行され、ページには触れられません。
