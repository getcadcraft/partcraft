解析ライブラリは、上から下へ順に読める関数で構成されたスクリプトの集まりです。剛性行列がどのように組み立てられるか、境界条件をどこに置くか、どのソルバーが実行されるか、結果がどのように求められるかが分かります。ブラックボックスとして隠されている部分はありません。組み込みになっているのは、高速な内側のループ（要素行列、疎ソルバー、メッシュ生成）だけです。

## 例から始める

**例**グループには、ライブラリを端から端まで使う短いスクリプトが 5 つあります。1 つをクリックし、{{ui:開く（読み取り専用）}} を押してから {{key:F5}} を押します。それぞれ、ビューをクリアしてキャンバスに結果を、サブディスプレイにプロットを表示します。

| 例 | 内容 |
|---|---|
| 片持ち梁の応力 | 100 N の先端荷重を受ける、100 × 10 × 10 mm の鋼製の棒: 変形した棒の von Mises 応力、4 つの要素サイズでの先端のたわみと梁理論との比較（プロット） |
| MBB 梁のトポロジー | 古典的な 60 × 20 のトポロジー最適化: 形状が形成される様子、コンプライアンスの低下、最終的なレイアウト（94 回の反復、コンプライアンス 203.19） |
| コンデンサーの電界 | 幅 4 mm、間隔 1 mm の 2 枚の極板: 電位と電界、フリンジングを含む静電容量と理想値、Palmer の式との比較 |
| 流路流れ | 流路内の柱の周りの格子ボルツマン流れ: 速度場と収束履歴 |
| 電磁石 | 空隙とコイルを備えた C 字形の鉄心: 磁束密度、空隙内の磁場を磁気回路の式と比較したもの、インダクタンス、空隙をまたぐ吸引力。[2次元の磁界](topic:magnetic-fields-2d) で順を追って説明しています |
| 永久磁石 | コイルの代わりに永久磁石を使った同じ鉄心: 磁石の動作点、磁気回路との比較による空隙内の磁場、漏れ磁束の量、吸引力。[2次元の磁界](topic:magnetic-fields-2d#permanent-magnets) で説明しています |

## グループ

| グループ | 関数 | 内容 |
|---|---|---|
| メッシュ生成 | `box_mesh`, `cylinder_mesh`, `voxel_mesh`, `tet_mesh`, `mesh_quality`, `nodes_at`, `face_nodes` | 箱と円柱を六面体、立方体、または四面体で生成。任意のモデル（パーツ、ボディ、読み込んだ STL）の立方体または四面体。要素の体積と品質。平面または面上の節点の選択 |
| 静応力 | `static_voxel`, `static_tet` | 立方体、または 10 節点の四面体での線形静応力: 変位、応力、von Mises、反力 |
| 骨組 | `frame3d` | 直接剛性法による梁、柱、ブレースの 3D 骨組: 端部の解放、支持とばね、部材に沿った荷重。変位、反力、部材端力。DetailCraft と BimCraft の {{ui:CraftScript として書き出し}} は、モデル全体をこの形式で書き出します。解析の補助であり、規定のチェックではありません |
| 振動 | `modal_tet` | 固有振動数とモード形状 |
| 熱 | `heat_steady`, `heat_transient`, `heat_system` | 固定温度、熱入力、発熱、熱流束、対流を伴う定常および非定常の熱伝導 |
| トポロジー最適化 | `top88`, `top99`, `topopt3d` | 発表された 88 行版と 99 行版の 2 次元コード、および立方体上の 3 次元で同じ手法 |
| 電磁気 | `poisson2d`, `magnetostatic2d` | 2 次元の静電気（電位、電界、静電容量、電荷）と静磁気（ベクトルポテンシャル、磁束密度、永久磁石） |
| 流体の流れ | `lbm2d`, `lbm3d` | 格子ボルツマン流れ: 2 次元はスクリプト内に展開して記述、3 次元は PartCraft 独自の流れのカーネル上で動作 |

各関数のヘッダーは、正確な引数を示しています。単位は、ヘッダーで別の指定がない限り PartCraft の解析と同じです: ミリメートル、ニュートン、メガパスカル、密度はトン毎立方ミリメートル、熱はワットとケルビン。電磁気と格子ボルツマンの関数は、任意の一貫した単位で動作します。ヘッダーにその方法が書かれています。

## ライブラリの検証方法

各関数のヘッダーは、既知の答えを持つ小さなケースである**チェック**で終わります。PartCraft のテストはそのすべてを実行します。PartCraft が同じ作業に独自の解析を持つ場合は、スクリプトの答えを同じメッシュ上でその解析と比較します:

- 片持ち梁の先端のたわみを梁理論と比較（立方体では 0.2 % 以内、四面体では 0.05 % 以内）、および **シミュレーション** ワークスペースのソルバーと同じメッシュ上で比較（何桁も一致）。
- 片持ち梁の一次固有振動数を梁理論と比較（短い梁では想定どおり 0.24 % 低い）、および **シミュレーション** のモーダルソルバーと比較。
- 熱: 加熱された平板の壁は厳密に、小さな物体の冷却は集中容量の式どおりに、スラブの温度低下は理論どおりに。
- トポロジー最適化: `top88` は論文の 94 回の反復と、コンプライアンス 203.1925（密度フィルターでは 218.8032）を再現します。`topopt3d` は同じ設定で **ジェネレーティブ** ワークスペースと同じコンプライアンスで終わります。
- コンデンサーの静電容量と長いソレノイドの磁場を教科書の値と、電磁石の空隙の磁場を磁気回路の式と比較します。永久磁石は、空気中の丸い磁石および鉄の保持材で閉じた磁石と比較します。
- 流路流れは、厳密な放物線状の分布と比較します。

## 関数を読む

1. スクリプトパネルの**ライブラリ**タブを開きます。
2. 関数をクリックします。ヘッダーには、計算内容、方法、単位、前提と制限、**参考文献**（書籍または論文、式番号付き）、そして**チェック**（PartCraft 自身のテストが実行する、既知の答えを持つ小さなケース）が表示されます。
3. {{ui:開く（読み取り専用）}} を押すと、破線の枠のタブでスクリプト全体が開きます。実行したり、一部を選んで実行したりできますが、変更はできません。

## 変更する

{{ui:コピーを作成}} を押します（読み取り専用タブの上にある**編集用のコピーを作成**でも同じです）。コピーは、パーツ内の同じ名前のスクリプトになり、パーツと一緒に保存されます。その関数を呼び出すすべての箇所は、今やあなたのコピーを使います。エディターの上にそのことが表示されます。両方を残すには、コピーの名前を変更してください。

## 使う

ライブラリ関数は、どのスクリプトからも組み込み関数と同じように名前で呼び出せます:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

結果は値としてワークスペースに返されます。関数が表示するプロットやフィールドは、ビューとサブディスプレイに現れます。

開いているパーツの静解析は、例えば数行で書けます:

```
v = voxel_mesh(part(), 2);                   % 2 mm の立方体
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % 底面を固定
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 上面に 500 N の下向きの力
r = static_voxel(v, 210000, 0.3, bc);       % 鋼
```

`r` には変位、応力、反力が入ります。von Mises 応力は、変形したパーツの上に描かれます。曲面のあるパーツには、`tet_mesh` と `static_tet` を使います。これらは面全体に荷重をかけたり固定したりすることもできます（`face_nodes`）。

:::note
ライブラリの関数は CraftScript で書かれています。Lua スクリプトは、組み込み関数と同じように `cs` を通してそれらを呼び出します: `cs.static_tet(t, 200000, 0.3, bc)`（[Lua のスクリプト](topic:craftscript-lua) を参照）。各関数は 1 つの材料と 1 つの荷重ケースを解きます。対象外の内容はヘッダーに記載されています。
:::
