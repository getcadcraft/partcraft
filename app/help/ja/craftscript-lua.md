[スクリプトワークスペース](topic:craftscript) の 2 番目の言語が Lua です。エディターの上の言語ボックスで **Lua** を選びます（`.lua` ファイルは自動的に Lua で開きます）。Lua と CraftScript は同じ変数と同じ組み込み関数を共有するので、Lua スクリプトは CraftScript スクリプトが作ったものを使えますし、その逆も可能です。

## 基本

```
-- 組み込み関数はすべて cs テーブルにあります
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1 始まり。CraftScript と同じ
print(K(1, 1), #K)             -- 要素と、要素の数
-- ワークスペース: すべてのスクリプトから見える同じ変数
ws.total = K(1, 1) * 2
print(ws.total)
-- 1 つの関数から複数の結果
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<名前>(…)` は任意の組み込み関数を呼び出し、最初の結果を返します。`cs.call(名前, n, …)` は `n` 個の結果を返します。
- `cs.tensor({1, 2, 3})` は行を、`cs.tensor({{1, 2}, {3, 4}})` は行列を作ります。
- 配列、疎行列、メッシュ、フィールドは、メソッドを持つ値です: `t(i, j)` または `t:get(i, j)`、`t:set(i, j, v)`、`t:shape()`、`#t`、`t:T()`（転置）、`t:totable()`。`+ - * / ^` の意味は CraftScript と同じです（`*` は行列積）。`t:times(u)` は要素ごとに掛け算します。
- 1×1 の配列は、普通の Lua の数値として渡されます。
- `ws.name` は共有ワークスペースを読み書きします。スクリプトが残したグローバル変数も、終了時にそこに入ります。
- `print(…)` はコンソールに書き出します。`cs.show(f)`、`cs.plot(y)` などの表示関数は、CraftScript と同じように動作します。

## 解析ライブラリを呼び出す

解析ライブラリの関数（ライブラリタブ）と、パーツ独自のスクリプトが定義する CraftScript 関数も、同じく `cs` を通して呼び出します:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- 出力は 2 つ
```

名前は、スクリプトの実行前に見つかります。そのため、名前はスクリプト内にそのまま書いてください: `cs.static_tet(` または `cs.call('static_tet', …)`。実行中に組み立てられた名前は、組み込み関数にしか届きません。`cs.struct({ … })` で作った構造体は CraftScript の構造体で、その Lua のリスト（`{ cs.struct(…), … }`）はセルになります。これがライブラリの設定が期待する形式です。ライブラリ関数の内部で問題が起きると、メッセージは関数名とその行を示し、それを呼び出したあなたの行を指します。

## 無効化されている機能

スクリプトは、ファイル、ネットワーク、ページに到達できません。`io`、`os`（時計を除く）、`require`、`dofile`、`loadfile`、`debug` は取り除かれています。データを取り込むには、スクリプトワークスペースの {{ui:開く}} と変数を使ってください。ステップ上限と {{ui:停止}} は、CraftScript と同じように働きます。
