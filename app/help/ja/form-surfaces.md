**フォーム**ワークスペースでは、有機的な形状を作成します。編集するのは**ケージ**です。ケージは、角、エッジ、面からなる粗いメッシュです。形状は、ケージが制御する滑らかな面（Catmull–Clark の極限曲面）なので、1 つの角を動かすと、その周りで面が緩やかに曲がります。形が整ったら、**仕上げ**を押すと、「フォーム」フィーチャーとして部品の履歴に追加され、正確なカーネルが本物の B スプライン曲面に変換します。その後は、フィレットをかけたり、切断したり、他のフィーチャーと結合したり、STEP で書き出したりできます。

ツールバーの左側にある**ワークスペース**の一覧で**フォーム**を選びます。

## ケージを作成する

1. 右のパネルで**サイズ**と**分割数**を設定します。分割数は、各辺の面の数です。
2. ツールバーの {{ui:Box}}、{{ui:Quadball}} または {{ui:Plane}} をクリックします。パネルには**円柱**、**トーラス**、**クリックで面を作成**もあります。

- **クアッドボール**は、角の点が球面上に来るように合わせた直方体のケージです。それらの点の間では、面は球よりわずかに内側にあります（分割数 2 の場合、体積は約 0.4 % 小さくなります）。
- **平面**は開いているため、サーフェス ボディになります（下の「設計のサーフェスのフィーチャー」を参照）。
- **クリックで面を作成**: 上面（地面）の平面、またはケージの角で 4 点をクリックして 1 つの面を作ります。角を共有する面はつながります。3 点の後に {{key:Enter}} を押すと三角形、{{key:Esc}} で停止します。

未完成のケージは部品ファイルと一緒に保存されるため、ファイルを閉じて、後で続けられます。

## 選択と移動

- ケージの角、エッジ、面をクリックします。{{key:Shift}}+クリックで項目を追加または除外します。{{key:Esc}} で選択を解除します。
- 選択の中央にギズモが表示されます。矢印をドラッグすると線に沿って移動し、正方形をドラッグすると平面内で移動します。{{key:W}} で移動、{{key:E}} で回転、{{key:R}} で拡大縮小します。またはパネルのボタンを使います。ツールバーの {{ui:Gizmo}} を押すと、それらを順に切り替えられます。
- **ソフトフォールオフ** (mm) は、その距離内の角も引き寄せ、距離の端では滑らかに 0 になります。
- ドラッグのたびに、元に戻す操作が 1 回分になります。{{key:Ctrl+Z}} と {{key:Ctrl+Y}} は通常どおり動作します。

## ケージを変更する

パネルの**変更**ボタンは、選択に対して動作します:

| ボタン | 動作 |
|---|---|
| {{ui:Extrude}} | 選択した面は、法線に沿って**押し出し距離**だけ外側に移動し、新しい側面が作られます。選択した開いたエッジは、外側に向かって新しい面を伸ばします。 |
| {{ui:Edge loop}} / エッジループを挿入 | 選択したエッジを横切る四角形の面のリングを、途中で分割します。ループを増やすと、曲線がよりタイトになります。 |
| 点を挿入 | 選択したエッジの中央に角を追加します。 |
| 細分化 | 選択した各面を、その中央を囲む四角形の面に分割します。 |
| ブリッジ | 2 つの選択した面、または 2 つの開口部（それぞれ開いたエッジを 1 つずつ選択）を、面のチューブでつなぎます。どちらも辺の数が同じである必要があります。 |
| 穴を埋める | 選択した開いたエッジを通る開口部を、1 つの面でふさぎます。 |
| 統合 | 選択した角を、その中央で 1 つにまとめます。 |
| 平坦化 | 選択した角を、それらに最もよく合う平面上に移動します。 |
| 削除 | 選択した面、エッジ（2 つの面が結合されます）、または角を削除します。 |

## 鋭いエッジ、対称性、表示

- {{ui:Crease}} は、選択したエッジを鋭くします。**折り目の重み** 10 は完全に鋭い状態です。小さい重みは、その回数の細分化の段階だけ鋭さを保ち、その後は柔らかくなります。これにより、硬い折れ目ではなく、きつい丸みになります。**折り目を解除**は、それらを再び滑らかにします。**鋭い頂点**は角を固定し、サーフェスがその点を通るようにします。
- **対称**は、ケージを X、Y、Z = 0 で鏡映します。正の側を残し、それを鏡映して、2 つの半分を結合します。その後は、どちらの側の編集も両側に適用されます。鏡面上の角は鏡面上にとどまります。
- {{ui:Display}} は、**滑らか**（フィーチャーになるサーフェス）と**箱**（ケージの面そのもの）を切り替えます。
- **解析**: **ゼブラストライプ**は、現在のビューから縞模様の光を反射させます。滑らかな面では滑らかに曲がり、折り目で途切れます。**平均曲率**は、凸の部分を赤、凹の部分を青、平らな部分を白で表示します。表示されたメッシュに対してコタンジェント式で計測されるため、目安であり、正確な測定値ではありません。

## 確認と仕上げ

- **厳密に確認**は、部品を変えずに、ケージを正確なカーネルで変換します。ケージが作る B スプライン パッチの数、そのうち正確なものの数、結果が閉じた有効なソリッドかどうか、およびその体積を報告します。
- {{ui:Finish}} は、履歴に「フォーム」フィーチャーを追加するか、編集していたフォームを更新して、設計に戻ります。閉じたケージはソリッドになります。設計パネルの**操作**は、新規ボディ、結合、カット、交差のいずれかを選べます。開いたケージはサーフェス ボディになります。
- 後でフォームを変更するには、履歴でそれを選択し、**フォームで編集**をクリックします。ケージを編集している間、作成されたボディは非表示になります。
- **破棄**は、履歴に触れずにケージを捨てます。

## 何が正確で、何が近似か

ケージの各四角形の面は、必要に応じて細分化され、1 つの双三次 B スプライン パッチになります。

- 面のすべての角が*正則*（面の内側で 4 本のエッジが集まる、または開いたエッジや折り目に沿って 3 本）である場合、パッチは**正確に**サブディビジョン曲面と一致します。テストはこれを 1e-9 mm まで確認します。
- **特異点**（3 本、5 本以上のエッジが集まる点、3 辺または 5 辺の面の角、折り目の終点）の周りには、正確な多項式パッチは存在しません。そこでは、パッチはその角での正確な点と接平面、および隣接するエッジ曲線を用いるため、パッチ同士は隙間なくつながります。その点で集まるエッジをまたぐ接線連続性は近似的です。フォームのパネルとフィーチャーのパネルには最大角度が表示され、通常は 2° 未満です。フィーチャーのパネルで**レベル**を上げると、これらのパッチはより小さく、より近くなります。
- 鋭い折り目は、ソリッドの実際のエッジなので、フィレットをかけられます。
- 各パッチは独自の面なので、フォームは多くの面を持ち、面の間に線が引かれます。

## 設計のサーフェスのフィーチャー

サーフェスのコマンドは、設計の{{ui:More}}メニューのフィーチャーの中にあります。正確なカーネルが必要です。サーフェス ボディは青の透過で描かれます。肉厚付けまたは縫い合わせるまでは、ソリッドの一部ではありません。

| コマンド | 動作 |
|---|---|
| パッチ | 閉じたエッジのループを埋めます。まずソリッドのエッジを {{key:Shift}}+クリックするか、サーフェス ボディを選択して、その開口部を埋めます。**接線 (G1)** は、そのサーフェスに滑らかに接するようにします。 |
| ロフトサーフェス | スケッチごとに 1 つのチェーンの曲線（開いたものまたは閉じたもの）を、履歴の順に通るサーフェスを作成します。 |
| 縫い合わせ | 共有するエッジに沿って、サーフェス ボディを縫い合わせます。閉じると、結果はソリッドになり、他のフィーチャーと同じように**操作**を持ちます。 |
| 肉厚付け | サーフェス ボディに厚みを与えます。法線に沿って、逆方向に、または両方向に半分ずつ。結果はソリッドです。 |
| サーフェスのオフセット | サーフェス ボディのコピーを、その法線に沿って移動します。元のものは残ります。 |
| サーフェスの延長 | 1 面のサーフェスを、選択したエッジを越えて伸ばします。 |
| サーフェスのトリム | 別のサーフェス ボディまたはソリッドがそれを横切る場所で、サーフェス ボディを切断します。**片側の点を指定**をクリックして残す側を選ぶか、残りをすべて残します。 |

縫い合わせ、肉厚付け、サーフェスの延長、サーフェスのトリムは、元になったサーフェス ボディを使い切ります。後のフィーチャーは新しいものを使います。

現時点の制限: 複数の離れた閉じた部分からなるフォームは、1 つのソリッドに変換されません。正則な領域は、より大きなサーフェスにまとめられません。また、[まだ作成されていないもの](topic:not-built-yet)も参照してください。
