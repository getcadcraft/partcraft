パラメーターとは、名前が付いた数値です。たとえば `width = 120` や `margin = bolt * 1.5` のようなものです。深さ、穴の直径、パターンの数、スケッチ寸法をパラメーターにリンクすると、パラメーターを変更したときに、それらすべてが 1 回の操作で変わります。これにより、設計意図を頭の中ではなく部品の中に保持できます。

## パラメーターを追加

1. 右パネルで {{ui:Parameters}} タブをクリックします。
2. **変数** の下で、「名前」欄に名前を入力します (例: `width`)。
3. 次の欄に値を入力します (例: `120`)。{{key:Enter}} を押します (または {{ui:Add}} をクリックします)。

値は、数値、または他のパラメーターの式にできます: `bolt * 1.5`、`width / 2 - 10`、`if(width > 100, 6, 4)`。**値** 列には、計算結果が表示されます。名前は文字または `_` で始まり、文字、数字、`_` のみを含みます。関数と単位の名前 (`sin`、`mm`、`pi`) は拒否されます。`a = b` と `b = a` のようなループも拒否されます。

## 数値をパラメーターにリンク

1. 履歴内のフィーチャー (例: 「Extrude1」) をクリックします。その設定が {{ui:Properties}} タブに表示されます。
2. **Depth (mm)** などの数値欄に `=` と式を入力します: `=thick` または `=width / 4`。
3. {{key:Enter}} を押します。

欄には結果が表示され、ラベルの横に **ƒ** ボタンが表示されます。カーソルを合わせると方程式が表示されます。スケッチ寸法も同じように機能します。フィーチャーの **Sketch dimensions** 一覧と、開いているスケッチの寸法欄の両方で使えます (寸法をダブルクリックし、`=width` と入力して {{key:Enter}} を押します)。

リンクできる数値: 押し出しの深さ、回転の角度、穴の直径、深さと座ぐりのサイズ、パターンの数、間隔と角度、フィレットの半径、面取りの距離、シェルの肉厚、すべてのスケッチ寸法、そして新しいフィーチャーのサイズ (2 番目の深さ、テーパー、皿穴、参照平面の距離、抜き勾配の角度など)。

## パラメーターを変更

{{ui:Parameters}} タブで、**式** 列に新しい値または式を入力して {{key:Enter}} を押します。リンクされているものはすべて変わり、部品は 1 回の操作で再構築されます。{{key:Mod+Z}} で元に戻せます。

数値を反対側から変更する方法は、[両方向の方程式](topic:equations-two-way) を参照してください。

## パラメーターの使用箇所を確認

{{ui:Parameters}} タブで、各パラメーターの下に、それを使用しているものを示す行が表示されます。

- それが駆動する数値。たとえば **Extrude1 depth** や **Sketch1 D2 (distance)**。クリックすると、そのフィーチャーを選択し、プロパティを表示します。
- 他のパラメーターを**経由して**駆動する数値。たとえば `d = h + 2` と `h = w / 2` の場合の **Hole1 diameter (through h, d)**。
- そのパラメーターを使用する式の **パラメーター**、それを設定する **構成**、それを読み取る **スクリプト** ([スクリプトを作成して実行](topic:craftscript) を参照)。

「Not used yet.」は、何も使用していないことを意味します。確認なしで削除できます。

## リンク解除、名前変更、削除

- **数値のリンク解除**: その **ƒ** ボタンをクリックするか、**Equations** 一覧の {{ui:Unlink}} を使います。現在の値は保持され、パラメーターはそれを変更しなくなります。
- **パラメーターの名前変更**: **Name** 欄に新しい名前を入力します。それを使用するすべての式が書き換えられます。
- **パラメーターの削除**: その行の × をクリックします。使用されている場合、PartCraft は、まず現在の値をそれらの式に書き込むかどうかを確認します。
- **フィーチャーの削除** は、そのフィーチャーの数値の方程式を削除します。どの方程式かは、ステータスバーに表示されます。

:::note
パラメーターは `.partcraft.json` ファイルに保存されます (ファイルバージョン 3)。パラメーターのない部品は、以前とまったく同じ形式で保存されます。
:::

## 式

| 記述 | 意味 |
|---|---|
| `120`、`12.5`、`1e3` | 数値 (ミリメートル、または角度の場合は度) |
| `2in`、`1ft`、`3"`、`1.5cm`、`0.2m` | 別の単位の長さ。ミリメートルに変換されます |
| `30deg`、`0.5rad` | 角度。度に変換されます |
| `+ - * / %` と `^` | 算術演算。`^` は累乗、`-2^2` は −4 |
| `sin cos tan asin acos atan atan2` | 度単位の三角関数 |
| `sqrt pow exp ln log abs sign` | その他の関数 |
| `ceil floor int round(x, digits) min max` | 丸めと範囲の制限 |
| `if(test, a, b)` と `< <= > >= == !=` | 選択。例: `if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

名前は大文字と小文字を区別します。`Width` と `width` は 2 つのパラメーターです。
