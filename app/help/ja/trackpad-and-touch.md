PartCraft はホイールと中ボタンを備えたマウス向けに作られていますが、ジェスチャーを覚えれば、トラックパッドでも快適に使えます。タッチ画面では、部品を見たり、簡単なスケッチを描いたりできます。

## トラックパッド

:::mac
| 操作 | 方法 |
|---|---|
| 部品を回転（3D） | 1 本指でクリックしてドラッグします（3 本指ドラッグをオンにしている場合は、3 本指でドラッグします） |
| パン（3D） | {{key:Shift}}（または ⌘）を押しながらクリックしてドラッグするか、2 本指を押したままクリックしてドラッグします（セカンダリクリックのドラッグ） |
| スワイプで部品を回転 | 2 本指でスワイプします。{{key:Shift}} を押すと、スワイプでパンします。**スクロール**を「自動判定」（最初の設定）または「トラックパッド」にする必要があります |
| ズーム（3D とスケッチ） | ピンチします。ズームはポインターの方向へ行われます。**スクロール**を「マウスホイール」にすると、2 本指スクロールでもズームします |
| 右クリック | 2 本指でクリック、または {{key:Ctrl}}+クリック |
| スケッチでパン | 2 本指でスワイプ（「自動判定」または「トラックパッド」）、または 2 本指を押したままクリックしてドラッグします。スケッチでは {{key:Shift}}+ドラッグはパンになりません（選択窓になります） |
| スケッチで選択に追加 | {{key:Shift}}+クリック、または ⌘+クリック |

2 本指クリックが動作しない場合は、**システム設定** › **トラックパッド** › **ポイントとクリック** で、セカンダリクリックをオンにしてください。
:::

:::windows linux
| 操作 | 方法 |
|---|---|
| 部品を回転（3D） | タッチパッドを押す（またはタップして押したまま）し、ドラッグします |
| パン（3D） | {{key:Shift}} または {{key:Ctrl}} を押しながらドラッグするか、右ボタンの領域を押したままドラッグします |
| スワイプで部品を回転 | 2 本指でスワイプします。{{key:Shift}} を押すと、スワイプでパンします。**スクロール**を「自動判定」（最初の設定）または「トラックパッド」にする必要があります |
| ズーム（3D とスケッチ） | タッチパッドが対応していればピンチします。ズームはポインターの方向へ行われます。**スクロール**を「マウスホイール」にすると、2 本指スクロールでズームします |
| 右クリック | 2 本指でタップするか、タッチパッドの右下の領域を使います |
| スケッチでパン | 2 本指でスワイプ（「自動判定」または「トラックパッド」）するか、右ボタンの領域を押したままドラッグします。スケッチでは {{key:Shift}}+ドラッグはパンになりません |
| スケッチで選択に追加 | {{key:Shift}}+クリック、または {{key:Ctrl}}+クリック |
:::

**スクロール**は、[PartCraft の設定](topic:settings)にあります。「自動判定」（最初の設定）は、横方向や細かいスクロールをトラックパッドとして扱います。「トラックパッド」は常にそうし、「マウスホイール」は決してそうしません。ピンチは 3 つのどの設定でもズームします。

ビュー内をクリックした後は、矢印キーで 3D ビューを回転させ、{{key:Shift}} と矢印キーでパンできます。トラックパッドでは便利です。{{key:Plus}} と {{key:Minus}} でズームします。

## タッチ画面

PartCraft はタッチ入力に対応しているため、タブレット、タッチ対応のノートパソコン、スマートフォンで使えます。ただし制限があります。

:::touch
**タッチ用のキー**

画面に触れると、ビューの右下に小さなバーが表示され、指にはないキーを使えます。マウスを使うと消えます。

- {{ui:Esc}}: Esc キーです。開始した操作をキャンセルするか、一つ前に戻ります（キーと同じ動作です）。
- {{ui:Add}}（スケッチの選択中）: オンの間は、タップするたびに項目が選択に追加されるか、選択から外れます（{{key:Shift}}+クリックと同じです）。もう一度タップすると、1 つずつの選択に戻ります。
- {{ui:Done}}（線の連鎖、スプライン、多角形を描いている間）: 右クリックと同じように完了させます。

指を約 0.5 秒間静止させると、1 回のタップと同じ効果になります。描画ツールでは描いているものを完了させ、選択ツールでは、指の下にある項目を選択に追加するか、選択から外します。点と線は指で当てやすくなっています。PartCraft は、クリックの場合の約 2 倍の範囲でタップを判定します。

**3D ビュー**

- 1 本指: 部品を回転します。
- 2 本指: ピンチでズームし、同時に動かすとパンします。
- タップ: 面、エッジ、平面を選びます。タップする前のホバー表示はありません。

**スケッチ**

- 描画ツールでは、タップして各点を置きます。始点をタップし、終点をタップします。指を離した位置でスナップします。
- 2 本指でピンチとパンをします。2 本目の指を置くと、最初の指で始めたドラッグはキャンセルされます。
- 線の連鎖を終えるには、{{ui:Done}} をタップするか、指を静止させるか、ツールバーで {{ui:Line}}（または別のツール）をもう一度タップします。
- 選択ツールでは、タップして選択します。点や線をドラッグして動かします。何もない場所でドラッグすると選択窓になります。2 回目のタップで選択が置き換わります（{{ui:Add}} がオンの場合、または 2 つ目の項目で指を静止させた場合を除きます）。
- 寸法を変更するには、右のパネルでその横にある**編集**を使います。

**図面シート**

記号をタップして置き、選択します。記号をドラッグして動かします。ピンチでズーム、2 本指で動かしてパン、または 1 本指で空白の用紙をドラッグします。ドラッグ中の記号があるときに 2 本目の指を置くと、その記号は止まり、元の位置に戻ります。

**キーボードが必要なもの**

- 数値の入力: 数値欄と寸法欄では、画面キーボードが表示されます。
- ツールのキーボードショートカット: ツールバーを使ってください。
:::

## 小さい画面とスマートフォン

- 1280 ピクセル以上では、ツールバーが 1 行に収まります。
- およそ 760～1100 ピクセルでは、サイドパネルが狭くなります。
- およそ 760 ピクセル未満（スマートフォン、または狭いウィンドウ）では、画面が縦に積み重なります。ツールバー（横にスワイプするとさらにボタンが出てきます）、3D ビュー、ステータスバー、その後にプロパティパネルと履歴が表示されます。パネルに移動するには、ページをスクロールしてください。
- メニュー（{{ui:エクスポート}}、{{ui:表示}}）は画面の幅いっぱいに開きます。

:::note
iPhone では、ブラウザーに全画面表示モードがありません。{{key:Ctrl+Shift+F}} と画面モードのボタンは、通常表示とバーを隠した表示の切り替えだけを行います。
:::

スマートフォンでも、部品を開いて回転させ、その情報を確認することはできます。本格的なモデリングには、大きい画面とマウスまたはトラックパッドが必要です。

## ブラウザー

Windows、macOS、Linux、タブレット、スマートフォンでは、最新の Chrome、Edge、Firefox、Safari で PartCraft を実行できます（WebGL と WebAssembly が使える限り）。[ブラウザーとコンピューター](common:browsers)を参照してください。
