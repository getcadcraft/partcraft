ジオメトリカーネルは、履歴をソリッドに変換するエンジンです。このバージョンのPartCraftには、**メッシュカーネル**(manifold-3d)があります。コンピューター上で小さなWebAssemblyプログラムとして動作し、アプリが開いた後すぐに使える状態になります。パーツの情報がどこかに送信されることはありません。

| | メッシュカーネル |
|---|---|
| 丸い形状 | 平らなファセット。パーツパネルの**曲線**で細かさを設定します |
| ボリュームと面積 | ファセット化されたソリッドの値です。丸い部分では少し小さめになります |
| スケッチ、押し出し、切り抜き、回転、穴、パターン、ミラー、基準平面 | はい |
| フィレットと面取り | 平らな面の間の直線のエッジ上で有効です。交わる丸み部分は留め継ぎになります |
| シェルと抜き勾配 | シェルは平らな面を開きます(壁の厚さは正確です)。抜き勾配は平らな面を傾けます |
| 書き出し | STL、3MF、STEP(厳密: 丸い面は真の曲面として書き出されます。またはファセット)、図面PDF、DXF |
| 図面ビュー | ファセットから描かれます。断面ビューを含みます |
| 面とエッジ | 名前が付き、種類(平面、円柱、円錐、球、トーラス、直線、円)で認識されます。スケッチから取得され、シミュレーション、ジェネレーティブ、製造のワークスペース、計測、選択、穴の表で使われます |

ステータスバーの右端近くの表示には、パーツを作成している間、**メッシュカーネル**と表示されます。

## 厳密カーネルを待つ機能

厳密(B-rep)カーネルは、真の円、円柱、円錐を保持します。また、任意のエッジ上の滑らかなフィレット、スイープ、ロフト、サーフェス、板金、リブ、複数のボディ、曲面を保持したままのSTEPインポートは、この上で作成されます。(厳密STEPの書き出しはこれを待つ必要はありません。メッシュカーネルはスケッチから各面の真の曲面を把握しており、書き出しはその曲面で行われます。)PartCraftの以前の検証ビルドでは、そのためにOpenCascadeを使っていました。そのライセンス(LGPL)は、すべてのアプリがApache-2.0で、寛容なライセンスのライブラリだけを使うこのリリースには合わないため、含まれていません。ここには、まだ日付は決まっていません。

それまでは、これらの機能を選択すると**まだ作成されていません**と表示されます。ステータスバーに理由が表示され、ボタンのツールチップは「まだ作成されていません(厳密カーネルが必要)」で終わります。[まだ作成されていない機能](topic:not-built-yet)では、各機能と代わりにできる操作を一覧にしています。

以前のビルドで作られたパーツは、今でも開けます。それらの機能は、まだ作成されていないとマークされた状態で履歴に残ります(理由は、項目にマウスを重ねると表示されます)。残りのパーツは作成され、保存するとそれらはそのまま残ります。

## 丸い面と曲線

メッシュカーネルは円を多角形として描画します。パーツパネルの**曲線**は、1つの円に何辺を割り当てるかを設定します。辺が多いほど滑らかに見え、真の値に近い測定結果になりますが、作成に時間がかかります。計測からのボリューム、面積、距離は、このファセット化されたソリッドのものです。穴やボスの場合、丸い形状の値よりわずかに小さくなります。

## オンラインとオフライン

メッシュカーネルは、アプリ自体のダウンロードに含まれています。接続なしで作業するには、オンラインのときにPartCraftをオフラインで使えるように保存します。アプリバーで{{ui:オフライン用に保存}}を選び、**オフライン準備完了**と表示されるまで待ちます。詳細: [オフラインでの作業](common:offline)。
