ジオメトリカーネルは、履歴をソリッドに変えるエンジンです。このバージョンのPartCraftには、**メッシュカーネル** (manifold-3d) が1つあります。小さなWebAssemblyプログラムとしてお使いのコンピューター上で動作し、アプリを開いてすぐに利用できます。部品のデータがどこかに送信されることはありません。

| | メッシュカーネル |
|---|---|
| 丸い形状 | 平らなファセット。細かさは部品パネルの**曲線**で設定 |
| 体積と面積 | ファセット化したソリッドの値。丸い部品では少し小さめ |
| スケッチ、押し出し、カット、回転、穴、パターン、ミラー、基準平面 | 対応 |
| フィレットと面取り | 平らな面の間のまっすぐなエッジ。交わる丸みはマイター処理 |
| シェルと抜き勾配 | シェルは平らな面を開く (壁の厚さは正確)、抜き勾配は平らな面を傾ける |
| 書き出し | STL、3MF、STEP (ファセット)、図面PDF、DXF |
| 図面のビュー | ファセットから描画。断面ビューを含む |
| 面とエッジ | 種類 (平面、円柱、円錐、球、トーラス、直線、円) を持ち、スケッチから名前が付けられます。シミュレーション、ジェネレーティブ、製造のワークスペース、計測、ピック、穴の表が利用します |

部品を作成している間、ステータスバーの右寄りのチップに**メッシュカーネル**と表示されます。

## 厳密カーネルを待っているもの

厳密 (B-rep) カーネルは、本物の円、円柱、円錐を保持します。任意のエッジの滑らかなフィレット、スイープ、ロフト、サーフェス、板金、リブ、複数のボディ、STEPの読み込み、厳密なSTEPの書き出しは、これを土台にしています。以前のラボビルドのPartCraftは、そのためにOpenCascadeを使っていました。そのライセンス (LGPL) は、すべてのアプリがApache-2.0で、寛容なライセンスのライブラリのみを使うこのリリースには適合しないため、含まれていません。これに日付はありません。

それまでは、それらのフィーチャーを選ぶと**まだ作成されていません**と表示されます。理由はステータスバーに表示され、ボタンのツールチップは「まだ作成されていません (厳密カーネルが必要です)」で終わります。代わりにできることは、各フィーチャーとともに[まだ作成されていないもの](topic:not-built-yet)に一覧しています。

以前のビルドでそれらを使って作った部品も、引き続き開けます。それらのフィーチャーは、作成されていないものとして履歴に残り (ポインターを合わせると理由が表示されます)、部品のほかの部分は作成され、保存してもそのまま保持されます。

## 丸い面と曲線

メッシュカーネルは、円を多角形として描きます。部品パネルの**曲線**で、円1周の辺の数を指定します。辺が多いほど滑らかに見え、実際の値に近く測定され、作成に時間がかかります。{{ui:計測}}の体積、面積、距離は、このファセット化したソリッドの値です。穴やボスでは、丸い形状の値より少し小さくなります。

## オンラインとオフライン

メッシュカーネルは、アプリ自体のダウンロードに含まれます。接続なしで使うには、オンラインのうちにPartCraftをオフライン用に保存します。アプリバーで{{ui:オフライン用に保存}}を選び、**オフライン対応済み**と表示されるまで待ちます。詳細は[オフラインで使う](common:offline)を参照してください。
