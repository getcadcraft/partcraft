CraftScript は MATLAB に似せて書かれた行列言語なので、古典的な数値計算コード（88 行のトポロジー最適化コードなど）の多くは、わずかな修正だけで動きます。[スクリプトワークスペース](topic:craftscript) で実行するほか、コマンドラインからも実行できます。

## 値

| 型 | 例 | 補足 |
|---|---|---|
| 数値、配列 | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | すべての数値は配列です（1×1 の配列）。配列は列ごとに格納され、最大 8 次元まで使えます |
| 論理 | `A > 2`, `true` | true/false の配列。添字として使えます |
| 文字列 | `'beam'`, `"beam"` | |
| 疎行列 | `sparse(i, j, v, n, n)` | 剛性行列向け |
| メッシュ、フィールド、モデル | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` が描くもの |
| 構造体 | `s.E = 210e3` | 名前付きのフィールド |
| セル | `c = {1, 'two', [3 4]}` | 任意の値の一覧 |
| 関数ハンドル | `f = @(x) x.^2` | |

## 配列と添字

- 範囲: `1:5`, `0:0.1:1`。`linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`。
- 添字は 1 から始まります: `A(2, 3)`, `v(end)`, `A(:, 1)`（列全体）, `A(:)`（すべてを 1 列にしたもの）, `v(v > 0)`（論理添字）。
- 末尾を超えて代入すると、MATLAB と同じく配列が大きくなります: `v(10) = 1`。

## 演算子

- `+ - * / \ ^` は行列演算です（`A \ b` は連立方程式を解きます）。`.* ./ .^` は要素ごとに動作します。`'` は転置します。
- 比較は `== ~= < <= > >=`。論理は `& | ~`（要素ごと）と `&& ||`（短絡評価）です。

## 制御フローと関数

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

関数は、スクリプト内のコマンドの後ろに置くか、関数名を付けた独自のスクリプトタブに置きます:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

名前は次の順で探されます: 変数、このパーツ内の同名のスクリプト、ライブラリ関数、組み込み関数。

## 値の表示、コメント、出力

- `;` を付けない文は値を表示します。`;` を付けると表示されません。
- `%` でコメントを始めます。`%{` と `%}` を単独の行に書くと、その間の行がコメントアウトされます。
- `disp(x)`, `fprintf('%g\n', x)`, `display(x)` はコンソールに表示します。

## エラーと制限

- エラーは、何が問題かを平易な言葉で示し、行番号（と関数呼び出しの連鎖）を示します。
- 実行ごとにステップ上限があります（パネルの実行オプション）。終わらないループはメッセージとともに停止します。または {{ui:停止}} を押してください。
- 配列には、それぞれ最大 1 億 3400 万の値を保持できます。

## MATLAB との違い

- プロットのコマンドは、オプションを呼び出しの中に書きます: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`。`figure`、`hold`、`axis`、`title(…)` などは受け付けられますが、何もしません。
- `input` と `keyboard` は対応していません。スクリプトは、質問のために止まることができません。
- ツールボックスはありません。[解析ライブラリ](topic:craftscript-library) と組み込み関数が、利用できるすべてです。
