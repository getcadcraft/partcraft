## 作業内容

**部品のすべてのサイズを一度に**まとめます。各コンフィギュレーションにつき、STEP、IFC、DWGのファイルと画像を1つずつ、それぞれの内容を示す表、そしてすべてを1ページにまとめたライブラリ項目を作成します。

まず**コンフィギュレーション**を設定した部品が必要です（[コンフィギュレーションと設計表](topic:design-tables)を参照）。特徴をオフにするコンフィギュレーション（例: 穴のある板と穴のない板）は、それぞれ独自のバリアントになります。

## 手順

1. 部品を開きます。{{ui:パラメーター}}タブで**コンフィギュレーション**を探します。
2. {{ui:バリアントパック…}}をクリックします。
3. 構築するコンフィギュレーション（初期状態ではすべてチェック済み）と、書き出すファイル（STEP、IFC、DWG、プレビュー、ライブラリ項目）にチェックを入れます。
4. {{ui:パックを作成}}をクリックします。ステータス行に、バリアントを構築するたびに数が表示されます。部品は変更されません。
5. zipファイルが1つダウンロードされます: `<part> variants.zip`

## zipの内容

| ファイル | 内容 |
|---|---|
| `<name>.step` | コンフィギュレーションをSTEPソリッドとして書き出したもの。 |
| `<name>.ifc` | IFC4。構築された本体を含む1つの要素で、部品のパラメーターがプロパティとして入ります。値はそのコンフィギュレーション自身のものです。 |
| `<name>.dwg` | 正面、上面、右面、等角投影の各ビューを、実寸の図面シートとして書き出したもの。 |
| `<name>.svg` | その等角投影の線画。 |
| `variants.csv`, `variants.json` | パラメーターの表です。各バリアントのID、名前、すべてのパラメーターの値、オフにする特徴、そのファイル、体積、サイズを含みます。 |
| `<part>.item.json` | バリアントを含めて1つのライブラリ項目とした部品（下記を参照）。 |
| `README.txt` | 作成内容、以下の注記、構築されなかったものを記載したもの。 |

ファイル名はコンフィギュレーションの名前から付けられます。構築に失敗したコンフィギュレーション（その値では作成できない特徴がある場合）は、ファイルと表から除外されます。除外されたものはREADMEと、zipの保存後に表示されるメッセージに記載されます。その他は引き続き書き出されます。

## 知っておくと便利なこと

- **STEP** は、お使いのビルドで厳密カーネルが有効な場合は厳密になります。無効な場合、STEPはファセット（平面の三角形）になり、READMEにその旨が記載されます。
- **DWG** は3Dモデルではなく図面シートです。線はメッシュから作られるため、曲線のエッジは多数の短い線になります。
- **ライブラリ項目** には、ライブラリ自身の軸（Z軸が上、正面は−Y方向、挿入点は背面の底部中央）で、バリアントごとに1つの本体と1つの平面形状が含まれます。平面形状はバリアントごとの外接矩形です。項目のサイズは8 MBまでに制限されます。非常に重いバリアントは、そのサイズの箱に置き換えられます。その数はREADMEに記載されます。
- 部品で現在有効なコンフィギュレーションが、項目の既定のバリアントになります。
- ポート（配管やダクトの接続点）はPartCraftからは設定されません。

## バリアントをライブラリページに掲載する

サイトの **ライブラリ › アップロード** で `<part>.item.json` をアップロードします。カテゴリ、ライセンス、帰属表示を選ぶと、バリアントを含むライブラリ項目になります。BimCraftで配置すると、どのバリアントかを尋ねられ、入れ替えで他のバリアントに切り替えられます。訪問者がオプションを選び、3Dを確認し、バリアントをダウンロードするコンフィギュレーターのページは、現時点では**スタッフ向けプレビュー**です。まだ一般公開されていません。

## コマンドラインから

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` はコンフィギュレーションを名前で指定します。`--formats` には `step`、`ifc`、`dwg`、`preview` のいずれかを指定します。`--no-item` を付けるとライブラリ項目を作成しません。フォルダー、zip、またはその両方を書き出します。バリアントを構築できなかった場合は終了コード 1 で終了します。[スクリプトとコマンドライン](topic:scripts-and-cli)を参照してください。
