数値がわかっている場合は、クリックして寸法を付けるより、数値を入力するほうが速く済みます。**座標で追加** は、スケッチを開いているときは右パネルにあります。ポインターを使わずにスケッチを作成することもできます。

座標の単位はミリメートルで、スケッチ自身の軸を使います。スケッチを見たときに、x は右方向、y は上方向です。原点 (0, 0) は十字の付いた赤い円です。

## 形状を追加

1. スケッチを開きます ([最初のスケッチを描く](topic:sketch-basics) を参照)。
2. 右パネルで **座標で追加** までスクロールします。
3. **追加** で形状を選びます: 線分、中心線、長方形、円、点。
4. ボックスに値を入力します:

| 形状 | ボックス |
|---|---|
| 線分 | **始点 x, y** と **終点 x, y** |
| 中心線 | **始点 x, y** と **終点 x, y** |
| 長方形 | **角 x, y** と **対角の角 x, y** |
| 円 | **中心 x, y** と **半径** |
| 点 | **位置 x, y** |

5. {{ui:追加}} を選ぶか、いずれかのボックスで {{key:Enter}} を押します。

形状が表示され、ステータスバーに、たとえば「長方形を追加しました。」と表示されます。ボックスは空になり、次の形状を入力できます。追加は一つずつ、{{ui:元に戻す}} の 1 回分になります。

点の座標は、2 つの数値をカンマまたはスペースで区切って入力します: `0, 0`、`25 -10`、`12.5,40`。負の数と小数も使えます。半径は 0 より大きい値にする必要があります。数値として読めない場合、ステータスバーに「座標は "x, y" の形式で、半径は 0 より大きい値で入力してください。」と表示されます。

## 例: 溝付きプレートの輪郭を入力

1. **正面平面** にスケッチを開きます。
2. **追加**: 長方形。**角 x, y**: `-50, -30`。**対角の角 x, y**: `50, 30`。{{key:Enter}}。
3. **追加**: 円。**中心 x, y**: `-30, 0`。**半径**: `5`。{{key:Enter}}。
4. **中心 x, y**: `30, 0`。**半径**: `5`。{{key:Enter}}。
5. {{ui:スケッチを終了}} を選び、続けて {{ui:押し出し}} を選びます: 100 × 60 のプレートに、直径 10 mm の穴が 2 つ付きます。

## 入力した形状は配置されるだけで、拘束はされません

入力した座標によって形状は正しい位置に置かれますが、**拘束** ではありません。形状は青色 (不足定義) のままで、ドラッグしたり別の寸法を変更したりすると動くことがあります:

- 入力した長方形には、描いた長方形と同じ角、水平、垂直の拘束が付きますが、原点とは結び付けられていません。
- 入力した線分には、水平や垂直の拘束は付きません。水平な線を入力した場合も同様です。
- 入力した円の中心は自由に動きます。

スケッチを完全定義するには、後から寸法や拘束を追加します ([スケッチを完全定義する](topic:relations-dimensions) を参照)。たとえば、長方形の角と原点を選択して **• 一致** を選ぶか、円の中心を原点から寸法で指定します。

:::note
ポインターを使わなくても、ここまでは操作できます。履歴で {{key:Tab}} と矢印キーを使って平面の行に移動し、{{key:Enter}} で選択、{{key:S}} でスケッチを開始して、ここで形状を追加します。各寸法の横にある **編集** に移動し、{{key:Tab}} で {{ui:スケッチを終了}} を選べます。ただし、このビルドでは、形状を選択して拘束や新しい寸法を追加するには、まだクリックまたはタップが必要です。
:::

## 制限

- 円弧はまだ入力できません。円弧ツールで描くか、円を入力してから拘束を使ってください。
- このボックスでは、相対座標 (直前の点からの座標) や極座標 (長さと角度) は使えません。
- 入力した形状は既存の点に吸着しません。既存の点と同じ座標を入力し、それらをつないだままにする必要がある場合は、その間に **• 一致** の拘束を追加してください。
