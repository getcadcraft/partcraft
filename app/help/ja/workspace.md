画面は5つの部分でできています。上部のツールバー、左の履歴、中央の3Dビュー、右のプロパティパネル、下部のステータスバーです。それらすべての上にCadCraftのアプリバーがあります。

## アプリバー

最上部の細いバーは、PartCraft自体ではなくCadCraftサイトに属しています。アプリ名と実行場所、バージョンメニュー、**PartCraftについて**、画面モードのボタン、ペーパー / モデルのテーマ切り替えがあります。

- **ペーパー**は明るいシートに暗い線、**モデル**は暗い背景に明るい線です。スケッチの色はテーマに従います。
- {{ui:設定}} (歯車、または{{key:Mod+,}}) には{{ui:PartCraft}}タブがあり、ビューを回すマウスボタン、マウスホイールまたはトラックパッド、スケッチ中の拘束を設定します。[PartCraftの設定](topic:settings)を参照してください。
- 画面モードのボタン、または{{key:Ctrl+Shift+F}}で、通常、全画面表示、バーを隠した全画面表示を順に切り替えます。バーを隠しているときは、ポインターを上端に動かす (またはそこをタップする) とバーが戻ります。{{key:Esc}}キーで通常に戻ります。このキーは、Macでも⌘ではなく{{key:Ctrl+Shift+F}}です。

## ツールバー

ツールバーはグループ分けされています。操作に応じて内容が変わり、1行に収まります。

| グループ | ボタン | 表示される場面 |
|---|---|---|
| ファイル | {{ui:新規}}、{{ui:開く}}、{{ui:保存}}、{{ui:エクスポート}} (メニュー) | 常時 |
| スケッチ | {{ui:スケッチ}} | スケッチが開いていないとき |
| スケッチ | {{ui:終了}}、{{ui:線分}}、{{ui:長方形}}、{{ui:円}}、{{ui:円弧}}、{{ui:点}}、{{ui:中心線}}、{{ui:フィレット}}、{{ui:寸法}}、{{ui:補助ジオメトリ}} | スケッチを開いている間のみ |
| フィーチャー | {{ui:押し出し}}、{{ui:カット}}、{{ui:回転}}、{{ui:穴}}、{{ui:直線}}、{{ui:円形}}、{{ui:鏡像化}}、{{ui:フィレット}}、{{ui:面取り}}、{{ui:シェル}}、{{ui:その他}} (メニュー: 回転カット、平面、軸、点、スイープ、ロフト、抜き勾配) | 部品の上。スケッチや図面を開いている間は表示されません。フィレットと面取りは、2つの平らな面の間のまっすぐなエッジに対して、シェルと抜き勾配は平らな面に対して使えます。スイープとロフトはこのバージョンではまだ作成されていません (厳密カーネルが必要)。クリックすると、その旨が表示されます |
| フィーチャー | {{ui:完了}} | フィレット、面取り、シェル、抜き勾配のエッジや面を選んでいる間のみ |
| 図面 | {{ui:図面}} | 部品の上 (部品にソリッドができると使えます) |
| 図面 | {{ui:データム}}、{{ui:公差枠}}、{{ui:表面粗さ}}、{{ui:詳細図}}、{{ui:PDF}}、{{ui:戻る}} | 図面シートの上のみ |
| アセンブリ | {{ui:アセンブリ}} | 部品の上 (部品にソリッドができると使えます) |
| アセンブリ | {{ui:コピーを追加}}、{{ui:挿入}}、{{ui:ジョイント}}、{{ui:干渉チェック}}、{{ui:部品を編集}}、{{ui:閉じる}} | アセンブリの中のみ |
| アセンブリ | {{ui:戻る}} | アセンブリから部品を編集している間 |
| 編集 | {{ui:元に戻す}}、{{ui:やり直し}}、{{ui:コピー}}、{{ui:貼り付け}}、{{ui:その他}} (メニュー: 切り取り、コピー、貼り付け、同じ位置に貼り付け、複製、削除、すべて選択、選択解除) | 常時。各項目は、いま操作しているスケッチ、履歴、アセンブリに作用します |
| 表示 | {{ui:全体表示}}、{{ui:法線方向}}、{{ui:表示}} (メニュー: 計測、質量特性、断面、抜き勾配、ゼブラ、曲率、{{ui:基準平面}}、続いて等角投影、正面、背面、上面、下面、右面、左面) | 常時 |

ボタンにポインターを合わせると、機能とキーが表示されます。グレー表示のボタンは、いまは使えません。たとえば、スケッチを開いている間のフィーチャーボタンや、アセンブリに部品が2つない状態の{{ui:ジョイント}}です。

編集グループの{{ui:その他}}メニューには、各編集操作がキーとともに並びます。コピーと貼り付けが何に作用するかは、いま操作している場所によって変わります。[コピー、貼り付け、複製](topic:copy-paste)を参照してください。グレー表示の項目は、ツールチップに使えない理由が表示されます。

{{ui:エクスポート}}メニューには、{{ui:STL（3Dプリント用）}}、{{ui:3MF（3Dプリント用）}}、{{ui:STEP AP242（厳密ソリッド）}}、{{ui:STEP AP214（厳密ソリッド）}}、{{ui:STEP（ファセット、メッシュカーネル）}}、{{ui:STEP AP214 (ファセット、メッシュカーネル)}}、{{ui:スケッチまたは平らな面の DXF}}、{{ui:図面 (PDF): 図、断面、詳細図、幾何公差}}があります。2つの厳密STEPの項目はグレー表示です。このバージョンではまだ作成されていないので、{{ui:STEP（ファセット、メッシュカーネル）}}を使ってください。

## 履歴 (左)

左のパネルは部品のフィーチャー履歴で、PartCraftが上から下へ再作成するリストです。

- 見出しは部品の名前です (名前を変えるまでは「Part1」)。
- **正面**、**上面**、**右面**が最初に並びます。クリックで選択され、ビューで強調表示されます。
- その下に、作成した順にフィーチャーが並びます。フィーチャーが使うスケッチは、そのフィーチャーの下にインデントされます。
- 行の右端のフラグが、その状態を示します。

| フラグ | 意味 |
|---|---|
| (なし) | 作成済みで、スケッチは完全拘束 |
| − | 拘束不足のスケッチ (まだ動かせます) |
| + | 過剰定義のスケッチ |
| ⚠ | 作成済みだが警告あり (ポインターを合わせると読めます) |
| ⚠ エラー | フィーチャーが失敗。ポインターを合わせるかクリックすると理由がわかります |
| ⚠ 未作成 | 失敗した、またはオフになっている別のフィーチャーが必要 |
| オフ | 抑制済み |

- 各フィーチャーは、名前の後ろに主な数値を表示します。押し出しなら「25 mm」、穴なら「Ø6.6 thru」などです。数値をダブルクリックするか、行で{{key:F2}}キーを押すと、その場で変更できます。[サイズを変更する](topic:change-sizes)を参照してください。
- フィーチャーをクリックすると、右で編集できます。スケッチはダブルクリックで開きます。
- ロールバックすると、リストに**ロールバックバー · ロールフォワード**の行が現れます。その下のフィーチャーはグレー表示になり、作成されません。
- 行にフォーカスがあるとき、{{key:Up}}と{{key:Down}}で行を移動し、{{key:Alt+Up}} / {{key:Alt+Down}}で、履歴が許す範囲でフィーチャー自体を移動します。

アセンブリでは、同じパネルに代わりに**部品** (最初のものには「固定」と表示) と**ジョイント**が一覧されます。

### 部品情報

履歴の下の**部品**ボックスには、ソリッドの**体積**、**表面積**、**サイズ (X × Y × Z)**、**貫通穴**、**ボディ**、**三角形**、**フィーチャー**の数、**失敗**している数が一覧されます。体積と面積は、メッシュカーネルが作成したファセット化したソリッドの値で、丸い形状では実際の値よりやや小さくなります ([フィーチャーとオプション](topic:features#curves-resolution)を参照)。

アセンブリでは、このボックスの見出しは**アセンブリ**になり、部品、インスタンス、ジョイント、未結合、干渉が表示されます。

## 3Dビュー (中央)

ビューには、ソリッド、基準平面、まだフィーチャーに使われていないスケッチが表示されます。

基準平面は、部品が空の間はそのまま描かれます。ソリッドができると、部品を覆わないように薄く描かれ、クリックは平面を通り抜けて部品に届きます。スケッチする場所を選んでいるとき (何も選択せずに{{ui:スケッチ}}を選んだとき)、および履歴で平面を選択したときは、元の表示に戻ります。{{ui:表示}} › {{ui:基準平面}}で完全に非表示にできます。ただし、スケッチする場所を選んでいる間は表示されます。PartCraftはその選択を記憶します。

- ドラッグで部品を回し、右ドラッグまたは中ボタンドラッグでパン、ホイールでポインター位置にズームします。詳細は[キーとマウス](topic:keyboard)を参照してください。
- 面、エッジ、平面にポインターを合わせると光ります。クリックで選択されます。面は全体が強調表示され、エッジは全体が描画・選択されます。{{key:Shift}}+クリックで、複数のエッジや面を集められます。それらはマークされたままになります。
- 右上のビューキューブは部品とともに回ります。面、エッジ、角をクリックするとそこから見る向きになり、ドラッグで回転し、家のボタンで開始時の状態に戻ります。[ビューキューブ](topic:view-cube)を参照してください。
- 選択した押し出しには、端面にオレンジ色の矢印が、回転には回転の終端に曲がった矢印が表示されます。ドラッグして深さや角度を変更するか、横のボックスに入力します。[サイズを変更する](topic:change-sizes#drag-it-in-the-view)を参照してください。
- 部品が空のときは、「部品を作成する」というボックスに、最初の手順が一覧されます。
- `.partcraft.json`または`.partcraft-asm.json`ファイルをビューのどこにでもドロップすると開きます。`.step`、`.stp`、`.stl`、`.obj`、`.3mf`、`.3dm`ファイルをドロップすると、ソリッドボディとして開きます。

### エッジや面を選んでいる間

何も選択せずに{{ui:フィレット}}、{{ui:面取り}}、{{ui:シェル}}を選んだ後 (またはそのようなフィーチャーで{{ui:エッジを選択}}を選んだ後)、部品はそのフィーチャーの前の状態で表示されます。エッジや面をクリックして追加または除外します。マークが含まれているものを示します。{{ui:完了}}または{{key:Esc}}キーで終了します。[丸め、面取り、中空化](topic:fillet-chamfer-shell)を参照してください。

### 図面シートの上

{{ui:図面}}は、3DビューをA3の図面シートに置き換えます。ホイールでズーム、右または中ボタンドラッグでパン、{{key:F}}キーで全体表示します。[図面を作る](topic:drawing-pdf)を参照してください。

### スケッチを開いている間

ビューはスケッチ平面を正面から見る向きに回り、上に2Dのスケッチレイヤーが現れます。部品には、このスケッチより前に作ったフィーチャーだけが表示されます。左上の帯に、スケッチの状態チップ (「完全拘束」「拘束不足・自由度 3」など) と、「Sketch2 on a face of Extrude1」のような名前が表示されます。

## プロパティパネル (右)

右のパネルには、選択しているものが表示され、見出しがその名前を示します。

- **部品** (何も選択していない): 部品の**名前**と**曲線**の設定。
- 平面: {{ui:この平面にスケッチ}}ボタン。
- **面**: その種類 (平面、半径と軸を持つ円柱、円錐、球、トーラス)、面積、作成したフィーチャー、平らな面では{{ui:この面にスケッチ}}、{{ui:法線方向から表示}}、{{ui:面を DXF で書き出す}}、{{ui:この面から押し出し}}、{{ui:この面に切り込み}}、{{ui:ここに穴}} ([面全体を引く・押す](topic:extrude-and-cut#pull-or-push-a-whole-face)を参照)。
- **エッジ**: その種類 (直線、中心と半径を持つ円、曲線)、長さ、挟んでいる2つの面 (「Extrude1 end face and Extrude1 side」など)、{{ui:フィレット}}と{{ui:面取り}}ボタン。
- {{key:Shift}}で選択した複数のエッジや面: その数、エッジでは{{ui:フィレット}}と{{ui:面取り}}、そして{{ui:クリア}}。
- フィーチャー: その数値とオプション、そのスケッチの寸法、続いて{{ui:抑制}}、{{ui:ここまでロールバック}}、{{ui:上に移動}}、{{ui:下に移動}}、{{ui:削除}}、**名前**。
- 開いているスケッチ: その状態、選択に追加できる拘束、拘束と寸法の一覧、**座標で追加**、{{ui:スケッチを終了}}、{{ui:全体表示}}、{{ui:DXF として書き出す}}。
- 図面シートの上: 断面と詳細図の設定、または選択した幾何公差記号。
- アセンブリの中: アセンブリ、選択した部品、または選択したジョイント。

数値ボックスは、{{key:Enter}}キーまたは{{key:Tab}}キーを押すか、ほかをクリックすると反映されます。部品はすぐに再作成され、OKボタンはありません。戻るには{{key:Mod+Z}}を使います。

## ステータスバー (下)

- 左: スケッチ内のポインターの座標 (スケッチを開いている間のみ)。
- 中央: メッセージ。次にすること、何かが拒否された理由。何も起きないように見えるときは、ここを読んでください。
- 右寄り: カーネルのチップ。このバージョンでは常に「メッシュカーネル」です。ポインターを合わせると意味が表示されます。[メッシュカーネル](topic:solid-kernels)を参照してください。
- 右端: チップ。部品の再作成中は「再作成中…」、問題がなければ「… ms で再作成しました」、問題があれば「1 feature failing」。アセンブリでは「… ms で配置しました」か、ジョイントの問題の数が表示されます。

[Illustrateでマニュアルを始める](topic:illustrate)も参照してください。部品とアセンブリから、アセンブリのマニュアルを作るワークスペースです。

## 画面幅が狭い場合

幅が760ピクセル以下 (スマートフォンなど) の場合は、ビューが画面を占めます。ツールバーは1行で横にスクロールし、パネルは下部のバーからシートとして開きます。{{ui:ツール}}はツールバーを隠し、{{ui:移動}}はツールバーを下に配置します。[トラックパッド、タッチ、小さな画面](topic:trackpad-and-touch)を参照してください。
