画面は5つの部分で構成されます。上部のツールバー、左の履歴、中央の3Dビュー、右のプロパティパネル、下のステータスバーです。その上には、CadCraftのアプリバーがあります。

## アプリバー

最上部の細いバーは、PartCraftではなくCadCraftのサイトに属します。アプリ名と実行場所、バージョンメニュー、**PartCraftについて**、画面モードボタン、ペーパー / モデルのテーマ切り替えを表示します。

- **ペーパー** は明るいシートに暗い線、**モデル** は暗い背景に明るい線です。スケッチの色はテーマに従います。
- {{ui:設定}}（歯車、または {{key:Mod+,}}）には {{ui:PartCraft}} タブがあり、ビューを回転させるマウスボタン、マウスホイールまたはトラックパッド、スケッチ中の拘束を設定します。[PartCraftの設定](topic:settings)を参照してください。
- 画面モードボタン、または {{key:Ctrl+Shift+F}} で、通常、全画面、バーを隠した全画面の順に切り替えます。バーを隠した状態では、ポインターを上端に移動する（またはそこをタップする）と、バーが戻ります。{{key:Esc}} で通常に戻ります。このキーはMacでも {{key:Ctrl+Shift+F}} です（⌘ ではありません）。

## ツールバー

ツールバーはグループ化されています。作業内容に応じて変わり、1行に収まるように表示されます。

| グループ | ボタン | 表示条件 |
|---|---|---|
| ファイル | {{ui:新規}}、{{ui:開く}}、{{ui:保存}}、{{ui:エクスポート}}（メニュー） | 常に |
| スケッチ | {{ui:スケッチ}} | スケッチが開いていないとき |
| スケッチ | {{ui:終了}}、{{ui:線分}}、{{ui:長方形}}、{{ui:円}}、{{ui:円弧}}、{{ui:点}}、{{ui:中心線}}、{{ui:フィレット}}、{{ui:寸法}}、{{ui:補助ジオメトリ}} | スケッチが開いているときのみ |
| 特徴 | {{ui:押し出し}}、{{ui:切り取り}}、{{ui:回転}}、{{ui:穴}}、{{ui:直線}}、{{ui:円形}}、{{ui:ミラー}}、{{ui:フィレット}}、{{ui:面取り}}、{{ui:シェル}}、{{ui:その他}}（メニュー: 回転切り取り、平面、軸、点、スイープ、ロフト、ドラフト） | 部品上にあるとき。スケッチや図面が開いている間は除く。フィレットと面取りは、2つの平面の間にある直線のエッジに使えます。シェルとドラフトは平面に使えます。スイープとロフトは、このバージョンではまだ作成されていません（厳密カーネルが必要です）。クリックすると、その旨が表示されます |
| 特徴 | {{ui:完了}} | フィレット、面取り、シェル、またはドラフトのエッジや面を選択中のみ |

| 図面 | {{ui:データム}}、{{ui:公差枠}}、{{ui:仕上げ}}、{{ui:詳細図}}、{{ui:PDF}}、{{ui:戻る}} | 図面シートのみ |
| アセンブリ | {{ui:アセンブリ}} | 部品上（部品にソリッドがあれば使用可） |

ボタンにポインターを合わせると、その機能とキーが表示されます。グレーアウトしたボタンは、今は使えません。例えば、スケッチが開いている間の特徴ボタン、またはアセンブリに部品が2つそろう前の{{ui:ジョイント}}です。

編集グループの {{ui:その他}} メニューには、各編集操作がキーとともに一覧表示されます。コピーと貼り付けの対象は、現在の位置に従います。[コピー、貼り付け、複製](topic:copy-paste)を参照してください。グレーアウトした項目のツールヒントには、今は実行できない理由が表示されます。

{{ui:エクスポート}} メニューには、{{ui:STL（3Dプリント用）}}、{{ui:3MF（3Dプリント用）}}、{{ui:STEP AP242（厳密ソリッド）}}、{{ui:STEP AP214（厳密ソリッド）}}、{{ui:STEP（ファセット、メッシュカーネル）}}、{{ui:STEP AP214 (ファセット、メッシュカーネル)}}、{{ui:スケッチまたは平らな面のDXF}}、{{ui:図面 (PDF): 図、断面、詳細図、幾何公差}} があります。厳密なSTEPの項目は、丸い面を真の曲面で書き出します。ファセットの項目は、それらを平らなファセットとして書き出します。

## 履歴（左）

左のパネルは部品の特徴履歴で、PartCraftが上から下へ再構築する一覧です。

- 見出しは部品の名前です（名前を変更するまでは「Part1」）。
- **正面平面**、**上面平面**、**右面平面** が最初に並びます。クリックすると選択され、ビューで強調表示されます。
- その下に、作成された順に特徴が並びます。特徴が使うスケッチは、その特徴の下にインデントされて表示されます。
- 行の右端のフラグは、その状態を示します。

| フラグ | 意味 |
|---|---|
| （なし） | 構築済みで、スケッチは完全に定義されています |
| − | スケッチの定義が不完全です（まだ動かせます） |
| + | スケッチが過剰に定義されています |
| ⚠ | 構築済みですが警告があります（ポインターを合わせると内容が表示されます） |
| ⚠ エラー | 特徴が失敗しました。ポインターを合わせる、またはクリックすると理由が表示されます |
| ⚠ 未構築 | 特徴には、失敗したか無効になっている別の特徴が必要です |
| オフ | 抑制されています |

- 各特徴は、名前の後に主要な数値を表示します（押し出しなら「25 mm」、穴なら「Ø6.6 thru」など）。その数値をダブルクリックするか、行で {{key:F2}} を押すと、その場で変更できます。[寸法の変更](topic:change-sizes)を参照してください。
- 特徴をクリックすると、右側で編集できます。スケッチをダブルクリックすると開きます。
- ロールバックすると、一覧に **ロールバックバー · ロールフォワード** の行が表示されます。その下にある特徴はグレーアウトされ、構築されません。
- 行にフォーカスがあるとき、{{key:Up}} と {{key:Down}} で行を移動し、履歴が許す場合は {{key:Alt+Up}} / {{key:Alt+Down}} で特徴そのものを移動します。

アセンブリでは、同じパネルに代わりに **部品**（最初の部品には「固定」と表示されます）と **ジョイント** が一覧表示されます。

### 部品情報

履歴の下にある **部品** ボックスには、ソリッドの **体積**、**表面積**、**サイズ（X × Y × Z）**、**貫通穴**、**本体数**、**三角形**、**特徴**の数、**失敗中**の数が一覧表示されます。体積と面積は、メッシュカーネルが構築したファセット化されたソリッドの値で、丸い形状では真の値よりやや小さくなります（[特徴とそのオプション](topic:features#curves-resolution)を参照）。

アセンブリでは、ボックスの見出しは **アセンブリ** になり、部品、インスタンス、ジョイント、未接合、干渉が表示されます。

## 3Dビュー（中央）

ビューには、ソリッド、基準平面、そして特徴にまだ使われていないスケッチが表示されます。

部品が空のとき、基準平面は全体が描かれます。ソリッドができると、基準平面は薄く描かれて奥に下がり、部品を隠さないようにします。クリックは基準平面を通り抜けて部品に届きます。何も選択せずに{{ui:スケッチ}}を実行している間や、履歴で基準平面を選んだときは、再び全体が表示されます。{{ui:表示}} › {{ui:基準平面}} で基準平面を完全に非表示にできます。ただし、スケッチする場所を選んでいる間は表示されます。PartCraftはその選択を記憶します。

- 部品を回すにはドラッグ、パンは右ドラッグまたは中ドラッグ、ポインター位置へのズームはホイールです。詳細は [キーとマウス](topic:keyboard)を参照してください。
- 面、エッジ、平面にポインターを合わせると、それが光ります。クリックして選択します。面は全体が強調され、エッジは全体が描画されて、全体が選択されます。{{key:Shift}}+クリックで複数のエッジまたは面を集められます。選択された項目は印が付いたままになります。
- 右上のビューキューブは部品に合わせて回転します。面、エッジ、頂点をクリックするとその方向から見られ、ドラッグで回転し、ホームボタンで初期の表示に戻ります。[ビューキューブ](topic:view-cube)を参照してください。
- 選択中の押し出しは、端面にオレンジの矢印を表示します。回転は、回転の終わりに曲線の矢印を表示します。矢印をドラッグして深さまたは角度を変えるか、横の入力欄に値を入力します。[寸法の変更](topic:change-sizes#drag-it-in-the-view)を参照してください。
- 部品が空のとき、**部品を開始** と表示されたボックスに、最初の手順が一覧表示されます。
- `.partcraft.json` または `.partcraft-asm.json` ファイルをビューのどこにでもドロップすると開きます。`.step`、`.stp`、`.stl`、`.obj`、`.3mf`、`.3dm` ファイルをドロップすると、ソリッド本体として開きます。

### エッジや面を選択中

{{ui:フィレット}}、{{ui:面取り}}、{{ui:シェル}}を、何も選ばずに実行した後（または、そのような特徴の{{ui:エッジを選択}}）、部品はその特徴の前の状態で表示されます。エッジや面をクリックして追加または除外します。マークは、どれが含まれるかを示します。{{ui:完了}}または{{key:Esc}}で終了します。[丸め、面取り、中空化](topic:fillet-chamfer-shell)を参照してください。

### 図面シート上

{{ui:図面}}を選ぶと、3Dビューの代わりにA3の図面シートが表示されます。ホイールでズーム、右または中ドラッグでパン、{{key:F}} で全体表示します。[図面を作成する](topic:drawing-pdf)を参照してください。

### スケッチが開いているとき

ビューは、スケッチ平面を正面から見る向きに回転し、ビューの上に2Dスケッチのレイヤーが表示されます。部品には、このスケッチより前に作成された特徴だけが表示されます。左上の帯には、スケッチの状態表示（「完全に定義済み」「定義が不完全 · 自由度3」など）と、「Extrude1の面上のSketch2」のような名前が表示されます。

## プロパティパネル（右）

右のパネルには、選択されているものが表示され、その見出しが名前を示します。

- **部品**（何も選択していない場合）: 部品の **名前** と **曲線** の設定。
- 平面: {{ui:この上にスケッチ}}ボタン。
- **面**: 種類（平らな面、半径と軸を持つ円柱、円錐、球、トーラス）、面積、どの特徴が作ったか、そして平らな面の場合は {{ui:この面にスケッチ}}、{{ui:法線方向から表示}}、{{ui:面をDXFで書き出す}}、{{ui:この面から押し出し}}、{{ui:この面に切り込み}}、{{ui:ここに穴}}（[面全体を引き出す、押し込む](topic:extrude-and-cut#pull-or-push-a-whole-face)を参照）。
- **エッジ**: 種類（直線、中心と半径を持つ円、または曲線）、長さ、その両側の2つの面（「Extrude1の端面とExtrude1の側面」のように）。{{ui:フィレット}}と{{ui:面取り}}ボタンがあります。
- {{key:Shift}} で複数のエッジまたは面を選んだ場合: 数、エッジ用の {{ui:フィレット}} と {{ui:面取り}}、そして {{ui:クリア}}。
- **特徴**: その数値とオプション、スケッチの寸法、そして {{ui:抑制}}、{{ui:ここまでロールバック}}、{{ui:上に移動}}、{{ui:下に移動}}、{{ui:削除}}、その **名前**。
- 開いているスケッチ: 状態、選択に追加できる拘束、拘束と寸法の一覧、**座標で追加**、そして {{ui:スケッチを終了}}、{{ui:全体表示}}、{{ui:DXFとして書き出す}}。
- 図面シート: 断面と詳細の設定、または選択された GD&T 記号。
- アセンブリ: アセンブリ、選択された部品、または選択されたジョイント。

数値の入力欄は、{{key:Enter}} または {{key:Tab}} を押すか、欄の外をクリックすると反映されます。部品は直ちに再構築されます。OKボタンはありません。元に戻すには {{key:Mod+Z}} を使います。

## ステータスバー（下部）

- 左側は、スケッチ内のポインターの座標です（スケッチが開いている間のみ）。
- 中央はメッセージです。次に何をすべきか、拒否された理由が表示されます。何も起きていないように見えるときは、これを読んでください。
- 右寄りには、カーネルの表示があります。このバージョンでは常に「メッシュカーネル」です。ポインターを合わせると意味が表示されます。[メッシュカーネル](topic:solid-kernels)を参照してください。
- 右端のチップは、「再構築中…」（再構築中）、問題がなければ「○ msで再構築しました」、または「1件の特徴が失敗しています」と表示します。アセンブリでは「○ msで配置しました」、またはジョイントの問題数を示します。

関連項目: [Illustrateでマニュアルを作成する](topic:illustrate)。アセンブリのマニュアルを、部品とアセンブリから作成するワークスペースです。

## 狭い画面

幅760ピクセル以下（スマートフォンなど）では、ビューは画面に合わせます。ツールバーは1行で、横にスクロールします。パネルは、下部のバーからシートとして開きます。{{ui:ツール}} でツールバーを隠し、{{ui:移動}} でツールバーを下部に配置します。[トラックパッド、タッチ、小さな画面](topic:trackpad-and-touch)を参照してください。
