加工では、工具を角度を付けて保持できるほか、切削中に回転軸を動かすこともできます。方法は3つあり、単純なものから順に説明します。

**ここに記載の内容は、どれも機械で実行したことはありません。** 経路はテストによって形状と照合され、Gコードは読み戻して確認されていますが、内蔵のポストは、制御装置の公開されたコードに従うものであり、手元の機械に合わせたものではありません。切削の前に、お使いの制御装置自身のシミュレーターで検証し、まず素材の上の空中で実行してください。

## 機械の回転軸

**セットアップ**タブの{{ui:回転軸}}で、機械が持つ軸を指定します:

| 選択肢 | 機械 |
|---|---|
| なし（3軸） | 通常のフライス盤。工具の傾きが必要な工程は警告を表示し、ポストはそれを書き出しません。 |
| A（X 軸まわりに回転） | X に沿った回転軸が1つ: 第4軸テーブルまたは割り出し装置。工具は Y–Z 平面内でのみ傾けられます。 |
| B（Y 軸まわりに回転） | Y に沿った回転軸が1つ。工具は X–Z 平面内でのみ傾けられます。 |
| A と C | X 軸まわりの傾斜軸が、Z 軸まわりの回転を担うか、担われる: トラニオンテーブルまたはヘッド。 |
| B と C | 傾斜が Y 軸まわりである点を除き、同じ。 |

その他:

- **担う側**: {{ui:テーブル (部品が回転)}}または{{ui:ヘッド (工具が回転)}}。テーブルは、同じ面を工具の下に持ってくるため、逆方向に回転します。そのため、すべての角度の符号は、この設定から決まります。
- **制御装置が工具先端を経路上に保つ（TCP）**: オンの場合、プログラムの X Y Z は、パーツ自身の座標での工具先端となり、残りは制御装置が行います（内蔵の Fanuc 風および LinuxCNC のポストは、工具長に `G43.4` を書き出します）。オフの場合、テーブル式の機械では、PartCraft は、入力された**回転中心**（ワーク座標で指定。ワーク原点が中心にある場合は 0, 0, 0）のまわりで、回転するテーブルがパーツを運ぶ分の X Y Z を書き出します。ヘッド式の機械では TCP をオンにする必要があります。オフにすると、プログラムに機械のピボット長が必要になりますが、PartCraft はそれを把握していません。
- **傾斜の制限**: 傾斜軸がどこまで動くか。

機械によって、どちらの向きを正とするかは異なります。お使いの機械で軸が逆向きに回る場合は、ポストのコピーで符号を変更してください（[編集できるポストプロセッサー](topic:post-processors)）。

## 通常の工程での傾いた工具

すべてのフライス工程（面削り、ポケット、アダプティブ、輪郭、穴あけ、面取り、平行、スカラップ、3D荒取り、残り加工）には、**工具の傾き**と**傾ける方向**があります。これは、その工程だけの工具の向きで、セットアップの工具軸から測ります。これは 3+2 加工です。回転軸は位置に移動してそこにとどまり、3軸で切削します。

- 2つの角度を入力するか、{{ui:面に対して工具を垂直にする}}を押して平らな面をクリックします。工具はその面に対して真っすぐ向きます。
- 通常どおり工程の面とエッジを選択します。床または穴と見なされるかどうかは、傾いた工具の方向で判断されます。
- その方向の素材は、回転した素材を収める箱です。そのため、高さと逃げは、その側から見て安全です。

Gコードでは、工程の前に工具が上がり、回転軸が回転し、工具が最初の点の上まで下がります。TCP のないテーブル式の機械では、円弧は円弧のまま、固定サイクルの穴あけは固定サイクルのままです（書き出される座標系は Z 軸まわりにのみ回転します）。傾いた平面で TCP を使う場合、円弧は短い直線になり、サイクルはそれを表す移動になります。

素材のシミュレーションは、傾いた方向を**単独で**実行します。その工程が、その側から見た素材全体からどこを切削するかを表示し、そこで食い込みを検出します。ただし、ほかの方向からの切削は引き継がれません。

## 5軸仕上げ

加工ツールバーの{{ui:その他}}には、この工程と次の工程が、**工程**タブの上部に一覧表示されます。

{{ui:5軸}}は、[平行の仕上げパス](topic:finish-3d)を、**進むにつれて傾くボールエンドミル**で行う工程です。ボールは球で切削します。工具がその中心のまわりでどちらに傾いても、球は同じです。そのため、ボールは3軸のパスと正確に同じ経路をたどり、変わるのは工具の向きだけです:

- **面への向き**: 1 = 面に対して垂直、0 = 直立、その間の任意の値。
- **前傾**: 切削方向への角度。ボールの速度がゼロの中心ではなく、ボールの周囲が切削するようにします。
- **最大傾斜**: 工具は、セットアップの軸からこれより大きく傾くことはありません。

シャンクがモデルに接触する箇所では、傾きは接触がなくなるまで戻され、工程は何か所で戻したかを表示します。各パスは、直線の持ち上げで進入と退出を行います。

## 回転仕上げ（第4軸）

{{ui:回転}}は、回転軸上で**ワーク X** に沿って保持されたパーツ用です。パーツが回転し、常に軸を向いたボールエンドミルが、その曲面に沿って動きます:

- **パス**: {{ui:軸方向に}}（X に沿った線、回転方向にステップオーバー1つ分の間隔）または{{ui:部品の周囲に}}（リング、X 方向にステップオーバー1つ分の間隔）。
- **軸の位置 Y / Z**: 軸がある位置。空欄の場合は素材の中央です。TCP のないテーブル式の機械では、これはセットアップの回転中心と一致している必要があります。一致していない場合は、工程が警告します。
- **X の開始 / 終了** と **角度の開始 / 終了**: 切削する長さと回転の範囲。

各点でのボールの軸からの高さは、その側から見たパーツのメッシュ上の球の正確な降下量です。

## 制限事項

- 5軸と回転仕上げは、**ボールエンドミル**のみを使用します。スワーフ加工（直線の壁で工具の側面を使う切削）、曲面自身の方向に沿ったフローライン、マルチ軸の荒取り、衝突を避けるための傾きの自動選択はありません。
- 5軸と回転のパスは、**素材のシミュレーションを通過しません**。素材のシミュレーションは高さマップであり、傾いた切削を表現できないためです。
- 5軸仕上げでは、シャンクは上から見たモデルに対してチェックされます。ホルダー、主軸、機械自体は、どこでもチェックされません。
- 回転仕上げは、軸を見たときに工具から見える箇所だけを切削します。
- 5軸仕上げは、大きなパーツでは計算に1分以上かかります。シャンクは、すべてのパスのすべての点でチェックされるためです。
- 回転軸が直線軸と同時に動き、TCP がオフの場合、内蔵のポストは送りを逆時間（`G93`）で書き出し、その後 `G94` に戻します。
- 傾いたワーク平面のコード（`G68.2` など）は書き出されず、機械固有の制限、巻き戻し、衝突ゾーンは把握していません。
