Το CraftScript είναι γλώσσα πινάκων γραμμένη ώστε να διαβάζεται σαν MATLAB, οπότε οι περισσότεροι κλασικοί αριθμητικοί κώδικες (ο κώδικας βελτιστοποίησης τοπολογίας των 88 γραμμών, για παράδειγμα) τρέχουν με μικρές μόνο αλλαγές. Τρέχει στον [χώρο εργασίας «Σενάριο»](topic:craftscript) και από τη γραμμή εντολών.

## Τιμές

| Τύπος | Παράδειγμα | Σημειώσεις |
|---|---|---|
| Αριθμός, πίνακας | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Κάθε αριθμός είναι πίνακας (ένας 1×1). Οι πίνακες αποθηκεύονται κατά στήλες, έως 8 διαστάσεις |
| Λογική τιμή | `A > 2`, `true` | Πίνακες αληθών και ψευδών· χρησιμοποιούνται ως δείκτες |
| Κείμενο | `'beam'`, `"beam"` | |
| Αραιός πίνακας | `sparse(i, j, v, n, n)` | Για πίνακες δυσκαμψίας |
| Πλέγμα, πεδίο, μοντέλο | `hexGrid(…)`, `part()`, `load('part.stl')` | Αυτό που σχεδιάζει το `show` |
| Δομή | `s.E = 210e3` | Ονομασμένα πεδία |
| Κελί | `c = {1, 'two', [3 4]}` | Λίστα από οποιεσδήποτε τιμές |
| Χειριστής συνάρτησης | `f = @(x) x.^2` | |

## Πίνακες και δείκτες

- Περιοχές: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Η αρίθμηση ξεκινά από το 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (μια ολόκληρη στήλη), `A(:)` (όλα ως μία στήλη), `v(v > 0)` (λογική ευρετηρίαση).
- Η ανάθεση πέρα από το τέλος μεγαλώνει τον πίνακα, όπως στο MATLAB: `v(10) = 1`.

## Τελεστές

- Τα `+ - * / \ ^` είναι πράξεις πινάκων (`A \ b` λύνει)· τα `.* ./ .^` δουλεύουν στοιχείο προς στοιχείο. Το `'` κάνει ανάστροφο.
- Συγκρίσεις `== ~= < <= > >=`· λογικοί `& | ~` (στοιχείο προς στοιχείο) και `&& ||` (με βραχυκύκλωση).

## Ροή ελέγχου και συναρτήσεις

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Οι συναρτήσεις γράφονται σε ένα σενάριο μετά από τις εντολές του, ή στη δική τους καρτέλα σεναρίου με το όνομα της συνάρτησης:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Ένα όνομα αναζητείται με αυτή τη σειρά: μια μεταβλητή, ένα σενάριο σε αυτό το εξάρτημα με αυτό το όνομα, μια συνάρτηση της βιβλιοθήκης, μια ενσωματωμένη συνάρτηση.

## Echo, σχόλια, έξοδος

- Μια εντολή χωρίς `;` εμφανίζει την τιμή της· το `;` την κρατά σιωπηλή.
- Το `%` ξεκινά σχόλιο· τα `%{` και `%}` σε δικές τους γραμμές σχολιάζουν τις γραμμές ανάμεσά τους.
- Τα `disp(x)`, `fprintf('%g\n', x)` και `display(x)` γράφουν στην κονσόλα.

## Σφάλματα και όρια

- Τα σφάλματα λένε με απλά λόγια τι πήγε στραβά και δίνουν τη γραμμή (και την αλυσίδα των κλήσεων συναρτήσεων).
- Κάθε εκτέλεση έχει προϋπολογισμό βημάτων (Επιλογές εκτέλεσης στο πλαίσιο)· ένας ατέρμων βρόχος σταματά με μήνυμα, ή πατήστε {{ui:Διακοπή}}.
- Οι πίνακες κρατούν έως 134 εκατομμύρια τιμές ο καθένας.

## Όχι όπως στο MATLAB

- Οι εντολές σχεδίασης βάζουν τις επιλογές τους μέσα στην κλήση: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. Τα `figure`, `hold`, `axis`, `title(…)` και παρόμοια γίνονται δεκτά και δεν κάνουν τίποτα.
- Τα `input` και `keyboard` δεν υποστηρίζονται: ένα σενάριο δεν μπορεί να σταματήσει για να κάνει ερώτηση.
- Δεν υπάρχουν εργαλειοθήκες· υπάρχουν η [βιβλιοθήκη ανάλυσης](topic:craftscript-library) και οι ενσωματωμένες συναρτήσεις.
