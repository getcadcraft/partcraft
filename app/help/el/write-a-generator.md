Μια γεννήτρια είναι ένα συνηθισμένο σενάριο ([CraftScript](topic:craftscript), Lua ή Python) με λίγες γραμμές σχολίων στην αρχή. Το PartCraft διαβάζει τα σχόλια και δημιουργεί τη φόρμα· το σενάριό σας διαβάζει τις εισόδους ως μεταβλητές που έχουν ήδη οριστεί.

## Η κεφαλίδα

Γράψτε αυτές τις γραμμές ως γραμμές σχολίων (`%` στο CraftScript, `--` στη Lua, `#` στην Python):

```
% @generator Εναλλάκτης θερμότητας
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Μαζική ροή"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Επιφάνεια"
% @input solid: = true
% @input note: = "text"
```

Μια είσοδος έχει τη μορφή `name: unit = default` και, προαιρετικά, ένα εύρος `[min .. max]` (οι αριθμοί μένουν μέσα σε αυτό), μια λίστα επιλογών `{a, b, c}` και μια ετικέτα σε εισαγωγικά. Η μονάδα είναι μόνο ετικέτα για τη φόρμα: **η τιμή φτάνει σε αυτή τη μονάδα**, οπότε ένα σενάριο που θέλει SI τη μετατρέπει, και η `to_si(value, 'kg/s', 'kg/s')` ελέγχει επίσης ότι η μονάδα σημαίνει αυτό που νομίζετε. Ένα όνομα αποτελείται από γράμματα, ψηφία και κάτω παύλα· τα `body`, `sheet` και `problems` είναι δεσμευμένα.

## Τι αφήνει πίσω του το σενάριο

| Μεταβλητή | Τι είναι |
|---|---|
| `body` | **Υποχρεωτική.** Ένα πλέγμα επιφάνειας, συνήθως από το `[body, info] = to_body(field, h)`. Επιδιορθώνεται και ελέγχεται όταν τελειώσει η εκτέλεση. |
| `sheet` | Προαιρετική. Μια δομή (struct): κάθε πεδίο είναι αριθμός ή κείμενο, ή δομή με `value`, `unit`, `ref` και `note`. Γίνεται το φύλλο δεδομένων. |
| `problems` | Προαιρετική. Το κελί `problems` από το `mfg_check(field, 'sls', struct(), h)`, ή δικές σας εγγραφές. Πηγαίνουν στους ελέγχους και στη λίστα Προβλημάτων. |

## Ένα πλήρες μικρό παράδειγμα

```
% Ένας κοίλος κύβος με τοίχωμα.
% @generator Κοίλος κύβος
% @input side: mm = 12 [4 .. 40] "Πλευρά"
% @input wall: mm = 1.5 [0.5 .. 5] "Τοίχωμα"
% @input h: mm = 0.5 [0.25 .. 2] "Μέγεθος voxel"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'of the mesh');
```

Δημιουργεί ένα κλειστό κουτί, και ο έλεγχος αναφέρει το κλειστό εσωτερικό του ως σφάλμα για διαδικασία σε σκόνη. Ορίστε το μέγεθος voxel `h` το πολύ στο ένα τρίτο του λεπτότερου τοιχώματος που θέλετε: κάτω από περίπου τρία voxel ένα τοίχωμα δεν είναι αξιόπιστο.

## Πεδία

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ένα στερεό εκ περιστροφής από ένα προφίλ), `tpms` (επιφάνειες gyroid, Schwarz P και diamond, με μέγεθος κελιού και τοίχωμα που μπορούν να αλλάζουν σε όλο το εξάρτημα), `lattice` και `lattice_beams`, `along` (ένας στρογγυλός αγωγός κατά μήκος μιας διαδρομής), οι πράξεις boolean `field_union`, `field_intersect`, `field_subtract`, η ομαλή `field_blend`, και τα `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. Το `sample(f, points)` δίνει την προσημασμένη απόσταση στα σημεία (αρνητική στο εσωτερικό), και το `field_voxel` δίνει voxel για τους επιλυτές. Το [Πεδία](topic:fields) εξηγεί τι είναι.

Όρια που αξίζει να γνωρίζετε: ένα τοίχωμα επιφάνειας πιο παχύ από περίπου το ένα τέταρτο του κελιού κλείνει τους αγωγούς· ένα χαρακτηριστικό λεπτότερο από περίπου τρία voxel μπορεί να στραγγαλιστεί· το `along` ενώνει στρογγυλούς κώνους, οπότε μια ακτίνα που αλλάζει γρήγορα αφήνει μια εξόγκωση (χρησιμοποιήστε το `field_revolve` για ένα προφίλ).

## Ανοίξτε το σενάριό σας ως γεννήτρια

Στον χώρο εργασίας {{ui:Engineer}} επιλέξτε {{ui:Open}} και διαλέξτε το αρχείο. Ένα σενάριο χωρίς γραμμή `@generator` ή `@input` απορρίπτεται: δεν θα υπήρχε τι να οριστεί. Η γεννήτρια διατηρείται σε αυτό το πρόγραμμα περιήγησης (έως 20) και το {{ui:Remove}} τη διαγράφει. Ένα στερεό που ξεκινά από αυτήν φέρει ένα αντίγραφο του σεναρίου, ώστε το εξάρτημα να μην εξαρτάται από αυτό.

Ένα αρχείο μπορεί επίσης να περιέχει πολλές γεννήτριες: ένα πακέτο JSON `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
