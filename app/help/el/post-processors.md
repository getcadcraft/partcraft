Η ίδια διαδρομή εργαλείου πρέπει να γράφεται διαφορετικά για διαφορετικούς ελέγχους: αριθμούς γραμμών ή καθόλου, `M6` ή παύση, `G28` ή `G53`, `M30` ή `M2`. Ένα **post** είναι το σύντομο κείμενο που ορίζει πώς. Τα τρία ενσωματωμένα post του PartCraft (τύπου Fanuc, GRBL και LinuxCNC) είναι γραμμένα σε αυτή τη μορφή, οπότε ένα δικό σας post μπορεί να ξεκινήσει ως αντίγραφο ενός από αυτά.

Ελέγξτε την έξοδο στον προσομοιωτή του δικού σας μηχανήματος πριν από την κοπή, και δοκιμάστε την πρώτα στον αέρα πάνω από το υλικό. Τα ενσωματωμένα post γράφουν ακριβώς ό,τι έγραφαν πριν υπάρξει αυτή η μορφή (οι δοκιμές συγκρίνουν την έξοδό τους byte προς byte σε εκατοντάδες προγράμματα), αλλά τίποτα εδώ δεν έχει αποδειχθεί στο δικό σας μηχάνημα, και ένα post που αλλάζετε είναι δική σας ευθύνη να το αποδείξετε.

## Δημιουργία ενός post

Στην Κατασκευή, κάτω από **Post**:

- {{ui:Επεξεργασία post…}} σε ένα ενσωματωμένο έλεγχο ανοίγει **το δικό σας αντίγραφό** του. Σε ένα δικό σας post, ανοίγει αυτό το post.
- {{ui:Νέο post…}} ξεκινά από ένα μικρό κενό post με όλα τα γεγονότα.
- {{ui:Εισαγωγή αρχείου post…}} διαβάζει ένα αρχείο κειμένου `.cpost` (το αρχείο που παίρνετε από το **Αποθήκευση ως αρχείο…** στον επεξεργαστή).

Ο επεξεργαστής εμφανίζει το κείμενο, μια γραμμή που λέει αν διαβάζεται (και ποια γραμμή είναι λάθος), και το G-code που γράφει το post καθώς πληκτρολογείτε. Η **Προεπισκόπηση με** επιλέγει ένα μικρό δείγμα προγράμματος που εκτελεί κάθε γεγονός, ή το δικό πρόγραμμα αυτού του εξαρτήματος. Το {{ui:Αποθήκευση}} κρατά το post στο αρχείο του εξαρτήματος (έως 20 post) και το επιλέγει ως έλεγχο. Τα post ταξιδεύουν μαζί με το εξάρτημα· για να χρησιμοποιήσετε ένα σε άλλο εξάρτημα, αποθηκεύστε το ως αρχείο και εισαγάγετέ το εκεί.

## Τι μοιάζει ένα post

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

Οι γραμμές που αρχίζουν με `//` και οι κενές γραμμές αγνοούνται. Στην αρχή έρχονται οι ρυθμίσεις· μετά ένα μπλοκ `on <event>` για κάθε γεγονός, κλεισμένο με `end`. Ένα γεγονός που παραλείπετε δεν γράφει τίποτα.

| Ρύθμιση | Σημασία |
|---|---|
| `post <id>` | Το αναγνωριστικό του post: γράμματα, ψηφία, `-` και `_` |
| `name <text>` | Τι εμφανίζει η λίστα ελέγχων |
| `extension <ext>` | Η κατάληξη του αρχείου: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … σε κάθε γραμμή `emit`, ή καμία |
| `decimal-point yes` / `no` | `10.` αντί για `10` (τα σχόλια δεν έχουν ποτέ τελεία) |
| `canned-cycles yes` / `no` | `no`: οι οπές γράφονται ως κινήσεις G0/G1 που αντιπροσωπεύουν |
| `modal <group> <words>` | Λέξεις μιας ομάδας (`modal motion G0 G1 G2 G3`) που γράφονται μόνο όταν αλλάζουν |

## Γεγονότα

Εκτελούνται με αυτή τη σειρά για ένα πρόγραμμα: `start`· μετά, για κάθε λειτουργία, `operation`, `tool-change` (όταν αλλάζει το εργαλείο), `spindle` (όταν αλλάζει η ταχύτητα), `approach` (η κίνηση προς το πρώτο σημείο, πριν την πρώτη ταχεία κίνηση), `coolant-on`, και μετά οι κινήσεις της ως `rapid`, `feed` και `arc`, και κάθε σταθερός κύκλος ως `cycle-start`, ένα `cycle-hole` για κάθε οπή και `cycle-end`· τέλος `end`.

Κάθε γεγονός μπορεί να χρησιμοποιεί τις μεταβλητές του δικού του είδους κίνησης, γραμμένες `{name}`: το πρόγραμμα (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), το υλικό (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), το εργαλείο (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), τη λειτουργία (`op.name`, `op.type`), το `rpm`, το σημείο μιας κίνησης (`x`, `y`, `z`, `f`, και `moved`: αληθές όταν άλλαξε ένας άξονας), τόξα (`arc.g` 2 ή 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) και οπές (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Η λίστα **Γεγονότα και μεταβλητές** του επεξεργαστή δείχνει ποιο γεγονός βλέπει ποια. Κατάσταση που μπορείτε να διαβάσετε και να ορίσετε: `cool`, `offset`, και `at.x`, `at.y`, `at.z`, `at.f` (οι τελευταίες γραμμένες τιμές).

## Εντολές

| Εντολή | Τι κάνει |
|---|---|
| `raw TEXT` | Μια γραμμή ακριβώς όπως πληκτρολογείται (χωρίς αριθμό γραμμής) |
| `comment TEXT` | `(TEXT)` με τους μη-ASCII χαρακτήρες και τις αγκύλες αφαιρεμένα |
| `emit WORD WORD …` | Μια γραμμή λέξεων· οι λέξεις που βγαίνουν κενές παραλείπονται· χωρίς λέξεις, καμία γραμμή |
| `word WORD …` | Προσθέτει λέξεις στη γραμμή που χτίζεται· ένα απλό `emit` την κλείνει |
| `if EXPR` … `else` … `end` | Συνθήκες: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, αλλιώς b) |
| `for tool in tools` … `end` | Μία φορά για κάθε εργαλείο που χρησιμοποιεί το πρόγραμμα |
| `set NAME EXPR` | Θυμάται μια τιμή (`set offset tool.number`) |
| `reset NAME …` | Ξεχνά τις modal λέξεις (μια ομάδα, ένα γράμμα διεύθυνσης όπως `Z`, ή το `at.z`) |
| `do rapid X Y Z` | Εκτελεί το γεγονός `rapid` για ένα σημείο |

Μια λέξη είναι κείμενο με οπές `{variable|filter}`. Τα φίλτρα είναι `upper`, `lower`, `pad:N` (συμπλήρωση με μηδενικά), `cut:N` (πρώτοι N χαρακτήρες), `safe` (ASCII ασφαλές για σχόλια) και `int`. Μια λέξη που τελειώνει σε `~` είναι **modal**: γράφεται μόνο όταν διαφέρει από αυτό που γράφτηκε τελευταία (`G1~`, `X{x}~`). Μια λέξη που τελειώνει σε `~!` γράφεται κάθε φορά και θυμάται. Ένα όνομα που δεν είναι μεταβλητή είναι απλό κείμενο (`G81`, `mist`). Οι αριθμοί στρογγυλοποιούνται στα 0.001 mm και γράφονται χωρίς τελικά μηδενικά.

## Τι δεν μπορεί να κάνει ένα post

Το post αποφασίζει μόνο πώς γράφονται οι κινήσεις, τίποτα περισσότερο. Δεν μπορεί να αλλάξει τη διαδρομή εργαλείου, να αλλάξει τη σειρά των λειτουργιών, να χωρίσει ένα τόξο, να προσθέσει άξονα, να γνωρίζει τη διαδρομή ή την κινηματική του μηχανήματός σας, ούτε να κάνει πράξεις σε συντεταγμένες (δεν υπάρχει `+`). Οι κύκλοι ψηλάφησης, οι κύκλοι διάρκειας εργαλείου και υπορουτινών, η έξοδος 4ου και 5ου άξονα και οι κώδικες τόρνου δεν έχουν υλοποιηθεί. Ένα αρχείο `.cps` από άλλο πρόγραμμα δεν μπορεί να φορτωθεί: αυτή είναι διαφορετική, απλούστερη μορφή.
