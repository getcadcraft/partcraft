Η προσεκτική μοντελοποίηση έχει περισσότερο να κάνει με πειθαρχία παρά με κουμπιά. Ένα εξάρτημα γραμμένο ως κείμενο μπορεί να διαβαστεί, να ελεγχθεί, να συγκριθεί γραμμή προς γραμμή και να ξαναχτιστεί από ένα σενάριο. Το PartCraft πηγαίνει και προς τις δύο κατευθύνσεις: κάθε εξάρτημα μπορεί να γραφτεί ως σενάριο, και ένα σενάριο χτίζει το εξάρτημα.

## Στην εφαρμογή

Στην καρτέλα {{ui:Parameters}}, κάτω από το **Σενάριο**:

- {{ui:Αποθήκευση ως σενάριο}} κατεβάζει το ανοιχτό εξάρτημα ως `<name>.pcscript`.
- {{ui:Άνοιγμα σεναρίου}} χτίζει ένα εξάρτημα από αρχείο `.pcscript`. Ένα σφάλμα αναφέρεται με τον αριθμό της γραμμής του, και δεν αντικαθίσταται τίποτα.

## Η μορφή σεναρίου

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

Οι κανόνες:

- Μια γραμμή στο αριστερό άκρο ξεκινά μια δήλωση: `pcscript`, `part`, `param`, ένας τύπος χαρακτηριστικού (`sketch`, `extrude`, `revolve`, `hole`, `lpattern`, `cpattern`, `mirror`, `fillet`, `chamfer`, `shell`, `import` και οι νεότεροι τύποι) ακολουθούμενος από το όνομά του, ή `rollback <feature>`.
- Οι εσοχές είναι οι ρυθμίσεις της δήλωσης από πάνω. Μια ρύθμιση που στέκεται μόνη της (`through`, `reverse`, `suppressed`) σημαίνει «ναι».
- Μια αριθμητική ρύθμιση είναι αριθμός, ή `=` και μια παράσταση, που γίνεται εξίσωση: `depth = thick`.
- Σε ένα σκαρίφημα: το `on` ονομάζει το επίπεδο (`front`, `top`, `right`, `face Base end`, `face Revolve1 side l3`)· η γεωμετρία είναι `point <name> x, y`, `line <name> <point> <point>`, `circle <name> <centre> <radius>`, `arc <name> <centre> <start> <end>` (αντίθετα από τους δείκτες του ρολογιού) ή `spline <name> fit|control <points>`· οι σχέσεις είναι ο τύπος τους και τα ονόματα που ενώνουν (`O` είναι η αρχή των αξόνων)· μια διάσταση τελειώνει με την τιμή της ή με `= παράσταση`.
- Προαιρετικές ρυθμίσεις μιας γραμμής γεωμετρίας ή σχέσης μπαίνουν σε τετράγωνες αγκύλες στο τέλος, χωρισμένες με `;`: `[construction]`, `[side -1; label 5, 3]`.
- Το `#` ξεκινά σχόλιο (στην αρχή μιας γραμμής ή μετά από κενό). Τα ονόματα με κενά μπαίνουν σε "διπλά εισαγωγικά".
- Τα αναγνωριστικά των χαρακτηριστικών μετρούν από το f1 με τη σειρά που γράφονται. Οι αναφορές ακμών και εδρών τα χρησιμοποιούν, για παράδειγμα `edge f2.side:l3 f2.end [at 50, 0, 10]`.
- Οι ρυθμίσεις που η μορφή δεν έχει λέξεις για αυτές γράφονται `json` και μια τιμή· διαβάζονται πίσω όπως είναι.

Όταν αποθηκεύεται από την εφαρμογή, το σενάριο περιλαμβάνει κάθε ρύθμιση, άρα ανοίγει ως το ίδιο εξάρτημα. Ένα εισηγμένο στερεό STEP γράφεται μέσα στο σενάριο από την εφαρμογή, και ως ξεχωριστό αρχείο `.step` με όνομα από το `step-file` στη γραμμή εντολών.

## Το εργαλείο γραμμής εντολών

Το εργαλείο τρέχει σε υπολογιστή με Node.js 24, από ένα αντίγραφο του πηγαίου κώδικα του CadCraft: `node tools/partcraft-cli/partcraft.mjs <command>`. Είναι εργαλείο για προγραμματιστές και χρησιμοποιεί τις ίδιες ενότητες (modules) με την εφαρμογή. Τα εξαρτήματα είναι αρχεία `.partcraft.json` ή σενάρια `.pcscript`.

| Εντολή | Τι κάνει |
|---|---|
| `info <part>` | Χαρακτηριστικά, παράμετροι, γραμμή rollback, ο όγκος και το μέγεθος του κατασκευασμένου στερεού |
| `params <part>` | Κάθε παράμετρος και εξίσωση με την τιμή της |
| `set <part> width=150 Base.depth==thick` | Κατά την ευθεία φορά: αλλάζει παραμέτρους, συνδέει αριθμούς (`==` ή μια παράσταση) και ορίζει απλούς αριθμούς |
| `drive <part> Base.depth=12` | Αντίστροφα: λύνει την παράμετρο πίσω από έναν οδηγούμενο αριθμό (`--prefer width` επιλέγει μία) |
| `build <part> --out x.step` | Γράφει `.step`, `.stl`, `.3mf`, `.json`, `.pcscript` ή μακροεντολή (`.swb`) |
| `build <part> --table sizes.csv --out-dir sizes` | Ένα αρχείο για κάθε γραμμή του πίνακα σχεδιασμού |
| `variants <part> --out-dir d` ή `--zip f.zip` | Κάθε διαμόρφωση ως STEP, IFC, DWG και προεπισκόπηση, έναν πίνακα παραλλαγών και ένα στοιχείο βιβλιοθήκης (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`)· βλ. [Δημιουργία πακέτου παραλλαγών](topic:variant-pack) |
| `script <in.pcscript> -o part.json` | Σενάριο σε εξάρτημα |
| `to-script <part> -o part.pcscript` | Εξάρτημα σε σενάριο |
| `rollback <part> [<feature>]`, `forward <part> [--end]` | Μετακινεί τη γραμμή rollback μέσα στο αρχείο |
| `check <part> [--strict]` | Ο έλεγχος πειθαρχίας (παρακάτω) |

Το `build` δέχεται επίσης `--set name=value` (μόνο για αυτή την κατασκευή) και `--upto <feature>`. Κάθε εντολή δέχεται `--json`. Κωδικοί εξόδου: 0 εντάξει, 1 βρέθηκε πρόβλημα, 2 η εντολή γράφτηκε λάθος. Ένα σενάριο δεν ξαναγράφεται ποτέ στη θέση του: δώστε `-o` για να αποθηκεύσετε ένα αλλαγμένο αντίγραφο.

## Ο έλεγχος

Το `check` αναφέρει ό,τι κάνει ένα εξάρτημα δύσκολο να αλλάξει αργότερα:

| Εύρημα | Μετράει ως |
|---|---|
| Σκαρίφημα που είναι υπερ-καθορισμένο (αντιφατικές ή επαναλαμβανόμενες σχέσεις) | σφάλμα |
| Χαρακτηριστικό που δεν κατασκευάζεται | σφάλμα |
| Παράμετρος ή εξίσωση με σφάλμα, ή παράμετροι που χρησιμοποιούν η μία την άλλη | σφάλμα |
| Σκαρίφημα που είναι υποκαθορισμένο, με τους βαθμούς ελευθερίας του | προειδοποίηση |
| Αριθμοί πληκτρολογημένοι απευθείας σε χαρακτηριστικά και διαστάσεις που καμία παράμετρος δεν οδηγεί | προειδοποίηση |
| Παράμετρος που δεν χρησιμοποιεί τίποτα | προειδοποίηση |
| Απενεργοποιημένο χαρακτηριστικό· η γραμμή rollback δεν βρίσκεται στο τέλος | προειδοποίηση |

Το `--strict` μετατρέπει κάθε προειδοποίηση σε σφάλμα, ώστε ένα σενάριο κατασκευής να μπορεί να αρνηθεί ένα εξάρτημα που δεν είναι πλήρως οδηγούμενο.

:::note
Η έξοδος μακροεντολής `.swb` προορίζεται για το πρόγραμμα μοντελοποίησης εξαρτημάτων που χρησιμοποιούν τα περισσότερα εργαστήρια: όταν εκτελεστεί μέσα σε εκείνο το πρόγραμμα, κατασκευάζει εκεί το εξάρτημα. Δεν έχει εκτελεστεί εκεί από εμάς (δεν είναι διαθέσιμο στους διακομιστές μας)· θεωρήστε την μη δοκιμασμένη.
:::
