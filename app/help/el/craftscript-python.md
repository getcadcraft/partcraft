Η Python είναι η τρίτη γλώσσα του [χώρου εργασίας «Σενάριο»](topic:craftscript). Επιλέξτε **Python** στο πλαίσιο γλώσσας πάνω από τον επεξεργαστή (ένα αρχείο `.py` ανοίγει σε Python αυτόματα). Η Python, η Lua και το CraftScript μοιράζονται τις ίδιες μεταβλητές και τις ίδιες ενσωματωμένες συναρτήσεις, άρα ένα σενάριο Python μπορεί να χρησιμοποιήσει όσα έφτιαξε ένα σενάριο CraftScript, και το αντίστροφο.

Η πρώτη εκτέλεση Python σε μια επίσκεψη φορτώνει την ίδια την Python (CPython 3.14, περίπου 7 MB) από αυτόν τον ιστότοπο, κάτι που παίρνει μερικά δευτερόλεπτα. Η Python δεν είναι ακόμη μέρος του {{ui:Αποθήκευση για χρήση εκτός σύνδεσης}}· εκτελέστε πρώτα ένα σενάριο Python ενώ είστε συνδεδεμένοι.

## Η Python είναι απομονωμένη

Τα σενάρια Python είναι απομονωμένα όπως τα σενάρια CraftScript και Lua: φτάνουν στο εξάρτημα, στις μεταβλητές και στις ενσωματωμένες συναρτήσεις, και τίποτα άλλο. Κάθε εκτέλεση είναι μια νέα Python στο δικό της sandbox, με ένα μικρό δέντρο αρχείων στη μνήμη (η τυπική της βιβλιοθήκη και ένας φάκελος `/tmp` που εξαφανίζεται μετά την εκτέλεση). Δεν μπορεί να φτάσει στο δίκτυο, στα αρχεία σας ή στο υπόλοιπο της σελίδας, τόσο στον περιηγητή όσο και στη γραμμή εντολών. Ένα σενάριο από άλλον μπορεί ακόμη να χρησιμοποιεί πολύ χρόνο ή μνήμη· το {{ui:Διακοπή}} το τερματίζει.

## Τα βασικά

```
A = cs.magic(3)              # κάθε ενσωματωμένη συνάρτηση είναι cs.<name>
B = A @ A.T                  # το @ είναι το γινόμενο πινάκων, το .T η ανάστροφος
C = A * 2 + 1                # τα + - * / ** είναι στοιχείο προς στοιχείο, όπως στο numpy
print(A[0, 1], A[-1, -1])    # από το 0· οι αρνητικοί μετρούν από το τέλος
row = A[1]                   # ένας δείκτης σε πίνακα: μια γραμμή
big = A[A > 4]               # μια λογική μάσκα επιλέγει στοιχεία
A[0, 0] = -5                 # ανάθεση σε πίνακα
V, D = cs.call('eig', 2, A)  # πολλά αποτελέσματα: cs.call(όνομα, πόσα, …)
```

- Ένας πίνακας 1 × 1 φτάνει ως απλός αριθμός· οι άλλοι πίνακες, οι αραιοί πίνακες, τα πλέγματα, τα πεδία και τα μοντέλα είναι **Τιμές**.
- Μια Τιμή έχει `shape` (πλειάδα), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (τις γραμμές της), και `float()`, `int()` και `bool()` για ένα μόνο στοιχείο.
- Οι συγκρίσεις (`<`, `==`, …) είναι στοιχείο προς στοιχείο, όπως στο numpy: δίνουν μια λογική Τιμή.
- Λίστες αριθμών που περνούν σε ενσωματωμένη συνάρτηση γίνονται πίνακες: `cs.sum([1, 2, 3])`. Το `cs.tensor([[1, 2], [3, 4]])` φτιάχνει έναν πίνακα.
- Ένα dict γίνεται struct και μια λίστα με ανάμεικτα στοιχεία γίνεται κελί, και το ανάποδο.

Κάθε καθολική μεταβλητή που φτιάχνει το σενάριο (ένας αριθμός, μια Τιμή, ένα dict, μια λίστα…) μπαίνει στην καρτέλα **Μεταβλητές** όταν τελειώσει η εκτέλεση, ακόμη και μετά από σφάλμα. Τα ονόματα που αρχίζουν με `_`, οι συναρτήσεις, οι κλάσεις και τα modules μένουν στην Python. Το `ws.name` διαβάζει ή ορίζει μια μεταβλητή απευθείας, και το `ws_names()` τις απαριθμεί.

Το `print(…)` γράφει στην κονσόλα. Το `display(…)` (ή το `cs.display`) εμφανίζει ένα πλέγμα, ένα πεδίο ή ένα διάγραμμα, όπως στο CraftScript.

## Καλέστε τη βιβλιοθήκη ανάλυσης

Οι συναρτήσεις της βιβλιοθήκης καλούνται όπως οι ενσωματωμένες: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Γράψτε το όνομα στο σενάριο όπως είναι· το PartCraft βρίσκει τις συναρτήσεις της βιβλιοθήκης που χρησιμοποιεί ένα σενάριο πριν εκτελεστεί.

## Τι δεν υπάρχει ακόμη

- numpy, scipy και άλλα πακέτα: υπάρχει μόνο η τυπική βιβλιοθήκη της Python (`math`, `json`, `itertools`, `decimal`, `statistics`…), χωρίς τα μέρη για παράθυρα, τερματικό και βάσεις δεδομένων (`tkinter`, `curses`, `sqlite3`).
- Sockets και ό,τι άλλο θα έφτανε έξω: η Python δεν έχει εδώ δίκτυο.
- Το `time.sleep` επιστρέφει αμέσως.
- Η αναδίπλωση στον επεξεργαστή και η κλήση μιας συνάρτησης Python από σενάριο CraftScript.
- Μια εκτέλεση ελέγχει το όριο εντολών και το {{ui:Διακοπή}} κάθε 1000 γραμμές· ένας μεγάλος υπολογισμός μέσα σε μία ενσωματωμένη συνάρτηση ολοκληρώνεται πρώτος.
