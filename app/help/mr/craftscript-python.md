Python ही [स्क्रिप्ट वर्कस्पेस](topic:craftscript) ची तिसरी भाषा आहे. एडिटरच्या वरील भाषा बॉक्समध्ये **Python** निवडा (`.py` फाइल आपोआप Python मध्ये उघडते). Python, Lua आणि CraftScript एकच व्हेरिएबल्स आणि एकच अंगभूत फंक्शन्स वापरतात, त्यामुळे Python स्क्रिप्ट CraftScript स्क्रिप्टने बनवलेले वापरू शकते, आणि उलट.

भेटीत पहिला Python रन Python स्वतः (CPython 3.14, सुमारे 7 MB) या साइटवरून लोड करतो, ज्यास काही सेकंद लागतात. Python अजून {{ui:ऑफलाइनसाठी जतन करा}} चा भाग नाही: आधी ऑनलाइन असताना एक Python स्क्रिप्ट चालवा.

## Python वेगळे ठेवले आहे

Python स्क्रिप्ट्स CraftScript आणि Lua स्क्रिप्ट्सप्रमाणेच वेगळ्या ठेवल्या आहेत: त्या भाग, व्हेरिएबल्स आणि अंगभूत फंक्शन्स पोहोचवतात, आणि इतर काहीही नाही. प्रत्येक रन म्हणजे स्वतःच्या सँडबॉक्समधील नवीन Python, मेमरीत एका छोट्या फाइल ट्रीसह (त्याची standard library आणि रननंतर नाहीशा होणाऱ्या `/tmp` फोल्डरसह). ती नेटवर्क, तुमच्या फाइल्स किंवा पेजच्या उरलेल्या भागापर्यंत पोहोचू शकत नाही, ब्राउझरमध्ये आणि कमांड लाइनवर दोन्ही ठिकाणी. दुसऱ्याची स्क्रिप्ट तरीही खूप वेळ किंवा मेमरी वापरू शकते: {{ui:थांबवा}} ती संपवतो.

## मूलभूत गोष्टी

```
A = cs.magic(3)              # every built-in function is cs.<name>
B = A @ A.T                  # @ is the matrix product, .T the transpose
C = A * 2 + 1                # + - * / ** are elementwise, as in numpy
print(A[0, 1], A[-1, -1])    # 0-based; negative counts from the end
row = A[1]                   # one index on a matrix: a row
big = A[A > 4]               # a logical mask picks elements
A[0, 0] = -5                 # assigning into an array
V, D = cs.call('eig', 2, A)  # several results: cs.call(name, how many, …)
```

- 1 × 1 अॅरे साध्या संख्येच्या रूपात येतो; इतर अॅरे, स्पार्स मॅट्रिक्स, मेश, फील्ड आणि मॉडेल **मूल्ये** आहेत.
- मूल्याला `shape` (tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (त्याच्या रो), आणि एका एलिमेंटसाठी `float()`, `int()` आणि `bool()` असतात.
- तुलना (`<`, `==`, …) numpy प्रमाणे एलिमेंट-एलिमेंट असतात: ते लॉजिकल मूल्य देतात.
- अंगभूत फंक्शनला दिलेल्या संख्यांच्या याद्या अॅरे बनतात: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` एक मॅट्रिक्स बनवते.
- dict चा struct होतो आणि मिश्र गोष्टींची यादी cell होते, आणि परत उलट.

तुमची स्क्रिप्ट बनवलेला प्रत्येक ग्लोबल (संख्या, Value, dict, list…) रन संपल्यावर **व्हेरिएबल्स** टॅबमध्ये जातो, त्रुटी आल्यानंतरही. `_` ने सुरू होणारी नावे, फंक्शन्स, क्लासेस आणि मॉड्यूल्स Python मध्येच राहतात. `ws.name` थेट व्हेरिएबल वाचते किंवा सेट करते, आणि `ws_names()` ती यादी करते.

`print(…)` कन्सोलवर लिहिते. `display(…)` (किंवा `cs.display`) मेश, फील्ड किंवा प्लॉट दाखवते, CraftScript प्रमाणेच.

## विश्लेषण लायब्ररी कॉल करा

लायब्ररी फंक्शन्स अंगभूत फंक्शन्सप्रमाणेच कॉल केली जातात: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. नाव स्क्रिप्टमध्ये जसे आहे तसे लिहा: स्क्रिप्ट चालण्यापूर्वी PartCraft ती वापरत असलेली लायब्ररी फंक्शन्स शोधते.

## अजून नाही

- numpy, scipy आणि इतर पॅकेजेस: फक्त Python ची स्वतःची standard library (`math`, `json`, `itertools`, `decimal`, `statistics`…) येथे आहे, तिच्या विंडो, टर्मिनल आणि डेटाबेस भागांशिवाय (`tkinter`, `curses`, `sqlite3`).
- Sockets आणि बाहेर पोहोचणारे काहीही: येथे Python ला नेटवर्क नाही.
- `time.sleep` लगेच परत येते.
- एडिटरमधील फोल्डिंग, आणि CraftScript स्क्रिप्टमधून Python फंक्शन कॉल करणे.
- रन प्रत्येक 1000 ओळींनी सूचना बजेट आणि Stop तपासतो; एका अंगभूत फंक्शनच्या आत लांब गणना आधी पूर्ण होते.
