स्क्रिप्ट वर्कस्पेसमधील विश्लेषण म्हणजे काही छोट्या स्क्रिप्ट्स जे एकमेकांना व्हेरिएबल्स देतात. तुम्हाला हवे आहे त्याच्या जवळचे एक [लायब्ररी](topic:craftscript-library) फंक्शन घ्या, त्याची प्रत तयार करा आणि बदला; किंवा खाली दाखवल्याप्रमाणे एक एक करून बनवा.

## 1. एक मेश

```
model = part();                  % the part you are modelling, as a model
m = tetmesh(model, 4);           % tetrahedra about 4 mm across
show(m)
```

पुढे जाण्यापूर्वी व्ह्यूमध्ये मेश तपासा: {{key:F}} त्याला बसवते, आणि **दाखवलेले** मधील {{ui:eye}} भाग लपवते.

## 2. जुळवा आणि सोडवा

स्क्रिप्टमध्ये एलिमेंट लूप लिहा (तो पाठ्यपुस्तकासारखा वाचला जातो), आणि जड भाग अंगभूत फंक्शन्सवर सोडा: एलिमेंट मॅट्रिक्स, ट्रिपल्सवरून स्पार्स जुळवणी, आणि प्रीकंडिशनरसह कॉन्ज्युगेट ग्रेडियंट सॉल्व्हर. `static_tet` सारखे लायब्ररी फंक्शन (एकदा लायब्ररीत आल्यावर) कॉपी करण्यासाठी पूर्ण उदाहरण आहे.

## 3. निकाल दाखवा

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % one value per node
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- लीजेंडची रेंज टाइप करता येते किंवा {{ui:स्वयं}} वर परत सेट करता येते.
- एका नोडवरील मूल्ये वाचण्यासाठी मेशवर क्लिक करा.
- एकच `'id'` असलेला प्लॉट जागेवरच अपडेट होतो, म्हणून अभिसरण पाहण्यासाठी तुमच्या लूपमध्ये print आणि plot करा.

## 4. तपासा

तुम्हाला माहीत असलेल्या गोष्टीशी तुलना करा: कँटिलिव्हरचे टोक-विक्षेपण PL³/3EI शी, छिद्र असलेली प्लेट तिच्या ताण केंद्रीकरण घटकाशी, प्रतिक्रिया भारांशी. तपासणी स्वतंत्र स्क्रिप्ट म्हणून लिहा, म्हणजे प्रत्येक बदलानंतर ती पुन्हा चालेल:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. जतन करा

- प्रत्येक चरण स्वतःचा स्क्रिप्ट टॅब असू शकतो: ते व्हेरिएबल्स सामायिक करतात, म्हणून एकामागून एक चालवा.
- स्क्रिप्ट्स भागामध्ये जतन होतात. निकालही ठेवण्यासाठी व्हेरिएबल्स टॅबवरील **भागासह व्हेरिएबल्स जतन करा** टिक करा (32 MB पर्यंत).
- स्क्रिप्ट्स वाटण्यासाठी डाउनलोड करायला स्क्रिप्ट गटातील {{ui:जतन करा}} वापरा; एक आणण्यासाठी {{ui:उघडा}} वापरा.
