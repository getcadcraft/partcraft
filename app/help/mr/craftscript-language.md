CraftScript ही मॅट्रिक्स भाषा आहे जी MATLAB सारखी वाचता यावी म्हणून लिहिली आहे, त्यामुळे बहुतेक क्लासिक संख्यात्मक कोड (उदाहरणार्थ 88-ओळींचा टोपोलॉजी ऑप्टिमायझेशन कोड) थोड्याच बदलांसह चालतात. ती [स्क्रिप्ट वर्कस्पेस](topic:craftscript) मध्ये आणि कमांड लाइनवरून चालते.

## मूल्ये

| प्रकार | उदाहरण | टिप्पणी |
|---|---|---|
| संख्या, अॅरे | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | प्रत्येक संख्या एक अॅरे असते (1×1 चा). अॅरे कॉलमनुसार साठवले जातात, 8 आयामांपर्यंत |
| लॉजिकल | `A > 2`, `true` | true/false चे अॅरे; इंडेक्स म्हणून वापरता येतात |
| मजकूर | `'beam'`, `"beam"` | |
| स्पार्स मॅट्रिक्स | `sparse(i, j, v, n, n)` | कडकपणा मॅट्रिक्ससाठी |
| मेश, फील्ड, मॉडेल | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` काय काढते |
| Struct | `s.E = 210e3` | नावाचे फील्ड्स |
| Cell | `c = {1, 'two', [3 4]}` | कोणत्याही मूल्यांची यादी |
| फंक्शन हँडल | `f = @(x) x.^2` | |

## अॅरे आणि इंडेक्सिंग

- रेंज: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- इंडेक्सिंग 1 पासून सुरू होते: `A(2, 3)`, `v(end)`, `A(:, 1)` (संपूर्ण कॉलम), `A(:)` (सर्व एका कॉलममध्ये), `v(v > 0)` (लॉजिकल इंडेक्सिंग).
- MATLAB प्रमाणेच, शेवटच्या पलीकडे असाइन केल्यास अॅरे वाढतो: `v(10) = 1`.

## ऑपरेटर

- `+ - * / \ ^` हे मॅट्रिक्स ऑपरेशन्स आहेत (`A \ b` सोडवते); `.* ./ .^` एलिमेंट-एलिमेंट चालतात. `'` ट्रान्सपोज करते.
- तुलना `== ~= < <= > >=`; लॉजिक `& | ~` (एलिमेंट-एलिमेंट) आणि `&& ||` (शॉर्ट-सर्किट).

## नियंत्रण प्रवाह आणि फंक्शन्स

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

फंक्शन्स स्क्रिप्टमध्ये त्याच्या कमांड्सनंतर, किंवा फंक्शनच्या नावाने असलेल्या स्वतःच्या स्क्रिप्ट टॅबमध्ये ठेवली जातात:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

नाव या क्रमाने शोधले जाते: व्हेरिएबल, त्या नावाची या भागातील स्क्रिप्ट, लायब्ररी फंक्शन, अंगभूत फंक्शन.

## Echo, टिप्पणी, आउटपुट

- `;` शिवाय असलेले स्टेटमेंट आपले मूल्य छापते; `;` ते शांत ठेवते.
- `%` टिप्पणी सुरू करते; स्वतंत्र ओळींवरील `%{` आणि `%}` त्यांच्यामधील ओळींची टिप्पणी करतात.
- `disp(x)`, `fprintf('%g\n', x)` आणि `display(x)` कन्सोलवर छापतात.

## त्रुटी आणि मर्यादा

- त्रुटी काय चुकले ते साध्या शब्दांत सांगतात आणि ओळ (आणि फंक्शन कॉल्सची साखळी) देतात.
- प्रत्येक रनला step budget असते (पॅनलमधील {{ui:चालवण्याचे पर्याय}}); अंतहीन लूप एका संदेशाने थांबतो, किंवा {{ui:थांबवा}} दाबा.
- प्रत्येक अॅरेमध्ये 134 दशलक्ष मूल्यांपर्यंत साठवता येतात.

## MATLAB सारखे नाही

- प्लॉट कमांड्स त्यांचे पर्याय कॉलमध्येच ठेवतात: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` आणि तत्सम स्वीकारले जातात, पण काहीही करत नाहीत.
- `input` आणि `keyboard` समर्थित नाहीत: स्क्रिप्ट प्रश्न विचारण्यासाठी थांबू शकत नाही.
- टूलबॉक्सेस नाहीत; उपलब्ध आहेत ते [विश्लेषण लायब्ररी](topic:craftscript-library) आणि अंगभूत फंक्शन्स.
