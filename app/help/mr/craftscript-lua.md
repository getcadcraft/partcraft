Lua ही [स्क्रिप्ट वर्कस्पेस](topic:craftscript) ची दुसरी भाषा आहे. एडिटरच्या वरील भाषा बॉक्समध्ये **Lua** निवडा (`.lua` फाइल आपोआप Lua मध्ये उघडते). Lua आणि CraftScript एकच व्हेरिएबल्स आणि एकच अंगभूत फंक्शन्स वापरतात, त्यामुळे Lua स्क्रिप्ट CraftScript स्क्रिप्टने बनवलेले वापरू शकते, आणि उलट.

## मूलभूत गोष्टी

```
-- every built-in function is in the cs table
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-based, like CraftScript
print(K(1, 1), #K)             -- an element; the number of elements

-- the workspace: the same variables every script sees
ws.total = K(1, 1) * 2
print(ws.total)

-- several results from one function
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` कोणतेही अंगभूत फंक्शन कॉल करते आणि त्याचा पहिला निकाल परत देते; `cs.call(name, n, …)` `n` निकाल परत देते.
- `cs.tensor({1, 2, 3})` एक रो तयार करते, `cs.tensor({{1, 2}, {3, 4}})` एक मॅट्रिक्स.
- अॅरे, स्पार्स मॅट्रिक्स, मेश आणि फील्ड हे मेथड्स असलेली मूल्ये आहेत: `t(i, j)` किंवा `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (ट्रान्सपोज), `t:totable()`. `+ - * / ^` CraftScript मध्ये जे अर्थ देतात तेच अर्थ देतात (`*` म्हणजे मॅट्रिक्स गुणाकार); `t:times(u)` एलिमेंट-एलिमेंट गुणाकार करते.
- 1×1 अॅरे असलेली संख्या साध्या Lua संख्येच्या रूपात येते.
- `ws.name` सामायिक वर्कस्पेस वाचते आणि लिहिते. तुमची स्क्रिप्ट मागे ठेवणारे ग्लोबल व्हेरिएबल्स स्क्रिप्ट संपल्यावर तिथेही जातात.
- `print(…)` कन्सोलवर लिहिते; `cs.show(f)`, `cs.plot(y)` आणि इतर डिस्प्ले फंक्शन्स CraftScript प्रमाणेच चालतात.

## विश्लेषण लायब्ररी कॉल करा

विश्लेषण लायब्ररीची फंक्शन्स (लायब्ररी टॅब) आणि तुमच्या भागाच्या स्क्रिप्ट्सने परिभाषित केलेली CraftScript फंक्शन्स यांनाही `cs` द्वारेच पोहोचता येते:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- two outputs
```

स्क्रिप्ट सुरू होण्यापूर्वीच ती सापडतात, म्हणून नाव स्क्रिप्टमध्ये लिहा: `cs.static_tet(` किंवा `cs.call('static_tet', …)`. स्क्रिप्ट चालताना तयार केलेले नाव फक्त अंगभूत फंक्शन्सपर्यंत पोहोचते. `cs.struct({ … })` ने बनवलेला struct हा CraftScript struct आहे, आणि त्यांची Lua यादी (`{ cs.struct(…), … }`) एक cell आहे, जी लायब्ररीच्या सेटिंग्जना हवी असते. लायब्ररी फंक्शनच्या आत काही चुकले, तर संदेश फंक्शन आणि त्याची ओळ सांगतो, आणि तुमची ओळ दाखवतो जिने ते कॉल केले.

## बंद केलेले

स्क्रिप्ट्स फाइल्स, नेटवर्क किंवा पेजपर्यंत पोहोचू शकत नाहीत: `io`, `os` (घड्याळ वगळता), `require`, `dofile`, `loadfile` आणि `debug` काढून टाकले आहेत. डेटा आत आणण्यासाठी स्क्रिप्ट वर्कस्पेसचा {{ui:उघडा}} आणि व्हेरिएबल्स वापरा. CraftScript प्रमाणेच स्टेप बजेट आणि {{ui:थांबवा}} काम करतात.
