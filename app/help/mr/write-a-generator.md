जनरेटर म्हणजे एक साधी स्क्रिप्ट ([CraftScript](topic:craftscript), Lua किंवा Python) ज्याच्या वरच्या भागात काही टिप्पणी ओळी असतात. PartCraft त्या टिप्पणी ओळी वाचून फॉर्म तयार करते; तुमची स्क्रिप्ट इनपुट्स आधीच सेट केलेले व्हेरिएबल्स म्हणून वाचते.

## हेडर

या ओळी टिप्पणी ओळींमध्ये लिहा (CraftScript मध्ये `%`, Lua मध्ये `--`, Python मध्ये `#`):

```
% @generator उष्णता विनिमयक
% @input mdot: kg/s = 0.2 [0.01 .. 10] "वस्तुमान प्रवाह"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "पृष्ठभाग"
% @input solid: = true
% @input note: = "text"
```

इनपुट म्हणजे `name: unit = default`, त्यानंतर पर्यायाने श्रेणी `[min .. max]` (संख्या त्या आत ठेवल्या जातात), निवडींची यादी `{a, b, c}` आणि अवतरण चिन्हांत लेबल. unit हे फॉर्मसाठी फक्त लेबल आहे: **किंमत त्या एककात येते**, म्हणून ज्या स्क्रिप्टला SI हवे आहे तिने रूपांतर करावे, आणि `to_si(value, 'kg/s', 'kg/s')` हे देखील तपासते की एककाचा अर्थ तुम्हाला वाटतो तसाच आहे. नाव म्हणजे अक्षरे, अंक आणि अंडरस्कोअर; `body`, `sheet` आणि `problems` आधीच वापरली आहेत.

## स्क्रिप्ट काय सोडते

| व्हेरिएबल | काय |
|---|---|
| `body` | **आवश्यक.** पृष्ठभाग जाळी, सहसा `[body, info] = to_body(field, h)` मधून. रन संपल्यावर ती दुरुस्त केली जाते आणि तपासली जाते. |
| `sheet` | ऐच्छिक. एक स्ट्रक्चर: प्रत्येक फील्ड संख्या किंवा मजकूर, किंवा `value`, `unit`, `ref` आणि `note` असलेले स्ट्रक्चर. ते डेटा शीट बनते. |
| `problems` | ऐच्छिक. `mfg_check(field, 'sls', struct(), h)` मधील `problems` सेल, किंवा तुमच्या स्वतःच्या नोंदी. त्या तपासण्यांना आणि समस्यांच्या यादीला जातात. |

## एक पूर्ण छोटे उदाहरण

```
% भिंत असलेला पोकळ घन.
% @generator पोकळ घन
% @input side: mm = 12 [4 .. 40] "बाजू"
% @input wall: mm = 1.5 [0.5 .. 5] "भिंत"
% @input h: mm = 0.5 [0.25 .. 2] "व्हॉक्सेल आकार"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'of the mesh');
```

हे बंद पेटी तयार करते, आणि तपासणी तिच्या बंद आतील भागाला पावडर प्रक्रियेसाठी त्रुटी म्हणून नोंदवते. व्हॉक्सेल आकार `h` हा तुम्हाला हव्या असलेल्या सर्वात पातळ भिंतीच्या एक तृतीयांशापेक्षा जास्त नसावा: सुमारे तीन व्हॉक्सेलपेक्षा कमी असलेली भिंत विश्वसनीय नसते.

## फील्ड्स

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (प्रोफाइलवरून घन क्रांती), `tpms` (gyroid, Schwarz P आणि diamond पृष्ठभाग, सेल आकार आणि भिंत जे भागात बदलू शकतात), `lattice` आणि `lattice_beams`, `along` (मार्गाबरोबर गोल वाहिनी), बुलियन ऑपरेशन्स `field_union`, `field_intersect`, `field_subtract`, गुळगुळीत `field_blend`, आणि `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` बिंदूंवर साइन्ड अंतर देते (आतील बाजू ऋण), `field_voxel` सॉल्व्हर्ससाठी व्हॉक्सेल देते. [फील्ड्स](topic:fields) त्या काय आहेत हे स्पष्ट करते.

लक्षात ठेवण्यासारख्या मर्यादा: शीटची भिंत सेलच्या एक चतुर्थांशापेक्षा जाड असेल तर ती वाहिन्या बंद करते; सुमारे तीन व्हॉक्सेलपेक्षा पातळ वैशिष्ट्य आकुंचन पावू शकते; `along` गोल शंकू जोडते, म्हणून त्रिज्या वेगाने बदलली तर फुगवटा राहतो (प्रोफाइलसाठी `field_revolve` वापरा).

## तुमची स्क्रिप्ट जनरेटर म्हणून उघडा

{{ui:अभियंता}} वर्कस्पेसमध्ये {{ui:उघडा}} क्लिक करा आणि फाइल निवडा. `@generator` किंवा `@input` ओळ नसलेली स्क्रिप्ट नाकारली जाते: सेट करण्यासारखे काहीच नसेल. जनरेटर या ब्राउझरमध्ये ठेवला जातो (जास्तीत जास्त 20) आणि {{ui:काढा}} तो हटवतो. त्यापासून सुरू केलेल्या body मध्ये स्क्रिप्टची प्रत असते, त्यामुळे भाग तिच्यावर अवलंबून नसतो.

एका फाइलमध्ये अनेक जनरेटरही असू शकतात: JSON बंडल `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
