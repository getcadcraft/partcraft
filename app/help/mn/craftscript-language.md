CraftScript бол MATLAB-тай адил уншигдахаар бичигдсэн матриц хэл бөгөөд ихэнх сонгодог тоон кодууд (жишээлбэл 88 мөрийн топологи оновчлолын код) бага зэрэг өөрчлөлттэйгээр ажиллана. Энэ нь [Скриптийн ажлын талбар](topic:craftscript)-д болон командын мөрөөс ажиллана.

## Утгууд

| Төрөл | Жишээ | Тэмдэглэл |
|---|---|---|
| Тоо, массив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Тоо бүр массив (1×1). Массивууд багана бүрээр нь дараалан хадгалагдана, 8 хэмжээс хүртэл |
| Логик | `A > 2`, `true` | Үнэн/худал массивууд; индекс болгон ашиглагдана |
| Текст | `'beam'`, `"beam"` | |
| Сийрэг матриц | `sparse(i, j, v, n, n)` | Хатуулгийн матрицад зориулагдсан |
| Тор, талбар, загвар | `hexGrid(…)`, `part()`, `load('part.stl')` | `show`-ийн зурдаг зүйл |
| Struct | `s.E = 210e3` | Нэртэй талбарууд |
| Cell | `c = {1, 'two', [3 4]}` | Ямар ч утгын жагсаалт |
| Функцийн заагч | `f = @(x) x.^2` | |

## Массив ба индекслэлт

- Муж: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индекс 1-ээс эхэлнэ: `A(2, 3)`, `v(end)`, `A(:, 1)` (бүтэн багана), `A(:)` (бүгдийг нэг багана болгон), `v(v > 0)` (логик индекслэлт).
- Төгсгөлөөс хэтрүүлж утга оноох үед массив MATLAB-ын адилаар өснө: `v(10) = 1`.

## Операторууд

- `+ - * / \ ^` нь матрицын үйлдлүүд (`A \ b` нь шийдэж өгнө); `.* ./ .^` нь элемент бүрээр ажиллана. `'` нь транспоз хийнэ.
- Харьцуулалт `== ~= < <= > >=`; логик `& | ~` (элемент бүрээр) ба `&& ||` (богино холбоо).

## Хяналтын бүтэц ба функцууд

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функцүүд скриптэд командуудынхаа ард, эсвэл функцийн нэртэй тусдаа скриптийн таб дээр байрлана:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Нэрийг дараах дарааллаар хайна: хувьсагч, энэ эд анги дахь тухайн нэртэй скрипт, номын сангийн функц, суурилуулсан функц.

## Echo, коммент, гаралт

- `;`-гүй мэдэгдэл утгаа хэвлэнэ; `;` нь чимээгүй байлгана.
- `%` коммент эхлүүлнэ; тусдаа мөрөнд байгаа `%{` ба `%}` нь тэдгээрийн хоорондох мөрүүдийг коммент болгоно.
- `disp(x)`, `fprintf('%g\n', x)` ба `display(x)` нь консол руу хэвлэнэ.

## Алдаа ба хязгаарууд

- Алдаа нь юу буруу болсныг энгийн үгээр хэлж, мөрийг (мөн функц дуудлагуудын гинжийг) заана.
- Гүйлт бүр алхмын төсөвтэй (панел дэх Ажиллуулах сонголтууд); хязгааргүй гогцоо мессеж гаргаж зогсоно, эсвэл Зогсоох дарна.
- Массив бүр 134 сая утга хүртэл агуулж чадна.

## MATLAB-аас ялгаа

- Зурах командууд сонголтоо дуудалтад нь байрлуулна: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` зэрэг нь хүлээн авагдана, харин юу ч хийхгүй.
- `input` ба `keyboard` дэмжигдэхгүй: скрипт асуулт асуухаар зогсож чадахгүй.
- Toolbox байхгүй; [шинжилгээний номын сан](topic:craftscript-library) ба суурилуулсан функцууд л байгаа зүйл.
