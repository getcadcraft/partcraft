Скриптийн ажлын талбар дахь шинжилгээ нь хувьсагчаа бие биедээ дамжуулдаг хэдхэн богино скрипт юм. Зорилгодоо ойр [номын сангийн](topic:craftscript-library) функцээс эхэлж, хуулбар хийгээд өөрчилнө; эсвэл доор заасан байдлаар бүхэлд нь бүтээнэ.

## 1. Тор

```
model = part();                  % загвар болгож буй эд анги
m = tetmesh(model, 4);           % ойролцоогоор 4 мм-ийн тетраэдр
show(m)
```

Алхам үргэлжлэхээсээ өмнө торыг харагдацад шалгана: {{key:F}} тороо багтаана, **Харуулсан** дахь {{ui:нүд}} эд ангийг нуудаг.

## 2. Угсрах ба бодох

Элементийн давталтыг скриптэд өөрөө бичнэ (номын дагуу уншигдана), харин хүнд хэсгүүдийг суурилуулсан функцүүдэд үлдээнэ: элементийн матрицууд, гурвалсан утгаас сийрэг угсралт, урьдчилан нөхцөлтэй нийлмэл градиент шийдвэрлэгч. Номын санд байгаа бол `static_tet` гэх мэт функц хуулах бүрэн жишээ болно.

## 3. Үр дүнг харуулах

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % зангилаа тус бүрт нэг утга
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- Легендийн мужыг гараар оруулж эсвэл {{ui:Авто}} болгож буцаана.
- Зангилаан дээрх утгыг унших бол торыг дарна.
- Ижил `'id'`-тай график шинэчлэгдэнэ, тиймээс нийлэлтийг хянахын тулд давталтынхаа дотор хэвлэж, график зурна.

## 4. Шалгах

Мэддэг зүйлтэйгээ харьцуул: консолын үзүүрийн хазайлтыг PL³/3EI-тэй, нүхтэй хавтанг түүний стресс төвлөрлийн коэффициентээр, урвалуудыг ачаалалтай. Шалгалтыг тусдаа скрипт болгож бич, ингэснээр өөрчлөлт бүрийн дараа дахин ажиллана:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('үзүүр %g мм, онолын дагуу %g мм (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Хадгалах

- Алхам бүр өөрийн скрипт табтай байж болно: тэд хувьсагчаа хуваалцдаг тул дараалан ажиллуулна.
- Скриптүүд эд ангид хадгалагдана. Үр дүнг мөн хадгалахын тулд **Хувьсагчид** табан дээр **Хувьсагчдыг эд ангитай хамт хадгалах**-ыг тэмдэглэнэ (32 МБ хүртэл).
- Скрипт бүлгийн {{ui:Хадгалах}} нь скриптийг хуваалцахаар татаж авна; {{ui:Нээх}} нь нэгийг оруулна.
