Загварыг загварчилдаг газартаа хэлбэржүүлж, харин энд машинд гаргах, шалгах, баримтжуулна. Нөгөө программд хийсэн өөрчлөлт бүр PartCraft дахь нэг импортолсон биеийг сольж, түүний дараах онцлогууд шинэ хэлбэр дээр дахин бүтнэ.

:::note
Холбоосонд ижил компьютер дээр **CadCraft Studio** хэрэгтэй. Хөтчийн таб холболтыг авч чадахгүй. Интернетээр юу ч дамжихгүй: скрипт нь токентой тухайн компьютерийн өөрийн хаягаар Studio-той харилцана.
:::

:::warning
Энэ холбоосыг скриптийн файл бичигч болон нөгөө программын орлуулагчтай туршсан, харин Rhino эсвэл Grasshopper дотроо одоогоор биш. Тэнд ямар нэг зүйл амжилтгүй болбол юу гэж гарснаа бидэнд мэдэгдэнэ үү.
:::

## Тохируулах

1. Studio дээр PartCraft-г нээнэ. {{ui:Settings}} › {{ui:PartCraft}} › {{ui:Assistants}} дотор **AI туслахууд болон скриптүүдэд PartCraft ашиглуулах**-ыг тэмдэглээд, дараа нь **Засах**-ыг дарна уу.
2. Studio дээр {{ui:Connect an assistant}}-г сонгоно уу. Доор буулгах хаяг ба токеныг харуулна.
3. Скриптийг татаж авна уу: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino-оос

1. Rhino-ийн скрипт засварлагч дээр `cadcraft_link.py`-г ажиллуулна уу (Rhino 8-д Python 3).
2. Анх удаа хаяг ба токеныг буулгана уу. Тэдгээр нь таны нүүр хавтсанд `.cadcraft-link.json`-д хадгалагдана, загварт хэзээ ч биш. Studio эхлэх бүрт шинэ токен үүсгэдэг тул скрипт дахин асууна.

Зогсоохын тулд скриптийг дахин ажиллуулна уу.

## Grasshopper-ээс

Эхлээд Rhino-д скриптийг нэг удаа ажиллуулна уу, ингэснээр хаяг ба токен хадгалагдана.

1. Script компонент (Python 3) нэмээд, `cadcraft_link.py`-ийн бүх текстийг түүн дотор буулгана уу.
2. Түүнд эдгээр оролтуудыг өгнө үү: `G` (геометр, жагсаалтын хандалттай), `N` (нэр, заавал биш), `On` (логик асаагч), мөн `Target` (заавал биш: `model` эсвэл `part`, хоёр аппаа нээсэн бол).
3. `On`-ийг true болгоно уу.

Тооцоолол бүр `G`-г илгээж, өмнө нь компонентийн илгээсэн зүйлийг орлуулна.

## Энд хэрхэн ажилладаг вэ

- **Нэг бие.** Загварт харагдах бүх зүйл нэг импортолсон онцлог болно, яг [.3dm файлыг нээх](topic:open-3dm-files) үед шиг.
- **Хаагдах ёстой.** PartCraft жижиг нүх ба тэгш нээлхийг дүүргэх ба нөгөө программд хэдэн нь дүүргэснийг мэдэгдэнэ. Хэрэв загвар хаагдахгүй хэвээр байвал PartCraft өмнөх биеийг хадгалж, статус мөрөнд тэр тухай харуулна. Дараагийн хаагдсан өөрчлөлт үүнийг шинэчилнэ.
- **Хийж буйгаа дуусгана уу.** Эскиз эсвэл зураг дээр шинэчлэлтийг татгалзаж, дахин оролдоно; та загварт буцаж ирмэгц хүрнэ.
- **Буцаах.** Бие биенээсээ хоёр секундын дотор хийгдсэн шинэчлэлтүүд нэг буцаах алхамыг хуваалцана.
- **Хадгалах.** Хэсгийн файл холбоосыг хадгална. Дахин нээсний дараа скриптийг дахин ажиллуулбал ижил онцлог шинэчлэгдэнэ.

**Зөвхөн нэг чиглэлтэй.** Энд хийсэн өөрчлөлт нөгөө программ руу буцахгүй.

## Хэрэв алдаа гарвал

- **«ModelCraft эсвэл PartCraft цонх үүнийг зөвшөөрөхгүй байна»:** тохируулгын 1-р алхмыг хийнэ үү.
- **«Studio токеныг татгалзлаа»:** Studio дахин эхэлсэн. Шинэ токеныг хуулж, скриптийг дахин ажиллуулна уу. Grasshopper-ийн хувьд эхлээд Rhino-д ажиллуулна уу.
- **«CadCraft Studio-д хүрч чадахгүй байна»:** Studio ажиллахгүй байна, эсвэл хаяг өөрчлөгдсөн.
