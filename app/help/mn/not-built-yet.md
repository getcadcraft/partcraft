PartCraft бол эрт үеийн хувилбар. Энэ хуудас энэ PartCraft хувилбарт юу хийдэггүйг жагсаана, та тэдгээрийг хайхгүйн тулд, мөн өнөөдөр оронд нь юу хийхийг. Эдгээрт огноо байхгүй.

## Яг кернел шаардана

Энэ хувилбар бүх эд ангийг торны кернелээр бүтээнэ ([Торны кернел](topic:solid-kernels)-г харна уу). Доорх бүх зүйл яг геометрийн кернел шаарддаг бөгөөд энэ хувилбарт одоогоор байхгүй. Эдгээр онцлогоор хадгалсан эд ангиуд нээгдэх боломжтой хэвээр байна: онцлогууд түүхэнд үлдэж, бүтээгээгүй гэж тэмдэглэгдэн, хадгалахад хадгалагдана.

| {{ui:Дугуйруулах}} ба {{ui:Фаск}} муруй ирмэгүүд дээр; ирмэгийн дагуу радиус өөрчлөгддөг дугуйлгууд; уулзах газарт жигд холбогдох дугуйлгууд (торны кернел тэдгээрийг өнцөгөөр огтолдог) | Дугуйруулах ба Фаск нь хавтгай нүүрнүүдийн хооронд шулуун ирмэгт ажилладаг; бусад булангуудыг эскизд экструдын өмнө дугуйлга хийнэ ({{ui:Дугуйруулах}} эскизд, {{key:F}}) |
| {{ui:Хальс}} муруй нүүрнүүдийг нээх; өөр зузаантай ханат | Тэгш хавтгай нүүрнүүдийг нээх; хана зузаан байх шаардлагатай газарт экструдаар материал нэмэх |
| Муруй нүүрнүүд дээрх {{ui:Шүүлтүүр}}, {{ui:Лофт}}, {{ui:Налалт}}; нүүр, дараагийн нүүр эсвэл оройд хүртэл экструд; өнцөгтэй (налуу) экструд | Экструд эсвэл эргүүлэлт, шаардлагатай газар алхмаар; хэмжсэн гүн хүртэл экструд |

| Олон бие: {{ui:Нэгтгэх}}, {{ui:Биеийг зөөх}}, {{ui:Биеийг масштаблах}}, {{ui:Замын массив}}, шинэ бие үүсгэдэг онцлогууд | Нэг бие; хэв маяг ба толин хуулбар онцлогууд |
| Зөвхөн яг кернел л олж чадах нүүр дээрх эскиз, хавтгай, тэнхлэг ба цэгүүд (филётоор үүссэн нүүр, нүхний хана, импортолсон биеийн нүүр) | Суурь хавтгай, лавлах хавтгай ба экструд болон эргүүлэлтийн тэгш нүүрнүүд дээр эскиз |
| Яг кернел дээр үүсэх генератив дизайны үр дүн эд ангид нээгдэх эсвэл нэмэгдэх (импортолсон бие болно) | Үр дүнг STL эсвэл STEP-ээр татна |
| Нээсэн STEP файлын муруй нүүрнүүдийг яг гадаргуу болгон засах; STEP-ийн сплайн, эргүүлсэн ба шүүсэн нүүрнүүдийн яг STEP; сплайн талууд, загварчилсан утаснууд, STL / OBJ / 3MF бие ба угсралтууд; бусад эд ангийн загвар зохиогчдод STEP | {{ui:Нээх}} нь STEP-ийг гурвалжингаар уншиж, файлын тэгш нүүр, цилиндр, конус, бөмбөлөг ба тороидыг экспортод хадгалдаг ([STEP файл нээх](topic:import-step)); {{ui:Экспорт}} › {{ui:STEP AP242 (нарийн бие)}} нь аналитик нүүр бүрийг яг бичиж, тэдгээрийг жижиг гадаргуугаар хадгална ([Экспорт](topic:export-files#for-other-cad-programs-step)); бусад эд ангийн загвар зохиогчийн макро одоо ч бичнэ |
| Зурагт муруй харагдац | Харагдац ба зүсэлтийн харагдацууд нь жижиг гадаргуугаас зурагдана |
| Яг эзэлхүүн, талбай, зай | {{ui:Хэмжих}} нь жижиг гадаргуутай бие дээрх тоонуудыг өгнө, дугуй хэсэгт бага зэрэг бага; илүү нарийн **Муруйнууд** тохиргоо тэдгээрийг ойртуулна |

Доорх хүснэгтүүдийн зарим мөр нь эдгээр онцлогуудын аль нэгийг өөр зүйлийн орлуулагч болгон санал болгоно. Эдгээр санал нь яг кернел буцаж ирсний дараа хамаарна.
