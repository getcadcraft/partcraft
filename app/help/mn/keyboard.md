Панел дэх хайрцагт бичиж байхад товчлуурууд ажиллахгүй, харин {{key:Mod+S}} ба {{key:Mod+O}} үргэлж ажилладаг. Үсгийн товчлуурууд өөр товчлуургүйгээр ажиллана.

Хөтөч дэх товчлуурууд болон функцийн товчгүй гар дээрх ерөнхий тэмдэглэл: [Товчлуур, хулгана ба трекпад](common:keys).

## Бүх газар

| Товч | Үйлдэл |
|---|---|
| {{key:Mod+S}} | Хэсгийг хадгалах (угсралтад: угсралтыг). Эхлээд нээлттэй эскизийг хаана |
| {{key:Mod+O}} | Хэсэг эсвэл угсралтын файлыг нээх (хадгалаагүй өөрчлөлт байвал эхлээд асууна) |
| {{key:Mod+Z}} | Буцаах |
| {{key:Mod+Y}} эсвэл {{key:Mod+Shift+Z}} | Дахин хийх |
| {{key:F1}} | Энэ тусламжийг нээх эсвэл хаах (мөн аппын дээд мөрөнд {{ui:Help}}). {{key:Esc}} ч мөн хаана. Олон зөөврийн компьютер ба Mac гар дээр Fn-ийг дарж барина уу |
| {{key:Ctrl+Shift+F}} | Дэлгэцийн горим: энгийн, бүтэн дэлгэц, мөрүүдийг нуусан бүтэн дэлгэц. Mac дээр ч Control, ⌘ биш |
| {{key:Esc}} | Бүтэн дэлгэцээс гарах (бүтэн дэлгэц горимд байхад) |
| {{key:Mod+,}} | {{ui:Settings}}, {{ui:PartCraft}} табыг оруулаад (үзнэ үү: [PartCraft-ийн тохиргоо](topic:settings)) |

Панелийн тооны хайрцагт {{key:Mod+Z}} нь хөтчийн өөрийн текстийн буцаалт. Эскизийн хэмжээсийн дээрх тооны хайрцагт PartCraft-д буцаана.

## Хуулах, буулгах ба хуулбарлах

Тэд таны ажиллаж буй зүйл дээр үйлчилнэ: нээлттэй эскиз дэх сонгосон геометр, түүхэн дэх сонгосон онцлог эсвэл угсралт дахь сонгосон хэсэг. Дэлгэрэнгүй: [Хуулах, буулгах ба хуулбарлах](topic:copy-paste).

| Товч | Үйлдэл |
|---|---|
| {{key:Mod+C}} | Сонголтыг хуулах |
| {{key:Mod+X}} | Таслах: хуулаад, устгах |
| {{key:Mod+V}} | Буулгах. Эскизд хуулбар заагчийг дагана: хаана очихыг дарна уу |
| {{key:Mod+Shift+V}} | Тэр байранд нь буулгах: ижил координат (угсралтад ижил байрлал) |
| {{key:Mod+D}} | Хуулбарлах: хуулах ба буулгах нэг алхамаар, түр санах ойд нөлөөлөхгүй |
| {{key:Mod+A}} | Бүгдийг сонгох (эскизд) |
| {{key:Esc}} | Юуг ч сонгохгүй (мөн заагчийг дагасан буулгалтыг цуцлах) |

Тооны хайрцагт эдгээр товчлуурууд текстийг ердийнх шигээ хуулж, буулгана. Панел дэх сонгосон текстийг хөтөч хуулна.

| {{key:X}} | Зүсэлтийн харагдацыг асаах эсвэл унтраах; бүх ажлын талбар ба угсралтад; {{key:Esc}} хаана (үзнэ үү: [Зүсэлтийн харагдацаар дотогш харах](topic:section-view)) |

| {{key:Esc}} | Эскизийн хавтгай сонгохоо зогсоох, эсвэл сонголтыг цэвэрлэх ({{key:Shift}}-ээр сонгосон ирмэг эсвэл гадаргууг оруулаад) |

## 3D харагдацад

Эхлээд харагдац дээр дарж товчлуурын фокусыг авна уу.

| Товч | Үйлдэл |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Харагдацыг 15 градусаар эргүүлэх |
| {{key:Shift+Left}} ба бусад сумнууд | Харагдац шилжүүлэх |
| {{key:Plus}} эсвэл {{key:=}} | Томруулах |
| {{key:Minus}} | Жижигрүүлэх |

| Хулгана | Үйлдэл |
|---|---|
| Зүүн товчийг чирэх | Харагдацыг эргүүлэх (тойрох) |
| Баруун эсвэл дунд товчийг чирэх | Харагдац шилжүүлэх |
| Зүүн товчийг чирэхдээ {{key:Shift}}, {{key:Ctrl}} эсвэл ⌘ барих | Харагдац шилжүүлэх |
| Дугуйг эргүүлэх | Заагчийн байрлалд томруулах (өөрөөсөө холдуулбал томрно) |
| Трекпад дээр хоёр хуруугаар шудрах | Харагдацыг эргүүлэх; {{key:Shift}}-тэй бол харагдац шилжүүлэх. Pinch-ээр томруулна. [PartCraft-ийн тохиргоо](topic:settings)-д **Гүйлгэлт** гэснээр тохируулна |

[PartCraft-ийн тохиргоо](topic:settings)-д **Харагдац эргүүлэх: Дунд товч** сонгосон бол дунд товч харагдацыг эргүүлнэ, дунд товчтой {{key:Shift}} эсвэл баруун товч харагдац шилжүүлнэ, зүүн товч зөвхөн сонгоно.
| Дарах | Гадаргуу (бүхлээр нь тодорно), ирмэг эсвэл хавтгай сонгох |
| {{key:Shift}}+дарах ирмэг эсвэл гадаргуу | Хэд хэдэн ирмэг эсвэл гадаргууг цуглуулах |
| Хоосон зайд дарах | Сонголтыг цэвэрлэх |

## Хөтчийн авч болох товчлолууд

- Safari дээр {{key:Mod+Y}} түүхийг нээж болзошгүй: дахин хийхдээ {{key:Mod+Shift+Z}} ашиглана уу.
- {{key:Mod+D}} нь хөтчийн хадгалсан хуудасны товч: аппд фокус байх үед PartCraft авна, хайрцагт бичиж байхад хөндөхгүй.
- {{key:F11}} ба {{key:Mod+Plus}} / {{key:Mod+Minus}} нь PartCraft-ийнх биш, хөтчийн бүтэн дэлгэц ба хуудасны томруулалт. Бүтэн дэлгэцэд {{key:Ctrl+Shift+F}}, загварыг томруулахад дугуйг ашиглана уу.
- Олон зөөврийн компьютер ба Mac дээр функцийн товчлуурт Fn хэрэгтэй: тусламжид Fn+{{key:F1}} дарна уу, эсвэл {{ui:Help}} товчийг ашиглана уу.

Хүрэлт ба трекпадын дохио: [Трекпад, хүрэлт ба жижиг дэлгэц](topic:trackpad-and-touch).
