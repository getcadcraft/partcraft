**Параметр** нь нэртэй тоо, жишээ нь `width = 120` эсвэл `margin = bolt * 1.5`. Гүн, нүхний диаметр, массивын тоо эсвэл эскизийн хэмжээг түүнд холбоход параметрийг өөрчлөхөд тэдгээр бүгд нэг алхамаар өөрчлөгдөнө. Ингэж та дизайны санааг толгойдоо биш эд ангид хадгална.

## Параметр нэмэх

1. Баруун самбарт {{ui:Параметрүүд}} табыг дар.
2. **Хувьсагчид** доор «нэр» талбарт нэр бич, жишээ нь `width`.
3. Дараагийн талбарт түүний утгыг бич, жишээ нь `120`, дараа нь {{key:Enter}} дар (эсвэл {{ui:Нэмэх}}-ийг дар).

Утга нь тоо эсвэл бусад параметрийн илэрхийлэл байж болно: `bolt * 1.5`, `width / 2 - 10`, `if(width > 100, 6, 4)`. **Утга** багана нь тооцоолсон үрийг харуулна. Нэр нь үсгээр эсвэл `_`-ээр эхэлж, зөвхөн үсэг, тоо, `_` агуулна; функц ба нэгжийн нэрс (`sin`, `mm`, `pi`) татгалзагдана, мөн `a = b`, `b = a` гэх мэт гогцоо бас.

## Тоог параметртай холбох

1. Түүхэнд онцлог дарна, жишээ нь "Extrude1". Түүний тохиргоо {{ui:Шинж чанар}} табд харагдана.
2. **Гүн (мм)** гэх мэт тоон хайрцагт `=` болон илэрхийлэл бич: `=thick` эсвэл `=width / 4`.
3. {{key:Enter}} дар.

Хайрцаг одоо үрийг харуулна, түүний шошгоны хажууд **ƒ** товч гарч ирнэ. Тэгшитгэлийг харахын тулд заана уу. Эскизийн хэмжээ мөн адил ажиллана, онцлогийн **Эскизийн хэмжээ** жагсаалтанд болон нээлттэй эскизийн хэмжээний хайрцагт (хэмжээ дээр хоёр удаа дарж, `=width` бичээд {{key:Enter}} дар).

Холбож болох тоонууд: экструдийн гүн, эргүүлэх өнцөг, нүхний диаметр, гүн ба counterbore хэмжээ, массивын тоо, зай ба өнцөг, дугуйруулалтын радиус, фаскийн зай, хальсны ханын зузаан, эскизийн бүх хэмжээ, шинэ онцлогуудын хэмжээ (хоёр дахь гүн, налалт, countersink, лавлах хавтгайн зай, налалтын өнцөг болон бусад).

## Параметрийг өөрчлөх

**Параметр** табд **Илэрхийлэл** баганад шинэ утга эсвэл илэрхийлэл бичээд {{key:Enter}} дар. Түүнд холбогдсон бүх зүйл өөрчлөгдөж, эд анги нэг алхамаар дахин бүтнэ: {{key:Mod+Z}} үүнийг буцаана.

Тоог эсрэг үзүүрээс өөрчлөхийн тулд үзэх: [Хоёр талын тэгшитгэл](topic:equations-two-way).

## Параметр хаана ашиглагдаж байгааг харах

{{ui:Параметрүүд}} табд параметр бүрийн доор түүнийг юу ашиглаж байгааг хэлсэн мөр байна:

- түүний удирдах тоонууд, жишээ нь **Extrude1 гүн** эсвэл **Sketch1 D2 (зай)**. Нэгийг нь дарахад онцлогийг сонгож, түүний шинж чанарыг харуулна;
- **параметрүүдээр дамжуулан** удирдах тоонууд, жишээ нь `d = h + 2` ба `h = w / 2` үед **Hole1 диаметр (h, d-ээр)**;
- илэрхийлэлдээ түүнийг ашигласан **параметрүүд**, түүнийг тохируулдаг **тохиргоонууд**, мөн түүнийг уншдаг **скриптүүд** (үзэх: [Скрипт бичих ба ажиллуулах](topic:craftscript)).

«Одоогоор ашиглагдаагүй.» гэдэг нь юу ч ашигладаггүй гэсэн үг: асуулгүйгээр устгаж болно.

## Салгах, нэр солих, устгах

- **Тоог салгах:** түүний **ƒ** товчийг дар, эсвэл **Тэгшитгэлүүд** жагсаалт дахь {{ui:Салгах}}. Одоогийн утгаа хадгална, ямар ч параметр түүнийг өөрчлөхгүй болно.
- **Параметрийн нэрийг солих:** **Нэр** талбарт шинэ нэр бич. Түүнийг ашигласан илэрхийлэл бүр дахин бичигдэнэ.
- **Параметрийг устгах:** мөрийнхөө × дээр дар. Хэрэв ямар нэг зүйл түүнийг ашигладаг бол PartCraft эхлээд түүний одоогийн утгыг тэдгээр илэрхийлэлд бичих эсэхийг асууна.
- **Онцлог устгах** нь түүний тоонуудын тэгшитгэлийг устгана; статусын мөр аль нь вэ гэдгийг хэлнэ.

:::note
Параметрүүд `.partcraft.json` файлд хадгалагдана (файлын 3-р хувилбараар). Параметргүй эд анги өмнөхтэй яг адилхан хадгалагдана.
:::

## Илэрхийлэл

| Бичих | Утга |
|---|---|
| `120`, `12.5`, `1e3` | тоо (миллиметр, эсвэл өнцгийн хувьд градус) |
| `2in`, `1ft`, `3"`, `1.5cm`, `0.2m` | бусад нэгжээр урт, миллиметр болгон хөрвүүлсэн |
| `30deg`, `0.5rad` | өнцөг, градус болгон хөрвүүлсэн |
| `+ - * / %` ба `^` | арифметик; `^` нь зэрэг, `-2^2` нь −4 |
| `sin cos tan asin acos atan atan2` | градусаар тригонометр |
| `sqrt pow exp ln log abs sign` | бусад функцүүд |
| `ceil floor int round(x, digits) min max` | дугуйруулалт ба хязгаар |
| `if(test, a, b)` ба `< <= > >= == !=` | сонголт: `if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

Нэрс том, жижиг үсгээр ялгагдана: `Width` ба `width` хоёр өөр параметр.
