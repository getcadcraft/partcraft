Сайн загварчлал товчлуураас илүү сахилгад түшиглэдэг. Текстээр бичсэн эд анги уншиж, шүүмжилж, мөр мөрөөр нь харьцуулж, скриптээр дахин бүтээгдэж болно. PartCraft хоёр талд ажиллана: аливаа эд ангийг скриптээр бичиж болох бөгөөд скрипт эд ангийг бүтээнэ.

## Аппд

{{ui:Параметрүүд}} табын **Script** хэсгийн доор:

- {{ui:Скрипт болгон хадгалах}} нээлттэй эд ангийг `<name>.pcscript` болгон татна.
- {{ui:Скрипт нээх}} `.pcscript` файлаас эд анги бүтээнэ. Алдааг мөрийнх нь дугаартайгаар мэдээлэх бөгөөд юу ч солигдохгүй.

## Скриптийн формат

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

Дүрмүүд:

- Зүүн захаас эхэлсэн мөр нь мэдэгдэл эхлүүлнэ: `pcscript`, `part`, `param`, элементийн төрөл (`sketch`, `extrude`, `revolve`, `hole`, `lpattern`, `cpattern`, `mirror`, `fillet`, `chamfer`, `shell`, `import` болон шинэ төрлүүд), түүний нэр дагасан, эсвэл `rollback <feature>`.
- Завсарлагатай мөр нь дээрх мэдэгдлийн тохиргоо. Ганцаараа бичсэн тохиргоо (`through`, `reverse`, `suppressed`) нь "тийм" гэсэн утгатай.
- Тоон тохиргоо нь тоо, эсвэл `=` ба илэрхийлэл байж болно, энэ нь тэгшитгэл үүсгэнэ: `depth = thick`.
- Эскизд: `on` нь хавтгайг нэрлэнэ (`front`, `top`, `right`, `face Base end`, `face Revolve1 side l3`); геометр нь `point <name> x, y`, `line <name> <point> <point>`, `circle <name> <centre> <radius>`, `arc <name> <centre> <start> <end>` (цагийн зүүний эсрэг) эсвэл `spline <name> fit|control <points>`; хамаарлууд нь төрөл ба холбосон нэрнүүд (`O` нь эх цэг); хэмжээс нь утгаараа эсвэл `= илэрхийлэл`-ээр төгсдөг.
- Геометр эсвэл хамаарлын мөрийн нэмэлт тохиргоо нь төгсгөлдөө дөрвөлжин хаалтад `;`-ээр тусгаарлагдан бичигдэнэ: `[construction]`, `[side -1; label 5, 3]`.
- `#` нь сэтгэгдэл эхэлнэ (мөрийн эхэнд эсвэл зайны дараа). Зайтай нэрийг "давхар хашилт"-д бичнэ.
- Элементийн id-ууд бичигдсэн дарааллаар f1-ээс тоологдоно. Ирмэг ба гадаргуугийн лавлагаа тэдгээрийг ашиглана, жишээ нь `edge f2.side:l3 f2.end [at 50, 0, 10]`.
- Формат үгээр илэрхийлж чадахгүй тохиргоог `json` ба утгатай нь бичнэ; тэдгээр нь яг хэвээрээ уншигдана.

Аппаас хадгалсан скрипт бүх тохиргоог агуулдаг тул ижил эд анги болж нээгдэнэ. Аппаас импортолсон STEP бодисыг скриптийн дотор бичдэг, командын мөрөөс бол `step-file`-ээр нэрлэгдсэн тусдаа `.step` файл болгон бичдэг.

## Командын мөрийн хэрэгсэл

Хэрэгсэл нь Node.js 24-тэй компьютер дээр, CadCraft эх кодын хуулбараас ажиллана: `node tools/partcraft-cli/partcraft.mjs <command>`. Энэ бол хөгжүүлэгчийн хэрэгсэл бөгөөд аппын ижил модулиудыг ашигладаг. Эд ангиуд нь `.partcraft.json` файлууд эсвэл `.pcscript` скриптүүд.

| Команд | Юу хийдэг |
|---|---|
| `info <part>` | Элементүүд, параметрүүд, rollback мөр, бүтээсэн бодисын эзэлхүүн ба хэмжээ |
| `params <part>` | Параметр ба тэгшитгэл бүр утгатайгаа |
| `set <part> width=150 Base.depth==thick` | Урагш: параметр өөрчлөх, тоо холбох (`==` эсвэл илэрхийлэл), энгийн тоо тогтоох |
| `drive <part> Base.depth=12` | Хойш: жолоодсон тооны ард байгаа параметрийг бодно (`--prefer width` аль нэгийг сонгоно) |
| `build <part> --out x.step` | `.step`, `.stl`, `.3mf`, `.json`, `.pcscript` эсвэл макро (`.swb`) бичнэ |
| `build <part> --table sizes.csv --out-dir sizes` | Загварын хүснэгтийн мөр бүрт нэг файл |
| `variants <part> --out-dir d` эсвэл `--zip f.zip` | Тохиргоо бүрийг STEP, IFC, DWG ба урьдчилан харах, хувилбарын хүснэгт, сангийн зүйлээр (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`); см. [Хувилбарын багц хийх](topic:variant-pack) |
| `script <in.pcscript> -o part.json` | Скриптээс эд анги |
| `to-script <part> -o part.pcscript` | Эд ангиас скрипт |
| `rollback <part> [<feature>]`, `forward <part> [--end]` | Файл дахь rollback мөрийг зөөх |
| `check <part> [--strict]` | Сахилгын шалгалт (доор) |

`build` нь мөн `--set name=value` (зөвхөн энэ бүтээцэд) болон `--upto <feature>`-ийг авна. Командын бүр `--json`-ийг авна. Гарах код: 0 зүгээр, 1 асуудал олдсон, 2 команд буруу бичигдсэн. Скриптийг хэзээ ч шууд дахин бичдэггүй: өөрчлөгдсөн хуулбарыг хадгалахын тулд `-o` өгнө.

## Шалгалт

`check` нь эд ангийг хожим өөрчлөхөд хэцүү болгодог зүйлсийг тайлагнана:

| Олдвор | Тооцогдох |
|---|---|
| Хэт тодорхойлогдсон эскиз (зөрчилдсөн эсвэл давтагдсан хамаарлууд) | алдаа |
| Бүтэхгүй элемент | алдаа |
| Алдаатай параметр эсвэл тэгшитгэл, эсвэл бие биеэ ашигладаг параметрүүд | алдаа |
| Дутуу тодорхойлогдсон эскиз, чөлөөний зэрэгтэйгээ хамт | анхааруулга |
| Ямар ч параметрээр жолоодогдоггүй элемент ба хэмжээсэд шууд бичсэн тоонууд | анхааруулга |
| Ашиглагддаггүй параметр | анхааруулга |
| Идэвхгүй болгосон элемент; rollback мөр төгсгөлд биш | анхааруулга |

`--strict` бүх анхааруулгыг алдаа болгож, ингэснээр бүтээх скрипт бүрэн жолоодогдоогүй эд ангийг татгалзана.

:::note
`.swb` макро гаралт нь ихэнх үйлдвэрүүдийн ашигладаг эд ангийн загвар хийх программд зориулагдсан: тэр программ дотор ажиллуулахад тэнд эд ангийг бүтээнэ. Энд тэр программ дээр ажиллуулаагүй (манай серверт байхгүй) тул туршаагүй гэж үзнэ.
:::
