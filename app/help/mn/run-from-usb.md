Инженерийн хэрэгслүүд (генераторууд, инженерийн сан, шалгалтууд ба өгөгдлийн файлууд) **администраторын эрх шаардахгүй** бөгөөд **суулгагч шаардахгүй**. Тэдгээр нь зөвхөн доор жагсаасан зүйлсийг бичдэг, өөр юу ч бичдэггүй.

| Юу вэ | Хаана хадгалагддаг |
|---|---|
| Таны эд ангиуд, тэдгээрийн үүсгэсэн бие, өгөгдлийн хуудас ба шалгалтууд | Таны хадгалсан эд ангийн файл (`.partcraft.json`), хадгалсан газраа. |
| Файлаас нээсэн генераторууд | Аппын өөрийн санах ойд: вэб хуудсан дээр хөтчийн local storage-д, зөөврийн Studio-д програмын хажууд байгаа `data` хавтаст. Хамгийн ихдээ 20. |
| Тохиргоо (тохируулсан воксель хэмжээ, бодогчийн урсгалууд, байрлал) | Мөн аппын санах ой. |
| Өгөгдлийн хуудас, талбарууд, тор | Зөвхөн таны хадгалсан газарт: татаж авалт таны сонгосон газар очно. |

Хэрэгслүүд **өөрсдийн сүлжээний дуудлага хийдэггүй**: хамт ирсэн генераторууд нь аппын өөрийн хавтасны файлууд, сан ба шалгалтууд таны компьютер дээр сүлжээнд хүрч чадахгүй worker дээр ажилладаг, инженерийн өгөгдөл (ус ба агаарын шинж чанар, материалууд) аппын дотор байна. Файлаас нээсэн генератор таны компьютер дээр уншигдах бөгөөд хаашаа ч явахгүй.

## Windows-ийн зөөврийн zip ба Linux

Windows-ийн зөөврийн Studio тохиргоо, кэш, нэмэлтүүдээ програмын хажууд байгаа `data` хавтаст хадгалдаг. Linux AppImage нь хажууд нь `portable` нэртэй файл байвал тохиргоо, кэшээ өөрийнхөө хажууд хадгалдаг; тэр файлгүй бол таны home хавтсыг ашигладаг. Mac-ийн зөөврийн хэлбэр байхгүй: системээс татаж авсан апп өөрийнхөө хажууд бичихгүй. Studio-ийн тусламж дахь зөөврийн тэмдэглэлүүд (`Studio` тусламж) програмын бичдэг зүйлсийг жагсаадаг.

## Хост хандалт

Энд хост хандалт асуудаггүй. Принтерүүд, цуваа төхөөрөмжүүд ба USB төхөөрөмжүүд тусдаа: ажил тэдгээрийг шаардах үед асууж, төхөөрөмж бүрд нэг удаа; генераторууд болон шалгалтууд тэдгээрт огт хүрдэггүй.
