Ижил хэрэгслийн замыг өөр өөр удирдлагад өөр өөрөөр бичих хэрэгтэй: мөрийн дугаартай эсвэл үгүй, `M6` эсвэл түр зогсолт, `G28` эсвэл `G53`, `M30` эсвэл `M2`. **Пост** нь үүнийг хэрхэн хийхийг хэлэх богино текст. PartCraft-ын гурван суурилуулсан пост (Fanuc төрлийн, GRBL ба LinuxCNC) энэ форматаар бичигдсэн тул таны өөрийн пост тэдгээрийн нэгнээс хуулж эхэлж болно.

Тайрахаас өмнө гаралтыг машиныхаа өөрийн симуляторт шалгаж, эхлээд түүхий эдийн дээр агаарт ажиллуулна уу. Суурилуулсан постууд энэ формат гарахаас өмнө бичиж байсан яг тэр зүйлийг бичдэг (туршилтууд түүний гаралтыг олон мянган програмын дээр байтаар харьцуулдаг), гэхдээ энд юу ч таны машин дээр баталгаажаагүй, таны өөрчилсөн пост таны баталгаажуулах зүйл.

## Нэг бүтээх

Манufacture-д, **Пост**-ын дор:

- {{ui:Постыг засах…}} суурилуулсан удирдлага дээр **таны өөрийн хуулбарыг** нээнэ. Өөрийн постон дээр тэр постыг нээнэ.
- {{ui:Шинэ пост…}} бүх үйл явдал орсон жижиг хоосон постоос эхэлнэ.
- {{ui:Постын файл импортлох…}} `.cpost` текст файлыг уншина (засварлагчийн **Файл болгон хадгалах…**-аас авсан файл).

Засварлагч текстийг, таныг бичиж байх үед уншигдах эсэх (ба аль мөр буруу байгааг), мөн пост бичиж буй G-code-ийг харуулна. **Урьдчилан харах** нь үйл явдал бүрийг ажиллуулах жишээ програм эсвэл энэ эд ангийн өөрийн програмыг сонгоно. {{ui:Хадгалах}} нь постыг эд ангийн файлд хадгалж (20 хүртэл пост), удирдлага болгон сонгоно. Постууд эд ангийн хамт явна; өөр эд ангид ашиглахын тулд файл болгон хадгалаад тэнд импортлоно уу.

## Пост ямар харагдах вэ

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//`-ээр эхэлсэн мөрүүд ба хоосон мөрүүдийг үл тооцно. Дээд талд тохиргоонууд байна; дараа нь үйл явдал бүрт нэг `on <event>` блок, `end`-ээр хаагдана. Орхисон үйл явдал юу ч бичихгүй.

| Тохиргоо | Утга |
|---|---|
| `post <id>` | Постын дугаар: үсэг, тоо, `-` ба `_` |
| `name <text>` | Удирдлагын жагсаалтад харагдах нэр |
| `extension <ext>` | Файлын өргөтгөл: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … `emit` мөр бүрт, эсвэл үгүй |
| `decimal-point yes` / `no` | `10.` `10`-ын оронд (тайлбар хэзээ ч цэг авахгүй) |
| `canned-cycles yes` / `no` | `no`: нүхүүд нь төлөөлдөг G0/G1 хөдөлгөөнөөр бичигдэнэ |
| `modal <group> <words>` | Бүлгийн үгс (`modal motion G0 G1 G2 G3`) зөвхөн өөрчлөгдөхөд бичигдэнэ |

## Үйл явдлууд

Програмын хувьд тэдгээр дараалалтай ажиллана: `start`; дараа нь үйлдэл бүрт `operation`, `tool-change` (хэрэгсэл солигдоход), `spindle` (хурд өөрчлөгдөхөд), `approach` (эхний цэг хүртэл хөдөлгөөн, эхний шилжилтийн өмнө), `coolant-on`, дараа нь хөдөлгөөнүүд `rapid`, `feed` ба `arc` хэлбэрээр, мөн мөчлөг бүр `cycle-start`, нүх бүр дээр `cycle-hole` ба `cycle-end`; эцэст нь `end`.

Гурван тэнхлэгээс давсан зүйлд нэмэлт үйл явдлууд (ийм програмыг үйл явдал дутуу пост татгалзаж, дутагдаж буй үйл явдлын нэрийг нэрлэнэ):

| Үйл явдал | Хэзээ | Хувьсагчид |
|---|---|---|
| `index` | Хэрэгслийн чиглэл өмнөхөөсөө ялгаатай үйлдлийн өмнө, эргэлтийн тэнхлэгтэй машин дээр эхний үйлдлийн өмнө | `rot.a`, `rot.b`, `rot.c` (очих байрлал; машинд байхгүй тэнхлэгийн хувьд хоосон), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | Огтлолын үед эргэлтийн тэнхлэгүүд хөдөлдөг үйлдлийн хөдөлгөөнүүд | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (тэжээл урвуу цаг байх ёстой үед тийм), `invf` (1/минут) |
| `rotary-end` | Ийм үйлдлийн дараа | |
| `probe-move` | Мэдрэгч унтрах үед зогсох хөдөлгөөн | `x`, `y`, `z`, `f`, `probe.n` (1-ээс 4), `probe.axis` (x, y эсвэл z), `probe.k` (1, 2 эсвэл 3) |
| `probe-set` | Нэг мэдрэгчийн мөчлөгийн хүрсний дараа | `probe.kind` (`"z"`, `"x"`, `"y"` эсвэл `centre`), `probe.action` (`set` эсвэл `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | Токарь дээр утаслах хөдөлгөөн | `x`, `z`, `thread.lead` |

Мөн үйл явдал бүрт: `kin` (none, a, b, ac, bc), `rotary` ба `tcp` (yes эсвэл no, Тохиргоон дахь машинаас), `pivot.x`, `pivot.y`, `pivot.z`, үйлдлийн `op.tilt` ба `op.turn`, токарь дээр `spin.mode` (css эсвэл rpm), `spin.css`, `spin.max` ба `tool.nose`. Утга нь хоосон үгийн хувьд, жишээ нь A тэнхлэггүй машин дээр `A{rot.a}`, мөрнөөс гардаг. Хашилтанд текстийн хувьд x, y, z-тэй харьцуул (`if probe.kind == "z"`): хашилтгүйгээр тэд хөдөлгөөний координат байна.

Постын дээд талд хоёр мөр нэмбэл түүнийг токарийн пост болгоно: `machine lathe` (энэ нь зөвхөн X ба Z бичих, милл замыг милл пост татгалзах шиг токарийн замыг татгалзана) ба `lathe-x diameter` эсвэл `lathe-x radius`.

Үйл явдал бүр өөрийн төрлийн хөдөлгөөний хувьсагчдыг ашиглаж болно, `{name}` гэж бичигдэнэ: програм (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), түүхий эд (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), хэрэгсэл (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), үйлдэл (`op.name`, `op.type`), `rpm`, хөдөлгөөний цэг (`x`, `y`, `z`, `f`, ба `moved`: тэнхлэг өөрчлөгдсөн бол үнэн), нумууд (`arc.g` 2 эсвэл 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) ба нүхнүүд (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Засварлагчийн **Үйл явдал ба хувьсагчид** жагсаалт аль үйл явдал аль нь харснийг харуулна. Унших ба тохируулж болох төлөв: `cool`, `offset`, ба `at.x`, `at.y`, `at.z`, `at.f` (сүүлд бичсэн утгууд).

## Мэдэгдлүүд

| Мэдэгдэл | Юу хийдэг |
|---|---|
| `raw TEXT` | Яг бичсэнээр мөр (мөрийн дугаар үгүй) |
| `comment TEXT` | `(TEXT)` ASCII бус тэмдэгт ба хаалтыг хасна |
| `emit WORD WORD …` | Үгсийн мөр; хоосон гарах үгийг хасна; үг байхгүй бол мөр байхгүй |
| `word WORD …` | Бүтээгдэж буй мөрөнд үг нэмнэ; зөвхөн `emit` мөрийг дуусгана |
| `if EXPR` … `else` … `end` | Нөхцөл: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, эс бөгөөс b) |
| `for tool in tools` … `end` | Програмын ашигласан хэрэгсэл бүрт нэг удаа |
| `set NAME EXPR` | Утга санах (`set offset tool.number`) |
| `reset NAME …` | Модаль үгсийг мартах (бүлэг, `Z` гэх мэт хаягийн үсэг, эсвэл `at.z`) |
| `do rapid X Y Z` | Цэгт `rapid` үйл явдлыг ажиллуулах |

Үг бол `{variable|filter}` нүхтэй бичигдсэн текст. Шүүлтүүрүүд: `upper`, `lower`, `pad:N` (тэгээр дүүргэх), `cut:N` (эхний N тэмдэгт), `safe` (тайлбарт аюулгүй ASCII) ба `int`. `~`-ээр төгссэн үг нь **модаль**: сүүлд бичсэнээсээ ялгаатай үед л бичигдэнэ (`G1~`, `X{x}~`). `~!`-ээр төгссэн үг нь үргэлж бичигдэж, мөн санагдана. Хувьсагч биш нэр нь энгийн текст (`G81`, `mist`). Тоонууд 0.001 мм хүртэл дугуйлагдаж, араас тэг бичигдэхгүй.

## Пост юу хийж чадахгүй вэ

Энэ нь зөвхөн хөдөлгөөнүүд хэрхэн бичигдэхийг шийддэг, өөр юу ч биш. Энэ нь хэрэгслийн замыг өөрчилж чадахгүй, үйлдлүүдийг дараалуулж чадахгүй, нумыг хуваах, тэнхлэг нэмэх, таны машины явах зай эсвэл кинематикийг мэдэх, эсвэл координатуудын арифметик хийх (`+` байхгүй). Эргэлтийн байрлалууд нь Тохиргоонд тайлбарласан машинаас гардаг, постоос биш: пост тэдний тэмдэг эсвэл үсгийг өөрчилж болно, кинематикийг өөрчилж чадахгүй. Хэрэгслийн амьдрал ба дэд програмын мөчлөгүүд бүтээгээгүй. Өөр програмын `.cps` маягийн пост файлыг ачаалах боломжгүй: энэ бол өөр, илүү энгийн формат.
