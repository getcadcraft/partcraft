## Та юу хийх вэ

**Эд ангийн бүх хэмжээг нэг дор** өгнө: тохиргоо бүрт нэг STEP, IFC, DWG файл ба зураг, тус бүр юу болохыг харуулсан хүснэгт, мөн бүгдийг нэг хуудсанд харуулах номын сангийн зүйл.

Танд эхлээд **тохиргоотой** эд анги хэрэгтэй (см. [Тохиргоо ба дизайны хүснэгтүүд](topic:design-tables)). Онцлогийг унтрааж байгаа тохиргоо, жишээ нь нүхгүй ба нүхтэй ялтас, өөрийн хувилбар болно.

## Алхмууд

1. Эд ангийг нээнэ үү. {{ui:Parameters}} табан дээрх **Тохиргоонууд**-ыг олно уу.
2. {{ui:Variant pack…}}-г дарна уу.
3. Бүтээх тохиргоонуудыг (бүгд тэмдэглэгдсэн байна) болон бичих файлуудыг тэмдэглэнэ үү: STEP, IFC, DWG, урьдчилсан харагдац, номын сангийн зүйл.
4. {{ui:Make the pack}}-г дарна уу. Статус мөр хувилбаруудыг бүтээхэд тоолно; таны эд анги өөрчлөгдөхгүй.
5. Нэг zip татагдана: `<part> variants.zip`.

## Zip-д юу байдаг вэ

| Файл | Юу вэ |
|---|---|
| `<name>.step` | Тохиргоо STEP солид хэлбэрээр. |
| `<name>.ifc` | IFC4, нэг элемент бүтээсэн бие ба эд ангийн параметрүүд шинж чанар болгон; утга нь тухайн тохиргооных. |
| `<name>.dwg` | Урд, дээд, баруун ба изометрийн харагдац бүтэн хэмжээтэй зургийн хуудас болгон. |
| `<name>.svg` | Түүний изометрийн шугаман зураг. |
| `variants.csv`, `variants.json` | Параметрийн хүснэгт: хувилбар бүрийн id, нэр, параметр бүрийн утга, унтраадаг онцлогууд, файлууд, эзэлхүүн, хэмжээ. |
| `<part>.item.json` | Эд анги хувилбаруудтайгаа нэг номын сангийн зүйл болгон (доор үз). |
| `README.txt` | Юу бүтсэн, доорх тэмдэглэлүүд, бүтээгдээгүй зүйлс. |

Файлууд тохиргооны нэрээр нэрлэгдэнэ. Бүтээж чадаагүй тохиргоо (тэр утгаар хийгдэх боломжгүй онцлог) файлууд болон хүснэгтээс хасагдаж, README болон zip хадгалсны дараах мессежид жагсаагдана; бусад нь бичигдэнэ.

## Сайн мэдэх зүйлс

- **STEP** нь таны бүтээлд нарийн цөм идэвхтэй байвал нарийн байна. Үгүй бол STEP фасеттэй (хавтгай гурвалжнууд) байх ба README үүнийг хэлнэ.
- **DWG** нь 3D загвар биш, зургийн хуудас. Түүний шугамууд торноос гардаг тул муруй ирмэг нь олон богино шугам болно.
- **Номын сангийн зүйл** нь хувилбар бүрт нэг бие ба нэг суурьтай, номын сангийн өөрийн тэнхлэгт: Z дээш, урд тал нь −Y рүү, оруулах цэг нь доод талын арын дундах хэсэг. Төлөвлөгөө нь хувилбар бүрийн хүрээлэх тэгш өнцөгт. Зүйл 8 МБ-аар хязгаарлагдана, тиймээс маш хүнд хувилбар нь өөрийн хэмжээтэй хайрцаг болж, README хэдэн ширхэг болсныг хэлнэ.
- Эд ангийн идэвхтэй тохиргоо нь зүйлийн анхдагч хувилбар болно.
- Портууд (хоолой, сувгийн холболтын цэгүүд) PartCraft-аас тохирохгүй.

## Хувилбаруудыг номын сангийн хуудсанд байрлуулах

`<part>.item.json`-оо сайтын **Номын сан › Байршуулах** хэсэгт оруулна уу. Ангилал, лиценз, зохиогчийн тэмдэглэлээ сонгоно уу, тэгвэл энэ нь хувилбаруудтайгаа нэг номын сангийн зүйл болно. BimCraft-д байрлуулахад аль хувилбарыг авахыг асуух ба Swap нь бусдыг санал болгоно. Зочдод сонголт хийх, 3D харах, хувилбар татах хуудас одоохондоо **ажилтны урьдчилсан харагдац** бөгөөд нийтэд нээлттэй биш.

## Командын мөрөөс

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` нь тохиргоонуудыг нэрлэнэ, `--formats` нь `step`, `ifc`, `dwg`, `preview`-ийн аль нэгийг, `--no-item` нь номын сангийн зүйлийг орхино. Энэ нь хавтас, zip эсвэл хоёуланг бичиж, хувилбар бүтээж чадаагүй үед 1 кодтой гарна. См. [Скриптүүд ба командын мөр](topic:scripts-and-cli).
