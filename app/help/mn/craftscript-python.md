Python бол [Скриптийн ажлын талбар](topic:craftscript)-ын гурав дахь хэл юм. Засварлагчийн дээрх хэлний хайрцагт **Python**-г сонгоно (`.py` файл нь өөрөө Python-оор нээгдэнэ). Python, Lua ба CraftScript нь ижил хувьсагч ба ижил суурилуулсан функцүүдийг хуваалцдаг тул Python скрипт CraftScript скриптийн үүсгэсэн зүйлийг ашиглаж чадна, эсрэгээр ч мөн адил.

Зочлолын эхний Python ажиллуулалт нь Python-ийг өөрийгөө (CPython 3.14, ойролцоогоор 7 МБ) энэ сайтаас ачаалдаг бөгөөд хэдхэн секунд үргэлжилдэг. Python одоогоор {{ui:Офлайнд хадгалах}}-ын нэг хэсэг биш: эхлээд нэг Python скриптийг онлайнд ажиллуул.

## Python тусгаарлагдсан байдаг

Python скриптүүд CraftScript ба Lua скриптүүдтэй адил тусгаарлагдсан: тэд эд анги, хувьсагчид, суурилуулсан функцүүдэд л хүрнэ, өөр юу ч биш. Гүйлт бүр санах ойд хадгалагдсан жижиг файлын модтой (стандарт сан ба гүйлтийн дараа устдаг `/tmp` хавтас) өөрийн хайрцагтай шинэ Python юм. Сүлжээ, таны файлууд эсвэл хуудасны бусад хэсэгт хүрч чадахгүй, браузерт ч, командын мөрөнд ч. Бусдын скрипт их цаг эсвэл санах ой ашиглаж болно: {{ui:Зогсоох}} дарснаар зогсооно.

## Үндэс

```
A = cs.magic(3)              # суурилуулсан функц бүр cs.<нэр>
B = A @ A.T                  # @ нь матрицын үржвэр, .T нь транспоз
C = A * 2 + 1                # + - * / ** нь numpy-ийн адил элемент бүрээр
print(A[0, 1], A[-1, -1])    # 0-ээс эхэлнэ; сөрөг нь төгсгөлөөс тоолно
row = A[1]                   # матриц дээрх нэг индекс: мөр
big = A[A > 4]               # логик маск элементүүдийг сонгоно
A[0, 0] = -5                 # массивт утга оруулах
V, D = cs.call('eig', 2, A)  # хэд хэдэн үр дүн: cs.call(нэр, хэдэн ширхэг, …)
```

- 1 × 1 массив нь энгийн тоо болж ирнэ; бусад массив, сийрэг матриц, тор, талбар ба загварууд нь **Утга** болно.
- Утга нь `shape` (tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (мөрийн тоо), мөн нэг элементийн `float()`, `int()` ба `bool()`-тай.
- Харьцуулалт (`<`, `==`, …) нь numpy-ийн адил элемент бүрээр; логик утга өгнө.
- Суурилуулсан функцэд өгсөн тооны жагсаалт массив болно: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` матриц үүсгэнэ.
- dict нь struct, холимог жагсаалт нь cell болно, мөн буцаж.

Таны скриптийн үүсгэсэн глобал бүр (тоо, Утга, dict, жагсаалт…) алдаа гарсан ч гүйлт дуусахад **Хувьсагчид** таб руу очно. `_`-ээр эхэлсэн нэрүүд, функцууд, классууд ба модулиуд Python дотор үлдэнэ. `ws.name` хувьсагчийг шууд уншина эсвэл тохируулна, `ws_names()` тэдгээрийг жагсаана.

`print(…)` консол руу бичнэ. `display(…)` (эсвэл `cs.display`) тор, талбар эсвэл графикийг харуулна, CraftScript-тэй адил.

## Шинжилгээний номын санг дуудах

Номын сангийн функцүүдийг суурилуулсан функцүүдийн адил дуудна: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Нэрийг скриптэд яг бичнэ: PartCraft ажиллахаас өмнө скриптийн ашигладаг номын сангийн функцүүдийг олдог.

## Одоогоор байхгүй зүйлс

- numpy, scipy болон бусад багцууд: зөвхөн Python-ийн өөрийн стандарт сан (`math`, `json`, `itertools`, `decimal`, `statistics`…) байгаа; цонх, терминал, өгөгдлийн сангийн хэсгүүд (`tkinter`, `curses`, `sqlite3`) байхгүй.
- Сокет ба гадагш гарах бусад зүйл: Python-д энд сүлжээ байхгүй.
- `time.sleep` шууд буцна.
- Редактор дахь нугалалт, мөн Python функцийг CraftScript скриптээс дуудах.
- Гүйлт зааврын төсвийг ба Зогсоохыг 1000 мөр тутамд шалгана; нэг суурилуулсан функцийн дотор урт тооцоолол эхлээд дуусна.
