Lua бол [Скриптийн ажлын талбар](topic:craftscript)-ын хоёр дахь хэл юм. Засварлагчийн дээрх хэлний хайрцагт **Lua**-г сонгоно (`.lua` файл нь өөрөө Lua-аар нээгдэнэ). Lua ба CraftScript нь ижил хувьсагч ба ижил суурилуулсан функцүүдийг хуваалцдаг тул Lua скрипт CraftScript скриптийн үүсгэсэн зүйлийг ашиглаж чадна, эсрэгээр ч мөн адил.

## Үндэс

```
-- суурилуулсан функц бүр cs хүснэгтэд байна
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-ээс эхэлнэ, CraftScript-тэй адил
print(K(1, 1), #K)             -- нэг элемент; элементийн тоо

-- ажлын талбар: скрипт бүрт харагддаг ижил хувьсагчид
ws.total = K(1, 1) * 2
print(ws.total)

-- нэг функцээс хэд хэдэн үр дүн
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<нэр>(…)` ямар ч суурилуулсан функцийг дуудаж, эхний үр дүнг буцаана; `cs.call(нэр, n, …)` нь `n` үр дүн буцаана.
- `cs.tensor({1, 2, 3})` мөр, `cs.tensor({{1, 2}, {3, 4}})` матриц үүсгэнэ.
- Массив, сийрэг матриц, тор ба талбарууд нь аргуудтай утгууд байна: `t(i, j)` эсвэл `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (транспоз), `t:totable()`. `+ - * / ^` нь CraftScript-д юу гэсэнтэй адил утгатай (`*` нь матрицын үржвэр); `t:times(u)` нь элемент бүрээр үржүүлнэ.
- 1×1 массив нь энгийн Lua тоо болж ирнэ.
- `ws.name` хуваалцсан ажлын талбарыг уншина ба бичнэ. Скриптийн үлдээсэн глобал хувьсагчид скрипт дуусахад мөн тэнд очно.
- `print(…)` консол руу бичнэ; `cs.show(f)`, `cs.plot(y)` ба бусад харуулах функцүүд CraftScript-тэй адил ажиллана.

## Шинжилгээний номын санг дуудах

Шинжилгээний номын сангийн функцүүд (Номын сан таб) ба таны эд ангийн скриптүүдийн тодорхойлсон CraftScript функцүүд мөн `cs`-ээр хандагдана:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- хоёр гаралт
```

Тэдгээрийг скрипт эхлэхээс өмнө олдог тул нэрийг скриптэд яг бичнэ: `cs.static_tet(` эсвэл `cs.call('static_tet', …)`. Гүйлтийн явцад бүрддэг нэр зөвхөн суурилуулсан функцүүдэд хүрнэ. `cs.struct({ … })`-ээр бүтээсэн struct нь CraftScript struct бөгөөд тэдгээрийн Lua жагсаалт (`{ cs.struct(…), … }`) нь cell болно — номын сангийн тохиргоонд шаардлагатай байдаг. Номын сангийн функц дотор ямар нэг зүйл буруу болбол мессеж функцийг ба мөрийг нь нэрлээд, таны дуудсан мөрийг заана.

## Унтраасан зүйлс

Скриптүүд файл, сүлжээ, хуудсанд хүрч чадахгүй: `io`, `os` (цагаас бусад), `require`, `dofile`, `loadfile` ба `debug` нь устгагдсан. Өгөгдлөө оруулахдаа скриптийн {{ui:Нээх}} ба хувьсагчдыг ашиглана. Алхмын төсөв ба Зогсоох нь CraftScript-тэй адил ажиллана.
