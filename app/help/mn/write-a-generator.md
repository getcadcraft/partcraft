Генератор бол толгой хэсэгтээ цөөн тооны тайлбар мөртэй энгийн скрипт ([CraftScript](topic:craftscript), Lua эсвэл Python). PartCraft тайлбар мөрүүдийг уншаад маягтыг үүсгэнэ; таны скрипт оролтуудыг аль хэдийн тохируулагдсан хувьсагч мэт уншина.

## Толгой хэсэг

Эдгээрийг тайлбар мөрөнд бичнэ (CraftScript-д `%`, Lua-д `--`, Python-д `#`):

```
% @generator Дулаан солилцогч
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Массын урсгал"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Гадаргуу"
% @input solid: = true
% @input note: = "text"
```

Оролт нь `name: unit = default` хэлбэртэй бичигдэнэ, дараа нь заавал биш байдлаар муж `[min .. max]` (тоонууд түүний дотор байна), сонголтуудын жагсаалт `{a, b, c}` болон хашилтад бичсэн шошго орно. Нэгж нь зөвхөн маягтад зориулсан шошго юм: **утга нь тэр нэгжээр ирнэ**, тиймээс SI хэрэгтэй скрипт үүнийг хөрвүүлнэ. Мөн `to_si(value, 'kg/s', 'kg/s')` нь нэгж таны бодсон зүйлийг илэрхийлж байгаа эсэхийг шалгана. Нэр нь үсэг, цифр, доогуур зураасаас бүрдэнэ; `body`, `sheet` болон `problems` нэрүүд аль хэдийн эзлэгдсэн байна.

## Скриптийн үлдээх зүйлс

| Хувьсагч | Юу вэ |
|---|---|
| `body` | **Заавал.** Гадаргуугийн тор, ихэвчлэн `[body, info] = to_body(field, h)`-аас. Ажил дуусахад засварлагдаж, шалгагдана. |
| `sheet` | Заавал биш. Бүтэц: талбар бүр тоо эсвэл текст, эсвэл `value`, `unit`, `ref` болон `note`-тай бүтэц. Энэ нь өгөгдлийн хуудас болно. |
| `problems` | Заавал биш. `mfg_check(field, 'sls', struct(), h)`-ийн `problems` эс, эсвэл таны өөрийн оруулгууд. Эдгээр нь шалгалт болон Асуудлын жагсаалт руу очно. |

## Бүрэн жижиг жишээ

```
% Ханатай хоосон куб.
% @generator Хоосон куб
% @input side: mm = 12 [4 .. 40] "Тал"
% @input wall: mm = 1.5 [0.5 .. 5] "Хана"
% @input h: mm = 0.5 [0.25 .. 2] "Воксел хэмжээ"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'торын');
```

Энэ нь битүү хайрцаг үүсгэх бөгөөд шалгалт нь түүний битүү дотоод хэсгийг нунтаг процессд алдаа гэж мэдээлнэ. Воксел хэмжээ `h`-г хүссэн хамгийн нимгэн хананы гуравны нэгээс хэтрүүлэхгүй байлга: гурван вокселээс бага хана найдвартай биш.

## Талбарууд

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (профайлаас эргэлтийн бие), `tpms` (гироид, Шварцын P болон диамонд гадаргуу; эсийн хэмжээ ба хана эд ангийн дагуу өөрчлөгдөж болно), `lattice` ба `lattice_beams` (тор), `along` (замын дагуух дугуй суваг), булийн үйлдлүүд `field_union`, `field_intersect`, `field_subtract`, зөөлөн `field_blend`, мөн `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` цэгүүд дээрх signed distance-ийг өгнө (дотор нь сөрөг), `field_voxel` нь солверуудад зориулсан воксель өгнө. [Талбарууд](topic:fields) нь тэдгээр юу болохыг тайлбарлана.

Анхаарах хязгаарууд: хуудас хана эсийн дөрөвний нэгээс зузаан бол суваг хаагдана; вокселийн гурваас бага хэмжээтэй онцлог шахагдаж болно; `along` дугуй конусуудыг холбодог тул радиус хурдан өөрчлөгдвөл бөмбөлөг үүснэ (профайлд `field_revolve`-ийг ашигла).

Генераторыг энэ хөтөч дээр хадгална (20 хүртэл), {{ui:Remove}} нь түүнийг хасна. Түүнээс эхэлсэн бие нь скриптийн хуулбарыг агуулдаг тул эд анги түүнээс хамаарахгүй.

Файл нь хэд хэдэн генератор агуулж болно: JSON багц `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
