Lua — [Скрипт жумушчу аймагынын](topic:craftscript) экинчи тили. Редактордун үстүндөгү тил кутучасынан **Lua** тандаңыз (`.lua` файл өзү Lua'да ачылат). Lua жана CraftScript бирдей өзгөрмөлөрдү жана бирдей курулган функцияларды бөлүшөт, ошондуктан Lua скрипти CraftScript скрипти жараткан нерсени колдоно алат, жана тескерисинче.

## Негиздер

```
-- ар бир курулган функция cs таблицасында
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1ден башталат, CraftScript сыяктуу
print(K(1, 1), #K)             -- элемент; элементтердин саны

-- жумушчу аймак: ар бир скрипт көргөн бирдей өзгөрмөлөр
ws.total = K(1, 1) * 2
print(ws.total)

-- бир функциядан бир нече натыйжа
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` каалаган курулган функцияны чакырат жана анын биринчи натыйжасын кайтарат; `cs.call(name, n, …)` `n` натыйжаны кайтарат.
- `cs.tensor({1, 2, 3})` сапты, `cs.tensor({{1, 2}, {3, 4}})` матрицаны жасайт.
- Массивдер, сейрек матрицалар, сеткалар жана талаалар ыкмалары бар маанилер болуп саналат: `t(i, j)` же `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (транспонирлөө), `t:totable()`. `+ - * / ^` CraftScript'тегидей мааниде (`*` матрица көбөйтүүсү); `t:times(u)` элемент-элемент көбөйтөт.
- 1×1 массив жөнөкөй Lua саны болуп келет.
- `ws.name` бөлүшүлгөн жумушчу аймакты окуйт жана жазат. Скрипт калтырган глобалдык өзгөрмөлөр скрипт аяктаганда ошол жерге да түшөт.
- `print(…)` консолго жазат; `cs.show(f)`, `cs.plot(y)` жана башка көрсөтүү функциялары CraftScript'тегидей иштейт.

## Анализ китепканасын чакыруу

Анализ китепканасынын функциялары (Китепкана өтмөгү) жана деталдын өз скрипттери аныктаган CraftScript функциялары да `cs` аркылуу жеткиликтүү:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- эки чыгаруу
```

Алар скрипт башталганга чейин табылат, ошондуктан атты скриптте так жазыңыз: `cs.static_tet(` же `cs.call('static_tet', …)`. Скрипт иштеп жатканда курулган аттар гана жетет. `cs.struct({ … })` менен курулган struct — CraftScript struct, ал эми Lua тизмеси алардан (`{ cs.struct(…), … }`) уячейка болот, китепкана жөндөөлөрү ушуну күтөт. Китепкана функциясынын ичинде бир нерсе туура эмес болсо, билдирүү функцияны жана анын сабын атап, сиздин чакырган сабыңызды көрсөтөт.

## Өчүрүлгөн

Скрипттер файлдарга, тармакка же баракка жете албайт: `io`, `os` (сааттан башкасы), `require`, `dofile`, `loadfile` жана `debug` алынып салынган. Маалыматты киргизүү үчүн скрипт жумушчу аймагынын Ачуу жана өзгөрмөлөрүн колдонуңуз. Кадам бюджети жана Токтотуу CraftScript'тегидей иштейт.
