CraftScript — MATLAB сыяктуу окулуучу матрица тили, ошондуктан классикалык сандык коддордун көпчүлүгү (мисалы, 88 сызыктуу топологиялык оптималдаштыруу коду) кичине гана өзгөртүүлөр менен иштейт. Ал [Скрипт жумушчу аймагында](topic:craftscript) жана буйрук сабынан иштейт.

## Маанилер

| Түрү | Мисал | Эскертүү |
|---|---|---|
| Сан, массив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Ар бир сан массив (1×1). Массивдер мамыча боюнча сакталат, 8 өлчөмгө чейин |
| Логикалык | `A > 2`, `true` | true/false массивдери; индекс катары колдонулат |
| Текст | `'beam'`, `"beam"` | |
| Сейрек матрица | `sparse(i, j, v, n, n)` | Катуулук матрицалары үчүн |
| Сетка, талаа, модель | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` эмнени чийет |
| Struct | `s.E = 210e3` | Аталган талаалар |
| Cell | `c = {1, 'two', [3 4]}` | Каалаган маанилердин тизмеси |
| Функция маркери | `f = @(x) x.^2` | |

## Массивдер жана индекстөө

- Диапазондор: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индекстөө 1ден башталат: `A(2, 3)`, `v(end)`, `A(:, 1)` (бүтүн мамыча), `A(:)` (баары бир мамыча катары), `v(v > 0)` (логикалык индекстөө).
- Аягынан ашык маани берүү массивди чоңойтот, MATLAB сыяктуу: `v(10) = 1`.

## Операторлор

- `+ - * / \ ^` матрица амалдары (`A \ b` чечет); `.* ./ .^` элемент-элемент менен иштейт. `'` транспонирлейт.
- Салыштыруулар `== ~= < <= > >=`; логика `& | ~` (элемент-элемент) жана `&& ||` (кыска туташуу).

## Башкаруу агымы жана функциялар

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функциялар скрипттин командаларынан кийин жазылат же функциянын атындагы өз скрипт өтмөгүнө жазылат:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Аты төмөнкү тартипте издеп табылат: өзгөрмө, ушул деталдагы ушул аттагы скрипт, китепкана функциясы, курулган функция.

## Эхо, комментарийлер, чыгаруу

- `;` жок оператор анын маанисин басып чыгарат; `;` аны унчукпай кармайт.
- `%` комментарийди баштайт; өз сабында турган `%{` жана `%}` алардын ортосундагы саптарды комментарийге алат.
- `disp(x)`, `fprintf('%g\n', x)` жана `display(x)` консолго чыгарат.

## Каталар жана чектөөлөр

- Каталар не болгонун жөнөкөй сөздөр менен айтат жана сапты (жана функция чакырууларынын чынжырын) көрсөтөт.
- Ар бир иштетүүнүн кадам бюджети бар (панелдеги **Иштетүү параметрлери**); чексиз цикл билдирүү менен токтойт же Токтотуу басылат.
- Ар бир массив 134 миллионго чейин маани кармайт.

## MATLAB'дан айырмасы

- График буйруктары опцияларын чакырууга жазат: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` жана ушул сыяктуулар кабыл алынат, бирок эч нерсе кылышпайт.
- `input` жана `keyboard` колдоого алынбайт: скрипт суроо үчүн токтой албайт.
- Куралдар топтому жок; жеткиликтүү нерселер — [анализ китепканасы](topic:craftscript-library) жана курулган функциялар.
