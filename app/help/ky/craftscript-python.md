Python — [Скрипт жумушчу аймагынын](topic:craftscript) үчүнчү тили. Редактордун үстүндөгү тил кутучасынан **Python** тандаңыз (`.py` файл өзү Python'до ачылат). Python, Lua жана CraftScript бирдей өзгөрмөлөрдү жана бирдей курулган функцияларды бөлүшөт, ошондуктан Python скрипти CraftScript скрипти жараткан нерсени колдоно алат, жана тескерисинче.

Визит учурундагы биринчи Python иштетүүсү Python'дун өзүн (CPython 3.14, 7 MB чамасында) бул сайттан жүктөйт, бул бир нече секундга созулат. Python азырынча {{ui:Оффлайнга сактоо}} курамында эмес: алгач бир Python скриптин онлайнда иштетиңиз.

## Python жабык

Python скрипттери CraftScript жана Lua скрипттери сыяктуу жабык: алар деталга, өзгөрмөлөргө жана курулган функцияларга гана жетет, башка эч нерсеге жок. Ар бир иштетүү жабык чөйрөдө өз жаңы Python'у болот, эс тутумдагы кичине файл дарагы менен (анын стандарттуу китепканасы жана иштеткенден кийин жок болуп кеткен `/tmp` папкасы). Ал тармакка, сиздин файлдарыңызга же баракчанын калган бөлүгүнө жете албайт, браузерде да, буйрук сабында да. Башка адамдын скрипти дагы көп убакытты же эс тутумду колдонушу мүмкүн: {{ui:Токтотуу}} аны токтотот.

## Негиздер

```
A = cs.magic(3)              # ар бир курулган функция cs.<name>
B = A @ A.T                  # @ матрица көбөйтүүсү, .T транспонирлөө
C = A * 2 + 1                # + - * / ** элемент-элемент, numpy сыяктуу
print(A[0, 1], A[-1, -1])    # 0дөн башталат; терс сан аягынан эсептелет
row = A[1]                   # матрицанын бир индекси: сап
big = A[A > 4]               # логикалык маска элементтерди тандайт
A[0, 0] = -5                 # массивге маани коюу
V, D = cs.call('eig', 2, A)  # бир нече натыйжа: cs.call(аты, канча, …)
```

- 1 × 1 массив жөнөкөй сан болуп келет; башка массивдер, сейрек матрицалар, сеткалар, талаалар жана моделдер **Маанилер** болуп саналат.
- Маани `shape` (кортеж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (анын саптары), жана бир элемент үчүн `float()`, `int()` жана `bool()` ээ.
- Салыштыруулар (`<`, `==`, …) numpy сыяктуу элемент-элемент: логикалык Маани берет.
- Курулган функцияга берилген сандардын тизмеси массивге айланат: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` матрица жасайт.
- Dict struct болот, аралаш нерселердин тизмеси уячейка болот жана кайра.

Скрипт жараткан ар бир глобалдык (сан, Маани, dict, тизме…) иштетүү аяктаганда **Өзгөрмөлөр** өтмөгүнө түшөт, ката болсо дагы. `_` менен башталган аттар, функциялар, класстар жана модулдар Python ичинде калат. `ws.name` өзгөрмөнү түз окуйт же коёт, `ws_names()` алардын тизмесин берет.

`print(…)` консолго жазат. `display(…)` (же `cs.display`) сеткаларды, талааларды же графиктерди CraftScript'тегидей көрсөтөт.

## Анализ китепканасын чакыруу

Китепкана функциялары курулган функциялар сыяктуу чакырылат: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Атты скриптте так жазыңыз: PartCraft скрипт иштетилгенге чейин колдонулган китепкана функцияларын табат.

## Азырынча жок

- numpy, scipy жана башка пакеттер: Python'дун өз стандарттуу китепканасы гана бар (`math`, `json`, `itertools`, `decimal`, `statistics`…), терезелер, терминал жана базанын бөлүктөрү (`tkinter`, `curses`, `sqlite3`) жок.
- Сокеттер жана тышка чыга турган башка нерселер: Python бул жерде тармаксыз.
- `time.sleep` дароо кайтат.
- Редакторду бүктөө (folding), жана CraftScript скриптинен Python функциясын чакыруу.
- Иштетүү ар 1000 саптан кийин нускама бюджетин жана Токтотууну текшерет; бир курулган функциянын ичиндеги узак эсеп алгач бүтөт.
