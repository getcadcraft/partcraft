## Эмне кыласыз

Детальдын **бардык өлчөмдөрүн бир учурда** берип коюңуз: ар бир конфигурация үчүн бир STEP, IFC жана DWG файлы жана сүрөт, ар биринин эмне экенин айтуучу таблица жана баарын бир бетке коёт китепкана буюму.

Адегенде **конфигурациялары** бар деталь керек (караңыз: [Конфигурациялар жана долбоор таблицалары](topic:design-tables)). Элементти өчүрүүчү конфигурация, мисалы тешиктери бар жана жок пластина, өзүнчө вариант болот.

## Кадамдар

1. Деталды ачыңыз. {{ui:Параметрлер}} өтмөгүндө **Конфигурациялар** бөлүмүн табыңыз.
2. {{ui:Вариант топтому…}} басыңыз.
3. Түзүлүчү конфигурацияларды (баары белгиленген) жана жазыла турган файлдарды белгилеңиз: STEP, IFC, DWG, алдын ала көрүү жана китепкана буюму.
4. {{ui:Топтомду түзүү}} басыңыз. Абал сабы варианттарды түзүлгөн сайын санайт; деталыңыз өзгөрбөйт.
5. Бир zip жүктөлөт: `<part> variants.zip`.

## Zip ичинде эмне бар

| Файл | Эмне экенин |
|---|---|
| `<name>.step` | Конфигурация STEP катуу дене катары. |
| `<name>.ifc` | IFC4, түзүлгөн денеси жана деталдын параметрлери касиет катары бар бир элемент; маани ошол конфигурациянын өзүнүкү. |
| `<name>.dwg` | Алдынкы, үстүнкү, оң жана изометриялык көрүнүштөр чийме барагында толук өлчөмдө. |
| `<name>.svg` | Анын изометриялык сызык сүрөтү. |
| `variants.csv`, `variants.json` | Параметрлер таблицасы: ар бир варианттын ID, аты жана ар бир параметрдин мааниси, ал өчүргөн элементтер, анын файлдары, көлөмү жана өлчөмү. |
| `<part>.item.json` | Деталь варианттары менен бир китепкана буюму катары (төмөндөн караңыз). |
| `README.txt` | Эмне түзүлгөнү, төмөнкү эскертүүлөр жана эмне түзүлбөгөнү. |

Файлдар конфигурация боюнча аталат. Түзүлбөй калган конфигурация (ошол маанилер менен жасалбаган элемент) файлдардан жана таблицадан чыгарылат, README'де жана zip сакталгандан кийинки билдирүүдө тизмеленет; калгандары дагы жазылат.

## Билип коюу пайдалуу

- **STEP** так ядро сиздин курулушта күйгүзүлгөндө так болот. Анысыз STEP тилкелүү (жалпак үч бурчтуктар) болот жана README муну айтат.
- **DWG** 3D модель эмес, чийме барагы. Анын сызыктары mesh'тен алынат, ошондуктан ийри кыр көп кыска сызыктан турат.
- **Китепкана буюму** китепкананын өз октору боюнча ар бир вариант үчүн бир дене жана бир тийген аянт камтыйт: Z өйдө, алдынкы жагы −Y тарапка, киргизүү чекити болсо артындагы төмөнкү ортосунда. План ар бир варианттын чектөөчү тик бурчтугу. Буюм 8 MB менен чектелет, ошондуктан өтө оор вариант өлчөмдөгү кутуга айланат жана README канча экенин айтат.
- Деталдын учурдагы конфигурациясы буюмдун демейки варианты болот.
- Порттор (түтүктөр жана аба түтүктөрү үчүн туташуу чекиттери) PartCraft'тан коюлбайт.

## Варианттарды китепкана бетине коюу

Сайттагы **Китепкана › Жүктөө** бөлүмүнө `<part>.item.json` жүктөңүз. Анын категориясын, лицензиясын жана авторлук белгисин тандаңыз, ал варианттары менен китепкана буюмуна айланат. BimCraft'та аны жайгаштырганда кайсы вариант экенин сурайт, ал эми Swap калгандарын сунуш кылат. Келгендер варианттарды тандап, 3D көрүп жана жүктөй турган бет азырынча **кызматкерлерге алдын ала көрүү** катары гана: ал коомчулукка али ачык эмес.

## Буйрук сабынан

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` конфигурацияларды атайт, `--formats` `step`, `ifc`, `dwg`, `preview` аркылуу каалаганын, `--no-item` китепкана буюмун чыгарып салат. Папканы, zip'ти же экөөнү тең жазат жана вариант түзүлбөй калса 1 менен чыгат. Караңыз: [Скрипттер жана буйрук сабы](topic:scripts-and-cli).
