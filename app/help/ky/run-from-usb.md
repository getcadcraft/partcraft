Инженердик куралдар (генераторлор, инженердик китепкана, текшерүүлөр жана маалымат файлдары) **администратор укуктарын** жана **орнотуучуну** талап кылбайт. Алар бул жерде тизмеленген нерселерди гана жазышат, башка эч нерсени эмес.

| Эмне | Кайда сакталат |
|---|---|
| Сиздин деталдарыңыз, алардын түзүлгөн денелери, маалымат барактары жана текшерүүлөр | Сиз сактаган деталь файлы (`.partcraft.json`), сиз аны кайда сактасаңыз ошол жерде. |
| Файлдан ачкан генераторлор | Колдонмонун өз сактагычында: веб баракта браузердин жергиликтүү сактагычы (local storage), портативдүү Studio'до программанын жанындагы `data` папкасында. Эң көбү менен 20. |
| Жөндөөлөр (сиз койгон воксел өлчөмдөрү, чечүүчүнүн агымдары, макет) | Ошол эле колдонмонун сактагычы. |
| Маалымат барактары, талаалар, тор (mesh) | Ал жерде гана, эгер сиз сактасаңыз: жүктөө сиз тандаган жерге барат. |

Куралдар **эч кандай өз тармак чалууларын жасашпайт**: жөнөтүлгөн генераторлор колдонмонун өз папкасындагы файлдар, китепкана жана текшерүүлөр компьютериңизде тармакка кире албаган жумушчу процессте иштешет, ал эми инженердик маалымат (суунун жана аанын касиеттери, материалдар) колдонмонун ичинде. Файлдан ачкан генератор сиздин компьютерде окулат жана эч жакка барбайт.

## Портативдүү Windows zip жана Linux

Windows үчүн портативдүү Studio өзүнүн жөндөөлөрүн, кэштерин жана кошумчаларын программанын жанындагы `data` папкасында сактайт. Linux AppImage алар өзүнүн жанында сакташат, эгерде жанында `portable` деген файл турса; ал файл жок болсо, үйүңүздүн папкасын колдонот. Портативдүү Mac формасы жок: система жүктөлүп алынган колдонмонун өзүнүн жанына жазышына тыюу салат. Studio жардамындагы портативдүү эскертмелер программа эмнелерди жазарын тизмелейт.

## Хост мүмкүнчүлүгү

Бул жерде эч нерсе хост мүмкүнчүлүгүн сурабайт. Принтерлер, сериялык станоктор жана USB түзмөктөр өзүнчө: алар иш керек болгондо сурашат, ар бир түзмөк үчүн бир жолу, ал эми генераторлордо же текшерүүлөрдө эч нерсе аларга тийбейт.
