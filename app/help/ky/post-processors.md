Бир эле инструмент траекториясы ар кандай башкаруу түзмөктөрү үчүн башкача жазылышы керек: саптын номерлери менен же номерсиз, `M6` же тыныгуу, `G28` же `G53`, `M30` же `M2`. **Пост** — ушуну кантип жасоону айткан кыска текст. PartCraft'тын үч орнотулган посту (Fanuc стилиндеги, GRBL жана LinuxCNC) ушул форматта жазылган, ошондуктан өз посту ушулардын бирин көчүрүүдөн башталышы мүмкүн.

Кесүүдөн мурун машинаңыздын өз симуляторунда текшериңиз жана биринчи материалдын үстүндө абада иштетип көрүңүз. Орнотулган посттор бул формат пайда болгонго чейин жазган нерсесин так жазат (тесттер алардын чыгарууларын жүздөгөн программада байт-байттап салыштырат), бирок бул жерде эч нерсе сиздин машинада далилденген эмес, ал эми сиз өзгөрткөн пост — сиздин далилдөөңүз.

## Өз постуңузду жасоо

**Өндүрүш** бөлүмүндө, **Пост** астында:

- Орнотулган башкаруу үчүн {{ui:Постту түзөтүү…}} — **өзүңүздүн көчүрмөңүздү** ачат. Өз постторуңуздун бирине болсо ошол постту ачат.
- {{ui:Жаңы пост…}} — ар бир окуясы бар кичинекей бош постту баштайт.
- {{ui:Пост файлын импорттоо…}} — `.cpost` текст файлын окуйт (редактордагы **Файл катары сактоо…** менен алынган файл).

Редактор текстти, ал окусанын (жана кайсы сап туура эмес экенин) көрсөткөн сапты жана сиз терип жатканда пост жазган G-code'ду көрсөтөт. **Алдын ала көрүү** талаасы ар бир окуяны иштеткен кичинекей үлгү программаны же ушул деталдын өз программасын тандайт. {{ui:Сактоо}} постту деталдын файлында сактайт (20га чейин пост) жана аны башкаруу түзмөгү катары тандайт. Посттор деталь менен бирге жүрөт; аны башка деталда колдонуу үчүн, файл катары сактап, ал жерде импорттоңуз.

## Пост кандай көрүнөт

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` менен башталган саптар жана бош саптар эске алынбайт. Башында орнотуулар турат; андан кийин ар бир окуя үчүн `on <event>` блогу, `end` менен жабылат. Калтырылган окуя эч нерсе жазбайт.

| Жөндөө | Мааниси |
|---|---|
| `post <id>` | Посттун идентификатору: тамгалар, цифралар, `-` жана `_` |
| `name <text>` | Башкаруу тизмесинде көрүнгөн текст |
| `extension <ext>` | Файлдын кеңейтүүсү: nc, ngc, tap … |
| `line-numbers 10` / `off` | Ар бир `emit` сабында `N10`, `N20` … же эч нерсе |
| `decimal-point yes` / `no` | `10.` ордуна `10` (комментарийлерде чекит болбойт) |
| `canned-cycles yes` / `no` | `no`: тешиктер алар билдирген G0/G1 жылдырууларына айландырылат |
| `modal <group> <words>` | Топтун сөздөрү (`modal motion G0 G1 G2 G3`), алар өзгөргөндө гана жазылат |

## Окуялар

Программа үчүн алар бул тартипте иштейт: `start`; андан кийин ар бир операция үчүн `operation`, `tool-change` (инструмент алмашканда), `spindle` (ылдамдык өзгөргөндө), `approach` (биринчи чекитке чейинки жылдыруу, биринчи `rapid` алдында), `coolant-on`, андан кийин анын жылдырууларын `rapid`, `feed` жана `arc` катары, ар бир даяр цикл `cycle-start` катары, ар бир тешик үчүн `cycle-hole` жана `cycle-end`; акырында `end`.

Ар бир окуя өз түрүнүн жылдыруусунун өзгөрмөлөрүн, `{name}` түрүндө колдоно алат: программа (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), запас (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), инструмент (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), операция (`op.name`, `op.type`), `rpm`, жылдыруунун чекити (`x`, `y`, `z`, `f`, жана `moved`: ок өзгөрсө true), аркалар (`arc.g` 2 же 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) жана тешиктер (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Редактордагы **Окуялар жана өзгөрмөлөр** тизмеси ар бир окуянын эмнени көрөөрүн көрсөтөт. Окуп жана коюуга болот: `cool`, `offset`, жана `at.x`, `at.y`, `at.z`, `at.f` (акыркы жазылган маанилер).

## Операторлор

| Оператор | Эмне кылат |
|---|---|
| `raw TEXT` | Сап терилгендей так (саптын номеринсиз) |
| `comment TEXT` | `(TEXT)`, ASCII эмес белгилер жана кашаалар алынып |
| `emit WORD WORD …` | Сөздөрдөн турган сап; бош чыккан сөздөр калтырылат; сөз жок болсо сап да жок |
| `word WORD …` | Түзүлүп жаткан сапка сөздөрдү кошуу; жалгыз `emit` аны аяктайт |
| `if EXPR` … `else` … `end` | Шарттар: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, болбосо b) |
| `for tool in tools` … `end` | Программа колдонгон ар бир инструмент үчүн бир жолу |
| `set NAME EXPR` | Маанини эстеп калуу (`set offset tool.number`) |
| `reset NAME …` | Модалдык сөздөрдү унутуу (топ, `Z` сыяктуу ок тамгасы же `at.z`) |
| `do rapid X Y Z` | Чекит үчүн `rapid` окуясын иштетүү |

Сөз — `{variable|filter}` тешиктери бар терилген текст. Фильтрлер: `upper`, `lower`, `pad:N` (нөл менен толтуруу), `cut:N` (биринчи N белги), `safe` (комментарийге ылайыктуу ASCII) жана `int`. `~` менен аяктаган сөз **модалдык**: ал акыркы жазылгандан айырмаланганда гана жазылат (`G1~`, `X{x}~`). `~!` менен аяктаган сөз ар дайым жазылат жана эсте калат. Өзгөрмө болбогон ат — жөнөкөй текст (`G81`, `mist`). Сандар 0.001 mm га чейин тегеректелип, аягындагы нөлдөрсүз жазылат.

## Пост эмнени кыла албайт

Ал жылдыруулар кандай жазыларын гана чечет, башка эч нерсе эмес. Ал инструмент траекториясын өзгөртө албайт, операцияларды иреттей албайт, аркты бөлө албайт, огун кошо албайт, машинаңыздын жүрүшүн же кинематикасын билбейт, же координаталарга арифметика кыла албайт (`+` жок). Зондлоо, инструменттин жашоосу жана подпрограммалык циклдер, 4- жана 5-огу чыгаруусу, токарлык кодтор түзүлгөн эмес. Башка программанын `.cps` стилиндеги посту жүктөлбөйт: бул башка, жөнөкөй формат.
