Бир эле курал жолун ар кандай башкаруучулар үчүн башкача жазуу керек: сап номерлери бар же жок, `M6` же пауза, `G28` же `G53`, `M30` же `M2`. **Пост** — бул кантип жазууну айткан кыска текст. PartCraft'тын үч даяр посту (Fanuc-style, GRBL жана LinuxCNC) ушул форматта жазылган, андыктан өзүңүздүн постуңуз ушул даяр посттордун бирин көчүрүүдөн башталышы мүмкүн.

Кесүүдөн мурун чыгарылганды машинанын өз симуляторунда текшериңиз жана адегенде заготовканын үстүндөгү абада иштетиңиз. Даяр посттор бул форматтан мурун жазгандай так жазат (тесттер алардын чыгарылышын миңдеген программалар боюнча байт-байт салыштырат), бирок бул жерде эч нерсе станокуңузда далилденген эмес, ал эми өзгөрткөн постуңузду өзүңүз далилдешиңиз керек.

## Бирин жасоо

Өндүрүштө, **Постпроцессор** астында:

- Даяр башкаруучуда {{ui:Постту түзөтүү…}} сиздин өз **көчүрмөңүздү** ачат. Өз постуңузда ал ошол постту ачат.
- {{ui:Жаңы пост…}} кичинекей бош постту баштайт, анда ар бир окуя бар.
- {{ui:Пост файлын импорттоо…}} `.cpost` текст файлын окуйт (редактордогу **Файл катары сактоо…** менен алынган файл).

Редактор текстти, окуй алабы же жокпу (жана кайсы сап туура эмес экенин) айткан сапты жана постун жазган G-code'ду, сиз терип жатканда көрсөтөт. **Мындай алдын ала көрүү** үлгү программаны тандайт, ал ар бир окуяны иштетет, же ушул бөлүктүн өз программасын. {{ui:Сактоо}} постту бөлүктүн файлында сактайт (20га чейин пост) жана аны контроллер катары тандайт. Посттор бөлүк менен бирге жүрөт; аны башка бөлүктө колдонуу үчүн файл катары сактап, ал жерге импорттоңуз.

## Пост кандай көрүнөт

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` менен башталган саптар жана бош саптар эске алынбайт. Башында орнотуулар келет; андан кийин ар бир окуя үчүн `on <event>` блогу, `end` менен жабылат. Сиз калтырган окуя эч нерсе жазбайт.

| Орнотуу | Мааниси |
|---|---|
| `post <id>` | Посттун идентификатору: тамгалар, цифралар, `-` жана `_` |
| `name <text>` | Контроллердин тизмесинде көрүнгөн текст |
| `extension <ext>` | Файлдын кеңейтүүсү: nc, ngc, tap … |
| `line-numbers 10` / `off` | Ар бир `emit` сабында `N10`, `N20` … же эч бири |
| `decimal-point yes` / `no` | `10.` `10` ордуна (комментарийлерде чекит эч качан болбойт) |
| `canned-cycles yes` / `no` | `no`: тешиктер алар билдирген G0/G1 кыймылдары катары жазылат |
| `modal <group> <words>` | Топтун сөздөрү (`modal motion G0 G1 G2 G3`), алар өзгөргөндө гана жазылат |

## Окуялар

Программа үчүн алар бул тартипте иштейт: `start`; андан кийин ар бир операция үчүн `operation`, `tool-change` (курал алмашканда), `spindle` (ылдамдык өзгөргөндө), `approach` (биринчи чекитке жеткен кыймыл, биринчи ылдам жүрүштөн мурун), `coolant-on`, андан кийин анын кыймылдары `rapid`, `feed` жана `arc` катары, ар бир даяр цикл `cycle-start` катары, ар бир тешик үчүн бир `cycle-hole` жана `cycle-end`; акырында `end`.

Үч огудан ашкан нерселер үчүн кошумча окуялар (мындай программаны окуя жок пост четке кагат жана ал жоккон окуянын атын айтат):

| Окуя | Качан | Анын өзгөрмөлөрү |
|---|---|---|
| `index` | Курал багыты мурунку багыттан айырмаланганда, жана айлануучу уктары бар станокто биринчи операциядан мурун | `rot.a`, `rot.b`, `rot.c` (барууга керек позициялар; станокто жок ук үчүн бош), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | Кесип жатканда айлануучу уктары кыймылдаган операциянын кыймылдары | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (берүү тескери убакыт болушу керек болгондо ооба), `invf` (1/минут) |
| `rotary-end` | Ошондой операциядан кийин | |
| `probe-move` | Зонд ишке киргенде токтогон кыймыл | `x`, `y`, `z`, `f`, `probe.n` (1ден 4кө), `probe.axis` (x, y же z), `probe.k` (1, 2 же 3) |
| `probe-set` | Бир зонддоо циклинин тийүүлөрүнөн кийин | `probe.kind` (`"z"`, `"x"`, `"y"` же `centre`), `probe.action` (`set` же `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | Токарьдагы резьбалоо кыймылы | `x`, `z`, `thread.lead` |

Ар бир окуя өз кыймыл түрүнүн өзгөрмөлөрүн колдоно алат, `{name}` түрүндө жазылат: программа (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), заготовка (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), курал (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), операция (`op.name`, `op.type`), `rpm`, кыймылдын чекити (`x`, `y`, `z`, `f`, жана `moved`: ук өзгөргөндө чын), аркалар (`arc.g` 2 же 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) жана тешиктер (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Редактордун **Окуялар жана өзгөрмөлөр** тизмеси кайсы окуя эмнени көрөөрүн көрсөтөт. Окуп жана коюуга боло турган абал: `cool`, `offset`, жана `at.x`, `at.y`, `at.z`, `at.f` (акыркы жазылган маанилер).

## Билдирүүлөр

| Билдирүү | Эмне кылат |
|---|---|
| `raw TEXT` | Сап жазылгандай так (сап номеринсиз) |
| `comment TEXT` | `(TEXT)`, ASCII эмес жана кашаасыз |
| `emit WORD WORD …` | Сөздөрдөн турган сап; бош чыккан сөздөр калтырылат; сөз жок болсо, сап жок |
| `word WORD …` | Түзүлүп жаткан сапка сөздөрдү кошот; жалаң `emit` сапты бүтүрөт |
| `if EXPR` … `else` … `end` | Шарттар: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, болбосо b) |
| `for tool in tools` … `end` | Программа колдонгон ар бир курал үчүн бир жолу |
| `set NAME EXPR` | Маанини эстеп калуу (`set offset tool.number`) |
| `reset NAME …` | Модалдык сөздөрдү унутуу (топ, `Z` сыяктуу адрес тамгасы же `at.z`) |
| `do rapid X Y Z` | Чекит үчүн `rapid` окуясын иштетүү |

Сөз — `{variable|filter}` тешиктери бар терилген текст. Фильтрлер: `upper`, `lower`, `pad:N` (нөлдөр менен толтуруу), `cut:N` (биринчи N белги), `safe` (комментарий үчүн коопсуз ASCII) жана `int`. `~` менен аяктаган сөз **модалдык**: ал акыркы жазылгандан башкача болгондо гана жазылат (`G1~`, `X{x}~`). `~!` менен аяктаган сөз ар дайым жазылат жана эстелип калат. Өзгөрмө болбогон ат жөн текст (`G81`, `mist`). Сандар 0,001 mm чейин тегеректелип, аягындагы нөлдөрсүз жазылат.

## Пост эмне кыла албайт

Ал кыймылдардын жазылышын гана аныктайт, андан ашык эч нерсе эмес. Ал курал жолун өзгөртө албайт, операцияларды иретин өзгөртө албайт, аркаларды бөлө албайт, ук кошо албайт, станоктун жүрүүсүн же кинематикасын билбейт, же координаталарга арифметика жасай албайт (`+` жок). Айлануучу позициялардын өзү Орнотууда сүрөттөлгөн станоктон келет, постто эмес: пост аларды белгисин же тамгаларын өзгөртө алат, кинематиканы эмес. Курал жашоосу жана подпрограмма циклдери курулган эмес. Башка программанын `.cps` стилиндеги пост файлын жүктөө мүмкүн эмес: бул башка, жөнөкөй формат.
