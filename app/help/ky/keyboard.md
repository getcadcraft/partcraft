Панелдеги кутуга текст жазып жатканда баскычтар иштебейт, бирок {{key:Mod+S}} жана {{key:Mod+O}} ар дайым иштейт. Тамга баскычтары модификаторсуз иштейт.

Браузердеги жана функциялык баскычтары жок клавиатуралардагы баскычтар жөнүндө жалпы эскертүүлөр: [Баскычтар, чычкандар жана сенсордук панельдер](common:keys).

## Бардык жерде

| Баскыч | Аракет |
|---|---|
| {{key:Mod+S}} | Деталды сактоо (жыйнакта: жыйнакты). Адегенде ачык эскизди жабат |
| {{key:Mod+O}} | Деталь же жыйнак файлын ачуу (сакталбаган өзгөртүүлөр болсо, адегенде сурайт) |
| {{key:Mod+Z}} | Артка кайтаруу |
| {{key:Mod+Y}} же {{key:Mod+Shift+Z}} | Кайра аткаруу |
| {{key:F1}} | Бул жардамды ачуу же жабуу (ошондой эле тиркеме тилкесиндеги {{ui:Жардам}}). {{key:Esc}} да жабат. Көптөгөн ноутбуктарда жана Mac клавиатураларында Fn басып туруңуз |
| {{key:Ctrl+Shift+F}} | Экран режими: кадимки, толук экран, панелдери жашырылган толук экран. Mac'те да Control, ⌘ эмес |
| {{key:Esc}} | Толук экрандан чыгуу (толук экран режиминде) |
| {{key:Mod+,}} | Жөндөөлөр, анын ичинде PartCraft өтмөгү (см. [PartCraft жөндөөлөрү](topic:settings)) |

Панелдеги сан кутусунда {{key:Mod+Z}} браузердин өз текстти артка кайтаруусу. Эскиздеги өлчөмдүн үстүндөгү сан кутусунда ал PartCraft'та артка кайтарат.

## Көчүрүү, чаптоо жана эки эсе көчүрүү

Алар иштеп жаткан нерсеге таасир этет: ачык эскиздеги тандалган геометрия, тарыхтагы тандалган элемент же жыйнактагы тандалган деталь. Толук маалымат: [Көчүрүү, чаптоо жана эки эсе көчүрүү](topic:copy-paste).

| Баскыч | Аракет |
|---|---|
| {{key:Mod+C}} | Тандалганды көчүрүү |
| {{key:Mod+X}} | Кесип алуу: көчүрүп, андан кийин өчүрүү |
| {{key:Mod+V}} | Чаптоо. Эскизде көчүрмө көрсөткүчтү ээрчийт: барчу жерди басыңыз |
| {{key:Mod+Shift+V}} | Ошол жерге чаптоо: ошол эле координаталар (жыйнакта, ошол эле жер) |
| {{key:Mod+D}} | Эки эсе көчүрүү: бир кадамда көчүрүп чаптоо, буферди өзгөртпөйт |
| {{key:Mod+A}} | Баарын тандоо (эскизде) |
| {{key:Esc}} | Эч нерсени тандабоо (жана көрсөткүчтү ээрчиген чаптоону жокко чыгаруу) |

Сан кутусунда бул баскычтар адаттагыдай текст көчүрөт жана чаптайт. Панелдеги тандалган текстти браузер көчүрөт.

## 3D көрүнүштө

Көрүнүш клавиатура фокусуна ээ болушу үчүн адегенде көрүнүштүн ичин басыңыз.

| Баскыч | Аракет |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Көрүнүштү 15 градуска буруу |
| {{key:Shift+Left}} жана башка жебелер | Жылдыруу |
| {{key:Plus}} же {{key:=}} | Чоңойтуу |
| {{key:Minus}} | Кичирейтүү |

| Чычкан | Аракет |
|---|---|
| Сол баскычты сүйрөө | Көрүнүштү буруу (орбита) |
| Оң же орто баскычты сүйрөө | Жылдыруу |
| {{key:Shift}}, {{key:Ctrl}} же ⌘ кармап, сол баскыч менен сүйрөө | Жылдыруу |
| Дөңгөлөктү айлантуу | Көрсөткүч жанында чоңойтуу (өзүңүздөн алыстасаңыз чоңойот) |
| Сенсордук панелде эки манжа менен сүрүү | Көрүнүштү буруу; {{key:Shift}} менен жылдыруу. Чымчып чоңойтуу. [PartCraft жөндөөлөрүндө](topic:settings) **Сыйпоо** менен тууралайт |

[PartCraft жөндөөлөрүндө](topic:settings) **Көрүнүштү буруу: Орто баскыч** жандырылса, орто баскыч көрүнүштү бурат, {{key:Shift}} менен орто же оң баскыч жылдырат, ал эми сол баскыч гана тандайт.
| Басуу | Бетти тандоо (толук белгиленет), кырды же тегиздикти |
| {{key:Shift}}+басуу кырда же бетте | Бир нече кыр же бетти чогултуу |
| Бош мейкинди басуу | Тандоону тазалоо |

## Браузер алышы мүмкүн болгон кыска жолдор

- {{key:Mod+Y}} Safari'де тарыхты ачышы мүмкүн: кайра аткаруу үчүн {{key:Mod+Shift+Z}} колдонуңуз.
- {{key:Mod+D}} браузердин закладка баскычы: PartCraft аны тиркеме фокуста болгондо алат, ал эми кутуга текст жазганда тийбейт.
- {{key:F11}} жана {{key:Mod+Plus}} / {{key:Mod+Minus}} браузердин толук экраны жана барактын масштабы, PartCraft'тыкы эмес. Толук экран үчүн {{key:Ctrl+Shift+F}}, модель үчүн дөңгөлөк колдонуңуз.
- Көптөгөн ноутбуктар жана Mac'тарда функциялык баскычтарга Fn керек: жардам үчүн Fn+{{key:F1}} басыңыз же {{ui:Жардам}} баскычын колдонуңуз.

Сенсордук жана сенсордук панель жаңсоолору: [Сенсордук панель, сенсордук экран жана кичине экрандар](topic:trackpad-and-touch).

## Жылдыруу кайда жайгашкан

Жылдыруу {{ui:Элементтер}} тобунун {{ui:Дагы}} менюсунда {{ui:Денени жылдыруу}} катары, ΔX, ΔY жана ΔZ териле турган {{ui:Которуу}} кутусунда жана деталдагы {{ui:Жылдыруу үчүн сүйрөңүз}} жебелери катары турат.
