Генератор — бул [CraftScript](topic:craftscript), Lua же Python тилиндеги кадимки скрипт, анын башында бир нече комментарий саты бар. PartCraft ал саптарды окуп, форма жасайт; ал эми сиздин скриптиңиз киргизүүлөрдү даярдан коюлган өзгөрмөлөр катары окуйт.

## Баш бөлүгү

Муларды комментарий саптарына жазыңыз (CraftScript тилинде `%`, Lua тилинде `--`, Python тилинде `#`):

```
% @generator Жылуулук алмаштыргыч
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Масса агымы"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Бет"
% @input solid: = true
% @input note: = "текст"
```

Киргизүү `аты: бирлик = демейки маани` түрүндө жазылат. Анын артынан милдеттүү эмес түрдө диапазон `[min .. max]` (сандар ушул чектердин ичинде сакталат), тандоолордун тизмеси `{a, b, c}` жана тырмакчадагы этикетка берилиши мүмкүн. Бирлик формага болгону этикетка катары гана кызмат кылат: **маани ошол бирликте келет**, ошондуктан SI системасын каалаган скрипт аны түрдөн-түргө которот, ал эми `to_si(value, 'kg/s', 'kg/s')` бирликтин сиз ойлогондой экенин дагы текшерет. Аты тамгалардан, сандардан жана астын сызыктан турат; `body`, `sheet` жана `problems` аттары бекитилген.

## Скрипт калтырган нерселер

| Өзгөрмө | Мазмуну |
|---|---|
| `body` | **Милдеттүү.** Беттик тор, adatta `[body, info] = to_body(field, h)` аркылуу. Иш аяктаганда ал оңдолот жана текшерилет. |
| `sheet` | Милдеттүү эмес. Структура: ар бир талаа сан же текст, же `value`, `unit`, `ref` жана `note` талаалары бар структура. Ал маалымат барагына айланат. |
| `problems` | Милдеттүү эмес. `mfg_check(field, 'sls', struct(), h)` катаары `problems` катаги же өзүңүздүн жазуулар. Алар текшерүүлөргө жана Көйгөйлөр тизмесине барат. |

## Толук кичинекей мисал

```
% Дубалы бар көңдөй куб.
% @generator Көңдөй куб
% @input side: mm = 12 [4 .. 40] "Капталы"
% @input wall: mm = 1.5 [0.5 .. 5] "Дубал"
% @input h: mm = 0.5 [0.25 .. 2] "Воксель өлчөмү"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'тордун');
```

Бул жабык куб жасайт, жана текшерүү анын жабык ичин порошоктук процесс үчүн ката катары көрсөтөт. Воксель өлчөмү `h` сиз каалаган эң жука дубалдын үчтөн биринен ашпасын: үч вокселден азыраак болсо, дубал ишенимдүү эмес.

## Талаалар

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (профиль боюнча айлануу телосу), `tpms` (гироид, Шварц P жана алмаз беттери; клетка өлчөмү жана дубалы бөлүк боюнча өзгөрүшү мүмкүн), `lattice` жана `lattice_beams`, `along` (жол боюнда тегерек канал), булендик операциялар `field_union`, `field_intersect`, `field_subtract`, жумшак `field_blend`, жана `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` чекиттеринде кол арылык аралыкты берет (ичинде терс), `field_voxel` чечүүчүлөр үчүн вокселдерди берет. [Талаалар](topic:fields) алар эмне экенин түшүндүрөт.

Билүүгө татыктуу чектөөлөр: клетканын төрттөн бириненден калың беттик дубал каналдарды жабат; үч вокселден жука элемент кысылып калышы мүмкүн; `along` тегерек конустарды туташтырат, ошондуктан радиус тез өзгөрсө, томпоок калат (профиль үчүн `field_revolve` колдонуңуз).

## Скриптиңизди генератор катары ачуу

{{ui:Инженер}} иш мейкинде {{ui:Ачуу}} баскычын басып, файлды тандаңыз. `@generator` же `@input` сабы жок скрипт кабыл алынбайт: жөндөй турган эч нерсе болбойт. Генератор ушул браузерде сакталат (20гә чейин), ал эми {{ui:Алып салуу}} аны өчүрөт. Ушул генератордон түзүлгөн дене скрипттин көчүрмөсүн камтыйт, ошондуктан бөлүк ага көз каранды эмес.

Файлда бир нече генератор да болушу мүмкүн: JSON топтому `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
