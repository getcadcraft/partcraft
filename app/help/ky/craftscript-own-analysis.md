Скрипт жумушчу аймагындагы анализ — өзгөрмөлөрдү бири-бирине берген бир нече кыска скрипт. Эң жакын [китепкана](topic:craftscript-library) функциясынан баштаңыз, көчүрмөсүн жасаңыз жана өзгөртүңүз; же төмөндөгүдөй өзүңүз түзүңүз.

## 1. Сетка

```
model = part();                  % моделдешкен деталь, модель катары
m = tetmesh(model, 4);           % 4 мм өлчөмдөгү тетраэдрлер
show(m)
```

Улантуудан мурун көрүнүштө торду текшериңиз: {{key:F}} аны ылайыктайт, **Көрсөтүлгөн** тизмесиндеги {{ui:көз}} деталды жашырат.

## 2. Түзүү жана чечүү

Элемент циклин скриптте жазыңыз (ал окулуучу учебникке окшош), ауыр бөлүктөрүн курулган функцияларга калтырыңыз: элемент матрицалары, үчтүктөрдөн сейрек түзүү жана алдын ала шарттоочу менен түйүндөш градиент чечүүчүсү. `static_tet` сыяктуу китепкана функциясы (китепкана аны камтыганда) көчүрүү үчүн толук мисал болот.

## 3. Натыйжаны көрсөтүү

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % түйүнгө бир маани
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- Легенданын диапазонун жазып коюуга же {{ui:Авто}} коюуга болот.
- Түйүндөгү маанилерди окуу үчүн торду басыңыз.
- Бирдей `'id'` сактаган график жаңыртылат, ошондуктан циклдин ичинде басып чыгарыңыз жана график тартыңыз, жакындашууну байкоо үчүн.

## 4. Текшериңиз

Белгилүү нерсе менен салыштырыңыз: консолдун учунун ийилиши PL³/3EI менен, тешиги бар пластина стресстин концентрация коэффициенти менен, реакциялар жүктөр менен. Текшерүүнү өз скрипти катары жазыңыз, ошондо ар бир өзгөртүүдөн кийин кайра иштейт:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('учу %g мм, тилке теориясы %g мм (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Сактаңыз

- Ар бир кадам өз скрипт өтмөгү болушу мүмкүн: алар өзгөрмөлөрдү бөлүшөт, ошондуктан бирин артынан бири иштетиңиз.
- Скрипттер деталда сакталат. Натыйжаларды да сактоо үчүн Өзгөрмөлөр өтмөгүндө **Өзгөрмөлөрдү деталь менен бирге сактоо** белгисин коюңуз (32 MB чейин).
- Скрипт тобундагы {{ui:Сактоо}} скриптти бөлүшүү үчүн жүктөйт; {{ui:Ачуу}} аны киргизет.
