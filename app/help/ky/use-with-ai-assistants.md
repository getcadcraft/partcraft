## Эмнени үйрөнөсүз

AI ассистентине (же өзүңүз жазган скриптке) ачык турган деталды карап чыгууга, анын параметрлерин өзгөртүүгө, скриптти иштетип экспорттоого уруксат берүүнү жана ал эмнеге тийе аларын өзүңүз кантип чечерин.

PartCraft'та **өз AI жок** жана эч жакка эч нерсе жөнөтүлбөйт. Ассистентти өзүңүз алып келесиз: Model Context Protocol (MCP) протоколун колдогон каалаган программа. PartCraft ага гана куралдарды берет, ал эми кайсысын берүүнү өзүңүз тандайсыз.

## Иштетүү

1. {{ui:Жөндөөлөр}} ачыңыз (колдонмонун үстүнкү тилкесиндеги тиш белгиси же {{key:Mod+,}}) жана {{ui:PartCraft}} өтмөгүнө өтүңүз.
2. {{ui:Ассистенттер}} астынан **AI ассистенттерине жана скрипттерге PartCraft колдонууга уруксат берүү** белгисин коюңуз. Сиз муну кылмайынча ал өчүк турат.
3. Ал эмне кыла аларын тандаңыз. **Окуу** башынан белгиленген; калгандарын керек болгондо гана белгилеңиз.
4. Ассистентке экспорттоп, папкага сактоосуна уруксат берүү үчүн, **Колдоно ала турган папкалар** астынан {{ui:Папка кошуу…}} тандап, Studio диалогунда папканы тандаңыз.

Ассистенттер **CadCraft Studio** аркылуу сиздин компьютериңизде туташат: Studio ассистентке чаптоо үчүн даректи жана токенди көрсөтөт. Браузердин өтмөгү ассистент үчүн туташууну ача албайт.

## Ассистент эмнени сурай алат

| Курал | Уруксат | Эмне кылат |
|---|---|---|
| `part_describe`, `features_list` | Окуу | Элементтер тартиби менен, эмне түзүлгөнү жана эмне катаганы, материал, катуу дененин көлөмү жана өлчөмү |
| `params_list` | Окуу | Параметрлер жана теңдеме айдай ала турган ар бир сан, маанилери менен |
| `mass_properties` | Окуу | Көлөм, аянт, массанын борбору, ага карата инерция; деталдын материалы болсо, массасы |
| `param_set` | Түзөтүү | Параметрди же элементтин санын коюп, кайра түзөт. Бир кадам, аны артка кайтарууга болот |
| `script_run` | Түзөтүү | CraftScript, Lua же Python скриптин {{ui:Скрипт}} иш мейкиндиги сыяктуу иштетет: жабык, файлдар жана тармак жок. Деталь өзгөрбөйт |
| `part_export` | Экспорттоо | STL, 3MF, STEP же OpenUSD (.usdz, .usda, .usdc), {{ui:Файл}} › {{ui:Экспорттоо}} жазгандай жазат |
| `link_push` | Түзөтүү | Башка программадан шилтелген модельди жаңыртат (караңыз: [.3dm моделин түз убакытта кармоо](topic:live-3dm-link)) |
| `link_status` | Окуу | Шилтелген модель азыр да бар-жогун жана качан акыркы жолу жаңыртылганын айтат |
| `part_save` | Сактоо | PartCraft'тын өз {{ui:Сактоо}} командасы |
| `illustrate_export` | Экспорттоо | {{ui:Иллюстрация}} иш мейкиндигиндеги {{ui:Колдонмо}} PDF же SVG сызык сүрөт катары, анын көрүнүштөрү, интерактивдүү 3D файл катары же анын {{ui:Нускамалар}} PDF же веб-бет катары, иш мейкиндигинин {{ui:Экспорттоо}} жана {{ui:Нускамалар}} меню жазгандай ([Колдонмолор](topic:illustrate)) |

:::note
Бул курулушта mesh ядросу колдонулат: көлөмдөр үч бурчтуктардан алынат (ийри катуу денеден бир аз кичирээк), ал эми STEP тилкелүү түрдө, так беттердин ордуна үч бурчтуктар менен жазылат.
:::

## Башкаруу сизде калат

- **Ар бир өзгөртүү артка кайтаруунун бир кадамы**, ассистент үчүн белгиленет, мисалы "Assistant: set l = 45". Аны кайтаруу үчүн {{key:Mod+Z}} басыңыз.
- **Туташканын билесиз.** Колдонмонун үстүнкү тилкесиндеги баскыч туташкан учурда ассистентти атайт. Ал эмне кыла аларын көрүү же аны **Ажыратуу** үчүн басыңыз.
- **Иш-аракеттер.** {{ui:Жөндөөлөр}} › {{ui:PartCraft}} › {{ui:Ассистенттер}} › {{ui:Иш-аракеттер}} ар бир чакырууну тизмелейт; {{ui:Журналды сактоо}} көчүрмөсүн сактайт.
- **Папкалар.** Ассистент файлдарды сиз кошкон папкаларда гана окуйт жана жазат; {{ui:Алып салуу}} папканы дароо кайтарып алат.

## PartCraft ачпай туруп

Ассистенттер үчүн CadCraft файл сервери (`npx @getcadcraft/mcp`) жана `cadcraft` буйрук сабы `.partcraft.json` деталдарын терезесиз, PartCraft'тын өз коду жана mesh ядросу менен ачат: ошол окуу куралдары, параметрлерди коюу, CraftScript скрипттери, экспорттор (OpenUSD да) жана сактоо. `cadcraft convert bracket.partcraft.json bracket.stl` деталды түзүп, буйрук сабынан жазат. Колдонмолор (`.partcraft-manual.json`) да ошол жерден экспорттолот: `illustrate_export`, же `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (нускамалар үчүн `--instructions` кошуңуз).

## Эгер бир нерсе иштебесе

- **"needs the edit permission":** {{ui:Ассистенттер}} астынан **Түзөтүү** белгисин коюңуз, андан кийин кайра сураңыз.
- **"driven by the equation":** бул сан параметрди ээрчийт; анын ордуна ассистенттен параметрди коюуну сураңыз.
- **Анын өзгөртүүсү туура эмес болду:** {{key:Mod+Z}} басыңыз.
