Моделди аны жасаган жерде формалай бериңиз, ал эми машиналоо, текшерүү жана документтөө бул жерде. Башка программадагы ар бир өзгөртүү PartCraft'та бир импорттолгон денени алмаштырат, андан кийингилер жаңы формада кайра курулат.

:::note
Байланыш ушул компьютерде **CadCraft Studio** талап кылат. Браузер өтмөгү туташууну кабыл албайт. Интернет аркылуу эч нерсе өтпөйт: скрипт Studio менен ушул компьютердин өз дареги аркылуу, токен менен сүйлөшөт.
:::

:::warning
Бул байланыш скрипттин файл жазгычы жана башка программанын орун басары менен сыналган, Rhino же Grasshopper'дин ичинде али эмес. Эгер ал жерде бир нерсе иштебесе, эмне деп жазганын бизге айтыңыз.
:::

## Орнотуу

1. Studio'да PartCraft'ты ачыңыз. {{ui:Жөндөөлөр}} › {{ui:PartCraft}} › {{ui:Ассистенттер}} ичинен **AI ассистенттерине жана скрипттерге PartCraft'ты колдонууга уруксат берүү** белгисин коюңуз, андан кийин **Түзөтүү**.
2. Studio'да {{ui:Ассистентти туташтыруу}} тандаңыз. Ал төмөндө чаптай турган даректи жана токенди көрсөтөт.
3. Скриптти жүктөп алыңыз: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino'дон

1. `cadcraft_link.py` скриптин Rhino'нун скрипт редакторунда иштетиңиз (Rhino 8'де Python 3).
2. Биринчи жолу даректи жана токенди чаптаңыз. Алар сиздин үй папкаңыздагы `.cadcraft-link.json` файлында сакталат, моделде эч качан эмес. Studio ар бир жолу баштаганда жаңы токен жасайт, ошондо скрипт кайра сурайт.

Скриптти токтотуу үчүн аны кайра иштетиңиз.

## Grasshopper'дон

Адегенде скриптти Rhino'до бир жолу иштетиңиз, дарек жана токен сакталсын.

1. Python 3 Script компонентин кошуп, `cadcraft_link.py` скриптинин бүт текстин ага чаптаңыз.
2. Ага мындай киргизүүлөрдү бериңиз: `G` (геометрия, тизме жеткиликтүүлүгү менен), `N` (аты, милдеттүү эмес), `On` (boolean которгуч), жана `Target` (милдеттүү эмес: `model` же `part`, эгер эки колдонмо ачык болсо).
3. `On` маанисин true кылыңыз.

Ар бир эсептөө `G` жөнөтөт жана компоненттин акыркы жолу жөнөткөнүн алмаштырат.

## Бул жерде иштеши

- **Бир дене.** Моделдеги баары бир импорттолгон элементке айланат, [.3dm файлын ачкандай](topic:open-3dm-files).
- **Жабылышы керек.** PartCraft кичинекей тешиктерди жана жалпак ачылыштарды толтурат, ал эми башка программага канча экенин билдирет. Эгер модель дагы эле жабылбаса, PartCraft мурунку денени сактайт жана абал тилкесинде ал жөнүндө жазылат. Жабылган кийинки өзгөртүү аны жаңыртат.
- **Иштеп жаткан ишти бүтүрүңүз.** Эскизде же чиймеде жаңыртуулар четке кагылат жана кайра аракет кылынат; сиз моделге кайтканда алар келишет.
- **Кайтаруу.** Эки секунд ичиндеги жаңыртуулар бир артка кайтаруу кадамын бөлүшөт.
- **Сактоо.** Деталь файлы байланышты сактайт. Аны кайра ачкандан кийин скриптти кайра иштетиңиз, ошол эле элемент жаңыртылат.

**Бир тарапка гана.** Бул жерде киргизген өзгөртүүлөр башка программага кайтып барбайт.

## Эгерде бир нерсе туура болбосо

- **"Бул уруксат бербейт: ModelCraft же PartCraft терезеси жок":** орнотуунун 1-кадамын аткарыңыз.
- **"Studio токенди четке какты":** Studio кайра ишке кирди. Жаңы токенди көчүрүп, скриптти кайра иштетиңиз. Grasshopper үчүн адегенде Rhino'до иштетиңиз.
- **"CadCraft Studio'га жетүү мүмкүн эмес":** Studio иштеп жатпайт, же дарек өзгөрдү.
