CraftScript යනු MATLAB වැනි ලෙස කියවීමට හැකි පරිදි ලියන ලද න්‍යාස භාෂාවකි, එබැවින් බොහෝ සාම්ප්‍රදායික සංඛ්‍යාත්මක කේත (උදාහරණයක් ලෙස රේඛා 88ක ටොපොලොජි ප්‍රශස්තිකරණ කේතය) කුඩා වෙනස්කම් සහිතව ක්‍රියාත්මක වේ. එය [ස්ක්‍රිප්ට් වැඩතලයේ](topic:craftscript) සහ විධාන රේඛාවෙන් ධාවනය වේ.

## අගයන්

| වර්ගය | උදාහරණය | සටහන් |
|---|---|---|
| සංඛ්‍යාව, අරාව | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | සෑම සංඛ්‍යාවක්ම අරාවකි (1×1 එකක්). අරා තීරු අනුව ගබඩා වන අතර මාන 8 දක්වා ඇත |
| තාර්කික | `A > 2`, `true` | සත්‍ය/අසත්‍ය අරා; දර්ශක ලෙස භාවිතා කළ හැක |
| පෙළ | `'beam'`, `"beam"` | |
| විරල න්‍යාසය | `sparse(i, j, v, n, n)` | දෘඪතා න්‍යාස සඳහා |
| දැලිස, ක්ෂේත්‍රය, ආකෘතිය | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` ඇඳින දේ |
| ව්‍යුහය | `s.E = 210e3` | නම් කළ ක්ෂේත්‍ර |
| කෝෂය | `c = {1, 'two', [3 4]}` | ඕනෑම අගයන්ගේ ලැයිස්තුවකි |
| ශ්‍රිත හසුරුව | `f = @(x) x.^2` | |

## අරා සහ දර්ශකගත කිරීම

- පරාසයන්: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- දර්ශකගත කිරීම 1 සිට ආරම්භ වේ: `A(2, 3)`, `v(end)`, `A(:, 1)` (සම්පූර්ණ තීරුවක්), `A(:)` (සියල්ල එක් තීරුවක් ලෙස), `v(v > 0)` (තාර්කික දර්ශකගත කිරීම).
- MATLAB හි මෙන්, අවසානයෙන් ඔබ්බට පැවරීම අරාව වර්ධනය කරයි: `v(10) = 1`.

## ක්‍රියාකාරක

- `+ - * / \ ^` යනු න්‍යාස ක්‍රියාකාරක වේ (`A \ b` විසඳයි); `.* ./ .^` මූලකයෙන් මූලකයට ක්‍රියා කරයි. `'` පරිවර්තනය කරයි.
- සංසන්දන `== ~= < <= > >=`; තාර්කික `& | ~` (මූලකයෙන් මූලකයට) සහ `&& ||` (කෙටි පරිපථ).

## පාලන ප්‍රවාහය සහ ශ්‍රිත

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ශ්‍රිත ස්ක්‍රිප්ටයක විධානවලට පසුව, හෝ ශ්‍රිතයේ නමින් නම් කළ තමන්ගේම ස්ක්‍රිප්ට් ටැබයේ තැබිය හැක:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

නමක් පහත අනුපිළිවෙලට සොයනු ලැබේ: විචල්‍යයක්, මෙම කොටසේ එම නම ඇති ස්ක්‍රිප්ටයක්, පුස්තකාල ශ්‍රිතයක්, ගොඩනඟන ලද ශ්‍රිතයක්.

## අදහස්, echo, ප්‍රතිදානය

- `;` නොමැති ප්‍රකාශයක් එහි අගය මුද්‍රණය කරයි; `;` එය නිශ්ශබ්දව තබයි.
- `%` අදහසක් ආරම්භ කරයි; ස්වකීය පේළි මත ඇති `%{` සහ `%}` ඒවා අතර පේළි අදහස් බවට පත් කරයි.
- `disp(x)`, `fprintf('%g\n', x)` සහ `display(x)` කොන්සෝලයට මුද්‍රණය කරයි.

## දෝෂ සහ සීමා

- දෝෂ මගින් වැරැද්ද සරල වචනවලින් කියා, පේළිය (සහ ශ්‍රිත ඇමතුම් දාමය) දක්වයි.
- සෑම ධාවනයකටම පියවර අයවැයක් ඇත (පැනලයේ ධාවන විකල්ප); අවසන් නොවන ලූපයක් පණිවිඩයක් සමඟ නවතියි, නැතහොත් {{ui:නවත්වන්න}} ඔබන්න.
- සෑම අරාවකම අගයන් මිලියන 134 දක්වා තබා ගත හැක.

## MATLAB වලින් වෙනස්

- ප්ලොට් විධානවල විකල්ප ඇමතුම තුළ තබයි: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` සහ ඒ හා සමාන දේ පිළිගනී, නමුත් කිසිවක් නොකරයි.
- `input` සහ `keyboard` සහාය නොදක්වයි: ස්ක්‍රිප්ටයකට ප්‍රශ්නයක් අසා නැවතීමට නොහැක.
- මෙවලම් කට්ටල නොමැත; [විශ්ලේෂණ පුස්තකාලය](topic:craftscript-library) සහ ගොඩනඟන ලද ශ්‍රිත පමණක් ඇත.
