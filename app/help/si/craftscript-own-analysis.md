ස්ක්‍රිප්ට් වැඩතලයේ විශ්ලේෂණයක් යනු එකිනෙකට විචල්‍ය භාර දෙන කෙටි ස්ක්‍රිප්ට් කිහිපයකි. ඔබට අවශ්‍ය දෙයට සමීප [පුස්තකාලයේ](topic:craftscript-library) ශ්‍රිතයකින් ආරම්භ කර, පිටපතක් සාදා එය වෙනස් කරන්න; නැතහොත් පහත පරිදි එකතු කරන්න.

## 1. දැලිසක්

```
model = part();                  % ඔබ මාදිලිකරණය කරන කොටස, ආකෘතියක් ලෙස
m = tetmesh(model, 4);           % මිලිමීටර 4ක් පමණ හරහා චතුස්තලක
show(m)
```

ඉදිරියට යාමට පෙර දසුනේ දැලිස පරීක්ෂා කරන්න: {{key:F}} එය ගලපයි, **පෙන්වන ලද** හි {{ui:ඇස}} කොටස සඟවයි.

## 2. එකලස් කර විසඳන්න

මූලද්‍රව්‍ය ලූපය ස්ක්‍රිප්ටයේ ලියන්න (එය පා-පොතේ මෙන් කියවේ), සහ බර කොටස් ගොඩනඟන ලද ශ්‍රිතවලට භාර දෙන්න: මූලද්‍රව්‍ය න්‍යාස, ත්‍රිත්ව වලින් විරල එකලස් කිරීම, සහ පූර්ව-කොන්දේසිකරණය සහිත සංයුග්මක අනුක්‍රමණ විසඳුම්කරුව. `static_tet` වැනි පුස්තකාල ශ්‍රිතයක් (පුස්තකාලයේ එය ඇති පසු) පිටපත් කිරීමට සම්පූර්ණ උදාහරණයකි.

## 3. ප්‍රතිඵලය පෙන්වන්න

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % නෝඩයකට එක් අගයක්
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- යතුරේ පරාසය ටයිප් කළ හැක හෝ {{ui:ස්වයංක්‍රීය}} වෙත ආපසු සැකසිය හැක.
- නෝඩයක අගයන් කියවීමට දැලිස ක්ලික් කරන්න.
- එකම `'id'` තබා ගන්නා ප්ලොටය ස්ථානයේම යාවත්කාලීන වේ, එබැවින් එය අභිසාරී වන ආකාරය බැලීමට ඔබේ ලූපය තුළ මුද්‍රණය කර ප්ලොට් කරන්න.

## 4. පරීක්ෂා කරන්න

ඔබ දන්නා දෙයකට සංසන්දනය කරන්න: කැන්ටිලීවරයේ අග්‍ර නැමීම PL³/3EI ට එරෙහිව, සිදුරක් ඇති තහඩුව එහි ආතති සාන්ද්‍රණ සාධකයට එරෙහිව, ප්‍රතික්‍රියා බරවලට එරෙහිව. පරීක්ෂාව එහි තනි ස්ක්‍රිප්ටයක ලියන්න, එවිට සෑම වෙනසකින් පසුවම එය නැවත ධාවනය වේ:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. එය තබා ගන්න

- සෑම පියවරක්ම එහි තනි ස්ක්‍රිප්ට් ටැබයක් විය හැක: ඒවා විචල්‍ය බෙදා ගනී, එබැවින් ඒවා එකින් එක ධාවනය කරන්න.
- ස්ක්‍රිප්ට් කොටසේ සුරැකේ. ප්‍රතිඵලත් තබා ගැනීමට විචල්‍ය ටැබයේ **කොටස සමඟ විචල්‍ය සුරකින්න** ටික් කරන්න (MB 32 දක්වා).
- ස්ක්‍රිප්ට් කණ්ඩායමේ {{ui:සුරකින්න}} ස්ක්‍රිප්ටයක් බෙදා ගැනීමට බාගනී; {{ui:විවෘත කරන්න}} එකක් ගෙන එයි.
