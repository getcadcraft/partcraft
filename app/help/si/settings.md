PartCraft සැකසීම් යෙදුමේ පමණක් පවතී: ඒවා මෙහි වෙනස් කරන්න, සහ මෙම බ්‍රවුසරය ඒවා මතක තබාගනී. {{ui:PartCraft සැකසීම් යළි සකසන්න}} සෑම දෙයක්ම ආරම්භයට නැවත තබයි.

## දසුන කරකවන්න

- **වම් බොත්තම** (ආරම්භයේදී): කොටස කරකවීමට වම් බොත්තමෙන් ඇදගන්න; ගෙනයාමට දකුණු හෝ මැද බොත්තමෙන් ඇදගන්න.
- **මැද බොත්තම**: රෝදය ඔබා ඇදගෙන කොටස කරකවන්න; මැද බොත්තම සමග {{key:Shift}} (හෝ {{key:Ctrl}}, හෝ ⌘) අල්ලාගෙන, හෝ දකුණු බොත්තමෙන් ඇදගෙන, ගෙනයන්න. වම් බොත්තම මුහුණත්, දාර සහ තල තෝරන්න පමණි, එබැවින් ටිකක් චලනය වන ක්ලික් එකක් කිසිවිට කොටස කරකවන්නේ නැත. බොහෝ CAD වැඩසටහන් මෙසේ ක්‍රියා කරයි.

රෝදය ඕනෑම ආකාරයකින් දර්ශකය ළඟට විශාලනය කරයි. ස්කෙච් එකක, දකුණු සහ මැද බොත්තම් පෙර ලෙසම ගෙනයයි.

## අනුචලනය: මූසික රෝදය හෝ trackpad

- **හඳුනාගන්න** (ආරම්භයේදී): PartCraft අනුචලනය නිරීක්ෂණය කරයි. trackpad එක යවන පරිදි පැත්තට හෝ සියුම් අනුචලනය කොටස කරකවයි; සම්පූර්ණ රෝද ඇණ විශාලනය කරයි.
- **මූසික රෝදය**: අනුචලනය සැමවිටම දර්ශකය දෙසට විශාලනය කරයි.
- **Trackpad**: කොටස කරකවීමට ඇඟිලි දෙකකින් swipe කරන්න, {{key:Shift}} අල්ලාගෙන swipe කර ගෙනයන්න, විශාලනය කිරීමට pinch කරන්න. ස්කෙච් එකක ඇඟිලි දෙකේ swipe එකෙන් ස්කෙච් ගෙනයයි.

pinch සෑම තේරීමකම විශාලනය කරයි. "හඳුනාගන්න" ඔබේ මූසිකය හෝ trackpad එකට වැරදියට අනුමාන කළහොත්, ඔබ සතු එක තෝරන්න. වැඩි විස්තර [Trackpad, ස්පර්ශය සහ කුඩා තිර](topic:trackpad-and-touch) හි.

## ස්කෙච් කිරීම: ඇඳීමේදී සම්බන්ධතා එකතු කරන්න

**ඇඳීමේදී සම්බන්ධතා එකතු කරන්න** (ආරම්භයේදී ක්‍රියාත්මක): ලක්ෂ්‍යයකට snap වන ක්ලික් එකක් නව ලක්ෂ්‍යය එයට coincident කරයි, වක්‍රයක් මත ක්ලික් එකක් ලක්ෂ්‍යය එම වක්‍රය මතට දමයි, සහ පාහේ මට්ටම් හෝ සිරස් ඇඳි රේඛාවක් තිරස් හෝ සිරස් වේ. බලන්න [සම්බන්ධතා සහ මානයන්](topic:relations-dimensions).

වෙනත් ජ්‍යාමිතියකට බැඳීමකින් තොරව ජ්‍යාමිතිය වෙනත් ජ්‍යාමිතියක් අසල තැබීමට අවශ්‍ය විට එය අක්‍රිය කරන්න. දර්ශකය තවමත් ලක්ෂ්‍ය සහ වක්‍ර වෙත snap වේ, නමුත් කිසිවක් සම්බන්ධ නොවේ: දාමයක ඇඳි රේඛා ඒවායේ කෙළවර බෙදා නොගන්නා බැවින්, ඇදීමකින් ඒවා වෙන් කළ හැක. ඔබට අවශ්‍ය සම්බන්ධතා දකුණු පැනලයෙන් ඔබම එකතු කරන්න. කෙළවර හමුවන විට සංවෘත පැතිකඩ තවමත් extrude වේ.

## ස්කෙච් කිරීම: ඇඳීමේදී මානය

**ඇඳීමේදී මානය** (ආරම්භයේදී ක්‍රියාත්මක): රේඛාවක්, සෘජුකෝණාස්‍රයක්, වෘත්තයක් හෝ චාපයක් ඇඳෙන අතරතුර, අංකයක් ටයිප් කිරීම දර්ශකය අසල ප්‍රමාණ පෙට්ටිය පුරවයි ({{key:Tab}} ඊළඟ පෙට්ටියට යයි) සහ {{key:Enter}} හැඩය එම ප්‍රමාණයෙන් ඇඳයි, ඔබ ටයිප් කළ සෑම ප්‍රමාණයකටම ධාවන මානයක් සමග. අක්‍රිය: ඇඳීමේදී අංකයක් ටයිප් කිරීම කිසිවක් නොකරයි, සහ හැඩ ක්ලික් වලින් පමණක් ඇඳේ. බලන්න [ඇඳීමේදී ප්‍රමාණය ටයිප් කරන්න](topic:sketch-basics#type-the-size-as-you-draw).

## කෝණ දර්ශකය

3D දසුනේ කෙළවරේ පෙන්වන දේ: **View cube** (ආරම්භය; ඉහළ දකුණු — එතැනින් බැලීමට මුහුණතක්, දාරයක් හෝ කෙළවරක් ක්ලික් කරන්න, orbit කිරීමට ඇදගන්න, මොඩලය කරකවීමට එහි කම්පාස් වළලුව ඇදගන්න), **Axis icon** (පහළ වමේ කුඩා X, Y, Z ලකුණ, දසුන සමග කරකවයි: X රතු, Y කොළ, Z නිල්) හෝ **None**. ස්කෙච් කිරීමේදී හෝ ඇඳීම් පත්‍රයේදී කිසිවක් නොපෙන්වයි. බලන්න [View cube](topic:view-cube).

## විසඳුම් ත්‍රෙඩ්

simulation විසඳුම් කීයක් ත්‍රෙඩ් භාවිත කළ හැකිද. **ස්වයංක්‍රීය** (ආරම්භය) පරිගණකයේ තාර්කික processors ගණනට වඩා එකක් අඩු ගනී (උපරිම 16), එබැවින් අධ්‍යයනයක් විසඳන අතරතුර පිටුව ප්‍රතිචාරාත්මකව පවතී; හෝ අංකයක් තෝරන්න. විශාල voxel අධ්‍යයන, buckling, කාලය සමග ආතතිය සහ flow කිහිපයක ත්‍රෙඩ් මත වේගවත්ව විසඳේ (අපගේ මිනුම්වල 80,000 cubes සඳහා ත්‍රෙඩ් 4ක් මත ආසන්න වශයෙන් 2×, අලස පරිගණකයක තවත් වැඩි); ආසන්න වශයෙන් 20,000 unknowns ට අඩු මාදිලි එක් ත්‍රෙඩ් මත පවතී, මන්ද ත්‍රෙඩ් ආරම්භ කිරීමේ පිරිවැය ඒවා ඉතිරි කරන දෙයට වඩා වැඩිය. ත්‍රෙඩ් විසඳුමක් එක් ත්‍රෙඩ් එකක් මෙන්ම පිළිතුර දෙයි (පෙරළීමට: එකතුවන් වෙනස් අනුපිළිවෙලකින් එකතු වේ). සෑම අධ්‍යයනයකම ප්‍රතිඵල **Solver** යටතේ හේතුව සමග **N ත්‍රෙඩ්** හෝ **1 ත්‍රෙඩ්** ලැයිස්තු කරයි.

ත්‍රෙඩ් සඳහා පිටුව **cross-origin isolated** විය යුතුය (එවිට පමණක් බ්‍රවුසරය workers ට මතකය බෙදා ගැනීමට ඉඩ දෙයි). ලැබ් පිටුව එසේය; නොවන තැන, සැකසීම එය කියයි ("This page is not cross-origin isolated, so solvers run on one thread whatever is chosen here.") සහ සෑම විසඳුමක්ම එක් ත්‍රෙඩ් භාවිත කරයි. අනෙක් සියල්ල සමානව ක්‍රියා කරයි, සහ පිළිතුරු සමානය.

Laminar flow අධ්‍යයන ද ත්‍රෙඩ් භාවිත කරයි (ත්‍රෙඩ් 4ක් මත 54,000 fluid cells සඳහා ආසන්න වශයෙන් 2.5×, අවසාන ඉලක්කමටම එම පිළිතුර). quadratic-tetrahedron විසඳුම සහ තාප හුවමාරුව එක් ත්‍රෙඩ් මත ධාවනය වේ: ඒවා ත්‍රෙඩ් කිරීම අපගේ පරීක්ෂණ පරිගණකයේ මන්දගාමී විය (ඒවායේ විසඳුම් මතක වේගය සහ බෙදිය නොහැකි පියවරකින් සීමා වේ).

### ඔබේම වෙබ් සේවාදායකයක

ඔබ PartCraft ඔබේම සේවාදායකයෙන් ධාවනය කරන්නේ නම්, එය සේවා කළ ආකාරයටම ක්‍රියා කරයි. විසඳුම් ත්‍රෙඩ් සඳහා, සේවාදායකයට PartCraft පිටුව සමග headers දෙකක් යැවීමට ඉඩ දෙන්න:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Apache හි, ෆෝල්ඩරයේ `.htaccess` තුළ (mod_headers අවශ්‍යයි):

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

nginx හි, PartCraft සේවා කරන `location` තුළ:

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

පිටුව නැවත පූරණය කරන්න: සැකසීම් › විසඳුම් ත්‍රෙඩ් එවිට ඔබේ පරිගණකයේ ගණන සමග **ස්වයංක්‍රීය** ඉදිරිපත් කරයි. දෙවන header මගින් බ්‍රවුසරය පිටුව වෙනත් අඩවියකින් පූරණය කරන, එයට ඉඩ නොදෙන ඕනෑම දෙයක් ප්‍රතික්ෂේප කරයි, එය PartCraft එකෙන්ම සඳහා හොඳයි (එය සියල්ල තමන්ගේම ෆෝල්ඩරයෙන් පූරණය කරයි).
