ජනකයක් යනු කොමෙන්ට් රේඛා කිහිපයක් මුදුනේ ඇති සාමාන්‍ය ස්ක්‍රිප්ටයකි ([CraftScript](topic:craftscript), Lua හෝ Python). PartCraft කොමෙන්ට් කියවා ආකෘතිය සාදයි; ඔබේ ස්ක්‍රිප්ට් ආදානයන් කියවන්නේ දැනටමත් සකසා ඇති විචල්‍ය ලෙසයි.

## ශීර්ෂය

මේවා කොමෙන්ට් රේඡාවල තබන්න (CraftScript හි `%`, Lua හි `--`, Python හි `#`):

```
% @generator තාප හුවමාරුකය
% @input mdot: kg/s = 0.2 [0.01 .. 10] "ස්කන්ධ ප්‍රවාහය"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "පෘෂ්ඨය"
% @input solid: = true
% @input note: = "text"
```

ආදානයක් යනු `name: unit = default` ය, ඉන් පසු විකල්පයෙන් පරාසයක් `[min .. max]` (සංඛ්‍යා එය තුළ තබා ගැනේ), තේරීම් ලැයිස්තුවක් `{a, b, c}` සහ උද්ධෘත ලකුණු තුළ ලේබලයක්. ඒකකය ආකෘතිය සඳහා ලේබලයක් පමණි: **අගය ලැබෙන්නේ එම ඒකකයෙන්**, එබැවින් SI ඒකක අවශ්‍ය ස්ක්‍රිප්ටය එය පරිවර්තනය කළ යුතුය. `to_si(value, 'kg/s', 'kg/s')` මගින් ඒකකය ඔබ සිතන දෙයම ද යන්න ද පරීක්ෂා කරයි. නමක් යනු අකුරු, ඉලක්කම් සහ යටි ඉරක්; `body`, `sheet` සහ `problems` දැනටමත් භාවිතා වේ.

## ස්ක්‍රිප්ටය තබන දේ

| විචල්‍යය | අර්ථය |
|---|---|
| `body` | **අනිවාර්ය.** පෘෂ්ඨ දැලියකි, සාමාන්‍යයෙන් `[body, info] = to_body(field, h)` වලින්. ධාවනය අවසන් වන විට එය අලුත්වැඩියා කර පරීක්ෂා කෙරේ. |
| `sheet` | විකල්පයයි. ව්‍යුහයක්: එක් එක් ක්ෂේත්‍රය සංඛ්‍යාවක් හෝ පෙළක්, නැත්නම් `value`, `unit`, `ref` සහ `note` සහිත ව්‍යුහයක්. එය දත්ත පත්‍රය බවට පත්වේ. |
| `problems` | විකල්පයයි. `mfg_check(field, 'sls', struct(), h)` වෙතින් ලැබෙන `problems` සෛලය, හෝ ඔබේම ඇතුළත් කිරීම්. ඒවා පරීක්ෂාවලටත් ගැටලු ලැයිස්තුවටත් යයි. |

## කුඩා සම්පූර්ණ උදාහරණය

```
% බිත්තියක් සහිත හිස් ඝනකය.
% @generator හිස් ඝනකය
% @input side: mm = 12 [4 .. 40] "පැත්ත"
% @input wall: mm = 1.5 [0.5 .. 5] "බිත්තිය"
% @input h: mm = 0.5 [0.25 .. 2] "වොක්සල් ප්‍රමාණය"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'දැලියේ');
```

එය සංවෘත පෙට්ටියක් සාදයි, සහ පරීක්ෂාව එහි සීල් කළ ඇතුළත කුඩු (powder) ක්‍රියාවලිය සඳහා දෝෂයක් ලෙස වාර්තා කරයි. voxel size `h` ඔබට අවශ්‍ය තුනීම බිත්තියේ තුනෙන් එකට වඩා වැඩි නොවිය යුතුය: වොක්සල් තුනකට අඩු බිත්තියක් විශ්වාසදායක නොවේ.

## ක්ෂේත්‍ර

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (පැතිකඩකින් භ්‍රමණ ඝන වස්තුවක්), `tpms` (gyroid, Schwarz P සහ diamond පෘෂ්ඨ, කෝෂ ප්‍රමාණය සහ බිත්ති සමඟ කොටස තුළ වෙනස් විය හැක), `lattice` සහ `lattice_beams`, `along` (මාර්ගයක් ඔස්සේ වටැති නාලිකාව), බූලියන `field_union`, `field_intersect`, `field_subtract`, සුමට `field_blend`, සහ `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` ලකුණු වලදී සංඥා සහිත දුර ලබා දෙයි (ඇතුළතදී negative), `field_voxel` විසඳුම් සඳහා වොක්සල් ලබා දෙයි. [ක්ෂේත්‍ර](topic:fields) මගින් ඒවා කුමක්ද යන්න පැහැදිලි කෙරේ.

දැන ගත යුතු සීමා: දැලි බිත්තියක් කෝෂයේ තුනෙන් එකකට වඩා ඝන නම් නාලිකා වැසේ; ව්‍යුහයක් වොක්සල් තුනකට වඩා තුනී නම් හැකුළිය හැක; `along` වටැති කේතු සම්බන්ධ කරයි, එබැවින් අරය වේගයෙන් වෙනස් වුවහොත් නැමීමක් ඇති වේ (පැතිකඩක් සඳහා `field_revolve` භාවිතා කරන්න).

## ඔබේ ස්ක්‍රිප්ටය ජනකයක් ලෙස විවෘත කරන්න

{{ui:Engineer}} වැඩතලයේ {{ui:Open}} ක්ලික් කර ගොනුව තෝරන්න. `@generator` හෝ `@input` රේඛාවක් නැති ස්ක්‍රිප්ටයක් ප්‍රතික්ෂේප කෙරේ: සැකසීමට කිසිවක් නැත. ජනකය මෙම බ්‍රව්සරයේ තබා ගනු ලැබේ (20 දක්වා) සහ {{ui:Remove}} එය මකා දමයි. එයින් ආරම්භ කළ බොඩියක් ස්ක්‍රිප්ට් හි පිටපතක් රැගෙන යන නිසා කොටස එය මත රඳා නොපවතී.

ගොනුවක කිහිප ජනකයක් ද තිබිය හැක: JSON බණ්ඩලයක් `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
