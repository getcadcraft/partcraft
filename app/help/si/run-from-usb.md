ඉංජිනේරු මෙවලම් (උත්පාදක, ඉංජිනේරු පුස්තකාලය, පරීක්ෂා සහ දත්ත ගොනු) **පරිපාලක අයිතිවාසිකම්** සහ **ඉන්ස්ටෝලරයක්** අවශ්‍ය නොවේ. ඒවා මෙහි ලැයිස්තුගත කර ඇති දේ පමණක් ලියන අතර, වෙන කිසිවක් නොවේ.

මෙවලම් **තමන්ගේම ජාල ඇමතුම් කිසිවක් නොකරයි**: නිකුත් වන උත්පාදක යෙදුමේ තමන්ගේ ෆෝල්ඩරයේ ගොනු වේ, පුස්තකාලය සහ පරීක්ෂා ඔබේ පරිගණකයේ, ජාලයට ළඟා විය නොහැකි worker එකක ධාවනය වේ, සහ ඉංජිනේරු දත්ත (ජලය සහ වාතයේ ගුණ, ද්‍රව්‍ය) යෙදුම තුළ ඇත. ඔබ ගොනුවකින් විවෘත කරන උත්පාදකය ඔබේ පරිගණකයේ කියවෙන අතර කොහෙටවත් නොයයි.

## ජංගම Windows zip සහ Linux

Windows සඳහා ජංගම Studio එහි සැකසීම්, cache සහ add-ons වැඩසටහන අසල `data` ෆෝල්ඩරයේ තබයි. `portable` නම් ගොනුවක් ඒ අසල තිබේ නම් Linux AppImage ඒවා තමන් අසලම තබයි; එම ගොනුව නැත්නම් ඔබේ home ෆෝල්ඩරය භාවිත කරයි. ජංගම Mac ආකෘතියක් නැත: බාගත කළ යෙදුම තමන් අසල ලිවීම පද්ධතිය වළක්වයි. ෂෙල් හි තමන්ගේම ජංගම සටහන් (`Studio` උදව්ව) වැඩසටහන ලියන දේ ලැයිස්තු කරයි.

## සත්කාරක ප්‍රවේශය

මෙහි කිසිවක් සත්කාරක ප්‍රවේශය ඉල්ලන්නේ නැත. මුද්‍රකයන්, serial යන්ත්‍ර සහ USB උපාංග වෙනම වේ: කාර්යයකට ඒවා අවශ්‍ය වූ විට, එක් උපාංගයකට එක් වරක් ඉල්ලයි, සහ උත්පාදක හෝ පරීක්ෂා කිසිවක් ඒවාට ස්පර්ශ නොකරයි.
