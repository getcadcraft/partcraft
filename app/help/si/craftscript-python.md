Python යනු [ස්ක්‍රිප්ට් වැඩතලයේ](topic:craftscript) තුන්වන භාෂාවයි. සංස්කාරකයට ඉහළ භාෂා පෙට්ටියෙන් **Python** තෝරන්න (`.py` ගොනුවක් ස්වයංක්‍රීයව Python හි විවෘත වේ). Python, Lua සහ CraftScript එම විචල්‍ය සහ එම ගොඩනඟන ලද ශ්‍රිත බෙදා ගනී, එබැවින් Python ස්ක්‍රිප්ටයකට CraftScript ස්ක්‍රිප්ටයක් සාදා ඇති දේ භාවිතා කළ හැක, සහ අනෙක් ආකාරයටත්.

එක් පැමිණීමක පළමු Python ධාවනය Python ම (CPython 3.14, 7 MB පමණ) මෙම අඩවියෙන් පූරණය කරයි, එයට තත්පර කිහිපයක් ගතවේ. Python තවමත් {{ui:නොබැඳි සඳහා සුරකින්න}} හි කොටසක් නොවේ: පළමුව ඔන්ලයින් සිටිමින් Python ස්ක්‍රිප්ටයක් එක් වරක් ධාවනය කරන්න.

## Python වසා ඇත

Python ස්ක්‍රිප්ට් CraftScript සහ Lua ස්ක්‍රිප්ට් මෙන් වසා ඇත: ඒවා කොටස, විචල්‍ය සහ ගොඩනඟන ලද ශ්‍රිත වෙත පමණක් ළඟා වේ, වෙන කිසිවක් නොවේ. සෑම ධාවනයකම නව Python එකක් එහි තමන්ගේම වැලිපෙට්ටියේ (sandbox) මතකයේ කුඩා ගොනු ගසක් සමඟ (එහි සම්මත පුස්තකාලය සහ ධාවනයෙන් පසු නැති වන `/tmp` ෆෝල්ඩරය) ධාවනය වේ. එයට ජාලය, ඔබේ ගොනු, හෝ පිටුවේ අනෙක් කොටස්, බ්‍රවුසරයේ සහ විධාන රේඛාවේ දෙකෙහිම, ළඟා විය නොහැක. වෙනත් අයෙකුගෙන් ආ ස්ක්‍රිප්ටයකට තවමත් බොහෝ කාලයක් හෝ මතකයක් භාවිතා කළ හැක: {{ui:නවත්වන්න}} එය අවසන් කරයි.

## මූලික දේවල්

```
A = cs.magic(3)              # ගොඩනඟන ලද සෑම ශ්‍රිතයක්ම cs.<name>
B = A @ A.T                  # @ න්‍යාස ගුණිතයයි, .T පරිවර්තනයයි
C = A * 2 + 1                # + - * / ** මූලකයෙන් මූලකයට, numpy හි මෙන්
print(A[0, 1], A[-1, -1])    # 0-පදනම්; ඍණ අගය අවසානයෙන් ගණනය කරයි
row = A[1]                   # න්‍යාසයක එක් දර්ශකයක්: පේළියක්
big = A[A > 4]               # තාර්කික වෙස්මුහුණක් මූලක තෝරයි
A[0, 0] = -5                 # අරාව තුළට පැවරීම
V, D = cs.call('eig', 2, A)  # ප්‍රතිඵල කිහිපයක්: cs.call(නම, කීයක්, …)
```

- 1 × 1 අරාවක් සාමාන්‍ය සංඛ්‍යාවක් ලෙස ලැබේ; අනෙකුත් අරා, විරල න්‍යාස, දැලිස්, ක්ෂේත්‍ර සහ ආකෘති **අගයන්** වේ.
- අගයකට `shape` (ටපල්), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (එහි පේළි), සහ තනි මූලකයක් සඳහා `float()`, `int()` සහ `bool()` ඇත.
- සංසන්දන (`<`, `==`, …) numpy හි මෙන් මූලකයෙන් මූලකයට වේ: ඒවා තාර්කික අගයක් දෙයි.
- ගොඩනඟන ලද ශ්‍රිතයකට ලබා දෙන සංඛ්‍යා ලැයිස්තු අරා බවට පත් වේ: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` න්‍යාසයක් සාදයි.
- dict ව්‍යුහයක් බවට සහ මිශ්‍ර දේවල ලැයිස්තුවක් කෝෂයක් බවට පත් වේ, ආපසු ද.

ඔබේ ස්ක්‍රිප්ටය සාදන සෑම ගෝලීය දෙයක් (සංඛ්‍යාවක්, අගයක්, dict, ලැයිස්තුව…) දෝෂයකට පසුවත්, ධාවනය අවසන් වන විට **විචල්‍ය** ටැබයට වැටේ. `_` වලින් ආරම්භ වන නම්, ශ්‍රිත, පන්ති සහ මොඩියුල Python තුළම රැඳේ. `ws.name` විචල්‍යයක් කෙලින්ම කියවයි හෝ සකසයි, සහ `ws_names()` ඒවා ලැයිස්තුගත කරයි.

`print(…)` කොන්සෝලයට ලියයි. `display(…)` (හෝ `cs.display`) දැලිසක්, ක්ෂේත්‍රයක් හෝ ප්ලොටයක් පෙන්වයි, CraftScript හි මෙන්.

## විශ්ලේෂණ පුස්තකාලය ඇමතීම

පුස්තකාල ශ්‍රිත ගොඩනඟන ලද ඒවා මෙන් ඇමතේ: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. නම ස්ක්‍රිප්ටයේ එලෙසම ලියන්න: PartCraft ස්ක්‍රිප්ටයක් භාවිතා කරන පුස්තකාල ශ්‍රිත එය ධාවනය කිරීමට පෙර සොයයි.

## තවම එහි නැත

- numpy, scipy සහ අනෙකුත් පැකේජ: Python හි තමන්ගේම සම්මත පුස්තකාලය (`math`, `json`, `itertools`, `decimal`, `statistics`…) පමණක් මෙහි ඇත, එහි කවුළු, ටර්මිනලය සහ දත්ත සමුදා කොටස් (`tkinter`, `curses`, `sqlite3`) නොමැතිව.
- සොකට් සහ පිටතට ළඟා විය හැකි වෙනත් කිසිවක්: මෙහි Python හට ජාලයක් නැත.
- `time.sleep` වහාම ආපසු ලබා දෙයි.
- සංස්කාරකයේ නැමීම (folding), සහ CraftScript ස්ක්‍රිප්ටයකින් Python ශ්‍රිතයක් ඇමතීම.
- ධාවනයක් සෑම පේළි 1000කට වරක් උපදෙස් අයවැය සහ නවතා දැමීම පරීක්ෂා කරයි; ගොඩනඟන ලද එක් ශ්‍රිතයක් ඇතුළේ දිගු ගණනයක් පළමුව අවසන් වේ.
