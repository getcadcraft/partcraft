## සකසන්න

1. Studio හි, PartCraft විවෘත කරන්න. {{ui:Settings}} › {{ui:PartCraft}} › {{ui:Assistants}} හි, **AI සහායකයින්ට සහ ස්ක්‍රිප්ට්වලට PartCraft භාවිත කිරීමට ඉඩ දෙන්න** ටික් කරන්න, ඉන්පසු **සංස්කරණය**.
2. Studio හි, {{ui:Connect an assistant}} තෝරන්න. එය පහත ඔබ අලවන ලිපිනය සහ token එක පෙන්වයි.
3. ස්ක්‍රිප්ට් බාගන්න: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino වෙතින්

1. Rhino හි script සංස්කාරකයේ `cadcraft_link.py` ධාවනය කරන්න (Rhino 8 හි Python 3).
2. පළමු වරට, ලිපිනය සහ token අලවන්න. ඒවා ඔබේ home folder එකේ `.cadcraft-link.json` හි තබයි, කිසි විටෙක ආකෘතිය තුළ නොවේ. Studio ආරම්භ වන සෑම වරම නව token එකක් සාදයි, එවිට ස්ක්‍රිප්ට් නැවත අසයි.

නැවැත්වීමට ස්ක්‍රිප්ට් නැවතත් ධාවනය කරන්න.

## Grasshopper වෙතින්

ලිපිනය සහ token සුරැකීමට, පළමුව Rhino හි ස්ක්‍රිප්ට් එක එක් වරක් ධාවනය කරන්න.

1. Script සංරචකයක් (Python 3) එක් කර, `cadcraft_link.py` සම්පූර්ණයම එහි අලවන්න.
2. එයට මෙම ආදාන දෙන්න: `G` (ජ්‍යාමිතිය, ලැයිස්තු ප්‍රවේශය සමඟ), `N` (නමක්, විකල්ප), `On` (boolean toggle), සහ `Target` (විකල්ප: `model` හෝ `part`, යෙදුම් දෙකම විවෘත නම්).
3. `On` true වෙත හරවන්න.

සෑම solve එකකම `G` යවා, සංරචකය අවසන් වරට යැවූ දේ ප්‍රතිස්ථාපනය කරයි.

## මෙහි එය ක්‍රියා කරන ආකාරය

- **එක ශරීරයක්.** ආකෘතියේ දෘශ්‍යමාන සියල්ල එක ආයාත විශේෂාංගයක් බවට පත්වේ, ඔබ [.3dm ගොනුවක් විවෘත කරන විට](topic:open-3dm-files) මෙන්.
- **එය වැසිය යුතුයි.** PartCraft කුඩා සිදුරු සහ පැතලි විවරයන් පුරවයි, අනෙක් වැඩසටහනට කීයක් දැයි දන්වයි. ආකෘතිය තවමත් නොවැසුණොත්, PartCraft එහි තිබූ ශරීරය තබයි සහ තත්ත්ව තීරුවෙන් එය පවසයි. වැසෙන ඊළඟ වෙනස එය යාවත්කාලීන කරයි.
- **ඔබ කරන දේ අවසන් කරන්න.** ස්කෙචයක හෝ ඇඳීමක, යාවත්කාලීන ප්‍රතික්ෂේප වී නැවත උත්සාහ කෙරේ; ඔබ ආකෘතියට ආපසු ගිය පසු ඒවා පැමිණේ.
- **අහෝසි කරන්න.** එකිනෙකට තත්පර දෙකක් ඇතුළත යාවත්කාලීන එක් අහෝසි පියවරක් බෙදා ගනී.
- **සුරකින්න.** කොටස් ගොනුව සම්බන්ධතාවය තබයි. එය නැවත විවෘත කිරීමෙන් පසු ස්ක්‍රිප්ට් නැවත ධාවනය කරන්න, එවිට එම විශේෂාංගය යාවත්කාලීන වේ.

**එක් මාර්ගයකට පමණි.** මෙහි වෙනස්කම් අනෙක් වැඩසටහනට ආපසු නොයයි.
