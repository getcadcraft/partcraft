Python هي اللغة الثالثة في [مساحة السكربت](topic:craftscript). اختر **Python** في مربع اللغة فوق المحرّر (يُفتح ملف `.py` بلغة Python تلقائيًا). تتشارك Python وLua وCraftScript المتغيرات نفسها والدوال المدمجة نفسها، فيمكن لسكربت Python استخدام ما أنشأه سكربت CraftScript، والعكس.

يحمّل أول تشغيل لـ Python في الزيارة Python نفسها (CPython 3.14، بحجم نحو 7 MB) من هذا الموقع، وهذا يستغرق بضع ثوانٍ. ولا تدخل Python في {{ui:حفظ للعمل دون اتصال}} بعد: شغّل سكربت Python واحدًا وأنت متصل أولًا.

## Python معزولة

سكربتات Python معزولة مثل سكربتات CraftScript وLua: تصل إلى الجزء والمتغيرات والدوال المدمجة، ولا شيء غير ذلك. كل تشغيل هو Python جديدة في صندوق حماية خاص بها، مع شجرة ملفات صغيرة في الذاكرة (مكتبتها القياسية ومجلد `/tmp` الذي يزول بعد التشغيل). لا تستطيع الوصول إلى الشبكة أو ملفاتك أو بقية الصفحة، سواء في المتصفح أو في سطر الأوامر. وقد يستهلك سكربت من شخص آخر وقتًا أو ذاكرة كثيرة: ينهيه {{ui:إيقاف}}.

## الأساسيات

```
A = cs.magic(3)              # كل دالة مدمجة هي cs.<name>
B = A @ A.T                  # @ هو الضرب المصفوفي، و.T هو المنقول
C = A * 2 + 1                # + - * / ** عنصر بعنصر، كما في numpy
print(A[0, 1], A[-1, -1])    # من الصفر؛ والسالب يُعد من النهاية
row = A[1]                   # فهرس واحد على مصفوفة: صف
big = A[A > 4]               # القناع المنطقي يختار العناصر
A[0, 0] = -5                 # الإسناد إلى مصفوفة
V, D = cs.call('eig', 2, A)  # عدة نتائج: cs.call(name, how many, …)
```

- المصفوفة 1 × 1 تصل كعدد عادي؛ أما المصفوفات الأخرى والمصفوفات المتناثرة والشبكات والحقول والنماذج فهي **Values**.
- لكل Value الخصائص `shape` (tuple)، و`T`، و`type`، والدوال `numel()` و`copy()` و`tolist()` و`len()` (عدد صفوفها)، والدوال `float()` و`int()` و`bool()` لعنصر واحد.
- المقارنات (`<`، `==`، …) عنصرًا بعنصر، كما في numpy: وتعطي Value منطقيًا.
- تتحول قوائم الأعداد التي تُمرَّر إلى دالة مدمجة إلى مصفوفات: `cs.sum([1, 2, 3])`. و`cs.tensor([[1, 2], [3, 4]])` ينشئ مصفوفة.
- يتحول القاموس (dict) إلى بنية، والقائمة المختلطة إلى خلية، والعكس أيضًا.

كل متغير عام يُنشئه سكربتك (عدد، أو Value، أو قاموس، أو قائمة…) يُضاف إلى تبويب **المتغيرات** عند انتهاء التشغيل، حتى بعد خطأ. أما الأسماء التي تبدأ بـ`_`، والدوال والفئات والوحدات، فتبقى داخل Python. و`ws.name` يقرأ متغيرًا أو يضبطه مباشرة، و`ws_names()` يسرد المتغيرات.

`print(…)` يكتب إلى وحدة التحكم. و`display(…)` (أو `cs.display`) يعرض شبكة أو حقلًا أو رسمًا، كما في CraftScript.

## استدعاء مكتبة التحليل

تُستدعى دوال المكتبة كما تُستدعى الدوال المدمجة: `cs.box_mesh(20, 10, 10, 5, 'hex')`، و`cs.call('modal_tet', 2, …)`. اكتب الاسم في السكربت كما هو: يجد PartCraft دوال المكتبة التي يستخدمها السكربت قبل تشغيله.

## ما ليس موجودًا بعد

- numpy وscipy وحزم أخرى: المتوفر هو المكتبة القياسية الخاصة بـ Python فقط (`math` و`json` و`itertools` و`decimal` و`statistics`…)، دون أجزائها الخاصة بالنوافذ والطرفية وقواعد البيانات (`tkinter` و`curses` و`sqlite3`).
- المقابس (Sockets) وكل ما يصل إلى الخارج: لا توجد شبكة لـ Python هنا.
- `time.sleep` يعود فورًا.
- طيّ الشيفرة في المحرّر، واستدعاء دالة Python من سكربت CraftScript.
- يتحقق التشغيل من ميزانية التعليمات ومن الإيقاف كل 1000 سطر؛ والحساب الطويل داخل دالة مدمجة واحدة يكتمل أولًا.
