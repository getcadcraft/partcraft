تُعدّ CraftScript لغة مصفوفات مكتوبة لتُقرأ كما تُقرأ MATLAB، لذلك تعمل معظم الشيفرات العددية الكلاسيكية (مثل شيفرة تحسين الطوبولوجيا المكوّنة من 88 سطرًا، على سبيل المثال) بتعديلات طفيفة فقط. تعمل في [مساحة السكربت](topic:craftscript) وفي سطر الأوامر.

## القيم

| النوع | مثال | ملاحظات |
|---|---|---|
| عدد، مصفوفة | `a = 3`، `v = [1 2 3]`، `A = [1 2; 3 4]` | كل عدد هو مصفوفة (بحجم 1×1). تُخزَّن المصفوفات عمودًا بعمود، حتى 8 أبعاد |
| منطقي | `A > 2`، `true` | مصفوفات صواب/خطأ؛ وتُستخدم كفهارس |
| نص | `'beam'`، `"beam"` | |
| مصفوفة متناثرة | `sparse(i, j, v, n, n)` | لمصفوفات الصلابة |
| شبكة، حقل، نموذج | `hexGrid(…)`، `part()`، `load('part.stl')` | ما يرسمه `show` |
| بنية | `s.E = 210e3` | حقول مسمّاة |
| خلية | `c = {1, 'two', [3 4]}` | قائمة من أي قيم |
| مقبض دالة | `f = @(x) x.^2` | |

## المصفوفات والفهرسة

- النطاقات: `1:5`، `0:0.1:1`. و`linspace(a, b, n)`، و`zeros(n, m)`، و`ones`، و`eye`، و`rand`.
- تبدأ الفهرسة من 1: `A(2, 3)`، و`v(end)`، و`A(:, 1)` (عمود كامل)، و`A(:)` (كل شيء كعمود واحد)، و`v(v > 0)` (الفهرسة المنطقية).
- الكتابة بعد النهاية تُوسّع المصفوفة كما في MATLAB: `v(10) = 1`.

## العوامل

- `+ - * / \ ^` عمليات مصفوفية (`A \ b` يحلّ)؛ و`.* ./ .^` تعمل عنصرًا بعنصر. و`'` ينقل المصفوفة.
- المقارنات `== ~= < <= > >=`؛ والمنطق `& | ~` (عنصرًا بعنصر) و`&& ||` (قصر الدائرة).

## التحكم في التدفق والدوال

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

تُكتب الدوال في السكربت بعد أوامره، أو في تبويب السكربت الخاص بها الذي يحمل اسم الدالة:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

يُبحث عن الاسم بهذا الترتيب: متغيّر، ثم سكربت في هذا الجزء بهذا الاسم، ثم دالة من المكتبة، ثم دالة مدمجة.

## الصدى والتعليقات والمخرجات

- العبارة التي لا تنتهي بـ `;` تطبع قيمتها؛ و`;` تُبقيها صامتة.
- `%` يبدأ تعليقًا؛ و`%{` و`%}` في سطرين مستقلين تُعلِّقان ما بينهما من أسطر.
- تطبع `disp(x)` و`fprintf('%g\n', x)` و`display(x)` إلى وحدة التحكم.

## الأخطاء والحدود

- تذكر الأخطاء ما الذي حدث بكلمات واضحة، وتعطي السطر (وسلسلة استدعاءات الدوال).
- لكل تشغيل ميزانية خطوات (خيارات التشغيل في اللوحة)؛ تتوقف الحلقة اللانهائية برسالة، أو اضغط إيقاف.
- تحمل المصفوفة الواحدة حتى 134 مليون قيمة.

## الاختلافات عن MATLAB

- تضع أوامر الرسم خياراتها داخل الاستدعاء: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. وتُقبل `figure` و`hold` و`axis` و`title(…)` وما شابهها، لكنها لا تفعل شيئًا.
- لا تُدعم `input` و`keyboard`: لا يستطيع السكربت أن يتوقف ليطرح سؤالًا.
- لا توجد صناديق أدوات؛ المتاح هو [مكتبة التحليل](topic:craftscript-library) والدوال المدمجة.
