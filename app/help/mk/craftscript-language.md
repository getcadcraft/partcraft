CraftScript е матричен јазик напишан така да се чита како MATLAB, па повеќето класични нумерички кодови (на пример кодот за оптимизација на топологија од 88 линии) работат со мали измени. Работи во [работниот простор за скрипти](topic:craftscript) и од командната линија.

## Вредности

| Тип | Пример | Забелешки |
|---|---|---|
| Број, низа | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Секој број е низа (1×1). Низите се чуваат колона по колона, до 8 димензии |
| Логичка | `A > 2`, `true` | Низи од true/false; може да се користат како индекси |
| Текст | `'beam'`, `"beam"` | |
| Ретка матрица | `sparse(i, j, v, n, n)` | За матриците на крутост |
| Мрежа, поле, модел | `hexGrid(…)`, `part()`, `load('part.stl')` | Она што го црта `show` |
| Структура | `s.E = 210e3` | Именувани полиња |
| Ќелија | `c = {1, 'two', [3 4]}` | Список од какви било вредности |
| Ракувач на функција | `f = @(x) x.^2` | |

## Низи и индексирање

- Опсези: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индексирањето почнува од 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (цела колона), `A(:)` (сè како една колона), `v(v > 0)` (логичко индексирање).
- Доделување надвор од крајот ја проширува низата, како во MATLAB: `v(10) = 1`.

## Оператори

- `+ - * / \ ^` се матрични операции (`A \ b` решава); `.* ./ .^` работат елемент по елемент. `'` транспонира.
- Споредби `== ~= < <= > >=`; логика `& | ~` (елемент по елемент) и `&& ||` (со скратено сметање).

## Контрола на текот и функции

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функциите се ставаат во скрипта по нејзините наредби, или во сопствена табулација на скрипта со името на функцијата:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Името се бара по овој редослед: променлива, скрипта во овој дел со тоа име, функција од библиотеката, вградена функција.

## Испис, коментари, излез

- Наредба без `;` ја печати својата вредност; `;` ја држи тивка.
- `%` започнува коментар; `%{` и `%}` на сопствени редови ги коментираат редовите меѓу нив.
- `disp(x)`, `fprintf('%g\n', x)` и `display(x)` печатат во конзолата.

## Грешки и ограничувања

- Грешките со едноставни зборови кажуваат што не е во ред и ја даваат линијата (и синџирот на повици на функции).
- Секое извршување има буџет на чекори (опции за извршување во панелот); бесконечна јамка запира со порака, или притиснете {{ui:Запри}}.
- Низите содржат до 134 милиони вредности секоја.

## Не е како MATLAB

- Наредбите за графици ги ставаат опциите во повикот: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` и слични се прифаќаат и не прават ништо.
- `input` и `keyboard` не се поддржани: скриптата не може да запре и да постави прашање.
- Нема алатки (toolbox): [библиотеката за анализа](topic:craftscript-library) и вградените функции се сè што постои.
