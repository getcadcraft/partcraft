Python е третиот јазик на [работниот простор за скрипти](topic:craftscript). Изберете **Python** во кутијата за јазик над уредникот (датотеката `.py` се отвора во Python сама по себе). Python, Lua и CraftScript ги делат истите променливи и истите вградени функции, па скриптата во Python може да го користи она што го направила скрипта во CraftScript, и обратно.

Првото извршување на Python во една посета го вчитува самиот Python (CPython 3.14, околу 7 MB) од оваа страница, што трае неколку секунди. Python сè уште не е дел од {{ui:Зачувај за офлајн}}: прво извршете една Python скрипта додека сте на мрежа.

## Python е затворен

Python скриптите се затворени како CraftScript и Lua скриптите: достапни им се делот, променливите и вградените функции, и ништо друго. Секое извршување е нов Python во сопствен сандбокс со мало дрво на датотеки во меморија (неговата стандардна библиотека и папка `/tmp` што исчезнува по извршувањето). Не може да пристапи до мрежата, до вашите датотеки или до остатокот од страницата, во прелистувачот и во командната линија подеднакво. Скрипта од некој друг сепак може да троши многу време или меморија: {{ui:Запри}} ја прекинува.

## Основно

```
A = cs.magic(3)              # секоја вградена функција е cs.<name>
B = A @ A.T                  # @ е матричен производ, .T транспонирање
C = A * 2 + 1                # + - * / ** се елемент по елемент, како во numpy
print(A[0, 1], A[-1, -1])    # од 0; негативните броиме од крајот
row = A[1]                   # еден индекс на матрица: ред
big = A[A > 4]               # логичка маска ги избира елементите
A[0, 0] = -5                 # доделување во низа
V, D = cs.call('eig', 2, A)  # неколку резултати: cs.call(име, колку, …)
```

- Низа 1 × 1 стигнува како обичен број; другите низи, ретките матрици, мрежите, полињата и моделите се **Вредности**.
- Вредноста има `shape` (торка), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (нејзините редови), и `float()`, `int()` и `bool()` за еден елемент.
- Споредбите (`<`, `==`, …) се елемент по елемент, како во numpy: даваат логичка Вредност.
- Списоци од броеви предадени на вградена функција стануваат низи: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` прави матрица.
- Речник станува структура, а мешана листа ќелија, и обратно.

Секоја глобална променлива што ја прави скриптата (број, Вредност, речник, листа…) се појавува во табот **Променливи** кога ќе заврши извршувањето, дури и после грешка. Имињата што почнуваат со `_`, функциите, класите и модулите остануваат во Python. `ws.name` чита или поставува променлива директно, а `ws_names()` ги наведува.

`print(…)` пишува во конзолата. `display(…)` (или `cs.display`) прикажува мрежа, поле или график, како во CraftScript.

## Повик на библиотеката за анализа

Функциите од библиотеката се повикуваат како вградените: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Напишете го името во скриптата како што е: PartCraft ги наоѓа функциите од библиотеката што ги користи скриптата пред да работи.

## Уште не е тука

- numpy, scipy и други пакети: тука е само стандардната библиотека на Python (`math`, `json`, `itertools`, `decimal`, `statistics`…), без нејзините делови за прозорци, терминал и база (`tkinter`, `curses`, `sqlite3`).
- Сокети и сè друго што би излегло надвор: Python тука нема мрежа.
- `time.sleep` се враќа веднаш.
- Свивање (folding) во уредникот и повикување на Python функција од скрипта на CraftScript.
- Извршувањето ги проверува буџетот на инструкции и {{ui:Запри}} на секои 1000 линии; долга пресметка во една вградена функција прво ќе заврши.
