কোনো প্যানেলের একটি বাক্সে লেখার সময় কী কোনো কাজ করে না, তবে {{key:Mod+S}} ও {{key:Mod+O}} ব্যতিক্রম, এগুলো সবসময় কাজ করে। অক্ষর কী কোনো মডিফায়ার ছাড়াই কাজ করে।

ব্রাউজারের কী এবং ফাংশন কী-বিহীন কীবোর্ড সম্পর্কে সাধারণ নোট: [কী, মাউস ও ট্র্যাকপ্যাড](common:keys)।

## সর্বত্র

| কী | কাজ |
|---|---|
| {{key:Mod+S}} | পার্ট সংরক্ষণ করুন (অ্যাসেম্বলিতে: অ্যাসেম্বলি)। আগে খোলা স্কেচ বন্ধ করে |
| {{key:Mod+O}} | পার্ট বা অ্যাসেম্বলি ফাইল খুলুন (সংরক্ষণ না করা পরিবর্তন থাকলে আগে জিজ্ঞেস করে) |
| {{key:Mod+Z}} | পূর্বাবস্থায় ফিরুন |
| {{key:Mod+Y}} বা {{key:Mod+Shift+Z}} | আবার করুন |
| {{key:F1}} | এই সহায়তা খুলুন বা বন্ধ করুন (অ্যাপ বারের {{ui:Help}}-ও)। {{key:Esc}} দিয়েও এটি বন্ধ হয়। অনেক ল্যাপটপ ও Mac কীবোর্ডে Fn চেপে ধরে রাখুন |
| {{key:Ctrl+Shift+F}} | স্ক্রিন মোড: স্বাভাবিক, পূর্ণ স্ক্রিন, বার লুকানো পূর্ণ স্ক্রিন। Mac-এও Control, ⌘ নয় |
| {{key:Esc}} | পূর্ণ স্ক্রিন থেকে বের হন (পূর্ণ স্ক্রিনে থাকলে) |
| {{key:Mod+,}} | সেটিংস, PartCraft ট্যাবসহ (দেখুন [PartCraft-এর সেটিংস](topic:settings)) |

প্যানেলের সংখ্যার বাক্সে {{key:Mod+Z}} ব্রাউজারের নিজস্ব লেখা পূর্বাবস্থায় ফেরায়। স্কেচ মাপের উপরের সংখ্যার বাক্সে এটি PartCraft-এ পূর্বাবস্থায় ফেরায়।

## কপি, পেস্ট ও ডুপ্লিকেট

এগুলো আপনি যেখানে কাজ করছেন সেখানকার জিনিসেই কাজ করে: খোলা স্কেচে নির্বাচিত জ্যামিতি, ইতিহাসে নির্বাচিত ফিচার, বা অ্যাসেম্বলিতে নির্বাচিত পার্ট। বিস্তারিত [কপি, পেস্ট ও ডুপ্লিকেট](topic:copy-paste)-এ।

| কী | কাজ |
|---|---|
| {{key:Mod+C}} | নির্বাচন কপি করুন |
| {{key:Mod+X}} | কাট: কপি করে তারপর মুছুন |
| {{key:Mod+V}} | পেস্ট। স্কেচে কপিটি পয়েন্টারের সঙ্গে চলে: যেখানে যাবে সেখানে ক্লিক করুন |
| {{key:Mod+Shift+V}} | একই জায়গায় পেস্ট: একই কোঅর্ডিনেটে (অ্যাসেম্বলিতে, একই স্থানে) |
| {{key:Mod+D}} | ডুপ্লিকেট: এক ধাপে কপি ও পেস্ট, ক্লিপবোর্ড অপরিবর্তিত থাকে |
| {{key:Mod+A}} | সব নির্বাচন করুন (স্কেচে) |
| {{key:Esc}} | কিছুই নির্বাচন না করুন (এবং পয়েন্টারের সঙ্গে চলা পেস্ট বাতিল করুন) |

সংখ্যার বাক্সে এই কীগুলো স্বাভাবিকভাবে লেখা কপি ও পেস্ট করে। প্যানেলে নির্বাচিত লেখা ব্রাউজার কপি করে।

## পার্টের উপর (কোনো স্কেচ খোলা নেই)

| কী | কাজ |
|---|---|
| {{key:S}} | নির্বাচিত সমতল বা সমতল তলে স্কেচ করুন; কিছু নির্বাচন না থাকলে ক্লিক করে জায়গা বেছে নিন |
| {{key:F}} | পার্টটি ভিউতে ফিট করুন |
| {{key:M}} | পরিমাপ, সব ওয়ার্কস্পেসে ও অ্যাসেম্বলিতে; {{key:Esc}} বাছাই মুছে দেয়, আবার {{key:Esc}} এটি বন্ধ করে (দেখুন [দূরত্ব, কোণ ও ভর পরিমাপ](topic:measure)) |
| {{key:X}} | সেকশন ভিউ চালু বা বন্ধ, সব ওয়ার্কস্পেসে ও অ্যাসেম্বলিতে; {{key:Esc}} এটি বন্ধ করে (দেখুন [সেকশন ভিউ দিয়ে ভেতরে দেখুন](topic:section-view)) |
| {{key:Delete}} | নির্বাচিত ফিচার মুছুন (অন্যরা ব্যবহার করলে জিজ্ঞেস করে) |
| {{key:0}} … {{key:9}}, {{key:.}} | ফিচার নির্বাচিত থাকলে তার প্রধান সংখ্যাটি লিখুন (এক্সট্রুডের গভীরতা, হোলের ব্যাস, প্যাটার্নের সংখ্যা, ফিলেটের ব্যাসার্ধ …), তারপর {{key:Enter}}। {{key:Esc}} পুরোনো মানটি রাখে |
| {{key:Backspace}} | একটি ফিচার নির্বাচিত থাকলে সেটি মুছুন |
| {{key:Esc}} | স্কেচ সমতল বাছাই বন্ধ করুন, বা নির্বাচন মুছুন ({{key:Shift}} দিয়ে বাছা প্রান্ত বা তলও) |

## 3D ভিউতে

আগে ভিউতে ক্লিক করুন, যাতে ভিউটি কীবোর্ড ফোকাস পায়।

| কী | কাজ |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | ভিউ ১৫ ডিগ্রি ঘোরান |
| {{key:Shift+Left}} ও অন্য তীরগুলো | প্যান |
| {{key:Plus}} বা {{key:=}} | জুম ইন |
| {{key:Minus}} | জুম আউট |

| মাউস | কাজ |
|---|---|
| বাম বাটন টেনে ধরে টানুন | ভিউ ঘোরান (অরবিট) |
| ডান বা মধ্য বাটন টেনে ধরে টানুন | প্যান |
| বাম বাটন টানার সময় {{key:Shift}}, {{key:Ctrl}} বা ⌘ ধরে রাখুন | প্যান |
| হুইল ঘোরান | পয়েন্টারের জায়গায় জুম (দূরে ঠেললে জুম ইন হয়) |
| ট্র্যাকপ্যাডে দুই আঙুল সোয়াইপ | ভিউ ঘোরান; {{key:Shift}} সহ প্যান। পিঞ্চ জুম করে। [PartCraft-এর সেটিংস](topic:settings)-এর **স্ক্রোলিং** দিয়ে ঠিক করা হয় |

[PartCraft-এর সেটিংস](topic:settings)-এ **ভিউ ঘোরানো: মধ্য বাটন** চালু থাকলে মধ্য বাটন ভিউ ঘোরায়, {{key:Shift}} সহ মধ্য বাটন বা ডান বাটন প্যান করে, এবং বাম বাটন শুধু বাছাই করে।
| ক্লিক | একটি তল (পুরোটা হাইলাইট হয়), একটি প্রান্ত বা একটি সমতল বাছাই করুন |
| {{key:Shift}}+ক্লিক প্রান্ত বা তল | একাধিক প্রান্ত বা তল সংগ্রহ করুন |
| ফাঁকা জায়গায় ক্লিক করুন | বাছাই মুছুন |

## ফিলেট, চ্যামফার বা শেল-এর জন্য প্রান্ত বা তল বাছাই করার সময়

| কী বা মাউস | কাজ |
|---|---|
| প্রান্ত বা তলে ক্লিক করুন | যোগ করুন, আগে থেকে থাকলে বাদ দিন |
| {{key:Esc}} বা {{key:Enter}} | বাছাই শেষ করুন ({{ui:Done}}-এর মতো) |
| {{key:F}} | ফিট |
| তীর কী, ভিউ ফোকাসে থাকলে | ঘোরান; {{key:Shift}} সহ, প্যান |

## ড্রয়িং শিটে

|---|---|
| {{key:F}} | শিট ফিট করুন |
| {{key:Plus}} / {{key:Minus}} | জুম (শিট ফোকাসে থাকলে) |
| {{key:Shift+Left}} ও অন্য তীরগুলো | প্যান (শিট ফোকাসে থাকলে) |
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | নির্বাচিত GD&T প্রতীক ১ mm সরান |

| {{key:Esc}} | প্রতীক বসানো বন্ধ করুন; না হলে নির্বাচন মুছুন; না হলে মডেলে ফিরে যান |

| মাউস | কাজ |
|---|---|

| প্রতীকে ক্লিক করুন | প্রতীকটি নির্বাচন করুন |
| প্রতীক টেনে সরান | সরে যায় (লিডার তার বিন্দুতে থাকে) |
| হুইল ঘোরান | পয়েন্টারের জায়গায় জুম |
| ডান বা মধ্য বাটন টেনে ধরে টানুন | প্যান |

| {{key:Alt+Up}} / {{key:Alt+Down}} | নির্বাচিত ফিচার উপরে বা নিচে সরান, ইতিহাস যেখানে অনুমতি দেয় |
| {{key:F2}} | সারিতে ফিচারের প্রধান সংখ্যা বদলান; {{key:Enter}} দিয়ে সেট করুন, {{key:Esc}} পুরোনোটি রাখে |

| কী | কাজ |
|---|---|
| {{key:J}} | একটি জয়েন্ট শুরু করুন: তারপর দুটি পার্টের প্রতিটিতে একটি করে সমতল তলে ক্লিক করুন |
| {{key:F}} | ফিট |
| {{key:Esc}} | শুরু করা জয়েন্ট বাতিল করুন, বা নির্বাচন মুছুন |
| {{key:Delete}} | নির্বাচিত পার্ট বা জয়েন্ট সরিয়ে দিন |
| {{key:Backspace}} | নির্বাচিত পার্ট বা জয়েন্ট সরিয়ে দিন |
| {{key:Mod+Z}} / {{key:Mod+Y}} | অ্যাসেম্বলির নিজস্ব তালিকায় পূর্বাবস্থায় ফিরুন ও আবার করুন |
| {{key:Mod+D}} | নির্বাচিত পার্ট ডুপ্লিকেট করুন (একই পার্ট, অন্যগুলোর পাশে) |

## ব্রাউজার যেসব শর্টকাট নিতে পারে

- Safari-তে {{key:Mod+Y}} ইতিহাস খুলতে পারে: আবার করতে {{key:Mod+Shift+Z}} ব্যবহার করুন।
- {{key:Mod+D}} ব্রাউজারের বুকমার্ক কী: অ্যাপ ফোকাসে থাকলে PartCraft এটি নেয়, আর কোনো বাক্সে লেখার সময় ছেড়ে দেয়।
- {{key:F11}} ও {{key:Mod+Plus}} / {{key:Mod+Minus}} ব্রাউজারের পূর্ণ স্ক্রিন ও পেজ জুম, PartCraft-এর নয়। পূর্ণ স্ক্রিনের জন্য {{key:Ctrl+Shift+F}} ও মডেলের জন্য হুইল ব্যবহার করুন।
- অনেক ল্যাপটপ ও Mac-এ ফাংশন কীর জন্য Fn কী লাগে: সহায়তার জন্য Fn+{{key:F1}} চাপুন, বা {{ui:Help}} বোতাম ব্যবহার করুন।

টাচ ও ট্র্যাকপ্যাড অঙ্গভঙ্গি: [ট্র্যাকপ্যাড, টাচ ও ছোট স্ক্রিন](topic:trackpad-and-touch)।

## সরান কোথায় থাকে

সরান ফিচার গ্রুপের {{ui:আরও}} মেনুতে {{ui:বডি সরান}} হিসেবে থাকে, {{ui:সরান}} বাক্সে যেখানে ΔX, ΔY ও ΔZ লেখেন, এবং পার্টের উপর {{ui:সরাতে টানুন}} তীর হিসেবে।
