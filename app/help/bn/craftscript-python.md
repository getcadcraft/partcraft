Python হলো [Script ওয়ার্কস্পেসের](topic:craftscript)-এর তৃতীয় ভাষা। এডিটরের উপরের ভাষার বাক্সে **Python** বাছুন (একটি `.py` ফাইল নিজে থেকে Python-এ খোলে)। Python, Lua ও CraftScript একই ভেরিয়েবল ও একই বিল্ট-ইন ফাংশন শেয়ার করে, তাই একটি Python স্ক্রিপ্ট CraftScript স্ক্রিপ্টের বানানো জিনিস ব্যবহার করতে পারে, এবং উল্টোটাও।

একটি ভিজিটে প্রথম Python চালানো Python নিজেই এই সাইট থেকে লোড করে (CPython 3.14, প্রায় 7 MB), যার জন্য কয়েক সেকেন্ড লাগে। Python এখনো {{ui:অফলাইনের জন্য সংরক্ষণ করুন}}-এর অংশ নয়: আগে অনলাইনে একটি Python স্ক্রিপ্ট চালান।

## Python সিল করা

Python স্ক্রিপ্ট CraftScript ও Lua স্ক্রিপ্টের মতোই সিল করা: এরা পার্ট, ভেরিয়েবল ও বিল্ট-ইন ফাংশনে পৌঁছায়, আর কিছুতে নয়। প্রতিটি রান একটি নতুন Python, তার নিজের স্যান্ডবক্সে, মেমোরিতে একটি ছোট ফাইল ট্রি সহ (এর স্ট্যান্ডার্ড লাইব্রেরি ও একটি `/tmp` ফোল্ডার, যা রান শেষে মুছে যায়)। এটি নেটওয়ার্ক, আপনার ফাইল বা পেজের বাকি অংশে পৌঁছাতে পারে না, ব্রাউজারে ও কমান্ড লাইনে একইভাবে। অন্য কারো স্ক্রিপ্ট এখনো অনেক সময় বা মেমোরি নিতে পারে: {{ui:থামান}} এটি শেষ করে।

## মূল বিষয়

```
A = cs.magic(3)              # প্রতিটি বিল্ট-ইন ফাংশন cs.<name>
B = A @ A.T                  # @ ম্যাট্রিক্স গুণ, .T ট্রান্সপোজ
C = A * 2 + 1                # + - * / ** numpy-র মতো প্রতিটি উপাদানে
print(A[0, 1], A[-1, -1])    # 0-ভিত্তিক; ঋণাত্মক শেষ থেকে গোনে
row = A[1]                   # একটি ইনডেক্সে ম্যাট্রিক্স: একটি সারি
big = A[A > 4]               # একটি লজিক্যাল মাস্ক উপাদান বাছে
A[0, 0] = -5                 # অ্যারেতে অ্যাসাইন করা
V, D = cs.call('eig', 2, A)  # একাধিক ফলাফল: cs.call(name, কতগুলো, …)
```

- 1 × 1 অ্যারে একটি সাধারণ সংখ্যা হিসেবে আসে; অন্য অ্যারে, স্পার্স ম্যাট্রিক্স, মেশ, ফিল্ড ও মডেল হলো **Values**।
- একটি Value-র `shape` (একটি tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (এর সারি), এবং একটি একক উপাদানের জন্য `float()`, `int()` ও `bool()` আছে।
- তুলনা (`<`, `==`, …) numpy-র মতো প্রতিটি উপাদানে হয়: এরা একটি লজিক্যাল Value দেয়।
- বিল্ট-ইন ফাংশনে পাঠানো সংখ্যার তালিকা অ্যারে হয়ে যায়: `cs.sum([1, 2, 3])`। `cs.tensor([[1, 2], [3, 4]])` একটি ম্যাট্রিক্স বানায়।
- একটি dict স্ট্রাক্ট হয়, এবং মিশ্র জিনিসের একটি তালিকা সেল হয়, এবং আবার ফিরে।

আপনার স্ক্রিপ্টের বানানো প্রতিটি গ্লোবাল (একটি সংখ্যা, একটি Value, একটি dict, একটি list…) রান শেষে **Variables** ট্যাবে যায়, এমনকি ত্রুটির পরেও। `_` দিয়ে শুরু নাম, ফাংশন, ক্লাস ও মডিউল Python-এ থাকে। `ws.name` সরাসরি একটি ভেরিয়েবল পড়ে বা সেট করে, এবং `ws_names()` তাদের তালিকা করে।

`print(…)` কনসোলে লেখে। `display(…)` (বা `cs.display`) একটি মেশ, ফিল্ড বা প্লট দেখায়, CraftScript-এর মতো।

## বিশ্লেষণ লাইব্রেরি কল করুন

লাইব্রেরি ফাংশনগুলো বিল্ট-ইনের মতো কল হয়: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`। নামটি স্ক্রিপ্টে যেমন আছে তেমন লিখুন: PartCraft চালানোর আগে একটি স্ক্রিপ্ট যে লাইব্রেরি ফাংশনগুলো ব্যবহার করে তা খুঁজে নেয়।

## এখনো নেই

- numpy, scipy ও অন্য প্যাকেজ: শুধু Python-এর নিজস্ব স্ট্যান্ডার্ড লাইব্রেরি (`math`, `json`, `itertools`, `decimal`, `statistics`…) আছে, এর উইন্ডো, টার্মিনাল ও ডেটাবেস অংশ ছাড়া (`tkinter`, `curses`, `sqlite3`)।
- সকেট ও বাইরে পৌঁছাতে পারে এমন যেকোনো কিছু: এখানে Python-এর নেটওয়ার্ক নেই।
- `time.sleep` সঙ্গে সঙ্গে ফেরে।
- এডিটরে ফোল্ডিং, এবং একটি CraftScript স্ক্রিপ্ট থেকে একটি Python ফাংশন কল করা।
- একটি রান প্রতি 1000 লাইনে ইনস্ট্রাকশন বাজেট ও থামানো পরীক্ষা করে; একটি বিল্ট-ইন ফাংশনের ভেতরের দীর্ঘ গণনা আগে শেষ হয়।
