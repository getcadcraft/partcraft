Script ওয়ার্কস্পেসের একটি বিশ্লেষণ কয়েকটি ছোট স্ক্রিপ্ট, যারা একে অপরকে ভেরিয়েবল দেয়। আপনার প্রয়োজনের কাছাকাছি একটি [লাইব্রেরি](topic:craftscript-library) ফাংশন থেকে শুরু করুন, একটি কপি তৈরি করুন, এবং বদলান; অথবা নিচের মতো ধাপে ধাপে তৈরি করুন।

## 1. একটি মেশ

```
model = part();                  % আপনি যে পার্টটি মডেল করছেন, একটি মডেল হিসেবে
m = tetmesh(model, 4);           % প্রায় 4 mm চওড়া টেট্রাহেড্রা
show(m)
```

এগোনোর আগে ভিউতে মেশটি পরীক্ষা করুন: {{key:F}} এটি ফিট করে, **দেখানো** তালিকার {{ui:চোখ}} পার্টটি লুকায়।

## 2. জোড়া লাগান ও সমাধান করুন

এলিমেন্ট লুপটি স্ক্রিপ্টে লিখুন (এটি পাঠ্যবইয়ের মতো পড়া যায়), আর ভারী অংশগুলো বিল্ট-ইন ফাংশনে রাখুন: এলিমেন্ট ম্যাট্রিক্স, ট্রিপলেট থেকে স্পার্স অ্যাসেম্বলি, এবং প্রিকন্ডিশনারসহ কনজুগেট গ্রেডিয়েন্ট সলভার। একটি লাইব্রেরি ফাংশন যেমন `static_tet` (লাইব্রেরিতে থাকলে) নকল করার জন্য একটি সম্পূর্ণ উদাহরণ।

## 3. ফল দেখান

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % প্রতি নোডে একটি মান
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- লেজেন্ডের পরিসর টাইপ করা যায়, অথবা {{ui:স্বয়ংক্রিয়}}-তে ফেরানো যায়।
- একটি নোডের মান পড়তে মেশে ক্লিক করুন।
- একই `'id'` থাকা প্লট জায়গায় আপডেট হয়, তাই কনভার্জেন্স দেখতে আপনার লুপের ভেতরে print ও plot করুন।

## 4. যাচাই করুন

জানা কিছুর সাথে তুলনা করুন: একটি ক্যান্টিলিভারের টিপ বিচ্যুতির সাথে PL³/3EI, একটি ছিদ্রসহ প্লেটের সাথে তার স্ট্রেস কনসেন্ট্রেশন ফ্যাক্টর, প্রতিক্রিয়ার সাথে লোড। যাচাইটি আলাদা স্ক্রিপ্ট হিসেবে লিখুন, যাতে প্রতিটি পরিবর্তনের পর আবার চলে:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. রাখুন

- প্রতিটি ধাপ নিজের স্ক্রিপ্ট ট্যাব হতে পারে: তারা ভেরিয়েবল শেয়ার করে, তাই একটির পর একটি চালান।
- স্ক্রিপ্ট পার্টের মধ্যে সংরক্ষিত হয়। ফলও রাখতে Variables ট্যাবে **পার্টের সাথে ভেরিয়েবল সংরক্ষণ করুন** টিক দিন (32 MB পর্যন্ত)।
- স্ক্রিপ্ট গ্রুপের {{ui:সংরক্ষণ করুন}} একটি স্ক্রিপ্ট শেয়ার করার জন্য ডাউনলোড করে; {{ui:খুলুন}} একটি স্ক্রিপ্ট আনে।
