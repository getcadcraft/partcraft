একটি জেনারেটর হলো একটি সাধারণ স্ক্রিপ্ট ([CraftScript](topic:craftscript), Lua বা Python), যার শুরুতে কয়েকটি মন্তব্য লাইন থাকে। PartCraft মন্তব্যগুলো পড়ে ফর্ম তৈরি করে; আপনার স্ক্রিপ্ট ইনপুটগুলো ভেরিয়েবল হিসেবে পড়ে, যেগুলো আগে থেকেই সেট করা থাকে।

## হেডার

এগুলো মন্তব্য লাইনে লিখুন (CraftScript-এ `%`, Lua-তে `--`, Python-এ `#`):

```
% @generator তাপ বিনিময়কারী
% @input mdot: kg/s = 0.2 [0.01 .. 10] "ভর প্রবাহ"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "পৃষ্ঠ"
% @input solid: = true
% @input note: = "text"
```

একটি ইনপুট হলো `name: unit = default`, এরপর ঐচ্ছিকভাবে একটি পরিসর `[min .. max]` (সংখ্যাগুলো এর ভেতরে থাকে), একটি পছন্দের তালিকা `{a, b, c}`, এবং উদ্ধৃতিচিহ্নের ভেতরে একটি লেবেল। unit শুধু ফর্মের জন্য একটি লেবেল: **মানটি সেই unit-এই আসে**, তাই যে স্ক্রিপ্ট SI চায় তাকে সেটি রূপান্তর করতে হবে; `to_si(value, 'kg/s', 'kg/s')` আবার যাচাই করে যে unit-টি আপনার ভাবনামতো অর্থ বহন করে। একটি নাম হতে পারে অক্ষর, সংখ্যা ও আন্ডারস্কোর দিয়ে; `body`, `sheet` ও `problems` আগে থেকেই সংরক্ষিত।

## স্ক্রিপ্ট যা রেখে যায়

| ভেরিয়েবল | কী |
|---|---|
| `body` | **আবশ্যক।** একটি সারফেস মেশ, সাধারণত `[body, info] = to_body(field, h)` থেকে। রান শেষ হলে এটি মেরামত ও যাচাই করা হয়। |
| `sheet` | ঐচ্ছিক। একটি struct: প্রতিটি ফিল্ড একটি সংখ্যা বা লেখা, অথবা `value`, `unit`, `ref` ও `note` সহ একটি struct। এটি ডেটা শিট হয়ে যায়। |
| `problems` | ঐচ্ছিক। `mfg_check(field, 'sls', struct(), h)`-এর `problems` সেল, অথবা আপনার নিজের এন্ট্রি। এগুলো চেকে এবং সমস্যা তালিকায় যায়। |

## একটি ছোট সম্পূর্ণ উদাহরণ

```
% একটি দেয়ালসহ ফাঁপা ঘনক।
% @generator ফাঁপা ঘনক
% @input side: mm = 12 [4 .. 40] "বাহু"
% @input wall: mm = 1.5 [0.5 .. 5] "দেয়াল"
% @input h: mm = 0.5 [0.25 .. 2] "ভক্সেল আকার"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'মেশের');
```

এটি একটি বন্ধ বাক্স তৈরি করে, এবং পাউডার প্রক্রিয়ার জন্য চেক এর সিল করা ভেতরটিকে একটি ত্রুটি হিসেবে জানায়। ভক্সেল আকার `h` আপনার চাওয়া সবচেয়ে পাতলা দেয়ালের সর্বোচ্চ এক-তৃতীয়াংশ রাখুন: প্রায় তিনটি ভক্সেলের নিচে কোনো দেয়াল নির্ভরযোগ্য থাকে না।

## ফিল্ড

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (একটি প্রোফাইল থেকে ঘূর্ণনের কঠিন বস্তু), `tpms` (gyroid, Schwarz P ও diamond পৃষ্ঠ, যার সেল আকার ও দেয়াল পুরো অংশ জুড়ে বদলাতে পারে), `lattice` ও `lattice_beams`, `along` (একটি পথ বরাবর গোল চ্যানেল), বুলিয়ান `field_union`, `field_intersect`, `field_subtract`, মসৃণ `field_blend`, এবং `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`। `sample(f, points)` বিন্দুগুলোতে signed distance দেয় (ভেতরে ঋণাত্মক), `field_voxel` সলভারের জন্য ভক্সেল দেয়। [ফিল্ড](topic:fields) এগুলো কী তা ব্যাখ্যা করে।

জানা দরকারী সীমাবদ্ধতা: সেলের প্রায় এক-চতুর্থাংশের চেয়ে পুরু শিট দেয়াল চ্যানেল বন্ধ করে দেয়; প্রায় তিনটি ভক্সেলের চেয়ে পাতলা বৈশিষ্ট্য চেপে যেতে পারে; `along` গোল কোন জোড়া দেয়, তাই দ্রুত বদলানো ব্যাসার্ধ একটি ফোলা অংশ রেখে যায় (প্রোফাইলের জন্য `field_revolve` ব্যবহার করুন)।

## আপনার স্ক্রিপ্টটি জেনারেটর হিসেবে খুলুন

{{ui:ইঞ্জিনিয়ার}} ওয়ার্কস্পেসে {{ui:খুলুন}} ক্লিক করে ফাইলটি বেছে নিন। `@generator` বা `@input` লাইন ছাড়া স্ক্রিপ্ট গ্রহণ করা হয় না: সেট করার মতো কিছুই থাকবে না। জেনারেটরটি এই ব্রাউজারে রাখা হয় (সর্বোচ্চ ২০টি), এবং {{ui:সরিয়ে দিন}} সেটি মুছে দেয়। এটি থেকে শুরু করা একটি body স্ক্রিপ্টের একটি কপি বহন করে, তাই অংশটি এর ওপর নির্ভর করে না।

একটি ফাইলে একাধিক জেনারেটরও থাকতে পারে: একটি JSON বান্ডিল `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`।
