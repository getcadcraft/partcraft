CraftScript একটি ম্যাট্রিক্স ভাষা, যা MATLAB-এর মতো পড়া যায়, তাই বেশিরভাগ ক্লাসিক সংখ্যাভিত্তিক কোড (যেমন ৮৮-লাইনের টপোলজি অপটিমাইজেশন কোড) সামান্য পরিবর্তনে চলে। এটি [Script ওয়ার্কস্পেস](topic:craftscript)-এ এবং কমান্ড লাইন থেকে চলে।

## মান

| ধরন | উদাহরণ | মন্তব্য |
|---|---|---|
| সংখ্যা, অ্যারে | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | প্রতিটি সংখ্যা একটি অ্যারে (1×1)। অ্যারে কলাম অনুযায়ী সংরক্ষিত হয়, সর্বোচ্চ 8 মাত্রা পর্যন্ত |
| লজিক্যাল | `A > 2`, `true` | true/false-এর অ্যারে; ইনডেক্স হিসেবে ব্যবহারযোগ্য |
| টেক্সট | `'beam'`, `"beam"` | |
| স্পার্স ম্যাট্রিক্স | `sparse(i, j, v, n, n)` | স্টিফনেস ম্যাট্রিক্সের জন্য |
| মেশ, ফিল্ড, মডেল | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` যা আঁকে |
| স্ট্রাক্ট | `s.E = 210e3` | নামযুক্ত ফিল্ড |
| সেল | `c = {1, 'two', [3 4]}` | যেকোনো মানের একটি তালিকা |
| ফাংশন হ্যান্ডল | `f = @(x) x.^2` | |

## অ্যারে ও ইনডেক্সিং

- রেঞ্জ: `1:5`, `0:0.1:1`। `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`।
- ইনডেক্সিং 1 থেকে শুরু হয়: `A(2, 3)`, `v(end)`, `A(:, 1)` (একটি পুরো কলাম), `A(:)` (সব কিছু একটি কলামে), `v(v > 0)` (লজিক্যাল ইনডেক্সিং)।
- শেষের বাইরে অ্যাসাইন করলে অ্যারে বড় হয়, MATLAB-এর মতো: `v(10) = 1`।

## অপারেটর

- `+ - * / \ ^` ম্যাট্রিক্স অপারেশন (`A \ b` সমাধান করে); `.* ./ .^` প্রতিটি উপাদানের উপর কাজ করে। `'` ট্রান্সপোজ করে।
- তুলনা: `== ~= < <= > >=`; লজিক: `& | ~` (প্রতিটি উপাদানের উপর) এবং `&& ||` (শর্ট-সার্কিট)।

## নিয়ন্ত্রণ প্রবাহ ও ফাংশন

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ফাংশন একটি স্ক্রিপ্টে কমান্ডের পরে রাখা যায়, অথবা নিজস্ব স্ক্রিপ্ট ট্যাবে, যার নাম ফাংশনের নামে রাখা হয়:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

নাম খোঁজার ক্রম: একটি ভেরিয়েবল, এই পার্টে সেই নামের একটি স্ক্রিপ্ট, একটি লাইব্রেরি ফাংশন, তারপর একটি বিল্ট-ইন ফাংশন।

## Echo, মন্তব্য, আউটপুট

- `;` ছাড়া একটি স্টেটমেন্ট তার মান প্রিন্ট করে; `;` সেটিকে নীরব রাখে।
- `%` একটি মন্তব্য শুরু করে; আলাদা লাইনে `%{` ও `%}` তাদের মধ্যের লাইনগুলোকে মন্তব্যে পরিণত করে।
- `disp(x)`, `fprintf('%g\n', x)` ও `display(x)` কনসোলে প্রিন্ট করে।

## ত্রুটি ও সীমা

- ত্রুটি সাধারণ ভাষায় বলে কী ভুল হয়েছে এবং লাইন (ও ফাংশন কলের শৃঙ্খল) দেখায়।
- প্রতিটি রানের একটি ধাপ-বাজেট আছে (প্যানেলের রান বিকল্পে); একটি অন্তহীন লুপ একটি বার্তা দিয়ে থামে, অথবা Stop চাপুন।
- অ্যারের প্রতিটিতে সর্বোচ্চ 134 million মান থাকতে পারে।

## MATLAB-এর মতো নয়

- প্লট কমান্ড তাদের বিকল্প কলের ভেতরে রাখে: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`। `figure`, `hold`, `axis`, `title(…)` এবং অনুরূপ ফাংশন গৃহীত হয়, কিন্তু কিছুই করে না।
- `input` ও `keyboard` সমর্থিত নয়: একটি স্ক্রিপ্ট প্রশ্ন করার জন্য থামতে পারে না।
- কোনো টুলবক্স নেই; [বিশ্লেষণ লাইব্রেরি](topic:craftscript-library) ও বিল্ট-ইন ফাংশনগুলোই আছে।
