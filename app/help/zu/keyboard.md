Okhiye abasebenzi lapho uthayipha kubhokisi epaneli, ngaphandle kwe-{{key:Mod+S}} ne-{{key:Mod+O}}, ezisebenza njalo. Okhiye bezinhlamvu basebenza ngaphandle komodifayi.

Izincazelo ezijwayelekile mayelana nokhiye kusiphequluli, nakumakhibhodi angenawo okhiye bomsebenzi: [Okhiye, ama-mouse nama-trackpad](common:keys).

## Noma kuphi

| Okhiye | Isenzo |
|---|---|
| {{key:Mod+S}} | Londoloza ingxenye (kuhlanganiso: inhlanganisela). Ivala i-sketch evulekile kuqala |
| {{key:Mod+O}} | Vula ifayela lengxenye noma lenhlanganisela (ibuza kuqala uma kukhona okungalondolozwanga) |
| {{key:Mod+Z}} | Hlehlisa |
| {{key:Mod+Y}} noma {{key:Mod+Shift+Z}} | Phinda wenze |
| {{key:F1}} | Vula noma uvale lo msizo (futhi {{ui:Usizo}} kwi-app bar). {{key:Esc}} nayo iyawuvala. Kumalaptop amaningi namakhibhodi e-Mac, bamba Fn |
| {{key:Ctrl+Shift+F}} | Imodi yesikrini: ejwayelekile, isikrini esigcwele, isikrini esigcwele nezinhlamvu zifihliwe. Control nakwi-Mac, hhayi ⌘ |
| {{key:Esc}} | Phuma kusikrini esigcwele (uma usesikrinini esigcwele) |
| {{key:Mod+,}} | {{ui:Izilungiselelo}}, kubandakanya ithebhu ye-PartCraft (bheka [Izilungiselelo ze-PartCraft](topic:settings)) |

Kubhokisi lenombolo epaneli, {{key:Mod+Z}} iwukuhlehlisa kombhalo wesiphequluli. Kubhokisi lenombolo ngaphezu kwesilinganiso se-sketch, ihlehlisa kwi-PartCraft.

## Kopisha, namathisela nephinde

Zisebenza kokusebenzayo: ijiyometri ekhethiwe ku-sketch evulekile, isici esikhethiwe emlandweni, noma ingxenye ekhethiwe kuhlanganiso. Imininingwane ku-[Kopisha, namathisela nephinde](topic:copy-paste).

| Okhiye | Isenzo |
|---|---|
| {{key:Mod+C}} | Kopisha okukhethiwe |
| {{key:Mod+X}} | Sika: kopisha, bese usula |
| {{key:Mod+V}} | Namathisela. Ku-sketch ikhophi ilandela iphoyinti: chofoza lapho okuyoya khona |
| {{key:Mod+Shift+V}} | Namathisela endaweni efanayo: amakhonjana afanayo (kuhlanganiso, indawo efanayo) |
| {{key:Mod+D}} | Phinda: kopisha futhi unamathisele ngesinyathelo esisodwa, ingabi nalutho ku-clipboard |
| {{key:Mod+A}} | Khetha konke (ku-sketch) |
| {{key:Esc}} | Khetha lutho (futhi ukhansele ukunamathisela okulandela iphoyinti) |

Kubhokisi lenombolo, lezi zinkinobho zikopisha futhi zinamathisele umbhalo njengoba kujwayelekile. Umbhalo okhethiwe kupaneli ukopishwa yisiphequluli.

## Ku-ngxenye (akukho sketch evulekile)

| Okhiye | Isenzo |
|---|---|
| {{key:S}} | Sketch ekhethiwe kundiza noma ebusweni obuncane obukhethiwe; uma kungakhethwanga lutho, khetha indawo ngokuchofoza |
| {{key:F}} | Lingana ingxenye ku-view |
| {{key:M}} | Linganisa, kuzo zonke izindawo zokusebenza nakuhlanganiso; {{key:Esc}} isula okukhethiwe, {{key:Esc}} futhi iyavala (bheka [Linganisa amakhaza, ama-engeli nobuningi](topic:measure)) |
| {{key:X}} | Ukubuka kwesigaba ukuvula noma ukuvala, kuzo zonke izindawo zokusebenza nakuhlanganiso; {{key:Esc}} iyavala (bheka [Bheka ngaphakathi ngokubuka kwesigaba](topic:section-view)) |
| {{key:Delete}} | Susa isici esikhethiwe (ibuza uma ezinye zisisebenzisa) |
| {{key:0}} … {{key:9}}, {{key:.}} | Nesici esikhethiwe: thayipha inombolo yaso enkulu (ukujula kwe-Extrude, ububanzi be-Hole, inani lephethini, iradiyasi ye-fillet …), bese {{key:Enter}}. {{key:Esc}} igcina eyakudala |
| {{key:Backspace}} | Susa isici esikhethiwe, uma kukhethiwe esisodwa |
| {{key:Esc}} | Yeka ukukhetha indiza ye-sketch, noma sula ukukhetha (kuhlanganisa imiphetho noma ubuso obukhethwe nge-{{key:Shift}}) |

| Okhiye | Isenzo |

| {{key:Minus}} | Sondeza ngaphandle |

| Imouse | Isenzo |
|---|---|
| Donsa ngenkinobho yokunxele | Phendula (zungeza) ukubuka |

Nge-**Ukuphendula ukubuka: Inkinobho ephakathi** kuzilungiselelo ze-[PartCraft](topic:settings), inkinobho ephakathi iphendula ukubuka, {{key:Shift}} nenkinobho ephakathi noma yesokudla kushelelisa, bese inkinobho yokunxele ikhetha kuphela.
| Chofoza | Khetha ubuso (buyagqamiswa bonke), umphetho noma indiza |
| {{key:Shift}}+chofoza umphetho noma ubuso | Qoqa imiphetho noma ubuso obuningi |
| Chofoza isikhala esingenalutho | Sula ukukhetha |

## Izinkinobho isiphequluli esingazithatha

- {{key:Mod+Y}} ku-Safari ingavula umlando: sebenzisa {{key:Mod+Shift+Z}} ukuphinda wenze.
- {{key:Mod+D}} ukhiye wamabhukhimakhi wesiphequluli: i-PartCraft iyithatha lapho uhlelo lugxilile, iyishiye uma uthayipha kubhokisi.
- {{key:F11}} ne-{{key:Mod+Plus}} / {{key:Mod+Minus}} zisikrini esigcwele nokusondeza kwekhasi lesiphequluli, hhayi ezePartCraft. Sebenzisa {{key:Ctrl+Shift+F}} ukuze uthole isikrini esigcwele, nevili ukuze uthole imodeli.
- Okhiye bomsebenzi kumalaptop amaningi namaMac badinga okhiye Fn: cindezela Fn+{{key:F1}} ukuthola usizo, noma sebenzisa inkinobho ethi {{ui:Usizo}}.

Ukuthinta nezinhlamvu ze-trackpad: [Ama-trackpad, ukuthinta nezikrini ezincane](topic:trackpad-and-touch).
