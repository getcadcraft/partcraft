Vula {{ui:Settings}} ngegiya elisendaweni yesicelo noma ngo {{key:Mod+,}}. Ithebhu yokuqala, {{ui:PartCraft}}, ibamba izilungiselelo zalolu hlelo; {{ui:General}} ibamba ezabelwa zonke izinhlelo ze-CadCraft (itimu, ithuluzi, amapaneli). Izilungiselelo ze-PartCraft zikhona kuhlelo kuphela: uzishintsha lapha, futhi lesi siphequluli siyazikhumbula. {{ui:Reset PartCraft settings}} ibuyisela konke esimweni sokuqala.

## Ukugingqa kokubuka

- **Inkinobho yesobunxele** (okokuqala): donsa ngenkinobho yesobunxele ukugingqa ingxenye; donsa ngenkinobho yesokudla noma ephakathi ukuze ushelelise.
- **Inkinobho ephakathi**: cindezela ivili bese udonsa ukugingqa ingxenye; bamba {{key:Shift}} (noma {{key:Ctrl}}, noma ⌘) ngenkinobho ephakathi, noma donsa ngenkinobho yesokudla, ukuze ushelelise. Inkinobho yesobunxele ikhetha ubuso, imiphetho namapuleni kuphela, ngakho ukuchofoza okunyakaza kancane akusoze kugingqe ingxenye. Izinhlelo eziningi ze-CAD zisebenza ngale ndlela.

Ivili lisondeza endaweni isikhombi sikuyo noma kunjalo. Esikethini, inkinobho yesokudla neyephakathi zishelelisa njengakuqala.

## Ukuskrola: ivili noma i-trackpad

- **Thola ngokwakho** (okokuqala): I-PartCraft iyaqapha ukuskrola. Ukuskrola okuvundlile noma okuncane, njengoba i-trackpad ikuthumela, kugingqa ingxenye; izinotshi zevili eliphelele zisondeza.
- **Ivili**: ukuskrola kuhlala kusondeza endaweni isikhombi sikuyo.
- **Trackpad**: swayiphela ngeminwe emibili ukugingqa ingxenye, bamba {{key:Shift}} uswayiphe ukuze ushelelise, khama ukuze usondeze. Esikethini ukuswayiphela ngeminwe emibili kushelelisa isikethi.

Ukukhama kusondeza kuzo zonke izinketho. Uma "Thola ngokwakho" ingakunqumi kahle ngevili noma nge-trackpad yakho, khetha ohlobo olunalo. Okwengeziwe ku-[I-trackpad, ukuthinta nezikrini ezincane](topic:trackpad-and-touch).

## Ukudweba: engeza izixhumanisi ngesikhathi udweba

**Engeza izixhumanisi ngesikhathi udweba** (ivuliwe ekuqaleni): ukuchofoza okubambelela ephoyintini kwenza iphoyinti elisha lihlangane nayo, ukuchofoza ejikeni kubeka iphoyinti kuleyo jika, nomugqa odwetshwe ocishe ulingane noma umile uba ngohlangothi noma oqondile. Bheka [Izixhumanisi nezilinganiso](topic:relations-dimensions).

Yicime uma ufuna ukubeka ijometri eduze nezinye ngaphandle kokuyixhumanisa nazo. Isikhombi sisabambelela eziphoyintini nasemajikeni, kodwa akukho okuxhunyiwe: imigqa edwetshwe ngokulandelana ayabelani ngemiphetho yayo, ngakho ukudonsa kungazihlukanisa. Engeza izixhumanisi ofuna wena ngokwakho esigabeni sakwesokudla. Iphrofayili evaliwe isakhishwa uma imiphetho yayo ihlangana.

:::note
Isilungiselelo siguqula kuphela okwengezwa yisidwebi esisha. Izixhumanisi ezisesikethini zisala, nethuluzi le-Fillet lisadala ijika layo elithintayo neradiyasi.
:::

## Ukudweba: isilinganiso ngesikhathi udweba

**Isilinganiso ngesikhathi udweba** (ivuliwe ekuqaleni): ngesikhathi umugqa, irektangela, indilinga noma umnsalo udwetshwa, ukuthayipha inombolo kugcwalisa ibhokisi losayizi eduze nesikhombi ({{key:Tab}} iya kwebhokisi elilandelayo) bese {{key:Enter}} idweba ukwakheka ngalolo sayizi, nesilinganiso esishayelayo sosayizi ngamunye obuthayipha. Ivaliwe: ukuthayipha inombolo ngesikhathi udweba akwenzi lutho, futhi izakheko zidwetshwa ngokuchofoza kuphela. Bheka [Thayipha usayizi ngesikhathi udweba](topic:sketch-basics#type-the-size-as-you-draw).

## Isibonisi sekhona

Okubonakala ekhoneni lokubuka kwe-3D: **Ikhyubhu lokubuka** (okokuqala; ngakwesokudla phezulu — chofoza ubuso, umphetho noma ikhona ukuze ubuke kuleyo ndawo, donsa ukuze uzungeze, donsa indilinga yekhampasi ukuze ugingqe imodeli), **Isithonjana sesiqondiso** (uphawu oluncane lwe-X, Y, Z ngakwesokunxele phansi olugingqa ngokubuka: X ibomvu, Y eluhlaza, Z eluhlaza okwesibhakabhaka) noma **Lutho**. Akukho okubonakala lapho udweba isikethi noma eshidini lomdwebo. Bheka [Ikhyubhu lokubuka](topic:view-cube).

## Amathrendi esixazululi

Amathrendi angangamalingana isixazululi sesimulation. **Okuzenzakalelayo** (okokuqala) kusebenzisa okungaphansi kwe-processor ezisebenzayo zekhompyutha ngu-1 (okungafika ku-16), ukuze ikhasi lisasabela ngesikhathi isifundo sixazulula; noma khetha inombolo. Izifundo ezinkulu ze-voxel, ukuwohloka (buckling), ukucindezeleka ngokuhamba kwesikhathi nokugeleza kwe-flow zixazulula ngokushesha kumathrendi amaningi (cishe 2× ku-4 amathrendi kuma-80,000 amakhyubhu ezilinganisweni zethu, ngaphezu kakhulu ekhompyutheni engasebenzi); amamodeli angaphansi kuka-20,000 okungaziwa ahlala ethrendini eyodwa, ngoba ukuqala amathrendi kubiza ngaphezu kwalokho akonga. Isixazululo esinamathrendi sinikeza impendulo efanayo nethrendi eyodwa (ngokuzungeza: amasamba ahlanganiswa ngolunye ulandelelo). Imiphumela yesifundo ngasinye ibala **N amathrendi** noma **ithrendi eyodwa** nesizathu ngaphansi kwe-**Isixazululi**.

Amathrendi adinga ukuthi ikhasi libe **lihlukaniswe ngokuphambene** (isiphequluli sivumela abasebenzi babelane ngenkumbulo kuphela ngalokho). Ikhasi le-lab lenza kanjalo; lapho lingenjalo, isilungiselelo sithi lokho ("Leli khasi alihlukaniswe ngokuphambene, ngakho abaxazululi basebenza ngethrendi eyodwa noma yini okhethiwe lapha.") bese yonke ukuxazulula isebenzisa ithrendi eyodwa. Okunye konke kusebenza ngokufanayo, nezimpendulo ziyafana.

Izifundo zokugeleza kwe-laminar nazo zisebenzisa amathrendi (cishe 2.5× ku-4 amathrendi kumaseli oketshezi angama-54,000, impendulo efanayo kudijithi lokugcina). Isixazululi se-quadratic-tetrahedron nokudlulisa kokushisa kusebenza ethrendini eyodwa: ukusebenzisa amathrendi kwabo kulinganiswe kukhompyutha yethu yokuhlola kuba kancane (abaxazululi babo bavinjelwa isivinini senkumbulo nesinyathelo esingahlukaniswa).

### Kuseva yewebhu yakho

Uma usebenzisa i-PartCraft kusuka kuseva yakho, isebenza njengoba ihlinzekwa. Ngamathrendi esixazululi, yenza iseva ithumele izinhloko ezimbili nekhasi le-PartCraft:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Ku-Apache, kufayela le-`.htaccess` lefolda (kudinga mod_headers):

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

Ku-nginx, ku-`location` ehlinzeka i-PartCraft:

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

Layisha kabusha ikhasi: Settings › Solver threads bese kunikeza **Automatic** nenani lekhompyutha yakho. Inhloko yesibili yenza isiphequluli senqabe noma yini ikhasi elayilayisha kwenye indawo engavumeli lokho, okulungile kwi-PartCraft ngokwayo (ilayisha konke kusuka kufolda yayo).
