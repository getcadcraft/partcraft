கவனமான மாதிரியமைப்பு பொத்தான்களை விட ஒழுங்கைப் பற்றியது. உரையாக எழுதப்பட்ட பாகத்தைப் படிக்கலாம், மதிப்பாய்வு செய்யலாம், வரி வரியாக ஒப்பிடலாம், ஒரு ஸ்கிரிப்ட் மூலம் மீண்டும் உருவாக்கலாம். PartCraft இரு வழியிலும் செயல்படும்: எந்தப் பாகத்தையும் ஸ்கிரிப்டாக எழுதலாம், ஒரு ஸ்கிரிப்ட் பாகத்தை உருவாக்கும்.

## பயன்பாட்டில்

{{ui:அளபுருக்கள்}} தாவலில், **ஸ்கிரிப்ட்** பிரிவின் கீழ்:

- {{ui:ஸ்கிரிப்டாகச் சேமி}} திறந்திருக்கும் பாகத்தை `<name>.pcscript` ஆகப் பதிவிறக்கும்.
- {{ui:ஸ்கிரிப்டைத் திற}} ஒரு `.pcscript` கோப்பிலிருந்து பாகத்தை உருவாக்கும். தவறு இருந்தால் அதன் வரி எண்ணுடன் தெரிவிக்கப்படும்; எதுவும் மாற்றப்படாது.

## ஸ்கிரிப்ட் வடிவம்

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

விதிகள்:

- இடது ஓரத்தில் உள்ள வரி ஒரு கூற்றைத் தொடங்கும்: `pcscript`, `part`, `param`, ஒரு அம்ச வகை (`sketch`, `extrude`, `revolve`, `hole`, `lpattern`, `cpattern`, `mirror`, `fillet`, `chamfer`, `shell`, `import` மற்றும் புதிய வகைகள்) அதன் பெயருடன், அல்லது `rollback <feature>`.
- உள்தள்ளப்பட்ட வரிகள் மேலுள்ள கூற்றின் அமைப்புகள். தனியாக வரும் ஓர் அமைப்பு (`through`, `reverse`, `suppressed`) ஆம் என்று பொருள்படும்.
- எண் அமைப்பு ஓர் எண், அல்லது `=` மற்றும் ஒரு கோவை; அது ஒரு சமன்பாட்டை உருவாக்கும்: `depth = thick`.
- ஓவியத்தில்: `on` தளத்தைப் பெயரிடும் (`front`, `top`, `right`, `face Base end`, `face Revolve1 side l3`); வடிவியல்: `point <name> x, y`, `line <name> <point> <point>`, `circle <name> <centre> <radius>`, `arc <name> <centre> <start> <end>` (எதிர்க் கடிகாரத் திசையில்) அல்லது `spline <name> fit|control <points>`; கட்டுப்பாடுகள் அவற்றின் வகையும் அவை இணைக்கும் பெயர்களும் (`O` ஆதிப்புள்ளி); ஒரு பரிமாணம் அதன் மதிப்பிலோ அல்லது `= expression` இலோ முடியும்.
- வடிவியல் அல்லது கட்டுப்பாட்டு வரியின் விருப்ப அமைப்புகள் இறுதியில் சதுர அடைப்புக்குறிக்குள் `;` ஆல் பிரிக்கப்பட்டு வரும்: `[construction]`, `[side -1; label 5, 3]`.
- `#` ஒரு கருத்தைத் தொடங்கும் (வரியின் தொடக்கத்திலோ அல்லது ஓர் இடைவெளிக்குப் பின்போ). இடைவெளி உள்ள பெயர்கள் "இரட்டை மேற்கோள்களுக்குள்" வரும்.
- அம்ச அடையாளங்கள் எழுதிய வரிசையில் f1 இலிருந்து எண்ணப்படும். விளிம்பு மற்றும் முகக் குறிப்புகள் அவற்றைப் பயன்படுத்தும், எடுத்துக்காட்டாக `edge f2.side:l3 f2.end [at 50, 0, 10]`.
- வடிவத்துக்கு சொற்கள் இல்லாத அமைப்புகள் `json` மற்றும் ஒரு மதிப்பாக எழுதப்படும்; அவை அப்படியே மீண்டும் படிக்கப்படும்.

பயன்பாட்டிலிருந்து சேமிக்கப்பட்ட ஸ்கிரிப்டில் ஒவ்வொரு அமைப்பும் இருக்கும், எனவே அது அதே பாகமாகத் திறக்கும். இறக்குமதி செய்யப்பட்ட STEP திடப்பொருள் பயன்பாட்டிலிருந்து ஸ்கிரிப்டுக்குள் எழுதப்படும்; கட்டளை வரியிலிருந்து `step-file` பெயரிடும் தனி `.step` கோப்பாக எழுதப்படும்.

## கட்டளை வரிக் கருவி

இந்தக் கருவி Node.js 24 உள்ள கணினியில், CadCraft மூலக் குறியீட்டின் நகலிலிருந்து இயங்கும்: `node tools/partcraft-cli/partcraft.mjs <command>`. இது ஓர் உருவாக்குநர் கருவி; பயன்பாட்டின் அதே தொகுதிகளைப் பயன்படுத்துகிறது. பாகங்கள் `.partcraft.json` கோப்புகள் அல்லது `.pcscript` ஸ்கிரிப்டுகள்.

| கட்டளை | என்ன செய்கிறது |
|---|---|
| `info <part>` | அம்சங்கள், அளபுருக்கள், பின்செல் பட்டை, உருவாக்கப்பட்ட திடப்பொருளின் கனஅளவு மற்றும் அளவு |
| `params <part>` | ஒவ்வோர் அளபுருவும் சமன்பாடும் அதன் மதிப்புடன் |
| `set <part> width=150 Base.depth==thick` | முன்னோக்கி: அளபுருக்களை மாற்று, எண்களை இணை (`==` அல்லது ஒரு கோவை), வெற்று எண்களை அமை |
| `drive <part> Base.depth=12` | பின்னோக்கி: இயக்கப்படும் எண்ணுக்குப் பின்னுள்ள அளபுருவைத் தீர்க்கும் (`--prefer width` ஒன்றைத் தேர்ந்தெடுக்கும்) |
| `build <part> --out x.step` | `.step`, `.stl`, `.3mf`, `.json`, `.pcscript` அல்லது ஒரு மேக்ரோ (`.swb`) எழுதும் |
| `build <part> --table sizes.csv --out-dir sizes` | வடிவமைப்பு அட்டவணையின் ஒவ்வொரு வரிக்கும் ஒரு கோப்பு |
| `variants <part> --out-dir d` அல்லது `--zip f.zip` | ஒவ்வொரு கட்டமைவும் STEP, IFC, DWG மற்றும் முன்னோட்டமாக, ஒரு மாறுபாட்டு அட்டவணையும் ஒரு நூலக உருப்படியுமாக (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`); பார்க்க [மாறுபாட்டுத் தொகுப்பை உருவாக்கு](topic:variant-pack) |
| `script <in.pcscript> -o part.json` | ஸ்கிரிப்டிலிருந்து பாகத்துக்கு |
| `to-script <part> -o part.pcscript` | பாகத்திலிருந்து ஸ்கிரிப்டுக்கு |
| `rollback <part> [<feature>]`, `forward <part> [--end]` | கோப்பிலுள்ள பின்செல் பட்டையை நகர்த்து |
| `check <part> [--strict]` | ஒழுங்குச் சோதனை (கீழே) |

`build` `--set name=value` (இந்தக் கட்டமைப்புக்கு மட்டும்) மற்றும் `--upto <feature>` ஐயும் ஏற்கும். ஒவ்வொரு கட்டளையும் `--json` ஐ ஏற்கும். வெளியேறும் குறியீடுகள்: 0 சரி, 1 ஒரு சிக்கல் கண்டறியப்பட்டது, 2 கட்டளை தவறாகத் தட்டச்சு செய்யப்பட்டது. ஸ்கிரிப்ட் ஒருபோதும் அதே இடத்தில் மீண்டும் எழுதப்படாது: மாற்றப்பட்ட நகலைச் சேமிக்க `-o` கொடு.

## சோதனை

`check` பின்னர் ஒரு பாகத்தை மாற்றுவதைக் கடினமாக்குவது எது என்பதை அறிவிக்கும்:

| கண்டறிதல் | எனக் கணக்கிடப்படும் |
|---|---|
| ஓவியம் மிகையாக வரையறுக்கப்பட்டது (முரண்படும் அல்லது திரும்பத் திரும்ப வரும் கட்டுப்பாடுகள்) | பிழை |
| உருவாக்கப்படாத அம்சம் | பிழை |
| பிழையுள்ள அளபுரு அல்லது சமன்பாடு, அல்லது ஒன்றையொன்று பயன்படுத்தும் அளபுருக்கள் | பிழை |
| போதுமான அளவு வரையறுக்கப்படாத ஓவியம், அதன் சுதந்திர அளவுகளுடன் | எச்சரிக்கை |
| எந்த அளபுருவும் இயக்காத, அம்சங்களிலும் பரிமாணங்களிலும் நேரடியாகத் தட்டச்சு செய்த எண்கள் | எச்சரிக்கை |
| எதுவும் பயன்படுத்தாத அளபுரு | எச்சரிக்கை |
| அடக்கப்பட்ட அம்சம்; பின்செல் பட்டை இறுதியில் இல்லை | எச்சரிக்கை |

`--strict` ஒவ்வொரு எச்சரிக்கையையும் பிழையாக்கும்; எனவே ஓர் உருவாக்க ஸ்கிரிப்ட் முழுமையாக இயக்கப்படாத பாகத்தை நிராகரிக்க முடியும்.

:::note
`.swb` மேக்ரோ வெளியீடு பெரும்பாலான கடைகள் பயன்படுத்தும் பாக மாதிரி நிரலுக்கானது: அந்த நிரலுக்குள் இயக்கினால் அங்கேயே பாகத்தை உருவாக்கும். இங்கே அந்த நிரலில் இது இயக்கப்படவில்லை (இது எங்கள் சேவையகங்களில் கிடைக்காது), எனவே இதைச் சோதிக்கப்படாததாகக் கருது.
:::
