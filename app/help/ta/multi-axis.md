Manufacture கருவியை ஒரு கோணத்தில் வைத்திருக்க முடியும், சுழல் அச்சுகளை வெட்டும்போது நகர்த்தவும் முடியும். மூன்று வழிகள் இதைச் செய்கின்றன, எளியதிலிருந்து தொடங்கி.

**இங்கே எதுவும் ஓர் இயந்திரத்தில் இயக்கப்படவில்லை.** பாதைகள் சோதனைகளால் வடிவவியலுக்கு எதிராகச் சரிபார்க்கப்படுகின்றன, G-குறியீடு மீண்டும் படிக்கப்படுகிறது; ஆனால் உள்ளமைந்த போஸ்ட்கள் கட்டுப்பாட்டிகளின் ஆவணப்படுத்திய குறியீடுகளைப் பின்பற்றுகின்றன, நமக்கு முன்னால் உள்ள எந்த இயந்திரத்தையும் அல்ல. உங்கள் கட்டுப்பாட்டியின் சொந்த உருவகப்படுத்தியிலும் காற்றிலும் ஒரு நிரலை நிரூபித்த பிறகே அது உலோகத்தைச் சந்திக்கட்டும்.

## இயந்திரத்தின் சுழல் அச்சுகள்

**அமைப்பு** தாவலில், {{ui:சுழல் அச்சுகள்}} இயந்திரத்தில் என்ன உள்ளது என்று சொல்கிறது:

| தேர்வு | இயந்திரம் |
|---|---|
| எதுவுமில்லை (3 அச்சுகள்) | சாதாரண அரவை. கருவி சாய்வதைத் தேவைப்படுத்தும் எந்தச் செயல்பாடும் எச்சரிக்கும்; போஸ்ட் அதை எழுத மறுக்கும். |
| A (X-ஐச் சுற்றித் திரும்பும்) | X வழியே ஒரு சுழல் அச்சு: 4-ஆம் அச்சு மேசை அல்லது இண்டெக்சர். கருவி Y–Z தளத்தில் மட்டுமே சாயலாம். |
| B (Y-ஐச் சுற்றித் திரும்பும்) | Y வழியே ஒரு சுழல் அச்சு. கருவி X–Z தளத்தில் மட்டுமே சாயலாம். |
| A மற்றும் C | X-ஐச் சுற்றிய சாய்வு அச்சு, Z-ஐச் சுற்றிய திருப்புடன் சுமக்கப்படும் அல்லது சுமக்கும்: ஒரு டிரன்னியன் மேசை அல்லது ஒரு தலை. |
| B மற்றும் C | சாய்வு Y-ஐச் சுற்றி இருப்பதைத் தவிர அதேதான். |

அதன் பின்:

- **சுமக்கப்படுவது**: {{ui:மேசை (பாகம் திரும்பும்)}} அல்லது {{ui:தலை (கருவி திரும்பும்)}}. மேசை எதிர்த் திசையில் திரும்பி அதே முகத்தைக் கருவியின் கீழ் கொண்டுவரும்; ஆகவே ஒவ்வொரு கோணத்தின் குறியும் இதிலிருந்தே வருகிறது.
- **கட்டுப்பாட்டி கருவி முனையைப் பாதையில் வைத்திருக்கிறது (TCP)**: இயக்கத்தில், நிரலில் உள்ள X Y Z என்பது பகுதியின் சொந்த ஆயத்தொலைவுகளில் கருவி முனை; மீதத்தைக் கட்டுப்பாட்டி கவனிக்கும் (உள்ளமைந்த Fanuc பாணி மற்றும் LinuxCNC போஸ்ட்கள் கருவி நீளத்துக்கு `G43.4` எழுதுகின்றன). அணைத்திருந்தால், மேசை இயந்திரத்தில், PartCraft X Y Z-ஐ திருப்பப்படும் மேசை பகுதியைச் சுமக்கும்படி எழுதும், நீங்கள் கொடுக்கும் **சுழல் மையத்தைச்** சுற்றி (வேலை ஆயத்தொலைவுகளில்; வேலை தொடக்கம் மையத்தில் இருக்கும்போது 0, 0, 0). தலை இயந்திரத்துக்கு TCP இயக்கத்தில் இருக்க வேண்டும்: இல்லையெனில் நிரலுக்கு இயந்திரத்தின் பிவட் நீளம் தேவைப்படும், அதை PartCraft அறியாது.
- **சாய்வு வரம்பு**: சாய்வு அச்சு எவ்வளவு தூரம் செல்லும்.

இயந்திரங்கள் எந்தத் திசையை நேர்மறையாக எண்ணுகின்றன என்பதில் வேறுபடுகின்றன. உங்களுடையதில் ஓர் அச்சு தவறான திசையில் திரும்பினால், போஸ்டின் நகலில் குறியை மாற்றுங்கள் ([திருத்தக்கூடிய போஸ்ட் செயலிகள்](topic:post-processors)).

## சாதாரண செயல்பாட்டுக்கு சாய்ந்த கருவி

ஒவ்வொரு அரவைச் செயல்பாட்டுக்கும் (முகம், பள்ளம், அடாப்டிவ், விளிம்பு, துளை, சாய்விளிம்பு, இணை, ஸ்காலப், 3D ரஃப், ரெஸ்ட்) **கருவிச் சாய்வு** மற்றும் **நோக்கிச் சாய்** உள்ளன: அந்தச் செயல்பாட்டுக்கு மட்டுமே கருவியின் திசை, அமைப்பின் கருவி அச்சிலிருந்து அளக்கப்படுகிறது. இது 3+2 இயந்திரமாக்கல்: சுழல் அச்சுகள் ஒரு நிலைக்குச் சென்று அங்கேயே இருக்கும், மூன்று அச்சுகள் வெட்டும்போது.

- இரண்டு கோணங்களையும் தட்டச்சு செய்யுங்கள், அல்லது {{ui:கருவியை ஒரு முகத்துக்குச் செங்குத்தாக்கு}} அழுத்தி ஒரு தட்டை முகத்தைக் கிளிக் செய்யுங்கள்: கருவி நேராக அதைச் சுட்டும்.
- வழக்கம்போல் செயல்பாட்டின் முகங்களையும் விளிம்புகளையும் தேர்ந்தெடுங்கள். தளம் அல்லது துளை என்பது சாய்ந்த கருவியின் வழியே தீர்மானிக்கப்படும்.
- அந்தத் திசைக்கான பங்கு, திருப்பப்பட்ட பங்கைத் தாங்கும் பெட்டியாகும்; ஆகவே அந்தப் பக்கத்திலிருந்து உயரங்களும் விலகல்களும் பாதுகாப்பானவை.

G-குறியீட்டில், செயல்பாட்டுக்கு முன் கருவி மேலே செல்லும், சுழல் அச்சுகள் திரும்பும், கருவி அதன் முதல் புள்ளியின்மேல் இறங்கும். TCP இல்லாத மேசை இயந்திரத்தில் வளைவுகள் வளைவுகளாகவே இருக்கும், நிலையான துளையிடு சுழற்சிகள் சுழற்சிகளாகவே இருக்கும் (எழுதப்படும் சட்டகம் Z-ஐச் சுற்றி மட்டுமே திரும்பியது). TCP உடன் சாய்ந்த தளத்தில் வளைவுகள் குறுகிய நேர்கோடுகளாகவும், சுழற்சிகள் அவை குறிக்கும் நகர்வுகளாகவும் மாறும்.

பங்கு உருவகப்படுத்தல் ஒரு சாய்ந்த திசையை **தனியாக** இயக்கும்: அந்தச் செயல்பாடு அதன் பக்கத்திலிருந்து முழு பங்கில் என்ன வெட்டுகிறது என்பதைக் காட்டும், அங்கே ஆழ வெட்டுகளைக் கண்டறியும்; ஆனால் பிற திசைகளிலிருந்து செய்யப்பட்ட வெட்டுகள் கொண்டுவரப்படுவதில்லை.

## 5-அச்சு முடித்தல்

Manufacture கருவிப்பட்டியில் {{ui:மேலும்}} இந்தச் செயல்பாட்டையும் அடுத்ததையும் **Operations** தாவலின் மேலே பட்டியலிடுகிறது.

{{ui:5-அச்சு}} என்பது [இணை முடித்தல் கடவு](topic:finish-3d), அது **போகும்போது சாயும் பந்து முனை அரவையுடன்**. பந்து கோளத்தால் வெட்டுகிறது; கருவி அதன் மையத்தைச் சுற்றி எந்தத் திசையில் சாய்ந்தாலும் அந்தக் கோளம் ஒன்றுதான். ஆகவே பந்து 3-அச்சுக் கடவு தரும் பாதையைச் சரியாகப் பின்பற்றும், கருவியின் திசை மட்டுமே மாறுகிறது:

- **மேற்பரப்பை நோக்கி**: 1 = மேற்பரப்புக்குச் செங்குத்தாக, 0 = நேராக, இடையில் எதுவும்.
- **முன்னோக்கிச் சாய்**: வெட்டும் திசையில் பாகைகள், ஆகவே பந்தின் நிலையான மையம் வெட்டாது.
- **அதிகபட்சச் சாய்**: கருவி அமைப்பின் அச்சிலிருந்து இதைவிட அதிகமாக ஒருபோதும் சாயாது.

கருவியின் தண்டு மாதிரியைத் தொடும் இடத்தில் சாய்வு அது விலகும் வரை பின்வாங்கப்படும்; எத்தனை புள்ளிகளில் என்று செயல்பாடு சொல்லும். ஒவ்வொரு கடவும் ஒரு நேர் தூக்குதலால் நுழைந்து வெளியேறும்.

## சுழல் முடித்தல் (4-ஆம் அச்சு)

{{ui:சுழல்}} என்பது **work X** வழியே ஒரு சுழல் அச்சில் பிடிக்கப்பட்ட பகுதிக்கானது. பகுதி திரும்புகிறது; எப்போதும் அச்சை நோக்கிய பந்து முனை அரவை அதன் மேற்பரப்பைப் பின்தொடர்கிறது:

- **கடவுகள்**: {{ui:அச்சின் வழியே}} (அச்சின் வழியே X-இல் கோடுகள், ஒரு படி இடைவெளி திருப்பத்தில்) அல்லது {{ui:பாகத்தைச் சுற்றி}} (வளையங்கள், ஒரு படி இடைவெளி X-இல்).
- **அச்சு Y / Z-இல்**: அச்சு எங்கே இருக்கிறது. காலியாக இருந்தால் பங்கின் நடுவில். TCP இல்லாத மேசை இயந்திரத்தில் இது அமைப்பில் உள்ள சுழல் மையமாக இருக்க வேண்டும்; அது அப்படி இல்லையெனில் செயல்பாடு எச்சரிக்கும்.
- **From / To X** மற்றும் **From / To angle**: வெட்ட வேண்டிய நீளத்தின் மற்றும் திருப்பத்தின் பகுதி.

ஒவ்வொரு புள்ளியிலும் அச்சுக்கு மேலே பந்தின் உயரம், அந்தப் பக்கத்திலிருந்து, பகுதியின் மெஷ்மேல் ஒரு கோளத்தின் சரியான இறக்கம்.

## வரம்புகள்

- 5-அச்சு மற்றும் சுழல் முடித்தல் **பந்து முனை அரவையை** மட்டுமே ஏற்கும். ஸ்வார்ஃப் வெட்டு (தனிச்சுவரில் கருவியின் பக்கம்) இல்லை, மேற்பரப்பின் சொந்த திசைகளில் ஓட்டக் கோடுகள் இல்லை, பல அச்சு ரஃபிங் இல்லை, மோதலைத் தவிர்க்க தானியங்கி சாய்வுத் தேர்வும் இல்லை.
- 5-அச்சு மற்றும் சுழல் பாதைகள் **பங்கு உருவகப்படுத்தலில்** இயக்கப்படுவதில்லை; அது ஓர் உயர வரைபடம், சாயும் வெட்டைக் கொண்டிருக்க முடியாது.
- 5-அச்சு முடித்தலில் தண்டு, மேலிருந்து பார்த்த மாதிரிக்கெதிராகச் சரிபார்க்கப்படுகிறது; பிடிப்பான், சுழல் மற்றும் இயந்திரமே எங்கும் சரிபார்க்கப்படுவதில்லை.
- சுழல் முடித்தல் அச்சைப் பார்த்துப் பார்க்க முடிவதை மட்டுமே வெட்டுகிறது.
- 5-அச்சு முடித்தல் ஒரு பெரிய பகுதிக்குக் கணக்கிட ஒரு நிமிடம் அல்லது அதற்கு மேல் ஆகும்: ஒவ்வொரு கடவின் ஒவ்வொரு புள்ளியிலும் தண்டு சரிபார்க்கப்படுகிறது.
- நேரியல் அச்சுகளுடன் சுழல் அச்சுகள் நகர்ந்து TCP அணைக்கப்பட்டிருக்கும்போது, உள்ளமைந்த போஸ்ட்கள் ஊட்டத்தை நேர வீதத்தின் தலைகீழாக (`G93`) எழுதி, பிறகு `G94`-க்குத் திரும்பும்.
- சாய்ந்த வேலைத் தளக் குறியீடு (`G68.2` போன்றவை) எழுதப்படுவதில்லை; குறிப்பிட்ட இயந்திர வரம்புகள், அவிழ்த்தல் அல்லது மோதல் மண்டலங்கள் எதுவும் அறியப்படவில்லை.
