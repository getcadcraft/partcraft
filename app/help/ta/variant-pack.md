## நீங்கள் என்ன செய்வீர்கள்

**ஒரு பாகத்தின் ஒவ்வொரு அளவையும் ஒரே நேரத்தில்** வழங்கவும்: ஒவ்வொரு கட்டமைவுக்கும் ஒரு STEP, IFC மற்றும் DWG கோப்பும் ஒரு படமும், ஒவ்வொன்று எது என்று சொல்லும் ஓர் அட்டவணையும், அனைத்தையும் ஒரே பக்கத்தில் வைக்கும் ஒரு நூலக உருப்படியும்.

முதலில் உங்களுக்கு **கட்டமைவுகள்** கொண்ட ஒரு பாகம் தேவை ([கட்டமைவுகளும் வடிவமைப்பு அட்டவணைகளும்](topic:design-tables) ஐப் பார்க்கவும்). ஓர் அம்சத்தை அணைக்கும் கட்டமைவு, உதாரணமாக துளைகளுடன் மற்றும் துளைகள் இல்லாமல் உள்ள தகடு, அதன் சொந்த மாறுபாடாகும்.

## படிகள்

1. பாகத்தைத் திறக்கவும். {{ui:அளபுருக்கள்}} தாவலில், **கட்டமைவுகள்** என்பதைக் கண்டறியவும்.
2. {{ui:மாறுபாட்டுத் தொகுப்பு…}} என்பதைக் கிளிக் செய்யவும்.
3. உருவாக்க வேண்டிய கட்டமைவுகளையும் எழுத வேண்டிய கோப்புகளையும் தேர்வுசெய்யவும் (அனைத்தும் தேர்வுசெய்யப்பட்டிருக்கும்): STEP, IFC, DWG, ஒரு முன்னோட்டம், மற்றும் நூலக உருப்படி.
4. {{ui:தொகுப்பை உருவாக்கு}} என்பதைக் கிளிக் செய்யவும். மாறுபாடுகள் உருவாக்கப்படும்போது நிலை வரி அவற்றை எண்ணும்; உங்கள் பாகம் மாறாது.
5. ஒரு zip பதிவிறக்கம் ஆகும்: `<part> variants.zip`.

## zip கோப்பில் என்ன இருக்கிறது

| கோப்பு | அது என்ன |
|---|---|
| `<name>.step` | கட்டமைவை STEP திடப்பொருளாக. |
| `<name>.ifc` | IFC4, ஒரு உறுப்பு, கட்டப்பட்ட உடலுடனும் பாகத்தின் அளபுருக்களை பண்புகளாகவும் கொண்டது; மதிப்பு அந்தக் கட்டமைவுக்கே உரியது. |
| `<name>.dwg` | முன், மேல், வலது மற்றும் ஐசோமெட்ரிக் காட்சிகள் முழு அளவில் ஒரு வரைபடத் தாளாக. |
| `<name>.svg` | அதன் ஐசோமெட்ரிக் கோட்டுப் படம். |
| `variants.csv`, `variants.json` | அளபுருக்களின் அட்டவணை: ஒவ்வொரு மாறுபாட்டின் அடையாளம், பெயர், ஒவ்வொரு அளபுருவின் மதிப்பு, அது அணைக்கும் அம்சங்கள், அதன் கோப்புகள், கன அளவு மற்றும் அளவு. |
| `<part>.item.json` | பாகம் அதன் மாறுபாடுகளுடன் ஒரு நூலக உருப்படியாக (கீழே பார்க்கவும்). |
| `README.txt` | என்ன உருவாக்கப்பட்டது, கீழ்க்குறிப்புகள், உருவாக்கப்படாதவை. |

கோப்புகளுக்குக் கட்டமைவின் பெயரே இடப்படும். உருவாக்க முடியாத கட்டமைவு (அந்த மதிப்புகளுடன் உருவாக்க முடியாத அம்சம்) கோப்புகளிலும் அட்டவணையிலும் சேர்க்கப்படாது; அது README இலும், zip சேமிக்கப்பட்ட பிறகு வரும் செய்தியிலும் பட்டியலிடப்படும்; மற்றவை இன்னும் எழுதப்படும்.

## தெரிந்துகொள்ள வேண்டியவை

- **STEP** உங்கள் பதிப்பில் துல்லிய கர்னல் இயக்கத்தில் இருந்தால் துல்லியமாக இருக்கும். இல்லையென்றால் STEP முகங்களாக (தட்டையான முக்கோணங்கள்) இருக்கும், README அதைக் குறிப்பிடும்.
- **DWG** என்பது வரைபடத் தாள், 3D மாதிரி அல்ல. அதன் கோடுகள் மெஷிலிருந்து வருகின்றன; எனவே வளைந்த விளிம்பு பல குறுகிய கோடுகளாக இருக்கும்.
- **நூலக உருப்படி** ஒவ்வொரு மாறுபாட்டுக்கும் ஒரு உடலையும் ஒரு தடத்தையும் கொண்டிருக்கும், நூலகத்தின் சொந்த அச்சுகளில்: Z மேல், முன்பகுதி −Y நோக்கி, செருகும் புள்ளி அடியில் பின்பக்கத்தின் நடுவில். திட்டம் ஒவ்வொரு மாறுபாட்டின் சுற்றுவளைவு செவ்வகம். ஓர் உருப்படி 8 MB வரை மட்டுமே; மிக எடையான மாறுபாடு அதன் அளவுள்ள ஒரு பெட்டியாக மாறும், எத்தனை என்பதை README சொல்லும்.
- பாகத்தின் இப்போதைய செயலில் உள்ள கட்டமைவு உருப்படியின் இயல்புநிலை மாறுபாடாகும்.
- போர்ட்டுகள் (குழாய்கள் மற்றும் காற்றுக்குழாய்களுக்கான இணைப்புப் புள்ளிகள்) PartCraft இலிருந்து அமைக்கப்படுவதில்லை.

## மாறுபாடுகளை ஒரு நூலகப் பக்கத்தில் வை

தளத்தில் **நூலகம் › பதிவேற்று** இல் `<part>.item.json` ஐப் பதிவேற்றவும். அதன் வகை, உரிமம் மற்றும் உங்கள் பெயர்க் குறிப்பைத் தேர்வுசெய்யவும்; அது அதன் மாறுபாடுகளுடன் ஒரு நூலக உருப்படியாகும். BimCraft இல் அதை வைக்கும்போது எந்த மாறுபாடு என்று கேட்கும், மாற்று மற்றவற்றை வழங்கும். பார்வையாளர்கள் விருப்பங்களைத் தேர்ந்தெடுக்கவும், 3D ஐப் பார்க்கவும், ஒரு மாறுபாட்டைப் பதிவிறக்கவும் உதவும் பக்கம் இப்போதைக்கு **ஊழியர் முன்னோட்டம்**: அது இன்னும் பொதுமக்களுக்குத் திறக்கப்படவில்லை.

## கட்டளை வரியிலிருந்து

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` கட்டமைவுகளின் பெயர்களைக் கொடுக்கும்; `--formats` என்பது `step`, `ifc`, `dwg`, `preview` இவற்றில் ஏதேனும்; `--no-item` நூலக உருப்படியை விட்டுவிடும். அது ஒரு கோப்புறை, ஒரு zip அல்லது இரண்டையும் எழுதும்; ஒரு மாறுபாட்டை உருவாக்க முடியாதபோது 1 உடன் வெளியேறும். [ஸ்கிரிப்ட்கள் மற்றும் கட்டளை வரி](topic:scripts-and-cli) ஐப் பார்க்கவும்.
