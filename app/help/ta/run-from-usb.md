பொறியியல் கருவிகள் (உருவாக்கிகள், பொறியியல் நூலகம், சோதனைகள் மற்றும் தரவுக் கோப்புகள்) **நிர்வாக உரிமைகள் தேவையில்லை** மற்றும் **நிறுவி தேவையில்லை**. இங்கே பட்டியலிடப்பட்டவற்றை மட்டுமே அவை எழுதுகின்றன, வேறெதையும் அல்ல.

| என்ன | எங்கே வைக்கப்படுகிறது |
|---|---|
| உங்கள் பாகங்கள், அவற்றின் உருவாக்கிய உடல்கள், தரவுத் தாள்கள் மற்றும் சோதனைகள் | நீங்கள் சேமிக்கும் பாகக் கோப்பு (`.partcraft.json`), நீங்கள் சேமிக்கும் இடத்தில். |
| கோப்புகளிலிருந்து நீங்கள் திறந்த உருவாக்கிகள் | பயன்பாட்டின் சொந்தச் சேமிப்பகத்தில்: இணையப் பக்கத்தில் உலாவியின் உள்ளூர் சேமிப்பகத்தில், மற்றும் போர்ட்டபிள் Studio-வில் நிரலுக்கு அருகில் உள்ள `data` கோப்புறையில். அதிகபட்சம் 20. |
| அமைப்புகள் (நீங்கள் அமைத்த voxel அளவுகள், தீர்வி இழைகள், அமைப்பு) | அதே பயன்பாட்டுச் சேமிப்பகம். |
| தரவுத் தாள்கள், புலங்கள், வலைகள் (மெஷ்கள்) | நீங்கள் சேமிக்கும் இடத்தில் மட்டுமே: பதிவிறக்கம் நீங்கள் தேர்ந்தெடுக்கும் இடத்திற்குச் செல்லும். |

கருவிகள் தங்களாகவே **பிணைய அழைப்புகள் எதையும் செய்வதில்லை**: அனுப்பப்படும் உருவாக்கிகள் பயன்பாட்டின் சொந்தக் கோப்புறையில் உள்ள கோப்புகள், நூலகமும் சோதனைகளும் உங்கள் கணினியிலேயே, பிணையத்தை அடைய முடியாத ஒரு பணியாளரில் இயங்குகின்றன, மேலும் பொறியியல் தரவு (நீர் மற்றும் காற்றின் பண்புகள், பொருட்கள்) பயன்பாட்டினுள்ளேயே உள்ளது. நீங்கள் கோப்பிலிருந்து திறக்கும் உருவாக்கி உங்கள் கணினியிலேயே படிக்கப்படுகிறது; அது எங்கும் அனுப்பப்படுவதில்லை.

## போர்ட்டபிள் Windows zip மற்றும் Linux

Windows-க்கான போர்ட்டபிள் Studio தனது அமைப்புகள், தற்காலிக சேமிப்புகள் மற்றும் துணை நிரல்களை நிரலுக்கு அருகில் உள்ள `data` கோப்புறையில் வைத்திருக்கிறது. Linux AppImage, `portable` என்ற கோப்பு அதற்கு அருகில் இருந்தால், அவற்றை அதற்கு அருகிலேயே வைத்திருக்கும்; அந்தக் கோப்பு இல்லையென்றால் உங்கள் முகப்புக் கோப்புறையைப் பயன்படுத்தும். Mac-க்கு போர்ட்டபிள் வடிவம் இல்லை: பதிவிறக்கப்பட்ட பயன்பாடு தனக்கு அருகில் எழுதாதபடி கணினி தடுக்கிறது. ஷெல்லின் சொந்த போர்ட்டபிள் குறிப்புகள் (`Studio` உதவி) நிரல் எழுதுவதைப் பட்டியலிடுகின்றன.

## ஹோஸ்ட் அணுகல்

இங்கே எதுவும் ஹோஸ்ட் அணுகலைக் கேட்பதில்லை. அச்சுப்பொறிகள், சீரியல் இயந்திரங்கள் மற்றும் USB சாதனங்கள் தனித்தவை: ஒரு பணிக்கு அவை தேவைப்படும்போது, ஒவ்வொரு சாதனத்துக்கும் ஒருமுறை கேட்கும்; உருவாக்கிகளிலோ சோதனைகளிலோ எதுவும் அவற்றைத் தொடுவதில்லை.
