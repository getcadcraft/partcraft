ஸ்கிரிப்ட் பணியிடத்தில் ஒரு பகுப்பாய்வு என்பது மாறிகளை ஒன்றுக்கொன்று கையளிக்கும் சில சிறிய ஸ்கிரிப்ட்கள். உங்களுக்கு நெருக்கமான [நூலகச்](topic:craftscript-library) செயல்பாட்டிலிருந்து தொடங்குங்கள், நகல் எடுத்து மாற்றுங்கள்; அல்லது கீழே உள்ளபடி ஒன்றைக் கட்டுங்கள்.

## 1. ஒரு வலை

```
model = part();                  % நீங்கள் மாதிரியாக்கும் பாகம், ஒரு மாதிரியாக
m = tetmesh(model, 4);           % ஏறத்தாழ 4 mm குறுக்களவுள்ள டெட்ராஹெட்ராக்கள்
show(m)
```

தொடர்வதற்கு முன் காட்சியில் வலையைச் சரிபாருங்கள்: {{key:F}} அதைப் பொருத்தும், **காட்டப்பட்டவை** இல் உள்ள {{ui:eye}} பாகத்தை மறைக்கும்.

## 2. இணைத்துத் தீர்த்தல்

உறுப்புச் சுழற்சியை ஸ்கிரிப்டில் எழுதுங்கள் (அது பாடநூலைப் போலப் படிக்கும்), கனமான பகுதிகளை உள்ளமைந்த செயல்பாடுகளிடம் விடுங்கள்: உறுப்பு அணிகள், மும்மைகளிலிருந்து சிதறல் இணைப்பு, முன்நிபந்தனையுடன் இணைச் சாய்வு (conjugate gradient) தீர்வி. `static_tet` போன்ற ஒரு நூலகச் செயல்பாடு (நூலகத்தில் இப்போது இருந்தால்) நகலெடுக்க ஒரு முழுமையான எடுத்துக்காட்டு.

## 3. முடிவைக் காட்டுதல்

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % ஒரு முனைக்கு ஒரு மதிப்பு
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- வண்ண அளவுகோலின் வரம்பைத் தட்டச்சு செய்யலாம், அல்லது {{ui:தானியங்கி}} க்கு மீட்டமைக்கலாம்.
- ஒரு முனையின் மதிப்புகளைப் படிக்க காட்டப்பட்ட வலையைக் கிளிக் செய்யுங்கள்.
- அதே `'id'` ஐ வைத்திருக்கும் ஒரு வரைபடம் இடத்திலேயே புதுப்பிக்கப்படும், ஆகவே ஒருங்கலைக் கவனிக்க உங்கள் சுழற்சிக்குள் அச்சிட்டு வரையுங்கள்.

## 4. அதைச் சரிபார்த்தல்

உங்களுக்குத் தெரிந்த ஒன்றுடன் ஒப்பிடுங்கள்: கான்டிலீவரின் முனை விலகலை PL³/3EI உடன், துளையுள்ள தகட்டை அதன் அழுத்தச் செறிவுக் காரணியுடன், எதிர்வினைகளை சுமைகளுடன். ஒவ்வொரு மாற்றத்துக்குப் பிறகும் மீண்டும் இயங்க, சரிபார்ப்பைத் தனி ஸ்கிரிப்ட்டாக எழுதுங்கள்:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);     % கற்றைக் கோட்பாடு
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. வைத்திருத்தல்

- ஒவ்வொரு படியும் அதன் சொந்த ஸ்கிரிப்ட் தாவலாக இருக்கலாம்: அவை மாறிகளைப் பகிர்கின்றன, ஆகவே அவற்றை ஒன்றன்பின் ஒன்றாக இயக்குங்கள்.
- ஸ்கிரிப்ட்கள் பாகத்தில் சேமிக்கப்படுகின்றன. முடிவுகளையும் வைத்திருக்க, மாறிகள் தாவலில் **பாகத்துடன் மாறிகளைச் சேமி** ஐத் தேர்ந்தெடுங்கள் (32 MB வரை).
- ஸ்கிரிப்ட் குழுவில் உள்ள {{ui:சேமி}} ஒரு ஸ்கிரிப்டைப் பகிர இறக்கும்; {{ui:திற}} ஒன்றைக் கொண்டுவரும்.
