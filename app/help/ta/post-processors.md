ஒரே கருவிப் பாதை வெவ்வேறு கட்டுப்பாடுகளுக்கு வெவ்வேறு விதமாக எழுதப்பட வேண்டும்: வரி எண்கள் வேண்டுமா அல்லது இல்லையா, `M6` அல்லது இடைநிறுத்தம், `G28` அல்லது `G53`, `M30` அல்லது `M2`. **போஸ்ட்** என்பது அதை எப்படிச் செய்வது என்று கூறும் குறுகிய உரை. PartCraft இன் மூன்று உள்ளமைந்த போஸ்ட்கள் (Fanuc-style, GRBL மற்றும் LinuxCNC) இந்த வடிவத்தில் எழுதப்பட்டுள்ளன; எனவே உங்கள் சொந்த போஸ்ட் ஒன்றை அவற்றில் ஒன்றின் நகலாகத் தொடங்கலாம்.

வெட்டுவதற்கு முன் உங்கள் இயந்திரத்தின் சொந்த சிமுலேட்டரில் சரிபார்த்துக்கொள்ளுங்கள், முதலில் பொருளுக்கு மேலே காற்றில் இயக்கிப் பாருங்கள். உள்ளமைந்த போஸ்ட்கள் இந்த வடிவம் வருவதற்கு முன் எழுதியதையே எழுதுகின்றன (சோதனைகள் நூற்றுக்கணக்கான நிரல்களில் அவற்றின் வெளியீட்டை பைட்-பை-பைட்டாக ஒப்பிடுகின்றன), ஆனால் இங்குள்ள எதுவும் உங்கள் இயந்திரத்தில் நிரூபிக்கப்படவில்லை; நீங்கள் மாற்றிய போஸ்ட்டை நிரூபிக்க வேண்டியது உங்கள் பொறுப்பு.

## ஒன்றை உருவாக்கு

உற்பத்தியில், **போஸ்ட்** இன் கீழ்:

- {{ui:போஸ்ட்டைத் திருத்து…}} ஓர் உள்ளமைந்த கட்டுப்பாட்டில் **உங்கள் சொந்த நகலைத்** திறக்கும். நீங்கள் உருவாக்கிய போஸ்ட்டில் அது அதையே திறக்கும்.
- {{ui:புதிய போஸ்ட்…}} ஒவ்வொரு நிகழ்வும் உள்ள ஒரு சிறிய வெற்று போஸ்ட்டில் தொடங்கும்.
- {{ui:போஸ்ட் கோப்பை இறக்குமதி செய்…}} `.cpost` உரைக் கோப்பைப் படிக்கும் (திருத்தியில் **கோப்பாக சேமி…** இலிருந்து நீங்கள் பெறும் கோப்பு).

திருத்தி உரையைக் காட்டும்; அது படிக்கப்படுகிறதா (மற்றும் எந்த வரி தவறு) என்று சொல்லும் வரி; நீங்கள் தட்டச்சு செய்யும்போதே போஸ்ட் எழுதும் G-code ஐயும் காட்டும். **இதனுடன் முன்னோட்டம்** ஒவ்வொரு நிகழ்வையும் இயக்கும் ஒரு சிறிய மாதிரி நிரலைத் தேர்ந்தெடுக்கும், அல்லது இந்தப் பகுதியின் சொந்த நிரலைத் தேர்ந்தெடுக்கும். {{ui:சேமி}} போஸ்ட்டை பகுதியின் கோப்பில் வைத்திருக்கும் (20 போஸ்ட்கள் வரை) மற்றும் அதைக் கட்டுப்பாடாகத் தேர்ந்தெடுக்கும். போஸ்ட்கள் பகுதியுடன் பயணிக்கும்; வேறொரு பகுதியில் பயன்படுத்த, கோப்பாக சேமித்து அங்கே இறக்குமதி செய்யுங்கள்.

## போஸ்ட் எப்படி இருக்கும்

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` என்று தொடங்கும் வரிகளும் வெற்று வரிகளும் புறக்கணிக்கப்படும். மேலே அமைப்புகள் வரும்; பின்னர் ஒவ்வொரு நிகழ்வுக்கும் ஒரு `on <event>` தொகுதி, `end` உடன் முடிந்து. நீங்கள் விட்டுவிடும் நிகழ்வு எதையும் எழுதாது.

| அமைப்பு | பொருள் |
|---|---|
| `post <id>` | போஸ்ட்டின் அடையாளம்: எழுத்துகள், எண்கள், `-` மற்றும் `_` |
| `name <text>` | கட்டுப்பாட்டுப் பட்டியல் காட்டுவது |
| `extension <ext>` | கோப்பு நீட்டிப்பு: nc, ngc, tap … |
| `line-numbers 10` / `off` | ஒவ்வொரு `emit` வரியிலும் `N10`, `N20` … அல்லது எதுவுமில்லை |
| `decimal-point yes` / `no` | `10` க்குப் பதிலாக `10.` (கருத்துரைகளில் புள்ளி ஒருபோதும் இடம்பெறாது) |
| `canned-cycles yes` / `no` | `no`: துளைகள் அவை குறிக்கும் G0/G1 நகர்வுகளாக எழுதப்படும் |
| `modal <group> <words>` | ஒரு குழுவின் சொற்கள் (`modal motion G0 G1 G2 G3`); மாறும்போது மட்டுமே எழுதப்படும் |

## நிகழ்வுகள்

அவை ஒரு நிரலுக்கு இந்த வரிசையில் இயங்கும்: `start`; பின்னர் ஒவ்வொரு செயல்பாட்டுக்கும் `operation`, `tool-change` (கருவி மாறும்போது), `spindle` (வேகம் மாறும்போது), `approach` (முதல் புள்ளிக்குச் செல்லும் நகர்வு, முதல் விரைவு நகர்வுக்கு முன்), `coolant-on`, பின்னர் அதன் நகர்வுகள் `rapid`, `feed` மற்றும் `arc` ஆக, ஒவ்வொரு நிலையான சுழற்சியும் `cycle-start` ஆக, ஒவ்வொரு துளைக்கும் ஒரு `cycle-hole`, மற்றும் `cycle-end`; கடைசியில் `end`.

ஒவ்வொரு நிகழ்வும் அதன் சொந்த வகை நகர்வின் மாறிகளைப் பயன்படுத்தலாம், `{name}` என எழுதப்படும்: நிரல் (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), பொருள் (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), கருவி (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), செயல்பாடு (`op.name`, `op.type`), `rpm`, ஒரு நகர்வின் புள்ளி (`x`, `y`, `z`, `f`, மற்றும் ஓர் அச்சு மாறினால் true ஆகும் `moved`), வளைவுகள் (`arc.g` 2 அல்லது 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) மற்றும் துளைகள் (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). திருத்தியின் **நிகழ்வுகளும் மாறிகளும்** பட்டியல் எந்த நிகழ்வு எதைப் பார்க்கிறது என்பதைக் காட்டும். நீங்கள் படிக்கவும் அமைக்கவும் முடியும் நிலை: `cool`, `offset`, மற்றும் `at.x`, `at.y`, `at.z`, `at.f` (கடைசியாக எழுதப்பட்ட மதிப்புகள்).

## கூற்றுகள்

| கூற்று | என்ன செய்கிறது |
|---|---|
| `raw TEXT` | தட்டச்சு செய்தபடியே ஒரு வரி (வரி எண் இல்லை) |
| `comment TEXT` | ASCII அல்லாதவையும் அடைப்புக்குறிகளும் நீக்கப்பட்ட `(TEXT)` |
| `emit WORD WORD …` | சொற்களின் ஒரு வரி; வெறுமையாக வரும் சொற்கள் விடப்படும்; சொற்கள் இல்லையெனில் வரி இல்லை |
| `word WORD …` | கட்டப்பட்டுக்கொண்டிருக்கும் வரியில் சொற்களைச் சேர்; வெறும் `emit` அதை முடிக்கும் |
| `if EXPR` … `else` … `end` | நிபந்தனைகள்: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, இல்லையெனில் b) |
| `for tool in tools` … `end` | நிரல் பயன்படுத்தும் ஒவ்வொரு கருவிக்கும் ஒருமுறை |
| `set NAME EXPR` | ஒரு மதிப்பை நினைவில் வை (`set offset tool.number`) |
| `reset NAME …` | modal சொற்களை மறந்துவிடு (ஒரு குழு, `Z` போன்ற முகவரி எழுத்து, அல்லது `at.z`) |
| `do rapid X Y Z` | ஒரு புள்ளிக்கு `rapid` நிகழ்வை இயக்கு |

ஒரு சொல் என்பது `{variable|filter}` துளைகளுடன் கூடிய தட்டச்சு செய்யப்பட்ட உரை. வடிப்பான்கள்: `upper`, `lower`, `pad:N` (பூஜ்ய நிரப்பு), `cut:N` (முதல் N எழுத்துகள்), `safe` (கருத்துரைக்கு பாதுகாப்பான ASCII) மற்றும் `int`. `~` இல் முடியும் சொல் **modal**: கடைசியாக எழுதப்பட்டதிலிருந்து மாறும்போது மட்டுமே எழுதப்படும் (`G1~`, `X{x}~`). `~!` இல் முடியும் சொல் ஒவ்வொரு முறையும் எழுதப்படும், ஆனாலும் நினைவில் வைக்கப்படும். மாறி அல்லாத பெயர் எளிய உரை (`G81`, `mist`). எண்கள் 0.001 mm க்கு முழுமையாக்கப்பட்டு பின்தொடர் பூஜ்யங்கள் இல்லாமல் எழுதப்படும்.

## போஸ்ட் என்ன செய்ய முடியாது

அது நகர்வுகள் எப்படி எழுதப்படுகின்றன என்பதை மட்டுமே தீர்மானிக்கும், வேறொன்றுமில்லை. அது கருவிப் பாதையை மாற்றாது, செயல்பாடுகளை வரிசைப்படுத்தாது, ஒரு வளைவைப் பிரிக்காது, ஓர் அச்சைச் சேர்க்காது, உங்கள் இயந்திரத்தின் பயண எல்லைகளையோ இயக்கவியலையோ அறியாது, அல்லது ஆயங்களில் கணிதம் செய்யாது (`+` இல்லை). ஆய்வு (ப்ராபிங்), கருவி ஆயுள் மற்றும் துணை நிரல் சுழற்சிகள், 4வது மற்றும் 5வது அச்சு வெளியீடு, மற்றும் லேத் குறியீடுகள் உருவாக்கப்படவில்லை. வேறொரு நிரலின் `.cps`-பாணி போஸ்ட் கோப்பை ஏற்ற முடியாது: இது வேறுபட்ட, எளிய வடிவம்.
