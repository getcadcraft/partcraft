ஒரே கருவிப் பாதை வெவ்வேறு கட்டுப்பாட்டிகளுக்கு வெவ்வேறு முறையில் எழுதப்பட வேண்டும்: வரி எண்கள் உள்ளதா இல்லையா, `M6` அல்லது ஒரு இடைநிறுத்தம், `G28` அல்லது `G53`, `M30` அல்லது `M2`. **போஸ்ட்** என்பது அதை எப்படிச் செய்வது என்று சொல்லும் சிறிய உரை. PartCraft-இன் மூன்று உள்ளமைந்த போஸ்ட்களும் (Fanuc பாணி, GRBL மற்றும் LinuxCNC) இந்த வடிவத்தில் எழுதப்பட்டுள்ளன; ஆகவே உங்கள் சொந்த போஸ்ட் அவற்றில் ஒன்றின் நகலாகத் தொடங்கலாம்.

வெட்டுவதற்கு முன் உங்கள் இயந்திரத்தின் சொந்த உருவகப்படுத்தியில் வெளியீட்டைச் சரிபார்க்கவும்; பங்குக்கு மேலே காற்றில் முதலில் இயக்கவும். உள்ளமைந்த போஸ்ட்கள், இந்த வடிவம் இருப்பதற்கு முன் எழுதியதையே சரியாக எழுதுகின்றன (சோதனைகள் நூற்றுக்கணக்கான நிரல்களில் அவற்றின் வெளியீட்டை பைட்-பைட்டாக ஒப்பிடுகின்றன); ஆனால் இங்குள்ள எதுவும் உங்கள் இயந்திரத்தில் நிரூபிக்கப்படவில்லை, நீங்கள் மாற்றும் போஸ்ட் நீங்கள் நிரூபிக்க வேண்டியது.

## ஒன்றை உருவாக்குவது

Manufacture-இல், **போஸ்ட்** கீழ்:

- ஒரு உள்ளமைந்த கட்டுப்பாட்டியில் {{ui:போஸ்ட்டைத் திருத்து…}} **உங்கள் சொந்த நகலை** திறக்கும். உங்கள் சொந்த போஸ்ட்களில் ஒன்றில் அது அதைத் திறக்கும்.
- {{ui:புதிய போஸ்ட்…}} ஒவ்வொரு நிகழ்வும் உள்ள ஒரு சிறிய வெற்று போஸ்டில் தொடங்கும்.
- {{ui:போஸ்ட் கோப்பை இறக்குமதி செய்…}} ஒரு `.cpost` உரைக் கோப்பைப் படிக்கும் (எடிட்டரில் **Save as a file…**-இலிருந்து நீங்கள் பெறும் கோப்பு).

எடிட்டர் உரையைக் காட்டும்; அது படிக்கப்படுகிறதா (எந்த வரி தவறு என்பதுடன்) என்று சொல்லும் ஒரு வரி, மற்றும் நீங்கள் தட்டச்சு செய்யும்போதே போஸ்ட் எழுதும் G-குறியீடு. **முன்னோட்டம்** ஒவ்வொரு நிகழ்வையும் இயக்கும் ஒரு சிறிய மாதிரி நிரலை அல்லது இந்தப் பகுதியின் சொந்த நிரலைத் தேர்ந்தெடுக்கும். {{ui:சேமி}} போஸ்டைப் பகுதிக் கோப்பில் வைத்திருக்கும் (20 போஸ்ட்கள் வரை) மற்றும் அதைக் கட்டுப்பாட்டியாகத் தேர்ந்தெடுக்கும். போஸ்ட்கள் பகுதியுடன் பயணிக்கும்; இன்னொரு பகுதியில் ஒன்றைப் பயன்படுத்த, அதைக் கோப்பாகச் சேமித்து அங்கே இறக்குமதி செய்யுங்கள்.

## போஸ்ட் எப்படித் தோன்றுகிறது

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` உடன் தொடங்கும் வரிகளும் வெற்று வரிகளும் புறக்கணிக்கப்படுகின்றன. மேலே அமைப்புகள் வருகின்றன; பின்னர் ஒவ்வொரு நிகழ்வுக்கும் ஒரு `on <event>` தொகுதி, `end`-உடன் மூடப்படும். நீங்கள் விட்ட நிகழ்வு எதையும் எழுதாது.

| அமைப்பு | பொருள் |
|---|---|
| `post <id>` | போஸ்டின் அடையாள எண்: எழுத்துகள், இலக்கங்கள், `-` மற்றும் `_` |
| `name <text>` | கட்டுப்பாட்டிப் பட்டியல் காட்டுவது |
| `extension <ext>` | கோப்பு நீட்சி: nc, ngc, tap … |
| `line-numbers 10` / `off` | ஒவ்வொரு `emit` வரியிலும் `N10`, `N20` … அல்லது எதுவுமில்லை |
| `decimal-point yes` / `no` | `10` என்பதற்குப் பதில் `10.` (கருத்துகள் ஒருபோதும் புள்ளியைக் கொண்டிருக்காது) |
| `canned-cycles yes` / `no` | `no`: துளைகள் அவை குறிக்கும் G0/G1 நகர்வுகளாக எழுதப்படும் |
| `modal <group> <words>` | ஒரு குழுவின் சொற்கள் (`modal motion G0 G1 G2 G3`) மாறும்போது மட்டுமே எழுதப்படும் |

## நிகழ்வுகள்

ஒரு நிரலுக்கு அவை இந்த வரிசையில் இயங்கும்: `start`; பிறகு ஒவ்வொரு செயல்பாட்டுக்கும் `operation`, `tool-change` (கருவி மாறும்போது), `spindle` (வேகம் மாறும்போது), `approach` (முதல் புள்ளிக்கான மேல்நோக்கிய நகர்வு, முதல் விரைவுக்கு முன்), `coolant-on`, பிறகு அதன் நகர்வுகள் `rapid`, `feed` மற்றும் `arc` ஆக, ஒவ்வொரு நிலையான சுழற்சியும் `cycle-start` ஆக, ஒவ்வொரு துளைக்கும் ஒரு `cycle-hole` மற்றும் `cycle-end`; கடைசியாக `end`.

மூன்று அச்சுகளுக்கு அப்பாற்பட்டவற்றுக்கான கூடுதல் நிகழ்வுகள் (அத்தகைய நிரலை ஒரு போஸ்ட் நிராகரிக்கும், அதற்கு இல்லாத நிகழ்வின் பெயரைச் சொல்லும்):

| நிகழ்வு | எப்போது | அதன் மாறிகள் |
|---|---|---|
| `index` | கருவித் திசை கடைசியிலிருந்து வேறுபடும் ஒரு செயல்பாட்டுக்கு முன், மற்றும் சுழல் அச்சுகள் உள்ள இயந்திரத்தில் முதல் செயல்பாட்டுக்கு முன் | `rot.a`, `rot.b`, `rot.c` (செல்ல வேண்டிய நிலைகள்; இயந்திரத்தில் இல்லாத அச்சுக்கு காலி), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | அது வெட்டும்போது சுழல் அச்சுகள் நகரும் ஒரு செயல்பாட்டின் நகர்வுகள் | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (ஊட்டம் நேரத்தின் தலைகீழாக இருக்க வேண்டிய போது yes), `invf` (1/நிமிடங்கள்) |
| `rotary-end` | அத்தகைய செயல்பாட்டுக்குப் பிறகு | |
| `probe-move` | ப்ரோப் தொடும்போது நிற்கும் ஒரு நகர்வு | `x`, `y`, `z`, `f`, `probe.n` (1 முதல் 4), `probe.axis` (x, y அல்லது z), `probe.k` (1, 2 அல்லது 3) |
| `probe-set` | ஒரு ப்ரோபிங் சுழற்சியின் தொடுதல்களுக்குப் பிறகு | `probe.kind` (`"z"`, `"x"`, `"y"` அல்லது `centre`), `probe.action` (`set` அல்லது `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | லேத்தில் ஒரு திரிகை நகர்வு | `x`, `z`, `thread.lead` |

ஒவ்வொரு நிகழ்விற்கும்: `kin` (none, a, b, ac, bc), `rotary` மற்றும் `tcp` (yes அல்லது no, அமைப்பில் உள்ள இயந்திரத்திலிருந்து), `pivot.x`, `pivot.y`, `pivot.z`, செயல்பாட்டின் `op.tilt` மற்றும் `op.turn`, லேத்தில் `spin.mode` (css அல்லது rpm), `spin.css`, `spin.max` மற்றும் `tool.nose`. மதிப்பு காலியான ஓர் எழுத்து சொல், எடுத்துக்காட்டாக A அச்சு இல்லாத இயந்திரத்தில் `A{rot.a}`, வரியிலிருந்து விடப்படும். x, y மற்றும் z-ஐ உரையாக மேற்கோள்களுடன் ஒப்பிடுங்கள் (`if probe.kind == "z"`): வெறுமையாக, அவை நகர்வின் ஆயத்தொலைவுகள்.

போஸ்டை ஒரு லேத் போஸ்ட் ஆக்கும் மேலும் இரண்டு வரிகள்: `machine lathe` (அது X மற்றும் Z மட்டுமே எழுதும், அரவைப் போஸ்ட் திருப்பு பாதைகளை மறுப்பது போலவே அரவைப் பாதைகளை மறுக்கும்) மற்றும் `lathe-x diameter` அல்லது `lathe-x radius`.

ஒவ்வொரு நிகழ்வும் அதன் சொந்த வகை நகர்வின் மாறிகளைப் பயன்படுத்தலாம், `{name}` என எழுதப்பட்டவை: நிரல் (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), பங்கு (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), கருவி (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), செயல்பாடு (`op.name`, `op.type`), `rpm`, ஒரு நகர்வின் புள்ளி (`x`, `y`, `z`, `f`, மற்றும் `moved`: ஓர் அச்சு மாறியிருந்தால் true), வளைவுகள் (`arc.g` 2 அல்லது 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) மற்றும் துளைகள் (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). எடிட்டரின் **நிகழ்வுகளும் மாறிகளும்** பட்டியல் எந்த நிகழ்வு எதைப் பார்க்கிறது என்று காட்டும். நீங்கள் படிக்கவும் அமைக்கவும் முடியும் நிலை: `cool`, `offset`, மற்றும் `at.x`, `at.y`, `at.z`, `at.f` (கடைசியாக எழுதப்பட்ட மதிப்புகள்).

## அறிக்கைகள்

| அறிக்கை | அது என்ன செய்கிறது |
|---|---|
| `raw TEXT` | தட்டச்சு செய்தபடியே ஒரு வரி (வரி எண் இல்லாமல்) |
| `comment TEXT` | `(TEXT)`, ASCII அல்லாதவையும் அடைப்புக்குறிகளும் நீக்கப்பட்டு |
| `emit WORD WORD …` | சொற்களின் ஒரு வரி; காலியாக வரும் சொற்கள் விடப்படும்; சொற்கள் இல்லையெனில் வரி இல்லை |
| `word WORD …` | கட்டமைக்கப்படும் வரியில் சொற்களைச் சேர்; ஒரு வெற்று `emit` அதை முடிக்கும் |
| `if EXPR` … `else` … `end` | நிபந்தனைகள்: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, இல்லையெனில் b) |
| `for tool in tools` … `end` | நிரல் பயன்படுத்தும் ஒவ்வொரு கருவிக்கும் ஒருமுறை |
| `set NAME EXPR` | ஒரு மதிப்பை நினைவில் வை (`set offset tool.number`) |
| `reset NAME …` | மாடல் சொற்களை மறந்துவிடு (ஒரு குழு, `Z` போன்ற ஓர் ஆயத்தொலைவு எழுத்து, அல்லது `at.z`) |
| `do rapid X Y Z` | ஒரு புள்ளிக்கு `rapid` நிகழ்வை இயக்கு |

ஒரு சொல் `{variable|filter}` துளைகளுடன் தட்டச்சு செய்யப்பட்ட உரை. வடிகட்டிகள்: `upper`, `lower`, `pad:N` (பூஜ்யம் நிரப்பு), `cut:N` (முதல் N எழுத்துகள்), `safe` (கருத்துக்கு ஏற்ற ASCII) மற்றும் `int`. `~` இல் முடியும் சொல் **மாடல்** ஆகும்: கடைசியாக எழுதப்பட்டதிலிருந்து அது வேறுபட்டால் மட்டுமே எழுதப்படும் (`G1~`, `X{x}~`). `~!` இல் முடியும் சொல் ஒவ்வொரு முறையும் எழுதப்படும், இன்னும் நினைவில் வைக்கப்படும். மாறி அல்லாத பெயர் வெற்று உரையாகும் (`G81`, `mist`). எண்கள் 0.001 mm-க்கு வட்டமிடப்பட்டு, பின்தொடரும் பூஜ்யங்கள் இல்லாமல் எழுதப்படும்.

## போஸ்டால் என்ன செய்ய முடியாது

அது நகர்வுகள் எப்படி எழுதப்படுகின்றன என்பதை மட்டுமே தீர்மானிக்கும், அதற்கு மேல் எதுவுமில்லை. கருவிப் பாதையை மாற்ற முடியாது, செயல்பாடுகளை வரிசைப்படுத்த முடியாது, ஒரு வளைவைப் பிரிக்க முடியாது, ஓர் அச்சைச் சேர்க்க முடியாது, உங்கள் இயந்திரத்தின் பயண வரம்பு அல்லது இயக்கவியலை அறிய முடியாது, ஆயத்தொலைவுகளின்மேல் கணிதம் செய்ய முடியாது (`+` இல்லை). சுழல் நிலைகள் போஸ்டிலிருந்து அல்ல, அமைப்பில் விவரிக்கப்பட்ட இயந்திரத்திலிருந்து வருகின்றன: போஸ்ட் அவற்றின் குறியையோ எழுத்துகளையோ மாற்றலாம், இயக்கவியலை அல்ல. கருவி-ஆயுள் மற்றும் துணை நிரல் சுழற்சிகள் கட்டப்படவில்லை. வேறொரு நிரலின் `.cps` வடிவக் போஸ்ட் கோப்பை ஏற்ற முடியாது: இது வேறுபட்ட, எளிய வடிவம்.
