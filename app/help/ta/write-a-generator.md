உருவாக்கி என்பது மேலே சில கருத்துரை வரிகளுடன் கூடிய ஒரு சாதாரண ஸ்கிரிப்ட் ([CraftScript](topic:craftscript), Lua அல்லது Python) ஆகும். PartCraft கருத்துரைகளைப் படித்து படிவத்தை உருவாக்குகிறது; உங்கள் ஸ்கிரிப்ட் உள்ளீடுகளை ஏற்கனவே அமைக்கப்பட்ட மாறிகளாகப் படிக்கிறது.

## தலைப்புப் பகுதி

இவற்றைக் கருத்துரை வரிகளில் இடவும் (CraftScript: `%`, Lua: `--`, Python: `#`):

```
% @generator வெப்பப் பரிமாற்றி
% @input mdot: kg/s = 0.2 [0.01 .. 10] "நிறை ஓட்டம்"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "மேற்பரப்பு"
% @input solid: = true
% @input note: = "உரை"
```

உள்ளீடு என்பது `name: unit = default`; அதன் பின் விருப்பமாக வரம்பு `[min .. max]` (எண்கள் அதற்குள் வைக்கப்படும்), தேர்வுகளின் பட்டியல் `{a, b, c}`, மற்றும் மேற்கோள்களுக்குள் ஒரு பெயர். அலகு என்பது படிவத்திற்கான ஒரு குறிச்சொல் மட்டுமே: **மதிப்பு அந்த அலகிலேயே வந்து சேரும்**, எனவே SI வேண்டும் ஸ்கிரிப்ட் அதை மாற்ற வேண்டும்; `to_si(value, 'kg/s', 'kg/s')` அலகு நீங்கள் நினைப்பதைக் குறிக்கிறதா என்பதையும் சரிபார்க்கிறது. பெயர் எழுத்துகள், இலக்கங்கள் மற்றும் அடிக்கோடு கொண்டிருக்கலாம்; `body`, `sheet` மற்றும் `problems` ஏற்கனவே பயன்பாட்டில் உள்ளன.

## ஸ்கிரிப்ட் விட்டுச்செல்வது

| மாறி | என்ன |
|---|---|
| `body` | **கட்டாயம்.** மேற்பரப்பு வலை (மெஷ்), பொதுவாக `[body, info] = to_body(field, h)` இலிருந்து. இயக்கம் முடியும்போது அது சரிசெய்யப்பட்டு சரிபார்க்கப்படும். |
| `sheet` | விருப்பத்தேர்வு. ஒரு struct: ஒவ்வொரு புலமும் ஓர் எண் அல்லது உரை, அல்லது `value`, `unit`, `ref` மற்றும் `note` கொண்ட struct. இது தரவுத் தாளாக மாறும். |
| `problems` | விருப்பத்தேர்வு. `mfg_check(field, 'sls', struct(), h)` இலிருந்து வரும் `problems` செல், அல்லது உங்கள் சொந்த உள்ளீடுகள். அவை சரிபார்ப்புகளுக்கும் சிக்கல்கள் பட்டியலுக்கும் செல்லும். |

## முழுமையான சிறிய எடுத்துக்காட்டு

```
% ஒரு சுவருடன் கூடிய உட்புழையுள்ள கனசதுரம்.
% @generator உட்புழை கனசதுரம்
% @input side: mm = 12 [4 .. 40] "பக்கம்"
% @input wall: mm = 1.5 [0.5 .. 5] "சுவர்"
% @input h: mm = 0.5 [0.25 .. 2] "வோக்சல் அளவு"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'வலையிலிருந்து');
```

இது மூடிய பெட்டியை உருவாக்குகிறது; தூள் செயல்முறைக்கு, அதன் மூடிய உட்புறம் ஒரு பிழையாக சரிபார்ப்பில் தெரிவிக்கப்படும். நீங்கள் விரும்பும் மெல்லிய சுவரின் மூன்றில் ஒரு பங்கிற்கு மேல் வோக்சல் அளவு `h` ஐ அமைக்க வேண்டாம்: மூன்று வோக்சல்களுக்குக் கீழே சுவர் நம்பகமாக இருக்காது.

## புலங்கள்

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ஒரு சுயவிவரத்திலிருந்து சுழற்சியின் திடப்பொருள்), `tpms` (gyroid, Schwarz P மற்றும் diamond மேற்பரப்புகள்; பாகம் முழுவதும் மாறக்கூடிய செல் அளவு மற்றும் சுவருடன்), `lattice` மற்றும் `lattice_beams`, `along` (ஒரு பாதையில் வட்ட வழித்தடம்), பூலியன் செயல்பாடுகள் `field_union`, `field_intersect`, `field_subtract`, மென்மையான `field_blend`, மற்றும் `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` புள்ளிகளில் கையொப்பமிட்ட தொலைவைத் தருகிறது (உட்புறத்தில் எதிர்மறை), `field_voxel` தீர்வுகளுக்கான வோக்சல்களைத் தருகிறது. [புலங்கள்](topic:fields) அவை என்னவென்று விளக்குகிறது.

தெரிந்துகொள்ள வேண்டிய வரம்புகள்: செல்லின் கால் பங்கை விடத் தடிமனான தாள் சுவர் வழித்தடங்களை மூடிவிடும்; மூன்று வோக்சல்களை விடக் குறுகிய அம்சம் கிள்ளிவிடக்கூடும்; `along` வட்ட கூம்புகளை இணைக்கிறது, எனவே ஆரம் வேகமாக மாறினால் புடைப்பு ஏற்படும் (ஒரு சுயவிவரத்திற்கு `field_revolve` ஐப் பயன்படுத்தவும்).

## உங்கள் ஸ்கிரிப்டை உருவாக்கியாகத் திறத்தல்

{{ui:பொறியாளர்}} பணியிடத்தில் {{ui:திற}} பொத்தானைச் சொடுக்கி கோப்பைத் தேர்ந்தெடுக்கவும். `@generator` அல்லது `@input` வரி இல்லாத ஸ்கிரிப்ட் ஏற்கப்படாது: அமைக்க எதுவும் இருக்காது. உருவாக்கி இந்த உலாவியில் சேமிக்கப்படும் (20 வரை), மேலும் {{ui:நீக்கு}} அதை நீக்கும். அதிலிருந்து தொடங்கப்பட்ட உடல் ஸ்கிரிப்டின் நகலைக் கொண்டிருக்கும், எனவே பாகம் அதைச் சார்ந்திருக்காது.

ஒரு கோப்பில் பல உருவாக்கிகளும் இருக்கலாம்: ஒரு JSON தொகுப்பு `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
