நீங்கள் பலகத்தில் உள்ள பெட்டியில் தட்டச்சு செய்யும்போது விசைகள் எதுவும் செய்யாது. ஆனால் {{key:Mod+S}} மற்றும் {{key:Mod+O}} எப்போதும் வேலை செய்யும். எழுத்து விசைகள் மாற்றி விசை இல்லாமலும் வேலை செய்யும்.

உலாவியில் உள்ள விசைகள் மற்றும் செயல்பாட்டு விசைகள் இல்லாத விசைப்பலகைகள் பற்றிய பொதுவான குறிப்புகள்: [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys).

## எல்லா இடங்களிலும்

| விசை | செயல் |
|---|---|
| {{key:Mod+S}} | பாகத்தைச் சேமி (அசெம்பிளியில்: அசெம்பிளியைச் சேமி). திறந்துள்ள ஓவியம் இருந்தால் முதலில் அதை மூடும் |
| {{key:Mod+O}} | பாகம் அல்லது அசெம்பிளிக் கோப்பைத் திற (சேமிக்காத மாற்றங்கள் இருந்தால் முதலில் கேட்கும்) |
| {{key:Mod+Z}} | செயல்தவிர் |
| {{key:Mod+Y}} அல்லது {{key:Mod+Shift+Z}} | மீண்டும்செய் |
| {{key:F1}} | இந்த உதவியைத் திற அல்லது மூடு (ஆப் பட்டியில் உள்ள {{ui:Help}} பொத்தானும் இதைச் செய்யும்). {{key:Esc}} இதையும் மூடும். பல மடிக்கணினிகள் மற்றும் Mac விசைப்பலகைகளில் Fn ஐ அழுத்திப் பிடி |
| {{key:Ctrl+Shift+F}} | திரை முறை: சாதாரணம், முழுத் திரை, பட்டிகள் மறைக்கப்பட்ட முழுத் திரை. Mac இலும் Control; ⌘ அல்ல |
| {{key:Esc}} | முழுத் திரையிலிருந்து வெளியேறு (முழுத் திரையில் இருக்கும்போது) |
| {{key:Mod+,}} | அமைப்புகள், PartCraft தாவல் உட்பட (see [PartCraft அமைப்புகள்](topic:settings)) |

ஒரு பலகத்தின் எண் பெட்டியில், {{key:Mod+Z}} உலாவியின் சொந்த உரைச் செயல்தவிர். ஓவியப் பரிமாணத்தின் மேல் உள்ள எண் பெட்டியில் அது PartCraft இல் செயல்தவிர்க்கும்.

## நகலெடு, ஒட்டு மற்றும் நகலாக்கு

இவை நீங்கள் வேலை செய்யும் இடத்தின் மீது செயல்படும்: திறந்துள்ள ஓவியத்தில் தேர்ந்தெடுத்த வடிவவியல், வரலாற்றில் தேர்ந்தெடுத்த அம்சம், அல்லது அசெம்பிளியில் தேர்ந்தெடுத்த பாகம். விவரங்களுக்கு [நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste).

| விசை | செயல் |
|---|---|
| {{key:Mod+C}} | தேர்வை நகலெடு |
| {{key:Mod+X}} | வெட்டு: நகலெடு, பிறகு நீக்கு |
| {{key:Mod+V}} | ஒட்டு. ஓவியத்தில் நகல் சுட்டியைப் பின்தொடரும்: அது போக வேண்டிய இடத்தில் கிளிக் செய் |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: அதே ஆயத்தொலைவுகளில் (அசெம்பிளியில், அதே இடத்தில்) |
| {{key:Mod+D}} | நகலாக்கு: ஒரே படியில் நகலெடுத்து ஒட்டு; கிளிப்போர்டைத் தொடாது |
| {{key:Mod+A}} | அனைத்தையும் தேர்ந்தெடு (ஓவியத்தில்) |
| {{key:Esc}} | எதுவும் தேர்ந்தெடுக்காதே (பின்தொடரும் ஒட்டுதலையும் ரத்துசெய்யும்) |

எண் பெட்டியில் இந்த விசைகள் வழக்கம்போல உரையை நகலெடுத்து ஒட்டும். பலகத்தில் தேர்ந்தெடுத்த உரையை உலாவி நகலெடுக்கும்.

## உலாவி எடுத்துக்கொள்ளக்கூடிய குறுக்குவழிகள்

- Safari இல் {{key:Mod+Y}} வரலாற்றைத் திறக்கலாம்: மீண்டும்செய்ய {{key:Mod+Shift+Z}} பயன்படுத்து.
- {{key:Mod+D}} உலாவியின் புக்மார்க் விசை: ஆப் கவனத்தில் இருக்கும்போது PartCraft அதை எடுத்துக்கொள்ளும்; பெட்டியில் நீ தட்டச்சு செய்யும்போது அதை விட்டுவிடும்.
- {{key:F11}} மற்றும் {{key:Mod+Plus}} / {{key:Mod+Minus}} உலாவியின் முழுத் திரை மற்றும் பக்கப் பெரிதாக்கம்; PartCraft இன் அல்ல. முழுத் திரைக்கு {{key:Ctrl+Shift+F}} மற்றும் மாதிரிக்குச் சக்கரம் பயன்படுத்து.
- பல மடிக்கணினிகள் மற்றும் Mac களில் செயல்பாட்டு விசைகளுக்கு Fn தேவை: உதவிக்கு Fn+{{key:F1}} அழுத்து, அல்லது {{ui:Help}} பொத்தானைப் பயன்படுத்து.

தொடு மற்றும் டிராக்பேடு சைகைகள்: [டிராக்பேடு, தொடுதல் மற்றும் சிறிய திரைகள்](topic:trackpad-and-touch).

## நகர்த்து எங்கே உள்ளது

நகர்த்து, அம்சங்கள் குழுவின் {{ui:More}} பட்டியில் {{ui:Move body}} ஆக உள்ளது; நீ ΔX, ΔY மற்றும் ΔZ தட்டச்சு செய்யும் {{ui:Move}} பெட்டியிலும், பாகத்தின் மீது {{ui:Drag to move}} அம்புகளாகவும் உள்ளது.
