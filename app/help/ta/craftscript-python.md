Python என்பது [ஸ்கிரிப்ட் பணியிடத்தின்](topic:craftscript) மூன்றாவது மொழி. பெட்டித் தொகுப்பின் மேலே உள்ள மொழிப் பெட்டியில் **Python** ஐத் தேர்ந்தெடுக்கவும் (`.py` கோப்பு தானாக Python இல் திறக்கும்). Python, Lua மற்றும் CraftScript ஒரே மாறிகளையும் ஒரே உள்ளமைந்த செயல்பாடுகளையும் பகிர்கின்றன; ஆகவே ஒரு Python ஸ்கிரிப்ட் ஒரு CraftScript ஸ்கிரிப்ட் உருவாக்கியதைப் பயன்படுத்தலாம், மறுதலையும் உண்டு.

வருகையில் முதல் Python இயக்கம் Python தானே (CPython 3.14, ஏறத்தாழ 7 MB) இந்தத் தளத்திலிருந்து ஏற்றும், இதற்குச் சில வினாடிகள் ஆகும். Python இன்னும் {{ui:இணைப்பின்றிப் பயன்பாட்டுக்குச் சேமி}} இன் பகுதி அல்ல: முதலில் இணையத்தில் இருக்கும்போது ஒரு Python ஸ்கிரிப்டை இயக்கவும்.

## Python அடைக்கப்பட்டுள்ளது

Python ஸ்கிரிப்ட்கள் CraftScript மற்றும் Lua ஸ்கிரிப்ட்களைப் போலவே அடைக்கப்பட்டுள்ளன: அவை பாகம், மாறிகள், உள்ளமைந்த செயல்பாடுகள் ஆகியவற்றை அடைகின்றன, வேறெதையும் அல்ல. ஒவ்வோர் இயக்கமும் அதன் சொந்த மணல்பெட்டியில் ஒரு புதிய Python ஆகும், நினைவகத்தில் ஒரு சிறிய கோப்பு மரத்துடன் (அதன் நிலையான நூலகமும், இயக்கத்துக்குப் பிறகு மறையும் ஒரு `/tmp` கோப்புறையும்). அது பிணையம், உங்கள் கோப்புகள், பக்கத்தின் மற்றவை ஆகியவற்றை அடைய முடியாது, உலாவியிலும் கட்டளை வரியிலும் ஒரே மாதிரி. வேறொருவரின் ஸ்கிரிப்ட் இன்னும் நிறைய நேரம் அல்லது நினைவகத்தை எடுக்கலாம்: {{ui:நிறுத்து}} அதை முடிக்கும்.

## அடிப்படைகள்

```
A = cs.magic(3)              # ஒவ்வோர் உள்ளமைந்த செயல்பாடும் cs.<பெயர்>
B = A @ A.T                  # @ அணிப் பெருக்கம், .T இடமாற்று
C = A * 2 + 1                # + - * / ** ஒவ்வோர் உறுப்பாக, numpy போல
print(A[0, 1], A[-1, -1])    # 0-அடிப்படை; எதிர்மறை இறுதியிலிருந்து எண்ணும்
row = A[1]                   # அணியில் ஒரு குறியீடு: ஒரு வரிசை
big = A[A > 4]               # ஒரு தருக்க முகமூடி உறுப்புகளைத் தேர்ந்தெடுக்கும்
A[0, 0] = -5                 # அணிக்குள் ஒதுக்குதல்
V, D = cs.call('eig', 2, A)  # பல முடிவுகள்: cs.call(பெயர், எத்தனை, …)
```

- 1 × 1 அணி ஒரு சாதாரண எண்ணாக வரும்; மற்ற அணிகள், சிதறல் அணிகள், வலைகள், புலங்கள், மாதிரிகள் **மதிப்புகள்**.
- ஒரு மதிப்புக்கு `shape` (ஒரு tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (அதன் வரிசைகள்), மற்றும் ஒரே உறுப்புக்கு `float()`, `int()`, `bool()` உண்டு.
- ஒப்பீடுகள் (`<`, `==`, …) numpy போல ஒவ்வோர் உறுப்பாக; அவை ஒரு தருக்க மதிப்பைத் தரும்.
- உள்ளமைந்த செயல்பாட்டுக்குக் கொடுக்கப்படும் எண்களின் பட்டியல்கள் அணிகளாகும்: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` ஓர் அணியை உருவாக்கும்.
- ஒரு dict ஒரு struct ஆகும்; கலந்த பொருட்களின் பட்டியல் ஒரு cell ஆகும்; மீண்டும் திரும்பவும்.

உங்கள் ஸ்கிரிப்ட் உருவாக்கும் ஒவ்வோர் உலகளாவிய மாறியும் (ஓர் எண், ஒரு மதிப்பு, ஒரு dict, ஒரு பட்டியல்…) பிழைக்குப் பின்னும், இயக்கம் முடியும்போது **மாறிகள்** தாவலில் சேரும். `_` இல் தொடங்கும் பெயர்கள், செயல்பாடுகள், வகுப்புகள், தொகுதிகள் Python இல் தங்கும். `ws.name` ஒரு மாறியை நேரடியாகப் படிக்கும் அல்லது அமைக்கும், `ws_names()` அவற்றைப் பட்டியலிடும்.

`print(…)` கன்சோலில் எழுதும். `display(…)` (அல்லது `cs.display`) CraftScript இல் போலவே ஒரு வலை, ஒரு புலம் அல்லது ஒரு வரைபடத்தைக் காட்டும்.

## பகுப்பாய்வு நூலகத்தை அழைத்தல்

நூலகச் செயல்பாடுகள் உள்ளமைந்தவை போலவே அழைக்கப்படுகின்றன: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. அவற்றின் பெயரை ஸ்கிரிப்டில் அது இருப்பது போலவே எழுதுங்கள்: ஒரு ஸ்கிரிப்ட் பயன்படுத்தும் நூலகச் செயல்பாடுகளை PartCraft இயக்கத்துக்கு முன்பே கண்டறியும்.

## இன்னும் இல்லாதவை

- numpy, scipy மற்றும் பிற தொகுப்புகள்: Python இன் சொந்த நிலையான நூலகம் மட்டுமே (`math`, `json`, `itertools`, `decimal`, `statistics`…) உள்ளது; அதன் சாளரம், முனையம், தரவுத்தளப் பகுதிகள் (`tkinter`, `curses`, `sqlite3`) இல்லாமல்.
- சாக்கெட்டுகளும் வெளியே எட்டக்கூடிய வேறெதுவும்: இங்கே Python க்கு பிணையம் இல்லை.
- `time.sleep` உடனே திரும்பும்.
- எடிட்டரில் மடித்தல், மற்றும் ஒரு CraftScript ஸ்கிரிப்டிலிருந்து ஒரு Python செயல்பாட்டை அழைப்பது.
- ஓர் இயக்கம் ஒவ்வோர் 1000 வரிகளுக்கும் அறிவுறுத்தல் வரம்பையும் நிறுத்தத்தையும் சரிபார்க்கும்; ஓர் உள்ளமைந்த செயல்பாட்டுக்குள் நீண்ட கணக்கீடு முதலில் முடியும்.
