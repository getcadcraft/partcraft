CraftScript என்பது MATLAB போலப் படிக்கும்படி எழுதப்பட்ட ஓர் அணி மொழி. ஆகவே பெரும்பாலான பாரம்பரிய எண்ணியல் குறிமுறைகள் (உதாரணமாக 88 வரி இடவியல் உகப்பாக்கக் குறிமுறை) சிறிய மாற்றங்களுடனேயே இயங்கும். இது [ஸ்கிரிப்ட் பணியிடத்திலும்](topic:craftscript) கட்டளை வரியிலும் இயங்கும்.

## மதிப்புகள்

| வகை | எடுத்துக்காட்டு | குறிப்புகள் |
|---|---|---|
| எண், வரிசை | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ஒவ்வொரு எண்ணும் ஓர் அணி (1×1 அணி). அணிகள் நிரல் வாரியாகச் சேமிக்கப்படுகின்றன, 8 பரிமாணங்கள் வரை |
| தருக்கம் | `A > 2`, `true` | உண்மை/பொய் அணிகள்; குறியீட்டெண்களாகப் பயன்படுத்தலாம் |
| உரை | `'beam'`, `"beam"` | |
| சிதறல் அணி | `sparse(i, j, v, n, n)` | விறைப்பு அணிகளுக்கு |
| வலை, புலம், மாதிரி | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` வரைவது |
| Struct | `s.E = 210e3` | பெயரிட்ட புலங்கள் |
| Cell | `c = {1, 'two', [3 4]}` | எந்த மதிப்புகளின் பட்டியல் |
| செயல்பாட்டுக் கைப்பிடி | `f = @(x) x.^2` | |

## வரிசைகளும் குறியீட்டெண்ணும்

- வரம்புகள்: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- குறியீட்டெண் 1 இலிருந்து தொடங்கும்: `A(2, 3)`, `v(end)`, `A(:, 1)` (முழு நிரல்), `A(:)` (அனைத்தும் ஒரே நிரலாக), `v(v > 0)` (தருக்கக் குறியீட்டெண்).
- இறுதிக்கு அப்பால் ஒதுக்கினால் அணி பெரிதாகும், MATLAB இல் போல: `v(10) = 1`.

## இயக்கிகள்

- `+ - * / \ ^` அணி இயக்கங்கள் (`A \ b` தீர்க்கும்); `.* ./ .^` ஒவ்வோர் உறுப்பாக வேலை செய்யும். `'` இடமாற்றும்.
- ஒப்பீடுகள் `== ~= < <= > >=`; தருக்கம் `& | ~` (ஒவ்வோர் உறுப்பாக) மற்றும் `&& ||` (குறுக்குவழி).

## கட்டுப்பாட்டுப் பாய்வும் செயல்பாடுகளும்

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

செயல்பாடுகள் ஸ்கிரிப்டில் அதன் கட்டளைகளுக்குப் பின், அல்லது செயல்பாட்டின் பெயரிடப்பட்ட தனி ஸ்கிரிப்ட் தாவலில் இருக்கலாம்:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ஒரு பெயர் இந்த வரிசையில் தேடப்படும்: ஒரு மாறி, இந்தப் பகுதியில் அந்தப் பெயருடைய ஒரு ஸ்கிரிப்ட், ஒரு நூலகச் செயல்பாடு, ஒரு உள்ளமைந்த செயல்பாடு.

## எதிரொலி, கருத்துரைகள், வெளியீடு

- `;` இல்லாத கூற்று அதன் மதிப்பை அச்சிடும்; `;` அமைதியாக வைக்கும்.
- `%` ஒரு கருத்துரையைத் தொடங்கும்; தனி வரிகளில் `%{` மற்றும் `%}` அவற்றுக்கு இடையிலுள்ள வரிகளைக் கருத்துரையாக்கும்.
- `disp(x)`, `fprintf('%g\n', x)` மற்றும் `display(x)` கன்சோலில் அச்சிடும்.

## பிழைகளும் வரம்புகளும்

- பிழைகள் என்ன தவறு என்பதை எளிய சொற்களில் கூறும், வரியையும் (மற்றும் செயல்பாட்டு அழைப்புகளின் தொடரையும்) தரும்.
- ஒவ்வோர் இயக்கத்துக்கும் ஒரு படிநிலை வரம்பு உண்டு (பலகத்தில் இயக்க விருப்பங்கள்); முடிவற்ற சுழல் ஒரு செய்தியுடன் நிற்கும், அல்லது நிறுத்து ஐ அழுத்தவும்.
- ஒவ்வோர் அணியும் 134 மில்லியன் மதிப்புகள் வரை வைத்திருக்கும்.

## MATLAB போல் அல்லாதவை

- வரைபடக் கட்டளைகள் தங்கள் விருப்பங்களை அழைப்பிலேயே வைக்கும்: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` போன்றவை ஏற்கப்படும், ஆனால் எதுவும் செய்யாது.
- `input` மற்றும் `keyboard` ஆதரிக்கப்படுவதில்லை: ஒரு ஸ்கிரிப்ட் கேள்வி கேட்க நிற்க முடியாது.
- கருவிப்பெட்டிகள் இல்லை; [பகுப்பாய்வு நூலகமும்](topic:craftscript-library) உள்ளமைந்த செயல்பாடுகளுமே உள்ளன.
