## நீங்கள் கற்றுக்கொள்வது

உங்கள் AI உதவியாளர் (அல்லது நீங்கள் எழுதிய ஸ்கிரிப்ட்) நீங்கள் திறந்திருக்கும் பாகத்தைப் பார்க்கவும், அதன் அளபுருக்களை மாற்றவும், ஸ்கிரிப்டை இயக்கவும், ஏற்றுமதி செய்யவும் எப்படி அனுமதிப்பது, மேலும் அது எதைத் தொடலாம் என்பதை நீங்கள் எப்படித் தீர்மானிப்பது என்பது பற்றியது.

PartCraft தனக்கென **AI எதையும் கொண்டிருக்கவில்லை**; எதையும் எங்கும் அனுப்புவதில்லை. உதவியாளரை நீங்கள் கொண்டு வர வேண்டும்: Model Context Protocol (MCP) பேசும் எந்த நிரலும். PartCraft அதற்குக் கருவிகளை மட்டுமே தரும்; எவற்றைத் தருவது என்பதை நீங்கள் தேர்ந்தெடுக்கலாம்.

## இயக்கு

1. {{ui:அமைப்புகள்}} ஐத் திற (பயன்பாட்டுப் பட்டியில் உள்ள கியர், அல்லது {{key:Mod+,}}) பிறகு {{ui:PartCraft}} தாவலுக்குச் செல்லவும்.
2. {{ui:உதவியாளர்கள்}} பிரிவின் கீழ், **AI உதவியாளர்களும் ஸ்கிரிப்ட்களும் PartCraft ஐப் பயன்படுத்தட்டும்** என்பதைத் தேர்வுசெய்யவும். நீங்கள் அவ்வாறு செய்யும் வரை இது அணைந்திருக்கும்.
3. அது என்ன செய்யலாம் என்பதைத் தேர்ந்தெடுக்கவும். **வாசி** தொடக்கத்திலேயே தேர்வுசெய்யப்பட்டிருக்கும்; மற்றவற்றை உங்களுக்குத் தேவைப்படும்போது மட்டும் தேர்வுசெய்யவும்.
4. அது ஒரு கோப்புறைக்கு ஏற்றுமதி செய்து சேமிக்க, **அது பயன்படுத்தக்கூடிய கோப்புறைகள்** என்பதன் கீழ் {{ui:கோப்புறையைச் சேர்…}} என்பதைத் தேர்ந்தெடுத்து, Studio உரையாடல் பெட்டியில் அந்தக் கோப்புறையைத் தேர்ந்தெடுக்கவும்.

உதவியாளர்கள் உங்கள் கணினியில் உள்ள **CadCraft Studio** வழியாக இணைகின்றன: Studio முகவரியையும், உதவியாளரில் ஒட்ட வேண்டிய டோக்கனையும் காட்டும். உலாவித் தாவல் உதவியாளருக்காக இணைப்பைத் திறக்க முடியாது.

## உதவியாளர் என்ன கேட்கலாம்

| கருவி | அனுமதி | அது என்ன செய்கிறது |
|---|---|---|
| `part_describe`, `features_list` | வாசி | அம்சங்கள் வரிசையாக, எவை கட்டப்பட்டன, எவை தோல்வியுற்றன என்பதுடன்; பொருள்; திடப்பொருளின் கன அளவு மற்றும் அளவு |
| `params_list` | வாசி | அளபுருக்களும், ஒரு சமன்பாடு இயக்கக்கூடிய ஒவ்வொரு எண்ணும், அவற்றின் மதிப்புகளுடன் |
| `mass_properties` | வாசி | கன அளவு, பரப்பளவு, நிறை மையம், அதைச் சுற்றியுள்ள நிலைமத்திறன்; பாகத்துக்குப் பொருள் இருக்கும்போது நிறை |
| `param_set` | திருத்து | ஓர் அளபுருவையோ அம்சத்தின் எண்ணையோ அமைத்து மீண்டும் கட்டும். நீங்கள் செயல்தவிர்க்கக்கூடிய ஒரு படி |
| `script_run` | திருத்து | CraftScript, Lua அல்லது Python ஸ்கிரிப்டை {{ui:ஸ்கிரிப்ட்}} பணியிடம் இயக்குவது போல் இயக்கும்: தனிமைப்படுத்தப்பட்டது, கோப்புகளும் பிணையமும் இல்லை. பாகம் மாறாது |
| `part_export` | ஏற்றுமதி | STL, 3MF, STEP அல்லது OpenUSD (.usdz, .usda, .usdc), {{ui:கோப்பு}} › {{ui:ஏற்றுமதி}} எழுதுவது போல் |
| `link_push` | திருத்து | வேறொரு நிரலிலிருந்து இணைக்கப்பட்ட மாதிரியைப் புதுப்பிக்கும் ([.3dm மாதிரியை நேரலையில் வைத்திரு](topic:live-3dm-link)) |
| `link_status` | வாசி | இணைக்கப்பட்ட மாதிரி இன்னும் இருக்கிறதா என்றும், அது கடைசியாக எப்போது புதுப்பிக்கப்பட்டது என்றும் சொல்லும் |
| `part_save` | சேமி | PartCraft இன் சொந்த {{ui:சேமி}} |
| `illustrate_export` | ஏற்றுமதி | {{ui:விளக்கப்படம்}} பணியிடத்திலிருந்து ஒரு கையேடு: அதன் காட்சிகளின் PDF அல்லது SVG கோட்டுப் படமாக, அல்லது ஊடாடும் 3D கோப்பாக, அல்லது அதன் வழிமுறைகளை PDF அல்லது இணையப் பக்கமாக; பணியிடத்தின் {{ui:ஏற்றுமதி}} மற்றும் {{ui:வழிமுறைகள்}} பட்டிகள் எழுதுவது போல் ([கையேடுகள்](topic:illustrate)) |

:::note
இந்தப் பதிப்பு மெஷ் கர்னலைப் பயன்படுத்துகிறது: கன அளவுகள் முக்கோணங்களிலிருந்து வருகின்றன (உண்மையான வளைவுத் திடப்பொருளை விட சற்றுக் குறைவாக), மேலும் STEP முக்கோணங்களால் ஆன வடிவில், துல்லியமான மேற்பரப்புகளுக்குப் பதிலாக முக்கோணங்களுடன் எழுதப்படுகிறது.
:::

## நீங்களே பொறுப்பு

- **ஒவ்வொரு மாற்றமும் ஒரு செயல்தவிர் படி**; அது உதவியாளருக்கு என்று குறிக்கப்படும், உதாரணமாக "Assistant: set l = 45". அதைத் திரும்பப் பெற {{key:Mod+Z}} அழுத்தவும்.
- **அது இணைக்கப்பட்டிருப்பது உங்களுக்குத் தெரியும்.** இணைக்கப்பட்டிருக்கும்போது பயன்பாட்டுப் பட்டியில் உள்ள ஒரு பொத்தான் உதவியாளரின் பெயரைக் காட்டும். அது என்ன செய்யலாம் என்று பார்க்க அதைக் கிளிக் செய்யவும், அல்லது **இணைப்பைத் துண்டி** என்பதற்காகவும்.
- **செயல்பாடு.** {{ui:அமைப்புகள்}} › {{ui:PartCraft}} › {{ui:உதவியாளர்கள்}} › {{ui:செயல்பாடு}} ஒவ்வொரு அழைப்பையும் பட்டியலிடும்; {{ui:பதிவைச் சேமி}} அதன் நகலை வைத்திருக்கும்.
- **கோப்புறைகள்.** நீங்கள் சேர்த்த கோப்புறைகளில் மட்டுமே அது கோப்புகளைப் படிக்கவும் எழுதவும் செய்யும்; {{ui:நீக்கு}} ஒரு கோப்புறையை உடனடியாகத் திரும்பப் பெறும்.

## PartCraft ஐத் திறக்காமல்

உதவியாளர்களுக்கான CadCraft கோப்பு சேவையகம் (`npx @getcadcraft/mcp`) மற்றும் `cadcraft` கட்டளை வரி, சாளரம் இல்லாமல், PartCraft இன் சொந்தக் குறியீடு மற்றும் மெஷ் கர்னலுடன் `.partcraft.json` பாகங்களைத் திறக்கின்றன: அதே வாசிப்புக் கருவிகள், அளபுருக்களை அமைத்தல், CraftScript ஸ்கிரிப்ட்கள், ஏற்றுமதிகள் (OpenUSD உட்பட) மற்றும் சேமித்தல். `cadcraft convert bracket.partcraft.json bracket.stl` ஒரு பாகத்தைக் கட்டி கட்டளை வரியிலிருந்து எழுதுகிறது. கையேடுகளும் (`.partcraft-manual.json`) அங்கேயும் ஏற்றுமதியாகும்: `illustrate_export`, அல்லது `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (வழிமுறைகளுக்கு `--instructions` சேர்க்கவும்).

## ஏதாவது வேலை செய்யவில்லை என்றால்

- **"needs the edit permission":** {{ui:உதவியாளர்கள்}} பிரிவின் கீழ் **திருத்து** என்பதைத் தேர்வுசெய்து, பிறகு மீண்டும் கேட்கவும்.
- **"driven by the equation":** அந்த எண் ஓர் அளபுருவைப் பின்தொடர்கிறது; அதற்குப் பதிலாக அளபுருவை அமைக்குமாறு உதவியாளரிடம் கேட்கவும்.
- **அதன் மாற்றம் தவறாக இருந்தது:** {{key:Mod+Z}} அழுத்தவும்.
