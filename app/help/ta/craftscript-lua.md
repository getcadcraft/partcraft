Lua என்பது [ஸ்கிரிப்ட் பணியிடத்தின்](topic:craftscript) இரண்டாவது மொழி. பெட்டித் தொகுப்பின் மேலே உள்ள மொழிப் பெட்டியில் **Lua** ஐத் தேர்ந்தெடுக்கவும் (`.lua` கோப்பு தானாக Lua வில் திறக்கும்). Lua மற்றும் CraftScript ஒரே மாறிகளையும் ஒரே உள்ளமைந்த செயல்பாடுகளையும் பகிர்கின்றன; ஆகவே ஒரு Lua ஸ்கிரிப்ட் ஒரு CraftScript ஸ்கிரிப்ட் உருவாக்கியதைப் பயன்படுத்தலாம், மறுதலையும் உண்டு.

## அடிப்படைகள்

```
-- ஒவ்வொரு உள்ளமைந்த செயல்பாடும் cs அட்டவணையில் உள்ளது
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-அடிப்படை, CraftScript போல
print(K(1, 1), #K)             -- ஓர் உறுப்பு; உறுப்புகளின் எண்ணிக்கை

-- பணியிடம்: ஒவ்வொரு ஸ்கிரிப்டும் காணும் அதே மாறிகள்
ws.total = K(1, 1) * 2
print(ws.total)

-- ஒரே செயல்பாட்டிலிருந்து பல முடிவுகள்
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<பெயர்>(…)` எந்த உள்ளமைந்த செயல்பாட்டையும் அழைத்து அதன் முதல் முடிவைத் தரும்; `cs.call(பெயர், n, …)` `n` முடிவுகளைத் தரும்.
- `cs.tensor({1, 2, 3})` ஒரு வரிசையையும், `cs.tensor({{1, 2}, {3, 4}})` ஓர் அணியையும் உருவாக்கும்.
- அணிகள், சிதறல் அணிகள், வலைகளும் புலங்களும் முறைகளுடன் கூடிய மதிப்புகள்: `t(i, j)` அல்லது `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (இடமாற்று), `t:totable()`. `+ - * / ^` CraftScript இல் அவை என்ன பொருள் தருமோ அதையே தரும் (`*` அணிப் பெருக்கம்); `t:times(u)` ஒவ்வோர் உறுப்பாகப் பெருக்கும்.
- 1×1 அணியாக உள்ள ஓர் எண் சாதாரண Lua எண்ணாக வரும்.
- `ws.name` பகிரப்பட்ட பணியிடத்தைப் படிக்கும், எழுதும். உங்கள் ஸ்கிரிப்ட் விட்டுச்செல்லும் உலகளாவிய மாறிகளும் அது முடியும்போது அங்கேயே சேரும்.
- `print(…)` கன்சோலில் எழுதும்; `cs.show(f)`, `cs.plot(y)` மற்றும் பிற காட்சிச் செயல்பாடுகள் CraftScript இல் போலவே வேலை செய்யும்.

## பகுப்பாய்வு நூலகத்தை அழைத்தல்

பகுப்பாய்வு நூலகத்தின் (நூலகத் தாவல்) செயல்பாடுகளும், உங்கள் பாகத்தின் சொந்த ஸ்கிரிப்ட்கள் வரையறுக்கும் CraftScript செயல்பாடுகளும் `cs` வழியாகவே அடையப்படுகின்றன:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- இரண்டு வெளியீடுகள்
```

அவை ஸ்கிரிப்ட் தொடங்குவதற்கு முன்பே கண்டறியப்படும்; ஆகவே பெயரை ஸ்கிரிப்டில் எழுதுங்கள்: `cs.static_tet(` அல்லது `cs.call('static_tet', …)`. ஸ்கிரிப்ட் இயங்கும்போது உருவாக்கப்படும் பெயர் உள்ளமைந்த செயல்பாடுகளை மட்டுமே அடையும். `cs.struct({ … })` மூலம் கட்டப்பட்ட struct ஓர் CraftScript struct; அவற்றின் Lua பட்டியல் (`{ cs.struct(…), … }`) ஒரு cell, நூலகத்தின் அமைப்புகள் எதிர்பார்ப்பது அதுவே. ஒரு நூலகச் செயல்பாட்டுக்குள் ஏதேனும் தவறினால், செய்தி அந்தச் செயல்பாட்டின் பெயரையும் அதன் வரியையும் குறிக்கும், உங்கள் அழைப்பு வரியையும் சுட்டும்.

## முடக்கப்பட்டவை

ஸ்கிரிப்டுகள் கோப்புகள், பிணையம், பக்கம் ஆகியவற்றை அடைய முடியாது: `io`, `os` (கடிகாரம் தவிர்த்து), `require`, `dofile`, `loadfile` மற்றும் `debug` அகற்றப்பட்டுள்ளன. தரவைக் கொண்டுவர ஸ்கிரிப்ட் பணியிடத்தின் {{ui:திற}} மற்றும் மாறிகளைப் பயன்படுத்துங்கள். படிநிலை வரம்பும் நிறுத்தமும் CraftScript இல் போலவே வேலை செய்யும்.
