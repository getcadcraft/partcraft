## Ano ang gagawin mo

Gumuhit ng arko sa sketch gamit ang paraang tugma sa alam mo: tatlong punto sa arko, ang center nito, ang radius nito, ang anggulong sinasaklaw nito o ang direksyong pinanggagalingan nito. Maaaring i-click o i-type ang mga halaga.

## Mga hakbang

1. Buksan ang sketch (tingnan ang [Mga batayan ng sketching](topic:sketch-basics)).
2. Sa sketch toolbar, buksan ang listahan sa tabi ng {{ui:Arc}} at pumili ng paraan, halimbawa {{ui:Arc: Start, End, Radius}}. Ang mga paraan ay 3-Point; Start, Center, End; Start, Center, Angle; Start, Center, Length; Start, End, Angle; Start, End, Direction; Start, End, Radius; Center, Start, End; Center, Start, Angle; Center, Start, Length; at Continue.
3. Sundin ang status bar, na nagpapangalan sa paraan at nagsasabi kung ano ang ibibigay sa susunod: i-click ang start point, ang center point, ang pangalawang punto sa arko o ang end point.
4. Kung sinasabi ng prompt ang "or type", i-type ang numero at pindutin ang {{key:Enter}}: ang included angle sa degree (negatibo ang clockwise), ang haba ng chord, ang direksyon ng start tangent sa degree, o ang radius (negatibo ang mas mahabang daan paikot).
5. Iginuguhit na ang arko. Sisimulan ng {{ui:Arc: Continue}} ang susunod na arko mula sa dulo ng huling linya o arko.

## Mga tala

- Pinapanatili ng mga arko ang kanilang center, start at end, kaya gumagana pa rin ang mga relation at dimension sa mga ito gaya ng dati.
- Tinatanggihan ng status bar ang imposibleng input at sinasabi kung bakit, halimbawa tatlong punto sa iisang linya, o radius na masyadong maliit para maabot sa pagitan ng dalawang end point.
- Kapag walang iginuhit, sasabihin ng {{ui:Arc: Continue}}: "Walang mapagpapatuluyan: gumuhit muna ng linya o arko."
