Buksan ang seksyong {{ui:Mga instruction}} at i-click ang {{ui:Simulan ang instructions mula sa mga view}}: ang bawat view ay nagiging isang hakbang, ayon sa pagkakasunod-sunod ng mga view.

Para sa bawat hakbang, piliin ang {{ui:View}}, isang {{ui:Title}}, ang {{ui:Larawan}} (kung paano itsura ng view: line art, flat na kulay o shaded), kung ilista ang {{ui:Ilista ang mga piyesang ipinapakita ng hakbang na ito}} o hindi, at mag-type ng {{ui:Mga note}}, {{ui:Mga babala}} at {{ui:Mga tool}} (isa kada linya). Nagagalaw pataas at pababa ang mga hakbang; nagdadagdag ng isa mula sa kahit anong view ang {{ui:Idagdag ang hakbang}}.

{{ui:Cover page}} at {{ui:Parts-list page sa dulo}} ay naka-on bilang default. Isinusulat ng {{ui:I-save bilang PDF}} ang mga page; isinusulat ng {{ui:I-save bilang HTML}} ang isang page na nababasa sa screen at nagpi-print ng isang hakbang bawat page.

## Mga template

Itinatakda ng {{ui:Template}} ang papel, landscape o portrait, isang logo (PNG o JPEG), ang kulay ng heading at isang linya ng footer. Isinusulat ng {{ui:I-save ang template}} ito bilang `.partcraft-template.json` na file para magamit sa ibang manual gamit ang {{ui:Gumamit ng template…}}.
