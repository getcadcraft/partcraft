I-click ang {{ui:I-update mula sa design…}} sa ilalim ng pangalan ng manual, tapos piliin ang bukas na part o assembly, o isang file (ang parehong uri kung saan ginawa ang manual).

Inilalista ng report ang mga magbabago:

- **Nagalaw** na mga piyesa, at kung gaano kalayo.
- **Nagbago ang hugis**.
- **Bagong** mga piyesa: ipinapakita sa bawat view, at wala pang balloon number.
- **Inalis** na mga piyesa, kasama ang mga annotation at animation key na tumuturo sa kanila: aalisin din ang mga ito, at pinangalanan dito para walang mawala nang hindi namamalayan.
- **Pinalitan ng pangalan** na mga piyesa.

I-click ang {{ui:I-update}} para ilapat ito. Itinutugma ang mga piyesa sa sarili nilang id sa design, kaya nananatili sa kanila ang mga view, annotation, balloon number at key. Isang hakbang ang Update: ibinabalik ng {{ui:I-undo}} ang manual sa dati nitong kalagayan.
