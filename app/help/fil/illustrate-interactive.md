{{ui:Export}}, tapos {{ui:As}} {{ui:Interactive 3D file (HTML, gumagana offline)}}, mag-save ng isang `.html` file. Ipadala sa email, ilagay sa USB stick o shared folder: bubukas ito sa anumang browser na may WebGL 2, sa computer, tablet o phone.

Sa loob ng file:

- I-drag para paikutin ang model, right-drag o {{key:Shift}}+drag para mag-pan, wheel o pinch para mag-zoom.
- I-click ang isang view sa listahan: gagalaw ang camera doon, at kukunin ng mga piyesa ang mga posisyon, itsura, cut at magnifier ng view na iyon.
- I-click ang isang row ng parts list para i-light up ang mga piyesa nito; i-click ang isang piyesa para i-light up ang row nito.
- Kapag may animation ang manual, may bar sa ilalim ng model na nagpe-play, nagpa-pause at nag-scrub dito.

Dala ng file ang lahat ng kailangan nito (ang model, ang viewer at three.js, sa ilalim ng MIT licence nito) at hinaharangan ang bawat request: hindi ito makakaabot sa internet, walang account at walang tracking.

Hindi inaalok ang interactive 3D sa loob ng PDF: hindi ito maipakita ng mga browser at ng karamihan sa PDF reader, at ang reader na kayang magpakita nito ay naka-off bilang default. Ang HTML file ang interactive na sagot.
