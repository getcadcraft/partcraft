การวิเคราะห์ในพื้นที่ทำงานสคริปต์คือสคริปต์สั้น ๆ ไม่กี่ตัวที่ส่งตัวแปรให้กันและกัน เริ่มจากฟังก์ชันของ[ไลบรารี](topic:craftscript-library) ที่ใกล้เคียงกับสิ่งที่คุณต้องการ แล้วทำสำเนาและแก้ไข หรือสร้างขึ้นเองตามด้านล่าง

## 1. เมช

```
model = part();                  % ชิ้นส่วนที่กำลังสร้างแบบจำลอง เป็นโมเดล
m = tetmesh(model, 4);           % เตตระฮีดรอนกว้างราว 4 mm
show(m)
```

ตรวจสอบเมชในมุมมองก่อนดำเนินการต่อ: {{key:F}} ปรับให้พอดีกับมุมมอง และ{{ui:eye}}ใน **ที่แสดง** จะซ่อนชิ้นส่วน

## 2. ประกอบและแก้สมการ

เขียนลูปขององค์ประกอบในสคริปต์ (อ่านคล้ายตำรา) และปล่อยส่วนหนักให้ฟังก์ชันในตัว ได้แก่ เมทริกซ์องค์ประกอบ การประกอบเมทริกซ์เบาบางจากสามค่า (triplets) และตัวแก้สมการคอนจูเกตกราเดียนต์พร้อมตัวปรับสภาพ ฟังก์ชันของไลบรารี เช่น `static_tet` (เมื่อไลบรารีมีแล้ว) เป็นตัวอย่างที่สมบูรณ์ให้คัดลอกมาใช้

## 3. แสดงผลลัพธ์

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % หนึ่งค่าต่อโนด
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- ช่วงของคำอธิบายสี (legend) พิมพ์เองได้ หรือตั้งกลับเป็น {{ui:Auto}}
- คลิกเมชเพื่ออ่านค่าที่โนด
- กราฟที่คงค่า `'id'` เดิมจะถูกอัปเดตในที่เดิม ดังนั้นให้ใส่ print และ plot ไว้ในลูปเพื่อดูการลู่เข้า

## 4. ตรวจสอบ

เทียบกับสิ่งที่คุณรู้: การแอ่นที่ปลายของคานยื่นเทียบกับ PL³/3EI แผ่นที่มีรูเทียบกับตัวประกอบความเข้มข้นของความเค้น แรงปฏิกิริยาเทียบกับแรงที่กระทำ เขียนการตรวจสอบเป็นสคริปต์ของมันเอง เพื่อให้รันใหม่ได้ทุกครั้งหลังการเปลี่ยนแปลง:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. เก็บไว้

- แต่ละขั้นตอนเป็นแท็บสคริปต์ของตัวเองได้ เพราะใช้ตัวแปรร่วมกัน จึงรันทีละอันตามลำดับ
- สคริปต์ถูกบันทึกในชิ้นส่วน ทำเครื่องหมาย **บันทึกตัวแปรพร้อมชิ้นส่วน** ในแท็บ **ตัวแปร** เพื่อเก็บผลลัพธ์ไว้ด้วย (สูงสุด 32 MB)
