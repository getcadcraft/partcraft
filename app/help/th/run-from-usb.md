เครื่องมือวิศวกรรม (ตัวสร้าง ไลบรารีวิศวกรรม การตรวจสอบ และไฟล์ข้อมูล) **ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ** และ**ไม่ต้องติดตั้ง** เครื่องมือเหล่านี้เขียนเฉพาะสิ่งที่ระบุไว้ที่นี่เท่านั้น และไม่เขียนสิ่งอื่น

| สิ่งที่บันทึก | ตำแหน่งที่เก็บ |
|---|---|
| ชิ้นส่วนของคุณ พร้อมบอดี้ที่สร้างขึ้น ชีตข้อมูล และการตรวจสอบ | ไฟล์ชิ้นส่วนที่คุณบันทึก (`.partcraft.json`) ในตำแหน่งที่คุณบันทึกไว้ |
| ตัวสร้างที่คุณเปิดจากไฟล์ | ที่เก็บของแอปเอง: local storage ของเบราว์เซอร์ในหน้าเว็บ และโฟลเดอร์ `data` ข้างโปรแกรมใน Studio แบบพกพา สูงสุด 20 รายการ |
| การตั้งค่า (ขนาด voxel ที่คุณตั้ง จำนวนเธรดของตัวแก้สมการ และเลย์เอาต์) | ที่เก็บของแอปเดียวกัน |
| ชีตข้อมูล ฟิลด์ และเมช | เฉพาะตำแหน่งที่คุณบันทึก: การดาวน์โหลดจะไปยังที่ที่คุณเลือก |

เครื่องมือเหล่านี้**ไม่มีการเรียกเครือข่ายของตัวเอง**: ตัวสร้างที่มาพร้อมแอปเป็นไฟล์ในโฟลเดอร์ของแอป ไลบรารีและการตรวจสอบทำงานบนคอมพิวเตอร์ของคุณในเวิร์กเกอร์ที่เข้าถึงเครือข่ายไม่ได้ และข้อมูลทางวิศวกรรม (คุณสมบัติของน้ำและอากาศ วัสดุ) อยู่ในตัวแอป ตัวสร้างที่คุณเปิดจากไฟล์จะถูกอ่านบนคอมพิวเตอร์ของคุณและไม่ถูกส่งไปที่ใด

## ไฟล์ zip แบบพกพาของ Windows และ Linux

Studio แบบพกพาสำหรับ Windows เก็บการตั้งค่า แคช และส่วนเสริมไว้ในโฟลเดอร์ `data` ข้างโปรแกรม AppImage ของ Linux จะเก็บไว้ข้างตัวเองเมื่อมีไฟล์ชื่อ `portable` วางอยู่ข้างกัน หากไม่มีไฟล์นั้นจะใช้โฟลเดอร์โฮมของคุณ ไม่มีรูปแบบ Mac แบบพกพา เพราะระบบจะไม่ให้แอปที่ดาวน์โหลดมาเขียนไฟล์ไว้ข้างตัวเอง บันทึกแบบพกพาของเชลล์เอง (ช่วยเหลือ `Studio`) ระบุรายการที่โปรแกรมเขียน

## การเข้าถึงโฮสต์

ที่นี่ไม่มีการขอสิทธิ์เข้าถึงโฮสต์ เครื่องพิมพ์ เครื่องจักรที่เชื่อมต่อแบบซีเรียล และอุปกรณ์ USB เป็นเรื่องแยกต่างหาก อุปกรณ์เหล่านี้จะขอสิทธิ์เมื่อคำสั่งงานต้องใช้ โดยขอครั้งเดียวต่ออุปกรณ์หนึ่งเครื่อง และไม่มีตัวสร้างหรือการตรวจสอบใดแตะต้องอุปกรณ์เหล่านี้
