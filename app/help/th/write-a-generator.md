ตัวสร้างคือสคริปต์ทั่วไป ([CraftScript](topic:craftscript), Lua หรือ Python) ที่มีบรรทัดคอมเมนต์ไม่กี่บรรทัดอยู่ด้านบน PartCraft อ่านคอมเมนต์และสร้างฟอร์ม ส่วนสคริปต์ของคุณอ่านอินพุตเป็นตัวแปรที่ถูกตั้งค่าไว้แล้ว

## ส่วนหัว

ใส่สิ่งเหล่านี้ในบรรทัดคอมเมนต์ (`%` ใน CraftScript, `--` ใน Lua, `#` ใน Python):

```
% @generator เครื่องแลกเปลี่ยนความร้อน
% @input mdot: kg/s = 0.2 [0.01 .. 10] "อัตราการไหลมวล"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "พื้นผิว"
% @input solid: = true
% @input note: = "text"
```

อินพุตคือ `name: unit = default` จากนั้นจะมีช่วง `[min .. max]` ได้ตามต้องการ (ตัวเลขจะอยู่ภายในช่วงนี้) รายการตัวเลือก `{a, b, c}` และป้ายกำกับในเครื่องหมายคำพูด หน่วยเป็นเพียงป้ายกำกับสำหรับฟอร์มเท่านั้น: **ค่าจะมาถึงในหน่วยนั้น** ดังนั้นสคริปต์ที่ต้องการ SI ต้องแปลงค่า และ `to_si(value, 'kg/s', 'kg/s')` ยังช่วยตรวจว่าหน่วยมีความหมายตามที่คุณคิดหรือไม่ ชื่อประกอบด้วยตัวอักษร ตัวเลข และขีดล่าง โดย `body`, `sheet` และ `problems` ถูกใช้แล้ว

## สิ่งที่สคริปต์ทิ้งไว้

| ตัวแปร | คืออะไร |
|---|---|
| `body` | **จำเป็น** เมชพื้นผิว มักได้จาก `[body, info] = to_body(field, h)` ระบบจะซ่อมและตรวจสอบเมื่อการรันสิ้นสุด |
| `sheet` | ไม่บังคับ สตรักต์ที่แต่ละฟิลด์เป็นตัวเลขหรือข้อความ หรือเป็นสตรักต์ที่มี `value`, `unit`, `ref` และ `note` จะกลายเป็นแผ่นข้อมูล |
| `problems` | ไม่บังคับ เซลล์ `problems` จาก `mfg_check(field, 'sls', struct(), h)` หรือรายการของคุณเอง รายการเหล่านี้จะถูกส่งไปยังการตรวจสอบและรายการปัญหา |

## ตัวอย่างสมบูรณ์แบบย่อ

```
% ลูกบาศก์กลวงที่มีผนัง.
% @generator ลูกบาศก์กลวง
% @input side: mm = 12 [4 .. 40] "ด้าน"
% @input wall: mm = 1.5 [0.5 .. 5] "ผนัง"
% @input h: mm = 0.5 [0.25 .. 2] "ขนาดวอกเซล"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'ของเมช');
```

ได้กล่องปิด และการตรวจสอบรายงานว่าช่องภายในที่ปิดสนิทเป็นข้อผิดพลาดสำหรับกระบวนการแบบผง ตั้งขนาดวอกเซล `h` ให้มีค่าไม่เกินหนึ่งในสามของผนังที่บางที่สุดที่คุณต้องการ: หากต่ำกว่าประมาณสามวอกเซล ผนังจะไม่น่าเชื่อถือ

## ฟิลด์

ฟิลด์ที่ใช้ได้: `field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ของแข็งจากการหมุนโปรไฟล์), `tpms` (พื้นผิว gyroid, Schwarz P และ diamond พร้อมขนาดเซลล์และผนังที่เปลี่ยนไปทั่วชิ้นส่วนได้), `lattice` และ `lattice_beams`, `along` (ช่องกลมตามเส้นทาง), บูลีน `field_union`, `field_intersect`, `field_subtract`, การผสมแบบเรียบ `field_blend`, และ `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` ให้ระยะทางแบบมีเครื่องหมายที่จุดต่าง ๆ (ค่าลบคือด้านใน) `field_voxel` ให้วอกเซลสำหรับตัวแก้สมการ [ฟิลด์](topic:fields) อธิบายว่าฟิลด์คืออะไร

ข้อจำกัดที่ควรทราบ: ผนังแผ่นที่หนากว่าประมาณหนึ่งในสี่ของเซลล์จะปิดช่องทาง; ฟีเจอร์ที่บางกว่าประมาณสามวอกเซลอาจบีบตัว; `along` เชื่อมกรวยกลม ดังนั้นรัศมีที่เปลี่ยนเร็วจะทิ้งส่วนโป่งไว้ (ใช้ `field_revolve` สำหรับโปรไฟล์)

## เปิดสคริปต์ของคุณเป็นตัวสร้าง

ในพื้นที่ทำงาน {{ui:วิศวกรรม}} คลิก {{ui:เปิด}} แล้วเลือกไฟล์ สคริปต์ที่ไม่มีบรรทัด `@generator` หรือ `@input` จะถูกปฏิเสธ เพราะไม่มีอะไรให้ตั้งค่า ตัวสร้างจะถูกเก็บไว้ในเบราว์เซอร์นี้ (สูงสุด 20 รายการ) และ {{ui:นำออก}} จะลบออก บอดี้ที่เริ่มจากตัวสร้างจะมีสำเนาของสคริปต์ติดมาด้วย ดังนั้นชิ้นส่วนจะไม่ขึ้นอยู่กับสคริปต์นั้น

ไฟล์เดียวอาจเก็บตัวสร้างหลายตัวได้ด้วย ในรูปของชุด JSON: `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`
