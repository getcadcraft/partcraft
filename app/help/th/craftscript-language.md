CraftScript เป็นภาษาเมทริกซ์ที่เขียนให้อ่านคล้าย MATLAB จึงทำให้โค้ดเชิงตัวเลขแบบดั้งเดิมส่วนใหญ่ (เช่น โค้ดการหาค่าเหมาะสมของโทโพโลยี 88 บรรทัด) ทำงานได้โดยแก้ไขเพียงเล็กน้อย ภาษานี้ทำงานใน [พื้นที่ทำงานสคริปต์](topic:craftscript) และจากบรรทัดคำสั่ง

## ค่า

| ชนิด | ตัวอย่าง | หมายเหตุ |
|---|---|---|
| จำนวน, อาร์เรย์ | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ทุกจำนวนเป็นอาร์เรย์ (ขนาด 1×1) อาร์เรย์เก็บตามคอลัมน์ รองรับได้สูงสุด 8 มิติ |
| ตรรกะ | `A > 2`, `true` | อาร์เรย์ของค่าจริง/เท็จ ใช้เป็นดัชนีได้ |
| ข้อความ | `'beam'`, `"beam"` | |
| เมทริกซ์เบาบาง | `sparse(i, j, v, n, n)` | สำหรับเมทริกซ์ความแข็ง |
| เมช ฟิลด์ โมเดล | `hexGrid(…)`, `part()`, `load('part.stl')` | สิ่งที่ `show` วาด |
| สตรักต์ | `s.E = 210e3` | ฟิลด์ที่มีชื่อ |
| เซลล์ | `c = {1, 'two', [3 4]}` | รายการของค่าใดก็ได้ |
| ฟังก์ชันอ้างอิง | `f = @(x) x.^2` | |

## อาร์เรย์และการจัดดัชนี

- ช่วง: `1:5`, `0:0.1:1` `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`
- การจัดดัชนีเริ่มที่ 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (ทั้งคอลัมน์), `A(:)` (ทุกค่าเป็นคอลัมน์เดียว), `v(v > 0)` (การจัดดัชนีแบบตรรกะ)
- การกำหนดค่าเกินจุดสิ้นสุดจะขยายอาร์เรย์ เหมือนใน MATLAB: `v(10) = 1`

## ตัวดำเนินการ

- `+ - * / \ ^` เป็นการดำเนินการเมทริกซ์ (`A \ b` แก้สมการ) ส่วน `.* ./ .^` ทำทีละองค์ประกอบ `'` คือการทรานสโพส
- การเปรียบเทียบ `== ~= < <= > >=` ตรรกะ `& | ~` (ทีละองค์ประกอบ) และ `&& ||` (ลัดวงจร)

## การควบคุมการทำงานและฟังก์ชัน

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ฟังก์ชันวางไว้ในสคริปต์หลังคำสั่ง หรือในแท็บสคริปต์ของตัวเองที่ตั้งชื่อตามฟังก์ชัน:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ชื่อจะถูกค้นหาตามลำดับนี้: ตัวแปร, สคริปต์ในชิ้นส่วนนี้ที่มีชื่อนั้น, ฟังก์ชันในไลบรารี, ฟังก์ชันในตัว

## การแสดงผลคำสั่ง คอมเมนต์ และเอาต์พุต

- คำสั่งที่ไม่มี `;` จะพิมพ์ค่าของมัน; `;` ทำให้เงียบ
- `%` เริ่มคอมเมนต์; `%{` และ `%}` ที่อยู่บรรทัดของตัวเอง จะคอมเมนต์บรรทัดที่อยู่ระหว่างกัน
- `disp(x)`, `fprintf('%g\n', x)` และ `display(x)` พิมพ์ลงคอนโซล

## ข้อผิดพลาดและขีดจำกัด

- ข้อผิดพลาดจะบอกว่าเกิดอะไรขึ้นด้วยคำอธิบายธรรมดา และระบุบรรทัด (และลำดับการเรียกฟังก์ชัน)
- การรันแต่ละครั้งมีงบขั้นตอน (ตั้งค่าได้ที่ตัวเลือกการรันในพาเนล) ลูปที่ไม่สิ้นสุดจะหยุดพร้อมข้อความ หรือกด {{ui:Stop}}
- อาร์เรย์แต่ละอันเก็บค่าได้สูงสุด 134 ล้านค่า

## ต่างจาก MATLAB

- คำสั่งพล็อตใส่ตัวเลือกไว้ในการเรียก: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')` ส่วน `figure`, `hold`, `axis`, `title(…)` และคำสั่งที่คล้ายกันจะรับไว้แต่ไม่ทำอะไร
- `input` และ `keyboard` ไม่รองรับ: สคริปต์หยุดเพื่อถามคำถามไม่ได้
- ไม่มีชุดเครื่องมือ (toolbox) มีเพียง [ไลบรารีการวิเคราะห์](topic:craftscript-library) และฟังก์ชันในตัว
