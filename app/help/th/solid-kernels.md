เคอร์เนลเรขาคณิตคือเอนจินที่เปลี่ยนประวัติของคุณเป็นทรงตัน PartCraft รุ่นนี้มีหนึ่งตัว: **เคอร์เนลเมช** (manifold-3d) ทำงานบนคอมพิวเตอร์ของคุณเป็นโปรแกรม WebAssembly ขนาดเล็ก และพร้อมใช้หลังแอปเปิดไม่นาน ไม่มีสิ่งใดเกี่ยวกับชิ้นส่วนของคุณถูกส่งไปที่ใด

| | เคอร์เนลเมช |
|---|---|
| รูปทรงกลม | หน้าย่อยเรียบ **เส้นโค้ง** ในพาเนลชิ้นส่วนกำหนดความละเอียด |
| ปริมาตรและพื้นที่ | ของทรงตันที่เป็นหน้าย่อย ต่ำกว่าเล็กน้อยบนชิ้นส่วนกลม |
| สเกตช์ เอ็กซ์ทรูด ตัด หมุนรอบแกน รู แพตเทิร์น สะท้อน ระนาบอ้างอิง | ได้ |
| ฟิลเลตและชัมเฟอร์ | บนขอบตรงระหว่างหน้าเรียบ ส่วนมนที่มาบรรจบกันถูกตัดเฉียง |
| เชลล์และดราฟต์ | เชลล์เปิดหน้าเรียบ (ความหนาผนังที่แน่นอน) ดราฟต์เอียงหน้าเรียบ |
| การส่งออก | STL, 3MF, STEP (หน้าเรียบ), PDF ของแบบ และ DXF |
| มุมมองของแบบ | วาดจากหน้าย่อย รวมถึงมุมมองภาพตัด |
| หน้าและขอบ | ตั้งชื่อและรู้ชนิด (เรียบ ทรงกระบอก กรวย ทรงกลม ทอรัส เส้นตรง วงกลม) จากสเกตช์: พื้นที่ทำงานการจำลอง เจเนอเรทีฟ และการผลิต วัด การเลือก และตารางรู ใช้สิ่งเหล่านี้ |

ชิปใกล้ปลายขวาของแถบสถานะขึ้นว่า **เคอร์เนลเมช** ขณะที่มันสร้างชิ้นส่วนของคุณ

## สิ่งที่รอเคอร์เนลแม่นยำ

เคอร์เนลแม่นยำ (B-rep) เก็บวงกลม ทรงกระบอก และกรวยที่แท้จริง และฟิลเลตเรียบบนขอบใดก็ได้ สวีป ลอฟต์ พื้นผิว แผ่นโลหะ ซี่ หลายบอดี้ การนำเข้า STEP และการส่งออก STEP ที่แม่นยำ ถูกสร้างบนมัน รุ่นทดลองก่อนหน้าของ PartCraft ใช้ OpenCascade สำหรับสิ่งนั้น ใบอนุญาตของมัน (LGPL) ไม่เข้ากับรุ่นนี้ ซึ่งทุกแอปเป็น Apache-2.0 และใช้เฉพาะไลบรารีที่มีใบอนุญาตแบบอนุญาต จึงไม่รวมไว้ ไม่มีสิ่งใดที่นี่มีกำหนดวัน

จนกว่าจะถึงเวลานั้น ฟีเจอร์เหล่านั้นขึ้นว่า **ยังไม่ได้สร้าง** เมื่อคุณเลือก: แถบสถานะบอกเหตุผล และคำแนะนำเครื่องมือของปุ่มลงท้ายด้วย "ยังไม่ได้สร้าง (ต้องใช้เคอร์เนลแม่นยำ)" [สิ่งที่ยังไม่ได้สร้าง](topic:not-built-yet) ระบุแต่ละอันพร้อมสิ่งที่ทำแทนได้

ชิ้นส่วนที่สร้างด้วยฟีเจอร์เหล่านั้นในรุ่นก่อนยังเปิดได้ ฟีเจอร์เหล่านั้นอยู่ในประวัติโดยทำเครื่องหมายว่ายังไม่ได้สร้าง (วางเมาส์เหนืออันหนึ่งเพื่อดูเหตุผล) ส่วนที่เหลือของชิ้นส่วนสร้างได้ และการบันทึกเก็บมันไว้โดยไม่เปลี่ยนแปลง

## หน้ากลมและเส้นโค้ง

เคอร์เนลเมชวาดวงกลมเป็นรูปหลายเหลี่ยม **เส้นโค้ง** ในพาเนลชิ้นส่วนกำหนดว่าวงกลมเต็มมีกี่ด้าน ด้านมากกว่าดูเรียบกว่าและวัดได้ใกล้ค่าจริงกว่า และใช้เวลาสร้างนานกว่า ปริมาตร พื้นที่ และระยะจาก {{ui:วัด}} เป็นของทรงตันหน้าย่อยนี้: สำหรับรูหรือบอสจะเล็กกว่ารูปทรงกลมเล็กน้อย

## ออนไลน์และออฟไลน์

เคอร์เนลเมชเป็นส่วนหนึ่งของการดาวน์โหลดของแอปเอง หากต้องการทำงานโดยไม่มีการเชื่อมต่อ ให้บันทึก PartCraft ไว้ใช้ออฟไลน์ขณะที่คุณออนไลน์: เลือก {{ui:บันทึกสำหรับออฟไลน์}} ในแถบแอปและรอจนขึ้นว่า **พร้อมใช้ออฟไลน์** รายละเอียด: [การทำงานแบบออฟไลน์](common:offline)
