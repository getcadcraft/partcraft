## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียนเอง) ดูชิ้นส่วนที่คุณเปิดอยู่ เปลี่ยนพารามิเตอร์ รันสคริปต์และส่งออก และวิธีกำหนดว่ามันแตะต้องอะไรได้บ้าง

PartCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใดเลย คุณนำผู้ช่วยมาเอง คือโปรแกรมใดก็ได้ที่ใช้ Model Context Protocol (MCP) PartCraft เพียงมอบเครื่องมือให้ และคุณเป็นผู้เลือกว่าจะให้เครื่องมือใดบ้าง

## การเปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนเฟืองบนแถบของแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:PartCraft}}
2. ภายใต้ {{ui:ผู้ช่วย}} ทำเครื่องหมาย **อนุญาตให้ผู้ช่วย AI และสคริปต์ใช้ PartCraft** ระบบจะปิดไว้จนกว่าคุณจะทำเช่นนั้น
3. เลือกสิ่งที่มันทำได้ **อ่าน** ถูกทำเครื่องหมายไว้ตั้งแต่เริ่มต้น ทำเครื่องหมายรายการอื่นเฉพาะเมื่อคุณต้องการ
4. หากต้องการให้ส่งออกและบันทึกลงโฟลเดอร์ ให้เลือก {{ui:เพิ่มโฟลเดอร์…}} ภายใต้ **โฟลเดอร์ที่มันใช้ได้** แล้วเลือกโฟลเดอร์ในกล่องโต้ตอบของ Studio

ผู้ช่วยเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ Studio จะแสดงที่อยู่และโทเคนให้วางลงในผู้ช่วย แท็บเบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้

## สิ่งที่ผู้ช่วยขอได้

| เครื่องมือ | สิทธิ์ | สิ่งที่ทำ |
|---|---|---|
| `part_describe`, `features_list` | อ่าน | ฟีเจอร์ตามลำดับพร้อมสิ่งที่สร้างสำเร็จและที่ล้มเหลว วัสดุ ปริมาตรและขนาดของโซลิด |
| `params_list` | อ่าน | พารามิเตอร์และทุกตัวเลขที่สมการควบคุมได้ พร้อมค่าของแต่ละตัว |
| `mass_properties` | อ่าน | ปริมาตร พื้นที่ จุดศูนย์กลางมวล โมเมนต์ความเฉื่อยรอบจุดนั้น และมวลเมื่อชิ้นส่วนมีวัสดุ |
| `param_set` | แก้ไข | ตั้งค่าพารามิเตอร์หรือตัวเลขของฟีเจอร์แล้วสร้างใหม่ เป็นหนึ่งขั้นที่เลิกทำได้ |
| `script_run` | แก้ไข | รัน CraftScript, Lua หรือ Python ในลักษณะเดียวกับพื้นที่ทำงาน {{ui:สคริปต์}} คือถูกปิดผนึก ไม่มีไฟล์และไม่มีเครือข่าย ชิ้นส่วนจะไม่เปลี่ยนแปลง |
| `part_export` | ส่งออก | STL, 3MF, STEP หรือ OpenUSD (.usdz, .usda, .usdc) ตามที่ {{ui:ไฟล์}} › {{ui:ส่งออก}} เขียนไว้ |
| `link_push` | แก้ไข | อัปเดตโมเดลที่เชื่อมโยงจากโปรแกรมอื่น (ดู [ให้โมเดล .3dm อัปเดตสด](topic:live-3dm-link)) |
| `link_status` | อ่าน | บอกว่าโมเดลที่เชื่อมโยงยังอยู่หรือไม่ และอัปเดตล่าสุดเมื่อใด |
| `part_save` | บันทึก | {{ui:บันทึก}} ของ PartCraft เอง |
| `illustrate_export` | ส่งออก | คู่มือจากพื้นที่ทำงาน {{ui:Illustrate}} เป็น PDF หรือ SVG ของภาพเส้นของมุมมอง เป็นไฟล์ 3D แบบโต้ตอบ หรือขั้นตอนการประกอบเป็น PDF หรือหน้าเว็บ ตามที่เมนู {{ui:ส่งออก}} และ {{ui:ขั้นตอนการประกอบ}} ของพื้นที่ทำงานเขียนไว้ ([คู่มือ](topic:illustrate)) |

:::note
รุ่นนี้ใช้เคอร์เนลเมช: ปริมาตรคำนวณจากสามเหลี่ยม (น้อยกว่าโซลิดโค้งจริงเล็กน้อย) และ STEP ถูกเขียนเป็นรูปหลายเหลี่ยม โดยใช้สามเหลี่ยมแทนพื้นผิวที่แน่นอน
:::

## คุณยังคงควบคุมอยู่

- **ทุกการเปลี่ยนแปลงคือหนึ่งขั้นของการเลิกทำ** มีป้ายกำกับสำหรับผู้ช่วย เช่น "ผู้ช่วย: ตั้งค่า l = 45" กด {{key:Mod+Z}} เพื่อเลิกทำ
- **คุณจะรู้ว่ามีการเชื่อมต่อหรือไม่** ปุ่มบนแถบของแอปจะระบุชื่อผู้ช่วยขณะที่เชื่อมต่อ คลิกเพื่อดูว่ามันทำอะไรได้ หรือเพื่อ **ตัดการเชื่อมต่อ**
- **กิจกรรม** {{ui:การตั้งค่า}} › {{ui:PartCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงทุกการเรียกใช้ {{ui:บันทึกบันทึกกิจกรรม}} เก็บสำเนาไว้
- **โฟลเดอร์** มันอ่านและเขียนไฟล์ได้เฉพาะในโฟลเดอร์ที่คุณเพิ่มไว้ {{ui:นำออก}} จะเอาโฟลเดอร์กลับทันที

## โดยไม่ต้องเปิด PartCraft

เซิร์ฟเวอร์ไฟล์ของ CadCraft สำหรับผู้ช่วย (`npx @getcadcraft/mcp`) และบรรทัดคำสั่ง `cadcraft` เปิดชิ้นส่วน `.partcraft.json` ด้วยโค้ดและเคอร์เนลเมชของ PartCraft เอง โดยไม่มีหน้าต่าง ได้เครื่องมือการอ่าน การตั้งค่าพารามิเตอร์ สคริปต์ CraftScript การส่งออก (รวม OpenUSD) และการบันทึกเหมือนกัน `cadcraft convert bracket.partcraft.json bracket.stl` สร้างชิ้นส่วนและเขียนไฟล์จากบรรทัดคำสั่ง คู่มือ (`.partcraft-manual.json`) ก็ส่งออกที่นั่นได้เช่นกัน: `illustrate_export` หรือ `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (เพิ่ม `--instructions` เพื่อได้ขั้นตอนการประกอบ)

## หากมีบางอย่างไม่ทำงาน

- **"ต้องใช้สิทธิ์แก้ไข":** ทำเครื่องหมาย **แก้ไข** ภายใต้ {{ui:ผู้ช่วย}} แล้วขอใหม่อีกครั้ง
- **"ถูกควบคุมโดยสมการ":** ตัวเลขนั้นทำตามพารามิเตอร์ ให้ขอให้ผู้ช่วยตั้งค่าพารามิเตอร์แทน
- **การเปลี่ยนแปลงของมันผิด:** กด {{key:Mod+Z}}
