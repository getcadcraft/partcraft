Lua เป็นภาษาที่สองของ[พื้นที่ทำงานสคริปต์](topic:craftscript) เลือก **Lua** ในกล่องภาษาเหนือตัวแก้ไข (ไฟล์ `.lua` จะเปิดเป็น Lua เอง) Lua และ CraftScript ใช้ตัวแปรและฟังก์ชันในตัวชุดเดียวกัน ดังนั้นสคริปต์ Lua ใช้สิ่งที่สคริปต์ CraftScript สร้างไว้ได้ และในทางกลับกัน

## พื้นฐาน

```
-- ฟังก์ชันในตัวทุกตัวอยู่ในตาราง cs
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- เริ่มที่ 1 เหมือน CraftScript
print(K(1, 1), #K)             -- ค่าหนึ่งองค์ประกอบ; จำนวนองค์ประกอบ

-- พื้นที่ทำงาน: ตัวแปรชุดเดียวกันที่ทุกสคริปต์เห็น
ws.total = K(1, 1) * 2
print(ws.total)

-- ผลลัพธ์หลายค่าจากฟังก์ชันเดียว
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` เรียกฟังก์ชันในตัวใดก็ได้และคืนค่าแรก; `cs.call(name, n, …)` คืนค่า `n` ค่า
- `cs.tensor({1, 2, 3})` สร้างแถว และ `cs.tensor({{1, 2}, {3, 4}})` สร้างเมทริกซ์
- อาร์เรย์ เมทริกซ์เบาบาง เมช และฟิลด์เป็นค่าที่มีเมธอด: `t(i, j)` หรือ `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (ทรานสโพส), `t:totable()` `+ - * / ^` มีความหมายเหมือนใน CraftScript (`*` คือผลคูณเมทริกซ์) `t:times(u)` คูณทีละองค์ประกอบ
- จำนวนที่เป็นอาร์เรย์ 1×1 จะได้มาเป็นตัวเลข Lua ธรรมดา
- `ws.name` อ่านและเขียนพื้นที่ทำงานที่ใช้ร่วมกัน ตัวแปรส่วนกลางที่สคริปต์ทิ้งไว้ก็จะไปอยู่ที่นั่นเมื่อสคริปต์สิ้นสุด
- `print(…)` เขียนลงคอนโซล ส่วน `cs.show(f)`, `cs.plot(y)` และฟังก์ชันแสดงผลอื่น ๆ ทำงานเหมือนใน CraftScript

## เรียกไลบรารีการวิเคราะห์

ฟังก์ชันของไลบรารีการวิเคราะห์ (แท็บ Library) และฟังก์ชัน CraftScript ที่สคริปต์ของชิ้นส่วนนั้นกำหนดเอง เข้าถึงได้ผ่าน `cs` เช่นกัน:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- ผลลัพธ์สองค่า
```

ฟังก์ชันเหล่านี้ถูกค้นพบก่อนสคริปต์เริ่มทำงาน จึงต้องเขียนชื่อไว้ในสคริปต์: `cs.static_tet(` หรือ `cs.call('static_tet', …)` ชื่อที่ประกอบขึ้นระหว่างสคริปต์ทำงานจะเข้าถึงได้เฉพาะฟังก์ชันในตัว โครงสร้างที่สร้างด้วย `cs.struct({ … })` คือสตรักต์ CraftScript และลิสต์ Lua ของโครงสร้างเหล่านั้น (`{ cs.struct(…), … }`) คือเซลล์ ซึ่งเป็นสิ่งที่การตั้งค่าของไลบรารีคาดหวัง หากมีอะไรผิดพลาดภายในฟังก์ชันของไลบรารี ข้อความจะระบุชื่อฟังก์ชันและบรรทัด และชี้ไปยังบรรทัดของคุณที่เรียกใช้

## ปิดการใช้งาน

สคริปต์เข้าถึงไฟล์ เครือข่าย หรือหน้าเว็บไม่ได้: `io`, `os` (ยกเว้นนาฬิกา), `require`, `dofile`, `loadfile` และ `debug` ถูกลบออก ใช้ {{ui:Open}} ของพื้นที่ทำงานสคริปต์และตัวแปรเพื่อนำข้อมูลเข้ามา งบขั้นตอนและ {{ui:Stop}} ทำงานเหมือนใน CraftScript
