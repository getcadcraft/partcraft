เปิด {{ui:การตั้งค่า}} ด้วยไอคอนรูปเฟืองในแถบแอปหรือกด {{key:Mod+,}} แท็บแรก {{ui:PartCraft}} มีการตั้งค่าที่เป็นของแอปนี้ ส่วน {{ui:ทั่วไป}} มีการตั้งค่าที่แอป CadCraft ทุกตัวใช้ร่วมกัน (ธีม แถบเครื่องมือ พาเนล) การตั้งค่าของ PartCraft มีเฉพาะในแอปนี้: คุณเปลี่ยนได้ที่นี่ และเบราว์เซอร์นี้จะจำไว้ {{ui:รีเซ็ตการตั้งค่า PartCraft}} จะคืนทุกอย่างเป็นค่าเริ่มต้น

## การหมุนมุมมอง

- **ปุ่มซ้าย** (ค่าเริ่มต้น): ลากด้วยปุ่มซ้ายเพื่อหมุนชิ้นส่วน ลากด้วยปุ่มขวาหรือปุ่มกลางเพื่อแพน
- **ปุ่มกลาง**: กดล้อแล้วลากเพื่อหมุนชิ้นส่วน กด {{key:Shift}} (หรือ {{key:Ctrl}} หรือ ⌘) ค้างไว้พร้อมปุ่มกลาง หรือลากด้วยปุ่มขวาเพื่อแพน ปุ่มซ้ายใช้เพื่อเลือกหน้า ขอบ และระนาบเท่านั้น ดังนั้นการคลิกที่ขยับเล็กน้อยจะไม่หมุนชิ้นส่วน โปรแกรม CAD หลายตัวทำงานแบบนี้

ล้อเลื่อนซูมที่ตำแหน่งตัวชี้ในทั้งสองแบบ ในสเกตช์ ปุ่มขวาและปุ่มกลางยังแพนตามเดิม

## การเลื่อน: ล้อเมาส์หรือแทรคแพด

- **ตรวจอัตโนมัติ** (ค่าเริ่มต้น): PartCraft สังเกตการเลื่อน การเลื่อนด้านข้างหรือการเลื่อนละเอียดแบบที่แทรคแพดส่งมาจะหมุนชิ้นส่วน ส่วนการหมุนล้อเป็นขั้น ๆ จะซูม
- **ล้อเมาส์**: การเลื่อนจะซูมเข้าหาตัวชี้เสมอ
- **แทรคแพด**: ปัดสองนิ้วเพื่อหมุนชิ้นส่วน กด {{key:Shift}} ค้างแล้วปัดเพื่อแพน บีบเพื่อซูม ในสเกตช์ การปัดสองนิ้วจะแพนสเกตช์

การบีบซูมได้ในทุกตัวเลือก หาก "ตรวจอัตโนมัติ" เดาผิดสำหรับเมาส์หรือแทรคแพดของคุณ ให้เลือกแบบที่คุณมี เพิ่มเติมที่ [แทรคแพด การสัมผัส และหน้าจอขนาดเล็ก](topic:trackpad-and-touch)

## สเกตช์: เพิ่มความสัมพันธ์ขณะวาด

**เพิ่มความสัมพันธ์ขณะวาด** (เปิดเป็นค่าเริ่มต้น): การคลิกที่สแนปไปยังจุดจะทำให้จุดใหม่ทับกับจุดนั้น การคลิกบนเส้นโค้งจะวางจุดบนเส้นโค้งนั้น และเส้นที่วาดเกือบระดับหรือตั้งตรงจะกลายเป็นแนวนอนหรือแนวตั้ง ดู [ความสัมพันธ์และไดเมนชัน](topic:relations-dimensions)

ปิดเมื่อคุณต้องการวางรูปทรงใกล้รูปทรงอื่นโดยไม่ผูกติดกัน ตัวชี้ยังคงสแนปไปยังจุดและเส้นโค้ง แต่จะไม่มีการต่อเชื่อม: เส้นที่วาดต่อกันเป็นโซ่จะไม่ใช้ปลายร่วมกัน ดังนั้นการลากอาจดึงให้แยกออกจากกันได้ เพิ่มความสัมพันธ์ที่ต้องการเองจากพาเนลด้านขวา โปรไฟล์ปิดยังคงรีดออก (เอ็กซ์ทรูด) ได้เมื่อปลายทั้งสองมาบรรจบกัน

:::note
การตั้งค่านี้เปลี่ยนเฉพาะสิ่งที่การวาดใหม่เพิ่มเข้าไป ความสัมพันธ์ที่มีอยู่แล้วในสเกตช์จะคงอยู่ และเครื่องมือฟิลเลตยังสร้างส่วนโค้งสัมผัสและรัศมีตามเดิม
:::

## สเกตช์: ใส่ไดเมนชันขณะวาด

**ใส่ไดเมนชันขณะวาด** (เปิดเป็นค่าเริ่มต้น): ขณะวาดเส้น สี่เหลี่ยมผืนผ้า วงกลม หรือส่วนโค้ง การพิมพ์ตัวเลขจะกรอกในช่องขนาดข้างตัวชี้ ({{key:Tab}} ไปยังช่องถัดไป) และ {{key:Enter}} จะวาดรูปร่างที่ขนาดนั้น โดยมีไดเมนชันควบคุมสำหรับทุกขนาดที่คุณพิมพ์ ปิด: การพิมพ์ตัวเลขขณะวาดจะไม่ทำอะไร และรูปร่างจะวาดด้วยการคลิกเท่านั้น ดู [พิมพ์ขนาดขณะวาด](topic:sketch-basics#type-the-size-as-you-draw)

## ตัวบอกมุม

สิ่งที่แสดงที่มุมของมุมมอง 3D: **คิวบ์มุมมอง** (ค่าเริ่มต้น; มุมขวาบน — คลิกหน้า ขอบ หรือมุมเพื่อดูจากตำแหน่งนั้น ลากเพื่อหมุนวงโคจร ลากวงเข็มทิศเพื่อหมุนโมเดล), **ไอคอนแกน** (เครื่องหมาย X, Y, Z เล็ก ๆ มุมล่างซ้ายที่หมุนตามมุมมอง: X สีแดง, Y สีเขียว, Z สีน้ำเงิน) หรือ **ไม่มี** ทั้งสองแบบจะไม่แสดงขณะวาดสเกตช์หรือบนแผ่นแบบ ดู [คิวบ์มุมมอง](topic:view-cube)

## เธรดของตัวแก้สมการ

จำนวนเธรดที่ตัวแก้สมการการจำลองใช้ได้ **อัตโนมัติ** (ค่าเริ่มต้น) ใช้น้อยกว่าจำนวนตัวประมวลผลเชิงตรรกะของคอมพิวเตอร์หนึ่งตัว (สูงสุด 16) เพื่อให้หน้าเว็บตอบสนองขณะที่การศึกษากำลังแก้สมการ หรือเลือกตัวเลขเอง การศึกษาวอกเซลขนาดใหญ่ การโก่งเดาะ (buckling) ความเค้นตามเวลา และการไหลจะแก้เร็วขึ้นบนหลายเธรด (ประมาณ 2 เท่าบน 4 เธรดสำหรับ 80,000 ลูกบาศก์ จากการวัดของเรา และมากกว่านั้นบนคอมพิวเตอร์ที่ว่าง); โมเดลที่มีตัวไม่ทราบค่า (unknowns) ต่ำกว่าประมาณ 20,000 ยังใช้หนึ่งเธรด เพราะการเริ่มเธรดใช้เวลามากกว่าที่ประหยัดได้ การแก้สมการแบบหลายเธรดให้คำตอบเดียวกับหนึ่งเธรด (ต่างกันเพียงการปัดเศษ: ผลรวมถูกบวกในลำดับต่างกัน) ผลลัพธ์ของแต่ละการศึกษาจะแสดง **N threads** หรือ **1 thread** พร้อมเหตุผลภายใต้ **Solver**

เธรดต้องให้หน้าเว็บเป็น **cross-origin isolated** (เบราว์เซอร์จะอนุญาตให้เวิร์กเกอร์ใช้หน่วยความจำร่วมกันเฉพาะเมื่อเป็นเช่นนั้น) หน้าแล็บเป็นเช่นนั้น หากไม่ใช่ การตั้งค่าจะแจ้งไว้ ("หน้านี้ไม่ได้เป็น cross-origin isolated ดังนั้นตัวแก้สมการจะทำงานบนหนึ่งเธรดไม่ว่าจะเลือกค่าใดไว้ที่นี่") และทุกการแก้สมการจะใช้หนึ่งเธรด ส่วนอื่นทำงานเหมือนเดิม และคำตอบก็เหมือนกัน

การศึกษาการไหลแบบลามินาร์ก็ใช้เธรดเช่นกัน (ประมาณ 2.5 เท่าบน 4 เธรดสำหรับเซลล์ของไหล 54,000 เซลล์ คำตอบเหมือนกันทุกหลัก) ตัวแก้สมการเตตระฮีดรอนกำลังสอง และการถ่ายเทความร้อนทำงานบนหนึ่งเธรด เพราะการทำเธรดให้ผลช้ากว่าที่วัดได้บนคอมพิวเตอร์ทดสอบของเรา (ตัวแก้สมการของทั้งสองถูกจำกัดด้วยความเร็วหน่วยความจำและขั้นตอนที่แบ่งไม่ได้)

### บนเว็บเซิร์ฟเวอร์ของคุณเอง

หากคุณรัน PartCraft จากเซิร์ฟเวอร์ของคุณเอง ก็ทำงานได้ตามที่เสิร์ฟ สำหรับเธรดของตัวแก้สมการ ให้เซิร์ฟเวอร์ส่งสองเฮดเดอร์พร้อมหน้าของ PartCraft:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

บน Apache ในไฟล์ `.htaccess` ของโฟลเดอร์ (ต้องมี mod_headers):

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

บน nginx ใน `location` ที่เสิร์ฟ PartCraft:

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

รีโหลดหน้า: การตั้งค่า › เธรดของตัวแก้สมการ จะแสดง **อัตโนมัติ** พร้อมจำนวนของคอมพิวเตอร์คุณ เฮดเดอร์ที่สองทำให้เบราว์เซอร์ปฏิเสธทุกอย่างที่หน้าโหลดจากเว็บไซต์อื่นที่ไม่อนุญาต ซึ่งใช้ได้ดีสำหรับ PartCraft ที่ทำงานเอง (โหลดทุกอย่างจากโฟลเดอร์ของตัวเอง)
