## สิ่งที่คุณจะทำ

ส่งมอบ **ทุกขนาดของชิ้นส่วนในครั้งเดียว** ไฟล์ STEP, IFC และ DWG หนึ่งไฟล์ และรูปหนึ่งรูปต่อการกำหนดค่าแต่ละอัน ตารางที่บอกว่าแต่ละอันคืออะไร และรายการในไลบรารีที่รวมทั้งหมดไว้ในหน้าเดียว

ก่อนอื่นคุณต้องมีชิ้นส่วนที่มี **การกำหนดค่า** (ดู [การกำหนดค่าและตารางการออกแบบ](topic:design-tables)) การกำหนดค่าที่ปิดฟีเจอร์ เช่น แผ่นที่มีรูและไม่มีรู จะกลายเป็นตัวแปรของตัวเองหนึ่งตัว

## ขั้นตอน

1. เปิดชิ้นส่วน ในแท็บ {{ui:พารามิเตอร์}} ค้นหา **การกำหนดค่า**
2. คลิก {{ui:ชุดตัวแปร…}}
3. ทำเครื่องหมายการกำหนดค่าที่จะสร้าง (ทั้งหมดถูกทำเครื่องหมายไว้) และไฟล์ที่จะเขียน ได้แก่ STEP, IFC, DWG, ภาพตัวอย่าง และรายการในไลบรารี
4. คลิก {{ui:สร้างชุด}} แถบสถานะจะนับตัวแปรขณะที่สร้าง ชิ้นส่วนของคุณจะไม่ถูกเปลี่ยนแปลง
5. ไฟล์ zip หนึ่งไฟล์จะดาวน์โหลด: `<part> variants.zip`

## สิ่งที่อยู่ในไฟล์ zip

| ไฟล์ | คืออะไร |
|---|---|
| `<name>.step` | การกำหนดค่าเป็นโซลิด STEP |
| `<name>.ifc` | IFC4 หนึ่งองค์ประกอบ มีบอดี้ที่สร้างแล้วและพารามิเตอร์ของชิ้นส่วนเป็นคุณสมบัติ โดยค่าเป็นของการกำหนดค่านั้นเอง |
| `<name>.dwg` | มุมมองด้านหน้า ด้านบน ด้านขวา และไอโซเมตริก เป็นแผ่นแบบขนาดเต็ม |
| `<name>.svg` | ภาพลายเส้นไอโซเมตริกของการกำหนดค่านั้น |
| `variants.csv`, `variants.json` | ตารางพารามิเตอร์: รหัส ชื่อ และค่าของพารามิเตอร์ทุกตัวของแต่ละตัวแปร ฟีเจอร์ที่มันปิด ไฟล์ ปริมาตร และขนาดของมัน |
| `<part>.item.json` | ชิ้นส่วนเป็นรายการในไลบรารีหนึ่งรายการพร้อมตัวแปร (ดูด้านล่าง) |
| `README.txt` | สิ่งที่สร้าง หมายเหตุด้านล่าง และสิ่งที่ยังไม่ได้สร้าง |

ไฟล์ตั้งชื่อตามการกำหนดค่า การกำหนดค่าที่สร้างไม่สำเร็จ (ฟีเจอร์ที่ไม่สามารถสร้างด้วยค่าเหล่านั้นได้) จะไม่อยู่ในไฟล์และตาราง จะถูกระบุไว้ใน README และในข้อความหลังจากบันทึกไฟล์ zip แล้ว ส่วนอื่นจะยังถูกเขียนอยู่

## ควรทราบ

- **STEP** จะแน่นอนเมื่อเปิดเคอร์เนลที่แน่นอนในบิลด์ของคุณ หากไม่มี STEP จะเป็นรูปหลายเหลี่ยม (สามเหลี่ยมแบน) และ README จะบอกไว้
- **DWG** คือแผ่นแบบ ไม่ใช่โมเดล 3D เส้นของมันมาจากเมช ดังนั้นขอบโค้งจะเป็นเส้นสั้นหลายเส้น
- **รายการในไลบรารี** มีบอดี้และพื้นที่ฐานหนึ่งชุดต่อตัวแปร ในแกนของไลบรารีเอง: Z ชี้ขึ้น ด้านหน้าหันไปทาง −Y และจุดแทรกอยู่กึ่งกลางด้านหลังที่ด้านล่าง ผังคือสี่เหลี่ยมขอบเขตของแต่ละตัวแปร รายการจำกัดขนาด 8 MB ตัวแปรที่หนักมากจะกลายเป็นกล่องที่มีขนาดเท่ากัน และ README จะบอกว่ามีกี่รายการ
- การกำหนดค่าที่ใช้งานอยู่ของชิ้นส่วนจะเป็นตัวแปรเริ่มต้นของรายการ
- พอร์ต (จุดเชื่อมต่อสำหรับท่อและท่อลม) ไม่ได้ตั้งค่าจาก PartCraft

## นำตัวแปรขึ้นหน้าไลบรารี

อัปโหลด `<part>.item.json` ที่ **คลังไลบรารี › อัปโหลด** บนเว็บไซต์ เลือกหมวดหมู่ ลิขสิทธิ์ และการระบุแหล่งที่มาของคุณ แล้วมันจะกลายเป็นรายการในไลบรารีพร้อมตัวแปร ใน BimCraft เมื่อวางรายการ ระบบจะถามว่าต้องการตัวแปรใด และ สลับ จะเสนอตัวอื่น หน้าที่ผู้เยี่ยมชมเลือกตัวเลือก ดู 3D และดาวน์โหลดตัวแปร ตอนนี้เป็น **ตัวอย่างสำหรับเจ้าหน้าที่** ยังไม่เปิดให้สาธารณะ

## จากบรรทัดคำสั่ง

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` ระบุการกำหนดค่า `--formats` รับค่าใดก็ได้จาก `step`, `ifc`, `dwg`, `preview` และ `--no-item` ไม่รวมรายการในไลบรารี โปรแกรมจะเขียนโฟลเดอร์ ไฟล์ zip หรือทั้งสองอย่าง และจะออกด้วยรหัส 1 เมื่อไม่สามารถสร้างตัวแปรได้ ดู [สคริปต์และบรรทัดคำสั่ง](topic:scripts-and-cli)
