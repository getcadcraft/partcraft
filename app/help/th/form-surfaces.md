:::note
**ยังไม่ได้สร้างในเวอร์ชันนี้** การทำให้รูปร่างเสร็จเป็นส่วนหนึ่งของชิ้นส่วน และฟีเจอร์พื้นผิว ต้องใช้เคอร์เนลเรขาคณิตที่แน่นอน ซึ่งเวอร์ชัน PartCraft นี้ไม่มี: มันสร้างทุกชิ้นส่วนด้วยเคอร์เนลเมช [สิ่งที่ยังไม่ได้สร้าง](topic:not-built-yet) บอกว่าควรทำอย่างไรแทน ส่วนที่เหลือของหน้านี้อธิบายการทำงานของฟีเจอร์เหล่านั้นเมื่อใช้เคอร์เนลที่แน่นอน
:::

พื้นที่ทำงาน **Form** ใช้สร้างรูปทรงอินทรีย์ คุณแก้ไข **กรง** ซึ่งเป็นเมชหยาบของมุม ขอบ และหน้า รูปร่างคือพื้นผิวเรียบที่กรงควบคุม (พื้นผิวลิมิต Catmull–Clark) ดังนั้นการขยับมุมหนึ่งจะโค้งพื้นผิวรอบ ๆ มุมนั้นอย่างนุ่มนวล เมื่อรูปร่างถูกต้อง **เสร็จสิ้น** จะเพิ่มมันเข้าประวัติของชิ้นส่วนเป็นฟีเจอร์ *Form* และเคอร์เนลที่แน่นอนจะแปลงให้เป็นพื้นผิว B-spline จริง จากนั้นคุณสามารถทำ fillet ตัด เชื่อมกับฟีเจอร์อื่น และส่งออกเป็น STEP ได้

เลือก **Form** ในรายการ **พื้นที่ทำงาน** ทางซ้ายของแถบเครื่องมือ

## เริ่มกรง

1. ตั้ง **ขนาด** และ **การแบ่ง** ในพาเนลด้านขวา การแบ่งคือจำนวนหน้าที่แต่ละด้านได้รับ
2. คลิก {{ui:Box}}, {{ui:Quadball}} หรือ {{ui:Plane}} ในแถบเครื่องมือ พาเนลยังมี **ทรงกระบอก** **ทอรัส** และ **หน้าจากการคลิก**

- **quadball** คือกรงกล่องที่ปรับให้จุดมุมวางอยู่บนทรงกลม ระหว่างจุดเหล่านั้นพื้นผิวจะอยู่ด้านในทรงกลมเล็กน้อย ประมาณน้อยกว่า 0.4 % ของปริมาตรเมื่อแบ่ง 2 ครั้ง
- **plane** เป็นแบบเปิด ดังนั้นมันจะกลายเป็นวัตถุพื้นผิว (ดู "ฟีเจอร์พื้นผิวใน Design" ด้านล่าง)
- **หน้าจากการคลิก**: คลิก 4 จุดบนระนาบบน (พื้น) หรือบนมุมของกรงเพื่อสร้างหนึ่งหน้า หน้าที่ใช้มุมร่วมกันจะเชื่อมกัน กด {{key:Enter}} หลังจาก 3 จุดสำหรับรูปสามเหลี่ยม หรือ {{key:Esc}} เพื่อหยุด

กรงที่ยังไม่เสร็จจะถูกบันทึกพร้อมไฟล์ชิ้นส่วน ดังนั้นคุณปิดไฟล์และทำต่อภายหลังได้

## เลือกและย้าย

- คลิกมุม ขอบ หรือหน้าของกรง **Shift**+คลิกเพื่อเพิ่มหรือเอาออก {{key:Esc}} ล้างการเลือก
- {{ui:Gizmo}} ปรากฏตรงกลางของที่เลือก ลากลูกศรเพื่อเคลื่อนที่ตามแกนนั้น หรือลากสี่เหลี่ยมเพื่อเคลื่อนที่ในระนาบนั้น กด {{key:W}} เพื่อย้าย {{key:E}} เพื่อหมุน และ {{key:R}} เพื่อสเกล หรือใช้ปุ่มในพาเนล {{ui:Gizmo}} ในแถบเครื่องมือจะวนผ่านโหมดเหล่านี้
- **การลดลงแบบนุ่ม** (mm) ดึงมุมที่อยู่ในระยะนั้นด้วย โดยค่อย ๆ จางลงจนเป็นศูนย์ที่ขอบของระยะนั้น
- การลากทุกครั้งเป็นหนึ่งขั้นของการเลิกทำ {{key:Ctrl+Z}} และ {{key:Ctrl+Y}} ทำงานตามปกติ

## เปลี่ยนกรง

ปุ่ม **แก้ไข** ในพาเนลทำงานกับที่เลือก:

| ปุ่ม | ทำอะไร |
|---|---|
| {{ui:Extrude}} | หน้าที่เลือกเคลื่อนออกตาม **ระยะเอ็กซ์ทรูด** ตามเวกเตอร์ปกติของหน้า พร้อมหน้าด้านข้างใหม่ ขอบเปิดที่เลือกจะสร้างหน้าใหม่ออกด้านนอก |
| {{ui:Edge loop}} / แทรกลูปขอบ | แบ่งวงของหน้าสี่เหลี่ยมที่ตัดกับขอบที่เลือกตรงกลาง ลูปมากขึ้นทำให้เส้นโค้งแน่นขึ้น |
| แทรกจุด | เพิ่มมุมตรงกลางของขอบที่เลือก |
| แบ่งย่อย | แบ่งแต่ละหน้าที่เลือกเป็นหน้าสี่เหลี่ยมรอบจุดกึ่งกลาง |
| สะพาน | เชื่อมหน้าที่เลือกสองหน้า หรือช่องเปิดสองช่อง (เลือกขอบเปิดหนึ่งขอบบนแต่ละช่อง) ด้วยท่อของหน้า ทั้งสองต้องมีจำนวนขอบเท่ากัน |
| เติมรู | ปิดช่องเปิดผ่านขอบเปิดที่เลือกด้วยหนึ่งหน้า |
| เชื่อม | รวมมุมที่เลือกให้เป็นหนึ่ง ที่จุดกึ่งกลาง |
| ทำให้แบน | ย้ายมุมที่เลือกไปยังระนาบที่เข้ากับมันดีที่สุด |
| ลบ | เอาหน้า ขอบ (สองหน้ารวมกัน) หรือมุมที่เลือกออก |

## ขอบคม ความสมมาตร และการแสดงผล

- {{ui:Crease}} ทำให้ขอบที่เลือกคม **น้ำหนักรอยพับ** 10 คือคมเต็มที่ น้ำหนักที่น้อยกว่าจะคมตามจำนวนขั้นการปรับละเอียดนั้นแล้วค่อยนุ่มลง ซึ่งให้โค้งแคบแทนการพับแข็ง **ยกเลิกรอยพับ** ทำให้ขอบเรียบอีกครั้ง **มุมคม** ตรึงมุมเพื่อให้พื้นผิวผ่านมุมนั้นด้วยจุด
- **สมมาตร** สะท้อนกรงข้ามแกน X, Y หรือ Z = 0 โดยเก็บด้านบวกไว้ สะท้อนมัน และเชื่อมสองครึ่ง หลังจากนั้นการแก้ไขด้านใดด้านหนึ่งจะเกิดขึ้นทั้งสองด้าน มุมบนระนาบสะท้อนจะอยู่บนระนาบนั้น
- {{ui:Display}} สลับระหว่าง **Smooth** (พื้นผิวที่ฟีเจอร์จะเป็น) และ **Box** (หน้าของกรงเอง)
- **การวิเคราะห์**: **Zebra stripes** สะท้อนแสงลายทางจากมุมมองปัจจุบัน ลายจะโค้งอย่างนุ่มนวลบนพื้นผิวเรียบและขาดที่รอยพับ **ความโค้งเฉลี่ย** ระบายสีบริเวณนูนเป็นสีแดง บริเวณเว้าเป็นสีน้ำเงิน และบริเวณแบนเป็นสีขาว วัดบนเมชที่แสดงด้วยสูตรโคแทนเจนต์ จึงเป็นแนวทาง ไม่ใช่การวัด

## ตรวจสอบและทำให้เสร็จ

- **ตรวจสอบแบบแม่นยำ** แปลงกรงในเคอร์เนลที่แน่นอนโดยไม่เปลี่ยนชิ้นส่วน รายงานจำนวนแพตช์ B-spline ที่กรงสร้าง จำนวนที่แน่นอน และว่าผลลัพธ์เป็นโซลิดปิดที่ถูกต้องหรือไม่ รวมถึงปริมาตร
- {{ui:Finish}} เพิ่มฟีเจอร์ *Form* เข้าประวัติ หรืออัปเดตรูปทรงที่คุณกำลังแก้ไข แล้วพากลับไปที่ Design กรงที่ปิดจะกลายเป็นโซลิด **การดำเนินการ** ในพาเนล Design ของมันอาจเป็น New body, Join, Cut หรือ Intersect กรงที่เปิดจะกลายเป็นวัตถุพื้นผิว
- หากต้องการเปลี่ยนรูปทรงภายหลัง ให้เลือกในประวัติแล้วคลิก **แก้ไขใน Form** วัตถุที่สร้างแล้วจะถูกซ่อนขณะแก้ไขกรง
- **ทิ้ง** ทิ้งกรงโดยไม่แตะประวัติ

## สิ่งที่แน่นอนและสิ่งที่ประมาณ

แต่ละหน้าสี่เหลี่ยมของกรง ปรับละเอียดเมื่อจำเป็น จะกลายเป็นแพตช์ B-spline bicubic หนึ่งแพตช์

- เมื่อทุกมุมของหน้าเป็น *ปกติ* (มีสี่ขอบมาบรรจบกันภายในพื้นผิว หรือสามขอบบนขอบเปิดหรือตามรอยพับ) แพตช์ **แน่นอน** เป็นพื้นผิวซับดิวิชันนั้น การทดสอบตรวจสอบค่านี้ถึง 1e-9 mm
- รอบ **จุดพิเศษ** (มีสาม ห้า หรือมากกว่าขอบมาบรรจบกัน มุมของหน้าสามหรือห้าด้าน หรือปลายของรอยพับ) ไม่มีแพตช์พหุนามที่แน่นอน ตรงนั้นแพตช์ใช้จุดที่แน่นอนและระนาบสัมผัสที่มุมนั้น และเส้นโค้งขอบของเพื่อนบ้าน ดังนั้นแพตช์ยังคงมาบรรจบกันโดยไม่มีช่องว่าง ความต่อเนื่องแบบสัมผัสข้ามขอบที่มาบรรจบกันที่จุดนั้นเป็นค่าประมาณ พาเนลรูปทรงและพาเนลของฟีเจอร์จะให้มุมที่ใหญ่ที่สุด โดยปกติต่ำกว่า 2° **ระดับ** ที่สูงขึ้นในพาเนลของฟีเจอร์จะทำให้แพตช์เหล่านั้นเล็กลงและใกล้กว่า
- รอยพับที่คมคือขอบจริงของโซลิด ดังนั้นคุณทำ fillet ได้
- แต่ละแพตช์เป็นหน้าของตัวเอง ดังนั้นรูปทรงมีหลายหน้า และเส้นจะถูกวาดระหว่างหน้าเหล่านั้น

## ฟีเจอร์พื้นผิวใน Design

คำสั่งพื้นผิวอยู่ในเมนู {{ui:More}} ของ Design ภายใต้ฟีเจอร์ ต้องใช้เคอร์เนลที่แน่นอน วัตถุพื้นผิวถูกวาดโปร่งแสงเป็นสีน้ำเงิน และไม่เป็นส่วนของโซลิดจนกว่าคุณจะทำให้หนาหรือเย็บ

| คำสั่ง | ทำอะไร |
|---|---|
| แพตช์ | เติมลูปปิดของขอบ {{key:Shift}}+คลิกขอบของโซลิดก่อน หรือเลือกวัตถุพื้นผิวเพื่อเติมช่องเปิดของมัน **สัมผัส (G1)** ทำให้แพตช์มาบรรจบกับพื้นผิวนั้นอย่างนุ่มนวล |
| ลอฟต์พื้นผิว | พื้นผิวผ่านหนึ่งโซ่ของเส้นโค้งต่อสเกตช์ (เปิดหรือปิด) ตามลำดับในประวัติ |
| เย็บ | เย็บวัตถุพื้นผิวตามขอบที่ใช้ร่วมกัน ถ้าปิดสนิท ผลลัพธ์คือโซลิด พร้อม การดำเนินการ เหมือนฟีเจอร์อื่น |
| ทำให้หนา | ให้วัตถุพื้นผิวมีความหนา: ตามเวกเตอร์ปกติ สวนกับมัน หรือครึ่งหนึ่งในแต่ละทาง ผลลัพธ์คือโซลิด |
| ออฟเซ็ตพื้นผิว | สำเนาของวัตถุพื้นผิวที่เคลื่อนตามเวกเตอร์ปกติ ต้นฉบับยังอยู่ |
| ขยายพื้นผิว | ขยายพื้นผิวหนึ่งหน้าให้เกินขอบที่คุณเลือก |
| ตัดพื้นผิว | ตัดวัตถุพื้นผิวตรงที่วัตถุพื้นผิวอีกชิ้นหรือโซลิดตัดผ่าน คลิก **เลือกจุดบนชิ้นส่วน** เพื่อเลือกชิ้นที่จะเก็บ หรือเก็บทุกอย่างที่เหลือ |

เย็บ ทำให้หนา ขยาย และตัด จะใช้วัตถุพื้นผิวที่มันเริ่มต้นจากไป ฟีเจอร์ถัดไปจะใช้วัตถุใหม่

ข้อจำกัดในปัจจุบัน: รูปทรงที่มีหลายชิ้นปิดแยกกันจะไม่แปลงเป็นโซลิดเดียว พื้นที่ปกติจะไม่ถูกรวมเป็นพื้นผิวที่ใหญ่ขึ้น และดู [สิ่งที่ยังไม่ได้สร้าง](topic:not-built-yet)
