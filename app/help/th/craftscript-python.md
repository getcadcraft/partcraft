Python เป็นภาษาที่สามของ[พื้นที่ทำงานสคริปต์](topic:craftscript) เลือก **Python** ในกล่องภาษาเหนือตัวแก้ไข (ไฟล์ `.py` จะเปิดเป็น Python เอง) Python, Lua และ CraftScript ใช้ตัวแปรและฟังก์ชันในตัวชุดเดียวกัน ดังนั้นสคริปต์ Python ใช้สิ่งที่สคริปต์ CraftScript สร้างไว้ได้ และในทางกลับกัน

การรัน Python ครั้งแรกในการเข้าชมแต่ละครั้งจะโหลด Python เอง (CPython 3.14 ประมาณ 7 MB) จากเว็บไซต์นี้ ซึ่งใช้เวลาไม่กี่วินาที Python ยังไม่ได้เป็นส่วนหนึ่งของ {{ui:Save for offline}} ดังนั้นให้รันสคริปต์ Python หนึ่งตัวขณะออนไลน์ก่อน

## Python ถูกปิดผนึก

สคริปต์ Python ถูกปิดผนึกเช่นเดียวกับสคริปต์ CraftScript และ Lua: เข้าถึงได้เฉพาะชิ้นส่วน ตัวแปร และฟังก์ชันในตัวเท่านั้น การรันแต่ละครั้งเป็น Python ใหม่ในแซนด์บ็อกซ์ของตัวเอง พร้อมระบบไฟล์ขนาดเล็กในหน่วยความจำ (ไลบรารีมาตรฐานและโฟลเดอร์ `/tmp` ที่หายไปหลังการรัน) เข้าถึงเครือข่าย ไฟล์ของคุณ หรือส่วนอื่นของหน้าเว็บไม่ได้ ทั้งในเบราว์เซอร์และบรรทัดคำสั่ง สคริปต์ของผู้อื่นยังใช้เวลาหรือหน่วยความจำได้มาก: {{ui:Stop}} จะหยุดสคริปต์นั้น

## พื้นฐาน

```
A = cs.magic(3)              # ฟังก์ชันในตัวทุกตัวคือ cs.<name>
B = A @ A.T                  # @ คือผลคูณเมทริกซ์ .T คือทรานสโพส
C = A * 2 + 1                # + - * / ** ทำทีละองค์ประกอบ เหมือนใน numpy
print(A[0, 1], A[-1, -1])    # เริ่มที่ 0; ค่าลบนับจากท้าย
row = A[1]                   # ดัชนีเดียวบนเมทริกซ์: หนึ่งแถว
big = A[A > 4]               # มาสก์ตรรกะเลือกองค์ประกอบ
A[0, 0] = -5                 # กำหนดค่าให้อาร์เรย์
V, D = cs.call('eig', 2, A)  # ผลลัพธ์หลายค่า: cs.call(name, จำนวน, …)
```

- อาร์เรย์ขนาด 1 × 1 จะได้มาเป็นตัวเลขธรรมดา ส่วนอาร์เรย์อื่น เมทริกซ์เบาบาง เมช ฟิลด์ และโมเดลเป็น **Value**
- Value มี `shape` (ทูเพิล) `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (จำนวนแถว) และ `float()`, `int()` กับ `bool()` สำหรับองค์ประกอบเดียว
- การเปรียบเทียบ (`<`, `==`, …) ทำทีละองค์ประกอบ เหมือนใน numpy: ให้ผลเป็น Value ตรรกะ
- รายการตัวเลขที่ส่งให้ฟังก์ชันในตัวจะกลายเป็นอาร์เรย์: `cs.sum([1, 2, 3])` และ `cs.tensor([[1, 2], [3, 4]])` สร้างเมทริกซ์
- dict จะกลายเป็นสตรักต์ และลิสต์ของสิ่งที่ปนกันจะกลายเป็นเซลล์ และกลับกันได้

ตัวแปรส่วนกลางทุกตัวที่สคริปต์สร้าง (ตัวเลข Value dict list…) จะไปอยู่ในแท็บ **ตัวแปร** เมื่อการรันสิ้นสุด แม้จะเกิดข้อผิดพลาด ชื่อที่ขึ้นต้นด้วย `_` ฟังก์ชัน คลาส และโมดูลจะอยู่ใน Python `ws.name` อ่านหรือกำหนดตัวแปรได้โดยตรง และ `ws_names()` แสดงรายชื่อ

`print(…)` เขียนลงคอนโซล `display(…)` (หรือ `cs.display`) แสดงเมช ฟิลด์ หรือกราฟ เหมือนใน CraftScript

## เรียกไลบรารีการวิเคราะห์

ฟังก์ชันของไลบรารีถูกเรียกเหมือนฟังก์ชันในตัว: `cs.box_mesh(20, 10, 10, 5, 'hex')` และ `cs.call('modal_tet', 2, …)` เขียนชื่อในสคริปต์ตามที่เป็น: PartCraft จะค้นหาฟังก์ชันไลบรารีที่สคริปต์ใช้ก่อนที่สคริปต์จะรัน

## ยังไม่มี

- numpy, scipy และแพ็กเกจอื่น: มีเพียงไลบรารีมาตรฐานของ Python เอง (`math`, `json`, `itertools`, `decimal`, `statistics`…) โดยไม่มีส่วนหน้าต่าง เทอร์มินัล และฐานข้อมูล (`tkinter`, `curses`, `sqlite3`)
- ซ็อกเก็ตและสิ่งอื่นที่จะออกไปภายนอก: Python ไม่มีเครือข่ายที่นี่
- `time.sleep` คืนค่าทันที
- การพับโค้ดในตัวแก้ไข และการเรียกฟังก์ชัน Python จากสคริปต์ CraftScript
- การรันจะตรวจงบคำสั่งและ {{ui:Stop}} ทุก 1000 บรรทัด การคำนวณยาวภายในฟังก์ชันในตัวเพียงฟังก์ชันเดียวจะทำจนเสร็จก่อน
