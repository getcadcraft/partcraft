PartCraft เป็นบิลด์ระยะเริ่มต้น หน้านี้แสดงสิ่งที่ยังไม่ทำ เพื่อไม่ให้ต้องค้นหาเอง พร้อมวิธีทำแทนในปัจจุบัน ยังไม่มีกำหนดเวลาสำหรับรายการใดในหน้านี้

## ต้องใช้เคอร์เนลแม่นยำ

บิลด์นี้สร้างชิ้นส่วนทั้งหมดด้วยเคอร์เนลเมช (ดู [เคอร์เนลเมช](topic:solid-kernels)) สิ่งด้านล่างต้องใช้เคอร์เนลเรขาคณิตที่แม่นยำ ซึ่งรุ่นนี้ยังไม่มี ชิ้นส่วนที่บันทึกด้วยฟีเจอร์เหล่านี้ยังเปิดได้ ฟีเจอร์จะคงอยู่ในประวัติ มีเครื่องหมายว่ายังไม่ได้สร้าง และจะถูกเก็บไว้เมื่อบันทึก

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| {{ui:Fillet}} และ {{ui:Chamfer}} บนขอบโค้ง; ฟิลเลตที่รัศมีเปลี่ยนไปตามขอบ; การปัดมุมที่มาบรรจบกันอย่างนุ่มนวล (เคอร์เนลเมชจะตัดมุมแบบเฉียง) | ฟิลเลตและชัมเฟอร์ใช้ได้กับขอบตรงระหว่างหน้าแบน ปัดมุมอื่นที่โค้งในสเกตช์ก่อนเอ็กซ์ทรูด ({{ui:Fillet}} ในสเกตช์, {{key:F}}) |
| {{ui:Shell}} ที่เปิดหน้าโค้ง; ผนังที่มีความหนาต่างกัน | เปิดหน้าแบน; เพิ่มวัสดุด้วยการเอ็กซ์ทรูดในจุดที่ผนังต้องหนากว่า |
| {{ui:Sweep}}, {{ui:Loft}}, {{ui:Draft}} บนหน้าโค้ง; เอ็กซ์ทรูดจนถึงหน้า หน้าถัดไป หรือจุดยอด; เอ็กซ์ทรูดแบบเรียว | เอ็กซ์ทรูดหรือหมุนรอบแกน เป็นขั้นตอนเมื่อจำเป็น; เอ็กซ์ทรูดไปยังความลึกที่วัดไว้ |
| {{ui:Rib}}, {{ui:Base flange}}, {{ui:Edge flange}} และแพตเทิร์นแบน | เอ็กซ์ทรูดแผ่นหรือโปรไฟล์ของซี่ |
| พื้นผิว: การทำ {{ui:Form}} ให้สมบูรณ์เข้าไปในชิ้นส่วน, {{ui:Patch}}, {{ui:Loft surface}}, {{ui:Gordon surface}}, {{ui:Stitch}}, {{ui:Thicken}}, {{ui:Offset surface}}, {{ui:Extend surface}}, {{ui:Trim surface}} | ไม่มี |
| หลายบอดี้: {{ui:Combine}}, {{ui:Move body}}, {{ui:Scale body}}, {{ui:Path pattern}}, ฟีเจอร์ที่สร้างบอดี้ใหม่ | โซลิดเดียว; แพตเทิร์นและมิเรอร์คัดลอกฟีเจอร์ |
| สเกตช์ ระนาบ แกน และจุดบนหน้าที่หาได้เฉพาะด้วยเคอร์เนลแม่นยำ (หน้าที่สร้างจากฟิลเลต ผนังรู หรือหน้าของโซลิดที่นำเข้า) | สเกตช์บนระนาบฐาน ระนาบอ้างอิง และหน้าแบนของเอ็กซ์ทรูดและการหมุน |
| ผลลัพธ์การออกแบบเชิงกำเนิดที่เปิดเป็นชิ้นส่วนหรือเพิ่มเข้าชิ้นส่วน (จะกลายเป็นโซลิดที่นำเข้า) | ดาวน์โหลดผลลัพธ์เป็น STL หรือ STEP |
| แก้ไขพื้นผิวโค้งของไฟล์ STEP ที่เปิดเป็นพื้นผิวแม่นยำ; STEP แม่นยำของหน้าสไปลน์ หน้าที่สวีปและหมุน ขอบสไปลน์ เกลียวที่สร้างแบบจำลอง; บอดี้และแอสเซมบลีของ STL / OBJ / 3MF; STEP ของโปรแกรมโมเดลชิ้นส่วนอื่น | {{ui:Open}} อ่าน STEP เป็นสามเหลี่ยม และคงหน้าแบน กระบอกสูบ กรวย ทรงกลม และทอรัสของไฟล์ไว้สำหรับการส่งออก ([เปิดไฟล์ STEP](topic:import-step)); {{ui:Export}} › {{ui:STEP AP242 (exact solid)}} เขียนทุกหน้าแบบวิเคราะห์อย่างแม่นยำ และคงไว้เป็นเฟเซ็ต ([ส่งออก](topic:export-files#for-other-cad-programs-step)); มาโครสำหรับโปรแกรมโมเดลชิ้นส่วนอื่นยังคงเขียนแบบเดิม |
| ส่วนโค้งจริงในมุมมองแบบ | มุมมองและมุมมองภาพตัดวาดจากเฟเซ็ต |
| ปริมาตร พื้นที่ และระยะทางที่แม่นยำ | {{ui:Measure}} ให้ค่าของโซลิดเฟเซ็ต ซึ่งต่ำไปเล็กน้อยในชิ้นส่วนโค้ง การตั้งค่า **Curves** ที่ละเอียดกว่าจะทำให้ค่าใกล้เคียงขึ้น |

บางแถวในตารางด้านล่างแนะนำให้ใช้ฟีเจอร์เหล่านี้เป็นทางเลี่ยงสิ่งอื่น คำแนะนำเหล่านั้นจะใช้ได้เมื่อเคอร์เนลแม่นยำกลับมาใช้ได้

## ฟีเจอร์

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| ฟิลเลตหน้า, ฟิลเลตแบบโค้งเต็มวง, ฟิลเลตที่กำหนดรัศมีที่จุดตามขอบ | {{ui:Fillet}} แบบรัศมีคงที่หรือรัศมีแปรผันเชิงเส้น; ฟีเจอร์ฟิลเลตหลายชุด |
| เชลล์ที่มีความหนาผนังต่างกัน | {{ui:Shell}} ความหนาเดียว; เพิ่มวัสดุด้วยการเอ็กซ์ทรูดในจุดที่ผนังต้องหนากว่า |
| Draft บนหน้าฟรีฟอร์ม (สไปลน์) | {{ui:Draft}} ทำงานบนหน้าแบน หน้าทรงกระบอก และหน้ากรวย |
| สวีปแบบบิด สวีปผนังบางและสวีปพื้นผิว; การสัมผัสปลายบนฟีเจอร์ Loft; ลอฟต์ที่มีรางนำหนึ่งราง; เส้นทางแบบสไปลน์ | {{ui:Sweep}} แบบทิศทางคงที่หรือสเกลปลาย; ลอฟต์ที่มีรางนำสองรางขึ้นไป: ดู [สวีป ลอฟต์ และ draft](topic:sweep-loft-draft) |
| ซี่จากส่วนโค้งหรือสไปลน์; ซี่ที่โตเป็นมุมฉากกับสเกตช์ (จากมุมมองด้านบน); draft บนซี่; ซี่หลายชิ้นจากสเกตช์เดียว | {{ui:Rib}} จากโซ่ของเส้นหนึ่งเส้นบนระนาบของซี่เอง: ดู [ซี่และแผ่นค้ำ](topic:rib) |
| "ขึ้นไปจนถึง" พื้นผิวโค้ง "ขึ้นไปถึงถัดไป" ที่หยุดบนหน้าโค้ง | ขึ้นไปจนถึงหน้าแบนหรือระนาบอ้างอิง |
| รูเคาน์เตอร์ดริล เกลียวนิ้วและเกลียวท่อ เกลียวเรียว การสิ้นสุดของเกลียว และจุดเริ่มเกลียวที่ทำชัมเฟอร์ | เคาน์เตอร์บอร์ที่ความลึกเล็ก; เกลียวเมตริก ISO และเกลียวสี่เหลี่ยมคางหมู ทั้งแบบเขียนแสดงหรือแบบจำลอง: ดู [เกลียวบนเพลาและรู วาดหรือจำลอง](topic:threads) |
| เอ็กซ์ทรูดแบบฟีเจอร์บาง | วาดทั้งสองผนังของโปรไฟล์ |
| ทำสำเนาแพตเทิร์นทีละชิ้น แพตเทิร์นเติม | ใช้ฟีเจอร์แยกกัน; แพตเทิร์นตามเส้นโค้ง: {{ui:Path pattern}} |
| การคัดลอกแพตเทิร์น มิเรอร์ ฟิลเลต ชัมเฟอร์ เชลล์ และโซลิดที่นำเข้า | คัดลอกสเกตช์หรือฟีเจอร์ที่สร้างไว้บน หรือทำแพตเทิร์นของมัน |
| แทนเจนซีที่แม่นยำ (G1) ที่จุดพิเศษของฟอร์ม; การรวมแพตช์ของฟอร์มเป็นหน้าที่ใหญ่ขึ้น | เพิ่ม **Level** ของฟอร์ม แพตช์ที่ประมาณจะเล็กลง: ดู [รูปร่างอิสระด้วยฟอร์ม](topic:form-surfaces) |
| ฟอร์มที่ประกอบจากหลายชิ้นปิดแยกกันในฟีเจอร์เดียว; สะพานระหว่างฟอร์ม | หนึ่งชิ้นปิดต่อหนึ่งฟีเจอร์ฟอร์ม เชื่อมด้วย Join |
| การเลือกบอดี้พื้นผิวในมุมมอง (ยกเว้นจุดของการตัดและแพตช์); ฟิลเลตพื้นผิว; untrim; แพตช์ G2; หน้า Gordon ที่สัมผัสกับหน้าโค้งข้างเคียง (สัมผัสกับระนาบและหน้าแบนสร้างได้แล้ว) | เลือกตามชื่อในพาเนลของฟีเจอร์; ทำ thicken ก่อน แล้วค่อยฟิลเลตโซลิด |
| รายการบอดี้ในประวัติ; การไม่รวมบอดี้ที่ซ่อนไว้ออกจากการส่งออก | เปลี่ยนชื่อและซ่อนบอดี้ในรายการบอดี้ของพาเนลชิ้นส่วน; ลบหรือระงับฟีเจอร์ที่สร้างบอดี้เพื่อไม่ให้รวมออก |
| การปรับสเกลแบบไม่สม่ำเสมอที่คงกระบอกสูบและกรวยเป็นเชิงวิเคราะห์; การปรับสเกลแบบไม่สม่ำเสมอของพื้นผิวออฟเซ็ต | {{ui:Scale body}} ทำให้หน้าโค้งเป็น B-spline ปิด (ภายใน 0.0000004 mm); การปรับสเกลแบบสม่ำเสมอยังคงแม่นยำ |
| การรวมบอดี้พื้นผิว; ผลรวม Minkowski | {{ui:Stitch}} หรือ {{ui:Thicken}} ก่อน แล้วค่อย {{ui:Combine}} |
| การวิเคราะห์ความคลาดเคลื่อน: stack-up ที่หักมุม (ลูปเวกเตอร์ 2D และ 3D) ความไวที่คำนวณจากเรขาคณิต Monte Carlo กับการแจกแจงอื่น ความคลาดเคลื่อนขนาดบนไดเมนชันของสเกตช์ ความคลาดเคลื่อนโบนัสจากสภาพวัสดุ | {{ui:Stack-up}} ในแอสเซมบลี: ทิศทางเดียว กรณีเลวร้ายที่สุดและ RSS พิมพ์ค่าความคลาดเคลื่อนเอง จากความคลาดเคลื่อนทั่วไปของตารางชื่อเรื่องหรือจากกรอบ GD&T: ดู [สแต็กความคลาดเคลื่อน](topic:tolerance-stackup) |
| การจัดวาง: ลำดับการตัดและจุดเริ่มเข้าเส้นตัด (lead-in) การตัดขอบร่วมเพียงครั้งเดียว ชิ้นส่วนที่ต้องเก็บไว้ด้วยกัน; เศษแผ่นของม้วน สต็อกที่ใช้ร่วมระหว่างโปรเจกต์ | {{ui:Nest flat parts on sheets…}} พร้อมระยะห่าง ระยะขอบ การหมุน และทิศทางลาย: ดู [จัดวางชิ้นส่วนแบนลงบนแผ่น](topic:nest-flat-parts); แผ่นเหลือจะถูกเก็บและใช้ก่อน: ดู [เก็บและใช้เศษวัสดุซ้ำ](topic:nest-offcuts); วางแผนการตัดในซอฟต์แวร์ของเครื่องตัดเอง |
| แผ่นโลหะ: ขอบพับ (hem) จ็อก (jog) ไมเตอร์ (miter) และ contour flange; flange บนขอบโค้ง หรือบนหน้าของ base flange ที่โค้ง; การพับแบบร่าง; ปิดมุม; เครื่องมือขึ้นรูป; แปลงโซลิดเป็นแผ่นโลหะ; แพตเทิร์นแบนของ base flange ที่พับแล้วซึ่งมีการตัดอยู่; ตารางการพับ | {{ui:Base flange}} (แผ่นหรือโปรไฟล์ที่พับ), {{ui:Edge flange}} บนขอบตรงของแผ่นพร้อมร่องคลายการพับ และแพตเทิร์นแบนพร้อม K-factor: ดู [แผ่นโลหะ](topic:sheet-metal) |
| การวิเคราะห์ draft บนแอสเซมบลี; การหาเส้นแบ่งแนวถอด (parting line); การวิเคราะห์ความหนาผนัง | {{ui:Draft analysis}} บนชิ้นส่วนใน Design: ดู [ตรวจ draft สำหรับการขึ้นรูปและการหล่อ](topic:draft-analysis); เปิดแต่ละชิ้นส่วนของแอสเซมบลีเพื่อตรวจ |

## สเกตช์

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| วงรี ส่วนโค้งสัมผัส คอนิก สไปลน์ที่มีดีกรีหรือน้ำหนักกำหนดเอง (NURBS) | สไปลน์ (ลูกบาศก์) ส่วนโค้งและวงกลมที่มีความสัมพันธ์ Tangent |
| จุดบนสไปลน์ (ความสัมพันธ์) ความสัมพันธ์ความโค้ง (G2) | วางจุดของสไปลน์เองตรงจุดที่ต้องให้ผ่าน |
| สำเนาออฟเซ็ตของสไปลน์ที่ตามการเปลี่ยนแปลงภายหลัง; ออฟเซ็ตของโซ่ที่มีมุมแหลมของสไปลน์ | ทำออฟเซ็ตใหม่หลังการเปลี่ยนแปลง; ปัดมุมก่อน |
| สำเนาแพตเทิร์นที่ยังเชื่อมกับต้นฉบับ; แพตเทิร์นตามเส้นโค้ง | ทำแพตเทิร์นใหม่หลังการเปลี่ยนแปลง |
| การฉายขอบวงกลมที่เป็นฟรีฟอร์มหรือเอียง, เรขาคณิตที่ฉายซึ่งตามชิ้นส่วน | ฉายขอบวงกลมที่ตรงและขนาน แล้วจึงใส่ไดเมนชัน |
| ไดเมนชันขับเคลื่อน (อ้างอิง) | อ่านขนาดจากพาเนลหรือข้อมูลของชิ้นส่วน |
| ความสัมพันธ์อยู่บนเส้นเดียวกัน (Collinear) | Parallel ที่ระยะ 0 |
| การวางลงในโปรแกรมอื่น (คลิปบอร์ดของระบบ) | ส่งออก DXF, STEP, STL หรือ 3MF |
| การพิมพ์ส่วนโค้ง พิกัดสัมพัทธ์หรือพิกัดขั้ว | พิมพ์เส้นและวงกลม; วาดส่วนโค้งด้วยเครื่องมือส่วนโค้ง |

## การจำลองและการออกแบบเชิงกำเนิด

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| การศึกษาแบบไม่เชิงเส้น: การคราก การโก่งตัวขนาดใหญ่ การสัมผัสระหว่างชิ้นส่วน ความล้า | การคงที่เชิงเส้นและความถี่ธรรมชาติ: ดู [ตรวจความเค้นและการโก่งตัว](topic:simulation); ให้ค่าความปลอดภัยสูงกว่า 1 มาก |
| การโก่งแบบไม่เชิงเส้น (ความไม่สมบูรณ์ หลังการโก่ง การดีดตัว) | ค่าตัวคูณโหลดการโก่งเชิงเส้นพร้อมระยะขอบที่เผื่อไว้มาก: ดู [ความร้อน ความเค้นจากความร้อน และการโก่ง](topic:thermal-and-buckling) |
| การแผ่รังสีระหว่างหน้า (view factors), ความต้านทานการสัมผัส, วัสดุที่ขึ้นกับอุณหภูมิ, ความเฉื่อยในความเค้นจากความร้อน (คลื่นกระแทกความร้อน) | การแผ่รังสีสู่สภาพแวดล้อม ความเค้นจากความร้อนแบบคงที่หรือกึ่งสถิตตามเวลา คุณสมบัติคงที่: ดู [ความร้อน ความเค้นจากความร้อน และการโก่ง](topic:thermal-and-buckling) |
| การปรับปรุงอัตโนมัติสำหรับความร้อนชั่วคราวและการศึกษาที่มีโหลดความร้อน; ทำให้เมชหยาบขึ้นตรงที่ความผิดพลาดน้อย; เป้าหมายบนปริมาณเฉพาะที่ (ความเค้นสูงสุดที่จุดเดียว) | **ปรับปรุงอัตโนมัติ** สำหรับการศึกษาการคงที่ การโก่ง ความถี่ธรรมชาติ และความร้อนคงที่ โดยดูจากความผิดพลาดของชิ้นส่วนทั้งหมด: ดู [ตรวจความเค้นและการโก่งตัว](topic:simulation); มิฉะนั้นให้ลดขนาดองค์ประกอบ |
| โหลดของแบริ่งและสลักเกลียว แรงระยะไกล โมเมนต์ สปริง การกระจัดที่กำหนด | แรงและแรงดันบนหน้า แรงโน้มถ่วง หน้าที่ยึดและหน้าที่ไม่มีแรงเสียดทาน |
| การจำลองแอสเซมบลี; วัสดุที่ต่างกันตามทิศทาง (ชั้นพิมพ์ คอมโพสิต) | ชิ้นส่วนเดียว วัสดุเดียวที่ไอโซทรอปิก |
| ตัวแก้หลายเธรดสำหรับการศึกษาเตตระฮีดรอน การถ่ายเทความร้อน และการออกแบบเชิงกำเนิด; เธรดใดๆ ในหน้าที่ไม่ได้แยกจากต้นกำเนิดข้าม (cross-origin isolated) | การศึกษาแบบวอกเซล การโก่ง ความเค้นตามเวลา และการไหลแบบลามินาร์ใช้เธรดในที่ที่หน้าเว็บอนุญาต: ดู [การตั้งค่า PartCraft](topic:settings) |
| การไหลแบบปั่นป่วนที่มีความแม่นยำเชิงการออกแบบ (แบบจำลอง Spalart–Allmaras อยู่ในฐานะทดลอง: แรงเสียดทานในท่อสูงเกินไป 30 ถึง 34 %, การกลับมาติดที่ขั้นย้อนกลับสั้นลง 21 ถึง 39 %; มีแผนไว้: เซลล์ที่ละเอียดขึ้นใกล้ผนัง), ความร้อนในการไหล, การไหลที่ไม่คงที่ (ตามเวลาจริง), พื้นผิวอิสระ, ของไหลที่ไม่ใช่นิวตัน, ชิ้นส่วนที่หมุน | การไหลแบบลามินาร์ คงที่ ไอโซเทอร์มอล ของของไหลนิวตัน หรือแบบจำลองปั่นป่วนทดลองสำหรับรูปแบบเชิงคุณภาพ: ดู [จำลองการไหลของของไหล](topic:flow-simulation); แผงจะเตือนเมื่อเลขเรย์โนลด์สูงเกินช่วงลามินาร์ |
| ขีดจำกัดความเค้นและกฎการผลิต (มุมยื่น ทิศทางการกัด) ในการออกแบบเชิงกำเนิด; หลายวัสดุในรูปร่างเดียว | รูปร่างที่แข็งที่สุดสำหรับปริมาตร; ตรวจผลลัพธ์ใน Simulation: ดู [สร้างรูปร่างจากโหลด](topic:generative-design) |
| ผลลัพธ์เป็นโซลิดที่แก้ไขได้ (เรียบ เชิงพารามิเตอร์) | STL, STEP แบบเฟเซ็ต หรือชิ้นส่วนที่มีผลลัพธ์เป็นโซลิดเฟเซ็ตที่นำเข้า |
| วิศวกรรมเครื่องจักรไฟฟ้า: โรเตอร์หมุนในสเตเตอร์ แรงบิดเทียบมุม เหล็กอิ่มตัว แม่เหล็กที่สูญเสียความแข็งแรงเมื่อผ่านจุดหัก (knee) กระแสวน และการสูญเสียในเหล็กและทองแดง; สนามแม่เหล็กใน 3 มิติหรือบนเมชโค้ง | แม่เหล็กไฟฟ้าสถิตเชิงเส้น 2 มิติบนกริดในไลบรารีการวิเคราะห์: ขดลวด เหล็ก แม่เหล็กถาวรบนเส้นการคืนตัว ช่องว่าง ความเหนี่ยวนำ และแรงดึง: ดู [สนามแม่เหล็กใน 2 มิติ](topic:magnetic-fields-2d) |

## แอป

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| การบันทึกบนคลาวด์ การแชร์ และประวัติเวอร์ชัน | ยังไม่มี บันทึกไฟล์ลงคอมพิวเตอร์และเก็บเวอร์ชันด้วยชื่อ |
| PartCraft เป็นแอปที่ติดตั้งบน iPad และ iPhone | ใช้ PartCraft ในเบราว์เซอร์ของอุปกรณ์; บน Android และเดสก์ท็อปจะใช้งานได้ใน CadCraft Studio ด้วย (getcadcraft.com/download) |
| เมนูบริบท (คลิกขวา) | แถบเครื่องมือและพาเนลด้านขวา |
| ทำงานเต็มรูปแบบแบบออฟไลน์จากการเริ่มต้นใหม่ | ใช้ได้เฉพาะเมื่อบันทึกแอปไว้สำหรับออฟไลน์แล้ว: ดู [ทำงานแบบออฟไลน์](common:offline) |

แจ้งสิ่งที่ขาดมากที่สุดผ่านหน้าสนับสนุนของเว็บไซต์ ข้อมูลนี้ช่วยกำหนดสิ่งที่จะทำต่อไป

## Engineer (เครื่องกำเนิดและฟิลด์)

| ยังไม่ได้สร้าง | ทำแทนในปัจจุบัน |
|---|---|
| ส่วนหัว พอร์ต และอุปกรณ์เชื่อมต่อบนตัวแลกเปลี่ยนความร้อนที่สร้างขึ้น; เส้นโค้งอุณหภูมิสำหรับความแข็งแรงของวัสดุ; การสูญเสียที่ข้อต่อตัวทีในท่อร่วม | เครื่องกำเนิดสร้างแกนและท่อ; เพิ่มอุปกรณ์เชื่อมต่อใน Design; ใช้ค่าที่อุณหภูมิห้องของวัสดุพร้อมค่าความปลอดภัย |
| การเพิ่มเครื่องกำเนิดจากไดเรกทอรีส่วนเสริมด้วยคลิกเดียว | {{ui:Open}} ในพื้นที่ทำงาน Engineer เพิ่มเครื่องกำเนิดจากไฟล์ |
| ไฟล์ฟิลด์ที่ละเอียดกว่าขนาดวอกเซลของเครื่องกำเนิดเอง; การอ่านไฟล์ `.vdb` | บันทึกฟิลด์ที่ละเอียดกว่าจากสคริปต์; `.vdb` เขียนไฟล์ได้ แต่อ่านไม่ได้ |
| การคำนวณตามมาตรฐานของภาชนะรับแรงดัน | สูตรตำราผนังบางและผนังหนา พร้อมค่าความปลอดภัยที่เลือก; ไม่ใช่ระยะขอบตามมาตรฐาน |
| เครื่องกำเนิดสำหรับแอปอื่น | PartCraft เท่านั้นในรุ่นนี้ |
