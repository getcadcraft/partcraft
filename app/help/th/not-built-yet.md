PartCraft เป็นบิลด์รุ่นแรก ๆ หน้านี้แสดงสิ่งที่ยังไม่ได้ทำ เพื่อไม่ให้คุณต้องค้นหา และสิ่งที่ควรทำแทนในวันนี้ ยังไม่มีกำหนดวันสำหรับสิ่งใดในหน้านี้

## ต้องการเคอร์เนลแม่นยำ

บิลด์นี้สร้างชิ้นงานทุกชิ้นด้วยเคอร์เนลเมช (ดู [เคอร์เนลเมช](topic:solid-kernels)) สิ่งที่อยู่ด้านล่างทั้งหมดต้องการเคอร์เนลเรขาคณิตแม่นยำ ซึ่งบิลด์นี้ยังไม่มี ไฟล์ชิ้นงานที่บันทึกด้วยฟีเจอร์เหล่านี้ยังเปิดได้: ฟีเจอร์จะคงอยู่ในประวัติ มีเครื่องหมายว่ายังไม่ได้สร้าง และจะถูกเก็บไว้เมื่อคุณบันทึก

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| {{ui:ฟิลเลต}} และ {{ui:ชัมเฟอร์}} บนขอบโค้ง; ฟิลเลตที่รัศมีเปลี่ยนไปตามขอบ; ขอบโค้งที่ผสมกันอย่างนุ่มนวลตรงจุดที่มาบรรจบ (เคอร์เนลเมชจะทำมุมตัด (mitre) ให้) | ฟิลเลตและชัมเฟอร์ทำงานบนขอบตรงระหว่างหน้าเรียบ ทำมุมอื่นให้โค้งในสเกตช์ก่อนการ extrude ({{ui:ฟิลเลต}} ในสเกตช์, {{key:F}}) |
| {{ui:เชลล์}} ที่เปิดหน้าโค้ง; ผนังที่มีความหนาต่างกัน | เปิดหน้าเรียบ; เพิ่มวัสดุด้วยการ extrude ตรงที่ผนังต้องหนากว่า |
| {{ui:สวีป}}, {{ui:ลอฟต์}}, {{ui:ดราฟต์}} บนหน้าโค้ง; extrude ขึ้นไปถึงหน้า หน้าถัดไป หรือจุดยอด; extrude แบบเรียว | extrude หรือ revolve เป็นขั้น ๆ ตามที่จำเป็น; extrude ไปยังความลึกที่คุณวัด |
| {{ui:ซี่}}, {{ui:แฟลนจ์ฐาน}}, {{ui:แฟลนจ์ที่ขอบ}} และแพตเทิร์นแบน | extrude แผ่นหรือโปรไฟล์ของซี่ |
| พื้นผิว: การตกแต่ง {{ui:ฟอร์ม}} เข้าไปในชิ้นงาน, {{ui:แพตช์}}, {{ui:ลอฟต์พื้นผิว}}, {{ui:พื้นผิวกอร์ดอน}}, {{ui:เย็บ}}, {{ui:ทำให้หนา}}, {{ui:พื้นผิวออฟเซ็ต}}, {{ui:ขยายพื้นผิว}}, {{ui:ตัดพื้นผิว}} | ไม่มี |
| หลายบอดี้: {{ui:รวม}}, {{ui:ย้ายชิ้นงาน}}, {{ui:ปรับขนาดชิ้นงาน}}, {{ui:แพตเทิร์นตามเส้นทาง}}, ฟีเจอร์ที่สร้างบอดี้ใหม่ | ทรงตันเดียว; แพตเทิร์นและมิเรอร์คัดลอกฟีเจอร์ |
| สเกตช์ ระนาบ แกน และจุดบนหน้าที่เคอร์เนลแม่นยำเท่านั้นหาได้ (หน้าที่สร้างจากฟิลเลต ผนังรู หรือหน้าของโซลิดที่นำเข้า) | สเกตช์บนระนาบฐาน ระนาบอ้างอิง และหน้าเรียบของ extrude และ revolve |
| ผลลัพธ์การออกแบบเชิงสร้างสรรค์ที่เปิดเป็นชิ้นงานหรือเพิ่มเข้าไปในชิ้นงาน (จะกลายเป็นโซลิดที่นำเข้า) | ดาวน์โหลดผลลัพธ์เป็น STL หรือ STEP |
| การแก้ไขหน้าโค้งของไฟล์ STEP ที่เปิดเป็นผิวแม่นยำ; STEP แม่นยำของหน้าแบบสไปลน์ สวีป และ revolve จากไฟล์ STEP, ด้านสไปลน์, เกลียวที่สร้างแบบจำลอง, บอดี้ STL / OBJ / 3MF และแอสเซมบลี; STEP สำหรับโปรแกรมโมเดลชิ้นส่วนอื่น | {{ui:เปิด}} อ่าน STEP เป็นสามเหลี่ยม และคงหน้าเรียบ ทรงกระบอก กรวย ทรงกลม และทอรัสของไฟล์ไว้สำหรับการส่งออก ([เปิดไฟล์ STEP](topic:import-step)); {{ui:ส่งออก}} › {{ui:STEP AP242 (ทรงตันแม่นยำ)}} เขียนทุกหน้าเชิงวิเคราะห์อย่างแม่นยำและคงหน้าเหล่านั้นเป็นแฟเซต ([ส่งออก](topic:export-files#for-other-cad-programs-step)); มาโครสำหรับโปรแกรมโมเดลชิ้นส่วนอื่นยังเขียนได้ |
| ส่วนโค้งจริงในมุมมองแบบ | มุมมองและมุมมองภาพตัดถูกวาดจากแฟเซต |
| ปริมาตร พื้นที่ และระยะที่แม่นยำ | {{ui:วัด}} ให้ค่าของโซลิดแบบแฟเซต ซึ่งต่ำกว่าค่าจริงเล็กน้อยบนชิ้นส่วนกลม; ตั้งค่า **Curves** ให้ละเอียดขึ้นเพื่อให้ค่าใกล้ขึ้น |

บางแถวในตารางด้านล่างแนะนำฟีเจอร์เหล่านี้เป็นทางเลือกแทนสิ่งอื่น คำแนะนำเหล่านั้นจะใช้ได้เมื่อเคอร์เนลแม่นยำกลับมาแล้ว

## ฟีเจอร์

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| ฟิลเลตหน้า ฟิลเลตกลมเต็มวง ฟิลเลตที่มีรัศมีกำหนดที่จุดตามขอบ | {{ui:ฟิลเลต}} แบบรัศมีคงที่หรือรัศมีเปลี่ยนเป็นเส้นตรง; หลายฟีเจอร์ฟิลเลต |
| เชลล์ที่ผนังมีความหนาต่างกัน | {{ui:เชลล์}} ความหนาเดียว; เพิ่มวัสดุด้วย extrude ตรงที่ผนังต้องหนากว่า |
| ดราฟต์บนหน้าอิสระ (สไปลน์) | {{ui:ดราฟต์}} ทำงานบนหน้าเรียบ ทรงกระบอก และกรวย |
| สวีปแบบบิด สวีปผนังบางและสวีปพื้นผิว การสัมผัสปลายในฟีเจอร์ Loft; loft ที่มีรางนำหนึ่งราง; เส้นทางสไปลน์ | {{ui:สวีป}} ที่ทิศทางคงที่หรือสเกลปลาย; loft ที่มีรางนำสองรางขึ้นไป: ดู [สวีป ลอฟต์ และดราฟต์](topic:sweep-loft-draft) |
| ซี่จากส่วนโค้งหรือสไปลน์; ซี่ที่ขยายตั้งฉากกับสเกตช์ (จากมุมมองด้านบน); ดราฟต์บนซี่; หลายซี่จากสเกตช์เดียว | {{ui:ซี่}} จากโซ่เส้นตรงหนึ่งโซ่ในระนาบของซี่เอง: ดู [ซี่และแผ่นยึดมุม](topic:rib) |
| "ขึ้นถึง" ผิวโค้ง "ขึ้นถึงถัดไป" ที่หยุดหน้าโค้ง | ขึ้นถึงหน้าเรียบหรือระนาบอ้างอิง |
| รูคาวน์เตอร์ดริลล์ เกลียวนิ้วและเกลียวท่อ เกลียวเรียว ปลายเกลียวที่หยุด และจุดเริ่มเกลียวที่ชัมเฟอร์ | Counterbore ที่ความลึกเล็ก; เกลียว ISO เมตริกและทราพีโซอิดาล แบบ cosmetic หรือแบบจำลอง: ดู [เกลียวบนเพลาและรู](topic:threads) |
| extrude ฟีเจอร์บาง | วาดทั้งสองผนังของโปรไฟล์ |
| การข้ามสำเนาแพตเทิร์นทีละชิ้น แพตเทิร์นเติม | ใช้ฟีเจอร์แยกกัน; แพตเทิร์นตามเส้นโค้ง: {{ui:แพตเทิร์นตามเส้นทาง}} |
| การคัดลอกแพตเทิร์น มิเรอร์ ฟิลเลต ชัมเฟอร์ เชลล์ และโซลิดที่นำเข้า | คัดลอกสเกตช์หรือฟีเจอร์ที่มันสร้างขึ้น หรือทำแพตเทิร์นมัน |
| การสัมผัสแม่นยำ (G1) ที่จุดพิเศษของฟอร์ม; รวมแพตช์ของฟอร์มเป็นหน้าที่ใหญ่ขึ้น | เพิ่ม Level ของฟอร์ม: แพตช์ประมาณจะเล็กลง; ดู [รูปทรงอิสระด้วย Form](topic:form-surfaces) |
| ฟอร์มที่ประกอบจากหลายชิ้นปิดแยกกันในฟีเจอร์เดียว; สะพานระหว่างฟอร์ม | ฟอร์มหนึ่งชิ้นปิดต่อหนึ่งฟีเจอร์ Form; เชื่อมเข้าด้วยกันด้วย Join |
| เลือกบอดี้พื้นผิวในมุมมอง (ยกเว้นจุดตัดและจุดแพตช์); ฟิลเลตพื้นผิว; untrim; แพตช์ G2; พื้นผิวกอร์ดอนที่สัมผัสกับเพื่อนบ้านโค้ง (สัมผัสกับระนาบและหน้าเรียบสร้างได้แล้ว) | เลือกตามชื่อในแผงของฟีเจอร์; ทำให้หนาก่อน แล้วฟิลเลตโซลิด |
| รายการบอดี้ในประวัติ; การไม่รวมบอดี้ที่ซ่อนออกจากการส่งออก | เปลี่ยนชื่อและซ่อนบอดี้ในรายการบอดี้ของแผงชิ้นงาน; ลบหรือระงับฟีเจอร์ที่สร้างบอดี้เพื่อไม่ให้รวม |
| การสเกลไม่สม่ำเสมอที่คงทรงกระบอกและกรวยเชิงวิเคราะห์; การสเกลไม่สม่ำเสมอของพื้นผิวออฟเซ็ต | {{ui:ปรับขนาดชิ้นงาน}} ทำให้ผิวโค้งกลายเป็น B-spline ที่ปิด (ภายใน 0.0000004 mm); สเกลสม่ำเสมอยังคงแม่นยำ |
| รวมบอดี้พื้นผิว; ผลบวกมิงคอฟสกี (Minkowski sums) | {{ui:เย็บ}} หรือ {{ui:ทำให้หนา}} ก่อน แล้ว {{ui:รวม}} |
| การวิเคราะห์ความคลาดเคลื่อน: การสะสมที่หักมุม (ลูปเวกเตอร์ 2 มิติและ 3 มิติ) ความไวที่คำนวณจากรูปทรงเรขาคณิต Monte Carlo ด้วยการแจกแจงอื่น ความคลาดเคลื่อนขนาดบนไดเมนชันสเกตช์ ความคลาดเคลื่อนโบนัสจากสภาพวัสดุ | {{ui:การสะสมความคลาดเคลื่อน}} ในแอสเซมบลี: ทิศทางเดียว กรณีเลวร้ายที่สุด และ RSS พิมพ์ความคลาดเคลื่อนเอง จากความคลาดเคลื่อนทั่วไปของบล็อกชื่อเรื่องหรือจากกรอบ GD&T: ดู [การสะสมความคลาดเคลื่อน](topic:tolerance-stackup) |
| การจัดวาง: ลำดับการตัดและส่วนนำเข้า การตัดขอบร่วมครั้งเดียว ชิ้นส่วนที่ต้องเก็บไว้ด้วยกัน; เศษม้วน วัตถุดิบที่ใช้ร่วมกันระหว่างโปรเจกต์ | {{ui:จัดวางชิ้นส่วนแบนลงบนแผ่น…}} พร้อมระยะห่าง ขอบ การหมุน และทิศเสี้ยน: ดู [จัดวางชิ้นส่วนแบนลงบนแผ่น](topic:nest-flat-parts); เศษแผ่นที่เหลือจะถูกเก็บและใช้ก่อน: ดู [เก็บและใช้เศษที่ตัดเหลือ](topic:nest-offcuts); วางแผนการตัดในซอฟต์แวร์ของเครื่องตัดของคุณเอง |
| แผ่นโลหะ: ขอบพับ (hem) ขั้นบันได (jog) แฟลนจ์มิเตอร์และคอนทัวร์; แฟลนจ์บนขอบโค้งหรือบนหน้าของแฟลนจ์ฐานที่งอ; การพับที่วาดด้วยสเกตช์; การปิดมุม; เครื่องมือขึ้นรูป; การแปลงโซลิดเป็นแผ่นโลหะ; แพตเทิร์นแบนของแฟลนจ์ฐานที่งอและมีการตัด; ตารางการพับ | {{ui:แฟลนจ์ฐาน}} (แผ่นหรือโปรไฟล์ที่งอ), {{ui:แฟลนจ์ที่ขอบ}} บนขอบเส้นตรงของแผ่นพร้อมร่องคลายการพับ และแพตเทิร์นแบนด้วยตัวประกอบ K: ดู [แผ่นโลหะ](topic:sheet-metal) |
| การวิเคราะห์ดราฟต์บนแอสเซมบลี การหาเส้นแบ่งแม่พิมพ์ การวิเคราะห์ความหนาผนัง | {{ui:การวิเคราะห์ดราฟต์}} กับชิ้นส่วนในพื้นที่ออกแบบ: ดู [ตรวจดราฟต์สำหรับการขึ้นรูปและการหล่อ](topic:draft-analysis); เปิดแต่ละชิ้นส่วนของแอสเซมบลีเพื่อตรวจ |

## สเกตช์

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| วงรี ส่วนโค้งสัมผัส คอนิก สไปลน์ที่มีดีกรีหรือน้ำหนักที่กำหนด (NURBS) | สไปลน์ (คิวบิก) ส่วนโค้งและวงกลมที่มีความสัมพันธ์แบบสัมผัส |
| จุดบนสไปลน์ (ความสัมพันธ์) ความสัมพันธ์ความโค้ง (G2) | วางจุดของสไปลน์เองตรงที่ต้องให้ผ่าน |
| สำเนาออฟเซ็ตของสไปลน์ที่ตามการเปลี่ยนแปลงภายหลัง; ออฟเซ็ตของโซ่ที่มีมุมสไปลน์แหลม | ออฟเซ็ตใหม่หลังการเปลี่ยนแปลง; ทำมุมให้โค้งก่อน |
| สำเนาแพตเทิร์นที่ยังเชื่อมกับต้นฉบับ; แพตเทิร์นตามเส้นโค้ง | ทำแพตเทิร์นใหม่หลังการเปลี่ยนแปลง |
| ฉายเรขาคณิตขอบวงกลมอิสระหรือเอียง เรขาคณิตที่ฉายซึ่งตามชิ้นงาน | ฉายขอบวงกลมที่ตรงและขนานกัน แล้วใส่ไดเมนชัน |
| ไดเมนชันแบบขับ (อ้างอิง) | อ่านขนาดจากแผงหรือข้อมูลของชิ้นงาน |

## การจำลองและการออกแบบเชิงสร้างสรรค์

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| การศึกษาไม่เชิงเส้น: การคราก การโก่งขนาดใหญ่ การสัมผัสระหว่างชิ้นส่วน ความล้า | สถิตเชิงเส้นและความถี่ธรรมชาติ: ดู [ตรวจความเค้นและการโก่ง](topic:simulation); รักษาค่าปัจจัยความปลอดภัยให้สูงกว่า 1 มาก |

| การแผ่รังสีระหว่างหน้า (view factor) ความต้านทานการสัมผัส คุณสมบัติวัสดุที่ขึ้นกับอุณหภูมิ ความเฉื่อยในความเค้นจากความร้อน (คลื่นกระแทกจากความร้อน) | การแผ่รังสีสู่สภาพแวดล้อม ความเค้นจากความร้อนแบบคงที่หรือกึ่งสถิตตามเวลา คุณสมบัติคงที่: ดู [ความร้อน ความเค้นจากความร้อน และการโก่ง](topic:thermal-and-buckling) |

| การออกแบบเครื่องจักรไฟฟ้า: โรเตอร์ที่หมุนในสเตเตอร์ แรงบิดเทียบมุม เหล็กที่อิ่มตัว แม่เหล็กที่สูญเสียความแรงเมื่อเกินจุดหัก กระแสวน และการสูญเสียเหล็กและทองแดง; สนามแม่เหล็กในสามมิติหรือบนเมชโค้ง | แม่เหล็กไฟฟ้าสถิตสองมิติเชิงเส้นบนตารางในคลังการวิเคราะห์: ขดลวด เหล็ก แม่เหล็กถาวรบนเส้นการคืนตัว ช่องว่าง ความเหนี่ยวนำ และแรงดูด: ดู [สนามแม่เหล็กในสองมิติ](topic:magnetic-fields-2d) |

| ข้อความช่วยเหลือเมื่อชี้ เบรกพอยต์ และการก้าวทีละขั้นในตัวแก้ไขสคริปต์ | การค้นหา พับ และเติมให้ครบมีแล้ว (ดู [เขียนและรันสคริปต์](topic:craftscript)); ส่วนที่เหลือใช้ตัวแก้ไขของคุณเอง: {{ui:บันทึก}} และ {{ui:เปิด}} ในกลุ่มสคริปต์ย้ายสคริปต์เข้าและออก; ฟังก์ชันในตัวแสดงอยู่ใน [ภาษา CraftScript](topic:craftscript-language) |
| เบรกพอยต์และการก้าวทีละขั้นในสคริปต์ | `disp` และ `fprintf` ระหว่างทาง; {{key:Mod+Enter}} รันบางบรรทัดที่เลือกทีละครั้ง |
| ฟิลด์และกราฟที่สคริปต์แสดงที่วาดในพื้นที่ออกแบบ; สคริปต์ที่เปลี่ยนพารามิเตอร์ของชิ้นงาน | แสดงในพื้นที่สคริปต์; สคริปต์อ่านพารามิเตอร์ด้วย `param` (ดู [เขียนและรันสคริปต์](topic:craftscript)) และเปลี่ยนค่าในแท็บ {{ui:พารามิเตอร์}} |
| รูปและตารางคู่กับกราฟ; แก้ไขกราฟ (ซูม ขีดจำกัดแกน) ก่อนบันทึก | วางกราฟเคียงกันได้; บันทึกกราฟเป็น PNG, SVG หรือ CSV แล้วตกแต่งต่อที่อื่น |
| numpy และแพ็กเกจ Python อื่น; Python แบบออฟไลน์; การพับ Python ในตัวแก้ไข; Pascal Script | ไลบรารีมาตรฐานของ Python, CraftScript และ Lua: ดู [สคริปต์ใน Python](topic:craftscript-python) |
| ส่งฟังก์ชัน Lua ไปยังฟังก์ชันในตัว; เรียกฟังก์ชันไลบรารีจาก Lua ด้วยชื่อที่สร้างขึ้นระหว่างการรันสคริปต์ | เขียนชื่อฟังก์ชันไลบรารีในสคริปต์ (`cs.static_tet(…)`) หรือเรียกจากสคริปต์ CraftScript |

## แอป

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| การบันทึกบนคลาวด์ การแชร์ และประวัติเวอร์ชัน | ยังไม่มี บันทึกไฟล์ไว้ในคอมพิวเตอร์และเก็บเวอร์ชันด้วยชื่อ |
| PartCraft เป็นแอปที่ติดตั้งบน iPad และ iPhone | ใช้ PartCraft ในเบราว์เซอร์ของอุปกรณ์; บน Android และเดสก์ท็อปยังรันใน CadCraft Studio ได้ด้วย (getcadcraft.com/download) |
| เมนูคลิกขวา (คอนเท็กซ์) | แถบเครื่องมือและแผงด้านขวา |
| ทำงานได้เต็มรูปแบบแบบออฟไลน์จากการเริ่มใหม่ | เฉพาะเมื่อบันทึกแอปไว้ใช้แบบออฟไลน์แล้ว: ดู [การทำงานแบบออฟไลน์](common:offline) |

แจ้งสิ่งที่คุณคิดถึงมากที่สุดผ่านหน้าสนับสนุนของเว็บไซต์: มันกำหนดสิ่งที่จะมาต่อไป

## วิศวกรรม (ตัวสร้างและสนาม)

| ยังไม่ได้สร้าง | แทนที่ด้วยวิธีในวันนี้ |
|---|---|
| หัว พอร์ต และข้อต่อบนตัวแลกเปลี่ยนความร้อนที่สร้างขึ้น; เส้นโค้งอุณหภูมิสำหรับความแข็งแรงของวัสดุ; การสูญเสียที่ทีในท่อร่วม | ตัวสร้างสร้างแกนกลางและท่อ; เพิ่มข้อต่อใน Design; ใช้ค่าที่อุณหภูมิห้องของวัสดุพร้อมปัจจัยความปลอดภัย |
| เพิ่มตัวสร้างจากไดเรกทอรีส่วนเสริมด้วยคลิกเดียว | {{ui:เปิด}} ในพื้นที่ทำงานวิศวกรรมเพื่อเพิ่มตัวสร้างจากไฟล์ |
| ไฟล์ฟิลด์ที่ละเอียดกว่าขนาดวอกเซลของตัวสร้างเอง; การอ่านไฟล์ `.vdb` | บันทึกฟิลด์ที่ละเอียดกว่าจากสคริปต์; `.vdb` เขียนได้อย่างเดียว ไม่อ่าน |
| การคำนวณรหัสภาชนะรับแรงดัน | สูตรผนังบางและผนังหนาในตำรา พร้อมปัจจัยความปลอดภัยที่คุณเลือก; ไม่ใช่ส่วนเผื่อตามรหัส |
| ตัวสร้างสำหรับแอปอื่น | PartCraft เท่านั้นในรุ่นนี้ |
