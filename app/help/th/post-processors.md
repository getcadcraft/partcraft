เส้นทางเครื่องมือเดียวกันต้องถูกเขียนต่างกันสำหรับตัวควบคุมต่างกัน: จะมีหรือไม่มีหมายเลขบรรทัด ใช้ `M6` หรือการหยุดชั่วคราว ใช้ `G28` หรือ `G53` ใช้ `M30` หรือ `M2` **โพสต์** คือข้อความสั้นที่บอกว่าต้องเขียนอย่างไร โพสต์ในตัวสามตัวของ PartCraft (แบบ Fanuc, GRBL และ LinuxCNC) เขียนด้วยรูปแบบนี้ ดังนั้นโพสต์ของคุณเองจึงเริ่มจากการคัดลอกตัวใดตัวหนึ่งได้

ตรวจผลลัพธ์ในโปรแกรมจำลองของเครื่องคุณก่อนตัด และให้เครื่องวิ่งในอากาศเหนือวัสดุก่อน โพสต์ในตัวเขียนสิ่งเดียวกับที่เคยเขียนก่อนมีรูปแบบนี้ (การทดสอบเปรียบเทียบผลลัพธ์ทีละไบต์กับโปรแกรมหลายร้อยโปรแกรม) แต่ยังไม่มีอะไรที่พิสูจน์แล้วบนเครื่องของคุณ และโพสต์ที่คุณแก้ไขเป็นของคุณ ที่ต้องพิสูจน์เอง

## สร้างโพสต์

ในการผลิต ภายใต้ **โพสต์**:

- {{ui:Edit post…}} บนตัวควบคุมในตัวจะเปิด**สำเนาของคุณเอง**ของมัน ถ้าเป็นโพสต์ของคุณเองจะเปิดโพสต์นั้น
- {{ui:New post…}} เริ่มจากโพสต์ว่างขนาดเล็กที่มีทุกเหตุการณ์
- {{ui:Import post file…}} อ่านไฟล์ข้อความ `.cpost` (ไฟล์ที่ได้จาก **บันทึกเป็นไฟล์…** ในตัวแก้ไข)

ตัวแก้ไขจะแสดงข้อความ บรรทัดที่บอกว่าอ่านได้หรือไม่ (และบรรทัดไหนผิด) และ G-code ที่โพสต์เขียน ขณะที่คุณพิมพ์ **ดูตัวอย่างด้วย** เลือกโปรแกรมตัวอย่างขนาดเล็กที่รันทุกเหตุการณ์ หรือโปรแกรมของชิ้นส่วนนี้เอง {{ui:Save}} เก็บโพสต์ไว้ในไฟล์ของชิ้นส่วน (สูงสุด 20 โพสต์) และเลือกเป็นตัวควบคุม โพสต์เดินทางไปกับชิ้นส่วน หากต้องการใช้ในชิ้นส่วนอื่น ให้บันทึกเป็นไฟล์แล้วนำเข้าที่นั่น

## โพสต์หน้าตาเป็นอย่างไร

```
post mymill
name เครื่องมิลของฉัน (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

บรรทัดที่ขึ้นต้นด้วย `//` และบรรทัดว่างจะถูกข้าม ตอนต้นคือการตั้งค่า จากนั้นเป็นบล็อก `on <event>` หนึ่งบล็อกต่อเหตุการณ์หนึ่ง ปิดด้วย `end` เหตุการณ์ที่คุณไม่ใส่จะไม่เขียนอะไรออกมา

| การตั้งค่า | ความหมาย |
|---|---|
| `post <id>` | รหัสของโพสต์: ตัวอักษร ตัวเลข `-` และ `_` |
| `name <text>` | สิ่งที่รายการตัวควบคุมแสดง |
| `extension <ext>` | นามสกุลไฟล์: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … ในทุกบรรทัด `emit` หรือไม่มีเลย |
| `decimal-point yes` / `no` | `10.` แทน `10` (คอมเมนต์ไม่เคยมีจุด) |
| `canned-cycles yes` / `no` | `no`: รูจะถูกเขียนเป็นการเคลื่อนที่ G0/G1 ที่มันแทน |
| `modal <group> <words>` | คำในกลุ่ม (`modal motion G0 G1 G2 G3`) ที่เขียนเฉพาะเมื่อมีการเปลี่ยน |

## เหตุการณ์

ทำงานตามลำดับนี้สำหรับโปรแกรมหนึ่ง: `start`; จากนั้นสำหรับแต่ละการทำงาน `operation`, `tool-change` (เมื่อเครื่องมือเปลี่ยน), `spindle` (เมื่อความเร็วเปลี่ยน), `approach` (การเคลื่อนขึ้นไปจุดแรก ก่อน rapid แรก), `coolant-on`, แล้วการเคลื่อนที่ของมันเป็น `rapid`, `feed` และ `arc` และแต่ละวงจรสำเร็จรูปเป็น `cycle-start` ตามด้วย `cycle-hole` หนึ่งครั้งต่อรู และ `cycle-end`; สุดท้ายคือ `end`

แต่ละเหตุการณ์ใช้ตัวแปรของการเคลื่อนที่ชนิดของมันได้ เขียนเป็น `{name}`: ของโปรแกรม (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), ของวัตถุดิบ (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), ของเครื่องมือ (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ของการทำงาน (`op.name`, `op.type`), `rpm`, จุดของการเคลื่อนที่ (`x`, `y`, `z`, `f` และ `moved`: เป็นจริงเมื่อแกนใดแกนหนึ่งเปลี่ยน), ส่วนโค้ง (`arc.g` 2 หรือ 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) และรู (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`) รายการ **เหตุการณ์และตัวแปร** ในตัวแก้ไขแสดงว่าเหตุการณ์ใดเห็นอะไร สถานะที่อ่านและตั้งค่าได้: `cool`, `offset`, และ `at.x`, `at.y`, `at.z`, `at.f` (ค่าที่เขียนล่าสุด)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `raw TEXT` | บรรทัดตามที่พิมพ์เป๊ะ (ไม่มีหมายเลขบรรทัด) |
| `comment TEXT` | `(TEXT)` โดยตัดอักขระที่ไม่ใช่ ASCII และวงเล็บออก |
| `emit WORD WORD …` | บรรทัดของคำ; คำที่ว่างเมื่อประมวลผลจะถูกตัดออก; ไม่มีคำก็ไม่มีบรรทัด |
| `word WORD …` | เพิ่มคำลงในบรรทัดที่กำลังสร้าง; `emit` เปล่าจะจบบรรทัด |
| `if EXPR` … `else` … `end` | เงื่อนไข: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a ถ้าไม่มีให้ใช้ b) |
| `for tool in tools` … `end` | ทำครั้งเดียวสำหรับเครื่องมือแต่ละชิ้นที่โปรแกรมใช้ |
| `set NAME EXPR` | จดจำค่า (`set offset tool.number`) |
| `reset NAME …` | ลืมคำโมดอล (กลุ่ม ตัวอักษรที่อยู่ เช่น `Z` หรือ `at.z`) |
| `do rapid X Y Z` | รันเหตุการณ์ `rapid` สำหรับจุดหนึ่ง |

คำคือข้อความที่พิมพ์ พร้อมช่อง `{variable|filter}` ตัวกรองคือ `upper`, `lower`, `pad:N` (เติมศูนย์), `cut:N` (N ตัวอักษรแรก), `safe` (ASCII ที่ปลอดคอมเมนต์) และ `int` คำที่ลงท้ายด้วย `~` เป็น **โมดอล**: จะเขียนเฉพาะเมื่อต่างจากที่เขียนล่าสุด (`G1~`, `X{x}~`) คำที่ลงท้ายด้วย `~!` จะเขียนทุกครั้งและยังจดจำอยู่ ชื่อที่ไม่ใช่ตัวแปรเป็นข้อความธรรมดา (`G81`, `mist`) ตัวเลขถูกปัดเป็น 0.001 mm และเขียนโดยไม่มีศูนย์ท้าย

## สิ่งที่โพสต์ทำไม่ได้

โพสต์กำหนดเพียงวิธีเขียนการเคลื่อนที่ ไม่มากกว่านั้น มันเปลี่ยนเส้นทางเครื่องมือไม่ได้ จัดลำดับการทำงานไม่ได้ แบ่งส่วนโค้งไม่ได้ เพิ่มแกนไม่ได้ ไม่รู้ระยะเดินทางหรือจลนศาสตร์ของเครื่องคุณ และคำนวณกับพิกัดไม่ได้ (ไม่มี `+`) การโพรบ วงจรอายุเครื่องมือและวงจรโปรแกรมย่อย ผลลัพธ์แกนที่ 4 และ 5 และโค้ดเครื่องกลึงยังไม่ได้สร้าง ไฟล์โพสต์แบบ `.cps` จากโปรแกรมอื่นโหลดไม่ได้: นี่เป็นรูปแบบที่ต่างและเรียบง่ายกว่า
