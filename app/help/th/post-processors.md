เส้นทางเครื่องมือเดียวกันต้องถูกเขียนต่างกันสำหรับตัวควบคุมต่างกัน: มีหรือไม่มีหมายเลขบรรทัด `M6` หรือการหยุดชั่วคราว `G28` หรือ `G53` `M30` หรือ `M2` **โพสต์** คือข้อความสั้น ๆ ที่บอกวิธี โพสต์ที่มีในตัวของ PartCraft สามตัว (Fanuc-style, GRBL และ LinuxCNC) เขียนในรูปแบบนี้ ดังนั้นโพสต์ของคุณเองสามารถเริ่มจากการคัดลอกหนึ่งในนั้น

ตรวจผลลัพธ์ในโปรแกรมจำลองของเครื่องจักรของคุณก่อนตัด และรันในอากาศเหนือวัตถุดิบก่อน โพสต์ที่มีในตัวเขียนสิ่งเดียวกับที่เขียนก่อนรูปแบบนี้มีอยู่ (การทดสอบเปรียบเทียบผลลัพธ์ทีละไบต์บนหลายร้อยโปรแกรม) แต่ยังไม่มีสิ่งใดที่นี่ได้รับการพิสูจน์บนเครื่องของคุณ และโพสต์ที่คุณเปลี่ยนเป็นของคุณที่ต้องพิสูจน์เอง

## สร้างโพสต์

ในการผลิต ภายใต้ **โพสต์**:

- {{ui:แก้ไขโพสต์…}} บนตัวควบคุมที่มีในตัวจะเปิด**สำเนาของคุณเอง**ของตัวนั้น บนโพสต์ของคุณเองจะเปิดโพสต์นั้น
- {{ui:โพสต์ใหม่…}} เริ่มจากโพสต์เปล่าขนาดเล็กที่มีทุกเหตุการณ์อยู่
- {{ui:นำเข้าไฟล์โพสต์…}} อ่านไฟล์ข้อความ `.cpost` (ไฟล์ที่คุณได้จาก **บันทึกเป็นไฟล์…** ในตัวแก้ไข)

ตัวแก้ไขแสดงข้อความ บรรทัดที่บอกว่าอ่านได้หรือไม่ (และบรรทัดใดผิด) และ G-code ที่โพสต์เขียนขณะที่คุณพิมพ์ **แสดงตัวอย่างด้วย** เลือกโปรแกรมตัวอย่างขนาดเล็กที่รันทุกเหตุการณ์ หรือโปรแกรมของชิ้นงานนี้เอง {{ui:บันทึก}} เก็บโพสต์ในไฟล์ของชิ้นงาน (สูงสุด 20 โพสต์) และเลือกเป็นตัวควบคุม โพสต์ไปพร้อมกับชิ้นงาน; หากต้องการใช้ในชิ้นงานอื่น ให้บันทึกเป็นไฟล์แล้วนำเข้าที่นั่น

## หน้าตาของโพสต์

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

บรรทัดที่ขึ้นต้นด้วย `//` และบรรทัดว่างจะถูกข้าม ด้านบนคือการกำหนดค่า ตามด้วยบล็อก `on <event>` หนึ่งบล็อกสำหรับแต่ละเหตุการณ์ ปิดด้วย `end` เหตุการณ์ที่คุณไม่ใส่จะไม่เขียนอะไร

| การกำหนดค่า | ความหมาย |
|---|---|
| `post <id>` | รหัสของโพสต์: ตัวอักษร ตัวเลข `-` และ `_` |
| `name <text>` | ที่รายการตัวควบคุมแสดง |
| `extension <ext>` | นามสกุลไฟล์: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … ในทุกบรรทัด `emit` หรือไม่มีเลย |
| `decimal-point yes` / `no` | `10.` แทน `10` (คอมเมนต์ไม่มีจุดทศนิยมเลย) |
| `canned-cycles yes` / `no` | `no`: รูถูกเขียนเป็นการเคลื่อนที่ G0/G1 ที่มันแทน |
| `modal <group> <words>` | คำของกลุ่ม (`modal motion G0 G1 G2 G3`) ที่เขียนเฉพาะเมื่อเปลี่ยน |

## เหตุการณ์

เหตุการณ์ทำงานตามลำดับนี้สำหรับโปรแกรม: `start`; จากนั้นสำหรับแต่ละการทำงาน `operation`, `tool-change` (เมื่อเครื่องมือเปลี่ยน), `spindle` (เมื่อความเร็วเปลี่ยน), `approach` (การเคลื่อนที่ขึ้นไปยังจุดแรก ก่อน rapid แรก), `coolant-on`, แล้วการเคลื่อนที่ของมันเป็น `rapid`, `feed` และ `arc` และแต่ละวงจรสำเร็จรูปเป็น `cycle-start`, `cycle-hole` หนึ่งครั้งต่อรู และ `cycle-end`; สุดท้ายคือ `end`

เหตุการณ์เพิ่มเติม สำหรับสิ่งที่เกินสามแกน (โพสต์ที่ไม่มีเหตุการณ์นี้จะปฏิเสธโปรแกรมดังกล่าวและระบุเหตุการณ์ที่ขาด):

| เหตุการณ์ | เมื่อใด | ตัวแปรของมัน |
|---|---|---|
| `index` | ก่อนการทำงานที่ทิศทางเครื่องมือต่างจากครั้งก่อน และก่อนการทำงานแรกบนเครื่องที่มีแกนหมุน | `rot.a`, `rot.b`, `rot.c` (ตำแหน่งที่จะไป ว่างสำหรับแกนที่เครื่องไม่มี), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | การเคลื่อนที่ของการทำงานที่แกนหมุนเคลื่อนขณะตัด | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (yes เมื่อต้องป้อนเป็นเวลาผกผัน), `invf` (1/นาที) |
| `rotary-end` | หลังการทำงานดังกล่าว | |
| `probe-move` | การเคลื่อนที่ที่หยุดเมื่อโพรบทริกเกอร์ | `x`, `y`, `z`, `f`, `probe.n` (1 ถึง 4), `probe.axis` (x, y หรือ z), `probe.k` (1, 2 หรือ 3) |
| `probe-set` | หลังการแตะของรอบโพรบหนึ่งรอบ | `probe.kind` (`"z"`, `"x"`, `"y"` หรือ `centre`), `probe.action` (`set` หรือ `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | การเคลื่อนที่เกลียวบนเครื่องกลึง | `x`, `z`, `thread.lead` |

สำหรับทุกเหตุการณ์ด้วย: `kin` (none, a, b, ac, bc), `rotary` และ `tcp` (yes หรือ no จากเครื่องใน Setup), `pivot.x`, `pivot.y`, `pivot.z`, `op.tilt` และ `op.turn` ของการทำงาน และบนเครื่องกลึง `spin.mode` (css หรือ rpm), `spin.css`, `spin.max` และ `tool.nose` คำที่มีตัวอักษรซึ่งค่าว่าง เช่น `A{rot.a}` บนเครื่องที่ไม่มีแกน A จะถูกนำออกจากบรรทัด เปรียบเทียบกับ x, y และ z เป็นข้อความในเครื่องหมายคำพูด (`if probe.kind == "z"`): เมื่อเขียนเปล่า ๆ มันคือพิกัดของการเคลื่อนที่

สองบรรทัดเพิ่มที่ด้านบนของโพสต์ทำให้มันเป็นโพสต์เครื่องกลึง: `machine lathe` (แล้วมันจะเขียนเฉพาะ X และ Z และปฏิเสธเส้นทางการกัด เหมือนโพสต์กัดที่ปฏิเสธเส้นทางกลึง) และ `lathe-x diameter` หรือ `lathe-x radius`

แต่ละเหตุการณ์ใช้ตัวแปรของชนิดการเคลื่อนที่ของตนเองได้ เขียนเป็น `{name}`: ของโปรแกรม (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), ของวัตถุดิบ (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` ถึง `stock.maxz`), ของเครื่องมือ (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ของการทำงาน (`op.name`, `op.type`), `rpm`, ของจุดในการเคลื่อนที่ (`x`, `y`, `z`, `f` และ `moved`: true เมื่อแกนใดเปลี่ยน), ของส่วนโค้ง (`arc.g` 2 หรือ 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) และของรู (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`) รายการ **เหตุการณ์และตัวแปร** ของตัวแก้ไขแสดงว่าเหตุการณ์ใดเห็นตัวแปรใด สถานะที่อ่านและตั้งค่าได้: `cool`, `offset`, และ `at.x`, `at.y`, `at.z`, `at.f` (ค่าที่เขียนล่าสุด)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `raw TEXT` | บรรทัดตามที่พิมพ์ทุกตัวอักษร (ไม่มีหมายเลขบรรทัด) |
| `comment TEXT` | `(TEXT)` โดยตัดอักษรที่ไม่ใช่ ASCII และวงเล็บออก |
| `emit WORD WORD …` | บรรทัดของคำ; คำที่ออกมาว่างจะถูกนำออก; ไม่มีคำ ไม่มีบรรทัด |
| `word WORD …` | เพิ่มคำลงในบรรทัดที่กำลังสร้าง; `emit` เปล่า ๆ จบบรรทัด |
| `if EXPR` … `else` … `end` | เงื่อนไข: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a หรือ b ถ้า a ว่าง) |
| `for tool in tools` … `end` | หนึ่งครั้งสำหรับแต่ละเครื่องมือที่โปรแกรมใช้ |
| `set NAME EXPR` | จดจำค่า (`set offset tool.number`) |
| `reset NAME …` | ลืมคำแบบ modal (กลุ่ม ตัวอักษรที่อยู่ เช่น `Z` หรือ `at.z`) |
| `do rapid X Y Z` | รันเหตุการณ์ `rapid` สำหรับจุด |

คำคือข้อความที่พิมพ์พร้อมช่อง `{variable|filter}` ตัวกรองคือ `upper`, `lower`, `pad:N` (เติมศูนย์), `cut:N` (N ตัวอักษรแรก), `safe` (ASCII ปลอดคอมเมนต์) และ `int` คำที่ลงท้ายด้วย `~` เป็น**แบบ modal**: เขียนเฉพาะเมื่อแตกต่างจากที่เขียนล่าสุด (`G1~`, `X{x}~`) คำที่ลงท้ายด้วย `~!` เขียนทุกครั้งและยังจำไว้ ชื่อที่ไม่ใช่ตัวแปรเป็นข้อความธรรมดา (`G81`, `mist`) ตัวเลขถูกปัดเป็น 0.001 mm และเขียนโดยไม่มีศูนย์ท้าย

## สิ่งที่โพสต์ทำไม่ได้

โพสต์ตัดสินเพียงวิธีที่การเคลื่อนที่ถูกเขียน ไม่มากกว่านั้น มันไม่สามารถเปลี่ยนเส้นทางเครื่องมือ จัดลำดับการทำงาน แบ่งส่วนโค้ง เพิ่มแกน รู้ระยะเคลื่อนที่หรือจลนศาสตร์ของเครื่องจักรของคุณ หรือคำนวณเลขบนพิกัดได้ (ไม่มี `+`) ตำแหน่งแกนหมุนมาจากเครื่องที่อธิบายไว้ในการตั้งค่า ไม่ใช่จากโพสต์: โพสต์เปลี่ยนเครื่องหมายหรือตัวอักษรของมันได้ แต่เปลี่ยนจลนศาสตร์ไม่ได้ อายุการใช้งานเครื่องมือและวงจรโปรแกรมย่อยยังไม่ได้สร้าง ไฟล์โพสต์แบบ `.cps` จากโปรแกรมอื่นโหลดไม่ได้: นี่คือรูปแบบที่ต่างและเรียบง่ายกว่า
