ไลบรารีการวิเคราะห์ของ PartCraft คำนวณสนามแม่เหล็กของขดลวดและเหล็กใน 2 มิติ ได้ นั่นคือหน้าตัดของสิ่งที่ยาวและเหมือนกันตลอดความยาว เช่น แม่เหล็กไฟฟ้า แกนหม้อแปลง บัสบาร์ หรือหน้าตัดของมอเตอร์ บทแนะนำนี้รันตัวอย่างแม่เหล็กไฟฟ้าของไลบรารี อ่านผลลัพธ์ เปลี่ยนแปลง แสดงวิธีจำลองรูปร่างของตนเอง แล้วเพิ่มแม่เหล็กถาวร

บทแนะนำนี้ใช้พื้นที่ทำงานสคริปต์และ[ไลบรารีการวิเคราะห์](topic:craftscript-library) ไม่จำเป็นต้องรู้ภาษา CraftScript เพื่อทำตาม ตัวอย่างจะอธิบายว่าแต่ละบรรทัดทำอะไร

## สิ่งที่ถูกจำลอง

แกนเหล็กรูปตัว C ขนาดภายนอก 100 × 80 มม. หนา 20 มม. มีช่องว่างอากาศ 2 มม. ที่ขาขวา ขดลวด 100 รอบ ที่กระแส 10 A (1000 แอมแปร์-รอบ) พันรอบขาซ้าย ทุกอย่างยาวในทิศทางที่พุ่งออกจากหน้าจอ ดังนั้นคำตอบเป็น**ต่อเมตรของความลึก**: คูณด้วยความลึกจริงสำหรับแม่เหล็กจริง

`magnetostatic2d` ของไลบรารีแก้หาศักย์เวกเตอร์แม่เหล็กบนตารางช่องขนาด 1 มม. ในกล่องอากาศที่ล้อมรอบแม่เหล็ก จากนั้นคำนวณความหนาแน่นฟลักซ์ **B** (เป็นเทสลา) จากค่านั้น

## รันตัวอย่าง

1. เลือก **สคริปต์** ในกล่อง **พื้นที่ทำงาน** ทางซ้ายของแถบเครื่องมือ
2. เปิดแท็บ **คลังไลบรารี** ของพาเนลสคริปต์ แล้วไปที่ **ตัวอย่าง** › **Electromagnet: field, gap, inductance**
3. คลิก {{ui:เปิด (อ่านอย่างเดียว)}} แล้วกด {{key:F5}}

ในเวลาหนึ่งถึงสองวินาที แคนวาสจะแสดงความหนาแน่นฟลักซ์ และคอนโซลจะพิมพ์:

```
B ในช่องว่าง 0.5427 T; วงจรแม่เหล็ก 0.5516 T (-1.6 %: การโป่งออกและการรั่วไหล)
อินดักแตนซ์ 0.1539 H ต่อเมตรของความลึก; วงจรให้ 0.1103 H/m ขาดฟลักซ์ที่รั่วผ่านช่องว่าง
พลังงานสะสม 7.694 J/m; |B| สูงสุดที่ 1.97 T ที่มุมด้านในของหน้าต่างของแกน (เหล็กจริงจะอิ่มตัวตรงนั้น)
แรงดึงข้ามช่องว่างประมาณ 2343 N ต่อเมตรของความลึก (117.2 N สำหรับลึก 50 มม.)
```

กราฟใต้แคนวาสคือความหนาแน่นฟลักซ์ในแนวตั้ง B_y ตามเส้นกึ่งกลางของแกน จากซ้ายไปขวา: ประมาณ −0.55 T ในขาซ้าย (ฟลักซ์ไหลลงมา) แทบไม่มีในหน้าต่าง และ +0.55 T ในขาขวาและข้ามช่องว่าง (ฟลักซ์ไหลกลับขึ้น) ฟลักซ์เดียวกันผ่านเหล็กและช่องว่าง ดังนั้นสองขาและช่องว่างแสดงค่าใกล้เคียงกัน

## อ่านผลลัพธ์

- **สนามในช่องว่าง** คือ 0.543 T การคำนวณด้วยมือถือว่าแกนเป็นวงจรแม่เหล็กเดียว B = μ0 N I / (g + l / μr) โดย g คือช่องว่าง l คือความยาวเส้นทางผ่านเหล็ก และ μr คือค่าการซึมผ่านสัมพัทธ์ของเหล็ก ได้ 0.552 T สนามต่ำกว่าการคำนวณด้วยมือเล็กน้อย เพราะฟลักซ์โป่งออกรอบช่องว่าง (fringing) และฟลักซ์บางส่วนลัดวงจรข้ามหน้าต่าง (leakage) เมื่อช่องว่างเล็กลงหรือตารางละเอียดขึ้น ผลทั้งสองจะใกล้กันมากขึ้น
- **อินดักแตนซ์** ของขดลวด 100 รอบคือ 0.154 H ต่อเมตรของความลึก จากพลังงานที่สะสมในสนาม สูตรวงจรให้น้อยกว่า (0.110 H/m) เพราะนับเฉพาะฟลักซ์ที่ผ่านช่องว่าง ไม่รวมฟลักซ์ที่รั่วผ่านไป
- **แรงดึง** ที่ปิดช่องว่างคือ B² w / (2 μ0) สำหรับหน้าช่องว่างที่กว้าง w: ประมาณ 2300 N ต่อเมตร หรือ 117 N สำหรับแม่เหล็กลึก 50 มม.
- **ค่าสูงสุด** 1.97 T อยู่ที่มุมด้านในของหน้าต่าง ซึ่งฟลักซ์หักเลี้ยวอย่างรวดเร็ว โมเดลถือว่าเหล็กเป็นเชิงเส้น เหล็กไฟฟ้าจริงจะอิ่มตัวประมาณ 1.5 ถึง 2 T ดังนั้นให้ถือค่าที่สูงกว่านั้นเป็นคำเตือน ไม่ใช่คำตอบ

:::note
การทดสอบของไลบรารีเองรันตัวอย่างนี้และตรวจสนามในช่องว่างเทียบกับสูตรวงจรแม่เหล็กทุกครั้งที่มีการเปลี่ยนแปลงของ PartCraft วิธีการ เอกสารอ้างอิง และการตรวจสอบอื่น (โซลีนอยด์ยาว โซลีนอยด์ที่มีแกนเหล็ก) อยู่ในส่วนหัวของ `magnetostatic2d`: คลิกที่ชื่อในไลบรารี
:::

## เปลี่ยนการออกแบบ

1. คลิก {{ui:ทำสำเนา}} เหนือสคริปต์แบบอ่านอย่างเดียว สำเนาจะถูกบันทึกพร้อมชิ้นส่วน
2. เปลี่ยนค่าใกล้ด้านบนแล้วกด {{key:F5}} อีกครั้ง ลองดู:
   - `g = 0.001;` — ช่องว่างครึ่งหนึ่ง: สนามในช่องว่างเกือบเพิ่มเป็นสองเท่า และแรงดึงก็เช่นกัน (แปรตาม B²)
   - `mur = 200;` — แกนที่ด้อยกว่า: แอมแปร์-รอบจำนวนมากถูกใช้ไปในเหล็ก
   - `N = 200;` — รอบเป็นสองเท่า: สนามเป็นสองเท่า อินดักแตนซ์เป็นสี่เท่า
   - `h = 0.0005;` — ตารางละเอียดขึ้น: คำตอบใกล้ขึ้น ใช้เวลาประมาณสี่เท่า

แต่ละครั้งที่รันจะแทนที่แคนวาส ตัวแปรที่สคริปต์สร้าง (เช่น `Bgap`, `L`, `F`) จะคงอยู่ในรายการ **ตัวแปร** สำหรับการคำนวณเพิ่มเติม

## จำลองรูปร่างของตนเอง

ตัวอย่างสร้างทุกอย่างจากสามลิสต์ โดยมีหนึ่งค่าต่อช่องตาราง ซึ่งทำได้สำหรับรูปร่างใดก็ตามที่วาดด้วยเส้นตรงตามตาราง:

- **ตำแหน่งที่มีเหล็ก:** `iron` เป็นจริงสำหรับช่องที่อยู่ในแกน ตัวอย่างสร้างจากสี่เหลี่ยมผืนผ้า `frame & ~window & ~gap` หมายความว่า "อยู่ในกรอบ ไม่อยู่ในหน้าต่าง ไม่อยู่ในช่องว่าง"
- **การซึมผ่าน:** `1 + (mur - 1) * iron` เป็น 1 ในอากาศและ `mur` ในเหล็ก ให้วัสดุหลายชนิดมีค่าของตนด้วยวิธีเดียวกัน
- **กระแส:** `J` คือความหนาแน่นกระแสเป็นแอมแปร์ต่อตารางเมตร เป็นบวกเมื่อพุ่งออกจากหน้าจอ และเป็นลบเมื่อพุ่งเข้าไป ขดลวดมีสองด้านที่เครื่องหมายตรงข้ามกัน ตัวอย่างคำนวณ `J0` เพื่อให้ด้านหนึ่งมี N I

จากนั้น `r = magnetostatic2d(m, permeability, J)` แก้โมเดล `r.B` คือความหนาแน่นฟลักซ์ในแต่ละช่อง (สองคอลัมน์ x และ y) `r.Bmag` คือขนาดของมัน `r.energy` คือพลังงานที่สะสมต่อเมตร และ `plot(x, y)` วาดเส้น

ไลบรารีทำงานเป็นเมตร และมุมมองเป็นมิลลิเมตร ดังนั้นสนามที่แสดงตามค่าจริงจะถูกวาดเล็กกว่าจริงพันเท่า ตัวอย่างแสดงสนามบนสำเนาของตารางในหน่วยมิลลิเมตร (`mm = quadGrid(…)` แล้ว `show(field(mm, …))`): ให้คัดลอกสองบรรทัดนั้นไปใช้

โดยค่าเริ่มต้น ขอบของกล่องกักฟลักซ์ไว้: ไม่มีฟลักซ์ออกนอกกล่อง ควรให้กล่องมีขนาดอย่างน้อยสองหรือสามเท่าของแม่เหล็ก เพื่อไม่ให้ขอบบีบสนาม สำหรับแม่เหล็กที่สมมาตร สามารถจำลองเพียงครึ่งหนึ่งได้: ส่วนหัวของ `magnetostatic2d` บอกว่าต้องใช้เงื่อนไขขอบใดบนเส้นสมมาตร

## แม่เหล็กถาวร

ตัวอย่างที่สอง **ตัวอย่าง** › **Permanent magnet in an iron core: working point, leakage, pull** คือแกนเดียวกันโดยถอดขดลวดออก และแทนที่ชิ้นหนา 10 มม. ของขาซ้ายด้วยแม่เหล็กที่ถูกทำให้เป็นแม่เหล็กไปทางบน รันด้วย {{key:F5}} ระบบจะพิมพ์:

```
แม่เหล็กทำงานที่ B = 1.036 T, H = -124 kA/m (บนเส้น recoil ของมัน B = Br + μ0 μr H)
B ในช่องว่าง 0.6778 T; วงจรแม่เหล็กโดยไม่รั่วไหล 0.9692 T (-30.1 %)
ตัวประกอบการรั่วไหล 1.53: จากฟลักซ์ที่ออกจากแม่เหล็ก 65 % ข้ามช่องว่างระหว่างหน้าขั้ว
แรงดึงข้ามช่องว่างประมาณ 3656 N ต่อเมตรของความลึก (182.8 N สำหรับลึก 50 มม.)
```

- **จุดทำงาน** แม่เหล็กถูกอธิบายด้วย **remanence** Br (สนามที่มันคงไว้เมื่อถูกลัดวงจรด้วยเหล็ก: ประมาณ 1.2 T สำหรับ NdFeB แบบซินเตอร์ และ 0.4 T สำหรับเฟอร์ไรต์) และค่าการซึมผ่านแบบ recoil (ประมาณ 1.05 และ 1.1) เมื่อเปิดช่องว่าง มันจะถูกดันลงตามเส้น recoil: ที่นี่ลงไปที่ 1.04 T โดย H ชี้สวนทางกับ B ภายในมัน
- **การรั่วไหล** การคำนวณด้วยมือโดยไม่มีการรั่วไหลให้ 0.97 T ในช่องว่าง ส่วนโมเดลให้ 0.68 T แม่เหล็กขับฟลักซ์ด้วยแรงดันสูงในความยาวสั้น ดังนั้นฟลักซ์จำนวนมากไหลกลับข้ามหน้าต่างโดยตรง แทนที่จะผ่านช่องว่าง ตัวประกอบการรั่วไหลบอกว่ามากแค่ไหน: 1.53 ที่นี่ ตั้ง `g = 0;` สำหรับแผ่นเหล็กปิดวงจร (keeper) แม่เหล็กจะทำงานภายในครึ่งเปอร์เซ็นต์ของการคำนวณด้วยมือ
- **แม่เหล็กในโมเดลของตนเอง** ให้ `magnetostatic2d` รับแม่เหล็กเป็น `struct('Br', Br)` โดย `Br` มีหนึ่งแถวต่อช่องตาราง พร้อม remanence ตามแกน x และ y เป็นเทสลา (เป็นศูนย์นอกแม่เหล็ก) และให้ช่องแม่เหล็กมีค่าการซึมผ่านแบบ recoil ในลิสต์ค่าการซึมผ่าน:

  ```
  Brem = [zeros(numel(mag), 1), 1.2 * mag];     % 1.2 T ขึ้นในช่องที่ mag เป็นจริง
  r = magnetostatic2d(m, 1 + (mur - 1) * iron + 0.05 * mag, 0, struct(), struct('Br', Brem));
  ```

  สำหรับแม่เหล็กที่ถูกทำให้เป็นแม่เหล็กที่มุม ให้ใส่ `Br·cos(angle)` และ `Br·sin(angle)` ในสองคอลัมน์ สำหรับวงแหวนที่ทำให้เป็นแม่เหล็กออกนอก ให้คำนวณทิศทางของแต่ละช่องจากตำแหน่ง `r.H` ให้สนาม H ในแต่ละช่อง

โมเดลคงแม่เหล็กไว้บนเส้น recoil ตรงไม่ว่าจะถูกขับมากแค่ไหน แม่เหล็กจริงที่ถูกขับเกินจุดงอ (knee) (จากช่องว่างใหญ่ กระแสขดลวดแรง หรือความร้อน) จะสูญเสียความแรงบางส่วนอย่างถาวร ให้ตรวจสอบจุดทำงานกับเส้นโค้งของผู้ผลิตสำหรับเกรดและอุณหภูมินั้น

การทดสอบของไลบรารีตรวจแม่เหล็กเทียบกับผลการคำนวณด้วยมือสองค่า: แม่เหล็กกลมในอากาศเปิด (ภายในมัน B = Br / (1 + μr)) และแม่เหล็กที่ปิดด้วยแผ่นเหล็ก (วงจรแม่เหล็ก) ทั้งสองอยู่ภายใน 1 %

## สิ่งที่ยังไม่รองรับ

- **ความอิ่มตัว** เหล็กเป็นเชิงเส้น: เพิ่มกระแสเป็นสองเท่า สนามเพิ่มเป็นสองเท่า โดยไม่มีขีดจำกัด
- **การลดอำนาจแม่เหล็ก** แม่เหล็กยังคงอยู่บนเส้น recoil ตรง (ดูด้านบน)
- **กระแสวน (eddy currents)** และ **การสูญเสีย** (การสูญเสียในเหล็ก การสูญเสียในทองแดง)
- **ชิ้นส่วนที่เคลื่อนที่และแรงบิด** ไม่มีโรเตอร์หมุนในสเตเตอร์ ไม่มีแรงบิดเทียบกับมุม
- **รูปทรงกลม** ตารางประกอบจากช่องสี่เหลี่ยมเท่ากัน ดังนั้นเส้นโค้งจะออกมาเป็นขั้นบันได
- **3 มิติ** ทุกอย่างเป็นหน้าตัดของสิ่งที่ยาว
