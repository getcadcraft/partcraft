ไลบรารีการวิเคราะห์คือชุดของสคริปต์ โดยแต่ละสคริปต์เป็นฟังก์ชันที่คุณอ่านจากบนลงล่างได้: เมทริกซ์ความแข็งถูกประกอบอย่างไร เงื่อนไขขอบวางที่ไหน ใช้ตัวแก้สมการตัวใด และผลลัพธ์ถูกคำนวณอย่างไร ไม่มีส่วนใดในนั้นซ่อนอยู่ในกล่องดำ มีเพียงลูปชั้นในที่ต้องการความเร็ว (เมทริกซ์องค์ประกอบ ตัวแก้สมการเบาบาง การสร้างเมช) ที่ถูกสร้างไว้ในตัว

## เริ่มจากตัวอย่าง

กลุ่ม **Examples** มีสคริปต์สั้นห้าตัวที่ใช้ไลบรารีตั้งแต่ต้นจนจบ คลิกหนึ่งตัว กด {{ui:Open (read-only)}} แล้วกด {{key:F5}}: แต่ละตัวจะล้างมุมมอง แล้วแสดงผลลัพธ์บนมุมมอง 3 มิติและกราฟในจอแสดงผลย่อย

| ตัวอย่าง | สิ่งที่แสดง |
|---|---|
| ความเค้นของคานยื่น | แท่งเหล็กขนาด 100 × 10 × 10 mm ภายใต้แรงปลาย 100 N: ความเค้นฟอนมิเซสบนแท่งที่เปลี่ยนรูป และการแอ่นที่ปลายเทียบกับทฤษฎีคาน ที่ขนาดองค์ประกอบสี่ขนาด (แสดงเป็นกราฟ) |
| โทโพโลยีคาน MBB | การหาค่าเหมาะสมของโทโพโลยีแบบคลาสสิกขนาด 60 × 20: การก่อตัวของการออกแบบ ค่าความอ่อนตัว (compliance) ที่ลดลง และรูปแบบสุดท้าย (94 รอบ ค่าความอ่อนตัว 203.19) |
| สนามตัวเก็บประจุ | แผ่นสองแผ่นกว้าง 4 mm ห่างกัน 1 mm: ศักย์และสนาม ความจุพร้อมผลขอบเทียบกับค่าในอุดมคติและสูตรของ Palmer |
| การไหลในช่องทาง | การไหลแบบ Lattice Boltzmann ผ่านเสาในช่องทาง: สนามความเร็วและประวัติการลู่เข้า |
| แม่เหล็กไฟฟ้า | แกนเหล็กรูปตัว C พร้อมช่องว่างอากาศและขดลวด: ความหนาแน่นฟลักซ์ สนามในช่องว่างเทียบกับสูตรวงจรแม่เหล็ก ค่าเหนี่ยวนำ และแรงดึงดูดข้ามช่องว่าง อธิบายทีละขั้นใน [สนามแม่เหล็กในสองมิติ](topic:magnetic-fields-2d) |
| แม่เหล็กถาวร | แกนเดียวกันแต่ใช้แม่เหล็กถาวรแทนขดลวด: จุดทำงานของแม่เหล็ก สนามในช่องว่างเทียบกับวงจรแม่เหล็ก ฟลักซ์ที่รั่ว และแรงดึงดูด ใน [สนามแม่เหล็กในสองมิติ](topic:magnetic-fields-2d#permanent-magnets) |

## กลุ่ม

| กลุ่ม | ฟังก์ชัน | หน้าที่ |
|---|---|---|
| การสร้างเมช | `box_mesh`, `cylinder_mesh`, `voxel_mesh`, `tet_mesh`, `mesh_quality`, `nodes_at`, `face_nodes` | กล่องและทรงกระบอกเป็นเฮกซาฮีดรอน ลูกบาศก์หรือเตตระฮีดรอน ลูกบาศก์หรือเตตระฮีดรอนของโมเดลใดก็ได้ (ชิ้นส่วน บอดี้ หรือ STL ที่โหลดแล้ว) ปริมาตรและคุณภาพขององค์ประกอบ การเลือกโนดบนระนาบหรือหน้า |
| ความเค้นสถิต | `static_voxel`, `static_tet` | ความเค้นสถิตเชิงเส้นบนลูกบาศก์หรือเตตระฮีดรอน 10 โนด: การเคลื่อนที่ ความเค้น ฟอนมิเซส และแรงปฏิกิริยา |
| โครงข้อ | `frame3d` | โครงสามมิติของคาน เสา และค้ำยัน ด้วยวิธีความแข็งโดยตรง: การปลดปล่อยปลาย จุดรองรับและสปริง แรงตามแนวชิ้นส่วน การเคลื่อนที่ แรงปฏิกิริยา และแรงที่ปลายชิ้นส่วน {{ui:Export as CraftScript}} ของ DetailCraft และ BimCraft เขียนโมเดลทั้งหมดให้ใช้กับฟังก์ชันนี้ได้ นี่เป็นเครื่องมือช่วยวิเคราะห์ ไม่ใช่การตรวจสอบตามมาตรฐาน |
| การสั่น | `modal_tet` | ความถี่ธรรมชาติและรูปแบบการสั่น |
| ความร้อน | `heat_steady`, `heat_transient`, `heat_system` | การนำความร้อนแบบคงที่และชั่วคราว ด้วยอุณหภูมิคงที่ การป้อนความร้อน การกำเนิดความร้อน ฟลักซ์ และการพาความร้อน |
| การหาค่าเหมาะสมของโทโพโลยี | `top88`, `top99`, `topopt3d` | โค้ดสองมิติ 88 และ 99 บรรทัดที่ตีพิมพ์แล้ว และวิธีเดียวกันในสามมิติบนลูกบาศก์ |
| แม่เหล็กไฟฟ้า | `poisson2d`, `magnetostatic2d` | ไฟฟ้าสถิตสองมิติ (ศักย์ สนาม ความจุ ประจุ) และแม่เหล็กสถิตสองมิติ (ศักย์เวกเตอร์ ความหนาแน่นฟลักซ์ แม่เหล็กถาวร) |
| การไหลของของไหล | `lbm2d`, `lbm3d` | การไหลแบบ Lattice Boltzmann: แบบสองมิติเขียนไว้ในสคริปต์ แบบสามมิติใช้เคอร์เนลการไหลของ PartCraft เอง |

ส่วนหัวของทุกฟังก์ชันระบุอาร์กิวเมนต์ที่แน่นอน หน่วยเป็นของการศึกษาใน PartCraft เว้นแต่ส่วนหัวจะระบุไว้เป็นอย่างอื่น: mm, N, MPa, ตันต่อ mm³ สำหรับความหนาแน่น และ W กับ K สำหรับความร้อน ฟังก์ชันทางแม่เหล็กไฟฟ้าและ lattice Boltzmann ทำงานได้กับหน่วยที่สอดคล้องกันใดก็ได้ ส่วนหัวของฟังก์ชันเหล่านั้นจะบอกว่าใช้หน่วยอะไร

## การตรวจสอบไลบรารี

ส่วนหัวของแต่ละฟังก์ชันจบด้วย **การตรวจสอบ** ซึ่งเป็นกรณีเล็ก ๆ ที่รู้คำตอบ การทดสอบของ PartCraft รันทุกกรณี และเมื่อ PartCraft มีการศึกษาของตัวเองสำหรับงานเดียวกัน คำตอบของสคริปต์จะถูกเทียบกับการศึกษานั้นบนเมชเดียวกัน:

- การแอ่นที่ปลายของคานยื่นเทียบกับทฤษฎีคาน (ภายใน 0.2 % กับลูกบาศก์ และ 0.05 % กับเตตระฮีดรอน) และกับตัวแก้สมการของพื้นที่ทำงาน **Simulation** บนเมชเดียวกัน (เหมือนกันจนถึงหลายหลัก)
- ความถี่แรกของคานยื่นเทียบกับทฤษฎีคาน (ต่ำกว่า 0.24 % ซึ่งคาดไว้สำหรับคานสั้น) และกับตัวแก้สมการโหมดของ **Simulation**
- ความร้อน: ผนังระนาบที่ถูกให้ความร้อนได้ค่าที่แน่นอน วัตถุขนาดเล็กที่เย็นตัวตามสูตร lumped-capacity และอุณหภูมิของแผ่นที่ค่อย ๆ ลดลงตามทฤษฎี
- การหาค่าเหมาะสมของโทโพโลยี: `top88` ให้ 94 รอบและค่าความอ่อนตัว 203.1925 ตามเอกสาร (และ 218.8032 เมื่อใช้ตัวกรองความหนาแน่น) ส่วน `topopt3d` ลงที่ค่าความอ่อนตัวเดียวกับพื้นที่ทำงาน **Generative** ด้วยการตั้งค่าเดียวกัน
- ความจุของตัวเก็บประจุและสนามของโซลินอยด์ยาวเทียบกับค่าในตำรา สนามในช่องว่างของแม่เหล็กไฟฟ้าเทียบกับสูตรวงจรแม่เหล็ก และแม่เหล็กถาวรเทียบกับแม่เหล็กทรงกลมในอากาศและแม่เหล็กที่ปิดด้วยตัวนำเหล็ก
- การไหลในช่องทางเทียบกับโปรไฟล์พาราโบลาที่แน่นอน

## อ่านฟังก์ชัน

1. เปิดแท็บ **ไลบรารี** ของพาเนลสคริปต์
2. คลิกฟังก์ชัน ส่วนหัวจะแสดง: สิ่งที่คำนวณ วิธี หน่วย สมมติฐานและขีดจำกัด **อ้างอิง** (หนังสือหรือบทความ พร้อมหมายเลขสมการ) และ **การตรวจสอบ** ซึ่งเป็นกรณีเล็ก ๆ ที่รู้คำตอบและการทดสอบของ PartCraft รันเอง
3. {{ui:Open (read-only)}} เปิดสคริปต์ทั้งหมดในแท็บที่มีกรอบเส้นประ รันได้ เลือกและรันบางส่วนได้ แต่แก้ไขไม่ได้

## แก้ไขฟังก์ชัน

กด {{ui:Make a copy}} (หรือ **ทำสำเนาเพื่อแก้ไข** เหนือแท็บแบบอ่านอย่างเดียว) สำเนาจะเป็นสคริปต์ในชิ้นส่วนของคุณที่มีชื่อเดียวกัน จึงถูกบันทึกไปพร้อมชิ้นส่วน และ **ทุกการเรียกฟังก์ชันนั้นจะใช้สำเนาของคุณ** ตัวแก้ไขจะแจ้งไว้เหนือสคริปต์ เปลี่ยนชื่อสำเนาเพื่อเก็บทั้งสองไว้

## ใช้ฟังก์ชัน

เรียกฟังก์ชันของไลบรารีจากสคริปต์ใดก็ได้ด้วยชื่อ เหมือนฟังก์ชันในตัว:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

ผลลัพธ์จะกลับมาเป็นค่าในพื้นที่ทำงาน กราฟและฟิลด์ที่ฟังก์ชันแสดงจะปรากฏในมุมมองและจอแสดงผลย่อย

ตัวอย่างการวิเคราะห์สถิตของชิ้นส่วนที่เปิดอยู่ใช้เพียงไม่กี่บรรทัด:

```
v = voxel_mesh(part(), 2);                   % ลูกบาศก์ขนาด 2 mm
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % ยึดด้านล่าง
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 500 N ลงที่ด้านบน
r = static_voxel(v, 210000, 0.3, bc);       % เหล็ก
```

`r` เก็บการเคลื่อนที่ ความเค้น และแรงปฏิกิริยา ความเค้นฟอนมิเซสถูกวาดบนชิ้นส่วนที่เปลี่ยนรูป สำหรับชิ้นส่วนโค้งให้ใช้ `tet_mesh` และ `static_tet` ซึ่งโหลดและยึดทั้งหน้าได้ด้วย (`face_nodes`)

:::note
ฟังก์ชันของไลบรารีเขียนด้วย CraftScript และสคริปต์ Lua เรียกผ่าน `cs` เหมือนฟังก์ชันในตัว: `cs.static_tet(t, 200000, 0.3, bc)` (ดู [สคริปต์ใน Lua](topic:craftscript-lua)) แต่ละฟังก์ชันแก้สมการหนึ่งวัสดุและหนึ่งกรณีโหลด ส่วนหัวระบุสิ่งที่ไม่ครอบคลุม
:::
