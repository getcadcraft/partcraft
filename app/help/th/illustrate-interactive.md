{{ui:Export}} จากนั้น {{ui:As}} {{ui:Interactive 3D file (HTML, opens offline)}} จะบันทึกเป็นไฟล์ `.html` หนึ่งไฟล์ ส่งทางอีเมล ใส่ใน USB หรือโฟลเดอร์ที่แชร์ไว้ก็ได้ ไฟล์จะเปิดในเบราว์เซอร์ที่รองรับ WebGL 2 ได้ ทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

ในไฟล์:

- ลากเพื่อหมุนโมเดล คลิกขวาแล้วลาก หรือ {{key:Shift}}+ลาก เพื่อแพน ใช้ล้อเมาส์หรือการบีบนิ้วเพื่อซูม
- คลิกมุมมองในรายการ กล้องจะเคลื่อนไปที่นั้น และชิ้นส่วนจะใช้ตำแหน่ง ลักษณะ การตัด และแว่นขยายของมุมมองนั้น
- คลิกแถวในรายการชิ้นส่วนเพื่อไฮไลต์ชิ้นส่วนของแถวนั้น คลิกชิ้นส่วนเพื่อไฮไลต์แถวของชิ้นส่วนนั้น
- เมื่อคู่มือมีแอนิเมชัน แถบด้านล่างโมเดลจะใช้เล่น หยุด และเลื่อนดูแอนิเมชันนั้นได้

ไฟล์มีทุกอย่างที่ต้องใช้ (โมเดล ตัวแสดงผล และ three.js ภายใต้สัญญาอนุญาต MIT) และปิดกั้นคำขอทั้งหมด: เข้าถึงอินเทอร์เน็ตไม่ได้ ไม่มีบัญชี และไม่มีการติดตาม

ไม่มีให้บริการ 3D แบบโต้ตอบภายใน PDF: เบราว์เซอร์และโปรแกรมอ่าน PDF ส่วนใหญ่แสดงไม่ได้ และโปรแกรมอ่านที่แสดงได้ก็ปิดฟีเจอร์นี้ไว้เป็นค่าเริ่มต้น ไฟล์ HTML คือทางเลือกแบบโต้ตอบ
