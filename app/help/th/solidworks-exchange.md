PartCraft แลกเปลี่ยนชิ้นส่วนกับ SolidWorks ได้ทั้งสองทาง โดยไม่ใช้ไฟล์รูปแบบที่ไม่มีใครอ่านได้:

- **ส่งออก:** มาโคร (`.swb` เป็นข้อความธรรมดา) ที่ SolidWorks รันเพื่อสร้างชิ้นส่วนเองทีละฟีเจอร์ พร้อมสเกตช์ ความสัมพันธ์ ไดเมนชัน ตัวแปรส่วนกลาง และสมการ คุณจะได้ชิ้นส่วนดั้งเดิมที่มีแผนผังฟีเจอร์ที่ใช้งานได้ ไม่ใช่โซลิดที่ไร้ชีวิต
- **กลับมา:** มาโครที่รันใน SolidWorks จะเขียนฟีเจอร์และสมการของชิ้นส่วนลงไฟล์ `.cadcraft-sw.json` การเปิดไฟล์นั้นใน PartCraft ยังไม่ได้สร้างในเวอร์ชันนี้ (ต้องใช้เคอร์เนลแม่นยำ)

:::warning
ยังไม่ได้ทดสอบทั้งหมดนี้ใน SolidWorks SolidWorks ทำงานเฉพาะบน Windows และต้องมีลิขสิทธิ์การใช้งาน PartCraft ยังไม่เคยรันมาโครเหล่านี้ใน SolidWorks มาโครเขียนจากเอกสาร API ของ SolidWorks และตรวจโครงสร้างที่นี่เท่านั้น คาดว่าจะพบปัญหา บันทึกที่มาโครเขียนจะบอกว่าขั้นตอนใดล้มเหลว
:::

PartCraft เขียนไฟล์ `.sldprt` ไม่ได้ เพราะรูปแบบนั้นปิดอยู่ มาโครคือวิธีที่จะได้ชิ้นส่วนดั้งเดิม

## ส่งชิ้นส่วนเป็นมาโคร

1. เปิดชิ้นส่วน
2. เลือก {{ui:Export}} แล้วเลือก {{ui:Macro for SolidWorks (.swb)}} PartCraft จะดาวน์โหลด `<part>.swb` และแถบสถานะจะบอกว่าเขียนโดยไม่มีเคอร์เนลแม่นยำ
3. กล่องโต้ตอบจะบอกจำนวนฟีเจอร์ ตัวแปรส่วนกลาง และสมการที่มาโครสร้าง และแสดงรายการสิ่งที่ถูกละไว้ ไม่มี STEP ไปพร้อมกันในเวอร์ชันนี้ ถ้าต้องการ ให้ใช้ {{ui:Export}} แล้วเลือก {{ui:STEP (faceted, mesh kernel)}}
4. ใน SolidWorks เลือก **Tools > Macro > Run** เลือกไฟล์ `.swb` แล้วรอ มันจะสร้างชิ้นส่วนใหม่จากเทมเพลตชิ้นส่วนเริ่มต้นของคุณ ตั้งหน่วยเป็นมิลลิเมตร และสร้างทุกฟีเจอร์
5. เมื่อเสร็จ ข้อความจะบอกว่าทำไปกี่ขั้นตอน ล้มเหลวกี่ขั้นตอน และตรงกับวัตถุของ PartCraft กี่ขั้นตอน บันทึกเต็ม `<part> macro log.txt` จะถูกเขียนไว้ข้างมาโคร

สิ่งที่มาโครสร้าง:

| PartCraft | ในชิ้นส่วนใหม่ |
|---|---|
| สเกตช์บนระนาบ Front, Top หรือ Right | สเกตช์บนระนาบนั้น พร้อมเส้น ส่วนโค้ง วงกลม จุด ความสัมพันธ์ และไดเมนชัน (ตั้งชื่อตามใน PartCraft เช่น `k7`) |
| สเกตช์บนหน้า | สเกตช์บนหน้าเดียวกัน ระบุด้วยจุดบนหน้านั้น |
| สเกตช์บนระนาบตรึง | ระนาบอ้างอิงที่ผ่านสามจุด และสเกตช์บนระนาบนั้น |
| เอ็กซ์ทรูด หรือตัด (บลายด์ ทะลุทั้งหมด กึ่งกลางระนาบ สองทิศทาง เรียว) | Boss-extrude หรือ cut-extrude |
| หมุนรอบแกน หรือตัดหมุนรอบแกน | หมุนรอบเส้นกึ่งกลางเดียวกัน |
| รู (ธรรมดา เคาน์เตอร์บอร์ เคาน์เตอร์ซิงก์ มีเกลียวใน) | การตัดหนึ่งหรือสองครั้งพร้อมสเกตช์ของตัวเอง (รูมีเกลียวในคือดอกสว่านนำ ไม่มีเกลียว) |
| แพตเทิร์นเชิงเส้นและวงกลม สะท้อน | Linear pattern, circular pattern, mirror (เป็นฟีเจอร์หรือทั้งบอดี้) |
| ฟิลเลต ชัมเฟอร์ เชลล์ | Fillet, chamfer และ shell บนขอบและหน้าเดียวกัน ระบุด้วยจุด |
| พารามิเตอร์และสมการ | ตัวแปรส่วนกลางและสมการบนไดเมนชันที่ตั้งชื่อใหม่ |
| ฟีเจอร์ที่ระงับ แถบย้อนกลับ | ระงับในลักษณะเดียวกัน แถบย้อนกลับอยู่ตำแหน่งเดิม |

หลังจากฟีเจอร์โซลิดแต่ละอัน มาโครจะเปรียบเทียบปริมาตรและขนาดของบอดี้กับของ PartCraft เมื่อต่างกัน มันจะกลับทิศทางของฟีเจอร์นั้นหนึ่งครั้งแล้วตรวจอีกครั้ง หากไม่ดีขึ้น มันจะกลับคืนและเขียน "Check" ในบันทึก

### สิ่งที่ถูกละไว้

กล่องโต้ตอบและส่วนต้นของมาโครจะแสดงทุกอย่างที่ไม่ได้ถูกนำมาด้วยพร้อมเหตุผล ตอนนี้ได้แก่ โซลิดที่นำเข้า (ให้แทรก STEP แทน) สวีป ลอฟต์ ดราฟต์ แกนอ้างอิงและจุดอ้างอิง เงื่อนไขปลาย "up to" การเอ็กซ์ทรูดเฉพาะบางคอนทัวร์ และทุกอย่างที่ขึ้นกับสิ่งเหล่านั้น สไปลน์จะกลายเป็นเส้นโค้งที่ผ่านจุดของมัน เวอร์ชันนี้ไม่มีเคอร์เนลแม่นยำ ดังนั้นสเกตช์บนหน้าและฟีเจอร์ที่เลือกขอบหรือหน้าก็ถูกละไว้ด้วย

## ส่ง STEP แบบมีชื่อ

ยังไม่ได้สร้างในเวอร์ชันนี้: {{ui:STEP for SolidWorks (named, AP214)}} ต้องใช้เคอร์เนลแม่นยำ และการเลือกมันจะขึ้นข้อความว่า "STEP for SolidWorks: not built yet. …" เมื่อมีเคอร์เนลแม่นยำ ไฟล์จะมีชื่อชิ้นส่วน หน่วยมิลลิเมตร และสีของชิ้นส่วน และตั้งแกน Y ขึ้นตามที่ SolidWorks แสดงชิ้นส่วน (การส่งออก {{ui:STEP AP214 (exact solid)}} ธรรมดาตั้งแกน Z ขึ้น) อักษรที่มีเครื่องหมายกำกับจะสูญเสียเครื่องหมายในชื่อ และอักขระอื่นที่อยู่นอก ASCII ธรรมดาจะกลายเป็น `_`

## นำชิ้นส่วนกลับมา

การเปิดไฟล์ใน PartCraft (ขั้นตอนที่ 3) ยังไม่ได้สร้างในเวอร์ชันนี้: จะขึ้นข้อความ "Opening a SolidWorks export: not built yet. …" แอป CadCraft Drafting ยังเปิดไฟล์และนำสเกตช์ไปได้

1. เลือก {{ui:File}} > {{ui:Export}} > {{ui:Export macro to bring parts back (.swb)}} เพื่อดาวน์โหลด `CadCraftExport.swb` และวางไว้ข้างชิ้นส่วนของคุณ
2. ใน SolidWorks เปิดชิ้นส่วน เลือก **Tools > Macro > Run** แล้วเลือก `CadCraftExport.swb` มันจะเขียน `<part>.cadcraft-sw.json` ไว้ข้างชิ้นส่วน และไม่เปลี่ยนแปลงชิ้นส่วนนั้น
3. ใน PartCraft เลือก {{ui:Open}} แล้วเลือกไฟล์นั้น หรือวางลงบนมุมมอง 3 มิติ
4. เมื่อมีเคอร์เนลแม่นยำ PartCraft จะสร้างชิ้นส่วนใหม่ทีละฟีเจอร์และแสดงว่าทำอะไรไป เช่น "5 of 5 features carried over from SolidWorks (Flange.SLDPRT)" ฟีเจอร์ที่นำมาไม่ได้ ("Not carried over: Sweep1 (Sweep).") และปริมาตรตรงกับที่ SolidWorks เขียนไว้หรือไม่
5. บันทึกเป็นชิ้นส่วน PartCraft ด้วย {{ui:Save}}

สเกตช์จะไปอยู่บนระนาบฐานเมื่ออยู่บนระนาบนั้น และไปอยู่บนหน้าแบนที่ตรงกันของชิ้นส่วนเมื่อมี (เพื่อให้ตามการแก้ไขภายหลัง) และบนระนาบตรึงในกรณีอื่น ขอบและหน้าของฟิลเลต ชัมเฟอร์ และเชลล์จะถูกค้นหาจากจุด และเก็บไว้เป็นการอ้างอิงที่ตั้งชื่อ ตัวแปรส่วนกลางจะกลายเป็นพารามิเตอร์ (ชื่อที่มีช่องว่างจะใช้ขีดล่าง: "Bolt count" กลายเป็น `Bolt_count`) และสมการจะกลายเป็นสมการบนไดเมนชันเดียวกัน ไม่มีการเดาอะไร สิ่งที่ไม่มีคู่จะถูกแสดงรายการไว้

แอป CadCraft Drafting เปิดไฟล์เดียวกันและนำสเกตช์ไปได้

:::note
รูปแบบคือ `cadcraft-sw-export` เวอร์ชัน 1 เป็น JSON ธรรมดาในหน่วยมิลลิเมตรและองศา ไฟล์จากมาโครที่ใหม่กว่า หรือไฟล์ที่ไม่ถูกต้อง จะถูกปฏิเสธพร้อมเหตุผล
:::
