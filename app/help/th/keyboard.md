ขณะกำลังพิมพ์ในช่องในพาเนล ปุ่มต่างๆ จะไม่ทำงาน ยกเว้น {{key:Mod+S}} และ {{key:Mod+O}} ซึ่งใช้ได้เสมอ ปุ่มตัวอักษรใช้ได้โดยไม่ต้องกดปุ่มดัดแปลง

หมายเหตุทั่วไปเกี่ยวกับปุ่มในเบราว์เซอร์ และบนคีย์บอร์ดที่ไม่มีปุ่มฟังก์ชัน: [คีย์บอร์ด เมาส์ และทัชแพด](common:keys)

## ทุกที่

| ปุ่ม | การทำงาน |
|---|---|
| {{key:Mod+S}} | บันทึกชิ้นส่วน (ในชุดประกอบ: บันทึกชุดประกอบ) ปิดสเกตช์ที่เปิดอยู่ก่อน |
| {{key:Mod+O}} | เปิดไฟล์ชิ้นส่วนหรือชุดประกอบ (ถามก่อนหากมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก) |
| {{key:Mod+Z}} | เลิกทำ |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำ |
| {{key:F1}} | เปิดหรือปิดหน้าช่วยเหลือนี้ (หรือ {{ui:ช่วยเหลือ}} บนแถบแอป) {{key:Esc}} ปิดด้วยเช่นกัน บนแล็ปท็อปและคีย์บอร์ด Mac หลายรุ่น ให้กดค้าง Fn |
| {{key:Ctrl+Shift+F}} | โหมดหน้าจอ: ปกติ เต็มหน้าจอ เต็มหน้าจอโดยซ่อนแถบ ใช้ Control บน Mac ด้วย ไม่ใช่ ⌘ |
| {{key:Esc}} | ออกจากโหมดเต็มหน้าจอ (เมื่ออยู่ในโหมดเต็มหน้าจอ) |
| {{key:Mod+,}} | การตั้งค่า รวมถึงแท็บ PartCraft (ดู [การตั้งค่า PartCraft](topic:settings)) |

ในช่องตัวเลขของพาเนล {{key:Mod+Z}} คือการเลิกทำข้อความของเบราว์เซอร์เอง ในช่องตัวเลขเหนือไดเมนชันสเกตช์ มันจะเลิกทำใน PartCraft

## คัดลอก วาง และทำสำเนา

ปุ่มเหล่านี้ทำงานกับสิ่งที่กำลังทำอยู่: รูปทรงที่เลือกในสเกตช์ที่เปิดอยู่ ฟีเจอร์ที่เลือกในประวัติ หรือชิ้นส่วนที่เลือกในชุดประกอบ รายละเอียดใน [คัดลอก วาง และทำสำเนา](topic:copy-paste)

| ปุ่ม | การทำงาน |
|---|---|
| {{key:Mod+C}} | คัดลอกส่วนที่เลือก |
| {{key:Mod+X}} | ตัด: คัดลอกแล้วลบ |
| {{key:Mod+V}} | วาง ในสเกตช์ สำเนาจะเคลื่อนตามตัวชี้ คลิกตรงจุดที่ต้องการวาง |
| {{key:Mod+Shift+V}} | วางที่เดิม: พิกัดเดียวกัน (ในชุดประกอบ คือตำแหน่งเดียวกัน) |
| {{key:Mod+D}} | ทำสำเนา: คัดลอกและวางในขั้นตอนเดียว โดยไม่เปลี่ยนคลิปบอร์ด |
| {{key:Mod+A}} | เลือกทั้งหมด (ในสเกตช์) |
| {{key:Esc}} | ยกเลิกการเลือก (และยกเลิกการวางที่เคลื่อนตามตัวชี้) |

ในช่องตัวเลข ปุ่มเหล่านี้คัดลอกและวางข้อความตามปกติ ข้อความที่เลือกในพาเนลจะถูกคัดลอกโดยเบราว์เซอร์

| {{key:Backspace}} | ลบฟีเจอร์ที่เลือก เมื่อมีการเลือกฟีเจอร์ |
| {{key:Esc}} | หยุดเลือกระนาบสเกตช์ หรือล้างการเลือก (รวมถึงขอบหรือหน้าที่เลือกด้วย {{key:Shift}}) |

## ในมุมมอง 3 มิติ

คลิกในมุมมองก่อน เพื่อให้มุมมองมีโฟกัสของคีย์บอร์ด

| ปุ่ม | การทำงาน |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | หมุนมุมมอง 15 องศา |
| {{key:Shift+Left}} และลูกศรอื่น | แพน |
| {{key:Plus}} หรือ {{key:=}} | ซูมเข้า |
| {{key:Minus}} | ซูมออก |

| เมาส์ | การทำงาน |
|---|---|
| ลากด้วยปุ่มซ้าย | โคจรมุมมอง |
| ลากด้วยปุ่มขวาหรือปุ่มกลาง | แพน |
| {{key:Shift}}, {{key:Ctrl}} หรือ ⌘ ที่กดค้างไว้ขณะลากด้วยปุ่มซ้าย | แพน |
| หมุนล้อ | ซูมที่ตำแหน่งตัวชี้ (เลื่อนออกห่างจากตัว = ซูมเข้า) |
| ปัดสองนิ้วบนทัชแพด | หมุนมุมมอง; กับ {{key:Shift}} คือแพน การบีบซูม ตั้งค่าโดย **การเลื่อน** ใน [การตั้งค่า PartCraft](topic:settings) |

เมื่อ **การหมุนมุมมอง: ปุ่มกลาง** ใน [การตั้งค่า PartCraft](topic:settings) ปุ่มกลางจะหมุนมุมมอง {{key:Shift}} กับปุ่มกลางหรือปุ่มขวาจะแพน และปุ่มซ้ายใช้เลือกเท่านั้น
| คลิก | เลือกหน้า (จะไฮไลต์ทั้งหน้า) ขอบ หรือระนาบ |
| {{key:Shift}}+คลิกขอบหรือหน้า | รวบรวมขอบหรือหน้าหลายรายการ |
| คลิกพื้นที่ว่าง | ล้างการเลือก |

## ปุ่มลัดที่เบราว์เซอร์อาจใช้

- {{key:Mod+Y}} ใน Safari อาจเปิดประวัติ: ใช้ {{key:Mod+Shift+Z}} เพื่อทำซ้ำ
- {{key:Mod+D}} คือปุ่มบุ๊กมาร์กของเบราว์เซอร์: PartCraft ใช้ปุ่มนี้ขณะแอปมีโฟกัส และจะไม่ทำงานขณะพิมพ์ในช่อง
- {{key:F11}} และ {{key:Mod+Plus}} / {{key:Mod+Minus}} เป็นการเต็มหน้าจอและการซูมหน้าเว็บของเบราว์เซอร์ ไม่ใช่ของ PartCraft ใช้ {{key:Ctrl+Shift+F}} สำหรับเต็มหน้าจอ และใช้ล้อเลื่อนสำหรับโมเดล
- ปุ่มฟังก์ชันบนแล็ปท็อปและ Mac หลายรุ่นต้องใช้ปุ่ม Fn: กด Fn+{{key:F1}} เพื่อเปิดช่วยเหลือ หรือใช้ปุ่ม {{ui:ช่วยเหลือ}}

ท่าทางสัมผัสและทัชแพด: [ทัชแพด การสัมผัส และหน้าจอขนาดเล็ก](topic:trackpad-and-touch)

## ตำแหน่งของคำสั่งย้าย

คำสั่งย้ายอยู่ในเมนู {{ui:เพิ่มเติม}} ของกลุ่มฟีเจอร์ ในชื่อ {{ui:ย้ายชิ้นงาน}} ในกล่อง {{ui:ย้าย}} ที่พิมพ์ ΔX, ΔY และ ΔZ และเป็นลูกศร {{ui:ลากเพื่อย้าย}} บนชิ้นส่วน
