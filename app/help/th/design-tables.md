**การกำหนดค่า** (configuration) คือขนาดหนึ่งของชิ้นส่วน: ชุดค่าที่มีชื่อสำหรับพารามิเตอร์ของมัน ชิ้นส่วนเก็บการกำหนดค่าไว้ในไฟล์ของมันเอง จึงไปพร้อมกับชิ้นส่วน **ตารางการออกแบบ** (design table) คือสิ่งเดียวกันในรูปไฟล์ CSV หนึ่งแถวต่อหนึ่งการกำหนดค่า

การกำหนดค่าตั้งค่า**พารามิเตอร์** ดังนั้นให้เพิ่มพารามิเตอร์ก่อน (ดู [ขับเคลื่อนชิ้นส่วนด้วยพารามิเตอร์](topic:parameters)) การกำหนดค่าเก็บพารามิเตอร์ที่เป็นตัวเลขธรรมดา ส่วนพารามิเตอร์ที่คำนวณจากตัวอื่น (เช่น `area = w * d`) จะตามเองโดยอัตโนมัติ

## บันทึกการกำหนดค่า

1. ในแท็บ {{ui:Parameters}} ตั้งค่าพารามิเตอร์สำหรับขนาดหนึ่งของชิ้นส่วน
2. ภายใต้ **การกำหนดค่า** พิมพ์ชื่อ (เช่น `Large`) แล้วกด {{ui:Save current values}} หรือ {{key:Enter}}

การกำหนดค่าใหม่จะถูกทำเครื่องหมาย **ใช้งานอยู่** หากคุณเปลี่ยนพารามิเตอร์ภายหลัง จะขึ้นว่า **ใช้งานอยู่ เปลี่ยนแปลงตั้งแต่** ทำให้ทราบว่าชิ้นส่วนไม่ตรงกับการกำหนดค่านั้นอีกต่อไป

## สลับ อัปเดต เปลี่ยนชื่อ ลบ

- {{ui:Apply}} ตั้งพารามิเตอร์เป็นค่าของการกำหนดค่านั้นและสร้างชิ้นส่วนใหม่
- {{ui:Update}} บันทึกค่าปัจจุบันลงในการกำหนดค่านั้น
- หากต้องการเปลี่ยนชื่อ พิมพ์ชื่อใหม่ในช่องของมันแล้วกด {{key:Enter}}
- {{ui:Delete}} ลบการกำหนดค่า พารามิเตอร์ยังคงค่าของมันไว้

แต่ละอย่างเป็นหนึ่งขั้น {{key:Mod+Z}} จะย้อนกลับได้ หากเปลี่ยนชื่อพารามิเตอร์ ทุกการกำหนดค่าจะตามชื่อใหม่ หากลบการกำหนดค่าหนึ่ง มันจะหายไปจากทั้งหมด

## เปิดและปิดฟีเจอร์ในการกำหนดค่า

การกำหนดค่ายังเก็บว่าฟีเจอร์ใดถูกปิดอยู่ ดังนั้นชิ้นส่วนเดียวจะมีเวอร์ชัน **มี** และ **ไม่มี** บางอย่างได้: รูยึด การตัดมุม ส่วนนูน

1. ปิดฟีเจอร์: คลิกฟีเจอร์ในประวัติ แล้วกด {{ui:Suppress}} ใน {{ui:Properties}}
2. บันทึกการกำหนดค่าตามปกติ เช่น `No holes` แถวของมันจะแสดงสิ่งที่ปิดไว้
3. เปิดฟีเจอร์กลับ ({{ui:Unsuppress}}) แล้วบันทึกการกำหนดค่าอีกอัน เช่น `With holes`

เมื่อมีการกำหนดค่าใดปิดฟีเจอร์ การใช้การกำหนดค่าจะปิดฟีเจอร์ของมัน และ **เปิดฟีเจอร์อื่นทุกตัว** พร้อมค่าพารามิเตอร์ของมัน ในขั้นตอนเดียว การกำหนดค่าที่บันทึกก่อนมีการปิดฟีเจอร์ใดเลยนับว่า "เปิดทั้งหมด" {{ui:Update}} บันทึกฟีเจอร์ตามที่เป็นอยู่ตอนนี้พร้อมค่า

ชิ้นส่วนที่การกำหนดค่าปิดฟีเจอร์จะถูกบันทึกเป็นเวอร์ชันไฟล์ที่ใหม่กว่า PartCraft รุ่นเก่าจะแจ้งว่าไฟล์มาจากเวอร์ชันที่ใหม่กว่า แทนที่จะเปิดโดยไม่มีฟีเจอร์เหล่านั้น

:::note
ตารางการออกแบบ CSV มีเพียงค่าพารามิเตอร์ การนำเข้าตารางทับการกำหนดค่าจะเปลี่ยนค่าของมันและยังคงฟีเจอร์ที่ปิดไว้ ส่วน `--table` ของบรรทัดคำสั่งสร้างเฉพาะค่า
:::

ไฟล์ชิ้นส่วนถูกบันทึกพร้อมการกำหนดค่าและการกำหนดค่าที่ใช้งานอยู่ ชิ้นส่วนจะเปิดด้วยค่าที่บันทึกไว้

## นำตารางการออกแบบเข้าหรือออก

ตารางการออกแบบคือไฟล์ CSV ที่มีคอลัมน์สำหรับแต่ละพารามิเตอร์ และแถวสำหรับแต่ละการกำหนดค่า:

```
name,width,thick,bolt
small,100,6,6.6
medium,140,8,8.5
large,200,12,13
```

คอลัมน์แรกอาจชื่อ `name`, `config` หรือ `configuration` ส่วนคอลัมน์อื่นทุกคอลัมน์ต้องเป็นชื่อของพารามิเตอร์ของชิ้นส่วน ค่าในช่องเป็นตัวเลข มีหน่วยได้หากต้องการ (`8in`) ช่องว่างจะไม่ใส่พารามิเตอร์นั้นในแถว

- {{ui:Import CSV}} เพิ่มแต่ละแถวเป็นการกำหนดค่า แถวที่มีชื่อของการกำหนดค่าที่มีอยู่แล้วจะแทนที่การกำหนดค่านั้น การนำเข้าเป็นหนึ่งขั้น
- {{ui:Export CSV}} เขียนการกำหนดค่าออก หากยังไม่มีการกำหนดค่า จะเขียนหนึ่งแถวของค่าปัจจุบัน ซึ่งเป็นจุดเริ่มต้นสำหรับสเปรดชีต

ชื่อการกำหนดค่าที่สเปรดชีตจะอ่านเป็นสูตร (ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@`) จะถูกเขียนโดยมี `'` นำหน้า

## ทุกขนาดพร้อมกัน

{{ui:Variant pack…}} ภายใต้ **การกำหนดค่า** สร้างทุกการกำหนดค่า หรือเพียงบางอัน เป็น STEP, IFC, DWG และตัวอย่างในไฟล์ zip เดียว พร้อมตารางพารามิเตอร์ของมัน: ดู [สร้างชุดตัวแปรจากการกำหนดค่าของคุณ](topic:variant-pack)

เครื่องมือบรรทัดคำสั่งสร้างหนึ่งไฟล์ต่อหนึ่งแถวของตารางการออกแบบ CSV:

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

ส่งออกการกำหนดค่าเป็น CSV ก่อน แล้วส่งไฟล์นั้นด้วย `--table` ดู [สคริปต์และบรรทัดคำสั่ง](topic:scripts-and-cli) ชิ้นส่วนที่บันทึกเป็นสคริปต์จะเก็บการกำหนดค่าไว้ในบรรทัด `configs json …`
