ปรับรูปร่างโมเดลต่อในที่ที่สร้างมัน แล้วทำการผลิต ตรวจสอบ และจัดทำเอกสารที่นี่ การเปลี่ยนแปลงในอีกโปรแกรมแต่ละครั้งจะแทนที่บอดี้ที่นำเข้าหนึ่งชิ้นใน PartCraft และฟีเจอร์ที่อยู่หลังจากนั้นจะสร้างใหม่บนรูปทรงใหม่

:::note
การเชื่อมต่อต้องใช้ **CadCraft Studio** บนคอมพิวเตอร์เครื่องเดียวกัน แท็บเบราว์เซอร์ไม่สามารถรับการเชื่อมต่อได้ ไม่มีข้อมูลส่งผ่านอินเทอร์เน็ต: สคริปต์คุยกับ Studio ที่ที่อยู่ของเครื่องนี้เอง พร้อมโทเคน
:::

:::warning
การเชื่อมต่อนี้ทดสอบด้วยตัวเขียนไฟล์ของสคริปต์และตัวแทนของอีกโปรแกรม ยังไม่ได้ทดสอบภายใน Rhino หรือ Grasshopper เอง หากมีอะไรล้มเหลวที่นั่น โปรดแจ้งข้อความที่ระบบแสดงให้เราทราบ
:::

## การตั้งค่า

1. ใน Studio เปิด PartCraft ใน {{ui:การตั้งค่า}} › {{ui:PartCraft}} › {{ui:ผู้ช่วย}} ทำเครื่องหมาย **ให้ผู้ช่วย AI และสคริปต์ใช้ PartCraft** แล้วจึง **แก้ไข**
2. ใน Studio เลือก {{ui:เชื่อมต่อผู้ช่วย}} ระบบจะแสดงที่อยู่และโทเคนที่จะวางด้านล่าง
3. ดาวน์โหลดสคริปต์: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)

## จาก Rhino

1. รัน `cadcraft_link.py` ใน script editor ของ Rhino (Python 3 ใน Rhino 8)
2. ครั้งแรก วางที่อยู่และโทเคน ระบบจะเก็บไว้ในไฟล์ `.cadcraft-link.json` ในโฟลเดอร์หลักของเครื่อง ไม่เก็บในโมเดล Studio จะสร้างโทเคนใหม่ทุกครั้งที่เริ่มทำงาน ดังนั้นสคริปต์จะถามอีกครั้งตอนนั้น

รันสคริปต์อีกครั้งเพื่อหยุด

## จาก Grasshopper

รันสคริปต์หนึ่งครั้งใน Rhino ก่อน เพื่อบันทึกที่อยู่และโทเคน

1. เพิ่มคอมโพเนนต์ Script (Python 3) และวาง `cadcraft_link.py` ทั้งหมดลงไป
2. ตั้งอินพุตเหล่านี้: `G` (เรขาคณิต พร้อมการเข้าถึงแบบลิสต์), `N` (ชื่อ ไม่บังคับ), `On` (สวิตช์ boolean) และ `Target` (ไม่บังคับ: `model` หรือ `part` หากเปิดทั้งสองแอป)
3. ตั้ง `On` เป็น true

ทุกครั้งที่คำนวณ (solve) จะส่ง `G` ไปและแทนที่สิ่งที่คอมโพเนนต์ส่งครั้งก่อน

## การทำงานในที่นี้

- **บอดี้เดียว** ทุกสิ่งที่มองเห็นในโมเดลจะกลายเป็นฟีเจอร์นำเข้าหนึ่งชิ้น เหมือนเมื่อ[เปิดไฟล์ .3dm](topic:open-3dm-files)
- **ต้องปิดสนิท** PartCraft จะอุดรูเล็กและช่องเปิดแบนๆ และอีกโปรแกรมจะได้รับแจ้งจำนวนนั้น หากโมเดลยังไม่ปิดสนิท PartCraft จะเก็บบอดี้เดิมไว้ และแถบสถานะจะแจ้งให้ทราบ การเปลี่ยนแปลงครั้งถัดไปที่ทำให้ปิดสนิทจะอัปเดตบอดี้
- **ทำงานที่กำลังทำให้เสร็จก่อน** ในสเกตช์หรือแบบ การอัปเดตจะถูกปฏิเสธและลองใหม่ จะเข้ามาเมื่อกลับมาอยู่ในโมเดลแล้ว
- **เลิกทำ** การอัปเดตที่ห่างกันไม่เกินสองวินาทีจะใช้ขั้นตอนเลิกทำร่วมกัน
- **บันทึก** ไฟล์ชิ้นส่วนจะเก็บการเชื่อมต่อไว้ รันสคริปต์อีกครั้งหลังเปิดไฟล์ใหม่ แล้วฟีเจอร์เดิมจะอัปเดต

**ทางเดียวเท่านั้น** การเปลี่ยนแปลงที่นี่จะไม่ส่งกลับไปยังอีกโปรแกรม

## หากมีปัญหา

- **"ไม่มีหน้าต่าง ModelCraft หรือ PartCraft ที่อนุญาตให้ทำ":** ทำขั้นตอนที่ 1 ของการตั้งค่า
- **"Studio ปฏิเสธโทเคน":** Studio เริ่มทำงานใหม่แล้ว คัดลอกโทเคนใหม่และรันสคริปต์อีกครั้ง สำหรับ Grasshopper ให้รันใน Rhino ก่อน
- **"ไม่สามารถเข้าถึง CadCraft Studio":** Studio ไม่ได้ทำงานอยู่ หรือที่อยู่เปลี่ยนไปแล้ว
