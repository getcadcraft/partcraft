**รุ่นตัวอย่าง** การเขียนสคริปต์เป็นฟีเจอร์ใหม่ใน PartCraft 0.3 และยังอยู่ในรุ่นตัวอย่าง ภาษา ไลบรารี และวิธีบันทึกสคริปต์อาจเปลี่ยนแปลงได้ สคริปต์ที่เขียนตอนนี้อาจต้องแก้เล็กน้อยในภายหลัง แจ้งให้เราทราบหากมีส่วนใดใช้งานไม่ได้

พื้นที่ทำงานสคริปต์รันการคำนวณของคุณเองควบคู่กับชิ้นส่วน ตั้งแต่ผลรวมเล็ก ๆ ไปจนถึงการวิเคราะห์ทั้งชุด หรือสคริปต์ใน[ไลบรารีการวิเคราะห์](topic:craftscript-library) สคริปต์เขียนด้วย **CraftScript** (ภาษาเมทริกซ์คล้าย MATLAB ดู [ภาษา CraftScript](topic:craftscript-language)) หรือ **Lua** (ดู [สคริปต์ใน Lua](topic:craftscript-lua)) หรือ **Python** (ดู [สคริปต์ใน Python](topic:craftscript-python))

เลือก **สคริปต์** ในกล่อง **พื้นที่ทำงาน** ทางซ้ายของแถบเครื่องมือ ชิ้นส่วนจะไม่ถูกเปลี่ยนแปลง พาเนลด้านขวาจะกลายเป็นพาเนลสคริปต์ (กว้างกว่าปกติ ลากขอบเพื่อปรับขนาด หรือย้ายไปยังจอที่สองด้วยเมนู {{ui:⋯}} ดู [การจัดวางพาเนล](common:arrange-panels))

## เขียนสคริปต์ระหว่างการสร้างแบบ

คุณไม่จำเป็นต้องออกจากพื้นที่ทำงานดีไซน์เพื่อเขียนสคริปต์ ในดีไซน์ แท็บ {{ui:Script}} ของพาเนลด้านขวามีตัวแก้ไข คอนโซล ตัวแปร และไลบรารีชุดเดียวกัน พร้อมสคริปต์เดียวกัน ต้นไม้ฟีเจอร์และมุมมองยังทำงานต่อได้: คลิกฟีเจอร์เพื่อเลือก ดับเบิลคลิกสเกตช์เพื่อแก้ไข หมุนมุมมอง แล้วกลับไปที่แท็บ {{ui:Script}} และกด {{key:F5}}

สิ่งที่สคริปต์ **แสดง** (เมช ฟิลด์ กราฟ ตาราง) จะไม่ถูกวาดทับโมเดลของคุณในดีไซน์ คอนโซลจะแจ้งไว้ และพื้นที่ทำงานสคริปต์จะมีทั้งหมดเมื่อคุณสลับไปที่นั่น

{{ui:Pop out}} อยู่ข้างปุ่ม {{ui:Run}} ย้ายพาเนลทั้งหมดไปยังหน้าต่างของตัวเอง เช่น บนจอที่สอง เพื่อให้ตัวแก้ไขกับมุมมองเต็มวางคู่กัน {{ui:Put back}} จะนำกลับมาติดที่เดิม ดู [การจัดวางพาเนล](common:arrange-panels)

## รันสคริปต์แรกของคุณ

1. พิมพ์ในตัวแก้ไข เช่น:

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. กด {{key:F5}} (หรือ {{ui:Run}}) คอนโซลใต้ตัวแก้ไขจะแสดงสิ่งที่สคริปต์พิมพ์ และ "เสร็จใน … s" กราฟจะปรากฏใน **จอแสดงผลย่อย** ที่ด้านล่างของมุมมอง 3 มิติ
3. บรรทัดที่ไม่มีเซมิโคลอนจะพิมพ์ค่าของมัน เหมือนใน MATLAB: `a = 3` พิมพ์ `a = 3` ส่วน `a = 3;` ไม่พิมพ์อะไร
4. หากต้องการรันเฉพาะบางส่วนของสคริปต์ ให้เลือกบรรทัดแล้วกด {{key:Mod+Enter}} ({{ui:Selection}}) หากไม่ได้เลือกอะไร จะรันบรรทัดที่เคอร์เซอร์อยู่
5. บรรทัดที่ด้านล่างของคอนโซล (หลัง `>>`) รันหนึ่งคำสั่งเมื่อคุณกด {{key:Enter}} {{key:Up}} และ {{key:Down}} เรียกบรรทัดก่อนหน้ากลับมา

## ค้นหา พับ และเติมให้สมบูรณ์

- **ค้นหาและแทนที่** กด {{key:Mod+F}} (หรือ {{key:Mod+H}} เพื่อแทนที่ด้วย) แถบจะเปิดขึ้นเหนือโค้ด: พิมพ์สิ่งที่ต้องการค้นหา รายการที่ตรงกันจะไฮไลต์และตัวนับบอกตำแหน่ง ปุ่มข้างช่องคือ match case (**Aa**) ค้นทั้งคำ (**W**) และนิพจน์ปกติ (**.\***; ในช่องแทนที่ `$1` ใส่สิ่งที่กลุ่มแรกจับได้กลับเข้าไป) {{ui:Replace}} แทนที่รายการปัจจุบัน {{ui:All}} แทนที่ทุกรายการเป็นหนึ่งขั้นของ {{key:Mod+Z}}
- **การพับ** คลิก ▾ ข้างหมายเลขบรรทัด หรือกด {{key:Mod+Shift+[}} เมื่อเคอร์เซอร์อยู่บนบรรทัด `function`, `if`, `for`, `while`, `switch` หรือ `try` (Lua: `function`, `do`, `if`, `repeat`) เพื่อซ่อนบรรทัดข้างในไว้ บรรทัดนั้นจะบอกจำนวนที่ซ่อน ▸ หรือ {{key:Mod+Shift+]}} จะเปิดอีกครั้ง การพับเพียงซ่อนบรรทัด การรัน การบันทึก การคัดลอก และหมายเลขบรรทัดยังนับทุกบรรทัด และการพิมพ์บนบรรทัดที่พับอยู่จะเปิดออกก่อน
- **การเติมคำ** พิมพ์สองตัวอักษรแรกของชื่อ หรือกด {{key:Mod+Space}}: รายการจะแสดงตัวแปรที่คุณมี ฟังก์ชันของภาษา (พร้อมอาร์กิวเมนต์) คีย์เวิร์ด และชื่อที่มีอยู่แล้วในสคริปต์ เลือกด้วยลูกศรแล้วกด {{key:Enter}} หรือ {{key:Tab}}

## เมื่อมีอะไรผิดพลาด

- ข้อผิดพลาดจะระบุปัญหาและบรรทัด: บรรทัดจะถูกทำเครื่องหมายเป็นสีแดงในตัวแก้ไข และ **Line n** ในคอนโซลจะพาไปยังบรรทัดนั้น
- ลูปที่ไม่มีวันจบ: กด {{ui:Stop}} (บนแถบเครื่องมือหรือพาเนล) สคริปต์จะหยุดทันที ตัวแปรยังคงค่าที่มีก่อนการรันนั้น
- การรันทุกครั้งมีงบขั้นตอนด้วย (ค่าเริ่มต้น 2 พันล้านขั้นตอน เปลี่ยนได้ที่ **Run options** ในพาเนล) การรันที่เกินงบจะหยุดพร้อมข้อความ

## ตัวแปรส่งต่อจากสคริปต์หนึ่งไปอีกสคริปต์

ตัวแปรระดับบนสุดทุกตัวที่สคริปต์สร้างจะไปอยู่ในแท็บ **ตัวแปร** (ชื่อ ชนิด ขนาด ค่าที่เล็กและใหญ่ที่สุด) และคงอยู่สำหรับสคริปต์ถัดไป ไม่ว่าจะใช้ภาษาใด นั่นคือวิธีที่สคริปต์หนึ่งสร้างเมช อีกสคริปต์แก้สมการ และสคริปต์ที่สามพล็อตกราฟ

- คลิกตัวแปรเพื่อแสดง: เมช ฟิลด์ และโมเดลในมุมมอง 3 มิติ อาร์เรย์เป็นตาราง (พร้อมกราฟเส้นสำหรับเวกเตอร์หรือแผนที่สีสำหรับเมทริกซ์) ในจอแสดงผลย่อย
- {{ui:Save as JSON}}, {{ui:Save as CSV}} (ตารางตัวเลข) และ {{ui:Save as HDF5}} ดาวน์โหลดตัวแปร {{ui:Delete}} ลบตัวแปร {{ui:Clear all}} ล้างพื้นที่ทำงาน
- ทำเครื่องหมาย **บันทึกตัวแปรพร้อมชิ้นส่วน** เพื่อเก็บไว้ในไฟล์ชิ้นส่วน (สูงสุด 32 MB ไฟล์ที่ใหญ่กว่านั้นจะอยู่เพียงในการเข้าชมนี้) เมื่อเปิดชิ้นส่วนดังกล่าว พาเนลจะเสนอให้โหลดตัวแปรเหล่านั้น

## เมช ฟิลด์ และกราฟ

- `show(m)` วาดเมช และ `show(f)` ระบายสีฟิลด์บนเมชพร้อมคำอธิบายสี รายการ **ที่แสดง** ที่มุมซ้ายบนของมุมมองจะซ่อน ({{ui:eye}}) หรือนำออกแต่ละรายการ และซ่อนหรือแสดงตัวชิ้นส่วนเอง ใต้คำอธิบายสี พิมพ์ช่วงได้ (**From**, **to**) หรือกด {{ui:Auto}} ฟิลด์เวกเตอร์หรือความเค้นยังเลือกองค์ประกอบที่จะแสดงได้
- `show(f, 'deform', u, 'scale', 50)` วาดเมชที่เลื่อนด้วยฟิลด์การเคลื่อนที่ `u` ขยายขึ้น 50 เท่า (ถ้าไม่มี `scale` จะขยายราว 8 % ของขนาดโมเดล)
- คลิกเมชที่แสดง: โนดที่ใกล้ที่สุด องค์ประกอบ และค่าฟิลด์ตรงนั้นจะปรากฏในจอแสดงผลย่อย (**Picked**)
- `plot`, `imagesc` และ `table` ใส่กราฟเส้น แผนที่สีของอาร์เรย์ 2 มิติ หรือตารางลงในจอแสดงผลย่อย กราฟที่มี `'id'` (หรือชื่อ) เดียวกับกราฟก่อนหน้าจะแทนที่กราฟนั้น ดังนั้นลูปจึงอัปเดตกราฟการลู่เข้าเพียงกราฟเดียวได้ `'append', true` เพิ่มเส้นโค้งเข้าไป {{ui:Clear}} ล้างจอแสดงผลย่อย และลูกศรจะพับเก็บ
- เมื่อมีกราฟสองกราฟขึ้นไป {{ui:Side by side}} แสดงทั้งหมดพร้อมกัน (หกอันล่าสุด) การคลิกแท็บของตารางหรือภาพจะแสดงเฉพาะอันนั้นอีกครั้ง
- กราฟทุกอันมี {{ui:PNG}}, {{ui:SVG}} และ {{ui:CSV}} อยู่ด้านล่าง PNG และ SVG พิมพ์บนพื้นขาวด้วยสีของกระดาษ ไม่ว่าธีมจะเป็นอะไร (PNG 1600 × 1000 พิกเซล SVG ขยายได้โดยไม่เบลอ) CSV เก็บตัวเลขทุกหลัก: คอลัมน์ x หนึ่งคอลัมน์และคอลัมน์ต่อเส้นโค้งเมื่อเส้นโค้งใช้ x ร่วมกัน ไม่เช่นนั้นจะมีหนึ่งแถวต่อจุด พร้อมชื่อของเส้นโค้ง
- {{key:F}} หรือ {{ui:Fit}} ปรับมุมมองให้พอดีกับสิ่งที่แสดง

## ไฟล์

- {{ui:Open}} ในกลุ่ม **สคริปต์** (หรือวางไฟล์บนมุมมองหรือพาเนล): ไฟล์ `.craft`, `.lua` และ `.py` เปิดเป็นสคริปต์ใหม่ (ไม่รัน) ไฟล์ข้อมูล (STL, OBJ, CSV, JSON, NPY, HDF5) จะโหลดเข้าตัวแปรภายใต้ชื่อไฟล์
- {{ui:Save}} ในกลุ่ม **สคริปต์** ดาวน์โหลดสคริปต์ปัจจุบันเป็นไฟล์
- {{ui:New}} ในกลุ่ม **สคริปต์** (หรือ {{ui:+}} ข้างแท็บ) เริ่มสคริปต์อีกตัว ดับเบิลคลิกแท็บเพื่อเปลี่ยนชื่อ ปุ่ม {{ui:×}} ของแท็บจะนำออก (เลิกทำได้)

## อ่านพารามิเตอร์ของชิ้นส่วน

สคริปต์อ่านพารามิเตอร์ของชิ้นส่วน (ดู [ขับเคลื่อนชิ้นส่วนด้วยพารามิเตอร์](topic:parameters)) ด้วยชื่อ:

```
w = param('width');     % ค่าของพารามิเตอร์หนึ่งตัว หน่วย mm (หรือองศา หรือตัวเลขธรรมดา)
p = params();           % ทั้งหมด เป็นสตรักต์: p.width, p.height
```

ใน Lua และ Python คือ `cs.param('width')` และ `cs.params()` สคริปต์อ่านพารามิเตอร์ได้อย่างเดียว: เปลี่ยนค่าในแท็บ {{ui:Parameters}} ใต้แท็บของสคริปต์ บรรทัดหนึ่งจะแสดงพารามิเตอร์ที่สคริปต์อ่านด้วย `param('…')` และทำเครื่องหมายพารามิเตอร์ที่ชิ้นส่วนไม่มี แท็บ {{ui:Parameters}} จะแสดงสคริปต์ใต้พารามิเตอร์แต่ละตัว ชื่อที่สร้างขึ้นระหว่างการรัน เช่น `param(name)` จะไม่ถูกแสดงในรายการ

## สคริปต์ถูกบันทึกในชิ้นส่วน

สคริปต์ทุกตัวในแท็บจะถูกเก็บไว้ในชิ้นส่วน ดังนั้น {{ui:Save}} ในกลุ่มไฟล์จะบันทึกสคริปต์ไปพร้อมกัน และการเปลี่ยนแปลงสามารถเลิกทำได้ การเปิดชิ้นส่วน **จะไม่รันสคริปต์ของมันเลย** คอนโซลจะบอกจำนวนสคริปต์ที่มี และสคริปต์จะรันเมื่อคุณกด {{ui:Run}} เท่านั้น ชิ้นส่วนจากผู้อื่นอาจมีสคริปต์ใดก็ได้ ให้อ่านก่อนรัน สคริปต์รันเบื้องหลังบนคอมพิวเตอร์เครื่องนี้โดยไม่มีการเข้าถึงเครือข่าย และแตะหน้าเว็บไม่ได้
