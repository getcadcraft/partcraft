เรขาคณิตอ้างอิงคือโครงที่ใช้สร้างฟีเจอร์: **ระนาบ** สำหรับเขียนสเกตช์ในตำแหน่งที่ไม่มีหน้า **แกน** สำหรับหมุนหรือทำแพตเทิร์นรอบ และ **จุด** สำหรับหยุดการเอ็กซ์ทรูด ไม่มีเนื้อวัสดุของตัวเอง ระนาบแสดงในมุมมองเป็นสี่เหลี่ยมสีอ่อน แกนเป็นเส้นประ จุดเป็นเครื่องหมายกากบาทเล็ก ทั้งสามอย่างเข้าไปอยู่ในประวัติและจะตามสิ่งที่ใช้สร้างมันเมื่อคุณเปลี่ยนขนาดในขั้นก่อนหน้า

ทั้งหมดอยู่ในเมนู {{ui:เพิ่มเติม}} ของกลุ่มฟีเจอร์: {{ui:ระนาบ}}, {{ui:แกน}}, {{ui:จุด}}

## สร้างระนาบ

1. คลิกหน้าเรียบ หรือระนาบฐานในประวัติเพื่อเริ่มจากตรงนั้น (ไม่บังคับ)
2. เลือก {{ui:เพิ่มเติม}} แล้วเลือก {{ui:ระนาบ}} ระนาบจะเริ่มเป็นระนาบเยื้องห่างจากสิ่งที่คุณเลือก (หรือจากระนาบบน) 20 % ของขนาดชิ้นส่วน
3. ในพาเนลด้านขวา เลือก **ประเภท** และการอ้างอิงของมัน:

| ประเภท | การอ้างอิง | ตัวเลข |
|---|---|---|
| เยื้องจากระนาบหรือหน้า | **จากระนาบ** | **ระยะ (mm)** ค่าลบสำหรับอีกด้าน |
| ทำมุมที่ผ่านขอบหรือแกน | **จากระนาบ**, **หมุนรอบ** (แกนโลก ฟีเจอร์แกน หรือขอบตรงที่เลือก) | **มุม (°)** |
| ผ่านสามจุด | **จุดที่ 1**, **จุดที่ 2**, **จุดที่ 3** | — |
| มิดเพลนระหว่างสองระนาบ | **ระนาบที่หนึ่ง**, **ระนาบที่สอง** (ขนาน: อยู่กึ่งกลาง; ตัดกัน: ระนาบที่แบ่งมุมครึ่งหนึ่ง) | — |
| สัมผัสทรงกระบอก | **ทรงกระบอก** (หน้าทรงกระบอก), **จุดใกล้** (อยู่ด้านไหน) | — |
| ตั้งฉากกับขอบ ที่จุด | **ขอบ**, **ที่จุด** (ระนาบผ่านจุดบนขอบที่ใกล้ที่สุด และผ่านจุดนั้นด้วย) | — |
| ผ่านขอบและจุด | **ขอบตรง** (หรือแกน), **ผ่านจุด** | — |
| ตั้งฉากกับขอบที่กึ่งกลาง | **ขอบ** (ตั้งฉากตรงจุดกึ่งกลางของขอบ) หรือถ้าไม่มีขอบ **จุดที่ 1** และ **จุดที่ 2** (ระนาบอยู่กึ่งกลางระหว่างสองจุด) | — |

ทุกการอ้างอิงมีปุ่ม **เลือก** เลือกปุ่มนั้นแล้วคลิกในมุมมอง ช่องระนาบรับระนาบฐาน ระนาบอ้างอิง หรือหน้าเรียบ ช่องจุดรับปลายของขอบ (คลิกใกล้ปลายนั้น) ฟีเจอร์จุด หรือตำแหน่งบนหน้า ช่องขอบรับขอบ {{key:Esc}} ยกเลิกการเลือก **กลับทิศทางเส้นตั้งฉาก** พลิกระนาบกลับ (สเกตช์บนระนาบจะหันไปทางใด)

ในเวอร์ชันนี้ ช่องที่ต้องการขอบหรือหน้าทรงกระบอก (สัมผัสทรงกระบอก และช่องขอบ) จะตอบว่า "ยังไม่ได้สร้าง" ให้ใช้จุดหรือแกนแทน

## เขียนสเกตช์บนระนาบ

เลือกระนาบ (ในประวัติ หรือคลิกสี่เหลี่ยมในมุมมอง) แล้วเลือก {{ui:สเกตช์}} หรือ **สร้างสเกตช์บนระนาบนี้** ในพาเนลของมัน สเกตช์จะตามระนาบ เมื่อคุณเปลี่ยนระยะของระนาบ สเกตช์และฟีเจอร์ทุกอย่างบนมันจะเคลื่อนที่ตามไปด้วย

## แกนและจุด

- {{ui:แกน}}: ผ่านสองจุด แกนของทรงกระบอกหรือกรวย ตรงที่สองระนาบตัดกัน ตามขอบตรง (หรือแกนของขอบวงกลม) หรือตั้งฉากกับหน้าที่จุดหนึ่ง
- {{ui:จุด}}: ที่พิกัด ที่จุดยอดหรือจุดสเกตช์ หรือที่จุดศูนย์กลางของขอบวงกลม รวมถึงจุด "ระหว่างวัตถุ":

| ประเภทจุด | การอ้างอิง |
|---|---|
| กึ่งกลางของขอบ (หรือระหว่างสองจุด) | **ขอบ** (อยู่กึ่งกลางตามความยาว รวมถึงส่วนโค้งและเส้นโค้ง) หรือถ้าไม่มีขอบ **จุดที่ 1** และ **จุดที่ 2** |
| ที่ขอบหรือแกนตัดกับหน้าหรือระนาบ | **ขอบ** (ตรงหรือโค้ง) หรือแกน และ **ตัดระนาบ** (ระนาบหรือหน้าเรียบ) หรือ **หรือหน้า** (หน้าเรียบหรือทรงกระบอก) วงกลมตัดระนาบสองครั้ง และเส้นตรงทะลุทรงกระบอกสองครั้ง: **การตัดอีกจุด** ใช้จุดที่สอง |
| ที่ระนาบสามระนาบตัดกัน | **ระนาบที่หนึ่ง**, **ระนาบที่สอง** และ **ระนาบที่สาม** (ระนาบหรือหน้าเรียบ) |

แต่ละแบบจะแจ้งข้อความธรรมดาเมื่อการอ้างอิงไม่เข้ากัน: เส้นขนานกับระนาบ เส้นที่ไม่โดนทรงกระบอก ขอบที่ไม่ถึงระนาบ ระนาบสามอันที่ไม่ตัดกันที่จุดเดียว หรือจุดที่อยู่บนเส้นที่ควรใช้กำหนดระนาบ

ใช้ในฟีเจอร์อื่นได้ดังนี้:

| ที่ไหน | วิธี |
|---|---|
| หมุนรอบแกน | **แกน**: เลือกฟีเจอร์แกนจากรายการ (ต้องอยู่ในระนาบของสเกตช์) |
| แพตเทิร์นวงกลม | **แกน**: ฟีเจอร์แกน |
| แพตเทิร์นเชิงเส้น | **ทิศทาง**: ฟีเจอร์แกน หรือระนาบ (เส้นตั้งฉากของมัน) |
| สะท้อน | **ระนาบสะท้อน**: ระนาบอ้างอิง |
| เอ็กซ์ทรูด | **สิ้นสุด**: ถึงหน้าหรือระนาบ, ถึงจุดยอด (ฟีเจอร์จุด) ยังไม่ได้สร้างในเวอร์ชันนี้ (ต้องใช้เคอร์เนลที่แม่นยำ) |
| ดราฟต์ | **ระนาบนิวทรัล** |

## เมื่อการอ้างอิงหายไป

ระนาบที่สร้างจากหน้าที่ไม่มีอยู่อีกต่อไปจะล้มเหลวพร้อมข้อความที่ระบุหน้านั้น เช่น "หน้าที่มันอยู่หายไปจาก Extrude1" ระนาบจะไม่ถูกย้ายไปยังหน้าอื่นเด็ดขาด สเกตช์และฟีเจอร์บนระนาบจะถูกทำเครื่องหมาย "ยังไม่ได้สร้าง" จนกว่าคุณจะเลือกการอ้างอิงใหม่ ส่วนอื่นของชิ้นส่วนยังคงเดิม

เวอร์ชันนี้สร้างชิ้นส่วนทั้งหมดด้วยเคอร์เนลเมช ซึ่งสร้างระนาบ แกน และจุดจากระนาบฐาน หน้าเรียบที่สร้างจากเอ็กซ์ทรูดหรือหมุนรอบแกน จุดสเกตช์ พิกัด และฟีเจอร์อ้างอิงอื่น สิ่งใดที่ต้องใช้ขอบ ปลายขอบ หรือหน้าโค้ง ต้องใช้เคอร์เนลที่แม่นยำ: ยังไม่ได้สร้างในเวอร์ชันนี้ ("It uses a face or edge of the solid, which only an exact kernel can find: not built yet in this version.")
