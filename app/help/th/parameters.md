**พารามิเตอร์** คือตัวเลขที่มีชื่อ เช่น `width = 120` หรือ `margin = bolt * 1.5` เชื่อมความลึก เส้นผ่านศูนย์กลางรู จำนวนแพตเทิร์น หรือไดเมนชันสเกตช์เข้ากับพารามิเตอร์ แล้วการเปลี่ยนพารามิเตอร์จะเปลี่ยนทั้งหมดในขั้นตอนเดียว วิธีนี้ช่วยเก็บเจตนาการออกแบบไว้ในชิ้นส่วน แทนที่จะอยู่แค่ในความคิด

## เพิ่มพารามิเตอร์

1. ในพาเนลด้านขวา คลิกแท็บ {{ui:Parameters}}
2. ภายใต้ **ตัวแปร** พิมพ์ชื่อในช่องชื่อ เช่น `width`
3. พิมพ์ค่าในช่องถัดไป เช่น `120` แล้วกด {{key:Enter}} (หรือคลิก {{ui:Add}})

ค่าอาจเป็นตัวเลขหรือนิพจน์ของพารามิเตอร์อื่น: `bolt * 1.5`, `width / 2 - 10`, `if(width > 100, 6, 4)` คอลัมน์ **ค่า** แสดงผลที่คำนวณได้ ชื่อขึ้นต้นด้วยตัวอักษรหรือ `_` และมีได้เฉพาะตัวอักษร ตัวเลข และ `_` ชื่อของฟังก์ชันและหน่วย (`sin`, `mm`, `pi`) จะถูกปฏิเสธ และการวนซ้ำ เช่น `a = b` กับ `b = a` ก็ถูกปฏิเสธด้วย

## เชื่อมตัวเลขกับพารามิเตอร์

1. คลิกฟีเจอร์ในประวัติ เช่น "Extrude1" การตั้งค่าจะปรากฏในแท็บ {{ui:Properties}}
2. ในช่องตัวเลข เช่น **Depth (mm)** พิมพ์ `=` และนิพจน์: `=thick` หรือ `=width / 4`
3. กด {{key:Enter}}

ช่องจะแสดงผลลัพธ์ และปุ่ม **ƒ** จะปรากฏถัดจากชื่อ ชี้ที่ปุ่มเพื่อดูสมการ ไดเมนชันสเกตช์ทำงานเหมือนกัน ทั้งในรายการ **ไดเมนชันของสเกตช์** ของฟีเจอร์ และในช่องไดเมนชันของสเกตช์ที่เปิดอยู่ (ดับเบิลคลิกไดเมนชัน พิมพ์ `=width` แล้วกด {{key:Enter}})

ตัวเลขที่เชื่อมได้: ความลึกของเอ็กซ์ทรูด มุมการหมุน เส้นผ่านศูนย์กลางรู ความลึกและขนาดเคาน์เตอร์บอร์ จำนวนแพตเทิร์น ระยะห่างและมุมของแพตเทิร์น รัศมีฟิลเลต ระยะชัมเฟอร์ ความหนาผนังของเชลล์ ทุกไดเมนชันของสเกตช์ และขนาดของฟีเจอร์ใหม่ (ความลึกที่สอง ความเรียว เคาน์เตอร์ซิงก์ ระยะระนาบอ้างอิง มุมดราฟต์ และอื่นๆ)

## เปลี่ยนพารามิเตอร์

ในแท็บ {{ui:Parameters}} พิมพ์ค่าหรือนิพจน์ใหม่ในคอลัมน์ **Expression** แล้วกด {{key:Enter}} ทุกอย่างที่เชื่อมอยู่จะเปลี่ยน และชิ้นส่วนจะสร้างใหม่ เป็นหนึ่งขั้นตอน: {{key:Mod+Z}} เลิกทำได้

ในการเปลี่ยนตัวเลขจากอีกด้าน ดู [สมการสองทาง](topic:equations-two-way)

## ดูว่าพารามิเตอร์ถูกใช้ที่ไหน

ใต้แต่ละพารามิเตอร์ในแท็บ {{ui:Parameters}} จะมีบรรทัดบอกว่าอะไรใช้มัน:

- ตัวเลขที่มันขับเคลื่อน เช่น **Extrude1 depth** หรือ **Sketch1 D2 (distance)** คลิกเพื่อเลือกฟีเจอร์นั้นและแสดงคุณสมบัติ;
- ตัวเลขที่มันขับเคลื่อน **ผ่าน** พารามิเตอร์อื่น เช่น **Hole1 diameter (through h, d)** เมื่อ `d = h + 2` และ `h = w / 2`;
- **พารามิเตอร์** ที่นิพจน์ของมันใช้ **การกำหนดค่า** ที่ตั้งค่ามัน และ **สคริปต์** ที่อ่านมัน (ดู [เขียนและรันสคริปต์](topic:craftscript))

"ยังไม่ถูกใช้" หมายความว่าไม่มีอะไรใช้มัน: ลบได้โดยไม่ต้องถาม

## ยกเลิกการเชื่อม เปลี่ยนชื่อ ลบ

- **ยกเลิกการเชื่อมตัวเลข:** คลิกปุ่ม **ƒ** หรือ {{ui:Unlink}} ในรายการ **สมการ** ตัวเลขจะคงค่าปัจจุบันไว้ และไม่มีพารามิเตอร์ใดเปลี่ยนมันอีก
- **เปลี่ยนชื่อพารามิเตอร์:** พิมพ์ชื่อใหม่ในช่อง **Name** ของมัน นิพจน์ทุกตัวที่ใช้มันจะถูกเขียนใหม่
- **ลบพารามิเตอร์:** คลิก × ที่แถวของมัน หากมีอะไรใช้มัน PartCraft จะถามว่าจะเขียนค่าปัจจุบันลงในนิพจน์เหล่านั้นก่อนหรือไม่
- **การลบฟีเจอร์** จะลบสมการของตัวเลขในฟีเจอร์นั้น แถบสถานะจะบอกว่าเป็นตัวไหน

:::note
พารามิเตอร์ถูกบันทึกในไฟล์ `.partcraft.json` (เป็นไฟล์เวอร์ชัน 3) ชิ้นส่วนที่ไม่มีพารามิเตอร์จะถูกบันทึกเหมือนเดิมทุกประการ
:::

## นิพจน์

| เขียน | หมายถึง |
|---|---|
| `120`, `12.5`, `1e3` | ตัวเลข (มิลลิเมตร หรือองศาสำหรับมุม) |
| `2in`, `1ft`, `3"`, `1.5cm`, `0.2m` | ความยาวในหน่วยอื่น แปลงเป็นมิลลิเมตร |
| `30deg`, `0.5rad` | มุม แปลงเป็นองศา |
| `+ - * / %` และ `^` | เลขคณิต `^` คือกำลัง `-2^2` คือ −4 |
| `sin cos tan asin acos atan atan2` | ตรีโกณมิติในหน่วยองศา |
| `sqrt pow exp ln log abs sign` | ฟังก์ชันอื่นๆ |
| `ceil floor int round(x, digits) min max` | การปัดเศษและขีดจำกัด |
| `if(test, a, b)` กับ `< <= > >= == !=` | การเลือก: `if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

ชื่อแยกตัวพิมพ์เล็กพิมพ์ใหญ่: `Width` และ `width` เป็นพารามิเตอร์สองตัว
