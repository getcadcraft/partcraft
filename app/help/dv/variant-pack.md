## ތިބާ ކުރާނީ

**ޕާޓެއްގެ ކޮންމެ ސައިޒެއް އެއްފަހަރާ** ހުށަހަޅާ: ކޮންފިގްރޭޝަނަކަށް އެއް STEP، IFC އަދި DWG ފައިލް، ކޮންމެއަކަށް ފޮޓޯއެއް، ކޮންމެއަކީ ކޮން ކަމެއް ކިޔާ ޖަދުވަލެއް، އަދި ހުރިހާ އެކެއް ޕޭޖަކުގައި ދައްކާ ލައިބްރަރީ އައިޓަމެއް.

މި ކަމަށް ކުރިން **ކޮންފިގްރޭޝަންސް** ހުންނަ ޕާޓެއް ބޭނުންވެއެވެ ([ކޮންފިގްރޭޝަންސް އަދި ޑިޒައިން ޓޭބަލްތައް](topic:design-tables) ބަލާ). ފީޗަރެއް ނޫން ކުރާ ކޮންފިގްރޭޝަނެއް، މިސާލަކަށް ހޯލްތަކާއި ނެތް ޕްލޭޓެއް، އެކަމަކު އޭގެ ވެރިއަންޓެއް ވާނެއެވެ.

## ގަޑުތައް

1. ޕާޓް ހުޅުވާ. {{ui:Parameters}} ޓެބުގައި، **Configurations** ހޯދާ.
2. {{ui:Variant pack…}} ކްލިކް ކުރޭ.
3. ހަދަންޖެހޭ ކޮންފިގްރޭޝަންތައް ޓިކް ކުރޭ (ހުރިހާ އެކެއް ޓިކްކޮށްފައި)، އަދި ލިޔޭ ފައިލްތައް: STEP، IFC، DWG، ޕްރިވިއު، އަދި ލައިބްރަރީ އައިޓަމް.
4. {{ui:Make the pack}} ކްލިކް ކުރޭ. ސްޓޭޓަސް ލައިން ވެރިއަންޓްތައް ހަދާ ވަގުތު ގިނަކުރެއެވެ؛ ތިބާގެ ޕާޓް ނުބަދަލު ވެއެވެ.
5. ޒިޕް ފައިލެއް ޑައުންލޯޑް ވޭ: `<part> variants.zip`.

## ޒިޕުގައި ހުންނަ ކަންތައް

| ފައިލް | އެއީ ކޮންކަމެއް |
|---|---|
| `<name>.step` | ކޮންފިގްރޭޝަން ސްޓެޕް ސޮލިޑް ގޮތުގައި. |
| `<name>.ifc` | IFC4، އެއް އެލިމަންޓް ބިނާކުރި ބޮޑީ އަދި ޕާޓުގެ ޕެރަމީޓަރުތައް ޕްރޮޕަރޓީތަކެއް ގޮތުގައި؛ އަގު އެ ކޮންފިގްރޭޝަނުގެ އަމިއްލަ. |
| `<name>.dwg` | ފްރޯންޓް، ޓޮޕް، ރައިޓް އަދި އައިސޮމެޓްރިކް ވިއުތައް ފުރަތަމަ ސައިޒުގެ ޑްރޯއިންގ ޝީޓެއް ގޮތުގައި. |
| `<name>.svg` | އެގެ އައިސޮމެޓްރިކް ލައިން ފޮޓޯއެއް. |
| `variants.csv`، `variants.json` | ޕެރަމީޓަރު ޖަދުވަލް: ކޮންމެ ވެރިއަންޓުގެ އައިޑީ، ނަން އަދި ކޮންމެ ޕެރަމީޓަރުގެ އަގު، އެ ކުރާ ފީޗަރު އޮފް ކުރާ ކަންތައް، ފައިލްތައް، ވޮލިއުމް އަދި ސައިޒް. |
| `<part>.item.json` | ޕާޓް އެކަމަނާ ލައިބްރަރީ އައިޓަމެއް ގޮތުގައި އޭގެ ވެރިއަންޓްތައް ހިމެނިގެން (ތިރީގައި ބަލާ). |
| `README.txt` | ހަދާފައިވާ ކަންތައް، ތިރީގެ ނޯޓުތައް، އަދި ހަދައި ނުވާ ކޮންމެ ކަމެއް. |

ފައިލްތައް ނަންދީ ލިބެނީ ކޮންފިގްރޭޝަނުގެ ނަމުން. ހަދަން ނުކެރޭ ކޮންފިގްރޭޝަނެއް (އަގުތައް ހިމެނިގެން ހަދަން ނޭނގޭ ފީޗަރެއް) ފައިލްތަކާއި ޖަދުވަލުން ފުރިހަމައަށް ނެގެވޭ، README އަދި ޒިޕް ރައްކާ ކުރުމަށްފަހު އުފެދޭ މެސެޖުގައި ލިސްޓު ވެއެވެ؛ އެހެންތައް ފަހަނާ ލިޔެވޭ.

## ރަނގަޅަށް އެދިވާ ކަންތައް

- **STEP** ރަނގަޅު (އެކްސެކްޓް) ވެއެވެ ތިބާގެ ބިލްޑުގައި އެކްސެކްޓް ކާނަލް އޮންނަ ވަގުތު. އެހެން ނޫނީ STEP ފެސެޓް (ފްލެޓް ތްރިކޯނު) ވާ، އަދި README އެ ކަން ދައްކާ.
- **DWG** އަކީ ޑްރޯއިންގ ޝީޓެއް، 3D މޮޑެލް ނޫން. އޭގެ ލައިންތައް މެޝުން ނެގެވެއެވެ، އެހެންކަމުން ވަށަނާ އެޖެއް ގިނަ ކުޑަ ލައިން.
- **ލައިބްރަރީ އައިޓަމް** ކޮންމެ ވެރިއަންޓަކަށް ބޮޑީއަކާއި ފުޓްޕްރިންޓަކެއް ގެންގުޅޭ، ލައިބްރަރީގެ އަމިއްލަ އެކްސިސްތަކުގައި: Z މައްޗަށް، ފުރަތަމަ ފަރާތް −Y ފަރާތަށް، އަދި ދާޅުވާ ޕޮއިންޓް ފުރާޅުގެ ފަހަށް މެދަށްގައި. ޕްލޭން ކޮންމެ ވެރިއަންޓުގެ ބައުންޑިންގ ރެކްޓެންގަލެވެ. އައިޓަމަކަށް 8 MB ސީމާ ވެއެވެ، އެހެންކަމުން ބުރު ވެރިއަންޓެއް އޭގެ ސައިޒުގެ ބޮކްސެއް ވާ، އަދި README ގައި ކިތައް ހުރިކަން ދައްކާ.
- ޕާޓުގެ އެކްޓިވް ކޮންފިގްރޭޝަން އައިޓަމުގެ ޑިފޯލްޓް ވެރިއަންޓް ވެއެވެ.
- ޕޯޓްސް (ޕައިޕާއި ޑަކްޓަށް ކަނެކްޝަން ޕޮއިންޓްތައް) PartCraft ން ސެޓް ނުކުރެވޭ.

## ވެރިއަންޓްތައް ލައިބްރަރީ ޕޭޖެއްގައި ޖައްސާ

`<part>.item.json` ފައިލް ސައިޓުގެ **ލައިބްރަރީ › އަޕްލޯޑް** ގައި އަޕްލޯޑް ކުރޭ. އޭގެ ކެޓަގަރީ، ލައިސެންސް އަދި ތިބާގެ ކްރެޑިޓް ލައިން ހޮވާ، އަދި އެއީ ވެރިއަންޓްތަކާއެކު ލައިބްރަރީ އައިޓަމެއް ވެއެވެ. BimCraft ގައި އެ ބަހައްޓާއިރު ކޮން ވެރިއަންޓެއް ކަން ސުވާލު ކުރެވޭ، އަދި Swap ން އެހެންތައް ހުށަހަޅާ. ވިޒިޓަރުން އޮޕްޝަން ހޮވައި، 3D ބެލުމާއި ވެރިއަންޓް ޑައުންލޯޑް ކުރާ ޕޭޖް މިހާރު **ސްޓާފް ޕްރިވިއު** އެކެވެ؛ ފަބްލިކަށް އަދި ހުޅުވިފައެއް ނުވެއެވެ.

## ކޮމާންޑް ލައިނުން

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` ކޮންފިގްރޭޝަންތައް ނަންދެއެވެ، `--formats` ކޮންމެ ކަމަކަށް `step`، `ifc`، `dwg`، `preview` ކުރެވެ، `--no-item` ލައިބްރަރީ އައިޓަމް ނައްތާލެވޭ. ފޯލްޑަރެއް، ޒިޕެއް، ނުވަތަ ދެކޮޅެވެ ލިޔޭ، އަދި ވެރިއަންޓެއް ނުހަދާއިރު 1 އުނިކުރޭ. ބަލާ [ސްކްރިޕްޓް އަދި ކޮމާންޑް ލައިން](topic:scripts-and-cli).
