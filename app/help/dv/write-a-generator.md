ޖެނެރޭޓަރަކީ ([CraftScript](topic:craftscript)، Lua ނުވަތަ Python) ސާދާ ސްކްރިޕްޓެއް، އިރުމަތީގައި ކޮމެންޓް ލައިން ކޮޅެއް ހިމެނޭ. PartCraft އިން ކޮމެންޓްތައް ކިޔަވައި ފޯމު ހަދައެވެ؛ ތިޔަ ސްކްރިޕްޓް އިނޫޓުތައް ކިޔަވަނީ އެކަމަށް ކުރެވިފައިވާ ވޭރިއަބަލްތަކެއް ގޮތުގައެވެ.

## ހެޑަރ

މިތަކެތި ކޮމެންޓް ލައިންތަކުގައި ލިޔޭ (CraftScript ގައި `%`، Lua ގައި `--`، Python ގައި `#`):

```
% @generator Heat exchanger
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Mass flow"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Surface"
% @input solid: = true
% @input note: = "text"
```

އިނޫޓަކީ `name: unit = default`، ފަހުން އިޚްތިޔާރުވެރި ގޮތުގައި ރޭންޖު `[min .. max]` (ނަންބަރުތައް އެ ތެރޭގައި ހިފެހެއްޓެވޭ)، ޗޮއިސް ލިސްޓް `{a, b, c}` އަދި ކޯޓްތަކުގެ ތެރޭގައި ލޭބަލެއް. ޔުނިޓް ފޯމަށް ލޭބަލެއް ބަހައްޓާ މާތަރެއް ނޫން: **އަގު ލިބެނީ އެ ޔުނިޓުގައެވެ**، އެހެންކަމުން SI އަށް ބަދަލުކުރަން ބޭނުންވާ ސްކްރިޕްޓް `to_si(value, 'kg/s', 'kg/s')` ބޭނުން ކުރުމުން ޔުނިޓް ތިޔަ މުރާދަށް ރަނގަޅު ހެއްޔެވެ ކަމުގެ ޗެކްވެސް ހިނގައިދެއެވެ. ނަމެއް ކަމަށް ހަމަ އަކުރު، އަދަދު އަދި އަންޑަސްކޯރ ބޭނުން ކުރެވޭ؛ `body`، `sheet` އަދި `problems` ކަމުގައި ނަގާފައިވެއެވެ.

## ސްކްރިޕްޓް ދޭ ތަކެތި

| ވޭރިއަބަލް | ކޮންތެއް |
|---|---|
| `body` | **ދެންމެހެން ޖެހޭ.** މަތީ ސަރފޭސް މެޝެއް، ބައެއްގައި `[body, info] = to_body(field, h)` އިން. ރަން ކުރެވި، ރަނގަޅުކަން ޗެކް ކުރެވެނީ ރަން ނިމުމުންނެވެ. |
| `sheet` | އިޚްތިޔާރުވެރި. ފީލްޑެއް ރަނގަޅު އަދަދެއް ނުވަތަ ޓެކްސްޓެއް، ނުވަތަ `value`، `unit`، `ref` އަދި `note` ހިމެނޭ ސްޓްރަކްޗަރެއް. އެއީ ޑޭޓާ ޝީޓު ވެއެވެ. |
| `problems` | އިޚްތިޔާރުވެރި. `mfg_check(field, 'sls', struct(), h)` އިން ފެންނަ `problems` ސެލް، ނުވަތަ ތިޔަ އަމިއްލަ އެންޓްރީތައް. އެއީ ޗެކްތަކާއި Problems ލިސްޓަށް ދެވެއެވެ. |

## ސާފު ކުޑަ މިސާލެއް

```
% ފާރެއް ހުންނަ ފުނި ކިއުބެއް.
% @generator Hollow cube
% @input side: mm = 12 [4 .. 40] "Side"
% @input wall: mm = 1.5 [0.5 .. 5] "Wall"
% @input h: mm = 0.5 [0.25 .. 2] "Voxel size"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'of the mesh');
```

އެއީ ބަންދު ބޯކްސެއް ހަދާ، ޗެކުން އެގެ ތެރެ ބަންދުވެފައިވާކަން ޕައުޑަރ ޕްރޮސެހަށް އެރަރެއްގެ ގޮތުގައި ރިޕޯޓު ކުރެއެވެ. ވޮކްސެލް ސައިޒު `h` ބޭނުންވާ ކުޑަމިން ފާރުގެ ތިންބައިންއެއްއަށް ވުރެ ބޮޑު ނުކުރޭ: ވޮކްސެލް ތިންގަނޑަށް ދަށުން ފާރެއް ރަނގަޅަށް ނުހުރެއެވެ.

## ފީލްޑު

`field_sphere`، `field_box`، `field_capsule`، `field_cylinder`، `field_torus`، `field_revolve` (ޕްރޮފައިލަކުން ރޫޓޭޓު ކުރާ ސޮލިޑް)، `tpms` (gyroid، Schwarz P އަދި diamond ސަރފޭސް، ސެލް ސައިޒާއި ފާރު ބަދަލުވެވޭ)، `lattice` އަދި `lattice_beams`، `along` (ފަތުގެ ކޮންމެ ސަރުކިއުލާރު ޗެނަލެއް)، ބޫލީޔަން `field_union`، `field_intersect`، `field_subtract`، ސްމުތު `field_blend`، އަދި `field_offset`، `field_shell`، `field_move`، `field_rotate`، `field_scale`. `sample(f, points)` ން ޕޮއިންޓްތަކުގައި ސައިންޑް ޑިސްޓަންސް ދެއެވެ (ތެރޭގައި ނެގިޓިވް)، `field_voxel` ން ސޮލްވަރުތަކަށް ވޮކްސެލް ދެއެވެ. [Fields](topic:fields) ގައި ފީލްޑު ކޮބައި ހެއްޔެވެ ކަމުގެ ރޮނގު ބަޔާންކުރެއެވެ.

ދެނެގަތަން ވާ ސީމާތައް: ޝީޓު ފާރެއް ސެލްގެ ހަތަރުބައިންއެއްއަށް ވުރެ ބޮޑު ނަމަ ޗެނަލްތައް ބަންދުވެދާނެއެވެ؛ ތިން ވޮކްސެލަށް ވުރެ ކުޑަ ފީޗަރެއް ކުޑަވެދާނެއެވެ؛ `along` ވަކި ކޯނުތައް ގުޅައިދެނީ، ރެޑިއަސް އަވަހާ ބަދަލުވެއްޖެ ނަމަ ބުލްޖެއް ފެނިދާނެއެވެ (ޕްރޮފައިލަކަށް `field_revolve` ބޭނުން ކުރޭ).

## ތިޔަ ސްކްރިޕްޓް ޖެނެރޭޓަރެއްގެ ގޮތުގައި ހުޅުވާ
