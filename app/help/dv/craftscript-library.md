އެނަލިސިސް ލައިބްރަރީ އަކީ ސްކްރިޕްޓްތަކުގެ ސެޓެކެވެ، ކޮންމެ އެކެއް މުޅި ފަށާއިން ނިމޭގެންދާ ގޮތަށް ކިޔެވޭ ފަންކްޝަނެކެވެ: ސްޓިފްނެސް މެޓްރިކްސް ކިހިނެއް އެސެމްބްލްކުރެވޭ، ބައުންޑަރީ ކޮންޑިޝަންތައް ކޮތަން ދާނެ ހެއް، ކޮން ސޮލްވަރެއް ރަން ވާނެ ހެއް، ނަތީޖާތައް ކިހިނެއް ހިސާބުކުރެވޭ ހެއް. އޭގައި އެއްވެސް ކަމެއް ބްލެކް ބޮކްސްއެއްގައި ފޮރުވިފައެއް ނުވެއެވެ؛ ހަމައެކަނި ވަރަށް އަވަހަށް ހިންގޭ ތަންތަން (އެލިމަންޓް މެޓްރިކްސް، ސްޕާސް ސޮލްވަރުތައް، މެޝިންގ) ބިލްޓް އިން ރަނގަޅެއެވެ.

## މިސާލަކުން ފަށާށެވެ

**Examples** ގްރޫޕުގައި ލައިބްރަރީ އެންމެ ފަށް މުޅިން ބޭނުންކުރާ ފަސްކުޑަ ސްކްރިޕްޓް ފަސް ހުންނެވެ. އެއްކޮށް ކްލިކްކޮށް {{ui:Open (read-only)}} ފިތާލާ، ދެން {{key:F5}}: ކޮންމެ އެއްކަމެއްގައި ވިއު ސާފުވެ، ކެންވަސްގައި ނަތީޖާއެއް އަދި ސަބް-ޑިސްޕްލޭގައި ޕްލޯޓެއް ފެންނާނެއެވެ.

| Capacitor field | 4 mm ފުޅާ، 1 mm ދުރު ދެ ޕްލޭޓް: ޕޮޓެންޝަލް އަދި ފީލްޑް، ފްރިންޖިންގ ހިމެނޭ ކެޕަސިޓަންސް އައިޑިއަލް އަގާއި Palmer ގެ ފޯމިއުލާއާ އެކު |
| Channel flow | ޗެނަލެއްގައި ޕޯސްޓެއް މައްޗަށް Lattice Boltzmann ފްލޯ: ވެލޮސިޓީ ފީލްޑް އަދި ކޮންވާޖެންސް ތާރީޚް |
| Electromagnet | އެއަރ ގެޕެއް އަދި ކޮއިލްއެއް ހުންނަ C ޝޭޕްގެ އައިރަން ކޯރެއް: ފްލަކްސް ޑެންސިޓީ، ގެޕުގެ ފީލްޑް މެގްނެޓިކް-ސާކިޓް ފޯމިއުލާއާ އެކު، އިންޑަކްޓަންސް އަދި ގެޕުގެ ކުރިން ފުޅުން. [Magnetic fields in 2-D](topic:magnetic-fields-2d) ގައި ފުރާވެސް ފެންނާނެ |
| Permanent magnet | އެއަރ ކޮއިލްގެ ބަދަލުގައި ޕަރމަނަންޓް މެގްނެޓް ހުންނަ ހެން އެއް ކޯރެވެ: މެގްނެޓުގެ ވޯކިންގ ޕޯއިންޓް، ގެޕުގެ ފީލްޑް މެގްނެޓިކް-ސާކިޓާއެކު، ކިހާ ފްލަކްސެއް ލީކުވެއްޖެ ހެއް، ފުޅުން. [Magnetic fields in 2-D](topic:magnetic-fields-2d#permanent-magnets) ގައި |

## ގްރޫޕްތައް

| ގްރޫޕް | ފަންކްޝަންތައް | ކުރާ ކަންތައް |
|---|---|---|
| Meshing | `box_mesh`، `cylinder_mesh`، `voxel_mesh`، `tet_mesh`، `mesh_quality`، `nodes_at`، `face_nodes` | ބޮކްސް އަދި ސިލިންޑަރ ހެކްސަހެޑްރާ، ކިއުބް ނުވަތަ ޓެޓްރާހެޑްރާއަކަށް؛ ކޮންމެ މޮޑެލެއްގެ (ޕާޓް، ބޮޑީ، ލޯޑް ކުރެވުނު STL) ކިއުބް ނުވަތަ ޓެޓްރާހެޑްރާ؛ އެލިމަންޓް ވޮލިއުމް އަދި ކުރިއަށް ފުޅުން؛ ޕްލޭނެއްގައި ނުވަތަ ފޭސްގައި ނޯޑް ނިންމުން |
| Static stress | `static_voxel`، `static_tet` | ކިއުބް ނުވަތަ 10-node ޓެޓްރާހެޑްރާ މައްޗަށް ލީނިއާ ސްޓޭޓިކް ސްޓްރެސް: ޑިސްޕްލޭސްމަންޓް، ސްޓްރެސް، von Mises، ރިއެކްޝަންތައް |
| Frames | `frame3d` | ބީމް، ކޮލަމް އަދި ބްރޭސްތަކުގެ 3D ފްރޭމްތައް ޑިރެކްޓް ސްޓިފްނެސް މެތޮޑުން: އެންޑް ރިލީސް، ސަޕޯޓް އަދި ސްޕްރިންގ، މެމްބަރު ގެ ތެރޭގައި ލޯޑް؛ ޑިސްޕްލޭސްމަންޓް، ރިއެކްޝަން، މެމްބަރު އެންޑް ފޯސްތައް. DetailCraft އަދި BimCraft ގެ {{ui:Export as CraftScript}} އިން މުޅި މޮޑެލް ލިޔެވެއެވެ. އެނަލިސިސް އަތް ފުށެއް، ކޯޑް ޗެކެއް ނޫން |
| Vibration | `modal_tet` | ނެޗުރަލް ފްރީކްވެންސީތައް އަދި މޯޑް ޝޭޕްތައް |
| Heat | `heat_steady`، `heat_transient`، `heat_system` | ސްޓެޑީ އަދި ޓްރާންސިއެންޓް ކަންޑަކްޝަން، ހުރި ޓެމްޕަރޭޗަރު، ހީޓް އިންޕުޓް، ޖެނެރޭޝަން، ފްލަކްސް އަދި ކަންވެކްޝަން |

| Electromagnetics | `poisson2d`، `magnetostatic2d` | 2-D އީލެކްޓްރޯސްޓޭޓިކްސް (ޕޮޓެންޝަލް، ފީލްޑް، ކެޕަސިޓަންސް، ޗާޖް) އަދި މެގްނެޓޯސްޓޭޓިކްސް (ވެކްޓަރ ޕޮޓެންޝަލް، ފްލަކްސް ޑެންސިޓީ، ޕަރމަނަންޓް މެގްނެޓްސް) |
| Fluid flow | `lbm2d`، `lbm3d` | Lattice Boltzmann ފްލޯ: 2-D ސްކްރިޕްޓުގައި ލިޔެވިފައި، 3-D ގެ ޕާޓްކްރާފްޓުގެ އެވެސް ފްލޯ ކާނަލްގައި |

ކޮންމެ ފަންކްޝަނެއްގެ ހެޑަރުން އެއްޗެހިގެ ރަނގަޅު ބުރާންތައް ދެއެވެ. ޔުނިޓްތަކީ PartCraft ގެ ސްޓަޑީތަކުގެ ޔުނިޓްތަކެވެ، ހެޑަރުން އެހެން ދައްކާ ނުވާތަނަށް: މިލިމީޓަރ، ނިއުޓަން، މެގާޕާސްކަލް، ޓަން އެއް ކިއުބިކް މިލިމީޓަރަށް ގަނޑު އަށް، ވަޓް އަދި ކެލްވިން ހީޓަށް. އިލެކްޓްރޯމެގްނެޓިކް އަދި ލެޓިސް ބޯލްޝްމަން ފަންކްޝަންތައް ކޮންސިސްޓެންޓް ޔުނިޓްތަކުގައި މަސައްކަތް ކުރެއެވެ؛ އެގެ ހެޑަރުތަކުން ކިހިނެއް ކަމެއް ދައްކާއެވެ.

## ލައިބްރަރީ ކިހިނެއް ޗެކް ކުރެވެއެވެ

ކޮންމެ ފަންކްޝަނެއްގެ ހެޑަރު ނިމެނީ **check** އަކުންނެވެ: ދެނެގަނެވޭ ޖަވާބެއްވާ ކުޑަ ކޭސެއް. PartCraft ގެ ޓެސްޓްތައް އެ ކޮންމެ އެކެއް ހިންގައެވެ، އަދި PartCraft ގައި އެ ފަދަ ސްޓަޑީއެއް ހުންނަ ތަނެއްގައި ސްކްރިޕްޓުގެ ޖަވާބު އެ ސްޓަޑީއާ އެއް މެޝުގައި ހަމަ ކުރެވެއެވެ:

- cantilever ގެ ޓިޕް ޑިފްލެކްޝަން ބީމް ތިއަރީއާ (cubes ގައި 0.2 % ތެރޭގައި، tetrahedra ގައި 0.05 %) އަދި **Simulation** ވޯކްސްޕޭސްގެ ސޮލްވަރުތަކާ އެއް މެޝުގައި (ޑިޖިޓް ގަނޑަށް އެއްކޮށް)؛
- cantilever ގެ ފަހި ފްރީކްވެންސީ ބީމް ތިއަރީއާ (0.24 % ދަށް، ކުރު ބީމަކަށް ފާސްކުރެވޭ ފަދައިން) އަދި **Simulation** ގެ މޯޑަލް ސޮލްވަރާ؛
- heat: ހީޓް ކުރެވުނު ސޮލިޑް ވޯލް އެކްސާކްޓްލީ، ކުޑަ ބޮޑީއެއް ލަމްޕްޑް-ކެޕެސިޓީ ފޯމިއުލާ ފަދައިން ފަރުވާވެދާ، ސްލެބެއްގެ ޓެމްޕަރޭޗަރު ތިއަރީ ފަދައިން ހިއްކެވެ؛
- topology optimization: `top88` ޕޭޕަރުގެ 94 އައިޓްރޭޝަން އަދި ކޮމްޕްލަޔަންސް 203.1925 ދައްކާ (އަދި ޑެންސިޓީ ފިލްޓަރާއެކު 218.8032)؛ `topopt3d` ސެޓިންގްސް އެއްގޮތަށް **Generative** ވޯކްސްޕޭސްގެ ކޮމްޕްލަޔަންސް އަކަށް ވާސިލް ވެއެވެ؛
- ކެޕެސިޓަރގެ ކެޕެސިޓަންސް އަދި ދިގު ސޮލެނޮއިޑުގެ ފީލްޑް ޓެކްސްޓްބުކް އަގުތަކާއެކު، އެލެކްޓްރޯމެގްނެޓުގެ ގެޕް ފީލްޑް މެގްނެޓިކް-ސާކިޓް ފޯމިއުލާއާއެކު، އަދި ޕަރމަނަންޓް މެގްނެޓްތައް އެއަރގައި ރައުންޑް މެގްނެޓާއި އައިރަން ކީޕާއެއް ބަންދުވާ މެގްނެޓާއެކު؛
- ޗެނަލް ފްލޯ އެގްޒެކްޓް ޕެރަބޮލިކް ޕްރޮފައިލާއެކު.

## ފަންކްޝަނެއް ކިއުރޭ

1. ސްކްރިޕްޓް ޕެނަލްގެ **Library** ޓެބް ހުޅުވާ.
2. ފަންކްޝަނެއް ކްލިކް ކުރޭ. އޭގެ ހެޑަރު ދައްކާނީ: އޭ ކޮންޕިއުޓް ކުރާ ކަން، މެތޮޑް، ޔުނިޓްތައް، އެސަމްޕްޝަންތަކާއި ސީމާތައް، **ރެފަރެންސް** (ފޮތް ނުވަތަ ޕޭޕަރު، އީކުއޭޝަން ނަންބަރުތަކާއެކު) އަދި **check**.
3. {{ui:Open (read-only)}} ފިތާލާ މުޅި ސްކްރިޕްޓް ޑޮޓޮޑް ބޯޑަރ ކުރެވޭ ޓެބަކުން ހުޅުވޭ. ރަން ކުރެވޭ، ބައެއް ސެލެކްޓްކޮށް ރަން ކުރެވޭ، ނަމަވެސް ބަދަލު ނުކުރެވޭ.

## އެއް ބަދަލުކުރޭ

{{ui:Make a copy}} ފިތާލާ (ނުވަތަ **Make a copy to edit** ކިއުރިހާ ރީޑް-ޮނލީ ޓެބުގެ މައްޗަށް). ކޮޕީ ވާނީ ތިޔަ ޕާޓުގައި އެ ނަމުން ސްކްރިޕްޓެކެވެ، އެހެންކަމުން ޕާޓާއެކު ސޭވް ވޭ، އަދި **ކޮންމެ ކޯލެއް އެ ފަންކްޝަނަށް މިހާރު ތިޔަ ކޮޕީ ބޭނުންކުރެއެވެ** — އެޑިޓަރުން އެ ކަން ސްކްރިޕްޓުގެ މައްޗަށް ދައްކާއެވެ. ދެކޮޅު ހިފަން ނަމެއް ބަދަލުކުރޭ.

## އެއް ބޭނުންކުރޭ

ކޮންމެ ސްކްރިޕްޓަކުން ލައިބްރަރީ ފަންކްޝަނެއް ނަމުން ކޯލްކުރޭ، ބިލްޓް އިން ފަންކްޝަނަކާ ފަދައިން:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

ނަތީޖާތައް އަގުތަކެއްގެ ގޮތުގައި ވޯކްސްޕޭސްއަށް ލިބެއެވެ؛ ދައްކާ ޕްލޯޓުތަކާއި ފީލްޑްތައް ވިއުގައި އަދި ސަބް-ޑިސްޕްލޭތަކުގައި ފެންނާނެއެވެ.

ހުޅުވާ ޕާޓުގެ ސްޓެޓިކް އެނަލިސިސް ނަމޫނާއެއް ލަފާކޮށް ކޮޑުން:

```
v = voxel_mesh(part(), 2);                   % 2 mm ކިއުބްތައް
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % ތިރީ ހިފާ
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % މަތީ ގައި 500 N ތިރިން
r = static_voxel(v, 210000, 0.3, bc);       % ސްޓީލް
```

`r` ގައި ޑިސްޕްލޭސްމަންޓް، ސްޓްރެސް އަދި ރިއެކްޝަންތައް ހުންނާނެއެވެ؛ von Mises ސްޓްރެސް ޑިފޯމް ކުރެވުނު ޕާޓުގައި ޑްރޯ ކުރެވޭނެއެވެ. ކާރވް ޕާޓްތަކަށް `tet_mesh` އަދި `static_tet` ބޭނުންކުރޭ، އެކަމަކު އެ ދެން ފުރިހަމަ ފޭސްތައް ލޯޑް އަދި ހޯލްޑް ކުރެވޭ (`face_nodes`).

:::note
ލައިބްރަރީ ފަންކްޝަންތައް ލިޔެވެނީ CraftScript އިންނެވެ، އަދި Lua ސްކްރިޕްޓެއް އެ ފަންކްޝަންތައް `cs` އިން ކޯލްކުރެއެވެ، ބިލްޓް އިން ފަންކްޝަންތައް ފަދައިން: `cs.static_tet(t, 200000, 0.3, bc)` (ބައްލަވާ [Lua ސްކްރިޕްޓްތައް](topic:craftscript-lua)). ކޮންމެ ފަންކްޝަނެއް ތަނެއް މަޓީރިއަލަކާއި ލޯޑް ކޭސެއް ސޮލްވްކުރެއެވެ؛ ހެޑަރުތަކުން ކޮންކަންތައް ކަވަރު ނުވާކަން ފާހަގަކުރެއެވެ.
:::
