ރެފަރެންސް ޖިއޮމެޓްރީ އަކީ ފީޗަރުތައް ބިނާކުރާ ސްކެފޯލްޑިންގެވެ: **ޕްލޭން** އެއް، ކޮތަރެއް ނެތް މަތީގައި ސްކެޗް ކުރުމަށް؛ **އެކްސް** އެއް، ރިވޯލްވް ނުވަތަ ޕެޓާން ކުރުމަށް؛ **ނުކުތާ** އެއް، އެކްސްޓުރޫޑް ނިމުމަށް. އޭގެ އަމިއްލަ މާއްދާއެއް ނެތެވެ. ޕްލޭންތައް ވިއުގައި ފެންނަނީ ފަރުދާ ޗޯކު ސްކެއާއެވެ، އެކްސް ކަމަށް ޑޭޝް ލައިން، ނުކުތާ ކުޑަ ކްރޮސް. ތިންވެސް ހިސްޓަރީއާ ބައިވެރި ވެ، ކުރިން ބޮޑުމިން ބަދަލުކުރާއިރު އެ ހަދާފައިވާ ތަންތަނާ އެކު ހަރަކާތް ކުރެވޭ.

އެ ފީޗަރުތަކުގެ ގްރޫޕުގެ {{ui:More}} މެނޫގައި ހުރެއެވެ: {{ui:Plane}}، {{ui:Axis}}، {{ui:Point}}.

## ޕްލޭނެއް ހަދާ

1. ފުޅާ މަތިއެއް، ނުވަތަ ހިސްޓަރީގެ ބޭސް ޕްލޭނެއް ކްލިކްކުރޭ، އޭންގެން ފަށަން (އިޚްތިޔާރީ).
2. {{ui:More}} ހޮވާ، ދެން {{ui:Plane}}. ފަށަންވާނީ ބައިގެ ސައިޒުގެ 20 % ދުރުން އޮފްސެޓް ޕްލޭނެއްގެ ގޮތުގައި، ހޮވި އެއްޗަކުން (ނުވަތަ ޓޮޕް ޕްލޭނުން).
3. ޑާބު ކަނާރުގެ ޕެނަލުގައި **ޓައިޕް** އާއި އޭގެ ރެފަރެންސްތައް ހޮވާ:

| ޓައިޕް | ރެފަރެންސް | އަދަދު |
|---|---|---|
| ޕްލޭނު ނުވަތަ މަތިން އޮފްސެޓް | **ފަރާތުން ޕްލޭން** | **ދުރުމިން (mm)**، އަނެއް ފަރާތަށް މައިނަސް |
| ކޯނައަކުން، އެޖު ނުވަތަ އެކްސް ދޫރުން | **ފަރާތުން ޕްލޭން**، **އެކްސް ފަރާތު ފެރުން** (ދުނިޔޭ އެކްސް، އެކްސް ފީޗަރ، ނުވަތަ ހޮވި ސީދާ އެޖް) | **ކޯނަ (°)** |
| ތިން ނުކުތާއިން ދާ | **ނުކުތާ 1**، **ނުކުތާ 2**، **ނުކުތާ 3** | — |
| ދެންނެވި ދެ ޕްލޭނާ ދެމެދުގެ މިޑްޕްލޭން | **ފުރަތަމަ ޕްލޭން**، **ދެވަނަ ޕްލޭން** (ޕެރަލަލް: ނިސްބަތު ފަހަރު؛ ގުޅުމުން: ކޯނަ ދެބައިކުރާ ޕްލޭން) | — |
| ސިލިންޑަރަށް ޓެންޖެންޓް | **ސިލިންޑަރ** (ސިލިންޑްރިކަލް މަތި)، **ގާތް ނުކުތާ** (ކޮންމެ ފަރާތް) | — |
| އެޖަށް ސްކެއާ، ނުކުތާއެއްގައި | **އެޖް**، **ނުކުތާގައި** (ޕްލޭން އެޖުގެ ގާތްވެވޭ ނުކުތާ މެދުވެރިކޮށް، އަދި އެ ނުކުތާ މެދުވެރިކޮށްވެސް ދާ) | — |
| އެޖާއި ނުކުތާ މެދުވެރިކޮށް | **ސީދާ އެޖް** (ނުވަތަ އެކްސް)، **ނުކުތާ މެދުވެރިކޮށް** | — |
| އެޖަށް ސްކެއާ، މެދުގައި | **އެޖް** (އޭގެ ދިގުމިނުގެ މެދުގައި، އެތަނުގައި ސްކެއާ)، ނުވަތަ އެޖެއް ނެތިއްޔާ **ނުކުތާ 1** އާއި **ނުކުތާ 2** (އެ ދެ ނުކުތާ ދެމެދުގެ ޕްލޭން) | — |

ކޮންމެ ރެފަރެންސަކަށް **ޚިޔާރުކުރޭ** ބަޓަން އޮވެއެވެ: އެ ހޮވައި، ވިއުގައި ކްލިކްކުރޭ. ޕްލޭން ސްލޮޓަށް ބޭސް ޕްލޭނެއް، ރެފަރެންސް ޕްލޭނެއް ނުވަތަ ފުޅާ މަތިއެއް ނަގާ؛ ނުކުތާ ސްލޮޓަށް އެޖުގެ ނިމުން (އެ ނިމުމަށް ގާތަށް ކްލިކްކުރޭ)، ނުކުތާ ފީޗަރެއް، ނުވަތަ މަތީގެ ތަނެއް ނަގާ؛ އެޖް ސްލޮޓަށް އެޖެއް ނަގާ. {{key:Esc}} ޚިޔާރުކުރުން ބާޠިލުކުރޭ. **ނޯމަލް ފްލިޕްކުރޭ** ޕްލޭން އުނި ކުރޭ (އޭގައި ސްކެޗް ކޮންފަރާތަށް ހުރި).

މި ވަރުޝަނުގައި އެޖް ނުވަތަ ސިލިންޑަރ މަތި ބޭނުންވާ ސްލޮޓް (ސިލިންޑަރަށް ޓެންޖެންޓް، އަދި އެޖް ސްލޮޓްތައް) "not built yet" އަށް ޖަވާބު ދެއެވެ: ނުކުތާ ނުވަތަ އެކްސް ބޭނުންކުރޭ.

## ޕްލޭނެއް މައްޗަށް ސްކެޗް ކުރޭ

ޕްލޭން ހޮވާ (ހިސްޓަރީގައި ނުވަތަ ވިއުގައި އޭގެ ސްކެއަރ ކްލިކްކޮށް) ދެން {{ui:Sketch}} ހޮވާ، ނުވަތަ އޭގެ ޕެނަލުގައި **ސްކެޗް އޭގެ މައްޗަށް** ހޮވާ. ސްކެޗް ޕްލޭނަށް ތަބާވެއެވެ: ޕްލޭނުގެ ދުރުމިން ބަދަލުކޮށް ސްކެޗާއި އޭގެ މަތީގެ ހުރިހާ ފީޗަރެއް ހަރަކާތް ކުރެވޭ.

## އެކްސްތަކާއި ނުކުތާތައް

- {{ui:Axis}}: ދެ ނުކުތާ މެދުވެރިކޮށް، ސިލިންޑަރ ނުވަތަ ކޯނެއްގެ އެކްސް، ދެ ޕްލޭން ގުޅޭ ތަނުގައި، ސީދާ އެޖާ ހަމައަށް (ނުވަތަ ވަށާ އެޖުގެ އެކްސް)، ނުވަތަ ނުކުތާއެއް މެދުވެރިކޮށް މަތިއަކަށް ސްކެއާ.
- {{ui:Point}}: ކޯޑިނޭޓްތަކުގައި، ވާޓެކްސް ނުވަތަ ސްކެޗް ނުކުތާއެއްގައި، ނުވަތަ ވަށާ އެޖުގެ މެދުގައި، އަދި "އޮބްޖެކްޓްތަކުގެ ދެމެދު" ނުކުތާތައް:

| ނުކުތާ ޓައިޕް | ރެފަރެންސް |
|---|---|
| އެޖުގެ މެދު (ނުވަތަ ދެ ނުކުތާއިން ދެމެދު) | **އެޖް** (އޭގެ ދިގުމިނުގެ މެދުގައި، އާކް އަދި ކާރވްތަކަށްވެސް)، ނުވަތަ އެޖެއް ނެތިއްޔާ **ނުކުތާ 1** އާއި **ނުކުތާ 2** |
| އެޖް ނުވަތަ އެކްސް މަތިއަކާ ނުވަތަ ޕްލޭނާ ހަމަވާ ތަން | **އެޖް** (ސީދާ ނުވަތަ ބެންޑް) ނުވަތަ އެކްސް، އަދި **ޕްލޭނާ ހަމަވޭ** (ޕްލޭން ނުވަތަ ފުޅާ މަތި) ނުވަތަ **މަތިއަކާ** (ފުޅާ މަތި ނުވަތަ ސިލިންޑަރ). ވަށެއް ޕްލޭނަކާ ދެފަހަރު ހަމަވޭ، ލައިނެއް ސިލިންޑަރ ދެފަހަރު ހަމަވޭ: **އެހެން ހަމަވުން** ދެވަނަ ގޮތަށް ނަގާ |
| ތިން ޕްލޭން ހަމަވާ ތަން | **ފުރަތަމަ**، **ދެވަނަ** އަދި **ތިންވަނަ ޕްލޭން** (ޕްލޭން ނުވަތަ ފުޅާ މަތިތައް) |

ކޮންމެ އެއްކޮޅު އޭގެ ރެފަރެންސް ނުޙުސާބުވެއްޖެނަމަ ސާދާ މެސެޖަކާއެކު ފެއިލްވެއެވެ: ޕްލޭނާ ޕެރަލަލް ލައިނެއް، ސިލިންޑަރ ނުލާ ލައިނެއް، ޕްލޭނަށް ނުލާ އެޖެއް، އެއް ނުކުތާއަކަށް ނުހަމަވާ ތިން ޕްލޭނެއް، ޕްލޭނެއް ހަދާ ލައިނުގައި ނުކުތާއެއް.

އެތައް ފީޗަރުތަކުގައި ބޭނުންކުރޭ:

| ތަން | ކިހިނެއް |
|---|---|
| ރިވޯލްވް | **އެކްސް**: ލިސްޓުން އެކްސް ފީޗަރ ހޮވާ (އެ ސްކެޗްގެ ޕްލޭނުގައި ހުރުން ޙަތްމެވެ) |
| ވަށް ޕެޓާން | **އެކްސް**: އެކްސް ފީޗަރ |
| ލައިން ޕެޓާން | **ޑައިރެކްޝަން**: އެކްސް ފީޗަރ، ނުވަތަ ޕްލޭން (އޭގެ ނޯމަލް) |
| މިރަރ | **މިރަރ ޕްލޭން**: ރެފަރެންސް ޕްލޭން |
| އެކްސްޓުރޫޑް | **އެންޑް**: މަތި ނުވަތަ ޕްލޭނަށް ހަމަ، ވާޓެކްސަށް ހަމަ (ނުކުތާ ފީޗަރ). މި ވަރުޝަނުގައި ނުބިނާކުރެވޭ (އެކްޒެކްޓް ކާނަލެއް ބޭނުންވޭ) |
| ޑްރާފްޓް | **ނިއުޓްރަލް ޕްލޭން** |

## ރެފަރެންސެއް ނެތްވުމުން

ނެތިފައިވާ މަތިއަކުން ހަދާ ޕްލޭން ނަން ޖަހާ މެސެޖަކާއެކު ފެއިލްވެއެވެ، މިސާލަކަށް "The face it sits on is gone from Extrude1." އެކަން އެހެން މަތިއަކަށް ހަރަކާތް ނުކުރެވޭ. އޭގައިވާ ސްކެޗްތަކާއި ފީޗަރުތަކަށް ނޫން ރެފަރެންސް ހޮވާންދެން "not built" ޗިހުން މާކްކުރެވެއެވެ؛ ބައި ބާކީ ގޮތަށް ހުންނާނެ.

:::note
މި ވަރުޝަނުން ހުރިހާ ބައެއް ބިނާ ކުރެވެނީ މެޝް ކާނަލުން، އޭގެމަތިން ޕްލޭނު، އެކްސް އަދި ނުކުތާ ހެދެނީ ބޭސް ޕްލޭނުން، އެކްސްޓުރޫޑް ނުވަތަ ރިވޯލްވުން ހަދާ ފުޅާ މަތިތަކުން، ސްކެޗް ނުކުތާތަކުން، ކޯޑިނޭޓްތަކުން އަދި އެހެން ރެފަރެންސް ފީޗަރުތަކުންނެވެ. އެޖެއް، އެޖުގެ ނިމުމެއް ނުވަތަ ވަށް މަތިއެއް ބޭނުންވާ ކޮންމެ ކަމަކަށް އެކްސެކްޓް ކާނަލް ބޭނުންވޭ: މި ވަރުޝަނުގައި ނުބިނާކުރެވޭ ("It uses a face or edge of the solid, which only an exact kernel can find: not built yet in this version.").
:::
