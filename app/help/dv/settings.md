{{ui:Settings}} ހުޅުވާ އެޕް ބާގެ ގިއާ ނުވަތަ {{key:Mod+,}}. ފުރަތަމަ ޓެބް، {{ui:PartCraft}}، މި އެޕުގެ ސެޓިންގްސް ހިމެނޭ؛ {{ui:General}} ހިމެނޭ ކޮންމެ CadCraft އެޕުން ބެހެއްޓޭ ސެޓިންގްސް (ތީމް، ޓޫލްބާ، ޕެނަލްތައް). PartCraft ސެޓިންގްސް މި އެޕުގައި ހުންނާނެއެވެ: މިތަނުގައި ބަދަލުކުރޭ، އަދި މި ބްރައުޒަރު ހަނދުވާލެއެވެ. {{ui:Reset PartCraft settings}} ހުރިހާ ކަމެއް ފުރަތަމަ ހާލަތަށް އަނބުރާ ދެއެވެ.

## ވިއު ފެރާލުން

- **ވާމު ބަޓަން** (ފުރަތަމަ ސެޓިންގް): ވާމު ބަޓަނުން ޑްރެގް ކޮށް ބައި ފެރާލާ؛ ރާސްތަ ނުވަތަ މެދު ބަޓަނުން ޑްރެގް ކޮށް ޕޭން ކުރޭ.
- **މެދު ބަޓަން**: ވީލް ދަބައިގެން ޑްރެގް ކޮށް ބައި ފެރާލާ؛ {{key:Shift}} (ނުވަތަ {{key:Ctrl}}، ނުވަތަ ⌘) ހިފައިގެން މެދު ބަޓަންނާ، ނުވަތަ ރާސްތަ ބަޓަނުން ޑްރެގްކޮށް ޕޭން ކުރޭ. ވާމު ބަޓަނަކީ ފަރާތް، އެޖް އަދި ޕްލޭން ހޮވާ ބަޓަން ފަދައިން، އެހެންކަމުން ކުޑަ ހަރަކާތެއްގެ ކްލިކް އެއްވެސް ފަހަރަށް ބައި ނުފެރާލާ. ގިނަ CAD ޕްރޮގްރާމްތައް މިގޮތަށް މަސައްކަތް ކުރެއެވެ.

ވީލް ކޮންމެ ގޮތަކުން ޖޫމް ކުރާއިރު ފޮލޯޕޮއިންޓުގެ ކައިރީ ކުރެއެވެ. ސްކެޗެއްގައި ރާސްތަ އަދި މެދު ބަޓަން އެންމެ ފަދައިން ޕޭން ކުރެއެވެ.

## ސްކްރޯލް: މައުސް ވީލް ނުވަތަ ޓްރެކްޕެޑް

- **ހުރި ގޮތް ބެލޭ** (ފުރަތަމަ): PartCraft ސްކްރޯލް ބަލާ. ސައިޑްވޭސް ނުވަތަ ރީތި ސްކްރޯލް، ޓްރެކްޕެޑް ފޮނުވާ ފަދައިން، ބައި ފެރާލައެވެ؛ ފުރިހަމަ ވީލް ނޯޓޭޝަން ޒޫމް ކުރެއެވެ.
- **މައުސް ވީލް**: ސްކްރޯލް ކުރާ ކޮންމެ ވަގުތެއްގައި ޕޮއިންޓަރާ ގުޅުމުން ޒޫމް ކުރެއެވެ.
- **ޓްރެކްޕެޑް**: ދެ ޚާނާއިން ސްވައިޕް ކޮށް ބައި ފެރާލާ، {{key:Shift}} ހިފައިގެން ސްވައިޕް ކޮށް ޕޭން ކުރޭ، ޕިންޗް ކޮށް ޒޫމް ކުރޭ. ސްކެޗެއްގައި ދެ ޚާނާއިން ސްވައިޕް ކޮށް ސްކެޗް ޕޭން ކުރެއެވެ.

ޕިންޗް ކޮންމެ އިޚްތިޔާރެއްގައި ޒޫމް ކުރެއެވެ. "ހުރި ގޮތް ބެލޭ" ތިޔަ މައުސް ނުވަތަ ޓްރެކްޕެޑަށް ގުނުން ވަރަށް ކަނޑުވެއްޖެނަމަ، ތިޔަ ހުންނަ އެކަކަށް ހޮވާ. އިތުރު ތަފްޞީލް [ޓްރެކްޕެޑް، ޓަޗް އަދި ކުޑަ ސްކްރީންތައް](topic:trackpad-and-touch) ގައި.

## ސްކެޗްކުރުން: ސްކެޗް ކުރާއިރު ރިލޭޝަން ދަމާ

**ސްކެޗް ކުރާއިރު ރިލޭޝަން ދަމާ** (ފުރަތަމަ އޮން): ޕޮއިންޓަކާ ސްނެޕް ވާ ކްލިކެއް އެ ޕޮއިންޓާ ކޯއިންސިޑެންޓް ހަދައެވެ، ކާވެ މަތީގައި ކްލިކެއް އެ ޕޮއިންޓް އެ ކާވާ ސްޓުކުރެއެވެ، އަދި ކުޑަ މައިމް ކުރާ ރޮނގު އުފުލުވައި ނުވަތަ އުފުލާ ހަދައިގެން ހޮރިޒޮންޓަލް ނުވަތަ ވަރޓިކަލް ވެއެވެ. [ރިލޭޝަންތަކާއި ޑައިމެންޝަންތައް](topic:relations-dimensions) ބަލާ.

ވަރަށް ގާތު ޖާގައި ޖިއޮމެޓްރީ ހިމެނުމަށް ހިޔާރުކުރާ ނަމަ ރިލޭޝަން ނުދަމާ ތިބޭ. ޕޮއިންޓަރު އަދިހާ ޕޮއިންޓްތަކާއި ކާވްތަކަށް ސްނެޕް ކުރެއެވެ، ނަމަވެސް އެއްވެސް ކަމެއް ނުގުޅޭ: ޗެއިނެއްގައި ދަމާ ރޮނގުތައް ފުށުތައް ބެހޭ ނޫން، އެހެންކަމުން ޑްރެގްކޮށް ވަކިކުރެވޭ. ކެންދޭ ރިލޭޝަންތައް ރާސްތަ ޕެނަލުން ތިޔަ އަމިއްލައަށް ގުޅާ. ވަސީލަ ބަންދު ޕްރޮފައިލް އެތަނުގެ ފުށުތައް ހަމަ ނަމަ އެކްސްޓްރޫޑްވެއެވެ.

:::note
ސެޓިންގް ބަދަލުކުރަނީ އާ ޑްރޯއިންގ ހުރި ކަން ބަދަލުކުރުމަށް ބަލާ. ސްކެޗުގައި ކުރިން ހުރި ރިލޭޝަންތައް ހުރިހާ ކަމަކަށް ހުންނާނެ، އަދި ފިލެޓް އުޑޫޓް އޭގެ ޓޭންޖަންޓް އާކް އަދި ރޭޑިއަސް ހަދައެވެ.
:::

## ސްކެޗްކުރުން: ސްކެޗް ކުރާއިރު ޑައިމެންޝަން

**ސްކެޗް ކުރާއިރު ޑައިމެންޝަން** (ފުރަތަމަ އޮން): ރޮނގު، ރެކްޓެންގަލް، ވަށް ނުވަތަ އާކް ހަދާއިރު ނަންބަރެއް ޓައިޕް ކުރުމުން ޕޮއިންޓަރުގެ ކައިރީ ސައިޒް ބޮކްސް ފުރޭ ({{key:Tab}} ކުރިޔަށް ދާ ބޮކްސަށް ދަނީ)، އަދި {{key:Enter}} ފޮނުވައި އެ ސައިޒުގައި ޝޭޕް ހަދާ، ކޮންމެ ސައިޒަކަށް ޑްރައިވިން ޑައިމެންޝަނެއް ހަދައި. އޮފް: ހަދާއިރު ނަންބަރު ޓައިޕްކުރުމުން އެއްވެސް ކަމެއް ނުކުރެއެވެ، އަދި ޝޭޕްތައް ކްލިކްތަކުން ބެހެއްޓެވެ. [ސައިޒް ހަދާއިރު ޓައިޕް ކުރޭ](topic:sketch-basics#type-the-size-as-you-draw) ބަލާ.

## ކޯނާ އިންޑިކޭޓަރ

3D ވިއުގެ ކޯނާގައި ފެންނަން: **View cube** (ފުރަތަމަ؛ މަތީ ރާސްތަ — ފަރާތް، އެޖް ނުވަތަ ކޯނަ ކްލިކްކޮށް އެތަނުން ބަލާ، ޑްރެގްކޮށް އޯބިޓް ކުރޭ، ކުޅުނު ރިންގ ޑްރެގްކޮށް މޮޑެލް ފެރާލާ)، **Axis icon** (ކުޑަ X، Y، Z މާކަރެއް ބާގެ ހޭކަލުގައި ވިއުއާއެކު ބަދަލުވޭ: X ރަތް، Y ހަރި، Z ނީލް) ނުވަތަ **None**. ސްކެޗް ކުރާއިރު ނުވަތަ ޑްރޯއިންގ ޝީޓުގައި އެއްވެސް އެއް ނުފެނޭ. [ވިއު ކިއުބް](topic:view-cube) ބަލާ.

## ސޮލްވަރ ތްރެޑްތައް

ސިމިއުލޭޝަން ސޮލްވަރުން ބޭނުންކުރެވޭ ތްރެޑްތަކުގެ އަދަދު. **ޙަލަތު އޮޓޮމެޓިކް** (ފުރަތަމަ) ކޮމްޕިއުޓަރުގެ ލޮޖިކަލް ޕްރޮސެސަރުތަކުން އެއް ކުޑަ ކުރެއެވެ (16 އަށްވުރެ ގިނަ ނޫން)، ޞަފްޙާ ސްޓޭޑީ ސޮލްވްކުރާއިރުގައި ރިސްޕޮންސިވް ކޮށް ތިބޭނެ ގޮތަށް؛ ނުވަތަ އަދަދެއް ހޮވާ. ބޮޑު ވޮކްސެލް ސްޓަޑީތައް، ބަކްލިންގ، ސްޓްރެސް ބޮޑަށް ވަގުތާއެކު އަދި ފްލޯ ގިނަ ތްރެޑްތަކުން އަވަސްވާ (ދެ ޔޫކެސް ތަށް ޒުވަވާކަށް 4 ތްރެޑުގައި 80,000 ކިއުބްތަކަށް ފަސް ކުރި ސާގުން ~2× ކަމުން، ކޮމްޕިއުޓަރު ހުސްވާ ނަމަ ގިނަ). 20,000 ނިޝާންކުރެވޭ ހުރުމުން އެކަނި ތްރެޑް ގައި ހުރިއިރު ޢަދަދު ކުށް، ތްރެޑްތައް ފަށާމަ ފަސްކުރާ ހުރުމަށްވުރެ ގިނަ ވަގުތު ހިނގާ. ތްރެޑް ސޮލްވް ކުރާ ޖަވާބު އެކަނި ތްރެޑް މަދުވެގެންފައި (ގުނުމުގެ ޒަރަފު ހަމަ އަދި ޑްރެޕްސާއި ގިނަވޭ). ސްޓަޑީ ރިޒަލްޓުގައި **N threads** ނުވަތަ **1 thread** ފެންނާއިރު ސަބަބު **Solver** ގައި ފެނޭ.

ތްރެޑްތަށް ޞަފްޙާ **cross-origin isolated** ވާންޖެހެއެވެ (ބްރައުޒަރު އެދައިންނެއް ޙާލަތުގައި ވޯކަރުންނަށް މެމަރީ ޝޭޒް ކުރެވޭ). ލެބް ޞަފްޙާ ވަނީ ހަމަ؛ ނޫނި ސެޓިންގް ބުނެއެވެ ("މި ޞަފްޙާ cross-origin isolated ނޫން، އެހެންކަމުން ސޮލްވަރ ތިޔަ ހޮވި އެއްވެސް އަދަދަކަށް ނޫން އެކަނި ތްރެޑް ގައި ރަން ކުރޭ.") އަދި ކޮންމެ ސޮލްވްކުރާ ހިނދަކު އެކަނި ތްރެޑް ބޭނުންވޭ. އެނިގޭ ހުރިހާ ކަމެއް އެއްފަދައިން ކުރާ، އަދި ޖަވާބުތަކަކީ އެއްފަދަ.

ލެމިނާ ފްލޯ ސްޓަޑީތައް ތްރެޑްތައް ބޭނުންކުރެއެވެ (54,000 ފްލޫއިޑް ސެލް ގައި 4 ތްރެޑުގައި ~2.5×، ހަމަ ޖަވާބު އެންމެ ފަހު ޑިޖިޓް އަށް). ކާޑްރެޓިކް ޓެޓްރާހެޑްރަލް ސޮލްވަރ އަދި ހީޓް ޓްރާންސްފާ އެކަނި ތްރެޑް ގައި ރަން ކުރެއެވެ (އަހަރުންގެ ޓެސްޓް ކޮމްޕިއުޓަރުގައި ތްރެޑިން ބާރު ވެއެވެ: ސޮލްވަރުތައް މެމަރީ ސްޕީޑް އަދި ބެހޭ ކުރާކުރާ ފަދައިން ބައިކުރެވޭ ނޫން ނަމަވެސް).

### ތިޔަ އަމިއްލަ ވެބް ސަރވަރުގައި

ތިޔަ އަމިއްލަ ސަރވަރުން PartCraft ރަން ކުރާ ނަމަ، އެ ވެސް ގޮތުން ރަން ވެއެވެ. ސޮލްވަރ ތްރެޑްތަށް، ސަރވަރު PartCraft ގެ ޞަފްޙާއާއެކު ދެ ހެޑަރ ފޮނުވާ:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

Apache ގައި، ފޯލްޑަރުގެ `.htaccess` ގައި (mod_headers ބޭނުންވޭ):

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

nginx ގައި، PartCraft ސަރވް ކުރާ `location` ގައި:

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

ޞަފްޙާ އަލުން ލޯޑް ކުރޭ: ސެޓިންގްސް › ސޮލްވަރ ތްރެޑްތައް ދެން **Automatic** ދެއެވެ ކޮމްޕިއުޓަރުގެ އަދަދާއެކު. ދެވަނަ ހެޑަރު ބްރައުޒަރަށް ޞަފްޙާއަށް ހުރިހާ ހަދާ އެހެން ސައިޓަކުން ނުހުޅުވާ ކުރޭ، އެއީ PartCraft އަމިއްލައަށް ކުރާ ކަމަށް ރަނގަޅު (އެއީ އެގެ އަމިއްލަ ފޯލްޑަރުން ހުރިހާ ކަމެއް ލޯޑް ކުރެއެވެ).
