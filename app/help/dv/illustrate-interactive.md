title: ޢިންޓަރެކްޓިވް 3D ފައިލް
summary: މެނުއަލް ހަމަ އެއް HTML ފައިލެއްގެ ގޮތުގައި އެކްސްޕޯޓް ކުރޭ، އެ ފައިލް ކޮންމެ ބްރައުޒަރަކުން އޮފްލައިން ހުޅުވޭ، އިންސްޓޯލް ކުރުމެއް، އެކައުންޓެއް ނުވަތަ ޓްރެކިންގެއް ނުބޭނުން: މޮޑެލް، ފެނުންތައް، ބައިތަކުގެ ލިސްޓް (ދެމެހެއްޓުމުން ގުޅިފައި)، އެނިމޭޝަން އަދި މެގްނިފަޔަރ.

{{ui:އެކްސްޕޯޓް}}، ދެން {{ui:ފޯމެޓް}} {{ui:ޢިންޓަރެކްޓިވް 3D ފައިލް (HTML، އޮފްލައިން ހުޅުވޭ)}} ޚިޔާރު ކުރޭ، އެކަމުން `.html` ފައިލް އެއް ރައްކާކުރޭ. އީމެއިލުން ފޮނުވާ، USB ސްޓިކެއް ނުވަތަ ހިއްސާކޮށްފައިވާ ފޯލްޑަރަކަށް ދޭ: އެ ފައިލް WebGL 2 ހުރި ކޮންމެ ބްރައުޒަރަކުން ހުޅުވޭ، ކޮމްޕިއުޓަރު، ޓެބްލެޓް ނުވަތަ ފޯނުގައި.

ފައިލުގެ ތެރޭގައި:

- މޮޑެލް އަރުވާލުމަށް ޑްރޭގް ކުރޭ، ރައިޓް-ޑްރޭގް ނުވަތަ {{key:Shift}}+ޑްރޭގް ޕޭން ކުރޭ، ވީލް ނުވަތަ ޕިންޗް ޒޫމް ކުރޭ.
- ލިސްޓުގެ ފެނުމަކަށް ކްލިކްކުރޭ: ކެމެރާ އެތަނަށް ހިލޭ، އަދި ބައިތަކުން އެ ފެނުމުގެ ތަންތަނާއި، ބެލުންތަކާއި، ކަޓާއި މެގްނިފަޔަރ ނަގައެވެ.
- ބައިތަކުގެ ލިސްޓުގެ ރޯއަކަށް ކްލިކްކުރޭ އެ ރޯގެ ބައިތައް ފެންނަވަރުކުރޭ؛ ބައިއަކަށް ކްލިކްކުރޭ އެ ބައިގެ ރޯ ފެންނަވަރުކުރޭ.
- މެނުއަލުގައި އެނިމޭޝަނެއް ހުންނަ ހިސާބުގައި، މޮޑެލްގެ ދަށުގެ ބާރެއް އެ އެނިމޭޝަން ޕްލޭ، ވަގުތަކު ހައްދަވާ އަދި ސްކްރަބް ކުރޭ.

ފައިލް ލެވޭ ހުރިހާ އެއްޗެއް ހިމެނިފައި (މޮޑެލް، ވިއުއަރ އަދި three.js، އޭގެ MIT ލައިސެންސުގެ ދަށުން)، އަދި ކޮންމެ ރިކުއެސްޓަކަށްވެސް ހާމަ ނުކުރޭ: އިންޓަނެޓަށް ނުގުޅޭ، އެކައުންޓެއް ނެތް އަދި ޓްރެކިންގެ ނެތް.

PDF ފައިލެއްގެ ތެރޭގައި ޢިންޓަރެކްޓިވް 3D ނުދެވޭ: ބްރައުޒަރުތަކާއި ގިނަ PDF ރީޑަރުތަކުން އެ ދެކެވޭކަށް ނެތް، އަދި ދެކެވޭ ރީޑަރު އޭގެ ފަރާތުން ބަންދު ކޮށްފައިވޭ. HTML ފައިލަކީ ޢިންޓަރެކްޓިވް ޖަވާބެވެ.
