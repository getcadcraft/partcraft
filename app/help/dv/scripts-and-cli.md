ކާމިލް މޮޑެލިންގ ބަޓަންތަކަށްވުރެ ފަރުވާ ކުރުމުގެ ގޮތުގައި ބަލާނީ. ޓެކްސްޓުން ލިޔާ ބައެއް ކިޔަވައި، ރިވިއު ކޮށް، ލައިންގ ލައިންގ ޚާއްޞަކޮށް ބަލައި، ސްކްރިޕްޓަކުން އާ ހަދަން ކުރެވޭ. PartCraft ދެ ފަރާތަށް ވޭ: ކޮންމެ ބައެއް ސްކްރިޕްޓެއްގެ ގޮތުގައި ލިޔެވޭ، އަދި ސްކްރިޕްޓެއް ބައެއް ހަދައެވެ.

## އެޕުގެ ތެރޭގައި

{{ui:Parameters}} ޓެބުގައި، **Script** ދަށުގައި:

- {{ui:Save as script}} ހުޅުވާ ބައި `<name>.pcscript` ގެ ގޮތުގައި ޑައުންލޯޑް ކުރާނެއެވެ.
- {{ui:Open script}} `.pcscript` ފައިލެއްން ބައެއް ހަދައެވެ. ޙަލަތެއް ވިޔަސް އޭގެ ލައިން ނަންބަރާއެކު ރިޕޯޓް ކުރެވެ، އެއްވެސް ކަމެއް ނުބަދަލުވެއެވެ.

## ސްކްރިޕްޓް ފޯމެޓް

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

ގަވާއިދު:

- ކުރު ފަރާތުން ފެށޭ ލައިނެއް ސްޓޭޓްމަންޓެއް ފަށައެވެ: `pcscript`، `part`، `param`، ފީޗަރ ޓައިޕް (`sketch`، `extrude`، `revolve`، `hole`، `lpattern`، `cpattern`، `mirror`، `fillet`، `chamfer`، `shell`، `import` އަދި އާ ޓައިޕްތައް) އަދި އޭގެ ނަމަ، ނުވަތަ `rollback <feature>`.
- ފަސްކޮށްފައިވާ ލައިންތައް މަތީ ސްޓޭޓްމަންޓުގެ ސެޓިންގްސެވެ. އެކަނި ހުންނަ ސެޓިންގެއް (`through`، `reverse`، `suppressed`) އެއީ "ހާ" ކަމެވެ.
- ނަންބަރު ސެޓިންގެއް ނަންބަރެއް ނުވަތަ `=` އަދި އެކްސްޕްރެޝަނެއް، އޭގައި އީކުއޭޝަނެއް ހެދެއެވެ: `depth = thick`.
- ސްކެޗެއްގައި: `on` ޕްލޭން ނަމާއެވެ (`front`، `top`، `right`، `face Base end`، `face Revolve1 side l3`); ޖިއޮމެޓްރީ `point <name> x, y`، `line <name> <point> <point>`، `circle <name> <centre> <radius>`، `arc <name> <centre> <start> <end>` (ކައުންޓަ-ކްލޮކްވައިޒް) ނުވަތަ `spline <name> fit|control <points>`؛ ރިލޭޝަންތައް އެމީހުންގެ ޓައިޕާއި އެ ގުޅޭ ނަންތައް ( `O` އަކީ އޮރިޖިން); ޑައިމެންޝަނެއް ނިމޭނީ އޭގެ ވެލިއު ނުވަތަ `= expression` އިންނެވެ.
- ޖިއޮމެޓްރީ ނުވަތަ ރިލޭޝަން ލައިނެއްގެ އިޚްތިޔާރީ ސެޓިންގްސް ކުޑަ ބްރެކެޓުގެ ތެރޭގައި ޑައިވްޝަން `;` އިން ފަސްކުރާ: `[construction]`، `[side -1; label 5, 3]`.
- `#` އިން ކޮމެންޓް ފެށެއެވެ (ލައިނގެ ފަށުގައި ނުވަތަ ސްޕޭސްއެއްގެ ފަހުން). ސްޕޭސް ހުރި ނަންތައް "ޑަބަލް ކޯޓު" ތެރޭގައި ލިޔޭ.
- ފީޗަރ އައިޑީތައް f1 އިން ފަށައި، ލިޔެވޭ ހިސާބުން ގިނަވޭ. އެޖް އަދި ފަރާތް ރެފަރެންސްތައް އެ އައިޑީތައް ބޭނުންކުރެއެވެ، މިސާލަކަށް `edge f2.side:l3 f2.end [at 50, 0, 10]`.
- ފޯމެޓުގައި ވޯޑުތެރެއެއް ނެތް ސެޓިންގްސް `json` އަދި ވެލިއުއެއް ލިޔެ، ބާކީ އެގޮތުން ކިޔެވެ.

އެޕުން ސޭވް ކުރާ ސްކްރިޕްޓަށް ހުރިހާ ސެޓިންގެއް ހިމެނޭ، ފަހުން އެއަށް އެއް ބައެއްގެ ގޮތުގައި ހުޅުވޭ. އެޕުން އިމްޕޯޓް ކުރެވުނު STEP ސޮލިޑެއް ސްކްރިޕްޓްގެ ތެރޭގައި ލިޔެވޭ، އަދި ކޮމާންޑް ލައިނުން `step-file` އިން ނަމަ ދޭ ވަކި `.step` ފައިލެއްގެ ގޮތުގައި.

## ކޮމާންޑް ލައިން ޓޫލް

ޓޫލް ރަން ވެއެވެ Node.js 24 ހުރި ކޮމްޕިއުޓަރެއްގައި، CadCraft ސޯސްގެ ކޮޕީއެއްން: `node tools/partcraft-cli/partcraft.mjs <command>`. އޭ ޑެވެލޮޕަރ ޓޫލެކެވެ އަދި އެޕުގެ އެހެން މޮޑިއުލްތައް ބޭނުންކުރެއެވެ. ބައިތައް `.partcraft.json` ފައިލްތައް ނުވަތަ `.pcscript` ސްކްރިޕްޓްތަކެވެ.

| ކޮމާންޑް | ކުރާ ކަންތައް |
|---|---|
| `info <part>` | ފީޗަރ، ޕެރަމީޓަރ، ރޯލްބެކް ބާ، ހަދާފައިވާ ސޮލިޑުގެ ވޮލިއުމާއި ސައިޒް |
| `params <part>` | ކޮންމެ ޕެރަމީޓަރއާއި އީކުއޭޝަނެއް އޭގެ ވެލިއުއާއެކު |
| `set <part> width=150 Base.depth==thick` | ފުރަތަމަ: ޕެރަމީޓަރ ބަދަލުކުރޭ، ނަންބަރު ގުޅޭ (`==` ނުވަތަ އެކްސްޕްރެޝަން)، ސާދާ ނަންބަރު ސެޓް ކުރޭ |
| `drive <part> Base.depth=12` | ފަހަތަށް: ޑްރައިވްކުރެވޭ ނަންބަރުގެ ފަހަތުގެ ޕެރަމީޓަރ ސޮލްވްކުރޭ (`--prefer width` އެއް ހޮވާ) |
| `build <part> --out x.step` | `.step`، `.stl`، `.3mf`، `.json`، `.pcscript` ނުވަތަ މެކްރޯ (`.swb`) ލިޔޭ |
| `build <part> --table sizes.csv --out-dir sizes` | ޑިޒައިން ޓޭބަލުގެ ކޮންމެ ރޯއަކަށް ފައިލެއް |
| `variants <part> --out-dir d` ނުވަތަ `--zip f.zip` | ކޮންފިގުރޭޝަން ހުރިހާ އެއް STEP، IFC، DWG އަދި ޕްރިވިއުއާއި، ވޭރިއަންޓްސް ޓޭބަލާއި ލައިބްރަރީ އައިޓަމެއް (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`); [ވޭރިއަންޓް ޕެކެއް ހަދާ](topic:variant-pack) ބަލާ |
| `script <in.pcscript> -o part.json` | ސްކްރިޕްޓް ބައަށް |
| `to-script <part> -o part.pcscript` | ބައި ސްކްރިޕްޓަށް |
| `rollback <part> [<feature>]`، `forward <part> [--end]` | ފައިލުގެ ރޯލްބެކް ބާ ގެންދޭ |
| `check <part> [--strict]` | ބަދަލުކުރުން ދުވަސްވަރުން އަވަސް ކުރާ ޑިސިޕްލިން ޗެކް (ތިރީގައި) |

`build` އަށް `--set name=value` (މި ބިލްޑަށް ބަހައްޓާ) އަދި `--upto <feature>` ވެސް ލިބޭ. ކޮންމެ ކޮމާންޑަކަށް `--json` ލިބޭ. ނިމުމުގެ ކޯޑު: 0 ރަނގަޅު، 1 މައްސަލައެއް ފެނުނު، 2 ކޮމާންޑް ގުނެވި ނުލިޔެވުނު. ސްކްރިޕްޓެއް ތަނުން ނުބަދަލުވޭ: ބަދަލުވެފައިވާ ކޮޕީއެއް ސޭވް ކުރުމަށް `-o` ދޭ.

## ޗެކް

`check` ބައި ފަހުން ބަދަލުކުރުމަށް ދަތި ކުރާ ކަންތައް ރިޕޯޓް ކުރެއެވެ:

| ފައިންޑިންގ | ގުނާ ގޮތް |
|---|---|
| ސްކެޗެއް އަރިހުން ގިނަ ރިލޭޝަން (ދެކޮޅު ނުވަތަ ތަކުރާރު ރިލޭޝަން) | މައްސަލަ |
| ފީޗަރެއް ހަދައިގަނެ ނުލެވޭ | މައްސަލަ |
| ޕެރަމީޓަރެއް ނުވަތަ އީކުއޭޝަނެއް މައްސަލައަކާއެކު، ނުވަތަ އެކަނެކު ބޭނުންކުރާ ޕެރަމީޓަރ | މައްސަލަ |
| ސްކެޗެއް ނިމިފައުނުވާ، އޭގެ ޑިގްރީސް އޮފް ފްރީޑަމާއެކު | އަގުހުރި ނޯޓުން |
| ފީޗަރާއި ޑައިމެންޝަނަށް ސީދާ ލިޔެ، އެއްވެސް ޕެރަމީޓަރ ޑްރައިވް ނުކުރާ ނަންބަރުތައް | އަގުހުރި ނޯޓުން |
| އެއްވެސް ކަމަކަށް ބޭނުން ނުވާ ޕެރަމީޓަރ | އަގުހުރި ނޯޓުން |
| ފަސްކޮށްފައިވާ ފީޗަރ؛ ރޯލްބެކް ބާ ނިމުމުގައި ނޫން | އަގުހުރި ނޯޓުން |

`--strict` ކުރާއިރު ކޮންމެ ވޯނިންގެއް މައްސަލައަކަށް ބަދަލުވާތީ، ބިލްޑް ސްކްރިޕްޓަކަށް މުޅިން ޑްރައިވްނުކުރެވޭ ބައެއް ރިފިއުޒް ކުރެވޭނެއެވެ.

:::note
`.swb` މެކްރޯ އުޅެނީ ގިނަ ޝޮޕްތައް ބޭނުންކުރާ ބައި މޮޑެލަރަށެވެ: އެ ޕްރޮގްރާމުގެ ތެރޭގައި ރަން ކުރުމުން އެތަނުގައި ބައި ހަދައެވެ. މިތަނުގައި އެ ޕްރޮގްރާމުގައި ރަން ނުކުރެވުނެވެ (އެ އަށް އަހަރުންގެ ސަރވަރުގައި ނުލިބޭ)، ފަހުން ޓެސްޓް ނުކުރެވުނު ގޮތަށް ބަލާ.
:::
