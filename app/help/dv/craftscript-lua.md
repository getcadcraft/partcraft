Lua އަކީ [ސްކްރިޕްޓް ވޯކްސްޕޭސްގެ](topic:craftscript) ދެވަނަ ބަހެވެ. އެޑިޓަރުގެ މައްޗަށް ބަހުގެ ބޮކްސްއިން **Lua** ނަގާ (`.lua` ފައިލެއް އޮޓޮމެޓިކުން Lua ގައި ހުޅުވެއެވެ). Lua އާއި CraftScript ދެކަމުން ވޭރިއަބަލްތަކާއި ބިލްޓް އިން ފަންކްޝަންތައް ޝޭއާކުރެއެވެ، އެހެންކަމުން Lua ސްކްރިޕްޓަކަށް CraftScript ސްކްރިޕްޓަކުން ހަދާ ކަންތައް ބޭނުންކުރެވޭ، އަދި އެއީ ދެމެހެއްޓުމެވެ.

## އަސާސީ ކަންތައް

```
-- ކޮންމެ ބިލްޓް އިން ފަންކްޝަނެއް cs ޓޭބަލްގައެވެ
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1 އިން ފެށެއެވެ، CraftScript ފަދައިން
print(K(1, 1), #K)             -- އެއް އެލިމަންޓް؛ އެލިމަންޓުގެ ޢަދަދު

-- ވޯކްސްޕޭސް: ކޮންމެ ސްކްރިޕްޓަކަށް ފެންނާ ވޭރިއަބަލްތަކެވެ
ws.total = K(1, 1) * 2
print(ws.total)

-- ފަންކްޝަނެއްގެ ތެރެއިން ކިތައް ނަތީޖާ
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` ކޮންމެ ބިލްޓް އިން ފަންކްޝަނަކަށް ކޯލްކުރެއެވެ އަދި އެގެ ފުރަތަމަ ނަތީޖާ ދެއެވެ؛ `cs.call(name, n, …)` ވެސް `n` ނަތީޖާ ދެއެވެ.
- `cs.tensor({1, 2, 3})` ރޯއެއް ހަދައެވެ، `cs.tensor({{1, 2}, {3, 4}})` މެޓްރިކްސެއް.
- އެރޭތައް، ސްޕާސް މެޓްރިކްސްތައް، މެޝުތައް އަދި ފީލްޑްތައް މިތަނުގައި މެތަޑުތައް އުޅޭ އަގުތަކެވެ: `t(i, j)` ނުވަތަ `t:get(i, j)`، `t:set(i, j, v)`، `t:shape()`، `#t`، `t:T()` (ޓްރާންސްޕޯސް)، `t:totable()`. `+ - * / ^` އެއީ CraftScript ގައި އަދި އެ މާނައެވެ (`*` ކަމުގައި މެޓްރިކްސް ޕްރޮޑަކްޓެވެ); `t:times(u)` އެއް އެއް އެލިމަންޓުން ގުނެއެވެ.
- އެއް×އެއް އެރޭއެއް ރޭވުމުން ރަނގަޅު Lua ނަންބަރެއް ލިބެއެވެ.
- `ws.name` ޝޭއާކުރެވޭ ވޯކްސްޕޭސް ކިޔަވައި ލިޔެއެވެ. ސްކްރިޕްޓް ނިމުމުން ތިޔަ ގްލޯބަލް ވޭރިއަބަލްތައް ވެސް އެތަނަށް ދާއެވެ.
- `print(…)` ކޮންސޯލަށް ލިޔެއެވެ؛ `cs.show(f)`، `cs.plot(y)` އަދި އެހެން ޑިސްޕްލޭ ފަންކްޝަންތައް CraftScript ގައިފަދައިން މަސައްކަތް ކުރެއެވެ.

## އެނަލިސިސް ލައިބްރަރީ ކޯލް ކުރޭ

އެނަލިސިސް ލައިބްރަރީގެ ފަންކްޝަންތައް (Library ޓެބް) އަދި ތިޔަ ޕާޓުގެ ސްކްރިޕްޓްތައް ގެ CraftScript ފަންކްޝަންތައް ވެސް `cs` ދެކެ ލިބެއެވެ:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- ދެ ނަތީޖާ
```

ސްކްރިޕްޓް ފަށާށެވެ ކުރިން ހޯދެވެ، ފަހެވެ ނަން ސްކްރިޕްޓުގައި ލިޔޭ: `cs.static_tet(` ނުވަތަ `cs.call('static_tet', …)`. ރަން ވާއިރު ޖަމާކުރާ ނަމެއް ބިލްޓް އިން ފަންކްޝަންތަކަށް ބަލަށި ހިނގާނެއެވެ. `cs.struct({ … })` އިން ހަދާ ސްޓްރަކްޓް އަކީ CraftScript ސްޓްރަކްޓެކެވެ، އަދި Lua ލިސްޓެއް (`{ cs.struct(…), … }`) ސެލެކެވެ، އެ ލައިބްރަރީ ސެޓިންގްސްއާ ބެހޭ. ލައިބްރަރީ ފަންކްޝަނެއްގެ ތެރޭގައި ކޮންމެ ކަމެއް ގޮވާލާ ފަހުން މެސެޖް އެ ފަންކްޝަނުގެ ނަމާއި ލައިން ދައްކާއެވެ، އަދި ކޯލް ކުރި ތިޔަ ލައިނަށް ފާހަގަކުރެއެވެ.

## ނިވާކުރެވުނު ކަންތައް

ސްކްރިޕްޓްތަކަށް ފައިލް، ނެޓްވާރކް، ނުވަތަ ޕޭޖަށް ޙާޟިރުވެވޭ ނުކުތާ ނެތެވެ: `io`، `os` (ކްލޮކް ނޫން ނުކުތާ ފިޔަވައި)، `require`، `dofile`، `loadfile` އަދި `debug` ނެރިފައިވެއެވެ. ޑޭޓާ ގެނެސް ބޭނުންކުރޭ ސްކްރިޕްޓް ވޯކްސްޕޭސްގެ Open އަދި ވޭރިއަބަލްތައް. ސްޓެޕް ބަޖެޓް އަދި Stop މަސައްކަތްކުރަނީ CraftScript ގައި ފަދައިންނެވެ.
