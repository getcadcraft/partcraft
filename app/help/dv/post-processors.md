އެއް ޓޫލްޕާތް ކޮންޓްރޯލްތަކަށް ބިން ގޮތްތަކުން ލިޔަންވީ: ލައިން ނަންބަރު ނުވަތަ ނޫން، `M6` ނުވަތަ ވަގުތީ ހިނިތުން، `G28` ނުވަތަ `G53`، `M30` ނުވަތަ `M2`. **ޕޯސްޓް** ކިޔަނީ އެ ގޮތް ބަޔާންކުރާ ކުޑަ ޓެކްސްޓެކެވެ. PartCraft ގެ ތިން ބިލްޓް އިން ޕޯސްޓް (Fanuc-style، GRBL އަދި LinuxCNC) މި ފޯމެޓުން ލިޔެފައިވާތީ، ތިޔަ ޕޯސްޓެއް އެއްގެ ކޮޕީއަކުން ފަށާ ކުރެވޭނެއެވެ.

ކަޓް ކުރުމުގެ ކުރިން ތިޔަ މެޝިނުގެ ސިމިއުލޭޓަރުން ނަތީޖާ ބަލާ، އަދި ސްޓޮކް މަތީގައި ހަވާއަށް ފުރަތަމަ ރަން ކުރޭ. ބިލްޓް އިން ޕޯސްޓްތައް މި ފޯމެޓް ހެދުމުގެ ކުރިން ލިއެވި ހުރިހާ ކަމެއް ލިޔެއެވެ (ޓެސްޓްތައް ގިނަ ޕްރޮގްރާމްތަކުގައި ބައިޓް ބައިޓް ބަރާބަރު ކުރެއެވެ). ނަމަވެސް މިތާ އެއްވެސް ކަމެއް ތިޔަ މެޝިނުގައި ޘާބިތު ނުވެއެވެ، އަދި ބަދަލު ކުރި ޕޯސްޓް ސާބިތު ކުރުން ތިޔަ ޒިންމާއެވެ.

## އެއް ހަދާ

Manufacture ގައި، **Post** ގެ ދަށުން:

- {{ui:ޕޯސްޓް ބަދަލުކުރޭ…}} ބިލްޓް އިން ކޮންޓްރޯލަކަށް ހުޅުވާ **ތިޔަ ޚާއްޞަ ކޮޕީ** ހުޅުވާ. ތިޔަ ޚާއްޞަ ޕޯސްޓަކަށް ހުޅުވާ އެ ޕޯސްޓް ހުޅުވާ.
- {{ui:އާ ޕޯސްޓް…}} ހުސް ބްލޭންކް ޕޯސްޓަކުން ފަށާ، ހުރިހާ އީވެންޓް ވެސް ތިރީ.
- {{ui:ޕޯސްޓް ފައިލް އިމްޕޯޓް ކުރޭ…}} `.cpost` ޓެކްސްޓް ފައިލެއް ކިޔަވާ (އެޑިޓަރުގެ **Save as a file…** އިން ލިބޭ ފައިލް).

އެޑިޓަރުގައި ޓެކްސްޓް ފެނޭ، ކިޔަވާ ކުރެވޭތޯ ހެއްޔެވަނީ ލައިންއެއް ދައްކާ (އަދި ސަމާންނުވާ ލައިން ދައްކާ)، އަދި ޓައިޕް ކުރާ ހިނދު ޕޯސްޓް ލިޔޭ G-code ފެނޭ. **Preview with** އިން ހުރިހާ އީވެންޓް ރަން ކުރާ ކުޑަ ނަމޫނާއި، ނުވަތަ މި ޕާޓުގެ ޕްރޮގްރާމް ޗޮއިސް ކުރެވޭ. {{ui:ރައްކާކުރޭ}} ޕޯސްޓް ޕާޓުގެ ފައިލްގައި ރައްކާ ކުރައި (20 ޕޯސްޓް އަށް ހަމަ) އަދި ކޮންޓްރޯލަށް ޗޮއިސް ކުރެއެވެ. ޕޯސްޓްތައް ޕާޓާއެކު ދާއެވެ؛ އެހެން ޕާޓެއްގައި ބޭނުން ކުރުމަށް، ފައިލަކަށް ރައްކާ ކޮށް އެ ޕާޓުގައި އިމްޕޯޓް ކުރޭ.

## ޕޯސްޓް ކިހިނެއް ހެއްޔެވެ

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` އިން ފަށާ ލައިންތަކާއި ހުސް ލައިންތައް ނުލިޔެވޭ. މަތީގައި ސެޓިންގްސް ހުރި؛ ދެން ކޮންމެ އީވެންޓަކަށް `on <event>` ބްލޮކެއް، `end` އިން ނިންމާ. ނުލިޔާ އީވެންޓަކަށް އެއްވެސް ކަމެއް ނުލިޔެވޭ.

| ސެޓިންގ | މާނަ |
|---|---|
| `post <id>` | ޕޯސްޓުގެ އައިޑީ: އަކުރު، އަދަދު، `-` އަދި `_` |
| `name <text>` | ކޮންޓްރޯލް ލިސްޓުގައި ފެންނާ ނަން |
| `extension <ext>` | ފައިލް އެކްސްޓެންޝަން: nc، ngc، tap … |
| `line-numbers 10` / `off` | `emit` ލައިން ކޮންމެ ލައިނަކަށް `N10`، `N20` … ނުވަތަ އެއްވެސް ނެތް |
| `decimal-point yes` / `no` | `10` ގެ ބަދަލުގައި `10.` (ކޮމެންޓުތަކުގައި ފޮއިންޓް ނެތް) |
| `canned-cycles yes` / `no` | `no`: ހޯލްތައް އެމީހުން ކުރާ G0/G1 މޫވްތަކަށް ލިޔެވޭ |
| `modal <group> <words>` | ގްރޫޕް ވާޑްތައް (`modal motion G0 G1 G2 G3`) ބަދަލު ވާއިރުގައި ކަމަކަށް ލިޔެވޭ |

## އީވެންޓްތައް

ޕްރޮގްރާމަކަށް މިވަރުން ރަން ވެއެވެ: `start`؛ ދެން ކޮންމެ އޮޕަރޭޝަނަކަށް `operation`، ޓޫލް ބަދަލުވާއިރު `tool-change`، ސްޕީޑް ބަދަލުވާއިރު `spindle`، ފުރަތަމަ ޕޮއިންޓަށް ދާ މޫވް `approach`، `coolant-on`، އަދި އޭގެ މޫވްތައް `rapid`، `feed` އަދި `arc` ގެ ގޮތުން، އަދި ކޮންމެ ކެނޯޙީ ސައިކަލް `cycle-start` ގެ ގޮތުން، ކޮންމެ ހޯލަށް `cycle-hole`، އަދި `cycle-end`؛ އަދި ފަހުން `end`.

ކޮންމެ އީވެންޓަކަށް އެ ގޮތުގެ މޫވްގެ ވެރިއަބަލްތައް ބޭނުން ކުރެވޭ، `{name}` ގޮތުގައި ލިޔެފައި: ޕްރޮގްރާމް (`name`، `program`، `setup.axis`، `setup.origin`، `setup.coolant`)، ސްޓޮކް (`stock.kind`، `stock.d`، `stock.sx`، `stock.sy`، `stock.sz`، `stock.minx` … `stock.maxz`)، ޓޫލް (`tool.number`، `tool.desc`، `tool.kind`، `tool.d`، `tool.flutes`، `tool.fluteLen`)، އޮޕަރޭޝަން (`op.name`، `op.type`)، `rpm`، މޫވްގެ ޕޮއިންޓް (`x`، `y`، `z`، `f`، އަދި `moved`: އޯކްސެއް ބަދަލު ވިޔަސް true)، އާކްސް (`arc.g` 2 ނުވަތަ 3، `arc.i`، `arc.j`، `arc.cx`، `arc.cy`) އަދި ހޯލްތައް (`hole.x`، `hole.y`، `hole.z`، `hole.r`، `hole.q`، `hole.return`، `hole.first`، `cycle.kind`، `cycle.init`، `feed`). އެޑިޓަރުގެ **Events and variables** ލިސްޓުން ކޮން އީވެންޓަށް ކޮން ވެރިއަބަލް ފެންނާނެކަން ދައްކައެވެ. ކިޔަވާ އަދި ސެޓް ކުރެވޭ ސްޓޭޓް: `cool`، `offset`، އަދި `at.x`، `at.y`، `at.z`، `at.f` (ފަހުން ލިޔެވުނު އަގުތައް).

## ސްޓޭޓްމަންޓްތައް

| ސްޓޭޓްމަންޓް | ކުރާ ކަންތައް |
|---|---|
| `raw TEXT` | ލައިންއެއް ޓައިޕް ކުރެވުނު ގޮތުގައި (ލައިން ނަންބަރެއް ނެތް) |
| `comment TEXT` | `(TEXT)` ASCII ނޫން އަދި ބްރެކެޓް ނެގުމަށްފަހު |
| `emit WORD WORD …` | ވާޑްތަކުގެ ލައިންއެއް؛ ހުސް ނިކުންނަ ވާޑްތައް ނެގެނީ؛ ވާޑް ނެތް ނަމަ ލައިން ނެތް |
| `word WORD …` | ހަދާ ލައިނަށް ވާޑް އިތުރު ކުރޭ؛ ހުސް `emit` އިން ނިންމާ |
| `if EXPR` … `else` … `end` | ޝަރުތު: `a == b`، `a != b`، `not a`، `a and b`، `a or b`، `a??b` (a، ނޫނަ b) |
| `for tool in tools` … `end` | ޕްރޮގްރާމް ބޭނުން ކުރާ ކޮންމެ ޓޫލަކަށް އެއް ފަހަރު |
| `set NAME EXPR` | އަގެއް މަހަކުރޭ (`set offset tool.number`) |
| `reset NAME …` | މޮޑަލް ވާޑް ހުސް ކުރޭ (ގްރޫޕެއް، `Z` ފަދަ އެޑްރެސް އަކުރު، ނުވަތަ `at.z`) |
| `do rapid X Y Z` | ޕޮއިންޓަކަށް `rapid` އީވެންޓް ރަން ކުރޭ |

ވާޑެއް ކިޔަނީ ޓައިޕް ކުރެވުނު ޓެކްސްޓް `{variable|filter}` ހޯލްތައް ހިމެނޭ. ފިލްޓަރ: `upper`، `lower`، `pad:N` (ޒީރޯ ފިލް)، `cut:N` (ފުރަތަމަ N އަކުރު)، `safe` (ކޮމެންޓް އަށް ސަލާމަތް ASCII) އަދި `int`. `~` އިން ނިންމާ ވާޑެއް **މޮޑަލް** ކަމުގައި: ފަހުން ލިޔެވުނު ކަމަށް ވަރަށް ބަދަލު ވާއިރު ލިޔެވޭ (`G1~`، `X{x}~`). `~!` އިން ނިންމާ ވާޑެއް ކޮންމެ ފަހަރަކު ލިޔެވޭ އަދި ހަނދާންވެއެވެ. ވެރިއަބަލް ނޫން ނަމެއް ސާދާ ޓެކްސްޓެއް (`G81`، `mist`). އަންކަ 0.001 mm އަށް ރައުންޑް ކުރެވޭ އަދި ފަހު ސުންނަތައް ލިޔެވޭ ނޫން.

## ޕޯސްޓަށް ނުކުރެވޭ ކަންތައް

އެއީ މޫވްތައް ކިހިނެއް ލިޔެވޭ ކަމަށް ނިންމާ، އެންމެ ހަމަ. ޓޫލްޕާތް ބަދަލު ނުކުރޭ، އޮޕަރޭޝަން ބަދަލު ނުކުރޭ، އާކް ބައިނާ ނުކުރޭ، އެކްސް އިތުރު ނުކުރޭ، މެޝިނުގެ ޓްރެވަލް ނުވަތަ ކައިނެމެޓިކްސް ނުދަނީ، އަދި ކޯއޯޑިނޭޓް މީހުން ޙިސާބު ނުކުރޭ (`+` ނެތް). ޕްރޫބިން، ޓޫލް ލައިފް އަދި ސަބްޕްރޮގްރާމް ސައިކަލް، 4 އަދި 5 އެކްސް އައުޓްޕުޓް އަދި ލޭތް ކޯޑްތައް ހެދިފައެއް ނުވެއެވެ. އެހެން ޕްރޮގްރާމްގެ `.cps` ފަދަ ޕޯސްޓް ފައިލް ލޯޑު ނުކުރެވޭ: މިއީ އަލަށް، ކުޑަ ފޯމެޓެއް.
