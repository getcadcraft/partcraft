summary: ޕޯސްޓް އަކީ ޓޫލްޕާތް ތިބާގެ ކޮންޓްރޯލަށް G-code ކުރާ ކުރު ޓެކްސްޓް ފައިލެއް. ބިލްޓް އިން ޕޯސްޓަކުން ކޮޕީކޮށް، ބޭނުންވާ ލައިންތައް ބަދަލު ކުރޭ (ލައިން ނަމްބަރ، ޓޫލް ބަދަލު، ހޯމް މޫވް، އެންޑް ކޯޑް)، ޓައިޕް ކުރާ ހިނދު ލިޔޭ G-code ފެނޭ، އަދި ފައިލް ބާއި އެކު ރައްކާ ކުރޭ.

ހަމަ ޓޫލްޕާތަކަށް ކޮންޓްރޯލްތައް އެކުގައި ވަކިވަކިން ލިޔޭ: ލައިން ނަމްބަރ ހުންނާނެ ނުވަތަ ނޫން، `M6` ހެއްޔެ ރަނގަޅު ނުވާ، `G28` ހެއްޔެ `G53`، `M30` ހެއްޔެ `M2`. **ޕޯސްޓް** އަކީ އެ ކަން ބުނާ ކުރު ޓެކްސްޓެވެ. PartCraft ގެ ތިން ބިލްޓް އިން ޕޯސްޓް (Fanuc ސްޓައިލް، GRBL އަދި LinuxCNC) މި ފޯމެޓުން ލިޔެފައިވާތީ، ތިބާގެ އަމިއްލަ ޕޯސްޓް އެއްގެ ކޮޕީއެއްގެ ގޮތުން ފަށާ ހިނދު ކުރެވޭ.

ކޮންޓްރޯލް ސިމިއުލޭޓަރުން ބަލާ، އަދި ކަނޑާ ކުރުމުގެ ކުރިން ހަވާއިން ރަން ކުރޭ. ބިލްޓް އިން ޕޯސްޓްތައް ކޮންޓްރޯލްތައް ލިޔެފައިވާ ފަދައިން ލިޔެވެ (ޓެސްޓްތަކުން ސައްތަ ރަތް ޕްރޮގްރާމްތަކުން ބައިޓް ބައިޓުން ބަލައެވެ)، ނަމަވެސް ކޮންމެ ކަމެއް މި ތަނުގައި ސާބިތު ނުވެފައި، އަދި ތިބާ ބަދަލު ކުރި ޕޯސްޓް ތިބާ ސާބިތު ކުރަން ޖެހޭ.

## އެއް ހަދާ ގޮތް

Manufacture ގައި، **Post** ދަށުން:

- ބިލްޓް އިން ކޮންޓްރޯލް ޚިޔާރުކުރާ {{ui:Edit post…}} ތިބާގެ އަމިއްލަ ކޮޕީ ހުޅުވޭ. ތިބާގެ އަމިއްލަ ޕޯސްޓެއް ހުޅުވާ ނަމަ އެ ޕޯސްޓް ހުޅުވޭ.
- {{ui:New post…}} ކުޑަ ޕޯސްޓަކާ ފަށައި، ހުރިހާ އީވެންޓް އެއް ތެރޭގައި.
- {{ui:Import post file…}} `.cpost` ޓެކްސްޓް ފައިލް ކިޔޭ (ފައިލް އެޑިޓަރުން **Save as a file…** ބިން ލިބޭ ފައިލް).

އެޑިޓަރ ޓެކްސްޓް ދައްކާ، އަދި ކިޔެވޭ ނުވަތަ ކިޔެވޭ ނޫން (އަދި ކޯން ލައިން ޙައްދު) ލިޔެ ދައްކާ، އަދި ޓައިޕް ކުރާ ހިނދު ޕޯސްޓް ލިޔޭ G-code ދައްކާ. **Preview with** ކުޑަ ނަމޫނާ ޕްރޮގްރާމެއް ނުވަތަ މި ޕާޓުގެ ޕްރޮގްރާމް ޗުނޭ. {{ui:Save}} ޕޯސްޓް ޕާޓުގެ ފައިލްގައި ރައްކާ ކުރޭ (20 ޕޯސްޓް އަށް ފަސް)، އަދި ކޮންޓްރޯލް ކަމުގައި ޗުނޭ. ޕޯސްޓްތައް ޕާޓާއެކު ދަނީ؛ އެހެން ޕާޓަކަށް ގެންގުޅުމަށް ފައިލްގެ ގޮތުން ސޭވްކޮށް އެހެން ތަނުގައި އިމްޕޯޓް ކުރޭ.

## ޕޯސްޓް ކޮންމެ ކޮން ފަރާތެއް

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` ން ފަށާ ލައިންތަކާއި ހުސް ލައިންތައް ނޭނގޭ. މަތީގައި ސެޓިންގްސް، ދެން ކޮންމެ އީވެންޓަށް `on <event>` ބްލޮކެއް، `end` އިން ނިމޭ. ނެރުނު އީވެންޓަކަށް އެއްވެސް ކަމެއް ނުލިޔޭ.

| ސެޓިންގ | މާނަ |
|---|---|
| `post <id>` | ޕޯސްޓުގެ އައިޑީ: އަކުރު، ޢަދަދު، `-` އަދި `_` |
| `name <text>` | ކޮންޓްރޯލް ލިސްޓްގައި ފެންނާ ނަން |
| `extension <ext>` | ފައިލް އެކްސްޓެންޝަން: nc، ngc، tap … |
| `line-numbers 10` / `off` | `N10`، `N20` … ކޮންމެ `emit` ލައިނުގައި، ނުވަތަ އެއް ނޫން |
| `decimal-point yes` / `no` | `10.` ކަމަށް `10` އުސާ (ކޮމަންޓްތަކުގައި ޕޮއިންޓް ނުހުރި) |
| `canned-cycles yes` / `no` | `no`: ހޯލްތައް ޖެހި G0/G1 މޫވްސްއަށް ލިޔެ |
| `modal <group> <words>` | ގްރޫޕް ވާ ވޯޑްތައް (`modal motion G0 G1 G2 G3`) ބަދަލުވާ ހިނދުން ލިޔެ |

## އީވެންޓްތައް

ޕްރޮގްރާމަކަށް ތަރުތީބު: `start`؛ ދެން ކޮންމެ އޮޕަރޭޝަނަށް `operation`، `tool-change` (ޓޫލް ބަދަލުވާ ހިނދު)، `spindle` (ސްޕީޑް ބަދަލުވާ ހިނދު)، `approach` (ފުރަތަމަ ޕޮއިންޓަށް ހިއްލާ މޫވް، ފުރަތަމަ ރެޕިޑްއަށް ކުރިން)، `coolant-on`، ދެން އޭގެ މޫވްތައް `rapid`، `feed` އަދި `arc`، އަދި ކޭންޢްޑް ސައިކަލްތައް `cycle-start` އާއި އެއް `cycle-hole` ކޮންމެ ހޯލަކަށް އަދި `cycle-end`؛ ފަހުން `end`.

ތިން އެކްސިސްއަށް ވުރެ ގިނަ ކަންތައް އަށް އިތުރު އީވެންޓްތައް (ޕޯސްޓަކަށް އެ އީވެންޓް ނެތް ނަމަ ޕްރޮގްރާމް ރިފިއުޒް ކޮށް ނެތް އީވެންޓްގެ ނަން ބުނޭ):

| އީވެންޓް | ކޮން ވަގުތު | ވެރިއަބަލްތައް |
|---|---|---|
| `index` | ޓޫލް ދިމާ ފަހު އޮޕަރޭޝަނަށް ވުރެ ތަފާތު ކަމުގައި ހުންނާ އޮޕަރޭޝަނަށް ކުރިން، އަދި ރޮޓަރީ އެކްސިސް ހުންނަ މެޝީނެއްގައި ފުރަތަމަ އޮޕަރޭޝަނަށް ކުރިން | `rot.a`، `rot.b`، `rot.c` (ދާންޖެހޭ ޕޮޒިޝަންތައް؛ މެޝީނުގައި ނެތް އެކްސިސް އަށް ހުސް)، `first.x`، `first.y`، `first.z` |
| `rapid-rotary`، `feed-rotary` | ކަނޑާ ހިނދު ރޮޓަރީ އެކްސިސްތައް ހަރަކާތް ކުރާ އޮޕަރޭޝަނެއްގެ މޫވްތައް | `x`، `y`، `z`، `rot.a`، `rot.b`، `rot.c`، `f`، `rot.moved`، `inverse` (ފީޑް އިންވާރސް ޓައިމް ކުރާ ހިނދު yes)، `invf` (1/މިނެޓް) |
| `rotary-end` | އެވެނި އޮޕަރޭޝަނަށް ފަހު | ނެތް |
| `probe-move` | ޕްރޯބު ތަނގާ ހިނދު ނިސްބަތު މޫވް | `x`، `y`، `z`، `f`، `probe.n` (1 އިން 4)، `probe.axis` (x، y ނުވަތަ z)، `probe.k` (1، 2 ނުވަތަ 3) |
| `probe-set` | ޕްރޯބިންގ ސައިކަލެއްގެ ޓަޗްތަކުން ފަހު | `probe.kind` (`"z"`، `"x"`، `"y"` ނުވަތަ `centre`)، `probe.action` (`set` ނުވަތަ `measure`)، `probe.expect`، `probe.cx`، `probe.cy` |
| `thread` | ލޭތެގައި ތްރެޑް މޫވް | `x`، `z`، `thread.lead` |

ކޮންމެ އީވެންޓަކަށް ހުރި ކޮންމެ ވެރިއަބަލް: `kin` (none، a، b، ac، bc)، `rotary` އަދި `tcp` (yes ނުވަތަ no، ސެޓަޕްގެ މެޝީނުން)، `pivot.x`، `pivot.y`، `pivot.z`، އޮޕަރޭޝަނުގެ `op.tilt` އަދި `op.turn`، އަދި ލޭތެގައި `spin.mode` (css ނުވަތަ rpm)، `spin.css`، `spin.max` އަދި `tool.nose`. ގަރާމާ މަތިން ހުސް އަގު ލިޔޭ ހުރި އަކުރު ވޯޑެއް، މިސާލަކަށް A ކެނެ `A{rot.a}` ހެންއޭ ހުރި މެޝީނުގައި ދައުރު ނެތް، ލައިނުން ފޮހެލެވޭ. x، y އަދި z ކުށް ނުކުރި ވަނީ ޓެކްސްޓް ގޮތުން ކޮޓް ތެރޭގައި (`if probe.kind == "z"`).

## ސްޓޭޓްމަންޓްސް

| ސްޓޭޓްމަންޓް | ކަންތައް |
|---|---|
| `raw TEXT` | ލައިން ޓައިޕް ކުރި ފަދައިން (ލައިން ނަމްބަރެއް ނެތި) |
| `comment TEXT` | `(TEXT)` ASCII ނޫން އަދި ބްރެކެޓް ނެރެލި |
| `emit WORD WORD …` | ވޯޑްތަކުގެ ލައިނެއް؛ ހުސް އަގުތައް ނައްތާލޭ؛ ވޯޑް ނެތް ނަމަ ލައިން ނެތް |
| `word WORD …` | ހަދާ ލައިނަށް ވޯޑް އިތުރު ކުރޭ؛ ސާދާ `emit` ލައިން ނިންމާ |
| `if EXPR` … `else` … `end` | ޝަރުތު: `a == b`، `a != b`، `not a`، `a and b`، `a or b`، `a??b` (a، ނޫނީ b) |
| `for tool in tools` … `end` | ޕްރޮގްރާމް ބޭނުން ކުރާ ޓޫލްތަކުގެ ކޮންމެއަކަށް އެއް ފަހަރު |
| `set NAME EXPR` | އަގެއް ހަނދުން ހިފެހެއްޓުން (`set offset tool.number`) |
| `reset NAME …` | މޯޑަލް ވޯޑްތައް ހަނދުން ނައްތާލޭ (ގްރޫޕެއް، `Z` ފަދަ އެޑްރެސް އަކުރު، ނުވަތަ `at.z`) |
| `do rapid X Y Z` | ޕޮއިންޓަކަށް `rapid` އީވެންޓް ރަން ކުރޭ |

ވޯޑެއް ޓައިޕް ކުރާ ޓެކްސްޓެކެވެ `{variable|filter}` ހޯލްތަކާއެކު. ފިލްޓަރުތައް `upper`، `lower`، `pad:N` (ޒީރޯ ފިލް)، `cut:N` (ފުރަތަމަ N އަކުރު)، `safe` (ކޮމަންޓް ރައްކާތެރި ASCII) އަދި `int`. `~` އަށް ނިންމާ ވޯޑް **މޯޑަލް**: ފަހުން ލިޔެވުނު އަގާ ތަފާތު ނަމަ ލިޔޭ (`G1~`، `X{x}~`). `~!` އަށް ނިންމާ ވޯޑް ކޮންމެ ފަހަރަކު ލިޔެ، އަދި ހަނދުން ހިފެހެއްޓޭ. ވޭރިއަބަލެއް ނޫން ނަމެއް ސާދާ ޓެކްސްޓް ގޮތުން ލިޔޭ (`G81`، `mist`). ނަމްބަރު 0.001 mm ރައުންޑް ކޮށް، ފަހު ސުންފާ ސައިފަރް ނެތި ލިޔޭ.

## ޕޯސްޓަކަށް ނުކުރާ ކަންތައް

ފަސް ރަނގަޅު ކޮންޓްރޯލްގެ މޫވްތައް ބުނޭ، އެއްވެސް ކަމެއް އޮންނާނެ ނޫން: ޓޫލްޕާތް ބަދަލު ނުކުރޭ، އޮޕަރޭޝަން ތަރުތީބު ނުކުރޭ، އާކް ނުކަނޑޭ، އެކްސިސް ނުލެއް، މެޝީނުގެ ޓްރެވެލް ނުދަންނާ، ނުވަތަ ކޯޑިނޭޓްސް އަށް ދަތިހެދި ގޮތުން ކުރެވޭ ނޫން (ޕްލަސް `+` ނެތް). ރޮޓަރީ ޕޮޒިޝަންތައް ޕޯސްޓުން ނޫން، Setup ގައި ހަދާ މެޝީނުން ލިބޭ؛ ޕޯސްޓަކަށް ސައިން އަދި އަކުރު ބަދަލު ކުރެވޭ، ކައިނަމެޓިކްސް ނޫން. ޓޫލް ލައިފް އަދި ސަބް ޕްރޮގްރާމް ސައިކަލްތައް ނެތް. `.cps` ސްޓައިލް ޕޯސްޓް ފައިލް އެހެން ޕްރޮގްރާމުން ލޯޑް ނުވެއެވެ: މިއީ ވަކި، ސާދާ ފޯމެޓެކެވެ.
