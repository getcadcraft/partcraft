މޮޑެލް ޝޭޕްކުރާ ތަނުގައި ދެމިހިންގާ، އަދި މެޝީން ކުރުން، ޗެކް ކުރުން އަދި ލިޔުން މިތަނުގައި ކުރޭ. އެހެން ޕްރޮގްރާމުގައި ކޮންމެ ބަދަލެއް PartCraft ގައިވާ އިމްޕޯޓް ކުރެވުނު ބޮޑީއަކަށް ބަދަލު ވާ، އަދި އޭގެ ފަހުން ހުންނަ ފީޗަރުތައް އާ ޝޭޕްގެ މަތީގައި އާދެ ހަދާނެއެވެ.

:::note
ލިންކް ކަމަށް ލާނީ **CadCraft Studio** ހަމަ އެ ކޮމްޕިއުޓަރުގައި. ބްރައުޒަރ ޓެބެއް މި ކަނެކްޝަން ނެގޭކަށް ނޫނެވެ. އިންޓަނެޓުން ކަމެއް ނުދެވޭ: ސްކްރިޕްޓް ކޮމްޕިއުޓަރގެ އަމިއްލަ އެޑްރެހުން Studio އާ ވާހަކަ ދައްކައެވެ، ޓޯކަނާއެކު.
:::

:::warning
މި ލިންކް ޓެސްޓް ކުރެވިފައިވަނީ ސްކްރިޕްޓުގެ ފައިލް ރައިޓަރާއި އެހެން ޕްރޮގްރާމުގެ ބަދަލުގެ ބަދަލުގައި، އެކަމަކު Rhino ނުވަތަ Grasshopper ތެރޭގައި އަދި ޓެސްޓް ނުކުރެވިފައެވެ. އެތަނުގައި ކަމެއް ނުވާނަމަ، އެ ދައްކި ކަން އަހަންނަށް ދަސްކުރައްވާ.
:::

## ސެޓަޕް ކުރޭ

1. Studio ގައި PartCraft ހުޅުވާ. {{ui:ސެޓިންގްސް}} › {{ui:PartCraft}} › {{ui:Assistants}} ގައި، **Let AI assistants and scripts use PartCraft** ޓިކް ކޮށް، ދެން **Edit**.
2. Studio ގައި {{ui:Connect an assistant}} ޚިޔާރުކުރޭ. އެއީ ދެން ތިބާ ޕޭސްޓް ކުރާ އެޑްރެހާއި ޓޯކަން ދައްކާނެއެވެ.
3. ސްކްރިޕްޓް ޑައުންލޯޑް ކުރޭ: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino އިން

1. `cadcraft_link.py` ރަން ކުރޭ Rhino ގެ ސްކްރިޕްޓް އެޑިޓަރުގައި (Rhino 8 ގައި Python 3).
2. ފުރަތަމަ ފަހަރު އެޑްރެހާއި ޓޯކަން ޕޭސްޓް ކުރޭ. އެ ދެ އެއްޗެއް `.cadcraft-link.json` ގައި، ތިބާގެ ހޯމް ފޯލްޑަރުގައި ރައްކާ ވޭ، މޮޑެލްގައި ނުވޭ. Studio ކޮންމެ ފަހަރަކު ފެށުމުން އާ ޓޯކަނެއް ހަދާތީ، ސްކްރިޕްޓް ފަހުން އަލުން ސުވާލު ކުރާނެއެވެ.

ހަމަ ނަގާ ކޮށްލުމަށް ސްކްރިޕްޓް އަލުން ރަން ކުރޭ.

## Grasshopper އިން

ފުރަތަމަ ޖަހާ Rhino ގައި ސްކްރިޕްޓް އެއް ފަހަރު ރަން ކުރޭ، ޭ އެޑްރެހާއި ޓޯކަން ރައްކާވާކަށް.

1. Script ކޮމްޕޯނަންޓް (Python 3) އެޑް ކޮށް `cadcraft_link.py` ގެ ހުރިހާ ކޯޑް އޭގައި ޕޭސްޓް ކުރޭ.
2. މި ޖޫކޮށްތައް ދޭ: `G` (ޖިއޮމެޓްރީ، ލިސްޓް އެކްސެސް އެކު)، `N` (ނަމެއް، އިޚްތިޔާރީ)، `On` (ބޫލިއަން ޓޮގަލް)، އަދި `Target` (އިޚްތިޔާރީ: `model` ނުވަތަ `part`، ދެ އެޕް ހުޅުވާފައި ހުންނަ ނަމަ).
3. `On` ހަގީގީ ކުރޭ.

ކޮންމެ solve އަކުން `G` ފޮނުއްވައި، ފަހުން ފޮނުއްވި އެއްޗަށް ބަދަލު ކުރެއެވެ.

## މިތަނުގައި އެ ކަންކުރާ ގޮތް

- **ބޮޑީ އެއް.** މޮޑެލްގައި ފެންނާ ހުރިހާ އެއްޗަކީ އިމްޕޯޓް ކުރެވުނު ފީޗަރެއް، [.3dm ފައިލް ހުޅުވުމުން](topic:open-3dm-files) ހިމެނޭ ގޮތަށް.
- **ހުށަހަޅަ ކަނޑައަޅާ ދައުރު ބަންދުވާންޖެހޭ.** PartCraft ކުޑަ ހޯލުތައް އަދި ފްލެޓް އޮޕެނިންގތައް ފުރޭ، އަދި އެހެން ޕްރޮގްރާމަށް ކިތައް ފުރިތޯ ދެނެގަނެވޭ. މޮޑެލް އަދިވެސް ބަންދު ނުވާނަމަ، PartCraft ހުރި ބޮޑީ ފުރުޅުން ފެންނާތީ ސްޓޭޓަސް ބާރުގައި އެ ކަން ދައްކާނެއެވެ. ބަންދުވާ ފަހުގެ ބަދަލު އަލުން އަޕްޑޭޓް ކުރާނެއެވެ.
- **ކުރަމުންދާ ކަން ނިންމާ.** ސްކެޗެއް ނުވަތަ ޑްރޯއިންގެއްގައި އަޕްޑޭޓް ނުލިބޭ، އަދި އެ ކަން ފަހުން މުއްސަނދި ޓްރައި ކުރެވޭ؛ މޮޑެލް ތެރޭގައި ފޮނުއްވާ ފަހުން ލިބޭ.
- **އަން ޑޫ.** ދެ ސެކަންޑުގެ ތެރޭގައި ހުރި އަޕްޑޭޓްތައް ހަމައެކަނި އަން ޑޫ ސްޓެޕެއް.
- **ސޭވް.** ޕާޓް ފައިލުގައި ލިންކް ބެހެއްޓެވޭ. ފައިލް ފަހުން ހުޅުވުމުން ސްކްރިޕްޓް އަލުން ރަން ކުރާށެވެ، އަދި އެ ހަމަ ފީޗަރު އަޕްޑޭޓް ވާނެއެވެ.

**އެއް މަގަށް ފަހަރު.** މިތަނުގައި ބަދަލުތައް އެހެން ޕްރޮގްރާމަށް ދާ ނޫނެވެ.

## ކަމެއް ގޮސްފިއްޔާ

- **"No ModelCraft or PartCraft window allows it":** ސެޓަޕްގެ ފުރަތަމަ ޤަދަމް ކުރޭ.
- **"Studio refused the token":** Studio ރީސްޓާޓް ވެއްޖެ. އާ ޓޯކަން ކޮޕީ ކޮށް ސްކްރިޕްޓް އަލުން ރަން ކުރޭ. Grasshopper އަށް، ފުރަތަމަ Rhino ގައި ރަން ކުރޭ.
- **"Cannot reach CadCraft Studio":** Studio ރަން ނުވޭ، ނުވަތަ އެޑްރެހް ބަދަލުވެއްޖެ.
