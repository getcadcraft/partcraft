PartCraft އެކަމާ ލިބެނީ ފުރަތަމަ ބިލްޑެކެވެ. މި ޞަފްޙާ ކުރާ ނޫން ކަންތައް ފެންނާށެވެ، އެހެންކަމުން ހޯދަން ނުހުރެ، އަދި މިއަދު ކުރެވޭ ކަމަށް ބަދަލު. މިތަނުގައި އެއްވެސް ތާރީހެއް ނެތް.

## ހަމަ ކާނަލް ބޭނުންވޭ

މި ނަސްޚާއިން ކޮންމެ ބައެއް މެޝް ކާނަލުން ހަދައެވެ (ބަލާށެވެ [މެޝް ކާނަލް](topic:solid-kernels)). ތިރީގައިވާ ހުރިހާ ކަމެއް ހަމަ ޖިއޮމެޓްރީ ކާނަލަކަށް ބޭނުންވެއެވެ، އެ މި ވާރޝަނުގައި ނެތް. މި ފީޗަރތަކާއެކު ރައްކާ ކުރެވުނު ބައިތައް އެނގޭ: ފީޗަރތައް ހިސްޓަރީގައި ހުރެ، ހަދާފައިނުވާ ގޮތަށް ނިޝާން ކުރެވެ، ރައްކާކުރުމުގައި ދެމިހުރެއެވެ.

|---|---|
| {{ui:Fillet}} އަދި {{ui:Chamfer}} ރައުންޑް ކަނޑުތަކުގައި؛ ރޭޑިއަސް ކަނޑުގެ ދިގުމިނާއެކު ބަދަލުވާ ފިލެޓްތައް؛ ކަނޑުތައް ދަތުރުވާ ރައުންޑްތައް ރުއްޖެހިގެން (މެޝް ކާނަލް އެތަންތަން މައިޓަރ ކުރެވެ) | Fillet އަދި Chamfer ކުރެވޭ ސީދާ ކަނޑުތަކުގައި ފްލެޓް ފޭސްތަކުގެ ދެމެދު؛ ބައި ޓަރު ކޮށް ކެޗަރ ކުރެވޭ ކޯނިތައް ސްކެޗްގައި ކުރުމަށް ފަހު އެކްސްޓުރޫޑް ކުރިން ({{ui:Fillet}} ސްކެޗްގައި، {{key:F}}) |
| {{ui:Shell}} ވެރި ފޭސްތައް ހުޅުވާ؛ ބިންދުތަކުގެ ތިކްނަސް ވަރަކީ ވަރ ވަންނާ ދިމާ | ފްލެޓް ފޭސްތައް ހުޅުވާ؛ ފާރު ގިނަ ކުރަން ބޭނުންވާ ތަނުގައި އެކްސްޓްރޫޑްތަކުން އިތުރު ކުރޭ |
| {{ui:Sweep}}، {{ui:Loft}}، {{ui:Draft}} ވެރި ފޭސްތަކުގައި؛ އެކްސްޓްރޫޑް ފޭސް، ނޫން ފޭސް ނުވަތަ ވާޓެކްސް ކުރިމަތީ؛ ޓޭޕަރުން އެކްސްޓްރޫޑް | އެކްސްޓްރޫޑް ނުވަތަ ރިވޯލްވް، ބޭނުންވާ ތަން ސްޓެޕްސްގައި؛ ކަނޑައަޅާ ދިގުމިނަށް އެކްސްޓްރޫޑް ކުރޭ |
| {{ui:Rib}}، {{ui:Base flange}}، {{ui:Edge flange}} އަދި ފްލެޓް ޕެޓާންތައް | ޕްލޭޓު އެކްސްޓްރޫޑް ނުވަތަ ރިބްގެ ޕްރޮފައިލް އެކްސްޓްރޫޑް ކުރޭ |
| ސަރފޭސްތައް: {{ui:Form}} ފަރާތެއް ޕާޓަށް ނިންމުން، {{ui:Patch}}، {{ui:Loft surface}}، {{ui:Gordon surface}}، {{ui:Stitch}}، {{ui:Thicken}}، {{ui:Offset surface}}، {{ui:Extend surface}}، {{ui:Trim surface}} | ނެތް |
| ގިނަ ބޮޑީތައް: {{ui:Combine}}، {{ui:Move body}}، {{ui:Scale body}}، {{ui:Path pattern}}، އާ ބޮޑީއެއް ހަދާ ފީޗަރތައް | ހަމަ ސޮލިޑް އެއް؛ ޕެޓާންތަކާއި މިރަރ ކޮޕީ ފީޗަރތައް |
| ސްކެޗްތައް، ޕްލޭންތައް، އެކްސްތައް އަދި ޕޮއިންޓްތައް ފޭސްތަކުގައި، ހަމަ ކާނަލުން ހޯދެވޭ ތަންތަނުގައި (ފިލެޓުން ހަދާ ފޭސް، ހޯލްގެ ދިމާ، އިމްޕޯޓުކުރާ ސޮލިޑުގެ ފޭސް) | ބޭސް ޕްލޭންތައް، ރެފަރެންސް ޕްލޭންތައް އަދި އެކްސްޓްރޫޑް އަދި ރިވޯލްވްގެ ފްލެޓް ފޭސްތައް މައްޗަށް ސްކެޗް ކުރޭ |
| ޖެނެރޭޓިވް ޑިޒައިން ނަތީޖާ ޕާޓެއް ކަމުގައި ހުޅުވާ ނުވަތަ އޭގެ ތެރޭ ޖައްސާ (އިމްޕޯޓު ކުރެވުނު ސޮލިޑެއް ކަމުގައި ވެއެވެ) | ނަތީޖާ STL ނުވަތަ STEP ގެ ގޮތުގައި ޑައުންލޯޑް ކުރޭ |
| ހުޅުވާފައިވާ STEP ފައިލުގެ ވަށާ ފޭސްތައް ސަރފޭސްތަކުގެ ގޮތުގައި އެޑިޓް ކުރުން؛ ސްޕްލައިން، ސްވީޕް އަދި ރިވޯލްވް ފޭސްތަކުގެ ހަމަ STEP، ސްޕްލައިން ކައިވެނި، މޮޑެލް ކުރާ ތްރެޑްތައް، STL / OBJ / 3MF ބޮޑީތައް އަދި އެސެމްބްލީތައް؛ އެހެން ޕާޓް މޮޑެލަރުންގެ STEP | {{ui:Open}} ގައި STEP ތްރިކޯނުންގެ ގޮތުގައި ކިޔަވައި، ފައިލުގެ ފްލެޓް ފޭސްތައް، ސިލިންޑަރ، ކޯނު، ސްފެއާ އަދި ޓޯރަސް ރައްކާކުރެއެވެ ([STEP ފައިލް ހުޅުވާ](topic:import-step))؛ {{ui:Export}} › {{ui:STEP AP242 (exact solid)}} ކޮންމެ އެނަލިޓިކަލް ފޭސް ހަމަ ފުރިހަމަ ލިޔައި، އެ ރޫޕުތައް ފެސެޓްސް ކަމުން ތިބޭ ([އެކްސްޕޯޓް](topic:export-files#for-other-cad-programs-step)); އެހެން ޕާޓް މޮޑެލަރުގެ މެކްރޯ އަދި ލިޔޭ |
| ޑްރޯއިންގ ވިއުތަކުގައި ޓްރުއާރކްސް | ވިއުތަކާއި ސެކްޝަން ވިއުތައް ފެސެޓްސްންނެވެ |
| ހަމަ ސަލާމަތުން ވޮލިއުމްސް، ޕާތް އަދި ދުރުތަކާ | {{ui:Measure}} ފެސެޓްޑް ސޮލިޑްގެ އަދަދު ދެއެވެ، ރައުންޑް ބައިތަކުގައި ކުޑަކޮށް؛ ގިނަ **Curves** ސެޓިންގ އަކީ ހަމަ އަދަދަށް ގާތު ކުރޭ |

ކޮންމެ ކަމެއް ރޯތަކުގެ ތަކުރާރަކަށް ރަނގަޅު ކުރުމަށް މި ނޫން ކަމެއް ފެންނާނެ: ހަމަ ކާނަލް އަލުން ރާސްތަ ވާއިރު އެ ހުރިހާ އެކްޝަންތައް ހެދި ނުވަތަ ހުރުމަށް.

| ސްވީޕްތައް ޓްވިސްޓްކުރާ، ތިން ވާލް އަދި ސަރފޭސް ސްވީޕް؛ {{ui:Loft}} ފީޗަރގެ އެންޑް ޓޭންޖެންސީ؛ ގައިޑް ރޭލެއްގެ ލޯފްޓް؛ ސްޕްލައިން ޕާތްތައް | {{ui:Sweep}} ފިކްސްޑް އޮރިޢެންޓޭޝަނާ ނުވަތަ އެންޑް ސްކޭލަށް؛ ދެ ނުވަތަ ގިނަ ގައިޑް ރޭލެއްގެ ލޯފްޓް: [ސްވީޕް، ލޯފްޓް އަދި ޑްރާފްޓް](topic:sweep-loft-draft) ބަލާށެވެ |
| ރިބްތައް ޗާކާ ނުވަތަ ސްޕްލައިންތަކުން؛ ރިބް ސްކެޗަށް ސްކެއަރ ވެ (ވިއުން ފަރާތުން)؛ ރިބްގެ ޑްރާފްޓް؛ އެއް ސްކެޗުން ގިނަ ރިބް | {{ui:Rib}} ރިބްގެ އަމިއްލަ ޕްލޭނުގައި ހަމަ ލައިނުގެ ޗެއިނަކުން: [ރިބްތަކާއި ގަސެޓްތައް](topic:rib) ބަލާށެވެ |
| ވަށް ވެރި ސަރފޭސަކަށް "އަޕް ޓޫ"، ފޭސަކަށް ވާ "އަޕް ޓު ނެކްސްޓް" ސްޓޮޕް ކުރުން | އެތަނުން ފްލެޓް ފޭސް ނުވަތަ ރެފަރެންސް ޕްލޭން ދަށުން |
| ކައުންޓަރޑްރިލް ހޯލްތައް، އިންޗު އަދި ޕައިޕު ތްރެޑް، ޓޭޕަރ ތްރެޑް، ތްރެޑް ރަން-އައުޓް އަދި ޗާމްފަރ ތްރެޑް ސްޓާޓް | ކުޑަ ޑެޕްތާ ކައުންޓަރބޯރ؛ ISO މެޓްރިކް އަދި ޓްރެޕެޒޯއިޑަލް ތްރެޑް، ކޮސްމެޓިކް ނުވަތަ މޮޑެލް: [ޝާފްޓާއި ބޯރުގެ ތްރެޑް](topic:threads) ބަލާށެވެ |
| ތިން ވާލް އެކްސްޓްރޫޑް | ޕްރޮފައިލްގެ ދެ ވާލް ހަދާ |
| ޕެޓާނުގެ ކޮޕީތައް ކުޑަ ކޮޅުން ކޮޅަށް ސްކިޕް ކުރެވުނު؛ ފިލް ޕެޓާން | ވަކި ފީޗަރތައް ބޭނުންކުރޭ؛ ވަށެއްގައި ޕެޓާންތަކާ: {{ui:Path pattern}} |
| ޕެޓާން ކޮޕީ ކުރުން، މިރާ، ފިލެޓް، ޗޭމްފަރ، ޝެލް އަދި އިމްޕޯޓްކުރެވުނު ސޮލިޑްތައް | އެ ހަދާ ސްކެޗް ނުވަތަ ފީޗަރ ކޮޕީ ކުރޭ، ނުވަތަ ޕެޓާން ކުރޭ |
| ފޯމްގެ އެކްސްޓްރާއޯޑިނަރީ ޕޮއިންޓްތަކުގައި ހަމަ (G1) ޓޭންޖެންސީ؛ ފޯމްގެ ޕެޗްތައް ބޮޑު ފޭސްތަކަށް ގުޅުން | ފޯމްގެ ލެވެލް ބޮޑުކުރޭ: ޑެޕްރޮކްސިމޭޓްކުރެވުނު ޕެޗްތައް ކުޑަވޭ؛ [ފޯމްގެ ޝްކްލު ފޯމްސް](topic:form-surfaces) ބަލާށެވެ |
| ފޯމެއް ކޮށްވާ ގިނަ ވަކި ބަންދު ބައި ހަމަ ފީޗަރއެއްގައި؛ ފޯމްތަކާ ދެމެދު ބްރިޖް | ފޯމް ފީޗަރއަކަށް އެއް ބަންދު ބައި؛ Join އިން ގުޅުން |
| ސާފޭސް ބޮޑީތައް ވިއުގައި ނުފެންނާ (ޓްރިމް އަދި ޕެޗް ޕޮއިންޓްތައް ނުވަތަ)؛ ސަރފޭސް ފިލެޓް؛ އަންޓްރިމް؛ G2 ޕެޗް؛ ގޯޑަން ސަރފޭސްތައް އަނާ ކާވު ޑިސްރިކްތަކާ ޓޭންޖަންޓް | ފީޗަރގެ ޕެނަލުން ނަމުން ހޯދާ؛ ފުރަތަމަ ތިކްން ކޮށް، ފަހުން ސޮލިޑު ފިލެޓް ކުރޭ |
| ހިސްޓަރީގައި ބޮޑީ ލިސްޓް؛ ފެނުން ކޮޅުން ހިއްޕަވާފައިވާ ބޮޑީތައް އެކްސްޕޯޓުން ބަހައް ފިޔަ | ޕާޓް ޕެނަލުގެ ބޮޑީ ލިސްޓުން ނަން ބަދަލު، ހިއްޕާ؛ ބޮޑީއެއް ހަދާ ފީޗަރ ފޮހެލާ ނުވަތަ ސަޕްރެސްޗް ކުރޭ |
| ސްކޭލް ވާ ޑައިރެކްޝަން ކިޔުން ސިލިންޑަރ އަދި ކޯނުތަކުން؛ އޮފްސެޓް ސަރފޭސްތަކުގެ ނޮން-ޔުނިފޯމް ސްކޭލް | {{ui:Scale body}} ކަރވްޑް ފޭސްތައް B-ސްޕްލައިން ކޮށް (0.0000004 mm ތެރެއިން)؛ ޔުނިފޯމް ސްކޭލް އެއް އެކްޒަކްޓް |
| ސަރފޭސް ބޮޑީތައް ޖެހުން؛ މިންކަސްކީ ޖޯކްތައް | {{ui:Stitch}} ނުވަތަ {{ui:Thicken}} ފުރަތަމަ، ފަހުން {{ui:Combine}} |
| ޓޮލަރެންސް އެނަލިސިސް: ކޯނަރ ޖަހާ ސްޓެކް-އަޕްތައް (2D އަދި 3D ވެކްޓަރ ލޫޕްސް)، ޖޮމެޓްރީން ހޯދެވޭ ސެންސިޓިވިޓީތައް، ޓޮލަރެންސް ފަހަރު ހުރި މޮންޓޭ ކާލޯ، ސްކެޗް ޑައިމެންޝަންތަކުގެ ސައިޒް ޓޮލަރެންސް، މެޓީރިއަލް ކޮންޑިޝަނުން ބޮނަސް ޓޮލަރެންސް | އެސެމްބްލީގައި {{ui:Stack-up}}: އެއް ދިމާ، ވަރަށް ނުރައްކާ އަދި RSS، ޓައިޕްކުރެވުނު ޓޮލަރެންސް، ޓައިޓްލް ބްލޮކްގެ ޖެނެރަލް ޓޮލަރެންސް ނުވަތަ GD&T ފްރޭމްތަކުން: [ޓޮލަރެންސް ސްޓެކް-އަޕް](topic:tolerance-stackup) ބަލާށެވެ |
| ނެސްޓިންގ: ކަޓިންގ އޯޑަރ އަދި ލީޑް-އިން، ޝެއާކުރާ ކަނޑުތައް އެއްފަހަރު ކަޓުކުރުން، އެކުގައި ހިފަހައްޓާ ބައިތައް؛ ރޯލްތަކުގެ ރިމަނެންޓް، ޕްރޮޖެކްޓްތަކާ ދެމެދު ޝޭއާކުރާ ސްޓޮކް | {{ui:Nest flat parts on sheets…}} ދުރުތެރޭ، މާރޖިން، ޓާންސް އަދި ފިބަރާއެކު: [ޝީޓްތަކުގައި ފްލެޓް ބައިތައް ޖައްސާ](topic:nest-flat-parts) ބަލާށެވެ؛ ބާކީ ޕްލޭޓްތައް ރައްކާކުރެވިފައިވާ ފުރަތަމަ ބޭނުންކުރެވޭ: [ބާކީ ތަންތަން ރައްކާކުރުން](topic:nest-offcuts) ބަލާށެވެ؛ ކަޓް ރާސްތަ ކުރޭ ކަޓަރގެ އަމިއްލަ ސޮފްޓްވެއާރުން |
| ޝީޓް މެޓަލް: ހީމް، ޖޮގް، މައިޓަރ އަދި ކޮންޓޯރ ފްލޭންޖް؛ ކާވުގެ ކަނޑުތަކުގެ ފްލޭންޖް ނުވަތަ ވަށް ބޭސް ފްލޭންޖްގެ ފޭސްތައް މައްޗަށް؛ ސްކެޗްކުރެވުނު ބެންޑް؛ ކޯނަރ ކްލޯޒާ؛ ފޯމިންގ ޓޫލްސް؛ ސޮލިޑް ޝީޓް މެޓަލަށް ބަދަލު؛ ބެންޑް ޓޭބަލްތައް | {{ui:Base flange}} (ޕްލޭޓެއް ނުވަތަ ބެންޑް ޕްރޮފައިލް)، {{ui:Edge flange}} ޕްލޭޓުގެ ސީދާ ކަނޑުތަކުގައި ބެންޑް ރިލީފްތަކާއެކު، އަދި ފްލެޓް ޕެޓާން K-ފެކްޓަރާއެކު: [ޝީޓް މެޓަލް](topic:sheet-metal) ބަލާށެވެ |
| ޑްރާފްޓް އެނަލިސިސް އެސެމްބްލީތަކުގައި؛ ޕާރޓިންގ ލައިން ހޯދުން؛ ވާލް ތިކްނަސް އެނަލިސިސް | ޑިޒައިންގ ގައި ޕާޓުގައި {{ui:Draft analysis}}: [ކޮންޑިމަންޓް ނުވަތަ ކާސްޓިންގަށް ޑްރާފްޓް ބެލުން](topic:draft-analysis) ބަލާށެވެ؛ އެސެމްބްލީގެ ކޮންމެ ބައެއް ހުޅުވައި ބަލާ |

## ސްކެޗްތައް

| ހަދާފައިނުވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| އެލިޕްސް، ޓޭންޖަންޓް އާކްތައް، ކޮނިކްސް، ސްޕްލައިންތައް ސެޓް ޑިގްރީއާއި ވެއިޓްސް (NURBS) ހުރެ | ސްޕްލައިން (ކިއުބިކް)، އާކްތައް އަދި ވަށްތައް ޓޭންޖަންޓް ރިލޭޝަންތަކާއެކު |
| ސްޕްލައިންގެ މައްޗަށް ޕޮއިންޓް (ރިލޭޝަން)، ކަރވެޗާ (G2) ރިލޭޝަންތައް | ސްޕްލައިންގެ އަމިއްލަ ޕޮއިންޓް ހިންގަން ބޭނުންވާ ތަނުގައި ދާށެވެ |
| ސްޕްލައިންގެ އޮފްސެޓް ކޮޕީތައް ބަދަލުތަކާއެކު ހުރެ؛ ކުޑަ ސްޕްލައިން ކޯނަރ ހުރި ޗެއިންތައް އޮފްސެޓް | ބަދަލުވުމަށްފަހު އަލުން އޮފްސެޓް ކުރޭ؛ ކޯނަރ ފުރަތަމަ ރައުންޑް ކުރޭ |
| ބޭނުންވާ ފަތް ކޮޕީތައް އެހެން އަސްލަށް ފުރުން ހުރެ؛ ވަށެއްގައި ޕެޓާންތައް | އަލުން ފަތް ކޮށް ބަދަލުވުމަށް ފަހު ވަނޑާ ފުރޭ |

## ފައިލްތައް

## ޑްރޯއިންގްސް

| ހަދާފައިނުވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ތިން ބޮޑު ސައިޒްތަކަށް ބޭރުން ޑައިމެންޝަންތައް (ވަށް ސައިޒްތައް، ފޮތީ ފުރަތަމަ، ސައިޒުގެ ޓޮލަރެންސް) | PDF މާކަޕް ކުރޭ، ނުވަތަ DXF އެކްސްޕޯޓް ކޮށް 2D CAD ޕްރޮގްރާމުގައި ޑައިމެންޝަން ކުރޭ |

| ކަރވްޑް ފޭސްތަކުގެ 3D ރަފިންގ، 3D އެޑެޕްޓިވް ކްލިއަރިންގ، ރެސްޓް މެޝިނިންގ؛ ވޯޓަލައިން، ޕެންސިލް، ރޭޑިއަލް އަދި ސްޕައިރަލް ފިނިޝިންގ؛ އެޑެޕްޓިވް ޕާސްތައް އާކްތައް ގޮތުން | 2.5-އެކްސިސް ފޭސް، ޕޮކެޓް، 2D އެޑެޕްޓިވް، ކޮންޓޫރ، ޑްރިލް އަދި ޗާމްފަރ: [ޓޫލްޕާތް އަދި G-code ހަދާ](topic:manufacture)؛ މުޅި މޮޑެލްގެ Parallel އަދި Scallop ފިނިޝިން: [3D ފިނިޝިން](topic:finish-3d) ބަލާށެވެ |
| 4 އަދި 5-އެކްސިސް ޓޫލްޕާތްތައް، ޓާރނިންގ، ޕްރޯބިންގ | ސެޓަޕް ޓެބުގައި ޓޫލް އެކްސިސާއެކު އެއް ފަރާތަކަށް އެއް ފަހަރު |
| ހޯލްޑަރ އަދި ޝޭންކް ކޮލިޝަން ޗެކް | ފްލޫޓް ލެންތް ވޯނިންގްސް ބަލާ، ކޮންޓްރޯލް ސިމިއުލޭޓަރުގައި ބަލާ |
| ޕްރޯބިންގ، ޓޫލް ލައިފް އަދި ސަބްޕްރޮގްރާމް ސައިކަލްސް؛ 4 އަދި 5 ވަނަ އެކްސިސް އަދި ލޭތް ކޯޑްތައް ޕޯސްޓުގައި؛ އެހެން ޕްރޮގްރާމްތަކުގެ ޕޯސްޓް ފައިލްތައް ލޯޑް ކުރުން | ޕާރޓް ޕޯސްޓް ފޯމެޓުން ޕޯސްޓް ލިޔޭ ނުވަތަ ބަދަލުކުރޭ: [ހިފަހައްޓާ ޕޯސްޓް ޕްރޮސެސަރސް](topic:post-processors) ބަލާށެވެ |

## ސިމިއުލޭޝަން އަދި ޖެނެރޭޓިވް ޑިޒައިން

| ހަދާފައިނުވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ނޯންލީނިއާ ސްޓަޑީތައް: ޔީލްޑިންގ، ބޮޑު ޑިފްލެކްޝަން، ޕާރޓްސްގެ ދެމެދު ކޮންޓެކްޓް، ފެޓިގް | ލީނިއާ ސްޓެޓިކް އަދި ނޭޗަރަލް ފްރީކްވެންސީ: [ސްޓްރެސް އަދި ޑިފްލެކްޝަން ޗެކް](topic:simulation)؛ ސޭފްޓީ ފެކްޓަރ 1 އަށްވުރެ ފުރިހަމަ ކުރޭ |
| ނޯންލީނިއާ ބަކްލިންގ (އިމްޕަރފެކްޝަންތައް، ޕޯސްޓް-ބަކްލިންގ، ސްނެޕް-ތްރޫ) | ލީނިއާ ބަކްލިންގ ލޯޑް ފެކްޓަރ ގިނަ މާރޖިންތަކާއެކު: [ހީޓް، ތާރމަލް ސްޓްރެސް އަދި ބަކްލިންގ](topic:thermal-and-buckling) ބަލާށެވެ |
| ފޭސްތަކުގެ ކިރުން (View factors)، ކޮންޓެކްޓް ރެޒިސްޓަންސް، ޓެމްޕަރޭޗަރ ސައިޑެންޓް މެޓީރިއަލްސް، ތާރމަލް ސްޓްރެސްގައި އިނާރޝިއާ (ތާރމަލް ޝޮކް ވޭވް) | ވަށައިގެންވާ ތަނުގެ ރޭޑިއޭޝަން، ސްޓެޑީ ނުވަތަ ކުއާސި-ސްޓެޓިކް ތާރމަލް ސްޓްރެސް ވަގުތު ބައެއް ތެރެއިން، ތަފާތު ނޫން ޕްރޮޕާޓީސް: [ހީޓް، ތާރމަލް ސްޓްރެސް އަދި ބަކްލިންގ](topic:thermal-and-buckling) ބަލާށެވެ |
| ޓްރާންސިއަންޓް ހީޓަށް ސްވޭޝަން ރީފައިންމަންޓް؛ ތާރމަލް ލޯޑް ހުރި ސްޓަޑީތައް؛ ގަދައަށް ފަރުވާ ކުރުމުގެ މެޝް؛ ކުޑަ އެރަރ ހުރެ ގޮތް ޕްރޮޕާޓީސް | **Refine automatically** ސްޓޭޓިކް، ބަކްލިންގ، ނޭޗަރަލް-ފްރީކްވެންސީ އަދި ސްޓެޑީ ތާރމަލް ސްޓަޑީތަކަށް، މުޅި ޕާޓުގެ އެރަރ މައްޗަށް: [ސްޓްރެސް އަދި ޑިފްލެކްޝަން ޗެކް](topic:simulation)؛ އެހެން ފަރާތެއްގައި އެލެމެންޓް ސައިޒް ކުޑަކުރޭ |
| ބިއަރިން އަދި ބޯލްޓް ލޯޑްތައް، ރިމޯޓް ފޯސްތައް، މޮމެންޓްސް، ސްޕްރިންގްސް، ޕްރެސްކްރައިބްޑް ޑިސްޕްލޭސްމަންޓްސް | ފޭސްތަކުގައި ފޯސްތައް އަދި ޕްރެޝަރ، ގްރެވިޓީ؛ ފިކްސްޑް އަދި ފްރިކްޝަން-ފްރީ ފޭސްތައް |
| އެސެމްބްލީތަކުގެ ސިމިއުލޭޝަން؛ ޑިރެކްޝަން އަށް ބަދަލުވާ މެޓީރިއަލް (ޕްރިންޓް ކުރާ ލޭޔަރތައް، ކޮމްޕޯޒިޓްސް) | ޕާޓެއް، އައިސޮޓްރޮޕިކް މެޓީރިއަލް އެކެއް |
| ޓެޓްރާހެޑްރަލް ސްޓަޑީތަކަށް ސޮލްވާ ތްރެޑް ގިނަ؛ ހީޓް ޓްރާންސްފަރ އަދި ޖެނެރޭޓިވް ޑިޒައިން؛ ކޮންމެ ކޮންމެ ސަރފޭސްގެ ތްރެޑް | ވޮކްސަލް ސްޓަޑީތައް، ބަކްލިންގ، ސްޓްރެސް އަދި ލެމިނާ ފްލޯ ހަރަކާތު ތަނުން ތަނަށް؛ [PartCraft ސެޓިންގްސް](topic:settings) ބަލާށެވެ |
| ޑިޒައިން އެކިއުރަސީ ހުރި ޓާބިއުލެންޓް ފްލޯ (Spalart–Allmaras މޮޑެލް އެކްސްޕެރިމަންޓަލް ގޮތުން ހުރި: ޕައިޕް ފްރިކްޝަން 30 ދާއިރާ 34 % ކަމަށް ވެ، ބެކްވޯޑް-ސްޓެޕް ރީއެޓްޗްމަންޓް 21 އާ 39 % ކުޑަ؛ ކިއުރިސް: ވޯލްގެ ކައިވެނި ފޯން ސެލްސް ފަދަ) ހީޓް ފްލޯ، އަންސްޓެޑީ ފްލޯ، ފްރީ ސަރފޭސް، ނޮން-ނިއުޓޯނިއަން ފްލޫޑްސް، ރޮޓޭޓިންގ ޕާޓްސް | ލެމިނާ، ސްޓޭޓި، އައިސޮތާމަލް ފްލޯ ނިއުޓޯނިއަން ފްލޫއިޑަށް، ނުވަތަ އެކްސްޕެރިމަންޓަލް ޓާބިއުލެންޓް މޮޑެލް ކެރެކްޓިވް ނޫން ނަމޫނާތަކަށް: [ފްލޫއިޑް ފްލޯ ސިމިއުލޭޓް](topic:flow-simulation) ބަލާށެވެ؛ ރެނޮލްޑްސް ނަންބަރު ލެމިނާ ކަމުގައި ވަނީ ނަމަ ޕެނަލް އިންޒާރު ދެއެވެ |
| ސްޓްރެސް ލިމިޓްތަކާއި މެނިފެކްޗާރިންގ ރޫލްސް (އޯވަހޭންގްސް، މިލިންގ ޑިރެކްޝަންސް) ޖެނެރޭޓިވް ޑިޒައިން؛ ޝޭޕްގައި ގިނަ މެޓީރިއަލް އެއް ކޮށް | ވޮލިއުމަށް ވަރަށް ފޯރު ފޯމް؛ ނަތީޖާ ސިމިއުލޭޝަން ސަނބީ ބަލާ: [ލޯޑުންދެން ފޯމް ހަދާ](topic:generative-design) |
| ނަތީޖާ ކޮމްޕްޔުޓް ކުރެވޭ ސްމޫތު (ޕެރަމެޓްރިކް) ސޮލިޑެއް ގެ ގޮތުގައި | STL، ފެސެޓޑް STEP، ނުވަތަ ނަތީޖާ ފެސެޓޑް ސޮލިޑެއްގެ ގޮތުގައި އިމްޕޯޓް ކުރެވުނު ބައި |
| ޕޮލިހެޑްރަލް ދާއިރާ... ޑައިނެމޯ ޑިޒައިން: ރޮޓަރ އަކީ ސްޓޭޓަރ ތެރޭ ފެރިޖަހާ، ޓޯކް އަދި އެންގަލް، ސެޓޫރޭޓިންގ ސްޓީލް، މެގްނެޓްސް ހެއްސާ ހިސާބު ކުރުން؛ އެޑީ ކަރަންޓް އަދި އައިރަން އަދި ކޮޕާ ލޮސްސް؛ 3-D ނުވަތަ ކާވް މެޝްގައި މެގްނެޓިކް ފީލްޑްސް | ޑިސްކްރިޓް 2-D މެގްނެޓޮސްޓެޓިކްސް ލައިބްރަރީގައި: ކޮއިލްސް، އައިރަން، ޕާމަނެންޓް މެގްނެޓްސް، ގެޕްސް، އިންޑަކްޓަންސް އަދި ޕުލް: [2-D މެގްނެޓިކް ފީލްޑްސް](topic:magnetic-fields-2d) ބަލާށެވެ |

## ސްކްރިޕްޓްތައް

| ހަދާފައިނުވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
