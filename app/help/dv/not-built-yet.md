PartCraft މި ބިލްޑް ދަށް ވަރަކަށް ދަނީ. މި ސަފްޙާ ފެންނާނީ ދެން އެއް ކަންތައް މި ބިލްޑް ނުކުރާ ކަމަށް، ކަނޑައަޅާ ތަންތަނުގެ ގޮތުން ޙައްދު ނުވަތަ އަލަށް ކުރެވޭ ޓޫލް ނުފެނޭ ގޮތުން، އަދި މިހާރު ކުރެވޭ ކަންތައް. އެއްވެސް ތާރީޚެއް ނެތް.

## އެކްސާކްޓް ކާރނަލް ބޭނުންވޭ

މި ވާރޝަން ކޮންމެ ބައެއް މެޝް ކާރނަލްން ހަދައެވެ ([މެޝް ކާރނަލް](topic:solid-kernels) ބަލާ). ތިރީގައިވާ ހުރިހާ ކަމެއް އެކްސާކްޓް ޖިއޮމެޓްރީ ކާރނަލް ބޭނުންވޭ، އެއީ މި ވާރޝަނަށް އަދި ނެތް. މި ފީޗަރުތަކާއެކު ސޭވް ކުރެވުނު ބައިތައް އަދި ހުޅުވޭ: ފީޗަރުތައް ހިސްޓަރީގައި ހުރެ، ހެދިފައި ނުވާ ގޮތުގައި ފެންނާ، އަދި ސޭވް ކުރުމުގައި ހިފެހެއްޓެވެ.

| ސްކެޗުތައް، ޕްލޭންތައް، އެކްސިސްތަކާއި ފޮއިންޓްސް ފަރުތަކުގައި ހުރި ހަމައެކަނި އެކްސާކްޓް ކާރނަލް ހޯދެވޭ ފަރުތައް (ފިލެޓްކުރި ފަރާތް، ހޯލް ފާރު، އިމްޕޯޓް ކުރި ސޮލިޑެއްގެ ފަރާތް) | ބޭސް ޕްލޭންތައް، ރެފަރެންސް ޕްލޭންތައް އަދި އެކްސްޓްރޫޑް އަދި ރެވޮލްވްގެ ފްލެޓް ފަރާތްތައް މަތީގައި ސްކެޗް ކުރޭ |
| ޖެނެރޭޓިވް ޑިޒައިނުގެ ނަތީޖާ ޕާޓެއްގެ ގޮތުން ހުޅުވުން ނުވަތަ އެކަށީގެންވާކަށް އިތުރު ކުރުން (އިމްޕޯޓް ކުރި ސޮލިޑެއް ކުރެވޭ) | ނަތީޖާ STL ނުވަތަ STEP ގެ ގޮތުން ދައުންލޯޑް ކުރޭ |
| STEP ފައިލެއްގެ ވަށާފައިވާ ފަރާތްތައް އެކްސާކްޓް ސާފޭސްގެ ގޮތުން އެޑިޓް ކުރުން؛ ސްޕްލައިން، ސްވޭޕް އަދި ރިވޯލްވްޑް ފަރާތްތައް ފައިލުން އެކްސާކްޓް STEP؛ ސްޕްލައިން ސައިޑްސް؛ ސްކްރޫތައް ޑިޒައިން ކުރާ ތްރެޑްސް؛ STL / OBJ / 3MF ބޮޑީތައް އަދި އެސެމްބްލީތައް؛ އެހެން CAD ޕާޓް ޑިޒައިނަރުތަކަށް STEP | {{ui:Open}} STEP ހުޅުވާ ކްރައިޓްލްޕުން ކުރޭ، އަދި ފައިލުގެ ފްލެޓް ފަރާތްތައް، ސިލިންޑަރ، ކޯން، ސްފިއަރ އަދި ޓޯރސް އެކްސްޕޯޓަށް ހިފެހެއްޓޭ ([STEP ފައިލެއް ހުޅުވާ](topic:import-step)); {{ui:Export}} › {{ui:STEP AP242 (exact solid)}} ކޮންމެ އެނަލިޓިކަލް ފަރާތަށް އެކްސާކްޓް ލިޔެ، އެގެ ފަސް ކަނޑު ނުވަތަ ފަސް ހުސްކޮށް ހިފެހެއްޓޭ ([އެކްސްޕޯޓް](topic:export-files#for-other-cad-programs-step)); އެހެން ޕާޓް މޮޑެލަރަށް މެކްރޯ އެކަން ފެނޭ |
| ޑްރޯއިން ވިއުތަކުގައި ހަގީގީ އާކްސް | ވިއުތަކާއި ސެކްޝަން ވިއުތައް ފަސް ކުރުމުން ޑްރޯ ކުރޭ |
| ހަގީގީ ވޮލިއުމްތައް، ފަރާތުތަކާއި މިނުން | {{ui:Measure}} ފަސް ކުރި ސޮލިޑުގެ އަގުތައް، ވަށާފައިވާ ބައިތަކުން ނުލުމެވެ؛ ބާރަ ފިނޭންމެ **Curves** ސެޓިންގ ބާޅެވެ |

ކިޓަރ ތަނެއްގައި ތިރީގައިވާ ޓޭބަލްތަކުގައި ހުރި ފީޗަރުތަކުގެ ގޮތުން މި ކަމަށް ތަފާތު ކަންތައް ކަނޑައަޅާ ކަމަށް ހިނދު. އެ ސަލާޙް އެކްސާކްޓް ކާރނަލް ފަސް ވެއްޖެނަމަ ހުންނާނެ.

| ކަމުގައި އާކްސް ނުވަތަ ސްޕްލައިން ކަމުގައި ވާ ރިބްސް؛ ސްކެޗަށް ސްކެއާ ވާ ރިބްސް (މަތީ ވިއުން)؛ ރިބްގައި ޑްރާފްޓް؛ ސްކެޗެއްންނު ގިނަ ރިބްސް | {{ui:Rib}} ރިބްގެ ޕްލޭނުގައި ތަނބު ލައިނާ މުޅިއެއްން: [Ribs and gussets](topic:rib) ބަލާ |
| ވަށާފައިވާ ފަރާތަކަށް "އަޕް ޓު"، "އަޕް ޓު ނެކްސްޓް" ފަރާތް ދެމިގެން ވަށާފައިވާ ފަރާތް | ފްލެޓް ފަރާތަށް ނުވަތަ ރެފަރެންސް ޕްލޭނަށް އަޕް ޓު |
| ކައުންޓަރޑްރިލްޑް ހޯލްތައް، އިންޗް އަދި ޕައިޕް ތްރެޑްތައް، ޓޭޕަރޑް ތްރެޑްތައް، ތްރެޑް ރަން އައުޓްސް އަދި ޗޭމްފަރޑް ތްރެޑް ސްޓާޓްސް | ކުޑަ ގޮތް ކައުންޓަރ-ބޯ؛ ISO މެޓްރިކް އަދި ޓްރެޕެޒޯއިޑަލް ތްރެޑްތައް، ކޮސްމެޓިކް ނުވަތަ މޮޑެލްކޮށްފައި: [Threads on shafts and bores](topic:threads) ބަލާ |
| ފީޗާ ޕާތްލާ ސްލް އެކްސްޓްރޫޑްތައް | ޕްރޮފައިލްގެ ދެ ފާރު ވާންޏެ ޑްރޯ ކުރޭ |
| ޕެޓާން ކޮޕީތައް އެއް އެއް ތުރުމް، ފިލް ޕެޓާންތައް | ވަކި ފީޗަރުތައް ބޭނުންކުރޭ؛ ވަށާ ޕޭތަ ޕެޓާންތައް: {{ui:Path pattern}} |
| ޕެޓާން ކޮޕީތައް، މިރާރ، ފިލެޓް، ޗޭމްފަރ، ޝެލް އަދި އިމްޕޯޓް ކުރި ސޮލިޑްތައް | ފަރާތުގައި ހުރި ސްކެޗް ނުވަތަ ފީޗަރ ކޮޕީ ކުރޭ، ނުވަތަ ޕެޓާން ކުރޭ |
| ފޯމުގެ ޚާއްޞަ ޕޮއިންޓްތަކުގައި ރާވާ (G1) ޓޭންޖެންސީ؛ ފޯމްގެ ޕެޗްތައް ބޮޑު ފަރާތްތަކަށް ގުޅުން | ފޯމްގެ ލެވެލް ބޮޑު ކުރޭ: ޕެޗްތައް ކުޑަވޭ؛ [Freeform shapes with Form](topic:form-surfaces) ބަލާ |
| ފީޗަރެއްގައި ކޮންމެ ވަރެއް ވަކި ފުރިހަމަ ކުރި ފޯމް؛ ފޯމްތަކާ ދެމެދު ފުލެއް | ފީޗަރެއްގައި ފުރިހަމަ ޕީސަކު ފޯމް؛ ޖޯއިން ކުރޭ |
| ވިއުގައި ސަރފޭސް ބޮޑީތައް އިޚްތިޔާރު ކުރުން (ޓްރިމް އަދި ޕެޗް ޕޮއިންޓްތަކުން މެދުވެރި)؛ ސަރފޭސް ފިލެޓް؛ އަންޓްރިމް؛ G2 ޕެޗްތައް؛ ކާރވުންގ ނައްތާފައި ގޮތްތަކާ ޖަހައި Gordon ސަރފޭސް (ޕްލޭންތަކާ ފްލެޓް ފަރާތުން ޖޮޅުވާ ހިނދު ހެދިފައި) | ފީޗަރުގެ ޕެނަލުގައި ނަމުން ޚިޔާރުކުރޭ؛ ފުރަތަމަ ތަނބު ކުރޭ، ފަހު ސޮލިޑް ފިލެޓް ކުރޭ |
| ހިސްޓަރީގައި ބޮޑީތަކުގެ ލިސްޓް؛ އެކްސްޕޯޓްތަކުން ފޮރުވާ ބޮޑީތައް ފަހަރު ކުރުން | ޕާޓް ޕެނަލުގެ ބޮޑީ ލިސްޓުގައި ބޮޑީތައް ނަން ބަދަލުކޮށް ފޮރުވާ؛ ބޮޑީ ހަދާ ފީޗަރ ފޮހެލާ ނުވަތަ ސަޕްރެސްކޮށް ފޮރުވާ |
| ނާމަދުން ސްކޭލް، ސިލިންޑަރ އަދި ކޯން ނުގުޅާ ދަށް ކުރެވޭ؛ އޮފްސެޓް ސަރފޭސްގެ ނަން ނުވާ ސްކޭލް | {{ui:Scale body}} ކާރވްޑް ފަރާތްތައް B-ސްޕްލައިން ކުރޭ (0.0000004 mm ތެރޭގައި); ހަމަ ސްކޭލް އެކަނި ހަގީގީ ހުރެ |
| ސަރފޭސް ބޮޑީތައް ޖޮޅު ކުރުން؛ މިންކަވޮސްކީ ގުނަ | {{ui:Stitch}} ނުވަތަ {{ui:Thicken}} ފުރަތަމަ، ދެން {{ui:Combine}} |
| ސްޓެކް-އަޕް ކޮނެހެ ސްކްލޯޖް، ޓޫލް (2D އަދި 3D ވެކްޓަރ ލޫޕް)؛ ޖިއޮމެޓްރީން ފެންނާ ސެންސިޓިވިޓީ؛ ހިއެވާޑާ ނެތް ޑިސްޓްރިބިއުޝަން؛ ސްކެޗް ޑައިމެންޝަންތަކުގެ ސައިޒް ޓޮލަރެންސް؛ މެޓީރިއަލް ކޮންޑިޝަނުން ބޮނަސް ޓޮލަރެންސް | އެސެމްބްލީގައި {{ui:Stack-up}}: ދިރިއަދި އެއް ދިރިއާ ގައި، ހަރަސް ކޭސް އަދި RSS، ޓައިޕް ކުރި ޓޮލަރެންސް، ޓައިޓްލް ބްލޮކުގެ ޖެނެރަލް ޓޮލަރެންސް ނުވަތަ GD&T ފްރޭމްތަކުން: [Tolerance stack-ups](topic:tolerance-stackup) ބަލާ |
| ނެސްޓިންގ: ކަނޑާ އޯޑާ އަދި ލީޑް-އިންތައް؛ ހާއްސަ އެޖްތައް އެކްގޮތަށް ކަނޑާ؛ އެކުގައި ހިފެހެއްޓޭ ޕާޓްތައް؛ ރޯލްތަކުގެ ރިމްނަންތައް، ޕްރޮޖެކްޓްތަކުގެ ސްޓޮކް ޝެއާ ކުރެވޭ | {{ui:Nest flat parts on sheets…}}: ވަރާއި ސްޕޭސިންގ، މާޖިންސް، ޓާންސް އަދި ގްރޭން: [Nest flat parts on sheets](topic:nest-flat-parts) ބަލާ؛ ބާކީވާ ޕްލޭޓް ރައްކާ އަދި ފުރަތަމަ ބޭނުންކުރޭ: [Keep and reuse offcuts](topic:nest-offcuts) ބަލާ؛ ކަނޑާ ރޭޑާ ސޮފްޓްވެއާ ރޭޑީ ކުރޭ |
| ޝީޓް މެޓަލް: ހެމްސް، ޖޮގްސް، މިޓަރ އަދި ކޮންޓޫރ ފްލޭންޖް؛ ކާރވްޑް އެޖްތައް ނުވަތަ ވަކި ބޭސް ފްލޭންޖް ފަރުތަކުގައި ފްލޭންޖް؛ ސްކެޗުން ބެންޑް؛ ކޮނަރ ކްލޯޒަރ؛ ފޯމިންގ ޓޫލްސް؛ ސޮލިޑް ޝީޓް މެޓަލަށް ބަދަލުކުރުން؛ ބޭސް ފްލޭންޖްގެ ކަނޑަލުގެ ބޮޑު؛ ބެންޑް ޓޭބަލްތައް | {{ui:Base flange}} (ޕްލޭޓް ނުވަތަ ބެންޑް ޕްރޮފައިލް)، {{ui:Edge flange}} ޕްލޭޓުގެ ސީދާ އެޖްތަކުގައި ބެންޑް ރިލީފްތައް ހިމެނޭ، އަދި K-ފެކްޓަރ ހިމެނޭ ފްލެޓް ޕެޓާން: [Sheet metal](topic:sheet-metal) ބަލާ |
| އެސެމްބްލީތަކުގެ ޑްރާފްޓް އެނަލިސިސް؛ ޕާރޓިންގ ލައިން ހޯދުން؛ ފުޅާ އެނަލިސިސް | ޑިޒައިން ގައި ޕާރޓް މަތީގައި {{ui:Draft analysis}}: [Check draft for moulding and casting](topic:draft-analysis) ބަލާ؛ އެސެމްބްލީގެ ކޮންމެ ޕާޓް ވަކިން ހުޅުވާ ބަލާ |

## ސްކެޗްތައް

|---|---|
| އެލިޕްސް، ޓޭންޖަންޓް އާކްސް، ކޮނިކްސް، ސްޕްލައިން ސެޓް ޑިގްރީ ނުވަތަ ވެއިޓްސްއާ (NURBS) | ސްޕްލައިން (ކިއުބިކް)، އާކްސް އަދި ސަރކަލްސް ޓޭންޖެންޓް ރިލޭޝަންސާ |
| ސްޕްލައިނެއްގެ ފޮއިންޓް (ރިލޭޝަން)، ކަރްވޭޗަރ (G2) ރިލޭޝަންސް | ސްޕްލައިނުގެ ފޮއިންޓް ފަސްކުރާ ތަނަށް ދާންޖެހޭ ޗަންދު ހަދާ |
| ސްޕްލައިން އޮފްސެޓް ކޮޕީތައް ބަދަލުތަކާއި ދިގުއެވެ؛ ސްޕްލައިން ކޯނަރ ހުރި ޗޭން ޢޮފްސެޓް | ބަދަލުގެ ފަހު އަލުން އޮފްސެޓް ކުރޭ؛ ކޯނަރ ފުރަތަމަ ރައުންޑް ކުރޭ |

| ސްވާފް ކަނޑާ، ފްލޯ ލައިން އަދި ގިނަ އެކްސިސް ރަފް ޕާތްތައް؛ ޓިލްޓް ވޯކް ޕްލޭން ކޯޑު (G68.2)، ހޯލްޑަރާއި މެޝީންގެ ކޮލިޝަން ޗެކް؛ 5-އެކްސިސް އަދި ރޮޓަރީ ކަނޑާތަކުގެ ސިމިއުލޭޝަން | ކޮންމެ އޮޕަރޭޝަނަށް ޓިލްޓެޑް ޓޫލް، 5-އެކްސިސް ފިނިޝިންގ ބޯލް އެންޑް މިލް ނާލާ، 4 ވަނަ އެކްސިސް ރޮޓަރީ ފިނިޝިންގ: [4- އަދި 5-އެކްސިސް މެޝިނިންގ](topic:multi-axis) |
| ލޭތެ މަތީގައި ބޯރިންގ އަދި އެތެރެ ތްރެޑްތައް؛ G71/G76 ސައިކަލްތައް؛ ޓާންކުރުމުގެ ފަރާތްތަކުގައި އާކްސް؛ ލައިވް ޓޫލްތައް؛ ސަބް-ސްޕިންޑަލް | ބާހިރު ޓާންކުރުން: ފެނޭ، ރަފް، ފިނިޝް، ގްރޫވް، ޕާޓް އޮފް، ތްރެޑް، ސެންޓަރުގައި ޑްރިލް: [ލޭތެގައި ޓާންކުރުން](topic:turning) |
| ކޯނެއް ނުވަތަ ސިކުރުތައް ޕްރޯބިންގ؛ ޓޫލް ސެޓަރ؛ ސައިޒެއް ޓޮލަރެންސަށް ފަރާތުން މިން ކުރުން | ފަރާތަކަށް، ގުޅުން، ހޯލަކަށް ނުވަތަ ބޮސްއަށް ޕްރޯބިންގ، ވޯކް އޮފްސެޓް ސެޓް ކުރުމަށް: [Probing](topic:probing) |
| ހޯލްޑަރާއި ޝޭންކް ކޮލިޝަން ޗެކް | ފްލޫޓް ދިގުމިން އިންޒާރު ބަލާ، ކޮންޓްރޯލް ސިމިއުލޭޓަރުން ބަލާ |
| ޓޫލް ލައިފް ފަރާތުން ރާވުން؛ ސަބް-ޕްރޮގްރާމް ސައިކަލްތައް ޕޯސްޓުގައި؛ އެހެން ޕްރޮގްރާމްތަކުގެ ޕޯސްޓް ފައިލް ލޯޑް ކުރުން | ޕޯސްޓް PartCraft ގެ ފޯމެޓުން ލިޔޭ ނުވަތަ ބަދަލުކުރޭ: [Post processors you can edit](topic:post-processors) |

## ސިމިއުލޭޝަން އަދި ޖެނެރޭޓިވް ޑިޒައިން

| ހެދިފައި ނުވާ | މިހާރު ކުރެވޭ ގޮތް |
|---|---|
| ނޮންލީނިއާ ސްޓަޑީޒް: ޔީލްޑިންގ، ބޮޑު ޑިފްލެކްޝަން، ޕާޓްތަކާ ދެމެދު ކޮންޓެކްޓް، ފެޓިގް | ލީނިއާ ސްޓޭޓިކް އަދި ނޭޗަރަލް ފްރީކުއެންސީ: [Check stress and deflection](topic:simulation)؛ ސޭފްޓީ ފެކްޓަރ 1 ގެ މަތީން ބައެއް ބޮޑަށް ބަލާ |
| ނޮންލީނިއާ ބަކްލިންގ (އިމްޕާފެކްޝަންސް، ޕޯސްޓް-ބަކްލިންގ، ސްނޭޕް-ތްރޫ) | ލީނިއާ ބަކްލިންގ ލޯޑް ފެކްޓަރ ބޮޑު މާރޖިންއަކަށް: [Heat, thermal stress and buckling](topic:thermal-and-buckling) |
| ރޭޑިއޭޝަން ފޭސްތަކާ ދެމެދު (ވިއު ފެކްޓަރްސް)، ކޮންޓެކްޓް ރެޒިސްޓަންސް، ޓެމްޕަރޭޗަރ ބަލާ މެޓީރިއަލްސް، ތާރމަލް ސްޓްރެސް ތެރެ އިނޭޝިއާ (ތާރމަލް ޝޮކް ވޭވްސް) | ސުރުވިލްލާއަށް ރޭޑިއޭޝަން، ސްޓެޑީ ނުވަތަ ކުއާސި-ސްޓެޓިކް ތާރމަލް ސްޓްރެސް ވަގުތާ ގުޅި، ކޮންސްޓަންޓް ޕްރޮޕަޓީޒް: [Heat, thermal stress and buckling](topic:thermal-and-buckling) |
| ޓްރާންސިއެންޓް ހީޓަށް އޯޓޯމެޓިކް ރިފައިންމަންޓް އަދި ލޯޑް ހުރި ސްޓަޑީ؛ ފަރާތް ފޮޓޯ ކުރާ ހިނދު މެޝް ޕްރޮޕަޑް ކުރުން؛ ލޯކަލް ކުއާންޓިޓީއަކަށް ޓާގެޓް (ޕީކް ސްޓްރެސް އެއް ޓުސްޕޮޓުގައި) | ސްޓެޓިކް، ބަކްލިންގ، ނޭޗަރަލް ފްރީކުއެންސީ އަދި ސްޓެޑީ ތާރމަލް ސްޓަޑީތަކަށް **Refine automatically**، ފަރާތުގެ މުޅި އެރަރއަށް: [Check stress and deflection](topic:simulation)؛ އެހެން ނަމަ މެޝް ސައިޒް ކުޑަ ކުރޭ |
| ބިއަރިންގ އަދި ބޯލްޓު ލޯޑްސް، ރިމޯޓް ފޯހުން، މޮމެންޓްސް، ސްޕްރިންގ، ޕްރެސްކްރައިބްޑް ޑިސްޕްލޭސްމަންޓްސް | ފަރާތްތަކުގައި ފޯހުން އަދި ޕްރެޝަރ، ގްރެވިޓީ؛ ފިކްސްޑް އަދި ފްރިކްޝަން ނެތް ފަރާތްތައް |
| އެސެމްބްލީތަކުގެ ސިމިއުލޭޝަން؛ ދިމާން ވަކިވާ މެޓީރިއަލްތައް (ޕްރިންޓް ކުރި ލޭޔަރ، ކޮމްޕޯޒިޓްސް) | ޕާޓަކަށް، އެއް އައިސޮޓްރޮޕިކް މެޓީރިއަލް |
| ޓެޑްރަހެޑްރަލް ސްޓަޑީތަކަށް ގިނަ ސޯލްވަރ ތްރެޑްސް؛ ހީޓް ޓްރާންސްފަރ އަދި ޖެނެރޭޓިވް ޑިޒައިން؛ ކްރޮސް-އޯރިޖިން އައިސޮލޭޓްކުރެވިފައި ނެތް ސަފްޙާގެ ތްރެޑްސް | ވޯކްސް ސްޓަޑީތައް، ބަކްލިންގ، ސްޓްރެސް ވަގުތު އަދި ލަމިނާ ފްލޯ ތްރެޑްސް ބޭނުންކުރޭ ސަފްޙާ ހުއްދަ ދެނީ: [PartCraft settings](topic:settings) |
| ޓަރބިއުލެންޓް ފްލޯ ޑިޒައިން އެކުރަސީ (Spalart–Allmaras މޮޑެލް ތަޖްރިބީ ގޮތުން ހިމެނި: ޕައިޕް ފްރިކްޝަން 30 އިން 34 % ބޮޑު، ބެކްވޯޑް-ސްޓެޕް ރީއެޓޭޗްމަންޓް 21 އިން 39 % ކުޑަ؛ ކަމަށްވާ ގިނަ ސެލްތައް ވާލް ކައިރި) ހީޓް ފްލޯގައި، ޓައިމް-އެކިއުރެޓް ފްލޯ، ފްރީ ސާފަސް، ނޮން-ނިއުޓޯނިއަން ފްލޫޢިޑްސް، ރޮޓޭޓިންގ ޕާޓްސް | ލަމިނާ، ސްޓޭޓީ، އައިސޮތާމަލް ފްލޫއިޑު ނުވަތަ ތަޖްރިބީ ޓަރބިއުލެންޓް މޮޑެލް ކުއާލިޓޭޓިވް ޕެޓާންތަކަށް: [Simulate fluid flow](topic:flow-simulation)؛ ރެނޮލްޑްސް ނަމްބަރު ލަމިނާ ފާސް ކުރުމުން ޕެނަލް އިންޒާރު ދެއެވެ |
| ޖެނެރޭޓިވް ޑިޒައިނުގައި ސްޓްރެސް ލިމިޓްސް އަދި މެނިއުފެކްޗަރިންގ ރޫލްސް (އޯވާހޭންގްސް، މިލިންގ ޑިރެކްޝަންސް)؛ ހަދަމަ ހުރި ގިނަ މެޓީރިއަލްސް | ވޮލިއުމަށް ދަށް ޝޭޕް؛ ނަތީޖާ ސިމިއުލޭޝަނުން ބަލާ: [Grow a shape from loads](topic:generative-design) |
| ނަތީޖާ އެޑިޓް ކުރެވޭ (ސްމޫތް، ޕެރަމެޓްރިކް) ސޮލިޑެއް | STL، ފެސެޓް STEP، ނުވަތަ އިމްޕޯޓް ކުރި ފެސެޓް ސޮލިޑެއް ހުރި ޕާޓް |
| އީލެކްޓްރިކް މެޝީން ޑިޒައިން: ސްޓޭޓަރގައި ރޯޓަރ އުޅުން، ޓޯކް ކޮންޓްރާ އެންގަލް، ހޫހުން ސިލިކޮން ސްޓީލް، ބެންޑުން ފަހަށް ނޫން ހޫހަށް ހުރި މެގްނެޓް؛ އެޑީ ކަރަންޓްސް އަދި އައިރަން ކޮޕާ ލޮސް؛ 3-D ސާފަސް ކުރި ފީލްޑް | 2-D ލީނިއާ މެގްނެޓޮސްޓޭޓިކްސް އެނަލިސިސް ލައިބްރަރީގައި ކޮއިލް، އައިރަން، ޕަރމަނަންޓް މެގްނެޓް؛ [Magnetic fields in 2-D](topic:magnetic-fields-2d) ބަލާ |
