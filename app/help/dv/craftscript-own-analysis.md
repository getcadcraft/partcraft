ސްކްރިޕްޓް ވޯކްސްޕޭސްގައި އެނަލިސިސެއް އަކީ ކުޑަ ސްކްރިޕްޓްތަކެއް ކުޅެ، ވޭރިއަބަލްތައް އެއަކަށް އެއް ދޫކުރާ. [ލައިބްރަރީ](topic:craftscript-library) ފަންކްޝަނެއް ކަމެއް ފަށާށެވެ ކަމުގައި ގެންގުޅެނީ ބޭނުންވާ ކަމަށް ގާތް ކަމަކުން، ކޮޕީއެއް ހަދާ، ބަދަލުކުރޭ؛ ނުވަތަ ތިރީގައި ވާ ފަދައިން އެކަމެއް ބިނާކޮށް ހަދާ.

## 1. މެޝެއް

```
model = part();                  % ތިޔަ މޮޑެލްކުރާ ޕާޓް، މޮޑެލެއްގެ ގޮތުގައި
m = tetmesh(model, 4);           % ޓެޓްރާހެޑްރާ 4 mm ފަދައިން ފުޅާ
show(m)
```

ކުރިއަށް ދާންކުރިން މެޝް ވިއުގައި ބަލާ: {{key:F}} ފިޓް ކުރޭ، **Shown** ގައި {{ui:eye}} ޕާޓް ފޮރުވާ.

## 2. އެސެމްބްލް އަދި ސޮލްވް

ސްކްރިޕްޓުގައި އެލިމަންޓް ލޫޕް ލިޔޭ (ވަށިން ފަދައިން ކިޔެވޭގޮތަށް)، އަދި ބަރު ކަންތައް ބިލްޓް އިން ފަންކްޝަންތަކަށް ދޫކުރޭ: އެލިމަންޓް މެޓްރިކްސް، ޓްރިޕްލެޓުންކުރާ ސްޕާސް އެސެމްބްލީ، އަދި ޕްރިކަންޑިޝަނަރ ހިމެނޭ ކޮންޖޫގޭޓް ގްރޭޑިއަންޓް ސޮލްވަރ. ލައިބްރަރީ ފަންކްޝަނެއް ހަމަ `static_tet` (ލައިބްރަރީ ނިންމީމަ) ކޮޕީ ކުރުމަށް ފުރިހަމަ މިސާލެކެވެ.

## 3. ނަތީޖާ ދައްކާ

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % ނޯޑަށް އެއް އަގެއް
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- ލެޖެންޑުގެ ރޭންޖް ލިޔައި ނުވަތަ {{ui:Auto}} އަށް ނަގާ ލިބޭ.
- ނޯޑެއްގެ އަގުތައް ކިޔާށެއް ކުރުމަށް މެޝް ކްލިކް ކުރޭ.
- އެއް `'id'` ބާކީ ގެންގުޅޭ ޕްލޯޓަކީ އެ ތަނުގައި އަލުން އަޕްޑޭޓް ވާ ޕްލޯޓެއް، އެހެންކަމުން ލޫޕްގެ ތެރޭގައި ޕްރިންޓް އަދި ޕްލޯޓް ކުރޭ، ކޮންވާޖް ވާކަން ބަލަން.

## 4. ޗެކް ކުރޭ

ތިޔަ އެއްވެސް ދަންނަ ކަމަކާ ހަވާލު ކުރޭ: ކެންޓިލީވަރ ފިހުރާމަ ޓިޕް ޑިފްލެކްޝަން PL³/3EI އާ، ހިފަކޮށް ޕްލޭޓް އަކީ އޭގެ ސްޓްރެސް ކޮންސަންޓްރޭޝަން ފެކްޓަރާ، ރިއެކްޝަންތައް ލޯޑުތަކާ. ޗެކް އެކަމެއްގެ ސްކްރިޕްޓަކަށް ލިޔެ ކޮންމެ ބަދަލަކަށް ފަހު އަލުން ރަން ވާނެއެވެ:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. ސަލާމަތް ކުރޭ

- ކޮންމެ ސްޓެޕަކީ އެކަކު ސްކްރިޕްޓް ޓެބެއް ކަމުގައި ވެވޭ: އެ ޝޭއާ ކުރަނީ ވޭރިއަބަލްތައް، ފަހެވެ އެކަކު އަނެއް ފަހަތުން ރަން ކުރޭ.
- ސްކްރިޕްޓް ޕާޓުގެ ތެރޭގައި ސޭވް ވޭ. ވޭރިއަބަލްތައް ޕާޓާއެކު ސަލާމަތް ކުރުމަށް Variables ޓެބުގައި **Save the variables with the part** ޓިކް ކުރޭ (32 MB ތަނަވަސްކަމަށް).
- Script ގްރޫޕުގެ {{ui:Save}} ސްކްރިޕްޓް ޑައުންލޯޑް ކުރެއެވެ ޝޭއާ ކުރުމަށް؛ {{ui:Open}} އިންނާނެ ސްކްރިޕްޓް ގެނެސްދޭ.
