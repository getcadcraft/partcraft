Python އަކީ [ސްކްރިޕްޓް ވޯކްސްޕޭސްގެ](topic:craftscript) ތިންވަނަ ބަހެވެ. އެޑިޓަރުގެ މައްޗަށް ބަހުގެ ބޮކްސްއިން **Python** ނަގާ (`.py` ފައިލެއް އޮޓޮމެޓިކުން Python ގައި ހުޅުވެއެވެ). Python، Lua އަދި CraftScript ދެކަމުން ވޭރިއަބަލްތަކާއި ބިލްޓް އިން ފަންކްޝަންތައް ޝޭއާކުރެއެވެ، އެހެންކަމުން Python ސްކްރިޕްޓަކަށް CraftScript ސްކްރިޕްޓަކުން ހަދާ ކަންތައް ބޭނުންކުރެވޭ، އަދި އެކަމަށް ފަހަތަށް ވެސް.

ވިޒިޓެއްގެ ފުރަތަމަ Python ރަނުން Python އަމިއްލަ (CPython 3.14، 7 MB ހަމަ) މި ސައިޓުން ލޯޑުކުރެއެވެ، އެއީ ސިކުންތު ކޮޅެއް ނަގާ. Python އަދިވެސް {{ui:Save for offline}} ގެ ކަމެއް ނޫން: ފުރަތަމަ އޮންލައިންގައި Python ސްކްރިޕްޓެއް ރަން ކުރޭ.

## Python ސީލްކުރެވިފައި

Python ސްކްރިޕްޓްތަކަށް CraftScript އަދި Lua ސްކްރިޕްޓްތަކުން ފަދައިން ސީލްކުރެވިފައެވެ: އެމީހުންނަށް ޕާޓު، ވޭރިއަބަލްތައް އަދި ބިލްޓް އިން ފަންކްޝަންތަކަށް ނުކުތާ ލިބެއެވެ، އަދި އެހެން އެއްވެސް ކަމަކަށް ނޫން. ކޮންމެ ރަނެއްވެސް އައު Python ކަމުގައި އޭގެ އަމިއްލަ ސޭންޑްބޮކްސްގައި އަދި މެމަރީގައި ފައިލް ޓްރީއެއް ހިމެނިގެން (އޭގެ ސްޓޭންޑަރޑް ލައިބްރަރީ އަދި ނިމިފައި ނިމޭ `/tmp` ފޯލްޑަރެކެވެ). ނެޓްވާރކް، ތިޔަ ފައިލްތައް ނުވަތަ ޕޭޖުގެ އެހެން ކަންތައް ނުކުތާ ނުލިބެއެވެ، ބްރައުޒަރުގައިވެސް އަދި ކޮމާންޑް ލައިނުގައިވެސް. ކޮންމެ އެހެން މީހަކުގެ ސްކްރިޕްޓަކަށް ވަރަށް ފަހަރަށް ވަގުތެއް ނުވަތަ މެމަރީ ނަގަން ފަރާތް، {{ui:Stop}} އިން ހަމަ ކުރެވޭ.

## އަސާސީ ކަންތައް

```
A = cs.magic(3)              # ކޮންމެ ބިލްޓް އިން ފަންކްޝަނެއް cs.<name>
B = A @ A.T                  # @ މެޓްރިކްސް ޕްރޮޑަކްޓް، .T ޓްރާންސްޕޯސް
C = A * 2 + 1                # + - * / ** އެއް އެއް އެލިމަންޓުން، numpy ފަދައިން
print(A[0, 1], A[-1, -1])    # 0 އިން ފެށެއެވެ؛ މައިނަސް ފަހުން ފެށެއެވެ
row = A[1]                   # މެޓްރިކްސެއް މައްޗަށް އިންޑެކްސް އެއް: ރޯއެއް
big = A[A > 4]               # ލޮޖިކަލް މާސްކެއް އެލިމަންޓް ނަގައެވެ
A[0, 0] = -5                 # އެރޭއަށް ލިޔުން
V, D = cs.call('eig', 2, A)  # ކިތައް ނަތީޖާ: cs.call(name, ކިތައް, …)
```

- 1 × 1 އެރޭ ލިބެނީ ރަނގަޅު ނަންބަރެއްގެ ގޮތުގައެވެ؛ އެހެން އެރޭތައް، ސްޕާސް މެޓްރިކްސްތައް، މެޝްތައް، ފީލްޑްތައް އަދި މޮޑެލްތައް **Values** އެކެވެ.
- Value ގައި `shape` (tuple)، `T`، `type`، `numel()`، `copy()`، `tolist()`، `len()` (އޭގެ ރޯތައް)، އަދި އެއް އެލިމަންޓަށް `float()`، `int()` އަދި `bool()` ހުރެއެވެ.
- ކޮމްޕެރިސަންތައް (`<`، `==`، …) އެއް އެއް އެލިމަންޓުން، numpy ފަދައިން: އެމީހުން ލޮޖިކަލް Value ދެއެވެ.
- ފަންކްޝަނަކަށް ދޭ ނަންބަރުތަކުގެ ލިސްޓް އެރޭ ވެއެވެ: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` މެޓްރިކްސެއް ހަދައެވެ.
- ޑިކްޝަނަރީ ސްޓްރަކްޓް ވެއެވެ، މިކްސް ލިސްޓް ސެލް ވެއެވެ، އަދި އެ ފަދައިން އުނދަގޫ ގޮތަށް ފަހަތަށް.

ތިޔަ ސްކްރިޕްޓުން ހަދާ ކޮންމެ ގްލޯބަލެއް (ނަންބަރެއް، Value، ޑިކްޝަނަރީ، ލިސްޓް…) ރަނެއް ނިމުމުން **Variables** ޓެބަށް ވެސް ދާއެވެ، އެރަރެއްގެ ފަހުން ވެސް. `_` ގެ ނަމުންވާ ނަމަކީ ފަންކްޝަންތަކާއި ކްލާސްތަކާއި މޮޑިއުލްތައް Python ގައި ހިފެއެވެ. `ws.name` ވޭރިއަބަލަކަށް ސީދާ ކިޔަވައި ނުވަތަ ސެޓް ކުރެއެވެ، އަދި `ws_names()` ޑިސްޕްލޭ ކުރެއެވެ.

`print(…)` ކޮންސޯލަށް ލިޔެއެވެ. `display(…)` (ނުވަތަ `cs.display`) މެޝް، ފީލްޑް ނުވަތަ ޕްލޯޓެއް ދައްކާއެވެ، CraftScript ގައި ފަދައިން.

## އެނަލިސިސް ލައިބްރަރީ ކޯލް ކުރޭ

ލައިބްރަރީ ފަންކްޝަންތައް ބިލްޓް އިން ފަންކްޝަންތައް ފަދައިން ކޯލްކުރެވެއެވެ: `cs.box_mesh(20, 10, 10, 5, 'hex')`، `cs.call('modal_tet', 2, …)`. ނަން ސްކްރިޕްޓުގައި އެ ފަދައިން ލިޔޭ: PartCraft ރަނުގެ ކުރިން ސްކްރިޕްޓް ބޭނުންކުރާ ލައިބްރަރީ ފަންކްޝަންތައް ހޯދައެވެ.

## އަދިވެސް ނެތް ކަންތައް

- numpy، scipy އަދި އެހެން ޕެކޭޖްތައް: Python އަމިއްލަ ސްޓޭންޑަރޑް ލައިބްރަރީ (`math`، `json`، `itertools`، `decimal`، `statistics`…) ހަމަ އެހެންކަމަށް، ނަމަވެސް ކުޑަ ވިންޑޯ، ޓާމިނަލް އަދި ޑޭޓާބޭސް ބައިތައް (`tkinter`، `curses`، `sqlite3`) ނެތެވެ.
- ސޮކެޓްސް އަދި އެހެން ކޮންމެ ކަމެއް ބޭރުން ގަޑިން ދާ: Python ގައި މިތަނުގައި ނެޓްވާރކް ނެތެވެ.
- `time.sleep` ވަގުތުން ރިޓާން ވެއެވެ.
- އެޑިޓަރުގައި ފޯލްޑިންގ، އަދި CraftScript ސްކްރިޕްޓަކުން Python ފަންކްޝަނެއް ކޯލް ކުރުން.
- ރަނެއް ކޮމާންޑް ބަޖެޓް އަދި Stop ކޮންމެ 1000 ލައިންގެ ފަހުން ޗެކް ކުރެއެވެ؛ ބިލްޓް އިން ފަންކްޝަނެއްގެ ތެރޭގައި ދިގު ހިސާބެއް އެއީ ފުރަތަމަ ނިމެއެވެ.
