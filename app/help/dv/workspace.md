ސްކްރީނުގައި ބައި ފަސް ކަމުގައި ހުންނެވެ: މަތީގައި ޓޫލްބާ، ކޮޅުން ހިސްޓްރީ، މެދުގައި 3D ވިއު، ކަނާތް ފަރާތުގައި ޕްރޮޕަޓީސް ޕެނަލް އަދި ތިރީގައި ސްޓޭޓަސް ބާ. ހުރިހާ އެއްޗަކަށް މަތީގައި CadCraft އެޕް ބާ ހުރެއެވެ.

## އެޕް ބާ

ވަރަށް ސާފު ބާއެއް މަތީގައި ހުންނަނީ CadCraft ސައިޓަށް ޚާއްޞަ ކަމުގައި، PartCraft އަށް ނޫނެވެ. އެއީ އެޕްގެ ނަން އަދި އެ ހިންގޭ ތަން، ވާރޝަން މެނޫ، **About PartCraft**، ސްކްރީން މޯޑް ބަޓަން އަދި Paper / Model ތީމް ސްވިޗް ދައްކައެވެ.

- **Paper** އަކީ ޅަދަ ލައިންތައް ލޭސް ޝީޓެއްގައި. **Model** އަކީ ލޭސް ލައިންތައް ތެރޭ ބެކްގްރައުންޑެއްގައި. ސްކެޗް ރަންގު ތީމާ އެއްގޮތަށް ހިންގެއެވެ.
- {{ui:Settings}} (ގިރާ ނުވަތަ {{key:Mod+,}}) ގައި {{ui:PartCraft}} ޓެބް ހުއްޓެއެވެ: ވިއު ހިއްލާ ކުރާ މައުސް ބަޓަން، މައުސް ވީލް ނުވަތަ ޓްރެކްޕެޑް، އަދި ސްކެޗް ކުރާއިރުގެ ރިލޭޝަންތައް. ބަލާ [PartCraft ސެޓިންގްސް](topic:settings).
- ސްކްރީން މޯޑް ބަޓަން، ނުވަތަ {{key:Ctrl+Shift+F}}، ނޯމަލް، ފުރިހަމަ ސްކްރީން، އަދި ބާ ހުއްޓި ފުރިހަމަ ސްކްރީން ގެ ތެރޭގައި ޖަހައެވެ. ބާ ހުއްޓި ވަގުތު މައުސް މަތީ ކަނޑަށް ގެންދިއުން (ނުވަތަ އެތަނަށް ޓެޕް ކުރުން) ބާ ފެނިވަޑައިގަންނާނެއެވެ. {{key:Esc}} ނޯމަލަށް އަންނާނެއެވެ. މި ކީ މެކްގައިވެސް {{key:Ctrl+Shift+F}} ކަމުން، ⌘ ނޫނެވެ.

## ޓޫލްބާ

ޓޫލްބާ ގުރޫޕްކުރެވިފައިވެއެވެ. އެ ކުރާ ކަމާ އެކު އެ ބަދަލުވެ، އެއް ރޯއެއްގައި ފިޓް ވެއެވެ:

| ގުރޫޕް | ބަޓަންތައް | ފެންނަނީ |
|---|---|---|
| File | {{ui:New}}، {{ui:Open}}، {{ui:Save}}، {{ui:Export}} (މެނޫއެއް) | ކޮންމެވެސް |
| Sketch | {{ui:Sketch}} | ސްކެޗެއް ހުޅުވާފައި ނުވާއިރު |
| Sketch | {{ui:Exit}}، {{ui:Line}}، {{ui:Rectangle}}، {{ui:Circle}}، {{ui:Arc}}، {{ui:Point}}، {{ui:Centerline}}، {{ui:Fillet}}، {{ui:Dimension}}، {{ui:Construction}} | ސްކެޗެއް ހުޅުވާ ވަގުތު އެކަނި |
| Features | {{ui:Extrude}}، {{ui:Cut}}، {{ui:Revolve}}، {{ui:Hole}}، {{ui:Linear}}، {{ui:Circular}}، {{ui:Mirror}}، {{ui:Fillet}}، {{ui:Chamfer}}، {{ui:Shell}}، {{ui:More}} (މެނޫއެއް: Revolved cut، Plane، Axis، Point، Sweep، Loft، Draft) | ބައިގެ މަތީގައި، ސްކެޗެއް ނުވަތަ ޑްރޯއިންގެއް ހުޅުވާފައި ނުވާއިރު. Fillet އަދި Chamfer މަތީ ފްލެޓް ފޭސްތަކާ ދެމެދު ސްޓްރެއިޓް ކަނޑުތަކުގައި ކަންކޮށްދެއެވެ؛ Shell އަދި Draft ފްލެޓް ފޭސްތަކުގައި. Sweep އަދި Loft މި ވާރޝަނުގައި އަދިވެސް ހަދާފައި ނެތެވެ (ހަމަ ކާނަލް ބޭނުންވެއެވެ)؛ ކްލިކްކުރާއިރު އެ ކަން ދައްކައެވެ |
| Features | {{ui:Done}} | Fillet، Chamfer، Shell ނުވަތަ Draft އަށް ކަނޑު ނުވަތަ ފޭސް ހޮވާއިރު އެކަނި |
| Drawing | {{ui:Drawing}} | ބައިގައި (ބައިއަށް ސޮލިޑެއް ލިބުމުން ބޭނުން ކުރެވޭ) |
| Drawing | {{ui:Datum}}، {{ui:Frame}}، {{ui:Finish}}، {{ui:Detail}}، {{ui:PDF}}، {{ui:Back}} | ޑްރޯއިންގ ޝީޓުގައި އެކަނި |
| Assembly | {{ui:Assembly}} | ބައިގައި (ބައިއަށް ސޮލިޑެއް ލިބުމުން ބޭނުން ކުރެވޭ) |
| Assembly | {{ui:Add copy}}، {{ui:Insert}}، {{ui:Joint}}، {{ui:Clash}}، {{ui:Edit part}}، {{ui:Close}} | އެސެމްބްލީއެއްގައި އެކަނި |
| Assembly | {{ui:Back}} | އެސެމްބްލީއިން ބައި އެޑިޓް ކުރާ ވަގުތު |
| Edit | {{ui:Undo}}، {{ui:Redo}}، {{ui:Copy}}، {{ui:Paste}}، {{ui:More}} (މެނޫއެއް: Cut، Copy، Paste، Paste in place، Duplicate، Delete، Select all، Select none) | ކޮންމެވެސް؛ ކޮންމެ އެއްޗަކީ ތިޔަ ހުންނަ ސްކެޗް، ހިސްޓްރީ ނުވަތަ އެސެމްބްލީއަށް ކަންކުރާ |
| View | {{ui:Fit}}، {{ui:Normal to}}، {{ui:Views}} (މެނޫއެއް: Measure، Mass properties، Section، Draft، Zebra، Curvature، {{ui:Base planes}}، ދެން Isometric، Front، Back، Top، Bottom، Right، Left) | ކޮންމެވެސް |

ބަޓަނެއްގެ މަތީަށް މައުސް ގެންދިޔުމުން އޭގެ ކަންތައް އަދި އޭގެ ކީ ފެންނާނެއެވެ. ރަނގަޅު ނުވާ (ހަނދާނެ ފެންނާ) ބަޓަން މިވަގުތު ބޭނުން ކުރެވޭކަށް ނޫނެވެ: މިސާލަކަށް ސްކެޗް ހުޅުވާއިރު ފީޗަރ ބަޓަންތައް، ނުވަތަ ދެ ބައި އެސެމްބްލީގައި ނުވާންދެން {{ui:Joint}}.

Edit ގުރޫޕުގެ {{ui:More}} މެނޫން ކޮންމެ އެޑިޓިންގ ކަމެއް އެކީ ކީ ދައްކައެވެ. ކޮޕީ އަދި ޕޭސްޓް ކުރާ ކަންތައް ތިޔަ ހުންނަ ތަނާ ގުޅެއެވެ؛ ބަލާ [ކޮޕީ، ޕޭސްޓް އަދި ޑުޕްލިކޭޓް](topic:copy-paste). ކުރެވިފައި ނުވާ ޑިމް ކުރެވޭ އައިޓަމެއްގެ ޓޫލްޓިޕް ކީއްވެ މިހާރު ކުރެވޭނެ ނޫން ކަމުގެ ސަބަބު ދައްކައެވެ.

{{ui:Export}} މެނޫގައި {{ui:STL, for 3D printing}}، {{ui:3MF, for 3D printing}}، {{ui:STEP AP242 (exact solid)}}، {{ui:STEP AP214 (exact solid)}}، {{ui:STEP (faceted, mesh kernel)}}، {{ui:STEP AP214 (faceted, mesh kernel)}}، {{ui:DXF of the sketch or flat face}} އަދި {{ui:Drawing (PDF): views, section, detail, GD&T}} ހުއްޓެއެވެ. ދެ އެކްސެކްޓް STEP އައިޓަމް ޑިމް ކުރެވިފައިވެއެވެ: އެއީ މި ވާރޝަނުގައި އަދިވެސް ހަދާފައި ނެތް ކަމުން، {{ui:STEP (faceted, mesh kernel)}} ބޭނުން ކުރާށެވެ.

## ހިސްޓްރީ (ކޮޅުން)

ކޮޅުގެ ޕެނަލް ބައިގެ ފީޗަރ ހިސްޓްރީ އެކެވެ، އެ ކަމަށް PartCraft މަތީން ކޮޅަށް ރީބިލްޑް ކުރެއެވެ.

- ހެޑިންގ ބައިގެ ނަމެވެ ("Part1" ތިޔަ ނަމަކަށް ބަދަލު ނުކުރާންދެން).
- **Front plane**، **Top plane** އަދި **Right plane** ފުރަތަމަ ފެންނާނެއެވެ. އެއްޗެއް ހޮވުމަށް ކްލިކް ކުރޭ؛ އެ ވިއުގައި ހައިލައިޓް ވެއެވެ.
- އެތަންތަނުގެ ދަށުން ތިޔައިން ހަދާފައިވާ ފީޗަރުތައް އެ ހަދާ ތަރުތީބުގައި ހުންނެވެ. ފީޗަރެއް ބޭނުން ކުރާ ސްކެޗެއް އެ ފީޗަރުގެ ދަށަށް އިންޑެންޓް ވެއެވެ.
- ރޯގެ ކޮޅުގައި ފްލެގެއް އެންމެ ފަހު ކޮޅުގައި ވާ ހާލަތެއް ދައްކައެވެ:

| ފްލެގް | މާނަ |
|---|---|
| (ކުނި) | ބިނާކުރެވިފައި، ސްކެޗް ފުރިހަމައަށް ހިނގައެވެ |
| − | ސްކެޗް އަޑު ކުޑަ (އަދިވެސް ހިއްލާވެވޭ) |
| + | ސްކެޗް އަޑު ގިނަ |
| ⚠ | ބިނާކުރެވިފައި، ވާރނިން ފެންނަ (ފަހަރު ފޮއިންޓް ކޮށް ކިޔަވާ) |
| ⚠ error | ފީޗަރ ފެއިލްވެއެވެ. ކީއްވެ ކަން ކިޔުމަށް ފޮއިންޓް ކުރޭ ނުވަތަ ކްލިކް ކުރޭ |
| ⚠ not built | ފީޗަރަށް ފެއިލްވި ނުވަތަ އޮފް ވި އެހެން ފީޗަރެއް ބޭނުންވެއެވެ |
| off | ފޮރުވިފައި |

- ކޮންމެ ފީޗަރެއް އޭގެ ނަމަށްފަހު އޭގެ މުހިންމު އަދަދު ދައްކައެވެ، މިސާލަކަށް Extrude އަށް "25 mm" ނުވަތަ ހިޅަކަށް "Ø6.6 thru". އަދަދު ދެފަހަރު ކްލިކް ކުރޭ، ނުވަތަ ރޯ މަތީގައި {{key:F2}} ޕްރެސް ކުރޭ އެތަނުގައި ބަދަލުކުރުމަށް. ބަލާ [ސައިޒް ބަދަލު ކުރުން](topic:change-sizes).
- ފީޗަރެއް ކްލިކް ކޮށް ކަނޑުގައި އެޑިޓް ކުރޭ. ސްކެޗެއް ދެފަހަރު ކްލިކް ކޮށް ހުޅުވާ.
- ރޯލްބެކް ކުރާއިރު، ލިސްޓުގައި **Rollback bar · roll forward** ރޯ ހުރެއެވެ. އެ ބާއަށް ތިރީގައި ހުރި ފީޗަރުތައް ގްރޭ ވެ، ބިނާކުރެވިފައި ނުވެއެވެ.
- ރޯއެއް ފޯކަސް ކޮށް ހުންނައިރު، {{key:Up}} އަދި {{key:Down}} ރޯތައް ތެރެއިން ހިއްލާކުރޭ، އަދި {{key:Alt+Up}} / {{key:Alt+Down}} ފީޗަރ އަމިއްލައަށް ހިއްލާ ކުރޭ، ހިސްޓްރީ ހުއްދަ ދޭތަން.

އެސެމްބްލީގައި އެ ޕެނަލް **Parts** (ފުރަތަމަ ކަމަށް "grounded" ކުރެވިފައި) އަދި **Joints** ދައްކައެވެ.

### ބައިގެ ޙަޤީޤަތްތައް

ހިސްޓްރީ ދަށުން، **Part** ބޮކްސުގައި ސޮލިޑުގެ **Volume**، **Surface area**، **Size (X × Y × Z)**، **Through holes**، **Bodies**، **Triangles**، ފީޗަރުތަކުގެ އަދަދު އަދި **Failing** ފީޗަރުތަކުގެ އަދަދު ލިސްޓް ކުރެއެވެ. ވޮލިއުމް އަދި ނިޔާވެ ހަދާ ފޭސްތައް، މެޝް ކާނަލުން ހަދާފައިވާ ފައިސެޓް ސޮލިޑެއްގެ ކަމަށް، ރައުންޑް ޝޭޕްތަކަށް ޙަޤީޤީ އަގުން ކުޑަ ކަމުން ([ފީޗަރުތައް އަދި އެގެ އޮޕްޝަންތައް](topic:features#curves-resolution) ބަލާ).

އެސެމްބްލީގައި ބޮކްސުގެ ހެޑިންގ **Assembly** ކަމުން: Parts، Instances، Joints، Not joined އަދި Interference.

## 3D ވިއު (މެދުގައި)

ވިއުގައި ސޮލިޑް، ބޭސް ޕްލޭންތައް އަދި ފީޗަރެއްގައި ބޭނުން ނުކުރާ ކޮންމެ ސްކެޗެއް ފެންނާނެއެވެ.

ބައި ހުސްވެފައި ހުންނައިރު ބޭސް ޕްލޭންތައް ފުރިހަމަ ގޮތުން ފެންނާނެއެވެ. ސޮލިޑެއް ލިބުމުން އެ ޕްލޭންތައް ފަހަށް ދާންދާ: ފާޅު ގޮތުން ފެންނާނެ، އެ ކުރެކެތައް ބައި ފަހަށް ފާއިތު ވެދާނެއެވެ. ސްކެޗެއް ކުރުމަށް ތަން ހޮވާއިރު (ކޮންމެ އެއްޗެއް ހޮވާ ނުލައި {{ui:Sketch}}) ނުވަތަ ހިސްޓްރީން އެކަކު ހޮވާއިރު އެ ޕްލޭންތައް ފުރިހަމަ ފެންނާނެއެވެ. {{ui:Views}} › {{ui:Base planes}} އިން އެ ޕްލޭންތައް ފުރާ ނައްޓަވައެވެ؛ ސްކެޗަކަށް ތަން ހޮވާއިރު އަދިވެސް ފެންނާނެއެވެ. PartCraft އެ ހޮވުން ހަނދާންކުރެއެވެ.

- ބައި ހިއްލާކުރުމަށް ދިޔުން، ކުރިޔަ މައުސް ނުވަތަ މެދުގެ މައުސް ހިއްލާކޮށް ޕޭން ކުރޭ، ވީލް ރޯލް ކޮށް މައުސް ފޮޒިޝަނުގައި ޒޫމް ކުރޭ. ތަފްސީލް [ކީތައް އަދި މައުސް](topic:keyboard) ގައި.
- ފޭސް، ކަނޑު ނުވަތަ ޕްލޭނެއް މަތީގައި ގެންދިޔުމުން ހައިލައިޓް ވެއެވެ. ހޮވުމަށް ކްލިކް ކުރޭ. ފޭސްތައް ފުރިހަމައަށް ހައިލައިޓް ވެ، ކަނޑުތައް އަދި ޕްލޭންތައް ފުރިހަމައަށް ހޮވެއެވެ. {{key:Shift}}+ކްލިކް ކޮށް ކަނޑު ގިނަ ނުވަތަ ފޭސްތައް ރައްކާކުރޭ. އެތަން ރަން މާކުކޮށް ހުންނެވެ.
- ވިއު ކިއުބް ކަނާތް މަތީ ކަނޑުގައި ބައި ހިއްލާ ގޮތަށް ހިއްލާ ވެއެވެ: ފޭސް، ކަނޑު ނުވަތަ ކޯނަރ ކްލިކް ކޮށް އެތަނުން ބެލޭ، ހިއްލާކުރުމަށް ދިމާ ކުރޭ، ފަރުރާ ބަޓަން ދެން ފަށަށް ދާ. ބަލާ [ވިއު ކިއުބް](topic:view-cube).
- Extrude ހޮވާއިރު އޭގެ އެންޑް ފޭސްގައި ރީ ހުންނަ ތީރެއް ފެންނާނެއެވެ، Revolve ގެ ނަމަ އޭގެ ކަރުގެ އެންޑުގައި ކަރުވެ ދާ ތީރެއެވެ: އޭގެ ބޮޑުކަމަށް ނުވަތަ ކޯނަށް ދިއުމަށް ދިމާ ކުރޭ، ނުވަތަ ތަކުރާރުކޮށް ބޮކްސައި ލިޔޭ. ބަލާ [ސައިޒް ބަދަލު ކުރުން](topic:change-sizes#drag-it-in-the-view).
- ބައި ހުސްވެފައި ހުންނައިރު، **Start a part** ނަމުގެ ބޮކްސުން ފުރަތަމަ ކަންތައްތައް ފެންނާނެއެވެ.
- `.partcraft.json` ނުވަތަ `.partcraft-asm.json` ފައިލެއް ވިއު މަތީގައި ޑްރޮޕް ކޮށް ހުޅުވާ. `.step`، `.stp`، `.stl`، `.obj`، `.3mf` ނުވަތަ `.3dm` ފައިލެއް އެތަނަށް ޑްރޮޕް ކުރެއްވިއިރު ސޮލިޑް ބޮޑީއެއްގެ ގޮތުން ހުޅުވޭ.

### ކަނޑު ނުވަތަ ފޭސް ހޮވާއިރު

{{ui:Fillet}}، {{ui:Chamfer}} ނުވަތަ {{ui:Shell}} ކަމަށް އެއްވެސް ކަމެއް ހޮވާ ނުލައި (ނުވަތަ އެ ފީޗަރަށް {{ui:Pick edges}}), ބައި ކުރިން ފެންނަ ގޮތް ފެންނާނެއެވެ. ކަނޑުތައް ނުވަތަ ފޭސްތައް ކްލިކް ކޮށް އިތުރުކުރޭ ނުވަތަ ފޮހެލާ ކުރޭ؛ އެތަންތަނުގެ މާކުތައް ވަނީ ކޮންތަ ހޮވިފައިވާ ކަން ދައްކައެވެ. {{ui:Done}} ނުވަތަ {{key:Esc}} ފުރިހަމަ ކުރޭ. ބަލާ [ރައުންޑް، ބެވެލް އަދި ހޯލޯ](topic:fillet-chamfer-shell).

### ޑްރޯއިންގ ޝީޓުގައި

{{ui:Drawing}} 3D ވިއު ބަދަލުކޮށް A3 ޑްރޯއިންގ ޝީޓް ހުޅުވައެވެ. ވީލް ޒޫމް ކުރޭ، ރައިޓް ނުވަތަ މެދުގެ ޑްރެގް ޕޭން ކުރޭ، {{key:F}} ފިޓް ކުރޭ. ބަލާ [ޑްރޯއިންގެއް ހަދާ](topic:drawing-pdf).

### ސްކެޗެއް ހުޅުވާއިރު

ވިއު ސްކެޗް ޕްލޭނަށް ސީދާ ބެލިގެން، 2D ސްކެޗް ލޭޔަރެއް މަތީގައި ފެންނާނެއެވެ. ބައި ފެންނާނީ ސްކެޗް ފަށަން ކުރިން ހަދާފައިވާ ފީޗަރުތައް ބަހައް. މަތީ ކަނާތުގައި ސްކެޗްގެ ސްޓޭޓް ޗިޕް ("Fully defined", "Under defined · 3 degrees of freedom" ފަދަ) އަދި ނަން ("Sketch2 on a face of Extrude1" ފަދަ) ފެންނާނެއެވެ.

## ޕްރޮޕަޓީސް ޕެނަލް (ކަނާތް ފަރާތުގައި)

ޕެނަލް ހޮވާ އެއްޗާ މުޅިން ދައްކައި، ހެޑިންގ އެ ނަން ދައްކައެވެ:

- **Part** (އެއްޗެއް ހޮވައެއް ނުވާއިރު): ބައިގެ **Name** އަދި **Curves** ސެޓިންގް.
- ޕްލޭނެއް: {{ui:Sketch on it}} ބަޓަން.
- **Face**: އޭގެ ބާވަތް (Flat face، Cylinder އޭގެ ރޭޑިއަސް އަދި އެކްސިސްއާއެކު، Cone، Sphere ނުވަތަ Torus)، އޭގެ ފޮތް، އެ ފޭސް ހަދާ ފީޗަރ، އަދި ފްލެޓް ފޭސަކަށް {{ui:Sketch on this face}}، {{ui:Normal to}}، {{ui:Export face as DXF}}، {{ui:Extrude from it}}، {{ui:Cut into it}} އަދި {{ui:Hole here}} (ބަލާ [ފޭސް ފުރިހަމައަށް ފުރާ ނުވަތަ ދަތުރު ކުރުން](topic:extrude-and-cut#pull-or-push-a-whole-face)).
- **Edge**: އޭގެ ބާވަތް (ސްޓްރެއިޓް، ސެންޓަރާއި ރޭޑިއަސް ހިމެނޭ ވަށެއް ނުވަތަ ކާރވް)، އޭގެ ދިގުކަން، އަދި އޭގެ ދެ ފޭސްތަކާ ދެމެދު (މިސާލަކަށް "Extrude1 end face and Extrude1 side") އަދި {{ui:Fillet}} އަދި {{ui:Chamfer}} ބަޓަންތައް.
- {{key:Shift}} އިން ކަނޑު ނުވަތަ ފޭސް ގިނަ ހޮވާފައި: އެކަންކަން ކިތައް ހުރިކަން، ކަނޑުތަކަށް {{ui:Fillet}} އަދި {{ui:Chamfer}} އަދި {{ui:Clear}}.
- ފީޗަރެއް: އޭގެ ނަންބަރުތަކާއި އޮޕްޝަންތައް، އޭގެ ސްކެޗުގެ ޑައިމެންޝަންތައް، ދެން {{ui:Suppress}}، {{ui:Roll back to here}}، {{ui:Move up}}، {{ui:Move down}}، {{ui:Delete}} އަދި އޭގެ **Name**.
- ހުޅުވާފައިވާ ސްކެޗެއް: އޭގެ ސްޓޭޓް، ހޮވާ އެއްޗަށް ދިނުމަށް ހުރި ރިލޭޝަންތައް، ރިލޭޝަންތަކާއި ޑައިމެންޝަންތަކުގެ ލިސްޓް، **Add by coordinates**، އަދި {{ui:Exit sketch}}، {{ui:Fit}} އަދި {{ui:Export as DXF}}.
- ޑްރޯއިންގ ޝީޓުގައި: ސެކްޝަން އަދި ޑީޓެއިލް ސެޓިންގްސް، ނުވަތަ ހޮވާ GD&T ސިމްބަލް.
- އެސެމްބްލީގައި: އެސެމްބްލީ، ހޮވާ ބައި، ނުވަތަ ހޮވާ ޖޮއިންޓް.

ކޮންމެ ނަންބަރު ބޮކްސް ނިންމާލާފައި {{key:Enter}} ނުވަތަ {{key:Tab}} ޕްރެސް ކުރުމުން، ނުވަތަ އެތަނުން ކްލިކް ކުރުމުން އަސަރު ކުރެއެވެ. ބައި އެވަގުތު ރީބިލްޑް ކުރެއެވެ؛ އޯކޭ ބަޓަނެއް ނެތެވެ. ފަހަތަށް ދިއުމަށް {{key:Mod+Z}} ބޭނުން ކުރޭ.

## ސްޓޭޓަސް ބާ (ތިރީގައި)

- ކޮޅުން، ސްކެޗް ހުޅުވާފައި ހުންނަ ވަގުތު ހަމައެކަނި، ސްކެޗުގައި ކޯޑިނޭޓްސް.
- މެދުގައި މެސެޖްތައް: ކަން ކުރަން ޖެހޭ އެއްޗަކާއި، ކީއްވެ އެއްޗަކަށް ހުއްދަ ނުދެވޭ ކަން. އެއްވެސް ކަމެއް ނުދިމާވާއިރު ކިޔަވާ.
- ކަނާތް ފަރާތަށް ކައިރީ: ކާނަލް ޗިޕް، މި ވާރޝަނުގައި ނުކުތާ "Mesh kernel" ކަމުން. އެ ކަމުގެ މާނަ ކިޔުމަށް ފޮއިންޓް ކުރޭ. ބަލާ [މެޝް ކާނަލް](topic:solid-kernels).
- ކަނާތް ފަރާތުގައި: ޗިޕެއް، ބައި ރީބިލްޑް ވާއިރު "Rebuilding…"، ފަހުން ހުރިހާ ރަނގަޅު ނަމަ "Rebuilt in … ms"، ނުވަތަ "1 feature failing". އެސެމްބްލީގައި "Placed in … ms" ނުވަތަ ޖޮއިންޓް މައްސަލަތައް ގުނާ.

ފުރަތަމަ ކަމެއް ހަދަން [Illustrate ގައި ފެށޭ](topic:illustrate) ބަލާ: ތިޔަ ބައިތަކާއި އެސެމްބްލީތަކުން އެސެމްބްލީ މެނުއަލް ހަދާ ވޯކްސްޕޭސް.

## ފަސް ސްކްރީނުގައި

760 ޕިކްސެލް އަށް ފުނި ފަހަރު، ފޯނެއްގައި ފަދައިން، ވިއު ސްކްރީން ހިފާ ގެންދެއެވެ: ޓޫލްބާ އެއް ރޯ ކަމުގައި ކަނާތަށް ސްކްރޯލް ވެ، ޕެނަލްތައް ކޮޅުން ބާއިން ޝީޓްތަކެއް ކަމުގައި ހުޅުވެއެވެ. {{ui:Tools}} ޓޫލްބާ ފޮރުވާ، {{ui:Move}} އެ ދަށަށް ލަވައިދެއެވެ. ބަލާ [ޓްރެކްޕެޑް، ޓަޗް އަދި ކުޑަ ސްކްރީން](topic:trackpad-and-touch).
