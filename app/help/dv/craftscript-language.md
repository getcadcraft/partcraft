CraftScript އަކީ MATLAB ފަދަ ކިޔެވޭގޮތަށް ލިޔެވިފައިވާ މެޓްރިކްސް ބަހެކެވެ، އެހެންކަމުން ކްލާސިކް ނަމްބަރިކަލް ކޯޑުތަކުގެ އިތުރުން އަނެއް ކޮންމެ ކޯޑެއް (މިސާލަކަށް 88 ލައިނުގެ ޓޮޕޮލޮޖީ އޮޕްޓިމައިޒޭޝަން ކޯޑު) ކުޑަ ބަދަލުތަކާއެކު ހިންގެއެވެ. އެ ހިންގަނީ [ސްކްރިޕްޓް ވޯކްސްޕޭސްގައި](topic:craftscript) އަދި ކޮމާންޑް ލައިނުންނެވެ.

## އަގުތައް

| ޓައިޕް | މިސާލު | ނޯޓުތައް |
|---|---|---|
| ނަންބަރު، އެރޭ | `a = 3`، `v = [1 2 3]`، `A = [1 2; 3 4]` | ކޮންމެ ނަންބަރެއްވެސް އެރޭއެކެވެ (1×1 އެއް). އެރޭތައް ސްޓޯރުކުރެވެނީ ކޮލަމް ކޮލަމުންނެވެ، 8 ޑައިމެންޝަން އަށް ހަމައަށެވެ |
| ލޮޖިކަލް | `A > 2`، `true` | true/false އެރޭތައް؛ އިންޑެކްސްއެއް ގޮތުގައި ބޭނުންކުރެވޭ |
| ޓެކްސްޓް | `'beam'`، `"beam"` | |
| ސްޕާސް މެޓްރިކްސް | `sparse(i, j, v, n, n)` | ސްޓިފްނެސް މެޓްރިކްސަށް |
| މެޝް، ފީލްޑް، މޮޑެލް | `hexGrid(…)`، `part()`، `load('part.stl')` | `show` ގެ ދަށުން ހަދާ ކަންތައް |
| ސްޓްރަކްޓް | `s.E = 210e3` | ނަމަވެރި ފީލްޑްތައް |
| ސެލް | `c = {1, 'two', [3 4]}` | ކޮންމެ އަގެއްގެ ލިސްޓެއް |
| ފަންކްޝަން ހެންޑަލް | `f = @(x) x.^2` | |

## އެރޭތަކާއި އިންޑެކްސިން

- ރޭންޖްތައް: `1:5`، `0:0.1:1`. `linspace(a, b, n)`، `zeros(n, m)`، `ones`، `eye`، `rand`.
- އިންޑެކްސިން ފެށެނީ 1 އިންނެވެ: `A(2, 3)`، `v(end)`، `A(:, 1)` (ކޮލަމެއް ހުރިހާ)، `A(:)` (ހުރިހާ އެއްޗެއް ކޮލަމެއްގެ ގޮތުގައި)، `v(v > 0)` (ލޮޖިކަލް އިންޑެކްސިން).
- ނިމުމުން ބޭރަށް އެއްކުރުމުން އެރޭ ބޮޑުވެއެވެ، MATLAB ފަދައިން: `v(10) = 1`.

## އޮޕަރޭޓަރުތައް

- `+ - * / \ ^` އަކީ މެޓްރިކްސް އޮޕަރޭޝަންތެކެވެ (`A \ b` ހައްލުކުރެވެއެވެ); `.* ./ .^` ދެނީ އެއް އެއްގޮތެއް އެއްކޮށްގެންނެވެ. `'` ޓްރާންސްޕޯސް ކުރެއެވެ.
- ކޮމްޕެރިސަންތައް `== ~= < <= > >=`; ލޮޖިކް `& | ~` (އެއް އެއްގޮތަށް) އަދި `&& ||` (ކޮޕް ސާކިޓް).

## ކޮންޓްރޯލް ފްލޯ އަދި ފަންކްޝަންތައް

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ފަންކްޝަންތައް ހުންނާނީ ސްކްރިޕްޓެއްގެ ކޮމާންޑްތަކަށްފަހުގައި، ނުވަތަ އެ ފަންކްޝަނުގެ ނަމުން ނަމަވެރި ސްކްރިޕްޓް ޓެބެއްގައެވެ:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ނަމެއް ހޯދާނީ މި ތަރުތީބުން: ވޭރިއެބަލެއް، މި ޕާޓުގައި ނަމުގެ ސްކްރިޕްޓެއް، ލައިބްރަރީ ފަންކްޝަނެއް، ފަހުން ބިލްޓް އިން ފަންކްޝަނެއް.

## އީކޯ، ކޮމެންޓް، އައުޓްޕުޓް

- `;` ނެތް ސްޓޭޓްމަންޓެއް އޭގެ އަގު ޕްރިންޓްކުރެއެވެ؛ `;` ޖެހިފައިވާއިރު ހިއްކެވެ.
- `%` ކޮމެންޓް ފެށެއެވެ؛ ވަކި ލައިންތަކުގައި `%{` އަދި `%}` ލިޔުމުން އެކިއެކި ލައިންތައް ކޮމެންޓް ކުރެއެވެ.
- `disp(x)`، `fprintf('%g\n', x)` އަދި `display(x)` ކޮންސޯލަށް ޕްރިންޓްކުރެއެވެ.

## އެރަރ އަދި ސީމާތައް

- އެރަރތައް ދައްކާނީ ކޮންމެހެން ކަމެއް ކީކޭ ހެއްޔެވެ، ރަނގަޅު ބަހުން، އަދި ލައިން ނަންބަރު (އަދި ފަންކްޝަން ކޯލްތަކުގެ ސިލްސިލާ) ދައްކާއެވެ.
- ކޮންމެ ރަނެއްގެ ސްޓެޕް ބަޖެޓެއް ވެއެވެ (ރަން އޮޕްޝަންސް ޕެނަލުގައި)؛ ނޮޅޭ ލޫޕެއް މެސެޖެއް އަކަށް ފަހު ނިމެއެވެ، ނުވަތަ ހަމަކުރޭ ފިތާލާ.
- އެރޭތައް ހިފާނީ ކޮންމެއަކަށް 134 މިލިއަން އަގު އަށް ހަމައަށެވެ.

## MATLAB ފަދަ ނޫން

- ޕްލޯޓް ކޮމާންޑްތައް އެމީހުންގެ އޮޕްޝަންތައް ކޯލްގެ ތެރޭގައި ދޭއެވެ: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`، `hold`، `axis`، `title(…)` އަދި އެފަދަ ކަންތައް ޤަބޫލުކުރެއެވެ، އެކަމެއް ނުކުރެއެވެ.
- `input` އަދި `keyboard` ސަޕޯޓް ނުކުރެއެވެ: ސްކްރިޕްޓަކަށް ސުވާލެއް އަހުލުވުމަށް ހިނދެއް ނުހިއްކެވެ.
- ޓޫލްބޮކްސް ނެތެވެ؛ [އެނަލިސިސް ލައިބްރަރީ](topic:craftscript-library) އަދި ބިލްޓް އިން ފަންކްޝަންތަކަކީ ލިބޭ އެއްޗެހިއެވެ.
