ឧបករណ៍វិស្វកម្ម (ឧបករណ៍បង្កើត បណ្ណាល័យវិស្វកម្ម ការត្រួតពិនិត្យ និងឯកសារទិន្នន័យ) **មិនត្រូវការសិទ្ធិអ្នកគ្រប់គ្រង** ហើយ**មិនត្រូវការកម្មវិធីដំឡើង**ទេ។ ពួកវាសរសេរតែអ្វីដែលបានរាយក្នុងនេះប៉ុណ្ណោះ ហើយគ្មានអ្វីផ្សេងទៀតទេ។

| អ្វី | កន្លែងដែលវាត្រូវបានរក្សាទុក |
|---|---|
| ផ្នែករបស់អ្នក ជាមួយតួដែលបានបង្កើត សន្លឹកទិន្នន័យ និងការត្រួតពិនិត្យ | ឯកសារផ្នែកដែលអ្នករក្សាទុក (`.partcraft.json`) នៅកន្លែងដែលអ្នករក្សាទុកវា។ |
| ឧបករណ៍បង្កើតដែលអ្នកបានបើកពីឯកសារ | នៅក្នុងទំហំផ្ទុករបស់កម្មវិធីខ្លួនឯង៖ ទំហំផ្ទុកក្នុងកម្មវិធីរុករកសម្រាប់ទំព័រវែបសាយ និងថត `data` ក្បែរកម្មវិធីក្នុង Studio ចល័ត។ យ៉ាងច្រើន 20។ |
| ការកំណត់ (ទំហំវ៉ុកសែលដែលអ្នកកំណត់ ចំនួនខ្សែដំណោះស្រាយ ប្លង់) | ទំហំផ្ទុកកម្មវិធីដដែល។ |

ឧបករណ៍ទាំងនេះ**មិនធ្វើការហៅបណ្តាញផ្ទាល់ខ្លួនទេ**៖ ឧបករណ៍បង្កើតដែលមកជាមួយគឺជាឯកសារនៅក្នុងថតរបស់កម្មវិធីខ្លួនឯង ហើយបណ្ណាល័យ និងការត្រួតពិនិត្យដំណើរការនៅលើកុំព្យូទ័ររបស់អ្នក ក្នុងកម្មវិធីរង (worker) ដែលមិនអាចចូលបណ្តាញបាន។ ទិន្នន័យវិស្វកម្ម (លក្ខណៈទឹក និងខ្យល់ សម្ភារៈ) មាននៅក្នុងកម្មវិធី។ ឧបករណ៍បង្កើតដែលអ្នកបើកពីឯកសារត្រូវបានអាននៅលើកុំព្យូទ័ររបស់អ្នក ហើយមិនបញ្ជូនទៅណាឡើយ។

## ទម្រង់ Windows ចល័ត និង Linux

Studio ចល័តសម្រាប់ Windows រក្សាការកំណត់ ឃ្លាំងបណ្តោះអាសន្ន និងផ្នែកបន្ថែមក្នុងថត `data` ក្បែរកម្មវិធី។ AppImage របស់ Linux រក្សាទុកវាក្បែរខ្លួនវា នៅពេលមានឯកសារឈ្មោះ `portable` នៅក្បែរវា; បើគ្មានឯកសារនោះ វាប្រើថតផ្ទះរបស់អ្នក។ គ្មានទម្រង់ចល័តសម្រាប់ Mac ទេ៖ ប្រព័ន្ធរក្សាកម្មវិធីដែលបានទាញយកមិនឱ្យសរសេរនៅក្បែរខ្លួនវា។ កំណត់ចំណាំចល័តរបស់សែលកម្មវិធីខ្លួនឯង (ជំនួយ `Studio`) រាយអ្វីដែលកម្មវិធីសរសេរ។

## ការចូលប្រើម៉ាស៊ីន

គ្មានអ្វីនៅទីនេះសុំការចូលប្រើម៉ាស៊ីនទេ។ ម៉ាស៊ីនបោះពុម្ព ម៉ាស៊ីន serial និងឧបករណ៍ USB ស្ថិតក្រៅពីនេះ៖ ពួកវាសួរនៅពេលការងារត្រូវការ ម្តងសម្រាប់ឧបករណ៍នីមួយៗ ហើយគ្មានអ្វីក្នុងឧបករណ៍បង្កើត ឬការត្រួតពិនិត្យប៉ះពាល់ពួកវាឡើយ។
