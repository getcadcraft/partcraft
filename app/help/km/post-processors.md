## Post មើលទៅដូចម្ដេច

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

បន្ទាត់ដែលចាប់ផ្ដើមដោយ `//` និងបន្ទាត់ទទេត្រូវបានមិនអើពើ។ នៅខាងលើគឺការកំណត់; បន្ទាប់មកមានប្លុក `on <event>` មួយសម្រាប់ព្រឹត្តិការណ៍នីមួយៗ បិទដោយ `end`។ ព្រឹត្តិការណ៍ដែលអ្នកទុកចោលមិនសរសេរអ្វីឡើយ។

| ការកំណត់ | អត្ថន័យ |
|---|---|
| `post <id>` | លេខសម្គាល់របស់ post៖ អក្សរ លេខ `-` និង `_` |
| `name <text>` | អ្វីដែលបញ្ជីឧបករណ៍គ្រប់គ្រងបង្ហាញ |
| `extension <ext>` | ផ្នែកបន្ថែមឯកសារ៖ nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … នៅលើគ្រប់បន្ទាត់ `emit` ឬគ្មានទេ |
| `decimal-point yes` / `no` | `10.` ជំនួស `10` (មតិយោបល់មិនដែលមានចុច) |
| `canned-cycles yes` / `no` | `no`៖ រន្ធត្រូវបានសរសេរជាចលនា G0/G1 ដែលវាតំណាង |
| `modal <group> <words>` | ពាក្យនៃក្រុម (`modal motion G0 G1 G2 G3`) ដែលត្រូវបានសរសេរតែនៅពេលវាផ្លាស់ប្ដូរ |

## ព្រឹត្តិការណ៍

ពួកវារត់តាមលំដាប់នេះសម្រាប់កម្មវិធីមួយ៖ `start`; បន្ទាប់មកសម្រាប់ប្រតិបត្តិការនីមួយៗ `operation`, `tool-change` (នៅពេលឧបករណ៍ផ្លាស់ប្ដូរ), `spindle` (នៅពេលល្បឿនផ្លាស់ប្ដូរ), `approach` (ចលនាឡើងទៅចំណុចដំបូង មុនការ rapid ដំបូង), `coolant-on`, បន្ទាប់មកចលនារបស់វាជា `rapid`, `feed` និង `arc`, ហើយវដ្តកំណត់នីមួយៗជា `cycle-start`, `cycle-hole` មួយសម្រាប់រន្ធនីមួយៗ និង `cycle-end`; ទីបញ្ចប់ `end`។

ព្រឹត្តិការណ៍នីមួយៗអាចប្រើអថេរនៃប្រភេទចលនារបស់វា សរសេរជា `{name}`៖ កម្មវិធី (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), វត្ថុធាតុដើម (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), ឧបករណ៍ (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ប្រតិបត្តិការ (`op.name`, `op.type`), `rpm`, ចំណុចនៃចលនា (`x`, `y`, `z`, `f`, និង `moved`៖ true នៅពេលអ័ក្សណាមួយផ្លាស់ប្ដូរ), អំបោះ (`arc.g` 2 ឬ 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) និងរន្ធ (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`)។ បញ្ជី **ព្រឹត្តិការណ៍និងអថេរ** របស់កម្មវិធីកែសម្រួលបង្ហាញថាព្រឹត្តិការណ៍ណាមួយមើលឃើញអ្វី។ ស្ថានភាពដែលអ្នកអាចអាននិងកំណត់៖ `cool`, `offset`, និង `at.x`, `at.y`, `at.z`, `at.f` (តម្លៃចុងក្រោយដែលបានសរសេរ)។

## សេចក្ដីថ្លែងការណ៍

| សេចក្ដីថ្លែងការណ៍ | វាធ្វើអ្វី |
|---|---|
| `raw TEXT` | បន្ទាត់ដែលបានវាយបញ្ចូលដូចដែលវាជា (គ្មានលេខបន្ទាត់) |
| `comment TEXT` | `(TEXT)` ដោយយកតួអក្សរដែលមិនមែន ASCII និងវង់ក្រចកចេញ |
| `emit WORD WORD …` | បន្ទាត់នៃពាក្យ; ពាក្យដែលទទេត្រូវបានលុបចេញ; គ្មានពាក្យ គ្មានបន្ទាត់ |
| `word WORD …` | បន្ថែមពាក្យទៅបន្ទាត់ដែលកំពុងសាងសង់; `emit` ទទេបញ្ចប់វា |
| `if EXPR` … `else` … `end` | លក្ខខណ្ឌ៖ `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a ឬ b បើ a ទទេ) |
| `for tool in tools` … `end` | ម្ដងសម្រាប់ឧបករណ៍នីមួយៗដែលកម្មវិធីប្រើ |
| `set NAME EXPR` | ចងចាំតម្លៃមួយ (`set offset tool.number`) |
| `reset NAME …` | បំភ្លេចពាក្យ modal (ក្រុម, អក្សរអាស័យដ្ឋានដូចជា `Z`, ឬ `at.z`) |
| `do rapid X Y Z` | ដំណើរការព្រឹត្តិការណ៍ `rapid` សម្រាប់ចំណុចមួយ |

ពាក្យគឺជាអត្ថបទដែលបានវាយបញ្ចូលជាមួយ​ប្រហោង `{variable|filter}`។ តម្រង (filter) គឺ `upper`, `lower`, `pad:N` (បំពេញដោយសូន្យ), `cut:N` (N តួអក្សរដំបូង), `safe` (ASCII ដែលមានសុវត្ថិភាពក្នុងមតិយោបល់) និង `int`។ ពាក្យដែលបញ្ចប់ដោយ `~` គឺ **modal**៖ វាត្រូវបានសរសេរតែនៅពេលវាខុសពីអ្វីដែលបានសរសេរចុងក្រោយ (`G1~`, `X{x}~`)។ ពាក្យដែលបញ្ចប់ដោយ `~!` ត្រូវបានសរសេរគ្រប់ពេល ហើយនៅតែចងចាំ។ ឈ្មោះដែលមិនមែនជាអថេរគឺជាអត្ថបទធម្មតា (`G81`, `mist`)។ លេខត្រូវបានបង្គត់ទៅ 0.001 mm ហើយសរសេរដោយគ្មានសូន្យចុងក្រោយ។
