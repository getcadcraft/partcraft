ផ្លូវឧបករណ៍តែមួយត្រូវសរសេរខុសគ្នាសម្រាប់ការគ្រប់គ្រងផ្សេងៗ៖ លេខបន្ទាត់ ឬគ្មាន `M6` ឬការផ្អាក `G28` ឬ `G53` `M30` ឬ `M2`។ **post** គឺជាអត្ថបទខ្លីដែលនិយាយថាធ្វើដូចម្ដេច។ post ភ្ជាប់មកបីរបស់ PartCraft (Fanuc-style, GRBL និង LinuxCNC) ត្រូវបានសរសេរជាទម្រង់នេះ ដូច្នេះ post ផ្ទាល់ខ្លួនអាចចាប់ផ្ដើមជាច្បាប់ចម្លងនៃមួយក្នុងចំណោមវា។

សូមពិនិត្យលទ្ធផលក្នុងឧបករណ៍ក្លែងធ្វើរបស់ម៉ាស៊ីនអ្នកមុនពេលកាត់ ហើយដំណើរការវានៅលើអាកាសខាងលើដុំវត្ថុជាមុនសិន។ post ភ្ជាប់មកសរសេរប្រតិបត្តិការដូចដែលវាបានសរសេរមុនទម្រង់នេះមានឡើង (ការសាកល្បងប្រៀបធៀបលទ្ធផលរបស់វាតាមបៃលើកម្មវិធីរាប់រយ) ប៉ុន្តែគ្មានអ្វីនៅទីនេះត្រូវបានបញ្ជាក់លើម៉ាស៊ីនរបស់អ្នកទេ ហើយ post ដែលអ្នកផ្លាស់ប្ដូរគឺជារបស់អ្នក ហើយអ្នកត្រូវបញ្ជាក់វា។

## បង្កើតមួយ

នៅ **ការផលិត** នៅក្រោម **Post**:

- {{ui:Edit post…}} នៅលើការគ្រប់គ្រងភ្ជាប់មកបើក**ច្បាប់ចម្លងរបស់អ្នក** របស់វា។ នៅលើ post ផ្ទាល់ខ្លួនរបស់អ្នក វាបើក post នោះ។
- {{ui:New post…}} ចាប់ផ្ដើមពី post ទទេខ្នាតតូចដែលមានគ្រប់ event។
- {{ui:Import post file…}} អានឯកសារអត្ថបទ `.cpost` (ឯកសារដែលអ្នកទទួលពី **Save as a file…** ក្នុងកម្មវិធីកែ)។

កម្មវិធីកែបង្ហាញអត្ថបទ បន្ទាត់ដែលប្រាប់ថាវាអាចអាន (និងបន្ទាត់ណាខុស) និង G-code ដែល post សរសេរ ពេលអ្នកវាយ។ **Preview with** ជ្រើសកម្មវិធីគំរូតូចដែលដំណើរការគ្រប់ event ឬកម្មវិធីរបស់ផ្នែកនេះ។ {{ui:Save}} រក្សា post ក្នុងឯកសារផ្នែក (រហូតដល់ 20 post) ហើយជ្រើសវាជាការគ្រប់គ្រង។ Post ធ្វើដំណើរជាមួយផ្នែក; ដើម្បីប្រើវានៅផ្នែកផ្សេង សូមរក្សាទុកវាជាឯកសារ ហើយនាំចូលទៅទីនោះ។

## Post មើលទៅដូចម្ដេច

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

បន្ទាត់ដែលចាប់ផ្ដើមដោយ `//` និងបន្ទាត់ទទេត្រូវបានមិនអើ។ នៅកំពូលគឺការកំណត់; បន្ទាប់មកប្លុក `on <event>` មួយសម្រាប់ event នីមួយៗ បិទដោយ `end`។ event ដែលអ្នកទុកចោលមិនសរសេរអ្វីទេ។

| ការកំណត់ | អត្ថន័យ |
|---|---|
| `post <id>` | id របស់ post៖ អក្សរ លេខ `-` និង `_` |
| `name <text>` | អ្វីដែលបញ្ជីការគ្រប់គ្រងបង្ហាញ |
| `extension <ext>` | ផ្នែកបន្ថែមឯកសារ៖ nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … នៅលើគ្រប់បន្ទាត់ `emit` ឬគ្មាន |
| `decimal-point yes` / `no` | `10.` ជាជាង `10` (មតិយោបល់មិនដែលមានចំណុចទសភាគទេ) |
| `canned-cycles yes` / `no` | `no`៖ រន្ធត្រូវបានសរសេរជាចលនា G0/G1 ដែលវាតំណាងឲ្យ |
| `modal <group> <words>` | ពាក្យនៃក្រុម (`modal motion G0 G1 G2 G3`) ដែលត្រូវបានសរសេរតែនៅពេលវាផ្លាស់ប្ដូរ |

## Events

ពួកវាដំណើរការតាមលំដាប់នេះសម្រាប់កម្មវិធីមួយ៖ `start`; បន្ទាប់មកសម្រាប់ប្រតិបត្តិការនីមួយៗ `operation`, `tool-change` (នៅពេលឧបករណ៍ផ្លាស់ប្ដូរ), `spindle` (នៅពេលល្បឿនផ្លាស់ប្ដូរ), `approach` (ចលនាឡើងទៅចំណុចដំបូង មុនលឿនដំបូង), `coolant-on`, បន្ទាប់មកចលនារបស់វាជា `rapid`, `feed` និង `arc`, ហើយវដ្តថេរនីមួយៗជា `cycle-start`, `cycle-hole` មួយសម្រាប់រន្ធនីមួយៗ និង `cycle-end`; ទីបញ្ចប់ `end`។

ទៀតសម្រាប់អ្វីដែលលើសបីអ័ក្ស (post ដែលគ្មាន event បដិសេធកម្មវិធីបែបនេះ ហើយដាក់ឈ្មោះ event ដែលវាខ្វះ)៖

| Event | ពេលណា | អថេររបស់វា |
|---|---|---|
| `index` | មុនប្រតិបត្តិការដែលទិសឧបករណ៍ខុសពីមុន និងមុនប្រតិបត្តិការដំបូងនៅលើម៉ាស៊ីនដែលមានអ័ក្សបង្វិល | `rot.a`, `rot.b`, `rot.c` (ទីតាំងដែលត្រូវទៅ; ទទេសម្រាប់អ័ក្សដែលម៉ាស៊ីនមិនមាន), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | ចលនារបស់ប្រតិបត្តិការដែលអ័ក្សបង្វិលផ្លាស់ទីខណៈពេលកាត់ | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (yes នៅពេលការចង្អុលត្រូវតែជាពេលបញ្ច្រាស), `invf` (1/នាទី) |
| `rotary-end` | បន្ទាប់ពីប្រតិបត្តិការបែបនេះ | |
| `probe-move` | ចលនាដែលឈប់នៅពេលប្រូបប៉ះ | `x`, `y`, `z`, `f`, `probe.n` (1 ដល់ 4), `probe.axis` (x, y ឬ z), `probe.k` (1, 2 ឬ 3) |
| `probe-set` | បន្ទាប់ពីការប៉ះនៃវដ្តប្រូបមួយ | `probe.kind` (`"z"`, `"x"`, `"y"` ឬ `centre`), `probe.action` (`set` ឬ `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | ចលនាកាត់ខ្សែនៅឡាត | `x`, `z`, `thread.lead` |

ក៏សម្រាប់ event ទាំងអស់៖ `kin` (none, a, b, ac, bc), `rotary` និង `tcp` (yes ឬ no, ពីម៉ាស៊ីននៅ Setup), `pivot.x`, `pivot.y`, `pivot.z`, `op.tilt` និង `op.turn` របស់ប្រតិបត្តិការ, និងនៅឡាត `spin.mode` (css ឬ rpm), `spin.css`, `spin.max` និង `tool.nose`។ ពាក្យអក្សរដែលតម្លៃរបស់វាទទេ ដូចជា `A{rot.a}` នៅលើម៉ាស៊ីនដែលគ្មានអ័ក្ស A ត្រូវបានដកចេញពីបន្ទាត់។ ប្រៀបធៀប x, y និង z ជាអត្ថបទក្នុងសញ្ញាដកស្រង់ (`if probe.kind == "z"`): ដោយគ្មានសញ្ញា ពួកវាជាកូអរដោនេនៃចលនា។

បន្ទាត់ពីរបន្ថែមនៅកំពូលនៃ post ធ្វើឲ្យវាក្លាយជា post ឡាត៖ `machine lathe` (វាសរសេរតែ X និង Z ហើយបដិសេធផ្លូវកិនដូចដែល post កិនបដិសេធផ្លូវ turning) និង `lathe-x diameter` ឬ `lathe-x radius`។

រាល់ event អាចប្រើអថេរនៃប្រភេទចលនារបស់វា ដែលសរសេរជា `{name}`៖ កម្មវិធី (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), ដុំវត្ថុ (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), ឧបករណ៍ (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ប្រតិបត្តិការ (`op.name`, `op.type`), `rpm`, ចំណុចនៃចលនា (`x`, `y`, `z`, `f`, និង `moved`៖ true នៅពេលអ័ក្សមួយផ្លាស់ប្ដូរ), ធ្នូ (`arc.g` 2 ឬ 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) និងរន្ធ (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`)។ បញ្ជី **Events and variables** របស់កម្មវិធីកែបង្ហាញថា event ណាមើលឃើញអ្វី។ ស្ថានភាពដែលអ្នកអាចអាន និងកំណត់៖ `cool`, `offset`, និង `at.x`, `at.y`, `at.z`, `at.f` (តម្លៃដែលបានសរសេរចុងក្រោយ)។

## សេចក្ដីថ្លែងការណ៍

| សេចក្ដីថ្លែងការណ៍ | អ្វីដែលវាធ្វើ |
|---|---|
| `raw TEXT` | បន្ទាត់ដូចដែលបានវាយ (គ្មានលេខបន្ទាត់) |
| `comment TEXT` | `(TEXT)` ដែលបានយកអក្សរមិនមែន ASCII និងវង់ក្រចកចេញ |
| `emit WORD WORD …` | បន្ទាត់នៃពាក្យ; ពាក្យដែលទទេត្រូវបានដកចេញ; គ្មានពាក្យ គ្មានបន្ទាត់ |
| `word WORD …` | បន្ថែមពាក្យទៅបន្ទាត់ដែលកំពុងសាងសង់; `emit` ទទេបញ្ចប់វា |
| `if EXPR` … `else` … `end` | លក្ខខណ្ឌ៖ `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a ប្រសិនបើមាន បើមិនដូច្នេះ b) |
| `for tool in tools` … `end` | ម្ដងសម្រាប់ឧបករណ៍នីមួយៗដែលកម្មវិធីប្រើ |
| `set NAME EXPR` | ចងចាំតម្លៃ (`set offset tool.number`) |
| `reset NAME …` | ភ្លេចពាក្យ modal (ក្រុម អក្សរអាសយដ្ឋានដូចជា `Z` ឬ `at.z`) |
| `do rapid X Y Z` | ដំណើរការ event `rapid` សម្រាប់ចំណុចមួយ |

ពាក្យគឺជាអត្ថបទដែលបានវាយជាមួយចន្លោះ `{variable|filter}`។ តម្រង់គឺ `upper`, `lower`, `pad:N` (បំពេញសូន្យ), `cut:N` (N តួអក្សរដំបូង), `safe` (ASCII ដែលមានសុវត្ថិភាពសម្រាប់មតិយោបល់) និង `int`។ ពាក្យដែលបញ្ចប់ដោយ `~` គឺ**modal**៖ វាត្រូវបានសរសេរតែនៅពេលវាខុសពីអ្វីដែលបានសរសេរចុងក្រោយ (`G1~`, `X{x}~`)។ ពាក្យដែលបញ្ចប់ដោយ `~!` ត្រូវបានសរសេរគ្រប់ពេល ហើយនៅតែចងចាំ។ ឈ្មោះដែលមិនមែនជាអថេរគឺជាអត្ថបទធម្មតា (`G81`, `mist`)។ លេខត្រូវបានបង្គត់ដល់ 0.001 mm ហើយសរសេរដោយគ្មានសូន្យបញ្ចប់។

## អ្វីដែល post មិនអាចធ្វើ

វាសម្រេចតែរបៀបសរសេរចលនា ហើយគ្មានអ្វីលើសនេះទេ។ វាមិនអាចផ្លាស់ប្ដូរផ្លូវឧបករណ៍ តម្រៀបប្រតិបត្តិការ បំបែកធ្នូ បន្ថែមអ័ក្ស ដឹងពីការធ្វើដំណើរ ឬ kinematics របស់ម៉ាស៊ីនអ្នក ឬគណនាលើកូអរដោនេ (គ្មាន `+`) បានទេ។ ទីតាំងបង្វិលខ្លួនវាមកពីម៉ាស៊ីនដែលបានពិពណ៌នានៅ Setup មិនមែនពី post ទេ; post អាចផ្លាស់ប្ដូរសញ្ញា ឬអក្សររបស់វា មិនមែន kinematics ទេ។ វដ្តជីវិតឧបករណ៍ និងវដ្ត subprogram មិនទាន់បានបង្កើត។ ឯកសារ post ទម្រង់ `.cps` ពីកម្មវិធីផ្សេងមិនអាចផ្ទុកបានទេ៖ នេះជាទម្រង់ផ្សេង ងាយស្រួលជាង។
