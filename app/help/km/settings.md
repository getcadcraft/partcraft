បើក {{ui:ការកំណត់}} ដោយចុចកង់ក្នុងរបារកម្មវិធី ឬ {{key:Mod+,}}។ ផ្ទាំងដំបូង {{ui:PartCraft}} មានការកំណត់ដែលជារបស់កម្មវិធីនេះ; {{ui:ទូទៅ}} មានការកំណត់ដែលកម្មវិធី CadCraft ទាំងអស់ចែករំលែក (ស្បែក របារឧបករណ៍ ផ្ទាំង)។ ការកំណត់ PartCraft មានតែក្នុងកម្មវិធីប៉ុណ្ណោះ៖ អ្នកផ្លាស់ប្តូរនៅទីនេះ ហើយកម្មវិធីរុករកនេះចងចាំវា។ {{ui:កំណត់ការកំណត់ PartCraft ឡើងវិញ}} ដាក់អ្វីៗទាំងអស់ត្រឡប់ទៅចាប់ផ្តើមវិញ។

## បង្វិលទិដ្ឋភាព

- **ប៊ូតុងឆ្វេង** (ការចាប់ផ្តើម)៖ អូសដោយប៊ូតុងឆ្វេងដើម្បីបង្វិលផ្នែក; អូសដោយប៊ូតុងស្តាំ ឬកណ្តាលដើម្បីរំកិល។
- **ប៊ូតុងកណ្តាល**៖ ចុចវីល ហើយអូសដើម្បីបង្វិលផ្នែក; សង្កត់ {{key:Shift}} (ឬ {{key:Ctrl}} ឬ ⌘) ជាមួយប៊ូតុងកណ្តាល ឬអូសដោយប៊ូតុងស្តាំ ដើម្បីរំកិល។ ប៊ូតុងឆ្វេងគ្រាន់តែជ្រើសមុខ គែម និងប្លង់ ដូច្នេះការចុចដែលរំកិលបន្តិចមិនដែលបង្វិលផ្នែកឡើយ។ កម្មវិធី CAD ជាច្រើនដំណើរការតាមរបៀបនេះ។

វីលពង្រីកត្រង់ទីតាំងកណ្តុរក្នុងទម្រង់ទាំងពីរ។ ក្នុងគំនូរកំណត់ ប៊ូតុងស្តាំ និងកណ្តាលនៅតែរំកិលដូចពីមុន។

## រំកិល៖ វីលកណ្តុរ ឬបន្ទះប៉ះ

- **ស្វែងរកដោយខ្លួនឯង** (ការចាប់ផ្តើម)៖ PartCraft មើលការរំកិល។ ការរំកិលចំហៀង ឬល្អិតដូចដែលបន្ទះប៉ះផ្ញើ បង្វិលផ្នែក; ជំហានវីលពេញ ពង្រីក។
- **វីលកណ្តុរ**៖ ការរំកិលតែងតែពង្រីកឆ្ពោះទៅកាន់ទីតាំងកណ្តុរ។
- **បន្ទះប៉ះ**៖ អូសដោយម្រាមដៃពីរដើម្បីបង្វិលផ្នែក; សង្កត់ {{key:Shift}} ហើយអូសដើម្បីរំកិល; ច្បិចដើម្បីពង្រីក។ ក្នុងគំនូរកំណត់ អូសដោយម្រាមដៃពីរនឹងរំកិលគំនូរកំណត់។

ច្បិចពង្រីកក្នុងគ្រប់ជម្រើសទាំងអស់។ បើ "ស្វែងរកដោយខ្លួនឯង" ទាយខុសសម្រាប់កណ្តុរ ឬបន្ទះប៉ះរបស់អ្នក សូមជ្រើសមួយដែលអ្នកមាន។ បន្ថែមទៀតក្នុង [បន្ទះប៉ះ ការប៉ះ និងអេក្រង់តូច](topic:trackpad-and-touch)។

## គំនូរកំណត់៖ បន្ថែមទំនាក់ទំនងខណៈគូរ

**បន្ថែមទំនាក់ទំនងខណៈគូរ** (បើកតាំងពីដើម)៖ ការចុចដែលចាប់ទៅចំណុចធ្វើឱ្យចំណុចថ្មីត្រួតគ្នាជាមួយវា ការចុចលើខ្សែកោងដាក់ចំណុចនៅលើខ្សែកោងនោះ ហើយបន្ទាត់ដែលគូរស្ទើរផ្ដេក ឬបញ្ឈរ ក្លាយជាផ្ដេក ឬបញ្ឈរពិតប្រាកដ។ សូមមើល [ទំនាក់ទំនង និងវិមាត្រ](topic:relations-dimensions)។

បិទវានៅពេលអ្នកចង់ដាក់ធរណីមាត្រជិតធរណីមាត្រផ្សេងទៀតដោយមិនភ្ជាប់ទៅវា។ ទស្សន៍ទ្រនិចនៅតែចាប់ទៅចំណុច និងខ្សែកោង ប៉ុន្តែគ្មានអ្វីត្រូវបានភ្ជាប់ទេ៖ បន្ទាត់ដែលគូរជាច្រវាក់មិនចែករំលែកចុងរបស់វាទេ ដូច្នេះការអូសអាចទាញពួកវាចេញពីគ្នា។ បន្ថែមទំនាក់ទំនងដែលអ្នកចង់បានដោយខ្លួនឯងពីផ្ទាំងខាងស្តាំ។ ទម្រង់បិទនៅតែអាច extrude បានពេលចុងរបស់វាជួបគ្នា។

## គំនូរកំណត់៖ វិមាត្រខណៈពេលគូរ

**វិមាត្រខណៈពេលគូរ** (បើកតាំងពីដើម)៖ ខណៈគូរបន្ទាត់ ចតុកោណ រង្វង់ ឬធ្នូ ការវាយលេខនឹងបំពេញប្រអប់ទំហំនៅក្បែរទស្សន៍ទ្រនិច ({{key:Tab}} ទៅប្រអប់បន្ទាប់) ហើយ {{key:Enter}} គូររូបរាងនៅទំហំនោះ ជាមួយវិមាត្របញ្ជាសម្រាប់ទំហំនីមួយៗដែលអ្នកបានវាយ។ បិទ៖ ការវាយលេខខណៈគូរមិនធ្វើអ្វីទេ ហើយរូបរាងត្រូវបានគូរតែដោយការចុចប៉ុណ្ណោះ។ សូមមើល [វាយទំហំខណៈគូរ](topic:sketch-basics#type-the-size-as-you-draw)។

## សញ្ញាសម្គាល់ជ្រុង

អ្វីដែលបង្ហាញនៅជ្រុងនៃទិដ្ឋភាព 3D៖ **ដុំមើលទិដ្ឋភាព** (ការចាប់ផ្តើម; ជ្រុងខាងលើស្ដាំ — ចុចមុខ គែម ឬជ្រុងដើម្បីមើលពីទីនោះ អូសវាដើម្បីវិលជុំវិញ អូសចិញ្ចៀនត្រីវិស័យរបស់វាដើម្បីបង្វិលម៉ូដែល), **រូបតំណាងអ័ក្ស** (សញ្ញាតូច X, Y, Z នៅជ្រុងខាងឆ្វេងខាងក្រោម ដែលបង្វិលតាមទិដ្ឋភាព៖ X ក្រហម, Y បៃតង, Z ខៀវ) ឬ **គ្មាន**។ មិនមានអ្វីទាំងពីរបង្ហាញខណៈគូរគំនូរកំណត់ ឬនៅលើសន្លឹកគំនូរប្លង់ឡើយ។ សូមមើល [ដុំមើលទិដ្ឋភាព](topic:view-cube)។

## ខ្សែឧបករណ៍ដោះស្រាយ

ចំនួនខ្សែដែលឧបករណ៍ដោះស្រាយការក្លែងធ្វើអាចប្រើ។ **ស្វ័យប្រវត្តិ** (ការចាប់ផ្តើម) យកតិចជាងចំនួនប្រព័ន្ធដំណើរការឡូជីខលរបស់កុំព្យូទ័រមួយ (អតិបរមា 16) ដូច្នេះទំព័រនៅតែឆ្លើយតបខណៈការសិក្សាកំពុងដោះស្រាយ; ឬជ្រើសលេខមួយ។ ការសិក្សាវ៉ុកសែលធំ ការដួលរលំ ភាពតានតឹងតាមពេល និងលំហូរដោះស្រាយលឿនជាងនៅលើខ្សែច្រើន (ប្រហែល 2× លើ 4 ខ្សែ សម្រាប់ 80,000 គូប តាមការវាស់របស់យើង ហើយច្រើនជាងនេះនៅលើកុំព្យូទ័រទំនេរ); ម៉ូដែលក្រោមប្រហែល 20,000 មិនស្គាល់ស្ថិតនៅលើខ្សែមួយ ព្រោះការចាប់ផ្តើមខ្សែចំណាយច្រើនជាងដែលវាសន្សំ។ ការដោះស្រាយជាខ្សែផ្តល់ចម្លើយដូចគ្នានឹងខ្សែមួយ (ដល់ការបង្គត់ ព្រោះផលបូកត្រូវបានបូកតាមលំដាប់ផ្សេង)។ លទ្ធផលនៃការសិក្សានីមួយៗបង្ហាញ **N ខ្សែ** ឬ **1 ខ្សែ** ជាមួយហេតុផលនៅក្រោម **ឧបករណ៍ដោះស្រាយ**។

ខ្សែត្រូវការឱ្យទំព័រជា **cross-origin isolated** (កម្មវិធីរុករកអនុញ្ញាតឱ្យកម្មវិធីធ្វើការ (workers) ចែករំលែកអង្គចងចាំតែក្នុងករណីនេះ)។ ទំព័រមន្ទីរពិសោធន៍ជាបែបនេះ; ប្រសិនបើមិនមែន ការកំណត់បញ្ជាក់វា ("ទំព័រនេះមិនមែនជា cross-origin isolated ដូច្នេះឧបករណ៍ដោះស្រាយដំណើរការលើខ្សែមួយ មិនថាអ្វីដែលបានជ្រើសនៅទីនេះទេ។") ហើយការដោះស្រាយគ្រប់ដង ប្រើខ្សែមួយ។ អ្វីផ្សេងទៀតដំណើរការដូចគ្នា ហើយចម្លើយគឺដូចគ្នា។

ការវិភាគលំហូរឡាមីណេ (laminar) ក៏ប្រើខ្សែដែរ (ប្រហែល 2.5× លើ 4 ខ្សែ សម្រាប់ 54,000 ក្រឡាអង្គធាតុរាវ ចម្លើយដូចគ្នាដល់ខ្ទង់ចុងក្រោយ)។ ឧបករណ៍ដោះស្រាយ tetrahedron ការ៉េ និងការផ្ទេរកំដៅដំណើរការលើខ្សែមួយ៖ ការធ្វើឱ្យពួកវាជាខ្សែត្រូវបានវាស់ថាយឺតជាងនៅលើកុំព្យូទ័រសាកល្បងរបស់យើង (ពួកវាកំណត់ដោយល្បឿនអង្គចងចាំ និងជំហានមួយដែលមិនអាចបំបែកបាន)។

### លើម៉ាស៊ីនមេរបស់អ្នកផ្ទាល់

ប្រសិនបើអ្នកដំណើរការ PartCraft ពីម៉ាស៊ីនមេរបស់អ្នក វាដំណើរការដូចដែលបានបម្រើ។ សម្រាប់ខ្សែឧបករណ៍ដោះស្រាយ សូមឱ្យម៉ាស៊ីនមេផ្ញើបឋមកថាពីរទៅកាន់ទំព័រ PartCraft៖

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

នៅ Apache ក្នុង `.htaccess` របស់ថត (ត្រូវការ mod_headers)៖

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

នៅ nginx ក្នុង `location` ដែលបម្រើ PartCraft៖

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

ផ្ទុកទំព័រឡើងវិញ៖ ការកំណត់ › ខ្សែឧបករណ៍ដោះស្រាយ នោះនឹងផ្តល់ **ស្វ័យប្រវត្តិ** ជាមួយចំនួនរបស់កុំព្យូទ័ររបស់អ្នក។ បឋមកថាទីពីរធ្វើឱ្យកម្មវិធីរុករកបដិសេធអ្វីក៏ដោយដែលទំព័របានផ្ទុកពីគេហទំព័រផ្សេងដែលមិនអនុញ្ញាត ដែលល្អសម្រាប់ PartCraft តែឯង (វាផ្ទុកអ្វីៗទាំងអស់ពីថតរបស់ខ្លួន)។
