**ការមើលជាមុន។** ការសរសេរស្គ្រីបថ្មីនៅ PartCraft 0.3 ហើយវាជាការមើលជាមុន: ភាសា បណ្ណាល័យ និងវិធីដែលស្គ្រីបត្រូវបានរក្សាទុកអាចនឹងផ្លាស់ប្តូរនៅតែមាន ហើយស្គ្រីបដែលសរសេរឥឡូវអាចត្រូវការកែតិចតួចនៅពេលក្រោយ។ សូមប្រាប់យើងថាមានអ្វីខូច។

ផ្ទាំងការងារស្គ្រីបដំណើរការការគណនារបស់អ្នកផ្ទាល់នៅក្បែរគ្រឿង៖ ផលបូកតូចៗ ការវិភាគទាំងមូល ឬស្គ្រីបនៅក្នុង[បណ្ណាល័យវិភាគ](topic:craftscript-library)។ ស្គ្រីបត្រូវបានសរសេរជា **CraftScript** (ភាសាម៉ាទ្រីសដូច MATLAB សូមមើល [ភាសា CraftScript](topic:craftscript-language)) ឬជា **Lua** (សូមមើល [ស្គ្រីប Lua](topic:craftscript-lua)) ឬជា **Python** (សូមមើល [ស្គ្រីប Python](topic:craftscript-python))។

ជ្រើសរើស **Script** នៅក្នុងប្រអប់ **Workspace** នៅខាងឆ្វេងនៃរបារឧបករណ៍។ គ្រឿងមិនត្រូវបានផ្លាស់ប្តូរទេ។ ផ្ទាំងស្ដាំក្លាយជាផ្ទាំងស្គ្រីប (ធំជាងធម្មតា; អូសគែមរបស់វាដើម្បីផ្លាស់ប្តូរទំហំ ឬផ្លាស់ទីវាទៅអេក្រង់ទីពីរដោយម៉ឺនុយ {{ui:⋯}} របស់វា សូមមើល [ការរៀបចំផ្ទាំង](common:arrange-panels))។

## សរសេរស្គ្រីបខណៈធ្វើម៉ូដែល

អ្នកមិនចាំបាច់ចាកចេញពីផ្ទាំងការងារ Design ដើម្បីសរសេរស្គ្រីបទេ។ នៅ Design ផ្ទាំង {{ui:Script}} នៃផ្ទាំងស្ដាំមានកម្មវិធីកែ កុងសូល អថេរ និងបណ្ណាល័យដូចគ្នា ជាមួយស្គ្រីបដូចគ្នា។ ដើមឈើលក្ខណៈពិសេស និងទិដ្ឋភាពនៅតែដំណើរការ: ចុចលក្ខណៈពិសេសដើម្បីជ្រើសរើសវា ចុចពីរដងលើស្កេច ដើម្បីកែវា បង្វិលទិដ្ឋភាព បន្ទាប់មកត្រឡប់ទៅផ្ទាំង {{ui:Script}} ហើយចុច {{key:F5}}។

អ្វីដែលស្គ្រីប **បង្ហាញ** (ម៉ែស វាល ក្រាហ្វ តារាង) មិនត្រូវបានគូរលើម៉ូដែលរបស់អ្នកនៅ Design ទេ: កុងសូលប្រាប់ដូច្នេះ ហើយផ្ទាំងការងារស្គ្រីបមានគ្រប់យ៉ាងនៅពេលអ្នកប្តូរទៅវា។

{{ui:Pop out}} នៅក្បែរ {{ui:Run}} ផ្លាស់ទីផ្ទាំងទាំងមូលទៅជាវិនដូរបស់ខ្លួន ឧទាហរណ៍នៅលើអេក្រង់ទីពីរ ដូច្នេះកម្មវិធីកែ និងទិដ្ឋភាពពេញលេញនៅក្បែរគ្នា។ {{ui:Put back}} ដាក់វាចូលវិញ។ សូមមើល [ការរៀបចំផ្ទាំង](common:arrange-panels)។

## ដំណើរការស្គ្រីបដំបូងរបស់អ្នក

1. វាយនៅក្នុងកម្មវិធីកែ ឧទាហរណ៍៖

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. ចុច {{key:F5}} (ឬ {{ui:Run}})។ កុងសូលនៅក្រោមកម្មវិធីកែបង្ហាញអ្វីដែលស្គ្រីបបានបោះពុម្ព និង "Done in … s"។ ក្រាហ្វបង្ហាញនៅក្នុង **ផ្ទាំងបង្ហាញរង** តាមបាតនៃទិដ្ឋភាព 3D។
3. បន្ទាត់ដែលគ្មានសញ្ញាក្បៀសចុងបង្ហាញតម្លៃរបស់វា ដូចក្នុង MATLAB: `a = 3` បង្ហាញ `a = 3`; `a = 3;` មិនបង្ហាញអ្វីទេ។
4. ដើម្បីដំណើរការតែផ្នែកខ្លះនៃស្គ្រីប ជ្រើសរើសបន្ទាត់ ហើយចុច {{key:Mod+Enter}} ({{ui:Selection}})។ បើមិនបានជ្រើសរើសអ្វីទេ វាដំណើរការបន្ទាត់ដែលសញ្ញាព្រួញនៅលើ។
5. បន្ទាត់នៅបាតកុងសូល (បន្ទាប់ពី `>>`) ដំណើរការសេចក្តីថ្លែងការណ៍មួយនៅពេលអ្នកចុច {{key:Enter}}។ {{key:Up}} និង {{key:Down}} នាំបន្ទាត់ពីមុនត្រឡប់មកវិញ។

## ស្វែងរក បត់ និងបំពេញ

- **ស្វែងរក និងជំនួស។** ចុច {{key:Mod+F}} (ឬ {{key:Mod+H}} ដើម្បីជំនួសផងដែរ)។ របារមួយបើកពីលើកូដ៖ វាយអ្វីដែលត្រូវរក; ការផ្គូផ្គងនឹងភ្លឺ ហើយចំនួនប្រាប់ថាអ្នកនៅទីណា។ ប៊ូតុងក្បែរប្រអប់ផ្គូផ្គងអក្សរតូចធំ (**Aa**) ស្វែងរកតែពាក្យទាំងមូល (**W**) និងប្រើកន្សោមធម្មតា (**.\***; ក្នុងការជំនួស `$1` ដាក់ត្រឡប់អ្វីដែលក្រុមទីមួយផ្គូផ្គង)។ {{ui:Replace}} ជំនួសការផ្គូផ្គងបច្ចុប្បន្ន {{ui:All}} ជំនួសការផ្គូផ្គងទាំងអស់ជាជំហានមួយនៃ {{key:Mod+Z}}។
- **ការបត់។** ចុច ▾ នៅក្បែរលេខបន្ទាត់ ឬចុច {{key:Mod+Shift+[}} ដោយសញ្ញាព្រួញនៅលើបន្ទាត់ `function`, `if`, `for`, `while`, `switch` ឬ `try` (Lua: `function`, `do`, `if`, `repeat`) ដើម្បីលាក់បន្ទាត់ខាងក្នុងរបស់វា; បន្ទាត់ប្រាប់ថាមានប៉ុន្មាន។ ▸ ឬ {{key:Mod+Shift+]}} បើកវាឡើងវិញ។ ការបត់គ្រាន់តែលាក់បន្ទាត់ ការដំណើរការ ការរក្សាទុក ការចម្លង និងលេខបន្ទាត់នៅតែរាប់គ្រប់បន្ទាត់; ការវាយលើបន្ទាត់ដែលបានបត់នឹងបើកវាជាមុនសិន។
- **ការបំពេញ។** វាយពីរអក្សរនៃឈ្មោះ ឬចុច {{key:Mod+Space}}: បញ្ជីមួយបង្ហាញអថេរដែលអ្នកមាន អនុគមន៍ភាសា (ជាមួយអាគុយម៉ង់របស់វា) ពាក្យគន្លឹះ និងឈ្មោះដែលមាននៅក្នុងស្គ្រីបរួចហើយ។ ជ្រើសរើសដោយព្រួញ ហើយចុច {{key:Enter}} ឬ {{key:Tab}}។

## នៅពេលមានអ្វីខុស

- កំហុសនិយាយពីបញ្ហា និងបន្ទាត់របស់វា៖ បន្ទាត់ត្រូវបានសម្គាល់ជាពណ៌ក្រហមនៅក្នុងកម្មវិធីកែ ហើយ **Line n** នៅក្នុងកុងសូលនាំអ្នកទៅទីនោះ។
- រង្វិលដែលមិនចេះចប់: ចុច {{ui:Stop}} (របារឧបករណ៍ ឬផ្ទាំង)។ ស្គ្រីបឈប់ភ្លាមៗ; អថេរនៅតែរក្សាតម្លៃដែលពួកវាមានមុនការដំណើរការនោះ។
- ការដំណើរការនីមួយៗក៏មានថវិកាជំហានផងដែរ (2 ពាន់លានជំហានតាមលំនាំដើម; ផ្លាស់ប្តូរនៅក្រោម **Run options**ក្នុងផ្ទាំង)។ ការដំណើរការដែលលើសថវិកានោះនឹងឈប់ជាមួយសារមួយ។

## អថេរធ្វើដំណើរពីស្គ្រីបមួយទៅស្គ្រីបមួយ

អថេរថ្នាក់លើគ្រប់ដួងដែលស្គ្រីបបង្កើតចូលទៅក្នុងផ្ទាំង **Variables** (ឈ្មោះ ប្រភេទ ទំហំ តម្លៃតូចបំផុត និងធំបំផុត) ហើយនៅទីនោះសម្រាប់ស្គ្រីបបន្ទាប់ ក្នុងភាសាណាក៏បាន។ នោះជារបៀបដែលស្គ្រីបមួយធ្វើម៉ែស ស្គ្រីបបន្ទាប់ដោះស្រាយ ហើយស្គ្រីបទីបីគូសក្រាហ្វ។

- ចុចអថេរមួយដើម្បីបង្ហាញវា: ម៉ែស វាល និងម៉ូដែលក្នុងទិដ្ឋភាព 3D អារ៉ាយជាតារាង (និងក្រាហ្វបន្ទាត់សម្រាប់វ៉ិចទ័រ ឬផែនទីពណ៌សម្រាប់ម៉ាទ្រីស) នៅក្នុងផ្ទាំងបង្ហាញរង។
- {{ui:Save as JSON}}, {{ui:Save as CSV}} (តារាងលេខ) និង {{ui:Save as HDF5}} ទាញវាចុះ; {{ui:Delete}} លុបវា; {{ui:Clear all}} សម្អាតផ្ទាំងការងារ។
- ដាក់សញ្ញា **រក្សាទុកអថេរជាមួយគ្រឿង** ដើម្បីរក្សាវាក្នុងឯកសារគ្រឿង (រហូតដល់ 32 MB; ធំជាងនេះនៅសម្រាប់ការចូលមើលនេះតែប៉ុណ្ណោះ)។ នៅពេលអ្នកបើកគ្រឿងបែបនេះ ផ្ទាំងនឹងផ្តល់ជម្រើសឲ្យផ្ទុកពួកវា។

## ម៉ែស វាល និងក្រាហ្វ

- `show(m)` គូរម៉ែស; `show(f)` ដាក់ពណ៌វាលលើម៉ែសរបស់វាជាមួយផ្លាកលេខ។ បញ្ជី **បានបង្ហាញ** នៅជ្រុងខាងឆ្វេងខាងលើនៃទិដ្ឋភាពលាក់ ({{ui:eye}}) ឬដកចេញនូវធាតុនីមួយៗ ហើយលាក់ ឬបង្ហាញគ្រឿងខ្លួនឯង។ នៅក្រោមផ្លាកលេខ វាយជួរ (**From**, **to**) ឬចុច {{ui:Auto}}; វ៉ិចទ័រ ឬវាលភាពតានតឹងក៏ផ្តល់ជម្រើសនៃសមាសធាតុដែលត្រូវបង្ហាញផងដែរ។
- `show(f, 'deform', u, 'scale', 50)` គូរម៉ែសដែលផ្លាស់ទីដោយវាលការផ្លាស់ទី `u` ពង្រីក 50 ដង (ដោយគ្មាន `scale` ប្រហែល 8 % នៃទំហំម៉ូដែល)។
- ចុចម៉ែសដែលបានបង្ហាញ: ចំណុចជិតបំផុត ធាតុ និងតម្លៃវាលនៅទីនោះលេចឡើងក្នុងផ្ទាំងបង្ហាញរង (**បានជ្រើសរើស**)។
- `plot`, `imagesc` និង `table` ដាក់ក្រាហ្វបន្ទាត់ ផែនទីពណ៌នៃអារ៉ាយ 2-D ឬតារាងក្នុងផ្ទាំងបង្ហាញរង។ ក្រាហ្វដែលមាន `'id'` (ឬចំណងជើង) ដូចគ្នាទៅនឹងមួយមុន នឹងជំនួសវា ដូច្នេះរង្វិលអាចធ្វើបច្ចុប្បន្នភាពក្រាហ្វការបង្រួបបង្រួមមួយ; `'append', true` បន្ថែមខ្សែកោងទៅវា។ {{ui:Clear}} សម្អាតផ្ទាំងបង្ហាញរង; ព្រួញបត់ពួកវាចូល។
- ជាមួយក្រាហ្វពីរ ឬច្រើន {{ui:Side by side}} បង្ហាញពួកវាទាំងអស់ក្នុងពេលតែមួយ (ប្រាំមួយថ្មីបំផុត); ចុចផ្ទាំងតារាង ឬរូបភាពដើម្បីបង្ហាញតែមួយនោះម្តងទៀត។
- ក្រាហ្វនីមួយៗមាន {{ui:PNG}}, {{ui:SVG}} និង {{ui:CSV}} នៅក្រោមវា។ PNG និង SVG បោះពុម្ពវាលើផ្ទៃស ដោយពណ៌ក្រដាស ពុំខ្លឹមសារសារពើពណ៌ (PNG 1600 × 1000 ភីកសែល; SVG ពង្រីកដោយមិនព្រិល); CSV រក្សាលេខរបស់វាជាមួយគ្រប់ខ្ទង់៖ ជួរឈរមួយនៃ x និងជួរឈរមួយសម្រាប់ខ្សែកោងនីមួយៗនៅពេលខ្សែកោងចែករំលែក x ផ្សេងក្រៅពីនេះ ជួរមួយសម្រាប់ចំណុចនីមួយៗជាមួយឈ្មោះខ្សែកោង។
- {{key:F}} ឬ {{ui:Fit}} ឲ្យទិដ្ឋភាពសមនឹងអ្វីដែលបង្ហាញ។

## ឯកសារ

- {{ui:Open}} ក្នុងក្រុម Script (ឬទម្លាក់ឯកសារលើទិដ្ឋភាពឬផ្ទាំង): ឯកសារ `.craft`, `.lua` និង `.py` បើកជាស្គ្រីបថ្មី (ពួកវាមិនដំណើរការ); ឯកសារទិន្នន័យ (STL, OBJ, CSV, JSON, NPY, HDF5) ផ្ទុកចូលទៅក្នុងអថេរក្រោមឈ្មោះឯកសាររបស់វា។
- {{ui:Save}} ក្នុងក្រុម Script ទាញស្គ្រីបបច្ចុប្បន្នចុះជាឯកសារ។
- {{ui:New}} ក្នុងក្រុម Script (ឬ {{ui:+}} ក្បែរផ្ទាំង) ចាប់ផ្តើមស្គ្រីបមួយទៀត។ ចុចពីរដងលើផ្ទាំងដើម្បីប្តូរឈ្មោះវា; {{ui:×}} របស់វាដកវាចេញ (អ្នកអាច undo បាន)។

## អានប៉ារ៉ាម៉ែត្ររបស់គ្រឿង

ស្គ្រីបអានប៉ារ៉ាម៉ែត្ររបស់គ្រឿង (សូមមើល [បញ្ជាគ្រឿងដោយប៉ារ៉ាម៉ែត្រ](topic:parameters)) តាមឈ្មោះ៖

```
w = param('width');     % តម្លៃមួយនៃប៉ារ៉ាម៉ែត្រ ជា mm (ឬដឺក្រេ ឬលេខធម្មតា)
p = params();           % ទាំងអស់ ជារចនាសម្ព័ន្ធ៖ p.width, p.height
```

នៅក្នុង Lua និង Python ពួកវាគឺ `cs.param('width')` និង `cs.params()`។ ស្គ្រីបគ្រាន់តែអានប៉ារ៉ាម៉ែត្រ៖ ប្តូរពួកវានៅផ្ទាំង {{ui:Parameters}}។ នៅក្រោមផ្ទាំងស្គ្រីប បន្ទាត់មួយចុះបញ្ជីប៉ារ៉ាម៉ែត្រដែលវាអាន ជាមួយ `param('…')` ហើយសម្គាល់ណាមួយដែលគ្រឿងមិនមាន; ផ្ទាំង {{ui:Parameters}} បញ្ជីស្គ្រីបក្រោមនីមួយៗ។ ឈ្មោះដែលបង្កើតពេលស្គ្រីបកំពុងដំណើរការ ដូចជា `param(name)` មិនត្រូវបានចុះបញ្ជីទេ។

## ស្គ្រីបត្រូវបានរក្សាទុកក្នុងគ្រឿង

ស្គ្រីបគ្រប់ដួងក្នុងផ្ទាំងត្រូវបានរក្សាក្នុងគ្រឿង ដូច្នេះ {{ui:Save}} ក្នុងក្រុម File រក្សាទុកវាជាមួយ ហើយការផ្លាស់ប្តូររបស់វាអាច undo បាន។ ការបើកគ្រឿង **មិនដែលដំណើរការស្គ្រីបរបស់វាទេ**: កុងសូលប្រាប់ថាមានប៉ុន្មាន ហើយពួកវាដំណើរការតែនៅពេលអ្នកចុច Run។ គ្រឿងពីមនុស្សម្នាក់ទៀតអាចមានស្គ្រីបណាក៏បាន: អានវាមុនពេលអ្នកដំណើរការ។ ស្គ្រីបដំណើរការនៅផ្ទៃខាងក្រោយនៅលើកុំព្យូទ័រនេះដោយគ្មានការចូលបណ្តាញ ហើយមិនអាចប៉ះពាល់ទំព័របានទេ។
