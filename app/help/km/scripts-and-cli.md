ការធ្វើម៉ូដែលដោយប្រុងប្រយ័ត្នពឹងលើវិន័យច្រើនជាងប៊ូតុង។ ផ្នែកដែលសរសេរជាអត្ថបទអាចអាន ពិនិត្យ ប្រៀបធៀបបន្ទាត់ម្ខាងម្ខាង និងសាងសង់ឡើងវិញដោយស្គ្រីបបាន។ PartCraft ដំណើរការទាំងពីរទិសដៅ៖ ផ្នែកណាក៏អាចសរសេរជាស្គ្រីបបាន ហើយស្គ្រីបសាងសង់ផ្នែកបាន។

## នៅក្នុងកម្មវិធី

នៅផ្ទាំង {{ui:ប៉ារ៉ាម៉ែត្រ}} ក្រោម **Script**៖

- {{ui:រក្សាទុកជាស្គ្រីប}} ទាញយកផ្នែកដែលកំពុងបើកជា `<name>.pcscript`។
- {{ui:បើកស្គ្រីប}} សាងសង់ផ្នែកពីឯកសារ `.pcscript`។ កំហុសត្រូវបានរាយការណ៍ជាមួយលេខបន្ទាត់ ហើយគ្មានអ្វីត្រូវបានជំនួសឡើយ។

## ទម្រង់ស្គ្រីប

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

ក្បួន៖

- បន្ទាត់នៅគែមខាងឆ្វេងចាប់ផ្តើមសេចក្តីថ្លែង៖ `pcscript`, `part`, `param`, ប្រភេទលក្ខណៈពិសេស (`sketch`, `extrude`, `revolve`, `hole`, `lpattern`, `cpattern`, `mirror`, `fillet`, `chamfer`, `shell`, `import` និងប្រភេទថ្មីៗ) ដែលមានឈ្មោះបន្ទាប់ ឬ `rollback <feature>`។
- បន្ទាត់ដែលចូលជួរគឺជាការកំណត់នៃសេចក្តីថ្លែងខាងលើ។ ការកំណត់ដាច់ឯង (`through`, `reverse`, `suppressed`) មានន័យថា បាទ។
- ការកំណត់លេខគឺជាលេខ ឬ `=` ហើយកន្សោម ដែលបង្កើតសមីការ៖ `depth = thick`។
- ក្នុងគំនូរកំណត់៖ `on` ដាក់ឈ្មោះប្លង់ (`front`, `top`, `right`, `face Base end`, `face Revolve1 side l3`); ធរណីមាត្រគឺ `point <name> x, y`, `line <name> <point> <point>`, `circle <name> <centre> <radius>`, `arc <name> <centre> <start> <end>` (ច្រាសទ្រនិចនាឡិកា) ឬ `spline <name> fit|control <points>`; ទំនាក់ទំនងគឺប្រភេទរបស់វា និងឈ្មោះដែលវាភ្ជាប់ (`O` គឺជាចំណុចដើម); វិមាត្រចប់ដោយតម្លៃរបស់វា ឬ `= expression`។
- ការកំណត់ជាជម្រើសនៃបន្ទាត់ធរណីមាត្រ ឬទំនាក់ទំនងដាក់ក្នុងតង្កៀបការ៉េនៅចុង ដាច់ដោយ `;`៖ `[construction]`, `[side -1; label 5, 3]`។
- `#` ចាប់ផ្តើមមតិយោបល់ (នៅដើមបន្ទាត់ ឬបន្ទាប់ពីចន្លោះ)។ ឈ្មោះដែលមានចន្លោះដាក់ក្នុងសម្រង់ទ្វេ "..."។
- លេខសម្គាល់លក្ខណៈពិសេសរាប់ពី f1 តាមលំដាប់ដែលបានសរសេរ។ ការយោងគែម និងមុខប្រើពួកវា ឧទាហរណ៍ `edge f2.side:l3 f2.end [at 50, 0, 10]`។
- ការកំណត់ដែលទម្រង់មិនមានពាក្យសម្រាប់ត្រូវសរសេរជា `json` និងតម្លៃ ហើយត្រូវបានអានត្រឡប់មកវិញដូចដែលវាជា។

នៅពេលរក្សាទុកពីកម្មវិធី ស្គ្រីបមានការកំណត់ទាំងអស់ ដូច្នេះវាបើកជាផ្នែកដូចគ្នា។ តួ STEP ដែលបាននាំចូលត្រូវបានសរសេរនៅក្នុងស្គ្រីបពីកម្មវិធី ហើយជាឯកសារ `.step` ដាច់ដោយឡែកដែលមានឈ្មោះដោយ `step-file` ពីបន្ទាត់ពាក្យបញ្ជា។

## ឧបករណ៍បន្ទាត់ពាក្យបញ្ជា

ឧបករណ៍ដំណើរការលើកុំព្យូទ័រដែលមាន Node.js 24 ពីច្បាប់ចម្លងនៃកូដប្រភព CadCraft៖ `node tools/partcraft-cli/partcraft.mjs <command>`។ វាជាឧបករណ៍អ្នកអភិវឌ្ឍ ហើយប្រើម៉ូឌុលដូចគ្នានឹងកម្មវិធី។ ផ្នែកគឺជាឯកសារ `.partcraft.json` ឬស្គ្រីប `.pcscript`។

| ពាក្យបញ្ជា | អ្វីដែលវាធ្វើ |
|---|---|
| `info <part>` | លក្ខណៈពិសេស ប៉ារ៉ាម៉ែត្រ របារ rollback មាឌ និងទំហំនៃតួដែលបានសាងសង់ |
| `params <part>` | ប៉ារ៉ាម៉ែត្រ និងសមីការនីមួយៗជាមួយតម្លៃរបស់វា |
| `set <part> width=150 Base.depth==thick` | ទៅមុខ៖ ផ្លាស់ប្តូរប៉ារ៉ាម៉ែត្រ ភ្ជាប់លេខ (`==` ឬកន្សោម) កំណត់លេខធម្មតា |
| `drive <part> Base.depth=12` | ថយក្រោយ៖ ដោះស្រាយប៉ារ៉ាម៉ែត្រដែលនៅពីក្រោយលេខដែលត្រូវបានបញ្ជា (`--prefer width` ជ្រើសមួយ) |
| `build <part> --out x.step` | សរសេរ `.step`, `.stl`, `.3mf`, `.json`, `.pcscript` ឬម៉ាក្រូ (`.swb`) |
| `build <part> --table sizes.csv --out-dir sizes` | ឯកសារមួយសម្រាប់ជួរនីមួយៗនៃតារាងការរចនា |
| `variants <part> --out-dir d` ឬ `--zip f.zip` | ការកំណត់រចនាសម្ព័ន្ធទាំងអស់ជា STEP, IFC, DWG និងការមើលជាមុន តារាងវ៉ារ្យ៉ង់ និងធាតុបណ្ណាល័យ (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`); សូមមើល [បង្កើតកញ្ចប់វ៉ារ្យ៉ង់](topic:variant-pack) |
| `script <in.pcscript> -o part.json` | ស្គ្រីបទៅផ្នែក |
| `to-script <part> -o part.pcscript` | ផ្នែកទៅស្គ្រីប |
| `rollback <part> [<feature>]`, `forward <part> [--end]` | ផ្លាស់ទីរបារ rollback ក្នុងឯកសារ |
| `check <part> [--strict]` | ការពិនិត្យវិន័យ (ខាងក្រោម) |

`build` ក៏ទទួល `--set name=value` (សម្រាប់ការសាងសង់នេះតែមួយ) និង `--upto <feature>`។ ពាក្យបញ្ជានីមួយៗទទួល `--json`។ លេខកូដចេញ៖ 0 ល្អ, 1 រកឃើញបញ្ហា, 2 ពាក្យបញ្ជាត្រូវបានវាយខុស។ ស្គ្រីបមិនត្រូវបានសរសេរឡើងវិញនៅកន្លែងដើមឡើយ៖ ផ្តល់ `-o` ដើម្បីរក្សាទុកច្បាប់ចម្លងដែលបានផ្លាស់ប្តូរ។

## ការត្រួតពិនិត្យ

`check` រាយការណ៍អ្វីដែលធ្វើឱ្យផ្នែកពិបាកផ្លាស់ប្តូរនៅពេលក្រោយ៖

| ការរកឃើញ | រាប់ជា |
|---|---|
| គំនូរកំណត់ដែលកំណត់លើសកំណត់ (ទំនាក់ទំនងផ្ទុយគ្នា ឬដដែលៗ) | កំហុស |
| លក្ខណៈពិសេសដែលមិនអាចសាងសង់បាន | កំហុស |
| ប៉ារ៉ាម៉ែត្រ ឬសមីការដែលមានកំហុស ឬប៉ារ៉ាម៉ែត្រដែលប្រើគ្នាទៅវិញទៅមក | កំហុស |
| គំនូរកំណត់ដែលកំណត់មិនគ្រប់ ជាមួយដឺក្រេនៃសេរីភាពរបស់វា | ការព្រមាន |
| លេខដែលវាយចូលដោយផ្ទាល់ក្នុងលក្ខណៈពិសេស និងវិមាត្រ ដែលគ្មានប៉ារ៉ាម៉ែត្រណាបញ្ជា | ការព្រមាន |
| ប៉ារ៉ាម៉ែត្រដែលគ្មានអ្វីប្រើ | ការព្រមាន |
| លក្ខណៈពិសេសដែលបានផ្អាក; របារ rollback មិននៅចុង | ការព្រមាន |

`--strict` ធ្វើឱ្យការព្រមានទាំងអស់ទៅជាកំហុស ដូច្នេះស្គ្រីបសាងសង់អាចបដិសេធផ្នែកដែលមិនត្រូវបានបញ្ជាពេញលេញ។

:::note
ឯកសារម៉ាក្រូ `.swb` សម្រាប់កម្មវិធីធ្វើម៉ូដែលផ្នែកដែលហាងភាគច្រើនប្រើ៖ នៅពេលដំណើរការក្នុងកម្មវិធីនោះ វាសាងសង់ផ្នែកនៅទីនោះ។ វាមិនត្រូវបានដំណើរការក្នុងកម្មវិធីនោះនៅទីនេះទេ (វាមិនមាននៅលើម៉ាស៊ីនមេរបស់យើង) ដូច្នេះចាត់ទុកវាថាមិនទាន់បានសាកល្បង។
:::
