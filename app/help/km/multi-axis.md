ការផលិតអាចកាន់ឧបករណ៍ក្នុងមុំមួយ ហើយវាអាចផ្លាស់ទីអ័ក្សបង្វិលខណៈពេលកាត់។ របៀបបីធ្វើវា ពីសាមញ្ញទៅស្មុគស្មាញ។

**គ្មានអ្វីនៅទីនេះត្រូវបានដំណើរការលើម៉ាស៊ីនទេ។** ផ្លូវត្រូវបានពិនិត្យជាមួយធរណីមាត្រដោយការសាកល្បង ហើយ G-code ត្រូវបានអានត្រឡប់មកវិញ ប៉ុន្តែ post ភ្ជាប់មកធ្វើតាមកូដដែលការគ្រប់គ្រងបានឯកសារ មិនមែនម៉ាស៊ីនណាមួយនៅមុខយើងទេ។ សូមបញ្ជាក់កម្មវិធីនៅក្នុងឧបករណ៍ក្លែងធ្វើរបស់ការគ្រប់គ្រងរបស់អ្នក ហើយនៅលើអាកាសមុនពេលវាប៉ះលោហៈ។

## អ័ក្សបង្វិលរបស់ម៉ាស៊ីន

នៅផ្ទាំង **ការតំឡើង** {{ui:Rotary axes}} និយាយថាម៉ាស៊ីនមានអ្វី៖

| ជម្រើស | ម៉ាស៊ីន |
|---|---|
| None (3 axes) | កិនធម្មតា។ ប្រតិបត្តិការណាមួយដែលត្រូវការឧបករណ៍ផ្អៀងព្រមាន ហើយ post បដិសេធការសរសេររបស់វា។ |
| A (turns about X) | អ័ក្សបង្វិលមួយតាម X៖ តុអ័ក្សទីបួន ឬ indexer។ ឧបករណ៍អាចផ្អៀងក្នុងប្លង់ Y–Z តែប៉ុណ្ណោះ។ |
| B (turns about Y) | អ័ក្សបង្វិលមួយតាម Y។ ឧបករណ៍អាចផ្អៀងក្នុងប្លង់ X–Z តែប៉ុណ្ណោះ។ |
| A and C | អ័ក្សផ្អៀងជុំវិញ X ដែលដឹកដោយ ឬដឹក ការបង្វិលជុំវិញ Z៖ តុ trunnion ឬ head។ |
| B and C | ដូចគ្នាជាមួយការផ្អៀងជុំវិញ Y។ |

បន្ទាប់មក៖

- **ដឹកដោយ**៖ {{ui:The table (the part turns)}} ឬ {{ui:The head (the tool turns)}}។ តុបង្វិលទិសផ្ទុយដើម្បីនាំមុខដូចគ្នាមកក្រោមឧបករណ៍ ដូច្នេះសញ្ញានៃមុំទាំងអស់ដើរតាមនេះ។
- **ការគ្រប់គ្រងរក្សាចុងឧបករណ៍នៅលើផ្លូវ (TCP)**៖ បើក X Y Z នៅកម្មវិធីគឺជាចុងឧបករណ៍ក្នុងកូអរដោនេផ្ទាល់របស់គ្រឿង ហើយការគ្រប់គ្រងធ្វើផ្សេងទៀត (post Fanuc-style និង LinuxCNC ភ្ជាប់មកសរសេរ `G43.4` សម្រាប់ប្រវែងឧបករណ៍)។ បិទ នៅលើម៉ាស៊ីនតុ PartCraft សរសេរ X Y Z ដូចដែលតុដែលបង្វិលដឹកគ្រឿង ជុំវិញ **ចំណុចកណ្ដាលបង្វិល** ដែលអ្នកផ្ដល់ (ក្នុងកូអរដោនេការងារ; 0, 0, 0 នៅពេលចំណុចដើមការងារនៅចំកណ្ដាល)។ ម៉ាស៊ីនដែលមាន head ត្រូវការ TCP បើក៖ បើគ្មានវា កម្មវិធីនឹងត្រូវការប្រវែងអ័ក្សបង្វិលរបស់ម៉ាស៊ីន ដែល PartCraft មិនដឹង។
- **ដែនកំណត់ផ្អៀង**៖ អ័ក្សផ្អៀងទៅឆ្ងាយប៉ុណ្ណា។

ម៉ាស៊ីនខុសគ្នាត្រង់ទិសដៅដែលវាចាត់ទុកថាវិជ្ជមាន។ ប្រសិនបើអ័ក្សបង្វិលខុសទិសនៅលើម៉ាស៊ីនរបស់អ្នក សូមប្ដូរសញ្ញានៅក្នុងច្បាប់ចម្លងនៃ post ([Post processors ដែលអ្នកអាចកែបាន](topic:post-processors)).

## ឧបករណ៍ផ្អៀងសម្រាប់ប្រតិបត្តិការធម្មតា

ប្រតិបត្តិការកិនគ្រប់ប្រភេទ (face, pocket, adaptive, contour, drill, chamfer, parallel, scallop, 3D rough, rest) មាន **Tool tilt** និង **Tilt towards**៖ ទិសដៅឧបករណ៍សម្រាប់ប្រតិបត្តិការនោះតែមួយ វាស់ពីអ័ក្សឧបករណ៍នៃការតំឡើង។ នេះជាការកិនបី+ពីរ៖ អ័ក្សបង្វិលទៅទីតាំងមួយ ហើយនៅទីនោះ ខណៈពេលដែលអ័ក្សបីកាត់។

- វាយមុំទាំងពីរ ឬចុច {{ui:Tool square to a face}} ហើយចុចមុខរាបមួយ៖ ឧបករណ៍នឹងចង្អុលត្រង់ទៅវា។
- ជ្រើសមុខ និងគែមនៃប្រតិបត្តិការដូចធម្មតា។ អ្វីដែលរាប់ជាបាត ឬរន្ធត្រូវបានវិនិច្ឆ័យតាមឧបករណ៍ដែលផ្អៀង។
- ដុំវត្ថុសម្រាប់ទិសនោះគឺជាប្រអប់ដែលផ្ទុកដុំវត្ថុដែលបានបង្វិល ដូច្នេះកម្ពស់ និងចន្លោះមានសុវត្ថិភាពពីចំហៀងនោះ។

នៅក្នុង G-code មុនប្រតិបត្តិការ ឧបករណ៍ឡើង អ័ក្សបង្វិលបង្វិល ហើយឧបករណ៍ចុះមកលើចំណុចដំបូងរបស់វា។ នៅលើម៉ាស៊ីនតុដោយគ្មាន TCP ធ្នូនៅតែជាធ្នូ ហើយវដ្តខួងថេរនៅតែជាវដ្ត (ក្រប់ដែលសរសេរគ្រាន់តែបង្វិលជុំវិញ Z)។ ជាមួយ TCP នៅក្នុងប្លង់ផ្អៀង ធ្នូក្លាយជាបន្ទាត់ខ្លី ហើយវដ្តក្លាយជាចលនាដែលពួកវាតំណាង។

ការក្លែងធ្វើដុំវត្ថុដំណើរការទិសផ្អៀង **ដោយខ្លួនឯង**៖ វាបង្ហាញអ្វីដែលប្រតិបត្តិការនោះកាត់ពីដុំវត្ថុទាំងមូល ដែលមើលពីចំហៀងរបស់វា ហើយរកការកាត់ចូលនៅទីនោះ ប៉ុន្តែការកាត់ពីទិសដៅផ្សេងមិនត្រូវបានយកមកទេ។

## ការបញ្ចប់ 5 អ័ក្ស

{{ui:More}} នៅរបារការផលិតរាយប្រតិបត្តិការនេះ និងបន្ទាប់នៅកំពូលនៃផ្ទាំង **ប្រតិបត្តិការ**។

{{ui:5-axis}} គឺជា[ការឆ្លងកាត់បន្ទាត់ស្របបញ្ចប់](topic:finish-3d) ជាមួយ**ដែកកាត់ចុងបាល់ដែលផ្អៀងខណៈដែលវាទៅមុខ**។ បាល់កាត់ដោយស្វ៊ែរ ហើយស្វ៊ែរដូចគ្នាមិនថាឧបករណ៍ផ្អៀងទៅទិសណាជុំវិញចំណុចកណ្ដាលរបស់វាទេ ដូច្នេះបាល់ដើរតាមផ្លូវដូចដែលការឆ្លងកាត់ 3 អ័ក្សផ្តល់ឲ្យ ហើយមានតែទិសនៃឧបករណ៍ប៉ុណ្ណោះដែលផ្លាស់ប្ដូរ៖

- **ឆ្ពោះទៅផ្ទៃ**៖ 1 = កែងទៅផ្ទៃ, 0 = ឈរបញ្ឈរ, ណាមួយរវាងនោះ។
- **ផ្អៀងទៅមុខ**៖ ដឺក្រេតាមទិសនៃការកាត់ ដូច្នេះចំណុចកណ្ដាលនៅនឹងនៃបាល់មិនមែនជាអ្វីដែលកាត់ទេ។
- **ការផ្អៀងច្រើនបំផុត**៖ ឧបករណ៍មិនដែលផ្អៀងឆ្ងាយជាងនេះពីអ័ក្សការតំឡើងទេ។

កន្លែងដែលដងនឹងប៉ះគំរូ ការផ្អៀងត្រូវបានកាត់ថយរហូតដល់វាសម្អាត ហើយប្រតិបត្តិការនិយាយថាមានចំណុចប៉ុន្មាន។ ផ្លូវនីមួយៗចូល និងចេញដោយការលើកត្រង់។

## ការបញ្ចប់បង្វិល (អ័ក្សទី 4)

{{ui:Rotary}} សម្រាប់គ្រឿងដែលកាន់តាម **work X** នៅលើអ័ក្សបង្វិល។ គ្រឿងបង្វិល ហើយដែកកាត់ចុងបាល់ តែងតែចង្អុលទៅអ័ក្ស ដើរតាមផ្ទៃរបស់វា៖

- **ផ្លូវ**៖ {{ui:Along the axis}} (បន្ទាត់តាម X ឃ្លាតមួយ stepover នៃការបង្វិល) ឬ {{ui:Round the part}} (ចិញ្ចៀន ឃ្លាតមួយ stepover នៃ X)។
- **អ័ក្សនៅ Y / Z**៖ អ័ក្សនៅទីណា។ ទទេមានន័យថាកណ្ដាលនៃដុំវត្ថុ។ នៅលើម៉ាស៊ីនតុដោយគ្មាន TCP នេះត្រូវតែជាចំណុចកណ្ដាលបង្វិលនៅការតំឡើង; ប្រតិបត្តិការព្រមានពេលវាមិនមែន។
- **ពី / ដល់ X** និង **ពី / ដល់ មុំ**៖ ផ្នែកនៃប្រវែង និងនៃការបង្វិលដែលត្រូវកាត់។

កម្ពស់នៃបាល់លើអ័ក្សនៅគ្រប់ចំណុចគឺជាការធ្លាក់ពិតនៃស្វ៊ែរលើ mesh របស់គ្រឿង ពីចំហៀងនោះ។

## ដែនកំណត់

- ការបញ្ចប់ 5 អ័ក្ស និងបង្វិលយកតែ **ដែកកាត់ចុងបាល់** ប៉ុណ្ណោះ។ គ្មានការកាត់ swarf (ចំហៀងនៃឧបករណ៍លើជញ្ជាំងដែលមានបន្ទាត់), គ្មានខ្សែ flow តាមទិសផ្ទៃផ្ទាល់, គ្មានការកាត់ដំបូងច្រើនអ័ក្ស ហើយគ្មានការជ្រើសរើសស្វ័យប្រវត្តិនៃការផ្អៀងដើម្បីជៀសវាងការប៉ះទង្គិច។
- ផ្លូវ 5 អ័ក្ស និងបង្វិល **មិនត្រូវបានដំណើរការតាមការក្លែងធ្វើដុំវត្ថុ** ដែលជាផែនទីកម្ពស់ ហើយមិនអាចផ្ទុកការកាត់ផ្អៀងបានទេ។
- ដងនៃការបញ្ចប់ 5 អ័ក្សត្រូវបានពិនិត្យធៀបនឹងគំរូដែលមើលពីលើ; ដៃកាន់ ស្ពីនដែល និងម៉ាស៊ីនផ្ទាល់មិនត្រូវបានពិនិត្យនៅកន្លែងណាទេ។
- ការបញ្ចប់បង្វិលកាត់តែអ្វីដែលឧបករណ៍អាចមើលឃើញពីការក្រឡេកមើលទៅអ័ក្ស។
- ការបញ្ចប់ 5 អ័ក្សត្រូវការពេលមួយនាទី ឬច្រើនជាងនេះដើម្បីគណនាលើគ្រឿងធំ៖ ដងត្រូវបានពិនិត្យនៅគ្រប់ចំណុចនៃគ្រប់ការឆ្លងកាត់។
- នៅពេលអ័ក្សបង្វិលផ្លាស់ទីជាមួយអ័ក្សលីនេអ៊ែរ ហើយ TCP បិទ post ភ្ជាប់មកសរសេរការចង្អុលជាពេលបញ្ច្រាស (`G93`) ហើយបន្ទាប់មកត្រលប់ទៅ `G94`។
- គ្មានកូដប្លង់ការងារផ្អៀង (`G68.2` និងស្រដៀងគ្នា) ត្រូវបានសរសេរ ហើយគ្មានដែនកំណត់ជាក់លាក់ម៉ាស៊ីន ការមិនបត់ ឬតំបន់ប៉ះទង្គិចត្រូវបានស្គាល់ទេ។
