## ភាពខុសគ្នាដែលធ្វើឱ្យមនុស្សជំពប់

**គំនូរព្រាងទាំងមូលគឺជាប្រូហ្វាយល៍។** ទាញចេញ និងបង្វិលប្រើរង្វិលបិទទាំងអស់ក្នុងគំនូរព្រាង។ អ្នកមិនអាចជ្រើសតំបន់ ឬខ្សែព្រំដែនមួយនៃគំនូរព្រាងសម្រាប់លក្ខណៈបានទេ។ ប្រើគំនូរព្រាងមួយក្នុងមួយលក្ខណៈ។

**លក្ខណៈយកគំនូរព្រាងណា។** លក្ខណៈប្រើគំនូរព្រាងដែលអ្នកទើបតែបិទ ឬដែលបានជ្រើសក្នុងប្រវត្តិ។ បើមិនបានជ្រើសអ្វីសោះ វាយកគំនូរព្រាងថ្មីបំផុតដែលមិនទាន់មានលក្ខណៈណាប្រើ។ បើអ្នកទទួលបានមួយខុស ជ្រើសគំនូរព្រាងត្រឹមត្រូវ ហើយជ្រើសលក្ខណៈម្ដងទៀត។

**ការផ្លាស់ប្ដូរអនុវត្តខណៈអ្នកវាយ។** គ្មានប្រអប់លក្ខណៈជាមួយ OK និង Cancel ទេ។ លេខនីមួយៗសាងសង់ឡើងវិញភ្លាមៗ ហើយ {{key:Mod+Z}} គឺជាផ្លូវត្រឡប់។ បញ្ជីមិនធ្វើវិញគ្របដណ្ដប់លើការកែគំនូរព្រាង លក្ខណៈ និងការកំណត់ដូចគ្នា។

**កំណត់លើសមិនត្រូវបានអនុញ្ញាតឱ្យនៅស្ងៀមទេ។** គ្មានវិមាត្របញ្ជា (យោង) ទេ។ វិមាត្រមួយដែលទំនាក់ទំនងផ្សេងទៀតកំណត់រួចហើយ ត្រូវបានរាយការណ៍ថាកំណត់លើស ("ត្រូវបានបញ្ជាក់រួចហើយ។ លុបវា។")។ វិមាត្រដែលប៉ះទង្គិចទុកធរណីមាត្រមិនប៉ះពាល់ ហើយប្រែពណ៌ក្រហម។ លុបមួយ ឬមិនធ្វើវិញ។

**ស្វីប និងឡុហ្វមិនទាន់សាងសង់; Fillet, chamfer, shell និងទំនោរមានដែនកំណត់។** កំណែ PartCraft នេះសាងសង់គ្រប់គ្រឿងដោយ mesh kernel; ឈីបរបារស្ថានភាពតែងតែនិយាយថា "Mesh kernel"។ Fillet និង chamfer ដំណើរការលើគែមត្រង់រវាងផ្ទៃរាបពីរ ហើយកន្លែងដែលការបង្គត់ជួបគ្នាត្រង់ជ្រុង ពួកវាត្រូវបានកាត់ជា mitre មិនមែនលាយទេ។ Shell បើក ហើយទំនោរផ្អៀង តែលើផ្ទៃរាបប៉ុណ្ណោះ។ លក្ខណៈដែលត្រូវការ exact kernel នៅតែចុចបាន ប៉ុន្តែនិយាយថា "មិនទាន់សាងសង់" នៅពេលជ្រើស។ សូមមើល [mesh kernel](topic:solid-kernels) និង [អ្វីដែលមិនទាន់សាងសង់](topic:not-built-yet)។

**ប៊ូតុងពីរដែលហៅថា Fillet។** ក្នុងគំនូរព្រាង {{ui:Fillet}} ({{key:F}}) បង្គត់ជ្រុងគំនូរព្រាង។ លើគ្រឿង {{ui:Fillet}} ក្នុងក្រុមលក្ខណៈ បង្គត់គែមរូបរាងរឹង (គែមត្រង់រវាងផ្ទៃរាបក្នុងកំណែនេះ)។ មិនមានស្វីប ឬឡុហ្វក្នុងកំណែនេះទេ៖ សូមមើល [អ្វីដែលមិនទាន់សាងសង់](topic:not-built-yet)។

**រន្ធត្រូវការចំណុចដោយឥតទំនាក់ទំនង។** {{ui:រន្ធ}} ខួងនៅចំណុចដែលបានបង្កើតដោយឧបករណ៍ {{ui:ចំណុច}}។ ផ្ចិតរង្វង់ និងចុងបន្ទាត់មិនរាប់ទេ។

**ឆ្លងកាត់ទាំងអស់សម្រាប់តែការកាត់។** បូសត្រូវការជម្រៅ។ មិនទាន់មានលក្ខខណ្ឌបញ្ចប់ "ដល់ចំនុចកំពូល / ផ្ទៃ / បន្ទាប់" ទេនៅពេលនេះ។

**រូបរាងរឹងត្រូវបានកាត់ជាផ្ទៃ។** mesh kernel សាងសង់ផ្ទៃមូលពីផ្ទៃរាបល្អិតៗ ដូច្នេះទិដ្ឋភាព បរិមាណ និងការនាំចេញ STL និង 3MF ត្រូវបានធ្វើពីពួកវា៖ **ខ្សែកោង** ក្នុងផ្ទាំងគ្រឿងធ្វើឱ្យពួកវាល្អិតជាងនេះ។ ការនាំចេញ STEP ពិតមិនមែនដូច្នេះទេ៖ វាសរសេរផ្ទៃមូលនៅលើផ្ទៃពិតរបស់ពួកវា។

**មីលីម៉ែត្រតែប៉ុណ្ណោះ។** មិនទាន់មានការកំណត់អ៊ីញទេ។ គុណទំហំអ៊ីញនឹង 25.4 នៅពេលអ្នកវាយវា។

**ចំណុចភ្ជាប់គឺជាផ្ទៃ មិនមែនគូធរណីមាត្រទេ។** ចំណុចភ្ជាប់តែងតែចាប់ផ្ដើមពីផ្ទៃរាបពីរដែលដាក់ទល់ផ្ទៃ។ សម្រាប់ចង្កឹះក្នុងរន្ធ ជ្រើសផ្ទៃរាបជុំវិញរន្ធ និងស្មារបស់ចង្កឹះ បន្ទាប់មកកំណត់ **ផ្ចិតនៅ** ទៅអ័ក្សរន្ធ និងអ័ក្សបង្វិលរបស់ចង្កឹះ។ គ្រឿងដែលចំណុចភ្ជាប់មិនទៅដល់នៅតែនៅកន្លែងដែលពួកវាត្រូវបានបញ្ចូល; អ្នកមិនអាចអូសវាបានទេ។ ចំណុចភ្ជាប់ក្នុងរង្វិលមិនត្រូវបានដោះស្រាយទេ។
