## អ្វីដែលអ្នកនឹងធ្វើ

ផ្តល់ **ទំហំទាំងអស់នៃផ្នែកមួយក្នុងពេលតែមួយ**៖ ឯកសារ STEP, IFC និង DWG មួយ និងរូបមួយសម្រាប់ការកំណត់រចនាសម្ព័ន្ធនីមួយៗ តារាងដែលប្រាប់ថាម្យ៉ាងៗជាអ្វី និងធាតុបណ្ណាល័យដែលដាក់ទាំងអស់នៅលើទំព័រតែមួយ។

ដំបូងអ្នកត្រូវការផ្នែកដែលមាន **ការកំណត់រចនាសម្ព័ន្ធ** (សូមមើល [ការកំណត់រចនាសម្ព័ន្ធ និងតារាងការរចនា](topic:design-tables))។ ការកំណត់រចនាសម្ព័ន្ធដែលបិទលក្ខណៈមួយ ដូចជាបន្ទះដែលមាន និងគ្មានរន្ធ ក្លាយជាវ៉ារ្យ៉ង់របស់វាផ្ទាល់។

## ជំហាន

1. បើកផ្នែក។ នៅផ្ទាំង {{ui:ប៉ារ៉ាម៉ែត្រ}} ស្វែងរក **ការកំណត់រចនាសម្ព័ន្ធ**។
2. ចុច {{ui:កញ្ចប់វ៉ារ្យ៉ង់…}}។
3. ធីកការកំណត់រចនាសម្ព័ន្ធដែលត្រូវសាងសង់ (ទាំងអស់ត្រូវបានធីក) និងឯកសារដែលត្រូវសរសេរ៖ STEP, IFC, DWG រូបមើលជាមុន និងធាតុបណ្ណាល័យ។
4. ចុច {{ui:បង្កើតកញ្ចប់}}។ បន្ទាត់ស្ថានភាពរាប់វ៉ារ្យ៉ង់ពេលពួកវាត្រូវបានសាងសង់; ផ្នែករបស់អ្នកមិនត្រូវបានផ្លាស់ប្តូរទេ។
5. ឯកសារ zip មួយនឹងទាញចុះ៖ `<part> variants.zip`។

ឯកសារត្រូវបានដាក់ឈ្មោះតាមការកំណត់រចនាសម្ព័ន្ធ។ ការកំណត់រចនាសម្ព័ន្ធដែលសាងសង់មិនបាន (លក្ខណៈមួយដែលមិនអាចធ្វើបានជាមួយតម្លៃទាំងនោះ) ត្រូវបានលុបចេញពីឯកសារ និងតារាង ហើយត្រូវបានរាយក្នុង README និងក្នុងសារបន្ទាប់ពីរក្សាទុក zip; ការកំណត់រចនាសម្ព័ន្ធផ្សេងទៀតនៅតែត្រូវបានសរសេរ។

## គួរដឹង

- **STEP** គឺពិតប្រាកដនៅពេលខឺណែលពិតត្រូវបានបើកក្នុងកំណែរបស់អ្នក។ បើគ្មានវា STEP ជាមុខ (ត្រីកោណរាប) ហើយ README និយាយដូច្នេះ។
- **DWG** គឺជាសន្លឹកគំនូរប្លង់ មិនមែនម៉ូដែល 3D ទេ។ បន្ទាត់របស់វាមកពីមែស ដូច្នេះគែមកោងគឺជាបន្ទាត់ខ្លីជាច្រើន។
- **ធាតុបណ្ណាល័យ** ផ្ទុកតួមួយ និងស្នាមជើងមួយសម្រាប់វ៉ារ្យ៉ង់នីមួយៗ ក្នុងអ័ក្សរបស់បណ្ណាល័យផ្ទាល់៖ Z ឡើងលើ ផ្នែកខាងមុខទៅ −Y និងចំណុចបញ្ចូលនៅកណ្តាលផ្នែកខាងក្រោយនៅផ្នែកខាងក្រោម។ ផែនការគឺចតុកោណព្រំដែនរបស់វ៉ារ្យ៉ង់នីមួយៗ។ ធាតុមួយត្រូវបានកំណត់ទំហំ 8 MB ដូច្នេះវ៉ារ្យ៉ង់ធ្ងន់ខ្លាំងក្លាយជាប្រអប់ទំហំរបស់វា ហើយ README បង្ហាញចំនួនវា។
- ការកំណត់រចនាសម្ព័ន្ធសកម្មរបស់ផ្នែកគឺជាវ៉ារ្យ៉ង់លំនាំដើមរបស់ធាតុ។
- ច្រក (ចំណុចភ្ជាប់សម្រាប់បំពង់ និងបំពង់ខ្យល់) មិនត្រូវបានកំណត់ពី PartCraft ទេ។

## ដាក់វ៉ារ្យ៉ង់នៅលើទំព័របណ្ណាល័យ

ផ្ទុកឡើង `<part>.item.json` នៅ **បណ្ណាល័យ › ផ្ទុកឡើង** លើគេហទំព័រ។ ជ្រើសរើសប្រភេទ អាជ្ញាបណ្ណ និងសេចក្តីឥណទានរបស់អ្នក ហើយវានឹងក្លាយជាធាតុបណ្ណាល័យជាមួយវ៉ារ្យ៉ង់របស់វា។ នៅ BimCraft ពេលដាក់វា វាសួរថាវ៉ារ្យ៉ង់ណា ហើយ {{ui:ប្តូរ}} ផ្តល់ជម្រើសផ្សេងទៀត។ ទំព័រដែលអ្នកមើលជ្រើសជម្រើស មើល 3D និងទាញយកវ៉ារ្យ៉ង់ គឺជា**ការមើលជាមុនសម្រាប់បុគ្គលិក** សម្រាប់ពេលនេះ៖ វាមិនទាន់បើកជាសាធារណៈនៅឡើយទេ។

## ពីបន្ទាត់ពាក្យបញ្ជា

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` ដាក់ឈ្មោះការកំណត់រចនាសម្ព័ន្ធ `--formats` ជាទម្រង់ណាមួយក្នុង `step`, `ifc`, `dwg`, `preview`; `--no-item` មិនរួមបញ្ចូលធាតុបណ្ណាល័យ។ វាសរសេរថត zip ឬទាំងពីរ ហើយចេញដោយកូដ 1 នៅពេលវ៉ារ្យ៉ង់មិនអាចសាងសង់បាន។ សូមមើល [ស្គ្រីប និងបន្ទាត់ពាក្យបញ្ជា](topic:scripts-and-cli)។
