បណ្ណាល័យវិភាគគឺជាសំណុំនៃស្គ្រីប ដែលនីមួយៗជាអនុគមន៍ដែលអ្នកអាចអានពីដើមដល់ចប់៖ របៀបដែលម៉ាទ្រីសភាពរឹងត្រូវបានផ្គុំ ល័ក្ខខណ្ឌព្រំដែនទៅទីណា អ្នកដោះស្រាយណាដំណើរការ និងរបៀបដែលលទ្ធផលត្រូវបានគណនា។ គ្មានអ្វីនៅក្នុងវាត្រូវបានលាក់ក្នុងប្រអប់ខ្មៅទេ; មានតែរង្វិលខាងក្នុងដែលលឿន (ម៉ាទ្រីសធាតុ អ្នកដោះស្រាយស្រាល ការបង្កើតម៉ែស) ប៉ុណ្ណោះដែលត្រូវបានបង្កប់។

## ចាប់ផ្តើមជាមួយឧទាហរណ៍

ក្រុម **ឧទាហរណ៍** មានស្គ្រីបខ្លីចំនួនប្រាំដែលប្រើបណ្ណាល័យពីដើមដល់ចប់។ ចុចមួយ បន្ទាប់មកចុច {{ui:Open (read-only)}} រួចចុច {{key:F5}}៖ នីមួយៗសម្អាតទិដ្ឋភាព បង្ហាញលទ្ធផលលើផ្ទាំងកាត់ និងក្រាហ្វនៅក្នុងផ្ទាំងបង្ហាញរង។

| Electromagnet | ស្នូលដែករូបអក្សរ C ជាមួយចន្លោះខ្យល់ និងខ្សែមួយ៖ ដង់ស៊ីតេលំហូរ វាលក្នុងចន្លោះធៀបនឹងរូបមន្តសៀគ្វីម៉ាញេទិច អាំងឌុចតង់ស៍ និងកម្លាំងទាញឆ្លងចន្លោះ។ ពន្យល់ក្នុង [វាលម៉ាញេទិចក្នុង 2-D](topic:magnetic-fields-2d) |

## របៀបពិនិត្យបណ្ណាល័យ

ក្បាលរបស់អនុគមន៍នីមួយៗបញ្ចប់ដោយ **ការពិនិត្យ**៖ ករណីតូចមួយដែលមានចម្លើយដែលដឹង។ ការសាកល្បងរបស់ PartCraft ដំណើរការពួកវាទាំងអស់ ហើយកន្លែងដែល PartCraft មានការសិក្សារបស់ខ្លួនសម្រាប់ការងារដូចគ្នា ចម្លើយរបស់ស្គ្រីបត្រូវបានប្រៀបធៀបជាមួយការសិក្សានោះនៅលើម៉ែសដូចគ្នា៖

- ការពត់ចុងនៃ cantilever ធៀបនឹងទ្រឹស្តីធ្នឹម (ក្នុងកម្រិត 0.2 % ជាមួយខូប, 0.05 % ជាមួយតេត្រាហេដ្រា) និងធៀបនឹងអ្នកដោះស្រាយនៃផ្ទាំងការងារ **ការក្លែងធ្វើ** លើម៉ែសដូចគ្នា (ដូចគ្នាទាំងស្រុងដល់ខ្ទង់ជាច្រើន);
- ប្រេកង់ទីមួយនៃ cantilever ធៀបនឹងទ្រឹស្តីធ្នឹម (ទាបជាង 0.24 % ដូចដែលរំពឹងសម្រាប់ធ្នឹមខ្លី) និងធៀបនឹងអ្នកដោះស្រាយម៉ូដាល់របស់ **ការក្លែងធ្វើ**;
- កំដៅ៖ ជញ្ជាំងរាបស្មើដែលកំដៅយ៉ាងត្រឹមត្រូវ តួតូចដែលត្រជាក់ដូចរូបមន្តសមត្ថភាពរួម ហើយសីតុណ្ហភាពនៃបន្ទះដែលរលត់ដូចទ្រឹស្តី;
- ការបង្កើនប្រសិទ្ធភាពតូប៉ូឡូជី៖ `top88` បង្កើតឡើងវិញនូវ 94 ការធ្វើឡើងវិញ និងភាពអ៊ុតក្រញ៉ាក់ 203.1925 របស់ក្រដាស (និង 218.8032 ជាមួយតម្រងដង់ស៊ីតេ); `topopt3d` បញ្ចប់ត្រង់ភាពអ៊ុតក្រញ៉ាក់ដូចផ្ទាំងការងារ **បង្កើតដោយស្វ័យប្រវត្តិ** ជាមួយការកំណត់ដូចគ្នា;
- សមត្ថភាពកាប៉ាស៊ីទ័រ និងវាលសូឡេណូអ៊ីតវែង ធៀបនឹងតម្លៃក្នុងសៀវភៅ វាលចន្លោះនៃអេឡិចត្រូម៉ាញ៉េធៀបនឹងរូបមន្តសៀគ្វីម៉ាញេទិច និងម៉ាញ៉េអចិន្ត្រៃយ៍ធៀបនឹងម៉ាញ៉េរាងមូលក្នុងខ្យល់ និងម៉ាញ៉េដែលបិទដោយអ្នករក្សាដែក;
- លំហូរឆានែលធៀបនឹងប្រវត្តិល្បឿនប៉ារ៉ាបូឡាពិតប្រាកដ។

## អានអនុគមន៍

1. បើកផ្ទាំង **បណ្ណាល័យ** នៃផ្ទាំងស្គ្រីប។
2. ចុចអនុគមន៍។ ក្បាលរបស់វាបង្ហាញ៖ អ្វីដែលវាគណនា វិធីសាស្ត្រ ឯកតា សន្មត និងដែនកំណត់ **ឯកសារយោង** (សៀវភៅ ឬក្រដាស ជាមួយលេខសមីការ) និង **ការពិនិត្យ** — ករណីតូចមួយដែលមានចម្លើយដែលដឹង ហើយការសាកល្បងផ្ទាល់របស់ PartCraft ដំណើរការវា។
3. {{ui:Open (read-only)}} បើកស្គ្រីបទាំងមូលក្នុងផ្ទាំងដែលមានព្រំដែនដាច់ៗ។ អ្នកអាចដំណើរការវា ជ្រើសរើស និងដំណើរការផ្នែកខ្លះបាន ប៉ុន្តែមិនអាចផ្លាស់ប្តូរវាបានទេ។

## ផ្លាស់ប្តូរមួយ

ចុច {{ui:Make a copy}} (ឬ **ធ្វើច្បាប់ចម្លងដើម្បីកែ** នៅពីលើផ្ទាំងអានតែប៉ុណ្ណោះ)។ ច្បាប់ចម្លងគឺជាស្គ្រីបក្នុងគ្រឿងរបស់អ្នកដែលមានឈ្មោះដូចគ្នា ដូច្នេះវាត្រូវបានរក្សាទុកជាមួយគ្រឿង ហើយ **ការហៅអនុគមន៍នោះទាំងអស់ឥឡូវប្រើច្បាប់ចម្លងរបស់អ្នក** — កម្មវិធីកែនិយាយរឿងនេះនៅពីលើស្គ្រីប។ ប្តូរឈ្មោះច្បាប់ចម្លងដើម្បីរក្សាទាំងពីរ។

## ប្រើមួយ

ហៅអនុគមន៍បណ្ណាល័យពីស្គ្រីបណាមួយដោយឈ្មោះរបស់វា ដូចអនុគមន៍ដែលមានស្រាប់៖

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

លទ្ធផលត្រឡប់មកវិញជាតម្លៃក្នុងផ្ទាំងការងារ; ក្រាហ្វ និងវាលដែលវាបង្ហាញបង្ហាញនៅក្នុងទិដ្ឋភាព និងផ្ទាំងបង្ហាញរង។

ឧទាហរណ៍ ការវិភាគស្ថិតិនៃគ្រឿងដែលបើក ត្រូវការតែពីរបីបន្ទាត់៖

```
v = voxel_mesh(part(), 2);                   % ខូប 2 mm
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % ចាប់ផ្នែកខាងក្រោម
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 500 N ចុះលើផ្នែកខាងលើ
r = static_voxel(v, 210000, 0.3, bc);       % ដែក
```

`r` មានការផ្លាស់ទី ភាពតានតឹង និងប្រតិកម្ម; ភាពតានតឹង von Mises ត្រូវបានគូរលើគ្រឿងដែលបានផ្លាស់ទី។ សម្រាប់គ្រឿងកោង ប្រើ `tet_mesh` និង `static_tet` ដែលអាចផ្ទុក និងទ្រទាំងមុខទាំងមូលបាន (`face_nodes`)។

:::note
អនុគមន៍បណ្ណាល័យត្រូវបានសរសេរជា CraftScript ហើយស្គ្រីប Lua ហៅវាតាម `cs` ដូចអនុគមន៍ដែលមានស្រាប់៖ `cs.static_tet(t, 200000, 0.3, bc)` (សូមមើល [ស្គ្រីប Lua](topic:craftscript-lua))។ អនុគមន៍នីមួយៗដោះស្រាយសម្ភារៈមួយ និងករណីផ្ទុកមួយ; ក្បាលរបស់វាចុះបញ្ជីអ្វីដែលមិនបានគ្រប។
:::
