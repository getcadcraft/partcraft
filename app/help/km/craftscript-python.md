Python គឺជាភាសាទីបីនៃ[ផ្ទាំងការងារស្គ្រីប](topic:craftscript)។ ជ្រើសរើស **Python** នៅក្នុងប្រអប់ភាសាពីលើកម្មវិធីកែ (ឯកសារ `.py` បើកជា Python ដោយខ្លួនឯង)។ Python, Lua និង CraftScript ចែករំលែកអថេរដូចគ្នា និងអនុគមន៍ដែលមានស្រាប់ដូចគ្នា ដូច្នេះស្គ្រីប Python អាចប្រើអ្វីដែលស្គ្រីប CraftScript បានបង្កើត ហើយផ្ទុយមកវិញ។

ការដំណើរការ Python លើកដំបូងក្នុងការចូលមើលម្តង នឹងផ្ទុក Python ខ្លួនវា (CPython 3.14 ប្រហែល 7 MB) ពីគេហទំព័រនេះ ដែលចំណាយពេលពីរបីវិនាទី។ Python មិនទាន់ជាផ្នែកនៃ {{ui:Save for offline}} នៅឡើយទេ: ដំណើរការស្គ្រីប Python មួយនៅលើបណ្តាញជាមុនសិន។

## Python ត្រូវបានបិទជិត

ស្គ្រីប Python ត្រូវបានបិទជិតដូចស្គ្រីប CraftScript និង Lua៖ ពួកវាទៅដល់គ្រឿង អថេរ និងអនុគមន៍ដែលមានស្រាប់ ហើយគ្មានអ្វីផ្សេងទៀតទេ។ ការដំណើរការនីមួយៗគឺជា Python ថ្មីក្នុង sandbox ផ្ទាល់ខ្លួនជាមួយដើមឈើឯកសារតូចមួយនៅក្នុងអង្គចងចាំ (បណ្ណាល័យស្តង់ដារ និងថត `/tmp` ដែលបាត់ទៅក្រោយការដំណើរការ)។ វាមិនអាចទៅដល់បណ្តាញ ឯកសាររបស់អ្នក ឬទំព័រផ្សេងទៀតបានទេ ទោះក្នុងកម្មវិធីរុករក ឬក្នុងបន្ទាត់បញ្ជា។ ស្គ្រីបពីមនុស្សម្នាក់ទៀតនៅតែអាចប្រើពេលវេលា ឬអង្គចងចាំច្រើន: {{ui:Stop}} បញ្ចប់វា។

## ចំណុចសំខាន់

```
A = cs.magic(3)              # អនុគមន៍ដែលមានស្រាប់ទាំងអស់គឺ cs.<name>
B = A @ A.T                  # @ គឺជាផលគុណម៉ាទ្រីស .T គឺជាការផ្លាស់ប្តូរទិស
C = A * 2 + 1                # + - * / ** ធ្វើតាមធាតុ ដូច numpy
print(A[0, 1], A[-1, -1])    # ចាប់ពី 0; លេខអវិជ្ជមានរាប់ពីចុង
row = A[1]                   # សន្ទស្សន៍មួយលើម៉ាទ្រីស៖ ជួរដេក
big = A[A > 4]               # ម៉ាស្កតក្កវិជ្ជាជ្រើសធាតុ
A[0, 0] = -5                 # កំណត់ចូលទៅក្នុងអារ៉ាយ
V, D = cs.call('eig', 2, A)  # លទ្ធផលជាច្រើន៖ cs.call(name, ចំនួនប៉ុន្មាន, …)
```

- អារ៉ាយ 1 × 1 មកដល់ជាលេខធម្មតា; អារ៉ាយផ្សេងទៀត ម៉ាទ្រីសស្ពារ ម៉ែស វាល និងម៉ូដែលគឺជា **តម្លៃ**។
- តម្លៃមាន `shape` (tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (ចំនួនជួររបស់វា) និង `float()`, `int()` និង `bool()` សម្រាប់ធាតុតែមួយ។
- ការប្រៀបធៀប (`<`, `==`, …) ធ្វើតាមធាតុ ដូចក្នុង numpy: ពួកវាផ្តល់តម្លៃតក្កវិជ្ជា។
- បញ្ជីលេខដែលបញ្ជូនទៅអនុគមន៍ដែលមានស្រាប់ក្លាយជាអារ៉ាយ: `cs.sum([1, 2, 3])`។ `cs.tensor([[1, 2], [3, 4]])` បង្កើតម៉ាទ្រីសមួយ។
- វចនានុក្រមក្លាយជារចនាសម្ព័ន្ធ ហើយបញ្ជីនៃអ្វីចម្រុះជាក្រឡា ហើយត្រឡប់ទៅវិញបាន។

ឧបករណ៍សកលគ្រប់ដួងដែលស្គ្រីបរបស់អ្នកបង្កើត (លេខ តម្លៃ វចនានុក្រម បញ្ជី…) ចូលទៅក្នុងផ្ទាំង **Variables** នៅពេលការដំណើរការបញ្ចប់ សូម្បីតែបន្ទាប់ពីកំហុសក៏ដោយ។ ឈ្មោះដែលចាប់ផ្តើមដោយ `_` អនុគមន៍ ថ្នាក់ និងម៉ូឌុលនៅតែនៅក្នុង Python។ `ws.name` អាន ឬកំណត់អថេរដោយផ្ទាល់ ហើយ `ws_names()` បញ្ជីពួកវា។

`print(…)` សរសេរទៅកុងសូល។ `display(…)` (ឬ `cs.display`) បង្ហាញម៉ែស វាល ឬក្រាហ្វ ដូចក្នុង CraftScript។

## ហៅបណ្ណាល័យវិភាគ

អនុគមន៍បណ្ណាល័យត្រូវបានហៅដូចអនុគមន៍ដែលមានស្រាប់៖ `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`។ សរសេរឈ្មោះក្នុងស្គ្រីបដូចវាជា៖ PartCraft រកឃើញអនុគមន៍បណ្ណាល័យដែលស្គ្រីបប្រើ មុនពេលវាដំណើរការ។

## នៅមិនទាន់មាន

- numpy, scipy និងកញ្ចប់ផ្សេងទៀត: មានតែបណ្ណាល័យស្តង់ដាររបស់ Python ប៉ុណ្ណោះ (`math`, `json`, `itertools`, `decimal`, `statistics`…) ដោយគ្មានផ្នែកវិនដូ ទែមីណាល និងមូលដ្ឋានទិន្នន័យ (`tkinter`, `curses`, `sqlite3`)។
- Sockets និងអ្វីផ្សេងទៀតដែលនឹងទៅកាន់ខាងក្រៅ: Python មិនមានបណ្តាញនៅទីនេះទេ។
- `time.sleep` ត្រឡប់ភ្លាមៗ។
- ការបត់នៅក្នុងកម្មវិធីកែ និងការហៅអនុគមន៍ Python ពីស្គ្រីប CraftScript។
- ការដំណើរការពិនិត្យថវិកាការណែនាំ និង Stop រាល់ 1000 បន្ទាត់; ការគណនាវែងក្នុងអនុគមន៍ដែលមានស្រាប់មួយនឹងបញ្ចប់ជាមុន។
