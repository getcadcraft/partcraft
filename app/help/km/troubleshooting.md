នៅពេលអ្វីមួយមិនដំណើរការ សូមអានមុនគេ **របារស្ថានភាព** នៅខាងក្រោម៖ PartCraft ប្រាប់នៅទីនោះថាហេតុអ្វីវាបដិសេធ ឬអ្វីដែលវារំពឹងបន្ទាប់។ feature ដែលបរាជ័យក៏បង្ហាញសាររបស់វានៅកំពូលផ្ទាំងស្ដាំរបស់វា និងនៅពេលអ្នកចង្អុលជួរនៅក្នុងប្រវត្តិ។

## កម្មវិធីមិនចាប់ផ្ដើម

### "កម្មវិធីរុករកនេះមិនអាចបង្ហាញ 3D បាន (WebGL បិទ ឬបាត់) ដូច្នេះ PartCraft មិនអាចដំណើរការនៅទីនេះបានទេ។"

**មូលហេតុ៖** កម្មវិធីរុករកមានក្រាហ្វិក 3D (WebGL) បិទ បានរារាំង ឬមិនគាំទ្រដោយ driver ក្រាហ្វិក។

**ការដោះស្រាយ៖**

:::chromium
បើក `chrome://settings/system` (ឬ `edge://settings/system` ក្នុង Edge) ហើយបើក "Use graphics acceleration when available" បន្ទាប់មកចាប់ផ្ដើមកម្មវិធីរុករកឡើងវិញ។ បើវាបើករួចហើយ ពិនិត្យ `chrome://gpu` សម្រាប់ស្ថានភាព WebGL ហើយធ្វើបច្ចុប្បន្នភាព driver ក្រាហ្វិក។
:::

:::firefox
បើក `about:support` ហើយមើល Graphics, WebGL។ បើវាត្រូវបានរារាំង ធ្វើបច្ចុប្បន្នភាព driver ក្រាហ្វិក។ ក្នុង `about:config` `webgl.disabled` ត្រូវតែជា `false`។
:::

:::safari
WebGL តែងតែបើកក្នុង Safari បច្ចុប្បន្ន។ ធ្វើបច្ចុប្បន្នភាព macOS (Safari ធ្វើបច្ចុប្បន្នភាពជាមួយវា)។ បើនៅតែបរាជ័យ សាក Chrome ឬ Firefox លើ Mac ដូចគ្នា ដើម្បីដកចេញថាជាហាតវែរក្រាហ្វិក។
:::

ដែស្ក្ទុបពីចម្ងាយ និងម៉ាស៊ីនវែរ្ចួលមួយចំនួនគ្មាន WebGL។ សាកនៅលើកុំព្យូទ័រផ្ទាល់។

### "ខឺណែលសូលីដមិនបានផ្ទុក៖ …"

**មូលហេតុ៖** ខឺណែលធរណីមាត្រ (កម្មវិធី WebAssembly) មិនអាចទាញ ឬចាប់ផ្ដើមបានទេ។ ជាធម្មតា ការតភ្ជាប់ដាច់ពេលកម្មវិធីកំពុងផ្ទុក WebAssembly ត្រូវបានបិទដោយគោលការណ៍ក្រុមហ៊ុន ឬការកំណត់សុវត្ថិភាពកម្មវិធីរុករក ឬកម្មវិធីរុករកចាស់ខ្លាំង។

**ការដោះស្រាយ៖** ផ្ទុកទំព័រឡើងវិញពេលមានអ៊ីនធឺណិត។ បើនៅតែបរាជ័យ សាកកម្មវិធីរុករកបច្ចុប្បន្នមួយផ្សេង។ ក្នុង Firefox `javascript.options.wasm` ក្នុង `about:config` ត្រូវតែជា `true`។ ពេលគ្មានអ៊ីនធឺណិត កម្មវិធី និងខឺណែលរបស់វាផ្ទុកបានលុះត្រាតែរបារកម្មវិធីបាននិយាយ **Offline ready** មុនពេលអ្នកបាត់ការតភ្ជាប់ ({{ui:Save for offline}} ពេលមានអ៊ីនធឺណិត; សូមមើល [ធ្វើការក្រៅបណ្ដាញ](common:offline))។

### ប៊ូតុងក្រៅបណ្ដាញនិយាយថា "Could not save" ឬ "Offline not available"

**Could not save**៖ ឯកសារមួយចំនួនមិនបានទាញ។ ចុចវាដើម្បីសាកម្ដងទៀតពេលមានអ៊ីនធឺណិត; ការតភ្ជាប់យឺត ឬគិតថ្លៃអាចត្រូវការសាកម្ដងទៀត។ **Offline not available**៖ បង្អួចកម្មវិធីរុករកនេះមិនអាចរក្សាច្បាប់ក្រៅបណ្ដាញបានទេ (បង្អួចឯកជន និងកុំព្យូទ័រដែលគ្រប់គ្រងខ្លះរារាំងវា)។ ប្រើបង្អួចធម្មតា ឬរក្សាផ្ទាំងបើកទុក។

### "Sweep៖ មិនទាន់សង់ទេ។ វាត្រូវការខឺណែលត្រឹមត្រូវ …"

សាររួមទាំងអស់គឺ "<Name>៖ មិនទាន់សង់ទេ។ វាត្រូវការខឺណែលត្រឹមត្រូវ ដែលកំណែ PartCraft នេះមិនមាន។ ជំនួយ › អ្វីដែលមិនទាន់សង់ប្រាប់ថាត្រូវធ្វើអ្វីជំនួស។" អ្នកឃើញវាពេលអ្នកជ្រើស Sweep, Loft, Rib, ផ្នែកផ្លិតសន្លឹកដែក, feature ផ្ទៃ, Combine, Move body, Scale body ឬ Path pattern ហើយសម្រាប់របស់ផ្សេងទៀតដែលមានតែខឺណែលត្រឹមត្រូវអាចធ្វើបាន។ គ្មានអ្វីខុសជាមួយកម្មវិធីរុករក ឬផ្នែករបស់អ្នកទេ៖ កំណែ PartCraft នេះសង់ផ្នែកទាំងអស់ដោយខឺណែលក្រឡាចត្រង្គ។ សូមមើល [អ្វីដែលមិនទាន់សង់](topic:not-built-yet) សម្រាប់អ្វីដែលត្រូវធ្វើជំនួស និង [ខឺណែលក្រឡាចត្រង្គ](topic:solid-kernels)។

រង់ចាំបន្តិចលើការតភ្ជាប់យឺត៖ ខឺណែល និងបណ្ណាល័យ 3D ត្រូវបានទាញលើកដំបូង។ បន្ទាប់មកផ្ទុកឡើងវិញ។ បើទំព័រខ្លួនឯងបង្ហាញកំហុស សូមមើលខាងលើ។

- ចំនួន pattern ធំ (រយច្បាប់ចម្លង) ត្រូវការពេលសង់ឡើងវិញនៅគ្រប់ការផ្លាស់ប្ដូរ។ បិទ pattern ខណៈពេលធ្វើការលើ feature ផ្សេង។
- Clash និងការពិនិត្យចលនាប្រៀបធៀបគ្រប់គូនៃផ្នែក; ការផ្គុំធំត្រូវការពេលយូរ។
- បិទផ្ទាំងធ្ងន់ៗផ្សេងទៀត។ PartCraft ដំណើរការលើ processor និងក្រាហ្វិកកុំព្យូទ័ររបស់អ្នក។
