ឧបករណ៍បង្កើតគឺជាស្គ្រីបធម្មតា ([CraftScript](topic:craftscript), Lua ឬ Python) ដែលមានបន្ទាត់មតិយោបល់ពីរបីនៅផ្នែកខាងលើ។ PartCraft អានមតិយោបល់ ហើយបង្កើតទម្រង់; ស្គ្រីបរបស់អ្នកអានការបញ្ចូលជាអថេរដែលបានកំណត់រួចហើយ។

## បឋមកថា

ដាក់ទាំងនេះក្នុងបន្ទាត់មតិយោបល់ (`%` ក្នុង CraftScript, `--` ក្នុង Lua, `#` ក្នុង Python)៖

```
% @generator ឧបករណ៍ផ្លាស់ប្តូរកំដៅ
% @input mdot: kg/s = 0.2 [0.01 .. 10] "លំហូរម៉ាស់"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "ផ្ទៃ"
% @input solid: = true
% @input note: = "text"
```

ការបញ្ចូលគឺ `name: unit = default` បន្ទាប់មកជម្រើសជួរ `[min .. max]` (លេខត្រូវបានរក្សាទុកក្នុងនោះ), បញ្ជីជម្រើស `{a, b, c}` និងស្លាកក្នុងសញ្ញាសម្រង់។ ឯកតាគឺគ្រាន់តែជាស្លាកសម្រាប់ទម្រង់ប៉ុណ្ណោះ៖ **តម្លៃមកដល់ក្នុងឯកតានោះ** ដូច្នេះស្គ្រីបដែលចង់បាន SI ត្រូវបម្លែង ហើយ `to_si(value, 'kg/s', 'kg/s')` ក៏ពិនិត្យថាឯកតានោះមានន័យដូចដែលអ្នកគិតដែរ។ ឈ្មោះមានអក្សរ លេខ និងសញ្ញាក្រោម; `body`, `sheet` និង `problems` ត្រូវបានប្រើរួចហើយ។

## អ្វីដែលស្គ្រីបទុក

| អថេរ | មាតិកា |
|---|---|
| `body` | **តម្រូវ។** ផ្ទៃ mesh ជាធម្មតាមកពី `[body, info] = to_body(field, h)`។ វាត្រូវបានជួសជុល និងពិនិត្យនៅពេលដំណើរការបញ្ចប់។ |
| `sheet` | ស្រេចចិត្ត។ រចនាសម្ព័ន្ធ (struct)៖ វាលនីមួយៗជាលេខ ឬអត្ថបទ ឬរចនាសម្ព័ន្ធដែលមាន `value`, `unit`, `ref` និង `note`។ វាក្លាយជាសន្លឹកទិន្នន័យ។ |
| `problems` | ស្រេចចិត្ត។ ក្រឡា `problems` ពី `mfg_check(field, 'sls', struct(), h)` ឬធាតុផ្ទាល់ខ្លួនរបស់អ្នក។ វាទៅកាន់ការពិនិត្យ និងបញ្ជីបញ្ហា។ |

## ឧទាហរណ៍តូចពេញលេញ

```
% គូបប្រហោងមួយដែលមានជញ្ជាំង។
% @generator គូបប្រហោង
% @input side: mm = 12 [4 .. 40] "ជ្រុង"
% @input wall: mm = 1.5 [0.5 .. 5] "ជញ្ជាំង"
% @input h: mm = 0.5 [0.25 .. 2] "ទំហំ voxel"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'នៃ mesh');
```

វាបង្កើតប្រអប់បិទជិត ហើយការពិនិត្យរាយការណ៍ផ្ទៃខាងក្នុងដែលបិទជិតរបស់វាជាកំហុសសម្រាប់ដំណើរការម្សៅ។ ធ្វើឱ្យទំហំ voxel `h` មានតិចជាងមួយភាគបីនៃជញ្ជាំងស្តើងបំផុតដែលអ្នកចង់បាន៖ ក្រោមប្រមាណ បី voxel ជញ្ជាំងមិនគួរឱ្យទុកចិត្តទេ។

## វាល

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (រាងរឹងនៃការបង្វិលពីទម្រង់), `tpms` (ផ្ទៃ gyroid, Schwarz P និង diamond ជាមួយទំហំកោសិកា និងជញ្ជាំងដែលអាចផ្លាស់ប្តូរទូទាំងផ្នែក), `lattice` និង `lattice_beams`, `along` (ច្រកមូលតាមផ្លូវ), ប្រតិបត្តិការបូលីន `field_union`, `field_intersect`, `field_subtract`, `field_blend` ដែលរលូន, និង `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`។ `sample(f, points)` ផ្តល់ចម្ងាយដែលមានសញ្ញានៅចំណុច (អវិជ្ជមានខាងក្នុង), `field_voxel` ផ្តល់ voxel សម្រាប់អ្នកដោះស្រាយ។ [វាល](topic:fields) ពន្យល់ថាវាជាអ្វី។

ដែនកំណត់ដែលគួរដឹង៖ ជញ្ជាំងសន្លឹកដែលក្រាស់ជាងប្រមាណមួយភាគបួននៃកោសិកាបិទច្រកផ្លូវ; លក្ខណៈពិសេសស្តើងជាងប្រមាណ បី voxel អាចច្របាច់; `along` ភ្ជាប់កោណមូល ដូច្នេះកាំដែលផ្លាស់ប្តូរលឿនទុកឱ្យមានប៉ោង (ប្រើ `field_revolve` សម្រាប់ទម្រង់)។
