ផ្ទៃធ្វើការ **Form** បង្កើតរាងសរីរាង្គ។ អ្នកកែ **cage** ដែលជាក្រឡាចត្រង្គទូលាយនៃជ្រុង គែម និងមុខ។ រូបរាងគឺជាផ្ទៃរលូនដែល cage គ្រប់គ្រង (ដែនកំណត់ផ្ទៃ Catmull–Clark របស់វា) ដូច្នេះការផ្លាស់ទីជ្រុងមួយបត់ផ្ទៃនៅជុំវិញវាយ៉ាងទន់ភ្លន់។ នៅពេលដែលវាមើលទៅត្រឹមត្រូវ **Finish** បន្ថែមវាទៅប្រវត្តិផ្នែកជាលក្ខណៈ *Form* ហើយខឺណែលត្រឹមត្រូវបំប្លែងវាទៅជាផ្ទៃ B-spline ពិតប្រាកដ។ បន្ទាប់មកអ្នកអាចធ្វើ fillet វា កាត់វា ភ្ជាប់វាទៅលក្ខណៈផ្សេងទៀត និងនាំចេញជា STEP។

ជ្រើស **Form** នៅក្នុងបញ្ជី **Workspace** ផ្នែកខាងឆ្វេងនៃរបារឧបករណ៍។

## ចាប់ផ្តើម cage

1. កំណត់ **Size** និង **Divisions** នៅក្នុងផ្ទាំងខាងស្តាំ។ Divisions គឺចំនួនមុខដែលនីមួយៗមានម្ខាង។
2. ចុច {{ui:Box}}, {{ui:Quadball}} ឬ {{ui:Plane}} នៅក្នុងរបារឧបករណ៍។ ផ្ទាំងក៏មាន **Cylinder**, **Torus** និង **Faces by clicks**។

- **Quadball** គឺជា cage ប្រអប់ដែលត្រូវបានសម្រួលឲ្យចំណុចជ្រុងរបស់វានៅលើស្វ៊ែរ។ នៅចន្លោះចំណុចទាំងនោះ ផ្ទៃនៅក្នុងស្វ៊ែរបន្តិច៖ ប្រហែល 0.4 % តិចជាងបរិមាណជាមួយ 2 divisions។
- **Plane** គឺបើកចំហ ដូច្នេះវាក្លាយជាតួផ្ទៃ (សូមមើល "លក្ខណៈផ្ទៃនៅក្នុង Design" ខាងក្រោម)។
- **Faces by clicks**៖ ចុចចំណុច 4 នៅលើប្លង់កំពូល (ដី) ឬលើជ្រុងនៃ cage ដើម្បីបង្កើតមុខមួយ។ មុខដែលចែករំលែកជ្រុងភ្ជាប់គ្នា។ ចុច {{key:Enter}} បន្ទាប់ពី 3 ចំណុចសម្រាប់ត្រីកោណ ឬ {{key:Esc}} ដើម្បីបញ្ឈប់។

cage ដែលមិនទាន់បញ្ចប់របស់អ្នកត្រូវបានរក្សាទុកជាមួយឯកសារផ្នែក ដូច្នេះអ្នកអាចបិទឯកសារ ហើយបន្តពេលក្រោយ។

## ជ្រើស និងផ្លាស់ទី

- ចុចជ្រុង គែម ឬមុខនៃ cage។ {{key:Shift}}+ចុច បន្ថែមឬដកធាតុ។ {{key:Esc}} សម្អាតការជ្រើស។
- ឧបករណ៍ (gizmo) លេចឡើងនៅកណ្តាលការជ្រើស។ អូសព្រួញដើម្បីផ្លាស់ទីតាមវា ឬការេដើម្បីផ្លាស់ទីក្នុងប្លង់នោះ។ ចុច {{key:W}} ដើម្បីផ្លាស់ទី {{key:E}} ដើម្បីបង្វិល និង {{key:R}} ដើម្បីធ្វើមាត្រដ្ឋាន ឬប្រើប៊ូតុងក្នុងផ្ទាំង។ {{ui:Gizmo}} នៅក្នុងរបារឧបករណ៍ ឆ្លងកាត់ពួកវា។
- **Soft falloff** (mm) ក៏ទាញជ្រុងដែលនៅក្នុងចម្ងាយនោះ ហើយរសាត់ទៅសូន្យយ៉ាងរលូននៅគែមនៃចម្ងាយនោះ។
- ការអូសនីមួយៗគឺជាជំហានមិនធ្វើវិញមួយ៖ {{key:Ctrl+Z}} និង {{key:Ctrl+Y}} ដំណើរការដូចធម្មតា។

## កែ cage

ប៊ូតុង **Modify** នៅក្នុងផ្ទាំងធ្វើការលើការជ្រើស៖

| ប៊ូតុង | វាធ្វើអ្វី |
|---|---|
| {{ui:Extrude}} | មុខដែលបានជ្រើសផ្លាស់ទីចេញតាម **Extrude distance** តាមធម្មជាតិរបស់ពួកវា ជាមួយមុខចំហៀងថ្មី។ គែមបើកដែលបានជ្រើសបង្កើតមុខថ្មីចេញទៅក្រៅ។ |
| {{ui:Edge loop}} / Insert edge loop | បំបែកវង់នៃមុខបួនជ្រុងដែលឆ្លងកាត់គែមដែលបានជ្រើស នៅកណ្តាលផ្លូវ។ ច្រើនលូបផ្តល់ខ្សែកោងតឹងជាង។ |
| Insert point | បន្ថែមជ្រុងនៅកណ្តាលគែមដែលបានជ្រើស។ |
| Subdivide | បំបែកមុខដែលបានជ្រើសនីមួយៗទៅជាមុខបួនជ្រុងជុំវិញចំណុចកណ្តាលរបស់វា។ |
| Bridge | ភ្ជាប់មុខដែលបានជ្រើសពីរ ឬចំហពីរ (ជ្រើសគែមបើកមួយនីមួយៗ) ជាមួយបំពង់នៃមុខ។ ទាំងពីរត្រូវការចំនួនគែមដូចគ្នា។ |
| Fill hole | បិទចំហតាមគែមបើកដែលបានជ្រើសជាមួយមុខមួយ។ |
| Weld | បញ្ចូលជ្រុងដែលបានជ្រើសទៅជាមួយ នៅកណ្តាលរបស់វា។ |
| Flatten | ផ្លាស់ទីជ្រុងដែលបានជ្រើសទៅប្លង់ដែលសមបំផុតនឹងពួកវា។ |
| Delete | លុបមុខដែលបានជ្រើស គែម (មុខពីរបញ្ចូលគ្នា) ឬជ្រុង។ |

## គែមមុត ស៊ីមេទ្រី និងការបង្ហាញ

- {{ui:Crease}} ធ្វើឲ្យគែមដែលបានជ្រើសមុត។ **Crease weight** 10 គឺមុតពេញ។ ទម្ងន់ដែលតូចជាងនឹងនៅមុតសម្រាប់ជំហានការបំបែកចំនួនដូចនោះ ហើយបន្ទាប់មករលុង ដែលផ្តល់ឲ្យជ្រុងមូលតឹងជាជាងការបត់រឹង។ **Uncrease** ធ្វើឲ្យពួកវារលូនម្តងទៀត។ **Sharp vertex** ចាក់ជ្រុងមួយ ដូច្នេះផ្ទៃឆ្លងកាត់វាជាមួយចំណុច។
- **Symmetry** ឆ្លុះ cage ឆ្លងកាត់ X, Y ឬ Z = 0។ វារក្សាផ្នែកវិជ្ជមាន ឆ្លុះវា ហើយភ្ជាប់ពាក់កណ្តាលទាំងពីរ។ បន្ទាប់ពីនោះ ការកែនៅម្ខាងណាក៏កើតឡើងនៅទាំងពីរ។ ជ្រុងនៅលើប្លង់ឆ្លុះនៅតែនៅលើវា។
- {{ui:Display}} ប្តូររវាង **Smooth** (ផ្ទៃដែលលក្ខណៈនឹងក្លាយជា) និង **Box** (មុខ cage ខ្លួនឯង)។
- **Analysis**៖ **Zebra stripes** ឆ្លុះបន្ទាត់ពន្លឺពីទិដ្ឋភាពបច្ចុប្បន្ន។ ពួកវាកោងរលូនឆ្លងកាត់ផ្ទៃរលូន ហើយបែកនៅគែមមុត។ **Mean curvature** ពណ៌តំបន់ប៉ោងពណ៌ក្រហម តំបន់ខាំងពណ៌ខៀវ និងតំបន់រាបពណ៌ស។ វាវាស់នៅលើមែសដែលបង្ហាញដោយរូបមន្ត cotangent ដូច្នេះវាជាការណែនាំ មិនមែនជាការវាស់ទេ។

## ពិនិត្យនិងបញ្ចប់

- **Check exact** បំប្លែង cage នៅក្នុងខឺណែលត្រឹមត្រូវ ដោយមិនផ្លាស់ប្តូរផ្នែករបស់អ្នក។ វារាយការណ៍ថា cage បង្កើតបានប៉ុន្មាន B-spline patch ប៉ុន្មានត្រឹមត្រូវ និងថាលទ្ធផលជាដុំរឹងបិទជិតដែលត្រឹមត្រូវ ហើយបរិមាណរបស់វា។
- {{ui:Finish}} បន្ថែមលក្ខណៈ *Form* ទៅប្រវត្តិ ឬធ្វើបច្ចុប្បន្នភាពរូបរាងដែលអ្នកកំពុងកែ ហើយនាំអ្នកត្រឡប់ទៅ Design។ cage បិទជិតក្លាយជាដុំរឹង។ **Operation** របស់វានៅក្នុងផ្ទាំង Design អាចជា New body, Join, Cut ឬ Intersect។ cage បើកចំហក្លាយជាតួផ្ទៃ។
- ដើម្បីផ្លាស់ប្តូររូបរាងនៅពេលក្រោយ ជ្រើសវានៅក្នុងប្រវត្តិ ហើយចុច **Edit in Form**។ តួដែលបានសាងសង់ត្រូវបានលាក់ខណៈពេលអ្នកកែ cage របស់វា។
- **Discard** បោះ cage ចោលដោយមិនប៉ះប្រវត្តិ។

## អ្វីដែលត្រឹមត្រូវនិងអ្វីដែលប៉ាន់ស្មាន

មុខបួនជ្រុងនីមួយៗនៃ cage ដែលបានកែលម្អនៅពេលត្រូវការ ក្លាយជា bicubic B-spline patch មួយ។

- នៅកន្លែងដែលជ្រុងទាំងអស់នៃមុខមួយគឺ *ធម្មតា* (គែមបួនជួបគ្នានៅខាងក្នុងផ្ទៃ ឬបីនៅគែមបើកចំហ ឬតាមបណ្តោយការបត់) patch គឺ **ត្រឹមត្រូវ** ជាផ្ទៃ subdivision។ ការធ្វើតេស្តពិនិត្យនេះដល់ 1e-9 mm។
- នៅជុំវិញ **ចំណុចមិនធម្មតា** (គែមបី ប្រាំ ឬច្រើនជួបគ្នា ជ្រុងនៃមុខបីឬប្រាំជ្រុង ឬចុងនៃការបត់) គ្មាន polynomial patch ត្រឹមត្រូវទេ។ នៅទីនោះ patch យកចំណុចត្រឹមត្រូវនិងប្លង់តង់ហ្សង់ត្រង់ជ្រុងនោះ និងខ្សែកោងគែមរបស់អ្នកជិតខាង ដូច្នេះ patch នៅតែជួបគ្នាដោយគ្មានចន្លោះ។ ការបន្តតង់ហ្សង់នៅឆ្លងកាត់គែមដែលជួបគ្នាត្រង់ចំណុចនោះគឺប្រហាក់ប្រហែល។ ផ្ទាំង Form និងផ្ទាំងនៃលក្ខណៈផ្តល់មុំធំបំផុត ជាធម្មតាក្រោម 2°។ **Level** ខ្ពស់ជាងនៅក្នុងផ្ទាំងនៃលក្ខណៈធ្វើឲ្យ patch ទាំងនេះតូចជាង និងជិតជាង។
- គែមមុតដែលជាការបត់គឺជាគែមពិតនៃដុំរឹង ដូច្នេះអ្នកអាច fillet វាបាន។
- Patch នីមួយៗជាមុខរបស់វាផ្ទាល់ ដូច្នេះរូបរាងមានមុខច្រើន ហើយខ្សែត្រូវបានគូរនៅចន្លោះពួកវា។

## លក្ខណៈផ្ទៃនៅក្នុង Design

ពាក្យបញ្ជាផ្ទៃនៅក្នុងម៉ឺនុយ {{ui:More}} របស់ Design នៅក្រោមលក្ខណៈ។ ពួកវាត្រូវការខឺណែលត្រឹមត្រូវ។ តួផ្ទៃត្រូវបានគូរថ្លាពណ៌ខៀវ។ ពួកវាមិនមែនជាផ្នែកនៃដុំរឹងទេរហូតដល់អ្នកធ្វើឲ្យក្រាស់ ឬដេរពួកវា។

| ពាក្យបញ្ជា | វាធ្វើអ្វី |
|---|---|
| Patch | បំពេញរង្វិលបិទនៃគែម។ {{key:Shift}}+ចុចគែមនៃដុំរឹងជាមុនសិន ឬជ្រើសតួផ្ទៃដើម្បីបំពេញចំហរបស់វា។ **Tangent (G1)** ធ្វើឲ្យ patch ជួបផ្ទៃនោះដោយរលូន។ |
| Loft surface | ផ្ទៃឆ្លងកាត់ខ្សែកោងមួយខ្សែ ក្នុងមួយ sketch (បើកចំហ ឬបិទ) តាមលំដាប់ប្រវត្តិ។ |
| Stitch | ដេរតួផ្ទៃតាមគែមរួមរបស់ពួកវា។ បើពួកវាបិទ លទ្ធផលគឺជាដុំរឹង ដោយមាន Operation ដូចលក្ខណៈផ្សេងទៀត។ |
| Thicken | ផ្តល់កម្រាស់ដល់តួផ្ទៃ៖ តាមធម្មជាតិរបស់វា ទល់នឹងវា ឬពាក់កណ្តាលម្ខាងៗ។ លទ្ធផលគឺជាដុំរឹង។ |
| Offset surface | ច្បាប់ចម្លងនៃតួផ្ទៃដែលផ្លាស់ទីតាមធម្មជាតិរបស់វា។ ដើមនៅតែនៅ។ |
| Extend surface | ធ្វើឲ្យផ្ទៃមួយមុខលូតលាស់លើសពីគែមដែលអ្នកជ្រើស។ |
| Trim surface | កាត់តួផ្ទៃនៅកន្លែងដែលតួផ្ទៃផ្សេង ឬដុំរឹងឆ្លងកាត់វា។ ចុច **Pick a point on the piece** ដើម្បីជ្រើសចំណែកដែលត្រូវរក្សា ឬរក្សាអ្វីៗទាំងអស់ផ្សេងទៀត។ |

Stitch, Thicken, Extend និង Trim ប្រើតួផ្ទៃដែលពួកវាចាប់ផ្តើមពី។ លក្ខណៈក្រោយៗប្រើតួថ្មី។

ដែនកំណត់បច្ចុប្បន្ន៖ រូបរាងដែលមានផ្នែកបិទដាច់ដោយឡែកច្រើនមិនបំប្លែងទៅជាដុំរឹងតែមួយទេ; តំបន់ធម្មតាមិនត្រូវបានបញ្ចូលទៅជាផ្ទៃធំជាងទេ; និងសូមមើល [អ្វីដែលមិនទាន់សាងសង់](topic:not-built-yet)។
