បន្តរៀបចំម៉ូដែលនៅកន្លែងដែលអ្នកបង្កើតវា ហើយផលិត ពិនិត្យ និងកត់ត្រាវានៅទីនេះ។ ការផ្លាស់ប្ដូរនីមួយៗក្នុងកម្មវិធីផ្សេងទៀតជំនួសផ្នែកដែលបាននាំចូលមួយក្នុង PartCraft ហើយលក្ខណៈដែលនៅបន្ទាប់ពីវានឹងបង្កើតឡើងវិញលើរូបរាងថ្មី។

:::note
ការភ្ជាប់ត្រូវការ **CadCraft Studio** នៅលើកុំព្យូទ័រតែមួយ។ ផ្ទាំងកម្មវិធីរុករកមិនអាចទទួលការភ្ជាប់បានទេ។ គ្មានអ្វីឆ្លងកាត់អ៊ីនធឺណិតទេ៖ ស្គ្រីបនិយាយជាមួយ Studio នៅអាសយដ្ឋានរបស់កុំព្យូទ័រនេះផ្ទាល់ ជាមួយ token។
:::

:::warning
ការភ្ជាប់នេះត្រូវបានសាកល្បងជាមួយកម្មវិធីសរសេរឯកសាររបស់ស្គ្រីប និងកម្មវិធីជំនួសសម្រាប់កម្មវិធីផ្សេង មិនទាន់នៅខាងក្នុង Rhino ឬ Grasshopper ខ្លួនឯងនៅឡើយទេ។ បើមានអ្វីបរាជ័យនៅទីនោះ សូមប្រាប់យើងពីអ្វីដែលវាបាននិយាយ។

## ការរៀបចំ

1. នៅក្នុង Studio បើក PartCraft។ នៅ {{ui:ការកំណត់}} › {{ui:PartCraft}} › {{ui:ជំនួយការ}} ធីក **អនុញ្ញាតឱ្យជំនួយការ AI និងស្គ្រីបប្រើ PartCraft** បន្ទាប់មក **កែសម្រួល**។
2. នៅក្នុង Studio ជ្រើស {{ui:ភ្ជាប់ជំនួយការ}}។ វាបង្ហាញអាសយដ្ឋាន និង token ដែលអ្នកនឹងបិទភ្ជាប់ខាងក្រោម។
3. ទាញយកស្គ្រីប៖ [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)។

## ពី Rhino

1. ដំណើរការ `cadcraft_link.py` នៅក្នុងកម្មវិធីនិពន្ធស្គ្រីបរបស់ Rhino (Python 3 ក្នុង Rhino 8)។
2. លើកដំបូង បិទភ្ជាប់អាសយដ្ឋាន និង token។ ពួកវាត្រូវបានរក្សាទុកក្នុង `.cadcraft-link.json` នៅក្នុងថតផ្ទះរបស់អ្នក មិនដែលនៅក្នុងម៉ូដែលទេ។ Studio បង្កើត token ថ្មីរាល់ពេលវាចាប់ផ្ដើម ដូច្នេះស្គ្រីបនឹងសួរម្ដងទៀតនៅពេលនោះ។

ដំណើរការស្គ្រីបម្ដងទៀតដើម្បីបញ្ឈប់។

## ពី Grasshopper

ដំណើរការស្គ្រីបមួយដងនៅក្នុង Rhino ជាមុនសិន ដើម្បីរក្សាទុកអាសយដ្ឋាន និង token។

1. បន្ថែមសមាសធាតុ Script (Python 3) ហើយបិទភ្ជាប់ `cadcraft_link.py` ទាំងមូលចូលក្នុងវា។
2. ផ្ដល់ឱ្យវានូវបញ្ចូលទាំងនេះ៖ `G` (ធរណីមាត្រ ជាមួយការចូលប្រើបញ្ជី), `N` (ឈ្មោះ ជាជម្រើស), `On` (ប៊ូតុងបិទបើកប៊ូលេអាំង) និង `Target` (ជាជម្រើស៖ `model` ឬ `part` ប្រសិនបើកម្មវិធីទាំងពីរបើក)។
3. បើក `On` ទៅ true។

ការដោះស្រាយនីមួយៗផ្ញើ `G` ហើយជំនួសអ្វីដែលសមាសធាតុបានផ្ញើលើកមុន។

## របៀបដំណើរការនៅទីនេះ

- **ផ្នែកតែមួយ។** អ្វីៗទាំងអស់ដែលមើលឃើញក្នុងម៉ូដែលក្លាយជាលក្ខណៈដែលបាននាំចូលមួយ ដូចពេលអ្នក[បើកឯកសារ .3dm](topic:open-3dm-files)។
- **វាត្រូវតែបិទ។** PartCraft បំពេញប្រហោងតូចៗ និងចំហរាបៗ ហើយកម្មវិធីផ្សេងទៀតត្រូវបានប្រាប់ថាមានប៉ុន្មាន។ បើម៉ូដែលនៅតែមិនបិទ PartCraft រក្សាផ្នែកដែលវាមាន ហើយរបារស្ថានភាពនិយាយបែបនោះ។ ការផ្លាស់ប្ដូរបន្ទាប់ដែលបិទនឹងធ្វើបច្ចុប្បន្នភាពវា។
- **បញ្ចប់អ្វីដែលអ្នកកំពុងធ្វើ។** ក្នុងស្កេច ឬគំនូរប្លង់ ការធ្វើបច្ចុប្បន្នភាពត្រូវបានបដិសេធ ហើយព្យាយាមម្ដងទៀត; វានឹងមកដល់ពេលអ្នកត្រឡប់ទៅម៉ូដែលវិញ។
- **មិនធ្វើវិញ។** ការធ្វើបច្ចុប្បន្នភាពដែលនៅក្នុងរយៈពេលពីរវិនាទីនៃគ្នាទៅវិញទៅមក ចែករំលែកជំហានមិនធ្វើវិញមួយ។
- **រក្សាទុក។** ឯកសារផ្នែករក្សាការភ្ជាប់។ ដំណើរការស្គ្រីបម្ដងទៀតបន្ទាប់ពីអ្នកបើកវាឡើងវិញ ហើយលក្ខណៈដដែលនឹងធ្វើបច្ចុប្បន្នភាព។

**ផ្លូវតែមួយ។** ការផ្លាស់ប្ដូរនៅទីនេះមិនត្រឡប់ទៅកម្មវិធីផ្សេងទៀតទេ។
