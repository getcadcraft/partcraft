ការវិភាគក្នុងផ្ទាំងការងារស្គ្រីបគឺជាស្គ្រីបខ្លីៗពីរបីដែលផ្ទេរអថេរឲ្យគ្នាទៅវិញទៅមក។ ចាប់ផ្តើមពី[បណ្ណាល័យ](topic:craftscript-library) មួយដែលជិតនឹងអ្វីដែលអ្នកត្រូវការ ធ្វើច្បាប់ចម្លង ហើយកែវា; ឬសាងសង់វាឡើងដូចខាងក្រោម។

## 1. ម៉ែស

```
model = part();                  % គ្រឿងដែលអ្នកកំពុងធ្វើម៉ូដែល ជាម៉ូដែល
m = tetmesh(model, 4);           % តេត្រាហេដ្រាប្រហែល 4 mm ទទឹង
show(m)
```

ពិនិត្យម៉ែសនៅក្នុងទិដ្ឋភាពមុនពេលបន្ត៖ {{key:F}} ដាក់ទិដ្ឋភាពឲ្យសម ហើយ {{ui:eye}} នៅក្នុង **បានបង្ហាញ** លាក់គ្រឿង។

## 2. ផ្គុំ និងដោះស្រាយ

សរសេររង្វិលធាតុនៅក្នុងស្គ្រីប (វាអានដូចក្នុងសៀវភៅ) ហើយទុកផ្នែកធ្ងន់ឲ្យអនុគមន៍ដែលមានស្រាប់៖ ម៉ាទ្រីសធាតុ ការផ្គុំស្ពារពីត្រីកោណ និងអ្នកដោះស្រាយ conjugate gradient ជាមួយ preconditioner។ អនុគមន៍បណ្ណាល័យដូចជា `static_tet` (នៅពេលបណ្ណាល័យមានវា) គឺជាឧទាហរណ៍ពេញលេញដើម្បីចម្លង។

## 3. បង្ហាញលទ្ធផល

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % តម្លៃមួយក្នុងមួយចំណុច
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- ជួររបស់ផ្លាកលេខអាចវាយបញ្ចូល ឬកំណត់ឡើងវិញទៅ {{ui:Auto}}។
- ចុចម៉ែសដើម្បីអានតម្លៃនៅចំណុចមួយ។
- ក្រាហ្វដែលរក្សា `'id'` ដដែលនឹងត្រូវបានធ្វើបច្ចុប្បន្នភាពនៅនឹងកន្លែង ដូច្នេះបោះពុម្ព និងដាក់ក្រាហ្វនៅក្នុងរង្វិលរបស់អ្នក ដើម្បីមើលការបង្រួបបង្រួម។

## 4. ពិនិត្យវា

ប្រៀបធៀបជាមួយអ្វីដែលអ្នកដឹង៖ ការពត់ចុងនៃ cantilever ធៀបនឹង PL³/3EI, បន្ទះមានរន្ធធៀបនឹងកត្តាកំហាប់ភាពតានតឹងរបស់វា, ប្រតិកម្មធៀបនឹងបន្ទុក។ សរសេរការពិនិត្យជាស្គ្រីបដាច់ដោយឡែក ដូច្នេះវាដំណើរការម្តងទៀតបន្ទាប់ពីគ្រប់ការផ្លាស់ប្តូរ៖

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. រក្សាវា

- ជំហាននីមួយៗអាចជាផ្ទាំងស្គ្រីបរបស់វាផ្ទាល់៖ ពួកវាចែករំលែកអថេរ ដូច្នេះដំណើរការពួកវាមួយបន្ទាប់ពីមួយ។
- ស្គ្រីបត្រូវបានរក្សាទុកក្នុងគ្រឿង។ ដាក់សញ្ញា **រក្សាទុកអថេរជាមួយគ្រឿង** នៅផ្ទាំង Variables ដើម្បីរក្សាលទ្ធផលផងដែរ (រហូតដល់ 32 MB)។
- {{ui:Save}} ក្នុងក្រុម Script ទាញស្គ្រីបចុះដើម្បីចែករំលែក; {{ui:Open}} នាំវាចូល។
