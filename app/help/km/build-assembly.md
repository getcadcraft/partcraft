ការផ្គុំដាក់គ្រឿងមកជាមួយគ្នា។ នៅក្នុង PartCraft **ចំណុចភ្ជាប់** ដាក់គ្រឿង៖ ចំណុចភ្ជាប់នីមួយៗអង្គុយលើផ្ទៃរាបនៃគ្រឿងទាំងពីរ ហើយដាក់ពួកវាឱ្យទល់ផ្ទៃ។ ចំណុចភ្ជាប់បង្វិលអនុញ្ញាតឱ្យគ្រឿងមួយបង្វិល ស្លាយអនុញ្ញាតឱ្យវារអិល ចំណុចភ្ជាប់រឹងចាប់ទុកវា។

## ចាប់ផ្ដើមការផ្គុំ

1. សាងសង់គ្រឿងមួយដែលមានរូបរាងរឹង (គ្រឿងទទេមិនអាចចូលក្នុងការផ្គុំបានទេ៖ "សាងសង់រូបរាងរឹងជាមុនសិន បន្ទាប់មកដាក់វាចូលក្នុងការផ្គុំ។")
2. ជ្រើស {{ui:ការផ្គុំ}} នៅក្នុងរបារឧបករណ៍។

របារស្ថានភាពនិយាយថា "បានចាប់ផ្ដើមការផ្គុំជាមួយ Part1 ជាគ្រឿងជាប់ដី។ បញ្ចូលគ្រឿងបន្ថែម (បន្ថែមច្បាប់ចម្លង, បញ្ចូល, ឬ កែសម្រួល › ធ្វើច្បាប់ចម្លង) បន្ទាប់មកភ្ជាប់ពួកវា។" ផ្ទាំងខាងឆ្វេងឥឡូវបង្ហាញ **គ្រឿង** និង **ចំណុចភ្ជាប់** ហើយរបារឧបករណ៍បង្ហាញឧបករណ៍ការផ្គុំ។ ឧបករណ៍គំនូរព្រាង និងលក្ខណៈត្រូវលាក់។

គ្រឿងទីមួយគឺ **ជាប់ដី**៖ វាមិនដែលផ្លាស់ទីទេ ហើយអ្វីៗផ្សេងទៀតត្រូវបានដាក់ទាក់ទងនឹងវា។

## បញ្ចូលគ្រឿង

- {{ui:បន្ថែមច្បាប់ចម្លង}} បញ្ចូលច្បាប់ចម្លងមួយទៀតនៃគ្រឿងដែលបានជ្រើស (ឬនៃគ្រឿងចុងក្រោយ)។ ច្បាប់ចម្លងចែករំលែកគ្រឿងមួយ៖ កែវា ហើយច្បាប់ចម្លងទាំងអស់ផ្លាស់ប្ដូរ។
- {{ui:ធ្វើច្បាប់ចម្លង}} ({{key:Mod+D}}) ក្នុងក្រុម កែសម្រួល ធ្វើដូចគ្នាសម្រាប់គ្រឿងដែលបានជ្រើស។ {{key:Mod+C}} និង {{key:Mod+V}} ចម្លងគ្រឿង ហើយបិទភ្ជាប់វាក្បែរគ្រឿងផ្សេង នៅក្នុងការផ្គុំនេះ ឬមួយផ្សេង; {{key:Mod+Shift+V}} បិទភ្ជាប់វានៅកន្លែងដដែល។ សូមមើល [ចម្លង បិទភ្ជាប់ និងធ្វើច្បាប់ចម្លង](topic:copy-paste)។
- {{ui:បញ្ចូល}} បញ្ចូលគ្រឿងពីឯកសារ `.partcraft.json` នៅលើកុំព្យូទ័ររបស់អ្នក។ គ្រឿងត្រូវបានចម្លងចូលក្នុងការផ្គុំ។

គ្រឿងថ្មីបង្ហាញឡើងនៅខាងស្ដាំ 20 mm នៃអ្វីៗទាំងអស់ដែលមាននៅទីនោះរួចហើយ ហើយនៅទីនោះរហូតដល់ចំណុចភ្ជាប់ដាក់វា។ គ្រឿងដែលគ្មានចំណុចភ្ជាប់ក៏អាចផ្លាស់ទីដោយដៃបានដែរ៖ តម្លៃដែលបានវាយ ឬព្រួញដែលអ្នកអូស (សូមមើល [បញ្ជីគ្រឿង ទិដ្ឋភាពបែកចេញ និងការផ្លាស់ទីគ្រឿង](topic:assembly-bom-explode))។

## ភ្ជាប់គ្រឿងពីរ

1. ជ្រើស {{ui:ចំណុចភ្ជាប់}} ឬចុច {{key:J}}។ ផ្ទាំងខាងស្ដាំនិយាយថា **ចំណុចភ្ជាប់ថ្មី**។
2. ចុចផ្ទៃរាបលើគ្រឿងទីមួយ។ វាត្រូវបានបន្លិច។
3. ចុចផ្ទៃរាបលើគ្រឿងទីពីរ។

គ្រឿងទីពីរលោតដូច្នេះផ្ទៃរបស់វានៅជាប់នឹងផ្ទៃគ្រឿងទីមួយ ដោយប្រឈមមុខវា។ ចំណុចភ្ជាប់បង្ហាញនៅក្រោម **ចំណុចភ្ជាប់** ឧទាហរណ៍ "Revolute1" ហើយផ្ទាំងខាងស្ដាំបង្ហាញការកំណត់របស់វា។

- បើផ្ទៃទាំងពីរត្រូវបានបង្កើតដោយ បង្វិល ចំណុចភ្ជាប់ចាប់ផ្ដើមជា **បង្វិល**; បើមិនដូច្នោះទេ **រឹង**។ ផ្លាស់ប្ដូរវាក្រោយ។
- មិនអាចជ្រើសផ្ទៃកោងបានទេ៖ "ផ្ទៃនេះកោង។ ជ្រើសផ្ទៃរាប (ដើម្បីបង្វិលជុំវិញរន្ធ ឬអ័ក្សបង្វិល ជ្រើសវានៅក្នុងចំណុចភ្ជាប់ក្រោយ)។"
- {{key:Esc}} បោះបង់ចំណុចភ្ជាប់ដែលអ្នកបានចាប់ផ្ដើម (ឬចុចគ្រឿងក្នុងបញ្ជីខាងឆ្វេង)។

### ការកំណត់ចំណុចភ្ជាប់

| ការកំណត់ | មុខងាររបស់វា |
|---|---|
| **ប្រភេទ** | មួយក្នុងចំណោមចំណុចភ្ជាប់ក្នុងតារាងខាងក្រោម |
| **មុំ (°)** | បង្វិលគ្រឿងទីពីរជុំវិញអ័ក្សចំណុចភ្ជាប់ (កែងទៅផ្ទៃ) |
| **ការផ្លាស់ទី (mm)** | ផ្លាស់ទីគ្រឿងទីពីរតាមអ័ក្ស ចេញពីផ្ទៃ (តម្លៃអវិជ្ជមានរុញចូលក្នុងវា) |
| **តាម X**, **តាម Y**, **ទ្រេតជុំវិញ X**, **ទ្រេតជុំវិញ Y**, **តាមស្លុត**, **ទិសដៅស្លុត** | តម្លៃផ្សេងទៀត បង្ហាញសម្រាប់ចំណុចភ្ជាប់ដែលប្រើវា |
| **ផ្ចិតនៅ** (សម្រាប់ម្ខាងនីមួយៗ) | កន្លែងដែលអ័ក្សចំណុចភ្ជាប់ឆ្លងកាត់ផ្ទៃ៖ "ប្រភពដើមរបស់ផ្ទៃ" អ័ក្សនៃបង្វិល ("Axis of Revolve1") ឬអ័ក្សរន្ធមួយ ("Hole1, hole 2") |

តម្លៃនីមួយៗដែលចំណុចភ្ជាប់អនុញ្ញាតឱ្យផ្លាស់ទី មានរបារអូសនៅក្រោមប្រអប់របស់វា; តម្លៃផ្សេងទៀតត្រូវបានកំណត់ម្ដង។

| ចំណុចភ្ជាប់ | អ្វីដែលផ្លាស់ទី | កំណត់ម្ដង |
|---|---|---|
| **រឹង** | គ្មាន | មុំ, ការផ្លាស់ទី |
| **បង្វិល** | មុំ (ចីរ) | ការផ្លាស់ទី |
| **ស្លាយ** | ការផ្លាស់ទី (ថូ) | មុំ |
| **ស៊ីឡាំង** | មុំ និងការផ្លាស់ទី (ដើមក្នុងបាច់ធម្មតា) | |
| **ប្លង់** | តាម X, តាម Y ឆ្លងកាត់ផ្ទៃ និងមុំ (គ្រឿងរអិលលើតុ) | |
| **បាល់** | មុំ (បង្វិល) និងទ្រេតជុំវិញ X និង Y ជុំវិញផ្ចិតចំណុចភ្ជាប់ (ចំណុចភ្ជាប់បាល់) | |
| **ចង្កឹះក្នុងស្លុត** | តាមស្លុត និងមុំ (ចង្កឹះក្នុងស្លុតត្រង់) | **ទិសដៅស្លុត**៖ មុំស្លុតពី X នៃផ្ទៃ |

X និង Y នៃផ្ទៃគឺជារបស់ផ្ទៃគ្រឿងទីមួយ; ផ្ចិតចំណុចភ្ជាប់ត្រូវបានកំណត់ដោយ **ផ្ចិតនៅ**។

"ប្រភពដើមរបស់ផ្ទៃ" គឺជាប្រភពដើមរបស់គ្រឿងដែលបានបញ្ចាំងទៅផ្ទៃ ដែលជារឿយៗមិនមែនជាកន្លែងដែលអ្នកចង់ឱ្យគ្រឿងតម្រឹមទេ។ សម្រាប់គ្រឿងមូល និងចង្កឹះ កំណត់ **ផ្ចិតនៅ** ទៅអ័ក្សនៃបង្វិល ឬរន្ធនៅសងខាង៖ អ័ក្សនោះនឹងតម្រឹម ដូចការភ្ជាប់ដូចអ័ក្ស។

### ឧទាហរណ៍៖ ហ្វឡែនពីរដែលចងជាប់ដោយប៊ូឡុងទល់ផ្ទៃ

1. បើកគ្រឿងហ្វឡែន (បង្វិលដែលមានលំនាំរង្វង់នៃរន្ធ) ហើយជ្រើស {{ui:ការផ្គុំ}}។
2. ជ្រើស {{ui:បន្ថែមច្បាប់ចម្លង}}។
3. ចុច {{key:J}} ចុចផ្ទៃរាបនៃឌីសហ្វឡែនទីមួយ (ផ្ទៃដែលរន្ធប៊ូឡុងចាប់ផ្ដើមពី) បន្ទាប់មកផ្ទៃដូចគ្នានៅហ្វឡែនទីពីរ។ ផ្ទៃទាំងនោះត្រូវបានបង្កើតដោយការបង្វិល ដូច្នេះចំណុចភ្ជាប់គឺបង្វិល។
4. កំណត់ **ផ្ចិតនៅ** ទៅ "Axis of Revolve1" សម្រាប់សងខាង។ ហ្វឡែនឥឡូវចែករំលែកអ័ក្សមួយ។

## រង្វិលបិទ៖ ប្រព័ន្ធតភ្ជាប់

គ្រឿងដែលភ្ជាប់ជារង្វង់ (ប្រព័ន្ធតភ្ជាប់ four-bar, crank និង slider, ក្របខណ្ឌដែលទប់ពីរខាង) បង្កើតជា **រង្វិល**។ PartCraft ដោះស្រាយរាល់រង្វិលឱ្យវាបិទ៖ ចំណុចភ្ជាប់នៅលើវាយកតម្លៃដែលភ្ជាប់រង្វង់ឱ្យបិទ ដោយផ្លាស់ទីតិចបំផុតពីកន្លែងដែលពួកវានៅ។

- នៅក្នុងបញ្ជី ចំណុចភ្ជាប់នៅលើរង្វិលដែលនៅតែអាចផ្លាស់ទីបាន ជា **ពណ៌ខៀវ**៖ តម្លៃផ្សេងទៀតនៅតែអាចកំណត់បាន។ រង្វិលដែលមិនអាចផ្លាស់ទី (ក្របខណ្ឌទប់) នៅតែពណ៌ខ្មៅ។ រង្វិលដែលមិនអាចបិទបាន គឺ **ពណ៌ក្រហម**។
- ប្រអប់ **គ្រឿង** បង្ហាញ **រង្វិល**៖ មានប៉ុន្មានបិទ និងតម្លៃប៉ុន្មានអាចផ្លាស់ទីនៅឡើយ ឧទាហរណ៍ "1 បិទ; 1 តម្លៃអាចផ្លាស់ទីនៅឡើយ"។
- {{ui:ពិនិត្យចលនាសម្រាប់ការប៉ះទង្គិច}} ស្កេនចំណុចភ្ជាប់នៅលើរង្វិល ដោយរង្វិលធ្វើតាម ជាជំហានម្ដងមួយៗ (សូមមើល [ពិនិត្យការផ្គុំសម្រាប់ការប៉ះគ្នា និងចលនា](topic:check-assembly))។

ប្រព័ន្ធតភ្ជាប់រាបដែលរៀបចំពីដែកបន្ទះរាប ត្រូវតែស្របគ្នាក្នុងជម្រៅ៖ គ្រឿងពីរដែលភ្ជាប់ទល់ផ្ទៃនៅសងខាងរង្វិលត្រូវការកម្ពស់ស្ទីកដូចគ្នាទាំងពីរទិស។ ប្រើ **ការផ្លាស់ទី** របស់ចំណុចភ្ជាប់ដើម្បីលើកគ្រឿងនៅកន្លែងដែលស្ទីកមិនបូកគ្នា ឬរង្វិលមិនអាចបិទបាន។

## ធ្វើការជាមួយគ្រឿង

ចុចគ្រឿងក្នុងទិដ្ឋភាព ឬក្នុងបញ្ជី ដើម្បីជ្រើសវា។ ផ្ទាំងខាងស្ដាំបង្ហាញឈ្មោះគ្រឿង ចំនួនច្បាប់ចម្លង បរិមាណ ចំណុចភ្ជាប់ និងថាតើវាជាប់ដីឬត្រូវបានកំណត់ដោយចំណុចភ្ជាប់របស់វា ឬ "មិនបានភ្ជាប់៖ នៅតែកន្លែងដែលវាត្រូវបានដាក់" ។ ប៊ូតុង៖
