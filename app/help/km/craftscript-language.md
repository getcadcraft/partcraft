CraftScript គឺជាភាសាម៉ាទ្រីសដែលសរសេរឲ្យអានដូច MATLAB ដូច្នេះកូដលេខគណនាបុរាណភាគច្រើន (ឧទាហរណ៍ កូដបង្កើនប្រសិទ្ធភាពតូប៉ូឡូជី 88 បន្ទាត់) ដំណើរការបានជាមួយការកែតិចតួចប៉ុណ្ណោះ។ វាដំណើរការនៅក្នុង [ផ្ទាំងការងារស្គ្រីប](topic:craftscript) និងពីបន្ទាត់បញ្ជា។

## តម្លៃ

| ប្រភេទ | ឧទាហរណ៍ | កំណត់សម្គាល់ |
|---|---|---|
| លេខ អារ៉ាយ | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | លេខគ្រប់ប្រភេទគឺជាអារ៉ាយ (1×1 មួយ)។ អារ៉ាយត្រូវបានរក្សាទុកតាមជួរឈរ រហូតដល់ 8 វិមាត្រ |
| តក្កវិជ្ជា | `A > 2`, `true` | អារ៉ាយនៃ true/false; ប្រើជាសន្ទស្សន៍បាន |
| អក្សរ | `'beam'`, `"beam"` | |
| ម៉ាទ្រីសស្ពារ | `sparse(i, j, v, n, n)` | សម្រាប់ម៉ាទ្រីសភាពរឹង |
| ម៉ែស វាល ម៉ូដែល | `hexGrid(…)`, `part()`, `load('part.stl')` | អ្វីដែល `show` គូរ |
| រចនាសម្ព័ន្ធ | `s.E = 210e3` | វាលដែលមានឈ្មោះ |
| ក្រឡា | `c = {1, 'two', [3 4]}` | បញ្ជីនៃតម្លៃអ្វីក៏បាន |
| ឯកសារយោងអនុគមន៍ | `f = @(x) x.^2` | |

## អារ៉ាយ និងការដាក់លេខសន្ទស្សន៍

- ជួរ៖ `1:5`, `0:0.1:1`។ `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`។
- ការដាក់លេខសន្ទស្សន៍ចាប់ពី 1៖ `A(2, 3)`, `v(end)`, `A(:, 1)` (ជួរឈរទាំងមូល), `A(:)` (ទាំងអស់ជាជួរឈរមួយ), `v(v > 0)` (ការដាក់លេខសន្ទស្សន៍តក្កវិជ្ជា)។
- ការកំណត់តម្លៃហួសចុងនឹងធ្វើឲ្យអារ៉ាយធំឡើង ដូចក្នុង MATLAB៖ `v(10) = 1`។

## ប្រតិបត្តិករ

- `+ - * / \ ^` គឺជាប្រតិបត្តិការម៉ាទ្រីស (`A \ b` ដោះស្រាយ); `.* ./ .^` ដំណើរការធាតុម្តងមួយ។ `'` បំប្លែងទិសដៅ (transpose)។
- ការប្រៀបធៀប `== ~= < <= > >=`; តក្កវិជ្ជា `& | ~` (ធាតុម្តងមួយ) និង `&& ||` (short-circuit)។

## ការគ្រប់គ្រងលំហូរ និងអនុគមន៍

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

អនុគមន៍ត្រូវដាក់នៅក្នុងស្គ្រីបបន្ទាប់ពីពាក្យបញ្ជារបស់វា ឬនៅក្នុងផ្ទាំងស្គ្រីបរបស់វាផ្ទាល់ ដែលដាក់ឈ្មោះតាមអនុគមន៍នោះ៖

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ឈ្មោះមួយត្រូវបានស្វែងរកតាមលំដាប់នេះ៖ អថេរ ស្គ្រីបក្នុងគ្រឿងនេះដែលមានឈ្មោះនោះ អនុគមន៍បណ្ណាល័យ បន្ទាប់មកអនុគមន៍ដែលមានស្រាប់។

## បង្ហាញ មតិយោបល់ លទ្ធផល

- សេចក្តីថ្លែងការណ៍ដែលគ្មាន `;` នឹងបង្ហាញតម្លៃរបស់វា; `;` ធ្វើឲ្យវានៅស្ងៀម។
- `%` ចាប់ផ្តើមមតិយោបល់; `%{` និង `%}` នៅលើបន្ទាត់ដាច់ដោយឡែក នឹងដាក់បន្ទាត់ដែលនៅចន្លោះពួកវាជាមតិយោបល់។
- `disp(x)`, `fprintf('%g\n', x)` និង `display(x)` បោះពុម្ពទៅកុងសូល។

## កំហុស និងដែនកំណត់

- កំហុសនិយាយពីអ្វីដែលខុសជាពាក្យសាមញ្ញ ហើយផ្តល់បន្ទាត់ (និងខ្សែនៃការហៅអនុគមន៍)។
- ការដំណើរការនីមួយៗមានថវិកាជំហាន (ជម្រើសដំណើរការនៅក្នុងផ្ទាំង); រង្វិលដែលមិនចេះចប់ឈប់ជាមួយសារមួយ ឬចុច {{ui:Stop}}។
- អារ៉ាយនីមួយៗអាចផ្ទុកតម្លៃរហូតដល់ 134 លាន។

## ខុសពី MATLAB

- ពាក្យបញ្ជា plot ដាក់ជម្រើសរបស់វានៅក្នុងការហៅ៖ `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`។ `figure`, `hold`, `axis`, `title(…)` និងស្រដៀងគ្នាត្រូវបានទទួលយក ប៉ុន្តែមិនធ្វើអ្វីទេ។
- `input` និង `keyboard` មិនត្រូវបានគាំទ្រ៖ ស្គ្រីបមិនអាចឈប់ដើម្បីសួរសំណួរបានទេ។
- គ្មានប្រអប់ឧបករណ៍ឯកទេសទេ; [បណ្ណាល័យវិភាគ](topic:craftscript-library) និងអនុគមន៍ដែលមានស្រាប់ គឺជាអ្វីដែលមាន។
