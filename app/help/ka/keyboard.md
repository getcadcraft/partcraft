პანელის ველში ტექსტის წერისას კლავიშები არ მოქმედებს, გარდა {{key:Mod+S}} და {{key:Mod+O}} კომბინაციებისა, რომლებიც ყოველთვის მუშაობს. ასოების კლავიშები მოდიფიკატორის გარეშე მუშაობს.

ბრაუზერში კლავიშებზე და კლავიატურებზე, რომლებსაც ფუნქციონალური კლავიშები არ აქვთ, ზოგადი შენიშვნები: [კლავიშები, მაუსები და სენსორული პანელები](common:keys).

| {{key:Mod+O}} | დეტალის ან აწყობის ფაილის გახსნა (ჯერ კითხულობს, თუ არ შენახული ცვლილებებია) |
| {{key:Mod+Z}} | დაბრუნება |
| {{key:Mod+Y}} ან {{key:Mod+Shift+Z}} | გამეორება |

პანელის რიცხვით ველში {{key:Mod+Z}} ბრაუზერის საკუთარი ტექსტის დაბრუნებაა. ესკიზის ზომის რიცხვით ველში კი PartCraft-ში აბრუნებს მოქმედებას.

## კოპირება, ჩასმა და დუბლირება

ისინი მოქმედებს იმაზე, რასაც მუშაობთ: ღია ესკიზში მონიშნულ გეომეტრიაზე, ისტორიაში მონიშნულ ელემენტზე ან აწყობაში მონიშნულ დეტალზე. დეტალები: [კოპირება, ჩასმა და დუბლირება](topic:copy-paste).

| კლავიში | მოქმედება |
|---|---|
| {{key:Mod+C}} | მონიშნულის კოპირება |
| {{key:Mod+X}} | ამოჭრა: კოპირება, შემდეგ წაშლა |
| {{key:Mod+V}} | ჩასმა. ესკიზში ასლი მაჩვენებელს მისდევს: დააწკაპუნეთ, სადაც უნდა გადავიდეს |
| {{key:Mod+Shift+V}} | ჩასმა იმავე ადგილზე: იგივე კოორდინატებით (აწყობაში იმავე ადგილას) |
| {{key:Mod+D}} | დუბლირება: კოპირება და ჩასმა ერთ ნაბიჯად, ბუფერი უცვლელი რჩება |
| {{key:Mod+A}} | ყველას არჩევა (ესკიზში) |
| {{key:Esc}} | არაფრის არჩევა (და მაჩვენებელს მიმდევარი ჩასმის გაუქმება) |

რიცხვით ველში ეს კლავიშები ჩვეულებრივად აკოპირებს და ჩასვამს ტექსტს. პანელში მონიშნულ ტექსტს ბრაუზერი აკოპირებს.

## 3D ხედში

ჯერ ხედში დააწკაპუნეთ, რომ კლავიატურის ფოკუსი მიიღოს.

| ორთითიანი გადაადგილება სენსორულ პანელზე | ხედის შემობრუნება; {{key:Shift}} კლავიშით — პანორამირება. ორი თითის შეკუმშვა-გაშლა მასშტაბირებს. იწყობა **გადახვევით** [PartCraft-ის პარამეტრებში](topic:settings) |

[PartCraft-ის პარამეტრებში](topic:settings) **ხედის შებრუნება: შუა ღილაკი** ჩართვისას შუა ღილაკი აბრუნებს ხედს, {{key:Shift}} კლავიშით შუა ან მარჯვენა ღილაკი პანორამირებს, ხოლო მარცხენა ღილაკი მხოლოდ არჩევს.
| დაწკაპუნება | წახნაგის (მთლიანად ნათდება), წიბოს ან სიბრტყის არჩევა |
| {{key:Shift}}+დაწკაპუნება წიბოზე ან წახნაგზე | რამდენიმე წიბოს ან წახნაგის შეგროვება |
| დაწკაპუნება ცარიელ სივრცეზე | არჩევის მოხსნა |
