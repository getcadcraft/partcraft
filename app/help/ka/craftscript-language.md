CraftScript მატრიცული ენაა, დაწერილი ისე, რომ MATLAB-ის მსგავსად იკითხებოდეს, ამიტომ კლასიკური რიცხვითი კოდების უმეტესობა (მაგალითად, 88-ხაზიანი ტოპოლოგიური ოპტიმიზაციის კოდი) მცირე ცვლილებებით მუშაობს. ის [სკრიპტების სამუშაო სივრცეში](topic:craftscript) და ბრძანებათა ხაზიდან მუშაობს.

## მნიშვნელობები

| ტიპი | მაგალითი | შენიშვნები |
|---|---|---|
| რიცხვი, მასივი | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ყოველი რიცხვი მასივია (1×1 მასივი). მასივები ინახება სვეტ-სვეტად, 8 განზომილებამდე |
| ლოგიკური | `A > 2`, `true` | ჭეშმარიტი/მცდარი მასივები; ინდექსებად გამოიყენება |
| ტექსტი | `'beam'`, `"beam"` | |
| იშვიათი მატრიცა | `sparse(i, j, v, n, n)` | სიხისტის მატრიცებისთვის |
| ბადე, ველი, მოდელი | `hexGrid(…)`, `part()`, `load('part.stl')` | რას ხატავს `show` |
| სტრუქტურა | `s.E = 210e3` | დასახელებული ველები |
| უჯრედი | `c = {1, 'two', [3 4]}` | ნებისმიერი მნიშვნელობების სია |
| ფუნქციის მითითება | `f = @(x) x.^2` | |

## მასივები და ინდექსაცია

- დიაპაზონები: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- ინდექსაცია 1-დან იწყება: `A(2, 3)`, `v(end)`, `A(:, 1)` (მთელი სვეტი), `A(:)` (ყველაფერი ერთ სვეტად), `v(v > 0)` (ლოგიკური ინდექსაცია).
- ბოლოს მიღმა მნიშვნელობის მინიჭება მასივს ზრდის, როგორც MATLAB-ში: `v(10) = 1`.

## ოპერატორები

- `+ - * / \ ^` მატრიცული ოპერაციებია (`A \ b` ხსნის); `.* ./ .^` მუშაობს ელემენტ-ელემენტად. `'` ახდენს ტრანსპონირებას.
- შედარებები `== ~= < <= > >=`; ლოგიკა `& | ~` (ელემენტ-ელემენტად) და `&& ||` (მოკლედ შეფასებით).

## მართვის სტრუქტურები და ფუნქციები

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ფუნქციები სკრიპტში მის ბრძანებებს მოსდევს, ან საკუთარ სკრიპტის ჩანართში, რომელსაც ფუნქციის სახელი ჰქვია:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

სახელს ეძებენ ამ თანმიმდევრობით: ცვლადი, ამ ნაწილში ამ სახელის მქონე სკრიპტი, ბიბლიოთეკის ფუნქცია, ჩაშენებული ფუნქცია.

## ექო, კომენტარები, გამოტანა

- გამოსახულება `;`-ის გარეშე თავის მნიშვნელობას ბეჭდავს; `;` ჩუმად ტოვებს.
- `%` იწყებს კომენტარს; `%{` და `%}` საკუთარ ხაზებზე ჩაწერილი, შუალედურ ხაზებს აკომენტარებს.
- `disp(x)`, `fprintf('%g\n', x)` და `display(x)` კონსოლში ბეჭდავს.

## შეცდომები და ზღვრები

- შეცდომები მარტივი სიტყვებით ამბობს, რა მოხდა, და მიუთითებს ხაზს (და ფუნქციების გამოძახების ჯაჭვს).
- თითოეულ გაშვებას აქვს ნაბიჯების ბიუჯეტი (გაშვების ოფციები პანელში); უსასრულო ციკლი შეტყობინებით ჩერდება, ან დააჭირეთ გაჩერებას.
- თითოეულ მასივში 134 მილიონამდე მნიშვნელობაა.

## განსხვავება MATLAB-თან

- გრაფიკის ბრძანებები ოფციებს გამოძახებაში ათავსებს: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` და მსგავსი მიიღება და არაფერს არ აკეთებს.
- `input` და `keyboard` არ მუშაობს: სკრიპტი ვერ გაჩერდება კითხვის დასასმელად.
- ხელსაწყოების ნაკრებები არ არსებობს; არსებობს [ანალიზის ბიბლიოთეკა](topic:craftscript-library) და ჩაშენებული ფუნქციები.
