Lua არის [სკრიპტების სამუშაო სივრცის](topic:craftscript) მეორე ენა. აირჩიეთ **Lua** რედაქტორის ზემოთ მდებარე ენის ველში (`.lua` ფაილი თავისით იხსნება Lua-ში). Lua და CraftScript იზიარებენ ერთსა და იმავე ცვლადებს და ჩაშენებულ ფუნქციებს, ამიტომ Lua სკრიპტს შეუძლია გამოიყენოს ის, რაც CraftScript-მა შექმნა, და პირიქით.

## ძირითადი

```
-- ყველა ჩაშენებული ფუნქცია cs ცხრილშია
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-დან იწყება, CraftScript-ის მსგავსად
print(K(1, 1), #K)             -- ელემენტი; ელემენტების რაოდენობა

-- სამუშაო სივრცე: იგივე ცვლადები, რასაც ყველა სკრიპტი ხედავს
ws.total = K(1, 1) * 2
print(ws.total)

-- რამდენიმე შედეგი ერთი ფუნქციიდან
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` იძახებს ნებისმიერ ჩაშენებულ ფუნქციას და აბრუნებს მის პირველ შედეგს; `cs.call(name, n, …)` აბრუნებს `n` შედეგს.
- `cs.tensor({1, 2, 3})` ქმნის სტრიქონს, `cs.tensor({{1, 2}, {3, 4}})` — მატრიცას.
- მასივები, იშვიათი მატრიცები, ბადეები და ველები მნიშვნელობებია მეთოდებით: `t(i, j)` ან `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (ტრანსპონირება), `t:totable()`. `+ - * / ^` ნიშნავს იმას, რასაც CraftScript-ში (`*` მატრიცული ნამრავლია); `t:times(u)` ელემენტ-ელემენტად ამრავლებს.
- 1×1 მასივი, როგორც რიცხვი, ჩვეულ Lua რიცხვად მოდის.
- `ws.name` კითხულობს და წერს საერთო სამუშაო სივრცეს. გლობალური ცვლადები, რომლებსაც სკრიპტი ტოვებს, სკრიპტის დასრულებისას იქაც ხვდება.
- `print(…)` კონსოლში წერს; `cs.show(f)`, `cs.plot(y)` და სხვა ჩვენების ფუნქციები CraftScript-ის მსგავსად მუშაობს.

## ანალიზის ბიბლიოთეკის გამოძახება

ანალიზის ბიბლიოთეკის ფუნქციებს (ბიბლიოთეკის ჩანართი) და იმ CraftScript ფუნქციებს, რომლებსაც თქვენი ნაწილის საკუთარი სკრიპტები განსაზღვრავს, `cs`-ითაც მიწვდებით:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- ორი გამოსავალი
```

ისინი სკრიპტის დაწყებამდე ნაპოვნია, ამიტომ სახელი სკრიპტში ჩაწერეთ: `cs.static_tet(` ან `cs.call('static_tet', …)`. სახელი, რომელიც სკრიპტის გაშვებისას შედგება, მხოლოდ ჩაშენებულ ფუნქციებს აღწევს. `cs.struct({ … })`-ით აგებული სტრუქტურა CraftScript-ის სტრუქტურაა, ხოლო მათი Lua სია (`{ cs.struct(…), … }`) უჯრედია, რასაც ბიბლიოთეკის პარამეტრები მოელის. თუ ბიბლიოთეკის ფუნქციის შიგნით რამე არასწორად მიდის, შეტყობინება ფუნქციას და მის ხაზს ასახელებს და მიუთითებს თქვენს ხაზზე, რომელმაც ის გამოიძახა.

## გამორთულია

სკრიპტები ფაილებს, ქსელსა და გვერდს ვერ მიწვდება: `io`, `os` (საათის გარდა), `require`, `dofile`, `loadfile` და `debug` ამოღებულია. მონაცემების შემოსატანად გამოიყენეთ სკრიპტების სამუშაო სივრცის გახსნა და ცვლადები. ნაბიჯების ბიუჯეტი და გაჩერება CraftScript-ის მსგავსად მუშაობს.
