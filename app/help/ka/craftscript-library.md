ანალიზის ბიბლიოთეკა სკრიპტების ნაკრებია, თითოეული ფუნქცია, რომლის წაკითხვაც ზევიდან ქვემოთ შეგიძლიათ: როგორ აგროვებს სიხისტის მატრიცა, სად მიდის სასაზღვრო პირობები, რომელი ამომხსნელი მუშაობს, როგორ ითვლება შედეგები. მასში არაფერია შავ ყუთში დამალული; მხოლოდ სწრაფი შიდა ციკლები (ელემენტების მატრიცები, იშვიათი ამომხსნელები, ბადეების აგება) არის ჩაშენებული.

## დაიწყეთ მაგალითით

**მაგალითების** ჯგუფში ხუთი მოკლე სკრიპტია, რომლებიც ბიბლიოთეკას თავიდან ბოლომდე იყენებს. აირჩიეთ ერთ-ერთი, დააჭირეთ {{ui:გახსნა (მხოლოდ კითხვა)}}, შემდეგ {{key:F5}}: თითოეული ასუფთავებს ხედს, აჩვენებს შედეგს ტილოზე და გრაფიკს ქვეჩვენებებში.

ყოველი ფუნქციის სათაური მის ზუსტ არგუმენტებს ასახელებს. ერთეულები PartCraft-ის კვლევების ერთეულებია, თუ სათაური სხვას არ მიუთითებს: მილიმეტრები, ნიუტონები, მეგაპასკალები, სიმკვრივისთვის ტონა კუბურ მილიმეტრზე, სითბოსთვის ვატი და კელვინი. ელექტრომაგნიტური და მესერული ბოლცმანის ფუნქციები ნებისმიერ თანმიმდევრულ ერთეულებში მუშაობს; მათი სათაურები მიუთითებს, როგორ.

## როგორ მოწმდება ბიბლიოთეკა

ყოველი ფუნქციის სათაური **შემოწმებით** მთავრდება: მცირე მაგალითი ცნობილი პასუხით. PartCraft-ის ტესტები თითოეულს ატარებს, და სადაც PartCraft-ს აქვს საკუთარი კვლევა იმავე ამოცანისთვის, სკრიპტის პასუხი იმავე ბადეზე ამ კვლევასთან შედარდება:

- კონსოლის წვეროს გადახრა ძელის თეორიასთან შედარებით (კუბებით 0.2 %-ის ფარგლებში, ტეტრაედრებით 0.05 %-ის ფარგლებში) და **სიმულაციის** სამუშაო სივრცის ამომხსნელებთან იმავე ბადეზე (ბევრ ციფრამდე იგივე);
- კონსოლის პირველი სიხშირე ძელის თეორიასთან შედარებით (0.24 %-ით დაბალი, როგორც მოკლე ძელისთვის მოსალოდნელია) და **სიმულაციის** მოდალურ ამომხსნელთან;
- სითბო: გახურებული სიბრტყის კედელი ზუსტად, პატარა სხეულის გაცივება თავმოყრილი სიმძლავრის ფორმულით, ფილის ტემპერატურის ჩაცხრომა თეორიის მიხედვით;
- ტოპოლოგიური ოპტიმიზაცია: `top88` იმეორებს ნაშრომის 94 იტერაციას და მოქნილობას 203.1925 (და 218.8032 სიმკვრივის ფილტრით); `topopt3d` იგივე მოქნილობით სრულდება, რაც **გენერაციული** სამუშაო სივრცე იმავე პარამეტრებით;
- კონდენსატორის ტევადობა და გრძელი სოლენოიდის ველი სახელმძღვანელოს მნიშვნელობებთან, ელექტრომაგნიტის უფსკრულის ველი მაგნიტური წრედის ფორმულასთან, და მუდმივი მაგნიტები ჰაერში მდებარე მრგვალ მაგნიტთან და რკინის ჩამკეტით დახურულ მაგნიტთან შედარებით;
- არხის ნაკადი ზუსტ პარაბოლურ პროფილთან შედარებით.

## ფუნქციის წაკითხვა

1. გახსენით სკრიპტის პანელის **ბიბლიოთეკის** ჩანართი.
2. დააწკაპუნეთ ფუნქციაზე. მის სათაურში ჩანს: რას ითვლის, მეთოდი, ერთეულები, დაშვებები და ზღვრები, **ცნობარები** (წიგნი ან ნაშრომი, განტოლებათა ნომრებით) და **შემოწმება** — მცირე მაგალითი ცნობილი პასუხით, რომელსაც PartCraft-ის საკუთარი ტესტები ატარებს.
3. {{ui:გახსნა (მხოლოდ კითხვა)}} მთლიან სკრიპტს ხსნის ჩანართში პუნქტირებული საზღვრით. მისი გაშვება შეგიძლიათ, ნაწილების მონიშვნა და გაშვება, მაგრამ შეცვლა — არა.

## ერთის შეცვლა

დააჭირეთ {{ui:ასლის შექმნა}}-ს (ან **რედაქტირებისთვის ასლის შექმნა** წაკითხვა-მხოლოდ ჩანართის ზემოთ). ასლი თქვენს ნაწილში იმავე სახელის სკრიპტია, ამიტომ ნაწილთან ერთად ინახება, და **ამ ფუნქციის ყოველი გამოძახება ახლა თქვენს ასლს იყენებს** — რედაქტორი ამას სკრიპტის ზემოთ ამბობს. ორივეს შესანახად ასლს სხვა სახელი დაარქვით.

## გამოყენება

ბიბლიოთეკის ფუნქცია ნებისმიერი სკრიპტიდან გამოიძახეთ სახელით, ჩაშენებული ფუნქციის მსგავსად:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

შედეგები მნიშვნელობებად ბრუნდება სამუშაო სივრცეში; გრაფიკები და ველები, რომლებსაც ის აჩვენებს, ხედსა და ქვეჩვენებებში ჩნდება.

მაგალითად, გახსნილი ნაწილის სტატიკურ ანალიზს რამდენიმე ხაზი სჭირდება:

```
v = voxel_mesh(part(), 2);                   % 2 მმ კუბები
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % ქვედა მხარის დამაგრება
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % ზედა მხარეზე 500 N ქვევით
r = static_voxel(v, 210000, 0.3, bc);       % ფოლადი
```

`r` შეიცავს გადაადგილებებს, ძაბვებსა და რეაქციებს; ფონ მიზესის ძაბვა დეფორმირებულ ნაწილზე იხაზება. მრუდი ნაწილებისთვის გამოიყენეთ `tet_mesh` და `static_tet`, რომლებიც მთლიან წახნაგებსაც ტვირთავს და იჭერს (`face_nodes`).

ბიბლიოთეკის ფუნქციები CraftScript-ზეა დაწერილი, ხოლო Lua სკრიპტი მათ `cs`-ით იძახებს, ჩაშენებული ფუნქციების მსგავსად: `cs.static_tet(t, 200000, 0.3, bc)` (იხილეთ [Lua სკრიპტები](topic:craftscript-lua)). თითოეული ფუნქცია ერთ მასალასა და ერთ დატვირთვის შემთხვევას ხსნის; სათაურებში ჩამოთვლილია, რა არ არის დაფარული.
:::
