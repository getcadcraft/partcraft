ანალიზი სკრიპტების სამუშაო სივრცეში რამდენიმე მოკლე სკრიპტია, რომლებიც ცვლადებს ერთმანეთს გადასცემს. დაიწყეთ იმ [ბიბლიოთეკის](topic:craftscript-library) ფუნქციიდან, რომელიც თქვენს საჭიროებას ემთხვევა, შექმენით ასლი და შეცვალეთ; ან ააგეთ ქვემოთ მოცემული წესით.

## 1. ბადე

```
model = part();                  % ნაწილი, რომელსაც მოდელირებთ, როგორც მოდელი
m = tetmesh(model, 4);           % ტეტრაედრები დაახლოებით 4 მმ-იანი
show(m)
```

სანამ გააგრძელებთ, შეამოწმეთ ბადე ხედში: {{key:F}} მას ეტევა, **ნაჩვენებში** {{ui:თვალი}} ნაწილს მალავს.

## 2. აწყობა და ამოხსნა

ელემენტების ციკლი სკრიპტში დაწერეთ (სახელმძღვანელოს მსგავსად იკითხება), ხოლო მძიმე ნაწილები ჩაშენებულ ფუნქციებს დაუტოვეთ: ელემენტების მატრიცები, იშვიათი აწყობა სამეულებიდან და შეუღლებული გრადიენტის ამომხსნელი წინაპირობით. ბიბლიოთეკის ფუნქცია, მაგალითად `static_tet` (როცა ბიბლიოთეკაში უკვე არის), სრული მაგალითია, საიდანაც კოპირება შეიძლება.

## 3. შედეგის ჩვენება

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % თითო მნიშვნელობა კვანძზე
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- ლეგენდის დიაპაზონი შეიძლება ჩაიწეროს ან დაბრუნდეს {{ui:ავტო}}-ზე.
- დააწკაპუნეთ ბადეზე, რომ კვანძზე მნიშვნელობები წაიკითხოთ.
- გრაფიკი, რომელიც იგივე `'id'`-ს ინარჩუნებს, ადგილზე განახლდება, ამიტომ ციკლის შიგნით ბეჭდეთ და ხაზავთ, რომ კონვერგენცია დააკვირდეთ.

## 4. შემოწმება

შეადარეთ იმას, რაც იცით: კონსოლის წვეროს გადახრა PL³/3EI-სთან, ხვრელიანი ფირფიტა მისი ძაბვის კონცენტრაციის კოეფიციენტთან, რეაქციები დატვირთვებთან. შემოწმება ცალკე სკრიპტად დაწერეთ, რომ ყოველი ცვლილების შემდეგ ხელახლა გაეშვას:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. შენახვა

- ყოველი ნაბიჯი შეიძლება საკუთარი სკრიპტის ჩანართი იყოს: ისინი ცვლადებს იზიარებენ, ამიტომ ერთმანეთის მიყოლებით გაუშვით.
- სკრიპტები ნაწილში ინახება. შედეგების შესანახადაც ჩართეთ **ცვლადების შენახვა ნაწილთან ერთად** ცვლადების ჩანართზე (32 MB-მდე).
- სკრიპტების ჯგუფში {{ui:შენახვა}} სკრიპტს ჩამოტვირთავს გასაზიარებლად; {{ui:გახსნა}} ამოაქვს შემოსატანად.
