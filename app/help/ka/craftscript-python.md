Python არის [სკრიპტების სამუშაო სივრცის](topic:craftscript) მესამე ენა. აირჩიეთ **Python** რედაქტორის ზემოთ მდებარე ენის ველში (`.py` ფაილი თავისით იხსნება Python-ში). Python, Lua და CraftScript იზიარებენ ერთსა და იმავე ცვლადებს და ჩაშენებულ ფუნქციებს, ამიტომ Python სკრიპტს შეუძლია გამოიყენოს ის, რაც CraftScript-მა შექმნა, და პირიქით.

ვიზიტის პირველი Python გაშვება თავად Python-ს (CPython 3.14, დაახლოებით 7 MB) ამ საიტიდან ჩატვირთავს, რაც რამდენიმე წამს იკავებს. Python ჯერ არ შედის {{ui:ხაზგარეშე შესანახად}}-ში: ჯერ ონლაინ გაუშვით ერთი Python სკრიპტი.

## Python იზოლირებულია

Python სკრიპტები CraftScript-ისა და Lua სკრიპტების მსგავსად იზოლირებულია: ისინი ნაწილს, ცვლადებსა და ჩაშენებულ ფუნქციებს აღწევენ და სხვას არაფერს. ყოველი გაშვება ახალი Python-ია საკუთარ სენდბოქსში, მეხსიერებაში მცირე ფაილური ხით (მისი სტანდარტული ბიბლიოთეკა და `/tmp` საქაღალდე, რომელიც გაშვების შემდეგ ქრება). ის ვერ აღწევს ქსელს, თქვენს ფაილებს ან გვერდის დანარჩენ ნაწილს — ბრაუზერში და ბრძანებათა ხაზზე ერთნაირად. სხვისი სკრიპტი მაინც შეიძლება ბევრ დროსა და მეხსიერებას მოიხმარდეს: {{ui:გაჩერება}} ამთავრებს მას.

## ძირითადი

```
A = cs.magic(3)              # ყველა ჩაშენებული ფუნქცია cs.<name>-ია
B = A @ A.T                  # @ მატრიცული ნამრავლია, .T ტრანსპონირება
C = A * 2 + 1                # + - * / ** ელემენტ-ელემენტადაა, როგორც numpy-ში
print(A[0, 1], A[-1, -1])    # 0-დან; უარყოფითი ბოლოდან ითვლის
row = A[1]                   # მატრიცაზე ერთი ინდექსი: სტრიქონი
big = A[A > 4]               # ლოგიკური ნიღაბი ელემენტებს არჩევს
A[0, 0] = -5                 # მასივში მინიჭება
V, D = cs.call('eig', 2, A)  # რამდენიმე შედეგი: cs.call(name, რამდენი, …)
```

- 1 × 1 მასივი ჩვეულ რიცხვად მოდის; სხვა მასივები, იშვიათი მატრიცები, ბადეები, ველები და მოდელები **მნიშვნელობებია**.
- მნიშვნელობას აქვს `shape` (მრავალეული), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (მისი სტრიქონები), და `float()`, `int()` და `bool()` ერთი ელემენტისთვის.
- შედარებები (`<`, `==`, …) ელემენტ-ელემენტადაა, როგორც numpy-ში: ლოგიკურ მნიშვნელობას იძლევიან.
- ჩაშენებულ ფუნქციას გადაცემული რიცხვების სიები მასივებად იქცევა: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` ქმნის მატრიცას.
- dict სტრუქტურად იქცევა, შერეული ელემენტების სია — უჯრედად, და პირიქით.

ყოველი გლობალური, რომელსაც სკრიპტი ქმნის (რიცხვი, მნიშვნელობა, dict, სია…), გაშვების დასრულებისას **ცვლადების** ჩანართში ხვდება, შეცდომის შემდეგაც კი. `_`-ით დაწყებული სახელები, ფუნქციები, კლასები და მოდულები Python-ში რჩება. `ws.name` პირდაპირ კითხულობს ან ადგენს ცვლადს, ხოლო `ws_names()` მათ ჩამოთვლის.

`print(…)` კონსოლში წერს. `display(…)` (ან `cs.display`) აჩვენებს ბადეს, ველს ან გრაფიკს, CraftScript-ის მსგავსად.

## ანალიზის ბიბლიოთეკის გამოძახება

ბიბლიოთეკის ფუნქციები ჩაშენებულივით იძახება: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. სახელი სკრიპტში ისე ჩაწერეთ, როგორც არის: PartCraft სკრიპტის გაშვებამდე პოულობს, რომელ ბიბლიოთეკის ფუნქციებს იყენებს.

## ჯერ არ არის

- numpy, scipy და სხვა პაკეტები: აქ მხოლოდ Python-ის საკუთარი სტანდარტული ბიბლიოთეკაა (`math`, `json`, `itertools`, `decimal`, `statistics`…), მისი ფანჯრებისა, ტერმინალისა და მონაცემთა ბაზის ნაწილების გარეშე (`tkinter`, `curses`, `sqlite3`).
- სოკეტები და ყველაფერი, რაც გარეთ გავიდოდა: აქ Python-ს ქსელი არ აქვს.
- `time.sleep` მაშინვე ბრუნდება.
- კოდის ჩაკეცვა რედაქტორში და Python ფუნქციის გამოძახება CraftScript სკრიპტიდან.
- გაშვება ინსტრუქციების ბიუჯეტს და გაჩერებას ყოველ 1000 ხაზში ამოწმებს; ერთი ჩაშენებული ფუნქციის შიგნით გრძელი გამოთვლა ჯერ დამთავრდება.
