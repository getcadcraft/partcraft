გენერატორი არის ჩვეულებრივი სკრიპტი ([CraftScript](topic:craftscript), Lua ან Python) რამდენიმე კომენტარის სტრიქონით ზემოთ. PartCraft კითხულობს კომენტარებს და ქმნის ფორმას; თქვენი სკრიპტი კითხულობს შეყვანებს როგორც უკვე დაყენებულ ცვლადებს.

## სათაური

ჩასვით ეს კომენტარის სტრიქონებში (`%` CraftScript-ში, `--` Lua-ში, `#` Python-ში):

```
% @generator სითბოს გადამცვლელი
% @input mdot: kg/s = 0.2 [0.01 .. 10] "მასის ნაკადი"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "ზედაპირი"
% @input solid: = true
% @input note: = "text"
```

შეყვანა არის `name: unit = default`, შემდეგ არასავალდებულოდ დიაპაზონი `[min .. max]` (რიცხვები მასში ინახება), არჩევანის სია `{a, b, c}` და ეტიკეტი ბრჭყალებში. ერთეული მხოლოდ ფორმისთვის არის ეტიკეტი: **მნიშვნელობა მოდის ამ ერთეულში**, ამიტომ სკრიპტი, რომელსაც სურს SI, გარდაქმნის მას, და `to_si(value, 'kg/s', 'kg/s')` ასევე ამოწმებს, რომ ერთეული ნიშნავს იმას, რაც თქვენ ფიქრობთ. სახელი შედგება ასოებისგან, ციფრებისგან და ქვედა ტირესგან; `body`, `sheet` და `problems` უკვე დაკავებულია.

## რას ტოვებს სკრიპტი

| ცვლადი | რა არის |
|---|---|
| `body` | **სავალდებულოა.** ზედაპირის ბადე, როგორც წესი `[body, info] = to_body(field, h)`-დან. ის სწორდება და მოწმდება გაშვების დასრულებისას. |
| `sheet` | არასავალდებულო. სტრუქტურა: თითოეული ველი არის რიცხვი ან ტექსტი, ან სტრუქტურა `value`, `unit`, `ref` და `note` ველებით. ის ხდება მონაცემთა ფურცელი. |
| `problems` | არასავალდებულო. `problems` უჯრა `mfg_check(field, 'sls', struct(), h)`-დან, ან თქვენი საკუთარი ჩანაწერები. ისინი გადადის შემოწმებებსა და პრობლემების სიაში. |

## სრული მცირე მაგალითი

```
% ღრუ კუბი კედლით.
% @generator ღრუ კუბი
% @input side: mm = 12 [4 .. 40] "გვერდი"
% @input wall: mm = 1.5 [0.5 .. 5] "კედელი"
% @input h: mm = 0.5 [0.25 .. 2] "ვოქსელის ზომა"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'ბადის მიხედვით');
```

ის ქმნის დახურულ კოლოფს, და შემოწმება მის დალუქულ შიდა ნაწილს შეცდომად აღნიშნავს ფხვნილის პროცესისთვის. გახადეთ ვოქსელის ზომა `h` არაუმეტეს თქვენს სასურველი ყველაზე თხელი კედლის მესამედისა: სამ ვოქსელზე ნაკლები კედელი სანდო არ არის.

## ველები

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ბრუნვის სხეული პროფილიდან), `tpms` (გიროიდის, შვარცის P და ალმასის ზედაპირები, უჯრედის ზომითა და კედლით, რომლებიც შეიძლება შეიცვალოს მთელ დეტალზე), `lattice` და `lattice_beams`, `along` (მრგვალი არხი გზის გასწვრივ), ბულური ოპერაციები `field_union`, `field_intersect`, `field_subtract`, გლუვი `field_blend`, და `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` აბრუნებს ნიშნიან მანძილს წერტილებში (უარყოფითი შიგნით), `field_voxel` აბრუნებს ვოქსელებს ამომხსნელებისთვის. [ველები](topic:fields) განმარტავს, რაც არიან.

ღირს ცოდნა შეზღუდვები: ფურცლის კედელი, რომელიც უჯრედის დაახლოებით მეოთხედზე სქელია, ხურავს არხებს; ელემენტი, რომელიც დაახლოებით სამ ვოქსელზე თხელია, შეიძლება შეიკუმშოს; `along` აერთებს მრგვალ კონუსებს, ამიტომ რადიუსი, რომელიც სწრაფად იცვლება, ტოვებს ამობურცულობას (პროფილისთვის გამოიყენეთ `field_revolve`).

## სკრიპტის გახსნა როგორც გენერატორი

{{ui:ინჟინერი}} სამუშაო სივრცეში დააწკაპუნეთ {{ui:გახსნა}} ღილაკს და აირჩიეთ ფაილი. სკრიპტი, რომელსაც არ აქვს `@generator` ან `@input` სტრიქონი, უარყოფილია: არაფერი იქნებოდა დასაყენებელი. გენერატორი ინახება ამ ბრაუზერში (მაქსიმუმ 20) და {{ui:წაშლა}} შლის მას. ამ გენერატორით დაწყებული სხეული ატარებს სკრიპტის ასლს, ამიტომ დეტალი არ არის მისგან დამოკიდებული.

ფაილს ასევე შეუძლია რამდენიმე გენერატორის შენახვა: JSON პაკეტი `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
