## რას შეისწავლით

როგორ მივცეთ AI ასისტენტს (ან თქვენს მიერ დაწერილ სკრიპტს) საშუალება, შეხედოს ნაწილს, რომელიც ღია გაქვთ, შეცვალოს მისი პარამეტრები, გაუშვას სკრიპტი და ექსპორტი გაუკეთოს, და როგორ განსაზღვრავთ, რისი შეხება შეუძლია.

PartCraft-ს **საკუთარი AI არ აქვს** და არაფერს არსად არ აგზავნის. ასისტენტს თქვენ მოიტანთ: ნებისმიერ პროგრამას, რომელიც ელაპარაკება მოდელის კონტექსტის პროტოკოლს (MCP). PartCraft მას მხოლოდ ინსტრუმენტებს აძლევს, ხოლო იმას, თუ რომელს, თქვენ ირჩევთ.

## ჩართვა

1. გახსენით {{ui:პარამეტრები}} (აპის ზოლში მექანიზმის ხატულა, ან {{key:Mod+,}}) და გადადით {{ui:PartCraft}} ჩანართზე.
2. {{ui:ასისტენტები}}-ის ქვეშ მონიშნეთ **დართეთ AI ასისტენტებსა და სკრიპტებს PartCraft-ის გამოყენების უფლება**. ის გამორთულია, სანამ არ მონიშნავთ.
3. აირჩიეთ, რისი უფლება ექნება. **წაკითხვა** დასაწყისში მონიშნულია; დანარჩენები მონიშნეთ მხოლოდ მაშინ, როცა გჭირდებათ.
4. იმისთვის, რომ მან საქაღალდეში ექსპორტი და შენახვა შეძლოს, აირჩიეთ {{ui:საქაღალდის დამატება…}} **საქაღალდეები, რომლებსაც შეძლებს გამოყენებას** ქვეშ და Studio-ს დიალოგში აირჩიეთ საქაღალდე.

ასისტენტები უერთდებიან **CadCraft Studio**-ს თქვენს კომპიუტერზე: Studio აჩვენებს მისამართს და ჟეტონს, რომელიც ასისტენტში უნდა ჩასვათ. ბრაუზერის ჩანართი ასისტენტისთვის კავშირს ვერ გახსნის.

## რის თხოვნა შეუძლია ასისტენტს

| ინსტრუმენტი | უფლება | რას აკეთებს |
|---|---|---|
| `part_describe`, `features_list` | წაკითხვა | ელემენტები თანმიმდევრობით, რა აიგო და რა ჩაიშალა, მასალა, მყარი სხეულის მოცულობა და ზომა |
| `params_list` | წაკითხვა | პარამეტრები და ყველა რიცხვი, რომელსაც განტოლება შეუძლია მართოს, მათი მნიშვნელობებით |
| `mass_properties` | წაკითხვა | მოცულობა, ფართობი, სიმძიმის ცენტრი, მის მიმართ ინერცია; მასა, თუ ნაწილს მასალა აქვს |
| `param_set` | რედაქტირება | ადგენს პარამეტრს ან ელემენტის რიცხვს და ახდენს ხელახლა აგებას. ერთი ნაბიჯი, რომლის გაუქმებაც შეიძლება |
| `script_run` | რედაქტირება | უშვებს CraftScript, Lua ან Python სკრიპტს იმ წესით, როგორც {{ui:სკრიპტი}} სამუშაო სივრცე: დახურულად, ფაილებისა და ქსელის გარეშე. ნაწილი არ იცვლება |
| `part_export` | ექსპორტი | STL, 3MF, STEP ან OpenUSD (.usdz, .usda, .usdc), ისე, როგორც {{ui:ფაილი}} › {{ui:ექსპორტი}} წერს მათ |
| `link_push` | რედაქტირება | ანახლებს სხვა პროგრამიდან მიბმულ მოდელს (იხ. [.3dm მოდელის ცოცხლად შენარჩუნება](topic:live-3dm-link)) |
| `link_status` | წაკითხვა | ამბობს, არის თუ არა მიბმული მოდელი კვლავ და როდის განახლდა ბოლოს |
| `part_save` | შენახვა | PartCraft-ის საკუთარი {{ui:შენახვა}} |
| `illustrate_export` | ექსპორტი | სახელმძღვანელო {{ui:Illustrate}} სამუშაო სივრციდან PDF ან SVG ხაზოვან ნახატად მისი ხედებისთვის, ინტერაქტიულ 3D ფაილად, ან მისი ინსტრუქციები PDF-ად ან ვებგვერდად, ისე, როგორც სამუშაო სივრცის {{ui:ექსპორტი}} და {{ui:ინსტრუქციები}} მენიუები წერს მათ ([სახელმძღვანელოები](topic:illustrate)) |

:::note
ეს build იყენებს mesh kernel-ს: მოცულობები მოდის სამკუთხედებიდან (ცოტათი ნაკლები, ვიდრე ნამდვილი მრუდი სხეული), ხოლო STEP იწერება წახნაგებულად, სამკუთხედებით ზუსტი ზედაპირების ნაცვლად.
:::

## თქვენ მართავთ

- **ყოველი ცვლილება ერთი გაუქმების ნაბიჯია**, რომელსაც ასისტენტის სახელი აქვს, მაგალითად „Assistant: set l = 45“. გასაუქმებლად დააჭირეთ {{key:Mod+Z}}-ს.
- **იცით, როდის არის დაკავშირებული.** აპის ზოლში ღილაკი ასახელებს ასისტენტს, სანამ ის დაკავშირებულია. დააწკაპუნეთ, რომ ნახოთ, რისი უფლება აქვს, ან რომ **გათიშოთ** იგი.
- **აქტივობა.** {{ui:პარამეტრები}} › {{ui:PartCraft}} › {{ui:ასისტენტები}} › {{ui:აქტივობა}} ჩამოთვლის ყველა გამოძახებას; {{ui:ჟურნალის შენახვა}} ინახავს მის ასლს.
- **საქაღალდეები.** ის კითხულობს და წერს ფაილებს მხოლოდ იმ საქაღალდეებში, რომლებიც დაამატეთ; {{ui:წაშლა}} საქაღალდეს მაშინვე უკან იბრუნებს.

## PartCraft-ის გახსნის გარეშე

CadCraft-ის ფაილური სერვერი ასისტენტებისთვის (`npx @getcadcraft/mcp`) და `cadcraft` ბრძანებათა ხაზი ხსნიან `.partcraft.json` ნაწილებს PartCraft-ის საკუთარი კოდით და mesh kernel-ით, ფანჯრის გარეშე: იგივე წაკითხვის ინსტრუმენტები, პარამეტრების დაყენება, CraftScript სკრიპტები, ექსპორტი (OpenUSD-იც) და შენახვა. `cadcraft convert bracket.partcraft.json bracket.stl` აგებს ნაწილს და წერს მას ბრძანებათა ხაზიდან. სახელმძღვანელოებიც (`.partcraft-manual.json`) იქ ექსპორტდება: `illustrate_export`, ან `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (დაამატეთ `--instructions` ინსტრუქციებისთვის).

## თუ რამე არ მუშაობს

- **„საჭიროა რედაქტირების ნებართვა“:** მონიშნეთ **რედაქტირება** {{ui:ასისტენტები}}-ის ქვეშ, შემდეგ ხელახლა სთხოვეთ.
- **„განტოლებით მართული“:** ეს რიცხვი პარამეტრს მისდევს; სთხოვეთ ასისტენტს, პარამეტრი დააყენოს.
- **მისი ცვლილება არასწორი იყო:** დააჭირეთ {{key:Mod+Z}}-ს.
