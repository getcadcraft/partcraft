Python — третий язык [рабочей области «Скрипт»](topic:craftscript). Выберите **Python** в поле языка над редактором (файл `.py` открывается в Python сам по себе). Python, Lua и CraftScript используют одни и те же переменные и встроенные функции, поэтому скрипт на Python может использовать то, что создал скрипт CraftScript, и наоборот.

Первый запуск Python за визит загружает сам Python (CPython 3.14, около 7 МБ) с этого сайта; это занимает несколько секунд. Python пока не входит в {{ui:Сохранить для офлайн}}: сначала запустите хотя бы один скрипт Python в онлайне.

## Python изолирован

Скрипты Python изолированы так же, как скрипты CraftScript и Lua: они получают доступ к детали, переменным и встроенным функциям и ничему больше. Каждый запуск — это новый Python в собственной песочнице с небольшим деревом файлов в памяти (его стандартная библиотека и папка `/tmp`, которая исчезает после запуска). Он не может обратиться к сети, вашим файлам или остальной части страницы — ни в браузере, ни в командной строке. Скрипт от другого человека все равно может занять много времени или памяти: {{ui:Стоп}} его останавливает.

## Основное

```python
A = cs.magic(3)              # каждая встроенная функция — cs.<name>
B = A @ A.T                  # @ — матричное произведение, .T — транспонирование
C = A * 2 + 1                # + - * / ** поэлементно, как в numpy
print(A[0, 1], A[-1, -1])    # с 0; отрицательные — с конца
row = A[1]                   # один индекс у матрицы: строка
big = A[A > 4]               # логическая маска выбирает элементы
A[0, 0] = -5                 # присваивание в массив
V, D = cs.call('eig', 2, A)  # несколько результатов: cs.call(имя, сколько, …)
```

- Массив 1 × 1 приходит как обычное число; другие массивы, разреженные матрицы, сетки, поля и модели — это **значения**.
- У значения есть `shape` (кортеж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (его строки), а также `float()`, `int()` и `bool()` для одного элемента.
- Сравнения (`<`, `==`, …) поэлементны, как в numpy: они дают логическое значение.
- Списки чисел, которые передаются встроенной функции, становятся массивами: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` создает матрицу.
- Словарь становится структурой, а список из разных элементов — ячейкой, и обратно.

Каждая глобальная переменная вашего скрипта (число, значение, словарь, список…) попадает во вкладку **Переменные** по окончании запуска, даже после ошибки. Имена, начинающиеся с `_`, функции, классы и модули остаются в Python. `ws.name` читает или задает переменную напрямую, а `ws_names()` перечисляет их.

`print(…)` выводит в консоль. `display(…)` (или `cs.display`) показывает сетку, поле или график, как в CraftScript.

## Вызов библиотеки анализа

Функции библиотеки вызываются так же, как встроенные: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Пишите имя в скрипте точно, как оно есть: PartCraft находит функции библиотеки, которые использует скрипт, до его запуска.

## Пока не реализовано

- numpy, scipy и другие пакеты: есть только стандартная библиотека Python (`math`, `json`, `itertools`, `decimal`, `statistics`…) без ее частей для окон, терминала и баз данных (`tkinter`, `curses`, `sqlite3`).
- Сокеты и все, что могло бы выйти наружу: в Python здесь нет сети.
- `time.sleep` возвращает управление сразу.
- Сворачивание в редакторе и вызов функции Python из скрипта CraftScript.
- Запуск проверяет лимит инструкций и «Стоп» каждые 1000 строк; длинный расчет внутри одной встроенной функции сначала завершается.
