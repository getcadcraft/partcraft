CraftScript — матричный язык, написанный так, чтобы читаться как MATLAB, поэтому большинство классических численных кодов (например, 88-строчный код оптимизации топологии) запускается с небольшими изменениями. Он работает в [рабочей области «Скрипт»](topic:craftscript) и из командной строки.

## Значения

| Тип | Пример | Примечания |
|---|---|---|
| Число, массив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Каждое число является массивом (1×1). Массивы хранятся по столбцам, до 8 измерений |
| Логический | `A > 2`, `true` | Массивы из true/false; можно использовать как индексы |
| Текст | `'beam'`, `"beam"` | |
| Разреженная матрица | `sparse(i, j, v, n, n)` | Для матриц жесткости |
| Сетка, поле, модель | `hexGrid(…)`, `part()`, `load('part.stl')` | То, что рисует `show` |
| Структура | `s.E = 210e3` | Именованные поля |
| Ячейка | `c = {1, 'two', [3 4]}` | Список значений любого вида |
| Дескриптор функции | `f = @(x) x.^2` | |

## Массивы и индексация

- Диапазоны: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индексация начинается с 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (весь столбец), `A(:)` (все элементы одним столбцом), `v(v > 0)` (логическая индексация).
- Присваивание за пределами массива расширяет его, как в MATLAB: `v(10) = 1`.

## Операторы

- `+ - * / \ ^` — матричные операции (`A \ b` решает систему); `.* ./ .^` работают поэлементно. `'` транспонирует.
- Сравнения `== ~= < <= > >=`; логика `& | ~` (поэлементно) и `&& ||` (с сокращенной оценкой).

## Управление ходом выполнения и функции

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функции записываются в скрипт после его команд или на собственной вкладке скрипта, названной по имени функции:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Имя ищется в таком порядке: переменная, скрипт этой детали с таким именем, функция библиотеки, встроенная функция.

## Вывод значений, комментарии, вывод на экран

- Оператор без `;` выводит свое значение; `;` оставляет его без вывода.
- `%` начинает комментарий; `%{` и `%}` в отдельных строках закомментируют строки между ними.
- `disp(x)`, `fprintf('%g\n', x)` и `display(x)` выводят в консоль.

## Ошибки и ограничения

- Ошибки простыми словами сообщают, что пошло не так, и указывают строку (и цепочку вызовов функций).
- Каждый запуск имеет лимит шагов (пункт «Параметры запуска» на панели); бесконечный цикл останавливается с сообщением, или нажмите «Стоп».
- Массивы содержат до 134 миллиона значений каждый.

## Отличия от MATLAB

- Команды построения получают свои параметры в самом вызове: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` и похожие принимаются и ничего не делают.
- `input` и `keyboard` не поддерживаются: скрипт не может остановиться и задать вопрос.
- Наборов инструментов (toolboxes) нет; есть [библиотека анализа](topic:craftscript-library) и встроенные функции.
