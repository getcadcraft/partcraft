Инженерным инструментам (генераторам, инженерной библиотеке, проверкам и файлам данных) **не нужны права администратора** и **не нужен установщик**. Они записывают только то, что перечислено здесь, и ничего больше.

| Что | Где хранится |
|---|---|
| Ваши детали с их построенными телами, таблицами данных и проверками | Файл детали, который вы сохраняете (`.partcraft.json`), в том месте, куда вы его сохраняете. |
| Генераторы, которые вы открыли из файлов | В собственном хранилище приложения: локальное хранилище браузера на веб-странице и папка `data` рядом с программой в переносной версии Studio. Не более 20. |
| Настройки (размеры вокселей, которые вы задали, потоки решателя, расположение интерфейса) | В том же хранилище приложения. |
| Таблицы данных, поля, сетки | Только там, где вы их сохраняете: файл сохраняется туда, куда вы выберете. |

Инструменты **не выполняют собственных сетевых запросов**: поставляемые генераторы — это файлы в собственной папке приложения, библиотека и проверки работают на вашем компьютере в фоновом рабочем процессе (worker), который не может обратиться к сети, а инженерные данные (свойства воды и воздуха, материалы) находятся внутри приложения. Генератор, открытый из файла, читается на вашем компьютере и никуда не отправляется.

## Переносная версия для Windows (zip) и Linux

Переносная версия Studio для Windows хранит настройки, кэши и дополнения в папке `data` рядом с программой. AppImage для Linux хранит их рядом с собой, если рядом лежит файл `portable`; без этого файла он использует вашу домашнюю папку. Переносной версии для Mac нет: система не позволяет приложению, загруженному из интернета, записывать файлы рядом с собой. Собственные заметки оболочки о переносной версии (справка `Studio`) перечисляют, что программа записывает.

## Доступ к компьютеру

Здесь ничего не запрашивает доступ к компьютеру. Принтеры, устройства с последовательным портом и USB-устройства отдельные: они запрашивают доступ, когда задание требует их, по одному разу для каждого устройства, и ни генераторы, ни проверки к ним не обращаются.
