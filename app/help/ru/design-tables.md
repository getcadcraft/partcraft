**Конфигурация** — это один размер детали: именованный набор значений ее параметров. Деталь хранит свои конфигурации в собственном файле, поэтому они переносятся вместе с ней. **Таблица конфигураций** — то же самое в виде CSV-файла: одна строка на конфигурацию.

Конфигурации задают **параметры**, поэтому сначала добавьте их (см. [Управление деталью с помощью параметров](topic:parameters)). Конфигурация хранит параметры, которые являются простыми числами; параметры, вычисляемые из других (например, `area = w * d`), следуют за ними сами.

## Сохранение конфигурации

1. На вкладке {{ui:Параметры}} задайте параметры для одного размера детали.
2. В разделе **Конфигурации** введите имя (например, `Большая`) и нажмите {{ui:Сохранить текущие значения}} или {{key:Enter}}.

Новая конфигурация отмечается как **активная**. Если потом изменить параметр, появится надпись **активна, изменена с тех пор**, чтобы вы знали, что деталь больше не соответствует ей.

## Переключение, обновление, переименование, удаление

- {{ui:Применить}} задает параметрам значения этой конфигурации и перестраивает деталь.
- {{ui:Обновить}} сохраняет текущие значения в эту конфигурацию.
- Чтобы переименовать, введите новое имя в ее поле и нажмите {{key:Enter}}.
- {{ui:Удалить}} удаляет конфигурацию. Параметры сохраняют свои значения.

Каждое из этих действий — один шаг: {{key:Mod+Z}} возвращает назад. Если вы переименуете параметр, каждая конфигурация получит новое имя; если удалите параметр, он исчезнет из конфигураций.

## Включение и выключение операций в конфигурации

Конфигурация также хранит, какие операции выключены, поэтому у одной детали могут быть версии **с** и **без** чего-то: крепежных отверстий, фаски, бобышки.

1. Выключите операцию: щелкните по ней в истории, затем {{ui:Подавить}} в {{ui:Свойства}}.
2. Сохраните конфигурацию как обычно, например `Без отверстий`. В ее строке перечислено, что она выключает.
3. Включите операцию обратно ({{ui:Вернуть}}) и сохраните другую конфигурацию, например `С отверстиями`.

Как только любая конфигурация выключает операцию, применение конфигурации выключает ее операции и **включает все остальные**, вместе с ее значениями параметров, одним шагом. Конфигурация, сохраненная до того, как в какой-либо из них были выключены операции, считается «все включено». {{ui:Обновить}} сохраняет операции такими, какие они есть сейчас, вместе со значениями.

Деталь, у которой конфигурации выключают операции, сохраняется как более новая версия файла: старый PartCraft сообщает, что файл создан в более новой версии, вместо того чтобы открыть его без них.

:::note
CSV-таблица конфигураций содержит только значения параметров. Загрузка таблицы поверх конфигурации меняет ее значения и сохраняет выключенные в ней операции; параметр командной строки `--table` строит только значения.
:::

Файл детали сохраняется вместе с конфигурациями и с той, что была активна. Деталь открывается с теми значениями, с которыми была сохранена.

## Загрузка и выгрузка таблицы конфигураций

Таблица конфигураций — это CSV-файл с колонкой для каждого параметра и строкой для каждой конфигурации:

```
name,width,thick,bolt
small,100,6,6.6
medium,140,8,8.5
large,200,12,13
```

Первая колонка может называться `name`, `config` или `configuration`; каждая другая колонка должна быть именем параметра детали. Ячейки — числа, при желании с единицами (`8in`). Пустая ячейка исключает этот параметр из строки.

- {{ui:Импорт CSV}} добавляет каждую строку как конфигурацию. Строка с именем существующей конфигурации заменяет ее. Импорт — один шаг.
- {{ui:Экспорт CSV}} записывает конфигурации. Если их еще нет, он записывает одну строку текущих значений — отправную точку для электронной таблицы.

Имя конфигурации, которое электронная таблица приняла бы за формулу (начинается с `=`, `+`, `-` или `@`), записывается с ведущим `'`.

## Все размеры сразу

{{ui:Набор вариантов…}} в разделе **Конфигурации** строит все конфигурации или выбранные из них как STEP, IFC, DWG и предпросмотр в одном zip-архиве с таблицей их параметров: см. [Создание набора вариантов из конфигураций](topic:variant-pack).

Инструмент командной строки строит по одному файлу на каждую строку CSV-таблицы конфигураций:

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

Сначала выгрузите конфигурации как CSV, затем передайте этот файл через `--table`. См. [Скрипты и командная строка](topic:scripts-and-cli). Деталь, сохраненная как скрипт, хранит свои конфигурации в строке `configs json …`.
