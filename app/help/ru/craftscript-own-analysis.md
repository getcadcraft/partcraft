Анализ в рабочей области «Скрипт» — это несколько коротких скриптов, которые передают друг другу переменные. Начните с функции из [библиотеки](topic:craftscript-library), которая близка к вашей задаче, сделайте копию и измените ее, или постройте анализ с нуля, как показано ниже.

## 1. Сетка

```
model = part();                  % деталь, которую моделируете, как модель
m = tetmesh(model, 4);           % тетраэдры размером около 4 mm
show(m)
```

Проверьте сетку в виде, прежде чем идти дальше: {{key:F}} вписывает ее в вид, а {{ui:значок глаза}} в **Показано** скрывает деталь.

## 2. Сборка и решение

Напишите цикл по элементам в скрипте (он читается как учебник), а тяжелые части оставьте встроенным функциям: матрицам элементов, разреженной сборке из троек и решателю сопряженных градиентов с предобуславливателем. Функция библиотеки, такая как `static_tet` (когда она есть в библиотеке), — это полный пример для копирования.

## 3. Показ результата

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % одно значение на узел
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Невязка решателя', 'id', 'conv')
```

- Диапазон легенды можно ввести вручную или вернуть через {{ui:Авто}}.
- Щелкните по сетке, чтобы прочитать значения в узле.
- График с тем же `'id'` обновляется на месте, поэтому выводите (`print`) и рисуйте внутри цикла, чтобы наблюдать сходимость.

## 4. Проверка

Сравните с тем, что вам известно: прогиб конца консоли с PL³/3EI, пластину с отверстием с ее коэффициентом концентрации напряжений, реакции с нагрузками. Оформите проверку отдельным скриптом, чтобы она запускалась после каждого изменения:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Сохранение

- Каждый шаг может быть отдельной вкладкой скрипта: они используют общие переменные, поэтому запускайте их один за другим.
- Скрипты сохраняются в детали. Отметьте **Сохранять переменные вместе с деталью** на вкладке «Переменные», чтобы сохранить и результаты (до 32 MB).
- {{ui:Сохранить}} в группе «Скрипт» скачивает скрипт, чтобы поделиться им; {{ui:Открыть}} загружает его.
