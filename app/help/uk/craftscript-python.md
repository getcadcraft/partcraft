Python — третя мова [робочого простору скриптів](topic:craftscript). Оберіть **Python** у полі мови над редактором (файл `.py` відкривається в Python сам собою). Python, Lua і CraftScript мають спільні змінні та спільні вбудовані функції, тож скрипт Python може використовувати те, що створив скрипт CraftScript, і навпаки.

Перший запуск Python під час сеансу завантажує сам Python (CPython 3.14, близько 7 MB) з цього сайту, що займає кілька секунд. Python ще не входить до {{ui:Зберегти для роботи без зʼєднання}}: спершу запустіть один скрипт Python, перебуваючи онлайн.

## Python ізольований

Скрипти Python ізольовані, як скрипти CraftScript і Lua: вони мають доступ до деталі, змінних і вбудованих функцій, і більше нічого. Кожен запуск — це новий Python у власній пісочниці з невеликим деревом файлів у пам’яті (його стандартна бібліотека та тека `/tmp`, яка зникає після запуску). Він не має доступу до мережі, ваших файлів чи решти сторінки, як у браузері, так і в командному рядку. Скрипт від іншої особи все ще може використати багато часу чи пам’яті: {{ui:Зупинити}} його завершує.

## Основне

```
A = cs.magic(3)              # кожна вбудована функція — це cs.<назва>
B = A @ A.T                  # @ — матричний добуток, .T — транспонування
C = A * 2 + 1                # + - * / ** поелементні, як у numpy
print(A[0, 1], A[-1, -1])    # з 0; відʼємні відраховуються з кінця
row = A[1]                   # один індекс у матриці: рядок
big = A[A > 4]               # логічна маска вибирає елементи
A[0, 0] = -5                 # присвоєння в масив
V, D = cs.call('eig', 2, A)  # кілька результатів: cs.call(назва, скільки, …)
```

- Масив 1 × 1 приходить як звичайне число; інші масиви, розріджені матриці, сітки, поля та моделі є **Value**.
- Value має `shape` (кортеж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (її рядки), а також `float()`, `int()` і `bool()` для одного елемента.
- Порівняння (`<`, `==`, …) поелементні, як у numpy: вони дають логічний Value.
- Списки чисел, передані вбудованій функції, стають масивами: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` створює матрицю.
- Словник стає структурою, а список змішаних елементів — коміркою, і навпаки.

Кожна глобальна змінна, яку створює ваш скрипт (число, Value, словник, список…), потрапляє на вкладку **Змінні** після завершення запуску, навіть після помилки. Назви, що починаються з `_`, функції, класи та модулі залишаються в Python. `ws.name` напряму читає або встановлює змінну, а `ws_names()` перелічує їх.

`print(…)` виводить у консоль. `display(…)` (або `cs.display`) показує сітку, поле чи графік, як у CraftScript.

## Виклик бібліотеки аналізу

Функції бібліотеки викликаються, як вбудовані: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Пишіть назву в скрипті саме так, як вона є: PartCraft знаходить функції бібліотеки, які використовує скрипт, перед запуском.

## Ще не реалізовано

- numpy, scipy та інші пакети: тут є лише стандартна бібліотека Python (`math`, `json`, `itertools`, `decimal`, `statistics`…) без її частин для вікон, терміналу та баз даних (`tkinter`, `curses`, `sqlite3`).
- Сокети та все інше, що виходить назовні: тут у Python немає мережі.
- `time.sleep` повертається одразу.
- Згортання в редакторі та виклик функції Python зі скрипта CraftScript.
- Запуск перевіряє бюджет інструкцій і Зупинити кожні 1000 рядків; довге обчислення всередині однієї вбудованої функції спершу завершується.
