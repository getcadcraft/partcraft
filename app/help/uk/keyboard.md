Клавіші не працюють, поки ви вводите текст у полі на панелі, за винятком {{key:Mod+S}} і {{key:Mod+O}}: вони завжди працюють. Клавіші літер працюють без модифікатора.

Загальні примітки про клавіші в браузері та на клавіатурах без функціональних клавіш: [Клавіші, миші та трекпади](common:keys).

## Скрізь

| Клавіша | Дія |
|---|---|
| {{key:Mod+S}} | Зберегти деталь (у складанні: складання). Спершу закриває відкритий ескіз |
| {{key:Mod+O}} | Відкрити файл деталі або складання (спершу запитає, якщо є незбережені зміни) |
| {{key:Mod+Z}} | Скасувати дію |
| {{key:Mod+Y}} або {{key:Mod+Shift+Z}} | Повторити дію |
| {{key:F1}} | Відкрити або закрити цю довідку (також {{ui:Help}} у рядку програми). {{key:Esc}} теж її закриває. На багатьох ноутбуках і клавіатурах Mac утримуйте Fn |
| {{key:Ctrl+Shift+F}} | Режим екрана: звичайний, повноекранний, повноекранний з прихованими панелями. На Mac це теж Control, а не ⌘ |
| {{key:Esc}} | Вийти з повноекранного режиму (коли він увімкнений) |
| {{key:Mod+,}} | Налаштування, зокрема вкладка PartCraft (див. [Налаштування PartCraft](topic:settings)) |

У полі числа на панелі {{key:Mod+Z}} — це власне скасування тексту браузера. У полі числа над розміром ескізу вона скасовує дію в PartCraft.

## Копіювання, вставлення й дублювання

Вони діють на те, з чим ви працюєте: на вибрану геометрію у відкритому ескізі, на вибраний елемент в історії або на вибрану деталь у складанні. Докладніше в [Копіювання, вставлення й дублювання](topic:copy-paste).

| Клавіша | Дія |
|---|---|
| {{key:Mod+C}} | Копіювати вибране |
| {{key:Mod+X}} | Вирізати: копіювати, потім видалити |
| {{key:Mod+V}} | Вставити. В ескізі копія слідує за покажчиком: клацніть, куди її помістити |
| {{key:Mod+Shift+V}} | Вставити на місце: ті самі координати (у складанні — те саме місце) |
| {{key:Mod+D}} | Дублювати: копіювати й вставити одним кроком, не змінюючи буфер обміну |
| {{key:Mod+A}} | Вибрати все (в ескізі) |
| {{key:Esc}} | Скасувати вибір (і вставлення, яке слідує за покажчиком) |

У полі числа ці клавіші копіюють і вставляють текст, як зазвичай. Вибраний текст на панелі копіює браузер.

## На деталі (ескіз не відкрито)

| Клавіша | Дія |
|---|---|
| {{key:S}} | Створити ескіз на вибраній площині або плоскій грані; якщо нічого не вибрано, оберіть місце клацанням |
| {{key:F}} | Розмістити деталь у виді |
| {{key:M}} | Виміряти в кожному робочому просторі та в складанні; {{key:Esc}} скидає вибір, ще один {{key:Esc}} закриває вимірювання (див. [Виміряти відстані, кути й масу](topic:measure)) |
| {{key:X}} | Увімкнути або вимкнути перерізний вид у кожному робочому просторі та в складанні; {{key:Esc}} його закриває (див. [Подивитися всередину за допомогою перерізного виду](topic:section-view)) |
| {{key:Delete}} | Видалити вибраний елемент (запитає, якщо його використовують інші) |
| {{key:0}} … {{key:9}}, {{key:.}} | Коли вибрано елемент: введіть його головне число (глибину витягування, діаметр отвору, кількість у масиві, радіус скруглення …), потім {{key:Enter}}. {{key:Esc}} залишає старе значення |
| {{key:Backspace}} | Видалити вибраний елемент, якщо один вибрано |
| {{key:Esc}} | Припинити вибір площини ескізу або скасувати вибір (зокрема ребра чи грані, вибрані з {{key:Shift}}) |

## У 3D-виді

Спершу клацніть у виді, щоб він отримав фокус клавіатури.

| Клавіша | Дія |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Повернути вид на 15 градусів |
| {{key:Shift+Left}} та інші стрілки | Зсув |
| {{key:Plus}} або {{key:=}} | Збільшити |
| {{key:Minus}} | Зменшити |

| Миша | Дія |
|---|---|
| Перетягування лівою кнопкою | Обертати (орбітувати) вид |
| Перетягування правою або середньою кнопкою | Зсув |
| {{key:Shift}}, {{key:Ctrl}} або ⌘, утримувані під час перетягування лівою кнопкою | Зсув |
| Прокручування колеса | Масштаб біля покажчика (від себе збільшує) |
| Двопальцевий свайп на трекпаді | Обертати вид; з {{key:Shift}} — зсув. Щипок масштабує. Задається **Прокручування** в [Налаштуваннях PartCraft](topic:settings) |

З **Обертання виду: середня кнопка** у [Налаштуваннях PartCraft](topic:settings) середня кнопка обертає вид, {{key:Shift}} із середньою або правою кнопкою виконує зсув, а ліва кнопка лише вибирає.
| Клік | Вибрати грань (вона підсвічується повністю), ребро або площину |
| {{key:Shift}}+клік по ребру або грані | Зібрати кілька ребер або граней |
| Клік по порожньому місцю | Скасувати вибір |

## Під час вибору ребер або граней для скруглення, фаски чи оболонки


| Клавіша або миша | Дія |
|---|---|
| Клік по ребру або грані | Додати його або прибрати, якщо він уже є |
| {{key:Esc}} або {{key:Enter}} | Завершити вибір (те саме, що {{ui:Done}}) |
| {{key:F}} | Розмістити |
| Клавіші стрілок, коли вид має фокус | Обертати; з {{key:Shift}} — зсув |

## Комбінації, які може перехопити браузер

- {{key:Mod+Y}} у Safari може відкрити історію: для повтору використовуйте {{key:Mod+Shift+Z}}.
- {{key:Mod+D}} — клавіша закладок браузера: PartCraft перехоплює її, коли програма має фокус, і не чіпає, поки ви вводите текст у полі.
- {{key:F11}} і {{key:Mod+Plus}} / {{key:Mod+Minus}} — це повноекранний режим і масштаб сторінки браузера, а не PartCraft. Для повноекранного режиму використовуйте {{key:Ctrl+Shift+F}}, для моделі — колесо.
- Функціональні клавіші на багатьох ноутбуках і Mac потребують Fn: натисніть Fn+{{key:F1}} для довідки або скористайтеся кнопкою {{ui:Help}}.

Жести на сенсорному екрані й трекпаді: [Трекпад, сенсорний екран і малі екрани](topic:trackpad-and-touch).

## Де знаходиться Переміщення

Переміщення є в меню {{ui:More}} групи Елементи як {{ui:Move body}}, у полі {{ui:Move}}, де ви вводите ΔX, ΔY і ΔZ, і як стрілки {{ui:Drag to move}} на деталі.
