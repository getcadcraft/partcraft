Генератор — це звичайний скрипт ([CraftScript](topic:craftscript), Lua або Python) з кількома рядками коментарів на початку. PartCraft читає коментарі та створює форму; ваш скрипт читає вхідні параметри як змінні, які вже задано.

## Заголовок

Запишіть їх у рядках коментарів (`%` у CraftScript, `--` у Lua, `#` у Python):

```
% @generator Теплообмінник
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Масова витрата"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Поверхня"
% @input solid: = true
% @input note: = "text"
```

Вхідний параметр має вигляд `name: unit = default`, далі за бажанням діапазон `[min .. max]` (числа мають бути всередині нього), список варіантів `{a, b, c}` і мітку в лапках. Одиниця — це лише мітка для форми: **значення надходить у цій одиниці**, тож скрипт, якому потрібна SI, перетворює його, а `to_si(value, 'kg/s', 'kg/s')` також перевіряє, що одиниця означає те, що ви маєте на увазі. Ім'я складається з літер, цифр і символу підкреслення; `body`, `sheet` і `problems` зайняті.

## Що залишає скрипт

| Змінна | Що це |
|---|---|
| `body` | **Обовʼязкове.** Сітка поверхні, зазвичай з `[body, info] = to_body(field, h)`. Її виправляють і перевіряють наприкінці виконання. |
| `sheet` | Необовʼязкове. Структура: кожне поле — число або текст, або структура з `value`, `unit`, `ref` і `note`. Вона стає таблицею даних. |
| `problems` | Необовʼязкове. Комірка `problems` з `mfg_check(field, 'sls', struct(), h)` або ваші власні записи. Вони потрапляють до перевірок і до списку проблем. |

## Повний невеликий приклад

```
% Порожнистий куб зі стінкою.
% @generator Порожнистий куб
% @input side: mm = 12 [4 .. 40] "Сторона"
% @input wall: mm = 1.5 [0.5 .. 5] "Стінка"
% @input h: mm = 0.5 [0.25 .. 2] "Розмір вокселя"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'за сіткою');
```

Це створює замкнуту коробку, і перевірка показує її герметичну внутрішню порожнину як помилку для порошкового процесу. Робіть розмір вокселя `h` не більшим за третину найтоншої стінки, яку хочете: при товщині менш ніж приблизно три вокселі стінка ненадійна.

## Поля

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (тіло обертання з профілю), `tpms` (поверхні гіроїда, Шварца P і diamond, з розміром комірки та стінкою, які можуть змінюватися по всій деталі), `lattice` і `lattice_beams`, `along` (круглий канал уздовж траєкторії), булеві операції `field_union`, `field_intersect`, `field_subtract`, плавна `field_blend`, а також `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` повертає знакову відстань у точках (від'ємна всередині), `field_voxel` дає воксели для розв'язувачів. [Поля](topic:fields) пояснює, що це таке.

Варто знати обмеження: стінка поверхні товща за приблизно чверть комірки закриває канали; елемент тонший за приблизно три воксели може зійтися; `along` з'єднує круглі конуси, тому радіус, що швидко змінюється, залишає випуклість (для профілю використовуйте `field_revolve`).

## Відкрийте свій скрипт як генератор

У робочому просторі {{ui:Engineer}} натисніть {{ui:Open}} і виберіть файл. Скрипт без рядка `@generator` або `@input` не приймається: нічого було б налаштовувати. Генератор зберігається в цьому браузері (до 20), а {{ui:Remove}} його видаляє. Тіло, створене з нього, містить копію скрипта, тож деталь від нього не залежить.

Файл також може містити кілька генераторів: пакет JSON `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
