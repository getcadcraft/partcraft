CraftScript — це матрична мова, написана так, щоб її було легко читати, як MATLAB, тож більшість класичних чисельних кодів (наприклад, 88-рядковий код оптимізації топології) працюють з невеликими змінами. Вона працює в [робочому просторі скриптів](topic:craftscript) і з командного рядка.

## Значення

| Тип | Приклад | Примітки |
|---|---|---|
| Число, масив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Кожне число є масивом (розміром 1×1). Масиви зберігаються стовпець за стовпцем, до 8 вимірів |
| Логічний | `A > 2`, `true` | Масиви істина/хибність; можна використовувати як індекси |
| Текст | `'beam'`, `"beam"` | |
| Розріджена матриця | `sparse(i, j, v, n, n)` | Для матриць жорсткості |
| Сітка, поле, модель | `hexGrid(…)`, `part()`, `load('part.stl')` | Те, що малює `show` |
| Структура | `s.E = 210e3` | Іменовані поля |
| Комірка | `c = {1, 'two', [3 4]}` | Список будь-яких значень |
| Дескриптор функції | `f = @(x) x.^2` | |

## Масиви та індексація

- Діапазони: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Індексація починається з 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (увесь стовпець), `A(:)` (усе як один стовпець), `v(v > 0)` (логічна індексація).
- Присвоєння за межами масиву збільшує його, як у MATLAB: `v(10) = 1`.

## Оператори

- `+ - * / \ ^` — матричні операції (`A \ b` розвʼязує); `.* ./ .^` працюють поелементно. `'` транспонує.
- Порівняння `== ~= < <= > >=`; логіка `& | ~` (поелементно) та `&& ||` (з короткою схемою обчислення).

## Керування потоком і функції

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функції розміщуються в скрипті після його команд або на окремій вкладці скрипта з назвою функції:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Імʼя шукається в такому порядку: змінна, скрипт у цій деталі з такою назвою, функція бібліотеки, вбудована функція.

## Вивід, коментарі, echo

- Оператор без `;` виводить своє значення; `;` вимикає вивід.
- `%` починає коментар; рядки з `%{` і `%}` окремо закоментовують рядки між ними.
- `disp(x)`, `fprintf('%g\n', x)` і `display(x)` виводять у консоль.

## Помилки та обмеження

- Помилки простими словами пояснюють, що пішло не так, і вказують рядок (і ланцюжок викликів функцій).
- Кожен запуск має бюджет кроків (Параметри запуску на панелі); нескінченний цикл зупиняється з повідомленням або після натискання Зупинити.
- Кожен масив містить до 134 мільйонів значень.

## Не як у MATLAB

- Команди побудови передають свої параметри в самому виклику: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` та подібні приймаються, але нічого не роблять.
- `input` і `keyboard` не підтримуються: скрипт не може зупинитися, щоб поставити запитання.
- Наборів інструментів немає; є лише [бібліотека аналізу](topic:craftscript-library) і вбудовані функції.
