Cliquez sur {{ui:Update from the design…}} sous le nom du manuel, puis choisissez la pièce ou l'assemblage ouvert, ou un fichier (du même type que celui à partir duquel le manuel a été créé).

Un rapport liste ce qui va changer :

- Pièces **déplacées**, avec la distance parcourue.
- **Forme modifiée**.
- Pièces **nouvelles** : affichées dans toutes les vues, sans numéro de repère pour l'instant.
- Pièces **supprimées**, avec les annotations et les images clés de l'animation qui les désignaient : elles disparaissent aussi, et sont nommées ici pour que rien ne soit supprimé sans que vous le sachiez.
- Pièces **renommées**.

Cliquez sur {{ui:Update}} pour l'appliquer. Les pièces sont associées par leur identifiant propre dans la conception : les vues, annotations, numéros de repère et images clés leur restent attachés. La mise à jour constitue une seule étape : {{ui:Undo}} remet le manuel dans son état précédent.
