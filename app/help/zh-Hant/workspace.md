畫面分為五個部分：頂端的工具列、左側的歷程、中間的 3D 檢視、右側的屬性面板，以及底部的狀態列。在它們之上是 CadCraft 應用程式列。

## 應用程式列

最上方的細長列屬於 CadCraft 網站，而不是 PartCraft 本身。它顯示應用程式名稱與執行位置、版本功能表、**關於PartCraft**、螢幕模式按鈕，以及圖紙 / 模型主題切換。

- **圖紙**是淺色紙面上的深色線條。**模型**是深色背景上的淺色線條。草圖的顏色隨主題而變。
- {{ui:設定}}（齒輪，或{{key:Mod+,}}）有{{ui:PartCraft}}索引標籤：以哪個滑鼠按鈕轉動檢視、滑鼠滾輪或觸控板，以及繪製草圖時的關係。見 [PartCraft 設定](topic:settings)。
- 螢幕模式按鈕或{{key:Ctrl+Shift+F}}會依序切換一般、全螢幕，以及隱藏各列的全螢幕。隱藏各列時，把指標移到上緣（或在該處輕點）即可叫回。{{key:Esc}}回到一般模式。此按鍵在 Mac 上同樣是{{key:Ctrl+Shift+F}}，而不是 ⌘。

| 檔案 | {{ui:新增}}、{{ui:開啟}}、{{ui:儲存}}、{{ui:匯出}}（功能表） | 一律顯示 |
| 草圖 | {{ui:草圖}} | 沒有開啟草圖時 |
| 草圖 | {{ui:結束}}、{{ui:直線}}、{{ui:矩形}}、{{ui:圓}}、{{ui:圓弧}}、{{ui:點}}、{{ui:中心線}}、{{ui:圓角}}、{{ui:標註}}、{{ui:輔助}} | 僅在草圖開啟時 |

把指標停在按鈕上可看到它的作用與按鍵。呈灰色的按鈕目前無法使用：例如草圖開啟時的特徵按鈕，或組合件還沒有兩個零件之前的{{ui:接頭}}。

編輯群組中的{{ui:更多}}功能表會連同按鍵列出每個編輯動作。複製與貼上作用的對象依你所在的位置而定；見[複製、貼上與建立副本](topic:copy-paste)。呈灰色的項目，其提示文字會說明為什麼現在無法作用。

{{ui:匯出}}功能表包含{{ui:STL，用於 3D 列印}}、{{ui:3MF，用於 3D 列印}}、{{ui:STEP AP242（精確實體）}}、{{ui:STEP AP214（精確實體）}}、{{ui:STEP（面片，網格核心）}}、{{ui:STEP AP214（面片，網格核心）}}、{{ui:草圖或平坦面的 DXF}}與{{ui:圖紙（PDF）：視圖、剖面、局部放大、GD&T}}。兩個精確 STEP 項目呈灰色：它們在此版本尚未實作，請改用{{ui:STEP（面片，網格核心）}}。

## 歷程（左側）

左側的面板是零件的特徵歷程，也就是 PartCraft 由上而下重新建構的清單。

- 標題是零件的名稱（重新命名之前為「Part1」）。
- **前視平面**、**上視平面**與**右視平面**排在最前面。按一下即可選取；它會在檢視中亮起。
- 其下是依建立順序排列的你的特徵。特徵所使用的草圖縮排在該特徵下。
- 每一列右端的旗標表示其狀態：

| 旗標 | 意義 |
|---|---|
| （無） | 已建構，且草圖為完全定義 |
| − | 欠定的草圖（仍可移動） |
| + | 過定的草圖 |
| ⚠ | 已建構，但有警告（把指標停在上面可閱讀） |
| ⚠ 錯誤 | 特徵失敗。把指標停在上面可看到原因，或按一下它 |
| ⚠ 未建構 | 該特徵需要另一個失敗或已關閉的特徵 |
| 關 | 已抑制 |

- 每個特徵的名稱後面會顯示其主要數字，例如拉伸的「25 mm」或孔的「Ø6.6 通孔」。在數字上按兩下，或在該列按{{key:F2}}，即可就地變更。見[變更尺寸](topic:change-sizes)。
- 按一下特徵即可在右側編輯。在草圖上按兩下可將其開啟。
- 回溯時，清單中會出現**回溯列 · 向前推進**這一列。它之下的特徵會變灰且不建構。
- 焦點在某一列時，{{key:Up}}與{{key:Down}}可在列之間移動，{{key:Alt+Up}} / {{key:Alt+Down}}則在歷程允許時移動特徵本身。

在組合件中，同一個面板改為列出**零件**（第一個標示為「接地」）與**接頭**。

### 零件資訊

歷程下方的**零件**方塊列出實體的**體積**、**表面積**、**尺寸（X × Y × Z）**、**貫穿孔**、**實體數**、**三角形數**、**特徵**數，以及有多少個**失敗**。體積與面積是網格核心所建構之面片實體的數值，圓形零件會略低於真值（見[特徵及其選項](topic:features#curves-resolution)）。

在組合件中，此方塊的標題為**組合件**：零件、實例、接頭、未接合與干涉。

## 3D 檢視（中間）

檢視顯示實體、基準平面，以及任何尚未被特徵使用的草圖。

零件為空時，基準平面會完整繪出。零件有了實體後，它們會退到後方：畫得很淡，以免遮住零件，點按時會穿過它們到達零件。當你選擇要在哪裡繪製草圖時（沒有選取任何東西時按{{ui:草圖}}），以及在歷程中選取其中一個時，它們會重新完整顯示。{{ui:檢視}} › {{ui:基準平面}}可將它們完全隱藏；選擇繪製草圖的位置時仍會顯示。PartCraft 會記住這個選擇。

- 拖曳可轉動零件，按住右鍵或中鍵拖曳可平移，轉動滾輪可在指標處縮放。細節見[按鍵與滑鼠](topic:keyboard)。
- 把指標停在面、邊或平面上，會看到它亮起。按一下即可選取。面是整面亮起，邊是整條繪出並選取。按住{{key:Shift}}再按一下可收集多條邊或多個面，它們會保持標記。
- 右上角的視圖方塊會隨零件轉動：按一個面、邊或角，即可從該處觀看；拖曳可轉動；房子按鈕會回到起始位置。見[視圖方塊](topic:view-cube)。
- 選取的拉伸會在其端面顯示橘色箭頭，旋轉則在轉動結束處顯示彎曲箭頭：拖曳它可變更深度或角度，也可在旁邊的方塊輸入。見[變更尺寸](topic:change-sizes#drag-it-in-the-view)。
- 零件為空時，標題為**開始建立零件**的方塊會列出最初幾個步驟。
- 把 `.partcraft.json` 或 `.partcraft-asm.json` 檔案拖放到檢視的任意位置即可開啟。拖放到那裡的 `.step`、`.stp`、`.stl`、`.obj`、`.3mf` 或 `.3dm` 檔案會作為實體開啟。

### 選取邊或面時

在沒有選取任何東西時按{{ui:圓角}}、{{ui:倒角}}或{{ui:殼體}}之後（或在這類特徵上按{{ui:選取邊}}），零件會顯示成該特徵之前的樣子。按一下邊或面可加入或移除；其標記會顯示目前包含了什麼。按{{ui:完成}}或{{key:Esc}}即可結束。見[圓角、倒角與抽殼](topic:fillet-chamfer-shell)。

### 在圖紙上

{{ui:圖紙}}會用 A3 圖紙取代 3D 檢視。滾輪縮放，按住右鍵或中鍵拖曳可平移，{{key:F}}則符合視窗。見[製作圖紙](topic:drawing-pdf)。

### 草圖開啟時

檢視會轉為正對草圖平面，並在上面出現一層 2D 草圖。零件只顯示這張草圖之前所建立的特徵。左上角的一條帶狀區域顯示草圖的狀態標籤（「完全定義」、「欠定 · 3 個自由度」等）及其名稱，例如「Sketch2 在 Extrude1 的面上」。

## 屬性面板（右側）

右側面板顯示目前選取的東西，其標題會指出那是什麼：

- **零件**（未選取任何東西）：零件的**名稱**與**曲線**設定。
- 平面：{{ui:在其上繪製草圖}}按鈕。
- **面**：它的種類（平面、含半徑與軸的圓柱、圓錐、球或圓環）、面積、由哪個特徵產生，以及對平面而言的{{ui:在此面上繪製草圖}}、{{ui:垂直於}}、{{ui:將面匯出為 DXF}}、{{ui:由此拉伸}}、{{ui:向內切入}}與{{ui:此處鑽孔}}（見[拉出或推入整個面](topic:extrude-and-cut#pull-or-push-a-whole-face)）。
- **邊**：它的種類（直線、含圓心與半徑的圓，或曲線）、長度，以及它所處的兩個面（例如「Extrude1 端面與 Extrude1 側面」），並有{{ui:圓角}}與{{ui:倒角}}按鈕。
- 以{{key:Shift}}選取的多條邊或多個面：數量，邊有{{ui:圓角}}與{{ui:倒角}}，並有{{ui:清除}}。
- 特徵：其數值與選項、其草圖的標註，然後是{{ui:抑制}}、{{ui:回溯至此}}、{{ui:上移}}、{{ui:下移}}、{{ui:刪除}}與其**名稱**。
- 開啟中的草圖：其狀態、可加到所選項目的關係、關係與標註的清單、**以座標新增**，以及{{ui:結束草圖}}、{{ui:符合視窗}}與{{ui:匯出為 DXF}}。
- 在圖紙上：剖面與局部放大設定，或選取的 GD&T 符號。
- 在組合件中：組合件、所選的零件，或所選的接頭。

每個數字方塊在你按{{key:Enter}}或{{key:Tab}}，或點到別處時生效。零件會立即重新建構；沒有「確定」按鈕。要回到之前，請用{{key:Mod+Z}}。

## 狀態列（底部）

- 左側是指標在草圖中的座標（僅在草圖開啟時）。
- 中間是訊息：下一步要做什麼，以及為什麼被拒絕。當看起來沒有任何事發生時，請看這裡。
- 靠右是核心標籤：此版本一律是「網格核心」。把指標停在上面可看到它的意義。見[網格核心](topic:solid-kernels)。
- 最右側是標籤：零件重新建構時顯示「重新建構中…」，一切正常時顯示「已於 … 毫秒內重新建構」，或「1 個特徵失敗」。在組合件中則顯示「已於 … 毫秒內放置」，或計算接頭問題的數量。

另見[在圖解中開始製作手冊](topic:illustrate)：這個工作區可由你的零件與組合件製作組裝手冊。

## 在窄螢幕上

寬度在 760 像素以內時（例如手機），檢視會佔據整個螢幕：工具列是可左右捲動的單一列，面板則從底部的列以工作表形式開啟。{{ui:工具}}會隱藏工具列，{{ui:移動}}則把它放到底部。見[觸控板、觸控與小螢幕](topic:trackpad-and-touch)。
