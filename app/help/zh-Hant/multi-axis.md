加工可以讓刀具以一個角度切削，也可以在切削時移動旋轉軸。有三種方式，由簡單到複雜。

**這裡的任何內容都尚未在機台上執行過。** 路徑已由測試依幾何檢查，G-code 也已回讀；但內建後處理器是依控制器所記載的代碼寫成，而非針對眼前的任何一台機台。請先在機台自己的控制器模擬器中，並在空中驗證程式，再讓它接觸金屬。

## 機台的旋轉軸

在**設定**索引標籤中，{{ui:旋轉軸}}說明機台具備哪些軸：

| 選項 | 機台 |
|---|---|
| 無（3 軸） | 一般銑床。任何需要傾斜刀具的操作都會發出警告，且後處理器會拒絕寫出。 |
| A（繞 X 旋轉） | 沿 X 的一個旋轉軸：第 4 軸工作台或分度器。刀具只能在 Y–Z 平面內傾斜。 |
| B（繞 Y 旋轉） | 沿 Y 的一個旋轉軸。刀具只能在 X–Z 平面內傾斜。 |
| A 與 C | 繞 X 的傾斜軸，搭載於繞 Z 的旋轉上，或承載繞 Z 的旋轉：雙軸傾斜工作台，或主軸頭。 |
| B 與 C | 同上，但傾斜繞 Y。 |

然後：

- **搭載於**：{{ui:工作台（工件旋轉）}}或{{ui:主軸頭（刀具旋轉）}}。工作台以相反方向轉動，以將同一面帶到刀具下，因此每個角度的正負號都由此決定。
- **控制器保持刀尖在路徑上（TCP）**：開啟時，程式中的 X Y Z 即為零件座標中的刀尖，其餘由控制器處理（內建的 Fanuc式與 LinuxCNC 後處理器會為刀長寫入 `G43.4`）。關閉時，在工作台機台上，PartCraft 會依你給定的**旋轉中心**（工件座標；工件原點位於中心時為 0, 0, 0），寫出隨旋轉工作台攜帶工件時的 X Y Z。主軸頭機台必須開啟 TCP：否則程式需要機台的樞軸長度，而 PartCraft 並不知道此值。
- **傾斜限制**：傾斜軸可以轉動的最大角度。

各機台對正向的定義不同。若你的機台某軸轉向錯誤，請在後處理器的副本中更改正負號（[可編輯的後處理器](topic:post-processors)）。

## 一般操作的傾斜刀具

每個銑削操作（端面、口袋、自適應、輪廓、鑽孔、倒角、平行、等殘高、3D 粗加工、殘料）都有**刀具傾斜**與**傾斜方向**：僅適用於該操作的刀具方向，以設定的刀具軸為基準量測。這是 3+2 加工：旋轉軸移到某一位置後保持不動，由三軸進行切削。

- 輸入兩個角度，或按{{ui:刀具對準一個面}}並點選一個平坦面：刀具將直接對準該面。
- 照常選取該操作的面與邊。判斷何者為底面或孔，是沿傾斜後的刀具方向進行的。
- 該方向的毛胚，是能容納旋轉毛胚的方塊，因此從該側看，高度與間隙都是安全的。

在 G-code 中，操作之前刀具會先抬起，旋轉軸轉動，然後刀具下降到其第一點的上方。在沒有 TCP 的工作台機台上，圓弧仍為圓弧，固定鑽孔循環仍為循環（寫出的座標系僅繞 Z 旋轉）。在傾斜平面中使用 TCP 時，圓弧會變成短直線，循環則變成其所代表的移動。

毛胚模擬會**單獨**執行傾斜方向：它顯示該操作從其側面所見的整個毛胚中切掉了什麼，並在那裡找出過切；但從其他方向所做的切削不會被帶入。

## 5 軸精修

加工工具列中的{{ui:更多}}會在**操作**索引標籤頂部列出此操作與下一項。

{{ui:5軸}}是[平行精修](topic:finish-3d)，只是改用**隨切削傾斜的球頭銑刀**。球頭以球面切削，無論刀具繞其中心如何傾斜，球面都相同，因此球頭所走的路徑與三軸道次完全一樣，只有刀具的方向改變：

- **朝向曲面**：1 = 垂直於曲面，0 = 直立，其間任何值皆可。
- **前傾**：沿切削方向的角度數，使球心靜止處不參與切削。
- **最大傾斜**：刀具距離設定軸的傾斜角度，不會超過此值。

刀柄若會碰到模型，傾斜會被收回，直到不再碰撞，並說明有多少點受到影響。每道次以直線抬刀進入與離開。

## 旋轉精修（第 4 軸）

{{ui:旋轉}}用於零件以**工作座標 X** 夾持於旋轉軸上的情況。零件旋轉，而刀尖始終指向軸線的球頭端銑刀沿其曲面切削：

- **道次**：{{ui:沿軸向}}（沿 X 的直線，相隔一個步距的旋轉量）或{{ui:繞工件}}（環狀，相隔一個步距的 X 量）。
- **軸位於 Y / Z**：軸的位置。留空表示毛胚中心。在沒有 TCP 的工作台機台上，這必須是設定中的旋轉中心；不符時操作會發出警告。
- **從／到 X**與**從／到角度**：要切削的長度與旋轉範圍。

在每個點上，球頭高於軸的高度，即為從該側看，球面在零件網格上的精確下降量。

## 限制

- 5 軸與旋轉精修**僅**接受**球頭銑刀**。不提供側面切削（直紋牆面的刀具側面）、沿曲面自身方向的流線、多軸粗加工，也不會自動選擇傾斜角度以避免碰撞。
- 5 軸與旋轉路徑**不會**經過毛胚模擬，因為毛胚模擬是高度圖，無法表示傾斜的切削。
- 5 軸精修只在從上方所見的模型上檢查刀柄；刀把、主軸與機台本身在任何地方都不作檢查。
- 旋轉精修只切削刀具從軸向看所能見的部分。
- 在大型零件上，5 軸精修需要一分鐘以上才能算出：刀柄會在每道次的每一點上都被檢查。
- 當旋轉軸與直線軸同時移動且 TCP 關閉時，內建後處理器會將進給寫成逆時間（`G93`），然後回到 `G94`。
- 不會寫出傾斜工作平面的代碼（`G68.2` 等），也不了解特定機台的限制、解纏或碰撞區域。
