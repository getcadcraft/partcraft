## 作業內容

一次交付**零件的每種尺寸**：每個組態各一份 STEP、IFC 與 DWG 檔案及一張圖片，一份說明各組態內容的表格，以及一個將全部組態放在同一頁的程式庫項目。

首先需要一個具有**組態**的零件（請參閱[組態與設計表](topic:design-tables)）。會關閉某特徵的組態（例如有孔與無孔的板件）會成為獨立的變體。

## 步驟

1. 開啟零件。在 {{ui:參數}} 索引標籤中，找到 **組態**。
2. 按一下 {{ui:變體套件…}}。
3. 勾選要建立的組態（預設全部勾選），以及要寫出的檔案：STEP、IFC、DWG、預覽及程式庫項目。
4. 按一下 {{ui:製作套件}}。狀態列會在建立變體時計數；零件不會變更。
5. 下載一個 zip 檔：`<part> variants.zip`。

## zip 檔內容

| 檔案 | 說明 |
|---|---|
| `<name>.step` | 組態的 STEP 實體。 |
| `<name>.ifc` | IFC4，包含一個元素，內含已建立的實體，以及零件參數作為屬性；其值為該組態自身的值。 |
| `<name>.dwg` | 前視、上視、右視與等角視圖，以完整尺寸的圖紙呈現。 |
| `<name>.svg` | 其等角線稿圖。 |
| `variants.csv`, `variants.json` | 參數表：每個變體的 ID、名稱及每個參數的值、其關閉的特徵、其檔案、體積與尺寸。 |
| `<part>.item.json` | 零件作為一個程式庫項目，包含其變體（見下文）。 |
| `README.txt` | 製作內容、下列說明，以及任何未建立的項目。 |

檔案以組態命名。無法建立的組態（即某特徵無法以這些數值製作）會從檔案與表格中排除，並列於 README 及 zip 儲存後的訊息中；其他組態仍會寫出。

## 注意事項

- **STEP** 在版本中啟用精確核心時為精確檔案。未啟用時，STEP 為多面體（平面三角形），README 會註明。
- **DWG** 是圖紙，而非 3D 模型。其線條來自網格，因此曲線邊緣由許多短線組成。
- **程式庫項目** 為每個變體包含一個實體與一個平面投影，採用程式庫自身的座標軸：Z 軸朝上、前方朝向 −Y，插入點位於底部後方的中間。平面為每個變體的外接矩形。項目上限為 8 MB，因此過大的變體會變成其尺寸的方塊，README 會註明數量。
- 零件目前使用的組態即為項目的預設變體。
- PartCraft 不會設定連接埠（管線與風管的連接點）。

## 將變體放到程式庫頁面

在網站的 **程式庫 › 上傳** 上傳 `<part>.item.json`。選擇其類別、授權及標示來源文字，即成為具有其變體的程式庫項目。在 BimCraft 中放置時會詢問要使用哪個變體，而「交換」會提供其他變體。供訪客選擇選項、查看 3D 並下載變體的頁面，目前僅供**工作人員預覽**，尚未開放給公眾。

## 從指令列執行

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` 指定組態，`--formats` 可為 `step`、`ifc`、`dwg`、`preview` 中的任一或多項，`--no-item` 則不包含程式庫項目。它會寫出資料夾、zip 檔或兩者，並在有變體無法建立時以代碼 1 結束。請參閱[指令稿與指令列](topic:scripts-and-cli)。
