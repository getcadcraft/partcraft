**預覽版。** 指令稿功能於PartCraft 0.3首次推出，目前為預覽版：語言、程式庫以及指令稿的儲存方式仍可能變更，現在撰寫的指令稿日後可能需要小幅修改。若遇到問題，請告訴我們。

指令稿工作區會在零件旁執行你自己的計算：小型加總、完整分析，或是[分析程式庫](topic:craftscript-library)中的指令稿。指令稿以 **CraftScript** 撰寫（一種與 MATLAB 相當類似的矩陣語言，見 [CraftScript 語言](topic:craftscript-language)），或以 **Lua**（見 [以 Lua 撰寫指令稿](topic:craftscript-lua)）或 **Python**（見 [以 Python 撰寫指令稿](topic:craftscript-python)）撰寫。

在工具列左側的 **工作區** 方塊中選擇 **指令稿**。零件不會被變更。右側面板會變成指令稿面板（比平常寬；拖曳其邊緣即可調整大小，或使用其 {{ui:⋯}} 功能表將其移至第二螢幕，見 [排列面板](common:arrange-panels)）。

## 建模時撰寫指令稿

撰寫指令稿時無須離開**設計**工作區。在設計工作區中，右側面板的 {{ui:指令稿}} 索引標籤包含相同的編輯器、主控台、變數與程式庫，以及相同的指令稿。特徵樹與檢視區仍可正常使用：點選特徵即可選取它，連按兩下草圖即可編輯，旋轉檢視，然後回到 {{ui:指令稿}} 索引標籤並按 {{key:F5}}。

指令稿所**顯示**的內容（網格、場、圖表、表格）不會疊加繪製在設計工作區中的模型上：主控台會說明此事，切換到指令稿工作區時即可看到全部內容。

{{ui:彈出}}（位於 {{ui:執行}} 旁）會將整個面板移至獨立視窗，例如移至第二螢幕，使編輯器與完整檢視區並排顯示。{{ui:放回}} 則會將其重新停駐。見 [排列面板](common:arrange-panels)。

## 執行第一個指令稿

1. 在編輯器中輸入，例如：

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', '正弦波')
   disp(max(y))
   ```

2. 按 {{key:F5}}（或 {{ui:執行}}）。編輯器下方的主控台會顯示指令稿印出的內容，以及「完成，用時 … 秒」。圖表會出現在 3D 檢視區底部的**次要顯示區**中。
3. 與 MATLAB 相同，不加分號的一行會印出其值：`a = 3` 會印出 `a = 3`；`a = 3;` 則不印出任何內容。
4. 若只想執行指令稿的一部分，請選取該幾行並按 {{key:Mod+Enter}}（{{ui:選取範圍}}）。若未選取任何內容，則會執行游標所在的那一行。
5. 主控台底部（`>>` 之後）的那一行，會在你按下 {{key:Enter}} 時執行一個陳述式。{{key:Up}} 與 {{key:Down}} 可叫回先前輸入的行。

## 尋找、摺疊與自動完成

- **尋找與取代。** 按 {{key:Mod+F}}（或按 {{key:Mod+H}} 以同時取代）。程式碼上方會開啟一個列：輸入要尋找的內容；符合項目會亮起，計數會顯示你目前所在的位置。輸入框旁的按鈕可切換區分大小寫（**Aa**）、只比對完整單字（**W**）以及使用正規表示式（**.\***；在取代文字中，`$1` 會放入第一個群組所比對到的內容）。{{ui:取代}} 會取代目前符合的項目，{{ui:全部}} 則會取代所有符合項目，並可用 {{key:Mod+Z}} 作為一個步驟復原。
- **摺疊。** 點選行號旁的 ▾，或將游標置於 `function`、`if`、`for`、`while`、`switch` 或 `try` 行（Lua：`function`、`do`、`if`、`repeat`），再按 {{key:Mod+Shift+[}}，即可收起其內部的行；該行會顯示收起的行數。按 ▸ 或 {{key:Mod+Shift+]}} 可再展開。摺疊只會隱藏行：執行、儲存、複製與行號仍會計算每一行；在已摺疊的行上輸入時會先展開。
- **自動完成。** 輸入名稱的前兩個字母，或按 {{key:Mod+Space}}：清單會顯示你擁有的變數、語言的函式（含其引數）、關鍵字，以及指令稿中已出現的名稱。使用方向鍵選擇，再按 {{key:Enter}} 或 {{key:Tab}}。

## 發生問題時

- 錯誤會指出問題及其行號：該行會在編輯器中以紅色標示，主控台中的 **第 n 行** 可帶你前往該行。
- 無窮迴圈：按 {{ui:停止}}（工具列或面板）。指令稿會立即停止；變數會保留該次執行之前的值。
- 每次執行也都有步數預算（預設為 20 億步；可在面板的**執行選項**下變更）。超過預算的執行會以訊息停止。

## 變數在指令稿之間傳遞

指令稿建立的每一個頂層變數都會出現在**變數**索引標籤中（名稱、類型、大小、最小與最大值），並在下一個指令稿中保留，不分語言。這就是一個指令稿劃分網格、下一個求解、第三個繪圖的運作方式。

- 點選變數即可顯示：網格、場與模型會顯示在 3D 檢視區中，陣列則以表格顯示於次要顯示區（向量另附折線圖，矩陣另附色彩圖）。
- {{ui:存成 JSON}}、{{ui:存成 CSV}}（數字表格）與 {{ui:存成 HDF5}} 會下載它；{{ui:刪除}} 會移除它；{{ui:全部清除}} 會清空工作區。
- 勾選**隨零件儲存變數**，即可將它們保留在零件檔案中（最多 32 MB；較大的變數僅保留於本次造訪期間）。開啟此類零件時，面板會提供載入這些變數的選項。

## 網格、場與圖表

- `show(m)` 會繪製網格；`show(f)` 會以圖例為其網格上的場著色。檢視區左上角的**顯示項目**清單可隱藏（{{ui:眼睛}}）或移除每個項目，也可隱藏或顯示零件本身。在圖例下方，可輸入範圍（**從**、**到**）或按 {{ui:自動}}；向量或應力場還會提供要顯示哪個分量的選項。
- `show(f, 'deform', u, 'scale', 50)` 會繪製依位移場 `u` 移動並放大 50 倍的網格（若省略 `scale`，約為模型尺寸的 8%）。
- 點選顯示中的網格：最近的節點、單元及該處的場值會顯示在次要顯示區中（**已選取**）。
- `plot`、`imagesc` 與 `table` 會將折線圖、二維陣列的色彩圖或表格放入次要顯示區。若圖表與先前的圖表具有相同的 `'id'`（或標題），則會取代先前的圖表，因此迴圈可以更新同一張收斂圖；`'append', true` 則會在圖表中加入一條曲線。{{ui:清除}} 會清空次要顯示區；箭頭可將其收合。
- 當有兩張或以上的圖表時，{{ui:並排}} 會同時顯示全部圖表（最新的六張）；點選表格或圖片的索引標籤，則會再次只顯示該項目。
- 每張圖表下方都有 {{ui:PNG}}、{{ui:SVG}} 與 {{ui:CSV}}。無論佈景主題為何，PNG 與 SVG 都會以白底與紙張色彩輸出（PNG 為 1600 × 1000 像素；SVG 縮放時不會模糊）；CSV 保留每個數字的所有位數：當曲線共用 x 時為一欄 x 加上每條曲線一欄，否則每個點一列，並附上曲線名稱。
- {{key:F}} 或 {{ui:符合視窗}} 會使檢視區符合目前顯示的內容。

## 檔案

- 指令稿群組中的 {{ui:開啟}}（或將檔案拖放到檢視區或面板）：`.craft`、`.lua` 與 `.py` 檔案會以新指令稿開啟（不會執行）；資料檔（STL、OBJ、CSV、JSON、NPY、HDF5）會以其檔名載入變數中。
- 指令稿群組中的 {{ui:儲存}} 會將目前的指令稿下載為檔案。
- 指令稿群組中的 {{ui:新增}}（或索引標籤旁的 {{ui:+}}）會開始另一個指令稿。連按兩下索引標籤即可重新命名；其 {{ui:×}} 會將其移除（可以復原）。

## 讀取零件的參數

指令稿會依名稱讀取零件的參數（見 [以參數驅動零件](topic:parameters)）：

```
w = param('width');     % 單一參數的值，單位為 mm（或度，或純數字）
p = params();           % 所有參數，以結構表示：p.width、p.height
```

在 Lua 與 Python 中，分別為 `cs.param('width')` 與 `cs.params()`。指令稿只會讀取參數：請在 {{ui:參數}} 索引標籤中變更參數。在指令稿索引標籤下方，有一行會列出它以 `param('…')` 讀取的參數，並標示零件中不存在的參數；{{ui:參數}} 索引標籤則會在每個參數下列出該指令稿。在指令稿執行期間才組合出的名稱（例如 `param(name)`）不會被列出。

## 指令稿會儲存在零件中

索引標籤中的每個指令稿都會保存在零件中，因此檔案群組中的 {{ui:儲存}} 會連同零件一併儲存，對指令稿的變更也可以復原。開啟零件**絕不會執行其指令稿**：主控台會說明零件包含多少個指令稿，且只有在你按下執行時才會執行。他人的零件可能包含任何指令稿：執行前請先閱讀。指令稿會在此電腦的背景中執行，無法存取網路，也無法變更網頁。
