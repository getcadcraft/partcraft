以下是 PartCraft 0.7 相較於 0.6 的變更。零件可從更多類型的檔案匯入，新的工作區可依設計製作手冊。

## 新增功能

### 依設計製作手冊

- **圖解工作區。** 在 {{ui:工作區}} 切換器中選擇 {{ui:圖解}}，然後在 {{ui:手冊}} 群組中選擇 {{ui:新增}}：手冊可從開啟的零件或組合件、已儲存的組合件，或 glTF、OBJ、STL 或 3MF 檔案開始（保留其樹狀結構與名稱；同一零件的複本會成為一個零件並標示數量）。手冊是一個獨立檔案（`.partcraft-manual.json`），內含零件的副本，因此設計持續進行時，文件也能同步撰寫。請參閱[在圖解中開始製作手冊](topic:illustrate)。
- **視圖與外觀。** 隱藏、半透明顯示、隔離或重新著色零件，播放爆炸視圖，從模型中切出剖面或方塊，加入放大鏡，並將全部內容儲存為視圖。請參閱[視圖、外觀、剖面與放大鏡](topic:illustrate-views)。
- **氣球註記與零件清單。** 按一下即可為視圖中顯示的每個零件加上氣球註記；編號會與零件保持對應，且絕不重複使用。清單可置於視圖中，並可儲存為 CSV。請參閱[零件清單與氣球註記](topic:illustrate-parts-list)。
- **附著式註解：** 標籤與註解框會自動填入零件的編號、名稱、材料或數量；箭頭、距離、角度與半徑，則可從零件、形狀與圖片量測。零件爆開時，註解會隨零件移動。請參閱[附著式註解](topic:illustrate-annotations)。
- **線稿、說明書與 3D 檔案。** 可將任何視圖匯出為向量線稿（SVG 或 PDF），並包含隱藏線與填滿的剖面，或匯出為 PNG；可將視圖製成 PDF 或單一 HTML 頁面的逐步說明書；或儲存一個 HTML 檔，可在任何瀏覽器中離線開啟，內含視圖、零件清單與動畫。請參閱[技術插圖](topic:illustrate-line-art)、[說明書文件](topic:illustrate-instructions)與[互動式 3D 檔案](topic:illustrate-interactive)。
- **動畫與更新。** 為零件與攝影機設定關鍵影格，逐步錄製爆炸視圖，並儲存影片。設計變更時，{{ui:從設計更新…}} 會在任何變更前顯示移動、變更、新增與移除的內容，並使視圖、註解、氣球註記與關鍵影格與其零件保持對應。請參閱[製作手冊動畫](topic:illustrate-animation)與[依設計更新手冊](topic:illustrate-update)。

### 開啟其他檔案

- **STEP 檔以實體開啟。** {{ui:開啟}} 可在未啟用精確核心的情況下讀取 AP203、AP214 與 AP242 STEP。平面維持為平面，曲面會變成許多小平面，組合件則會以一個實體匯入，各零件位於檔案所指定的位置。可於其平面上繪製草圖、切割，並在其上新增特徵。請參閱[開啟 STEP 檔並在其上建構](topic:import-step)。
- **STL、OBJ 與 3MF 網格轉為實體。** 開啟或拖放檔案：PartCraft 會合併重複的角點、封閉小縫隙、填補孔洞，並翻轉朝向錯誤的三角形，然後說明其所做的處理，以及網格現在是否已封閉。選擇單位與朝上的方向，實體即會以 **Imported1** 匯入，其平面會成為可繪製草圖的面。無法封閉的網格會說明剩餘的開口數，且不會新增任何內容。請參閱[以實體開啟 STL、OBJ 或 3MF](topic:open-meshes)。
- **.3dm 檔以單一實體開啟。** `.3dm` 檔案中的網格、多重曲面、擠出與區塊放置，會以單一實體匯入：來源為檔案中已儲存的網格，或由 PartCraft 網格化而成，並經過與網格相同的修復與「closes?」檢查。曲線、文字、SubD 物件、圖層與顏色會被略過，對話方塊會註明此事。請參閱[以實體開啟 .3dm 模型](topic:open-3dm-files)。

### 零件與組合件

- **由鋼材斷面製作框架。** 以線條繪製框架，可於單一草圖中完成，或於多個草圖中完成以製作 3D 框架，然後選擇 {{ui:更多}} › {{ui:結構構件}}：沿每條線套用 AISC 或 EN 10365 表格中的斷面。角落可採用斜接或對接，呈 T 形相接或三根相交的構件會裁切至合適長度，自由端可加上端蓋，角落可加上接合板，切割清單則會提供每個零件的長度與端角角度（{{ui:儲存裁切清單 (CSV)}}）。請參閱[由鋼材斷面製作框架](topic:structural-members)。
- **組合件中的閉合迴路。** 以環狀相接的零件（四連桿機構、曲柄滑塊、含斜撐的框架）現在可以閉合：拖曳迴路上的某處或輸入數值，其餘部分會隨之移動，動作檢查也會以相同方式掃描迴路。仍可移動的接頭會以藍色顯示；無法閉合的迴路會變紅，並說明偏差量。請參閱[閉合迴路：連桿](topic:build-assembly#closed-loops-linkages)。
- **具有數百個特徵的零件。** PartCraft 會保留歷程中途的實體，因此在歷程後段的變更只會重建其後的特徵，而互不相干的切除與凸台會一併套用。已在具有 750 個特徵的零件上測試。{{ui:參數}} 視窗可處理數百個方程式，除非會佔用大量記憶體，否則復原最多保留200個步驟（且至少 20 個）。請參閱[具有數百個特徵的零件](topic:edit-history#parts-with-hundreds-of-features)。
- **由組態製作變體套件。** {{ui:參數}} 索引標籤中**組態**下的 {{ui:變體套件…}} 會在一個 zip 中建立每個組態，或建立勾選的組態：每個組態各一份 STEP、IFC、DWG 圖紙與預覽，參數表（CSV 與 JSON），以及將零件作為含變體的單一程式庫項目。無法建立的組態會被列出並排除。指令列也可透過 `partcraft variants` 完成相同作業。請參閱[從組態製作變體套件](topic:variant-pack)。

### 製造

- **可編輯的後處理器。** 「製造」中的 Fanuc 風格、GRBL 與 LinuxCNC 後處理器，現在是 PartCraft 自有後處理器格式的簡短文字檔，且仍會寫出與先前完全相同的內容。{{ui:編輯後處理器…}} 會開啟其中一個的副本（{{ui:新增後處理器…}} 與 {{ui:匯入後處理器檔案…}} 亦同），指出有誤的行，並在輸入時顯示其寫出的 G 代碼。後處理器會儲存於零件中，並以 `.cpost` 檔案儲存。請參閱[可編輯的後處理器](topic:post-processors)。
- **3D 精加工：平行與殘脊。** 以球頭、圓角或平底銑刀精加工整個模型的表面，可沿任意角度的平行線進行，或以設定距離的路徑間距進行，使路徑之間的殘脊具有您指定的高度（平底銑刀不適用）。請參閱[3D 精加工：平行與殘脊](topic:finish-3d)。
- **工具程式庫。** 在此瀏覽器中儲存適用於所有零件的刀具，並可匯出或匯入為 JSON 檔以移至另一部電腦。請參閱[工具程式庫](topic:tool-library)。
- **以顏色比對毛胚與模型。** 開啟 **顯示模擬毛胚** 後，毛胚在模型上以綠色顯示，刀具切入之處為紅色，保留毛胚之處為黃色至灰色，面板中並附有圖例。請參閱[模擬](topic:manufacture#simulate)。
- **在排版之間保留餘料。** 完成排版後，每塊板材的剩餘部分可成為附有材料與厚度、並編有號碼的餘料。下一次相同材料與厚度的排版會優先使用餘料，然後才使用整塊板材；毛胚清單會儲存於檔案中並可存為 CSV，且 DXF 會標示每塊餘料。請參閱[保留與重複使用餘料](topic:nest-offcuts)。
- **雷射程式。** {{ui:匯出}} › {{ui:雷射程式…}} 會從 DXF 檔取得輪廓，並設定每個圖層的作用（切割、刻痕、雕刻、填滿），預覽雷射頭的移動，並儲存 GRBL 雷射模式的 G 代碼。在 Chrome 與 Edge 中，也可在關閉雷射的情況下框出加工範圍，然後透過 USB 傳送。設定會儲存於檔案中。請參閱[將圖形傳送至雷射](topic:laser-cutting)。
- **USD 匯出。** {{ui:匯出}} › {{ui:USD 封裝（.usdz）}} 會寫出零件及其材質、體積與質量，或寫出組合件（每個零件只寫一次，並放置每個複本），以公尺為單位且 Z 軸朝上。請參閱[將零件或組合件匯出為 USD](topic:usd)。

### 助理

- **供自有 AI 助理使用的工具。** 在 {{ui:設定}} › {{ui:PartCraft}} › {{ui:助理}} 中開啟後，透過 CadCraft Studio 連線的助理即可讀取特徵、參數與質量特性，設定參數並重建（為一個復原步驟），以 {{ui:腳本}} 工作區的方式執行 CraftScript、Lua 或 Python 指令稿，匯出 STL、3MF、多面 STEP 或 USD，儲存，並將手冊匯出為 PDF、SVG、說明書或互動式 3D 檔案。檔案伺服器與 `cadcraft` 指令列對已儲存的零件與手冊執行相同操作。PartCraft 不包含任何 AI。請參閱[搭配 AI 助理使用 PartCraft](topic:use-with-ai-assistants)。

## 變更

- **從檔案匯入實體的零件會以第 5 版儲存。** 具有 STEP、STL、OBJ、3MF 或 `.3dm` 實體的零件，會將修復後的三角形保留於 `.partcraft.json` 檔中，因此無需再使用原始檔案。PartCraft 0.6 會以其「較新版本」訊息拒絕第 5 版，而不會錯誤地開啟。其他零件的儲存方式不變。請參閱[PartCraft 檔案](topic:file-formats#the-partcraft-files)。
- 撰寫的後處理器會儲存於零件中。舊版 PartCraft 開啟此類零件後再次儲存時，會捨棄這些後處理器。

## 所有應用程式通用

- **單位。** {{ui:設定}} › {{ui:一般}} › {{ui:單位}} 中，長度、面積、體積、角度與斜率各有一份清單，其尺寸與單位定義所列完全相同（美國測量英呎為獨立單位）。關閉不使用的單位，即會將其移出單位清單；為某單位加上星號，新的作業即以該單位開始。檔案一律保留其自身的單位。PartCraft 自有的方塊目前仍不會依清單或星號設定：零件仍以毫米顯示。請參閱[單位、輸入的數值與單位清單](common:unit-lists)。
- **版面更緊湊，面板可收合。** {{ui:設定}} › {{ui:一般}} › {{ui:版面密度}} › {{ui:緊湊}} 可在螢幕上容納更多內容（觸控螢幕與手機仍保留較大的按鈕）。每個側邊面板都有窄版標題列：拖曳即可停駐或浮動面板，拖放至另一面板的標題列即可與之共用同一框架並以索引標籤呈現，釘選則可使其滑入邊緣收合，或隱藏後從邊緣叫回。請參閱[安排面板](common:arrange-panels#make-the-layout-denser)。
- **對話方塊可移動。** 拖曳對話方塊的標題列，將其移開圖形範圍；它會回到原位。連按兩下標題列可使其重新置中。請參閱[移動對話方塊](common:arrange-panels#move-a-dialog)。
- **AI 助理操作範例。** 為自有助理提供十則實作範例要求（整理圖形、列印一組圖紙、檢查圖紙、向模型提問、彙總數量計算、試用零件變體……），每則範例都列出所呼叫的工具與所需權限，且均經我們的測試重播。應用程式不含任何 AI。請參閱[AI 助理操作範例](common:assistants-recipes)。
- **語言。** **Português (Portugal)** 為 {{ui:設定}} › {{ui:一般}} › {{ui:語言}} 中的新增語言。該語言、**Português (Brasil)**、**Español (México)** 與 **Bahasa Indonesia** 現在已具備應用程式的全部文字，但皆為尚未經母語者審閱的草稿。說明主題為英文，另有一則為西班牙文。
- **CadCraft Studio** 會說明更新檢查失敗的原因（系統尚無對應檔案、無網路、簽章錯誤），而非僅顯示「完成」，且在有更新版本之前，不再重新顯示已關閉的「新功能」卡片。

## 此版本尚未提供

- **0.7 未經程式碼簽署。** 簽署與 Microsoft Store 套件已延至 0.8，因為憑證驗證尚未完成。請核對 getcadcraft.com/download 上每個檔案旁的 SHA-256。在 Windows 上，若 SmartScreen 阻擋安裝程式，請選擇 {{ui:詳細資訊}}，然後選擇 {{ui:仍要執行}}。在 Mac 上，首次開啟時請在 CadCraft Studio 上按右鍵並選擇 {{ui:開啟}}。CadCraft Studio 尚未在應用程式商店上架，也尚未提供 iPad 或 iPhone 版本。
- {{ui:單位}} 中的角度與斜率清單已儲存，但目前尚無任何方塊讀取這些清單。
- 來自 STEP、網格與 `.3dm` 檔案的實體沒有歷程，其曲面為平面小面。STEP 不會讀取顏色、零件名稱與組合件樹狀結構；`.3dm` 不會讀取曲線、SubD 物件、文字、圖層與顏色。`.3dm` 讀取器已針對格式本身的工具組所寫出的檔案進行檢查，尚未針對建模程式自行儲存的檔案進行檢查。
- 圖解尚無法於 {{ui:從其他檔案…}} 中開啟 STEP 檔（請先在設計中開啟 STEP，並從 {{ui:從開啟的零件}} 開始），ModelCraft 與 BimCraft 也無法直接將模型交給圖解，且尚未提供路徑追蹤品質的圖片。影片匯出與互動式檔案尚未在實際的手機與平板上測試。
- 雷射程式僅從 DXF 檔取得輪廓：鈑金零件的展開圖需要精確核心。CadCraft Studio 尚不支援 Web Serial，因此請改為儲存 G 代碼，並以雷射本身的程式傳送。雷射 G 代碼與三個內建後處理器尚未在實機上驗證：請先於控制器自身的模擬器中檢查每個程式。
- 3D 精加工僅提供平行與殘脊：不提供 3D 粗加工、等高線、鉛筆或殘料加工，也不提供車削。工具程式庫保存於此瀏覽器中，不會同步。
- 組態器頁面（訪客可在網站上選擇變體並下載）僅供工作人員使用，直到網站的開關開啟為止。PartCraft 不會設定連接埠（連接點）。
- 結構構件僅沿直線延伸，為單一實體，沒有銲道。
- PartCraft 的功能區功能表樣式仍以完整尺寸繪製每個按鈕。
- 磁學：永久磁鐵僅提供二維；馬達、飽和鋼材與曲面零件的網格產生器尚未實作。

其餘項目請見[尚未實作](topic:not-built-yet)。
