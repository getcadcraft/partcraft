PartCraft的分析程式庫可以在二維中計算線圈與鐵芯的磁場：適用於長度方向上截面相同的物體，例如電磁鐵、變壓器鐵芯、匯流排或馬達的截面。本教學會執行程式庫的電磁鐵範例、說明其結果、加以變更，示範如何建立自訂形狀的模型，接著加入永久磁鐵。

本教學使用指令稿工作區與[分析程式庫](topic:craftscript-library)。學習本教學不需要熟悉CraftScript語言；範例會說明每一行的作用。

## 建模內容

一個C形鐵芯，外部尺寸為100 × 80 mm，厚度20 mm，其右側支腳有2 mm的空氣氣隙。一個100匝、通過10 A電流（1000安匝）的線圈，纏繞在其左側支腳上。所有物體沿螢幕向外的方向都很長，因此結果以**每公尺深度**計：若要計算實際磁鐵，請乘以實際深度。

程式庫的`magnetostatic2d`會在磁鐵周圍的空氣方盒中，以1 mm方格的網格求解磁向量勢，再由此計算磁通密度**B**（單位為特斯拉）。

## 執行範例

1. 在工具列左側的**工作區**方塊中選擇**指令稿**。
2. 開啟指令稿面板的**程式庫**索引標籤，然後選擇**範例** › **電磁鐵：磁場、氣隙、電感**。
3. 按一下{{ui:開啟（唯讀）}}，然後按{{key:F5}}。

一兩秒後，畫布會顯示磁通密度，主控台會列印：

```
B in the gap 0.5427 T; magnetic circuit 0.5516 T (-1.6 %: fringing and leakage)
inductance 0.1539 H per metre of depth; the circuit gives 0.1103 H/m, missing the flux that leaks past the gap
stored energy 7.694 J/m; |B| peaks at 1.97 T in the window's inner corners (real steel would saturate there)
pull across the gap about 2343 N per metre of depth (117.2 N for 50 mm deep)
```

畫布下方的圖表顯示沿鐵芯中線由左至右的垂直磁通密度B_y：左側支腳約為−0.55 T（磁通向下流動），窗口內幾乎為零，右側支腳與氣隙處為+0.55 T（磁通向上回流）。同一磁通穿過鐵芯與氣隙，因此兩側支腳與氣隙幾乎顯示相同的數值。

## 讀取結果

- **氣隙磁場**為0.543 T。手算會將鐵芯視為單一磁路，B = μ0 N I / (g + l / μr)，其中g為氣隙、l為穿過鐵芯的路徑長度，μr為鐵的相對磁導率；結果為0.552 T。磁場略低於手算值，是因為磁通在氣隙處向外擴散（邊緣效應），且部分磁通走捷徑穿越窗口（漏磁）。若氣隙較小或網格較細，兩者會更加接近。
- **電感**：100匝線圈的電感為每公尺深度0.154 H，由磁場中儲存的能量求得。磁路公式的結果較小（0.110 H/m），因為它只計入通過氣隙的磁通，未計入漏過氣隙的磁通。
- **吸力**使氣隙閉合，對寬度為w的氣隙面為B² w / (2 μ0)：約為每公尺2300 N，或深度50 mm的磁鐵117 N。
- **峰值**1.97 T位於窗口的內側轉角處，磁通在此急轉。模型將鐵視為線性；實際的矽鋼片在約1.5至2 T時會飽和，因此高於此值的數值應視為警告，而非答案。

:::note
程式庫本身的測試會執行此範例，並在PartCraft每次變更時，將氣隙磁場與磁路公式進行比對。方法、參考資料與其他檢查（長螺線管、鐵芯螺線管）皆記載於`magnetostatic2d`的標頭中：請在程式庫中按一下該項目。
:::

## 變更設計

1. 在唯讀指令稿上方按一下{{ui:建立副本}}。副本會與零件一併儲存。
2. 變更頂端附近的數值，然後再次按{{key:F5}}。可嘗試：
   - `g = 0.001;` — 氣隙減半：氣隙磁場幾乎加倍，吸力也隨之加倍（與B²成正比）。
   - `mur = 200;` — 較差的鐵芯：更多安匝耗在鐵芯中。
   - `N = 200;` — 匝數加倍：磁場加倍，電感為四倍。
   - `h = 0.0005;` — 較細的網格：結果更接近，但耗時約四倍。

每次執行都會取代畫布。指令稿產生的變數（例如`Bgap`、`L`、`F`）會保留在**變數**清單中，供自行計算使用。

## 建立自訂形狀的模型

範例會由三個清單建立所有內容，每個方格各一個值；這些清單可用於任何沿網格以直線繪製的形狀：

- **鐵的位置：**`iron`在鐵芯內部的方格中為true。範例以矩形建立：`frame & ~window & ~gap`表示「在框架內、不在窗口內、不在氣隙內」。
- **磁導率：**`1 + (mur - 1) * iron`在空氣中為1，在鐵中為`mur`。若有多種材料，可以同樣方式各自給予數值。
- **電流：**`J`為電流密度，單位為安培每平方公尺，向螢幕外為正，向螢幕內為負。線圈有兩側，正負號相反；範例會計算`J0`，使其中一側通過N I。

接著以`r = magnetostatic2d(m, permeability, J)`求解。`r.B`為每個方格的磁通密度（兩欄，分別為x與y），`r.Bmag`為其大小，`r.energy`為每公尺儲存的能量。`plot(x, y)`繪製一條線。

程式庫以公尺計算，而視圖以毫米顯示，因此若直接顯示磁場，會被畫得小了一千倍。範例會在毫米單位的網格副本上顯示（`mm = quadGrid(…)`，接著`show(field(mm, …))`）：請複製這兩行。

預設情況下，方盒邊緣會將磁場保持在內部：沒有磁通離開。方盒至少應為磁鐵大小的兩至三倍，以免擠壓磁場。對於對稱的磁鐵，可以只模擬一半：`magnetostatic2d`的標頭說明了在對稱線上應使用的邊界條件。

## 永久磁鐵

第二個範例為**範例** › **鐵芯中的永久磁鐵：工作點、漏磁、吸力**，與前一範例相同的鐵芯，但移除線圈，並以向上充磁的磁鐵取代左側支腳10 mm厚的一段。以{{key:F5}}執行。它會列印：

```
the magnet works at B = 1.036 T, H = -124 kA/m (on its recoil line B = Br + μ0 μr H)
B in the gap 0.6778 T; the magnetic circuit without leakage 0.9692 T (-30.1 %)
leakage factor 1.53: of the flux leaving the magnet, 65 % crosses the gap between the pole faces
pull across the gap about 3656 N per metre of depth (182.8 N for 50 mm deep)
```

- **工作點。**磁鐵由其**剩磁**Br描述（被鐵短路時所保留的磁場：燒結NdFeB磁鐵約為1.2 T，鐵氧體約為0.4 T），以及其回復磁導率（約為1.05與1.1）。打開氣隙會使其沿回復線下移：此處降至1.04 T，磁鐵內部的H與B方向相反。
- **漏磁。**不計漏磁的手算結果，氣隙磁場為0.97 T；模型結果為0.68 T。磁鐵以短距離上的強力推動其磁通，因此大量磁通直接穿過窗口回流，而非經過氣隙。漏磁係數說明了程度：此處為1.53。若要使用閉合的銜鐵，請設定`g = 0;`：此時磁鐵的工作結果與手算值相差不超過0.5%。
- **自訂模型中的磁鐵。**將磁鐵以`struct('Br', Br)`傳給`magnetostatic2d`，其中`Br`每個方格一列，以特斯拉為單位給出x與y方向的剩磁（磁鐵外為零），並在磁導率清單中為磁鐵方格給定其回復磁導率：

  ```
  Brem = [zeros(numel(mag), 1), 1.2 * mag];     % 在 mag 為 true 的方格中，向上 1.2 T
  r = magnetostatic2d(m, 1 + (mur - 1) * iron + 0.05 * mag, 0, struct(), struct('Br', Brem));
  ```

  對於以角度充磁的磁鐵，請將`Br·cos(angle)`與`Br·sin(angle)`放入兩欄；對於向外充磁的環形磁鐵，請依各方格的位置計算其方向。`r.H`給出每個方格的磁場強度H。

無論驅動多強，模型都會使磁鐵保持在其直線回復線上。實際磁鐵若被驅動超過其膝點（例如因氣隙過大、線圈過強或受熱），會永久損失部分強度；請依廠商針對該等級與溫度提供的曲線，核對工作點。

程式庫的測試會以兩項手算結果檢查磁鐵：圓形磁鐵置於空氣中（其內部B = Br / (1 + μr)），以及以鐵銜鐵閉合的磁鐵（磁路），兩者誤差皆在1 %以內。

## 尚未支援的功能

- **飽和。**鐵為線性：電流加倍，磁場即加倍，無上限。
- **消磁。**磁鐵保持在其直線回復線上（見上文）。
- **渦電流**與**損耗**（鐵損、銅損）。
- **動件與力矩。**沒有定子中旋轉的轉子，也沒有隨角度變化的力矩。
- **圓弧形狀。**網格由相等的方格組成，因此曲線輪廓會呈階梯狀。
- **3-D。**所有內容皆為長型物體的截面。

馬達設計（二維中的旋轉轉子、力矩與損耗）正在規劃，預計於後續版本提供。見[尚未實作](topic:not-built-yet)。
