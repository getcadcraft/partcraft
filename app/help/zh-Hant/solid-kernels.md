幾何核心是把你的歷程轉成實體的引擎。此版本的 PartCraft 有一個：**網格核心**（manifold-3d）。它以小型 WebAssembly 程式的形式在你的電腦上執行，應用程式開啟後片刻即可使用。你的零件不會被傳送到任何地方。

| | 網格核心 |
|---|---|
| 圓形 | 小平面。零件面板中的**曲線**決定其精細程度 |
| 體積與面積 | 以面片實體計算，圓形零件會略低 |
| 草圖、拉伸、切除、旋轉、孔、陣列、鏡射、參考平面 | 支援 |
| 圓角與倒角 | 用於平面之間的直邊；相接的圓角以斜接處理 |
| 殼體與拔模 | 殼體可開啟平面（壁厚精確）；拔模可使平面傾斜 |
| 匯出 | STL、3MF、STEP（面片）、圖紙 PDF 與 DXF |
| 圖紙視圖 | 由小平面繪製，包含剖面視圖 |
| 面與邊 | 已命名並依種類辨識（平面、圓柱、圓錐、球、圓環；直線、圓），取自草圖：模擬、衍生式設計與製造工作區、量測、選取與孔表都會用到 |

網格核心在建構你的零件時，狀態列右端附近的標籤會顯示**網格核心**。

## 哪些要等精確核心

精確（B-rep）核心保留真正的圓、圓柱與圓錐，並在任何邊上做出平滑的圓角；掃出、放樣、曲面、鈑金、肋、多個實體、STEP 匯入與精確的 STEP 匯出都建立在其上。PartCraft 較早期的實驗室版本曾為此使用 OpenCascade。它的授權（LGPL）不適用於這個版本，因為這個版本中的每個應用程式都是 Apache-2.0，且只使用採寬鬆授權的程式庫，所以並未納入。這方面沒有任何日期。

在那之前，選擇這些特徵時會顯示**尚未實作**：狀態列會說明原因，其按鈕的提示文字結尾是「尚未實作（需要精確核心）」。[尚未實作的項目](topic:not-built-yet)逐一列出每一項，以及可以改用什麼做法。

用較早版本做出含有這些特徵的零件，仍然可以開啟。這些特徵會留在歷程中並標示為尚未建構（把指標停在上面可看到原因），零件的其餘部分則會建構，儲存時也會原封不動保留它們。

## 圓弧面與曲線

網格核心把圓畫成多邊形。零件面板中的**曲線**決定整圈圓有多少條邊；邊越多，看起來越平滑、量測越接近真值，但建構時間也越長。{{ui:量測}}得到的體積、面積與距離，都是這個面片實體的數值：對孔或凸台而言，會比圓形的略小一些。

## 線上與離線

網格核心是應用程式自身下載內容的一部分。要在沒有網路連線時工作，請在線上時先儲存 PartCraft 供離線使用：選擇應用程式列的{{ui:儲存供離線使用}}，並等到顯示**可離線使用**。詳見[離線工作](common:offline)。
