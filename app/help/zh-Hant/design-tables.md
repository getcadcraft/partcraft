**組態**是零件的一種尺寸：為其參數所設定的一組具名數值。零件會將其組態保存在自己的檔案中，因此組態會隨零件一起移動。**設計表**與 CSV 檔案是同一回事，每個組態一列。

組態會設定**參數**，因此請先新增參數（見 [以參數驅動零件](topic:parameters)）。組態會儲存為純數字的參數；由其他參數計算而得的參數（例如 `area = w * d`）會自動跟隨變動。

## 儲存組態

1. 在 {{ui:參數}} 索引標籤中，設定零件某一尺寸的參數。
2. 在**組態**下方輸入名稱（例如 `Large`），然後按 {{ui:儲存目前數值}} 或 {{key:Enter}}。

新組態會標示為**使用中**。之後若變更參數，它會顯示**使用中，之後已變更**，讓你知道零件已與其不符。

## 切換、更新、重新命名、刪除

- {{ui:套用}} 會將參數設為該組態的數值，並重建零件。
- {{ui:更新}} 會將目前的數值儲存到該組態中。
- 若要重新命名，請在其輸入框中輸入新名稱，然後按 {{key:Enter}}。
- {{ui:刪除}} 會移除該組態。參數會保留其數值。

以上每項操作都是一個步驟：{{key:Mod+Z}} 可以復原。若重新命名參數，所有組態都會跟隨新名稱；若刪除參數，它會從各組態中移除。

## 在組態中開啟與關閉特徵

組態也會保存哪些特徵被關閉，因此同一零件可以有**含有**與**不含**某項特徵的版本：安裝孔、倒角、凸台。

1. 關閉特徵：在歷程中點選該特徵，然後在 {{ui:屬性}} 中按 {{ui:抑制}}。
2. 照常儲存組態，例如 `No holes`。其列會列出它所關閉的項目。
3. 重新開啟特徵（{{ui:取消抑制}}），然後再儲存另一個組態，例如 `With holes`。

只要有任何組態關閉了某項特徵，套用組態時便會在同一步驟中，連同其參數數值，關閉該組態所列的特徵並**開啟所有其他特徵**。在任何組態關閉特徵之前儲存的組態，會被視為「全部開啟」。{{ui:更新}} 會將目前的特徵狀態連同數值一併儲存。

若零件的組態關閉了特徵，該零件會以較新的檔案版本儲存：較舊的 PartCraft 會表示檔案來自較新的版本，而不會在缺少這些特徵的情況下開啟它。

:::note
CSV 設計表只包含參數數值。將表格匯入至組態上會變更其數值，並保留其關閉的特徵；指令列的 `--table` 只會建立數值。
:::

零件檔案會與組態一併儲存，連同目前使用中的組態。零件會以儲存時的數值開啟。

## 匯入或匯出設計表

設計表是一個 CSV 檔案，每個參數一欄，每個組態一列：

```
name,width,thick,bolt
small,100,6,6.6
medium,140,8,8.5
large,200,12,13
```

第一欄可命名為 `name`、`config` 或 `configuration`；其他每一欄都必須是零件參數的名稱。儲存格為數字，若需要可附上單位（`8in`）。空白儲存格表示該列不包含此參數。

- {{ui:匯入 CSV}} 會將每一列新增為一個組態。若某列的名稱與既有組態相同，則會取代該組態。匯入為一個步驟。
- {{ui:匯出 CSV}} 會寫出各組態。若尚無組態，則會寫出一列目前的數值，作為試算表的起點。

若組態名稱會被試算表讀取為公式（以 `=`、`+`、`-` 或 `@` 開頭），則會在前面加上 `'` 再寫出。

## 一次建立所有尺寸

**組態**下方的 {{ui:變體套件…}} 會將所有組態或指定的部分，以 STEP、IFC、DWG 與預覽圖一併打包為一個 zip，並附上其參數表格：見 [由組態製作變體套件](topic:variant-pack)。

指令列工具會為 CSV 設計表的每一列建立一個檔案：

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

請先將組態匯出為 CSV，然後以 `--table` 傳入該檔案。見 [指令稿與指令列](topic:scripts-and-cli)。以指令稿儲存的零件會將其組態保存在 `configs json …` 那一行中。
