每個實體都從草圖開始：在平面上繪製的平面圖形。本導覽說明繪圖工具。若要以限制條件與標註將草圖定義完整，請見[完整定義草圖](topic:relations-dimensions)。

## 開始草圖

可以在基準面或零件的任何平面上繪製草圖。

1. 選取草圖位置：
   - 基準面：在{{ui:歷程}}中按一下**前基準面**、**上基準面**或**右基準面**，或在檢視中按一下該平面；
   - 平面：在檢視中按一下該面，整個面會反白顯示。
2. 在工具列中選擇{{ui:草圖}}，或按{{key:S}}。（已選取面時，也可以在右側面板中選擇{{ui:在此面上繪製草圖}}；已選取基準面時，則選擇{{ui:在其上繪製草圖}}。）

檢視會轉為正對該平面，工具列會顯示草圖工具，並且已啟用{{ui:直線}}工具。若未選取任何項目就按{{ui:草圖}}，會顯示基準面，狀態列會顯示「按一下平面或平面以開始繪製草圖。按Esc停止。」

:::note
曲面無法放置草圖：「該面為曲面。選取平面或基準面以繪製草圖。」
:::

**草圖會跟隨其所在的面。** 若該面由草圖邊線或拉伸的端面產生，特徵變更時新草圖會跟著移動（較深的凹槽會連同其底面上的草圖一起移動）。若面板顯示該面為「固定於選取位置」，草圖則會留在該面目前的位置。

## 繪圖工具

每個工具都有一個工具列按鈕與一個快速鍵。再次選擇同一個按鈕、按{{key:S}}，或按{{key:Esc}}，即可回到選取。

| 工具 | 快速鍵 | 繪製方式 |
|---|---|---|
| {{ui:直線}} | {{key:L}} | 依序按一下起點，再按一下每個後續點。直線會首尾相連。以{{key:Esc}}、{{key:Enter}}、按滑鼠右鍵或連按兩下結束連續直線。按一下既有的點也會結束 |
| {{ui:矩形}} | {{key:R}} | 按一下一個角點，再按一下對角點。會得到四條在角點相接的直線，其中兩條水平、兩條垂直 |
| {{ui:圓}} | {{key:C}} | 按一下圓心，再按一下圓上的一點 |
| {{ui:圓弧}} | {{key:A}} | 依序按一下圓心、起點、終點。圓弧的方向會跟隨滑鼠繞圓心移動的方向 |
| {{ui:點}} | {{key:P}} | 按一下即可。單獨的點可標示{{ui:孔}}的孔中心 |
| {{ui:中心線}} | {{key:N}} | 與直線相同，一次一段。以虛線繪製；屬於輔助幾何，可作為旋轉軸或參考 |
| {{ui:圓角}} | {{key:F}} | 按一下兩條直線相交的角，輸入半徑，再按{{key:Enter}} |
| {{ui:樣條}} | {{key:B}} | 依序按一下曲線經過的點；按{{key:Enter}}結束，按一下第一點則會封閉曲線。參見[樣條、修剪、偏移與其他草圖工具](topic:sketch-tools) |
| {{ui:修剪}} | {{key:T}} | 按一下要移除的曲線段（至最近的交點為止） |
| {{ui:標註}} | {{key:D}} | 參見[完整定義草圖](topic:relations-dimensions) |

繪製時，指標旁會顯示小方塊，列出長度、尺寸、直徑或半徑。

### 繪製時輸入尺寸

在直線、矩形、圓或圓弧的第一次按一下之後，可以改為輸入尺寸，而不必按一下決定。輸入數字會開啟指標旁的方塊，並顯示該數字：

| 工具 | 方塊（按{{key:Tab}}移到下一個） | 按{{key:Enter}}時的結果 |
|---|---|---|
| {{ui:直線}}、{{ui:中心線}} | 長度，然後是角度（°），自草圖 X 軸起算 | 直線會依輸入的長度繪製，朝向指標方向或輸入的角度；連續直線會從其終點繼續 |
| {{ui:矩形}} | 寬度，然後是高度 | 矩形會從第一個角點朝向指標繪製；未輸入的尺寸由指標決定 |
| {{ui:圓}} | 直徑 | 圓會以該直徑繪製 |
| {{ui:圓弧}} | 圓心之後為半徑，起點之後為圓弧角度（°） | 起點與圓心相距該半徑；圓弧再依滑鼠移動的方向繞過該角度 |

每個輸入的尺寸會在同一步驟中成為**驅動標註**，因此草圖會直接帶有尺寸：{{key:Mod+Z}}會同時移除圖形與其標註。若改為按一下而非按{{key:Enter}}，則保留已輸入的數值，其餘部分取自按一下的位置。{{key:Esc}}會關閉方塊並回到指標。

若只想以按一下方式繪製，可在{{ui:設定}} › {{ui:PartCraft}} › **繪製時標註**中關閉此功能。參見[PartCraft 設定](topic:settings)。

草圖工具末端的{{ui:更多}}包含控制點樣條、延伸、偏移、鏡射、多邊形、長槽、草圖陣列與投影邊：參見[樣條、修剪、偏移與其他草圖工具](topic:sketch-tools)。

### 鎖點

鎖點會自動加入限制條件，使草圖在移動時保持相連：

- 在**端點或原點**上會顯示小方塊。新點會與之重合。
- 在**直線、圓或圓弧**上會顯示小十字。新點會放在該曲線上。
- 與水平或垂直方向相差在 3 度以內的直線會鎖定至該方向，並獲得水平或垂直限制條件。標籤會顯示「H」或「V」。

若要避免鎖點，請放大檢視，讓按一下的位置與點或曲線相距更遠。

## 倒圓角

1. 按{{key:F}}或選擇{{ui:圓角}}。
2. 按一下兩條直線相交的角點。
3. 會開啟一個方塊，顯示建議的半徑。輸入半徑後按{{key:Enter}}。

兩條直線會被修剪，並以帶有半徑標註的相切圓弧連接。可能看到的訊息：「圓角需要恰好兩條直線相交的角。」與「此半徑對這些直線而言過大。」

:::tip
草圖圓角會對輪廓的角倒圓，因此拉伸後會得到圓角的垂直邊。若要對實體本身的邊倒圓（例如板件的上緣），請改用零件上的{{ui:圓角}}特徵：參見[倒圓角、倒角與抽殼](topic:fillet-chamfer-shell)。在草圖中，工具列的圓角是草圖工具；在零件上，它是特徵。
:::

## 輔助幾何

輔助直線、輔助圓與輔助圓弧以灰色虛線顯示。它們用來引導草圖，但不屬於拉伸或旋轉所用的輪廓。

1. 選取直線、圓或圓弧。
2. 按{{key:Q}}或選擇{{ui:輔助}}。再按一次可恢復為一般幾何。

## 選取、拖曳與刪除

按{{key:S}}（或按{{key:Esc}}直到沒有啟用任何工具）即可使用選取。

- 按一下點、直線、圓、圓弧、限制條件符號或標註即可選取。{{key:Shift}}+按一下可加入或移出選取。在 Windows 與 Linux 上，{{key:Ctrl}}+按一下作用相同；在 Mac 上則為 ⌘+按一下。
- 拖曳空白處以框選：完全位於框內的所有項目都會被選取。
- 拖曳點或直線即可移動。求解器會在移動時保持所有限制條件與標註，因此只會移動自由的幾何。拖曳圓的邊緣可變更其半徑。
- 拖曳標註的數字即可移動標籤。
- 按{{key:Delete}}或{{key:Backspace}}，或在右側面板中選擇{{ui:刪除}}，即可刪除選取的項目。刪除幾何會一併刪除其上的限制條件。

## 草圖中的縮放與平移

- 轉動滾輪可在指標位置縮放。
- 以中鍵或右鍵拖曳即可平移。
- 工具列或右側面板中的{{ui:符合視窗}}會讓草圖符合視窗。在草圖中，{{key:F}}鍵是圓角工具，而不是符合視窗。

## 結束草圖

在工具列中選擇{{ui:結束}}，或在右側面板中選擇{{ui:結束草圖}}，或按{{key:Esc}}直到草圖關閉。每按一次{{key:Esc}}，會先取消進行中的操作，接著回到選取，再清除選取；下一次則會關閉草圖。

草圖保持選取狀態，因此下一次的{{ui:拉伸}}或{{ui:旋轉}}會使用它。

## 好的輪廓須具備的條件

{{ui:拉伸}}與{{ui:旋轉}}會使用草圖中所有實線（非輔助）的直線、圓、圓弧與樣條所形成的**每個封閉迴圈**。迴圈內的迴圈會成為孔。

- 每個端點必須恰好與另一個端點相接。「輪廓未封閉：(12.5, 40) 處的端點未與任何物件相接。」會指出位置。
- 不得有三個端點相交於同一點：「輪廓在 (0, 20) 處分岔：有兩個以上的端點在此相交。」
- 點與輔助幾何會被輪廓忽略。

## 由照片建立草圖

**特徵 › {{ui:更多}} › 由照片建立草圖…**（或特徵樹功能區中的草圖群組）會將放在單色背景上的平面零件照片（其外框與孔）或筆繪圖，描成由直線、圓弧與圓組成的草圖。請指定一個長度（寬度、高度或最長邊），使草圖具有正確的尺寸；在預覽中檢查其找到的內容，然後選擇**建立草圖**。也可以在同一個復原步驟中一併拉伸。處理全部在此電腦上進行。圓角半徑的誤差約在 5% 以內，一兩個像素的細節會遺失；若照片是斜拍或零件上有陰影，則不會被校正：應正對零件拍攝，並使用均勻的光線。
