PartCraft 可與 SolidWorks 雙向交換零件，無需使用其他人無法讀取的檔案格式：

- **匯出：**一個巨集（`.swb`，純文字），由 SolidWorks 執行後逐一特徵建立零件本身，包括草圖、限制條件、標註、全域變數與方程式。取得的是具有即時特徵樹的原生零件，而不是靜態實體。
- **匯回：**在 SolidWorks 中執行的巨集，會將零件的特徵與方程式寫入 `.cadcraft-sw.json` 檔案。在 PartCraft 中開啟該檔案的功能，本版本尚未實作（需要精確核心）。

:::warning
以上功能尚未在 SolidWorks 中測試。SolidWorks 僅能在具授權的 Windows 上執行，而 PartCraft 從未在其中執行過這些巨集。這些巨集是依據 SolidWorks API 文件撰寫，並於此處檢查結構。可能會遇到問題；巨集寫出的記錄會指出失敗的步驟。
:::

PartCraft 無法寫入 `.sldprt` 檔案，因為該格式為封閉格式。取得原生零件的方法是使用巨集。

## 以巨集傳送零件

1. 開啟零件。
2. 選擇{{ui:匯出}}，然後選擇{{ui:給 SolidWorks 的巨集（.swb）}}。PartCraft 會下載 `<part>.swb`；狀態列會顯示「未使用精確核心寫入」。
3. 對話方塊會顯示巨集將建立多少特徵、全域變數與方程式，並列出未納入的項目。本版本不會同時產生 STEP；若需要，請使用{{ui:匯出}}，然後選擇{{ui:STEP（面片，網格核心）}}。
4. 在 SolidWorks 中選擇 **Tools > Macro > Run**，選取 `.swb` 檔案並等待。它會以預設零件範本建立新零件、設定為毫米，並建立每個特徵。
5. 完成時，訊息會顯示已完成的步驟數、失敗數，以及與 PartCraft 實體相符的數量。完整記錄 `<part> macro log.txt` 會寫在巨集旁邊。

巨集會建立的內容：

| PartCraft | 新零件中的內容 |
|---|---|
| 位於前、上或右基準面的草圖 | 位於該平面上的草圖，包含直線、圓弧、圓、點、限制條件與標註（與 PartCraft 同名，例如 `k7`） |
| 位於面上的草圖 | 位於同一個面上的草圖，依其上的一點選定 |
| 位於固定平面上的草圖 | 通過三點的參考平面，以及位於其上的草圖 |
| 拉伸、切除（盲孔、貫穿、中面、雙向、錐度） | 凸台拉伸或切除拉伸 |
| 旋轉、旋轉切除 | 繞相同中心線旋轉 |
| 孔（簡單孔、沉頭孔、錐形沉頭孔、攻牙孔） | 一或兩個切除，各自帶有草圖（攻牙孔以其底孔鑽頭表示，不含螺紋） |
| 線性與圓形陣列、鏡射 | 線性陣列、圓形陣列、鏡射（特徵或實體） |
| 圓角、倒角、抽殼 | 在相同的邊與面上建立圓角、倒角與抽殼，依點選定 |
| 參數與方程式 | 在更名後的標註上建立全域變數與方程式 |
| 壓縮的特徵、回溯列 | 以相同方式壓縮；回溯列位於相同位置 |

每個實體特徵建立後，巨集會比較實體的體積與尺寸和 PartCraft 的結果。若不一致，它會將該特徵的方向反轉一次並重新檢查；若結果沒有改善，則會將方向轉回並在記錄中寫入「Check」。

### 未納入的內容

對話方塊與巨集開頭會列出所有未被帶入的內容及原因。目前包括：匯入的實體（請改為插入 STEP）、掃出、放樣、拔模、參考軸與參考點、「直到」結束條件、僅拉伸部分輪廓，以及依賴這些內容的項目。樣條會轉為通過其各點的曲線。本版本沒有精確核心，因此位於面上的草圖，以及依邊或面選取的特徵，也一併被排除。

## 傳送具名 STEP

本版本尚未實作：{{ui:給 SolidWorks 的 STEP（具名，AP214）}}需要精確核心，選擇時會顯示「給 SolidWorks 的 STEP：尚未實作。…」。具備精確核心時，檔案會包含零件名稱、毫米單位與零件顏色，並將 Y 軸朝上，與 SolidWorks 顯示零件的方式相同（一般的{{ui:STEP AP214（精確實體）}}匯出則是 Z 軸朝上）。名稱中帶有重音的字母會去除重音，ASCII 以外的其他字元會變成 `_`。

## 匯回零件

在 PartCraft 中開啟該檔案（步驟 3）本版本尚未實作：會顯示「開啟 SolidWorks 匯出檔：尚未實作。…」。CadCraft 製圖應用程式仍可開啟該檔案並取得其草圖。

1. 選擇{{ui:檔案}} > {{ui:匯出}} > {{ui:匯出巨集以帶回零件（.swb）}}，下載 `CadCraftExport.swb`，並將其放在零件旁邊。
2. 在 SolidWorks 中開啟零件，選擇 **Tools > Macro > Run**，然後選取 `CadCraftExport.swb`。它會在零件旁寫入 `<part>.cadcraft-sw.json`，且不會修改零件本身。
3. 在 PartCraft 中選擇{{ui:開啟}}並選取該檔案，或將其拖放到 3D 檢視中。
4. 具備精確核心時，PartCraft 會逐一特徵重建零件，並顯示其執行結果，例如：「已從 SolidWorks 帶入 5 個特徵（共 5 個）（Flange.SLDPRT）」、無法帶入的每個特徵（「未帶入：Sweep1 (Sweep)。」），以及體積是否與 SolidWorks 寫出的體積相符。
5. 使用{{ui:儲存}}將其儲存為 PartCraft 零件。

草圖若位於基準面上，即放在該基準面上；若零件上有對應的平面，則放在該平面上（因此會跟隨之後的編輯）；否則放在固定平面上。圓角、倒角與抽殼的邊和面會依點找到，並保留為具名參照。全域變數會成為參數（含空格的名稱會以底線取代：「Bolt count」變為 `Bolt_count`），方程式則會成為作用於相同標註的方程式。不作任何猜測：沒有對應項目的內容會列出。

CadCraft 製圖應用程式可開啟同一檔案並取得其草圖。

:::note
格式為 `cadcraft-sw-export` 版本 1，為純 JSON，單位為毫米與度。來自較新巨集的檔案，或無效的檔案，會被拒絕並說明原因。
:::
