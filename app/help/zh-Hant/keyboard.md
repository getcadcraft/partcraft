在面板的方塊中輸入文字時，快速鍵不會作用，但{{key:Mod+S}}與{{key:Mod+O}}例外，隨時都可使用。字母鍵不需搭配修飾鍵即可使用。

關於瀏覽器中的按鍵，以及沒有功能鍵的鍵盤的一般說明，請見[按鍵、滑鼠與觸控板](common:keys)。

## 通用

| 按鍵 | 動作 |
|---|---|
| {{key:Mod+S}} | 儲存零件（在組合件中則儲存組合件）。會先關閉開啟中的草圖 |
| {{key:Mod+O}} | 開啟零件或組合件檔案（若有尚未儲存的變更，會先詢問） |
| {{key:Mod+Z}} | 復原 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 取消復原 |
| {{key:F1}} | 開啟或關閉此說明（也可使用應用程式列上的{{ui:說明}}）。{{key:Esc}}也可關閉。許多筆電與Mac鍵盤需按住Fn |
| {{key:Ctrl+Shift+F}} | 螢幕模式：一般、全螢幕、隱藏工具列的全螢幕。Mac上也是Control鍵，不是⌘ |
| {{key:Esc}} | 離開全螢幕（在全螢幕時） |
| {{key:Mod+,}} | 設定，包括PartCraft索引標籤（見[PartCraft設定](topic:settings)） |

在面板的數字方塊中，{{key:Mod+Z}}是瀏覽器本身的文字復原。在草圖標註上的數字方塊中，則由PartCraft復原。

## 複製、貼上與建立副本

這些操作作用於目前編輯的內容：開啟中草圖裡所選的幾何、歷程清單中所選的特徵，或組合件中所選的零件。詳細說明見[複製、貼上與建立副本](topic:copy-paste)。

| 按鍵 | 動作 |
|---|---|
| {{key:Mod+C}} | 複製所選取的內容 |
| {{key:Mod+X}} | 剪下：先複製，再刪除 |
| {{key:Mod+V}} | 貼上。在草圖中，副本會跟著指標移動：按一下要放置的位置 |
| {{key:Mod+Shift+V}} | 原位貼上：使用相同座標（在組合件中為相同位置） |
| {{key:Mod+D}} | 建立副本：一次完成複製與貼上，不改動剪貼簿 |
| {{key:Mod+A}} | 全選（在草圖中） |
| {{key:Esc}} | 取消選取（並取消跟隨指標的貼上） |

在數字方塊中，這些按鍵照常複製與貼上文字。面板中所選的文字由瀏覽器複製。

## 在零件上（未開啟草圖）

| 按鍵 | 動作 |
|---|---|
| {{key:S}} | 在所選的基準面或平面上建立草圖；未選取任何項目時，按一下以選擇位置 |
| {{key:F}} | 將零件符合視窗 |
| {{key:M}} | 量測，適用於所有工作區及組合件；{{key:Esc}}清除選取，再按一次{{key:Esc}}則關閉量測（見[量測距離、角度與質量](topic:measure)） |
| {{key:X}} | 剖面檢視開啟或關閉，適用於所有工作區及組合件；{{key:Esc}}可關閉（見[以剖面檢視查看內部](topic:section-view)） |
| {{key:Delete}} | 刪除所選特徵（若其他特徵使用它，會先詢問） |
| {{key:0}} … {{key:9}}、{{key:.}} | 選取特徵時：輸入其主要數值（拉伸的深度、孔的直徑、陣列的數量、圓角的半徑……），再按{{key:Enter}}。{{key:Esc}}保留原值 |
| {{key:Backspace}} | 刪除所選特徵（有選取特徵時） |
| {{key:Esc}} | 停止選擇草圖基準面，或清除選取（包括以{{key:Shift}}選取的邊或面） |

## 在3D視圖中

先在視圖中按一下，讓視圖取得鍵盤焦點。

| 按鍵 | 動作 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 以15度轉動視角 |
| {{key:Shift+Left}}及其他方向鍵 | 平移 |
| {{key:Plus}}或{{key:=}} | 放大 |
| {{key:Minus}} | 縮小 |

| 滑鼠 | 動作 |
|---|---|
| 以左鍵拖曳 | 轉動（環繞）視角 |
| 以右鍵或中鍵拖曳 | 平移 |
| 按住{{key:Shift}}、{{key:Ctrl}}或⌘並以左鍵拖曳 | 平移 |
| 滾動滾輪 | 以指標位置為中心縮放（朝遠離操作者的方向滾動為放大） |
| 觸控板雙指滑動 | 轉動視角；搭配{{key:Shift}}時平移。捏合縮放。由[PartCraft設定](topic:settings)中的**捲動**設定 |

在[PartCraft設定](topic:settings)中啟用**以中鍵轉動視角**後，中鍵會轉動視角，{{key:Shift}}配合中鍵或右鍵平移，左鍵只用來選取。
| 按一下 | 選取一個面（整個面會一起反白）、一條邊或一個基準面 |
| {{key:Shift}}+按一下邊或面 | 收集多條邊或多個面 |
| 按一下空白處 | 清除選取 |

## 選取邊或面以建立圓角、倒角或抽殼時


| 按鍵或滑鼠 | 動作 |
|---|---|
| 按一下邊或面 | 加入該邊或面；若已在選取中則移除 |
| {{key:Esc}}或{{key:Enter}} | 完成選取（與{{ui:完成}}相同） |
| {{key:F}} | 符合視窗 |
| 方向鍵（視圖有焦點時） | 轉動；搭配{{key:Shift}}時平移 |

## 在圖紙上

| 按鍵 | 動作 |
|---|---|
| {{key:F}} | 將圖紙符合視窗 |
| {{key:Plus}} / {{key:Minus}} | 縮放（圖紙有焦點時） |
| {{key:Shift+Left}}及其他方向鍵 | 平移（圖紙有焦點時） |
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 將所選的幾何公差（GD&T）符號微調1 mm |
| {{key:Delete}}或{{key:Backspace}} | 刪除所選符號 |
| {{key:Esc}} | 停止放置符號；否則取消選取；再否則回到模型 |

| 滑鼠 | 動作 |
|---|---|
| 已選擇基準、框架、表面處理或詳圖時，在視圖上按一下 | 放置於該處（自動貼齊最近的線） |
| 按一下符號 | 選取該符號 |
| 拖曳符號 | 移動符號（引線仍指向原點） |
| 滾動滾輪 | 以指標位置為中心縮放 |
| 以右鍵或中鍵拖曳 | 平移 |

## 在草圖中

| 按鍵 | 動作 |
|---|---|
| {{key:L}} | 直線 |
| {{key:R}} | 矩形 |
| {{key:C}} | 圓 |
| {{key:A}} | 圓弧（圓心、起點、終點） |
| {{key:P}} | 點 |
| {{key:N}} | 中心線 |
| {{key:F}} | 轉角圓角 |
| {{key:D}} | 標註 |
| {{key:B}} | 雲形線（通過點） |
| {{key:T}} | 修剪 |
| {{key:E}} | 延伸 |
| {{key:O}} | 偏移（偏移時按{{key:B}}：兩側同時偏移） |
| {{key:M}} | 鏡像 |
| {{key:S}} | 選取 |
| {{key:Q}} | 將所選曲線切換為參考線，再按一次切換回來 |
| {{key:Enter}} | 結束連續線段或雲形線 |
| {{key:Delete}}或{{key:Backspace}} | 刪除所選內容 |
| {{key:Mod+A}} | 選取草圖中的所有內容 |
| {{key:Mod+C}} / {{key:Mod+X}} / {{key:Mod+V}} | 複製、剪下、貼上幾何（貼上會跟隨指標） |

| 滑鼠 | 動作 |
|---|---|
| 按一下 | 使用繪圖工具時放置點；使用選取工具時選取 |
| {{key:Shift}}+按一下 | 加入或移出選取（在Windows與Linux上以{{key:Ctrl}}+按一下，在Mac上以⌘+按一下，效果相同） |
| 在空白處拖曳（選取工具） | 視窗選取：選取完全位於框內的所有內容 |
| 拖曳點、線或圓的邊（選取工具） | 移動它；幾何關係維持不變 |
| 拖曳標註的數字（選取工具） | 移動標註文字 |
| 雙擊標註 | 變更其數值 |
| 繪製直線時雙擊或右鍵按一下 | 結束連續線段 |
| 以右鍵或中鍵拖曳 | 平移 |
| 滾動滾輪 | 以指標位置為中心縮放 |

### 在數字方塊中

|---|---|

|---|---|

| {{key:Enter}}或{{key:Space}} | 選取該列 |

## 在組合件中

| 按鍵 | 動作 |
|---|---|
| {{key:J}} | 開始建立接頭：然後在兩個零件各按一下一個平面 |
| {{key:F}} | 符合視窗 |
| {{key:Esc}} | 取消已開始的接頭，或清除選取 |
| {{key:Delete}} | 移除所選零件或接頭 |
| {{key:Backspace}} | 移除所選零件或接頭 |
| {{key:Mod+Z}} / {{key:Mod+Y}} | 在組合件自己的清單中復原與取消復原 |
| {{key:Mod+D}} | 建立所選零件的副本（同一零件，放在其他零件旁） |
| {{key:Mod+C}}，然後{{key:Mod+V}}或{{key:Mod+Shift+V}} | 複製零件，然後貼在其他零件旁或同一位置 |

視圖中的滑鼠操作與上方的3D視圖相同。按一下零件即可選取。在清單中雙擊零件即可編輯。

| 按鍵 | 動作 |
|---|---|
| {{key:F5}} | 執行指令稿（在編輯器、面板或視圖中皆可） |
| {{key:Mod+Enter}} | 執行所選的行，或游標所在的行 |

## 瀏覽器可能會接管的快速鍵

- 在Safari中，{{key:Mod+Y}}可能會開啟瀏覽記錄：請使用{{key:Mod+Shift+Z}}取消復原。
- {{key:Mod+D}}是瀏覽器的加入書籤快速鍵：應用程式有焦點時由PartCraft接管，在方塊中輸入時則不作處理。
- {{key:F11}}與{{key:Mod+Plus}} / {{key:Mod+Minus}}是瀏覽器的全螢幕與網頁縮放，不是PartCraft的功能。全螢幕請使用{{key:Ctrl+Shift+F}}，模型縮放請使用滾輪。
- 許多筆電與Mac的功能鍵需要Fn鍵：按Fn+{{key:F1}}開啟說明，或使用{{ui:說明}}按鈕。

觸控與觸控板手勢：[觸控板、觸控與小螢幕](topic:trackpad-and-touch)。

## 「移動」的位置

「移動」位於特徵群組的{{ui:更多}}功能表中，名稱為{{ui:移動實體}}；位於{{ui:移動}}方塊中（在其中輸入ΔX、ΔY與ΔZ）；也以{{ui:拖曳以移動}}箭頭的形式出現在零件上。
