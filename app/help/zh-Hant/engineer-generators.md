**產生器**是一段腳本，依你的需求決定零件尺寸並將其建構出來。熱交換器產生器會接收要傳遞的熱量、兩股流體及其溫度、壓力與材料；它會算出核心需要多大、壁厚多少，建構出來，並告訴你所用的數值及其來源。修改輸入，零件會隨之變化。

產生的結果是零件中的一般實體：它會列在特徵清單中，可以列印，也可以匯出。產生器本身也保存在零件中，因此檔案可以在未安裝該產生器的任何電腦上開啟，而**開啟零件時從不會執行腳本**。

## 建立實體

1. 在切換器中選擇 {{ui:Engineer}} 工作區。
2. 在清單中選擇產生器（PartCraft隨附的，然後是你從檔案開啟的任何產生器），並按一下 {{ui:New}}。
3. 腳本會執行。完成後，實體會出現在視圖中，面板會顯示其輸入、其**資料表**與其**檢查**。

你也可以從設計工作區新增：{{ui:Features}} › {{ui:More}} › {{ui:Generated body}}。

## 變更

修改任何輸入，停止輸入後片刻，實體便會重新產生。面板會說明下列三種狀況中哪一種為真：

- **Up to date**：實體與腳本及其輸入相符。
- **The inputs changed**：零件中的實體來自先前的輸入；它正在重新產生，或按 {{ui:Run}}。
- **Not run yet** 或 **The last run failed**：會顯示腳本錯誤及其所在行。

{{ui:Stop}} 會結束執行時間過長的作業。復原會逐步回退：一次執行為一步，一項輸入也是一步。

## 資料表

產生器算出的每個數值，都會列出其**單位**與**來源**（教科書公式、標準、資料表）。沒有任何隱藏常數。資料表是檔案的一部分，因此在下一台電腦上也相同。[匯出資料](topic:data-out)說明如何將其儲存為JSON或PDF。

## 檢查

產生器可依列印製程檢查自身的零件：壁與間隙比製程所能容納的更薄、鬆散的零件、會留住粉末或樹脂的空腔、太窄以致無法清除的孔，以及需要支撐的懸垂。檢查結果會顯示在面板中及 {{ui:Problems}} 清單（⚠ 按鈕）中，並與零件一併保存。

製程數值是公開設計指南對該製程的一般性概數（FDM、SLA、SLS、金屬粉床）。它們**不是你的機器規格**：在依賴檢查結果之前，請以你工廠的數值取代。檢查是以體素網格進行，因此精確度約為一個體素：只有當壁厚比限制薄超過一個體素時，才會被回報。

## 隨附的產生器

| 產生器 | 產生的內容 |
|---|---|
| Gyroid 塊 | 以gyroid、Schwarz P或diamond薄片填滿的塊體：最簡單的晶格 |
| Gyroid 熱交換器 | 雙流體交換器的核心，依熱負荷以效能-NTU法決定尺寸，其壁厚依壓力決定；可用單一晶胞的流動研究檢查壓降 |
| 分配歧管 | 集管與支管，每根管依其所載流量決定尺寸 |
| 漸變晶格樑 | 一種晶格，其壁在拓撲最佳化認定需要材料處變厚 |

這些全部都是以教科書公式為基礎的初步估算。[工程程式庫](topic:engineering-library)列出公式及其限制。在依賴結果之前，請對其執行模擬、熱分析或流動分析。

## 出口管制

工程的產生器與資料表附有出口管制與制裁的聲明。請見[工程與出口管制](topic:engineer-export-notice)閱讀；它也位於每份資料表的末尾。
