指令稿工作區中的分析，是數個彼此傳遞變數的簡短指令稿。先從與你需求接近的[程式庫](topic:craftscript-library)函式出發，建立副本後加以修改；或如下方所示逐步建立。

## 1. 網格

```
model = part();                  % 你正在建模的零件，以模型形式表示
m = tetmesh(model, 4);           % 約 4 mm 大小的四面體
show(m)
```

繼續之前，請先在檢視區中檢查網格：{{key:F}} 會使其符合視窗，**顯示項目**中的 {{ui:眼睛}} 會隱藏零件。

## 2. 組裝與求解

在指令稿中撰寫單元迴圈（它讀起來就像教科書），並將繁重的部分交給內建函式：單元矩陣、由三元組進行的稀疏組裝，以及附前置處理器的共軛梯度求解器。程式庫中的函式（例如 `static_tet`，待程式庫提供後）是可以參考複製的完整範例。

## 3. 顯示結果

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % 每個節點一個值
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', '求解器殘差', 'id', 'conv')
```

- 圖例的範圍可以輸入，或恢復為 {{ui:自動}}。
- 點選網格即可讀取節點上的值。
- 具有相同 `'id'` 的圖表會原地更新，因此請在迴圈中列印並繪圖，以觀察其收斂情況。

## 4. 檢查

與已知結果比較：懸臂的末端撓度與 PL³/3EI、有孔平板與其應力集中係數、反力與載重。請將檢查寫成獨立指令稿，以便每次變更後重新執行：

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('末端 %g mm，樑理論 %g mm（%.1f %%）\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. 保存

- 每個步驟都可以是自己的指令稿標籤：它們共用變數，因此請依序執行。
- 指令稿會儲存在零件中。在 **變數** 索引標籤上勾選 **隨零件儲存變數**，即可連同結果一起保存（最多 32 MB）。
- 指令稿群組中的 {{ui:儲存}} 會下載指令稿以供分享；{{ui:開啟}} 則會載入指令稿。
