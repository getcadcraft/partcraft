參考幾何是建立特徵時所依附的支架：在沒有面的地方需要的**平面**供繪製草圖，供旋轉或陣列所用的**軸**，以及用來讓拉伸停止的**點**。它本身沒有材料。平面在視圖中以淺色方塊顯示，軸以虛線顯示，點以小十字顯示；三者都會加入歷程，並在你於上游變更尺寸時隨其來源一起更新。

它們位於「特徵」群組的 {{ui:更多}} 功能表中：{{ui:平面}}、{{ui:軸}}、{{ui:點}}。

## 建立平面

1. 按一下平坦面，或在歷程中按一下基準平面，以其作為起點（選用）。
2. 選擇 {{ui:更多}}，然後選擇 {{ui:平面}}。它一開始會是與你所選項目（或上方平面）相距零件尺寸 20 % 的偏移平面。
3. 在右側面板中選擇 **類型** 及其參照：

| 類型 | 參照 | 數字 |
|---|---|---|
| 與平面或面偏移 | **起始平面** | **距離(mm)**，負值表示另一側 |
| 成角度，通過邊或軸 | **起始平面**，**旋轉軸**（世界軸、軸特徵或所選的直線邊） | **角度(°)** |
| 通過三點 | **點 1**、**點 2**、**點 3** | — |
| 兩者之間的中間平面 | **第一平面**、**第二平面**（平行時取中間；相交時取平分夾角的平面） | — |
| 與圓柱相切 | **圓柱**（圓柱面）、**近點**（決定哪一側） | — |
| 垂直於邊，通過一點 | **邊**、**在點**（平面會通過邊上最接近該點的位置，也會通過該點） | — |
| 通過邊與點 | **直線邊**（或軸）、**通過點** | — |
| 在邊的中點處垂直於邊 | **邊**（沿其長度的中點，垂直於該邊），或不選邊時使用 **點 1** 與 **點 2**（兩點之間的中間平面） | — |

每個參照都有 **選取** 按鈕：選擇它，然後在視圖中按一下。平面欄位可接受基準平面、參考平面或平坦面；點欄位可接受邊的端點（在該端點附近按一下）、點特徵，或面上的某個位置；邊欄位可接受邊。{{key:Esc}} 可取消選取。**反轉法線**會將平面翻面（即其上草圖所朝的方向）。

在此版本中，需要邊或圓柱面的欄位（與圓柱相切，以及邊欄位）會回應「尚未實作」：改用點或軸即可。

## 在平面上繪製草圖

選取平面（在歷程中選取，或在視圖中按一下其方塊），然後選擇 {{ui:草圖}}，或其面板中的 **在其上繪製草圖**。草圖會跟隨平面：變更平面的距離時，草圖及其上的每個特徵也會一併移動。

## 軸與點

- {{ui:軸}}：通過兩點、圓柱或圓錐的軸、兩個平面相交處、沿直線邊（或圓形邊的軸），或垂直於面並通過一點。
- {{ui:點}}：位於座標處、頂點或草圖點，或圓形邊的圓心，另外還有「物件之間」的點：

| 點類型 | 參照 |
|---|---|
| 邊的中點（或兩點之間） | **邊**（沿其長度的中點，圓弧與曲線亦同），或不選邊時使用 **點 1** 與 **點 2** |
| 邊或軸與面或平面相交處 | **邊**（直線或曲線）或軸，以及 **與平面相交**（平面或平坦面）或 **或某個面**（平坦面或圓柱）。圓與平面相交兩次，直線穿過圓柱也會相交兩次：**另一交點** 取第二個 |
| 三個平面相交處 | **第一**、**第二**與**第三平面**（平面或平坦面） |

當參照不相容時，每一項都會以簡短訊息失敗：直線與平面平行、直線未穿過圓柱、邊未延伸到平面、三個平面未相交於一點，或用來固定平面的點位於該直線上。

在其他特徵中使用它們：

| 位置 | 方式 |
|---|---|
| 旋轉 | **軸**：從清單中選取軸特徵（它必須位於草圖所在的平面內） |
| 圓周陣列 | **軸**：軸特徵 |
| 線性陣列 | **方向**：軸特徵，或平面（其法線） |
| 鏡射 | **鏡射平面**：參考平面 |
| 拉伸 | **終止**：至面或平面、至頂點（點特徵）。在此版本中尚未實作（需要精確核心） |
| 拔模 | **中性平面** |

## 參照消失時

由已不存在的面建立的平面，會以指出該面的訊息失敗，例如「其所在的面已從 Extrude1 中消失。」它絕不會移到其他面。其上的草圖與特徵會標示為「未建置」，直到你選取新的參照為止；零件的其餘部分維持原狀。

:::note
此版本以網格核心建置所有零件，可從基準平面、拉伸或旋轉所產生的平坦面、草圖點、座標及其他參考幾何特徵建立平面、軸與點。任何需要邊、邊的端點或曲面的項目，都需要精確核心：此版本尚未實作（「此特徵使用實體的面或邊，只有精確核心能找到：此版本尚未實作。」）。
:::
