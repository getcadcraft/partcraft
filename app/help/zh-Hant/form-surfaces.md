**造型**工作區用來製作有機形狀。你編輯的是**控制網格**，即由角點、邊與面組成的粗略網格。形狀是控制網格所控制的平滑曲面（其 Catmull–Clark 極限曲面），因此移動一個角點，會使曲面在其附近平緩彎曲。形狀滿意後，按**表面處理**會將它以*造型*特徵加入零件歷程，精確核心再將其轉為真正的 B 雲形曲面。之後你可以對它做圓角、切除、與其他特徵接合，並匯出為 STEP。

在工具列左側的**工作區**清單中選擇**造型**。

## 建立控制網格

1. 在右側面板中設定**尺寸**與**分割數**。分割數是每一側的面數。
2. 在工具列中按 {{ui:Box}}、{{ui:Quadball}} 或 {{ui:Plane}}。面板還有**圓柱**、**環面**與**點選建立面**。

- **四邊球**是一個方形控制網格，經調整使其角點位於球面上。在這些點之間，曲面會略位於球面內側：分割數為 2 時，體積約少 0.4 %。
- **平面**是開放的，因此會成為曲面本體（見下方「設計中的曲面特徵」）。
- **點選建立面**：在頂部（地面）平面上或控制網格的角點上點選 4 個點，即可建立一個面。共用角點的面會相互接合。點選 3 個點後按 {{key:Enter}} 可建立三角形，或按 {{key:Esc}} 停止。

未完成的控制網格會隨零件檔案一併儲存，因此你可以關閉檔案，稍後再繼續。

## 選取與移動

- 點選控制網格的角點、邊或面。{{key:Shift}}+點選可加入或移除項目。{{key:Esc}} 清除選取。
- 選取範圍的中央會出現操作器。拖曳箭頭可沿該方向移動，拖曳方塊則可在該平面內移動。按 {{key:W}} 移動、{{key:E}} 旋轉、{{key:R}} 縮放，或使用面板中的按鈕。工具列中的 {{ui:Gizmo}} 可依序切換這些模式。
- **柔性衰減**（mm）也會拉動該距離內的角點，並在該距離的邊緣平滑地衰減至零。
- 每次拖曳都是一個復原步驟：{{key:Ctrl+Z}} 與 {{key:Ctrl+Y}} 的作用與一般相同。

## 變更控制網格

面板中的**修改**按鈕會作用於選取項目：

| 按鈕 | 功能 |
|---|---|
| {{ui:Extrude}} | 所選面會沿其法線方向，依**拉伸距離**向外移動，並產生新的側面。所選的開放邊會向外長出新面。 |
| {{ui:Edge loop}} / 插入邊迴圈 | 在所選邊所穿過的四邊形面環中，於中途將其分割。迴圈越多，曲線越緊密。 |
| 插入點 | 在所選邊的中點新增一個角點。 |
| 細分 | 將每個所選面以其中心分割為四邊形面。 |
| 橋接 | 以一段面的管狀結構接合兩個所選面，或兩個開口（每個開口各選一條開放邊）。兩者都需要相同的邊數。 |
| 填補孔洞 | 以一個面封閉所選開放邊所對應的開口。 |
| 焊合 | 將所選角點合併為一個，位於其中央。 |
| 壓平 | 將所選角點移至與其最吻合的平面上。 |
| 刪除 | 移除所選的面、邊（兩個面會合併）或角點。 |

## 銳利邊、對稱與顯示

- {{ui:Crease}} 會使所選的邊變得銳利。**折痕權重** 10 為完全銳利。權重較小時，會在相應的細化步數中保持銳利，之後逐漸軟化，因此得到的是緊密的圓角，而非硬折。**取消折痕**會使其恢復平滑。**銳利頂點**會固定一個角點，使曲面以一個點通過該處。
- **對稱**會將控制網格以 X、Y 或 Z = 0 為鏡射。它保留正向的一側，將其鏡射，並接合兩半。之後，對任一側的編輯都會同時套用到兩側。位於鏡射平面上的角點會留在該平面上。
- {{ui:Display}} 可在**平滑**（特徵將成為的曲面）與**方塊**（控制網格本身的面）之間切換。
- **分析**：**斑馬紋**會將條紋光線依目前視圖反射。它們在平滑曲面上平順彎曲，並在折痕處中斷。**平均曲率**會以紅色著色凸面區域、藍色著色凹面區域、白色著色平坦區域。它以餘切公式在顯示的網格上量測，因此僅供參考，並非精確量測。

## 檢查與完成

- **精確檢查**會在精確核心中轉換控制網格，但不改變你的零件。它會回報控制網格產生多少個 B 雲形曲面片、其中有多少為精確，以及結果是否為封閉且有效的實體及其體積。
- {{ui:Finish}} 會將一個*造型*特徵加入歷程，或更新你正在編輯的造型，並帶你回到設計。封閉的控制網格會成為實體。其在設計面板中的**運算**可為新增實體、接合、切除或相交。開放的控制網格則會成為曲面本體。
- 稍後要變更造型時，請在歷程中選取它，然後按**在造型中編輯**。編輯控制網格時，已建構的本體會被隱藏。
- **捨棄**會丟棄控制網格，且不影響歷程。

## 何者為精確，何者為近似

控制網格的每個四邊形面，在需要時細化後，會成為一個雙三次 B 雲形曲面片。

- 當面的每個角點都是*規則*的（曲面內有四條邊相交，或在開放邊或沿折痕處有三條邊相交）時，曲面片**精確**等於細分曲面。測試以 1e-9 mm 的精度檢查此點。
- 在**非正則點**（三條、五條或更多邊相交，三邊或五邊面的角點，或折痕的端點）周圍，不存在精確的多項式曲面片。在該處，曲面片採用該角點的精確點與切平面，以及鄰邊的邊曲線，因此各曲面片仍然相接而無縫隙。在該點相交的各邊之間的切線連續性為近似。造型面板與特徵面板會給出最大角度，通常在 2° 以下。在特徵面板中提高**層級**，可使這些曲面片更小、更貼合。
- 銳利折痕是實體的真正邊，因此你可以對其做圓角。
- 每個曲面片各自為一個面，因此造型會有許多面，且面與面之間會繪出線條。

## 設計中的曲面特徵

曲面指令位於設計的{{ui:More}}功能表中，列於特徵之下。它們需要精確核心。曲面本體以藍色透視繪出。在加厚或縫合之前，它們不屬於實體的一部分。

| 指令 | 功能 |
|---|---|
| 修補曲面 | 填滿一個封閉的邊迴圈。先按住 {{key:Shift}} 點選實體的邊，或選取一個曲面本體以填補其開口。**相切（G1）**會使修補曲面與該曲面平順相接。 |
| 放樣曲面 | 依歷程順序，通過每個草圖中一組曲線鏈（開放或封閉）的曲面。 |
| 縫合 | 沿共用邊縫合曲面本體。若它們封閉，結果即為實體，並具有與其他特徵相同的運算。 |
| 加厚 | 為曲面本體賦予厚度：沿其法線、逆其法線，或兩側各半。結果為實體。 |
| 偏移曲面 | 沿其法線移動的曲面本體副本。原件保留。 |
| 延伸曲面 | 將單一面的曲面延伸超過你所選的邊。 |
| 修剪曲面 | 在另一曲面本體或實體與其相交處切割曲面本體。按**在片段上選取一點**以選擇要保留的片段，或保留其餘部分。 |

縫合、加厚、延伸與修剪會用掉它們所起始的曲面本體。之後的特徵會使用新的本體。

目前的限制：由數個分離的封閉片段組成的造型無法轉換為一個實體；規則區域不會合併為較大的曲面；另見[尚未實作的功能](topic:not-built-yet)。
