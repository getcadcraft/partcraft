組合件會將零件組裝在一起。在 PartCraft 中，**接頭**負責定位零件：每個接頭位於兩個零件各自的一個平面上，並使兩者面對面貼合。旋轉接頭讓一個零件可以轉動，滑動接頭讓它可以滑動，剛性接頭則將其固定。

## 開始組合件

1. 先建立一個含實體的零件（空白零件無法放入組合件：「請先建立實體，再將其放入組合件。」）。
2. 在工具列中選擇{{ui:組合件}}。

狀態列會顯示「以 Part1 作為接地零件開始組合件。請插入更多零件（加入副本、插入，或編輯 › 建立副本），然後以接頭接合它們。」左側面板現在會列出**零件**與**接頭**，工具列會顯示組合件工具。草圖與特徵工具會隱藏。

第一個零件為**接地**：它永遠不會移動，其他所有零件都以它為基準定位。

## 插入零件

- {{ui:加入副本}}會插入所選零件（或最後一個零件）的另一個副本。副本共用同一個零件：編輯它，每個副本都會跟著變更。
- 「編輯」群組中的{{ui:建立副本}}（{{key:Mod+D}}）對所選零件執行相同的操作。{{key:Mod+C}}與{{key:Mod+V}}會複製零件，並將其貼在其他零件旁，可在此組合件或另一個組合件中進行；{{key:Mod+Shift+V}}則會將其貼在相同位置。參閱[複製、貼上與建立副本](topic:copy-paste)。
- {{ui:插入}}會從你電腦上的 `.partcraft.json` 檔案插入零件。該零件會被複製到組合件中。

新零件會出現在既有所有零件右側 20 mm 處，並會停留在那裡，直到接頭將其定位。沒有接頭的零件也可以以手動方式移動：輸入數值或拖曳箭頭（參閱[零件清單、爆炸視圖與移動零件](topic:assembly-bom-explode)）。

## 接合兩個零件

1. 選擇{{ui:接頭}}或按{{key:J}}。右側面板會顯示**新增接頭**。
2. 點擊第一個零件上的一個平面。該面會反白顯示。
3. 點擊第二個零件上的一個平面。

第二個零件會移動，使其面貼合於第一個零件的面，並面對它。接頭會出現在**接頭**下方，例如「Revolute1」，右側面板會顯示其設定。

- 若兩個面都是由旋轉產生，接頭會以**旋轉**開始；否則為**剛性**。之後可以變更。
- 無法選取曲面：「此面為曲面。請選取平面（若要繞孔或旋轉的軸轉動，請之後在接頭中選取它）。」
- 按{{key:Esc}}可取消已開始的接頭（或點擊左側清單中的零件）。

### 接頭設定

| 設定 | 作用 |
|---|---|
| **類型** | 下表所列的接頭之一 |
| **角度 (°)** | 使第二個零件繞接頭軸轉動（與兩面垂直） |
| **偏移 (mm)** | 使第二個零件沿軸移動，遠離該面（負值會推入面內） |
| **沿 X**、**沿 Y**、**繞 X 傾斜**、**繞 Y 傾斜**、**沿槽**、**槽方向** | 其他數值，僅顯示於使用它們的接頭 |
| **圓心位於**（每一側） | 接頭軸穿過該面的位置：「面本身的原點」、旋轉的軸（「Axis of Revolve1」）或某個孔的軸（「Hole1, hole 2」） |

接頭可移動的每個數值，其欄位下方都有拖曳滑桿；其他數值則只需設定一次。

| 接頭 | 可移動的項目 | 只需設定一次 |
|---|---|---|
| **剛性** | 無 | 角度、偏移 |
| **旋轉** | 角度（鉸鏈） | 偏移 |
| **滑動** | 偏移（抽屜） | 角度 |
| **圓柱** | 角度與偏移（滑動軸承中的軸） | |
| **平面** | 沿 X、沿面上的 Y，以及角度（在桌面上滑動的零件） | |
| **球** | 角度（自轉）以及繞接頭圓心的 X、Y 傾斜（球接頭） | |
| **銷入槽** | 沿槽與角度（直槽中的銷） | 槽方向：槽相對於面 X 軸的角度 |

面的 X 與 Y 採用第一個零件之面的 X 與 Y；接頭的圓心由**圓心位於**設定。

「面本身的原點」是零件原點投影到該面上的位置，通常並非你希望零件對齊的位置。對於圓形零件與銷，請在兩側都將**圓心位於**設為旋轉或孔的軸：如此軸便會對齊，效果如同同心配合。

### 範例：兩個法蘭面對面螺栓連接

1. 開啟法蘭零件（一個旋轉件，並帶有圓形陣列的孔），然後選擇{{ui:組合件}}。
2. 選擇{{ui:加入副本}}。
3. 按{{key:J}}，點擊第一個法蘭圓盤的平面（螺栓孔起始的那一面），然後點擊第二個法蘭上的同一面。這些面由旋轉產生，因此接頭為旋轉。
4. 將兩側的**圓心位於**都設為「Axis of Revolve1」。兩個法蘭現在共用同一軸。
5. 在**角度 (°)**中輸入 `22.5` 以對齊螺栓孔，或拖曳滑桿。

## 封閉迴圈：連桿機構

以環狀接合的零件（四連桿、曲柄滑塊，或兩側都有斜撐的框架）會形成一個**迴圈**。PartCraft 會求解每個迴圈，使其閉合：迴圈上的接頭會取得能將環連接起來的數值，並盡量從原來的位置少移動。

- **設定或拖曳**迴圈上接頭的數值，迴圈的其餘部分會跟隨移動。對於四連桿，拖曳曲柄的**角度**，耦合桿與搖桿會隨之移動。你設定的數值會被保留；其他數值則由它推算。
- 在清單中，迴圈上仍可移動的接頭為**藍色**：仍可設定另一個數值。無法移動的迴圈（有斜撐的框架）保持黑色。無法閉合的迴圈為**紅色**。
- **零件**方塊會顯示**迴圈**：已閉合的數量，以及仍可移動的數值數量，例如「1 個已閉合；1 個數值仍可移動」。
- {{ui:檢查運動過程中是否有干涉}}會讓迴圈上的接頭連同迴圈逐步掃描（參閱[檢查組合件的干涉與運動](topic:check-assembly)）。

由平板堆疊而成的平面連桿，其深度必須一致：在環的兩側以面對面方式接合的兩個零件，兩個方向都需要相同的堆疊高度。若堆疊高度加總不符，請使用接頭的**偏移**將零件抬高，否則迴圈無法閉合。

## 操作零件

在檢視或清單中點擊零件以選取它。右側面板會顯示其零件名稱、副本數量、體積、接頭，以及它是否為接地、由接頭設定，或「未接合：保持放置位置」。按鈕如下：

- {{ui:編輯此零件}}（或工具列中的{{ui:編輯零件}}，或在清單中按兩下零件）：開啟零件以進行編輯；
- {{ui:插入副本}}；
- {{ui:設為接地零件}}；
- {{ui:移除}}：也會在詢問後移除其接頭。

組合件至少會保留一個零件：「組合件至少需保留一個零件。請改為關閉它。」

### 就地編輯零件

1. 選取零件，然後選擇{{ui:編輯零件}}。零件會連同其歷程開啟；標題會顯示「Bracket (in Bracket assembly)」。
2. 像任何零件一樣進行變更。
3. 在工具列中選擇{{ui:返回}}。組合件會更新：該零件的每個副本都會跟著變更，而由草圖邊線產生的面上的接頭會隨之調整。

將變更帶回組合件是組合件復原清單中的一個步驟。

## 復原、儲存與關閉

- 組合件有自己的復原清單：{{key:Mod+Z}}與{{key:Mod+Y}}可用於接頭、插入與設定。
- {{ui:儲存}}或{{key:Mod+S}}會下載 `<assembly name>.partcraft-asm.json`，其中包含所有零件。之後可用{{ui:開啟}}開啟它。
- {{ui:關閉}}會關閉組合件，並返回你開始時所用的零件。若組合件尚未儲存，會詢問：{{ui:取消}}、{{ui:捨棄組合件}}或{{ui:先儲存}}。
- 若要重新命名組合件，請點擊空白處使未選取任何項目，然後在右側面板中變更**名稱**。

## 大型組合件

組合件可以容納數千個少數幾種零件的副本。同一零件的副本會一起繪製，你所轉動的接頭只會定位其後方的零件，而零件清單會顯示前幾列，列下方有「顯示更多」按鈕（所選零件一律列出）。

- 當你轉動或縮放檢視時，超過約 300,000 個三角形的組合件會以每個零件一個方塊繪製，停止操作後稍候便會完整繪製。
- {{ui:檢視}} › {{ui:輕量顯示}}會讓方塊始終顯示。選取零件與接頭時仍使用實際零件。
- 轉動速度也取決於你的顯示卡。PartCraft 所量測的數據列於版本說明中，並附上測試所用的機器。

## 接頭問題

- 沒有任何接頭接觸到的零件會列為**自由**，面板會顯示「Bracket2 未與接地零件接合，因此保持放置位置。」
- 無法閉合的迴圈（長度不夠、限制阻止接頭移動，或各面深度不一致）：「Revolute3 所在的迴圈無法閉合：誤差為 2.000 mm。請檢查該迴圈接頭的面、偏移與限制。」其接頭會變為紅色。
- 若編輯零件後，接頭所用的面或軸已不存在：「此接頭所用的面已從 Bracket 中移除。」請移除該接頭並重新建立。
