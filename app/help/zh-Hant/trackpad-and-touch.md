PartCraft專為配有滾輪與中鍵的滑鼠而設計，但一旦熟悉手勢，觸控板也能運作良好；觸控螢幕則適合檢視零件與簡單的草圖繪製。

## 觸控板

:::mac
| 目的 | 操作方式 |
|---|---|
| 旋轉零件（3D） | 單指按住拖曳（若已開啟三指拖曳，也可用三指拖曳） |
| 平移（3D） | 按住{{key:Shift}}（或⌘）並按住拖曳，或以雙指按住拖曳（次要點按拖曳） |
| 滑動旋轉零件 | 以雙指滑動；按住{{key:Shift}}時，滑動會平移。需要將**捲動**設為「自動判斷」（預設）或「觸控板」 |
| 縮放（3D與草圖） | 捏合。縮放以游標為中心。若**捲動**設為「滑鼠滾輪」，雙指捲動也會縮放 |
| 右鍵點按 | 以雙指點按，或按住{{key:Ctrl}}再點按 |
| 在草圖中平移 | 以雙指滑動（「自動判斷」或「觸控板」），或以雙指按住拖曳。{{key:Shift}}+拖曳在草圖中不會平移（它會繪製選取視窗） |
| 在草圖中加入選取 | {{key:Shift}}+點選或⌘+點選 |

若雙指點按無效，請在「系統設定」的「觸控板」中，於「輕點與點按」開啟次要點按。
:::

:::windows linux
| 目的 | 操作方式 |
|---|---|
| 旋轉零件（3D） | 按下觸控板（或輕觸並按住）後拖曳 |
| 平移（3D） | 按住{{key:Shift}}或{{key:Ctrl}}並拖曳，或按住右鍵區域拖曳 |
| 滑動旋轉零件 | 以雙指滑動；按住{{key:Shift}}時，滑動會平移。需要將**捲動**設為「自動判斷」（預設）或「觸控板」 |
| 縮放（3D與草圖） | 在支援的觸控板上捏合。縮放以游標為中心。若**捲動**設為「滑鼠滾輪」，雙指捲動也會縮放 |
| 右鍵點按 | 雙指輕觸，或點按觸控板右下角 |
| 在草圖中平移 | 以雙指滑動（「自動判斷」或「觸控板」），或按住右鍵區域拖曳。{{key:Shift}}+拖曳在草圖中不會平移 |
| 在草圖中加入選取 | {{key:Shift}}+點選或{{key:Ctrl}}+點選 |
:::

**捲動**位於[PartCraft設定](topic:settings)中：「自動判斷」（預設）會將側向或細緻的捲動視為觸控板，「觸控板」一律視為觸控板，「滑鼠滾輪」則從不視為觸控板。三種設定下，捏合都會縮放。

在你於視圖中點擊後，方向鍵會旋轉3D視圖，按住{{key:Shift}}再按方向鍵則會平移，這對觸控板很方便。{{key:Plus}}與{{key:Minus}}用於縮放。

## 觸控螢幕

PartCraft支援觸控輸入，因此平板、觸控筆電與手機都可使用，但有一些限制。

:::touch
**觸控按鍵**

觸碰螢幕後，視圖右下角會出現一個小列，提供手指缺少的按鍵。使用滑鼠時它會消失。

- {{ui:Esc}}：Esc鍵。它會取消你開始的操作或退回一步，與按鍵的效果完全相同。
- {{ui:加入}}（草圖中配合選取）：開啟時，每次輕觸都會將一個項目加入選取集或移出，相當於{{key:Shift}}+點選。再次點按即可回到一次選取一個項目。
- {{ui:完成}}（繪製直線鏈、雲形線或多邊形時）：完成繪製，相當於按一下滑鼠右鍵。

手指在畫面上靜止約半秒，對單次輕觸的效果相同：使用繪圖工具時會完成你正在繪製的內容；使用選取時會將手指下的項目加入選取集或移出。點與線較容易用手指點中：PartCraft在輕觸周圍搜尋的範圍，約為點按周圍的兩倍。

**在3D視圖中**

- 單指：旋轉零件。
- 雙指：捏合縮放，一起移動則平移。
- 輕觸：選取面、邊或平面。在輕觸之前不會有游標懸停的反白。

**在草圖中**

- 使用繪圖工具時輕觸以放置每個點：先輕觸起點，再輕觸終點。捕捉會在手指抬起的位置進行。
- 雙指捏合與平移。放下第二根手指會取消第一根手指開始的拖曳。
- 若要結束直線鏈，請點按{{ui:完成}}、手指靜止不動，或在工具列中再次點按{{ui:直線}}（或其他工具）。
- 使用選取時，輕觸即可選取；拖曳點或線可移動它；在空白處拖曳即可建立選取視窗。第二次輕觸會取代選取集，除非已開啟{{ui:加入}}（或在第二個項目上手指靜止不動）。
- 若要修改標註，請使用右側面板中標註旁的**編輯**。

**圖紙**

輕觸以放置與選取符號，拖曳符號即可移動。捏合縮放、雙指移動平移，或在空白紙面上以單指拖曳。第二根手指會停止拖曳中的符號，且該符號會回到原位。

**仍需鍵盤的功能**

- 輸入數字：數字方塊與標註欄位中會跳出螢幕鍵盤。
- 工具的鍵盤快速鍵：請使用工具列。
:::

## 小螢幕與手機

- 寬度為1280像素或以上時，工具列會排在同一列。
- 約760至1100像素之間，側邊面板會變窄。
- 低於約760像素（手機或窄視窗）時，畫面會改為堆疊排列：工具列（可左右滑動以顯示更多按鈕）、3D視圖、狀態列，然後是屬性面板與歷程。捲動頁面即可看到面板。
- 功能表（{{ui:匯出}}、{{ui:檢視}}）會橫跨整個螢幕寬度開啟。

:::note
在iPhone上，瀏覽器沒有全螢幕模式；{{key:Ctrl+Shift+F}}與螢幕模式按鈕只會在一般模式與隱藏列之間切換。
:::

手機適合開啟零件、旋轉它並檢查其資訊。實際建模需要較大的螢幕與滑鼠或觸控板。
