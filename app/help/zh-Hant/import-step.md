PartCraft可開啟STEP檔案（`.step`或`.stp`，AP203、AP214與AP242），並以**實體本體**呈現，可在其上繪製草圖、切割、鑽孔，並與自行加入的特徵結合。本體沒有自己的歷程：無法變更其原始建立時的尺寸，只能在其上增加或切除。

此版本以網格核心建構每個零件，因此STEP檔案會以**三角形**讀取：平面維持為平面，而曲面（圓柱、圓錐、球面、環面、B樣條曲面）會變成許多小平面。其體積與精確值相差不到百分之一。要精確保留曲面需要精確核心，此版本未包含。

## 開啟STEP檔案

1. 選擇{{ui:開啟}}或按下{{key:Mod+O}}，然後選取`.step`或`.stp`檔案。也可將檔案拖放到3D視圖上。
2. PartCraft會讀取檔案並顯示其內容，例如：「AP214檔案：1個實體、10個面，以三角形讀取。」下方會顯示三角形數量、因故遺漏或合併的部分，以及結果是否封閉。
3. 檢查**檔案中的向上**。STEP檔案會標示自己的單位（公釐、英吋、公尺……）；PartCraft會將其轉換為公釐，因此**檔案中的單位**會顯示公釐（「檔案已標示」）。**此處大小**會顯示其尺寸。
4. 若為空白零件，選擇{{ui:開啟為實體}}；若零件已有特徵，則選擇{{ui:加入此零件}}或{{ui:新零件}}。加入時會詢問**使用方式**：加入、切除，或僅保留重疊部分。

歷程中會出現一個**Imported1**特徵，狀態列會顯示例如：「plate.step為實體本體：57995.937 mm³，有6個平面可繪製草圖。」

## 組合件STEP

組合件會以**一個本體**匯入，其中每個零件都位於檔案中的放置位置（「檔案中放置的3個零件會依其所在位置匯入」）。同一零件若使用兩次，就會匯入兩次。零件名稱與組合件樹狀結構不會保留。

## 設定向上方向

多數CAD程式使用Z軸向上；PartCraft使用Y軸向上。預設情況下，PartCraft會轉動檔案，使其Z軸朝上。若零件以側躺方式匯入，請選取**Imported1**，並將**檔案中的向上**設為**Y up**。**檔案中的單位**與**使用方式**也可在該處變更；每次變更都是一個復原步驟。

## 在其上建構

- 點選本體的一個平面，並選擇{{ui:在此面上繪製草圖}}。STEP模型的平面在本體重建時會保持其位置。
- 如同任何零件一樣，加入切除、孔、凸台、陣列與鏡射。
- 在**零件**方塊中檢查其尺寸：體積、表面積與大小。

圓角、倒角與抽殼需要精確核心，與此版本中的任何零件相同（[網格核心](topic:solid-kernels)）。

## 儲存位置

三角形會保存在`.partcraft.json`檔案**內部**，因此零件檔案自成一體：不需要再次使用STEP檔案。

## 訊息

| 訊息 | 意義 |
|---|---|
| 「"part.stp" 不是STEP檔案（開頭不是ISO-10303-21）。」 | 此檔案不是純STEP文字。請向寄件者索取AP203、AP214或AP242的STEP檔案 |
| 「STEP檔案無法讀取：其資料區段遺失或已損毀。」 | 檔案已截斷或損毀。請重新複製 |
| 「此STEP檔案中沒有任何實體或曲面本體：無可匯入的內容。」 | 檔案只含圖面、點或資料。請索取實體 |
| 「該STEP檔案過大（超過60 MB），無法在此匯入。」，以及讀取器的其他限制（項目、面、三角形） | 請在來源處簡化模型，或逐一傳送零件 |
| 「……檔案中的損毀行已略過。」 | 部分行無法讀取；其餘已匯入。請檢查本體 |
| 「……面無法製成三角形，已被略過。」 | 這些面會留下孔洞，PartCraft會嘗試填補；若本體仍不封閉，則不予加入 |
| 「……不支援之類型（……）的面已略過。」 | 罕見的曲面類型。請索取使用平面或B樣條曲面的模型 |
| 「它不封閉……」 | 這些面無法組成封閉實體（曲面模型，或遺漏了面）。PartCraft會顯示開口，且不加入任何內容 |

## 限制

- 曲面會以平面小面繪製與量測，與此版本建構的所有零件相同。PartCraft會將檔案中的平面、圓柱、圓錐、球面與環面保留於本體上，因此{{ui:匯出}} › {{ui:STEP AP242（精確實體）}}會將其寫回為真實曲面，孔洞仍為孔洞，並連同所加入的特徵一併寫出。檔案中以樣條、掃掠或旋轉曲面表示的面，在匯出時仍為小面。0.9.1之前儲存的零件沒有保留的曲面：請重新開啟STEP檔案以取得曲面。
- {{ui:匯出}} › {{ui:草圖或平坦面的 DXF}}（選取平坦面時）會將檔案中的圓孔寫為真正的圓。
- 不會讀取顏色、本體名稱、組合件結構與PMI（檔案中的公差）。
- 除STEP外，PartCraft還可開啟STL、OBJ與3MF網格（[開啟STL、OBJ或3MF](topic:open-meshes)）以及`.3dm`檔案（[開啟.3dm模型](topic:open-3dm-files)），並將其作為實體本體。不支援IGES與其他程式的原生檔案。
- 若零件中的STEP實體是由具精確核心的版本匯入，會保留STEP文字；此版本會略過該功能（「尚未實作」）。請重新開啟STEP檔案，以三角形形式匯入。
