請點選應用程式列中的齒輪，或按{{key:Mod+,}}，以開啟{{ui:設定}}。第一個索引標籤{{ui:PartCraft}}包含屬於此應用程式的設定；{{ui:一般}}則包含所有CadCraft應用程式共用的設定（佈景主題、工具列、面板）。PartCraft的設定只存在於此應用程式中：在此變更後，本瀏覽器會記住這些設定。{{ui:重設PartCraft設定}}會將所有設定還原為初始狀態。

## 旋轉檢視

- **左鍵**（預設）：以左鍵拖曳可旋轉零件；以右鍵或中鍵拖曳可平移。
- **中鍵**：按下滾輪並拖曳可旋轉零件；按住{{key:Shift}}（或{{key:Ctrl}}，或⌘）並以中鍵拖曳，或以右鍵拖曳，即可平移。左鍵僅用來選取面、邊與平面，因此輕微移動的點擊不會旋轉零件。許多CAD程式都採用此方式。

不論哪種方式，滾輪都會以指標位置為中心縮放。在草圖中，右鍵與中鍵仍可照常平移。

## 捲動：滑鼠滾輪或觸控板

- **自動判斷**（預設）：PartCraft會觀察捲動方式。如觸控板傳送的橫向或細微捲動，會旋轉零件；整格的滾輪刻度則會縮放。
- **滑鼠滾輪**：捲動一律以指標位置為中心縮放。
- **觸控板**：以兩指滑動可旋轉零件；按住{{key:Shift}}並滑動可平移；以捏合手勢縮放。在草圖中，兩指滑動會平移草圖。

無論選擇哪一種，捏合都能縮放。若「自動判斷」對你的滑鼠或觸控板判斷有誤，請選擇實際使用的裝置類型。更多內容請參閱[觸控板、觸控與小螢幕](topic:trackpad-and-touch)。

## 草圖：繪製時新增關係

**繪製時新增關係**（預設為開啟）：點擊並貼齊某一點時，新點會與該點重合；點擊曲線時，該點會位於該曲線上；幾乎水平或垂直繪製的線，會變為水平或垂直。請參閱[關係與標註](topic:relations-dimensions)。

當你想將幾何放在其他幾何附近，但不想與之連接時，請將其關閉。指標仍會貼齊點與曲線，但不會連接：連續繪製的線段不會共用端點，因此拖曳時可能會將它們拉開。請自行從右側面板新增所需的關係。封閉輪廓的端點相接時，仍可拉伸。

:::note
此設定僅影響之後新增的繪製內容。草圖中既有的關係會保留，而圓角工具仍會建立其相切圓弧與半徑。
:::

## 草圖：繪製時標註尺寸

**繪製時標註尺寸**（預設為開啟）：繪製線段、矩形、圓或圓弧時，輸入數字會填入指標旁的尺寸框（按{{key:Tab}}移至下一個框），按{{key:Enter}}即會以該尺寸繪製圖形，並為你輸入的每個尺寸建立一個驅動標註。關閉時，繪製過程中輸入數字不會有任何作用，圖形僅能以點擊繪製。請參閱[繪製時輸入尺寸](topic:sketch-basics#type-the-size-as-you-draw)。

## 角落指示器

3D檢視角落顯示的內容：**視圖方塊**（預設；位於右上角，點選面、邊或角即可從該方向檢視，拖曳可環繞旋轉，拖曳其羅盤環可旋轉模型）、**座標軸圖示**（左下角的小型X、Y、Z標記，會隨檢視轉動：X為紅色、Y為綠色、Z為藍色）或**無**。在草圖或圖紙上兩者都不會顯示。請參閱[視圖方塊](topic:view-cube)。

## 求解器執行緒

模擬求解器可使用的執行緒數。**自動**（預設）會採用電腦邏輯處理器數量減一（最多16），使頁面在分析求解時仍保持回應；也可以選擇指定數字。大型體素分析、挫屈、隨時間變化的應力與流動的求解，在多個執行緒上會較快（依我們的測試，在4個執行緒上處理80,000個方塊約快2倍，在閒置的電腦上會更快）；約20,000個未知數以下的模型則維持單一執行緒，因為啟動執行緒的成本高於其節省的時間。多執行緒求解與單一執行緒的答案相同（僅在捨入誤差範圍內：加總的順序不同）。每個分析的結果會在**求解器**下列出**N個執行緒**或**1個執行緒**，並說明原因。

執行緒需要頁面為**跨來源隔離**（只有在此情況下，瀏覽器才允許工作執行緒共用記憶體）。實驗室頁面符合此條件；若不符合，設定會顯示說明（「此頁面未進行跨來源隔離，因此無論此處選擇為何，求解器都只會使用一個執行緒。」），且每次求解都只會使用一個執行緒。其他功能運作方式相同，答案也相同。

層流分析也會使用執行緒（在4個執行緒上處理54,000個流體單元時約快2.5倍，答案的每一位數字都相同）。二次四面體求解器與熱傳遞則在單一執行緒上執行：在我們的測試電腦上，改為多執行緒反而較慢（它們的求解器受限於記憶體速度，以及一個無法分割的步驟）。

### 在自己的網頁伺服器上

若你從自己的伺服器執行PartCraft，則會依原樣運作。若要使用求解器執行緒，請設定伺服器在PartCraft頁面中傳送以下兩個標頭：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

在Apache中，於資料夾的 `.htaccess` 內設定（需要mod_headers）：

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

在nginx中，於提供PartCraft的 `location` 區塊內設定：

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

重新載入頁面後，設定 › 求解器執行緒便會提供**自動**選項，並顯示電腦的數量。第二個標頭會讓瀏覽器拒絕頁面從不允許此行為的其他網站載入的任何內容；對PartCraft本身而言這沒有問題，因為它會從自己的資料夾載入所有內容。
