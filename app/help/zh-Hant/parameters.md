參數是一個有名稱的數字，例如 `width = 120` 或 `margin = bolt * 1.5`。將深度、孔徑、陣列數量或草圖尺寸連結到參數後，更改參數就能在一個步驟中更新所有連結的數值。這樣設計意圖就能保留在零件中，而不必只存在你的腦中。

## 新增參數

1. 在右側面板中，按一下 {{ui:參數}} 索引標籤。
2. 在**變數**下，於「名稱」方塊中輸入名稱，例如 `width`。
3. 在下一個方塊中輸入其值，例如 `120`，然後按 {{key:Enter}}（或按一下 {{ui:加入}}）。

數值可以是數字，也可以是其他參數的運算式：`bolt * 1.5`、`width / 2 - 10`、`if(width > 100, 6, 4)`。**值**欄會顯示計算結果。名稱必須以字母或 `_` 開頭，且只能包含字母、數字與 `_`；函式與單位的名稱（`sin`、`mm`、`pi`）會被拒絕，`a = b` 且 `b = a` 這類循環也會被拒絕。

## 將數字連結到參數

1. 在歷程中按一下某個特徵，例如「Extrude1」。其設定會顯示在{{ui:屬性}}索引標籤中。
2. 在數字方塊中（例如 **深度 (mm)**）輸入 `=` 與運算式：`=thick` 或 `=width / 4`。
3. 按 {{key:Enter}}。

方塊現在會顯示結果，其標籤旁會出現 **ƒ** 按鈕，將游標移到上面即可看到方程式。草圖尺寸的運作方式相同，無論是在特徵的**草圖尺寸**清單中，或在已開啟草圖的尺寸方塊中（連按兩下尺寸，輸入 `=width`，然後按 {{key:Enter}}）。

可連結的數字：拉伸深度、旋轉角度、孔徑、深度與沉頭尺寸、陣列數量、間距與角度、圓角半徑、倒角距離、殼體壁厚、所有草圖尺寸，以及較新特徵的尺寸（第二深度、錐度、埋頭孔、參考平面距離、拔模角度等）。

## 更改參數

在{{ui:參數}}索引標籤中，於**運算式**欄輸入新數值或運算式，然後按 {{key:Enter}}。所有連結到它的數值都會更新，零件也會重建，整個操作為一個步驟：{{key:Mod+Z}} 可復原。

若要從另一端修改數字，見[雙向方程式](topic:equations-two-way)。

## 查看參數的使用位置

在{{ui:參數}}索引標籤中，每個參數下方都有一行文字說明其用途：

- 它驅動的數字，例如 **Extrude1 depth** 或 **Sketch1 D2 (distance)**。按一下即可選取該特徵並顯示其屬性；
- 它**透過**其他參數驅動的數字，例如當 `d = h + 2` 且 `h = w / 2` 時的 **Hole1 diameter (through h, d)**；
- 運算式使用它的**參數**、設定它的**組態**，以及讀取它的**指令稿**（見[撰寫與執行指令稿](topic:craftscript)）。

「尚未使用」表示沒有任何項目使用它：你可以直接刪除，不會再詢問。

## 取消連結、重新命名、刪除

- **取消連結數字：**按一下其 **ƒ** 按鈕，或按一下**方程式**清單中的 {{ui:取消連結}}。它會保留目前的數值，且不再由任何參數更改。
- **重新命名參數：**在其**名稱**方塊中輸入新名稱。所有使用它的運算式都會改寫。
- **刪除參數：**按一下其列上的 ×。若有項目使用它，PartCraft 會詢問是否要先將其目前數值寫入那些運算式。
- **刪除特徵會移除其數字的方程式**；狀態列會說明是哪些。

:::note
參數會儲存在 `.partcraft.json` 檔案中（為檔案第 3 版）。沒有參數的零件會與以前完全相同地儲存。
:::

## 運算式

| 寫法 | 意義 |
|---|---|
| `120`、`12.5`、`1e3` | 數字（毫米，或角度時為度） |
| `2in`、`1ft`、`3"`、`1.5cm`、`0.2m` | 其他單位的長度，會換算為毫米 |
| `30deg`、`0.5rad` | 角度，會換算為度 |
| `+ - * / %` 與 `^` | 算術；`^` 為次方，`-2^2` 為 −4 |
| `sin cos tan asin acos atan atan2` | 三角函數（以度計） |
| `sqrt pow exp ln log abs sign` | 其他函式 |
| `ceil floor int round(x, digits) min max` | 取整與界限 |
| `if(test, a, b)` 搭配 `< <= > >= == !=` | 選擇：`if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

名稱區分大小寫：`Width` 與 `width` 是兩個參數。
