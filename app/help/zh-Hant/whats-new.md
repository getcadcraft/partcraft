這份說明列出 PartCraft 0.7 相較於 0.6 的變更。零件可從更多種檔案進來，並有一個新的工作區可由你的設計製作手冊。

## 新增

### 由你的設計製作手冊

- **圖解工作區。**在{{ui:工作區}}切換器中選擇{{ui:圖解}}，再按{{ui:手冊}}群組中的{{ui:新增}}：手冊可由開啟中的零件或組合件、已儲存的組合件，或 glTF、OBJ、STL 或 3MF 檔案開始（保留其樹狀結構與名稱；同一零件的多個副本會合為一個帶數量的零件）。手冊是獨立的檔案（`.partcraft-manual.json`），內含零件的副本，因此設計進行的同時，文件也能繼續製作。見[在圖解中開始製作手冊](topic:illustrate)。
- **視圖與外觀。**隱藏、半透明、隔離或重新著色零件，播放爆炸圖，從模型切出剖面或方塊，加入放大鏡，並把這一切儲存為一個視圖。見[視圖、外觀、剖面與放大鏡](topic:illustrate-views)。
- **氣球標號與零件清單。**一鍵為視圖中顯示的每個零件加上氣球標號；編號會跟著零件，且絕不重複使用。清單可放在視圖中，並可儲存為 CSV。見[零件清單與氣球標號](topic:illustrate-parts-list)。
- **保持附著的註解：**會自動填入零件編號、名稱、材料或數量的標籤與引註，從零件量測得出的箭頭、距離、角度與半徑，以及形狀與圖片。零件爆炸時，它們會隨零件移動。見[保持附著的註解](topic:illustrate-annotations)。
- **線稿、說明書與 3D 檔案。**可把任何視圖匯出為向量線稿（SVG 或 PDF），含隱藏線與剖面線，也可匯出為 PNG；可把各視圖做成逐步說明書，輸出為 PDF 或單一 HTML 頁面；也可儲存一個可在任何瀏覽器離線開啟的 HTML 檔案，內含各視圖、零件清單與動畫。見[技術圖解](topic:illustrate-line-art)、[說明書文件](topic:illustrate-instructions)與[互動式 3D 檔案](topic:illustrate-interactive)。
- **動畫與更新。**為零件與攝影機設定關鍵影格，逐步錄製爆炸圖，並儲存為影片。設計變更時，{{ui:從設計更新…}}會在任何變動發生之前，先顯示哪些項目移動、變更、新增或移除，並讓視圖、註解、氣球標號與關鍵影格繼續跟著各自的零件。見[為手冊製作動畫](topic:illustrate-animation)與[依設計更新手冊](topic:illustrate-update)。

### 開啟其他檔案

- **STEP 檔案以實體本體開啟。**{{ui:開啟}}不需精確核心即可讀取 AP203、AP214 與 AP242 STEP。平面保持平面，曲面變成許多小平面，組合件則以單一本體匯入，每個零件位於檔案所放置的位置。可在其平面上繪製草圖、切除，並在其上添加。見[開啟 STEP 檔案並在其上繼續建模](topic:import-step)。
- **STL、OBJ 與 3MF 網格變成實體。**開啟或拖放檔案：PartCraft 會接合重複的角點、封閉小縫隙、填補孔洞，並翻轉朝向錯誤的三角形，然後說明做了什麼，以及網格現在是否封閉。選擇單位與哪一軸朝上，本體便以 **Imported1** 的名稱進來，其平坦區域成為可繪製草圖的面。無法封閉的網格會說明還剩幾個開口，且不會加入任何東西。見[把 STL、OBJ 或 3MF 作為實體本體開啟](topic:open-meshes)。
- **.3dm 檔案以單一本體開啟。**`.3dm` 檔案中的網格、多重曲面、拉伸與區塊放置，會以單一實體本體匯入，採用檔案中存的網格或由 PartCraft 細分，並經過與網格相同的修復與「是否封閉？」檢查。曲線、文字、SubD 物件、圖層與顏色會略過，對話方塊會說明。見[把 .3dm 模型作為實體本體開啟](topic:open-3dm-files)。

### 零件與組合件

- **由型鋼斷面製作框架。**以直線繪製框架，可在一張草圖中，或分成數張草圖做出立體框架，再選擇{{ui:更多}} › {{ui:結構構件}}：AISC 或 EN 10365 表中的斷面會沿每條線延伸。轉角可斜接或對接，T 形相接或三根在一個轉角相交的構件會被切合，自由端可加蓋板，轉角可加接合板，並有切割清單列出每一件的長度與端部角度（{{ui:儲存裁切清單 (CSV)}}）。見[由型鋼斷面製作框架](topic:structural-members)。
- **組合件中的閉合迴路。**以環狀接合的零件（四連桿機構、曲柄滑塊、斜撐框架）現在可以閉合：在迴路上拖曳或輸入數值，其餘部分會隨之移動，運動檢查也以同樣方式掃過迴路。仍可移動的接頭為藍色，無法閉合的迴路會變紅並說明偏差多少。見[閉合迴路：連桿機構](topic:build-assembly#closed-loops-linkages)。
- **含數百個特徵的零件。**PartCraft 會保留歷程進行到一半時的實體，所以歷程後段的變更只重新建構其後的特徵，彼此不接觸的切除與凸台也會一併套用。已用含 750 個特徵的零件測試過。「參數」視窗可承受數百個方程式，復原則保留 200 個步驟，除非會用掉大量記憶體（但絕不少於 20 個）。見[含數百個特徵的零件](topic:edit-history#parts-with-hundreds-of-features)。
- **依你的組態產生變體套件。**在{{ui:參數}}索引標籤的**組態**下，{{ui:變體套件…}}會把每個組態（或你勾選的組態）建構成一個 zip：每個組態各有一份 STEP、一份 IFC、一張 DWG 圖紙與一張預覽圖，另有其參數表（CSV 與 JSON），以及把零件連同其變體做成一個程式庫項目。無法建構的組態會被列出並略過。命令列可用 `partcraft variants` 做同樣的事。見[依你的組態製作變體套件](topic:variant-pack)。

### 製造

- **可編輯的後處理器。**製造中的 Fanuc 風格、GRBL 與 LinuxCNC 後處理器，現在是 PartCraft 自己後處理器格式的簡短文字檔，寫出的內容與以前完全相同。{{ui:編輯後處理器…}}會開啟你自己的副本（{{ui:新增後處理器…}}與{{ui:匯入後處理器檔案…}}也一樣），指出哪一行有誤，並在你輸入時顯示它寫出的 G-code。後處理器儲存在零件中，也可存成 `.cpost` 檔案。見[可編輯的後處理器](topic:post-processors)。
- **3D 精加工：平行與扇形。**用球頭、牛鼻或平頭銑刀精加工整個模型的表面，可用任意角度的平行線，或相隔固定距離的行程，使其間的脊線高度符合你的要求（平頭銑刀除外）。見[3D 精加工：平行與扇形](topic:finish-3d)。
- **刀具庫。**把刀具儲存在這個瀏覽器中，供每個零件使用，也可匯出或匯入為 JSON 檔案，以移到另一台電腦。見[刀具庫](topic:tool-library)。
- **以顏色顯示毛胚與模型的對照。**開啟**顯示模擬毛胚**後，毛胚在模型上為綠色，刀具切入處為紅色，剩餘毛胚處則由黃色到灰色，面板中有色彩對照。見[模擬](topic:manufacture#simulate)。
- **在套料之間保留餘料。**套料之後，每塊板剩下的部分可成為帶編號的餘料，並記錄其材料與厚度。下一次相同材料與厚度的套料會先使用餘料，再使用整塊板材；庫存清單會存入檔案，也可存成 CSV，DXF 則會標記每塊餘料。見[保留並重複使用餘料](topic:nest-offcuts)。
- **雷射程式。**{{ui:匯出}} › {{ui:雷射程式…}}從 DXF 檔案取得輪廓，設定每個圖層的作用（切割、刻劃、雕刻、填滿），預覽雷射頭的移動，並儲存 GRBL 雷射模式的 G-code。在 Chrome 與 Edge 中，也能在雷射關閉的情況下框出作業範圍，再經由 USB 傳送。設定會存入檔案。見[把圖形送到雷射機](topic:laser-cutting)。
- **USD 匯出。**{{ui:匯出}} › {{ui:USD 封裝（.usdz）}}會寫出含材料、體積與質量的零件，或每個零件一份、每個副本各自放置的組合件，單位為公尺，Z 軸朝上。見[把零件或組合件匯出為 USD](topic:usd)。

### 助理

- **供你自己的 AI 助理使用的工具。**在{{ui:設定}} › {{ui:PartCraft}} › {{ui:助理}}中開啟後，經由 CadCraft Studio 連線的助理可以讀取特徵、參數與質量特性、設定參數並重新建構（一個復原步驟）、像指令稿工作區一樣執行 CraftScript、Lua 或 Python 指令稿、匯出 STL、3MF、面片 STEP 或 USD、儲存，並把手冊匯出為 PDF、SVG、說明書或互動式 3D 檔案。檔案伺服器與 `cadcraft` 命令列對已儲存的零件與手冊也能做同樣的事。PartCraft 本身不含 AI。見[在 AI 助理中使用 PartCraft](topic:use-with-ai-assistants)。

## 變更

- **含有來自檔案的本體的零件，會儲存為零件版本 5。**含有 STEP、STL、OBJ、3MF 或 `.3dm` 本體的零件，會把修復後的三角形保存在 `.partcraft.json` 檔案內，所以你不再需要原始檔案。PartCraft 0.6 會以其「較新版本」的訊息拒絕版本 5，而不是錯誤地開啟它。其他零件的儲存方式不變。見 [PartCraft 檔案](topic:file-formats#the-partcraft-files)。
- 你寫的後處理器會存入零件。較舊的 PartCraft 開啟這類零件後再次儲存時，會捨棄這些後處理器。

## 所有應用程式

- **單位。**{{ui:設定}} › {{ui:一般}} › {{ui:單位}}為長度、面積、體積、角度與坡度各提供一份清單，大小與單位定義給出的精確值一致（美國測量英尺是獨立的單位）。關閉從不使用的單位，它們就會從單位清單中消失；為某個單位加上星號，新的工作就從該單位開始。檔案一律保有自己的單位。PartCraft 自己的方塊目前尚未跟隨這些清單或星號：零件仍以公釐顯示。見[單位、輸入的數值與單位清單](common:unit-lists)。
- **更緊湊的版面與可收合的面板。**{{ui:設定}} › {{ui:一般}} › {{ui:版面密度}} › {{ui:緊湊}}可讓畫面容納更多內容（觸控螢幕與手機保留大按鈕）。每個側邊面板都有一條細的標題列：拖曳它即可停駐或浮動面板，放到另一個面板的標題列上則共用一個框架成為索引標籤，也可固定它使其滑到邊緣收起，或將它隱藏後再從邊緣叫回。見[排列面板](common:arrange-panels#make-the-layout-denser)。
- **對話方塊可以移動。**拖曳對話方塊的標題列，把它移到不擋住圖面的位置；之後它會回到你放下的地方。在標題列上按兩下可再次置中。見[移動對話方塊](common:arrange-panels#move-a-dialog)。
- **AI 助理的範例做法。**十個給你自己的助理的實際請求範例（整理圖形、列印一組圖紙、檢查圖面、對模型提問、加總數量計算、試用零件變化……），每個都附上它呼叫的工具與需要的權限，並由我們的測試重新執行。應用程式本身不含 AI。見[AI 助理的範例做法](common:assistants-recipes)。
- **語言。**{{ui:設定}} › {{ui:一般}} › {{ui:語言}}新增了 **Português (Portugal)**。它、**Português (Brasil)**、**Español (México)** 與 **Bahasa Indonesia** 現在涵蓋應用程式的每一個字詞，但都是尚未經母語人士審閱的草稿。說明主題為英文，另有一篇為西班牙文。
- **CadCraft Studio** 在檢查更新失敗時會說明原因（你的系統尚無檔案、沒有網路、簽章無效），而不是只顯示「完成」，並且在有更新的版本之前，不再重新顯示你已關閉的「新功能」卡片。

## 此版本尚未提供

- **0.7 沒有程式碼簽章。**簽章與 Microsoft Store 套件已移到 0.8，因為憑證驗證尚未完成。請核對 getcadcraft.com/download 上每個檔案旁的 SHA-256。在 Windows 上，若 SmartScreen 擋住安裝程式，請選擇{{ui:其他資訊}}，再選擇{{ui:仍要執行}}。在 Mac 上，第一次請在 CadCraft Studio 上按右鍵並選擇{{ui:開啟}}。CadCraft Studio 尚未上架任何應用程式商店，也尚無 iPad 或 iPhone 版本。
- {{ui:單位}}中的角度與坡度清單會儲存，但目前還沒有任何欄位讀取它們。
- 來自 STEP、網格與 `.3dm` 檔案的本體沒有歷程，其曲面是小平面。不會從 STEP 讀取顏色、零件名稱與組合件樹狀結構；不會從 `.3dm` 讀取曲線、SubD 物件、文字、圖層與顏色。`.3dm` 讀取器已用該格式自己的工具組所寫的檔案檢查過，尚未用建模程式本身儲存的檔案檢查。
- 圖解在{{ui:從其他檔案…}}中尚不開啟 STEP 檔案（請在設計中開啟該 STEP，再開始{{ui:從開啟的零件}}），ModelCraft 與 BimCraft 也無法直接把模型交給它，並且尚未提供路徑追蹤器品質的圖片。影片匯出與互動式檔案尚未在真正的手機與平板上檢查過。
- 雷射程式只從 DXF 檔案取得輪廓：鈑金零件的展開圖需要精確核心。CadCraft Studio 尚無 Web Serial，所以在那裡請儲存 G-code，再用你雷射機自己的程式傳送。雷射 G-code 與三個內建後處理器尚未在真正的機器上驗證過：請先在你控制器自己的模擬器中檢查每個程式。
- 3D 精加工只有平行與扇形：沒有 3D 粗加工、等高線、鉛筆式或殘料加工，也沒有車削。刀具庫存放在這個瀏覽器中，不會同步。
- 組態器頁面（訪客可在網站上選擇變體並下載）在網站的開關開啟之前，僅供工作人員使用。連接埠（連接點）無法從 PartCraft 設定。
- 結構構件只沿直線延伸，且是沒有銲道的單一實體。
- PartCraft 的功能區功能表樣式仍以完整大小繪製每個按鈕。
- 磁學：永久磁鐵只有 2D；馬達、飽和鋼材與彎曲零件的網格產生器尚未實作。

其餘一切見[尚未實作的項目](topic:not-built-yet)。
