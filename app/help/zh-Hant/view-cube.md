視圖方塊位於 3D 視圖的右上角（草圖繪製或圖紙上不顯示）。它會隨視圖轉動，因此總是顯示目前的檢視方向：{{ui:上視}} 為零件的 +Y 側（上視平面），{{ui:前視}} 為 +Z 側（檢視時前視平面朝向檢視者），{{ui:右視}} 為 +X 側。在指向它之前，它保持半透明。

## 從面、邊或角檢視

1. 指向方塊。指標下的零件會亮起：面的中央、邊（會同時亮起與之相接的兩個面），或角（會亮起三個面）。
2. 按一下。視圖會轉為從該處檢視，並保持相同的中心與縮放比例。

可點選的位置共有 26 處：6 個面（{{ui:上視}}、{{ui:下視}}、{{ui:前視}}、{{ui:後視}}、{{ui:左視}}、{{ui:右視}}）、12 條邊與 8 個角。角可得到經典的四分之三視圖；邊則是位於兩個面之間的視圖。

按一下 {{ui:前視}}、{{ui:上視}} 或 {{ui:右視}}，可得到與工具列中 {{ui:檢視}} 相同的視圖，但不會縮放至符合視窗。

## 拖曳方塊以環轉

拖曳方塊即可轉動視圖，與在視圖本身中環轉相同。拖曳永遠不會被視為點按，因此可在方塊的任何位置抓取。

## 羅盤環

方塊下方的環標示 N、E、S 與 W。

- **拖曳環**，使模型繞垂直軸轉動，宛如置於轉盤上。環會跟隨指標移動。
- **按一下字母**即可從該側檢視，並保持俯視的角度不變。在正上方的視圖中，被按下的字母會移到螢幕底部。

## 正對面視圖：箭頭

當正對某個面進行檢視時，方塊周圍會出現小箭頭：

- 四個**三角形**會將該側的面帶到正面：方塊上方的三角形表示原本位於上方的面，其餘依此類推。
- 右上角的兩個**弧形箭頭**會將畫面順時針或逆時針轉動四分之一圈，但不改變檢視的面。可用來轉動平面圖，使一道長牆橫跨螢幕。

## 首頁

方塊左上角的房屋按鈕會返回四分之一視圖，並將零件符合視窗。當方塊具有鍵盤焦點時，按 {{key:Home}} 可達到相同效果。

## 使用鍵盤

按 {{key:Tab}} 切換到方塊，然後：

| 按鍵 | 功能 |
|---|---|
| {{key:left}} / {{key:right}} | 以八分之一圈為步進，選擇方塊周圍的一個面、邊或角（螢幕閱讀器會朗讀所選項目） |
| {{key:up}} / {{key:down}} | 選擇較高或較低的一項，最高到 {{ui:上視}}，最低到 {{ui:下視}} |
| {{key:Enter}} 或 {{key:Space}} | 從所選項目檢視 |
| {{key:Shift+left}} / {{key:Shift+right}} | 使視圖繞垂直軸轉動四分之一圈 |
| {{key:Home}} | 首頁視圖 |
| {{key:Esc}} | 離開方塊 |

在方塊上按下的按鍵只作用於方塊：不會啟動 PartCraft 工具。

## 改用軸向圖示或不顯示

開啟 {{ui:設定}}（{{key:Mod+,}}）、{{ui:PartCraft}} 索引標籤，並將 **角落指示器** 設為 {{ui:視圖方塊}}（預設）、{{ui:軸向圖示}}（左下角的小型 X、Y、Z 標記：X 為紅色、Y 為綠色、Z 為藍色）或 {{ui:無}}。此瀏覽器會記住該選擇。請參閱 [PartCraft 設定](topic:settings#corner-indicator)。

:::note
方塊顯示 PartCraft 建立零件的方式：Y 軸朝上，因此方塊的 {{ui:上視}} 即為上視平面。羅盤字母僅用於轉動；零件沒有北方。
:::
