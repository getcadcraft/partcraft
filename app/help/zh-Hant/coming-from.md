如果你在 SolidWorks 中設計零件，PartCraft 的大部分概念都會很熟悉：草圖位於前、上、右平面上，有限制條件與智慧型標註，有含回溯列的特徵歷程，以及以配合定位的組合件。但存取它們的方式在某些地方不同，而且此第一個版本的功能較少。本頁會對應你的習慣，並列出會令人意外的地方。

## 習慣對應

| 你習慣的 | 在 PartCraft 中 |
|---|---|
| 左側的設計樹 | 左側的歷程：先是平面，然後是特徵，草圖縮排在使用它們的特徵之下 |
| 前、上、右平面 | 相同的三個平面，通過原點。前平面為 XY 平面，上平面為 XZ，右平面為 YZ；Y 向上 |
| 在平面或面上繪製草圖，然後以確認角退出 | 在選取的平面或平面上按{{ui:草圖}}（{{key:S}}）；按{{ui:結束}}或{{key:Esc}}直到草圖關閉 |
| 智慧型標註 | {{ui:標註}}（{{key:D}}）。點擊一或兩個項目，然後點擊數字要放置的位置。放置的位置會決定是水平、垂直還是對齊標註 |
| 在屬性面板中新增限制條件 | 選取項目，然後使用右側面板中的限制條件按鈕（重合、水平、平行、相切、相等等） |
| 繪製草圖時的自動限制條件 | 貼齊會新增重合、點在曲線上、水平與垂直限制條件 |
| 藍色／黑色／紅色草圖顏色 | 概念相同：藍色為尚未完全定義，黑色為完全定義，紅色為過度定義。標籤會顯示剩餘的自由度 |
| 旋轉用的中心線 | {{ui:中心線}}（{{key:N}}）；{{ui:旋轉}}會使用第一條中心線，除非你選取另一個軸 |
| 草圖圓角 | 在草圖中使用{{ui:圓角}}（{{key:F}}）：點擊角落，然後輸入半徑 |
| 輔助幾何切換 | {{ui:輔助}}（{{key:Q}}） |
| 拉伸凸台 | {{ui:拉伸}}：單向、中面、延伸至面／下一個／頂點、距面偏移、第二方向、錐度、單一輪廓（選取區域） |
| 拉伸切除 | {{ui:剪下}}：預設為貫穿全部；若要製作凹槽，請切換為單向 |
| 旋轉凸台／切除 | {{ui:旋轉}} / {{ui:更多}} › {{ui:旋轉切除}} |
| 參考平面／軸／點 | {{ui:更多}} › {{ui:平面}}、{{ui:軸}}、{{ui:點}}（參閱[參考平面、軸與點](topic:reference-geometry)） |
| 掃掠／放樣凸台或切除、拔模 | 在平面上使用{{ui:更多}} › {{ui:拔模}}（參閱[掃掠、放樣與拔模](topic:sweep-loft-draft)）。{{ui:掃掠}}與{{ui:放樣}}在此版本尚未實作（它們需要精確核心） |
| 孔精靈 | 在每個獨立的草圖點上使用{{ui:孔}}：簡單孔、沉頭孔、錐形沉孔（90° / 82°），或攻牙的 ISO 公制 M2–M24，貫穿或盲孔 |
| 線性／圓形陣列、鏡射 | {{ui:線性}}、{{ui:圓形}}、{{ui:鏡射}}（特徵或整個實體） |
| 邊的圓角與倒角 | {{ui:圓角}} / {{ui:倒角}}：點擊一條邊，再以{{key:Shift}}+點擊選取更多，然後按按鈕。一個半徑；等距、雙距離或距離與角度倒角。在此版本中，只支援兩個平面之間的直線邊，且在角落相交的圓角會以斜接方式處理。曲線邊的圓角或斜切請在草圖中處理（草圖中的{{ui:圓角}}，{{key:F}}） |
| 殼體 | {{ui:殼體}}：點擊要開口的平面，然後按按鈕。一個壁厚 |
| 開啟 STEP 檔案 | {{ui:開啟}}：以三角形讀入，成為可在其上繼續建立的實體（[開啟 STEP 檔案](topic:import-step)） |
| 編輯特徵後按確定 | 點擊特徵；在右側變更數字；輸入時即會重建。沒有確定，也沒有取消：請使用{{key:Mod+Z}} |
| 編輯草圖 | 在歷程中按兩下草圖 |
| 重建 | 每次變更後自動進行。沒有重建的按鍵 |
| 壓縮／取消壓縮 | 在右側面板中使用{{ui:抑制}} / {{ui:取消抑制}} |
| 拖曳回溯列 | 在特徵上使用{{ui:回溯至此}}；點擊「回溯列 · 向前推進」即可返回 |
| 拖曳特徵樹以重新排序 | {{ui:上移}} / {{ui:下移}}，或{{key:Alt+Up}} / {{key:Alt+Down}}；若會破壞相依關係，將會拒絕並說明原因 |
| 在模型上按兩下以編輯尺寸 | 選取特徵：其草圖的標註會列在右側面板中 |
| 配合：重合、同心、距離、角度 | {{ui:接頭}}（{{key:J}}）：在每個零件上選取一個平面；接頭會讓它們面對面貼合。**圓心位於**某軸的作用類似同心；**偏移**類似距離；**角度**類似角度 |
| 固定元件 | 第一個零件為接地；{{ui:設為接地零件}}可變更它 |
| 插入元件 | {{ui:加入副本}}、{{ui:建立副本}}（另一個副本）或{{ui:插入}}（從零件檔案） |
| 在組合件中編輯零件 | {{ui:編輯零件}}，然後{{ui:返回}} |
| 干涉偵測 | {{ui:干涉}} |
| 移動元件以查看運動 | 拖曳旋轉或滑動接頭的角度或偏移滑桿；{{ui:檢查運動過程中是否有干涉}}會掃描它。沒有接頭的零件：**手動移動**（拖曳箭頭，或輸入數值） |
| 量測／檢查 | {{ui:檢視}}，然後{{ui:量測}}（{{key:M}}）：距離、角度、半徑、面積；{{ui:質量性質}} |
| 爆炸視圖、物料清單 | 在組合件中未選取任何項目時，右側面板中的**爆炸視圖**與**物料清單** |
| 質量性質 | **零件**方塊：面狀實體的體積、表面積與尺寸（圓形零件會略為偏低）。沒有質量：目前尚未有材料 |
| 儲存、另存新檔為 STEP | {{ui:儲存}}會下載 `.partcraft.json`；{{ui:匯出}}提供 STL、3MF、精確 STEP（AP242 或 AP214）、面狀 STEP、DXF 與 PDF 圖紙 |
| 從零件製作圖紙 | {{ui:圖紙}}：自動產生 A3 圖紙，包含三個視圖、等角視圖、一個剖面、一個詳圖、基準、形位公差框與表面處理符號。只標註整體尺寸 |
| 中鍵拖曳以旋轉 | 此處**左鍵拖曳**旋轉。中鍵或右鍵拖曳平移。滾輪會以指標位置為中心縮放 |
| 檢視方向、垂直於 | {{ui:檢視}}選單；對於選取的面、平面或草圖使用{{ui:垂直於}} |
| 縮放至符合視窗（F） | {{key:F}}，或{{ui:符合視窗}}（在草圖中，{{key:F}}為圓角工具） |
| 右鍵選單 | 無。右鍵拖曳可平移；在草圖中，右鍵點擊會結束直線串接 |

## 常見的差異

**整個草圖就是輪廓。**拉伸與旋轉會使用草圖中的每個封閉迴圈。你無法為某個特徵選取草圖中的單一區域或單一輪廓。每個特徵請使用一個草圖。

**特徵使用哪個草圖。**特徵會使用你剛結束的草圖，或在歷程中所選取的草圖。若未選取任何項目，它會使用最新且尚未被任何特徵使用的草圖。若取得錯誤的草圖，請選取正確的草圖，然後重新選擇該特徵。

**變更會在輸入時立即套用。**沒有附有確定與取消的特徵對話方塊。每個數字都會立即重建，而{{key:Mod+Z}}是復原的方式。復原清單涵蓋草圖編輯、特徵與設定。

**過度定義絕不允許悄悄存在。**沒有驅動（參考）標註。若某標註已由其他限制條件固定，會被報告為過度定義（「已隱含此標註。請刪除它。」）。衝突的標註不會改動幾何，並會變為紅色。請刪除其中一個，或復原。

**掃掠與放樣尚未實作；圓角、倒角、殼體與拔模都有限制。**此版本的 PartCraft 以網格核心建立所有零件；狀態列的標籤一律顯示「網格核心」。圓角與倒角適用於兩個平面之間的直線邊，而在角落相交的圓角會以斜接處理，而非混合。殼體可開啟面，拔模僅適用於平面。需要精確核心的特徵仍可點擊，但選取時會顯示「尚未實作」。參閱[網格核心](topic:solid-kernels)與[尚未實作的功能](topic:not-built-yet)。

**有兩個名為圓角的按鈕。**在草圖中，{{ui:圓角}}（{{key:F}}）會將草圖角落倒圓。在零件上，「特徵」群組中的{{ui:圓角}}會將實體邊倒圓（在此版本中為兩個平面之間的直線邊）。此版本沒有掃掠或放樣：請參閱[尚未實作的功能](topic:not-built-yet)。

**孔需要獨立的點。**{{ui:孔}}會在以點工具建立的點上鑽孔。圓心與直線端點不計入。

**貫穿全部僅用於切除。**凸台需要指定深度。目前沒有「延伸至頂點／曲面／下一個」的終止條件。

**實體是面狀的。**網格核心會以平面小面建立圓形曲面，因此檢視、體積、STL 與 3MF 匯出都由它們組成：零件面板中的**曲線**可使其更精細。精確的 STEP 匯出則不同：它會將圓形曲面寫成其真實的曲面。

**僅使用毫米。**目前沒有英吋設定。輸入英吋尺寸時，請乘以 25.4。

**Y 軸朝上。**前平面面向你，上平面從上方俯視零件，正如你所預期，但世界座標的上方軸為 Y。STL、3MF 與精確 STEP 匯出會轉為 Z 軸朝上；面狀 STEP 則保持 Y 軸朝上。

**配合是面，而不是幾何對。**接頭一定是從兩個面對面貼合的平面開始。對於孔中的銷，請選取孔周圍的平面與銷的肩部，然後將**圓心位於**設為孔的軸與銷的旋轉軸。未被接頭觸及的零件會停留在插入的位置；你無法拖曳它們。迴圈中的接頭不會被求解。

**儲存即是下載。**沒有會被不斷覆寫的檔案。每次儲存都會在你的下載資料夾中建立新檔案。請先為零件命名，並將你的檔案放在專案資料夾中。

**沒有右鍵選單，也沒有指令管理員索引標籤。**所有功能都位於工具列與右側面板中，而工具列會依你目前的操作而變化：草圖工具只會在草圖中出現，組合件工具只會在組合件中出現。

**在草圖中，快速鍵是單一字母。**{{key:L}}、{{key:R}}、{{key:C}}、{{key:A}}、{{key:P}}、{{key:N}}、{{key:F}}、{{key:D}}、{{key:Q}}與{{key:S}}不需修飾鍵即可選取工具。參閱[快速鍵與滑鼠](topic:keyboard)。
