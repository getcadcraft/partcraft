PartCraft 目前是早期版本。本頁列出尚未支援的功能，讓你不必到處尋找，並說明目前可以改用的做法。這些項目都沒有預定日期。

## 需要精確核心

此版本使用網格核心建立所有零件（見[網格核心](topic:solid-kernels)）。以下所有項目都需要精確幾何核心，而此版本尚未提供。含這些特徵的已儲存零件仍可開啟：特徵會保留在歷程中並標示為尚未實作，儲存時也會保留。

| 尚未實作 | 目前的替代做法 |
|---|---|
| 圓形邊上的 {{ui:圓角}} 與 {{ui:倒角}}；沿邊緣半徑變化的圓角；在相交處平滑融合的圓角（網格核心會以斜接處理它們） | 圓角與倒角可用於平面之間的直線邊；其他角落請在拉伸前於草圖中先做圓角（草圖中的 {{ui:圓角}}，{{key:F}}） |
| 開啟彎曲面的 {{ui:殼體}}；不同厚度的壁 | 開啟平面；若需要較厚的壁，請用拉伸增加材料 |
| 在彎曲面上的 {{ui:掃掠}}、{{ui:放樣}}、{{ui:拔模}}；拉伸到某個面、下一個面或頂點；錐形拉伸 | 拉伸或旋轉，必要時分段進行；拉伸到你量測好的深度 |
| {{ui:肋板}}、{{ui:基礎凸緣}}、{{ui:邊緣凸緣}}與展開圖 | 拉伸板件或肋的截面 |
| 曲面：將{{ui:外形}}完成為零件的一部分、{{ui:補面}}、{{ui:放樣曲面}}、{{ui:Gordon 曲面}}、{{ui:縫合}}、{{ui:加厚}}、{{ui:偏移曲面}}、{{ui:延伸曲面}}、{{ui:修剪曲面}} | 無法使用 |
| 多個實體：{{ui:合併}}、{{ui:移動實體}}、{{ui:縮放實體}}、{{ui:路徑陣列}}，以及建立新實體的特徵 | 一個實體；陣列與鏡射會複製特徵 |
| 在只有精確核心才能找到的面上建立草圖、基準面、軸與點（圓角產生的面、孔壁，或匯入實體的面） | 在基準面、參考平面，以及拉伸與旋轉的平面上繪製草圖 |
| 將生成式設計結果開啟為零件或加入零件（它會成為匯入的實體） | 將結果下載為 STL 或 STEP |
| 編輯開啟的 STEP 檔案中彎曲面的精確曲面；從 STEP 檔案取得樣條、掃掠與旋轉面的精確 STEP；樣條側面；建模的螺紋；STL、OBJ、3MF 實體與組合件；其他零件建模軟體的 STEP | {{ui:開啟}} 會將 STEP 讀為三角形，並保留檔案中的平面、圓柱、圓錐、球面與環面，供匯出使用（[開啟 STEP 檔案](topic:import-step)）；{{ui:匯出}} › {{ui:STEP AP242（精確實體）}} 會精確寫入所有解析面，並以面片保存（[匯出](topic:export-files#for-other-cad-programs-step)）；其他零件建模軟體的巨集仍會寫入 |
| 工程圖檢視中的真實圓弧 | 檢視與剖面視圖由面片繪製 |
| 精確體積、面積與距離 | {{ui:量測}} 提供面片實體的數值，對圓形零件會略為偏低；調高**曲線**設定可使數值更接近 |

下方部分表格會建議以其中某項功能作為替代做法。這些建議在精確核心恢復後才適用。

## 草圖

| 尚未實作 | 目前的替代做法 |
|---|---|
| 橢圓、相切圓弧、圓錐曲線，以及可設定次數或權重的樣條（NURBS） | 樣條（三次）、圓弧與圓，搭配相切關係 |
| 樣條上的點（關係）、曲率（G2）關係 | 將樣條自身的控制點放在它必須通過的位置 |
| 會隨後續變更而更新的樣條偏移複本；帶有尖角樣條的鏈偏移 | 變更後再次偏移；先將角落圓化 |
| 與原始圖形保持連結的陣列複本；沿曲線的陣列 | 變更後重新陣列 |
| 投影自由造型或傾斜的圓形邊，以及會隨零件變化的投影幾何 | 投影直線與平行的圓形邊，然後標註尺寸 |
| 從屬（參考）尺寸 | 從面板或零件資訊讀取尺寸 |
| 共線關係 | 距離為 0 的平行 |
| 貼到其他程式（系統剪貼簿） | 匯出 DXF、STEP、STL 或 3MF |
| 輸入圓弧、相對或極座標 | 輸入直線與圓；使用圓弧工具繪製圓弧 |
| 不使用指標選取幾何 | 需要點按或觸控 |

| 暫態熱傳與具熱負載研究的自動細化；在誤差很小的地方讓網格變粗；針對局部量（某一點的峰值應力）的目標 | 針對靜力、挫屈、自然頻率與穩態熱研究，依整個零件的誤差**自動細化**：見[檢查應力與變形](topic:simulation)；否則請縮小元素尺寸 |
| 軸承與螺栓載重、遠端力、力矩、彈簧、指定位移 | 面上的力與壓力、重力；固定面與無摩擦面 |
