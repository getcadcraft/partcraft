分析程式庫是一組指令稿，每一個都是可以從頭讀到尾的函式：組裝剛度矩陣的方式、邊界條件放在哪裡、執行哪個求解器、結果如何算出。其中沒有任何部分是隱藏的黑箱；只有快速的內層迴圈（單元矩陣、稀疏求解器、網格劃分）是內建的。

## 從範例開始

**範例**群組包含五個簡短的指令稿，它們從頭到尾使用程式庫。點選其中一個，按 {{ui:開啟（唯讀）}}，然後按 {{key:F5}}：每個範例都會清除檢視區，在畫布上顯示結果，並在次要顯示區顯示圖表。

| 範例 | 內容說明 |
|---|---|
| 懸臂應力 | 一根 100 × 10 × 10 mm 的鋼桿，末端承受 100 N 集中載重：變形後鋼桿上的 von Mises 應力，以及四種單元尺寸下的末端撓度與樑理論之比較（繪成圖表） |
| MBB 樑拓撲 | 經典的 60 × 20 拓撲最佳化：設計逐漸成形、順應性下降，以及最終佈局（94 次迭代，順應性 203.19） |
| 電容器場 | 兩片寬 4 mm、相距 1 mm 的極板：電位與電場，以及考慮邊緣效應的電容與理想值及 Palmer 公式之比較 |
| 通道流 | 通道中流過立柱的格子玻茲曼流動：速度場與收斂歷程 |
| 電磁鐵 | 具有氣隙與線圈的 C 形鐵心：磁通密度、氣隙中的磁場與磁路公式之比較、電感，以及跨越氣隙的吸力。在 [二維磁場](topic:magnetic-fields-2d) 中有逐步說明 |
| 永久磁鐵 | 同一鐵心，但以永久磁鐵取代線圈：磁鐵的工作點、氣隙中的磁場與磁路之比較、漏磁量與吸力。見 [二維磁場](topic:magnetic-fields-2d#permanent-magnets) |

## 群組

| 群組 | 函式 | 功能 |
|---|---|---|
| 網格劃分 | `box_mesh`、`cylinder_mesh`、`voxel_mesh`、`tet_mesh`、`mesh_quality`、`nodes_at`、`face_nodes` | 以六面體、立方體或四面體表示的方塊與圓柱；任何模型（零件、實體、已載入的 STL）的立方體或四面體網格；單元體積與品質；在平面或面上選取節點 |
| 靜力應力 | `static_voxel`、`static_tet` | 立方體或 10 節點四面體上的線性靜力應力：位移、應力、von Mises、反力 |
| 框架 | `frame3d` | 以直接剛度法分析梁、柱與斜撐組成的 3D 框架：端部釋放、支承與彈簧、沿構件的載重；位移、反力、構件端部力。DetailCraft 與 BimCraft 的 {{ui:匯出為 CraftScript}} 會為其寫出整個模型。這是分析輔助工具，不是規範檢核 |
| 振動 | `modal_tet` | 自然頻率與模態形狀 |
| 熱 | `heat_steady`、`heat_transient`、`heat_system` | 穩態與暫態傳導，包含固定溫度、熱輸入、熱產生、熱通量與對流 |
| 拓撲最佳化 | `top88`、`top99`、`topopt3d` | 已發表的 88 行與 99 行二維程式碼，以及在立方體上以 3D 實作的相同方法 |
| 電磁學 | `poisson2d`、`magnetostatic2d` | 二維靜電學（電位、電場、電容、電荷）與靜磁學（向量位、磁通密度、永久磁鐵） |
| 流體流動 | `lbm2d`、`lbm3d` | 格子玻茲曼流動：二維在指令稿中完整寫出，三維使用 PartCraft 自有的流動核心 |

每個函式的標頭都會列出其確切引數。除非標頭另有說明，單位與 PartCraft 分析的單位相同：毫米、牛頓、兆帕、密度以噸每立方毫米計、熱以瓦特與克耳文計。電磁與格子玻茲曼函式可使用任何一致的單位；其標頭會說明如何使用。

## 程式庫如何檢查

每個函式的標頭最後都有一項**檢查**：一個已知答案的小型案例。PartCraft 的測試會執行其中的每一項；若 PartCraft 對同一工作有自己的分析，指令稿的答案會與該分析在相同網格上的結果比較：

- 懸臂末端撓度與樑理論相比（方塊單元誤差在 0.2% 以內，四面體在 0.05% 以內），並與 **Simulation** 工作區在相同網格上的求解器相比（相同到很多位數）；
- 懸臂的第一頻率與樑理論相比（低 0.24%，對短樑而言屬預期），並與 **Simulation** 的模態求解器相比；
- 熱：受熱的平面牆完全精確；小物體依集中電容公式冷卻；板的溫度依理論衰減；
- 拓撲最佳化：`top88` 重現論文的 94 次迭代與順應性 203.1925（使用密度濾波器時為 218.8032）；`topopt3d` 與 **Generative** 工作區在相同設定下的結束順應性相同；
- 電容器的電容與長螺線管的磁場與教科書數值比較，電磁鐵的氣隙磁場與磁路公式比較，永久磁鐵與空氣中的圓形磁鐵及以鐵軛閉合的磁鐵比較；
- 通道流與精確的拋物線剖面比較。

## 閱讀函式

1. 開啟指令稿面板的 **程式庫** 索引標籤。
2. 點選函式。其標頭會顯示：它計算什麼、方法、單位、假設與限制、**參考文獻**（書籍或論文，附方程式編號），以及**檢查**——一個已知答案、由 PartCraft 自身測試執行的小型案例。
3. {{ui:開啟（唯讀）}} 會在一個虛線邊框的索引標籤中開啟整個指令稿。你可以執行它、選取並執行其中的部分，但無法修改。

## 修改函式

按 {{ui:建立副本}}（或在唯讀索引標籤上方按 **建立可編輯的副本**）。副本是零件中同名的指令稿，因此會隨零件一起儲存，而且**此後該函式的每次呼叫都會使用你的副本**——編輯器會在指令稿上方說明此事。若要兩者都保留，請為副本重新命名。

## 使用函式

與內建函式一樣，可在任何指令稿中以名稱呼叫程式庫函式：

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

結果會以值的形式回傳至工作區；函式顯示的圖表與場會出現在檢視區與次要顯示區中。

例如，對開啟中的零件進行靜力分析，只需幾行：

```
v = voxel_mesh(part(), 2);                   % 2 mm 立方體
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % 固定底部
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 頂部向下 500 N
r = static_voxel(v, 210000, 0.3, bc);       % 鋼材
```

`r` 保存位移、應力與反力；von Mises 應力會繪製在變形後的零件上。對於曲面零件，請使用 `tet_mesh` 與 `static_tet`，它們也可以對整個面施加載重與固定（`face_nodes`）。

:::note
程式庫函式以 CraftScript 撰寫，Lua 指令稿則像呼叫內建函式一樣，透過 `cs` 呼叫它們：`cs.static_tet(t, 200000, 0.3, bc)`（見 [Lua 指令稿](topic:craftscript-lua)）。每個函式只求解一種材料與一種載重工況；標頭會列出未涵蓋的其他項目。
:::
