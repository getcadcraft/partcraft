Бір құралдар жолы әр түрлі басқару жүйелері үшін әр түрлі жазылуы керек: жол нөмірлері бар немесе жоқ, `M6` немесе үзіліс, `G28` немесе `G53`, `M30` немесе `M2`. **Пост** — бұны қалай жазу керектігін айтатын қысқа мәтін. PartCraft-тың үш кірістірілген посты (Fanuc стиліндегі, GRBL және LinuxCNC) осы форматта жазылған, сондықтан өз постыңыз кейбіреуінің көшірмесінен басталуы мүмкін.

Кесу алдында машинаңыздың өз симуляторында тексеріңіз, және алдымен дайындаманың үстінде ауада іске қосыңыз. Кірістірілген посттар осы формат шыққанға дейін жазған нәрсесін дәл жазады (сынақтар олардың шығысын жүз мыңдаған бағдарламада байт-байт салыстырады), бірақ мұнда ештеңе сіздің машинада дәлелденбеген, ал сіз өзгерткен пост — сіздікі, оны дәлелдеу де сізге байланысты.

## Жасау

**Өндіру** бөлімінде, **Пост** астында:

- Кірістірілген басқару жүйесіндегі {{ui:Постты өңдеу…}} **өз көшірмеңізді** ашады. Өзіңіздің посттарыңыздың біреуінде ол сол постты ашады.
- {{ui:Жаңа пост…}} барлық оқиғалары бар шағын бос постты бастайды.
- {{ui:Постпроцессор файлын импорттау…}} `.cpost` мәтін файлын оқиды (редактордағы **Файл ретінде сақтау…** арқылы алынатын файл).

Редактор мәтінді, оның оқылатынын (және қай жол қате екенін) көрсететін жолды, сондай-ақ теріп жатқанда пост жазатын G-code-ты көрсетеді. **Алдын ала қарау** барлық оқиғаны іске қосатын шағын үлгі бағдарламаны немесе осы бөлшектің өз бағдарламасын таңдайды. {{ui:Сақтау}} постты бөлшек файлында сақтайды (20 постқа дейін) және оны басқару жүйесі ретінде таңдайды. Посттар бөлшекпен бірге жүреді; оны басқа бөлшекте пайдалану үшін файл ретінде сақтап, сол жерге импорттаңыз.

## Пост қандай көрінеді

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` басталатын жолдар мен бос жолдар елемейді. Басында баптаулар келеді; содан кейін әрбір оқиға үшін `on <event>` блогы, `end` арқылы жабылады. Қалдырылған оқиға ештеңе жазбайды.

| Баптау | Мағынасы |
|---|---|
| `post <id>` | Посттың идентификаторы: әріптер, сандар, `-` және `_` |
| `name <text>` | Басқару тізімінде көрсетілетін атау |
| `extension <ext>` | Файл кеңейтімі: nc, ngc, tap … |
| `line-numbers 10` / `off` | Әрбір `emit` жолында `N10`, `N20` … немесе ешқандай |
| `decimal-point yes` / `no` | `10` орнына `10.` (түсініктемелерде нүкте ешқашан болмайды) |
| `canned-cycles yes` / `no` | `no`: тесіктер олар білдіретін G0/G1 қозғалыстары ретінде жазылады |
| `modal <group> <words>` | Топ сөздері (`modal motion G0 G1 G2 G3`), тек өзгергенде ғана жазылады |

## Оқиғалар

Бағдарлама үшін олар мына ретпен іске қосылады: `start`; содан кейін әрбір операция үшін `operation`, `tool-change` (құрал өзгергенде), `spindle` (жылдамдық өзгергенде), `approach` (бірінші нүктеге дейінгі қозғалыс, бірінші жылдам қозғалыстан бұрын), `coolant-on`, содан кейін оның қозғалыстары `rapid`, `feed` және `arc` ретінде, ал әрбір дайын цикл `cycle-start` ретінде, әр тесікке бір `cycle-hole` және `cycle-end`; соңында `end`.

Әрбір оқиға өз түріндегі қозғалыстың айнымалыларын `{name}` түрінде пайдалана алады: бағдарламаның (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), дайындаманың (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), құралдың (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), операцияның (`op.name`, `op.type`), `rpm`, қозғалыс нүктесінің (`x`, `y`, `z`, `f`, және осьтердің бірі өзгергенде `true` болатын `moved`), доғалардың (`arc.g` 2 немесе 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) және тесіктердің (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`) айнымалылары. Редактордағы **Оқиғалар мен айнымалылар** тізімі қай оқиға нені көретінін көрсетеді. Оқуға және орнатуға болатын күй: `cool`, `offset`, және `at.x`, `at.y`, `at.z`, `at.f` (соңғы жазылған мәндер).

## Операторлар

| Оператор | Не істейді |
|---|---|
| `raw TEXT` | Жол теріліп тұрғандай дәл (нөмірсіз) |
| `comment TEXT` | `(TEXT)`, ASCII емес таңбалар мен жақшалар алынып тасталған |
| `emit WORD WORD …` | Сөздер жолы; бос шыққан сөздер алынып тасталады; сөз жоқ болса, жол жоқ |
| `word WORD …` | Құрылып жатқан жолға сөздер қосады; жалаң `emit` оны аяқтайды |
| `if EXPR` … `else` … `end` | Шарттар: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, әйтпесе b) |
| `for tool in tools` … `end` | Бағдарлама пайдаланатын әрбір құрал үшін бір рет |
| `set NAME EXPR` | Мәнді есте сақтайды (`set offset tool.number`) |
| `reset NAME …` | Модальді сөздерді ұмытады (топ, `Z` сияқты адрес әрпі немесе `at.z`) |
| `do rapid X Y Z` | Нүкте үшін `rapid` оқиғасын іске қосады |

Сөз — `{variable|filter}` ұяшықтары бар мәтін. Сүзгілер: `upper`, `lower`, `pad:N` (нөлмен толтыру), `cut:N` (алғашқы N таңба), `safe` (түсініктемеге қауіпсіз ASCII) және `int`. `~` аяқталатын сөз **модальді**: ол тек соңғы жазылғаннан өзгеше болғанда ғана жазылады (`G1~`, `X{x}~`). `~!` аяқталатын сөз әрқашан жазылады және есте сақталады. Айнымалы емес атау — қарапайым мәтін (`G81`, `mist`). Сандар 0.001 мм дейін дөңгелектенеді және соңғы нөлдерсіз жазылады.

## Пост не істей алмайды

Ол тек қозғалыстардың қалай жазылатынын шешеді, басқа ештеңе емес. Құралдар жолын өзгерте алмайды, операцияларды реттей алмайды, доғаны бөлмейді, осьті қоса алмайды, машинаңыздың жүріс аймағын немесе кинематикасын білмейді, немесе координаттарға арифметика жасай алмайды (`+` жоқ). Зондтау, құрал мерзімі және ішкі бағдарлама циклдері, 4-ші және 5-ші осьтің шығысы мен токарлық кодтар әзірге жасалмаған. Басқа бағдарламадан келген `.cps` стиліндегі пост файлы жүктелмейді: бұл басқа, қарапайым формат.
