Бір траекторияны әр басқару жүйесі үшін әртүрлі жазу керек: жол нөмірлері бар немесе жоқ, `M6` немесе кідіріс, `G28` немесе `G53`, `M30` немесе `M2`. **Пост** — осыны қалай жасау керектігін айтатын қысқа мәтін. PartCraft-тың үш кірістірілген посты (Fanuc түріндегі, GRBL және LinuxCNC) осы пішімде жазылған, сондықтан өз посты кірістірілген посттың бірінің көшірмесінен басталуы мүмкін.

Кесер алдында шығысты станоктың өз симуляторында тексеріңіз және оны алдымен дайындаманың үстінде ауада іске қосыңыз. Кірістірілген посттар бұл пішім пайда болғанға дейін жазған нәрселерін дәл жазады (сынақтар олардың шығысын жүздеген бағдарламада байт-байтпен салыстырады), бірақ мұнда ештеңе сіздің станокта дәлелденбеген, ал өзгерткен пост — сіздің дәлелдейтін нәрсеңіз.

## Жасау

Өндіру бөлімінде, **Пост** астында:

- Кірістірілген басқару жүйесінде {{ui:Постты өңдеу…}} **сіздің өз көшіріңізді** ашады. Сіздің өз посытыңызда ол сол постты ашады.
- {{ui:Жаңа пост…}} барлық оқиғасы бар шағын бос постан басталады.
- {{ui:Постпроцессор файлын импорттау…}} `.cpost` мәтін файлын оқиды (редактордағы **Файл ретінде сақтау…** арқылы алынған файл).

Редактор мәтінді көрсетеді, ол оқылатынын (және қай жол қате екенін) айтатын жолды, және теріп жатқанда пост жазатын G-code-ты көрсетеді. **Мысал бойынша алдын ала қарау** әр оқиғаны іске қосатын шағын үлгі бағдарламаны немесе осы бөлшектің өз бағдарламасын таңдайды. {{ui:Сақтау}} постты бөлшек файлында сақтайды (20 пост дейін) және оны басқару жүйесі ретінде таңдайды. Посттар бөлшекпен бірге жүреді; басқа бөлшекте пайдалану үшін оны файл ретінде сақтап, сонда импорттаңыз.

## Пост қандай көрінеді

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

`//` басталатын жолдар мен бос жолдар елемеленеді. Басында параметрлер тұрады; содан кейін әр оқиға үшін `on <event>` блогы, ол `end` арқылы жабылады. Жіберіп алған оқиға ештеңе жазбайды.

| Параметр | Мағынасы |
|---|---|
| `post <id>` | Постың идентификаторы: әріптер, сандар, `-` және `_` |
| `name <text>` | Басқару тізімінде не көрсетіледі |
| `extension <ext>` | Файл кеңейтуі: nc, ngc, tap … |
| `line-numbers 10` / `off` | Әр `emit` жолында `N10`, `N20` … немесе ешқайсысы жоқ |
| `decimal-point yes` / `no` | `10.` орнына `10` (түсініктемелерде нүкте ешқашан болмайды) |
| `canned-cycles yes` / `no` | `no`: тесіктер олар білдіретін G0/G1 қозғалыстары ретінде жазылады |
| `modal <group> <words>` | Топтың сөздері (`modal motion G0 G1 G2 G3`) тек өзгергенде жазылады |

## Оқиғалар

Бағдарлама үшін олар мына ретпен орындалады: `start`; содан кейін әр операция үшін `operation`, `tool-change` (құрал өзгергенде), `spindle` (жылдамдық өзгергенде), `approach` (бірінші нүктеге дейінгі қозғалыс, бірінші жедел жылжудың алдында), `coolant-on`, содан кейін оның қозғалыстары `rapid`, `feed` және `arc` ретінде, әр тұрақты цикл `cycle-start` ретінде, әр тесікке бір `cycle-hole` және `cycle-end`; соңында `end`.

Үш осьтен асатын нәрселер үшін қосымша оқиғалар (мұндай оқиғасы жоқ пост бағдарламаны қабылдамайды және жетіспейтін оқиғаның атын айтады):

| Оқиға | Қашан | Оның айнымалылары |
|---|---|---|
| `index` | Құрал бағыты соңғысынан өзгеше операцияның алдында, және айналмалы осьтері бар станокта бірінші операцияның алдында | `rot.a`, `rot.b`, `rot.c` (барар позициялар; станокта жоқ осьтер үшін бос), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | Кесу кезінде айналмалы осьтері қозғалатын операцияның қозғалыстары | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (беріліс кері уақыт болуы керек болғанда yes), `invf` (1/минут) |
| `rotary-end` | Осындай операциядан кейін | |
| `probe-move` | Зонд іске қосылғанда тоқтайтын қозғалыс | `x`, `y`, `z`, `f`, `probe.n` (1-ден 4-ке дейін), `probe.axis` (x, y немесе z), `probe.k` (1, 2 немесе 3) |
| `probe-set` | Бір зондтау циклінің жанасулардан кейін | `probe.kind` (`"z"`, `"x"`, `"y"` немесе `centre`), `probe.action` (`set` немесе `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | Токарлық станокта бұрандалау қозғалысы | `x`, `z`, `thread.lead` |

Әр оқиға үшін де: `kin` (none, a, b, ac, bc), `rotary` және `tcp` (yes немесе no, Орнату бетіндегі станоктан), `pivot.x`, `pivot.y`, `pivot.z`, операцияның `op.tilt` және `op.turn`, ал токарлық станокта `spin.mode` (css немесе rpm), `spin.css`, `spin.max` және `tool.nose`. Мәні бос болатын әріптік сөз, мысалы, A осі жоқ станокта `A{rot.a}`, жолдан шығып қалады. Х, у және z-мен мәтін ретінде тырнақшада салыстырыңыз (`if probe.kind == "z"`): тырнақсыз олар қозғалыстың координаталары.

Постың басындағы тағы екі жол оны токарлық пост етеді: `machine lathe` (ол тек X және Z жазады, және фрезерлеу жолдарын фрезерлеу посты қабылдамайтындай қабылдамайды) және `lathe-x diameter` немесе `lathe-x radius`.

Әр оқиға өз қозғалыс түрінің айнымалыларын қолдана алады, `{name}` түрінде жазылған: бағдарлама (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), дайындама (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), құрал (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), операция (`op.name`, `op.type`), `rpm`, қозғалыс нүктесі (`x`, `y`, `z`, `f`, және `moved`: осьтердің бірі өзгергенде true), доғалар (`arc.g` 2 немесе 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) және тесіктер (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Редактордағы **Оқиғалар мен айнымалылар** тізімі әр оқиғаның нені көретінін көрсетеді. Оқуға және орнатуға болатын күй: `cool`, `offset`, және `at.x`, `at.y`, `at.z`, `at.f` (соңғы жазылған мәндер).

## Операторлар

| Оператор | Не істейді |
|---|---|
| `raw TEXT` | Теріліп тұрғандай жол (жол нөмірісіз) |
| `comment TEXT` | `(TEXT)`, бейқұрал және жақшалар алынған |
| `emit WORD WORD …` | Сөздер жолы; бос шыққан сөздер алынып тасталады; сөз жоқ — жол жоқ |
| `word WORD …` | Құрылып жатқан жолға сөздер қосу; жалаң `emit` жолды аяқтайды |
| `if EXPR` … `else` … `end` | Шарттар: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, болмаса b) |
| `for tool in tools` … `end` | Бағдарлама қолданатын әр құрал үшін бір рет |
| `set NAME EXPR` | Мәнді есте сақтау (`set offset tool.number`) |
| `reset NAME …` | Модальды сөздерді ұмыту (топ, `Z` сияқты әріп мекенжайы немесе `at.z`) |
| `do rapid X Y Z` | Нүкте үшін `rapid` оқиғасын іске қосу |

Сөз — `{variable|filter}` тесіктері бар мәтін. Сүзгілер: `upper`, `lower`, `pad:N` (нөлмен толтыру), `cut:N` (алғашқы N таңба), `safe` (түсініктемеге қауіпсіз ASCII) және `int`. `~` аяқталатын сөз **модальды**: ол тек соңғы жазылғаннан өзгеше болғанда жазылады (`G1~`, `X{x}~`). `~!` аяқталатын сөз әр уақытта жазылады және есте сақталады. Айнымалы емес ат — қарапайым мәтін (`G81`, `mist`). Сандар 0,001 мм-ге дейін дөңгелектеніп, соңғы нөлсіз жазылады.

## Пост не істей алмайды

Ол тек қозғалыстардың қалай жазылатынын шешеді, басқаны емес. Ол траекторияны өзгерте алмайды, операцияларды реттей алмайды, доғаны бөле алмайды, ось қоса алмайды, сіздің станоктың жүрісі мен кинематикасын білмейді, немесе координаталармен арифметика жасай алмайды (`+` жоқ). Айналмалы позициялардың өзі посттан емес, Орнату бөлімінде сипатталған станоктан келеді: пост олардың белгісін немесе әріптерін өзгерте алады, кинематиканы емес. Құрал мерзімі мен ішкі бағдарлама циклдері жасалмаған. Басқа бағдарламадан келген `.cps` стиліндегі пост файлы жүктелмейді: бұл басқа, қарапайым пішім.
