Script жұмыс аймағындағы талдау бір-біріне айнымалылар беретін бірнеше қысқа скрипт. Осы мақсатқа жақын [кітапхана](topic:craftscript-library) функциясынан бастаңыз, көшірме жасап, өзгертіңіз; немесе төменде көрсетілгендей бастан құрыңыз.

## 1. Тор

```
model = part();                  % сіз модельдеп жатқан бөлшек, модель ретінде
m = tetmesh(model, 4);           % шамамен 4 мм-лік тетраэдрлер
show(m)
```

Алға жылжымас бұрын көріністегі торды тексеріңіз: {{key:F}} оны сыйғызады, **Көрсетілген** ішіндегі {{ui:көз}} белгішесі бөлшекті жасырады.

## 2. Құрастыру және шешу

Элемент циклін скриптте жазыңыз (ол оқулықтағыдай оқылады), ал ауыр бөліктерді кірістірілген функцияларға беріңіз: элемент матрицалары, үш еселі мәндерден сирек құрастыру және алдын ала шарттау (preconditioner) бар конъюгат градиент шешушісі. Кітапхана функциясы, мысалы `static_tet` (кітапханада бар болған кезде), көшіруге болатын толық мысал.

## 3. Нәтижені көрсету

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % әр түйінге бір мән
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- Легендадағы диапазонды теріп енгізуге немесе {{ui:Авто}} күйіне қайтаруға болады.
- Түйіндегі мәндерді оқу үшін торды басыңыз.
- Бірдей `'id'` бар график жаңартылады (қайта жасалмайды), сондықтан конвергенцияны бақылау үшін циклдің ішінде басып шығарыңыз және графиктеңіз.

## 4. Тексеріңіз

Белгілі нәрсемен салыстырыңыз: консольдің ұшының иілуі PL³/3EI формуласымен, тесігі бар пластина — кернеу концентрациясы коэффициентімен, реакциялар — жүктемелермен. Тексеруді жеке скрипт ретінде жазыңыз, сонда әр өзгерістен кейін қайта іске қосылады:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('ұшы %g мм, балка теориясы %g мм (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Сақтаңыз

- Әр қадам өз скрипт қойындысы бола алады: олар айнымалыларды бөліседі, сондықтан оларды кезекпен іске қосыңыз.
- Скрипттер бөлшекке сақталады. Нәтижелерді де сақтау үшін Айнымалылар қойындысында **Айнымалыларды бөлшекпен бірге сақтау** белгісін қойыңыз (32 МБ-қа дейін).
- Скрипт тобындағы {{ui:Сақтау}} скриптті бөлісу үшін жүктеп алады; {{ui:Ашу}} оны жүктеп салады.
