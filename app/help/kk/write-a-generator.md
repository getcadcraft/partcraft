Генератор — жоғарғы жағында бірнеше түсіндірме жолы бар қарапайым скрипт ([CraftScript](topic:craftscript), Lua немесе Python). PartCraft түсіндірмелерді оқып, пішінді жасайды; сіздің скриптіңіз кірістерді дайын орнатылған айнымалылар ретінде оқиды.

## Тақырып бөлімі

Осыларды түсіндірме жолдарына жазыңыз (CraftScript-те `%`, Lua-да `--`, Python-да `#`):

```
% @generator Жылу алмастырғыш
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Масса ағыны"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Бет"
% @input solid: = true
% @input note: = "мәтін"
```

Енгізу `атауы: өлшем бірлігі = әдепкі мән` түрінде жазылады, содан кейін қосымша түрде диапазон `[min .. max]` (сандар осы аралықта ұсталады), таңдаулар тізімі `{a, b, c}` және тырнақшадағы белгі беріледі. Өлшем бірлігі тек пішін үшін белгі ғана: **мән осы өлшем бірлігінде келеді**, сондықтан SI қажет ететін скрипт оны түрлендіреді; `to_si(value, 'kg/s', 'kg/s')` өлшем бірлігінің сіз ойлағанды білдіретінін де тексереді. Атау әріптерден, сандардан және астыңғы сызықтан тұрады; `body`, `sheet` және `problems` сақталған атаулар болып табылады.

## Скрипт қалдыратын нәрселер

| Айнымалы | Мазмұны |
|---|---|
| `body` | **Міндетті.** Беттік тор, әдетте `[body, info] = to_body(field, h)` арқылы. Жұмыс аяқталғанда ол түзетіліп, тексеріледі. |
| `sheet` | Міндетті емес. Әр өрісі сан немесе мәтін, немесе `value`, `unit`, `ref` және `note` өрістері бар құрылым. Ол деректер парағына айналады. |
| `problems` | Міндетті емес. `mfg_check(field, 'sls', struct(), h)` ұяшығы `problems` немесе өз жазбаларыңыз. Олар тексерулерге және Мәселелер тізіміне жіберіледі. |

## Толық шағын мысал

```
% Қабырғасы бар қуыс куб.
% @generator Қуыс куб
% @input side: mm = 12 [4 .. 40] "Жақ"
% @input wall: mm = 1.5 [0.5 .. 5] "Қабырға"
% @input h: mm = 0.5 [0.25 .. 2] "Воксель өлшемі"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'тордың көлемі');
```

Бұл тұйық қорап жасайды, ал тексеру оның ішкі тығыз жабық бөлігін ұнтақ процесі үшін қате ретінде көрсетеді. Воксель өлшемі `h` қалаған ең жұқа қабырғаның үштен бірінен аспасын: шамамен үш вокселден кіші қабырға сенімді емес.

## Өрістер

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (профильден айналу денесі), `tpms` (гироид, Шварц P және алмаз беттері; ұяшық өлшемі мен қабырғасы бөлшек бойында өзгеруі мүмкін), `lattice` және `lattice_beams`, `along` (жол бойымен дөңгелек арна), логикалық `field_union`, `field_intersect`, `field_subtract`, тегіс `field_blend`, сондай-ақ `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` нүктелердегі таңбалы қашықтықты береді (ішінде теріс), `field_voxel` шешушілерге вокселдер береді. [Өрістер](topic:fields) олардың не екенін түсіндіреді.

Білген жөн шектеулер: қабырға қалыңдығы ұяшықтың шамамен төрттен бірінен асса, арналар жабылады; үш вокселден жіңішке элемент қысылып қалуы мүмкін; `along` дөңгелек конустарды қосады, сондықтан радиус тез өзгерсе, дөңестік пайда болады (профиль үшін `field_revolve` қолданыңыз).

## Скриптіңізді генератор ретінде ашу

{{ui:Engineer}} жұмыс кеңістігінде {{ui:Open}} түймесін басып, файлды таңдаңыз. `@generator` немесе `@input` жолы жоқ скрипт қабылданбайды: орнатылатын ештеңе болмайды. Генератор осы браузерде сақталады (20-ға дейін), ал {{ui:Remove}} оны жояды. Онан жасалған денеде скрипттің көшірмесі болады, сондықтан бөлшек оған тәуелді емес.

Бір файлда бірнеше генератор болуы мүмкін: JSON бумасы `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
