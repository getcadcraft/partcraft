## Не істейсіз

Бөлшектің **барлық өлшемін бір рет** беріңіз: әр конфигурация үшін бір STEP, IFC және DWG файлы мен сурет, әрқайсысының не екенін көрсететін кесте және барлығын бір бетке орналастыратын кітапхана элементі.

Алдымен **конфигурациялары** бар бөлшек керек ([Конфигурациялар және жобалау кестелері](topic:design-tables) қараңыз). Мүмкіндікті өшіретін конфигурация, мысалы тесігі бар және жоқ пластина, өз вариантына айналады.

## Қадамдар

1. Бөлшекті ашыңыз. {{ui:Parameters}} қойындысынан **Конфигурациялар** бөлімін табыңыз.
2. {{ui:Вариант топтамасы…}} түймесін басыңыз.
3. Құрылатын конфигурацияларды (барлығы белгіленген) және жазылатын файлдарды белгілеңіз: STEP, IFC, DWG, алдын ала көрініс және кітапхана элементі.
4. {{ui:Топтаманы жасау}} түймесін басыңыз. Күй жолы варианттарды құрылған сайын санайды; бөлшек өзгермейді.
5. Бір zip жүктеліп алынады: `<part> variants.zip`.

## Zip ішінде не бар

| Файл | Ол не |
|---|---|
| `<name>.step` | Конфигурация STEP қатты денесі ретінде. |
| `<name>.ifc` | IFC4, құрылған денесі бар бір элемент және бөлшек параметрлері қасиеттер ретінде; мәні сол конфигурацияның өзінікі. |
| `<name>.dwg` | Алдыңғы, жоғарғы, оң және изометриялық көріністер толық өлшемде сызба парағы ретінде. |
| `<name>.svg` | Оның изометриялық сызықтық суреті. |
| `variants.csv`, `variants.json` | Параметрлер кестесі: әр варианттың идентификаторы, аты және әр параметрдің мәні, өшіретін мүмкіндіктері, файлдары, көлемі және өлшемі. |
| `<part>.item.json` | Бөлшек варианттарымен бірге бір кітапхана элементі ретінде (төмендегіні қараңыз). |
| `README.txt` | Не жасалды, төмендегі ескертулер және құрылмаған нәрселердің бәрі. |

Файлдар конфигурация атымен аталады. Құрылмайтын конфигурация (бұл мәндермен жасалмайтын мүмкіндік) файлдар мен кестеден шығарылады, README-де және zip сақталғаннан кейінгі хабарламада тізіледі; басқалары әлі жазылады.

## Білгеніңіз жақсы

- **STEP** құрастыруыңызда нақты ядро қосылған болса, дәл болады. Онсыз STEP факеттелген (жазық үшбұрыштар) болады, және README бұны айтады.
- **DWG** — 3D модель емес, сызба парағы. Оның сызықтары mesh-тен алынады, сондықтан қисық қыр көптеген қысқа сызықтардан тұрады.
- **Кітапхана элементінде** әр вариант үшін бір дене мен бір негіз бар, кітапхананың өз осьтерінде: Z жоғары, алдыңғы жағы −Y бағытында, ал енгізу нүктесі төменгі артқы жағының ортасында. Жоспар әр варианттың шекаралық тіктөртбұрышы. Элемент 8 MB-пен шектелген, сондықтан өте ауыр вариант өз өлшемінің қорабына айналады және README олардың санын көрсетеді.
- Бөлшектің белсенді конфигурациясы элементтің әдепкі варианты болады.
- Порттар (құбырлар мен ауа өткізгіштерге арналған қосылым нүктелері) PartCraft-тан орнатылмайды.

## Варианттарды кітапхана бетіне қою

Сайттағы **Кітапхана › Жүктеу** бөлімінде `<part>.item.json` жүктеңіз. Санатын, лицензиясын және өз несие жолын таңдаңыз, сонда ол варианттарымен бірге Кітапхана элементіне айналады. BimCraft-та оны орналастырғанда қай вариант керектігі сұралады, ал **Ауыстыру** басқаларын ұсынады. Келушілер опцияларды таңдайтын, 3D көретін және вариантты жүктейтін бет әзірге **қызметкерлерге арналған алдын ала көрініс**: ол әлі ашық емес.

## Пәрмен жолынан

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` конфигурацияларды атайды, `--formats` — `step`, `ifc`, `dwg`, `preview` кез келгені, `--no-item` кітапхана элементін шығарып тастайды. Ол қалта, zip немесе екеуін де жазады және вариант құрыла алмаса, 1 кодымен шығады. Қараңыз: [Скрипттер және пәрмен жолы](topic:scripts-and-cli).
