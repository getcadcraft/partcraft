Python — [Скрипт жұмыс аймағының](topic:craftscript) үшінші тілі. Редактордың үстіндегі тіл қорапшасынан **Python** таңдаңыз (`.py` файлы өздігінен Python-да ашылады). Python, Lua және CraftScript бірдей айнымалыларды және бірдей кірістірілген функцияларды бөліседі, сондықтан Python скрипті CraftScript скриптінің жасағанын пайдалана алады, және керісінше.

Бір кірудегі алғашқы Python іске қосылуы Python-ның өзін (CPython 3.14, шамамен 7 МБ) осы сайттан жүктейді; бұл бірнеше секунд алады. Python әлі {{ui:Желіден тыс сақтау}} ішінде емес: алдымен бір Python скриптін желіде іске қосыңыз.

## Python оқшауланған

Python скрипттері CraftScript және Lua скрипттері сияқты оқшауланған: олар тек бөлшекке, айнымалыларға және кірістірілген функцияларға жетеді, басқа ешнәрсеге жоқ. Әр іске қосу өз құм жәшігінде жаңа Python-да жұмыс істейді, жадта шағын файлдар ағашы бар (стандартты кітапханасы және іске қосу аяқталғаннан кейін жоғалатын `/tmp` қалтасы). Ол желіге, сіздің файлдарыңызға немесе беттің қалғанына браузерде де, командалық жолда да бірдей қол жеткізе алмайды. Басқа біреуден келген скрипт әлі де көп уақыт немесе жадты пайдалана алады: {{ui:Тоқтату}} оны аяқтайды.

## Негіздері

```
A = cs.magic(3)              # әр кірістірілген функция — cs.<атауы>
B = A @ A.T                  # @ — матрицалық көбейтінді, .T — транспонирлеу
C = A * 2 + 1                # + - * / ** элементтік, numpy сияқты
print(A[0, 1], A[-1, -1])    # 0-ден басталады; теріс сан соңынан санайды
row = A[1]                   # матрицадағы бір индекс: жол
big = A[A > 4]               # логикалық маска элементтерді таңдайды
A[0, 0] = -5                 # массивке жазу
V, D = cs.call('eig', 2, A)  # бірнеше нәтиже: cs.call(атауы, неше, …)
```

- 1 × 1 массив қарапайым сан ретінде келеді; басқа массивтер, сирек матрицалар, торлар, өрістер және модельдер — **Мәндер**.
- Мәннің `shape` (кортеж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (оның жолдары) және бір элемент үшін `float()`, `int()` және `bool()` бар.
- Салыстырулар (`<`, `==`, …) numpy сияқты элементтік: логикалық Мән береді.
- Кірістірілген функцияға берілген сандар тізімі массивке айналады: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` матрица жасайды.
- dict құрылымға (struct), аралас заттардың тізімі ұяшыққа айналады, және кері.

Скрипт жасаған әр ғаламдық айнымалы (сан, Мән, dict, тізім…) іске қосу аяқталғанда, тіпті қатеден кейін де **Айнымалылар** қойындысына түседі. `_` басталатын атаулар, функциялар, кластар және модульдер Python-да қалады. `ws.name` айнымалыны тікелей оқиды немесе орнатады, `ws_names()` оларды тізімдейді.

`print(…)` консольге жазады. `display(…)` (немесе `cs.display`) CraftScript-тегідей торды, өрісті немесе графикті көрсетеді.

## Талдау кітапханасын шақыру

Кітапхана функциялары кірістірілгендер сияқты шақырылады: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Атауды скриптте дәл осылай жазыңыз: PartCraft скрипт пайдаланатын кітапхана функцияларын оны іске қосар алдында табады.

## Әлі жоқ

- numpy, scipy және басқа пакеттер: тек Python-ның өз стандартты кітапханасы (`math`, `json`, `itertools`, `decimal`, `statistics`…) бар, оның терезе, терминал және дерекқор бөліктерінсіз (`tkinter`, `curses`, `sqlite3`).
- Сокеттер және сыртқа шығатын басқа нәрсе: Python-да бұл жерде желі жоқ.
- `time.sleep` бірден қайтады.
- Редактордағы бүктеу, және Python функциясын CraftScript скриптінен шақыру.
- Іске қосу әр 1000 жолда нұсқаулар бюджетін және Тоқтатуды тексереді; бір кірістірілген функцияның ішіндегі ұзақ есептеу алдымен аяқталады.
