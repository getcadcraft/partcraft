Lua — [Скрипт жұмыс аймағының](topic:craftscript) екінші тілі. Редактордың үстіндегі тіл қорапшасынан **Lua** таңдаңыз (`.lua` файлы өздігінен Lua-да ашылады). Lua және CraftScript бірдей айнымалыларды және бірдей кірістірілген функцияларды бөліседі, сондықтан Lua скрипті CraftScript скриптінің жасағанын пайдалана алады, және керісінше.

## Негіздері

```
-- әр кірістірілген функция cs кестесінде
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-ден басталады, CraftScript сияқты
print(K(1, 1), #K)             -- элемент; элементтер саны

-- жұмыс кеңістігі: әр скрипт көретін бірдей айнымалылар
ws.total = K(1, 1) * 2
print(ws.total)

-- бір функциядан бірнеше нәтиже
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` кез келген кірістірілген функцияны шақырады және оның бірінші нәтижесін қайтарады; `cs.call(name, n, …)` `n` нәтиже қайтарады.
- `cs.tensor({1, 2, 3})` жол жасайды, `cs.tensor({{1, 2}, {3, 4}})` матрица жасайды.
- Массивтер, сирек матрицалар, торлар және өрістер — әдістері бар мәндер: `t(i, j)` немесе `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (транспонирлеу), `t:totable()`. `+ - * / ^` CraftScript-тегідей мағына береді (`*` — матрицалық көбейтінді); `t:times(u)` элементтен элементке көбейтеді.
- 1×1 массив қарапайым Lua санына айналып келеді.
- `ws.name` ортақ жұмыс кеңістігін оқиды және жазады. Скрипт аяқталғанда қалдырған ғаламдық айнымалылар да сонда түседі.
- `print(…)` консольге жазады; `cs.show(f)`, `cs.plot(y)` және басқа көрсету функциялары CraftScript-тегідей жұмыс істейді.

## Талдау кітапханасын шақыру

Талдау кітапханасының функциялары (Кітапхана қойындысы) және бөлшектің өз скрипттері анықтаған CraftScript функциялары да `cs` арқылы қолжетімді:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- екі шығыс
```

Олар скрипт басталғанға дейін табылады, сондықтан атауды скриптте жазыңыз: `cs.static_tet(` немесе `cs.call('static_tet', …)`. Скрипт жұмыс істеп тұрғанда құрастырылған атау тек кірістірілген функцияларға жетеді. `cs.struct({ … })` арқылы жасалған структура — CraftScript структурасы, ал Lua тізімі (`{ cs.struct(…), … }`) — ұяшық, кітапхана параметрлерінің қажет ететін түрі. Кітапхана функциясының ішінде бірдеңе дұрыс болмаса, хабарлама функцияны және оның жолын атайды, және сіздің оны шақырған жолыңызға көрсетеді.

## Өшірілгендер

Скрипттер файлдарға, желіге немесе бетке қол жеткізе алмайды: `io`, `os` (сағаттан басқа), `require`, `dofile`, `loadfile` және `debug` алынып тасталған. Деректерді енгізу үшін Script жұмыс аймағының Ашу мүмкіндігі мен айнымалыларын пайдаланыңыз. Қадам бюджеті мен Тоқтату CraftScript-тегідей жұмыс істейді.
