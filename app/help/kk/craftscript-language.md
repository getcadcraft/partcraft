CraftScript — MATLAB-ға ұқсап оқылатындай жазылған матрицалық тіл, сондықтан классикалық сандық кодтардың көпшілігі (мысалы, 88 жолдық топологиялық оңтайландыру коды) аз ғана өзгерістермен жұмыс істейді. Ол [Скрипт жұмыс аймағында](topic:craftscript) және командалық жолдан іске қосылады.

## Мәндер

| Түрі | Мысал | Ескертпе |
|---|---|---|
| Сан, массив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Әр сан — массив (1×1). Массивтер бағандап сақталады, 8 өлшемге дейін |
| Логикалық | `A > 2`, `true` | True/false массивтері; индекс ретінде пайдаланылады |
| Мәтін | `'beam'`, `"beam"` | |
| Сирек матрица | `sparse(i, j, v, n, n)` | Қаттылық матрицалары үшін |
| Тор, өріс, модель | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` салатын нәрселер |
| Структура | `s.E = 210e3` | Аталған өрістер |
| Ұяшық | `c = {1, 'two', [3 4]}` | Кез келген мәндер тізімі |
| Функция тұтқасы | `f = @(x) x.^2` | |

## Массивтер және индекстеу

- Диапазондар: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индекстеу 1-ден басталады: `A(2, 3)`, `v(end)`, `A(:, 1)` (бүкіл баған), `A(:)` (бәрі бір бағанда), `v(v > 0)` (логикалық индекстеу).
- Соңынан тысқа жазу MATLAB-дағыдай массивті ұзартады: `v(10) = 1`.

## Операторлар

- `+ - * / \ ^` — матрицалық амалдар (`A \ b` теңдеуді шешеді); `.* ./ .^` элементтен элементке жұмыс істейді. `'` транспонирлейді.
- Салыстырулар `== ~= < <= > >=`; логика `& | ~` (элементтен элементке) және `&& ||` (қысқартылған).

## Басқару ағымы және функциялар

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функциялар скрипттегі командалардан кейін немесе функция атымен аталған өз скрипт бетінде жазылады:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Атау мына ретпен ізделеді: айнымалы, осы бөлшектегі сол атпен аталған скрипт, кітапхана функциясы, кірістірілген функция.

## Echo, пікірлер, шығару

- `;`-сыз оператор өз мәнін шығарады; `;` оны үнсіз қалдырады.
- `%` пікірді бастайды; жеке жолдағы `%{` және `%}` олардың арасындағы жолдарды пікірге айналдырады.
- `disp(x)`, `fprintf('%g\n', x)` және `display(x)` консольге шығарады.

## Қателер мен шектеулер

- Қателер не болғанын қарапайым сөздермен айтады және жолды (және функция шақыру тізбегін) көрсетеді.
- Әр іске қосудың қадам бюджеті бар (панельдегі **Іске қосу параметрлері**); шексіз цикл хабарламамен тоқтайды, немесе {{ui:Тоқтату}} басыңыз.
- Әр массив 134 миллионға дейін мән ұстай алады.

## MATLAB-тан айырмашылығы

- Сызу командалары опцияларын шақыруға жазады: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` және ұқсас командалар қабылданады, бірақ ештеңе істемейді.
- `input` және `keyboard` қолдау көрсетілмейді: скрипт сұрақ қою үшін тоқтай алмайды.
- Құралдар жинақтары (toolbox) жоқ; [талдау кітапханасы](topic:craftscript-library) мен кірістірілген функциялар — бар нәрсе осы.
