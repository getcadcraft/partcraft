{{ui:Animation}} အပိုင်းကို ဖွင့်ပါ:

- {{ui:Key everything}}၊ {{ui:Key the selected parts}} နှင့် {{ui:Key the camera}} သည် လက်ရှိအချိန်တွင် အရာများ ယခု ဘယ်လိုရှိသည်ကို သိမ်းသည်: အစိတ်အပိုင်းတစ်ခုစီ၏ နေရာ၊ ပြနေခြင်း ရှိမရှိ၊ အလင်းပြတ်မှုနှင့် အရောင်၊ နှင့် ကင်မရာ။ မြင်ကွင်းကို ပြောင်းပါ၊ {{ui:Time}} slider ကို ရွှေ့ပါ၊ ထို့နောက် ထပ် key လုပ်ပါ: လှုပ်ရှားမှုသည် key တစ်ခုမှ နောက်တစ်ခုသို့ သွားသည်။
- {{ui:Record the exploded view}} သည် scene ၏ exploded view အဆင့်တစ်ခုလျှင် key တစ်ခုကို ထည့်သည်၊ အဆင့်တစ်ခုလျှင် စက္ကန့်တစ်ခု၊ ရှိပြီးသားအရာများ၏ နောက်တွင်။
- {{ui:Views as camera stops}} သည် view များကို အစဉ်လိုက် ဖွင့်သည်: ကင်မရာသည် view တစ်ခုစီသို့ ရွှေ့ပြီး ထိုနေရာတွင် ခဏရပ်ကာ အစိတ်အပိုင်းများသည် view ၏ အသွင်အပြင်ကို ယူသည်။

{{ui:Play}}၊ {{ui:Pause}}၊ {{ui:Stop}} နှင့် {{ui:Loop}} က view တွင် ဖွင့်သည်; အစိတ်အပိုင်းနှင့် ကင်မရာတိုင်း၏ key များကို စာရင်းပြုစုထားသည် (key တစ်ခုကို နှိပ်ပါ၊ ထို့အချိန်သို့ သွားသည်)။ {{ui:Save video}} က WebM သို့မဟုတ် MP4 (browser က encode လုပ်နိုင်ရာတွင်) သို့မဟုတ် PNG ပုံများကို ZIP တွင် ရေးသည်။

လှုပ်ရှားမှုကို ModelCraft ၏ Animate workspace သုံးသော ပုံစံအတိုင်း သိမ်းထားသည်။ ၎င်း၏ curve editor နှင့် clip များသည် ယခုအချိန်တွင် ModelCraft ၏ဖြစ်သည်။
