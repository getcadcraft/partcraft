:::note
**ဤဗားရှင်းတွင် ယခုမတည်ဆောက်ရသေးပါ။** Gordon surface သည် တိကျသော geometry kernel လိုအပ်ပြီး ဤ PartCraft ဗားရှင်းတွင် ထိုအရာ မရှိပါ: ၎င်းသည် အစိတ်အပိုင်းတိုင်းကို mesh kernel ဖြင့်သာ တည်ဆောက်သည်။ [ယခုမတည်ဆောက်ရသေးသည်များ](topic:not-built-yet) က အစားထိုး ဘာလုပ်ရမည်ကို ပြောသည်။ ဤစာမျက်နှာ၏ ကျန်အပိုင်းသည် တိကျသော kernel ဖြင့် ၎င်း မည်သို့ အလုပ်လုပ်သည်ကို ဖော်ပြသည်။
:::

**Gordon surface** သည် curve ကွန်ရက်၏ ကွေးတိုင်းကို ဖြတ်သန်းသော မျက်နှာပြင်တစ်ခုတည်း ဖြစ်သည်: တစ်ဘက်သို့ သွားသော **profile** အစုတစ်ခုနှင့် အခြားဘက်သို့ သွားသော **guide** အစုတစ်ခု၊ ကွန်ရက်၏ ချည်မျှင်များကဲ့သို့ ဖြတ်ကျော်သည်။ ၎င်းသည် သင် တိုက်ရိုက်ထိန်းချုပ်သော section ကွေးအနည်းငယ်မှ hull၊ fender သို့မဟုတ် handle ကို ပုံဖော်ရန် နည်းလမ်းဖြစ်သည်။ ၎င်းသည် **exact kernel** လိုအပ်သည် (see [mesh kernel](topic:solid-kernels))။

## ကွန်ရက်ကို ဆွဲခြင်း

1. **profile** များကို ဆွဲပါ: ဘေးချင်းကပ်လျက် ဆွဲသော ကွေးနှစ်ခု သို့မဟုတ် ပိုများ၊ ဥပမာ ပြားပါလယ်များပေါ်ရှိ section များ။ မျဉ်း၊ arc၊ စက်ဝိုင်းနှင့် spline အားလုံး အလုပ်လုပ်သည်၊ အဆုံးချင်းဆက်ထားသော ကွေးများ၏ ကွင်းတစ်ခုသည် ကွေးတစ်ခုအဖြစ် ရေတွက်သည်။
2. **guide** များကို ဆွဲပါ: profile များကို ဖြတ်ကျော်သော ကွေးနှစ်ခု သို့မဟုတ် ပိုများ။ guide တစ်ခုစီသည် profile တစ်ခုစီကို တစ်ကြိမ်ဖြတ်ရမည်၊ profile တစ်ခုစီသည် guide တစ်ခုစီကို တစ်ကြိမ်ဖြတ်ရမည်။
3. ကွေးများ တကယ်ဆုံအောင် လုပ်ပါ။ guide ၏ sketch ကို ကွေးသည် profile များ၏ အမှတ်များကို ဖြတ်သွားအောင် ဆွဲပါ (projected အမှတ်များသို့ snap လုပ်ပါ သို့မဟုတ် ကိုဩဒိနိတ်များ ရိုက်ထည့်ပါ)။ ကွန်ရက်သည် **Tolerance** (အစပိုင်း 0.01 mm) အထိ ကွာဟချက်ကို လက်ခံသည်။

sketch တစ်ခုတွင် ကွေးများ အများအပြား ရှိနိုင်သည်: ခွဲထားသော ကွင်းတစ်ခုစီသည် ကိုယ်ပိုင်ကွေး ဖြစ်သည်။ ထို့ကြောင့် ဥပမာ သင်သည် guide အားလုံးကို အပေါ်ပြားပေါ်ရှိ sketch တစ်ခုတည်းတွင် ဆွဲနိုင်သည်။


## မျက်နှာပြင်ကို ဖန်တီးခြင်း

1. Features အုပ်စုရှိ {{ui:More}} ကို ရွေးပြီး ထို့နောက် {{ui:Gordon surface}} ကို ရွေးပါ။
2. PartCraft က မည်သူမှ မသုံးသေးသော sketch များကို ယူသည်: ပထမတစ်ခုနှင့် ပြိုင်သော ပြားများရှိသော sketch များက **profile** ဖြစ်လာပြီး ကျန်တာများက **guide** ဖြစ်သည်။ ညာဘက်ရှိ စာရင်းကို စစ်ဆေး၍ sketch တစ်ခုစီကို **Profiles**၊ **Guides** သို့မဟုတ် **Not used** သို့ သတ်မှတ်ပါ။
3. အစိတ်အပိုင်း၏ အစွန်းများကို သုံးလိုလျှင် **Pick edges as profiles** (သို့မဟုတ် **as guides**) ကို နှိပ်ပါ၊ view တွင် အစွန်းများကို နှိပ်ပါ၊ ထို့နောက် Esc ကို နှိပ်ပါ။

ရလဒ်သည် **surface body** ဖြစ်သည်။ {{ui:Thicken}} က ၎င်းကို solid အဖြစ်ပြောင်းသည်၊ {{ui:Stitch}} က အခြားမျက်နှာပြင်များနှင့် ချုပ်သည်၊ နှင့် {{ui:Trim surface}} က ဖြတ်သည်။

### Solid အဖြစ် ပိတ်ခြင်း

profile များသည် ပိတ်ထားသော ကွေးများ (စက်ဝိုင်း၊ ပိတ်ထားသော spline၊ ပိတ်ထားသော ကွင်းများ) ဖြစ်ပြီး ပထမနှင့် နောက်ဆုံး profile တစ်ခုစီသည် ပြားတစ်ခုတွင် ပြားအောင် ရှိနေလျှင် **Close to a solid** ကို ရွေးပါ။ အဆုံးများကို ပြားမျက်နှာများဖြင့် ဖုံးပြီး ပိတ်သော ပုံသဏ္ဌာန်သည် အခြားအင်္ဂါရပ်ကဲ့သို့ ပေါင်း၊ ဖြတ်၊ ကြားဖြတ် သို့မဟုတ် body အသစ် ဖြစ်လာသည်။ guide ကွေးများကို လိုက်သော loft ကို ဤနည်းဖြင့် ပြုလုပ်သည်။ ပိတ်ထားသော guide များနှင့်လည်း အလုပ်လုပ်သည်။

## အစွန်းတစ်လျှောက် ပြားတစ်ခုနှင့် ထိတွေ့ခြင်း

Gordon surface သည် ၎င်း၏ ကွေးများကို ဖြတ်သော်လည်း ၎င်းတစ်ခုတည်းတွင် ထိတွေ့သော အရာ၏ စောက်ဆင်းမှုနှင့် မကိုက်ညီပါ။ ၎င်းကို အစွန်းတစ်ခုမှ ပြားတစ်ခုနှင့် **tangent** (G1) ဖြစ်ရန် ထွက်စေလိုလျှင်၊ ဥပမာ ထင်ဟပ်ပြား၊ ထင်ဟပ်မိတ္တူ ကြိတ်မိအောင် ပေါင်းရန်၊ သို့မဟုတ် ၎င်း ကြီးထွားရာ ပြားမျက်နှာ:

1. Gordon အင်္ဂါရပ်ကို ရွေးပါ။ **Tangent to** အောက်တွင် {{ui:Add a plane…}} ရှိ ပြားတစ်ခုကို ရွေးပါ (Front၊ Top၊ Right သို့မဟုတ် reference plane)၊ သို့မဟုတ် view တွင် ပြားမျက်နှာတစ်ခုကို ရွေးပြီး {{ui:Add the picked flat face}} ကို နှိပ်ပါ။
2. PartCraft က ထိုပြားတွင်ရှိသော ကွန်ရက်၏ ကန့်သတ်ကွေးကို ရှာပြီး မျက်နှာပြင်သည် ထိုပြားနှင့် tangent ဖြစ်အောင် ထွက်သည်။

ပြားတစ်ခုတွင် ကန့်သတ်ကွေး နှစ်ခု ရှိလျှင် (ပြားဆွဲပြီး နှစ်ဖက်စလုံးမှ ကြမ်းပြင်) ၎င်းကို နှစ်ကြိမ် ထည့်ပါ: မိတ္တူတစ်ခုစီသည် နောက်ကွေးကို ယူသည်။ အစွန်းတစ်ခုလျှင် ပြား လေးခုအထိ။

အစီရင်ခံစာသည် ကွေးမည်သည့်အရာ၏ အစွန်းတွင် ပြားကို tangent လုပ်ခဲ့သလဲ၊ နှင့် မျက်နှာပြင်က ယခင် ထိုပြားနှင့် တွေ့သော အမြင့်ဆုံး ထောင့်ကို ပြောသည်။ ထိုကွေးအစွန်းကို ပြားနှင့် tangent ဖြစ်စေသော guide များကို တိကျစွာ လိုက်သည်။ အစွန်းမှ တက်သွားသော guide များကို အစွန်းအနီး ကျဉ်းသော ဇုန်တွင် ကွေးစေပြီး အစီရင်ခံစာ၏ "follows every curve within" တန်ဖိုးက မည်မျှ ဖြစ်သည်ကို ပြသည်: တိကျသော ကိုက်ညီမှုအတွက် guide များကို အစွန်းမှ ပြားစွာ ထွက်စေရန် ဆွဲပါ။

## တိကျသည်နှင့် ကိုက်ညီအောင် လုပ်ထားသည်များ

panel က ဤတို့အနက် မည်သည့်အရာ သက်ဆိုင်သည်ကို နှင့် မျက်နှာပြင်က သင့်ကွေးများနှင့် မည်မျှ ထွက်သွားသည်ကို ပြောသည်။

- **Exact**: ကွေးတိုင်းသည် polynomial ဖြစ်သည် (မျဉ်းများ၊ spline များနှင့် ၎င်းတို့၏ ကွင်းများ) နှင့် guide များသည် profile အားလုံးကို တူညီသော parameter များတွင် ဖြတ်သည်ဆိုလျှင် မျက်နှာပြင်သည် ထိုကွေးများ၏ တိကျသော Gordon surface ဖြစ်သည်။ bicubic မျက်နှာပြင်မှ ဖြတ်ယူသော iso ကွေး ကွန်ရက်သည် ထိုမျက်နှာပြင်ကို ပြန်ပေးသည်၊ မျဉ်းဖြောင့် လေးခုသည် ပြား သို့မဟုတ် ကွေးနေသော (bilinear) patch ကို ပေးသည်။
- **Fitted**: arc၊ စက်ဝိုင်းနှင့် အစိတ်အပိုင်း၏ အစွန်းများသည် polynomial မဟုတ်ပါ၊ မတူညီသော parameter တွင် ဖြတ်သော ကွေးများကို ဖြတ်မှတ်ချိန်ညှိရမည် ထို့ကြောင့် ဖြတ်မှတ်များ တန်းစီသည်။ ထိုကွေးများကို ကွန်ရက်အရွယ်အစား၏ တစ်ဒသမ ဆယ်သန်းတစ်ခုအတွင်း (100 mm အစိတ်အပိုင်းအတွက် 0.00001 mm ခန့်) cubic B-spline ဖြင့် ကိုက်ညီအောင် လုပ်ထားသည်။ arc နှင့် မျဉ်းများဖြင့် ပြုလုပ်ထားသော cylinder patch သည် အမှန်တကယ် cylinder မှ 0.00001 mm အတွင်း ရှိသည်။

ကွေးများကြား မျက်နှာပြင်သည် နည်းလမ်းက ပေးသည်ဖြစ်သည်: profile များကို ဖြန့်ကျက်ပြီး guide များကိုလည်း ဖြန့်ကျက်ကာ ၎င်းတို့၏ ဖြတ်မှတ်အမှတ်များ၏ ဖြန့်ကျက်မှုကို နုတ်သည်။ ကွေးတစ်ခုတွင် ထောင့်ထက်ထက်မရှိလျှင် ဘယ်နေရာမဆို ချောမွေ့သည်။ Gordon မျက်နှာပြင် နှစ်ခုသည် ကွေးနယ်နိမိတ်တစ်ခုကို မျှဝေလျှင် ၎င်းတို့သည် အစွန်းချင်းဆက် (G0) ဖြစ်သည်၊ tangent မဟုတ်ပါ။

## ကန့်သတ်ချက်များ

- ကွန်ရက်တစ်ခုလျှင် B-spline မျက်နှာ တစ်ခု: ပတ်ဝန်းကျင် မျက်နှာပြင်များနှင့် G1 သို့မဟုတ် G2 tangency မရှိ။
- ပိတ်ထားသော ကွန်ရက်၏ seam သည် ပထမ guide တွင် အစွန်းချင်းဆက်ထားသော်လည်း tangent မဟုတ်။
- Loft အင်္ဂါရပ်တွင် guide rail မရှိ; ယင်းအစား solid အဖြစ် ပိတ်ထားသော Gordon surface ကို သုံးပါ။
- အလွန်ကွေးကောက်သော ကွေးများ၊ သို့မဟုတ် ကွေးတစ်ခုတွင် အခြားကွေးနှင့် နှိုင်းယှဉ်လျှင် မညီညာစွာ ခွာသော ဖြတ်မှတ်များ၊ ကိုက်ညီရန် အမှတ်များ အလွန်များ လိုအပ်နိုင်သည်; ထိုအခါ အင်္ဂါရပ်က ထိုအကြောင်း ပြောသည်။
