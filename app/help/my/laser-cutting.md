{{ui:Laser}} panel သည် ပုံဆွဲ၏ layer များကို GRBL ဖြင့် အလုပ်လုပ်သော လေဆာ (hobby နှင့် အသေးစား shop အများစုရှိ diode နှင့် CO2 controller) အတွက် program အဖြစ် ပြောင်းပေးသည်။ PartCraft တွင် {{ui:Export}} › {{ui:Laser program…}} ကို ရွေး၍ ထို့နောက် {{ui:Add outlines from a DXF…}} ကို ရွေးပါ: outline များနှင့် အပေါက်များသည် CUT layer ဖြင့် ဝင်လာမည်။ sheet metal part များ၏ flat pattern (bend လိုင်းများ BEND layer တွင်ရှိသည်) သည် exact kernel လိုအပ်ပြီး ဤဗားရှင်းတွင် မရှိပါ။ ဆက်တင်များကို part သို့မဟုတ် assembly ဖိုင်တွင် သိမ်းထားသည်။

:::warning
ဆက်တင်တိုင်းကို scrap ပေါ်တွင် အရင်စမ်းပါ၊ သင့်လေဆာနှင့် ကိုက်ညီသော မျက်ကာကို ဝတ်ပါ၊ ရှိလျှင် အဖုံးကို ပိတ်ထားပါ၊ လည်ပတ်နေသော လေဆာကို တစ်ယောက်တည်း ဘယ်တော့မှ မထားခဲ့ပါနှင့်။ layer တစ်ခု၏ စတင်တန်ဖိုးများသည် နေရာယူထားသော placeholder များဖြစ်ပြီး မည်သည့်ပစ္စည်းအတွက်မဆို အကြံပြုချက်မဟုတ်ပါ။
:::

## layer တစ်ခုစီ ဘာလုပ်မည်ကို ရွေးပါ

ပုံဆွဲ၏ layer တစ်ခုစီသည် row တစ်ခု ဖြစ်သည်။ {{ui:Does}} က ၎င်းကို **Cut**၊ **Score**၊ **Engrave lines**၊ **Fill shapes**၊ **Engrave picture** သို့မဟုတ် **Not sent** အဖြစ် သတ်မှတ်ပြီး {{ui:Power %}}၊ {{ui:Speed mm/min}} နှင့် {{ui:Passes}} အရေအတွက် တို့ဖြင့် သတ်မှတ်သည်။

- **Fill** သည် ပိတ်ထားသော ပုံသဏ္ဍာန်များ၏ အတွင်းပိုင်းကို မျဉ်းများဖြင့် မီးလောင်စေသည်။ မျဉ်းကြား {{ui:Line spacing}} ဖြင့်၊ {{ui:Angle}} ဖြင့်၊ နှစ်ဘက်လုံး သို့မဟုတ် တစ်ဘက်တည်း၊ overscan ပါဝင်၍ လေဆာ ဖွင့်ချိန်တွင် head သည် အရှိန်ပြည့်ဖြစ်နေစေသည်။ cross-hatch သည် 90° တွင် ဒုတိယ pass တစ်ခု ထပ်ထည့်သည်။ အပေါက်ပါသော ပုံသဏ္ဍာန်သည် အပေါက်နေရာတွင် ဖွင့်ထားသည်။
- **Engrave picture** သည် ပုံကို အစက်များအဖြစ် ပြောင်းသည် (Floyd–Steinberg၊ Atkinson၊ ordered၊ သို့မဟုတ် threshold ဖြင့် အမည်း-အဖြူ သက်သက်)၊ သို့မဟုတ် *Grey levels* ဖြင့် ပြောင်းလဲနိုင်သော power အဖြစ် ပြောင်းသည်။
- အစီအစဉ်: ပုံများနှင့် fill များက ဦးစွာ၊ ထို့နောက် မျဉ်းထွင်းခြင်း၊ ထို့နောက် score များ၊ ထို့နောက် cut များ၊ ထို့ကြောင့် ဖြတ်ထုတ်ပြီးသား အစိတ်အပိုင်းသည် ထွင်းနေစဉ် မရွေ့ပါ။ layer တစ်ခုအတွင်း လမ်းကြောင်းများသည် **inside-first** (အပေါက်ကို ၎င်းဝင်နေသော ပြားမတိုင်မီ) ဖြင့် ပြေးပြီး နီးသည့်အတိုင်း ဆက်သွားသည်။

## Preview ကြည့်ပြီး သိမ်းပါ

Preview တွင် head ၏ လှုပ်ရှားမှုကို ဆွဲပြသည်: မီးလောင်သော မျဉ်းများကို အရောင်ဖြင့်၊ အမြန် လှုပ်ရှားမှုများကို မီးခိုးရောင်ဖြင့်၊ မီးလောင်သည့် အရာအားလုံးကို အစိမ်းရောင် box ဖြင့် ပြသည်။ အောက်တွင် အရွယ်အစား၊ မီးလောင်သော အရှည်နှင့် အချိန်ခန့်မှန်းချက် (acceleration မပါဘဲ၊ အမှန်စက်သည် ပိုကြာသည်) ပြသည်။ {{ui:Save G-code…}} က GRBL laser-mode G-code ကို ရေးသည်: `$32=1`၊ S တန်ဖိုးများဖြင့် `M4` (သို့မဟုတ် `M3`)၊ `G0` နှင့် `G1` လှုပ်ရှားမှုများ၊ အဆုံးတွင် `M5`။ ပုံဆွဲ၏ မူလအချက်ကို ရွေးချယ်ခြင်း မရှိပါက X0 Y0 သည် job ၏ ဘယ်အောက်ထောင့် ဖြစ်သည်: သင့်စက်၏ work zero ကို ထိုနေရာတွင် သတ်မှတ်ပါ။ G-code သည် GRBL ၏ မှတ်တမ်းတင်ထားသော laser mode ကို လိုက်နာသည်၊ သို့သော် အမှန်လေဆာတွင် မစမ်းရသေးပါ။

## browser မှ ပို့ရန်

Chrome နှင့် Edge တွင် {{ui:Connect…}} က လေဆာ၏ USB port ကို ရွေးရန် မေးသည်။ ခလုတ်တစ်ခု မနှိပ်မချင်း ဘာမှ ချိတ်ဆက်ခြင်း သို့မဟုတ် ပို့ခြင်း မရှိပါ။ ပထမဦးဆုံး {{ui:Frame the job}} ကို နှိပ်ပါ: head သည် လေဆာ **ပိတ်ထား၍** (သို့မဟုတ် pointer အတွက် သင်သတ်မှတ်ထားသော အနည်းဆုံး power ဖြင့်) job ၏ အကွက်ကို ရေးဆွဲသဖြင့် မည်သည့်နေရာ မီးလောင်မည်ကို မြင်နိုင်သည်။ ထို့နောက်မှသာ {{ui:Send job}} ဖွင့်လာပြီး သင်တစ်ခုခု ပြောင်းလျှင် ပြန်ပိတ်သွားသည်။ {{ui:Pause}} က head ကို ဖိထားသည်၊ {{ui:Stop}} က ၎င်းကို ဖိထားပြီး controller ကို ပြန်သတ်မှတ်သည် (လေဆာ ပိတ်သွားသည်) နှင့် `M5` ပို့သည်။ Web Serial မရှိသော နေရာများ (Firefox၊ Safari နှင့် CadCraft Studio၊ ၎င်း၏ web view တွင် မရှိသေး) တွင် G-code ကို သိမ်းပြီး သင့်လေဆာ၏ ကိုယ်ပိုင် program ဖြင့် ပို့ပါ။

## မတည်ဆောက်ရသေးသော အရာများ
