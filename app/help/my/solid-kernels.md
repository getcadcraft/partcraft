geometry kernel သည် သင်၏ history ကို solid အဖြစ် ပြောင်းသော အင်ဂျင် ဖြစ်သည်။ PartCraft ၏ ဤဗားရှင်းတွင် တစ်ခု ရှိသည်- **mesh kernel** (manifold-3d)။ ၎င်းသည် သင့်ကွန်ပျူတာပေါ်တွင် WebAssembly အစီအစဉ်ငယ်တစ်ခုအဖြစ် ပြေးပြီး app ဖွင့်ပြီးနောက် ခဏအတွင်း အသင့်ဖြစ်သည်။ သင့်အစိတ်အပိုင်းအကြောင်း မည်သည့်အရာမျှ ဘယ်သို့မှ မပို့ပါ။

အစိတ်အပိုင်းကို တည်ဆောက်နေစဉ် status bar ၏ ညာဘက်အစွန်ရှိ ချစ်ပ်သည် **Mesh kernel** ဟု ပြသည်။

## Exact kernel ကို စောင့်နေသော အရာများ

exact (B-rep) kernel သည် အမှန်တကယ် စက်ဝိုင်း၊ ဘောင်ပုံနှင့် ကိုနီများကို ထိန်းထားပြီး ဘယ် edge ပေါ်မဆို ချောမွေ့သော fillet၊ sweep၊ loft၊ surface၊ sheet metal၊ ribs၊ အစိတ်အပိုင်းများစွာနှင့် မျဉ်းကွေးမျက်နှာပါ STEP import များကို တည်ဆောက်သည် (exact STEP export သည် ၎င်းကို မစောင့်ပါ: mesh kernel သည် sketch မှ မျက်နှာတိုင်း၏ မူလမျက်နှာကို သိပြီး export က ထိုအတိုင်း ရေးသည်)။ PartCraft ၏ ယခင် lab build များသည် ထိုအတွက် OpenCascade ကို သုံးခဲ့သည်။ ၎င်း၏ လိုင်စင် (LGPL) သည် ဤထုတ်ဝေမှုနှင့် မကိုက်ညီပါ။ ဤထုတ်ဝေမှုတွင် app တိုင်းသည် Apache-2.0 ဖြစ်ပြီး permissive လိုင်စင်ရ library များသာ သုံးသဖြင့် ၎င်းကို ထည့်မထားပါ။ ဤအရာတွင် ရက်စွဲ မရှိပါ။

ထိုအချိန်အထိ ထို feature များကို ရွေးသည့်အခါ **မတည်ဆောက်ရသေးပါ** ဟု ပြသည်- status bar က အကြောင်းပြချက် ပေးပြီး ခလုတ်များ၏ tooltip များက "မတည်ဆောက်ရသေး (exact kernel လိုအပ်သည်)" ဖြင့် အဆုံးသတ်သည်။ [မတည်ဆောက်ရသေးသည်များ](topic:not-built-yet) တွင် တစ်ခုစီနှင့် အစားထိုးနည်းကို ဖော်ပြသည်။

ယခင် build တွင် ထိုအရာများဖြင့် ပြုလုပ်ထားသော အစိတ်အပိုင်းသည် ဆက်ဖွင့်နိုင်သေးသည်။ ထို feature များသည် မတည်ဆောက်ရသေးဟု အမှတ်အသားပြုထားသော history တွင် ကျန်နေသည် (အကြောင်းပြချက်အတွက် ထိုတစ်ခုပေါ် hover လုပ်ပါ)၊ ကျန်အစိတ်အပိုင်းများ တည်ဆောက်သည်၊ သိမ်းလျှင် ၎င်းတို့ကို မပြောင်းလဲဘဲ ထိန်းထားသည်။

## လုံးပတ်မျက်နှာများနှင့် မျဉ်းကွေးများ

mesh kernel သည် စက်ဝိုင်းကို polygon အဖြစ် ဆွဲသည်။ အစိတ်အပိုင်း panel ရှိ **မျဉ်းကွေးများ** က စက်ဝိုင်းတစ်ပတ်လုံးတွင် ဘေးပေါင်း မည်မျှရမည်ကို သတ်မှတ်သည်; ဘေးများ ပိုများလျှင် ပိုချောသည်၊ အမှန်တန်ဖိုးနှင့် ပိုနီးစပ်စွာ တိုင်းတာပြီး တည်ဆောက်ရန် ပိုကြာသည်။ {{ui:တိုင်းတာ}} မှ ပမာဏ၊ ဧရိယာနှင့် အကွာအဝေးများသည် ဤ faceted solid အတွက်ဖြစ်သည်- hole သို့မဟုတ် boss အတွက် ၎င်းတို့သည် လုံးပတ်ပုံထက် အနည်းငယ် ငယ်သည်။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

mesh kernel သည် app ၏ ကိုယ်ပိုင် ဒေါင်းလုဒ်၏ အစိတ်အပိုင်း ဖြစ်သည်။ ချိတ်ဆက်မှုမရှိဘဲ အလုပ်လုပ်ရန် အင်တာနက်ရှိစဉ် PartCraft ကို offline အသုံးပြုရန် သိမ်းပါ- app bar ရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို ရွေး၍ **အော့ဖ်လိုင်း အသင့်ဖြစ်ပြီ** ဟု ပြသည်အထိ စောင့်ပါ။ အသေးစိတ်- [အော့ဖ်လိုင်း အလုပ်လုပ်ခြင်း](common:offline)။
