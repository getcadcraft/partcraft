solid တိုင်းသည် sketch တစ်ခုဖြင့် စတင်သည်- plane ပေါ်ရှိ ပြားညီသော ပုံဆွဲချက် ဖြစ်သည်။ ဤလမ်းညွှန်တွင် ပုံဆွဲကိရိယာများကို ဖော်ပြထားသည်။ relation နှင့် အတိုင်းအတာများဖြင့် sketch ကို တင်းကျပ်စွာ သတ်မှတ်ခြင်းကို [sketch ကို အပြည့်အဝ သတ်မှတ်ခြင်း](topic:relations-dimensions) တွင် ဖော်ပြထားသည်။

## Sketch စတင်ခြင်း

base plane တစ်ခု သို့မဟုတ် အစိတ်အပိုင်း၏ ပြားညီသော မျက်နှာမည်သည့်တစ်ခုပေါ်တွင်မဆို sketch ဆွဲနိုင်သည်။

1. sketch ဆွဲမည့်နေရာကို ရွေးပါ-
   - base plane: history ထဲရှိ **ရှေ့ plane**၊ **အပေါ် plane** သို့မဟုတ် **ညာဘက် plane** ကို နှိပ်ပါ၊ သို့မဟုတ် view ပေါ်ရှိ plane ကို နှိပ်ပါ၊
   - ပြားညီသော မျက်နှာ: view ပေါ်ရှိ မျက်နှာကို နှိပ်ပါ။ မျက်နှာတစ်ခုလုံး မီးမောင်းပြပါမည်။
2. toolbar ရှိ {{ui:Sketch}} ကို ရွေးပါ သို့မဟုတ် {{key:S}} ကို နှိပ်ပါ။ (မျက်နှာ ရွေးထားလျှင် ညာဘက် panel ရှိ {{ui:ဤမျက်နှာပေါ်တွင် ပုံဆွဲချက်}} ကိုလည်း ရွေးနိုင်သည်၊ plane ဖြစ်လျှင် {{ui:၎င်းပေါ်တွင် ပုံဆွဲရန်}} ကို ရွေးနိုင်သည်။)

view သည် plane နှင့် ထောင့်မှန်ကျစွာ လှည့်သွားပြီး sketch ကိရိယာများ toolbar တွင် ပေါ်လာကာ {{ui:မျဉ်း}} ကိရိယာ အသင့်ဖြစ်သည်။ အဘယ်အရာမျှ မရွေးဘဲ {{ui:Sketch}} ကို နှိပ်လျှင် base plane များ ပေါ်လာပြီး status bar တွင် "sketch ဆွဲရန် plane သို့မဟုတ် ပြားညီသော မျက်နှာကို နှိပ်ပါ။ Esc ဖြင့် ရပ်နိုင်သည်။" ဟု ပြသည်။

:::note
ကွေးသော မျက်နှာတွင် sketch မထားနိုင်ပါ- "ဤမျက်နှာသည် ကွေးသည်။ sketch ဆွဲရန် ပြားညီသော မျက်နှာ သို့မဟုတ် plane ကို ရွေးပါ။"
:::

**မျက်နှာပေါ်ရှိ sketch သည် ထိုမျက်နှာကို လိုက်သည်။** မျက်နှာကို sketch edge သို့မဟုတ် extrude ၏ အဆုံးမှ ဖန်တီးထားလျှင် feature ပြောင်းသည့်အခါ sketch သည်လည်း ရွေ့သွားမည်ဖြစ်သည် (ပိုနက်သော pocket သည် ၎င်း၏ အောက်ခြေရှိ sketch ကို ယူသွားသည်)။ panel က မျက်နှာကို "ရွေးချယ်ထားသည့်နေရာတွင် ပုံသေ" ဟု ပြလျှင် sketch သည် မျက်နှာ ယခုရှိနေသည့်နေရာတွင်သာ ရှိနေမည်။

## ပုံဆွဲကိရိယာများ

ကိရိယာတစ်ခုစီတွင် toolbar ခလုတ်နှင့် ကီးတစ်ခု ရှိသည်။ ခလုတ်ကို ပြန်နှိပ်ပါ၊ {{key:S}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{key:Esc}} ကို နှိပ်၍ ရွေးရန် သို့ ပြန်သွားပါ။

| ကိရိယာ | ကီး | ဆွဲနည်း |
|---|---|---|
| {{ui:မျဉ်း}} | {{key:L}} | စတင်မည့်နေရာကို နှိပ်ပါ၊ ထို့နောက် နောက်အမှတ်တိုင်းကို နှိပ်ပါ။ မျဉ်းများ အဆုံးချင်း ဆက်တိုက် ချိတ်ဆက်သည်။ ချိတ်ဆက်မှုကို {{key:Esc}}၊ {{key:Enter}}၊ ညာကလစ် သို့မဟုတ် နှစ်ချက်ကလစ်ဖြင့် အဆုံးသတ်ပါ။ ရှိပြီးသား အမှတ်ကို နှိပ်လည်း အဆုံးသတ်သည် |

| {{ui:အဝိုင်းကွေး}} | {{key:A}} | ဗဟိုကို နှိပ်ပါ၊ ထို့နောက် စတင်မှတ်နှင့် အဆုံးမှတ်ကို နှိပ်ပါ။ အဝိုင်းကွေးသည် pointer ကို ဗဟိုပတ်လည် ရွှေ့သည့် ဘက်အတိုင်း ဆွဲသွားသည် |

| {{ui:ဗဟိုမျဉ်း}} | {{key:N}} | မျဉ်းနှင့်တူသည်၊ တစ်ပိုင်းစီ။ မျဉ်းတုံးဖြင့် ဆွဲပြီး construction ဂျီသြမေတြီ ဖြစ်သည်၊ revolve axis သို့မဟုတ် reference အဖြစ် သုံးသည် |

ဆွဲနေစဉ် pointer ဘေးတွင် အလျား၊ အရွယ်အစား၊ အချင်း သို့မဟုတ် radius ကို ပြသည့် သေးငယ်သော အကွက်တစ်ခု ပေါ်လာသည်။

### ဆွဲရင်း အရွယ်အစား ရိုက်ထည့်ခြင်း

မျဉ်း၊ ထောင့်မှန်၊ စက်ဝိုင်း သို့မဟုတ် အဝိုင်းကွေး၏ ပထမ click ပြီးနောက် နှိပ်ခြင်းအစား အရွယ်အစားကို ရိုက်ထည့်နိုင်သည်။ နံပါတ်ရိုက်လျှင် pointer ဘေးတွင် ထိုနံပါတ်ပါသော အကွက် ပွင့်လာသည်-

| ကိရိယာ | အကွက်များ ({{key:Tab}} ဖြင့် နောက်သို့ ရွှေ့) | {{key:Enter}} တွင် ဖြစ်ပျက်ချက် |
|---|---|---|
| {{ui:မျဉ်း}}, {{ui:ဗဟိုမျဉ်း}} | အလျား၊ ထို့နောက် sketch ၏ X axis မှ ထောင့် (°) | မျဉ်းကို ထိုအလျားဖြင့် ဆွဲမည်၊ pointer ဆီသို့ သို့မဟုတ် ရိုက်ထည့်ထားသော ထောင့်ဖြင့်; ချိတ်ဆက်မှုသည် ၎င်း၏အဆုံးမှ ဆက်သွားသည် |
| {{ui:ထောင့်မှန်}} | အကျယ်၊ ထို့နောက် အမြင့် | ထောင့်မှန်ကို ပထမထောင့်မှ pointer ဆီသို့ ဆွဲမည်; ရိုက်မထည့်ထားသော အရွယ်အစားကို pointer မှ ယူမည် |
| {{ui:စက်ဝိုင်း}} | အချင်း | စက်ဝိုင်းကို ထိုအချင်းဖြင့် ဆွဲမည် |
| {{ui:အဝိုင်းကွေး}} | ဗဟိုနောက် Radius၊ ထို့နောက် စတင်မှတ်နောက် Arc angle (°) | စတင်မှတ်သည် ဗဟိုမှ ထိုအကွာအဝေးတွင် ရှိမည်; ထို့နောက် အဝိုင်းကွေးသည် ထိုမျှ ပတ်သွားမည်၊ pointer ရွှေ့ခဲ့သည့် ဘက်အတိုင်း |

ရိုက်ထည့်သော အရွယ်အစားတိုင်းသည် တူညီသော အဆင့်တွင် **မောင်းနှင်သော အတိုင်းအတာ** ဖြစ်လာသဖြင့် sketch သည် အရွယ်အစားရှိသော အနေအထားဖြင့် ထွက်လာသည်- {{key:Mod+Z}} သည် ပုံသဏ္ဍာန်နှင့် ၎င်း၏ အတိုင်းအတာများကို အတူတကွ ဖျက်သည်။ {{key:Enter}} နှိပ်မည့်အစား click လုပ်လျှင် ရိုက်ထည့်ထားသည်ကို ထိန်းထားပြီး ကျန်သည်ကို click မှ ယူသည်။ {{key:Esc}} သည် အကွက်ကို ပိတ်ပြီး pointer သို့ ပြန်သွားသည်။

click ဖြင့်သာ ဆွဲလိုလျှင် {{ui:ဆက်တင်များ}} › {{ui:PartCraft}} › **ဆွဲရင်း အတိုင်းအတာ** တွင် ပိတ်နိုင်သည်။ [PartCraft ဆက်တင်များ](topic:settings) ကို ကြည့်ပါ။

sketch ကိရိယာများ အဆုံးရှိ {{ui:နောက်ထပ်}} တွင် control-point spline၊ Extend၊ Offset၊ Mirror၊ Polygon၊ Slot၊ sketch pattern များနှင့် Project edge ပါဝင်သည်- [spline၊ trim၊ offset နှင့် အခြား sketch ကိရိယာများ](topic:sketch-tools) ကို ကြည့်ပါ။

### Snap လုပ်ခြင်း

Snap လုပ်ခြင်းက relation များကို အလိုအလျောက် ထည့်ပေးသဖြင့် sketch ရွေ့သည့်အခါ ချိတ်ဆက်နေဆဲ ရှိနေသည်-

- **အဆုံးအမှတ် သို့မဟုတ် origin** ပေါ်တွင် သေးငယ်သော လေးထောင့် ပေါ်လာသည်။ အမှတ်သစ်သည် ၎င်းနှင့် ထပ်တူကျသည်။
- **မျဉ်း၊ စက်ဝိုင်း သို့မဟုတ် အဝိုင်းကွေး** ပေါ်တွင် သေးငယ်သော လက်ကမ်းကုံး ပေါ်လာသည်။ အမှတ်သစ်ကို ထို curve ပေါ်တွင် ထားသည်။
- အလျားလိုက် သို့မဟုတ် ဒေါင်လိုက်နှင့် ၃ ဒီဂရီအတွင်းရှိ မျဉ်းသည် ထိုဘက်သို့ snap လုပ်ပြီး အလျားလိုက် သို့မဟုတ် ဒေါင်လိုက် relation ရရှိသည်။ အညွှန်းတွင် "H" သို့မဟုတ် "V" ဟု ပြသည်။

Snap မဖြစ်စေရန် zoom in လုပ်၍ အမှတ် သို့မဟုတ် curve နှင့် ပိုဝေးသော နေရာကို click လုပ်ပါ။

## ထောင့်ကို ဝိုင်းခြင်း

1. {{key:F}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Fillet}} ကို ရွေးပါ။
2. မျဉ်းနှစ်ကြောင် ဆုံသော ထောင့်အမှတ်ကို နှိပ်ပါ။
3. အကြံပြုထားသော radius ပါသည့် အကွက် ပွင့်လာသည်။ radius ကို ရိုက်ထည့်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

မျဉ်းနှစ်ကြောင်စလုံးကို trim လုပ်ပြီး radius အတိုင်းအတာပါသော tangent အဝိုင်းကွေးဖြင့် ချိတ်ဆက်သည်။ တွေ့နိုင်သော မက်ဆေ့ချ်များ- "Fillet သည် မျဉ်းနှစ်ကြောင်းသာ ဆုံသော ထောင့် လိုအပ်သည်။" နှင့် "ဤမျဉ်းများအတွက် radius ကြီးလွန်းသည်။"

:::tip
sketch fillet သည် profile ၏ ထောင့်ကို ဝိုင်းသဖြင့် extrude သည် ဝိုင်းထားသော ဒေါင်လိုက် edge များ ရရှိသည်။ solid ၏ edge များကို ဝိုင်းလိုလျှင် (ဥပမာ ပြား၏ အပေါ်ဘက် edge များ) အစိတ်အပိုင်းပေါ်ရှိ {{ui:Fillet}} feature ကို အစားသုံးပါ- [ဝိုင်းခြင်း၊ ထောင့်ဖြတ်ခြင်းနှင့် အတွင်းဖောက်ခြင်း](topic:fillet-chamfer-shell) ကို ကြည့်ပါ။ sketch အတွင်း toolbar ရှိ Fillet သည် sketch ကိရိယာ ဖြစ်သည်; အစိတ်အပိုင်းပေါ်တွင် ၎င်းသည် feature ဖြစ်သည်။
:::

## ဆောက်လုပ်ရေး ဂျီသြမေတြီ

Construction မျဉ်း၊ စက်ဝိုင်းနှင့် အဝိုင်းကွေးများသည် မျဉ်းတုံးနှင့် မီးခိုးရောင် ဖြစ်သည်။ ၎င်းတို့သည် sketch ကို လမ်းညွှန်သော်လည်း extrude သို့မဟုတ် revolve လုပ်မည့် profile ၏ အစိတ်အပိုင်း မဟုတ်ပါ။

1. မျဉ်း၊ စက်ဝိုင်း သို့မဟုတ် အဝိုင်းကွေးများကို ရွေးပါ။
2. {{key:Q}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:ဆောက်လုပ်ရေး}} ကို ရွေးပါ။ ပြန်ပြောင်းရန် နောက်တစ်ကြိမ် ထပ်နှိပ်ပါ။

## ရွေး၊ ဆွဲရွှေ့နှင့် ဖျက်ခြင်း

ရွေးရန်အတွက် {{key:S}} ကို နှိပ်ပါ (သို့မဟုတ် ကိရိယာ မရှိတော့သည်အထိ {{key:Esc}} ကို နှိပ်ပါ)။

- အမှတ်၊ မျဉ်း၊ စက်ဝိုင်း၊ အဝိုင်းကွေး၊ relation သင်္ကေတ သို့မဟုတ် အတိုင်းအတာကို နှိပ်၍ ရွေးပါ။ {{key:Shift}}+click ဖြင့် ရွေးချယ်မှုသို့ ထည့်ရန် သို့မဟုတ် ဖယ်ရန်။ Windows နှင့် Linux တွင် {{key:Ctrl}}+click သည် အလားတူလုပ်ဆောင်သည်; Mac တွင် ⌘+click။
- လွတ်သောနေရာတွင် ဆွဲ၍ window ဆွဲပါ- ၎င်းအတွင်း အပြည့်အဝ ရှိသမျှ ရွေးခံရမည်။
- အမှတ် သို့မဟုတ် မျဉ်းကို ဆွဲ၍ ရွှေ့ပါ။ solver သည် ရွှေ့နေစဉ် relation နှင့် အတိုင်းအတာအားလုံးကို ထိန်းထားသဖြင့် လွတ်လပ်သော ဂျီသြမေတြီသာ ရွေ့သည်။ စက်ဝိုင်း၏ ဘေးအစွန်းကို ဆွဲ၍ radius ပြောင်းပါ။
- အတိုင်းအတာ၏ နံပါတ်ကို ဆွဲ၍ အညွှန်းကို ရွှေ့ပါ။
- ရွေးထားသည်ကို ဖျက်ရန် {{key:Delete}} သို့မဟုတ် {{key:Backspace}} ကို နှိပ်ပါ၊ သို့မဟုတ် ညာဘက် panel ရှိ {{ui:ဖျက်ရန်}} ကို ရွေးပါ။ ဂျီသြမေတြီကို ဖျက်လျှင် ၎င်းပေါ်ရှိ relation များလည်း ဖျက်သည်။

## Sketch အတွင်း zoom နှင့် pan

- pointer နေရာတွင် zoom ဖြင့် ဘီးကို လှိမ့်ပါ။
- pan ဖြင့် အလယ် သို့မဟုတ် ညာခလုတ်ဖြင့် ဆွဲပါ။
- toolbar သို့မဟုတ် ညာဘက် panel ရှိ {{ui:ကိုက်ညီအောင်}} သည် sketch ကို view တွင် ကိုက်ညီစေသည်။ sketch အတွင်း {{key:F}} ကီးသည် Fillet ကိရိယာ ဖြစ်ပြီး ကိုက်ညီအောင် မဟုတ်ပါ။

## Sketch ကို ပိတ်ခြင်း

toolbar ရှိ {{ui:ထွက်ရန်}} သို့မဟုတ် ညာဘက် panel ရှိ {{ui:Sketch မှ ထွက်ရန်}} ကို ရွေးပါ၊ သို့မဟုတ် sketch ပိတ်သည်အထိ {{key:Esc}} ကို နှိပ်ပါ။ {{key:Esc}} တစ်ကြိမ်စီသည် လက်ရှိလုပ်ဆောင်နေသည်ကို ပထမဦးဆုံး ပယ်ဖျက်၊ ထို့နောက် ရွေးရန် သို့ ပြန်သွား၊ ထို့နောက် ရွေးချယ်မှုကို ရှင်းလင်း၍၊ နောက်တစ်ကြိမ်က sketch ကို ပိတ်သည်။

sketch သည် ရွေးထားဆဲ ဖြစ်သဖြင့် နောက် {{ui:Extrude}} သို့မဟုတ် {{ui:Revolve}} သည် ၎င်းကို အသုံးပြုသည်။

## ကောင်းမွန်သော profile ဖြစ်စေသည့်အရာ

{{ui:Extrude}} နှင့် {{ui:Revolve}} သည် sketch ၏ solid (non-construction) မျဉ်း၊ စက်ဝိုင်း၊ အဝိုင်းကွေးနှင့် spline များ၏ **ပိတ်ထားသော loop အားလုံး** ကို အသုံးပြုသည်။ loop အတွင်း loop များသည် hole ဖြစ်လာသည်။

- အဆုံးတိုင်းသည် အခြားအဆုံးတစ်ခုနှင့်သာ တိကျစွာ တွေ့ရမည်။ "profile ဖွင့်နေသည်- (12.5, 40) ရှိ အဆုံးသည် မည်သည်နှင့်မျှ ချိတ်ဆက်မထားပါ။" ဟု နေရာကို ဖော်ပြသည်။
- အဆုံးသုံးခုသည် အမှတ်တစ်ခုတည်းတွင် မတွေ့ရပါ- "profile (0, 20) တွင် အကိုင်းအခက်ရှိသည်- အဆုံးနှစ်ခုထက် ပိုများ တွေ့နေသည်။"
- အမှတ်များနှင့် construction ဂျီသြမေတြီကို profile က လျစ်လျူရှုသည်။

နောက်တစ်ခု- [relation နှင့် အတိုင်းအတာဖြင့် sketch ကို အပြည့်အဝ သတ်မှတ်ခြင်း](topic:relations-dimensions)။

## ဓာတ်ပုံမှ sketch

**အင်္ဂါရပ်များ › နောက်ထပ် › ဓာတ်ပုံမှ Sketch…** (သို့မဟုတ် Feature tree ribbon ရှိ Sketch အုပ်စု) သည် ရိုးရှင်းသော မြေပြင်ပေါ်ရှိ ပြားညီသော အစိတ်အပိုင်း၏ ဓာတ်ပုံ (အပြင်ပိုင်းနှင့် hole များ) ကို ခြေရာခံ၍ သို့မဟုတ် ဘောပင်ဆွဲချက်ကို မျဉ်း၊ အဝိုင်းကွေးနှင့် စက်ဝိုင်းများ၏ sketch အဖြစ် ပြောင်းသည်။ sketch သည် မှန်ကန်သော အရွယ်အစားရစေရန် အရှည်တစ်ခု (အကျယ်၊ အမြင့် သို့မဟုတ် အရှည်ဆုံးဘေး) ကို ပြောပါ၊ preview တွင် တွေ့ရှိချက်ကို စစ်ဆေးပြီး **sketch ဖန်တီးရန်** ကို ရွေးပါ; ထို့အပြင် အဆင့်တူ undo တစ်ကြိမ်တည်းဖြင့် extrude လုပ်နိုင်သည်။ ၎င်းသည် ဤကွန်ပျူတာပေါ်တွင်သာ ခြေရာခံသည်။ ထောင့် radius များသည် ၅ % အတွင်း ပြန်ရလာပြီး ပစ်ဆယ် တစ်ဝက်နှစ်ဝက် အသေးစိတ်များ ပျောက်သွားနိုင်သည်၊ စောင်းနေသော သို့မဟုတ် အရိပ်ပါသော ဓာတ်ပုံများကို ဖြောင့်ထားခြင်း မရှိပါ- အစိတ်အပိုင်းကို ထောင့်မှန်ကျကျ၊ အလင်းညီညီဖြင့် ရိုက်ပါ။
