**အစမ်းကြည့်ရှုမှု။** Scripting သည် PartCraft 0.3 တွင် အသစ်ဖြစ်ပြီး အစမ်းကြည့်ရှုမှု ဖြစ်သည်: ဘာသာစကား၊ စာကြည့်တိုက်နှင့် script များ သိမ်းပုံသည် ပြောင်းလဲနိုင်ပြီး ယခု ရေးထားသော script များသည် နောင်တွင် အသေးစား ပြင်ဆင်ရန် လိုအပ်နိုင်သည်။ ဘာများ ပျက်စီးသွားသည်ကို ငါတို့အား ပြောပြပါ။

Script workspace သည် သင့်ကိုယ်ပိုင် တွက်ချက်မှုများကို part ၏ ဘေးတွင် run သည်: ငယ်သော ပေါင်းခြင်းများ၊ ခွဲခြမ်းစိတ်ဖြာမှု အပြည့်အစုံ၊ သို့မဟုတ် [ခွဲခြမ်းစိတ်ဖြာမှု စာကြည့်တိုက်](topic:craftscript-library) ရှိ script များ။ Script များကို **CraftScript** (MATLAB နှင့် ဆင်တူသော matrix ဘာသာစကား၊ [CraftScript ဘာသာစကား](topic:craftscript-language) ကို ကြည့်ပါ) သို့မဟုတ် **Lua** ([Lua ဖြင့် script များ](topic:craftscript-lua) ကို ကြည့်ပါ) သို့မဟုတ် **Python** ([Python ဖြင့် script များ](topic:craftscript-python) ကို ကြည့်ပါ) ဖြင့် ရေးနိုင်သည်။

Toolbar ၏ ဘယ်ဘက်ရှိ **Workspace** box တွင် **Script** ကို ရွေးပါ။ Part ကို မပြောင်းလဲပါ။ ညာဘက် panel သည် script panel ဖြစ်သွားသည် (ပုံမှန်ထက် ပိုကျယ်သည်; ၎င်း၏ အစွန်းကို ဆွဲ၍ ပြောင်းနိုင်သည်၊ သို့မဟုတ် {{ui:⋯}} menu ဖြင့် ဒုတိယ မျက်နှာပြင်သို့ ရွှေ့နိုင်သည်၊ [panel များ စီစဉ်ခြင်း](common:arrange-panels) ကို ကြည့်ပါ)။

## Model လုပ်နေစဉ် script ရေးခြင်း

Design workspace မှ ထွက်ရန် မလိုပါ။ Design တွင် ညာဘက် panel ၏ {{ui:Script}} tab တွင် တူညီသော editor၊ console၊ variable များနှင့် library တို့ ရှိပြီး တူညီသော script များ ပါဝင်သည်။ Feature tree နှင့် view များ ဆက်လုပ်နိုင်သည်: feature ကို နှိပ်၍ ရွေးပါ၊ sketch ကို နှစ်ချက်နှိပ်၍ တည်းဖြတ်ပါ၊ view ကို လှည့်ပါ၊ ထို့နောက် {{ui:Script}} tab သို့ ပြန်သွားပြီး {{key:F5}} ကို နှိပ်ပါ။

Script က **ပြသသည့်အရာ** (mesh၊ field၊ plot၊ ဇယား) များကို Design တွင် သင့်မော်ဒယ်ပေါ်တွင် မဆွဲပါ: console က ထိုသို့ ပြောပြသည်၊ Script workspace သို့ ပြောင်းသောအခါ အားလုံးကို ရရှိသည်။

{{ui:Run}} ဘေးရှိ {{ui:Pop out}} သည် panel တစ်ခုလုံးကို ကိုယ်ပိုင် window သို့ ရွှေ့သည်၊ ဥပမာ ဒုတိယ မျက်နှာပြင်တွင်၊ ထို့ကြောင့် editor နှင့် view အပြည့်အစုံ ဘေးချင်းကပ်နေနိုင်သည်။ {{ui:Put back}} က ၎င်းကို ပြန်ထည့်သည်။ [panel များ စီစဉ်ခြင်း](common:arrange-panels) ကို ကြည့်ပါ။

## ပထမ script ကို run ခြင်း

1. Editor တွင် ရိုက်ထည့်ပါ၊ ဥပမာ:

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. {{key:F5}} (သို့မဟုတ် {{ui:Run}}) ကို နှိပ်ပါ။ Editor အောက်ရှိ console က script ပုံနှိပ်သည့်အရာနှင့် "ပြီးဆုံးသည် … s" ကို ပြသသည်။ Plot သည် 3D view အောက်ခြေရှိ **အောက်ခြေ ပြသမှုများ** တွင် ပေါ်လာသည်။
3. `;` မပါသော လိုင်းသည် MATLAB ကဲ့သို့ ၎င်း၏ တန်ဖိုးကို ပုံနှိပ်သည်: `a = 3` သည် `a = 3` ကို ပုံနှိပ်သည်; `a = 3;` သည် ဘာမျှ မပုံနှိပ်ပါ။
4. Script ၏ အစိတ်အပိုင်းကိုသာ run ရန် လိုင်းများကို ရွေးပြီး {{key:Mod+Enter}} ({{ui:Selection}}) ကို နှိပ်ပါ။ ဘာမျှမရွေးထားပါက cursor ရှိလိုင်းကို run သည်။
5. Console ၏ အောက်ဆုံးလိုင်း (`>>` ၏ နောက်တွင်) သည် statement တစ်ခုကို {{key:Enter}} ကို နှိပ်သည့်အခါ run သည်။ {{key:Up}} နှင့် {{key:Down}} က ယခင် လိုင်းများကို ပြန်ယူသည်။

## ရှာခြင်း၊ folding နှင့် ဖြည့်စွက်ခြင်း

- **ရှာခြင်းနှင့် အစားထိုးခြင်း။** {{key:Mod+F}} (သို့မဟုတ် အစားထိုးရန်အတွက် {{key:Mod+H}}) ကို နှိပ်ပါ။ Code အပေါ်တွင် bar တစ်ခု ဖွင့်သည်: ရှာရန်အရာကို ရိုက်ပါ; တွေ့သော အရာများ မီးထွန်းသည်၊ count က သင်ရှိနေသည့်နေရာကို ပြသည်။ Box ဘေးရှိ ခလုတ်များက case ကို ကိုက်ညီစေသည် (**Aa**)၊ စကားလုံးတစ်လုံးလုံးကိုသာ ရှာသည် (**W**) နှင့် regular expression ကို အသုံးပြုသည် (**.\***; အစားထိုးတွင် `$1` က ပထမ group ကိုက်ညီသည့်အရာကို ပြန်ထည့်သည်)။ {{ui:Replace}} က လက်ရှိ ကိုက်ညီမှုကို အစားထိုးသည်၊ {{ui:All}} က ကိုက်ညီမှုအားလုံးကို {{key:Mod+Z}} ၏ အဆင့်တစ်ခုအဖြစ် အစားထိုးသည်။
- **Folding။** လိုင်းနံပါတ်ဘေးရှိ ▾ ကို နှိပ်ပါ၊ သို့မဟုတ် cursor ကို `function`, `if`, `for`, `while`, `switch` သို့မဟုတ် `try` လိုင်းပေါ်တွင် ထားပြီး {{key:Mod+Shift+[}} ကို နှိပ်ပါ (Lua: `function`, `do`, `if`, `repeat`)၊ ၎င်း၏ အတွင်းလိုင်းများကို ဝှက်ရန်; လိုင်းက အရေအတွက် ပြောသည်။ ▸ သို့မဟုတ် {{key:Mod+Shift+]}} က ပြန်ဖွင့်သည်။ Folding သည် လိုင်းများကို ဝှက်ရုံသာ ဖြစ်သည်: Run၊ Save၊ ကူးယူခြင်းနှင့် လိုင်းနံပါတ်များအားလုံးက လိုင်းအားလုံးကို ဆက်ရေတွက်သည်၊ folded လိုင်းပေါ်တွင် ရိုက်ခြင်းသည် ဦးစွာ ဖွင့်သည်။
- **ဖြည့်စွက်ခြင်း။** နာမည်၏ စာလုံးနှစ်လုံးကို ရိုက်ပါ၊ သို့မဟုတ် {{key:Mod+Space}} ကို နှိပ်ပါ: စာရင်းတစ်ခုက သင့်တွင်ရှိသော variable များ၊ ဘာသာစကား၏ function များ (argument များနှင့်အတူ)၊ keyword များနှင့် script တွင် ရှိပြီးသား နာမည်များကို ပြသည်။ မြှားခလုတ်များဖြင့် ရွေးပြီး {{key:Enter}} သို့မဟုတ် {{key:Tab}} ကို နှိပ်ပါ။

## အရာတစ်ခု မှားသွားလျှင်

- Error က ပြဿနာနှင့် ၎င်း၏လိုင်းကို ပြောပြသည်: လိုင်းသည် editor တွင် အနီရောင်ဖြင့် အမှတ်အသားပြုထားပြီး console ရှိ **Line n** က ထိုနေရာသို့ သင့်ကို ခေါ်သွားသည်။
- ဘယ်တော့မှ မပြီးသော loop: {{ui:Stop}} (toolbar သို့မဟုတ် panel) ကို နှိပ်ပါ။ Script ချက်ချင်း ရပ်သည်; variable များသည် ထို run မတိုင်မီ ရှိခဲ့သော တန်ဖိုးများကို ဆက်ထားသည်။
- Run တိုင်းတွင် step budget (မူလအားဖြင့် step 2 ဘီလီယံ; **Run options** အောက်တွင် ပြောင်းပါ) ရှိသည်။ ထို budget ကို ကျော်သော run သည် မက်ဆေ့ဂျ်ဖြင့် ရပ်သည်။

## Variable များသည် script မှ script သို့ ကူးပြောင်းသည်

Script တိုင်းက ဖန်တီးသော top-level variable တိုင်းသည် **Variables** tab (နာမည်၊ အမျိုးအစား၊ အရွယ်အစား၊ အငယ်ဆုံးနှင့် အကြီးဆုံး တန်ဖိုး) သို့ ရောက်ပြီး နောက် script အတွက် ထိုနေရာတွင် ကျန်နေသည်၊ ဘာသာစကား နှစ်ခုလုံးတွင်။ ထို့ကြောင့် script တစ်ခုက mesh ပြုလုပ်၍ နောက်တစ်ခုက solve လုပ်ပြီး တတိယတစ်ခုက plot လုပ်နိုင်သည်။

- Variable ကို နှိပ်၍ ပြပါ: mesh၊ field နှင့် model များကို 3D view တွင်၊ array များကို ဇယား (vector အတွက် line plot သို့မဟုတ် matrix အတွက် colour map အပါအဝင်) ကို အောက်ခြေ ပြသမှုများတွင်။
- {{ui:Save as JSON}}, {{ui:Save as CSV}} (ဂဏန်းများ၏ ဇယား) နှင့် {{ui:Save as HDF5}} က download လုပ်သည်; {{ui:Delete}} က ဖယ်ရှားသည်; {{ui:Clear all}} က workspace ကို ရှင်းသည်။
- **ပြောင်းလဲမှုများကို part နှင့်အတူ သိမ်းရန်** ကို အမှန်ခြစ်ပါ ထို့ကြောင့် part ဖိုင်တွင် ထိန်းထားသည် (32 MB အထိ; ပိုကြီးသည်များသည် ဤအလည်အပတ်အတွက်သာ ရှိသည်)။ ထိုသို့ သိမ်းထားသော part ကို ဖွင့်သောအခါ panel က ၎င်းတို့ကို load လုပ်ရန် ကမ်းလှမ်းသည်။

## Mesh၊ field နှင့် plot များ

- `show(m)` က mesh ကို ဆွဲသည်; `show(f)` က field ကို legend ဖြင့် ၎င်း၏ mesh ပေါ်တွင် အရောင်ခြယ်သည်။ View ၏ ဘယ်ဘက်အပေါ်ရှိ **Shown** စာရင်းက item တစ်ခုစီကို ဝှက်သည် ({{ui:eye}} မျက်လုံး) သို့မဟုတ် ဖယ်ရှားသည်၊ နှင့် part ကိုယ်တိုင်ကို ဝှက်သည် သို့မဟုတ် ပြသည်။ Legend အောက်တွင် range (**From**၊ **to**) ကို ရိုက်ထည့်ပါ သို့မဟုတ် {{ui:Auto}} ကို နှိပ်ပါ; vector သို့မဟုတ် ဖိအား field သည် မည်သည့် component ကို ပြမည်ကိုလည်း ပေးသည်။
- `show(f, 'deform', u, 'scale', 50)` က displacement field `u` ဖြင့် ရွှေ့ထားသော mesh ကို ဆွဲသည်၊ 50 ဆ ချဲ့ထားသည် (`scale` မပါလျှင် model အရွယ်အစား၏ 8 % ခန့်)။
- ပြထားသော mesh ကို နှိပ်ပါ: အနီးဆုံး node၊ element နှင့် ထိုနေရာရှိ field တန်ဖိုးများ အောက်ခြေ ပြသမှုများ (**ရွေးထားသော**) တွင် ပေါ်လာသည်။
- `plot`, `imagesc` နှင့် `table` က line plot၊ 2-D array ၏ colour map သို့မဟုတ် ဇယားကို အောက်ခြေ ပြသမှုများတွင် ထည့်သည်။ အစောပိုင်း plot နှင့် တူညီသော `'id'` (သို့မဟုတ် title) ရှိသော plot သည် ထိုအရာကို အစားထိုးသည်၊ ထို့ကြောင့် loop တစ်ခုက convergence plot တစ်ခုကို အပ်ဒိတ်လုပ်နိုင်သည်; `'append', true` က curve တစ်ခုကို ထပ်ထည့်သည်။ {{ui:Clear}} က အောက်ခြေ ပြသမှုများကို ရှင်းသည်; မြားက ၎င်းတို့ကို ခေါက်ထားသည်။
- Plot နှစ်ခု သို့မဟုတ် ပိုရှိလျှင် {{ui:Side by side}} က အားလုံးကို တစ်ပြိုင်နက် ပြသည် (အသစ်ဆုံး ခြောက်ခု); ဇယား သို့မဟုတ် ပုံ၏ tab ကို နှိပ်လျှင် ထိုတစ်ခုတည်းကို ပြန်ပြသည်။
- Plot တိုင်းတွင် အောက်တွင် {{ui:PNG}}, {{ui:SVG}} နှင့် {{ui:CSV}} ရှိသည်။ PNG နှင့် SVG က theme မည်သည်ဖြစ်စေ စာရွက်အရောင်ဖြင့် အဖြူရောင်ပေါ်တွင် ပုံနှိပ်သည် (PNG 1600 × 1000 pixel; SVG က မပျက်စီးဘဲ scale လုပ်သည်); CSV က ဂဏန်းများကို digit အပြည့်ဖြင့် ထိန်းထားသည်: x ၏ column တစ်ခုနှင့် curve တစ်ခုချင်းစီအတွက် column တစ်ခု၊ curve များက x ကို မျှဝေသောအခါ၊ မဟုတ်ပါက point တစ်ခုချင်းစီအတွက် row တစ်ခုနှင့် curve ၏ နာမည်။
- {{key:F}} သို့မဟုတ် {{ui:Fit}} က view ကို ပြသထားသည်များနှင့် ကိုက်ညီအောင် လုပ်သည်။

## ဖိုင်များ

- Script အုပ်စုရှိ {{ui:Open}} (သို့မဟုတ် view သို့မဟုတ် panel ပေါ်သို့ ဖိုင်များ ချထားပါ): `.craft`, `.lua` နှင့် `.py` ဖိုင်များသည် script အသစ်များအဖြစ် ဖွင့်သည် (run မလုပ်ပါ); ဒေတာဖိုင်များ (STL, OBJ, CSV, JSON, NPY, HDF5) သည် ဖိုင်နာမည်အောက်တွင် variable များသို့ load ဖြစ်သည်။
- Script အုပ်စုရှိ {{ui:Save}} က လက်ရှိ script ကို ဖိုင်တစ်ခုအဖြစ် download လုပ်သည်။
- Script အုပ်စုရှိ {{ui:New}} (သို့မဟုတ် tab များဘေးရှိ {{ui:+}}) က script အခြားတစ်ခု စတင်သည်။ Tab ကို နှစ်ချက်နှိပ်၍ အမည်ပြောင်းပါ; ၎င်း၏ {{ui:×}} က ဖယ်ရှားသည် (ထိုအရာကို undo လုပ်နိုင်သည်)။

## Part ၏ ပါရာမီတာများကို ဖတ်ခြင်း

Script သည် part ၏ ပါရာမီတာများ ([ပါရာမီတာဖြင့် part ကို မောင်းနှင်ခြင်း](topic:parameters) ကို ကြည့်ပါ) ကို နာမည်ဖြင့် ဖတ်သည်:

```
w = param('width');     % ပါရာမီတာတစ်ခု၏ တန်ဖိုး၊ mm (သို့မဟုတ် ဒီဂရီ၊ သို့မဟုတ် ရိုးရိုးဂဏန်း)
p = params();           % အားလုံး၊ struct အဖြစ်: p.width, p.height
```

Lua နှင့် Python တွင် ၎င်းတို့က `cs.param('width')` နှင့် `cs.params()` ဖြစ်သည်။ Script များသည် ပါရာမီတာများကို ဖတ်ရုံသာ: ပြောင်းရန် **{{ui:Parameters}}** tab တွင်။ Script ၏ tab အောက်တွင် လိုင်းတစ်ခုက `param('…')` ဖြင့် ဖတ်သော ပါရာမီတာများကို စာရင်းပြုစုပြီး part တွင် မရှိသည်များကို အမှတ်အသားပြုသည်; {{ui:Parameters}} tab က script ကို ပါရာမီတာတစ်ခုစီအောက်တွင် စာရင်းပြုစုသည်။ Script run နေစဉ် တည်ဆောက်သော နာမည် (ဥပမာ `param(name)`) ကို စာရင်းမပြုစုပါ။

## Script များကို part တွင် သိမ်းခြင်း

Tab များရှိ script တိုင်းကို part တွင် ထိန်းထားသည်၊ ထို့ကြောင့် File အုပ်စုရှိ {{ui:Save}} က ၎င်းတို့နှင့်အတူ သိမ်းသည်နှင့် ၎င်းတို့ပေါ်ရှိ ပြောင်းလဲမှုများကို undo လုပ်နိုင်သည်။ Part ကို ဖွင့်ခြင်းသည် ၎င်း၏ script များကို **ဘယ်တော့မှ run မလုပ်ပါ**: console က ၎င်းသယ်ဆောင်သော အရေအတွက်ကို ပြောပြပြီး Run ကို နှိပ်မှသာ run သည်။ အခြားသူ၏ part တွင် မည်သည့် script မဆို ပါနိုင်သည်: run မလုပ်မီ ဖတ်ပါ။ Script များသည် ဤကွန်ပျူတာပေါ်တွင် နောက်ကွယ်တွင် network ဝင်ရောက်ခွင့်မရှိဘဲ run ပြီး page ကို မထိနိုင်ပါ။
