**ဤဗားရှင်းတွင်** PartCraft သည် fillet နှင့် chamfer များကို mesh kernel ဖြင့် တည်ဆောက်ပြီး **ပြားသော မျက်နှာနှစ်ခုကြား ဖြောင့်သော အစွန်းများတွင်သာ** အလုပ်လုပ်သည်: box အစွန်းများ နှင့် extrude နှင့် cut ၏ ဖြောင့်သော အစွန်းများ၊ အပြင် သို့မဟုတ် အတွင်း ထောင့်များ (အတွင်းထောင့်တွင် ပစ္စည်း ထည့်သည်)။ အပေါက်နှုတ်ခမ်းကဲ့သို့ ကွေးသော အစွန်းများနှင့် အစွန်းတစ်လျှောက် radius ပြောင်းလဲခြင်းကို မတည်ဆောက်ရသေးပါ။ ကွေးသော အစွန်းနှစ်ခု ထောင့်တွင် ဆုံသောအခါ round များကို mitre (ထောင့်ဖြတ်) လုပ်ပြီး (ထက်မြက်သော ခေါက်တစ်ခုတွင် ဆုံသည်)၊ blend မလုပ်ပါ။ **Shell** လည်း အလုပ်လုပ်သည်၊ mesh kernel ဖြင့် တည်ဆောက်သည်: ပြားသော မျက်နှာများကိုသာ ဖွင့်နိုင်သည်၊ နံရံအထူ မတူသော shell များကို မတည်ဆောက်ရသေး၊ ကွေးသော မျက်နှာများများသော အပိုင်းတွင် နှေးသည်။ ကြည့်ရန်- [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet)။
:::

{{ui:Fillet}} သည် အစွန်းများကို ဝိုင်းစေသည်၊ {{ui:Chamfer}} သည် ဘေးစောင်းစေသည်၊ {{ui:Shell}} သည် အပိုင်းကို hollow လုပ်သည်။ သုံးခုစလုံးသည် solid ၏ အစွန်းနှင့် မျက်နှာများပေါ်တွင် အလုပ်လုပ်ပြီး mesh kernel ဖြင့် တည်ဆောက်သည်။ ၎င်းတို့၏ round များသည် စက်ဝိုင်းမျက်နှာ တိုင်းကဲ့သို့ facet ဖြစ်သည် (**Curves** က ဘယ်လောက် သေးသည်ကို သတ်မှတ်သည်); စက်ဝိုင်းမျက်နှာများသည် ရွေးချယ်ပြီး တိုင်းနိုင်သော cylinder များ ဖြစ်သည် (ကြည့်ရန်- [mesh kernel](topic:solid-kernels))။

## Fillet သို့မဟုတ် chamfer အစွန်းများ

### အစွန်းများ ဦးစွာ ရွေးပါ

1. အပိုင်း၏ အစွန်းတစ်ခုကို နှိပ်ပါ။ အစွန်းတစ်ခုလုံး highlight ဖြစ်ပြီး right panel တွင် **Edge** ဟု ပြသည်: ၎င်း၏ အမျိုးအစား (Straight၊ Circle or arc၊ Curve)၊ အရှည်နှင့် ၎င်း ကြားရှိ မျက်နှာများ။
2. ပိုအစွန်းများ ထည့်ရန် {{key:Shift}}+နှိပ်ပါ။ တစ်ခုစီ အမှတ်အသားပြုသည်; အမှတ်အသားပြုထားသော အစွန်းကို ဖယ်ရန် {{key:Shift}}+နှိပ်ပါ။ panel ခေါင်းစီးက ရေတွက်သည် ("4 edges") နှင့် status bar က "4 edges picked. Fillet or Chamfer rounds them; Shift+click picks more, Esc clears." ဟု ပြသည်။ › "အစွန်း 4 ခု ရွေးပြီး။ Fillet or Chamfer က ၎င်းတို့ကို ဝိုင်းစေသည်; Shift+နှိပ်ခြင်းဖြင့် ပိုရွေးနိုင်သည်၊ Esc ဖြင့် ရှင်းသည်။"
3. toolbar တွင် {{ui:Fillet}} သို့မဟုတ် {{ui:Chamfer}}၊ သို့မဟုတ် right panel ရှိ ခလုတ်တူတူကို ရွေးပါ။

feature ကို ရွေးထားသော အစွန်းအားလုံးဖြင့် ထည့်သည်: 2 mm round သို့မဟုတ် 1 mm chamfer။ status bar က ဥပမာ "Fillet1 ထည့်ပြီးပြီ (4 edges)။ ၎င်း၏ အရွယ်အစားကို ညာဘက်တွင် ပြောင်းပါ; Pick edges က ဘယ်ဟာကို ပြောင်းသည်။" ဟု ပြသည်။

### သို့မဟုတ် feature ကို ဦးစွာ ထည့်ပါ

1. ဘာမျှ မရွေးထားဘဲ {{ui:Fillet}} သို့မဟုတ် {{ui:Chamfer}} ကို ရွေးပါ။
2. PartCraft သည် ရွေးချယ်မှု မုဒ်သို့ ဝင်သည်: right panel ခေါင်းစီးက "Fillet1: picking" ဟု ပြပြီး အပိုင်းသည် fillet မတိုင်မီကဲ့သို့ ပြသည် (panel က ထိုသို့ ပြောသည်)၊ toolbar က {{ui:Done}} ကို ပြသည်။
3. တစ်ခုစီ အစွန်းကို နှိပ်ပြီး ထည့်ပါ; ထပ်နှိပ်လျှင် ဖယ်သည်။ status bar က ရေတွက်သည်။
4. {{ui:Done}} (သို့မဟုတ် panel ရှိ {{ui:Done picking}}) ကို ရွေးပါ၊ သို့မဟုတ် {{key:Esc}} သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပါ။

### ဆက်တင်များ

| ဆက်တင် | Fillet | Chamfer |
|---|---|---|
| အရွယ်အစား (Size) | **အချင်းဝက် (mm) (Radius)**၊ မူလ 2 | **အကွာအဝေး (mm) (Distance)** အစွန်းမှ မျက်နှာနှစ်ခုတွင် နောက်သို့၊ မူလ 1 |
| **အစွန်းများ (Edges)** | ဘယ်နှစ်ခု | ဘယ်နှစ်ခု |

အောက်ရှိ စာရင်းက အစွန်းတစ်ခုစီကို ဆက်ထားသော မျက်နှာနှစ်ခုဖြင့် အမည်ပေးသည်၊ ဥပမာ "Edge 1: Extrude1 end face × Extrude1 side"။ **Remove** က တစ်ခု ဖယ်သည်။ {{ui:အစွန်းများ ရွေးရန်}} သည် ရွေးချယ်ခြင်းသို့ ပြန်သွားသည်။ history ရှိ feature ကို နှစ်ချက်နှိပ်ခြင်းလည်း တူညီသည်။

အစွန်းများကို ဆက်ထားသော မျက်နှာနှစ်ခုဖြင့် မှတ်ထားသဖြင့် history ၏ အစောပိုင်းတွင် dimension ပြောင်းလျှင်လည်း မှန်ကန်သော အစွန်းတွင် ဆက်ရှိနေသည်။

### Variable fillet နှင့် chamfer အမျိုးအစားများ

- **Variable radius** (fillet): ဤဗားရှင်းတွင် မတည်ဆောက်ရသေး ("အစွန်းတစ်လျှောက် radius ပြောင်းသော fillet: မတည်ဆောက်ရသေး (exact kernel လိုသည်)။ radius တစ်ခုတည်း ပေးပါ။"). exact kernel ရှိလျှင်- အမှန်ခြစ်ပြီး **End radius (mm)** သတ်မှတ်ပါ။ radius သည် အစွန်းတစ်ခု၏ တစ်ဖက်ရှိ **Radius** မှ တစ်ဖက်ရှိ **End radius** အထိ မျဉ်းဖြောင့် ပြောင်းသည်; **Swap the ends** က လှည့်ပေးသည်။
- **Type** (chamfer): **Equal distance**၊ **Two distances** (အခြား မျက်နှာတွင် **Second distance**) သို့မဟုတ် **Distance and angle** (မျက်နှာတစ်ခုတွင် အကွာအဝေး၊ ထိုမျက်နှာသို့ **Angle (°)** ဖြင့် bevel)။ **Flip sides** က ပထမ အကွာအဝေးကို အခြားမျက်နှာသို့ ထားသည်။

## အပိုင်းကို Shell လုပ်ခြင်း

1. ဖွင့်ထားရမည့် ပြားသော မျက်နှာကို နှိပ်ပါ၊ ဥပမာ box ၏ အပေါ်ဘက်။ သို့မဟုတ် {{key:Shift}}+နှိပ်ခြင်းဖြင့် မျက်နှာများစွာ။
2. toolbar တွင် {{ui:Shell}} သို့မဟုတ် မျက်နှာ၏ panel ရှိ {{ui:Shell, opening this face}} ကို ရွေးပါ။

အပိုင်းသည် 2 mm နံရံ ဖြစ်လာပြီး ရွေးထားသော မျက်နှာများ ဖွင့်ထားသည်။ ဆက်တင်များ-

| ဆက်တင် | လုပ်ဆောင်ချက် | မူလ |
|---|---|---|
| **နံရံ (mm) (Wall)** | နံရံအထူ | 2 |
| **နံရံများ အပြင်သို့ ကြီးသည် (မျက်နှာများ အတွင်းတွင် ရှိနေသည်)** | အမှန်ခြစ်- နံရံများကို အပြင်ဘက်တွင် ထည့်သည်၊ ထို့ကြောင့် အတွင်းသည် အပိုင်း၏ အရွယ်အစားကို ထိန်းသည် | ပိတ်- နံရံများ အတွင်းသို့ သွားပြီး အပြင်ဘက် အရွယ်အစား ထိန်းသည် |
| **ဖွင့်ထားသော မျက်နှာများ (Open faces)** | ဖယ်ရှားသော မျက်နှာအရေအတွက် | |

အတွင်းသို့ဆိုလျှင် နံရံများသည် နံရံအထူ အတိအကျ ဖြစ်သည်: အပြင်ထောင့်များ ထက်မြက်ကျန်ရှိ၊ အတွင်းထောင့်များ ဝိုင်းလာသည် (radius = နံရံ)၊ အပိုင်းကို ဖောက်သော အပေါက်တွင် ၎င်းပတ်လည် နံရံ ပြွန်တစ်ခု ရသည်။ အပြင်သို့ဆိုလျှင် နံရံများကို မူရင်း မျက်နှာပြင် အပြင်ဘက်တွင် ထည့်သည်၊ ထိုမျက်နှာပြင်သည် hollow ဖြစ်လာပြီး အပြင်အစွန်းများ ဝိုင်းလာသည်။ အတွင်း မျက်နှာများကို ၎င်းတို့ offset လုပ်သော မျက်နှာများ အမည်ဖြင့် ပေးထားသဖြင့် ရွေးနိုင်သည်။

ပြားသော မျက်နှာများကိုသာ ဖွင့်နိုင်သည်: ကွေးသော မျက်နှာကို ရွေးလျှင် "Shell: ဤဗားရှင်းတွင် ပြားသော မျက်နှာများကိုသာ ဖွင့်သည် (mesh kernel က တည်ဆောက်သည်)။" ဟု ပြသည်။ စက်ဝိုင်းမျက်နှာ အများအပြား ရှိသော အပိုင်းတွင် shell နှေးသည် (တြိဂံ တစ်ထောင်လျှင် စက္ကန့်အနည်းငယ်): ဒီဇိုင်းလုပ်စဉ် **Curves** ကို ပိုကြမ်းသော ဆက်တင်ဖြင့် သုံးပါ။

{{ui:မျက်နှာပြင်များ ရွေးရန်}} သည် အစွန်းများ ရွေးသည့်နည်းတူ ဖွင့်ထားသော မျက်နှာများကို ပြောင်းသည်။ စာရင်းက တစ်ခုစီကို အမည်ပေးသည်၊ ဥပမာ "Face 1: Extrude1 end face"။ ဖွင့်ထားသော မျက်နှာ မရှိသော shell ကို ခွင့်မပြုပါ: "ဖယ်ရှားရန် (ဖွင့်ရန်) မျက်နှာများ ရွေးပြီးမှ shell လုပ်ပါ။"

## အစဉ်အလိုက် အရေးကြီးခြင်း

feature များကို အပေါ်မှ အောက်သို့ တည်ဆောက်သည်။ shell မတိုင်မီ fillet သည် အပိုင်းနှင့်အတူ shell လုပ်သဖြင့် အတွင်းပိုင်းတွင်လည်း ဝိုင်းထောင့်များ ရသည်။ shell ပြီးနောက် fillet သည် ရွေးထားသော အစွန်းများကိုသာ ဝိုင်းစေသည်။ {{ui:Move up}} နှင့် {{ui:Move down}} ဖြင့် feature များကို ရွှေ့ပါ (ကြည့်ရန်- [history ဖြင့် အပိုင်းကို ပြင်ဆင်ခြင်း](topic:edit-history))။

Pattern နှင့် mirror များသည် fillet၊ chamfer သို့မဟုတ် shell ကို ကူး၍ မရပါ: "Fillet1 သည် body ၏ အစွန်း သို့မဟုတ် နံရံများကို ပြောင်းသည်; ကူး၍ မရပါ။ solid ပြုလုပ်သော feature များ (extrude၊ revolve၊ hole၊ import) ကို ကူးပါ။" အပေါက် သို့မဟုတ် cut များကို ဦးစွာ pattern လုပ်ပြီး၊ နောက် ကူးထားသော အားလုံး၏ အစွန်းများကို fillet တစ်ခုတည်းဖြင့် fillet လုပ်ပါ။

## ကန့်သတ်ချက်များ

ဤဗားရှင်းတွင် fillet နှင့် chamfer များသည် ပြားသော မျက်နှာနှစ်ခုကြား ဖြောင့်သော အစွန်းများပေါ်တွင်သာ၊ radius တစ်ခုဖြင့် အလုပ်လုပ်ပြီး ထောင့်တွင် ဆုံသော round များကို mitre လုပ်သည်။ Shell များသည် ပြားသော မျက်နှာများကိုသာ ဖွင့်သည်။ exact kernel ဖြင့်၊ variable fillet သည် အစွန်းတစ်လျှောက် မျဉ်းဖြောင့် ပြောင်းလဲသည် (feature တစ်ခုလျှင် စည်းမျဉ်းတစ်ခု; အမှတ်များတွင် radius သတ်မှတ်ချက် မရှိ)။ မျက်နှာ fillet၊ full-round fillet နှင့် နံရံအထူ မတူသော shell များကို မတည်ဆောက်ရသေး။
