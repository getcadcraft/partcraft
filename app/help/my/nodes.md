**Nodes** တည်းဖြတ်ကိရိယာသည် ဘောက်စ်များကို ဝါယာကြိုးဖြင့် ချိတ်၍ ဂျီသြမေတြီ တည်ဆောက်သည်။ ဘောက်စ်တစ်ခုစီ (node) သည် အလုပ်ငယ်တစ်ခုကို လုပ်သည်- ဂဏန်းတစ်ခု၊ အမှတ်တစ်ခု၊ စက်ဝိုင်းတစ်ခု၊ loft တစ်ခု ဖန်တီးသည်။ တစ်ခု၏ ရလဒ်ကို နောက်တစ်ခု၏ input သို့ ချိတ်ပြီး၊ အစတွင်ရှိသော ဂဏန်းကို ပြောင်းလျှင် မော်ဒယ်က လိုက်ပြောင်းသည်။

workspace စာရင်းမှ ဖွင့်ပါ- {{ui:Nodes}}။ ၎င်းသည် တည်းဖြတ်ကိရိယာ ပြတင်းပေါက်ကို ဖွင့်သည်။ ဂရပ်ရှိပြီးသား အစိတ်အပိုင်းသည် workspace ကို ဖွင့်သည့်အခါ ၎င်းကို ပြသည်။ ၎င်းသည် 3D view အပေါ်ရှိ ပြတင်းပေါက်ဖြစ်သည်- ခေါင်းစဉ်ဘားကို ဆွဲ၍ ရွှေ့ပါ၊ ထောင့်ကို ဆွဲ၍ အရွယ်ပြောင်းပါ။

## ချိတ်ခြင်း

1. ဘယ်ဘက်ရှိ စာရင်းမှ node တစ်ခုကို ရွေးပါ (ရှာဖွေရန် ရှာဖွေရေးအကွက်တွင် ရိုက်ပါ၊ <kbd>Enter</kbd> က ပထမဆုံး ကိုက်ညီသည်ကို ထည့်သည်)။ canvas အလယ်တွင် ပေါ်လာသည်။
2. node တစ်ခု၏ ညာဘက်ရှိ စက်ဝိုင်း **output** အစက်မှ အခြား node ၏ ဘယ်ဘက်ရှိ စက်ဝိုင်း **input** အစက်သို့ ဆွဲပါ။ ကိုက်ညီလျှင် အစက် အစိမ်းရောင်ဖြစ်၍ မကိုက်ညီလျှင် အနီရောင်ဖြစ်သည်၊ အကြောင်းရင်းကို သိရန် အစက်ပေါ် ညွှန်ပါ။
3. ဘာမှ မချိတ်ထားသော input တွင် ရိုက်ထည့်သော တန်ဖိုးအကွက် ပြသည်။ ဂဏန်းရိုက်ပြီး <kbd>Tab</kbd> နှိပ်ပါ- ရလဒ် ပြန်တည်ဆောက်သည်။
4. node ခေါင်းစဉ်ဘားရှိ သေးငယ်သော စက်ဝိုင်းသည် ၎င်း၏ **မျက်လုံး** ဖြစ်သည်။ မျက်လုံးဖွင့်ထားသော node ကို 3D view တွင် ဆွဲပြသည်- မျဉ်းကွေးများကို မျဉ်းများအဖြစ်၊ မျက်နှာပြင်များကို အရိပ်ထည့်၍၊ အမှတ်များကို အစက်များအဖြစ် ပြသည်။

node ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲပါ။ နောက်ခံကို ဆွဲ၍ ရွှေ့ပါ၊ ဘီးကို လှည့်၍ ချဲ့ပါ။ <kbd>Delete</kbd> က ရွေးထားသော node ကို ဖျက်သည်။ {{ui:သပ်ရပ်အောင်စီရန်}} က node များကို ကော်လံများအဖြစ် စီသည်၊ {{ui:ကိုက်ညီအောင်}} က အားလုံးကို မြင်ရအောင် ရွှေ့သည်၊ {{ui:ပြန်ဖျက်ရန်}} နှင့် {{ui:ပြန်လုပ်ရန်}} က သင့်ပြင်ဆင်ချက်များအတိုင်း ပြန်သွား/ရှေ့သို့ လှမ်းသည်။

## အမျိုးအစားနှင့် ယူနစ်များ

Port တွင် အမျိုးအစား ရှိသည်- ဂဏန်း၊ yes/no၊ အမှတ်၊ vector၊ curve၊ surface၊ mesh၊ solid၊ သို့မဟုတ် ထိုအရာများအတွက် "geometry"။ အမှတ်သည် vector input သို့ ပြန်လည်လည်း ချိတ်နိုင်သည်။ ဂဏန်းများတွင် ယူနစ် ပါသည်: **အရှည်** သည် မီလီမီတာဖြစ်ပြီး **ထောင့်** သည် ဒီဂရီဖြစ်သည်။ အရှည်ကို ထောင့် input သို့ ချိတ်၍မရပါ၊ အရှည်နှင့် အရှည်ကို မြှောက်ခြင်း (ဧရိယာ) ကို ငြင်းသည်၊ ဤကြောင့် မှားသော ဝါယာကို ချိတ်သည့်အချိန်တွင် ရပ်တန့်သည်။

စတုရန်းအစက်သည် **list** ဖြစ်သည်။ list တစ်ခုသည် တန်ဖိုးတစ်ခုတည်းသော input သို့ ရောက်သည့်အခါ node သည် အိတ်ဆေ့တစ်ခုစီအတွက် တစ်ကြိမ်စီ လုပ်ပြီး ရလဒ်သည် list ဖြစ်လာသည်။ တိုသော list သည် နောက်ဆုံး အိတ်ဆေ့ကို ထပ်ခါထပ်ခါ သုံးသည်။ ဥပမာ အမြင့်များ၏ **Series** ကို **Move** သို့ ချိတ်လျှင် မိတ္တူများ ပုံစံ ဖြစ်သည်။

## Solid များနှင့် Boolean များကို node အဖြစ်

**Solids** အုပ်စုသည် Surfaces panel နှင့် တူသော တိကျသော မျက်နှာပြင်များမှ ပိတ်ထားသော ခန္ဒာများကို ဖန်တီးသည်- **Box solid**၊ **Cylinder solid** နှင့် **Sphere solid** (အရွယ်အစားများ mm ဖြင့်)၊ **Union**၊ **Subtract** နှင့် **Intersect** (ဒုတိယ solid ကို ပထမ solid မှ ယူသည်၊ tolerance သည် solid engine ၏ တြိဂံများ တိကျသော မျက်နှာပြင်များမှ ဘယ်လောက်ဝေးနိုင်သည်ကို ဆိုသည်)၊ **Fillet between faces** (မျက်နှာများကို solid တွင် ၎င်းတို့၏ နံပါတ်ဖြင့်၊ ပထမဆုံးမှာ 1၊ အချင်းဝက်တစ်ခုနှင့် 0 ထက်ကြီးလျှင် အဆုံးတွင် အချင်းဝက်တစ်ခု)၊ **Solid volume** (mm³) နှင့် **Solid to mesh** (ကြည့်ရန် သို့မဟုတ် ဖုတ်ရန်)။ solid တွင် ကိုယ်ပိုင် port အမျိုးအစား ရှိသည်- အမှတ် သို့မဟုတ် ဂဏန်းကို solid input သို့ ချိတ်၍မရ၊ အစက်သည် အနီရောင်ဖြင့် ကျန်နေမည်။ Boolean နှင့် Fillet node များသည် ပရိုဂရမ်၏ ကိုယ်ပိုင် solid engine ကို သုံးပြီး တည်းဖြတ်ကိရိယာ ပထမဆုံးဖွင့်သည့်အခါ တင်သည်။

## အမှားများ

မိမိလုပ်ဆောင်ရမည့်အလုပ်ကို မလုပ်နိုင်သော node သည် ၎င်း၏အမည်အောက်တွင် အနီရောင်ဖြင့် အကြောင်းကို ပြသည် ("အချင်းဝက်သည် သုည ထက်ကြီးရမည်။")၊ နောက်ကလာသော node များက စောင့်သည်။ တူညီသော စာသားကို Problems panel တွင် Problem အဖြစ်လည်း ပြသည်၊ ထိုနေရာမှ ရှာနိုင်သည်။

## Node တိုင်းသည် script တစ်ကြောင်း

{{ui:Script}} ကို နှိပ်၍ ဂရပ်ကို CraftScript အဖြစ် ကြည့်ပါ- node တစ်ခုလျှင် တစ်ကြောင်း၊ ဥပမာ `n3 = nd_circle(n2, n1, [0 0 1]);`။ စာသားကို တည်းဖြတ်ပြီး {{ui:ဤ script မှ ဂရပ်ကို ဖန်တီးရန်}} ကို နှိပ်လျှင် ဂရပ်အဖြစ် ပြန်ရောက်သည်။ တူညီသော `nd_` function များသည် PartCraft ရှိ CraftScript တွင်လည်း အလုပ်လုပ်သည်၊ ထို့ကြောင့် ဂရပ်ကို ထိုနေရာတွင် run၊ loop သို့မဟုတ် စမ်းသပ်နိုင်သည်။ ကျပန်းဂဏန်းများသည် အမြဲ **seed** ယူသည်၊ ထို့ကြောင့် ဂရပ်တူသည် ကွန်ပျူတာတိုင်းတွင် ရလဒ်တူသည်။

## ဖိုင်နှင့်အတူ သိမ်းခြင်း

ဂရပ်ကို အစိတ်အပိုင်းဖိုင်တွင် သိမ်းသည် (history တွင် မဟုတ်၍ တည်းဖြတ်ကိရိယာ၏ Undo သည် ကိုယ်ပိုင်ဖြစ်သည်)။ node များသည် solid ဘေးတွင် မျဉ်းကွေး၊ မျက်နှာပြင်နှင့် mesh များ ဖန်တီးသော်လည်း အစိတ်အပိုင်း၏ feature များကို မပြောင်းလဲပါ။
