PartCraft ကို ဘီးနှင့် အလယ်ခလုတ်ပါသော mouse အတွက် ဖန်တီးထားသော်လည်း gesture များကို သိပြီးနောက် trackpad သည် ကောင်းစွာ အလုပ်လုပ်ပြီး touch screen သည် ပစ္စည်းကြည့်ခြင်းနှင့် ရိုးရှင်းသော sketch အတွက် အလုပ်လုပ်ပါသည်။

## Trackpad

:::mac
| ရည်ရွယ်ချက် | ဘယ်လိုလုပ်မလဲ |
|---|---|
| ပစ္စည်းကို လှည့်ရန် (3D) | လက်ညှိုးတစ်ချောင်းဖြင့် နှိပ်ပြီး ဆွဲပါ (သို့မဟုတ် three-finger drag ကို ဖွင့်ထားလျှင် လက်သုံးချောင်းဖြင့် ဆွဲပါ) |
| ရွှေ့ပြသရန် (3D) | {{key:Shift}} (သို့မဟုတ် ⌘) ကို ဖိထားပြီး click-drag၊ သို့မဟုတ် လက်ချောင်းနှစ်ချောင်း ဖိထားပြီး click-drag (secondary-click drag) |
| ပစ္စည်းကို swipe ဖြင့် လှည့်ရန် | လက်ချောင်းနှစ်ချောင်းဖြင့် swipe; {{key:Shift}} ဖြင့် swipe က pan လုပ်သည်။ **Scrolling** ကို "Work it out" (အစ) သို့မဟုတ် "Trackpad" သို့ သတ်မှတ်ရန် လိုသည် |
| Zoom (3D နှင့် sketch) | Pinch။ Zoom သည် pointer ဘက်သို့ သွားသည်။ **Scrolling** ကို "Mouse wheel" သို့ သတ်မှတ်ထားလျှင် လက်ချောင်းနှစ်ချောင်း scroll လည်း zoom လုပ်သည် |
| Right-click | လက်ချောင်းနှစ်ချောင်းဖြင့် နှိပ်ပါ၊ သို့မဟုတ် {{key:Ctrl}}+click |
| Sketch တွင် pan | လက်ချောင်းနှစ်ချောင်း swipe ("Work it out" သို့မဟုတ် "Trackpad")၊ သို့မဟုတ် လက်ချောင်းနှစ်ချောင်း ဖိထားပြီး click-drag။ {{key:Shift}}+drag သည် sketch တွင် pan မလုပ်ပါ (selection window ဆွဲသည်) |
| Sketch တွင် selection ထဲ ထည့်ရန် | {{key:Shift}}+click သို့မဟုတ် ⌘+click |

Two-finger click မအလုပ်လုပ်ပါက **System Settings, Trackpad, Point & Click** တွင် secondary click ကို ဖွင့်ပါ။
:::

| Right-click | လက်ချောင်းနှစ်ချောင်းဖြင့် တို့ပါ၊ သို့မဟုတ် touchpad ၏ ညာအောက်ထောင့် |
| Sketch တွင် pan | လက်ချောင်းနှစ်ချောင်း swipe ("Work it out" သို့မဟုတ် "Trackpad")၊ သို့မဟုတ် right button နေရာဖြင့် ဆွဲပါ။ {{key:Shift}}+drag သည် sketch တွင် pan မလုပ်ပါ |
| Sketch တွင် selection ထဲ ထည့်ရန် | {{key:Shift}}+click သို့မဟုတ် {{key:Ctrl}}+click |

**Scrolling** သည် [PartCraft settings](topic:settings) တွင် ရှိသည်: "Work it out" (အစ) က ဘေးသို့ သို့မဟုတ် ကွက်ကွက် scroll ကို trackpad အဖြစ် သတ်မှတ်သည်၊ "Trackpad" က အမြဲ ထိုသို့၊ "Mouse wheel" က ဘယ်တော့မှ မထိုသို့။ Pinch က သုံးမျိုးလုံးတွင် zoom လုပ်သည်။

Arrow keys က 3D view ကို လှည့်ပြီး {{key:Shift}} နှင့် arrows က pan လုပ်သည်၊ view ကို နှိပ်ပြီးနောက်သာ ဖြစ်သည်: trackpad အတွက် အသုံးဝင်သည်။ {{key:Plus}} နှင့် {{key:Minus}} က zoom လုပ်သည်။

## Touch screen များ

PartCraft သည် touch input ကို ဖတ်သောကြောင့် tablet၊ touch laptop နှင့် phone များ အလုပ်လုပ်သည်၊ ကန့်သတ်ချက်များဖြင့်။

:::touch
**Touch keys**

Screen ကို တစ်ကြိမ် ထိပြီးနောက် view ၏ ညာအောက်ထောင့်တွင် လက်ချောင်းမှာ မရှိသော key များပါသော အနည်းငယ်သော bar ပေါ်လာသည်။ mouse သုံးသောအခါ ပျောက်သွားသည်။

- {{ui:Esc}}: Esc key။ သင်စတင်ထားသည်ကို ပယ်ဖျက်သည် သို့မဟုတ် နောက်သို့ ပြန်သွားသည်၊ key နှင့် အတိအကျ တူညီသည်။
- {{ui:Add}} (sketch တွင်၊ Select နှင့်အတူ): ဖွင့်ထားစဉ် တို့တိုင်းတွင် selection သို့ item တစ်ခု ထည့်သည် သို့မဟုတ် ဖယ်ရှားသည်၊ {{key:Shift}}+click ကဲ့သို့။ တစ်ခုချင်းစီသို့ ပြန်သွားရန် နောက်တစ်ကြိမ် ထပ်တို့ပါ။
- {{ui:Done}} (မျဉ်းကွင်း၊ spline သို့မဟုတ် polygon ဆွဲနေစဉ်): ၎င်းကို ပြီးစီးစေသည်၊ right-click ကဲ့သို့။

လက်ချောင်းကို ~0.5 စက္ကန့်ခန့် ငြိမ်ငြိမ်ထားခြင်းက tap တစ်ခုအတွက် အတူတူ လုပ်ပေးသည်: ဆွဲရေးကိရိယာဖြင့် ဆွဲနေသည်ကို ပြီးစီးစေပြီး Select ဖြင့် လက်ချောင်းအောက်ရှိ item ကို selection သို့ ထည့်သည် သို့မဟုတ် ဖယ်ရှားသည်။ Point နှင့် မျဉ်းများကို လက်ချောင်းဖြင့် ထိရန် ပိုလွယ်သည်: PartCraft က tap ပတ်လည်ကို click ထက် ~နှစ်ဆ ကျယ်ကျယ် ကြည့်သည်။

**3D view တွင်**

- လက်ချောင်းတစ်ချောင်း: ပစ္စည်းကို လှည့်။
- လက်ချောင်းနှစ်ချောင်း: pinch ဖြင့် zoom၊ အတူရွှေ့ဖြင့် pan။
- Tap: မျက်နှာ၊ edge သို့မဟုတ် plane ကို ရွေး။ Tap မတိုင်မီ hover highlight မရှိပါ။

**Sketch တွင်**

- ဆွဲရေးကိရိယာဖြင့် point တစ်ခုစီကို နေရာချရန် tap: စတင်ချက်ကို tap၊ ထို့နောက် အဆုံးကို tap။ Snap သည် လက်မြှောက်သော နေရာတွင် ဖြစ်သည်။
- လက်ချောင်းနှစ်ချောင်း pinch နှင့် pan။ ဒုတိယလက်ချောင်းကို ချလိုက်ခြင်းက ပထမလက်ချောင်း စတင်ထားသော ဆွဲခြင်းကို ပယ်ဖျက်သည်။
- မျဉ်းကွင်းကို ပြီးစီးစေရန် {{ui:Done}} ကို tap၊ လက်ချောင်းကို ငြိမ်ငြိမ်ထား၊ သို့မဟုတ် toolbar ရှိ {{ui:Line}} (သို့မဟုတ် အခြား tool) ကို ထပ် tap။
- Select ဖြင့် tap ဖြင့် ရွေး; point သို့မဟုတ် မျဉ်းကို ဆွဲ၍ ရွှေ့; နေရာလွတ်ပေါ်တွင် ဆွဲ၍ window။ ဒုတိယ tap က {{ui:Add}} ဖွင့်မထားလျှင် ရွေးချယ်မှုကို အစားထိုးသည် (သို့မဟုတ် ဒုတိယ item ပေါ်တွင် လက်ချောင်းကို ငြိမ်ငြိမ်ထားပါ)။
- Dimension ပြောင်းရန် right panel တွင် ၎င်းဘေးရှိ **Edit** ကို သုံးပါ။

**Drawing sheet**

Symbol များကို နေရာချရန်နှင့် ရွေးရန် tap ပြုပြီး symbol ကို ရွှေ့ရန် ဆွဲပါ။ Zoom အတွက် pinch၊ pan အတွက် လက်ချောင်းနှစ်ချောင်း ရွှေ့၊ သို့မဟုတ် လွတ်သော စာရွက်ပေါ် လက်ချောင်းတစ်ချောင်းဖြင့် ဆွဲပါ။ ဒုတိယလက်ချောင်းက ဆွဲနေသော symbol ကို ရပ်စေပြီး ပြန်သွားစေသည်။

**Keyboard လိုအပ်သော အရာများ**

- ဂဏန်းရိုက်ခြင်း: ဂဏန်း box နှင့် dimension field များတွင် screen keyboard ပေါ်လာသည်။
- Tool များအတွက် keyboard shortcut များ: toolbar ကို သုံးပါ။
:::

## သေးငယ်သော screen နှင့် phone များ

- 1280 pixels သို့မဟုတ် ပိုကျယ်သောအခါ toolbar သည် တစ်တန်းတည်း ကိုက်ညီသည်။
- ~760 မှ 1100 pixels အကြား side panel များ ပိုကျဉ်းလာသည်။
- ~760 pixels အောက် (phone သို့မဟုတ် ကျဉ်းသော window) တွင် screen သည် အထပ်လိုက် ဖြစ်သည်: toolbar (ခလုတ်ပိုများအတွက် ဘေးသို့ swipe)၊ 3D view၊ status bar၊ ထို့နောက် properties panel နှင့် history။ panel များသို့ ရောက်ရန် page ကို scroll လုပ်ပါ။
- မီနူးများ ({{ui:Export}}၊ {{ui:Views}}) သည် screen အကျယ်တစ်လျှောက် ဖွင့်သည်။

:::note
iPhone တွင် browser ၏ full screen မုဒ် မရှိပါ; {{key:Ctrl+Shift+F}} နှင့် screen-mode ခလုတ်သည် ပုံမှန်နှင့် bars ဖျောက်ထားသော မုဒ်အကြားသာ ပြောင်းသည်။
:::

Phone သည် ပစ္စည်းဖွင့်ခြင်း၊ လှည့်ခြင်းနှင့် အချက်အလက် စစ်ဆေးခြင်းအတွက် ကောင်းသည်။ မော်ဒယ်ပြုလုပ်ခြင်းသည် ပိုကြီးသော screen နှင့် mouse သို့မဟုတ် trackpad လိုအပ်သည်။

## Browser များ

လက်ရှိ Chrome၊ Edge၊ Firefox နှင့် Safari တို့သည် Windows၊ macOS နှင့် Linux တွင်၊ tablet နှင့် phone များတွင် PartCraft ကို run ပြီး WebGL နှင့် WebAssembly ရနိုင်သရွေ့ အလုပ်လုပ်ပါသည်။ [Browser နှင့် ကွန်ပျူတာများ](common:browsers) ကို ကြည့်ပါ။
