ပုံသွင်းကုန်း၊ die သို့မဟုတ် sand casting ဖြင့် ပြုလုပ်သော အစိတ်အပိုင်းများသည် **draft** လိုအပ်သည်- အစိတ်အပိုင်း ထွက်လာနိုင်ရန် နံရံများကို အနည်းငယ် စောင်းထားရမည်။ **Draft analysis** သည် မျက်နှာတိုင်းကို mould ဖွင့်သော လမ်းကြောင်း (**pull**) နှင့် မည်မျှ စောင်းနေသလဲဆိုသည်ဖြင့် အရောင်ခြယ်သည်။

## ဖွင့်ခြင်း

1. Design workspace တွင် {{ui:Views}} ကို ဖွင့်ပြီး {{ui:Draft analysis}} ကို ရွေးပါ။
2. **Pull** ကို သတ်မှတ်ပါ- mould ဖွင့်သော လမ်းကြောင်း၊ X၊ Y သို့မဟုတ် Z ဘက်တစ်ဘက်ဘက်တွင်၊ သို့မဟုတ် **Square to a picked face**: {{ui:Pick a face}} ကို နှိပ်ပြီး အစိတ်အပိုင်း၏ ပြားသော မျက်နှာတစ်ခုကို နှိပ်ပါ။
3. **Minimum draft** ကို ဒီဂရီဖြင့် သတ်မှတ်ပါ- သင့်လုပ်ငန်းစဉ်လိုအပ်သော အနည်းဆုံး စောင်းမှု (များသောအားဖြင့် 1° မှ 3°)။

အစိတ်အပိုင်းကို အောက်ပါအတိုင်း အရောင်ခြယ်သည်-

| အရောင် | အဓိပ္ပာယ် |
|---|---|
| အစိမ်း: **Positive draft** | Minimum အနည်းဆုံးအထိ pull ဘက်သို့ စောင်းနေသည်: ဤ mould ၏ ဘက်မှ ထွက်သည် |
| ဝါညို: **Needs draft** | ဘယ်ဘက်ကမဆို minimum အတွင်းရှိသည်၊ ဥပမာ ဒေါင်လိုက်နံရံ: ဤနေရာတွင် draft ထည့်ပါ |
| နီ: **Negative draft** | Minimum အထိ pull ဆန့်ကျင်ဘက်သို့ စောင်းနေသည်: mould ၏ အခြားဘက်မှ ထွက်သည်၊ သို့မဟုတ် အစိတ်အပိုင်းကို ဘက်တစ်ဘက်မှသာ ထုတ်ရမည်ဆိုလျှင် undercut ဖြစ်သည် |

အတန်းတစ်ခုစီ၏ အစိတ်အပိုင်း မျက်နှာပြင် ဧရိယာ ပါဝင်မှုကို ၎င်းဘေးတွင် ပြသည်။ **Reverse the pull** သည် mould ၏ အခြားဘက်မှ ကြည့်သည်- အစိမ်းနှင့် နီ နေရာလဲသည်။

မျဉ်းကွေးမျက်နှာများကို အမှတ်တစ်ခုချင်းစီအလိုက် စစ်ဆေးသည်၊ ထို့ကြောင့် pull ကို ဖြတ်ထားသော ဘောင်ဝိုင်း (cylinder) သည် ဘေးဘက်များတွင် draft လိုအပ်သော အစင်းကို ပြမည်။

အရောင်များသည် သင် ပြောင်းသည့်အတိုင်း အစိတ်အပိုင်းကို လိုက်သည်။ {{key:Esc}} သို့မဟုတ် {{ui:Close}} သည် analysis ကို ပိတ်သည်; အစိတ်အပိုင်းတွင် ဘာမျှ မသိမ်းပါ။

:::tip
Draft ထည့်ရန် ဝါညိုရောင် မျက်နှာများပေါ်တွင် {{ui:Draft}} feature ကို သုံးပါ ([Sweep၊ loft နှင့် draft](topic:sweep-loft-draft) ကို ကြည့်ပါ)၊ ထို့နောက် ထပ်စစ်ပါ။
:::
