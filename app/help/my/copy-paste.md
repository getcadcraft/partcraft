toolbar ရှိ {{ui:Edit}} အုပ်စုတွင် {{ui:Undo}}၊ {{ui:Redo}}၊ {{ui:Copy}}၊ {{ui:Paste}} နှင့် {{ui:More}} မီနူး ရှိပြီး ၎င်းတွင် {{ui:Cut}}၊ {{ui:Copy}}၊ {{ui:Paste}}၊ {{ui:Paste in place}}၊ {{ui:Duplicate}}၊ {{ui:Delete}}၊ {{ui:Select all}} နှင့် {{ui:Select none}} ရှိပြီး ၎င်းတို့ ကီးတစ်ခုစီ ပါပါသည်။ ကူးသည့်အရာသည် သင်ရှိနေသော နေရာပေါ် မူတည်သည်: ဖွင့်ထားသော sketch ထဲရှိ ဂျီသြမေတြီ၊ history ထဲရှိ feature သို့မဟုတ် assembly ထဲရှိ အစိတ်အပိုင်း။

မရွေးနိုင်သော (မှိန်ထားသော) အရာသည် ယခု မလုပ်နိုင်ပါ။ ၎င်းပေါ် မောက်စ်ထားပါက tooltip က အကြောင်းပြောပါမည်၊ ဥပမာ "Select sketch geometry first" သို့မဟုတ် "The clipboard holds Sketch2 and Extrude2: features paste into the history, so exit the sketch first"။

ကူးထည့်ခြင်း၊ ပွားခြင်းနှင့် ဖြတ်ခြင်း တိုင်းသည် undo စာရင်းတွင် အဆင့်တစ်ခု ဖြစ်ပါသည်: {{key:Mod+Z}} က ပြန်ယူပြီး {{key:Mod+Y}} က ပြန်ထားပါသည်။

## sketch ထဲတွင်

1. ကူးမည့်အရာကို ရွေးပါ: နှိပ်ပါ၊ နောက်ထပ်အတွက် {{key:Shift}}+နှိပ်ပါ၊ ဝင်းဒိုး ဆွဲပါ၊ သို့မဟုတ် အားလုံးအတွက် {{key:Mod+A}} ကို နှိပ်ပါ။
2. {{key:Mod+C}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Copy}} ကို ရွေးပါ။ status bar က ဘာကို ကူးသည်ကို ပြောပါသည်။
3. {{key:Mod+V}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:Paste}} ကို ရွေးပါ။ အစက်ကြောင်း မိတ္တူတစ်ခုသည် pointer ကို လိုက်ပြီး ၎င်း၏ အလယ်ဖြင့် ကိုင်ထားသည်။ point များသို့ snap လုပ်သည်: ကူးထားသော စက်ဝိုင်း၏ center ကို point ပေါ်တွင် ထားရန် ထို point ကို နှိပ်ပါ။
4. သွားလိုသော နေရာကို နှိပ်ပါ။ ကူးထည့်ထားသော ဂျီသြမေတြီသည် ရွေးထားဆဲ ဖြစ်သဖြင့် ချက်ချင်း ဆွဲနိုင်ပြီး relations ထည့်နိုင်ပါသည်။ {{key:Esc}} က ကူးထည့်ခြင်းကို ပယ်ဖျက်ပါသည်။

ပါလာသည်များ:

- ကူးထားသော မျဉ်း၊ စက်ဝိုင် သို့မဟုတ် arc တို့သည် ၎င်းတို့၏ ကိုယ်ပိုင် အဆုံး point များနှင့် center ကို ယူလာသည်။
- **ကူးထားသော အရာများကြား** relations နှင့် အတိုင်းအတာများ ပါလာသည်: ကူးထားသော ထောင့်မှန်သည် ထောင့်မှန်ဖြစ်ဆဲ ဖြစ်ပြီး အရွယ်အစားများ ပါလာသည်။
- **ကူးမထားသော ဂျီသြမေတြီ** နှင့် origin သို့ relations များကို ချန်ထားခဲ့သည်။ status bar က ရေတွက်ပြသည်: "2 relations to geometry outside the copy will not come along"။ ထို့ကြောင့် ကူးထည့်ထားသော မိတ္တူသည် relations သို့မဟုတ် အတိုင်းအတာများဖြင့် ချိတ်ဆက်မချင်း လွတ်လပ်စွာ ရွှေ့နိုင်ပါသည်။
- ပုံသေ point သည် နေရာအသစ်တွင် ပုံသေ ဆက်နေသည်။

{{ui:Paste in place}} သည် မိတ္တူကို မူရင်း coordinates အတိအကျ ထားပေးသည်၊ ဤ sketch ထဲ သို့မဟုတ် အခြား sketch ထဲတွင်ပင် ဖြစ်သည်: sketch တစ်ခုမှ profile ကို အခြား sketch သို့ ယူရန် အသုံးဝင်သည်။ တူညီသော sketch ထဲတွင် မိတ္တူသည် မူရင်းပေါ်တွင် ထိုင်နေမည်; ၎င်းကို ဆွဲ၍ ဖယ်ပါ။

{{ui:Duplicate}} ({{key:Mod+D}}) သည် ရွေးချယ်မှုကို ကူးပြီး ချက်ချင်း နေရာချစတင်သည်၊ clipboard ထဲရှိ အရာကို မထိပါ။

:::tip
ဌာနခွဲ အမှတ် သို့မဟုတ် ပေါက် အချိုးကို အကြိမ်များစွာ ထပ်လုပ်ရန် တစ်ကြိမ် ကူးပြီး အကြိမ်များစွာ ကူးထည့်ပါ: {{key:Mod+V}} တိုင်းသည် pointer ကို လိုက်သော မိတ္တူအသစ် စတင်ပါသည်။
:::

## history ထဲတွင်

1. history ရှိ sketch၊ extrude၊ revolve သို့မဟုတ် hole တစ်ခုကို နှိပ်ပါ။
2. {{key:Mod+C}} က ကူးပါသည်။ sketch အခြေခံ feature တစ်ခုကို ၎င်း၏ sketch နှင့်အတူ ကူးသည်။
3. {{key:Mod+V}} က မိတ္တူကို history အဆုံး (rollback bar ကို ပြန်ရွှေ့ထားလျှင် ထိုနေရာတွင်) ထည့်ပြီး Sketch3 နှင့် Extrude2 ကဲ့သို့ အမည်အသစ်များ ပေးသည်။

မိတ္တူသည် မူရင်းနှင့် တူညီသော ပလေန် သို့မဟုတ် မျက်နှာပေါ်တွင် ရှိပြီး ထို့ကြောင့် ၎င်းပေါ်တွင် တည်ဆောက်သဖြင့် part သည် တူညီစွာ ပေါ်သည်။ မိတ္တူကို ရွှေ့ရန် sketch အသစ်ကို ရွေးပြီး ညာဘက်ပြားတွင် ၎င်း၏ ပလေန်ကို ပြောင်းပါ၊ သို့မဟုတ် ဖွင့်ပြီး profile ကို ဆွဲပါ သို့မဟုတ် အတိုင်းအတာ ပြန်ပေးပါ။

- **အခြား part** သို့ ကူးထည့်ရန်: ထို part ကို ဖွင့်ပြီး {{key:Mod+V}} ကို နှိပ်ပါ။ ကူးထားသော sketch က ထို part တွင် မရှိသော မျက်နှာပေါ်တွင် ရှိနေခဲ့လျှင် ၎င်းသည် front ပလေန်သို့ ရောက်ပြီး status bar က ထိုအကြောင်း ပြောပါသည်။
- {{ui:Duplicate}} သည် တူညီသော part အတွင်း တစ်ဆင့်တည်းဖြင့် ကူးပြီး ကူးထည့်သည်။
- {{ui:Cut}} သည် feature ကို ကူးပြီးနောက် ဖျက်သည် (အခြား feature များ သုံးထားလျှင် ဦးစွာ မေးသည်)။

Patterns၊ mirrors၊ fillets၊ chamfers၊ shells နှင့် တင်သွင်းထားသော solids များကို ကူး၍ မရပါ: ၎င်းတို့သည် ဤ part တွင် ရွေးထားသော edges၊ မျက်နှာများ သို့မဟုတ် features ပေါ်တွင် ချိတ်ထားသည်။ ၎င်းတို့ တည်ဆောက်ထားသော sketch သို့မဟုတ် feature ကို ကူးပါ၊ သို့မဟုတ် {{ui:Linear}} သို့မဟုတ် {{ui:Circular}} ဖြင့် pattern လုပ်ပါ။

## assembly ထဲတွင်

1. view သို့မဟုတ် ဘယ်ဘက်စာရင်းတွင် အစိတ်အပိုင်းတစ်ခုကို နှိပ်ပါ။
2. {{ui:Duplicate}} ({{key:Mod+D}}) ကို ရွေးပါ၊ သို့မဟုတ် {{key:Mod+C}} ထို့နောက် {{key:Mod+V}}။

မိတ္တူအသစ်သည် **တူညီသော part** ဖြစ်ပါသည်: တစ်ခု တည်းဖြတ်လျှင် မိတ္တူအားလုံး ပြောင်းပါမည်။ ၎င်းသည် assembly ထဲရှိ အရာအားလုံး၏ ညာဘက် 20 mm တွင် ပေါ်လာပြီး မိတ္တူနှင့် တူညီသော ပုံစံဖြင့် လှည့်ထားပြီး joint က နေရာမချမချင်း ထိုနေရာတွင် ရှိနေပါသည်။ {{ui:Paste in place}} ({{key:Mod+Shift+V}}) သည် ကူးထားသော အစိတ်အပိုင်း ရှိသော နေရာအတိအကျတွင် ထားပေးသည်; ရွှေ့ရန် ချိတ်ဆက်ပါ (slider joint ၏ offset က ၎င်းကို ဘေးသို့ တွန်းသည်)။

အခြား assembly မှ ကူးထားသော အစိတ်အပိုင်းကို ကူးထည့်လျှင် အစိတ်အပိုင်းကို ယူလာပါသည်၊ ၎င်း၏ ဖိုင်မှ {{ui:Insert}} နှင့် တူညီသည်။ Assembly အုပ်စုရှိ {{ui:Add copy}} သည် {{ui:Duplicate}} နှင့် တူညီစွာ လုပ်ပြီး ဘာမျှ မရွေးထားချိန်တွင်လည်း အလုပ်လုပ်သည် (နောက်ဆုံး အစိတ်အပိုင်းကို ကူးသည်)။

## clipboard

- ၎င်းသည် PartCraft ၏ ကိုယ်ပိုင် clipboard ဖြစ်ပြီး ကွန်ပျူတာ၏ မဟုတ်ပါ: PartCraft ဂျီသြမေတြီကို အခြား program သို့ သို့မဟုတ် စာသားကို PartCraft views ထဲ ကူး၍ မရပါ။
- ၎င်းကို ဤ browser တွင် သိမ်းထားသဖြင့် အခြား PartCraft tab က သင်ကူးထားသည်ကို ကူးထည့်နိုင်သည်။ ၎င်းကို ဖွင့်ထားသော ဖိုင်ကဲ့သို့ ပြန်ဖတ်ပြီး စစ်ဆေးသည်; ပျက်စီးနေသော သို့မဟုတ် အခြား ဗားရှင်းမှ ဖြစ်သည်များကို ငြင်းပါသည်။
- Imported STEP ဖိုင် ကြီးသော အစိတ်အပိုင်းသည် browser ထဲ သိမ်းရန် ကြီးလွန်းနိုင်သည်: ထိုအခါ ဤ tab တွင်သာ ကူးထည့်ပါသည်။
