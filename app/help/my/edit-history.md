PartCraft အစိတ်အပိုင်းသည် ၎င်း၏ history ဖြစ်သည်- ဘယ်ဘက်ရှိ planes၊ sketches နှင့် features များ၏ စာရင်း။ အရာတစ်ခု ပြောင်းတိုင်း PartCraft က စာရင်း၏ထိပ်မှ solid ကို ပြန်တည်ဆောက်သည်။ စာရင်းအစောပိုင်းရှိ ကိန်းတစ်ခုကို ပြောင်းလျှင် ၎င်းပေါ်တွင် တည်ဆောက်ထားသည့် အရာအားလုံး ပြောင်းသွားမည်။

## feature တစ်ခုကို တည်းဖြတ်ရန်

1. history တွင် feature ကို (သို့မဟုတ် ၎င်းအောက်တွင် ညွှန်းထားသော sketch ကို) နှိပ်ပါ။
2. ညာဘက်ပြတင်းတွင် ၎င်း၏ ဆက်တင်များကို ပြောင်းပါ။ ပြောင်းလဲမှုတိုင်း ချက်ချင်း ပြန်တည်ဆောက်သည်။

OK သို့မဟုတ် Cancel မရှိပါ- ပြောင်းလဲမှုတိုင်း အကျုံးဝင်သည်။ မကြိုက်ပါက {{key:Mod+Z}} ကို နှိပ်ပါ။

## fillet၊ chamfer သို့မဟုတ် shell မှ အသုံးပြုသည့် အစွန်းများ သို့မဟုတ် မျက်နှာပြင်များကို ပြောင်းရန်

feature ကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် ရွေးပြီး {{ui:အစွန်းများ ရွေးရန်}} (သို့မဟုတ် {{ui:မျက်နှာပြင်များ ရွေးရန်}}) ကို ရွေးပါ။ အစွန်း သို့မဟုတ် မျက်နှာပြင်များကို နှိပ်၍ ထည့်ခြင်း သို့မဟုတ် ဖယ်ခြင်း ပြုလုပ်ပြီးနောက် {{ui:ပြီးပြီ}} သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပါ။ [Round, bevel and hollow](topic:fillet-chamfer-shell) ကို ကြည့်ပါ။

## sketch တစ်ခုကို တည်းဖြတ်ရန်

1. history တွင် sketch ကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် ရွေးပြီး ညာဘက်ပြတင်းရှိ {{ui:ပုံဆွဲချက် တည်းဖြတ်ရန်}} (သို့မဟုတ် toolbar ရှိ {{ui:Sketch}}) ကို ရွေးပါ။
2. အစိတ်အပိုင်းသည် sketch ပြုလုပ်ချိန်က အခြေအနေသို့ ပြန်သွားမည်- တည်းဖြတ်နေစဉ် ၎င်းနောက်ရှိ features များကို ဖျောက်ထားမည်။
3. ဂျီသြမေတြီ၊ relations သို့မဟုတ် dimensions များကို ပြောင်းပါ။
4. sketch ကို ပိတ်ပါ။ အစိတ်အပိုင်းတစ်ခုလုံး ပြောင်းလဲမှုဖြင့် ပြန်တည်ဆောက်မည်။

အရွယ်အစားတစ်ခုတည်းကိုသာ ပြောင်းလိုပါက sketch ကို ဖွင့်ရန် မလိုပါ။ feature သို့မဟုတ် sketch ကို ရွေးပြီး ညာဘက်ပြတင်းရှိ **Sketch dimensions** (သို့မဟုတ် **Driving dimensions**) အောက်ရှိ ကိန်းကို ပြောင်းပါ။ [Change sizes without opening the sketch](topic:change-sizes) ကို ကြည့်ပါ။

## feature မအောင်မြင်သောအခါ

ပြောင်းလဲမှုက feature တစ်ခုကို မဖြစ်နိုင်စေလျှင် PartCraft က ကျန်အရာအားလုံးကို တည်ဆောက်ပြီး ပြဿနာကို အမှတ်အသားပြုသည်-

- feature က history တွင် **⚠ error** ပြမည်။ ၎င်း၏ message ကို ညာဘက်ပြတင်း၏ ထိပ်တွင် ပြသည် (row ပေါ်တွင် hover လုပ်လည်း ဖတ်နိုင်သည်);
- ထို feature ကို လိုအပ်သော features များက **⚠ not built** ပြမည်၊ "Needs Extrude2, which is failing." ဟု ဖော်ပြမည်;
- အခြေအနေဘားရှိ chip က "1 feature failing" ဟု ပြမည်။

အကြောင်းရင်းကို ပြင်ပါ (သို့မဟုတ် undo လုပ်ပါ)၊ အစိတ်အပိုင်းသည် ပြန်တည်ဆောက်မည်။ အဖြစ်များသော message များနှင့် ပြုလုပ်ရမည့်အရာများကို [Troubleshooting](topic:troubleshooting) တွင် ကြည့်ပါ။

## feature တစ်ခုကို ပိတ်ထားရန်

Suppress ဖြင့် feature ကို ဖျက်ခြင်းမရှိဘဲ ပိတ်ထားသည်- အပေါက် သို့မဟုတ် pattern မပါဘဲ အစိတ်အပိုင်းကို စမ်းကြည့်ရန် အသုံးဝင်သည်။

1. feature ကို ရွေးပါ။
2. {{ui:ပိတ်ထားရန်}} ကို ရွေးပါ။ ၎င်း၏ row တွင် **off** ပြမည်။ ၎င်းကို လိုအပ်သော features များလည်း မတည်ဆောက်ပါ။
3. ပြန်ဖွင့်ရန် {{ui:ပြန်ဖွင့်ရန်}} ကို ရွေးပါ။

## ပြန်သွားရန် (Roll back)

Rollback ဖြင့် အစိတ်အပိုင်းကို အမှတ်တစ်ခုအထိသာ တည်ဆောက်သည်၊ ထို့ကြောင့် မူလအခြေအနေကို မြင်နိုင်ပြီး history တွင် အစောပိုင်းတွင် feature ထည့်နိုင်သည်။

1. feature ကို ရွေးပြီး {{ui:ဤနေရာသို့ ပြန်သွားရန်}} ကို ရွေးပါ။ ထို feature နှင့် ၎င်းအောက်ရှိ feature အားလုံးကို မီးခိုးရောင်ပြပြီး မတည်ဆောက်ပါ။ **Rollback bar · ရှေ့သို့ ပြန်ဆက်ရန်** row က နေရာကို အမှတ်အသားပြုမည်။
2. ယခု ထည့်သော feature မည်သည်ကိုမဆို **bar တွင်** ထည့်မည်၊ မီးခိုးရောင် features များ၏ ရှေ့တွင်။
3. အရာအားလုံးကို ပြန်တည်ဆောက်ရန် **Rollback bar · ရှေ့သို့ ပြန်ဆက်ရန်** ကို နှိပ်ပါ။

rollback နေရာကို ဖိုင်တွင် သိမ်းထားသည်။

## features များ အစီအစဉ်ပြန်စီရန်

1. feature ကို ရွေးပါ။
2. {{ui:အပေါ်သို့ ရွှေ့ရန်}} သို့မဟုတ် {{ui:အောက်သို့ ရွှေ့ရန်}} ကို ရွေးပါ၊ သို့မဟုတ် history row ကို focus ထားပြီး {{key:Alt+Up}} သို့မဟုတ် {{key:Alt+Down}} ကို နှိပ်ပါ။

feature သည် ၎င်းအသုံးပြုသော အရာထက် အပေါ်သို့ ဘယ်တော့မှ မရွှေ့နိုင်ပါ။ ခလုတ်မီးခိုးရောင်ဖြစ်ပြီး hover လုပ်လျှင် (သို့မဟုတ် key ကို စမ်းလျှင်) အကြောင်းရင်းကို ပြမည်၊ ဥပမာ "Extrude2 uses Sketch2, so Sketch2 has to come first." ။

feature က အသုံးပြုသည်များ- ၎င်း၏ sketch; sketch ထိုင်နေသော မျက်နှာပြင်; pattern သို့မဟုတ် mirror ကူးသော features များ; direction သို့မဟုတ် axis အဖြစ် အသုံးပြုသော sketch line သို့မဟုတ် revolve။

## feature တစ်ခုကို ဖျက်ရန်

1. feature ကို ရွေးပြီး ညာဘက်ပြတင်း သို့မဟုတ် toolbar ရှိ {{ui:ဖျက်ရန်}} ကို ရွေးပါ၊ သို့မဟုတ် {{key:Delete}} ကို နှိပ်ပါ။
2. အခြား features များက အသုံးပြုနေလျှင် PartCraft က မေးမည်- "Extrude3, Hole1 use Extrude1 and will be deleted too." {{ui:အားလုံးဖျက်ရန်}} သို့မဟုတ် {{ui:ပယ်ဖျက်ရန်}} ကို ရွေးပါ။

feature ကို ဖျက်ခြင်းသည် ၎င်း၏ sketch ကို မဖျက်ပါ- sketch သည် အသုံးမပြုသော sketch အဖြစ် view တွင် ပြန်ပေါ်လာပြီး အခြား feature အတွက် အဆင်သင့်ဖြစ်မည်။ မလိုအပ်လျှင် sketch ကို သီးခြား ဖျက်ပါ။

## အမည်ပြောင်းရန်

feature ကို ရွေးပြီး ညာဘက်ပြတင်းအောက်ဆုံးရှိ **Name** တွင် အမည်အသစ်ရိုက်ပါ (စာလုံး 60 အထိ)။ အရာမရွေးထားသောအခါ အစိတ်အပိုင်း၏ အမည်ကို ညာဘက်ပြတင်းတွင် ပြသည်။

## feature ရာချီပါသော အစိတ်အပိုင်းများ

feature ရာချီပါသော အစိတ်အပိုင်းကို 750 ဖြင့် စမ်းသပ်ထားသည်။ PartCraft က history ၏ အလယ်တွင် ရှိသော solid ကို သိမ်းထားသဖြင့် history နောက်ပိုင်းရှိ ပြောင်းလဲမှုက ၎င်းနောက်ရှိ features များကိုသာ ပြန်တည်ဆောက်မည်။ အပေါ်ပိုင်းရှိ ပြောင်းလဲမှုက ၎င်းပေါ်ရှိ အရာအားလုံးကို ပြန်တည်ဆောက်ပြီး အချိန်အအကြာဆုံး ဖြစ်သည်။ Undo နှင့် redo သည် နှစ်ခုကွဲပြားသော နေရာမှစ၍သာ ပြန်တည်ဆောက်သည်။ ကြီးသော အစိတ်အပိုင်းကို ပိုမြန်အောင် လုပ်ရန် လုပ်နေသော နေရာသို့ rollback လုပ်ပါ (အထက်ရှိ ပြန်သွားရန် ကို ကြည့်ပါ) သို့မဟုတ် ယခု မလိုသည်များကို suppress လုပ်ပါ။ အချင်းချင်း မထိသော ဖြတ်ခြင်းနှင့် boss များကို အတူတကွ လျှောက်သဖြင့် အပေါက်နှင့် boss များစွာဖြင့် ဖွဲ့စည်းထားသော အစိတ်အပိုင်းသည် features အရေအတွက်ထက် ပိုမြန်စွာ တည်ဆောက်သည်။

ကြီးသော အစိတ်အပိုင်းသည် နောက်ခံတွင် ပြန်တည်ဆောက်သည်- အောက်ခြေရှိ build chip က **Rebuilding…** နှင့် ဘယ်လောက်ရောက်ပြီဆိုသည်ကို ပြသည်၊ view၊ ပြတင်းများနှင့် menus များသည် ဆက်လုပ်နိုင်သည်။ အသစ်မပြီးမချင်း စခရင်ပေါ်ရှိ အစိတ်အပိုင်းသည် နောက်ဆုံး တည်ဆောက်ပြီးသော ဗားရှင်း ဖြစ်သည်။ ပြန်တည်ဆောက်နေစဉ် တစ်ခုခုကို ထပ်ပြောင်းလျှင် PartCraft က နောက်ဆုံးဗားရှင်းကို တည်ဆောက်ပြီး မပြီးသေးသောအရာကို ချန်လှပ်မည်။ အသေးစား အစိတ်အပိုင်းသည် ချက်ချင်း ပြန်တည်ဆောက်သည်။

## Undo နှင့် redo

- {{key:Mod+Z}} သို့မဟုတ် {{ui:ပြန်ဖျက်ရန်}} သည် နောက်ဆုံးပြောင်းလဲမှုကို ပြန်ဖျက်သည်- feature၊ ဆက်တင်၊ sketch တည်းဖြတ်မှု၊ ဆွဲချမှု။ အခြေအနေဘားက ဥပမာ "Undid change dimension." ဟု ပြသည်။
- {{key:Mod+Y}}၊ {{key:Mod+Shift+Z}} သို့မဟုတ် {{ui:ပြန်လုပ်ရန်}} သည် ပြန်လုပ်သည်။
