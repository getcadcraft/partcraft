မော်ဒယ်ကို မော်ဒယ်လုပ်သည့်နေရာတွင် ဆက်ပုံဖော်ပါ၊ ဤနေရာတွင် စက်ဖြင့်လုပ်ခြင်း၊ စစ်ဆေးခြင်းနှင့် မှတ်တမ်းတင်ခြင်းကို လုပ်ပါ။ အခြား program ရှိ ပြောင်းလဲမှုတိုင်းသည် PartCraft ရှိ သွင်းထားသော body တစ်ခုကို အစားထိုးပြီး ၎င်းနောက်ရှိ feature များသည် ပုံသစ်ပေါ်တွင် ပြန်တည်ဆောက်သည်။

:::note
ချိတ်ဆက်မှုအတွက် ကွန်ပျူတာတစ်လုံးတည်းတွင် **CadCraft Studio** လိုအပ်သည်။ browser tab က ချိတ်ဆက်မှုကို မလုပ်နိုင်ပါ။ အင်တာနက်ဖြင့် မည်သည်ကိုမျှ မပို့ပါ: script သည် ဤကွန်ပျူတာ၏ ကိုယ်ပိုင်လိပ်စာဖြင့် token တစ်ခုနှင့်အတူ Studio နှင့် စကားပြောသည်။
:::

:::warning
ဤချိတ်ဆက်မှုကို script ၏ file writer နှင့် အခြား program အတွက် ထိုးထည့်ထားသော အစားထိုးတစ်ခုဖြင့် စမ်းသပ်ပြီးဖြစ်သည်၊ Rhino သို့မဟုတ် Grasshopper အတွင်းတွင် တိုက်ရိုက် မစမ်းရသေးပါ။ ထိုနေရာတွင် မအောင်မြင်ပါက ၎င်းက ဘာပြောသည်ကို ကျွန်ုပ်တို့အား ပြောပြပါ။
:::

## ပြင်ဆင်ခြင်း

1. Studio တွင် PartCraft ကို ဖွင့်ပါ။ {{ui:Settings}} › {{ui:PartCraft}} › {{ui:Assistants}} တွင် **Let AI assistants and scripts use PartCraft** ကို အမှန်ခြစ်ပြီး ထို့နောက် **ပြင်ရန်** ကို နှိပ်ပါ။
2. Studio တွင် {{ui:Connect an assistant}} ကို ရွေးပါ။ ၎င်းက လိပ်စာနှင့် အောက်တွင် ကူးထည့်ရမည့် token ကို ပြသသည်။
3. script ကို ဒေါင်းလုဒ်ဆွဲပါ: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py)။

## Rhino မှ

1. Rhino ၏ script editor တွင် `cadcraft_link.py` ကို လုပ်ဆောင်ပါ (Rhino 8 တွင် Python 3)။
2. ပထမအကြိမ်တွင် လိပ်စာနှင့် token ကို ကူးထည့်ပါ။ ၎င်းတို့ကို သင့် home folder ရှိ `.cadcraft-link.json` တွင် သိမ်းထားပြီး model ထဲတွင် ဘယ်တော့မှ မထားပါ။ Studio သည် စတင်တိုင်း token အသစ် ပြုလုပ်သဖြင့် script က ထိုအခါ ထပ်မေးသည်။

ရပ်ရန် script ကို ထပ်လုပ်ဆောင်ပါ။

## Grasshopper မှ

အရင် Rhino တွင် script ကို တစ်ကြိမ်လုပ်ဆောင်ပါ ထို့ကြောင့် လိပ်စာနှင့် token ကို သိမ်းထားမည်။

1. Script component (Python 3) တစ်ခု ထည့်ပြီး `cadcraft_link.py` တစ်ခုလုံးကို ထဲသို့ ကူးထည့်ပါ။
2. အောက်ပါ input များကို ပေးပါ: `G` (geometry၊ list access ဖြင့်)၊ `N` (အမည်၊ မဖြစ်မနေမဟုတ်)၊ `On` (boolean toggle)၊ နှင့် `Target` (မဖြစ်မနေမဟုတ်: `model` သို့မဟုတ် `part`၊ app နှစ်ခုလုံး ဖွင့်ထားပါက)။
3. `On` ကို true သို့ လှည့်ပါ။

Solve တိုင်း `G` ကို ပို့ပြီး နောက်ဆုံးပို့ထားသည်ကို အစားထိုးသည်။

## ဤနေရာတွင် မည်သို့အလုပ်လုပ်သလဲ

- **Body တစ်ခု။** model တွင် မြင်ရသည့် အရာအားလုံးသည် သွင်းထားသော feature တစ်ခု ဖြစ်လာသည်၊ [open a .3dm file](topic:open-3dm-files) ကို ဖွင့်သကဲ့သို့ပင်။
- **ပိတ်ရမည်။** PartCraft သည် သေးငယ်သော အပေါက်များနှင့် ပြားသော ပွင့်နေသော နေရာများကို ဖြည့်ပေးပြီး အခြား program သို့ ဘယ်နှစ်ခု ဖြည့်ခဲ့သည်ကို အကြောင်းကြားသည်။ model သည် မပိတ်သေးပါက PartCraft သည် ယခင်ရှိသော body ကိုထားပြီး status bar က ထိုသို့ ပြောသည်။ ပိတ်သွားသော နောက်ပြောင်းလဲမှုက ၎င်းကို အပ်ဒိတ်လုပ်မည်။
- **လုပ်နေသည်ကို ပြီးအောင်လုပ်ပါ။** sketch သို့မဟုတ် drawing တွင် အပ်ဒိတ်များကို ငြင်းပြီး ထပ်ကြိုးစားသည်; model သို့ ပြန်ရောက်သောအခါ ရောက်ရှိမည်။
- **Undo။** တစ်ခုနှင့်တစ်ခု စက္ကန့် ၂ ခုအတွင်း အပ်ဒိတ်များသည် undo အဆင့်တစ်ခုကို မျှသည်။
- **Save။** part ဖိုင်က ချိတ်ဆက်မှုကို ထိန်းထားသည်။ ဖိုင်ကို ပြန်ဖွင့်ပြီးနောက် script ကို ထပ်လုပ်ဆောင်ပါ၊ ထို့နောက် တူညီသော feature ကို အပ်ဒိတ်လုပ်သည်။

**တစ်ဖက်သတ်သာ။** ဤနေရာမှ ပြောင်းလဲမှုများသည် အခြား program သို့ ပြန်မသွားပါ။

## တစ်ခုခု မှားသွားပါက

- **"No ModelCraft or PartCraft window allows it":** ပြင်ဆင်ခြင်း အဆင့် ၁ ကို လုပ်ပါ။
- **"Studio refused the token":** Studio ပြန်စတင်သွားပါပြီ။ token အသစ်ကို ကူးပြီး script ကို ထပ်လုပ်ဆောင်ပါ။ Grasshopper အတွက် အရင် Rhino တွင် လုပ်ဆောင်ပါ။
- **"Cannot reach CadCraft Studio":** Studio မလည်ပတ်နေပါ၊ သို့မဟုတ် လိပ်စာပြောင်းသွားပါပြီ။
