## သင် သိရှိမည့်အရာ

AI assistant (သို့မဟုတ် သင်ရေးထားသော script) က ဖွင့်ထားသော အစိတ်အပိုင်းကို ကြည့်ခြင်း၊ ၎င်း၏ parameters ကို ပြောင်းခြင်း၊ script ကို လုပ်ဆောင်ပြီး ထုတ်ခြင်း၊ နှင့် ၎င်း တို့ထိနိုင်သည့်အရာကို သင် မည်သို့ ဆုံးဖြတ်သည်ကို ခွင့်ပြုပုံ။

PartCraft တွင် **ကိုယ်ပိုင် AI မရှိပါ** နှင့် မည်သည့်နေရာသို့မျှ ဘာမျှ မပို့ပါ။ assistant ကို သင် ယူလာပါ: Model Context Protocol (MCP) ကို နားလည်သည့် မည်သည့် ပရိုဂရမ်မဆို။ PartCraft က tools များကိုသာ ပေးပြီး မည်သည်ကို ရွေးသည်ကို သင် ရွေးသည်။

## ဖွင့်ရန်

1. {{ui:ဆက်တင်များ}} ကို ဖွင့်ပါ (app bar ရှိ gear သို့မဟုတ် {{key:Mod+,}}) ပြီး {{ui:PartCraft}} tab သို့ သွားပါ။
2. {{ui:အကူအညီပေးသူများ}} အောက်တွင် **AI assistant နှင့် script များကို PartCraft သုံးခွင့်ပြုရန်** ကို အမှန်ခြစ်ပါ။ သင် မလုပ်မချင်း ပိတ်ထားသည်။
3. ၎င်း လုပ်ခွင့်ရှိသည့်အရာကို ရွေးပါ။ **ဖတ်ရန်** ကို အစမှာ အမှန်ခြစ်ထားသည်; အခြားများကို လိုအပ်သည့်အခါမှသာ အမှန်ခြစ်ပါ။
4. ထုတ်ခြင်းနှင့် ဖိုဒါထဲ သိမ်းခွင့်ပေးရန် **အသုံးပြုနိုင်သော ဖိုဒါများ** အောက်ရှိ {{ui:ဖိုဒါ ထည့်ရန်…}} ကို ရွေးပြီး Studio ၏ ဒိုင်ယာလော့ခ်တွင် ဖိုဒါကို ရွေးပါ။

Assistant များသည် သင့်ကွန်ပျူတာရှိ **CadCraft Studio** မှတစ်ဆင့် ချိတ်ဆက်သည်။ Studio က လိပ်စာနှင့် assistant ထဲသို့ ကူးထည့်ရန် token ကို ပြသသည်။ browser tab သည် assistant အတွက် ချိတ်ဆက်မှုကို ဖွင့်၍ မရပါ။

## assistant က တောင်းဆိုနိုင်သည့်အရာ

| Tool | ခွင့်ပြုချက် | ဘာလုပ်သလဲ |
|---|---|---|
| `part_describe`, `features_list` | ဖတ်ရန် | features များကို အစဉ်လိုက်၊ ဘာတည်ဆောက်ပြီး ဘာမအောင်မြင်သည်၊ ပစ္စည်း၊ solid ၏ ထုထည်နှင့် အရွယ်အစား |
| `params_list` | ဖတ်ရန် | parameters နှင့် equation တစ်ခုက မောင်းနိုင်သော ဂဏန်းအားလုံး၊ တန်ဖိုးများနှင့်အတူ |
| `mass_properties` | ဖတ်ရန် | ထုထည်၊ ဧရိယာ၊ အလေးချိန်ဗဟို၊ ၎င်းပတ်လည် inertia; အစိတ်အပိုင်းတွင် ပစ္စည်းရှိလျှင် အလေးချိန် |
| `param_set` | တည်းဖြတ်ရန် | parameter သို့မဟုတ် feature ၏ ဂဏန်းကို သတ်မှတ်ပြီး ပြန်တည်ဆောက်သည်။ ပြန်ဖျက်နိုင်သော အဆင့်တစ်ခု |
| `script_run` | တည်းဖြတ်ရန် | {{ui:Script}} workspace လုပ်သည့်နည်းဖြင့် CraftScript, Lua သို့မဟုတ် Python script ကို လုပ်ဆောင်သည်: ပိတ်ထား၊ ဖိုင်နှင့် network မရှိ။ အစိတ်အပိုင်း မပြောင်းပါ |
| `part_export` | ထုတ်ရန် | STL, 3MF, STEP သို့မဟုတ် OpenUSD (.usdz, .usda, .usdc), {{ui:ဖိုင်}} › {{ui:ထုတ်ရန်}} ရေးသည့်ပုံစံအတိုင်း |
| `link_push` | တည်းဖြတ်ရန် | အခြားပရိုဂရမ်မှ ချိတ်ဆက်ထားသော မော်ဒယ်ကို အပ်ဒိတ်လုပ်သည် ([.3dm မော်ဒယ်ကို live ထားရန်](topic:live-3dm-link) ကို ကြည့်ပါ) |
| `link_status` | ဖတ်ရန် | ချိတ်ဆက်ထားသော မော်ဒယ် ရှိနေသေးခြင်း ရှိ/မရှိနှင့် နောက်ဆုံး အပ်ဒိတ်လုပ်ခဲ့သည့် အချိန်ကို ပြောသည် |
| `part_save` | သိမ်းရန် | PartCraft ၏ ကိုယ်ပိုင် {{ui:သိမ်းရန်}} |
| `illustrate_export` | ထုတ်ရန် | {{ui:Illustrate}} workspace မှ လက်စွဲကို PDF သို့မဟုတ် SVG မျဉ်းပုံအဖြစ် ၎င်း၏ မြင်ကွင်းများ၊ သို့မဟုတ် အပြန်အလှန်ဆက်သွယ်နိုင်သော 3D ဖိုင်အဖြစ်၊ သို့မဟုတ် ၎င်း၏ {{ui:ညွှန်ကြားချက်များ}} ကို PDF သို့မဟုတ် web page အဖြစ် ထုတ်သည်၊ workspace ၏ {{ui:ထုတ်ရန်}} နှင့် {{ui:ညွှန်ကြားချက်များ}} menu များ ရေးသည့်အတိုင်း ([လက်စွဲများ](topic:illustrate)) |

:::note
ဤ build သည် mesh kernel ကို အသုံးပြုသည်: ထုထည်များသည် တြိဂံများမှ ရသည် (မျဉ်းကွေး solid အမှန်ထက် အနည်းငယ် နည်းသည်)၊ နှင့် STEP ကို faceted အဖြစ် တိကျသော မျက်နှာပြင်များအစား တြိဂံများဖြင့် ရေးသည်။
:::

## သင် ထိန်းချုပ်ထားသည်

- **ပြောင်းလဲမှုတိုင်းသည် ပြန်ဖျက်မှု အဆင့်တစ်ခု ဖြစ်သည်**၊ assistant အတွက် အမှတ်အသားပါသည်၊ ဥပမာ "Assistant: set l = 45"။ ပြန်ယူရန် {{key:Mod+Z}} ကို နှိပ်ပါ။
- **ချိတ်ဆက်ထားမှုကို သင် သိသည်။** ချိတ်ဆက်ထားစဉ် app bar ရှိ ခလုတ်တစ်ခုက assistant ကို အမည်ပေးသည်။ ၎င်း လုပ်ခွင့်ရှိသည့်အရာကို ကြည့်ရန် သို့မဟုတ် **ချိတ်ဆက်ဖြတ်ရန်** ရန် ၎င်းကို နှိပ်ပါ။
- **လှုပ်ရှားမှု။** {{ui:ဆက်တင်များ}} › {{ui:PartCraft}} › {{ui:အကူအညီပေးသူများ}} › {{ui:လှုပ်ရှားမှု}} တွင် ခေါ်ဆိုမှုတိုင်းကို စာရင်းပြသည်; {{ui:မှတ်တမ်းကို သိမ်းရန်}} က မိတ္တူတစ်ခု သိမ်းထားသည်။
- **ဖိုဒါများ။** ၎င်းသည် သင် ထည့်ထားသော ဖိုဒါများထဲရှိ ဖိုင်များကိုသာ ဖတ်ပြီး ရေးသည်။ {{ui:ဖယ်ရန်}} က ဖိုဒါကို ချက်ချင်း ပြန်ယူသည်။

## PartCraft မဖွင့်ဘဲ

assistant အတွက် CadCraft ဖိုင်ဆာဗာ (`npx @getcadcraft/mcp`) နှင့် `cadcraft` command line သည် `.partcraft.json` အစိတ်အပိုင်းများကို PartCraft ၏ ကိုယ်ပိုင်ကုဒ်နှင့် mesh kernel ဖြင့် ဝင်းဒိုးမပါဘဲ ဖွင့်သည်: တူညီသော ဖတ်ရှုရေး tools၊ parameters သတ်မှတ်ခြင်း၊ CraftScript scripts၊ ထုတ်ခြင်း (OpenUSD ပါ) နှင့် သိမ်းခြင်း။ `cadcraft convert bracket.partcraft.json bracket.stl` သည် အစိတ်အပိုင်းတစ်ခု တည်ဆောက်ပြီး command line မှ ရေးသည်။ လက်စွဲများ (`.partcraft-manual.json`) ကိုလည်း ထိုနေရာတွင် ထုတ်နိုင်သည်: `illustrate_export`၊ သို့မဟုတ် `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (ညွှန်ကြားချက်များအတွက် `--instructions` ထည့်ပါ)။

## မအောင်မြင်ပါက

- **"needs the edit permission":** {{ui:အကူအညီပေးသူများ}} အောက်တွင် **တည်းဖြတ်ရန်** ကို အမှန်ခြစ်ပြီး ထပ်မေးပါ။
- **"driven by the equation":** ထိုဂဏန်းသည် parameter တစ်ခုကို နောက်လိုက်သည်; ထို့အစား parameter ကို သတ်မှတ်ရန် assistant ကို မေးပါ။
- **ပြောင်းလဲမှု မှားနေပါက:** {{key:Mod+Z}} ကို နှိပ်ပါ။
