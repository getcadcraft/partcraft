## သင် သိရှိမည့်အရာ

လူများစွာက အစိတ်အပိုင်းတစ်ခုကို တစ်ပြိုင်နက် မော်ဒယ်လုပ်သည့်အခါ ၎င်းတွင် ဘာဖြစ်သလဲ။ CadCraft Studio သည် Live TeamWork session ကို စတင်ပြီး ဝင်ရောက် (Share, Join) ပေးသည်; ဤစာမျက်နှာသည် အစိတ်အပိုင်းကိုယ်တိုင်အကြောင်း ဖြစ်သည်။

## လူအားလုံး တစ်ပြိုင်နက် မော်ဒယ်လုပ်သည်

လူတိုင်း တူညီသော feature tree ပေါ်တွင် အလုပ်လုပ်သည်: sketches၊ extrudes၊ holes၊ patterns၊ fillets၊ parameters။ သင့် ကိုယ်ပိုင် တည်းဖြတ်မှုများကို ချက်ချင်း ပြသည်; တခြားသူများ၏ တည်းဖြတ်မှုများကို ၎င်းတို့ ပြုလုပ်ပြီး ခဏအကြာတွင် ပေါ်လာသည်။ tree သာ ရွေ့သည်: window တိုင်းသည် solid ကို ကိုယ်တိုင် တည်ဆောက်ပြီး PartCraft ၏ kernel သည် tree တူတူမှ solid တူတူကို window တိုင်းတွင် တည်ဆောက်သည်။

- **လူနှစ်ယောက်က feature တစ်ခုကို ပြောင်းလျှင်:** ကွဲပြားသော ဆက်တင်များ (တစ်ယောက်က အနက်၊ တစ်ယောက်က အဆုံးအခြေအနေ) နှစ်ခုလုံး ထိန်းထားသည်; ဆက်တင်တူလျှင် နောက်ပြောင်းလဲမှုကို ယူသည်။
- **Sketch** သည် တစ်ခုလုံးအဖြစ် ရွေ့သည်: လူနှစ်ယောက်က sketch တစ်ခုကို တစ်ပြိုင်နက် တည်းဖြတ်လျှင် နောက်ဆုံး တည်းဖြတ်မှု အနိုင်ရသည်။ ဘယ်သူက ဘယ် sketch ကို ဆွဲမလဲ သဘောတူပါ။
- **ယခုမှ ဖျက်လိုက်သော feature တစ်ခုပေါ်တွင် တည်ဆောက်ထားသော feature** (ဖျက်ထားသော sketch ၏ extrude၊ ဖျက်ထားသော မျက်နှာပေါ်ရှိ အပေါက်) ကို ပြန်ယူပြီး status bar က အကြောင်းပြသည်။
- **Tree ကို ပြန်စီခြင်း** စစ်ဆေးထားသည်: လူနှစ်ယောက်က features များကို တစ်ချိန်တည်း ဆွဲလျှင် ဒုတိယ ရွှေ့မှုကို ပြန်ယူသည်။

## တစ်ဦးကို တစ်ဦး မြင်ရခြင်း

session ရှိ လူတိုင်းတွင် ကိုယ်ပိုင်အရောင် ရှိသည်။ လူတိုင်း၏ pointer ကို ၎င်းတို့ ညွှန်ပြနေသော မျက်နှာပေါ်တွင် ၎င်းတို့အရောင်ဖြင့် မြားတစ်ခုအဖြစ် ၎င်းတို့၏ အမည်ဘေးတွင် မြင်ရသည်။ tree တွင် feature တစ်ခုကို ရွေးထားလျှင် ၎င်း၏ အမည်သည် ၎င်းတို့ အမည်နောက်တွင် ပေါ်လာသည်။

Pointers၊ အမည်များနှင့် ရွေးချယ်မှုများသည် session အတွက်သာ ဖြစ်သည်: ဖိုင်တွင် ဘယ်တော့မှ မသိမ်းပြီး ဘယ်သူ့ undo ထဲမှ မဝင်ပါ။ ၎င်းတို့သည် လူတိုင်း ရှိနေရာသို့ ချောမွေ့စွာ ရွေ့သဖြင့် ချိတ်ဆက်မှု နှေးလျှင်လည်း ချောမွေ့နေသည်။

## Undo သည် သင့်ကိုယ်ပိုင် အလုပ်ကို ပြန်ယူသည်

{{key:Mod+Z}} သည် သင့်ကိုယ်ပိုင် နောက်ဆုံး တည်းဖြတ်မှုကို ပြန်ယူပြီး တခြားသူများကို မထိပါ။ ထို့နောက် တူညီသည်ကို တစ်စုံတစ်ယောက် ပြောင်းလဲခဲ့လျှင် ဘာမျှ ပြန်မယူရပါ၊ status bar က ဘယ်သူဟု ပြောသည်။

## browser မှ ဝင်ရောက်ခြင်း

Studio မရှိသော အဖော်တစ်ယောက်သည် host ၏ ကုဒ်အောက်ရှိ ပုံကို ဖုန်း၊ တက်ဘလက် သို့မဟုတ် ကွန်ပျူတာ ဖြင့် တူညီသော network ပေါ်မှ စကင်ဖတ်နိုင်သည်။ PartCraft သည် browser တွင် ဖွင့်ပြီး host က ဝင်ခွင့်ပေးသည်နှင့် host ၏ အစိတ်အပိုင်းဖြင့် ဖြည့်ပြီး တည်ဆောက်သည်။ invite link သည် တခြား network မှ ဝင်ခွင့် ပေးနိုင်သည်: host သည် app အတွက် Team Cloud Plan seat လိုအပ်သည်၊ အခြားသူတိုင်း အခမဲ့ ဝင်ရသည်၊ link သည် host ၏ session ဖွင့်နေချိန်တွင်သာ အလုပ်လုပ်သည်။

## session ပြီးဆုံးချိန်

host သာ အစိတ်အပိုင်းကို သိမ်းသည်။ တခြားသူအားလုံးက မသိမ်းရသေးသော မိတ္တူကို ထားရသည်: ထိန်းချင်လျှင် သိမ်းပါ။

:::note
အစုအဝေးများကို session တွင် မမျှဝေရသေးပါ: အတူတကွ လုပ်ဆောင်ရန် အစိတ်အပိုင်းကိုသာ ဖွင့်ပါ။
:::
