ပါရာမီတာသည် အမည်ပေးထားသော ဂဏန်းတစ်ခု ဖြစ်သည်၊ ဥပမာ `width = 120` သို့မဟုတ် `margin = bolt * 1.5`။ အနက်၊ အပေါက် အချင်း၊ pattern အရေအတွက် သို့မဟုတ် sketch dimension တစ်ခုကို ၎င်းနှင့် ချိတ်လိုက်လျှင် ပါရာမီတာကို ပြောင်းသည်နှင့် ထိုအရာအားလုံး တစ်ကြိမ်တည်း ပြောင်းသည်။ ဤနည်းဖြင့် ဒီဇိုင်း ရည်ရွယ်ချက်ကို သင့်ခေါင်းထဲမှာ မဟုတ်ဘဲ အစိတ်အပိုင်းထဲမှာ ထိန်းထားနိုင်သည်။

## ပါရာမီတာ ထည့်ခြင်း

1. ညာဘက် panel ရှိ {{ui:ပါရာမီတာများ}} tab ကို နှိပ်ပါ။
2. **Variables** အောက်တွင် "name" အကွက်တွင် အမည် ရိုက်ပါ၊ ဥပမာ `width`။
3. နောက်အကွက်တွင် တန်ဖိုးကို ရိုက်ပါ၊ ဥပမာ `120`၊ ပြီး {{key:Enter}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:ထည့်ရန်}} ကို နှိပ်ပါ)။

တန်ဖိုးသည် ဂဏန်း သို့မဟုတ် အခြားပါရာမီတာများ၏ expression ဖြစ်နိုင်သည်: `bolt * 1.5`၊ `width / 2 - 10`၊ `if(width > 100, 6, 4)`။ **Value** ကော်လံက ၎င်း ဘာဖြစ်သွားသလဲ ပြသည်။ အမည်သည် အက္ခရာ သို့မဟုတ် `_` ဖြင့် စတင်ပြီး အက္ခရာ၊ ဂဏန်းနှင့် `_` သာ ပါသည်; function နှင့် ယူနစ် အမည်များ (`sin`၊ `mm`၊ `pi`) ကို ငြင်းသည်၊ `a = b` နှင့် `b = a` ကဲ့သို့ loop ကိုလည်း ငြင်းသည်။

## ဂဏန်းကို ပါရာမီတာနှင့် ချိတ်ခြင်း

1. history ရှိ feature တစ်ခုကို နှိပ်ပါ၊ ဥပမာ "Extrude1"။ ၎င်း၏ ဆက်တင်များကို {{ui:ဂုဏ်သတ္တိများ}} tab တွင် ပြသည်။
2. **Depth (mm)** ကဲ့သို့ ဂဏန်းအကွက်တွင် `=` နှင့် expression ရိုက်ပါ: `=thick` သို့မဟုတ် `=width / 4`။
3. {{key:Enter}} ကို နှိပ်ပါ။

အကွက်က ရလဒ်ကို ယခု ပြပြီး၊ အညွှန်းဘေး **ƒ** ခလုတ် ပေါ်လာသည်။ ၎င်းပေါ် ညွှန်လျှင် ညီမျှခြင်းကို မြင်ရသည်။ sketch dimension များလည်း အတူတူ အလုပ်လုပ်သည်၊ feature ၏ **Sketch dimensions** စာရင်းနှင့် ဖွင့်ထားသော sketch ၏ dimension အကွက်နှစ်ခုစလုံးတွင် (dimension ကို နှစ်ကြိမ်နှိပ်၊ `=width` ရိုက်၊ {{key:Enter}} ကို နှိပ်ပါ)။

ချိတ်နိုင်သော ဂဏန်းများ: extrude အနက်၊ revolve ထောင့်၊ hole အချင်း၊ အနက်နှင့် counterbore အရွယ်များ၊ pattern အရေအတွက်၊ အကွာအဝေးနှင့် ထောင့်၊ fillet အချင်းဝက်၊ chamfer အကွာအဝေး၊ shell နံရံအထူ၊ sketch dimension တိုင်း၊ နှင့် feature အသစ်များ၏ အရွယ်အစားများ (ဒုတိယ အနက်၊ taper၊ countersink၊ reference plane အကွာအဝေး၊ draft ထောင့် နှင့် အခြား)။

## ပါရာမီတာ ပြောင်းခြင်း

{{ui:ပါရာမီတာများ}} tab တွင် **Expression** ကော်လံ၌ တန်ဖိုးအသစ် သို့မဟုတ် expression ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ ၎င်းနှင့် ချိတ်ထားသောအရာအားလုံး ပြောင်းပြီး အစိတ်အပိုင်း ပြန်တည်ဆောက်သည်၊ အဆင့်တစ်ခုတည်းအဖြစ်: {{key:Mod+Z}} က ပြန်ဖျက်သည်။

ဂဏန်းကို အခြားဘက်မှ ပြောင်းလိုလျှင် [Equations both ways](topic:equations-two-way) ကို ကြည့်ပါ။

## ပါရာမီတာ ဘယ်မှာ သုံးသလဲ ကြည့်ခြင်း

{{ui:ပါရာမီတာများ}} tab တွင် ပါရာမီတာတစ်ခုအောက်တွင် ၎င်းကို ဘာသုံးသလဲ ပြောသော စာကြောင်းတစ်ကြောင်း ရှိသည်:

- ၎င်း မောင်းနှင်သော ဂဏန်းများ၊ ဥပမာ **Extrude1 depth** သို့မဟုတ် **Sketch1 D2 (distance)**။ တစ်ခုကို နှိပ်လျှင် feature ကို ရွေးပြီး ၎င်း၏ ဂုဏ်သတ္တိများ ပြသည်;
- ပါရာမီတာ အခြားတစ်ခု မှတစ်ဆင့် **ဖြတ်၍** မောင်းနှင်သော ဂဏန်းများ၊ ဥပမာ `d = h + 2` နှင့် `h = w / 2` ဖြစ်သောအခါ **Hole1 diameter (through h, d)**;
- ၎င်း ကိုသုံးသော expression ရှိ **ပါရာမီတာများ**၊ ၎င်းကို သတ်မှတ်သော **configurations**၊ နှင့် ၎င်းကို ဖတ်သော **scripts** ([Write and run scripts](topic:craftscript) ကို ကြည့်ပါ)။

"Not used yet." ဆိုသည်မှာ ဘာမှ မသုံးသေးဘူးဟု ဆိုလိုသည်: မေးစရာမလိုဘဲ ဖျက်နိုင်သည်။

## ဖြုတ်ခြင်း၊ အမည်ပြောင်းခြင်း၊ ဖျက်ခြင်း

- **ဂဏန်းကို ဖြုတ်ခြင်း:** ၎င်း၏ **ƒ** ခလုတ်ကို နှိပ်ပါ၊ သို့မဟုတ် **Equations** စာရင်းရှိ {{ui:ဖြုတ်ရန်}}။ ၎င်း၏ လက်ရှိတန်ဖိုးကို ထိန်းထားပြီး ပါရာမီတာ မပြောင်းတော့ပါ။
- **ပါရာမီတာ အမည်ပြောင်းခြင်း:** **Name** အကွက်တွင် အမည်အသစ် ရိုက်ပါ။ ၎င်းကို သုံးသော expression အားလုံး ပြန်ရေးသည်။
- **ပါရာမီတာ ဖျက်ခြင်း:** ၎င်း၏ အတန်းရှိ × ကို နှိပ်ပါ။ တစ်ခုခုက သုံးနေလျှင် PartCraft က ၎င်း၏ လက်ရှိတန်ဖိုးကို ထို expression များထဲ ဦးစွာ ရေးရန် မေးသည်။
- **feature ဖျက်ခြင်း:** ၎င်း၏ ဂဏန်းများ၏ equation များ ပျက်သွားသည်; status bar က မည်သည်တို့ ဖြစ်သည်ကို ပြောသည်။

:::note
ပါရာမီတာများကို `.partcraft.json` ဖိုင်တွင် သိမ်းသည် (ဖိုင်ဗားရှင်း 3 အဖြစ်)။ ပါရာမီတာမရှိသော အစိတ်အပိုင်းကို ယခင်အတိုင်း သိမ်းသည်။
:::

## Expression များ

| ရေးပုံ | အဓိပ္ပာယ် |
|---|---|
| `120`၊ `12.5`၊ `1e3` | ဂဏန်း (မီလီမီတာ၊ သို့မဟုတ် ထောင့်အတွက် ဒီဂရီ) |
| `2in`၊ `1ft`၊ `3"`၊ `1.5cm`၊ `0.2m` | အခြား ယူနစ်ဖြင့် အရှည်၊ မီလီမီတာသို့ ပြောင်းသည် |
| `30deg`၊ `0.5rad` | ထောင့်၊ ဒီဂရီသို့ ပြောင်းသည် |
| `+ - * / %` နှင့် `^` | ဂဏန်းတွက်ချက်ခြင်း; `^` သည် power ဖြစ်ပြီး `-2^2` သည် −4 |
| `sin cos tan asin acos atan atan2` | ဒီဂရီဖြင့် ထရစ်ဂိုနိုမေတြီ |
| `sqrt pow exp ln log abs sign` | အခြား function များ |
| `ceil floor int round(x, digits) min max` | ဝိုင်းခြင်းနှင့် ကန့်သတ်ချက်များ |
| `if(test, a, b)` နှင့် `< <= > >= == !=` | ရွေးချယ်ခြင်း: `if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |
