PartCraft သည် SolidWorks နှင့် အစိတ်အပိုင်းများကို နှစ်ဖက်စလုံး လဲလှယ်သည်၊ တခြားသူ ဖတ်၍မရသော ဖိုင်ပုံစံ မသုံးဘဲ-

- **အပြင်သို့:** SolidWorks က အစိတ်အပိုင်းကို ကိုယ်တိုင် feature တစ်ခုချင်းစီ၊ ၎င်း၏ sketch၊ relation၊ အတိုင်းအတာ၊ global variable နှင့် equation များဖြင့် တည်ဆောက်ရန် ပြေးသော macro (`.swb`၊ စာသားဖိုင်)။ သေနေသော solid မဟုတ်ဘဲ အသက်ရှိသော feature tree ပါသည့် native part ရရှိမည်။
- **ပြန်လာခြင်း:** SolidWorks အတွင်း သင်ပြေးသော macro သည် အစိတ်အပိုင်း၏ feature နှင့် equation များကို `.cadcraft-sw.json` ဖိုင်သို့ ရေးသည်။ ထိုဖိုင်ကို PartCraft တွင် ဖွင့်ခြင်းသည် ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ (exact kernel လိုအပ်သည်)။

:::warning
ဤအရာအားလုံးကို SolidWorks တွင် မစမ်းသပ်ရသေးပါ။ SolidWorks သည် လိုင်စင်ရှိသော Windows ပေါ်တွင်သာ ပြေးပြီး PartCraft သည် ထို macro များကို ၎င်းတွင် တစ်ကြိမ်မျှ မပြေးဖူးပါ။ macro များကို SolidWorks API စာရွက်စာတမ်းမှ ရေးထားပြီး ဤနေရာတွင် ဖွဲ့စည်းပုံကိုသာ စစ်ဆေးထားသည်။ ပြဿနာများကို အစီရင်ခံရန် မျှော်လင့်ပါ; macro ရေးသော log တွင် မည်သည့်အဆင့် ပျက်ကွက်သည်ကို ပြောသည်။
:::

PartCraft သည် `.sldprt` ဖိုင်ကို ရေးနိုင်ခြင်း မရှိပါ- ထိုဖိုင်ပုံစံသည် ပိတ်ထားသည်။ native part ရယူရန် macro သည် နည်းလမ်းဖြစ်သည်။

## အစိတ်အပိုင်းကို macro အဖြစ် ပို့ခြင်း

1. အစိတ်အပိုင်းကို ဖွင့်ပါ။
2. {{ui:ထုတ်ရန်}} ကို ရွေးပြီး {{ui:SolidWorks အတွက် မက်ခရို (.swb)}} ကို ရွေးပါ။ PartCraft သည် `<part>.swb` ကို ဒေါင်းလုဒ်ဆွဲသည်; status bar က "exact kernel မပါဘဲ ရေးသားသည်" ဟု ပြသည်။
3. ဒိုင်ယာလော့ခ်က macro တည်ဆောက်သော feature၊ global variable နှင့် equation အရေအတွက်ကို ပြပြီး ချန်လှပ်ထားသည့်အရာများကို စာရင်းပြသည်။ ဤဗားရှင်းတွင် ၎င်းနှင့်အတူ STEP မပါပါ: လိုအပ်လျှင် {{ui:ထုတ်ရန်}} ပြီး {{ui:STEP (faceted၊ mesh kernel)}} ကို သုံးပါ။
4. SolidWorks တွင် **Tools > Macro > Run** ကို ရွေးပါ၊ `.swb` ဖိုင်ကို ရွေး၍ စောင့်ပါ။ သင်၏ မူလ part template မှ အစိတ်အပိုင်းအသစ် ဖန်တီးပြီး မီလီမီတာကို သတ်မှတ်ကာ feature အားလုံးကို တည်ဆောက်သည်။
5. အဆုံးတွင် မက်ဆေ့ချ်က အဆင့်မည်မျှ ပြီးခဲ့သည်၊ မည်မျှ ပျက်ကွက်သည်နှင့် PartCraft ၏ body နှင့် မည်မျှ ကိုက်ညီသည်ကို ပြသည်။ အပြည့်အစုံ log `<part> macro log.txt` ကို macro ဘေးတွင် ရေးသည်။

macro တည်ဆောက်သည့်အရာများ-

| PartCraft | အသစ် part တွင် |
|---|---|
| ရှေ့၊ အပေါ် သို့မဟုတ် ညာဘက် plane ပေါ်ရှိ sketch | ထို plane ပေါ်ရှိ sketch၊ ၎င်း၏ မျဉ်း၊ အဝိုင်းကွေး၊ စက်ဝိုင်း၊ အမှတ်၊ relation နှင့် အတိုင်းအတာများ (PartCraft ကဲ့သို့ အမည်ပေး၊ ဥပမာ `k7`) |
| မျက်နှာပေါ်ရှိ sketch | တူညီသော မျက်နှာပေါ်ရှိ sketch၊ ၎င်းပေါ်ရှိ အမှတ်တစ်ခုဖြင့် ရွေးထားသည် |
| ပုံသေ plane ပေါ်ရှိ sketch | အမှတ်သုံးခုမှ ဖြတ်သော reference plane နှင့် ၎င်းပေါ်ရှိ sketch |
| Extrude၊ cut (blind၊ through all၊ mid-plane၊ two directions၊ taper) | Boss-extrude သို့မဟုတ် cut-extrude |
| Revolve၊ revolved cut | တူညီသော centerline ပတ်လည် Revolve |
| Hole (simple၊ counterbore၊ countersink၊ tapped) | ကိုယ်ပိုင် sketch ဖြင့် cut တစ်ခု သို့မဟုတ် နှစ်ခု (tapped hole သည် ၎င်း၏ tap drill ဖြစ်သည်; thread မပါ) |
| Linear နှင့် circular pattern၊ mirror | Linear pattern၊ circular pattern၊ mirror (feature သို့မဟုတ် body) |
| Fillet၊ chamfer၊ shell | တူညီသော edge နှင့် မျက်နှာများပေါ် Fillet၊ chamfer နှင့် shell၊ အမှတ်များဖြင့် ရွေး |
| Parameter များနှင့် equation များ | အမည်ပြောင်းထားသော အတိုင်းအတာများပေါ် global variable နှင့် equation များ |
| Suppress လုပ်ထားသော feature၊ rollback bar | တူညီသောနည်းဖြင့် suppress; rollback bar ကို တူညီနေရာတွင် |

solid feature တစ်ခုစီ၏ နောက်တွင် macro သည် body ၏ ပမာဏနှင့် အရွယ်အစားကို PartCraft နှင့် နှိုင်းယှဉ်သည်။ ကွဲပြားလျှင် ထို feature ၏ ဦးတည်ချက်ကို တစ်ကြိမ်လှည့်ပြီး ထပ်စစ်သည်; ပိုမကောင်းလျှင် ပြန်လှည့်ပြီး log တွင် "Check" ဟု ရေးသည်။

### ချန်လှပ်ထားသည်များ

ဒိုင်ယာလော့ခ်နှင့် macro ထိပ်တွင် မသယ်ဆောင်ရသေးသည့် အရာအားလုံးနှင့် အကြောင်းပြချက်ကို ဖော်ပြသည်။ ယနေ့တွင် ထိုအရာများမှာ- သွင်းကုန် solid များ (အစား STEP ထည့်ပါ)၊ sweep များ၊ loft များ၊ draft များ၊ reference axis နှင့် အမှတ်များ၊ "up to" အဆုံးအခြေအနေများ၊ contour အချို့ကိုသာ extrude လုပ်ခြင်း၊ နှင့် ၎င်းတို့အပေါ် မူတည်သည့် အရာအားလုံး ဖြစ်သည်။ spline များသည် ၎င်းတို့၏ အမှတ်များကို ဖြတ်သော curve များ ဖြစ်လာသည်။ ဤဗားရှင်းတွင် exact kernel မရှိသဖြင့် မျက်နှာပေါ်ရှိ sketch များနှင့် edge သို့မဟုတ် မျက်နှာများကို ရွေးသော feature များကိုလည်း ချန်ထားသည်။

## အမည်ပေးထားသော STEP ပို့ခြင်း

ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ: {{ui:SolidWorks အတွက် STEP (အမည်ပေးထား၊ AP214)}} သည် exact kernel လိုအပ်ပြီး ရွေးလျှင် "SolidWorks အတွက် STEP: မတည်ဆောက်ရသေးပါ။ …" ဟု ပြသည်။ exact kernel ရှိသည့်အခါ ဖိုင်သည် အစိတ်အပိုင်းအမည်၊ မီလီမီတာနှင့် အစိတ်အပိုင်း အရောင်ကို သယ်ဆောင်ပြီး SolidWorks က အစိတ်အပိုင်းများ ပြသသည့်နည်းအတိုင်း Y ကို အထက်သို့ ထားသည် (ရိုးရိုး {{ui:STEP AP214 (တိကျသော solid)}} export သည် Z ကို အထက်သို့ ထားသည်)။ အမည်တွင် အသံထွက် အက္ခရာများကို ဆုံးရှုံးပြီး ASCII ပြင်ပ အခြား စာလုံးများကို `_` ဖြစ်စေသည်။

## အစိတ်အပိုင်းကို ပြန်ယူခြင်း

PartCraft တွင် ဖိုင်ကို ဖွင့်ခြင်း (အဆင့် ၃) သည် ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ- "SolidWorks export ကို ဖွင့်ခြင်း: မတည်ဆောက်ရသေးပါ။ …" ဟု ပြသည်။ CadCraft drafting app သည် ဖိုင်ကို ဖွင့်ပြီး ၎င်း၏ sketch များကို ယူသည်။

1. {{ui:ဖိုင်}} > {{ui:ထုတ်ရန်}} > {{ui:အစိတ်အပိုင်းများ ပြန်ယူရန် မက်ခရို ထုတ်ရန် (.swb)}} ကို ရွေး၍ `CadCraftExport.swb` ကို ဒေါင်းလုဒ်ဆွဲပြီး သင်၏ အစိတ်အပိုင်းများဘေးတွင် ထားပါ။
2. SolidWorks တွင် အစိတ်အပိုင်းကို ဖွင့်ပါ၊ **Tools > Macro > Run** ကို ရွေးပြီး `CadCraftExport.swb` ကို ရွေးပါ။ အစိတ်အပိုင်းဘေးတွင် `<part>.cadcraft-sw.json` ကို ရေးပြီး ၎င်းထဲရှိ မည်သည့်အရာကိုမျှ မပြောင်းပါ။
3. PartCraft တွင် {{ui:ဖွင့်ရန်}} ကို ရွေးပြီး ထိုဖိုင်ကို ရွေးပါ၊ သို့မဟုတ် 3D view ပေါ်သို့ ချပါ။
4. exact kernel ဖြင့် PartCraft သည် အစိတ်အပိုင်းကို feature တစ်ခုချင်းစီ ပြန်တည်ဆောက်ပြီး ၎င်းလုပ်ခဲ့သည်များကို ပြသည်၊ ဥပမာ "SolidWorks မှ feature 5 ခုအနက် 5 ခုလုံး ယူဆောင်ပြီး (Flange.SLDPRT)"၊ မယူဆောင်နိုင်သော feature တိုင်း ("မယူဆောင်ရသေး: Sweep1 (Sweep).") နှင့် ပမာဏသည် SolidWorks ရေးသော ပမာဏနှင့် ကိုက်ညီသလား။
5. {{ui:သိမ်းရန်}} ဖြင့် PartCraft အစိတ်အပိုင်းအဖြစ် သိမ်းပါ။

sketch များသည် base plane ပေါ်တွင် ရှိလျှင် base plane ပေါ်သို့၊ အစိတ်အပိုင်း၏ ကိုက်ညီသော ပြားညီ မျက်နှာရှိလျှင် ထိုမျက်နှာပေါ်သို့ (ထို့ကြောင့် နောက်ပိုင်း ပြင်ဆင်မှုများကို လိုက်သည်)၊ မဟုတ်လျှင် ပုံသေ plane ပေါ်သို့ ရောက်သည်။ fillet၊ chamfer နှင့် shell ၏ edge နှင့် မျက်နှာများကို အမှတ်များမှ ရှာပြီး အမည်ပေးထားသော reference အဖြစ် ထိန်းထားသည်။ Global variable များသည် parameter ဖြစ်လာသည် (space ပါသော အမည်များတွင် underscore ထည့်သည်: "Bolt count" သည် `Bolt_count` ဖြစ်လာသည်) နှင့် equation များသည် တူညီသော အတိုင်းအတာများပေါ်ရှိ equation ဖြစ်လာသည်။ ဘာမျှ ခန့်မှန်းမထားပါ: တူညီသည့် အရာမရှိသည်များကို စာရင်းပြုသည်။

CadCraft drafting app သည် တူညီသော ဖိုင်ကို ဖွင့်ပြီး ၎င်း၏ sketch များကို ယူသည်။

:::note
ပုံစံသည် `cadcraft-sw-export` ဗားရှင်း 1 ဖြစ်ပြီး မီလီမီတာနှင့် ဒီဂရီဖြင့် ရိုးရှင်းသော JSON ဖြစ်သည်။ အသစ်သော macro မှ ဖိုင် သို့မဟုတ် မမှန်ကန်သော ဖိုင်ကို အကြောင်းပြချက်ဖြင့် ငြင်းပယ်သည်။
:::
