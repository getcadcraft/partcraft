## ဘာလုပ်မလဲ

BimCraft မော်ဒယ်မှ လာသော အစိတ်အပိုင်းတစ်ခုကို ၎င်း၏ အဆောက်အအုံထဲရှိ နေရာတွင် ပြင်ဆင်ပြီး ပုံသဏ္ဍာန်အသစ်ကို အိမ်သို့ ပြန်ပို့ပါ။

## အဆင့်များ

1. BimCraft တွင် element တစ်ခုကို ရွေးပြီး {{ui:အစိတ်အပိုင် link များ}} › {{ui:PartCraft သို့ ပို့ရန်}} ကို ရွေးပါ။ PartCraft က ၎င်းကို အစိတ်အပိုင်းအသစ်အဖြစ် ဖွင့်ပေးမည်။ အခြေအနေဘားတွင် ၎င်းသည် BIM element ဖြစ်ကြောင်း ပြသမည်။
2. ၎င်းပတ်ပတ်လည်ရှိ element များ (3 m အတွင်း) ကို မီးခိုးရောင်ဖြင့် ဆွဲထားသည်။ ၎င်းတို့သည် ဒီဇိုင်းအတွက် ကိုးကားရန်သာ ဖြစ်သည်။ ရွေး၍မရ၊ ပြောင်း၍မရ၊ အစိတ်အပိုင်းဖိုင်တွင်လည်း မသိမ်းဆည်းပါ။
3. အခြားအစိတ်အပိုင်းကဲ့သို့ပင် ပြင်ဆင်ပါ- ဖြတ်ခြင်း၊ ထည့်ခြင်း၊ တူးခြင်း၊ ထင်ပုံပြန်ချခြင်း။ ၎င်း၏ origin နှင့် axes များသည် element ကိုယ်ပိုင်ဖြစ်သဖြင့် အစိတ်အပိုင်းသည် မူလနေရာသို့ ပြန်ရောက်မည်။
4. {{ui:ဖိုင်}} › {{ui:ထုတ်ရန်}} › {{ui:BimCraft သို့ နောက်သို့ သိမ်းရန်}} ကို ရွေးပါ။ ပို့လိုက်သော revision ကို အခြေအနေဘားက ပြသမည်။
5. BimCraft တွင် ၎င်းကို လက်ခံသည်အထိ element သည် ပြောင်းလဲပြီးကြောင်း ပြသမည်။

## ဘာကို မြင်ရမလဲ

- အစိတ်အပိုင်းသည် ဖိုင်တွင် ၎င်း၏ link ကို ဆက်ထားမည်။ နောက်မှ ဖွင့်လျှင် အခြေအနေဘားက BIM element ဖြစ်ကြောင်း ဆက်ပြသမည်။ ပို့ထားသော package ကို browser က ဆက်ရှိနေသရွေ့ မီးခိုးရောင် အဆောက်အအုံ ပြန်ပေါ်လာမည်။
- နောက်တစ်ကြိမ် ပြန်သိမ်းလျှင် revision 2၊ 3 စသဖြင့် ပို့မည်။ BimCraft က နောက်ဆုံးကို ထားမည်။

## သိထားသင့်သည်များ

- ပုံသဏ္ဍာန်ကို mesh အဖြစ် မီလီမီတာဖြင့် element ၏ ကိုယ်ပိုင် axes အတိုင်း ပြန်ပို့မည်။ features များမှာ PartCraft တွင် ကျန်ရှိမည်။
- {{ui:BimCraft သို့ နောက်သို့ သိမ်းရန်}} သည် BimCraft မှ မလာသော အစိတ်အပိုင်းအတွက် အလုပ်မလုပ်ပါ။
- solid မရှိသေးသော အစိတ်အပိုင်းတွင် ပို့စရာ မရှိပါ။
- app နှစ်ခုစလုံးကို browser တစ်ခုတည်းတွင် ဖွင့်ထားရမည်။ ဘာမျှ upload မလုပ်ပါ၊ စာမျက်နှာ နှစ်ခုက element ကို ၎င်းတို့ကြားတွင် ဖြတ်ပေးသည်။
