**field** သည် မည်သည့် အမှတ်မှ ၎င်း၏ မျက်နှာပြင်အထိ အကွာအဝေးဖြင့် ပုံသဏ္ဍာန်ကို ဖော်ပြသည်- အတွင်းဘက် အနုတ်၊ မျက်နှာပြင်ပေါ် သုည၊ အပြင်ဘက် အပေါင်း။ radius 5 ရှိသော ဘောလုံးသည် "ဗဟိုအထိ အကွာအဝေး နုတ် 5" ဖြစ်သည်။ ပုံသဏ္ဍာန်များ ပေါင်းခြင်းသည် အကွာအဝေးပေါ်ရှိ ရေတွက်ခြင်း ဖြစ်သည်: union သည် နှစ်ခု၏ ငယ်သည်၊ intersection သည် ကြီးသည်၊ တစ်ခုမှ တစ်ခု နုတ်ခြင်းသည် ပထမ၏ ကြီးသည်နှင့် ဒုတိယ၏ အနုတ် ဖြစ်သည်။ ပုံသဏ္ဍာန်ကို 1 mm ကြီးစေခြင်းသည် အကွာအဝေးမှ 1 ကို နုတ်သည်; hollow နံရံသည် ပြန်ခေါက်ထားသော အကွာအဝေး ဖြစ်သည်။

ထို့ကြောင့် field များသည် lattice၊ ချောင်းကြောင်းနှင့် အဆင့်အတန်းခွဲထားသော နံရံများအတွက် ကောင်းသည်: gyroid ၏ မျက်နှာပြင်သည် "sine sum သုည ဖြစ်သည်" ဖြစ်ပြီး အပိုင်းတစ်လျှောက် 1 မှ 3 mm အထိ ထူလာသော နံရံသည် အပိုင်းတစ်လျှောက် ပြောင်းလဲသော ဂဏန်း ဖြစ်သည်။

## Field မှ body သို့

`to_body(field, h)` သည် field ကို `h` မီလီမီတာ ခြားသော point grid ပေါ်တွင် နမူနာယူပြီး မျက်နှာပြင်အနီးရှိ point များကိုသာ ထိန်းထားသည် (8 × 8 × 8 brick များ၏ sparse grid)၊ မျက်နှာပြင်ကို **dual contouring** ဖြင့် တည်ဆောက်သည်: မျက်နှာပြင် cell တစ်ခုလျှင် vertex တစ်ခု၊ မျက်နှာပြင် planes ဆုံသော နေရာတွင် ထားသဖြင့် ထက်မြက်သော အစွန်းသည် voxel တစ်ခုအတွင်း ထက်မြက်ကျန်ရှိသည်။ မျက်နှာပြင်သည် ပိတ်ထားပြီး အစွန်းတိုင်း တြိဂံ နှစ်ခုတွင် တူညီစွာ မျှသည်; report က ထိုသို့ ပြောသည်။ voxel 3 ခုခန့်ထက် ပါးသော feature သည် ကျဉ်းနိုင်ပြီး၊ ထိုအခါ report က ကိုယ်ထည်ကို ပိတ်ထားသော solid မဟုတ်ဟု ဝှက်ထားခြင်းမရှိဘဲ ပြောသည်။

voxel အရွယ်အစားသည် တိကျမှုဖြစ်သည်: voxel 25 အချင်းရှိ ဘောလုံး၏ ထုထည်သည် ရာခိုင်နှုန်း အနည်းငယ်အတွင်း ရှိသည်၊ နံရံသည် ၎င်း၏ voxel များ အတိုင်းသာ မှန်သည်။ grid ပိုကြမ်းလေ ပိုမြန်သည်။

## အမြဲတမ်း တူညီသော bytes

field တွင် နာရီ သို့မဟုတ် random နံပါတ် မရှိပါ။ gyroid ၏ sine နှင့် cosine၊ နှင့် library ရှိ exponential၊ logarithm နှင့် power အားလုံးကို ရိုးရိုး arithmetic ဖြင့် တွက်သဖြင့် Node၊ Chrome၊ Firefox နှင့် Safari တို့သည် bit တူညီသည်ကို ပေးသည်; grid ကို ပုံသေ အစဉ်အတိုင်း လျှောက်သဖြင့် တူညီသော input ဖြင့် တူညီသော script သည် ကွန်ပျူတာ မည်သည့်တစ်ခုတွင်မဆို၊ worker thread အရေအတွက် မည်မျှပင်ဖြစ်စေ byte တူညီသော mesh နှင့် data sheet များကို ပေးသည်။ ၎င်းကို စမ်းသပ်ထားပြီး browser ကို Node နှင့် နှိုင်းယှဉ်ထားသည်ကိုပါ ပါဝင်သည်။
