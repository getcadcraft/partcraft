Relation များသည် ဂျီသြမေတြီတစ်ခု အခြားဂျီသြမေတြီနှင့် ဆက်စပ်နေပုံကို ပုံသေသတ်မှတ်သည်။ အတိုင်းအတာများသည် အရွယ်အစားများကို ပုံသေသတ်မှတ်သည်။ relation ထည့်ရန် ရွေးရန်ကိရိယာ ({{key:S}}) ဖြင့် အရာဝတ္ထုများကို ရွေးပြီး ညာဘက် panel ရှိ ခလုတ်ကို ရွေးပါ၊ အတိုင်းအတာ ထည့်ရန် အတိုင်းအတာကိရိယာ ({{key:D}}) သို့မဟုတ် ညာဘက် panel ရှိ အတိုင်းအတာ ခလုတ်များကို သုံးပါ။ အသုံးပြုပုံ- [sketch ကို အပြည့်အဝ သတ်မှတ်ခြင်း](topic:relations-dimensions)။

အောက်ပါ "curve" ဆိုသည်မှာ စက်ဝိုင်း သို့မဟုတ် အဝိုင်းကွေး ဖြစ်သည်။ origin ကို အမှတ်တစ်ခုအဖြစ် ရေတွက်သည်။

|---|---|---|---|
| {{ui:• ထပ်တူကျ}} | • (ရွေးထားချိန် သို့မဟုတ် ပြဿနာရှိချိန်တွင်သာ ပြသည်) | အမှတ်နှစ်ခု | အမှတ်များ ထပ်တူကျသည် |
| {{ui:• ထပ်တူကျ}} | • | အမှတ်နှင့် မျဉ်း | အမှတ်သည် မျဉ်း (သို့မဟုတ် ၎င်း၏ extension) ပေါ်တွင် ရှိသည် |
| {{ui:• ထပ်တူကျ}} | • | အမှတ်နှင့် curve | အမှတ်သည် စက်ဝိုင်း သို့မဟုတ် အဝိုင်းကွေးပေါ်တွင် ရှိသည် |

| {{ui:∥ အပြိုင်}} | ∥ | မျဉ်းနှစ်ကြောင်း | မျဉ်းများ တူညီသော ဦးတည်ချက်ဖြင့် သွားသည် |
| {{ui:⊥ ထောင့်မတ်}} | ⊥ | မျဉ်းနှစ်ကြောင်း | မျဉ်းများ ထောင့်မှန်ဖြင့် ဆုံသည် |
| {{ui:T ထိတွေ့}} | T | မျဉ်းတစ်ကြောင်းနှင့် curve | မျဉ်းသည် curve ကို မဖြတ်ဘဲ ထိသည် |
| {{ui:T ထိတွေ့}} | T | curve နှစ်ခု | ၎င်းတို့ ထိတွေ့သည်၊ အပြင် သို့မဟုတ် အတွင်း၊ ဆွဲထားသည့်အတိုင်း |
| {{ui:T ထိတွေ့}} | T | spline နှင့် မျဉ်း၊ အဝိုင်းကွေး သို့မဟုတ် spline ၏ အဆုံးတစ်ခုနှင့် တွေ့သော အခြား spline | spline သည် ထိုအဆုံးမှ အခြား curve ၏ ဦးတည်ချက်ဖြင့် ထွက်သည် |
| {{ui:= ညီမျှ}} | = | မျဉ်းနှစ်ကြောင်း | အလျား တူသည် |

| {{ui:◎ ဗဟိုတူ}} | ◎ | အမှတ်နှင့် curve | အမှတ်သည် curve ၏ ဗဟိုတွင် ရှိသည် |
| {{ui:M အလယ်အမှတ်}} | M | အမှတ်နှင့် မျဉ်း | အမှတ်သည် မျဉ်း၏ အလယ်တွင် ရှိသည် |
| {{ui:↔ ပုံထင်}} | ↔ | အမှတ်နှစ်ခုနှင့် မျဉ်း | အမှတ်များသည် မျဉ်းနှင့် ပုံထင်ပုံ ဖြစ်သည် (မှန်ထင်ပြ က ဤ relation များ ထည့်သည်) |
| {{ui:⚓ ပုံသေ}} | ⚓ | အမှတ်၊ မျဉ်း၊ curve သို့မဟုတ် spline | ယခုရှိနေသည့် နေရာတွင် တိတိကျကျ ထိန်းထားသည် (spline: ၎င်း၏ အမှတ်များ) |

ဤနေရာတွင် မျဉ်းများတွင် ဗဟိုမျဉ်းများ ပါဝင်သည်။ ဆွဲခြင်းက relation အချို့ကို အလိုအလျောက် ထည့်ပေးသည်- အမှတ်သို့ snap လုပ်လျှင် ထပ်တူကျသည်၊ curve သို့ snap လုပ်လျှင် အမှတ်သည် ထို curve ပေါ်တွင် ရှိသည်၊ ညီညာနီးစပ်သော သို့မဟုတ် ထောင်နီးစပ်သော မျဉ်းများသည် H သို့မဟုတ် V ရရှိသည်၊ ထောင့်မှန်သည် ထောင့်လေးခု ချိတ်ဆက်ပြီး H နှစ်ခု နှင့် V နှစ်ခု ပါလာသည်။

**ပုံသေ** သည် တစ်ခုခု ရွေ့မသွားစေရန် အမြန်နည်းဖြစ်သော်လည်း ပုံဆွဲချက်သည် အခြားနေရာရှိ အတိုင်းအတာ ပြောင်းလဲမှုကို နောက်မလိုက်နိုင်တော့ပါ။ origin သို့ အတိုင်းအတာကို ဦးစားပေးပါ။

အတိုင်းအတာကိရိယာဖြင့် PartCraft သည် သင်နှိပ်သည့်အရာနှင့် နံပါတ်ထားသည့်နေရာမှ အမျိုးအစားကို ရွေးသည်-

| သင်နှိပ်သည် | ရရှိမည် |
|---|---|
| မျဉ်းတစ်ကြောင်း | ၎င်း၏ အရှည်; စောင်းသော မျဉ်းဆိုလျှင် နံပါတ်သည် အပေါ် သို့မဟုတ် အောက်တွင် ဖြစ်လျှင် အလျားလိုက်၊ ဘေးတွင် ဖြစ်လျှင် ဒေါင်လိုက် |
| စက်ဝိုင်းတစ်ခု | အချင်း |
| အဝိုင်းကွေးတစ်ခု | radius |
| အမှတ်နှစ်ခု | အကွာအဝေး; စောင်းမျဉ်းကဲ့သို့ အလျားလိုက် သို့မဟုတ် ဒေါင်လိုက် |
| အမှတ်နှင့် မျဉ်း | အမှတ်မှ မျဉ်းသို့ အကွာအဝေး |
| မျဉ်းနှစ်ကြောင်း | ထောင့်၊ သို့မဟုတ် အပြိုင်ဖြစ်လျှင် အကွာအဝေး |
| အမှတ်နှင့် စက်ဝိုင်း | ဘာမျှမရ: "ထိုအရာများကို အတူတကွ အတိုင်းအတာ မပြုလုပ်နိုင်ပါ။" စက်ဝိုင်း၏ ဗဟိုအမှတ်သို့ အတိုင်းအတာ ထည့်ပါ |

**Offset** (အကွာအဝေးအဖြစ် ပြသည်) ကို Offset ကိရိယာဖြင့် ပြုလုပ်သည်- ၎င်းသည် ကူးထားသော မျဉ်းကို ထိုအကွာအဝေးဖြင့် အပြိုင် ထိန်းထားသည်၊ သို့မဟုတ် ကူးထားသော အဝိုင်းကွေး သို့မဟုတ် စက်ဝိုင်းကို ထိုမျှ ပိုကြီး သို့မဟုတ် ငယ်သော radius ဖြင့် ဗဟိုတူအောင် ထိန်းထားသည်။ တူညီသော offset ၏ အခြားအပိုင်းများသည် **O** relation ရရှိပြီး Offset အတိုင်းအတာ တစ်ခုတည်းကို လိုက်သည်။ [spline၊ trim၊ offset နှင့် အခြား sketch ကိရိယာများ](topic:sketch-tools) ကို ကြည့်ပါ။

အတိုင်းအတာ တန်ဖိုးများသည် မီလီမီတာ (သို့မဟုတ် ဒီဂရီ) ဖြစ်ပြီး အနုတ်လက္ခဏာ မရှိပါ။ radius နှင့် အချင်းသည် သုည ထက်ကြီးရမည်။ အကွာအဝေးအတွက် တန်ဖိုး 0 ခွင့်ပြုသည်- အကွာအဝေး 0 ဖြင့် အမှတ်နှစ်ခုသည် ထပ်တူကျသည်။

## Solving အပြုအမူ

- **အနည်းဆုံး ရွေ့လျားမှု။** တန်ဖိုး ပြောင်းသည့်အခါ solver သည် ဂျီသြမေတြီကို အနည်းဆုံး ရွှေ့စေသည်။ အရှည် ပြောင်းသော မျဉ်းသည် အဆုံးနှစ်ခုစလုံးကို ထိန်းမထားလျှင် နှစ်ဖက်စလုံးမှ ညီမျှစွာ ရှည်လာသည်။
- **ပြန်မလှန်ခြင်း။** အမှတ်မှ မျဉ်းသို့ အကွာအဝေး၊ အလျားလိုက်နှင့် ဒေါင်လိုက် အကွာအဝေး၊ ထောင့်နှင့် ထိတွေ့မှုတို့သည် မည်သည့်ဘက်တွင် ပြုလုပ်ခဲ့သည်ကို မှတ်မိသည်။ တန်ဖိုး ပြောင်းလဲခြင်းက ဂျီသြမေတြီကို တခြားဘက်သို့ ဘယ်တော့မျှ မလှန်ပါ။
- **ဆန့်ကျင်မှုများက ဘာမျှ မပြောင်းပါ။** relation များ ဆန့်ကျင်နေလျှင် sketch သည် မူလအတိုင်း ကျန်ခဲ့ပြီး ဆန့်ကျင်သော relation များ အနီရောင် ဖြစ်သည်။
- **အလိုလို ပါပြီးသား relation များ** (အခြားမှ ဆိုလိုသည့်) ကို status bar တွင် ("ဤ relation သည် ရှိပြီးသား ဖြစ်သည်။ ဖျက်ပါ။") ဟု အမည်ပေးသည်၊ သို့သော် feature သည် သတိပေးချက်ဖြင့် ဆက်တည်ဆောက်သည်။
- **Tangent ချိတ်ဆက်မှုများ။** fillet အဝိုင်းကွေးသည် မျဉ်းများနှင့် အဆုံးအမှတ်တူတွင် တွေ့သည့်အခါ ထိတွေ့မှုကို ထိုနေရာတွင် ရှင်းလင်းစွာ သတ်မှတ်နိုင်သော ပုံစံဖြင့် ဖြေရှင်းသဖြင့် sketch fillet များကို အလွန်အကျွံ သတ်မှတ်ထားသည်ဟု မဖတ်ပါ။

## ယခုမရရှိနိုင်သေးသည်များ

Collinear, coradial နှင့် pierce relation များ၊ spline ပေါ်ရှိ အမှတ်၊ driven (reference) အတိုင်းအတာများ၊ ordinate နှင့် arc-length အတိုင်းအတာများ၊ အတိုင်းအတာများကြား equation များ။ collinear မျဉ်းများအတွက် Parallel နှင့် အကွာအဝေး 0 ကို သုံးပါ။
