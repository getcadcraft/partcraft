:::note
**ဤဗားရှင်းတွင်** sweep နှင့် loft များကို မတည်ဆောက်ရသေးပါ- ၎င်းတို့သည် တိကျသော geometry kernel လိုအပ်ပြီး ဤ PartCraft ဗားရှင်းတွင် မရှိပါ။ [မတည်ဆောက်ရသေးသည့်အရာများ](topic:not-built-yet) တွင် အစားထိုးလုပ်နည်းကို ပြထားပါသည်။ Sweep နှင့် Loft အပိုင်းများသည် တိကျသော kernel ဖြင့် ၎င်းတို့ အလုပ်လုပ်ပုံကို ဖော်ပြထားပါသည်။ **Draft သည် အလုပ်လုပ်ပါသည်**- flat မျက်နှာများပေါ်တွင် mesh kernel က တည်ဆောက်ပြီး တိကျသော kernel ပေးသော ရလဒ်နှင့် တူညီပါသည်။
:::

သုံးခုလုံးသည် Features အုပ်စု၏ {{ui:More}} မီနူးတွင် ရှိပါသည် ([The mesh kernel](topic:solid-kernels) ကို ကြည့်ပါ)။ တစ်ခုစီက ပစ္စည်းကို ပေါင်းနိုင်၊ ဖြတ်နိုင်၊ **Intersect** ဖြင့် ထပ်နေသော အပိုင်းကိုသာ ထားနိုင်ပြီး သို့မဟုတ် **New body** ဖန်တီးနိုင်ပါသည် (Sweep နှင့် Loft အတွက် panel ရှိ **Operation** တွင် ရွေးပါ)။

## Sweep

Sweep သည် closed profile တစ်ခုကို path တစ်လျှောက် ရွှေ့ပါသည်- ပိုက်များ၊ လက်ကိုင်များ၊ ဝါယာ ဒံ့ကွိုင်များ၊ rails များ။

1. Sketch တစ်ခုတည်းတွင် **path** ကို ဆွဲပါ- မျဉ်းနှင့် arc များကို ဆုံးမှ ဆုံးအထိ ချိတ်ဆက်ပါ (သို့မဟုတ် အောက်တွင် ဖော်ပြသည့်အတိုင်း model edge များကို သုံးပါ)။
2. အခြား sketch တစ်ခုတွင် **profile** ကို ဆွဲပါ။ ၎င်း၏ ပလိန်သည် path ၏ တစ်ဖက်စွန်းကို ဖြတ်ရမည်၊ ဥပမာ front ပလိန်ပေါ်ဆွဲထားသော path ၏ အစရှိ top ပလိန်ပေါ်ရှိ စက်ဝိုင်း။
3. Profile sketch ကို ရွေးပြီး {{ui:More}} ထို့နောက် {{ui:Sweep}} ကို ရွေးပါ။ နောက်ဆုံး ဆွဲထားသော အခြား sketch သည် path ဖြစ်လာပါမည်။

Panel တွင်-

| ဆက်တင် | ဘာလုပ်သလဲ |
|---|---|
| **Path** | Path ကို ဖွဲ့သော sketch များကို အမှန်ခြစ်ပါ (sketch အများအပြား ဆုံးမှ ဆုံးအထိ ချိတ်ဆက်ပြီး 3D path တစ်ခု ဖြစ်လာသည်); **မော်ဒယ် edge များကို ရွေးရန်** က ပစ္စည်း၏ edge များ ထည့်သည် |
| **Orientation** | Path ကို လိုက်ခြင်း (မူလ)၊ Frenet၊ Fixed (section များသည် profile နှင့် အပြိုင် ကျန်ရှိသည်)၊ ဦးတည်ချက် ထိန်းထားခြင်း၊ guide curve တစ်လျှောက် |
| **End scale** | Profile သည် အဆုံးတွင် ဤအရွယ်အစားသို့ မျဉ်းဖြောင့်စွာ ကြီးလာ သို့မဟုတ် ကျုံ့သွားသည် (1 = မပြောင်းလဲ) |

Path ရှိ ထောင့်ချိုးများကို ထောင့်ဖြတ် (mitred) လုပ်ပါသည်။ radius 5 စက်ဝိုင်းကို 100 mm မျဉ်းတစ်လျှောက် sweep လုပ်ပါက တိတိကျကျ 2500π mm³ ထုထည်ရှိသော cylinder ဖြစ်ပါသည်၊ radius 50 quarter arc တစ်လျှောက်ဆိုလျှင် 625π² mm³ quarter torus ဖြစ်ပါသည်။

## Loft

Loft သည် မတူညီသော ပလိန်များပေါ်ရှိ section နှစ်ခု သို့မဟုတ် ထို့ထက်ပို၍ ရောစပ်ပေးပါသည်။

1. Section တစ်ခုစီကို ၎င်း၏ကိုယ်ပိုင် sketch တွင် ဆွဲပါ (loop တစ်ခုစီ)၊ base planes၊ [Reference planes, axes and points](topic:reference-geometry) ဖြစ်သော ကိုးကားပလိန်များ သို့မဟုတ် မျက်နှာများပေါ်တွင်။
2. {{ui:More}} ကို ရွေးပြီး {{ui:Loft}} ကို ရွေးပါ။ အသုံးမပြုသေးသော loop တစ်ခုတည်း ပါသည့် sketch အားလုံးသည် history အစဉ်အတိုင်း section ဖြစ်လာပါမည်။

Panel သည် section များကို အစဉ်လိုက် ဖော်ပြပါသည် (**Up** ဖြင့် ပြန်စီ၊ **Remove** ဖြင့် ဖယ်ရှား); **sketch ထည့်ရန်** က sketch တစ်ခု ထပ်ထည့်ပြီး **မျက်နှာတစ်ခု ရွေးရန်** က ပစ္စည်း၏ ပြားချပ် မျက်နှာ တစ်ခု ထည့်ပါသည်။ **Ruled** က ချောမွေ့သော ရောစပ်မှုအစား section များကြား ပြားချပ် မျက်နှာများ ပြုလုပ်ပါသည်။ စတုရန်းနှစ်ခုကြားတွင် နှစ်ခုစလုံးသည် တူညီသော frustum ဖြစ်ပါသည် (40 mm စတုရန်းမှ 30 mm အကွာတွင် 20 mm စတုရန်း၊ တိတိကျကျ 28000 mm³)။

ဘက်အရေအတွက် မတူညီသော section များ (စတုရန်းမှ တြိဂံ) ကို OpenCascade က ကိုက်ညီအောင် လုပ်ပေးပြီး ဘေးမျက်နှာများကို ကွေ့ခြင်း ဖြစ်စေနိုင်ပါသည်; feature က သတိပေးပါမည်။ ဘက်အရေအတွက် တူညီသော section များကို ကိုက်ညီသော ထောင့်များမှ စ၍ ဆွဲပါ- ရလဒ် အသန့်ဆုံး ဖြစ်ပါမည်။

### လမ်းညွှန် rails

လမ်းညွှန် rails များသည် loft ၏ ဘေးများက ပထမ section မှ နောက်ဆုံး section အထိ လိုက်ရမည့် curve များ ဖြစ်ပြီး သင်ကိုယ်တိုင် ဆွဲထားသော ဖောင်းခြင်း၊ ခါးလုံး သို့မဟုတ် ကားခြင်းအတွက် ဖြစ်ပါသည်။

1. Rails နှစ်ခု သို့မဟုတ် ထို့ထက်ပိုဆွဲပါ- ပထမ section မှ နောက်ဆုံး section အထိ ရောက်ပြီး section တစ်ခုစီကို တစ်ကြိမ်ဖြတ်သော open curve များ (မျဉ်း၊ arc၊ spline)။ Sketch တစ်ခုတည်းတွင် rails အများအပြား ထားနိုင်ပါသည်- ခွဲထားသော chain တစ်ခုစီသည် rail တစ်ခုစီ ဖြစ်ပါသည်။ Rail တစ်ခုကို section တစ်ခုစီနှင့် တကယ် တွေ့ဆုံစေရန် ၎င်း၏ အဆုံးများကို section များ၏ အမှတ်များသို့ snap လုပ်ပါ။
2. Loft panel ရှိ **Guide rails** အောက်တွင် ၎င်းတို့ပါသော sketch များကို အမှန်ခြစ်ပါ၊ သို့မဟုတ် {{ui:Pick model edges as rails}} ကို နှိပ်ပြီး ပစ္စည်း၏ edge များကို နှိပ်ပါ (Esc ဖြင့် ပြီးဆုံးသည်)။

Rails ပါသော loft သည် section များနှင့် rails များကြား [Surfaces through a curve network](topic:gordon-surfaces) ဖြစ်သည့် Gordon မျက်နှာပြင် ဖြစ်ပြီး နှစ်ဖက်စလုံးတွင် ပြားချပ်စွာ အဆုံးသတ်ကာ solid ဖြစ်လာပါသည်။ Panel က ၎င်းတို့ကို ဘယ်လောက် တိကျစွာ လိုက်သည်ကို ပြပါသည်။ Section တိုင်းသည် sketch ဖြစ်ရပါမည် (အမှတ် သို့မဟုတ် မျက်နှာသည် rail ကို လက်မခံနိုင်ပါ) နှင့် **Ruled** မသက်ရောက်ပါ။ Rail တစ်ခုသည် section တစ်ခုကို 0.01 mm ထက် ပိုလွဲပါက ကွာဟချက်ကို ပြပြီး ငြင်းပယ်ပါမည်။

စစ်ဆေးပြီး- အချင်း 20 mm နှင့် 10 mm စက်ဝိုင်းနှစ်ခု (40 mm ခွာ) နှင့် ဖြောင့်သော rails လေးခုသည် cone frustum ၏ ထုထည်ကို 0.000002 % အတွင်း ပေးပါသည်; 5 mm ဖောင်းသော arc များသည် rail တိုင်းကို 0.00001 mm အတွင်း လိုက်သော စည်ပုံ ပေးပါသည်။

## Draft

Draft သည် မျက်နှာများကို စောင်းစေပြီး ပစ္စည်းကို မှိုထဲမှ ထွက်လာနိုင်စေပါသည်။

1. {{ui:More}} ကို ရွေးပြီး {{ui:Draft}} ကို ရွေးပါ ({{key:Shift}}+click ဖြင့် မျက်နှာများကို ဦးစွာ ရွေးနိုင်သည်)။ ဘာမျှ မရွေးထားပါက pick mode ဖြစ်ပါသည်- စောင်းစေချင်သော မျက်နှာတိုင်းကို နှိပ်ပြီး {{ui:Done}} ကို နှိပ်ပါ။
2. **Angle (°)**၊ **Neutral plane** (မျက်နှာများ အရွယ်အစား မပြောင်းသော နေရာ) နှင့် **Pull direction** (မူလအားဖြင့် neutral plane ၏ normal) ကို သတ်မှတ်ပါ။

အပြုသဘော angle သည် မျက်နှာကို pull ဦးတည်ချက်အတိုင်း အတွင်းသို့ စောင်းစေပြီး ပစ္စည်းကို ဖယ်ထုတ်ပါသည်; အနုတ်ဖြစ်ပါက ထည့်ပေးပါသည်။ Neutral plane သည် Top plane ဖြင့် စတင်ပါသည်။ ဤဗားရှင်းတွင် flat မျက်နှာများကိုသာ draft လုပ်နိုင်ပါသည်- cylinder၊ cone သို့မဟုတ် freeform မျက်နှာဆိုလျှင် "Draft: in this version flat faces only (the mesh kernel builds it)." ဟု ပြပါမည်။ 100 × 100 × 50 block ၏ ဘက်လေးဘက်ကို အောက်ခြေအတွက် 5° ဖြင့် draft လုပ်ပါက တိတိကျကျ h/3·(a² + b² + ab) frustum ဖြစ်လာပြီး b = a − 2h·tan 5° ဖြစ်ပါသည်။
