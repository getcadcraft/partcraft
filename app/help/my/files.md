PartCraft သည် သင့်ကွန်ပျူတာပေါ်ရှိ ဖိုင်များပေါ်တွင် အလုပ်လုပ်သည်။ အပိုင်းကို ဘယ်တော့မှ upload မလုပ်ပါ၊ account သို့မဟုတ် cloud storage မပါဝင်ပါ။ Cloud သိမ်းခြင်းကို ယခု မရရှိနိုင်သေးပါ။

## PartCraft ဖွင့်နိုင်သော ဖိုင်များ

| ဖိုင် | Extension | နည်းလမ်း |
|---|---|---|
| PartCraft အပိုင်း | `.partcraft.json` | {{ui:ဖွင့်ရန်}}၊ {{key:Mod+O}}၊ သို့မဟုတ် 3D view ပေါ်သို့ ချထားပါ |
| PartCraft assembly | `.partcraft-asm.json` | အတူတူ- PartCraft က မည်သည့်အမျိုးအစား ဖြစ်ကြောင်း သိသည် |
| STEP solid | `.step`, `.stp` | တြိဂံအဖြစ် ဖတ်သော solid body: [STEP ဖိုင်ကို ဖွင့်ပြီး ဆက်တည်ဆောက်ခြင်း](topic:import-step) |

STL၊ OBJ နှင့် 3MF mesh များကိုလည်း solid body အဖြစ် ဖွင့်နိုင်သည် ([STL၊ OBJ သို့မဟုတ် 3MF ဖွင့်ခြင်း](topic:open-meshes)) နှင့် `.3dm` ဖိုင်များကိုလည်း ဖွင့်နိုင်သည် ([.3dm မော်ဒယ် ဖွင့်ခြင်း](topic:open-3dm-files))။ DXF၊ IGES နှင့် အခြား ပရိုဂရမ်များ၏ ကိုယ်ပိုင် part ဖိုင်များကို ဖွင့်၍ မရပါ (ကြည့်ရန်- [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet))။

ဖွင့်သည့်အခါ စည်းမျဉ်းများ-

- အပိုင်း သို့မဟုတ် assembly ဖိုင်အမည်သည် `.json` ဖြင့် အဆုံးသတ်ရမည်၊ ဖိုင်သည် 50 MB အောက် ဖြစ်ရမည်။
- ဘာမျှ မပြမီ ဖိုင်များကို စစ်ဆေးသည်။ ပျက်စီးသော သို့မဟုတ် တည်းဖြတ်ထားသော ဖိုင်ကို ရိုးရှင်းသော အကြောင်းပြချက်ဖြင့် ငြင်းသည်၊ ဥပမာ "This is not a PartCraft file."
- PartCraft အသစ်မှ သိမ်းထားသော ဖိုင်ကို ငြင်းသည်- "ဤဖိုင်ကို PartCraft အသစ် (file version 3) က သိမ်းထားသည်; ဤဗားရှင်းက version 2 ကို ဖတ်သည်။" ဟောင်းဖိုင်များ ဖွင့်သည်။
- ဖန်သားပြင်ပေါ်ရှိ အပိုင်းတွင် မသိမ်းရသေးသော ပြောင်းလဲမှုများ ရှိလျှင် PartCraft က ဦးစွာ မေးသည်: {{ui:ပယ်ဖျက်ရန်}}၊ {{ui:ပြောင်းလဲမှုများ ပယ်ဖျက်ရန်}} သို့မဟုတ် {{ui:ဦးစွာ သိမ်းရန်}}။

## သိမ်းခြင်း

{{ui:သိမ်းရန်}} သို့မဟုတ် {{key:Mod+S}} သည် ဖန်သားပြင်ပေါ်ရှိအရာကို သိမ်းသည်-

- အပိုင်းတွင်- `<part name>.partcraft.json`၊ history အပြည့်အစုံ (sketch၊ relation၊ dimension၊ feature၊ rollback နေရာ)၊ ပုံဆွဲစာရွက်၏ section၊ detail နှင့် GD&T မှတ်ချက်များ၊ ယခင် build တွင် တင်သွင်းထားသော STEP solid ၏ စာသားအပြည့်အစုံ။ ဤဗားရှင်းက တည်ဆောက်၍ မရသော feature များကို မပြောင်းလဲဘဲ ပြန်သိမ်းသည်။ solid ကိုယ်တိုင် မသိမ်းပါ; ဖိုင်ဖွင့်သည့်အခါ PartCraft က history မှ ပြန်တည်ဆောက်သည်။
- assembly တွင်- `<assembly name>.partcraft-asm.json`၊ **အပိုင်းအားလုံးကို အတွင်းထည့်ထား**။ ဖိုင်တစ်ခုတည်းတွင် assembly တစ်ခုလုံး ပါဝင်သဖြင့် သီးခြား ပို့နိုင်သည်။

သိမ်းခြင်းသည် **ဒေါင်းလုဒ်** ဖြစ်သည်။ browser က ဖိုင်ကို ၎င်း၏ downloads folder တွင် ထားသည်၊ သို့မဟုတ် သင် မေးရန် သတ်မှတ်ထားလျှင် ဘယ်နေရာတွင် ထားမည်ကို မေးမည်။ ထပ်သိမ်းလျှင် ဒေါင်းလုဒ်အသစ် ဖြစ်သည်; browser က `Part1 (1).partcraft.json` ဟု အမည်ပေးနိုင်ပြီး ဟောင်းကို အစားမထိုးပါ။ ဖိုင်များကို {{pick:mac=Finder|windows=File Explorer|linux=သင့်ဖိုင်မန်နေဂျာ}} တွင် သင်နှစ်သက်သလို အမည်ပြောင်း သို့မဟုတ် ရွှေ့နိုင်သည်။

အပိုင်းအမည်ရှိ အက္ခရာ၊ ဂဏန်း၊ space၊ `_`၊ `.` နှင့် `-` မဟုတ်သော စာလုံးများသည် ဖိုင်အမည်တွင် `_` ဖြစ်သွားသည်။

:::tip
browser အများစုတွင် ဒေါင်းလုဒ်တိုင်း နေရာမေးရန် ဆက်တင်ရှိသည်။ ဖွင့်ထားလျှင် "Save as" ရွေးချယ်စရာ အမြဲရရှိမည်- Chrome နှင့် Edge တွင် settings ရှိ Downloads အောက်; Firefox တွင် General၊ Files and Applications အောက်; Safari တွင် General၊ File download location အောက်။
:::

ဒေါင်းလုဒ်များ ရောက်ရှိသည့်နေရာနှင့် ဖိုင်များ ဘေးကင်းစေရန်: [ဖိုင်များ ရောက်ရှိသည့်နေရာ](common:your-files)။

## ထုတ်ခြင်း

{{ui:ထုတ်ရန်}} မီနူးသည် အခြား ဖော်မတ်များ ရေးသည်။ တစ်ခုစီသည် ဒေါင်းလုဒ် ဖြစ်ပြီး အပိုင်းအမည်ဖြင့် အမည်ပေးသည်။

| မီနူးအချက် | ဖိုင် | ပါဝင်သည် |
|---|---|---|
| {{ui:STL၊ 3D print အတွက်}} | `<name>.stl` | solid ၏ တြိဂံများ၏ binary STL၊ မီလီမီတာ၊ **Z up** |
| {{ui:3MF၊ 3D print အတွက်}} | `<name>.3mf` | solid ကို object တစ်ခုအဖြစ် ပါသော 3MF၊ မီလီမီတာ၊ **Z up** |
| {{ui:STEP AP242 (တိကျသော solid)}} | `<name>.step` | solid တိကျ တစ်ခု၊ မီလီမီတာ၊ Z up: စက်ဝိုင်းမျက်နှာများကို အမှန် cylinder၊ cone၊ sphere နှင့် torus အဖြစ်။ အခြား CAD နှင့် CAM ပရိုဂရမ်များအတွက် သုံးရမည့် STEP |
| {{ui:STEP AP214 (တိကျသော solid)}} | `<name>.step` | တူညီသော တိကျသော solid ကို ဗားရှင်းဟောင်း AP214 schema ဖြင့် |
| {{ui:STEP (faceted၊ mesh kernel)}} | `<name>.step` | mesh မှ ပြားသော မျက်နှာများဖြင့် ပြုလုပ်ထားသော solid: **စက်ဝိုင်းမျက်နှာပြင်များသည် ပြားငယ် facet အများအပြား ဖြစ်သည်**။ မီလီမီတာ၊ PartCraft ၏ ကိုယ်ပိုင် axis များ (Y up)။ တိကျသော ဖိုင်ကို ငြင်းသော ပရိုဂရမ်အတွက် |
| {{ui:DXF၊ sketch သို့မဟုတ် ပြန့်သော မျက်နှာပြင်အတွက်}} | `<name> - <sketch>.dxf` သို့မဟုတ် `<name> - face.dxf` | DXF R12။ sketch: မျဉ်း၊ arc၊ စက်ဝိုင်းနှင့် point များ sketch ၏ ကိုယ်ပိုင် coordinate ဖြင့်၊ layer များ PROFILE၊ CONSTRUCTION နှင့် POINTS တွင်။ ရွေးထားသော ပြားသော မျက်နှာ: outline များကို ပိတ်ထားသော polyline အဖြစ် (စက်ဝိုင်းအစွန်းများ facet အဖြစ်) |
| {{ui:ပုံဆွဲ (PDF): အမြင်များ၊ ဖြတ်ပိုင်း၊ အသေးစိတ်၊ GD&T}} | `<name> - drawing.pdf` | A3 ပုံဆွဲစာရွက်: views သုံးခု၊ isometric၊ ဖြတ်ပိုင်းနှင့် အသေးစိတ် (သတ်မှတ်ထားလျှင်)၊ အလုံးစုံ အရွယ်အစား၊ GD&T သင်္ကေတများ၊ title block |

:::note
{{ui:STEP AP242 (တိကျသော solid)}} သည် အပေါက်များ၊ bosses၊ fillet များ၊ cone များ၊ sphere များနှင့် torus များကို ၎င်းတို့၏ အမှန် မျက်နှာပြင်များပေါ်တွင် ရေးသည်၊ ထို့ကြောင့် အခြား ပရိုဂရမ်က အပေါက်ကို cylinder အဖြစ် ရွေးနိုင်သည်; **Curves** က ၎င်းကို မပြောင်းပါ။ spline ဘေးများ၊ ပုံစံထုတ်ထား thread များနှင့် တင်သွင်းထားသော mesh များတွင် တိကျသော မျက်နှာပြင် မရှိပါ၊ တူညီသော solid တွင် ပြားသော facet အဖြစ်သာ ကျန်သည်; status bar က အရေအတွက် ပြသည်။ {{ui:STEP (faceted၊ mesh kernel)}} သည် စက်ဝိုင်းမျက်နှာတိုင်းကို facet အဖြစ် ရေးသည်။
:::

- ထုတ်ခြင်းများသည် ဖန်သားပြင်ပေါ်ရှိ အပိုင်း၏ ဖြစ်သည်။ assembly တွင် Export ပိတ်ထားသည်; assembly export မရှိသေးပါ။
- STL၊ 3MF၊ faceted STEP နှင့် face DXF သည် အမြဲ facet ဖြစ်သည်။ **Curves** ဆက်တင် (ဘာမျှ မရွေးထားစဉ် ညာဘက်ပြားတွင်) က တစ်ပတ်လျှင် facet 32 မှ 256 အထိ ဘယ်လောက် ချောမွေ့မည်ကို သတ်မှတ်သည်။ ချောမွေ့သော print အတွက် STL သို့မဟုတ် 3MF မထုတ်မီ Fine သို့မဟုတ် Very fine ကို ရွေးပါ။
- PDF ပုံဆွဲသည် ဖတ်သူ၏ built-in Helvetica font ကို သုံးသည်။ ပြသနိုင်သည် မဟုတ်သော စာလုံးများကို "?" ဟု ပုံနှိပ်သည်။

အဆင့်ဆင့်- [3D print၊ STEP နှင့် DXF အတွက် ထုတ်ခြင်း](topic:export-files) နှင့် [ပုံဆွဲစာရွက် ပြုလုပ်ခြင်း](topic:drawing-pdf)။

## မသိမ်းရသေးသော အလုပ်

- PartCraft သည် ပြောင်းလဲမှုတိုင်းပြီးနောက် ဖွင့်ထားသော အပိုင်း သို့မဟုတ် assembly ၏ recovery မိတ္တူကို ဤ browser တွင် ထိန်းထားသည်၊ crash သို့မဟုတ် ပိတ်ထားသော tab က အလုပ်ကို မဆုံးရှုံးစေရန်: PartCraft ကို နောက်တစ်ကြိမ် ဖွင့်လျှင် "အလုပ်ကို ပြန်ယူမလား?" ဟု မေးသည်။ ၎င်းသည် သိမ်းခြင်း မဟုတ်ပါ: အလုပ်ကို ထိန်းသိမ်းရန် ဖိုင်သို့ သိမ်းပါ။ [မသိမ်းရသေးသော အလုပ်ကို ပြန်ယူခြင်း](common:recover) ကို ကြည့်ပါ။
- သိမ်းမထားသော ပြောင်းလဲမှုများဖြင့် tab ကို ပိတ်ရန် သို့မဟုတ် reload လုပ်ရန် ကြိုးစားလျှင် browser က "ဆိုက်မှ ထွက်မလား?" ဟု မေးသည်။ ၎င်းသည် browser ၏ ကိုယ်ပိုင် အကွက်ဖြစ်ပြီး PartCraft က စာသားကို ပြောင်းနိုင်သည် မဟုတ်ပါ။
- {{ui:အသစ်}}၊ {{ui:ဖွင့်ရန်}} နှင့် assembly ပိတ်ခြင်းများသည် မသိမ်းရသေးသော ပြောင်းလဲမှုများကို စွန့်ပစ်မီ မေးသည်။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

အရာအားလုံး သင့်ကွန်ပျူတာပေါ်တွင် ဖြစ်သည်- mesh kernel (WebAssembly ပရိုဂရမ်) ကို app နှင့်အတူ ဒေါင်းပြီး geometry ကို ဒေသတွင်း တည်ဆောက်သည်၊ ဖိုင်များကို သင့် disk မှ ဖတ်ပြီး ထဲသို့ ရေးသည်။ အပိုင်းဒေတာ ကွန်ရက်ပေါ် မသွားပါ။ ကြည့်ရန်- [mesh kernel](topic:solid-kernels)။

ချိတ်ဆက်မှု လုံးဝ မရှိဘဲ အလုပ်လုပ်ရန် အွန်လိုင်းရှိစဉ် PartCraft ကို အော့ဖ်လိုင်း အသုံးပြုရန် သိမ်းပါ: app bar ရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို ရွေးပြီး **Offline ready** ဟု မပြမချင် ရေတွက်နေချိန်ကို စောင့်ပါ (သိမ်းနေသည် (212 ထဲမှ 40))။ သိမ်းထားသော မိတ္တူတွင် 3D library နှင့် mesh kernel ပါဝင်သဖြင့် နောက်ပိုင်း modeling၊ သိမ်းခြင်း၊ ထုတ်ခြင်းအားလုံးနှင့် ပုံဆွဲများသည် အော့ဖ်လိုင်းတွင် အလုပ်လုပ်သည်။ **Could not save** ဟု ပြလျှင် အွန်လိုင်းရှိစဉ် နှိပ်၍ ထပ်ကြိုးစားပါ; **Offline not available** သည် ဤ browser window က မိတ္တူ မသိမ်းနိုင်ကြောင်း ဆိုလိုသည် (private window များနှင့် managed ကွန်ပျူတာအချို့)။ မိတ္တူ သိမ်းပြီးနောက် **Offline ready** ကို နှိပ်လျှင် {{ui:ထပ်သိမ်းရန် (နောက်ဆုံးဗားရှင်း ယူရန်)}} နှင့် {{ui:အော့ဖ်လိုင်းမိတ္တူကို ဖယ်ရှားရန်}} ကို ပေးသည်။ အသေးစိတ်- [အော့ဖ်လိုင်း အလုပ်လုပ်ခြင်း](common:offline)။

:::online
အွန်လိုင်း ဖြစ်နေပါသည်။ အော့ဖ်လိုင်း အသုံးပြုရန် မသိမ်းဘဲပင်၊ PartCraft ဖွင့်ပြီး status bar chip က "Mesh kernel" ဟု ပြပြီးလျှင် ချိတ်ဆက်မှု ပြတ်သွားလည်း ဆက်လုပ်နိုင်သည်။ ချိတ်ဆက်ပြန်ရမချင်း စာမျက်နှာကို ပြန်မဖွင့်ပါနှင့်။
:::

:::offline
အော့ဖ်လိုင်း ဖြစ်နေပါသည်။ PartCraft ဖွင့်ပြီးသားဆိုလျှင် ဆက်လုပ်ပါ; သိမ်းခြင်းနှင့် ထုတ်ခြင်း ဆက်အလုပ်လုပ်သည်။ app bar တွင် **Offline ready** ဟု ပြလျှင် PartCraft သည် ချိတ်ဆက်မှု မရှိဘဲ အစကတည်းက ဖွင့်နိုင်သည်; မဟုတ်လျှင် ဤ tab ကို reload မလုပ်ပါနှင့်။
:::

## Browser များအကြား ကွာခြားချက်

- **ဒေါင်းလုဒ်များ။** browser တစ်ခုစီတွင် ကိုယ်ပိုင် downloads folder နှင့် မေးပုံ ရှိသည်။ browser က ဤဆိုက်က ဖိုင်ဒေါင်းခွင့် မေးလျှင် ခွင့်ပြုပါ၊ မဟုတ်လျှင် သိမ်းခြင်းနှင့် ထုတ်ခြင်း အလုပ်မလုပ်နိုင်ပါ။
- **Drag and drop** ဖိုင်ကို view ပေါ်သို့ ဆွဲချခြင်းသည် Chrome၊ Edge၊ Firefox နှင့် Safari တွင် အလုပ်လုပ်သည်။
- **ဖုန်း သို့မဟုတ် တက်ဘလက်မှ ဖိုင်များ။** iPhone နှင့် iPad တွင် Open က Files app ကို ပြသည်; သိမ်းထားသော ဖိုင်များသည် Files၊ Downloads သို့ သွားသည်။ Android တွင် Downloads folder သို့ သွားသည်။

browser သို့မဟုတ် operating system အကြား ဖိုင်များ ပါဝင်သည့်အရာတွင် ကွာခြားချက် မရှိပါ။
