**Extrude1 depth = thick + extra** ကဲ့သို့သော ညီမျှခြင်းသည် နှစ်ဘက်လုံး အလုပ်လုပ်သည်။

## ရှေ့သို့: parameter ကို ပြောင်းခြင်း

{{ui:Parameters}} tab တွင် `thick` ကို 20 မှ 30 သို့ ပြောင်းပါ။ Extrude1 ၏ depth သည် 30 + extra ဖြစ်လာပြီး အစိတ်အပိုင်း ပြန်တည်ဆောက်သည်။

## နောက်သို့: driven နံပါတ်ကို ပြောင်းခြင်း

1. History ရှိ "Extrude1" ကို နှိပ်ပါ။ ၎င်း၏ **Depth (mm)** အကွက်တွင် **ƒ** ပြသည်: ညီမျှခြင်းတစ်ခုက မောင်းနှင်နေသည်။
2. သင်လိုချင်သော size ကို ရိုက်ပါ၊ ဥပမာ `40`၊ ထို့နောက် {{key:Enter}} ကို နှိပ်ပါ။

PartCraft သည် ညီမျှခြင်းနောက်ရှိ parameter ကို ဘယ်လောက်အဆင့်ရှိရှိ ဖြေရှင်းသည် (`depth = hub_h`, `hub_h = disc_t + 50`: အမြင့်ရိုက်လျှင် `disc_t` ပြောင်းသည်)။ Status bar က ဘာပြောင်းသွားသလဲ ပြောသည်၊ ဥပမာ extra သည် 5 မှ 15 သို့ ပြောင်းသွားသည်။

နံပါတ်ကို မောင်းနှင်သော parameter နှစ်ခု သို့မဟုတ် ထို့ထက်ပို ရှိလျှင် **Which parameter should change?** ဟု မေးသော အကွက်တစ်ခု ပေါ်ပြီး ၎င်းတို့ကို စာရင်းပြသည်။ တစ်ခုကို နှိပ်ပါ; အခြားများသည် တန်ဖိုးကို ထိန်းထားသည်။ {{ui:Cancel}} သည် ဘာမျှ မပြောင်းပါ။

Sketch တွင်လည်း အလားတူ အလုပ်လုပ်သည်: driven dimension ကို နှစ်ချက်နှိပ်ပါ၊ တန်ဖိုး ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ Parameter table ၏ **Value** column တွင်လည်း အလုပ်လုပ်သည်၊ ၎င်းသည် expression ဖြစ်နေသော parameter အတွက်ပါ။

## မရနိုင်သောအခါ

- အပြည့်အတိသာ ဖြစ်ရမည့် နံပါတ် (pattern အရေအတွက်) သို့မဟုတ် အကွာအဝေးတွင် ရှိရမည့် နံပါတ် (360° အထိ ထောင့်) ကို မည်သည်မျှ မပြောင်းမီ ငြင်းပယ်သည်။
- ကိန်းသေနံပါတ်များသာ ပါသော ညီမျှခြင်း (`=40`) တွင် ပြောင်းရန် parameter မရှိပါ: ရိုက်သော နံပါတ်က အစားထိုးသည်။
- သင်ရိုက်သော size ကို ပေးနိုင်သော parameter တန်ဖိုး မရှိလျှင် status bar က ထိုသို့ ပြောပြီး ဘာမျှ မပြောင်းပါ။
- တန်ဖိုးအသစ်ဖြင့် ဖြေရှင်း၍ မရသော sketch သည် ယခင်တန်ဖိုးများကို ထိန်းထားပြီး status bar က sketch အမည်ကို ပြောသည်။

ဘယ်ဘက်ကမဆို ပြောင်းလဲမှုတိုင်းသည် {{key:Mod+Z}} နှင့် {{key:Mod+Y}} အတွက် အဆင့်တစ်ခု ဖြစ်သည်။
