PartCraft ၏ analysis library သည် coil နှင့် သံ၏ သံလိုက် field ကို 2-D တွင် တွက်နိုင်သည်: အရှည်ရှိပြီး အရှည်အတိုင်း တူညီသော အရာတစ်ခု၏ အပိုင်းဖြတ်ကို ဆိုလိုသည်၊ ဥပမာ လျှပ်စစ်သံလိုက်၊ ထရန်စဖော်မာ အူတိုင်၊ busbar သို့မဟုတ် မော်တာ၏ အပိုင်းဖြတ်။ ဤသင်ခန်းစာသည် library ၏ လျှပ်စစ်သံလိုက် ဥပမာကို run ပြီး ဖတ်ပြီး ပြောင်းလဲကာ၊ ကိုယ်ပိုင်ပုံသဏ္ဍာန်ကို မော်ဒယ်လုပ်ပုံပြပြီး နောက်ဆုံး အမြဲတမ်သံလိုက် ထည့်ပေးသည်။

Script workspace နှင့် [analysis library](topic:craftscript-library) ကို အသုံးပြုသည်။ ဤသင်ခန်းစာကို လိုက်ရန် CraftScript ဘာသာစကားကို သိစရာမလိုပါ; ဥပမာက လိုင်းတစ်ခုစီ ဘာလုပ်သည်ကို ပြောပြသည်။

## မော်ဒယ်လုပ်ထားသည့်အရာ

အပြင်ဘက် 100 × 80 mm၊ အထူ 20 mm ရှိသော C ပုံသဏ္ဍာန် သံအူတိုင်တစ်ခု၊ ညာဘက်ခြေထောက်တွင် လေကွာဟချက် 2 mm ရှိသည်။ ဘယ်ဘက်ခြေထောက်ပတ်ပတ်လည်တွင် အကွေ့ 100 ရှိသော coil တစ်ခု၊ current 10 A (အကွေ့-အမ်ပီယာ 1000) ကို သယ်ဆောင်သည်။ အရာအားလုံးသည် မျက်နှာပြင်မှ ထွက်သည့်ဘက်သို့ ရှည်သဖြင့် အဖြေများသည် **အနက်တစ်မီတာလျှင်** ဖြစ်သည်: အမှန် သံလိုက်အတွက် မြှောက်ပါ။

library ၏ `magnetostatic2d` သည် သံလိုက်ပတ်ပတ်လည် လေ၏ သေတ္တာတစ်ခုအတွင်း 1 mm လက်ကွက်များပေါ်တွင် magnetic vector potential ကို ဖြေရှင်းပြီး ၎င်းမှ flux density **B** (tesla ဖြင့်) ကို တွက်သည်။

## ဥပမာကို run ပါ

1. toolbar ဘယ်ဘက်ရှိ **Workspace** box တွင် **Script** ကို ရွေးပါ။
2. script panel ၏ **Library** tab ကို ဖွင့်ပြီး **Examples** › **Electromagnet: field, gap, inductance** ကို ဖွင့်ပါ။
3. {{ui:Open (read-only)}} ကို နှိပ်ပြီး {{key:F5}} ကို နှိပ်ပါ။

စက္ကန့်အနည်းငယ်အကြာတွင် canvas သည် flux density ကို ပြပြီး console သည် အောက်ပါအတိုင်း ပုံနှိပ်သည်:

```
B in the gap 0.5427 T; magnetic circuit 0.5516 T (-1.6 %: fringing and leakage)
inductance 0.1539 H per metre of depth; the circuit gives 0.1103 H/m, missing the flux that leaks past the gap
stored energy 7.694 J/m; |B| peaks at 1.97 T in the window's inner corners (real steel would saturate there)
pull across the gap about 2343 N per metre of depth (117.2 N for 50 mm deep)
```

canvas အောက်ရှိ plot သည် core ၏ အလယ်မျဉ်းတစ်လျှောက် ဘယ်မှ ညာသို့ vertical flux density B_y ကို ပြသည်: ဘယ်ဘက်ခြေထောက်တွင် ခန့်မှန်း −0.55 T (flux သည် အောက်သို့ စီးသည်)၊ ပြတင်းပေါက်တွင် မရှိလောက်၊ ညာဘက်ခြေထောက်နှင့် gap တစ်လျှောက် +0.55 T (flux သည် အပေါ်သို့ ပြန်လာသည်)။ flux တူတူသည် သံနှင့် gap ကို ဖြတ်သန်းသဖြင့် ခြေထောက်နှစ်ချောင်းနှင့် gap သည် နီးနီးတူသော တန်ဖိုးကို ပြသည်။

## ရလဒ်များကို ဖတ်ပါ

- **Gap ရှိ field** သည် 0.543 T ဖြစ်သည်။ လက်ဖြင့် တွက်ချက်ခြင်းသည် core ကို magnetic circuit တစ်ခုအဖြစ် ယူသည်၊ B = μ0 N I / (g + l / μr)၊ ဤတွင် g သည် gap၊ l သည် သံထဲရှိ လမ်းကြောင်းအလျား၊ μr သည် သံ၏ relative permeability; ၎င်းက 0.552 T ပေးသည်။ field သည် လက်ဖြင့်တွက်ချက်ခြင်းထက် အနည်းငယ်နိမ့်သည်၊ အကြောင်းမှာ flux သည် gap ပတ်ပတ်လည် ဖောင်းထွက်ပြီး (fringing) အချို့ flux သည် ပြတင်းပေါက်ကို ဖြတ်၍ ဖြတ်လမ်းတိုသွားသည် (leakage)။ gap ငယ်သည် သို့မဟုတ် grid ပိုသေးသည်ဆိုလျှင် နှစ်ခုသည် ပိုနီးလာမည်။
- **Inductance** ကို 100-အကွေ့ coil အတွက် အနက်တစ်မီတာလျှင် 0.154 H ဖြစ်သည်၊ field တွင် သိမ်းထားသော စွမ်းအင်မှ။ circuit ပုံသေနည်းက ပိုနည်းသော (0.110 H/m) တန်ဖိုးပေးသည်၊ အကြောင်းမှာ gap ကို ဖြတ်သော flux ကိုသာ ရေတွက်ပြီး ၎င်းကို ကျော်ထွက်သော flux ကို မရေတွက်ပါ။
- gap ကို ပိတ်ရန် **pull** သည် gap မျက်နှာ w အကျယ်အတွက် B² w / (2 μ0) ဖြစ်သည်: မီတာလျှင် ခန့်မှန်း 2300 N၊ သို့မဟုတ် အနက် 50 mm သံလိုက်အတွက် 117 N။
- 1.97 T အမြင့်ဆုံးသည် ပြတင်းပေါက်၏ အတွင်းထောင့်များတွင် ရှိသည်၊ flux သည် ထိုနေရာတွင် ထိုးကွေ့သည်။ model သည် သံကို linear အဖြစ် ယူသည်; အမှန် လျှပ်စစ်သံမဏိသည် ~1.5 မှ 2 T တွင် saturate ဖြစ်သည်၊ ထို့ကြောင့် ထိုအထက်တန်ဖိုးများကို အဖြေမဟုတ်ဘဲ သတိပေးချက်အဖြစ် ယူပါ။

:::note
library ၏ ကိုယ်ပိုင်စမ်းသပ်မှုများသည် ဤဥပမာကို run ပြီး PartCraft ပြောင်းလဲတိုင်း gap field ကို magnetic-circuit ပုံသေနည်းနှင့် စစ်ဆေးသည်။ နည်းလမ်း၊ ၎င်း၏ ကိုးကားချက်များနှင့် အခြားစစ်ဆေးမှုများ (ရှည်သော solenoid၊ သံအူတိုင်ပါသော solenoid) ကို `magnetostatic2d` ၏ header တွင် ရှိသည်: library တွင် ၎င်းကို နှိပ်ပါ။
:::

## Design ကို ပြောင်းပါ

1. read-only script အပေါ်ရှိ {{ui:Make a copy}} ကို နှိပ်ပါ။ မိတ္တူကို သင့် part နှင့်အတူ သိမ်းသည်။
2. အပေါ်ပိုင်းရှိ တန်ဖိုးတစ်ခုကို ပြောင်းပြီး {{key:F5}} ကို ထပ်နှိပ်ပါ။ ဤတို့ကို စမ်းကြည့်ပါ:
   - `g = 0.001;` — gap ထက်ဝက်: gap field သည် ခန့်မှန်း နှစ်ဆနီးပါး တိုးသည်၊ pull လည်း တိုးသည် (B² နှင့်အတူ သွားသည်)။
   - `mur = 200;` — ပိုညံ့သော core: အမ်ပီယာ-အကွေ့ပိုမို သံထဲတွင် ကုန်သွားသည်။
   - `N = 200;` — အကွေ့နှစ်ဆ: field နှစ်ဆ၊ inductance လေးဆ။
   - `h = 0.0005;` — ပိုသေးသော grid: အဖြေများ ပိုနီးသည်၊ အချိန် ခန့်မှန်း လေးဆ။

run တိုင်းက canvas ကို အစားထိုးသည်။ script ဖန်တီးသော variable များ (`Bgap`၊ `L`၊ `F` ကဲ့သို့) သည် သင့်ကိုယ်ပိုင် တွက်ချက်မှုများအတွက် **Variables** list တွင် ကျန်နေသည်။

## ကိုယ်ပိုင်ပုံသဏ္ဍာန်ကို မော်ဒယ်လုပ်ပါ

ဥပမာသည် grid လက်ကွက်တစ်ခုလျှင် တန်ဖိုးတစ်ခုရှိသော စာရင်းသုံးခုမှ အရာအားလုံးကို တည်ဆောက်သည်။ ၎င်းကို grid ပေါ်ရှိ မျဉ်းဖြောင့်များဖြင့် ဆွဲထားသော ပုံသဏ္ဍာန်မည်သည့်အတွက်မဆို ပြုလုပ်နိုင်သည်:

- **သံရှိနေရာ:** `iron` သည် core ထဲရှိ လက်ကွက်များအတွက် true ဖြစ်သည်။ ဥပမာသည် ၎င်းကို ထောင့်မှန်များဖြင့် တည်ဆောက်သည်: `frame & ~window & ~gap` ဆိုသည်မှာ "frame ထဲတွင်၊ ပြတင်းပေါက်ထဲ မဟုတ်၊ gap ထဲ မဟုတ်" ဖြစ်သည်။
- **Permeability:** `1 + (mur - 1) * iron` သည် လေထဲတွင် 1 ဖြစ်ပြီး သံထဲတွင် `mur` ဖြစ်သည်။ ပစ္စည်းများစွာရှိပါက တူညီသော ပုံစံဖြင့် ၎င်းတို့၏ တန်ဖိုးများ ပေးပါ။
- **Current:** `J` သည် လက်ကွက်တစ်ခုစီအတွက် current density ဖြစ်ပြီး ယူနစ် A/m² ဖြင့် ဖြစ်သည်၊ မျက်နှာပြင်မှ ထွက်သည်ကို အပေါင်း၊ အထဲသို့ဝင်သည်ကို အနုတ်။ coil တစ်ခုတွင် ဆန့်ကျင်ဘက်အမှတ်ရှိသော ဘက်နှစ်ဘက် ရှိသည်; ဥပမာသည် `J0` ကို တွက်ထုတ်ပြီး တစ်ဘက်က N I ကို သယ်ဆောင်စေသည်။

ထို့နောက် `r = magnetostatic2d(m, permeability, J)` က ဖြေရှင်းသည်။ `r.B` သည် လက်ကွက်တစ်ခုစီရှိ flux density (ကော်လံနှစ်ခု၊ x နှင့် y)၊ `r.Bmag` သည် ၎င်း၏ အရွယ်အစား၊ `r.energy` သည် အနက်တစ်မီတာလျှင် သိမ်းထားသော စွမ်းအင်ဖြစ်သည်။ `plot(x, y)` က မျဉ်းတစ်ခု ဆွဲသည်။

library သည် မီတာဖြင့် အလုပ်လုပ်ပြီး view က မီလီမီတာဖြင့် ပြသသည်၊ ထို့ကြောင့် field ကို ဘာမပြောင်းဘဲ ပြလျှင် တစ်ထောင်ဆတစ်ဆ သေးငယ်စွာ ဆွဲမည်။ ဥပမာသည် grid ၏ မိတ္တူကို မီလီမီတာဖြင့် ပြသသည် (`mm = quadGrid(…)`၊ ထို့နောက် `show(field(mm, …))`): ထို လိုင်းနှစ်ကြောင်းကို ကူးပါ။

မူလအနေဖြင့် သေတ္တာ၏ အစွန်းက field ကို ထိန်းထားသည်: flux မထွက်သွားပါ။ သံလိုက်၏ အနည်းဆုံး နှစ်ဆ သို့မဟုတ် သုံးဆ အရွယ်ရှိသော သေတ္တာကို ပြုလုပ်ပါ၊ ထို့ကြောင့် ဤအရာက field ကို ညှစ်မည်မဟုတ်ပါ။ symmetric သံလိုက်အတွက် ထိုတစ်ဝက်ကိုသာ မော်ဒယ်လုပ်နိုင်သည်: `magnetostatic2d` ၏ header က symmetry လိုင်းတွင် မည်သည့် edge condition ကို သုံးရမည်ကို ပြောသည်။

## အမြဲတမ်သံလိုက်များ

ဒုတိယဥပမာ **Examples** › **Permanent magnet in an iron core: working point, leakage, pull** သည် core တူတူဖြစ်ပြီး coil ကို ဖယ်ထုတ်ကာ ဘယ်ဘက်ခြေထောက်၏ 10 mm အပိုင်းကို အပေါ်သို့ သံလိုက်ဖြစ်အောင် သံလိုက်ဖြင့် အစားထိုးထားသည်။ {{key:F5}} ဖြင့် run ပါ။ အောက်ပါအတိုင်း ပုံနှိပ်သည်:

```
the magnet works at B = 1.036 T, H = -124 kA/m (on its recoil line B = Br + μ0 μr H)
B in the gap 0.6778 T; the magnetic circuit without leakage 0.9692 T (-30.1 %)
leakage factor 1.53: of the flux leaving the magnet, 65 % crosses the gap between the pole faces
pull across the gap about 3656 N per metre of depth (182.8 N for 50 mm deep)
```

- **Working point။** သံလိုက်ကို **remanence** Br (သံဖြင့် short လုပ်ထားသည့်အခါ ထိန်းထားသော field: sintered NdFeB သံလိုက်အတွက် ခန့်မှန်း 1.2 T၊ ferrite အတွက် 0.4 T) နှင့် ၎င်း၏ recoil permeability (ခန့်မှန်း 1.05 နှင့် 1.1) ဖြင့် ဖော်ပြသည်။ gap ဖွင့်လိုက်သောအခါ ၎င်းကို ၎င်း၏ recoil မျဉ်းအတိုင်း ဆင်းစေသည်: ဤတွင် 1.04 T သို့၊ ၎င်းအတွင်း H သည် B ၏ ဆန့်ကျင်ဘက်ကို ညွှန်သည်။
- **Leakage။** leakage မရှိသော လက်ဖြင့်တွက်ချက်ခြင်းက gap တွင် 0.97 T ပေးသည်; model က 0.68 T ပေးသည်။ သံလိုက်သည် တိုတောင်းသော အလျားတွင် ခိုင်မာသော တွန်းအားဖြင့် flux ကို မောင်းသည်၊ ထို့ကြောင့် များစွာသော flux သည် gap ကို မဖြတ်ဘဲ ပြတင်းပေါက်ကို ဖြတ်၍ တိုက်ရိုက် ပြန်သွားသည်။ leakage factor သည် ဘယ်လောက်ဖြစ်သည်ကို ပြောသည်: ဤတွင် 1.53။ ပိတ်ထားသော keeper အတွက် `g = 0;` ထားပါ: ထိုအခါ သံလိုက်သည် လက်ဖြင့်တွက်ချက်ခြင်းနှင့် ရာခိုင်နှုန်း ဝက်အတွင်း အလုပ်လုပ်သည်။
- **သင့်ကိုယ်ပိုင် model ထဲရှိ သံလိုက်များ။** `magnetostatic2d` ကို သံလိုက်များကို `struct('Br', Br)` အဖြစ် ပေးပါ၊ ဤတွင် `Br` တွင် grid လက်ကွက်တစ်ခုစီအတွက် row တစ်ခု ရှိပြီး x နှင့် y ရှိ remanence ကို tesla ဖြင့် (သံလိုက်ပြင်ပတွင် သုည)၊ နှင့် သံလိုက်လက်ကွက်များကို permeability စာရင်းတွင် ၎င်းတို့၏ recoil permeability ပေးပါ:

  ```
  Brem = [zeros(numel(mag), 1), 1.2 * mag];     % 1.2 T upward in the squares where mag is true
  r = magnetostatic2d(m, 1 + (mur - 1) * iron + 0.05 * mag, 0, struct(), struct('Br', Brem));
  ```

  ထောင့်တစ်ခုဖြင့် သံလိုက်ဓာတ်ဝင်ထားပါက `Br·cos(angle)` နှင့် `Br·sin(angle)` ကို ကော်လံနှစ်ခုတွင် ထည့်ပါ; အပြင်သို့ ဓာတ်ဝင်ထားသော ring အတွက် လက်ကွက်တစ်ခုစီ၏ ဦးတည်ချက်ကို ၎င်း၏ နေရာမှ တွက်ပါ။ `r.H` သည် လက်ကွက်တစ်ခုစီရှိ field strength H ကို ပေးသည်။

model သည် သံလိုက်ကို ၎င်း၏ တည့်သော recoil မျဉ်းပေါ်တွင် ထားသည်၊ မည်မျှပင် ခိုင်မာစွာ မောင်းသည်ဖြစ်စေ။ အမှန်သံလိုက်တစ်ခုသည် ၎င်း၏ knee ကျော်သွားသည်အထိ (gap ကြီးခြင်း၊ coil ခိုင်မာခြင်း သို့မဟုတ် အပူကြောင့်) ၎င်း၏ အစွမ်းအစား အစိတ်အပိုင်းကို အမြဲတမ်ဆုံးရှုံးသည်; working point ကို grade နှင့် အပူချိန်အတွက် ထုတ်လုပ်သူ၏ curve နှင့် စစ်ဆေးပါ။

library ၏ စမ်းသပ်မှုများက သံလိုက်များကို လက်ဖြင့်ရလဒ်နှစ်ခုဖြင့် စစ်ဆေးသည်: လေထဲရှိ စက်ဝိုင်းသံလိုက် (အတွင်းတွင် B = Br / (1 + μr)) နှင့် သံ keeper ဖြင့် ပိတ်ထားသော သံလိုက် (magnetic circuit)၊ နှစ်ခုစလုံး 1 % အတွင်း။

## ၎င်းက ယခု မလုပ်နိုင်သေးသည်များ

- **Saturation။** သံသည် linear ဖြစ်သည်: current နှစ်ဆ၊ field နှစ်ဆ၊ အကန့်အသတ်မရှိ။
- **Demagnetisation။** သံလိုက်များသည် ၎င်းတို့၏ တည့်သော recoil မျဉ်းပေါ်တွင် ကျန်နေသည် (အထက်ကို ကြည့်ပါ)။
- **Eddy current** နှင့် **loss** (သံ loss၊ ကြေးနီ loss)။
- **ရွေ့လျားသော အစိတ်အပိုင်းများနှင့် torque။** stator ထဲရှိ rotor လည်ခြင်း မရှိ၊ angle ဆန့်ကျင်သော torque မရှိ။
- **အလုံးပုံ ပုံသဏ္ဍာန်များ။** grid သည် တူညီသော လက်ကွက်များဖြင့် ဖွဲ့စည်းထားသဖြင့် ကွေးသော outline များသည် အဆင့်ဆင့်ဖြစ်လာသည်။
- **3-D။** အရာအားလုံးသည် အရှည်ရှိသော အရာ၏ အပိုင်းဖြတ်ဖြစ်သည်။

Motor design (လည်နေသော rotor၊ 2-D ရှိ torque နှင့် loss) ကို နောက်ဗားရှင်းအတွက် စဉ်းစားနေသည်။ [Not built yet](topic:not-built-yet) ကို ကြည့်ပါ။
