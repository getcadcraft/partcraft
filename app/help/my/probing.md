Manufacture ရှိ {{ui:စမ်းသပ်ထိုးခြင်း}} က probing cycle တစ်ခုကို ပရိုဂရမ်ထဲ ရေးသည်: probe က ပစ္စည်းကို ထိပြီး ထိန်းချုပ်ကိရိယာက work offset (G54) ကို မျက်နှာကို တွေ့သည့်နေရာနှင့် model က ပြသည့်နေရာ ကွာခြားမှုအတိုင်း ရွှေ့သည်။ နောက်လုပ်ဆောင်ချက်များသည် ပစ္စည်း တကယ်ရှိနေသည့်နေရာတွင် ဖြတ်သည်။

**ဤအရာကို စက်ပေါ်တွင် မည်သည့်အခါမျှ မ run ထားပါ။** ထိမှုမတိုင်မီ ရွေ့လျားမှုများသည် ပုံမှန် ရွေ့လျားမှုများဖြစ်ပြီး probe ကို probing ရွေ့လျားမှု ကိုယ်တိုင်အထိ မကြည့်ရှုရပါ။ နှေးနှေးလုပ်ပါ၊ ပထမ လေထဲတွင် စမ်းပါ၊ လက်ကို feed hold ပေါ်တွင် ထားပါ။

## သုံးပုံ

1. **Tools** tab တွင် ပထမ probe လုပ်ဆောင်ချက်က **touch probe** ကို ထည့်သည်: ၎င်း၏ ball အချင်းနှင့် probing feed (100 mm/min သင်မသတ်မှတ်လျှင်)။
2. Manufacture toolbar ရှိ {{ui:နောက်ထပ်}} ကို နှိပ်ပြီး {{ui:စမ်းသပ်ထိုးခြင်း}} ကို နှိပ်၊ ထို့နောက် ထိရမည့်အရာကို နှိပ်ပါ။ ရွေးချယ်မှုတစ်ခုစီသည် cycle တစ်ခု ဖြစ်ပြီး သင်နှိပ်သည့် အစီအစဉ်အတိုင်း:

| ရွေးချယ်မှု | Cycle | ဘာသတ်မှတ်သလဲ |
|---|---|---|
| ကိရိယာ axis ကို ကြည့်သော ပြားသော မျက်နှာ | အောက်သို့ ဆင်းသော ထိမှုတစ်ကြိမ် | Z |
| X သို့မဟုတ် Y နှင့် ထောင့်မှန်သော ပြားသော ဘေးမျက်နှာ | မျက်နှာ၏ ထိပ်အနည်းငယ် အောက်တွင် မျက်နှာဆီ သွားသော ထိမှုတစ်ကြိမ် | X သို့မဟုတ် Y |
| ကိရိယာ axis တစ်လျှောက် အပေါက် သို့မဟုတ် boss | ထိမှုလေးကြိမ် (+X၊ −X၊ +Y၊ −Y) | ၎င်း၏ ဗဟို၏ X နှင့် Y |

3. **ရလဒ်ဖြင့်**: {{ui:Work offset ကို သတ်မှတ်ရန်}} သို့မဟုတ် {{ui:တိုင်းတာရုံသာ}}။
4. **ဤအကွာအဝေး ဝေးမှ စတင်ပါ** နှင့် **ဤအကွာအဝေး ကျော်ပြီး ရှာပါ** က probing ရွေ့လျားမှု မျှော်လင့်ထားသော မျက်နှာမှ ဘယ်လောက်ဝေးမှ စတင်လဲ၊ ထိန်းချုပ်ကိရိယာ လက်မလျှော့မီ probe က ဘယ်လောက် ကျော်သွားနိုင်လဲ ဖြစ်သည်။ **Depth** က ball သည် အပေါက်၊ boss သို့မဟုတ် ဘေးမျက်နှာ၏ အထက်မှ ဘယ်လောက် အောက်ဆင်းသလဲ ဖြစ်သည်။

Probe လုပ်ဆောင်ချက်ကို ပထမ ထားပါ၊ မည်သည်မျှ မဖြတ်မီ။

## ထိန်းချုပ်ကိရိယာ တစ်ခုစီ ဘာရေးသလဲ

| ထိန်းချုပ်ကိရိယာ | ထိမှု | ရလဒ် |
|---|---|---|
| Fanuc-style | `G31`၊ ရာထားကို `#101` မှ `#104` တွင် သိမ်း | Offset variables (`#5221` မှ `#5223`) ကို တွေ့သည် − မျှော်လင့်သည် ဖြင့် ရွှေ့သည်။ Measure only: ကွာခြားချက်ကို `#110` (နှင့် `#111`) တွင် ထားသည်။ |
| LinuxCNC | `G38.2`၊ ရာထားကို အမည်ပေးထားသော parameters တွင် သိမ်း | Offset အသစ်ဖြင့် `G10 L2 P1`။ Measure only: `(DEBUG, …)` မက်ဆေ့ချ်။ |
| GRBL | `G38.2` | ထိမှုတစ်ကြိမ်က `G10 L20 P1` ဖြင့် ဝင်ရိုးကို သတ်မှတ်သည်။ GRBL တွင် variables မရှိသဖြင့် **ဗဟိုကို တွက်၍ မရ**: ဖိုင်က comment တွင် ထိုသို့ ပြောပြပြီး မည်သည်ကိုမျှ မသတ်မှတ်ပါ။ |

သင်္ချာသည် post ၏ ဖြစ်သောကြောင့် ပြောင်းလဲနိုင်သည်: events များမှာ `probe-move` နှင့် `probe-set` ဖြစ်သည် ([ပြင်ဆင်နိုင်သော post processors](topic:post-processors))။

## ကန့်သတ်ချက်များ

- Work offset တစ်ခု (G54)။ အက်စ်ဝင်ရိုးများနှင့် ထောင့်မှန်သော မျက်နှာများသာ: ထောင့်မရှိ၊ corner cycle မရှိ၊ work ကို လှည့်ခြင်း မရှိ။
- Tool setter မရှိ၊ ကိရိယာ ကျိုးမှု စစ်ဆေးခြင်း မရှိ၊ size ကို tolerance နှင့် တိုင်းခြင်း မရှိ၊ အစီရင်ခံစာ မရှိ။
- Probe အတွက် spindle မစတင်ပါ၊ coolant ပိတ်ထားသည်; spindle ထဲရှိ ကိရိယာသည် probe ဖြစ်မဖြစ် ဘယ်သူမှ မစစ်ပါ။
- ကုန်ကြမ်း simulation သည် probing လမ်းကြောင်းကို မ run ပါ။
- Probe ၏ ကိုယ်ပိုင် calibration (ball offset၊ stylus deflection၊ trigger direction) သည် ထိန်းချုပ်ကိရိယာ၏ ဖြစ်သည်။
