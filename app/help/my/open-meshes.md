PartCraft သည် STL၊ OBJ နှင့် 3MF mesh များကို **solid body** အဖြစ် ဖွင့်သည်။ body သည် solid အခြားတစ်ခုကဲ့သို့ အလုပ်လုပ်သည်: ဖြတ်၊ ထည့်၊ အပေါက်ထွင်၊ pattern လုပ်၊ assembly သို့မဟုတ် machining အတွက် သုံး၊ ပြား မျက်နှာများပေါ် ပုံဆွဲချက်ဆွဲနိုင်သည်။ ၎င်း၏ကိုယ်ပိုင် history မရှိပါ: mesh သည် တြိဂံများသာ ဖြစ်သောကြောင့် အရွယ်အစားကို ပြောင်း၍မရ၊ ထည့်ခြင်း သို့မဟုတ် ဖြတ်ခြင်းသာ လုပ်နိုင်သည်။

## mesh ဖွင့်ခြင်း

1. {{ui:ဖွင့်ရန်}} ကို ရွေးပါ သို့မဟုတ် {{key:Mod+O}} ကို နှိပ်ပြီး `.stl`၊ `.obj` သို့မဟုတ် `.3mf` ဖိုင်ကို ရွေးပါ။ သို့မဟုတ် 3D view ပေါ် ချပါ။
2. PartCraft သည် ဖတ်ပြီး လုံခြုံစွာ ပြင်နိုင်သည်ကို ပြင်ကာ တွေ့သည်များကို ပြသည်: တြိဂံနှင့် အမှတ် ဘယ်နှစ်ခု၊ ပြုပြင်ချက်တစ်ခုစီ၊ နှင့် mesh ယခု **ပိတ်သလား** ရှိမရှိ။
3. **Units in the file** နှင့် **Up in the file** ကို စစ်ဆေးပါ။ STL နှင့် OBJ က ယူနစ်ကို မပြောသဖြင့် မီလီမီတာကို ခန့်မှန်းသည်; 3MF ဖိုင်က ကိုယ်ပိုင် ပြောသည်။ **Size here** စာကြောင်းက သင့်ရွေးချယ်မှုဖြင့် body ၏ အရွယ်အစားကို ပြသည်၊ ထို့ကြောင့် 25.4 ဆ သေးနေသော အစိတ်အပိုင်းကို လွယ်လွယ်တွေ့နိုင်သည် (လက်မဖြင့် ရေးထားခဲ့သည်)။
4. အစိတ်အပိုင်းက မြင်ကွင်းပေါ် ဗလာဖြစ်လျှင် {{ui:ခန္ဒာအဖြစ် ဖွင့်ရန်}} ကို ရွေးပါ။ အစိတ်အပိုင်းတွင် feature များ ရှိပြီးသားဆိုလျှင် **ဤအတွက် အသုံးပြုရန်** (ထည့်ရန်၊ ထိုမှ ဖြတ်ရန်၊ သို့မဟုတ် အထပ်ထပ်ကျသော အပိုင်းသာ ထိန်းရန်) ကို ရွေးပြီး {{ui:ဤအစိတ်အပိုင်းသို့ ထည့်ရန်}}၊ သို့မဟုတ် mesh ဖြင့် အစမှ ပြန်စရန် {{ui:အစိတ်အပိုင်းအသစ်}} ကို ရွေးပါ။

History တွင် **Imported1** feature ပေါ်လာသည်။ status bar က ဥပမာ "bracket.stl is a solid body: 15200.512 mm³, 14 flat faces to sketch on." ဟု ပြောသည်။

## mesh မပိတ်လျှင်

solid တစ်ခုသည် ဖွင့်ချက်မရှိသော မျက်နှာပြင် လိုအပ်သည်။ PartCraft ပိတ်၍ မရလျှင် dialog က ကျန်သော ဖွင့်ချက်နှင့် ဖွင့်ထားသော အစွန်းများ ဘယ်နှစ်ခု ရှိသလဲ ပြောပြီး ထည့်ရန် body မရှိပါ။ mesh ကို ပြုလုပ်ခဲ့သော ပရိုဂရမ်တွင် ဖွင့်ချက်များကို ပိတ်ပါ၊ သို့မဟုတ် ပိတ်ထားသော (watertight) mesh အဖြစ် ထပ် export လုပ်ပြီး ပြန်ဖွင့်ပါ။

PartCraft သည် ဖြည့်ခြင်းက မှားနိုင်သောအခါ ဖွင့်ချက်ကို ထားခဲ့သည်: ကောက်ကွေးသော ကြီးသော အပေါက်၊ သို့မဟုတ် ဆက်တိုက် ပလိန်းတစ်ခုတည်းတွင် ဖွင့်ချက် နှစ်ခု (ဖျက်ပျောက်နေသော ကွင်းပုံ မျက်နှာတစ်ခု၊ နယ်နိမိတ်တစ်ခုစီ ဖြည့်လျှင် အလယ်ကို ဖုံးသွားမည်)။ တြိဂံ သုံးခုထက်ပို မျှဝေသော အစွန်းတစ်ခုကိုလည်း အစီရင်ခံသည်: ထိုမျက်နှာသည် ရှင်းသော အတွင်းမရှိပါ။

## ပုံဆွဲချက်ပေါ် ပြား မျက်နှာများပေါ် ပုံဆွဲခြင်း

တြိဂံ အများအပြား ဖွဲ့ထားသော ပြား ဧရိယာများကို **flat face** တစ်ခုစီအဖြစ် ပေါင်းသည်၊ ထို့ကြောင့် ပုံဆွဲချက်ကို ထိုနေရာတွင် ထားနိုင်သည်: မျက်နှာကို နှိပ်ပြီး {{ui:ဤမျက်နှာပေါ်တွင် ပုံဆွဲချက်}} ကို ရွေးပါ။ နောက်မှ ဖြတ်သည် သို့မဟုတ် ထည့်သော မျက်နှာသည် မျက်နှာအဖြစ် ဆက်ရှိသည်။ အဝိုင်းပုံ ဧရိယာများ (အပေါက်၊ fillet) သည် တြိဂံ ဆက်ရှိသည်: ၎င်းတို့သည် ရွေးနိုင်သော မျက်နှာများ မဟုတ်ပါ၊ မြင်ကွင်းက တြိဂံများကြား ထောင့်မှ outline ကို ဆွဲသည်။

## နောက်မှ ပြောင်းခြင်း

**Imported1** ကို ရွေးပြီး ၎င်းလာသော ဖိုင်၊ တြိဂံ အရေအတွက်နှင့် ပြင်ဆင်ခဲ့သည်များကို ကြည့်ပါ။ **Units in the file**၊ **Up in the file** နှင့် **Use it to** ကို ထိုနေရာတွင် ပြောင်းနိုင်သည်; ပြောင်းလဲမှု တစ်ခုစီသည် undo step တစ်ခု ဖြစ်သည်။

## ဘယ်မှာ သိမ်းထားသလဲ

ပြင်ဆင်ပြီးသား mesh ကို `.partcraft.json` ဖိုင် **အတွင်း** သိမ်းသည်၊ ထို့ကြောင့် mesh ဖိုင်ကို နောက်တစ်ကြိမ် မလိုအပ်ပါ။ mesh body ပါသော အစိတ်အပိုင်းဖိုင်သည် ဗားရှင်း 5 ဖြစ်သည်; ဟောင်းသော PartCraft သည် ၎င်း၏ ဗားရှင်းဖြင့် ငြင်းသည်။ တြိဂံ 200,000 ပါသော mesh သည် ခန့်မှန်း 1.2 MB ထည့်သည်။

## ကန့်သတ်ချက်များ

- ဖိုင်တစ်ခုတွင် တြိဂံ 3 သန်းအထိနှင့် 200 MB အထိ။
- mesh မှ ပြုလုပ်သော body ကို mesh kernel က တည်ဆောက်သည်။ တိကျသော kernel ကို ဖွင့်ထားလျှင် (developer များအတွက်သာ) ထိုအကြောင်းကို ပြပြီး တည်ဆောက်မည်မဟုတ်ပါ။
- OBJ ပစ္စည်းများ၊ texture coordinate များနှင့် ကွေးသော free-form မျဉ်းများကို ချန်ထားသည်; 3MF အရောင်များ၊ ပစ္စည်းများနှင့် support object များကို ချန်ထားသည် (dialog က ကျော်သွားသော object အရေအတွက်ကို ပြသည်)။
- body သည် mesh နှင့် အတူ ကောင်းသည်: ကြမ်းသော STL သည် ကြမ်းသော ဝိုင်းမျက်နှာများ ပေးသည်။ သင်ထွင်သော အပေါက်များသည် သင့်ကိုယ်ပိုင် feature များကဲ့သို့ ဝိုင်းသည်။
