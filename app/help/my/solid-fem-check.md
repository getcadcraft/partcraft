## ဘာလုပ်မည်နည်း

load အောက်ရှိ solid အစိတ်အပိုင်းတစ်ခုကို စစ်ဆေးသည်- ၎င်း ရွေ့သည့်နေရာနှင့် stress အမြင့်ဆုံးနေရာ။ လေ့လာမှုသည် linear နှင့် elastic ဖြစ်သဖြင့် စစ်ဆေးရန် အကူအညီ သာ ဖြစ်သည်၊ သင်၏ အင်ဂျင်နီယာက ရလဒ်များကို သုံးသပ်ပါမည်။

## အဆင့်များ

1. {{ui:ဆက်တင်များ}} › {{ui:ထပ်ဆောင်းများ}} ကို ရွေးပြီး Solid FEM ကို ဖွင့်ပါ (သင်မဖွင့်မချင်း ပိတ်ထားသည်)။ ညာဘက် panel ရှိ Solid FEM tab ကို ဖွင့်ပါ။
2. {{ui:ပစ္စည်း}} အောက်တွင် တစ်ခု ရွေးပါ၊ သို့မဟုတ် {{ui:စိတ်ကြိုက်}} ကို ရွေး၍ Poisson ratio၊ density နှင့် yield stress ကို ရိုက်ထည့်ပါ။
3. ပုံသေ မျက်နှာများ ထည့်ရန် ကို နှိပ်ပါ၊ 3D view တွင် ထိန်းထားသည့် မျက်နှာများကို နှိပ်ပါ၊ ထို့နောက် {{ui:ရွေးပြီး}} ကို နှိပ်ပါ။
4. {{ui:အင်အား ထည့်ရန်}}၊ {{ui:ဖိအား ထည့်ရန်}} သို့မဟုတ် {{ui:ဆွဲငင်အား ထည့်ရန်}} ဖြင့် load ထည့်ပြီး ၎င်း၏ မျက်နှာများကို အတူတူ ရွေးပါ။
5. {{ui:အစိတ်အပိုင်းကို mesh လုပ်ရန်}} ကို နှိပ်ပါ၊ ထို့နောက် {{ui:ဖြေရှင်းရန်}}။ frequency လိုချင်လျှင် ပထမ {{ui:Study}} အောက်ရှိ {{ui:သဘာဝကြိမ်နှုန်းများ}} ကို ရွေးပါ။
6. {{ui:ရလဒ်များ}} နှင့် {{ui:သတိပေးချက်များ}} ကို ဖတ်ပါ၊ ထို့နောက် von Mises stress၊ displacement သို့မဟုတ် mode shape ကို ဆွဲရန် {{ui:မော်ဒယ်ပေါ်တွင် ပြရန်}} ကို နှိပ်ပါ၊ {{ui:ဂရပ်ကို ဖယ်ရန်}} က ၎င်းကို ဖယ်ပေးသည်။

## မှတ်ချက်များ

- စာမျက်နှာသည် element အရေအတွက် သတ်မှတ်ထားသည့်အထိ ဖြေရှင်းသည်; element အရွယ်အစား လွန်စွာ သေးငယ်သည့်အခါ status line က ပြောသည်။
- ပုံသေ မျက်နှာများ၊ load အမှတ်များနှင့် ထက်မြက်သော ထောင့်များတွင် stress သည် mesh ကို ပိုသေးစေသည့်အခါ တိုးလာသည်။ အထွတ်အထိပ်ကို မှီခိုမီ ပိုသေးစေ၍ နှိုင်းယှဉ်ပါ။
- ပြောင်းလဲမှုတိုင်းသည် undo အဆင့်တစ်ခု ဖြစ်ပြီး ဆက်တင်များကို အစိတ်အပိုင်း ဖိုင်တွင် သိမ်းသည်။
- yield နှင့် contact လေ့လာမှုများအတွက် [stress နှင့် deflection စစ်ဆေးခြင်း](topic:simulation) ကို ကြည့်ပါ။
