Manufacture သည် ကိရိယာကို ထောင့်တစ်ခုတွင် ထားနိုင်ပြီး ဖြတ်နေစဉ် rotary axes များကို ရွှေ့နိုင်သည်။ အရိုးရှင်းဆုံးမှ အဆင့်မြင့်သည်အထိ နည်းလမ်း သုံးခုရှိသည်။

**ဤအရာတွင် စက်ပေါ်တွင် မည်သည့်အရာမျှ မ run ထားပါ။** လမ်းကြောင်းများကို စမ်းသပ်မှုများက ပုံသဏ္ဍာန်နှင့် နှိုင်းယှဉ်ထားပြီး G-code ကို ပြန်ဖတ်ထားသည်၊ သို့သော် built-in posts များသည် ထိန်းချုပ်ကိရိယာများ၏ မှတ်တမ်းတင်ထားသော codes ကို လိုက်နာပြီး ကျွန်ုပ်တို့ရှေ့ရှိ မည်သည့်စက်ကိုမျှ မလိုက်နာပါ။ သင်၏ ထိန်းချုပ်ကိရိယာ၏ ကိုယ်ပိုင် simulator နှင့် လေထဲတွင် ပရိုဂရမ်ကို သက်သေပြပါ သတ္တုနှင့် မတွေ့မီ။

## စက်၏ rotary axes

**Setup** tab တွင် {{ui:Rotary axes}} က စက်တွင် ဘာရှိသလဲ ပြောသည်:

| ရွေးချယ်မှု | စက် |
|---|---|
| None (3 axes) | ရိုးရိုး mill။ ကိရိယာ စောင်းရန် လိုအပ်သော လုပ်ဆောင်ချက်တိုင်း သတိပေးပြီး post က ရေးရန် ငြင်းသည်။ |
| A (X ပတ်လည် လှည့်) | X ရှိ rotary axis တစ်ခု: 4th-axis စားပွဲ သို့မဟုတ် indexer။ ကိရိယာသည် Y–Z plane တွင်သာ စောင်းနိုင်သည်။ |
| B (Y ပတ်လည် လှည့်) | Y ရှိ rotary axis တစ်ခု။ ကိရိယာသည် X–Z plane တွင်သာ စောင်းနိုင်သည်။ |
| A နှင့် C | X ပတ်လည် tilt axis တစ်ခု၊ Z ပတ်လည် လှည့်မှုတစ်ခုက သယ်ထားသော သို့မဟုတ် သယ်သော: trunnion စားပွဲ သို့မဟုတ် ခေါင်း။ |
| B နှင့် C | Tilt Y ပတ်လည်ဖြင့် တူညီသည်။ |

ထို့နောက်:

- **Carried by**: {{ui:စားပွဲ (ပစ္စည်း လည်သည်)}} သို့မဟုတ် {{ui:ခေါင်း (ကိရိယာ လည်သည်)}}။ စားပွဲသည် တူညီသော မျက်နှာကို ကိရိယာအောက် ယူရန် ဆန့်ကျင်ဘက် ဘက်သို့ လှည့်သဖြင့် ထောင့်တိုင်း၏ လက္ခဏာသည် ဤကနေ လိုက်သည်။
- **ထိန်းချုပ်ကိရိယာက ကိရိယာ ထိပ်ကို လမ်းကြောင်းပေါ် ထားသည် (TCP)**: ဖွင့်ထားလျှင် ပရိုဂရမ်ရှိ X Y Z သည် ပစ္စည်း၏ ကိုယ်ပိုင် သြဒိနိတ်များတွင် ကိရိယာ ထိပ်ဖြစ်ပြီး ထိန်းချုပ်ကိရိယာက ကျန်သည်ကို လုပ်သည် (built-in Fanuc-style နှင့် LinuxCNC posts များက ကိရိယာ အရှည်အတွက် `G43.4` ကို ရေးသည်)။ ပိတ်ထားလျှင် စားပွဲစက်တွင် PartCraft က X Y Z ကို လှည့်သော စားပွဲက ပစ္စည်းကို သယ်သည့်အတိုင်း ရေးသည်၊ သင်ပေးသော **rotary centre** ပတ်လည် (work coordinates တွင်; work origin သည် ဗဟိုတွင်ရှိလျှင် 0၊ 0၊ 0)။ ခေါင်းစက်တွင် TCP ဖွင့်ရန် လိုအပ်သည်: မဟုတ်လျှင် ပရိုဂရမ်သည် စက်၏ pivot အရှည်ကို လိုအပ်မည် ဖြစ်ပြီး PartCraft က ၎င်းကို မသိပါ။
- **Tilt limit**: tilting axis က ဘယ်လောက် သွားသလဲ။

စက်များသည် ဘယ်ဘက်ကို အပေါင်းအဖြစ် ရေတွက်သည်ဆိုသည်တွင် ကွဲပြားသည်။ သင်၏စက်တွင် axis တစ်ခုက မှားသောဘက် လှည့်လျှင် post ၏ မိတ္တူတွင် လက္ခဏာကို ပြောင်းပါ ([ပြင်ဆင်နိုင်သော post processors](topic:post-processors))။

## ပုံမှန် လုပ်ဆောင်ချက်အတွက် ယိမ်းသော ကိရိယာ

ပိုင်းကြိုတိုင်း milling လုပ်ဆောင်ချက် (face၊ pocket၊ adaptive၊ contour၊ drill၊ chamfer၊ parallel၊ scallop၊ 3D rough၊ rest) တွင် **Tool tilt** နှင့် **Tilt towards** ရှိသည်: ထိုလုပ်ဆောင်ချက်တစ်ခုတည်းအတွက် ကိရိယာ၏ ဦးတည်ချက်၊ setup ၏ tool axis မှ တိုင်းသည်။ ဤသည်မှာ 3+2 machining ဖြစ်သည်: rotary axes များသည် နေရာတစ်ခုသို့ သွားပြီး သုံး axes ဖြတ်နေစဉ် ထိုနေရာတွင် ရှိနေသည်။

- ထောင့်နှစ်ခုကို ရိုက်ပါ၊ သို့မဟုတ် {{ui:ကိရိယာကို မျက်နှာပြင်နှင့် ထောင့်မှန်ထား}} ကို နှိပ်ပြီး ပြားသော မျက်နှာတစ်ခုကို နှိပ်ပါ: ကိရိယာက ထိုမျက်နှာကို တည့်တည့် ညွှန်မည်။
- လုပ်ဆောင်ချက်၏ မျက်နှာများနှင့် အစွန်းများကို ပုံမှန်အတိုင်း ရွေးပါ။ ကြမ်းပြင် သို့မဟုတ် အပေါက် ဖြစ်သည်ဟု ဆုံးဖြတ်ခြင်းကို စောင်းနေသော ကိရိယာ ဦးတည်ချက်အတိုင်း လုပ်သည်။
- ထိုဦးတည်ချက်အတွက် ကုန်ကြမ်းသည် လှည့်ထားသော ကုန်ကြမ်းကို ထိန်းထားသော ဘောက်စ် ဖြစ်သည်၊ ထို့ကြောင့် အမြင့်များနှင့် clearance များသည် ထိုဘက်မှ ဘေးကင်းသည်။

G-code တွင် လုပ်ဆောင်ချက်မတိုင်မီ ကိရိယာသည် အပေါ်သို့ တက်သည်၊ rotary axes များ လှည့်သည်၊ ကိရိယာသည် ၎င်း၏ ပထမအမှတ်အပေါ်သို့ ဆင်းသည်။ TCP မပါသော စားပွဲစက်တွင် arcs များသည် arcs ဖြစ်ဆဲ ဖြစ်ပြီး canned drilling cycles များသည် cycles ဖြစ်ဆဲ ဖြစ်သည် (ရေးထားသော frame သည် Z ပတ်လည်သာ လှည့်ထားသည်)။ TCP ဖြင့် စောင်းနေသော လေယာဉ်တွင် arcs များသည် တိုတောင်းသော မျဉ်းများ ဖြစ်လာပြီး cycles များသည် ၎င်းတို့ကိုယ်စားပြုသော ရွေ့လျားမှုများ ဖြစ်လာသည်။

ကုန်ကြမ်း simulation သည် စောင်းနေသော ဦးတည်ချက်ကို **သီးခြားစီ** run သည်: ထိုလုပ်ဆောင်ချက်က ထိုဘက်မှ မြင်သော ကုန်ကြမ်းတစ်ခုလုံးမှ ဘာကို ဖြတ်သလဲ ပြပြီး ထိုနေရာတွင် gouges များ ရှာသည်၊ သို့သော် အခြားဦးတည်ချက်များမှ ပြုလုပ်သော ဖြတ်ခြင်းများကို မယူဆောင်ပါ။

## 5-axis အချောသတ်

Manufacture toolbar ရှိ {{ui:More}} က ဤလုပ်ဆောင်ချက်နှင့် နောက်တစ်ခုကို **Operations** tab ၏ထိပ်တွင် စာရင်းပြုသည်။

{{ui:5-axis}} သည် **ရှေ့သွားစဉ် ယိမ်းသော ball end mill** ဖြင့် [parallel အချောသတ်အကြိမ်](topic:finish-3d) ဖြစ်သည်။ Ball သည် ဗဟိုအနားမှ အလယ်တွင် ကိရိယာ ယိမ်းသော ဘက်မရွေး အလုံးပုံ ဖြင့် ဖြတ်သည်၊ ထို့ကြောင့် ball သည် 3-axis အကြိမ်က ပေးမည့် လမ်းကြောင်းအတိအကျကို လိုက်ပြီး ကိရိယာ ဦးတည်ချက်သာ ပြောင်းသည်:

- **မျက်နှာပြင်ဆီသို့**: 1 = မျက်နှာနှင့် ထောင့်မှန်၊ 0 = ရပ်ထား၊ ကြားက တန်ဖိုးများ။
- **ရှေ့သို့ စောင်း**: ဖြတ်ခြင်း ဦးတည်ချက်အတိုင်း degrees၊ ball ၏ ငြိမ်သော ဗဟိုသည် ဖြတ်ခြင်းကို မလုပ်စေရန်။
- **အများဆုံး ယိမ်းမှု**: ကိရိယာသည် setup ၏ axis မှ ဤထက် ပိုမစောင်းပါ။

Shank သည် မော်ဒယ်ကို ထိမည့်နေရာတွင် ရှင်းသည်အထိ စောင်းကို နောက်ပြန်ဆုတ်သည်၊ လုပ်ဆောင်ချက်က အမှတ်မည်မျှတွင် ဖြစ်သည်ကို ပြောသည်။ အကြိမ်တိုင်းကို ဖြောင့်သော မြှောက်ခြင်းဖြင့် ဝင်ပြီး ထွက်သည်။

## Rotary အချောသတ် (4th axis)

{{ui:Rotary}} သည် **work X** ပေါ်ရှိ rotary axis တစ်ခုပေါ် ကိုင်ထားသော ပစ္စည်းအတွက် ဖြစ်သည်။ ပစ္စည်း လှည့်ပြီး axis ကို အမြဲညွှန်သော ball end mill က ၎င်း၏ မျက်နှာပြင်ကို လိုက်သည်:

- **Passes**: {{ui:ဝင်ရိုးတစ်လျှောက်}} (X တစ်လျှောက် မျဉ်းများ၊ လည်ပတ်မှု တစ်ခု stepover ခြား) သို့မဟုတ် {{ui:ပစ္စည်းပတ်လည်}} (ကွင်းများ၊ X တစ်ခု stepover ခြား)။
- **Axis at Y / Z**: axis ရှိနေသည့်နေရာ။ ဗလာဖြစ်လျှင် ကုန်ကြမ်း၏ အလယ်။ စားပွဲစက်တွင် TCP မပါလျှင် ဤသည် Setup ရှိ rotary centre ဖြစ်ရမည်; မဟုတ်လျှင် လုပ်ဆောင်ချက်က သတိပေးသည်။
- **From / To X** နှင့် **From / To angle**: ဖြတ်ရမည့် အရှည်နှင့် လှည့်မှု၏ အပိုင်း။

ဘောလ်၏ axis အထက် အမှတ်တိုင်းတွင် အမြင့်သည် ထိုဘက်မှ ပစ္စည်း၏ mesh ပေါ်ရှိ စက်ဝိုင်း၏ အတိအကျ ကျဆင်းမှု ဖြစ်သည်။

## ကန့်သတ်ချက်များ

- 5-axis နှင့် rotary အချောသတ်သည် **ball end mill** တစ်ခုတည်းကို ယူသည်။ Swarf ဖြတ်ခြင်း (ruled နံရံပေါ်ရှိ ကိရိယာ ဘေး) မရှိ၊ မျက်နှာတစ်ခု၏ ကိုယ်ပိုင် ဦးတည်ချက်များအတိုင်း flow lines မရှိ၊ multi-axis roughing မရှိ၊ ပဋိပက္ခ ရှောင်ရန် tilt ကို အလိုအလျောက် ရွေးချယ်ခြင်း မရှိပါ။
- 5-axis နှင့် rotary လမ်းကြောင်းများကို **stock simulation** မှ run မပြုပါ၊ ၎င်းသည် အမြင့်မြေပုံ ဖြစ်ပြီး ယိမ်းနေသော ဖြတ်ခြင်းကို ကိုင်မထားနိုင်ပါ။
- 5-axis အချောသတ်တွင် shank ကို မော်ဒယ်နှင့် ဆန့်ကျင်ပြီး အထက်မှ မြင်သည်အတိုင်း စစ်ဆေးသည်; holder၊ spindle နှင့် စက်ကိုယ်တိုင်ကို မည်သည့်နေရာမှ မစစ်ဆေးပါ။
- Rotary အချောသတ်သည် ကိရိယာက axis ကို ကြည့်သည့်အခါ မြင်နိုင်သော အရာကိုသာ ဖြတ်သည်။
- 5-axis အချောသတ်သည် ပစ္စည်းကြီးတစ်ခုတွင် ထုတ်ရန် မိနစ်တစ်ခု သို့မဟုတ် ပိုကြာသည်: shank ကို pass တိုင်း၏ အမှတ်တိုင်းတွင် စစ်ဆေးသည်။
- Rotary axes များသည် linear axes များနှင့်အတူ ရွေ့ပြီး TCP ပိတ်ထားလျှင် built-in posts များက feed ကို inverse time (`G93`) အဖြစ် ရေးပြီး `G94` သို့ ပြန်သွားသည်။
- Tilted work plane code (`G68.2` နှင့် ဆင်တူသော) မရေးပါ၊ စက်-သီးခြား ကန့်သတ်ချက်များ၊ unwinding သို့မဟုတ် collision zones များကို မသိပါ။
