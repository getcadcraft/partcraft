ဤသည်မှာ 0.6 နှင့် နှိုင်းယှဉ်လျှင် PartCraft 0.7 တွင် ပြောင်းလဲခဲ့သည်များ ဖြစ်သည်။ အစိတ်အပိုင်းများကို ဖိုင်ပိုမိုများမှ သွင်းနိုင်ပြီး workspace အသစ်တစ်ခုက သင့်ဒီဇိုင်းမှ လက်စွဲများ ဖန်တီးပေးသည်။

## အသစ်

### သင့်ဒီဇိုင်းမှ လက်စွဲများ

- **Illustrate workspace။** {{ui:လုပ်ငန်းခွင်}} switcher တွင် {{ui:Illustrate}} ကို ရွေးပြီး {{ui:Manual}} အုပ်စုရှိ {{ui:အသစ်}} ကို ရွေးပါ: လက်စွဲတစ်ခုသည် ဖွင့်ထားသော အစိတ်အပိုင် သို့မဟုတ် အစုအဝေး၊ သိမ်းထားသော အစုအဝေး၊ သို့မဟုတ် glTF, OBJ, STL, 3MF ဖိုင်မှ စတင်သည် (သစ်ပင်ဖွဲ့စည်းပုံနှင့် အမည်များ ထိန်းထားသည်; အစိတ်အပိုင်းတစ်ခု၏ မိတ္တူများသည် ပမာဏပါသော အစိတ်အပိုင်းတစ်ခု ဖြစ်လာသည်)။ လက်စွဲသည် အစိတ်အပိုင်းမိတ္တူပါသော ကိုယ်ပိုင်ဖိုင် (`.partcraft-manual.json`) ဖြစ်သဖြင့် ဒီဇိုင်း ဆက်ပြောင်းလဲနေစဉ်လည်း စာတမ်းများ ဆက်လုပ်နိုင်သည်။ [Illustrate တွင် လက်စွဲစတင်ခြင်း](topic:illustrate) ကို ကြည့်ပါ။
- **မြင်ကွင်းများနှင့် ပုံသဏ္ဍာန်များ။** အစိတ်အပိုင်းများကို ဖျောက်၊ ဖြူစင်၊ သီးခြားခွဲ သို့မဟုတ် အရောင်ပြောင်းနိုင်သည်၊ exploded view ကို ဖွင့်နိုင်သည်၊ section သို့မဟုတ် box ကို ဖြတ်နိုင်သည်၊ magnifier ထည့်နိုင်သည်၊ အားလုံးကို မြင်ကွင်းအဖြစ် သိမ်းနိုင်သည်။ [မြင်ကွင်းများ၊ ပုံသဏ္ဍာန်များ၊ section များနှင့် magnifier](topic:illustrate-views) ကို ကြည့်ပါ။
- **Balloons နှင့် အစိတ်အပိုင်းစာရင်း။** တစ်ချက်နှိပ်ခြင်းဖြင့် မြင်ကွင်းပြသသော အစိတ်အပိုင်းတိုင်းကို balloon လုပ်သည်; နံပါတ်များသည် ၎င်းတို့ အစိတ်အပိုင်းနှင့် တွဲနေပြီး ဘယ်တော့မှ ပြန်မသုံးပါ။ စာရင်းကို မြင်ကွင်းထဲတွင် ထားနိုင်ပြီး CSV အဖြစ် သိမ်းသည်။ [အစိတ်အပိုင်းစာရင်းနှင့် balloons](topic:illustrate-parts-list) ကို ကြည့်ပါ။
- **မတွယ်တွဲဘဲ မနေသော annotations။** အစိတ်အပိုင်း၏ နံပါတ်၊ အမည်၊ ပစ္စည်း သို့မဟုတ် ပမာဏကို ဖြည့်သော labels နှင့် callouts၊ မြား၊ အစိတ်အပိုင်း၊ ပုံသဏ္ဍာန်နှင့် ပုံများမှ တိုင်းတာသော အကွာအဝေး၊ ထောင့်နှင့် radius များ။ exploded ဖြစ်သည့်အခါ ၎င်းတို့ အစိတ်အပိုင်းနှင့်အတူ ရွေ့သည်။ [မတွယ်တွဲဘဲ မနေသော annotations](topic:illustrate-annotations) ကို ကြည့်ပါ။
- **လိုင်းပုံ၊ ညွှန်ကြားချက်များနှင့် 3D ဖိုင်။** မြင်ကွင်းတစ်ခုကို vector လိုင်းပုံ (SVG သို့မဟုတ် PDF) ဖြင့် ဖျောက်ထားသော မျဉ်းများနှင့် မျဉ်းဖြတ်ထားသော section များဖြင့် ထုတ်နိုင်သည်၊ သို့မဟုတ် PNG; မြင်ကွင်းများကို အဆင့်လိုက် ညွှန်ကြားချက်များ PDF သို့မဟုတ် HTML စာမျက်နှာတစ်ခုအဖြစ် ပြောင်းနိုင်သည်; သို့မဟုတ် မြင်ကွင်းများ၊ အစိတ်အပိုင်းစာရင်းနှင့် animation ပါသော HTML ဖိုင်တစ်ခုကို browser မှ အင်တာနက်မရှိဘဲ ဖွင့်နိုင်သည်။ [နည်းပညာ ပုံဖော်ခြင်း](topic:illustrate-line-art), [ညွှန်ကြားချက် စာတမ်းများ](topic:illustrate-instructions) နှင့် [အပြန်အလှန် 3D ဖိုင်](topic:illustrate-interactive) ကို ကြည့်ပါ။
- **Animation နှင့် အပ်ဒိတ်များ။** အစိတ်အပိုင်းနှင့် ကင်မရာကို key လုပ်ပါ၊ exploded view ကို အဆင့်လိုက် မှတ်တမ်းတင်ပြီး ဗီဒီယို သိမ်းပါ။ ဒီဇိုင်း ပြောင်းသွားသည့်အခါ {{ui:ဒီဇိုင်းမှ အပ်ဒိတ်လုပ်ရန်…}} က ဘာရွေ့၊ ပြောင်း၊ ရောက်လာ၊ ထွက်သွားသည်ကို မည်သည့်အရာမှ မပြောင်းမီ ပြသပြီး မြင်ကွင်းများ၊ annotations၊ balloons နှင့် keys များကို ၎င်းတို့ အစိတ်အပိုင်းနှင့် ထိန်းထားသည်။ [လက်စွဲ animate လုပ်ရန်](topic:illustrate-animation) နှင့် [ဒီဇိုင်းမှ လက်စွဲ အပ်ဒိတ်လုပ်ရန်](topic:illustrate-update) ကို ကြည့်ပါ။

### ဖိုင်အခြားများ ဖွင့်ခြင်း

- **STEP ဖိုင်များကို solid bodies အဖြစ် ဖွင့်သည်။** {{ui:ဖွင့်ရန်}} သည် exact kernel မပါဘဲ AP203, AP214 နှင့် AP242 STEP ကို ဖတ်သည်။ ပြား မျက်နှာများ ပြားနေဆဲ၊ မျဉ်းကွေး မျက်နှာများသည် ပြားငယ်များစွာ ဖြစ်လာသည်၊ အစုအဝေးသည် ဖိုင်က နေရာချထားသည့်နေရာတွင် အစိတ်အပိုင်းတိုင်းပါသော ကိုယ်ထည်တစ်ခုအဖြစ် ဝင်လာသည်။ ၎င်း၏ ပြား မျက်နှာများပေါ်တွင် sketch ပြုလုပ်နိုင်၊ ဖြတ်နိုင်၊ ထပ်ထည့်နိုင်သည်။ [STEP ဖိုင်ကို ဖွင့်ပြီး တည်ဆောက်ခြင်း](topic:import-step) ကို ကြည့်ပါ။
- **STL, OBJ နှင့် 3MF mesh များသည် solids ဖြစ်လာသည်။** ဖိုင်ကို ဖွင့်ခြင်း သို့မဟုတ် ချခြင်း: PartCraft သည် ထပ်နေသော ထောင့်များကို ပေါင်းပြီး၊ သေးငယ်သော အကွာအဟများကို ပိတ်ပြီး၊ အပေါက်များကို ဖြည့်ပြီး မှားနေသော တြိဂံများကို ပြင်သည်၊ ထို့နောက် ဘာလုပ်ခဲ့သည်နှင့် mesh ပိတ်သွားသလားကို ပြောသည်။ ယူနစ်နှင့် ဘယ်ဘက်က အပေါ်လဲကို ရွေးနိုင်သည်၊ ကိုယ်ထည်သည် **Imported1** အဖြစ် ရောက်လာပြီး ၎င်း၏ ပြား ဧရိယာများသည် sketch ပြုလုပ်နိုင်သော မျက်နှာများ ဖြစ်သည်။ ပိတ်၍မရသော mesh သည် ဖွင့်ထားသော အပေါက်မည်မျှ ကျန်သေးသည်ကို ပြပြီး ဘာမျှ မထည့်ပါ။ [STL, OBJ သို့မဟုတ် 3MF ကို solid body အဖြစ် ဖွင့်ခြင်း](topic:open-meshes) ကို ကြည့်ပါ။
- **.3dm ဖိုင်များကို body တစ်ခုအဖြစ် ဖွင့်သည်။** `.3dm` ဖိုင်၏ meshes၊ polysurfaces၊ extrusions နှင့် block နေရာချထားမှုများသည် solid body တစ်ခုအဖြစ် ဝင်လာသည်၊ ဖိုင်တွင် သိမ်းထားသော meshes မှ သို့မဟုတ် PartCraft မှ tessellate လုပ်သော meshes မှ၊ mesh ကဲ့သို့ တူညီသော ပြင်ဆင်ခြင်းနှင့် "closes?" စစ်ဆေးမှုဖြင့်။ မျဉ်းကွေးများ၊ စာသား၊ SubD objects၊ layers နှင့် အရောင်များကို ချန်ထားပြီး ဒိုင်ယာလော့ခ်က ထိုသို့ ပြောသည်။ [.3dm မော်ဒယ်ကို solid body အဖြစ် ဖွင့်ခြင်း](topic:open-3dm-files) ကို ကြည့်ပါ။

### အစိတ်အပိုင်းများနှင့် အစုအဝေးများ

- **သံမဏိပုံစံများမှ ဘောင်များ။** လိုင်းများဖြင့် ဘောင်ကို ဆွဲပါ၊ sketch တစ်ခုတည်း သို့မဟုတ် 3D ဘောင်အတွက် အများအပြား၊ ထို့နောက် {{ui:နောက်ထပ်}} › {{ui:Structural member}}: AISC သို့မဟုတ် EN 10365 ဇယားမှ ပုံသဏ္ဍာန်သည် လိုင်းတိုင်းတွင် ဖြတ်သွားသည်။ ထောင့်များကို mitre သို့မဟုတ် butt လုပ်နိုင်၊ T တွင် ဆုံသော သို့မဟုတ် ထောင့်တွင် သုံးခု ဆုံသော အဖွဲ့ဝင်များကို တပ်ဆင်ရန် ဖြတ်သည်၊ လွတ်သော အဆုံးများတွင် caps နှင့် ထောင့်များတွင် gussets ထည့်နိုင်သည်၊ ဖြတ်စာရင်းသည် အစိတ်အပိုင်းတစ်ခုစီ၏ အရှည်နှင့် အဆုံးထောင့်များကို ပေးသည် ({{ui:ဖြတ်စာရင်းကို သိမ်းရန် (CSV)}})။ [သံမဏိပုံစံများမှ ဘောင်များ](topic:structural-members) ကို ကြည့်ပါ။
- **Assemblies ထဲရှိ closed loops။** လက်စွဲ ring တစ်ခုအဖြစ် ချိတ်ဆက်ထားသော အစိတ်အပိုင်းများ (four-bar linkage၊ crank နှင့် slider၊ ထောက်ကန်ထားသော ဘောင်) သည် ယခု ပိတ်သည်: loop ပေါ်တွင် တန်ဖိုးကို ဆွဲ သို့မဟုတ် ရိုက်ထည့်ပါ၊ ကျန်သည်က လိုက်ပါလာသည်၊ လှုပ်ရှားမှု စစ်ဆေးမှုသည် loop ကို တူညီစွာ ရွေ့သည်။ ဆက်ရွေ့နိုင်သော joint သည် အပြာရောင်၊ မပိတ်နိုင်သော loop သည် အနီရောင် ဖြစ်ပြီး ဘယ်လောက် ကွာသည်ကို ပြောသည်။ [Closed loops: linkages](topic:build-assembly#closed-loops-linkages) ကို ကြည့်ပါ။
- **Feature ရာနှင့်ချီသော အစိတ်အပိုင်းများ။** PartCraft သည် သမိုင်းကြောင်း၏ အလယ်အလတ်တွင် ရှိသော solid ကို ထိန်းထားသည်၊ ထို့ကြောင့် သမိုင်းနောက်ပိုင်း ပြောင်းလဲမှုသည် ၎င်းနောက်ရှိ features များကိုသာ ပြန်တည်ဆောက်သည်၊ မထိသော cuts နှင့် bosses များကို အတူတကွ ကျင့်သုံးသည်။ feature 750 ပါသော အစိတ်အပိုင်းတွင် စမ်းသပ်ထားသည်။ Parameters ဝင်းဒိုးသည် equation ရာနှင့်ချီကို လိုက်နိုင်ပြီး undo သည် မှတ်ဉာဏ်အများကြီး မသုံးလျှင် ခြေလှမ်း 200 ထိ ထိန်းထားသည် (အနည်းဆုံး 20 မဖြစ်စေ)။ [Feature ရာနှင့်ချီသော အစိတ်အပိုင်းများ](topic:edit-history#parts-with-hundreds-of-features) ကို ကြည့်ပါ။
- **configurations မှ variant pack။** {{ui:ပါရာမီတာများ}} tab ရှိ **Configurations** အောက်ရှိ {{ui:Variant pack…}} သည် configuration အားလုံး သို့မဟုတ် သင်အမှန်ခြစ်သည့်များကို zip တစ်ခုတည်းတွင် တည်ဆောက်သည်: STEP, IFC, DWG ပုံဆွဲစာရွက်နှင့် preview တစ်ခုစီ၊ parameters ဇယား (CSV နှင့် JSON)၊ နှင့် အစိတ်အပိုင်းကို variants ပါသော library item တစ်ခု။ မတည်ဆောက်နိုင်သော configuration ကို စာရင်းပြုပြီး ချန်ထားသည်။ command line က `partcraft variants` ဖြင့် အတူတူ လုပ်သည်။ [configurations မှ variant pack ဖန်တီးရန်](topic:variant-pack) ကို ကြည့်ပါ။

### ထုတ်လုပ်ခြင်း

- **တည်းဖြတ်နိုင်သော post processors။** Manufacture ရှိ Fanuc-style၊ GRBL နှင့် LinuxCNC posts များသည် PartCraft ၏ ကိုယ်ပိုင် post ဖော်မတ်ဖြင့် စာသားဖိုင်တိုများ ဖြစ်လာပြီး ၎င်းတို့ မတိုင်မီ ရေးခဲ့သည်ကို အတိအကျ ဆက်ရေးသည်။ {{ui:post ပြင်ရန်…}} က သင့်ကိုယ်ပိုင် မိတ္တူတစ်ခုကို ဖွင့်သည် ({{ui:post အသစ်…}} နှင့် {{ui:post ဖိုင် သွင်းရန်…}} လည်း ရှိသည်)၊ မှားနေသော စာကြောင်းကို ပြောပြပြီး သင်ရိုက်နေစဉ် ရေးသော G-code ကို ပြသည်။ Posts များကို အစိတ်အပိုင်းအတွင်းနှင့် `.cpost` ဖိုင်များအဖြစ် သိမ်းသည်။ [တည်းဖြတ်နိုင်သော post processors](topic:post-processors) ကို ကြည့်ပါ။
- **3D finishing: Parallel နှင့် Scallop။** မော်ဒယ်အပေါ်ယံတစ်ခုလုံးကို ball, bull-nose သို့မဟုတ် flat end mill ဖြင့်၊ မည်သည့်ထောင့်ဖြစ်စေ parallel မျဉ်းများဖြင့်၊ သို့မဟုတ် သတ်မှတ်အကွာအဝေးဖြင့် ခွဲထားသော အလှည့်များဖြင့် ပြီးစီးနိုင်သည်၊ ထို့ကြောင့် ၎င်းတို့ကြားရှိ ထိပ်ဖျား အမြင့်သည် သင်တောင်းသည့်အတိုင်း ဖြစ်သည် (flat end mill ဖြင့် မရ)။ [3D finishing: parallel နှင့် scallop](topic:finish-3d) ကို ကြည့်ပါ။
- **Tool library။** tools များကို ဤ browser တွင် အစိတ်အပိုင်းတိုင်းအတွက် သိမ်းပြီး JSON ဖိုင်အဖြစ် export/import လုပ်ကာ အခြားကွန်ပျူတာသို့ ရွှေ့နိုင်သည်။ [Tool library](topic:tool-library) ကို ကြည့်ပါ။
- **ပစ္စည်းကို မော်ဒယ်နှင့် အရောင်ဖြင့် နှိုင်းယှဉ်ခြင်း။** **Show the simulated stock** ဖွင့်ထားလျှင် ပစ္စည်းသည် မော်ဒယ်ပေါ်တွင် အစိမ်းရောင်၊ tool ဖြတ်သွားသည့်နေရာတွင် အနီရောင်၊ ပစ္စည်း ကျန်ရှိသည့်နေရာတွင် အဝါမှ မီးခိုးရောင်ဖြစ်ပြီး panel ရှိ key နှင့်အတူ ဖြစ်သည်။ [Simulate](topic:manufacture#simulate) ကို ကြည့်ပါ။
- **Nests အကြား offcuts ထိန်းထားခြင်း။** nest ပြီးနောက် ပြားတစ်ခုစီ၏ ကျန်ရှိသည်မှာ ပစ္စည်းနှင့် အထူနှင့်အတူ နံပါတ်ပါသော remnant ဖြစ်လာနိုင်သည်။ ပစ္စည်းနှင့် အထူတူသော နောက် nest သည် remnants များကို အရင်သုံးပြီး၊ ထို့နောက် အပြည့် ပြားများကို သုံးသည်; ပစ္စည်းစာရင်းကို ဖိုင်တွင်နှင့် CSV အဖြစ် သိမ်းသည်၊ DXF သည် remnant တိုင်းကို အမှတ်အသားပြုသည်။ [Offcuts ထိန်းခြင်းနှင့် ပြန်သုံးခြင်း](topic:nest-offcuts) ကို ကြည့်ပါ။
- **လေဆာ ပရိုဂရမ်များ။** {{ui:Export}} › {{ui:လေဆာ ပရိုဂရမ်…}} သည် DXF ဖိုင်မှ အပြင်ပန်းများကို ယူပြီး layer တစ်ခုစီ ဘာလုပ်သည် (cut, score, engrave, fill) ကို သတ်မှတ်သည်၊ head ၏ ရွေ့လျားမှုများကို ကြိုကြည့်ပြီး GRBL laser-mode G-code ကို သိမ်းသည်။ Chrome နှင့် Edge တွင် လေဆာပိတ်ထားစဉ် အလုပ်ကို ဘောင်ဖမ်းနိုင်ပြီး USB ဖြင့် ပို့နိုင်သည်။ ဆက်တင်များကို ဖိုင်တွင် သိမ်းသည်။ [ပုံကို လေဆာသို့ ပို့ခြင်း](topic:laser-cutting) ကို ကြည့်ပါ။
- **USD export။** {{ui:Export}} › {{ui:USD package (.usdz)}} သည် ပစ္စည်းနှင့် ထုထည်၊ အလေးချိန်ပါသော အစိတ်အပိုင်းကို ရေးသည်၊ သို့မဟုတ် အစုအဝေးကို အစိတ်အပိုင်းတစ်ခုစီ တစ်ကြိမ်၊ ပုံတူတိုင်း နေရာချထားပြီး မီတာနှင့် Z အပေါ်ဖြင့်။ [အစိတ်အပိုင်း သို့မဟုတ် အစုအဝေးကို USD အဖြစ် ထုတ်ရန်](topic:usd) ကို ကြည့်ပါ။

### AI assistants

- **သင့်ကိုယ်ပိုင် AI assistant အတွက် tools။** {{ui:ဆက်တင်များ}} › {{ui:PartCraft}} › {{ui:အကူအညီပေးသူများ}} တွင် ဖွင့်ထားသည့်အခါ CadCraft Studio မှတစ်ဆင့် ချိတ်ဆက်ထားသော assistant သည် features၊ parameters နှင့် အလေးချိန်ဂုဏ်သတ္တိများကို ဖတ်နိုင်၊ parameter တစ်ခုကို သတ်မှတ်ပြီး ပြန်တည်ဆောက်နိုင် (ပြန်ဖျက်ခြင်း အဆင့်တစ်ခု)၊ CraftScript, Lua သို့မဟုတ် Python script ကို Script workspace လုပ်သည့်နည်းဖြင့် လုပ်ဆောင်နိုင်၊ STL, 3MF, faceted STEP သို့မဟုတ် USD ကို ထုတ်နိုင်၊ သိမ်းနိုင်၊ နှင့် လက်စွဲကို PDF, SVG, ညွှန်ကြားချက်များ သို့မဟုတ် အပြန်အလှန် 3D ဖိုင်အဖြစ် ထုတ်နိုင်သည်။ ဖိုင်ဆာဗာနှင့် `cadcraft` command line သည် သိမ်းထားသော အစိတ်အပိုင်းများနှင့် လက်စွဲများပေါ်တွင် အတူတူ လုပ်သည်။ PartCraft တွင် AI မပါဝင်ပါ။ [PartCraft ကို AI assistant နှင့် အသုံးပြုရန်](topic:use-with-ai-assistants) ကို ကြည့်ပါ။

## အက်ပ်အားလုံးတွင်

- **ယူနစ်များ။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ယူနစ်များ}} တွင် အရှည်၊ ဧရိယာ၊ ထုထည်၊ ထောင့်နှင့် စောက်စိမ်း အတွက် စာရင်းတစ်ခုစီ ရှိပြီး ယူနစ်တစ်ခုစီ၏ သတ်မှတ်ချက်များက ပေးသော တိကျသော အရွယ်အစားများ ပါသည် (US survey foot သည် ကိုယ်ပိုင်ယူနစ်ဖြစ်သည်)။ သင် မသုံးသော ယူနစ်များကို ပိတ်ထားလျှင် ယူနစ်စာရင်းမှ ထွက်သွားသည်; တစ်ခုကို star ပေးလျှင် အသစ်ဖန်တီးမှုများသည် ထိုယူနစ်ဖြင့် စတင်သည်။ ဖိုင်တစ်ခုသည် ကိုယ်ပိုင်ယူနစ်ကို အမြဲထိန်းသည်။ PartCraft ၏ ကိုယ်ပိုင် ဘောက်စ်များသည် စာရင်းများ သို့မဟုတ် star ကို ယခုအချိန်ထိ မလိုက်ပါ: အစိတ်အပိုင်းများသည် မီလီမီတာဖြင့်သာ ပြသသည်။ [ယူနစ်များ၊ ရိုက်ထည့်ထားသော တန်ဖိုးများနှင့် ယူနစ်စာရင်းများ](common:unit-lists) ကို ကြည့်ပါ။
- **ပိုကျစ်လစ်သော အပြင်အဆင်နှင့် ပြိုကျသွားသော panels။** {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:အပြင်အဆင် သိပ်သည်းမှု}} › {{ui:ကျစ်လစ်သော}} သည် မျက်နှာပြင်ပေါ်တွင် ပိုထည့်နိုင်သည် (touch screens နှင့် ဖုန်းများသည် ၎င်းတို့၏ ခလုတ်ကြီးများကို ဆက်ထားသည်)။ ဘေးဘက် panel တစ်ခုစီတွင် ပါးလွှာသော ခေါင်းစဉ်ဘား ရှိသည်: ဆွဲ၍ panel ကို ချိတ်ဆက်ရန် သို့မဟုတ် လွတ်ရန်၊ အခြား panel ၏ ဘားပေါ်သို့ ချပြီး frame တစ်ခုတည်းကို tabs အဖြစ် မျှဝေရန်၊ ဘေးသို့ လျှော့ဝင်ရန် pin လုပ်ရန်၊ သို့မဟုတ် ဖျောက်ပြီး ဘေးမှ ပြန်ခေါ်ရန်။ [panels များကို စီစဉ်ခြင်း](common:arrange-panels#make-the-layout-denser) ကို ကြည့်ပါ။
- **Dialogs ရွှေ့နိုင်သည်။** dialog ကို ခေါင်းစဉ်ဘားဖြင့် ဆွဲ၍ ပုံဆွဲမှ ဖယ်ပါ; သင်ထားခဲ့သည့်နေရာသို့ ပြန်ရောက်သည်။ ခေါင်းစဉ်ဘားကို နှစ်ချက်နှိပ်ပါက အလယ်သို့ ပြန်ထားသည်။ [dialog ကို ရွှေ့ခြင်း](common:arrange-panels#move-a-dialog) ကို ကြည့်ပါ။
- **AI assistants အတွက် ဥပမာများ။** သင့်ကိုယ်ပိုင် assistant အတွက် တောင်းဆိုမှု ဆယ်ခု (ပုံဆွဲကို သပ်ရပ်အောင်၊ ဇယားကို ပလော့ချ၊ ပုံများကို စစ်ဆေး၊ မော်ဒယ်ကို မေးမြန်း၊ ပမာဏကို စုစည်း၊ အစိတ်အပိုင်း variant ကို စမ်းကြည့်…) တစ်ခုစီသည် ခေါ်သော tools နှင့် လိုအပ်သော ခွင့်ပြုချက်များပါသည်၊ နှင့် တစ်ခုစီကို ကျွန်ုပ်တို့၏ စမ်းသပ်မှုများက ပြန်လည်လုပ်ဆောင်ထားသည်။ အက်ပ်များတွင် AI မပါဝင်ပါ။ [AI assistants အတွက် ဥပမာများ](common:assistants-recipes) ကို ကြည့်ပါ။
- **ဘာသာစကားများ။** **Português (Portugal)** သည် {{ui:ဆက်တင်များ}} › {{ui:အထွေထွေ}} › {{ui:ဘာသာစကား}} တွင် အသစ်ဖြစ်သည်။ ၎င်း၊ **Português (Brasil)**, **Español (México)** နှင့် **Bahasa Indonesia** တို့တွင် ယခု အက်ပ်များ၏ စကားလုံးအားလုံး ရှိပြီး မူကြမ်းအဖြစ်၊ ဗဟိုဘာသာပြန် မူရင်းသူက မဖတ်ရသေးပါ။ အကူအညီ စာမျက်နှာများသည် အင်္ဂလိပ်ဖြင့်ဖြစ်ပြီး တစ်ခုသာ စပိန်ဖြင့် ရှိသည်။
- **CadCraft Studio** သည် အပ်ဒိတ် စစ်ဆေးမှု မအောင်မြင်သည့် အကြောင်းရင်းကို ပြသည် (သင့်စနစ်အတွက် ဖိုင်မရှိသေး၊ network မရှိ၊ လက်မှတ် မမှန်) "Done" ဟု ရိုးရိုးပြခြင်းမဟုတ်ဘဲ၊ နှင့် သင်ပိတ်ထားသော What's new ကတ်ကို ပြန်မပြတော့ဘဲ ပိုအသစ်တစ်ခု မရှိမချင်း ထားသည်။

## ဤဗားရှင်းတွင် ရှိမနေသေးသည်များ

- **0.7 ကို code-signed မလုပ်ထားပါ။** Signing နှင့် Microsoft Store package ကို 0.8 သို့ ရွှေ့ထားသည်၊ အကြောင်းမှာ certificate စစ်ဆေးမှု မပြီးသေးသောကြောင့်ဖြစ်သည်။ getcadcraft.com/download ရှိ ဖိုင်တစ်ခုစီ၏ဘေးရှိ SHA-256 ကို စစ်ပါ။ Windows တွင် SmartScreen က installer ကို ရပ်လျှင် {{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}} ကို ရွေးပါ။ Mac တွင် ပထမအကြိမ် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ CadCraft Studio သည် app store တွင် မရှိသေးပြီး iPad သို့မဟုတ် iPhone build လည်း မရှိသေးပါ။
- {{ui:Units}} ရှိ angle နှင့် slope စာရင်းများကို သိမ်းထားသော်လည်း ဘောက်စ်တစ်ခုမှ ဖတ်ခြင်း မရှိသေးပါ။
- STEP, mesh နှင့် `.3dm` ဖိုင်များမှ ကိုယ်ထည်များတွင် သမိုင်းမရှိပါ၊ ၎င်းတို့၏ မျဉ်းကွေး မျက်နှာများသည် ပြား facets များဖြစ်သည်။ အရောင်များ၊ အစိတ်အပိုင်းအမည်များနှင့် assembly သစ်ပင်ကို STEP မှ မဖတ်ပါ; မျဉ်းကွေးများ၊ SubD objects၊ စာသား၊ layers နှင့် အရောင်များကို `.3dm` မှ မဖတ်ပါ။ `.3dm` reader ကို format ၏ ကိုယ်ပိုင် toolkit ရေးထားသော ဖိုင်များပေါ်တွင် စစ်ဆေးထားပြီး modelling ပရိုဂရမ်ကိုယ်တိုင် သိမ်းထားသော ဖိုင်များပေါ်တွင် မစစ်ရသေးပါ။
- Illustrate သည် **From another file…** တွင် STEP ဖိုင်များကို မဖွင့်ရသေးပါ (STEP ကို Design တွင် ဖွင့်ပြီး **From the open part** ကို စတင်ပါ)၊ ModelCraft နှင့် BimCraft တို့သည် မော်ဒယ်ကို တိုက်ရိုက် ပေးပို့နိုင်ခြင်း မရှိ၊ path tracer ၏ အရည်အသွေးရှိ ပုံများကို မပေးပါ။ ဗီဒီယို export နှင့် အပြန်အလှန် ဖိုင်ကို အစစ်အမှန် ဖုန်းနှင့် တက်ဘလက်များတွင် မစစ်ရသေးပါ။
- လေဆာ ပရိုဂရမ်များသည် DXF ဖိုင်များမှ အပြင်ပန်းများကိုသာ ယူသည်; ပြား သတ္တု အစိတ်အပိုင်းများ၏ flat patterns သည် exact kernel လိုအပ်သည်။ CadCraft Studio တွင် Web Serial မရှိသေးသဖြင့် G-code ကို သိမ်းပြီး လေဆာ၏ ကိုယ်ပိုင်ပရိုဂရမ်ဖြင့် ပို့ပါ။ လေဆာ G-code နှင့် ပါဝင်သော post သုံးခုကို အစစ်အမှန် စက်ပေါ်တွင် မသက်သေပြရသေးပါ: ပရိုဂရမ်တိုင်းကို သင့် control ၏ ကိုယ်ပိုင် simulator တွင် ဦးစွာ စစ်ပါ။
- 3D finishing သည် Parallel နှင့် Scallop သာ ဖြစ်သည်: 3D roughing၊ waterline၊ pencil သို့မဟုတ် rest machining မရှိ၊ turning မရှိ။ tool library သည် ဤ browser တွင် ထားသည်၊ sync မလုပ်ပါ။
- ဝက်ဘ်ဆိုက်ပေါ်တွင် ဧည့်သည်များ variant ရွေးပြီး ဒေါင်းလုဒ်လုပ်သည့် configurator စာမျက်နှာသည် ဆိုက်၏ switch ဖွင့်သည်အထိ ဝန်ထမ်းများအတွက်သာ ဖြစ်သည်။ Ports (ချိတ်ဆက်မှတ်များ) ကို PartCraft မှ သတ်မှတ်ခြင်း မရှိပါ။
- ပိုက်ဘောင်များသည် ဖြောင့်သော မျဉ်းများကိုသာ လိုက်ပြီး weld bead မပါသော solid တစ်ခုသာ ဖြစ်သည်။
- PartCraft ၏ ribbon menu styles များသည် ခလုတ်တိုင်းကို အရွယ်အစားအပြည့်ဖြင့် ဆွဲနေဆဲ ဖြစ်သည်။
- Magnetics: permanent magnets သည် 2-D တွင်သာ ရှိသည်; motors၊ saturating steel နှင့် မျဉ်းကွေးအစိတ်အပိုင်းအတွက် mesher ကို မတည်ဆောက်ရသေးပါ။
