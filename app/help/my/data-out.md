**Engineer** workspace တွင်၊ သို့မဟုတ် Generated body ၏ ဂုဏ်သတ္တိများတွင်၊ **Data out** ကို ဖွင့်ပါ:

| ခလုတ် | ဖိုင် | အတွက် |
|---|---|---|
| ဒေတာစာရွက် (JSON) | `.json` | ထည့်သွင်းသည့် အရာတိုင်း၊ unit နှင့် အရင်းအမြစ်ပါသော ဂဏန်းတိုင်း၊ စစ်ဆေးမှုများ၊ mesh လက်ဗွေ။ စီထားပြီး အချိန်မပါ: အစိတ်အပိုင်းတူလျှင် ဖိုင်တူသည်။ |
| ဒေတာစာရွက် (PDF) | `.pdf` | အတူတူ ကြေညာချက်ကို စာရွက်ပေါ်တွင်၊ လိုအပ်သလောက် စာမျက်နှာများစွာပေါ်တွင်။ |
| Field (.vti) | `.vti` | အစိတ်အပိုင်းကို signed distance (အတွင်း၌ အနုတ်) နှင့် အတွင်းပိုင်း mask အဖြစ် point grid ပေါ်တွင်: ParaView နှင့် VTK ပေါ်တွင် တည်ဆောက်ထားသော ကိရိယာများအတွက် VTK image ဖိုင်။ ၎င်းကို generator ၏ input များ၏ voxel အရွယ်အစားဖြင့် body ၏ မျက်နှာပြင်မှ တည်ဆောက်သဖြင့် အချိန်အနည်းငယ် ကြာသည်၊ triangle 400 000 ကျော်သော body သည် စာမျက်နှာအတွက် ကြီးလွန်းသည်: ထို့အစား script (`field_bake`) မှ field ကို သိမ်းပါ။ |
| Level set (.vdb) | `.vdb` | အတူတူ field ကို OpenVDB level set အဖြစ်: မျက်နှာပြင်ပတ်ပတ်ရှိ voxel ပါးလွှာသော band ကိုသာ ထိန်းထားသော sparse tree၊ OpenVDB ဖတ်သော ကိရိယာများအတွက် (renderer၊ simulation နှင့် 3D program များ)။ Voxel အရွယ်အစားနှင့် unit များသည် generator ၏ (millimetre)၊ narrow band သည် active အပိုင်းဖြစ်ပြီး အတွင်းပိုင်းသည် အနုတ်ဖြစ်သည်။ `.vti` ကဲ့သို့ မျက်နှာပြင်မှ တည်ဆောက်ပြီး triangle 400 000 ကန့်သတ်ချက်တူသည်; 1.5 GB ကျော်မည့် ဖိုင်ကို ငြင်းပယ်သည် (voxel အရွယ်အစားကြီးသုံးပါ)။ ဖိုင်သည် OpenVDB format 224 ဖြစ်ပြီး OpenVDB ၏ ကိုယ်ပိုင် active-value packing မှလွဲ၍ ချုံ့ထားခြင်း မရှိသဖြင့် မည်သည့် OpenVDB reader ကမဆို ဖွင့်နိုင်သည်။ |
| မျက်နှာပြင် (.vtu) | `.vtu` | Triangle များ၊ ၎င်းတို့တစ်ခုစီ၏ ဧရိယာနှင့် normal။ |
| Generator ဒေတာပါသော 3MF | `.3mf` | Slicer အတွက် millimetre ဖြင့် mesh၊ generator၊ ၎င်း၏ input များနှင့် (graded lattice အတွက်) ၎င်း၏ wall range ကို ဖိုင်ထဲတွင် metadata အဖြစ်။ |

ဤဖိုင်များထဲရှိ မည်သည့်အရာမျှ နာရီ သို့မဟုတ် စက်မှ မလာသဖြင့် ဖိုင်နှစ်ခုကို byte အလိုက် နှိုင်းယှဉ်နိုင်သည်: ပြောင်းလဲသော byte တစ်ခုသည် ပြောင်းလဲသော အစိတ်အပိုင်းကို ဆိုလိုသည်။

## မတည်ဆောက်ရသေးသည်များ

- Generator ၏ ကိုယ်ပိုင် voxel အရွယ်အစားမဟုတ်သော အခြား voxel အရွယ်အစားရှိ field ၏ `.vti` သို့မဟုတ် `.vdb`။
- `.vdb` ဖိုင်များကို ဖတ်ခြင်း (ရေးခြင်းသာ တည်ဆောက်ထားသည်)။
