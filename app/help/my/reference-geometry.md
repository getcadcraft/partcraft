ရည်ညွှန်း ဂျီသြမေတြီသည် သင် features များကို တည်ဆောက်သည့် ထောက်ပံ့ဘောင် ဖြစ်သည်- မျက်နှာပြင် မရှိသောနေရာတွင် sketch ဆွဲရန် **ပြား**၊ ပတ်ပြီး revolve သို့မဟုတ် pattern လုပ်ရန် **ဝင်ရိုး**၊ extrude ကို ရပ်ရန် **အမှတ်**။ ၎င်းတွင် ကိုယ်ပိုင်ပစ္စည်း မရှိပါ။ Planes များကို view တွင် ဖျော့ရောင် စတုရန်းများအဖြစ်၊ axes များကို အစင်းကြောင်းများအဖြစ်၊ points များကို သေးငယ်သော ကကြား အဖြစ် ပြသည်; သုံးမျိုးလုံးသည် history တွင် ပါဝင်ပြီး အထက်ရှိ အရွယ်ကို ပြောင်းလျှင် ၎င်းတို့ ဖန်တီးခဲ့သည့်အတိုင်း လိုက်ပြောင်းသည်။

၎င်းတို့ကို Features အုပ်စု၏ {{ui:နောက်ထပ်}} menu တွင် တွေ့ရမည်- {{ui:ပြား}}၊ {{ui:ဝင်ရိုး}}၊ {{ui:အမှတ်}}။

## ပြား ဖန်တီးရန်

1. မျက်နှာပြင်ပြားတစ်ခု သို့မဟုတ် history ရှိ base plane တစ်ခုကို နှိပ်၍ စတင်ပါ (ရွေးချယ်စရာ)။
2. {{ui:နောက်ထပ်}} ကို ရွေးပြီး {{ui:ပြား}} ကို ရွေးပါ။ ၎င်းသည် ရွေးထားသည် (သို့မဟုတ် top plane) မှ အစိတ်အပိုင်းအရွယ်၏ 20 % အကွာတွင် offset plane အဖြစ် စတင်သည်။
3. ညာဘက်ပြတင်းတွင် **Type** နှင့် ၎င်း၏ references များကို ရွေးပါ-

| Type | References | ကိန်းများ |
|---|---|---|
| ပြား သို့မဟုတ် မျက်နှာပြင်မှ offset | **From plane** | **Distance (mm)**၊ တဖက်အတွက် အနုတ် |
| ထောင့်ဖြင့်၊ အစွန်း သို့မဟုတ် axis မှတစ်ဆင့် | **From plane**၊ **Turn about** (world axis၊ axis feature၊ သို့မဟုတ် ရွေးထားသော ဖြောင့်အစွန်း) | **Angle (°)** |
| အမှတ်သုံးခုမှတစ်ဆင့် | **Point 1**၊ **Point 2**၊ **Point 3** | — |
| နှစ်ခုကြားမှ midplane | **First plane**၊ **Second plane** (ပါရာလယ်: ထက်ဝက်; ဆုံ: ထောင့်ကို ထက်ဝက်ခွဲသော ပြား) | — |
| ဘူးကို တိုက်ရိုက်ထိ | **Cylinder** (ဘူးမျက်နှာပြင်)၊ **Near point** (ဘယ်ဘက်ဖြစ်ရန်) | — |
| အစွန်းနှင့် ထောင့်မှန်၊ အမှတ်တွင် | **Edge**၊ **At point** (ပြားသည် အစွန်း၏ အနီးဆုံးအမှတ်မှ ဖြတ်ပြီး ထိုအမှတ်မှလည်း ဖြတ်သည်) | — |
| အစွန်းနှင့် အမှတ်မှတစ်ဆင့် | **Straight edge** (သို့မဟုတ် axis)၊ **Through point** | — |
| အစွန်းအလယ်တွင် ထောင့်မှန် | **Edge** (အလယ်တွင် ထောင့်မှန်), သို့မဟုတ် အစွန်းမရှိလျှင် **Point 1** နှင့် **Point 2** (ကြားမှ ပြား) | — |

reference တိုင်းတွင် **Pick** ခလုတ် ရှိသည်- ရွေးပြီး view တွင် နှိပ်ပါ။ ပြား slot သည် base plane၊ reference plane သို့မဟုတ် ပြားမျက်နှာပြင်ကို လက်ခံသည်; အမှတ် slot သည် အစွန်း၏ အဆုံး (ထိုအဆုံးအနီးတွင် နှိပ်ပါ)၊ point feature သို့မဟုတ် မျက်နှာပြင်ပေါ်ရှိ နေရာကို လက်ခံသည်; အစွန်း slot သည် အစွန်းကို လက်ခံသည်။ {{key:Esc}} သည် ရွေးခြင်းကို ပယ်ဖျက်သည်။ **normal ကို လှန်ရန်** သည် ပြားကို ပြောင်းပြန်လှန်သည် (ပေါ်ရှိ sketch မည်သည့်ဘက်ကို မျက်နှာမူမည်ကို ပြောင်းသည်)။

ဤဗားရှင်းတွင် အစွန်း သို့မဟုတ် ဘူးမျက်နှာပြင် လိုအပ်သော slot (Tangent to a cylinder နှင့် Edge slots) သည် "not built yet" ဟု ဖြေသည်- အမှတ်များ သို့မဟုတ် axis ကို အစားထိုးသုံးပါ။

## ပြားပေါ် sketch ဆွဲရန်

ပြားကို ရွေးပါ (history တွင် သို့မဟုတ် view ရှိ ၎င်း၏ စတုရန်းကို နှိပ်ပြီး) ပြီး {{ui:Sketch}} ကို ရွေးပါ၊ သို့မဟုတ် ၎င်း၏ panel ရှိ **Sketch on it** ကို ရွေးပါ။ sketch သည် ပြားကို လိုက်သည်- ပြား၏ အကွာကို ပြောင်းလျှင် sketch နှင့် ၎င်းပေါ်ရှိ feature အားလုံး လိုက်ရွှေ့မည်။

## ဝင်ရိုးများနှင့် အမှတ်များ

- {{ui:ဝင်ရိုး}}: အမှတ်နှစ်ခုမှတစ်ဆင့်၊ ဘူး သို့မဟုတ် ကိုနီး၏ ဝင်ရိုး၊ ပြားနှစ်ခု ဆုံရာ၊ ဖြောင့်အစွန်းတစ်လျှောက် (သို့မဟုတ် ပတ်လည်အစွန်း၏ ဝင်ရိုး)၊ သို့မဟုတ် အမှတ်မှတစ်ဆင့် မျက်နှာပြင်ကို ထောင့်မှန်။
- {{ui:အမှတ်}}: ကိုအော်ဒိနိတ်၊ vertex သို့မဟုတ် sketch point၊ ပတ်လည်အစွန်း၏ ဗဟိုတွင်၊ နှင့် "အရာများကြား" အမှတ်များ:

| အမှတ်အမျိုး | References |
|---|---|
| အစွန်း၏ အလယ် (သို့မဟုတ် အမှတ်နှစ်ခုကြား) | **Edge** (အလျား၏ ထက်ဝက်၊ arc နှင့် curve အတွက်လည်း)၊ သို့မဟုတ် အစွန်းမရှိလျှင် **Point 1** နှင့် **Point 2** |
| အစွန်း သို့မဟုတ် axis သည် မျက်နှာပြင် သို့မဟုတ် ပြားနှင့် ဆုံသောနေရာ | **Edge** (ဖြောင့် သို့မဟုတ် ကွေး) သို့မဟုတ် axis၊ နှင့် **Meets plane** (ပြား သို့မဟုတ် ပြားမျက်နှာပြင်) သို့မဟုတ် **Or a face** (ပြားမျက်နှာပြင် သို့မဟုတ် ဘူး)။ စက်ဝိုင်းသည် ပြားကို နှစ်ကြိမ်ဖြတ်ပြီး မျဉ်းသည် ဘူးကို နှစ်ကြိမ်ဖြတ်သည်- **The other crossing** က ဒုတိယကို ယူသည် |
| ပြားသုံးခု ဆုံသောနေရာ | **First**၊ **Second** နှင့် **Third plane** (ပြား သို့မဟုတ် ပြားမျက်နှာပြင်) |

တစ်ခုချင်းစီသည် references မကိုက်ညီလျှင် ရိုးရှင်းသော message ဖြင့် မအောင်မြင်ပါ- ပြားနှင့် ပါရာလယ်မျဉ်း၊ ဘူးကို မထိသောမျဉ်း၊ ပြားကို မရောက်သော အစွန်း၊ အမှတ်တစ်ခုတည်းတွင် မဆုံသော ပြားသုံးခု၊ ပြားကို သတ်မှတ်ရမည့် မျဉ်းပေါ်ရှိ အမှတ်။

အခြား features များတွင် သုံးပါ:

| နေရာ | နည်းလမ်း |
|---|---|
| Revolve | **Axis**: စာရင်းမှ axis feature ကို ရွေးပါ (sketch ၏ ပြားထဲတွင် ရှိရမည်) |
| Circular pattern | **Axis**: axis feature |
| Linear pattern | **Direction**: axis feature သို့မဟုတ် ပြား (၎င်း၏ normal) |
| Mirror | **Mirror plane**: reference plane |
| Extrude | **End**: မျက်နှာပြင် သို့မဟုတ် ပြားအထိ၊ vertex အထိ (point feature)။ ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ (exact kernel လိုအပ်သည်) |
| Draft | **Neutral plane** |

## reference ပျောက်သွားသောအခါ

ပျက်သွားပြီဖြစ်သော မျက်နှာပြင်မှ ပြုလုပ်ထားသည့် ပြားသည် ပျက်ကွက်ပြီး ၎င်းကို အမည်ဖော်ပြသော message ပြသည်၊ ဥပမာ "The face it sits on is gone from Extrude1."။ ၎င်းသည် အခြားမျက်နှာပြင်သို့ ဘယ်တော့မှ မရွှေ့ပါ။ reference အသစ် မရွေးမချင်း ၎င်းပေါ်ရှိ sketches နှင့် features များကို "not built" ဟု အမှတ်အသားပြုမည်; ကျန်အစိတ်အပိုင်းသည် မူလအတိုင်း ရှိနေမည်။

:::note
ဤဗားရှင်းသည် အစိတ်အပိုင်းအားလုံးကို mesh kernel ဖြင့် တည်ဆောက်သည်၊ ၎င်းသည် base planes၊ Extrude သို့မဟုတ် Revolve ဖြင့် ပြုလုပ်ထားသော ပြားမျက်နှာပြင်များ၊ sketch points၊ coordinates နှင့် အခြား reference features မှ ပြား၊ ဝင်ရိုးနှင့် အမှတ်များကို ဖန်တီးသည်။ အစွန်း၊ အစွန်း၏ အဆုံး သို့မဟုတ် ကွေးမျက်နှာပြင် လိုအပ်သည့်အရာမည်သည်ကိုမဆို exact kernel လိုအပ်သည်- ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ ("It uses a face or edge of the solid, which only an exact kernel can find: not built yet in this version.")။
:::
