Feature များကို ပြုလုပ်ခဲ့သော အစဉ်အတိုင်း history တွင် စာရင်းပြုထားပြီး အပေါ်မှ အောက်သို့ ပြန်တည်ဆောက်သည်။ တစ်ခုချင်းစီကို ၎င်း၏ အမျိုးအစားဖြင့် နံပါတ်တပ်ထားသည်- Sketch1၊ Extrude1၊ Revolve1၊ Hole1၊ LPattern1၊ CirPattern1၊ Mirror1၊ Fillet1၊ Chamfer1၊ Shell1၊ Imported1။

PartCraft သည် feature အားလုံးကို mesh kernel ဖြင့် တည်ဆောက်သည်။ Fillet နှင့် Chamfer သည် ပြားသော မျက်နှာနှစ်ခုကြား ဖြောင့်သော အစွန်းများတွင် အလုပ်လုပ်ပြီး Shell သည် ပြားသော မျက်နှာများကို ဖွင့်သည်။ တင်သွင်းထားသော solid များသည် exact kernel လိုအပ်သည်၊ ဤဗားရှင်းတွင် မရှိ- ၎င်းတို့ကို မတည်ဆောက်ရသေးပါ၊ အောက်ပါ အပိုင်းတွင် ယခင် build မှ ပြုလုပ်ထားသော အပိုင်းက ၎င်းတို့ကို ထိန်းသိမ်းထားသည်ဟု ဖော်ပြသည်။ ကြည့်ရန်- [mesh kernel](topic:solid-kernels) နှင့် [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet)။

- Cut သည် ပစ္စည်းအတွင်းသို့ ဝင်သည်၊ sketch plane ၏ အပြင်ဘက် အစွန်းမှ ဝေးရာသို့; Reverse က ပြောင်းပေးသည်။

## Fillet နှင့် Chamfer

ဤဗားရှင်းတွင် mesh kernel သည် ပြားသော မျက်နှာနှစ်ခုကြား ဖြောင့်သော အစွန်းများ (အပြင် သို့မဟုတ် အတွင်း ထောင့်များ) ပေါ်တွင် radius တစ်ခုဖြင့် တည်ဆောက်သည်။ ကွေးသော အစွန်းသည် "Fillet: ဤဗားရှင်းတွင် ပြားသော မျက်နှာနှစ်ခုကြား ဖြောင့်သော အစွန်းများသာ (mesh kernel က တည်ဆောက်သည်)။ sketch တွင် ကွေးသော အစွန်းများကို round သို့မဟုတ် bevel လုပ်ပါ။" ဟု ပြသည်; rounded အစွန်းများ ထောင့်တွင် ဆုံသောအခါ ၎င်းတို့ကို mitre (ထောင့်ဖြတ်) လုပ်ပြီး feature က "Fillet by the mesh kernel: rounded အစွန်းများ ဆုံသော နေရာတွင် mitre လုပ်ထားသည်၊ blend မလုပ်ပါ။" ဟု သတိပေးသည်။ Chamfer အမျိုးအစားများ (equal distance၊ two distances၊ distance and angle၊ **Flip sides** ဖြင့်) အားလုံး အလုပ်လုပ်သည်။ ကြည့်ရန်- [Round၊ bevel နှင့် hollow](topic:fillet-chamfer-shell)။

| ဆက်တင် | Fillet | Chamfer |
|---|---|---|
| အရွယ်အစား (Size) | **အချင်းဝက် (mm) (Radius)**၊ မူလ 2 | **အကွာအဝေး (mm) (Distance)** အစွန်းမှ မျက်နှာနှစ်ခုတွင် နောက်သို့၊ မူလ 1 |
| **အစွန်းများ (Edges)** | ရွေးထားသော အစွန်းများ၊ ဆက်ထားသော မျက်နှာနှစ်ခုဖြင့် စာရင်းပြု ("Extrude1 end face × Extrude1 side")၊ **Remove** ဖြင့် ဖယ်နိုင်သည် | ထည့်စဉ်က ရွေးထားသော အစွန်းများ |

- ခလုတ်ကို ရွေးခြင်းမတိုင်မီ အစွန်းများ ရွေးပါ ({{key:Shift}}+နှိပ်ခြင်းဖြင့် အများအပြား)၊ သို့မဟုတ် ဘာမျှ မရွေးဘဲ ရွေးပြီး နောက်မှ အစွန်းများကို နှိပ်ပါ။
- {{ui:အစွန်းများ ရွေးရန်}} (သို့မဟုတ် feature ကို နှစ်ချက်နှိပ်) သည် အစွန်းများကို ပြောင်းသည်။
- အစွန်းများကို ဆက်ထားသော မျက်နှာနှစ်ခုဖြင့် မှတ်ထားသဖြင့် အထက်ရှိ အရွယ်အစား ပြောင်းလဲသည့်အခါလည်း ပျောက်မသွားပါ။

## Shell

mesh kernel က တည်ဆောက်သည်။ ပြားသော မျက်နှာများကိုသာ ဖွင့်နိုင်သည် ("Shell: ဤဗားရှင်းတွင် ပြားသော မျက်နှာများကိုသာ ဖွင့်သည် (mesh kernel က တည်ဆောက်သည်)။"); နံရံ အထူ မတူသော shell များကို မတည်ဆောက်ရသေး။ ကြည့်ရန်- [Round၊ bevel နှင့် hollow](topic:fillet-chamfer-shell)။

| ဆက်တင် | လုပ်ဆောင်ချက် | မူလ |
|---|---|---|
| နံရံ (mm) (Wall) | နံရံအထူ | 2 |
| နံရံများ အပြင်သို့ ကြီးသည် (Walls grow outward) | ပိတ်- နံရံများ အတွင်းသို့။ ဖွင့်- နံရံများ အပြင်သို့ | ပိတ် |

## တင်သွင်းထားသော solid

STEP၊ STL၊ OBJ သို့မဟုတ် 3MF ဖိုင် ဖွင့်ခြင်းဖြင့် ပြုလုပ်သည်- တြိဂံများဖြင့် solid body တစ်ခု၊ ကိုယ်ပိုင် history မရှိ ([STEP ဖိုင် ဖွင့်ခြင်း](topic:import-step)၊ [STL၊ OBJ သို့မဟုတ် 3MF ဖွင့်ခြင်း](topic:open-meshes))။ ၎င်းသည် မူလဖိုင်နှင့် import က ပြင်ဆင်ခဲ့သည့်အရာများကို ပြသည်; **Units in the file**၊ **Up in the file** နှင့် **Use it to** တို့သည် တည်းဖြတ်နိုင်ဆဲ ဖြစ်သည်။ exact kernel ရှိသော ယခင် build မှ တင်သွင်းထားသော STEP solid သည် history တွင် not built အဖြစ် ကျန်ရှိသည်; ၎င်းကို တြိဂံများအဖြစ် ပြန်ယူရန် STEP ဖိုင်ကို ထပ်ဖွင့်ပါ။

| ဆက်တင် | ရွေးချယ်စရာများ | မူလ |
|---|---|---|
| ဖိုင်တွင် အပေါ်ဘက် (Up in the file) | Z up (CAD အများစု)၊ Y up | Z up |

Pattern နှင့် mirror များသည် တင်သွင်းထားသော solid ကို ကူးနိုင်သော်လည်း fillet၊ chamfer သို့မဟုတ် shell ကို မကူးနိုင်ပါ။

## Feature တိုင်းတွင် ရှိသည်များ

feature တစ်ခုစီ panel ၏ အောက်ခြေတွင်-

| ခလုတ် | လုပ်ဆောင်ချက် |
|---|---|
| {{ui:Suppress}} / {{ui:Unsuppress}} | ပိတ် သို့မဟုတ် ဖွင့်။ လိုအပ်သော features များသည် ပိတ်ထားစဉ် မတည်ဆောက်ပါ |
| {{ui:Roll back to here}} | ဤအရာအပေါ်ရှိ features များကိုသာ တည်ဆောက်သည်။ feature အသစ်များကို rollback bar တွင် ထည့်သည် |
| {{ui:Move up}} / {{ui:Move down}} | အစီအစဉ်ပြန်စီ၊ ၎င်းသုံးသည့်အရာ အောက်သို့ မရောက်သည့်အခါသာ။ မဟုတ်လျှင် အကြောင်းပြချက်နှင့်အတူ မှိန်ထားသည် |
| {{ui:Delete}} | ဖျက်ပြီး (မေးပြီးနောက်) ၎င်းကို သုံးသော feature တိုင်းကိုပါ ဖျက်သည် |
| အမည် (Name) | အမည်ပြောင်း (အက္ခရာ 60 အထိ) |

sketch ပါသော features များသည် **Sketch dimensions** ကိုလည်း ဖော်ပြပြီး နေရာတွင် တည်းဖြတ်နိုင်သည်။

## History ရှိ အခြေအနေများ

| အခြေအနေ | ပြသပုံ | အဓိပ္ပာယ် |
|---|---|---|
| တည်ဆောက်ပြီး (Built) | ပုံမှန် | အားလုံး ကောင်းသည် |
| သတိပေး (Warning) | ⚠ | တည်ဆောက်ပြီး၊ စစ်ရန် တစ်ခုရှိသည်: "Over defined: relation 1 ခု မလိုအပ်ပါ။" သို့မဟုတ် "ဤအရာပြီးနောက် အပိုင်းမှ ဘာမျှ မကျန်တော့။" |
| အမှား (Error) | ⚠ error၊ အနီ | မတည်ဆောက်နိုင်; မက်ဆေ့ချ်က အကြောင်းပြသည် |
| မတည်ဆောက်ရသေး (Not built) | ⚠ not built | ပျက်ကွက်သော၊ ပိတ်ထားသော သို့မဟုတ် rollback လုပ်ထားသော feature လိုအပ်သည်၊ သို့မဟုတ် ဤဗားရှင်းတွင် မရှိသော exact kernel လိုအပ်သည် ("Sweep: မတည်ဆောက်ရသေး။ …") |
| ပိတ်ထား (Suppressed) | off | ပိတ်ထားသည် |
| Rollback လုပ်ထား (Rolled back) | မှိန်ထား၊ rollback bar အောက်တွင် | ရှေ့သို့ ပြန်မတိုင်မီ မတည်ဆောက်ရသေး |

## အပိုင်းဆက်တင်များ

ဘာမျှ မရွေးထားစေရန် အလွတ်နေရာကို နှိပ်ပါ။ right panel တွင် **Part** ကို ပြသည်-

- **အမည် (Name)**: အပိုင်း၏ အမည်၊ ဖိုင်အမည်နှင့် ပုံဆွဲ title block အတွက် သုံးသည် (အက္ခရာ 120 အထိ)။
- **Curves**: အောက်တွင် ကြည့်ပါ။

### Curves ၏ အသေးစိတ်အဆင့်

mesh kernel သည် solid ကို ပြားသော facet များဖြင့် ကိုယ်တိုင် တည်ဆောက်သဖြင့် view၊ STL၊ 3MF၊ faceted STEP၊ ထုထည်နှင့် ပုံဆွဲ views အားလုံးသည် **Curves** ကို လိုက်သည်- တစ်ပတ်လျှင် facet မည်မျှ။

| ဆက်တင် | တစ်ပတ်လျှင် facet | စက်ဝိုင်းပုံ၏ ထုထည် |
|---|---|---|
| Coarse (32 per turn) | 32 | မှန်ကန်သော တန်ဖိုးထက် 0.64 % ခန့် နည်း |
| Normal (64 per turn) | 64 | 0.16 % ခန့် နည်း (မူလ) |
| Fine (128 per turn) | 128 | 0.04 % ခန့် နည်း |
| Very fine (256 per turn) | 256 | 0.01 % ခန့် နည်း |

ပိုသေးသော curves သည် ပိုချောမွေ့သော ထုတ်ယူမှုနှင့် view များ ပေးသော်လည်း ပြန်တည်ဆောက်ခြင်း ပိုနှေးသည်။ ဤဆက်တင်ကို အပိုင်းဖိုင်တွင် သိမ်းသည်။

## မတည်ဆောက်ရသေးသော အရာများ

ပြောင်းလဲ radius ပါသော fillet များ၊ ကွေးသော အစွန်းပေါ်ရှိ fillet နှင့် chamfer များ၊ ကွေးသော မျက်နှာများ ဖွင့်သော shell များ၊ ကွေးသော မျက်နှာပေါ်ရှိ draft၊ sweep၊ loft၊ rib၊ exact ကွေးသော မျက်နှာပါသော STEP solid များ၊ new body များ၊ taper များ၊ မျက်နှာ သို့မဟုတ် vertex အထိ "up to" နှင့် solid ၏ မျက်နှာနှင့် အစွန်းများပေါ်ရှိ reference များသည် exact kernel လိုအပ်ပြီး ဤဗားရှင်းတွင် မရှိပါ။ ထို့အပြင် မတည်ဆောက်ရသေး- tapped နှင့် countersunk အပေါက်များ။ ကြည့်ရန်- [မတည်ဆောက်ရသေးသော အရာများ](topic:not-built-yet)။
