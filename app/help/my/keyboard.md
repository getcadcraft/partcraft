panel ရှိ box ထဲတွင် စာရိုက်နေချိန်၌ key များ အလုပ်မလုပ်ပါ၊ သို့သော် {{key:Mod+S}} နှင့် {{key:Mod+O}} ကတော့ အမြဲအလုပ်လုပ်ပါသည်။ အက္ခရာ key များသည် modifier မပါဘဲ အလုပ်လုပ်ပါသည်။

browser ရှိ key များနှင့် function key မပါသော ကီးဘုတ်များအကြောင်း ယေဘုယျမှတ်ချက်များ: [Keys, mice and trackpads](common:keys)။

## နေရာတိုင်း

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Mod+S}} | part ကို သိမ်းရန် (assembly ထဲတွင်: assembly ကို သိမ်းရန်)။ ဖွင့်ထားသော sketch ကို ဦးစွာပိတ်ပေးသည် |
| {{key:Mod+O}} | part သို့မဟုတ် assembly ဖိုင်ကို ဖွင့်ရန် (မသိမ်းရသေးသော ပြောင်းလဲမှုရှိပါက ဦးစွာမေးသည်) |
| {{key:Mod+Z}} | ပြန်ဖျက်ရန် |
| {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} | ပြန်လုပ်ရန် |
| {{key:F1}} | ဤအကူအညီကို ဖွင့်ရန် သို့မဟုတ် ပိတ်ရန် (app bar ရှိ {{ui:Help}} ကိုလည်း သုံးနိုင်သည်)။ {{key:Esc}} ဖြင့်လည်း ပိတ်နိုင်သည်။ laptop နှင့် Mac keyboard အများစုတွင် Fn ကို ဖိထားပါ |
| {{key:Ctrl+Shift+F}} | မျက်နှာပြင်မုဒ်: ပုံမှန်၊ မျက်နှာပြင်အပြည့်၊ ဘားများဖျောက်ထားသော မျက်နှာပြင်အပြည့်။ Mac တွင်လည်း Control ဖြစ်ပြီး ⌘ မဟုတ်ပါ |
| {{key:Esc}} | မျက်နှာပြင်အပြည့်မှ ထွက်ရန် (မျက်နှာပြင်အပြည့်ဖြစ်နေချိန်တွင်သာ) |
| {{key:Mod+,}} | Settings၊ PartCraft tab အပါအဝင် (see [PartCraft settings](topic:settings)) |

panel ရှိ နံပါတ် box တွင် {{key:Mod+Z}} သည် browser ၏ ကိုယ်ပိုင်စာသား ပြန်ဖျက်ခြင်းဖြစ်သည်။ sketch dimension အပေါ်ရှိ နံပါတ် box တွင်ဆိုလျှင် PartCraft ထဲတွင် ပြန်ဖျက်သည်။

## Copy, paste နှင့် duplicate

ဤ key များသည် သင်လုပ်ဆောင်နေသည့်အရာပေါ်တွင် သက်ရောက်သည်: ဖွင့်ထားသော sketch ရှိ ရွေးထားသော geometry၊ history ရှိ ရွေးထားသော feature၊ သို့မဟုတ် assembly ရှိ ရွေးထားသော part။ အသေးစိတ်ကို [Copy, paste and duplicate](topic:copy-paste) တွင် ကြည့်ပါ။

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:Mod+C}} | ရွေးထားသည်ကို ကူးရန် |
| {{key:Mod+X}} | ဖြတ်ရန်: ကူးပြီးနောက် ဖျက်ရန် |
| {{key:Mod+V}} | ကူးထည့်ရန်။ sketch တွင် ကူးထားသည်က pointer ကို လိုက်သည်: ထားလိုသည့်နေရာကို click လုပ်ပါ |
| {{key:Mod+Shift+V}} | နေရာတူတွင် ကူးထည့်ရန်: သြဒိနိတ် အတူတူ (assembly တွင် နေရာတူ) |
| {{key:Mod+D}} | Duplicate: ကူးပြီး ထည့်ရန် တစ်ဆင့်တည်း၊ clipboard ကို မထိပါ |
| {{key:Mod+A}} | အားလုံးရွေးရန် (sketch တွင်) |
| {{key:Esc}} | ဘာမှမရွေးရန် (pointer ကို လိုက်သော ကူးထည့်မှုကိုလည်း ပယ်ဖျက်သည်) |

နံပါတ် box တွင် ဤ key များသည် စာသားကို ပုံမှန်အတိုင်း ကူး၍ ထည့်သည်။ panel ရှိ ရွေးထားသော စာသားကို browser က ကူးသည်။

## Part ပေါ်တွင် (sketch မဖွင့်ထားချိန်)

| Key | လုပ်ဆောင်ချက် |
|---|---|
| {{key:S}} | ရွေးထားသော plane သို့မဟုတ် ပြားသော face ပေါ်တွင် sketch ဆွဲရန်; ဘာမှမရွေးထားပါက နေရာကို click လုပ်၍ ရွေးပါ |
| {{key:F}} | part ကို view ထဲတွင် ကိုက်ညီအောင်ပြရန် |
| {{key:M}} | Measure: workspace အားလုံးနှင့် assembly တွင်; {{key:Esc}} က ရွေးချယ်မှုများကို ရှင်းသည်၊ {{key:Esc}} နောက်တစ်ကြိမ်က ပိတ်သည် (see [Measure distances, angles and mass](topic:measure)) |
| {{key:X}} | Section view ဖွင့်/ပိတ်: workspace အားလုံးနှင့် assembly တွင်; {{key:Esc}} ဖြင့် ပိတ်သည် (see [Look inside with a section view](topic:section-view)) |
| {{key:Delete}} | ရွေးထားသော feature ကို ဖျက်ရန် (အခြားက သုံးနေပါက မေးသည်) |
| {{key:0}} … {{key:9}}, {{key:.}} | feature တစ်ခု ရွေးထားချိန်: ၎င်း၏ အဓိကနံပါတ် (Extrude ၏ အနက်၊ Hole ၏ အချင်း၊ pattern ၏ အရေအတွက်၊ fillet ၏ radius …) ကို ရိုက်ပြီး {{key:Enter}}။ {{key:Esc}} က အဟောင်းကို ထားသည် |
| {{key:Backspace}} | feature တစ်ခု ရွေးထားပါက ၎င်းကို ဖျက်ရန် |
| {{key:Esc}} | sketch plane ရွေးခြင်းကို ရပ်ရန်၊ သို့မဟုတ် ရွေးချယ်မှုကို ရှင်းရန် ({{key:Shift}} ဖြင့် ရွေးထားသော edge သို့မဟုတ် face များအပါအဝင်) |

|---|---|

| ညာ သို့မဟုတ် အလယ်ခလုတ်ဖြင့် ဆွဲခြင်း | ရွှေ့ကြည့်ရန် (Pan) |
| ဘယ်ခလုတ်ဖြင့် ဆွဲနေစဉ် {{key:Shift}}, {{key:Ctrl}} သို့မဟုတ် ⌘ ကိုဖိထားခြင်း | ရွှေ့ကြည့်ရန် (Pan) |
| ဘီးလှိမ့်ခြင်း | pointer နေရာတွင် zoom (သင့်ထံမှ ဝေးသွားလျှင် zoom in) |
| trackpad ပေါ်တွင် လက်နှစ်ချောင်း ပွတ်ခြင်း | view ကို လှည့်ရန်; {{key:Shift}} ဖြင့် ရွှေ့ကြည့်ရန်။ ညှစ်ခြင်းက zoom။ [PartCraft settings](topic:settings) ရှိ **Scrolling** ဖြင့် သတ်မှတ်သည် |

[PartCraft settings](topic:settings) ရှိ **Turning the view: Middle button** ကို ဖွင့်ထားပါက အလယ်ခလုတ်က view ကို လှည့်သည်၊ အလယ်ခလုတ် သို့မဟုတ် ညာခလုတ်နှင့်အတူ {{key:Shift}} က ရွှေ့ကြည့်သည်၊ ဘယ်ခလုတ်က ရွေးရုံသာ ရွေးသည်။
| Click | face (အပြည့်အစုံ မီးမောင်းပြသည်)၊ edge သို့မဟုတ် plane ကို ရွေးရန် |
| {{key:Shift}}+click edge သို့မဟုတ် face | edge သို့မဟုတ် face အများအပြားကို စုရန် |
| နေရာလွတ်ကို click | ရွေးချယ်မှုကို ရှင်းရန် |

## browser က ယူနိုင်သော shortcut များ

- Safari တွင် {{key:Mod+Y}} သည် history ကို ဖွင့်နိုင်သည်: ပြန်လုပ်ရန် {{key:Mod+Shift+Z}} ကို သုံးပါ။
- {{key:Mod+D}} သည် browser ၏ bookmark key ဖြစ်သည်: app တွင် focus ရှိစဉ် PartCraft က ယူသည်၊ box တွင် စာရိုက်နေစဉ် ထားခဲ့သည်။
- {{key:F11}} နှင့် {{key:Mod+Plus}} / {{key:Mod+Minus}} သည် browser ၏ မျက်နှာပြင်အပြည့်နှင့် စာမျက်နှာ zoom ဖြစ်ပြီး PartCraft ၏ မဟုတ်ပါ။ မျက်နှာပြင်အပြည့်အတွက် {{key:Ctrl+Shift+F}}၊ model အတွက် ဘီးကို သုံးပါ။
- laptop နှင့် Mac အများအပြားတွင် function key များသည် Fn key လိုအပ်သည်: အကူအညီအတွက် Fn+{{key:F1}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Help}} ခလုတ်ကို သုံးပါ။

touch နှင့် trackpad gesture များ: [Trackpad, touch and small screens](topic:trackpad-and-touch)။
