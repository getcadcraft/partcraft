**ဖွဲ့စည်းမှု** တစ်ခုသည် အစိတ်အပိုင်း၏ အရွယ်အစားတစ်ခု ဖြစ်သည်: ၎င်း၏ ပါရာမီတာများအတွက် အမည်ပေးထားသော တန်ဖိုးအစုံ။ Part သည် ၎င်း၏ ဖွဲ့စည်းမှုများကို ကိုယ်ပိုင်ဖိုင်တွင် ထိန်းထားသဖြင့် ၎င်းနှင့်အတူ ပါလာသည်။ **ဒီဇိုင်းဇယား** သည် CSV ဖိုင်တစ်ခု ဖြစ်ပြီး ဖွဲ့စည်းမှုတစ်ခုစီအတွက် row တစ်ခု ပါသည်။

ဖွဲ့စည်းမှုများသည် **ပါရာမီတာများ** ကို သတ်မှတ်သဖြင့် ဦးစွာ ထိုပါရာမီတာများကို ထည့်ပါ ([ပါရာမီတာဖြင့် part ကို မောင်းနှင်ခြင်း](topic:parameters) ကို ကြည့်ပါ)။ ဖွဲ့စည်းမှုတစ်ခုသည် ရိုးရိုးဂဏန်းဖြစ်သော ပါရာမီတာများကို သိမ်းသည်; အခြားများမှ တွက်ချက်ထားသော ပါရာမီတာများ (ဥပမာ `area = w * d`) သည် ကိုယ်ဘာသာ လိုက်သည်။

## ဖွဲ့စည်းမှုတစ်ခု သိမ်းခြင်း

1. **{{ui:Parameters}}** tab တွင် အရွယ်အစားတစ်ခုအတွက် ပါရာမီတာများကို သတ်မှတ်ပါ။
2. **ဖွဲ့စည်းမှုများ** အောက်တွင် နာမည်ရိုက်ပါ (ဥပမာ `Large`) ပြီး {{ui:Save current values}} သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပါ။

ဖွဲ့စည်းမှုအသစ်ကို **အသက်ဝင်နေ** ဟု အမှတ်အသားပြုသည်။ နောက်မှ ပါရာမီတာတစ်ခုကို ပြောင်းလျှင် **အသက်ဝင်နေ၊ ထိုအချိန်မှစ၍ ပြောင်းလဲထား** ဟု ပြောသည်၊ ထို့ကြောင့် part သည် ၎င်းနှင့် မကိုက်ညီတော့ကြောင်း သင်သိသည်။

## ပြောင်းခြင်း၊ အပ်ဒိတ်လုပ်ခြင်း၊ အမည်ပြောင်းခြင်း၊ ဖျက်ခြင်း

- {{ui:Apply}} က ပါရာမီတာများကို ထိုဖွဲ့စည်းမှု၏ တန်ဖိုးများသို့ သတ်မှတ်ပြီး part ကို ပြန်တည်ဆောက်သည်။
- {{ui:Update}} က လက်ရှိတန်ဖိုးများကို ထိုဖွဲ့စည်းမှုထဲသို့ သိမ်းသည်။
- တစ်ခုကို အမည်ပြောင်းရန် ၎င်း၏ box တွင် အမည်အသစ်ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
- {{ui:Delete}} က ဖွဲ့စည်းမှုကို ဖယ်ရှားသည်။ ပါရာမီတာများသည် ၎င်းတို့၏ တန်ဖိုးများကို ဆက်ထားသည်။

ဤအရာတစ်ခုစီသည် အဆင့်တစ်ခုဖြစ်သည်: {{key:Mod+Z}} က နောက်သို့ သွားသည်။ ပါရာမီတာတစ်ခု၏ အမည်ကို ပြောင်းလျှင် ဖွဲ့စည်းမှုအားလုံးက အမည်အသစ်ကို လိုက်သည်; တစ်ခုကို ဖျက်လျှင် ၎င်းသည် ၎င်းတို့ထဲမှ ကျွတ်သွားသည်။

## ဖွဲ့စည်းမှုတစ်ခုတွင် feature များကို ဖွင့်/ပိတ်ခြင်း

ဖွဲ့စည်းမှုတစ်ခုသည် မည်သည့် feature များ ပိတ်ထားသည်ကိုလည်း သိမ်းထားသဖြင့် အစိတ်အပိုင်းတစ်ခုတွင် တစ်ခုနှင့် **ပါသော** နှင့် **မပါသော** ဗားရှင်းများ ရှိနိုင်သည်: တပ်ဆင်အပေါက်များ၊ chamfer၊ boss။

1. Feature ကို ပိတ်ပါ: history ထဲတွင် နှိပ်ပြီး **{{ui:Properties}}** ရှိ {{ui:Suppress}} ကို နှိပ်ပါ။
2. ဖွဲ့စည်းမှုကို ပုံမှန်အတိုင်း သိမ်းပါ၊ ဥပမာ `အပေါက်မရှိ`။ ၎င်း၏ row က ပိတ်ထားသည်များကို ဖော်ပြသည်။
3. Feature ကို ပြန်ဖွင့်ပါ ({{ui:Unsuppress}}) ပြီး အခြားဖွဲ့စည်းမှုတစ်ခု သိမ်းပါ၊ ဥပမာ `အပေါက်ရှိ`။

ဖွဲ့စည်းမှုတစ်ခုက feature တစ်ခုကို ပိတ်လိုက်သည်နှင့် ဖွဲ့စည်းမှုကို အသုံးပြုခြင်းသည် ၎င်း၏ feature များကို ပိတ်ပြီး **အခြား feature အားလုံးကို ဖွင့်ပေးသည်**၊ ၎င်းတို့၏ ပါရာမီတာတန်ဖိုးများနှင့်အတူ၊ အဆင့်တစ်ခုတည်းဖြင့်။ Feature များ မပိတ်မီ သိမ်းထားသော ဖွဲ့စည်းမှုသည် "ဘာအားလုံးဖွင့်" ဟု ရေတွက်သည်။ {{ui:Update}} က feature များကို ယခု အတိုင်း တန်ဖိုးများနှင့်အတူ သိမ်းသည်။

ဖွဲ့စည်းမှုများက feature များကို ပိတ်ထားသော part ကို ပိုသစ်သော ဖိုင်ဗားရှင်းအဖြစ် သိမ်းသည်: ပိုဟောင်းသော PartCraft က ၎င်းတို့မပါဘဲ ဖွင့်မည့်အစား ဖိုင်သည် ပိုသစ်သော ဗားရှင်းမှဖြစ်ကြောင်း ပြောသည်။

:::note
CSV ဒီဇိုင်းဇယားတွင် ပါရာမီတာတန်ဖိုးများသာ ပါဝင်သည်။ ဖွဲ့စည်းမှုတစ်ခုပေါ်သို့ ဇယားသွင်းခြင်းသည် ၎င်း၏ တန်ဖိုးများကို ပြောင်းပြီး ပိတ်ထားသော feature များကို ဆက်ထားသည်; command line ၏ `--table` က တန်ဖိုးများကိုသာ တည်ဆောက်သည်။
:::

Part ဖိုင်သည် ဖွဲ့စည်းမှုများနှင့် အသက်ဝင်နေသော တစ်ခုကို သိမ်းသည်။ Part သည် သိမ်းချိန်ရှိ တန်ဖိုးများဖြင့် ဖွင့်သည်။

## ဒီဇိုင်းဇယားကို သွင်းခြင်း သို့မဟုတ် ထုတ်ခြင်း

ဒီဇိုင်းဇယားသည် ပါရာမီတာတစ်ခုစီအတွက် column တစ်ခုနှင့် ဖွဲ့စည်းမှုတစ်ခုစီအတွက် row တစ်ခု ပါသော CSV ဖိုင်ဖြစ်သည်:

```
name,width,thick,bolt
small,100,6,6.6
medium,140,8,8.5
large,200,12,13
```

ပထမ column ကို `name`, `config` သို့မဟုတ် `configuration` ဟု ခေါ်နိုင်သည်; အခြား column တိုင်းသည် part ၏ ပါရာမီတာ၏ အမည် ဖြစ်ရမည်။ Cell များသည် ဂဏန်းများ ဖြစ်ပြီး သင်နှစ်သက်လျှင် unit ပါနိုင်သည် (`8in`)။ ဗလာ cell သည် ထို row မှ ပါရာမီတာကို ချန်လှပ်ထားသည်။

- {{ui:Import CSV}} က row တစ်ခုစီကို ဖွဲ့စည်းမှုတစ်ခုအဖြစ် ထည့်သည်။ ရှိပြီးသား ဖွဲ့စည်းမှု၏ အမည်နှင့် row တစ်ခုက ၎င်းကို အစားထိုးသည်။ သွင်းခြင်းသည် အဆင့်တစ်ခု ဖြစ်သည်။
- {{ui:Export CSV}} က ဖွဲ့စည်းမှုများကို ရေးထုတ်သည်။ မရှိသေးလျှင် လက်ရှိတန်ဖိုးများ၏ row တစ်ခုကို ရေးသည်၊ spreadsheet အတွက် စတင်ရန် အချက်အဖြစ်။

Spreadsheet က ပုံသေနည်းအဖြစ် ဖတ်မည့် ဖွဲ့စည်းမှုအမည် (`=`, `+`, `-` သို့မဟုတ် `@` ဖြင့် စသော) ကို ရှေ့တွင် `'` ဖြင့် ရေးသည်။

## အရွယ်အစားအားလုံး တစ်ပြိုင်နက်

**ဖွဲ့စည်းမှုများ** အောက်ရှိ {{ui:Variant pack…}} က ဖွဲ့စည်းမှုအားလုံး သို့မဟုတ် ရွေးထားသော အချို့ကို STEP၊ IFC၊ DWG နှင့် preview အဖြစ် zip တစ်ခုတွင် ၎င်းတို့၏ ပါရာမီတာများ၏ ဇယားနှင့်အတူ တည်ဆောက်သည်: [ဖွဲ့စည်းမှုများမှ variant pack ပြုလုပ်ခြင်း](topic:variant-pack) ကို ကြည့်ပါ။

Command line tool က ဒီဇိုင်းဇယား CSV ၏ row တစ်ခုစီအတွက် ဖိုင်တစ်ခု တည်ဆောက်သည်:

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

ဖွဲ့စည်းမှုများကို ဦးစွာ CSV အဖြစ် ထုတ်ပါ၊ ထို့နောက် ထိုဖိုင်ကို `--table` ဖြင့် ပေးပါ။ [Scripts နှင့် command line](topic:scripts-and-cli) ကို ကြည့်ပါ။ Script အဖြစ် သိမ်းထားသော part သည် ၎င်း၏ ဖွဲ့စည်းမှုများကို `configs json …` လိုင်းတွင် ထိန်းထားသည်။
