PartCraft ၏ command များသည် မည်သည့်နည်းဖြင့် ရောက်သည်ဖြစ်စေ အတူတူပင်ဖြစ်သည်။ **menu style** သည် ၎င်းတို့ screen ပေါ်တွင် ဘယ်မှာရှိမည်၊ ဘာနာမည်ဖြင့် ခေါ်မည်နှင့် ဘယ် key ဖြင့် run မည်ကိုသာ ဆုံးဖြတ်သည်။ {{ui:Settings}} ({{key:Mod+,}}) › {{ui:PartCraft}} › {{ui:Menus, keys and mouse}} တွင် ရွေးပါ; ပြောင်းလဲမှုက ချက်ချင်းဖြစ်ပြီး ဤ browser က မှတ်ထားသည်။

## Style နှစ်ခု

| Style | သင်ရရှိမည့်အရာ |
|---|---|
| {{ui:PartCraft}} | PartCraft ၏ ကိုယ်ပိုင် toolbar: workspace switcher၊ File၊ Sketch၊ Features၊ Drawing၊ Assembly၊ Edit နှင့် View။ Keys {{key:S}} sketch၊ {{key:F}} fit၊ {{key:M}} measure၊ {{key:X}} section view။ စတင်ရာ။ |
| {{ui:Feature tree}} | feature-based mechanical CAD program များ၏ ပုံစံနှင့် ကိုက်ညီသော ribbon: {{ui:File}} menu (export အားလုံးပါ)၊ quick ခလုတ်များ၊ နှင့် tab များ {{ui:Features}}၊ {{ui:Sketch}}၊ {{ui:Surfaces}}၊ {{ui:Evaluate}}၊ {{ui:Drawing}}၊ {{ui:Assembly}}၊ {{ui:Studies}} (workspace များနှင့် ၎င်းတို့၏ tool များ)၊ {{ui:Illustrate}} (Illustrate workspace ၏ manual tool များ၊ ၎င်း၏ tool များက Illustrate ကို ဦးစွာပြောင်းသည်) နှင့် {{ui:View}}။ {{ui:Features}} သည် {{ui:Sketch}} ဖြင့် စသည်၊ part တစ်ခုသည် sketch မှစတင်သောကြောင့်။ အပိုကီး: {{key:E}} extrude၊ {{key:H}} hole၊ နှင့် {{key:V}} ပြီးနောက် view အတွက် အက္ခရာ: {{key:V}} {{key:F}} front၊ {{key:V}} {{key:B}} back၊ {{key:V}} {{key:T}} top၊ {{key:V}} {{key:O}} bottom၊ {{key:V}} {{key:R}} right၊ {{key:V}} {{key:L}} left၊ {{key:V}} {{key:I}} isometric၊ {{key:V}} {{key:N}} normal to။ 3D view တွင် အလယ်ခလုတ်က လှည့်၊ {{key:Shift}} နှင့် အလယ်ခလုတ်က ရွှေ့၊ ညာခလုတ်က ရွှေ့၊ ဘယ်ခလုတ်က ရွေးရုံသာ။ |

style တိုင်းက {{key:Mod+Z}}၊ {{key:Mod+Y}}၊ {{key:Mod+S}}၊ {{key:Mod+O}}၊ {{key:Mod+C}}၊ {{key:Mod+X}}၊ {{key:Mod+V}}၊ {{key:Mod+D}} နှင့် {{key:Mod+A}} ကို ထိန်းထားသည်။

အခြား workspace ရှိ tool တစ်ခုက ဦးစွာ ၎င်းသို့ ပြောင်းသည်; အခြား workspace တွင် ရွေးထားသော Design tool က ဦးစွာ Design သို့ ပြန်သွားသည်။ Sketch tool များက sketch ကို စောင့်၊ drawing tool များက drawing sheet ကို၊ assembly tool များက assembly ကို စောင့်သည်: status bar က ဦးစွာ ဘာလုပ်ရမည်ကို ပြောသည်။

:::tip
sketch အတွင်း၊ drawing sheet ပေါ်၊ assembly နှင့် အခြား workspace များတွင် အက္ခရာများသည် ထိုနေရာတွင် ၎င်းတို့၏ ကိုယ်ပိုင်အဓိပ္ပာယ်ကို ထိန်းထားသည် ({{key:L}} line၊ {{key:R}} rectangle၊ {{key:J}} joint …) style တိုင်းတွင်။ {{key:Delete}}၊ {{key:Esc}}၊ {{key:Enter}}၊ {{key:Tab}}၊ {{key:Space}} နှင့် မြားများသည် အမြဲ ၎င်းတို့၏ အဓိပ္ပာယ်ကို ထိန်းထားသည်။ သင့် style က အခြား command တစ်ခုသို့ ပေးထားသော PartCraft ၏ layout key တစ်ခုသည် ဘာမှမလုပ်ပါ၊ ၎င်း command ရောက်သွားသည့်နေရာကို status bar က ပြောသည်။
:::

## သင့်ကိုယ်ပိုင် ပြုလုပ်ပါ

1. သင်လိုချင်သည်နှင့် အနီးဆုံး style ကို ရွေးပြီး {{ui:Customize…}} ကို click လုပ်ပါ။
2. {{ui:Keys and menus}} တွင် command တစ်ခုကို ရှာပါ (search box က ကူညီသည်)။ {{ui:Add a key}} ကို နှိပ်ပြီး key ကို နှိပ်ပါ၊ သို့မဟုတ် key ကို တစ်ဆက်တည်း နှစ်ခု နှိပ်ပါ။ key ကို click လုပ်၍ ဖယ်ထုတ်ပါ။
3. ribbon ဖြင့်၊ {{ui:Where it sits}} က command ကို အခြား tab နှင့် panel၊ {{ui:File}} menu၊ သို့မဟုတ် {{ui:Keys only}} သို့ ရွှေ့သည်။
4. {{ui:Mouse}} တွင် wheel၊ sketch ကို ရွှေ့သည့် ခလုတ်များနှင့် 3D view တွင် ခလုတ်တစ်ခုစီက ဘာလုပ်မည်ကို သတ်မှတ်ပါ။
5. အမည်ပေးပြီး {{ui:Save}} ကို click လုပ်ပါ။

built-in style ကို သိမ်းခြင်းသည် သင့်ကိုယ်ပိုင် မိတ္တူ ("My Feature tree") ကို ပြုလုပ်သည်; built-in တစ်ခုသည် ဘယ်တော့မှ မပြောင်းပါ။ command နှစ်ခုသို့ ပေးထားသော key သို့မဟုတ် နှစ်လုံး key မတိုင်မီ run မည့် key တစ်ခုသည် အနီရောင်ဖြင့် ပြပြီး သိမ်းခွင့်မရမီ ပြင်ရမည်။

## Mouse

- **Mouse wheel**: {{ui:Scroll up zooms in}} (စတင်အခြေအနေ) သို့မဟုတ် {{ui:Scroll up zooms out}}၊ နှင့် ဘယ်လောက်မြန်သလဲ။ trackpad pinch သည် သင့်လက်ချောင်းများ ရွေ့သည့်ဘက်အတိုင်း အမြဲ zoom လုပ်သည်။
- **Sketch ကို ရွှေ့ရန်**: အလယ်ခလုတ်၊ ညာခလုတ်၊ သို့မဟုတ် နှစ်ခုလုံး။ sketch တွင် ညာ click သည် tool ၏ အဆင့်ကို ဆက်ရပ်ပေးသည်။
- **3D view တွင် ဆွဲခြင်း**: {{ui:Each view's own}} က PartCraft ၏ ဆက်တင် ({{ui:Settings}} › {{ui:PartCraft}}: ဘယ်က လှည့်၊ သို့မဟုတ် အလယ်က လှည့်) ကို ထိန်းသည်။ သို့မဟုတ် ခလုတ်တစ်ခုစီကို လှည့်၊ ရွှေ့၊ zoom သို့မဟုတ် ဘာမှမလုပ်ရန် သတ်မှတ်ပါ; {{key:Shift}} နှင့် လှည့်သည့်ခလုတ်သည် ရွှေ့သည်။ ဆွဲခြင်းမရှိသော click သည် ရွေးရုံသာ ရွေးသည်။

## သင်နှင့်အတူ ယူသွားရန်

{{ui:Export}} က အသုံးပြုနေသော style ကို `.ccinput.json` ဖိုင်ငယ်တစ်ခုအဖြစ် သိမ်းသည်; {{ui:Import…}} က ၎င်းကို ထည့်သည်၊ အခြားကွန်ပျူတာ သို့မဟုတ် အလုပ်ဖော်ထံမှ။ တင်သွင်းသော ဖိုင်သည် PartCraft ၏ ကိုယ်ပိုင် command များကိုသာ ညွှန်နိုင်သည်: အခြားအရာ မည်သည်ကိုမဆို ဖယ်ထုတ်ပြီး status bar တွင် ရေတွက်သည်။ {{ui:Delete this style}} က သင့်ကိုယ်ပိုင်တစ်ခုကို ဖယ်ရှားသည်။

:::note
ဤဆက်တင်များသည် ဤ browser တွင်သာ ကျန်နေသည်။ style card များအောက်ရှိ {{ui:Use this style in every app}} က app တိုင်းကို ၎င်းနှင့်ကိုက်ညီသော style ဖြင့် (၎င်း၏ toolbar သို့မဟုတ် ribbon) ဖွင့်စေပြီး app တစ်ခုစီတွင် သင်ပြုလုပ်ထားသော ပြောင်းလဲမှုများနှင့်အတူ။ app တစ်ခုတွင် အခြား style ရွေးခြင်းသည် ထို app တစ်ခုတည်းကိုသာ ပြောင်းသည်။
:::
