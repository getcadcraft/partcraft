**Generator** သည် သင်၏ လိုအပ်ချက်များမှ အစိတ်အပိုင်းကို အရွယ်အစားသတ်မှတ်ပြီး တည်ဆောက်သော script တစ်ခု ဖြစ်သည်။ Heat exchanger generator သည် ရွေ့ရမည့် အပူ၊ flow နှစ်ခုနှင့် ၎င်းတို့၏ အပူချိန်များ၊ pressure နှင့် ပစ္စည်းကို ယူသည်; core ကို မည်မျှကြီးရမည်နှင့် နံရံ မည်မျှထူရမည်ကို တွက်ပြီး တည်ဆောက်ကာ အသုံးပြုခဲ့သော နံပါတ်များနှင့် ၎င်းတို့ ဘယ်ကရလာသည်ကို ပြောပြသည်။ Input တစ်ခုပြောင်းလျှင် အစိတ်အပိုင်းက လိုက်ပြောင်းသည်။

ရလဒ်သည် အစိတ်အပိုင်းအတွင်းရှိ ပုံမှန် body တစ်ခု ဖြစ်သည်: feature စာရင်းတွင် ရှိပြီး ပုံနှိပ်နိုင်သည်၊ export လုပ်နိုင်သည်။ Generator ကိုယ်တိုင်ကိုလည်း အစိတ်အပိုင်းတွင် သိမ်းထားသဖြင့် generator မတပ်ဆင်ထားသော ကွန်ပျူတာတိုင်းတွင်လည်း ဖိုင်ကို ဖွင့်နိုင်ပြီး **အစိတ်အပိုင်းကို ဖွင့်ခြင်းသည် script ကို ဘယ်တော့မှ မလုပ်ဆောင်ပါ**။

## Body တစ်ခု ပြုလုပ်ခြင်း

1. Workspace ပြောင်းသည့်နေရာတွင် {{ui:Engineer}} workspace ကို ရွေးပါ။
2. စာရင်းမှ generator တစ်ခုကို ရွေးပါ (PartCraft နှင့်အတူ ပါလာသည်များ၊ ထို့နောက် ဖိုင်မှ ဖွင့်ခဲ့သည့် မည်သည့် generator မဆို) ပြီး {{ui:New}} ကို နှိပ်ပါ။
3. Script က လုပ်ဆောင်သည်။ ပြီးသောအခါ body သည် မြင်ကွင်းတွင် ရှိပြီး panel က ၎င်း၏ input များ၊ **data sheet** နှင့် **စစ်ဆေးချက်များ** ကို ပြသည်။

Design မှလည်း ထည့်နိုင်သည်: {{ui:Features}} › {{ui:More}} › {{ui:Generated body}}။

## ပြောင်းခြင်း

Input မည်သည့်တစ်ခုကို ပြောင်းလဲလျှင် ရိုက်ခြင်းရပ်ပြီး ခဏအကြာတွင် body ကို ပြန်ဖန်တီးသည်။ Panel က သုံးခုအနက် မည်သည်မှန်သလဲ ပြောသည်:

- **Up to date**: body သည် script နှင့် ၎င်း၏ input များနှင့် ကိုက်ညီသည်။
- **The inputs changed**: အစိတ်အပိုင်းရှိ body သည် အရင် input များမှ ဖြစ်သည်; ယခု ပြန်ဖန်တီးနေသည်၊ သို့မဟုတ် {{ui:Run}} ကို နှိပ်ပါ။
- **Not run yet** သို့မဟုတ် **The last run failed**: script အမှားကို ၎င်း၏ လိုင်းနှင့်အတူ ပြသည်။

{{ui:Stop}} သည် အချိန်ကြာနေသော run ကို ရပ်စေသည်။ Undo သည် အဆင့်တစ်ဆင့်ချင်းစီ ပြန်သွားသည်: run တစ်ခုသည် အဆင့်တစ်ခု ဖြစ်ပြီး input တစ်ခုလည်း အဆင့်တစ်ခု ဖြစ်သည်။

## Data sheet

Generator က တွက်ချက်ထားသော နံပါတ်တိုင်းကို ၎င်း၏ **ယူနစ်** နှင့် **ဘယ်ကရလာသလဲ** (စာအုပ် ပုံသေနည်း၊ စံနှုန်း၊ data sheet) ဖြင့် စာရင်းပြုစုသည်။ ဝှက်ထားသော ကိန်းသေ မရှိပါ။ Sheet သည် ဖိုင်၏ အစိတ်အပိုင်းဖြစ်သဖြင့် နောက်ကွန်ပျူတာတွင်လည်း တူညီသည်။ [Data out](topic:data-out) တွင် JSON သို့မဟုတ် PDF အဖြစ် သိမ်းနည်းကို ပြောသည်။

## စစ်ဆေးချက်များ

Generator သည် ၎င်း၏ အစိတ်အပိုင်းကို ပုံနှိပ်ခြင်း process တစ်ခုနှင့် စစ်ဆေးနိုင်သည်: process ကိုင်ထားနိုင်သည်ထက် ပါးသော နံရံနှင့် ကွာလပ်များ၊ လွတ်နေသော အပိုင်းများ၊ အမှုန့် သို့မဟုတ် resin ကို ဖမ်းထားသော ပိုင်းခွက်များ၊ ရှင်းရန် ကျဉ်းလွန်းသော အပေါက်များ၊ နှင့် ထောက်ပံ့မှု လိုအပ်သော overhang များ။ တွေ့ရှိချက်များကို panel တွင်နှင့် **ပြဿနာများ** စာရင်း (⚠ ခလုတ်) တွင် ပြသပြီး အစိတ်အပိုင်းနှင့်အတူ သိမ်းထားသည်။

Process ကိန်းဂဏန်းများသည် ပုံမှန် process များ (FDM၊ SLA၊ SLS၊ metal powder bed) အတွက် အများသုံး design guide များက ပေးထားသော ဂဏန်း အပြောအဆိုများ ဖြစ်သည်။ ၎င်းတို့သည် **သင့်စက်၏ spec မဟုတ်ပါ**: စစ်ဆေးချက်ကို မှီခိုမည်ဆိုလျှင် သင့်ဆိုင်၏ ကိန်းဂဏန်းဖြင့် အစားထိုးပါ။ စစ်ဆေးချက်သည် voxel grid ပေါ်တွင် အလုပ်လုပ်သဖြင့် voxel တစ်ခုခန့်အထိသာ တိကျသည်: နံရံတစ်ခုကို ကန့်သတ်ချက်ထက် voxel တစ်ခုထက်ပို ပါးမှသာ အစီရင်ခံသည်။

## ပါဝင်သည်များ

| Generator | ဖန်တီးသည့်အရာ |
|---|---|
| Gyroid block | Gyroid၊ Schwarz P သို့မဟုတ် diamond sheet ဖြင့် ဖြည့်ထားသော block: အရိုးရှင်းဆုံး lattice |
| Gyroid heat exchanger | Fluid နှစ်မျိုး exchanger ၏ core၊ duty မှ effectiveness-NTU နည်းဖြင့် အရွယ်သတ်မှတ်ထား၊ နံရံကို pressure မှ; cell တစ်ခုပေါ်တွင် flow study ဖြင့် pressure drop ကို စစ်နိုင်သည် |
| Distribution manifold | Header နှင့် branch များ၊ tube တစ်ခုစီကို ၎င်းသယ်သော flow မှ အရွယ်သတ်မှတ်ထား |
| Graded lattice beam | Topology optimisation က material လိုအပ်သည်ဟု ပြသော နေရာတွင် နံရံ ထူလာသော lattice |

ဤအရာအားလုံးသည် စာအုပ် ပုံသေနည်းများအပေါ် အခြေခံသော ပထမ ခန့်မှန်းချက်များ ဖြစ်သည်။ [The engineering library](topic:engineering-library) တွင် ပုံသေနည်းများနှင့် ၎င်းတို့၏ ကန့်သတ်ချက်များကို ကြည့်ပါ။ ရလဒ်ကို မှီခိုမီ Simulation၊ Thermal သို့မဟုတ် Flow ကို လုပ်ဆောင်ပါ။

## ပို့ကုန် ထိန်းချုပ်မှုများ

Engineer ၏ generator များနှင့် data sheet များတွင် ပို့ကုန်ထိန်းချုပ်မှုနှင့် အရေးယူပိတ်ဆို့မှု အသိပေးချက် ပါဝင်သည်။ [Engineer နှင့် ပို့ကုန် ထိန်းချုပ်မှုများ](topic:engineer-export-notice) တွင် ဖတ်ပါ; data sheet တိုင်း၏ အောက်ခြေတွင်လည်း ရှိသည်။

## မပြုလုပ်ရသေးသည်များ

- Heat exchanger core ပေါ်ရှိ header၊ port နှင့် fitting များ- core သာလျှင် ဖြစ်သည်။
- Material ခွန်အားအတွက် အပူချိန် ကွေးများ- ပစ္စည်းများသည် အခန်းအပူချိန်တွင်သာ ရှိသည်။
- Manifold ရှိ tee ဆုံးရှုံးမှုနှင့် outlet များကြား flow ခွဲဝေမှု။
- Add-on directory မှ generator များကို တစ်ချက်နှိပ်ဖြင့် ထည့်ခြင်း; ဖိုင်ဖွင့်လျှင် ဤ browser သို့ တစ်ခု ထည့်သည်။
- အခြား အက်ပ်များအတွက် generator များ။
