ဤကိရိယာများသည် ဖွင့်ထားသော sketch တွင် အလုပ်လုပ်သည်။ {{ui:Spline}} နှင့် {{ui:Trim}} တို့သည် toolbar တွင် ရှိသည်။ အခြားများသည် sketch ကိရိယာများ အဆုံးရှိ {{ui:နောက်ထပ်}} အောက်တွင် ရှိသည်။ ကိရိယာတစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်ပြီး {{key:Esc}} ဖြင့် ရပ်နိုင်သည်။ အခြေခံ ပုံဆွဲကိရိယာများအတွက် [ပထမဆုံး sketch ကို ဆွဲခြင်း](topic:sketch-basics) ကို ကြည့်ပါ။

## Spline များ

spline သည် ချောမွေ့သော curve ဖြစ်သည်။ အမျိုးအစား နှစ်မျိုး ရှိသည်။

| ကိရိယာ | ကီး | ဆွဲနည်း |
|---|---|---|
| {{ui:Spline}} | {{key:B}} | curve ဖြတ်သွားမည့် အမှတ်များကို နှိပ်ပါ။ {{key:Enter}}၊ {{key:Esc}}၊ ညာကလစ် သို့မဟုတ် နှစ်ချက်ကလစ်ဖြင့် အဆုံးသတ်ပါ။ spline ပိတ်ရန် ပထမအမှတ်ကို ထပ်နှိပ်ပါ |
| {{ui:Control-point spline}} ({{ui:နောက်ထပ်}} အောက်တွင်) | | control point များကို နှိပ်ပါ။ curve သည် ၎င်းတို့ဆီသို့ ဆွဲယူသော်လည်း ပထမနှင့် နောက်ဆုံးအမှတ်ကိုသာ ထိသည်။ dashed control polygon ကို ဆွဲနေစဉ်နှင့် ပြီးနောက်တွင် ပြသည် |

- **အမှတ်များသည် sketch အမှတ်များ ဖြစ်သည်။** ၎င်းတို့ကို ဆွဲရွှေ့နိုင်သည်၊ သို့မဟုတ် အခြားအမှတ်တစ်ခုကဲ့သို့ relation နှင့် အတိုင်းအတာ ပေးနိုင်သည်။ spline ၏ ပထမအမှတ်သည် မျဉ်း၏ အဆုံးသို့ snap လုပ်နိုင်ပြီး ထပ်တူကျ relation ဖြင့် ချိတ်ဆက်သည်။
- **အဆုံးတွင် tangent။** spline ၏ အဆုံးတစ်ခုနှင့် တွေ့သော မျဉ်း၊ အဝိုင်းကွေး သို့မဟုတ် spline ကို ရွေးပြီး spline ကိုလည်း ရွေးကာ {{ui:T ထိတွေ့}} ကို ရွေးပါ။ ထို့နောက် spline ၏ အဆုံးဦးတည်ချက်သည် မျဉ်းကို လိုက်သည်။ spline အဆုံးများမှ ဝေးသော tangent ကို ငြင်းပယ်သည်- "spline နှင့် tangent လုပ်ရန် မျဉ်း၊ အဝိုင်းကွေး သို့မဟုတ် spline သည် ၎င်း၏ အဆုံးတစ်ခုနှင့် တွေ့ရမည်။"
- **အဆုံးများ။** tangent relation မရှိလျှင် fit-point spline ၏ အဆုံးများသည် သဘာဝဖြစ်သည် (အဆုံးတွင် ကွေးညွှတ်မှု မရှိ)။ curve သည် cubic ဖြစ်ပြီး အမှတ်တိုင်းကို ဖြတ်သွားသည်၊ အကွာအဝေးကို အမှတ်များကြား အကွာအဝေးက သတ်မှတ်သည်။
- **ပိတ်ထားသော spline များ** သည် ကိုယ်ပိုင် profile ဖြစ်စေသည်။ ဖွင့်ထားသော spline များသည် မျဉ်းနှင့် အဝိုင်းကွေးများကို တခြား curve များကဲ့သို့ ပိတ်ထားသော loop သို့ ချိတ်ဆက်သည်။
- spline အတွင်းရှိ အမှတ်ကို ဖျက်လျှင် ထိုအမှတ်ကို ဖယ်ရှားပြီး spline ကို ထိန်းထားသည်၊ အမှတ်အနည်းဆုံး နှစ်ခု (ပိတ်ထားလျှင် သုံးခု) ရှိနေသရွေ့။

Extrude နှင့် revolve သည် spline ကို mesh kernel ဖြင့် တိုတောင်းသော မျဉ်းတုံးများမှ တည်ဆောက်သည် (အမှန်တကယ် curve များအတွက် exact kernel လိုအပ်သည်- ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ)။ DXF export သည် spline ကို curve မှ 0.01 mm အတွင်း ကျန်နေသော polyline အဖြစ် ရေးသည်၊ အကြောင်းမှာ DXF R12 တွင် spline entity မရှိပါ။

## Trim နှင့် extend

| ကိရိယာ | ကီး | နည်း |
|---|---|---|
| {{ui:Trim}} | {{key:T}} | curve ပေါ်တွင် မှတ်ပါ- ဖယ်ရှားမည့် အပိုင်းသည် အနီရောင် ပြ၊ အနီးဆုံး ဖြတ်ကျော်မှုအထိ။ ဖယ်ရှားရန် နှိပ်ပါ။ မည်သည့်အရာကိုမျှ မဖြတ်သော curve ကို တစ်ခုလုံး ဖယ်ရှားသည် |
| {{ui:Extend}} ({{ui:နောက်ထပ်}} အောက်တွင်) | {{key:E}} | အဆုံးနား၏ မျဉ်း သို့မဟုတ် အဝိုင်းကွေးကို နှိပ်ပါ။ တွေ့သော နောက် curve အထိ ကြီးထွားသည်။ ထိုအဆုံး ရောက်ရန် ဘာမျှ မရှိသည့်အခါ "ထိုအဆုံးက ရောက်ရန် ဘာမျှ မရှိပါ။" |

Trim နှင့် Extend သည် မျဉ်း၊ အဝိုင်းကွေး၊ စက်ဝိုင်းနှင့် spline များတွင် အလုပ်လုပ်သည် (Extend- မျဉ်းနှင့် အဝိုင်းကွေးသာ)။

- trim လုပ်ထားသော **စက်ဝိုင်း** သည် အဝိုင်းကွေး ဖြစ်လာသည်။ ၎င်း၏ radius သို့မဟုတ် အချင်း အတိုင်းအတာသည် အဝိုင်းကွေးသို့ ပြောင်းသွားသည်။
- မျဉ်း၏ အလယ်ကို trim လုပ်လျှင် တူညီသော မျဉ်းဖြောင့်ပေါ်တွင် ရှိနေသော မျဉ်းနှစ်ကြောင်း ကျန်သည်။ အဝိုင်းကွေး၏ အလယ်ကို trim လုပ်လျှင် ဗဟိုတူပြီး ညီမျှ relation ရှိသော အဝိုင်းကွေးနှစ်ခု ကျန်သည်။
- trim လုပ်ထားသော **spline** သည် မူလ curve ကို တိကျစွာ လိုက်သော control-point spline ဖြစ်လာသည်။ ထိန်းထားသော အဆုံးတွင် tangent relation ကျန်နေသည်။
- အဆုံးအသစ်ကို ၎င်းကို ဖြတ်သော curve ပေါ်တွင် ထားသည် (မျဉ်း၊ အဝိုင်းကွေး သို့မဟုတ် စက်ဝိုင်းပေါ်၊ သို့မဟုတ် ၎င်း၏ အဆုံးနှင့် ထပ်တူကျ)။ spline များသည် အမှတ်ကို မထိန်းနိုင်သဖြင့် ဖြတ်သော spline သည် relation မထည့်ပါ။

**မကိုက်ညီတော့သော relation များကို ဖယ်ရှားသည်**၊ ဘယ်နှစ်ခု ဖယ်ရှားခဲ့သည်ကို status bar တွင် ပြသည်။ ဥပမာ trim လုပ်ထားသော မျဉ်းပေါ်ရှိ အရှည် အတိုင်းအတာကို ဖယ်ရှားသော်လည်း အလျားလိုက် သို့မဟုတ် အပြိုင် relation များသည် ကျန်နေသည်။

## Offset

1. {{ui:နောက်ထပ်}} အောက်ရှိ {{ui:Offset}} ကို ရွေးပါ သို့မဟုတ် {{key:O}} ကို နှိပ်ပါ။
2. မျဉ်း၊ အဝိုင်းကွေး၊ စက်ဝိုင်း သို့မဟုတ် spline ကို နှိပ်ပါ။ ၎င်း၏ chain တစ်ခုလုံး မီးမောင်းပြသည်- အဆုံးချင်း ချိတ်ဆက်ထားသော curve အားလုံး၊ သုံးခု သို့မဟုတ် ထို့ထက်ပို တွေ့သော အမှတ်အထိ။ chain ၏ အစိတ်အပိုင်းကိုသာ offset လုပ်လိုလျှင် ထို curve များကို အရင် ရွေးပြီး၊ ထို့နောက် Offset ကို ရွေးကာ ၎င်းတို့မှ တစ်ခုကို နှိပ်ပါ။
3. မိတ္တူသွားမည့် ဘက်သို့ pointer ကို ရွှေ့ပါ။ dashed preview လိုက်ပါလာသည်။ နှစ်ဖက်စလုံးအတွက် {{key:B}} ကို နှိပ်ပါ။
4. နှိပ်ပါ၊ အကွာအဝေးကို ရိုက်ထည့်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

မျဉ်းနှင့် အဝိုင်းကွေးများကို တိကျစွာ offset လုပ်သည်။ ထောင့်များကို တွေ့သည်အထိ ရှည်စေ သို့မဟုတ် trim လုပ်သည်။ မိတ္တူတွင် **Offset** အတိုင်းအတာ တစ်ခု ရှိပြီး အခြားအပိုင်းများက လိုက်သည်- မိတ္တူတစ်ခုလုံးကို ပြောင်းလိုလျှင် အတိုင်းအတာကို နှစ်ချက်ကလစ်ပါ။ chain အတွက် အကွာအဝေး ကြီးလွန်းလျှင် ငြင်းပယ်သည်၊ ဥပမာ "ဤ chain အတွက် ဤအကွာအဝေး ကြီးလွန်းသည်- ဘက်တစ်ဖက်သည် အတွင်းဘက်သို့ ပြောင်းပြန် ဖြစ်သွားမည်။"

**spline** ကို အမှန်တကယ် offset ၏ 0.001 mm အတွင်းရှိ fit-point spline အသစ်ဖြင့် offset လုပ်သည်။ ဤမိတ္တူသည် ပုံသေ ဖြစ်သည်- နောက်ပိုင်း ပြောင်းလဲမှုများကို မလိုက်ပါ၊ Offset အတိုင်းအတာ လည်း မရှိပါ။ chain တွင် spline သည် အဆုံးများတွင် ချောမွေ့သော (tangent) ချိတ်ဆက်မှု လိုအပ်သည်။

## မှန်ထင်ပြ

1. ရွေးရန် ဖြင့် မှန်ထင်ပြမည့်အရာကို ရွေးပါ။
2. {{ui:နောက်ထပ်}} အောက်ရှိ {{ui:မှန်ထင်ပြ}} ကို ရွေးပါ သို့မဟုတ် {{key:M}} ကို နှိပ်ပါ။
3. မှန်ထင်ပြမည့် မျဉ်း သို့မဟုတ် ဗဟိုမျဉ်းကို နှိပ်ပါ။

မှန်ထင်ပြသော အမှတ်တိုင်းသည် မူလနှင့် **ပုံထင်** relation ရရှိသဖြင့် မူလပြောင်းလဲသည့်အခါ မိတ္တူလိုက်ပြောင်းသည်။ မှန်ထင်ပြမည့် မျဉ်းပေါ်ရှိ အမှတ်များကို မျှဝေသည်၊ မှန်ထင်ပြသော စက်ဝိုင်းများသည် ညီမျှ relation ရရှိသည်။ ဘာမျှ မရွေးထားလျှင် မှန်ထင်ပြမည့် အရာများကို နှိပ်ပါ၊ {{key:Enter}} ကို နှိပ်ပါ၊ ထို့နောက် မှန်ထင်ပြမည့် မျဉ်းကို နှိပ်ပါ။

## Polygon နှင့် slot များ

| ကိရိယာ | နည်း |

## Sketch pattern များ

ဂျီသြမေတြီကို အရင်ရွေးပြီး-

- {{ui:Linear pattern}}- စတင်အမှတ်ကို နှိပ်ပါ၊ ထို့နောက် ပထမမိတ္တူ သွားမည့်နေရာ၊ ထို့နောက် မိတ္တူအရေအတွက် (မူလအပါအဝင်) ကို ရိုက်ထည့်ပါ။
- {{ui:Circular pattern}}- ဗဟိုကို နှိပ်ပါ၊ ထို့နောက် မိတ္တူအရေအတွက်ကို ရိုက်ထည့်ပါ၊ လုံးဝ ပတ်ပတ်လည် ညီညီညာညာ ခွဲဝေမည်။

မိတ္တူများသည် ရွေးထားသော ဂျီသြမေတြီအကြား relation များကို ယူဆောင်လာသည် (circular pattern တွင် အလျားလိုက်နှင့် ဒေါင်လိုက် relation များကို ချန်လှပ်သည်)။ မိတ္တူများသည် မူလနှင့် ချိတ်ဆက်မထားပါ- တစ်ခုကို ပြောင်းလျှင် အခြားများသည် မူလအတိုင်း ကျန်နေသည်။

## အစိတ်အပိုင်း၏ edge များကို project လုပ်ခြင်း

1. {{ui:နောက်ထပ်}} အောက်ရှိ {{ui:Project edge}} ကို ရွေးပါ။
2. sketch နောက်ကွယ်ရှိ အစိတ်အပိုင်း၏ ဖြောင့် သို့မဟုတ် စက်ဝိုင်းပုံ edge ကို နှိပ်ပါ။

edge ကို sketch plane ပေါ်သို့ တိကျစွာ ကူးပြီး ပုံသေ (Fix relation) ဖြစ်စေသည်။ အစိတ်အပိုင်းတွင် နောက်ပိုင်း ပြောင်းလဲမှုများကို မလိုက်ပါ။ ၎င်းကို construction ဂျီသြမေတြီ ပြုလုပ်ရန် {{key:Q}} ကို နှိပ်ပါ။ sketch plane သို့ စောင်းနေသော စက်ဝိုင်းကို ellipse အဖြစ် project လုပ်မည်ဖြစ်သဖြင့် ငြင်းပယ်သည်။ အလွတ်ပုံစံ edge များနှင့် sketch မှ တည့်တည့်ထွက်နေသော edge များလည်း ငြင်းပယ်သည်။ Project လုပ်ရန် exact kernel လိုအပ်သည်- ဤဗားရှင်းတွင် မတည်ဆောက်ရသေးပါ။
