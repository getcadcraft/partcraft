PartCraft သည် အသုံးများသော စက်ပိုင်းဆိုင်ရာ အစိတ်အပိုင်းများကို အသင့်ဖွင့်ပေးသည်- အတိုင်းအတာများသည် စံများ၏ table များမှ လာပြီး table ရှိ အရွယ်အစားတိုင်းသည် သင်ပြောင်းနိုင်သော configuration တစ်ခု ဖြစ်သည်။

## တစ်ခု ဖွင့်ခြင်း

1. File အုပ်စုရှိ {{ui:စံသတ်မှတ်ပစ္စည်း}} ကို နှိပ်ပါ။
2. {{ui:အစိတ်အပိုင်း}} တွင် အမျိုးအစားကို ရွေးပါ၊ ဥပမာ Hex head screw (ISO 4017)။
3. {{ui:အရွယ်အစား}} တွင် အရွယ်အစားကို ရွေးပါ၊ ဥပမာ `M10 × 40`။
4. {{ui:ဖွင့်ရန်}} ကို နှိပ်ပါ။

အစိတ်အပိုင်းသည် သိမ်းမထားသော အစိတ်အပိုင်းအသစ်အဖြစ် ဖွင့်သည်။ ထိန်းထားရန် သိမ်းပါ ({{key:Mod+S}})။

| အစိတ်အပိုင်း | စံ | ပါရာမီတာများ |
|---|---|---|
| Hex head screw၊ hex bolt | ISO 4017၊ ISO 4014၊ ASME B18.2.1 (inch) | `d` thread အရွယ်အစား၊ `s` across flats၊ `k` ခေါင်းအမြင့်၊ `l` အရှည် |
| Hex nut | ISO 4032၊ ASME B18.2.2 (inch) | `d`၊ `s`၊ `height` |
| Plain washer | ISO 7089 | `d1` အတွင်း၊ `d2` အပြင်၊ `h` အထူ |
| Parallel pin | ISO 2338 | `d`၊ `l` |
| Deep groove ball bearing | ISO 15 | `d` bore၊ `D` အပြင်၊ `B` အကျယ် |
| Parallel key | DIN 6885-1၊ form A | `b` အကျယ်၊ `h` အမြင့်၊ `l` အရှည် |

## အရွယ်အစား ပြောင်းခြင်း

အရွယ်အစားတိုင်းသည် configuration တစ်ခု ဖြစ်သည် ([Configuration များနှင့် design table များ](topic:design-tables) ကို ကြည့်ပါ): {{ui:ပါရာမီတာများ}} ကို ဖွင့်ပြီး တစ်ခုခု ရွေးပါ၊ သို့မဟုတ် ပါရာမီတာတစ်ခုကို ပြောင်းပါ၊ ဥပမာ screw ရှည်လိုလျှင် `l`၊ ထို့နောက် ကိုယ်ပိုင် configuration အဖြစ် သိမ်းပါ။

## ပုံဖော်ထားသည်များ

- Screw နှင့် bolt များ: ခြောက်ထောင့်ခေါင်းနှင့် ရိုးရှင်းသော ရိုး။ Nut များ: thread ၏ နာမည်ခေါ် အရွယ်အစားရှိသော အပေါက်ပါ ခြောက်ထောင့်။ Thread များကို ပုံဖော်ထားခြင်း မရှိပါ; လိုအပ်လျှင် {{ui:Thread}} ဖြင့် ထည့်ပါ ([Thread များ](topic:threads) ကို ကြည့်ပါ)။
- Pin များ: ရိုးရှင်းသော ဘောင်ပုံ; အဆုံး chamfer များကို ချန်ထားသည်။
- Bearing များ: အပြင်ဘက် envelope သာ (bore ring၊ အပြင် အချင်းနှင့် အကျယ်)၊ တစ်ခုကို နေရာချရန် လိုအပ်သည်။
- Key များ: စွန်းဝိုင်းသော key။

အစိတ်အပိုင်း၏ ပစ္စည်းသည် သံမဏိ ဖြစ်သဖြင့် mass panel က ၎င်း၏ အလေးချိန်ကို ပြသည်။ ဂီယာများ ယခုမရှိသေးပါ: PartCraft တွင် သွားဖန်းဖီချာ မရှိပါ၊ ဒစ်သည် ဂီယာ မဟုတ်ပါ။ CadCraft သည် ဂီယာကို ဆွဲသည့် စည်းမျဉ်းဖြင့် ဆွဲပြီး စာကြည့်တိုက်တွင် ၎င်းတို့ကို ပုံဆွဲများအဖြစ် ရှိသည်။
