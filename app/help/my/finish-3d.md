Manufacture ရှိ လုပ်ဆောင်ချက် နှစ်ခုသည် ကိရိယာကို ဒေါင်လိုက် (axis သုံးခု) ထားပြီး **မော်ဒယ်၏ မျက်နှာပြင်တစ်ခုလုံး** ကို ဖြတ်သည်။ ရွေးချယ်မှု မလိုပါ: အပေါ်မှ မြင်နိုင်သော မော်ဒယ်အားလုံးပေါ်တွင် အလုပ်လုပ်သည်။ ဦးစွာ အပိုင်းကို ကြမ်းဖြတ်ပါ (adaptive သို့မဟုတ် pocket); မဖြတ်ရသေးသော stock ပေါ်ရှိ finishing pass က နက်နက် ဖြတ်မည်ဟု သတိပေးသည်။

## Parallel

သတ်မှတ်ထားသော **angle** ဖြင့် မော်ဒယ်တစ်လျှောက် ဖြောင့်မျဉ်းများ၊ **stepover** ခြားသည် (ကိရိယာအချင်း၏ အစိတ်အပိုင်း)။ မျဉ်းတစ်ခုစီသည် မျက်နှာပြင်ကို လိုက်သည်: cutter ၏ အစိတ်အပိုင်း တစ်စိတ်တစ်ပိုင်းမျှ မော်ဒယ်အောက် မရောက်စေရန် tool tip သည် လိုအပ်သလောက် မြင့်သည်၊ မျက်နှာပြင် ကွေးသည့်နေရာတိုင်း မျဉ်းကို ပိုသေးစွာ ဖြတ်သည်။ **Zig-zag** ဖွင့်လျှင် ဘေးကင်းစွာ လုပ်နိုင်သည့်နေရာတွင် မျဉ်းများကြား tool သည် ဆက်နိမ့်ထားသည် (ရွေ့ခြင်းတလျှောက် စစ်ဆေးသည်); မဟုတ်လျှင် မြင့်တက်သည်။

- **Tolerance**: ဖြောင့်သော မျဉ်း အပိုင်းတစ်ခုသည် tool tip အမြင့် မှန်ကန်သော တန်ဖိုးမှ ဘယ်လောက် ဝေးနိုင်သည် (ထိုတစ်ဝက်ကို အပိုင်းတစ်ခု၏ အလယ်တွင် ကန့်သတ်အဖြစ် သုံးသည်)။ မူလ 0.01 mm။
- **Only where the surface is at least … and at most … (°)**: ပြားသော နေရာများ သို့မဟုတ် ထက်စောက်သော နေရာများကိုသာ ဖြတ်သည်။ မျက်နှာပြင်သည် အကွာအဝေးပြင်ပတွင် ရှိလျှင် မျဉ်းကို ချန်ထားပြီး tool မြင့်တက်သည်။
- **Stock to leave**: မော်ဒယ်ကို ထိုအကွာအဝေးဖြင့် offset လုပ်သည် (cutter ကို ထိုမျှ ကြီးစေသည်: ball နှင့် bull-nose ကိရိယာများအတွက် တိကျသည်; flat ကိရိယာသည် အနည်းဆုံး ထိုမျှ ကျန်သည်)။
- **Bottom**: ဤ z ထက်နိမ့်၍ ဘာမျှ မဖြတ်ပါ။

## Scallop

မျက်နှာပြင်ပေါ် တစ်ခုနှင့်တစ်ခု အကွာအဝေး ကိုယ်ဖြင့် ကိုက်ညီသော pass များဖြစ်ပြီး၊ ကပ်လျက် pass နှစ်ခုကြား ကျန်သော အတောင် (scallop) သည် သင်တောင်းဆိုသော **အမြင့်** ရှိသည်။ အကွာအဝေးသည် အမြင့်နှင့် ball ၏ radius မှ ရလာသည်: s = 2·√(2·R·h − h²)၊ ဥပမာ Ø6 ball နှင့် 0.02 mm အတောင်အတွက် pass များကြား 0.69 mm ခန့်။ bull-nose ကိရိယာသည် ၎င်း၏ ထောင့် radius ကို သုံးသည်။ flat end mill ကို ငြင်းသည်: အရွယ်သတ်မှတ်စရာ အတောင် မရှိပါ။

pass များသည် **မော်ဒယ်၏ အစွန်းမှ၊ အတွင်းသို့** သို့မဟုတ် **၎င်း၏ အပေါ်မှ၊ အောက်သို့** စတင်သည်။ ၎င်းတို့သည် မျက်နှာပြင်ပေါ် အကွာအဝေး၏ contour များ ဖြစ်သည် (အမြင့်မဟုတ်)၊ ထို့ကြောင့် စောင်းသည့်နေရာတွင် plan ပေါ် နီးပြီး ပြားသည့်နေရာတွင် ကျယ်ကျယ်ခွာခွာ ရှိသည်။ အကွာအဝေးကို မျက်နှာပြင်ပေါ် grid တွင် တိုင်းပြီး ၁% ခန့် တိကျသည်; အတောင်အမြင့်သည် မျက်နှာပြင် ပြားသော သို့မဟုတ် နူးညံ့စွာ ကွေးသော နေရာတွင် တိကျပြီး အမြန် ကွေးသော နေရာတွင် ခန့်မှန်းသည်။ **Climb** က မျက်နှာပြင်၏ မြင့်သော ဘက်ကို cutter ၏ ညာဘက်တွင် ထားသည်။

## လမ်းကြောင်းများ ကောင်းမွန်ပုံ

စမ်းသပ်ချက်များက စစ်သည်များ၊ ပိတ်ထားသော ပုံသေနည်းများ သို့မဟုတ် cutter ၏ footprint ကို သီးခြား brute-force ရှာဖွေမှုဖြင့်-

- tool အောက်ရှိ tip အမြင့်သည် mesh ၏ မျက်နှာ၊ အစွန်းနှင့် ထောင့်များပေါ် ball၊ bull-nose နှင့် flat ကိရိယာအတွက် တိကျပြီး အမှန် အမြင့်ထက် ဘယ်တော့မှ မကျော်; parallel မျဉ်းများအတွက် လမ်းကြောင်းသည် tolerance အတွင်း ရှိပြီး ထိုထက် နက်သော gouge မရှိ။
- စောင်းသော plane ပေါ် လမ်းကြောင်း အရှည်များသည် ပိတ်ထားသော ပုံသေနည်းနှင့် ကိုက်ညီသည်; plane ပေါ် scallop pass များသည် တောင်းဆိုထားသော အကွာအဝေးတွင် ရှိပြီး ၎င်းတို့ကြား အတောင်သည် တောင်းဆိုထားသော အမြင့်ဖြင့် ထွက်သည်။
- stock simulation သည် pass နောက်တွင် gouge မပြပြီး ကျန်ရှိသော အတောင်များကို ပြသည်။

ဤလမ်းကြောင်းများ မဟုတ်သည်များ: ၎င်းတို့သည် အခြေခံ finishing pass များသာ ဖြစ်ပြီး ထုတ်လုပ်ရေးစနစ်က ပေးသည့် အားလုံး မဟုတ်ပါ။

- မတည်ဆောက်ရသေး: waterline (constant z)၊ pencil နှင့် corner clean-up၊ radial နှင့် spiral pass များ၊ curve ကို မျက်နှာပြင်ပေါ် ပရိုဂျက်ခြင်း၊ flat-area ရှာဖွေခြင်း၊ rest machining၊ holder နှင့် shank collision စစ်ဆေးခြင်း၊ ကိရိယာ ထောင့်စောင်းခြင်း။
- ကိရိယာ၏ ဗဟိုသည် မော်ဒယ်အပေါ်တွင် ရှိနေသည်: လမ်းကြောင်းများသည် မော်ဒယ်အစွန်းတွင် ရပ်ပြီး ကျော်မသွား၊ ထို့ကြောင့် အစွန်းနားရှိ ဒေါင်လိုက် နံရံကို ခြေရင်းအထိ မပြီးပါ။
- Undercut များကို မမြင်ပါ (မျက်နှာပြင်သည် အပေါ်မှ ကိရိယာ တွေ့သည့်အရာသာ)။
- မော်ဒယ်သည် kernel မှ mesh ဖြစ်သဖြင့် လမ်းကြောင်းများသည် mesh ကို လိုက်သည် (chord tolerance သည် အပိုင်း၏ diagonal ၏ 0.0002 ခန့်)၊ တိကျသော မျက်နှာပြင်ကို မလိုက်ပါ။
- ကြီးသော မော်ဒယ်ကို သေးသော tolerance ဖြင့် finishing လုပ်ခြင်းသည် တိုတောင်းသော ရွေ့ခြင်း အများအပြား ပါသော ရှည်သော program ဖြစ်စေသည်။ ဖြတ်မီ သင့်စက်၏ ကိုယ်ပိုင် simulator တွင် output ကို စစ်ဆေးပါ။
