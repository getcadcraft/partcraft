Python — трэцяя мова [працоўнай вобласці «Скрыпт»](topic:craftscript). Выберыце **Python** у полі мовы над рэдактарам (файл `.py` адкрываецца на Python сам). Python, Lua і CraftScript выкарыстоўваюць адны і тыя ж пераменныя і адны і тыя ж убудаваныя функцыі, таму скрыпт на Python можа выкарыстоўваць тое, што стварыў скрыпт CraftScript, і наадварот.

Першы запуск Python за візіт загружае сам Python (CPython 3.14, каля 7 МБ) з гэтага сайта, што займае некалькі секунд. Python пакуль не ўваходзіць у {{ui:Захаваць для працы па-за сеткай}}: спачатку запусціце адзін скрыпт на Python, будучы анлайн.

## Python ізаляваны

Скрыпты на Python ізаляваныя, як скрыпты CraftScript і Lua: яны маюць доступ да дэталі, пераменных і ўбудаваных функцый і больш ні да чаго. Кожны запуск — гэта новы Python ў уласнай пясочніцы з невялікім файлавым дрэвам у памяці (яго стандартная бібліятэка і папка `/tmp`, якая знікае пасля запуску). Ён не можа звярнуцца да сеткі, вашых файлаў або астатняй старонкі — ні ў браўзеры, ні ў каманднам радку. Чужы скрыпт усё яшчэ можа займаць шмат часу або памяці: {{ui:Спыніць}} завяршае яго.

## Асновы

```
A = cs.magic(3)              # кожная ўбудаваная функцыя — cs.<імя>
B = A @ A.T                  # @ — матрычны здабытак, .T — транспанаванне
C = A * 2 + 1                # + - * / ** паэлементна, як у numpy
print(A[0, 1], A[-1, -1])    # з 0; адмоўныя лічацца з канца
row = A[1]                   # адзін індэкс у матрыцы: радок
big = A[A > 4]               # лагічная маска выбірае элементы
A[0, 0] = -5                 # запіс у масіў
V, D = cs.call('eig', 2, A)  # некалькі вынікаў: cs.call(імя, колькі, …)
```

- Масіў 1 × 1 прыходзіць як звычайны лік; іншыя масівы, разраджаныя матрыцы, сеткі, палі і мадэлі — гэта **значэнні**.
- Значэнне мае `shape` (кортэж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (яго радкі), а таксама `float()`, `int()` і `bool()` для аднаго элемента.
- Параўнанні (`<`, `==`, …) паэлементныя, як у numpy: яны даюць лагічнае значэнне.
- Спісы лікаў, перададзеныя ўбудаванай функцыі, становяцца масівамі: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` стварае матрыцу.
- Слоўнік становіцца структурай, а спіс рознатыпавых элементаў — вочкай, і назад.

Кожная глабальная пераменная скрыпта (лік, значэнне, слоўнік, спіс…) трапляе ў укладку **Пераменныя** пры завяршэнні запуску, нават пасля памылкі. Імёны, што пачынаюцца з `_`, функцыі, класы і модулі застаюцца ў Python. `ws.name` чытае або задае пераменную напрамую, а `ws_names()` пералічвае іх.

`print(…)` выводзіць у кансоль. `display(…)` (або `cs.display`) паказвае сетку, поле або графік, як у CraftScript.

## Выклік бібліятэкі аналізу

Функцыі бібліятэкі выклікаюцца, як убудаваныя: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Пішыце імя ў скрыпце так, як яно ёсць: PartCraft знаходзіць функцыі бібліятэкі, якія выкарыстоўвае скрыпт, перад яго запускам.

## Пакуль не даступна

- numpy, scipy і іншыя пакеты: тут ёсць толькі стандартная бібліятэка Python (`math`, `json`, `itertools`, `decimal`, `statistics`…), без яе частак для вокнаў, тэрмінала і базы дадзеных (`tkinter`, `curses`, `sqlite3`).
- Сокеты і ўсё, што выйшла б за межы: тут у Python няма сеткі.
- `time.sleep` вяртаецца адразу.
- Згортванне ў рэдактары і выклік функцыі Python са скрыпта CraftScript.
- Запуск правярае ліміт інструкцый і {{ui:Спыніць}} кожныя 1000 радкоў; доўгі разлік унутры адной убудаванай функцыі скончыцца першым.
