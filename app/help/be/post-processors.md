Адна і тая ж траекторыя павінна запісвацца па-рознаму для розных станкоў: з нумарамі радкоў або без, `M6` або паўза, `G28` або `G53`, `M30` або `M2`. **Пост** — гэта кароткі тэкст, які гэта вызначае. Тры ўбудаваныя пасты PartCraft (у стылі Fanuc, GRBL і LinuxCNC) напісаны ў гэтым фармаце, таму ўласны пост можа пачынацца як копія аднаго з іх.

Праверце вывад у сімулятары вашага станка перад рэзаннем і спачатку прагоніце яго ў паветры над загатоўкай. Убудаваныя пасты запісваюць тое самае, што запісвалі да з’яўлення гэтага фармату (тэсты параўноўваюць іх вывад байт у байт на сотнях праграм), але нічога тут не даказана на вашым станку. Пост, які вы змянілі, — гэта ваш пост, і даказваць яго прыдзецца вам.

## Стварыць пост

У Вытворчасці, у блоку **Post**:

- {{ui:Рэдагаваць пост…}} на ўбудаваным станку адкрывае **вашу ўласную копію** яго. На вашым уласным посце адкрываецца гэты пост.
- {{ui:Новы пост…}} пачынае з невялікага пустога поста з усімі падзеямі.
- {{ui:Імпартаваць файл поста…}} чытае тэкставы файл `.cpost` (той, які вы атрымліваеце праз **Захаваць як файл…** у рэдактары).

Рэдактар паказвае тэкст, радок, які кажа, ці чытаецца ён (і які радок няправільны), і G-код, які пішацца пры наборы. **Прагляд з** выбірае невялікую ўзорную праграму, якая праходзіць усе падзеі, або праграму гэтай дэталі. {{ui:Захаваць}} захоўвае пост у файле дэталі (да 20 пастаў) і выбірае яго як станок. Пасты ідуць разам з дэталлю; каб выкарыстаць адзін у іншай дэталі, захавайце яго як файл і імпартуйце там.

## Як выглядае пост

```
post mymill
name Мой фрэзерны станок (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Праграма {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

Радкі, якія пачынаюцца з `//`, і пустыя радкі ігнаруюцца. Спачатку ідуць налады; потым адзін блок `on <падзея>` для кожнай падзеі, закрыты `end`. Падзея, якую вы прапусцілі, нічога не запісвае.

| Налада | Значэнне |
|---|---|
| `post <id>` | Ідэнтыфікатар поста: літары, лічбы, `-` і `_` |
| `name <text>` | Тое, што паказвае спіс станкоў |
| `extension <ext>` | Пашырэнне файла: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … у кожным радку `emit`, або нічога |
| `decimal-point yes` / `no` | `10.` замест `10` (у каментарыях кропка ніколі не ставіцца) |
| `canned-cycles yes` / `no` | `no`: адтуліны запісваюцца як рухі G0/G1, якія яны прадстаўляюць |
| `modal <group> <words>` | Словы групы (`modal motion G0 G1 G2 G3`), якія запісваюцца толькі тады, калі мяняюцца |

## Падзеі

Яны выконваюцца ў такім парадку для праграмы: `start`; затым для кожнай аперацыі `operation`, `tool-change` (калі мяняецца інструмент), `spindle` (калі мяняецца хуткасць), `approach` (рух да першай кропкі, перад першым хуткім ходам), `coolant-on`, затым яго рухі як `rapid`, `feed` і `arc`, і кожны гатовы цыкл як `cycle-start`, адзін `cycle-hole` на кожную адтуліну і `cycle-end`; нарэшце `end`.

Кожная падзея можа выкарыстоўваць пераменныя свайго віду руху, якія пішуцца `{name}`: праграма (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), загатоўка (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), інструмент (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), аперацыя (`op.name`, `op.type`), `rpm`, кропка руху (`x`, `y`, `z`, `f`, і `moved`: true, калі змянілася вось), дугі (`arc.g` 2 або 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) і адтуліны (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Спіс **Падзеі і пераменныя** ў рэдактары паказвае, якая падзея што бачыць. Стан, які можна чытаць і задаваць: `cool`, `offset`, і `at.x`, `at.y`, `at.z`, `at.f` (апошнія запісаныя значэнні).

## Аператары

| Аператар | Што робіць |
|---|---|
| `raw TEXT` | Радок дакладна так, як напісаны (без нумара радка) |
| `comment TEXT` | `(TEXT)` без не-ASCII знакаў і дужак |
| `emit WORD WORD …` | Радок слоў; словы, якія атрымаліся пустымі, прапускаюцца; няма слоў — няма радка |
| `word WORD …` | Дадае словы да радка, які будуецца; голае `emit` завяршае яго |
| `if EXPR` … `else` … `end` | Умовы: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, інакш b) |
| `for tool in tools` … `end` | Адзін раз для кожнага інструмента, які выкарыстоўвае праграма |
| `set NAME EXPR` | Запамінае значэнне (`set offset tool.number`) |
| `reset NAME …` | Забывае мадальныя словы (групу, літару адраса, як `Z`, або `at.z`) |
| `do rapid X Y Z` | Запускае падзею `rapid` для кропкі |

Слова — гэта набраны тэкст з дзіркамі `{variable|filter}`. Фільтры: `upper`, `lower`, `pad:N` (запаўненне нулямі), `cut:N` (першыя N знакаў), `safe` (ASCII, бяспечны для каментарыя) і `int`. Слова, якое заканчваецца на `~`, — **мадальнае**: яно запісваецца толькі тады, калі адрозніваецца ад таго, што было запісана апошнім (`G1~`, `X{x}~`). Слова, якое заканчваецца на `~!`, запісваецца кожны раз і таксама запамінаецца. Назва, якая не з’яўляецца пераменнай, — просты тэкст (`G81`, `mist`). Лікі акругляюцца да 0,001 мм і запісваюцца без канцавых нулёў.

## Чаго пост не можа

Ён вырашае, як пішуцца рухі, і нічога больш. Ён не можа змяніць траекторыю, пераставіць аперацыі, падзяліць дугу, дадаць вось, ведаць ход або кінематыку вашага станка, ці рабіць арыфметыку з каардынатамі (няма `+`). Зандаванне, цыклы стойкасці інструмента і падпраграм, вывад для 4-й і 5-й восі і коды токарнага станка не створаны. Файл поста `.cps` з іншай праграмы загрузіць нельга: гэта іншы, прасцейшы фармат.
