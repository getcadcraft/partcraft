CraftScript — матрычная мова, напісаная так, каб яе можна было чытаць як MATLAB, таму большасць класічных лікавых кодаў (напрыклад, код аптымізацыі тапалогіі ў 88 радкоў) працуюць з невялікімі зменамі. Ён запускаецца ў [працоўнай вобласці «Скрыпт»](topic:craftscript) і з каманднага радка.

## Значэнні

| Тып | Прыклад | Заўвагі |
|---|---|---|
| Лік, масіў | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Кожны лік — масіў (1×1). Масівы захоўваюцца па слупках, да 8 вымярэнняў |
| Лагічны | `A > 2`, `true` | Масівы праўда/хлусня; выкарыстоўваюцца як індэксы |
| Тэкст | `'beam'`, `"beam"` | |
| Разраджаная матрыца | `sparse(i, j, v, n, n)` | Для матрыц жорсткасці |
| Сетка, поле, мадэль | `hexGrid(…)`, `part()`, `load('part.stl')` | Тое, што малюе `show` |
| Структура | `s.E = 210e3` | Названыя палі |
| Вочка | `c = {1, 'two', [3 4]}` | Спіс любых значэнняў |
| Дэскрыптар функцыі | `f = @(x) x.^2` | |

## Масівы і індэксацыя

- Дыяпазоны: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Індэксацыя пачынаецца з 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (уесь слупок), `A(:)` (усё як адзін слупок), `v(v > 0)` (лагічная індэксацыя).
- Прысваенне за межамі масіва яго павялічвае, як у MATLAB: `v(10) = 1`.

## Аператары

- `+ - * / \ ^` — матрычныя аперацыі (`A \ b` вырашае); `.* ./ .^` працуюць паэлементна. `'` транспануе.
- Параўнанні `== ~= < <= > >=`; логіка `& | ~` (паэлементна) і `&& ||` (з кароткім замыканнем).

## Кіраванне патокам і функцыі

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функцыі змяшчаюцца ў скрыпце пасля яго каманд або ва ўласнай укладцы скрыпта, названай па функцыі:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Імя шукаецца ў такім парадку: пераменная, скрыпт у гэтай дэталі з такім імем, функцыя бібліятэкі, убудаваная функцыя.

## Рэха (echo), каментарыі, вывад

- Аператар без `;` выводзіць сваё значэнне; `;` робіць яго ціхім.
- `%` пачынае каментарый; `%{` і `%}` на асобных радках закамэнтоўваюць радкі паміж імі.
- `disp(x)`, `fprintf('%g\n', x)` і `display(x)` выводзяць у кансоль.

## Памылкі і абмежаванні

- Памылкі простымі словамі кажуць, што пайшло не так, і даюць радок (і ланцужок выклікаў функцый).
- Кожны запуск мае ліміт кроўў (параметры запуску на панэлі); бясконцы цыкл спыняецца з паведамленнем або пры націску {{ui:Спыніць}}.
- Кожны масіў змяшчае да 134 мільёнаў значэнняў.

## Не як у MATLAB

- Каманды пабудовы графікаў змяшчаюць свае параметры ў выкліку: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` і падобныя прымаюцца, але нічога не робяць.
- `input` і `keyboard` не падтрымліваюцца: скрыпт не можа спыніцца і задаць пытанне.
- Тулбаксаў няма; ёсць толькі [бібліятэка аналізу](topic:craftscript-library) і ўбудаваныя функцыі.
