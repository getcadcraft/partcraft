Генератар — гэта звычайны скрыпт ([CraftScript](topic:craftscript), Lua або Python) з некалькімі радкамі каментарыяў уверсе. PartCraft чытае каментарыі і стварае форму; ваш скрыпт чытае ўваходныя параметры як ужо зададзеныя пераменныя.

## Загаловак

Запішыце іх у радках каментарыяў (`%` у CraftScript, `--` у Lua, `#` у Python):

```
% @generator Цеплаабменнік
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Масавы расход"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Паверхня"
% @input solid: = true
% @input note: = "тэкст"
```

Уваходны параметр — гэта `name: unit = default`, потым, па жаданні, дыяпазон `[min .. max]` (лічбы трымаюцца ўнутры яго), спіс варыянтаў `{a, b, c}` і подпіс у лапках. Адзінка вымярэння — толькі подпіс для формы: **значэнне прыходзіць у гэтай адзінцы**, таму скрыпт, які патрабуе SI, канвертуе яго, і `to_si(value, 'kg/s', 'kg/s')` таксама правярае, ці адпавядае адзінка таму, што вы маеце на ўвазе. Імя складаецца з літар, лічбаў і знака падкрэслівання; `body`, `sheet` і `problems` ужо заняты.

## Што пакідае скрыпт

| Пераменная | Што гэта |
|---|---|
| `body` | **Абавязковая.** Паверхневая сетка, звычайна з `[body, info] = to_body(field, h)`. Яна выпраўляецца і правяраецца па завяршэнні запуску. |
| `sheet` | Неабавязковая. Структура: кожнае поле — лік або тэкст, альбо структура з `value`, `unit`, `ref` і `note`. Яна становіцца табліцай даных. |
| `problems` | Неабавязковая. Ячэйка `problems` з `mfg_check(field, 'sls', struct(), h)` або вашыя ўласныя запісы. Яны перадаюцца ў праверкі і ў спіс праблем. |

## Поўны просты прыклад

```
% Пусты куб са сценкай.
% @generator Пусты куб
% @input side: mm = 12 [4 .. 40] "Бок"
% @input wall: mm = 1.5 [0.5 .. 5] "Сценка"
% @input h: mm = 0.5 [0.25 .. 2] "Памер вокселя"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'of the mesh');
```

Ён стварае замкнёны куб, і праверка паведамляе пра яго запячатаны ўнутраны бок як памылку для парашковага працэсу. Робіце памер вокселя `h` не больш за траціну самай тонкай сценкі, якую вы хочаце: пры менш чым каля трох вокселяў сценка не надзейная.

## Палі

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (цела вярчэння з профілю), `tpms` (паверхні gyroid, Schwarz P і diamond, з памерам ячэйкі і сценкай, якія могуць мяняцца па ўсёй дэталі), `lattice` і `lattice_beams`, `along` (круглы канал уздоўж шляху), булевы аперацыі `field_union`, `field_intersect`, `field_subtract`, гладкае `field_blend`, а таксама `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` вяртае адлегласць са знакам у кропках (адмоўная ўнутры), `field_voxel` дае вокселі для рашальнікаў. [Палі](topic:fields) тлумачыць, што яны сабой уяўляюць.

Варта ведаць пра абмежаванні: сценка лісту таўшчынёй больш за каля чвэрці ячэйкі зачыняе каналы; элемент тонкі менш за каля трох вокселяў можа сціснуцца; `along` злучае круглыя конусы, таму радыус, які хутка мяняецца, дае выпукласць (для профілю выкарыстоўвайце `field_revolve`).

## Адкрыйце скрыпт як генератар

У працоўнай прасторы {{ui:Engineer}} націсніце {{ui:Open}} і выберыце файл. Скрыпт без радка `@generator` або `@input` не прымаецца: тады не было б чаго задаваць. Генератар захоўваецца ў гэтым браўзеры (да 20), і {{ui:Remove}} яго выдаляе. Корпус, пачаты з яго, мае копію скрыпта, таму дэталь не залежыць ад генератара.

Файл таксама можа змяшчаць некалькі генератараў: набор JSON `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
