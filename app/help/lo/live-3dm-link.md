ສືບຕໍ່ປັ້ນໂມເດວໃນບ່ອນທີ່ທ່ານສ້າງມັນ, ແລະ ເຮັດການຜະລິດ, ກວດສອບ ແລະ ບັນທຶກເອກະສານຢູ່ທີ່ນີ້. ທຸກການປ່ຽນແປງໃນໂປຣແກຣມອື່ນຈະແທນທີ່ຕົວທີ່ນຳເຂົ້າໜຶ່ງຕົວໃນ PartCraft, ແລະ ຟີເຈີທີ່ຢູ່ຫຼັງມັນຈະຖືກສ້າງຄືນໃໝ່ເທິງຮູບຮ່າງໃໝ່.

:::note
ການເຊື່ອມຕໍ່ຕ້ອງການ **CadCraft Studio** ຢູ່ໃນຄອມພິວເຕີເຄື່ອງດຽວກັນ. ແທັບບຣາວເຊີບໍ່ສາມາດເຊື່ອມຕໍ່ໄດ້. ບໍ່ມີຫຍັງຖືກສົ່ງຜ່ານອິນເຕີເນັດ: script ຕິດຕໍ່ກັບ Studio ທີ່ທີ່ຢູ່ຂອງຄອມພິວເຕີເຄື່ອງນີ້ເອງ, ດ້ວຍ token.
:::

:::warning
ການເຊື່ອມຕໍ່ນີ້ໄດ້ຖືກທົດສອບກັບ file writer ຂອງ script ແລະ ໂປຣແກຣມທົດແທນອີກຕົວໜຶ່ງ, ຍັງບໍ່ໄດ້ທົດສອບພາຍໃນ Rhino ຫຼື Grasshopper ເອງ. ຖ້າມີຫຍັງຜິດພາດຢູ່ບ່ອນນັ້ນ, ກະລຸນາບອກພວກເຮົາວ່າມັນບອກຫຍັງ.
:::

## ຕັ້ງຄ່າ

1. ໃນ Studio, ເປີດ PartCraft. ໃນ {{ui:Settings}} › {{ui:PartCraft}} › {{ui:Assistants}}, ໃຫ້ໝາຍ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະ scripts ໃຊ້ PartCraft**, ແລ້ວ **Edit**.
2. ໃນ Studio, ເລືອກ {{ui:ເຊື່ອມຕໍ່ຜູ້ຊ່ວຍ}}. ມັນຈະສະແດງທີ່ຢູ່ ແລະ token ທີ່ທ່ານຈະວາງລົງຂ້າງລຸ່ມ.
3. ດາວໂຫຼດ script: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## ຈາກ Rhino

1. ແລ່ນ `cadcraft_link.py` ໃນ script editor ຂອງ Rhino (Python 3 ໃນ Rhino 8).
2. ຄັ້ງທຳອິດ, ວາງທີ່ຢູ່ ແລະ token. ມັນຈະຖືກເກັບໄວ້ໃນ `.cadcraft-link.json` ໃນໂຟນເດີ home ຂອງທ່ານ, ບໍ່ເຄີຍຢູ່ໃນໂມເດວ. Studio ສ້າງ token ໃໝ່ທຸກຄັ້ງທີ່ມັນເລີ່ມ, ດັ່ງນັ້ນ script ຈະຖາມໃໝ່ຕອນນັ້ນ.

ແລ່ນ script ອີກຄັ້ງເພື່ອຢຸດ.

## ຈາກ Grasshopper

ແລ່ນ script ໜຶ່ງຄັ້ງໃນ Rhino ກ່ອນ, ເພື່ອໃຫ້ທີ່ຢູ່ ແລະ token ຖືກບັນທຶກ.

1. ເພີ່ມ component Script (Python 3) ແລ້ວວາງ `cadcraft_link.py` ທັງໝົດໃສ່ມັນ.
2. ໃຫ້ມັນ input ເຫຼົ່ານີ້: `G` (ເລຂາຄະນິດ, ດ້ວຍ list access), `N` (ຊື່, ບໍ່ບັງຄັບ), `On` (boolean toggle), ແລະ `Target` (ບໍ່ບັງຄັບ: `model` ຫຼື `part`, ຖ້າທັງສອງແອັບເປີດຢູ່).
3. ຕັ້ງ `On` ເປັນ true.

ທຸກການ solve ຈະສົ່ງ `G` ໄປ ແລະ ແທນທີ່ສິ່ງທີ່ component ສົ່ງຄັ້ງກ່ອນ.

## ມັນເຮັດວຽກແນວໃດທີ່ນີ້

- **ໜຶ່ງຕົວ.** ທຸກຢ່າງທີ່ເຫັນໄດ້ໃນໂມເດວກາຍເປັນຟີເຈີນຳເຂົ້າໜຶ່ງອັນ, ຄືກັບເວລາທ່ານ [ເປີດໄຟລ໌ .3dm](topic:open-3dm-files).
- **ມັນຕ້ອງປິດ.** PartCraft ຕື່ມຮູນ້ອຍ ແລະ ຊ່ອງເປີດແບນທີ່ແບນ, ແລະ ໂປຣແກຣມອື່ນຈະຖືກບອກວ່າມີຈັກອັນ. ຖ້າໂມເດວຍັງບໍ່ປິດ, PartCraft ຈະຮັກສາຕົວທີ່ມີຢູ່ເດີມ ແລະ ແຖບສະຖານະຈະບອກ. ການປ່ຽນແປງຄັ້ງຕໍ່ໄປທີ່ປິດໄດ້ຈະອັບເດດມັນ.
- **ສຳເລັດສິ່ງທີ່ທ່ານກຳລັງເຮັດກ່ອນ.** ໃນພາບຮ່າງ ຫຼື ແບບແຕ້ມ, ການອັບເດດຈະຖືກປະຕິເສດ ແລະ ລອງໃໝ່; ມັນຈະມາເຖິງເມື່ອທ່ານກັບຄືນສູ່ໂມເດວ.
- **ຍ້ອນກັບ.** ການອັບເດດພາຍໃນສອງວິນາທີຂອງກັນແລະກັນຈະໃຊ້ຂັ້ນຕອນຍ້ອນກັບດຽວກັນ.
- **ບັນທຶກ.** ໄຟລ໌ຊິ້ນສ່ວນຈະເກັບການເຊື່ອມຕໍ່ໄວ້. ແລ່ນ script ອີກຄັ້ງຫຼັງຈາກທ່ານເປີດມັນໃໝ່, ແລະ ຟີເຈີດຽວກັນຈະອັບເດດ.

**ທິດທາງດຽວ.** ການປ່ຽນແປງທີ່ນີ້ຈະບໍ່ກັບໄປຫາໂປຣແກຣມອື່ນ.

## ຖ້າມີບາງຢ່າງຜິດພາດ

- **"ບໍ່ມີໜ້າຕ່າງ ModelCraft ຫຼື PartCraft ອະນຸຍາດ":** ເຮັດຂັ້ນຕອນທີ 1 ຂອງການຕັ້ງຄ່າ.
- **"Studio ປະຕິເສດ token":** Studio ໄດ້ຣີສະຕາດ. ໃຫ້ຄັດລອກ token ໃໝ່ ແລ້ວແລ່ນ script ອີກຄັ້ງ. ສຳລັບ Grasshopper, ໃຫ້ແລ່ນມັນໃນ Rhino ກ່ອນ.
- **"ບໍ່ສາມາດເຂົ້າເຖິງ CadCraft Studio":** Studio ບໍ່ໄດ້ເຮັດວຽກ, ຫຼື ທີ່ຢູ່ໄດ້ປ່ຽນແລ້ວ.
