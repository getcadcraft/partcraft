**ຄອນຟິກ** ແມ່ນຂະໜາດໜຶ່ງຂອງຊິ້ນສ່ວນ: ຊຸດຄ່າທີ່ມີຊື່ສຳລັບພາລາມິເຕີຂອງມັນ. ຊິ້ນສ່ວນເກັບຄອນຟິກຂອງມັນໄວ້ໃນໄຟລ໌ຂອງມັນເອງ, ດັ່ງນັ້ນພວກມັນເດີນທາງໄປກັບມັນ. **ຕາຕະລາງອອກແບບ** ແມ່ນສິ່ງດຽວກັນໃນຮູບແບບໄຟລ໌ CSV, ໜຶ່ງແຖວຕໍ່ຄອນຟິກ.

ຄອນຟິກກຳນົດ **ພາລາມິເຕີ**, ດັ່ງນັ້ນເພີ່ມພວກມັນກ່ອນ (ເບິ່ງ [ຂັບເຄື່ອນຊິ້ນສ່ວນດ້ວຍພາລາມິເຕີ](topic:parameters)). ຄອນຟິກເກັບພາລາມິເຕີທີ່ເປັນຕົວເລກທຳມະດາ; ພາລາມິເຕີທີ່ຄຳນວນຈາກອັນອື່ນ (ເຊັ່ນ `area = w * d`) ຈະເຮັດຕາມເອງ.

## ບັນທຶກຄອນຟິກ

1. ໃນແທັບ {{ui:Parameters}}, ຕັ້ງພາລາມິເຕີສຳລັບຂະໜາດໜຶ່ງຂອງຊິ້ນສ່ວນ.
2. ພາຍໃຕ້ **ຄອນຟິກ**, ພິມຊື່ (ຕົວຢ່າງ `ໃຫຍ່`) ແລ້ວກົດ {{ui:Save current values}} ຫຼື {{key:Enter}}.

ຄອນຟິກໃໝ່ຈະຖືກໝາຍວ່າ **ໃຊ້ງານ** ຢູ່. ຖ້າທ່ານປ່ຽນພາລາມິເຕີພາຍຫຼັງ ມັນຈະບອກວ່າ **ໃຊ້ງານ, ປ່ຽນແປງຕັ້ງແຕ່**, ເພື່ອໃຫ້ທ່ານຮູ້ວ່າຊິ້ນສ່ວນບໍ່ກົງກັບມັນອີກແລ້ວ.

## ສະຫຼັບ, ອັບເດດ, ປ່ຽນຊື່, ລຶບ

- {{ui:Apply}} ຕັ້ງພາລາມິເຕີໃຫ້ເປັນຄ່າຂອງຄອນຟິກນັ້ນ ແລະ ສ້າງຊິ້ນສ່ວນຄືນໃໝ່.
- {{ui:Update}} ບັນທຶກຄ່າປັດຈຸບັນລົງໃນຄອນຟິກນັ້ນ.
- ເພື່ອປ່ຽນຊື່ໜຶ່ງ, ພິມຊື່ໃໝ່ໃນກ່ອງຂອງມັນ ແລ້ວກົດ {{key:Enter}}.
- {{ui:Delete}} ເອົາຄອນຟິກອອກ. ພາລາມິເຕີຍັງຮັກສາຄ່າຂອງມັນໄວ້.

ແຕ່ລະອັນນີ້ເປັນຂັ້ນຕອນດຽວ: {{key:Mod+Z}} ຈະກັບຄືນ. ຖ້າທ່ານປ່ຽນຊື່ພາລາມິເຕີ, ທຸກຄອນຟິກຈະຕາມຊື່ໃໝ່; ຖ້າທ່ານລຶບອັນໜຶ່ງ, ມັນຈະຫຼຸດອອກຈາກພວກມັນ.

## ເປີດ ແລະ ປິດຟີເຈີໃນຄອນຟິກ

ຄອນຟິກຍັງເກັບວ່າຟີເຈີໃດຖືກປິດ, ດັ່ງນັ້ນຊິ້ນສ່ວນໜຶ່ງສາມາດມີຮຸ່ນ **ທີ່ມີ** ແລະ **ທີ່ບໍ່ມີ** ບາງສິ່ງ: ຮູຕິດຕັ້ງ, ການຕັດມຸມ, ແທ່ນຍື່ນ.

1. ປິດຟີເຈີ: ຄລິກມັນໃນປະຫວັດ, ແລ້ວກົດ {{ui:Suppress}} ໃນ {{ui:Properties}}.
2. ບັນທຶກຄອນຟິກຕາມປົກກະຕິ, ຕົວຢ່າງ `ບໍ່ມີຮູ`. ແຖວຂອງມັນລາຍຊື່ສິ່ງທີ່ມັນປິດ.
3. ເປີດຟີເຈີຄືນ ({{ui:Unsuppress}}) ແລ້ວບັນທຶກຄອນຟິກອີກອັນ, ຕົວຢ່າງ `ມີຮູ`.

ເມື່ອຄອນຟິກໃດໜຶ່ງປິດຟີເຈີ, ການນຳໃຊ້ຄອນຟິກຈະປິດຟີເຈີຂອງມັນ ແລະ **ເປີດທຸກຟີເຈີອື່ນ**, ພ້ອມກັບຄ່າພາລາມິເຕີຂອງມັນ, ໃນຂັ້ນຕອນດຽວ. ຄອນຟິກທີ່ບັນທຶກກ່ອນທີ່ຈະມີການປິດຟີເຈີໃນອັນໃດກໍຕາມ ນັບວ່າ "ທຸກຢ່າງເປີດ". **ອັບເດດ** ບັນທຶກຟີເຈີຕາມທີ່ມັນເປັນຢູ່ດຽວນີ້, ພ້ອມຄ່າ.

ຊິ້ນສ່ວນທີ່ຄອນຟິກຂອງມັນປິດຟີເຈີຖືກບັນທຶກເປັນເວີຊັນໄຟລ໌ໃໝ່ກວ່າ: PartCraft ລຸ້ນເກົ່າຈະບອກວ່າໄຟລ໌ມາຈາກເວີຊັນໃໝ່ກວ່າ ແທນທີ່ຈະເປີດມັນໂດຍບໍ່ມີຟີເຈີເຫຼົ່ານັ້ນ.

:::note
ຕາຕະລາງອອກແບບ CSV ມີພຽງຄ່າພາລາມິເຕີ. ການນຳເຂົ້າຕາຕະລາງທັບໃສ່ຄອນຟິກຈະປ່ຽນຄ່າຂອງມັນ ແລະ ຮັກສາຟີເຈີທີ່ມັນປິດໄວ້; ຕົວເລືອກ `--table` ຂອງເສັ້ນຄຳສັ່ງສ້າງພຽງຄ່າເທົ່ານັ້ນ.
:::

ໄຟລ໌ຊິ້ນສ່ວນຖືກບັນທຶກພ້ອມຄອນຟິກ ແລະ ອັນທີ່ກຳລັງໃຊ້ງານຢູ່. ຊິ້ນສ່ວນເປີດດ້ວຍຄ່າທີ່ມັນຖືກບັນທຶກດ້ວຍ.

## ນຳຕາຕະລາງອອກແບບເຂົ້າ ຫຼື ອອກ

ຕາຕະລາງອອກແບບແມ່ນໄຟລ໌ CSV ທີ່ມີຖັນໜຶ່ງສຳລັບພາລາມິເຕີແຕ່ລະອັນ ແລະ ແຖວໜຶ່ງສຳລັບຄອນຟິກແຕ່ລະອັນ:

```
name,width,thick,bolt
small,100,6,6.6
medium,140,8,8.5
large,200,12,13
```

ຖັນທຳອິດອາດຊື່ `name`, `config` ຫຼື `configuration`; ຖັນອື່ນທັງໝົດຕ້ອງເປັນຊື່ຂອງພາລາມິເຕີຂອງຊິ້ນສ່ວນ. ຊ່ອງເປັນຕົວເລກ, ພ້ອມຫົວໜ່ວຍຖ້າທ່ານຕ້ອງການ (`8in`). ຊ່ອງທີ່ຫວ່າງຈະບໍ່ໃສ່ພາລາມິເຕີນັ້ນໃນແຖວ.

- {{ui:Import CSV}} ເພີ່ມແຕ່ລະແຖວເປັນຄອນຟິກ. ແຖວທີ່ມີຊື່ຂອງຄອນຟິກທີ່ມີຢູ່ແລ້ວຈະແທນທີ່ມັນ. ການນຳເຂົ້າເປັນຂັ້ນຕອນດຽວ.
- {{ui:Export CSV}} ຂຽນຄອນຟິກອອກ. ຖ້າຍັງບໍ່ມີ, ມັນຂຽນໜຶ່ງແຖວຂອງຄ່າປັດຈຸບັນ, ເປັນຈຸດເລີ່ມຕົ້ນສຳລັບສເປຣດຊີດ.

ຊື່ຄອນຟິກທີ່ສເປຣດຊີດຈະອ່ານເປັນສູດ (ເລີ່ມດ້ວຍ `=`, `+`, `-` ຫຼື `@`) ຈະຖືກຂຽນດ້ວຍ `'` ນຳໜ້າ.

## ທຸກຂະໜາດພ້ອມກັນ

{{ui:Variant pack…}} ພາຍໃຕ້ **ຄອນຟິກ** ສ້າງທຸກຄອນຟິກ, ຫຼື ບາງອັນທີ່ເລືອກໄວ້, ເປັນ STEP, IFC, DWG ແລະ ຕົວຢ່າງໃນ zip ດຽວ, ພ້ອມຕາຕະລາງພາລາມິເຕີຂອງມັນ: ເບິ່ງ [ສ້າງຊຸດຕົວແປຈາກຄອນຟິກຂອງທ່ານ](topic:variant-pack).

ເຄື່ອງມືເສັ້ນຄຳສັ່ງສ້າງໄຟລ໌ໜຶ່ງອັນຕໍ່ແຖວຂອງຕາຕະລາງອອກແບບ CSV:

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

ສົ່ງອອກຄອນຟິກເປັນ CSV ກ່ອນ, ແລ້ວສົ່ງໄຟລ໌ນັ້ນດ້ວຍ `--table`. ເບິ່ງ [ສະຄຣິບ ແລະ ເສັ້ນຄຳສັ່ງ](topic:scripts-and-cli). ຊິ້ນສ່ວນທີ່ບັນທຶກເປັນສະຄຣິບຈະເກັບຄອນຟິກຂອງມັນໄວ້ໃນແຖວ `configs json …`.
