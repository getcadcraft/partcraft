Python ແມ່ນພາສາທີ່ສາມຂອງ [ພື້ນທີ່ສະຄຣິບ](topic:craftscript). ເລືອກ **Python** ໃນກ່ອງພາສາເທິງຕົວແກ້ໄຂ (ໄຟລ໌ `.py` ຈະເປີດເປັນ Python ເອງ). Python, Lua ແລະ CraftScript ໃຊ້ຕົວແປ ແລະ ຟັງຊັນທີ່ມີມາໃນຕົວຮ່ວມກັນ, ດັ່ງນັ້ນສະຄຣິບ Python ສາມາດໃຊ້ສິ່ງທີ່ສະຄຣິບ CraftScript ສ້າງໄວ້, ແລະ ກັບກັນກໍໄດ້.

ການຮັນ Python ຄັ້ງທຳອິດໃນການເຂົ້າໃຊ້ໜຶ່ງຄັ້ງຈະໂຫຼດ Python ເອງ (CPython 3.14, ປະມານ 7 MB) ຈາກເວັບໄຊນີ້, ເຊິ່ງໃຊ້ເວລາຫຼາຍວິນາທີ. Python ຍັງບໍ່ແມ່ນສ່ວນໜຶ່ງຂອງ {{ui:Save for offline}}: ໃຫ້ຮັນສະຄຣິບ Python ໜຶ່ງອັນໃນຂະນະອອນໄລນ໌ກ່ອນ.

## Python ຖືກຈຳກັດ

ສະຄຣິບ Python ຖືກຈຳກັດເຊັ່ນດຽວກັນກັບສະຄຣິບ CraftScript ແລະ Lua: ພວກມັນເຂົ້າເຖິງຊິ້ນສ່ວນ, ຕົວແປ ແລະ ຟັງຊັນທີ່ມີມາໃນຕົວ, ແລະ ບໍ່ມີຫຍັງອື່ນ. ແຕ່ລະການຮັນເປັນ Python ໃໝ່ໃນກ່ອງຊາຍຂອງຕົນເອງ ພ້ອມກັບຕົ້ນໄມ້ໄຟລ໌ນ້ອຍໆໃນໜ່ວຍຄວາມຈຳ (ໄລບຣາຣີມາດຕະຖານຂອງມັນ ແລະ ໂຟນເດີ `/tmp` ທີ່ຫາຍໄປເມື່ອການຮັນຈົບ). ມັນບໍ່ສາມາດເຂົ້າເຖິງເຄືອຂ່າຍ, ໄຟລ໌ຂອງທ່ານ ຫຼື ສ່ວນອື່ນຂອງໜ້າເວັບ, ທັງໃນບຣາວເຊີ ແລະ ໃນເສັ້ນຄຳສັ່ງ. ສະຄຣິບຈາກຄົນອື່ນຍັງສາມາດໃຊ້ເວລາ ຫຼື ໜ່ວຍຄວາມຈຳຫຼາຍ: {{ui:Stop}} ຢຸດມັນ.

## ພື້ນຖານ

```
A = cs.magic(3)              # ທຸກຟັງຊັນທີ່ມີມາໃນຕົວແມ່ນ cs.<ຊື່>
B = A @ A.T                  # @ ແມ່ນຜົນຄູນເມທຣິກ, .T ແມ່ນການປ່ຽນຖ່າຍ
C = A * 2 + 1                # + - * / ** ເປັນອົງປະກອບໆ, ຄືກັບ numpy
print(A[0, 1], A[-1, -1])    # ເລີ່ມຈາກ 0; ຄ່າລົບນັບຈາກທ້າຍ
row = A[1]                   # ດັດຊະນີດຽວໃນເມທຣິກ: ແຖວໜຶ່ງ
big = A[A > 4]               # ມາສກ໌ເງື່ອນໄຂເລືອກອົງປະກອບ
A[0, 0] = -5                 # ການກຳນົດຄ່າໃສ່ອາເຣ
V, D = cs.call('eig', 2, A)  # ຫຼາຍຜົນ: cs.call(ຊື່, ຈຳນວນ, …)
```

- ອາເຣ 1 × 1 ມາເປັນຕົວເລກທຳມະດາ; ອາເຣອື່ນ, ເມທຣິກກະຈາຍ, ເມຊ, ຟີລ໌ດ ແລະ ໂມເດວ ແມ່ນ **ຄ່າ**.
- ຄ່າມີ `shape` (ທູເພິນ), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (ຈຳນວນແຖວຂອງມັນ), ແລະ `float()`, `int()` ແລະ `bool()` ສຳລັບອົງປະກອບດຽວ.
- ການປຽບທຽບ (`<`, `==`, …) ເປັນອົງປະກອບໆ, ຄືກັບໃນ numpy: ພວກມັນໃຫ້ຄ່າຕາມເງື່ອນໄຂ.
- ລາຍຊື່ຕົວເລກທີ່ສົ່ງໃຫ້ຟັງຊັນທີ່ມີມາໃນຕົວຈະກາຍເປັນອາເຣ: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` ສ້າງເມທຣິກ.
- dict ກາຍເປັນສະຕຣັກ ແລະ ລາຍການຂອງສິ່ງປົນກັນກາຍເປັນເຊວ, ແລະ ກັບກັນໄດ້.

ທຸກຕົວແປທົ່ວໂລກທີ່ສະຄຣິບຂອງທ່ານສ້າງ (ຕົວເລກ, ຄ່າ, dict, list…) ຈະໄປຢູ່ໃນແທັບ **ຕົວແປ** ເມື່ອການຮັນຈົບ, ເຖິງແມ່ນຫຼັງຈາກມີຂໍ້ຜິດພາດ. ຊື່ທີ່ເລີ່ມດ້ວຍ `_`, ຟັງຊັນ, ຄລາດ ແລະ ໂມດູນຈະຢູ່ໃນ Python. `ws.name` ອ່ານ ຫຼື ຕັ້ງຕົວແປໂດຍກົງ, ແລະ `ws_names()` ລາຍຊື່ພວກມັນ.

`print(…)` ພິມໄປທີ່ຄອນໂຊນ. `display(…)` (ຫຼື `cs.display`) ສະແດງເມຊ, ຟີລ໌ດ ຫຼື ແຜນທີ່, ຄືກັບໃນ CraftScript.

## ເອີ້ນຄັງການວິເຄາະ

ຟັງຊັນຂອງຄັງຖືກເອີ້ນຄືກັບຟັງຊັນທີ່ມີມາໃນຕົວ: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. ຂຽນຊື່ໄວ້ໃນສະຄຣິບຕາມທີ່ມັນເປັນ: PartCraft ຄົ້ນພົບຟັງຊັນຄັງທີ່ສະຄຣິບໃຊ້ກ່ອນມັນຮັນ.

## ຍັງບໍ່ມີ

- numpy, scipy ແລະ ແພັກເກັດອື່ນ: ມີພຽງໄລບຣາຣີມາດຕະຖານຂອງ Python ເອງ (`math`, `json`, `itertools`, `decimal`, `statistics`…) ເທົ່ານັ້ນ, ໂດຍບໍ່ມີສ່ວນໜ້າຕ່າງ, ເທີມິນັນ ແລະ ຖານຂໍ້ມູນ (`tkinter`, `curses`, `sqlite3`).
- Socket ແລະ ສິ່ງອື່ນທີ່ຈະເຂົ້າເຖິງພາຍນອກ: Python ບໍ່ມີເຄືອຂ່າຍຢູ່ບ່ອນນີ້.
- `time.sleep` ສົ່ງຄືນທັນທີ.
- ການພັບໃນຕົວແກ້ໄຂ, ແລະ ການເອີ້ນຟັງຊັນ Python ຈາກສະຄຣິບ CraftScript.
- ການຮັນກວດສອບງົບຄຳສັ່ງ ແລະ ປຸ່ມຢຸດທຸກ 1000 ແຖວ; ການຄຳນວນຍາວພາຍໃນຟັງຊັນທີ່ມີມາໃນຕົວໜຶ່ງຈະສິ້ນສຸດກ່ອນ.
