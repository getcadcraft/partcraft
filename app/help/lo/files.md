PartCraft ເຮັດວຽກກັບໄຟລ໌ຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ. ມັນບໍ່ເຄີຍອັບໂຫຼດຊິ້ນສ່ວນ, ແລະບໍ່ມີບັນຊີ ຫຼືບ່ອນເກັບຂໍ້ມູນໃນຄລາວ. ການບັນທຶກຂຶ້ນຄລາວຍັງບໍ່ມີ.

## PartCraft ເປີດຫຍັງໄດ້ແດ່

| ໄຟລ໌ | ນາມສະກຸນ | ວິທີ |
|---|---|---|
| ຊິ້ນສ່ວນ PartCraft | `.partcraft.json` | {{ui:Open}}, {{key:Mod+O}}, ຫຼືລາກມັນໃສ່ມຸມມອງ 3D |
| ການປະກອບ PartCraft | `.partcraft-asm.json` | ເໝືອນກັນ: PartCraft ຮູ້ວ່າມັນເປັນປະເພດໃດ |
| ຕົວທຶບ STEP | `.step`, `.stp` | ຕົວວັດຖຸຕັນທຶບທີ່ອ່ານເປັນສາມຫຼ່ຽມ: [ເປີດໄຟລ໌ STEP ແລ້ວສ້າງຕໍ່ຈາກມັນ](topic:import-step) |

ໄຟລ໌ mesh ຂອງ STL, OBJ ແລະ 3MF ກໍເປີດເປັນຕົວວັດຖຸຕັນທຶບເຊັ່ນກັນ ([ເປີດ STL, OBJ ຫຼື 3MF](topic:open-meshes)), ແລະໄຟລ໌ `.3dm` ກໍເຊັ່ນກັນ ([ເປີດໂມເດວ .3dm](topic:open-3dm-files)). DXF, IGES ແລະໄຟລ໌ຊິ້ນສ່ວນຂອງໂປຣແກຣມອື່ນບໍ່ສາມາດເປີດໄດ້ (ເບິ່ງ [ສິ່ງທີ່ຍັງບໍ່ໄດ້ສ້າງ](topic:not-built-yet)).

ກົດເກນເວລາເປີດ:

- ຊື່ໄຟລ໌ຊິ້ນສ່ວນ ຫຼືການປະກອບຕ້ອງລົງທ້າຍດ້ວຍ `.json`, ແລະໄຟລ໌ຕ້ອງນ້ອຍກວ່າ 50 MB.
- ໄຟລ໌ຖືກກວດກ່ອນທີ່ຈະສະແດງຫຍັງ. ໄຟລ໌ທີ່ເສຍຫາຍ ຫຼືຖືກແກ້ໄຂຈະຖືກປະຕິເສດພ້ອມເຫດຜົນງ່າຍໆ, ຕົວຢ່າງ "ນີ້ບໍ່ແມ່ນໄຟລ໌ PartCraft."
- ໄຟລ໌ທີ່ບັນທຶກໂດຍ PartCraft ໃໝ່ກວ່າຈະຖືກປະຕິເສດ: "ໄຟລ໌ນີ້ຖືກບັນທຶກໂດຍ PartCraft ໃໝ່ກວ່າ (ເວີຊັນໄຟລ໌ 3); ເວີຊັນນີ້ອ່ານເວີຊັນ 2." ໄຟລ໌ເກົ່າເປີດໄດ້.
- ຖ້າຊິ້ນສ່ວນທີ່ຢູ່ໜ້າຈໍມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ, PartCraft ຈະຖາມກ່ອນ: {{ui:Cancel}}, {{ui:Discard changes}} ຫຼື {{ui:Save first}}.

## ການບັນທຶກ

{{ui:Save}} ຫຼື {{key:Mod+S}} ບັນທຶກສິ່ງທີ່ຢູ່ໜ້າຈໍ:

- ສຳລັບຊິ້ນສ່ວນ: `<part name>.partcraft.json`, ປະຫວັດທັງໝົດ (ພາບຮ່າງ, ຄວາມສຳພັນ, ມິຕິ, ຟີເຈີ, ຕຳແໜ່ງ rollback), ສ່ວນ, ລາຍລະອຽດ ແລະໝາຍເຫດ GD&T ຂອງແຜ່ນແບບແຕ້ມ, ແລະຂໍ້ຄວາມເຕັມຂອງຕົວທຶບ STEP ທີ່ນຳເຂົ້າໃນເວີຊັນກ່ອນ. ຟີເຈີທີ່ເວີຊັນນີ້ສ້າງບໍ່ໄດ້ຈະຖືກບັນທຶກກັບຄືນໂດຍບໍ່ປ່ຽນແປງ. ຕົວທຶບເອງບໍ່ໄດ້ຖືກເກັບ; PartCraft ສ້າງມັນຄືນຈາກປະຫວັດເມື່ອໄຟລ໌ເປີດ.
- ໃນການປະກອບ: `<assembly name>.partcraft-asm.json`, ພ້ອມ **ທຸກຊິ້ນສ່ວນຢູ່ພາຍໃນ**. ໄຟລ໌ດຽວເກັບການປະກອບທັງໝົດ, ດັ່ງນັ້ນທ່ານສາມາດສົ່ງມັນໄປໄດ້ດ້ວຍຕົວເອງ.

ການບັນທຶກແມ່ນ **ການດາວໂຫຼດ**. browser ຂອງທ່ານຈະໃສ່ໄຟລ໌ໄວ້ໃນໂຟນເດີດາວໂຫຼດ, ຫຼືຖາມວ່າຈະໃຫ້ໄປໄວ້ໃສ ຖ້າທ່ານຕັ້ງໃຫ້ຖາມ. ການບັນທຶກອີກຄັ້ງຈະສ້າງການດາວໂຫຼດໃໝ່; browser ອາດຕັ້ງຊື່ມັນ `Part1 (1).partcraft.json` ແທນທີ່ຈະແທນອັນເກົ່າ. ປ່ຽນຊື່ ຫຼືຍ້າຍໄຟລ໌ໃນ {{pick:mac=Finder|windows=File Explorer|linux=ໂປຣແກຣມຈັດການໄຟລ໌ຂອງທ່ານ}} ຕາມທີ່ທ່ານຕ້ອງການ.

ຕົວອັກສອນນອກຈາກຕົວໜັງສື, ຕົວເລກ, ຊ່ອງຫວ່າງ, `_`, `.` ແລະ `-` ໃນຊື່ຊິ້ນສ່ວນຈະກາຍເປັນ `_` ໃນຊື່ໄຟລ໌.

:::tip
browser ສ່ວນຫຼາຍມີການຕັ້ງຄ່າໃຫ້ຖາມບ່ອນບັນທຶກຂອງແຕ່ລະການດາວໂຫຼດ. ເປີດມັນໄວ້ຖ້າທ່ານຢາກມີທາງເລືອກ "Save as" ທຸກຄັ້ງ: ໃນ Chrome ແລະ Edge ມັນຢູ່ໃນ Downloads ໃນການຕັ້ງຄ່າ; ໃນ Firefox ຢູ່ໃນ General, Files and Applications; ໃນ Safari ຢູ່ໃນ General, File download location.
:::

ເພື່ອຮູ້ເພີ່ມເຕີມກ່ຽວກັບບ່ອນທີ່ການດາວໂຫຼດໄປ ແລະວິທີຮັກສາໄຟລ໌ໃຫ້ປອດໄພ: [ໄຟລ໌ຂອງທ່ານຢູ່ໃສ](common:your-files).

- ການສົ່ງອອກແມ່ນຂອງຊິ້ນສ່ວນທີ່ຢູ່ໜ້າຈໍ. ການສົ່ງອອກຖືກປິດໃນການປະກອບ; ຍັງບໍ່ມີການສົ່ງອອກການປະກອບ.
- STL, 3MF, STEP ແບບ faceted ແລະ DXF ໜ້າຮາບ ແມ່ນເປັນໜ້າຍ່ອຍສະເໝີ. ການຕັ້ງຄ່າ **Curves** (ໃນແຜງຂວາເມື່ອບໍ່ມີຫຍັງຖືກເລືອກ) ກຳນົດຄວາມລະອຽດຂອງມັນ, ຈາກ 32 ຫາ 256 ໜ້າຍ່ອຍຕໍ່ຮອບ. ເລືອກ Fine ຫຼື Very fine ກ່ອນສົ່ງອອກ STL ຫຼື 3MF ເພື່ອການພິມທີ່ລຽບ.
- ແບບແຕ້ມ PDF ໃຊ້ຟອນ Helvetica ທີ່ມາພ້ອມກັບຕົວອ່ານ. ຕົວອັກສອນທີ່ມັນສະແດງບໍ່ໄດ້ຈະພິມເປັນ "?".

## ວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກ

- PartCraft ເກັບສຳເນົາການກູ້ຄືນຂອງຊິ້ນສ່ວນ ຫຼືການປະກອບທີ່ເປີດຢູ່ໃນ browser ນີ້ບໍ່ດົນຫຼັງຈາກແຕ່ລະການປ່ຽນແປງ, ດັ່ງນັ້ນການຢຸດເຮັດວຽກ ຫຼືການປິດແທັບຈະບໍ່ເຮັດໃຫ້ວຽກຫາຍ: ຄັ້ງຕໍ່ໄປທີ່ທ່ານເປີດ PartCraft ມັນຈະຖາມ "ກູ້ຄືນວຽກຂອງທ່ານບໍ?". ນີ້ບໍ່ແມ່ນການບັນທຶກ: ໃຫ້ບັນທຶກເປັນໄຟລ໌ເພື່ອເກັບວຽກຂອງທ່ານ. ເບິ່ງ [ກູ້ຄືນວຽກທີ່ຍັງບໍ່ໄດ້ບັນທຶກ](common:recover).
- ຖ້າທ່ານພະຍາຍາມປິດແທັບ ຫຼື reload ໂດຍມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ, browser ຈະຖາມ "Leave site?". ນັ້ນແມ່ນກ່ອງຂອງ browser ເອງ; PartCraft ປ່ຽນຂໍ້ຄວາມຂອງມັນບໍ່ໄດ້.
- {{ui:New}}, {{ui:Open}} ແລະການປິດການປະກອບ ຈະຖາມກ່ອນທີ່ຈະຖິ້ມການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ.

## ອອນລາຍ ແລະອອບໄລນ໌

ທຸກຢ່າງເກີດຂຶ້ນໃນຄອມພິວເຕີຂອງທ່ານ: mesh kernel (ໂປຣແກຣມ WebAssembly) ຖືກດາວໂຫຼດພ້ອມແອັບ ແລະສ້າງເລຂາຄະນິດໃນເຄື່ອງ, ແລະໄຟລ໌ຖືກອ່ານ ແລະຂຽນໃສ່ດິສກ໌ຂອງທ່ານ. ບໍ່ມີຂໍ້ມູນຊິ້ນສ່ວນຜ່ານເຄືອຂ່າຍ. ເບິ່ງ [mesh kernel](topic:solid-kernels).

ເພື່ອເຮັດວຽກໂດຍບໍ່ມີການເຊື່ອມຕໍ່ເລີຍ, ໃຫ້ບັນທຶກ PartCraft ສຳລັບການໃຊ້ງານອອບໄລນ໌ ໃນຂະນະທີ່ອອນລາຍ: ເລືອກ {{ui:Save for offline}} ໃນແຖບແອັບ ແລ້ວລໍຖ້າໃນຂະນະທີ່ມັນນັບ ("Saving 40 of 212") ຈົນກວ່າມັນຈະບອກ **Offline ready**. ສຳເນົາທີ່ບັນທຶກປະກອບດ້ວຍຄັງ 3D ແລະ mesh kernel, ດັ່ງນັ້ນຫຼັງຈາກນັ້ນ ການສ້າງແບບ, ການບັນທຶກ, ການສົ່ງອອກທັງໝົດ ແລະແບບແຕ້ມຈະເຮັດວຽກອອບໄລນ໌ໄດ້. ຖ້າມັນບອກ **Could not save**, ໃຫ້ຄລິກມັນເພື່ອລອງໃໝ່ໃນຂະນະອອນລາຍ; **Offline not available** ໝາຍຄວາມວ່າ window browser ນີ້ບໍ່ສາມາດເກັບສຳເນົາໄດ້ (window ສ່ວນຕົວ ແລະຄອມພິວເຕີທີ່ຈັດການບາງເຄື່ອງ). ເມື່ອສຳເນົາຖືກບັນທຶກແລ້ວ, ການຄລິກ **Offline ready** ຈະສະເໜີ {{ui:Save again (get the newest version)}} ແລະ {{ui:Remove the offline copy}}. ລາຍລະອຽດ: [ເຮັດວຽກແບບອອບໄລນ໌](common:offline).

:::online
ທ່ານກຳລັງອອນລາຍ. ເຖິງແມ່ນບໍ່ໄດ້ບັນທຶກສຳລັບການໃຊ້ອອບໄລນ໌, ເມື່ອ PartCraft ໂຫຼດແລ້ວ ແລະຊິບແຖບສະຖານະບອກ "Mesh kernel", ທ່ານຍັງສາມາດເຮັດວຽກຕໍ່ໄດ້ຖ້າການເຊື່ອມຕໍ່ຂາດ. ພຽງແຕ່ຢ່າ reload ໜ້າຈົນກວ່າທ່ານຈະກັບມາອອນລາຍ.
:::

:::offline
ທ່ານກຳລັງອອບໄລນ໌. ຖ້າ PartCraft ເປີດຢູ່ແລ້ວ, ໃຫ້ເຮັດວຽກຕໍ່; ການບັນທຶກ ແລະການສົ່ງອອກຍັງເຮັດວຽກ. ຖ້າແຖບແອັບບອກ **Offline ready**, PartCraft ຈະເປີດຈາກຈຸດເລີ່ມຕົ້ນໄດ້ໂດຍບໍ່ມີການເຊື່ອມຕໍ່ເຊັ່ນກັນ; ຖ້າບໍ່ດັ່ງນັ້ນ ຢ່າ reload ແທັບນີ້.
:::

## ຄວາມແຕກຕ່າງລະຫວ່າງ browser

- **ການດາວໂຫຼດ.** ແຕ່ລະ browser ມີໂຟນເດີດາວໂຫຼດ ແລະວິທີຖາມຂອງຕົນເອງ. ຖ້າ browser ຖາມວ່າເວັບໄຊນີ້ອະນຸຍາດໃຫ້ດາວໂຫຼດໄຟລ໌ບໍ່, ໃຫ້ອະນຸຍາດ, ຖ້າບໍ່ດັ່ງນັ້ນການບັນທຶກ ແລະການສົ່ງອອກຈະເຮັດວຽກບໍ່ໄດ້.
- **ລາກ ແລະວາງ** ໄຟລ໌ໃສ່ມຸມມອງໃຊ້ໄດ້ໃນ Chrome, Edge, Firefox ແລະ Safari.
- **ໄຟລ໌ຈາກໂທລະສັບ ຫຼືແທັບເລັດ.** ໃນ iPhone ແລະ iPad, Open ສະແດງແອັບ Files; ໄຟລ໌ທີ່ບັນທຶກຈະໄປຢູ່ Files, Downloads. ໃນ Android ພວກມັນໄປໂຟນເດີ Downloads.

ບໍ່ມີຄວາມແຕກຕ່າງໃນເນື້ອໃນຂອງໄຟລ໌ລະຫວ່າງ browser ຫຼືລະບົບປະຕິບັດການ.
