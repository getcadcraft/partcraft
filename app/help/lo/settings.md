ເປີດ {{ui:Settings}} ດ້ວຍຮູບເຟືອງໃນແຖບແອັບ ຫຼື {{key:Mod+,}}. ແຖບທຳອິດ, {{ui:PartCraft}}, ມີການຕັ້ງຄ່າທີ່ເປັນຂອງແອັບນີ້; {{ui:General}} ມີການຕັ້ງຄ່າທີ່ທຸກແອັບ CadCraft ໃຊ້ຮ່ວມກັນ (ຮູບແບບ, ແຖບເຄື່ອງມື, ແຜງ). ການຕັ້ງຄ່າ PartCraft ມີຢູ່ໃນແອັບເທົ່ານັ້ນ: ທ່ານປ່ຽນພວກມັນຢູ່ທີ່ນີ້, ແລະ ເບຣົາເຊີນີ້ຈື່ພວກມັນໄວ້. ຣີເຊັດການຕັ້ງຄ່າ PartCraft ເອົາທຸກຢ່າງກັບໄປເປັນຄ່າເລີ່ມຕົ້ນ.

## ການໝຸນມຸມມອງ

- **ປຸ່ມຊ້າຍ** (ຄ່າເລີ່ມຕົ້ນ): ລາກດ້ວຍປຸ່ມຊ້າຍເພື່ອໝຸນຊິ້ນສ່ວນ; ລາກດ້ວຍປຸ່ມຂວາ ຫຼື ປຸ່ມກາງເພື່ອເລື່ອນມຸມມອງ.
- **ປຸ່ມກາງ**: ກົດລໍ້ແລ້ວລາກເພື່ອໝຸນຊິ້ນສ່ວນ; ກົດຄ້າງ {{key:Shift}} (ຫຼື {{key:Ctrl}}, ຫຼື ⌘) ດ້ວຍປຸ່ມກາງ, ຫຼື ລາກດ້ວຍປຸ່ມຂວາ, ເພື່ອເລື່ອນມຸມມອງ. ປຸ່ມຊ້າຍພຽງເລືອກໜ້າ, ຂອບ ແລະ ແຜ່ນ, ສະນັ້ນການຄລິກທີ່ຂະຍັບເລັກນ້ອຍຈະບໍ່ໝຸນຊິ້ນສ່ວນ. ໂປຣແກຣມ CAD ຈຳນວນຫຼາຍເຮັດວຽກແບບນີ້.

ລໍ້ເມົ້າສ໌ຊູມເຂົ້າຫາຕົວຊີ້ໃນທັງສອງກໍລະນີ. ໃນພາບຮ່າງ, ປຸ່ມຂວາ ແລະ ປຸ່ມກາງຍັງເລື່ອນມຸມມອງຄືເກົ່າ.

## ການເລື່ອນ: ລໍ້ເມົ້າສ໌ ຫຼື trackpad

- **ຊອກຫາເອງ** (ຄ່າເລີ່ມຕົ້ນ): PartCraft ສັງເກດການເລື່ອນ. ການເລື່ອນດ້ານຂ້າງ ຫຼື ລະອຽດ, ຄືກັບທີ່ trackpad ສົ່ງ, ໝຸນຊິ້ນສ່ວນ; ຂັ້ນລໍ້ເຕັມເທື່ອຊູມ.
- **ລໍ້ເມົ້າສ໌**: ການເລື່ອນຈະຊູມເຂົ້າຫາຕົວຊີ້ສະເໝີ.
- **Trackpad**: ປັດດ້ວຍສອງນິ້ວເພື່ອໝຸນຊິ້ນສ່ວນ, ກົດຄ້າງ {{key:Shift}} ແລ້ວປັດເພື່ອເລື່ອນມຸມມອງ, ບີບເພື່ອຊູມ. ໃນພາບຮ່າງ, ການປັດສອງນິ້ວຈະເລື່ອນພາບຮ່າງ.

ການບີບຊູມໄດ້ໃນທຸກທາງເລືອກ. ຖ້າ "ຊອກຫາເອງ" ເດົາຜິດສຳລັບເມົ້າສ໌ ຫຼື trackpad ຂອງທ່ານ, ໃຫ້ເລືອກອັນທີ່ທ່ານມີ. ເພີ່ມເຕີມໃນ [Trackpad, ການສຳຜັດ ແລະ ໜ້າຈໍນ້ອຍ](topic:trackpad-and-touch).

## ການວາດພາບ: ເພີ່ມຄວາມສຳພັນຂະນະວາດ

**ເພີ່ມຄວາມສຳພັນຂະນະວາດ** (ເປີດຢູ່ຕອນເລີ່ມ): ການຄລິກທີ່ດູດເຂົ້າຈຸດຈະເຮັດໃຫ້ຈຸດໃໝ່ທັບກັນ (coincident) ກັບມັນ, ການຄລິກເທິງເສັ້ນໂຄ້ງຈະວາງຈຸດເທິງເສັ້ນໂຄ້ງນັ້ນ, ແລະ ເສັ້ນທີ່ວາດເກືອບລະດັບ ຫຼື ເກືອບຕັ້ງຈະກາຍເປັນແນວນອນ ຫຼື ແນວຕັ້ງ. ເບິ່ງ [ຄວາມສຳພັນ ແລະ ຂະໜາດ](topic:relations-dimensions).

ປິດມັນເມື່ອທ່ານຕ້ອງການວາງເລຂາຄະນິດໃກ້ກັບເລຂາຄະນິດອື່ນໂດຍບໍ່ຜູກມັດກັບມັນ. ຕົວຊີ້ຍັງດູດເຂົ້າຈຸດ ແລະ ເສັ້ນໂຄ້ງ, ແຕ່ບໍ່ມີຫຍັງຖືກເຊື່ອມ: ເສັ້ນທີ່ວາດຕໍ່ກັນເປັນໂສ້ຈະບໍ່ໃຊ້ປາຍຮ່ວມກັນ, ສະນັ້ນການລາກອາດດຶງພວກມັນອອກຈາກກັນ. ເພີ່ມຄວາມສຳພັນທີ່ທ່ານຕ້ອງການດ້ວຍຕົນເອງຈາກແຜງຂວາ. ໂປຣໄຟລ໌ປິດຍັງຈະ extrude ໄດ້ເມື່ອປາຍຂອງມັນມາບົບກັນ.

:::note
ການຕັ້ງຄ່ານີ້ປ່ຽນພຽງສິ່ງທີ່ການວາດໃໝ່ເພີ່ມເທົ່ານັ້ນ. ຄວາມສຳພັນທີ່ມີຢູ່ແລ້ວໃນພາບຮ່າງຍັງຄົງຢູ່, ແລະ ເຄື່ອງມື Fillet ຍັງສ້າງເສັ້ນໂຄ້ງສຳຜັດ ແລະ ລັດສີຂອງມັນ.
:::

## ການວາດພາບ: ກຳນົດຂະໜາດຂະນະວາດ

**ກຳນົດຂະໜາດຂະນະວາດ** (ເປີດຢູ່ຕອນເລີ່ມ): ຂະນະທີ່ເສັ້ນ, ສີ່ຫຼ່ຽມ, ວົງມົນ ຫຼື ເສັ້ນໂຄ້ງກຳລັງຖືກວາດ, ການພິມຕົວເລກຈະຕື່ມກ່ອງຂະໜາດຂ້າງຕົວຊີ້ ({{key:Tab}} ໄປກ່ອງຕໍ່ໄປ), ແລະ {{key:Enter}} ວາດຮູບຮ່າງທີ່ຂະໜາດນັ້ນ, ໂດຍມີຂະໜາດຂັບເຄື່ອນສຳລັບແຕ່ລະຂະໜາດທີ່ທ່ານພິມ. ປິດ: ການພິມຕົວເລກຂະນະວາດບໍ່ເຮັດຫຍັງ, ແລະ ຮູບຮ່າງຖືກວາດດ້ວຍການຄລິກເທົ່ານັ້ນ. ເບິ່ງ [ພິມຂະໜາດຂະນະວາດ](topic:sketch-basics#type-the-size-as-you-draw).

## ຕົວຊີ້ມຸມ

ສິ່ງທີ່ສະແດງໃນມຸມຂອງມຸມມອງ 3D: **ລູກບາດມຸມມອງ** (ຄ່າເລີ່ມຕົ້ນ; ມຸມເທິງຂວາ — ຄລິກໜ້າ, ຂອບ ຫຼື ມຸມເພື່ອເບິ່ງຈາກບ່ອນນັ້ນ, ລາກມັນເພື່ອໝຸນໂດຍອ້ອມ, ລາກວົງແຫວນເຂັມທິດຂອງມັນເພື່ອໝຸນໂມເດວ), **ໄອຄອນແກນ** (ເຄື່ອງໝາຍ X, Y, Z ນ້ອຍຢູ່ມຸມລຸ່ມຊ້າຍ ທີ່ໝຸນຕາມມຸມມອງ: X ສີແດງ, Y ສີຂຽວ, Z ສີຟ້າ) ຫຼື **None**. ທັງສອງບໍ່ສະແດງໃນຂະນະທີ່ທ່ານວາດພາບຮ່າງ ຫຼື ໃນແຜ່ນແບບແຕ້ມ. ເບິ່ງ [ລູກບາດມຸມມອງ](topic:view-cube).

## ເທຣດຂອງຕົວແກ້

ຈຳນວນເທຣດທີ່ຕົວແກ້ການຈຳລອງອາດໃຊ້. **ອັດຕະໂນມັດ** (ຄ່າເລີ່ມຕົ້ນ) ໃຊ້ໜ້ອຍກວ່າຈຳນວນໂປຣເຊດເຊີແບບ logical ຂອງຄອມພິວເຕີໜຶ່ງ (ສູງສຸດ 16), ເພື່ອໃຫ້ໜ້າເວັບຕອບສະໜອງໄດ້ໃນຂະນະທີ່ການຈຳລອງກຳລັງແກ້; ຫຼື ເລືອກຕົວເລກ. ການແກ້ voxel ຂະໜາດໃຫຍ່, buckling, ຄວາມເຄັ່ງຕາມເວລາ ແລະ ການໄຫຼ ແກ້ໄວຂຶ້ນດ້ວຍຫຼາຍເທຣດ (ປະມານ 2× ດ້ວຍ 4 ເທຣດ ສຳລັບ 80,000 ລູກບາດ ໃນການວັດຂອງພວກເຮົາ, ຫຼາຍກວ່ານັ້ນຢູ່ຄອມພິວເຕີທີ່ບໍ່ມີງານ); ໂມເດວທີ່ມີຄ່າທີ່ບໍ່ຮູ້ຈັກຕ່ຳກວ່າປະມານ 20,000 ຈະຢູ່ໃນເທຣດດຽວ, ເພາະການເລີ່ມເທຣດໃຊ້ເວລາຫຼາຍກວ່າທີ່ມັນປະຢັດໄດ້. ການແກ້ດ້ວຍຫຼາຍເທຣດໃຫ້ຄຳຕອບດຽວກັນກັບເທຣດດຽວ (ຈົນເຖິງການປັດຄ່າ: ຜົນບວກຖືກບວກໃນລຳດັບທີ່ຕ່າງກັນ). ຜົນຂອງແຕ່ລະການຈຳລອງສະແດງ **N threads** ຫຼື **1 thread** ພ້ອມເຫດຜົນພາຍໃຕ້ **Solver**.

ເທຣດຕ້ອງການໃຫ້ໜ້າເວັບເປັນ **cross-origin isolated** (ເບຣົາເຊີໃຫ້ worker ແບ່ງປັນໜ່ວຍຄວາມຈຳໄດ້ພຽງເມື່ອເປັນແບບນັ້ນ). ໜ້າຂອງ lab ເປັນແບບນັ້ນ; ບ່ອນທີ່ບໍ່ແມ່ນ, ການຕັ້ງຄ່າຈະບອກວ່າ ("This page is not cross-origin isolated, so solvers run on one thread whatever is chosen here." ແປວ່າ: ໜ້ານີ້ບໍ່ແມ່ນ cross-origin isolated, ດັ່ງນັ້ນຕົວແກ້ເຮັດວຽກໃນເທຣດດຽວບໍ່ວ່າຈະເລືອກຫຍັງ), ແລະ ທຸກການແກ້ໃຊ້ເທຣດດຽວ. ສ່ວນອື່ນເຮັດວຽກຄືເກົ່າ, ແລະ ຄຳຕອບກໍຄືກັນ.

ການໄຫຼແບບ laminar ກໍໃຊ້ເທຣດເຊັ່ນກັນ (ປະມານ 2.5× ດ້ວຍ 4 ເທຣດ ສຳລັບ 54,000 ເຊວຂອງນ້ຳ, ຄຳຕອບດຽວກັນເຖິງຕົວເລກສຸດທ້າຍ). ຕົວແກ້ quadratic-tetrahedron ແລະ ການຖ່າຍເທຄວາມຮ້ອນເຮັດວຽກໃນເທຣດດຽວ: ການໃສ່ເທຣດໃຫ້ມັນຖືກວັດວ່າຊ້າກວ່າໃນຄອມພິວເຕີທົດສອບຂອງພວກເຮົາ (ຕົວແກ້ຂອງພວກມັນຖືກຈຳກັດດ້ວຍຄວາມໄວຂອງໜ່ວຍຄວາມຈຳ ແລະ ຂັ້ນຕອນທີ່ແບ່ງບໍ່ໄດ້).

### ຢູ່ເວັບເຊີຟເວີຂອງທ່ານເອງ

ຖ້າທ່ານເປີດ PartCraft ຈາກເວັບເຊີຟເວີຂອງທ່ານເອງ, ມັນເຮັດວຽກຕາມທີ່ໃຫ້ບໍລິການ. ສຳລັບເທຣດຂອງຕົວແກ້, ໃຫ້ເວັບເຊີຟເວີສົ່ງສອງ header ພ້ອມກັບໜ້າ PartCraft:

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

ໃນ Apache, ໃນ `.htaccess` ຂອງໂຟນເດີ (ຕ້ອງການ mod_headers):

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

ໃນ nginx, ໃນ `location` ທີ່ໃຫ້ບໍລິການ PartCraft:

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

ໂຫຼດໜ້າຄືນໃໝ່: ການຕັ້ງຄ່າ › ເທຣດຂອງຕົວແກ້ ຈະສະເໜີ **ອັດຕະໂນມັດ** ດ້ວຍຈຳນວນຂອງຄອມພິວເຕີຂອງທ່ານ. header ທີ່ສອງເຮັດໃຫ້ເບຣົາເຊີປະຕິເສດສິ່ງໃດກໍຕາມທີ່ໜ້າດຶງມາຈາກເວັບອື່ນທີ່ບໍ່ອະນຸຍາດ, ຊຶ່ງເໝາະສຳລັບ PartCraft ໂດຍຕົວມັນເອງ (ມັນດຶງທຸກຢ່າງຈາກໂຟນເດີຂອງມັນເອງ).
