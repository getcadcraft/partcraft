ເສັ້ນທາງເຄື່ອງມືດຽວກັນຕ້ອງຂຽນແຕກຕ່າງກັນສຳລັບ control ທີ່ຕ່າງກັນ: ໝາຍເລກແຖວ ຫຼື ບໍ່ມີ, `M6` ຫຼື ການຢຸດຊົ່ວຄາວ, `G28` ຫຼື `G53`, `M30` ຫຼື `M2`. **post** ແມ່ນຂໍ້ຄວາມສັ້ນທີ່ບອກວິທີ. ສາມ post ທີ່ມາພ້ອມຂອງ PartCraft (Fanuc-style, GRBL ແລະ LinuxCNC) ຖືກຂຽນໃນຮູບແບບນີ້, ດັ່ງນັ້ນ post ຂອງທ່ານເອງສາມາດເລີ່ມຈາກການສຳເນົາໜຶ່ງໃນນັ້ນໄດ້.

ກວດຜົນລັບໃນ simulator ຂອງເຄື່ອງຈັກຂອງທ່ານກ່ອນຕັດ, ແລະ ໃຫ້ລອງແລ່ນໃນອາກາດເໜືອວັດຖຸດິບກ່ອນ. post ທີ່ມາພ້ອມຂຽນສິ່ງທີ່ມັນເຄີຍຂຽນກ່ອນຮູບແບບນີ້ມີຢູ່ (ການທົດສອບປຽບທຽບຜົນລັບເປັນ byte ຕໍ່ byte ໃນຫຼາຍຮ້ອຍໂປຣແກຣມ), ແຕ່ບໍ່ມີຫຍັງໃນທີ່ນີ້ຖືກພິສູດກັບເຄື່ອງຂອງທ່ານ, ແລະ post ທີ່ທ່ານປ່ຽນແມ່ນຂອງທ່ານທີ່ຕ້ອງພິສູດ.

## ສ້າງໜຶ່ງ

ໃນ Manufacture, ພາຍໃຕ້ **Post**:

- {{ui:Edit post…}} ໃນ control ທີ່ມາພ້ອມເປີດ **ສຳເນົາຂອງທ່ານເອງ** ຂອງມັນ. ໃນ post ທີ່ເປັນຂອງທ່ານ ມັນເປີດ post ນັ້ນ.
- {{ui:New post…}} ເລີ່ມຈາກ post ເປົ່າຂະໜາດນ້ອຍທີ່ມີທຸກ event ຢູ່ໃນນັ້ນ.
- {{ui:Import post file…}} ອ່ານໄຟລ໌ຂໍ້ຄວາມ `.cpost` (ໄຟລ໌ທີ່ທ່ານໄດ້ຈາກ **Save as a file…** ໃນ editor).

editor ສະແດງຂໍ້ຄວາມ, ແຖວທີ່ບອກວ່າມັນອ່ານໄດ້ບໍ່ (ແລະ ແຖວໃດຜິດ), ແລະ G-code ທີ່ post ຂຽນ, ຂະນະທີ່ທ່ານພິມ. **Preview with** ເລືອກໂປຣແກຣມຕົວຢ່າງນ້ອຍທີ່ແລ່ນທຸກ event, ຫຼື ໂປຣແກຣມຂອງຊິ້ນສ່ວນນີ້ເອງ. {{ui:Save}} ເກັບ post ໄວ້ໃນໄຟລ໌ຊິ້ນສ່ວນ (ສູງສຸດ 20 post) ແລະ ເລືອກມັນເປັນ control. Post ເດີນທາງໄປກັບຊິ້ນສ່ວນ; ເພື່ອໃຊ້ໃນຊິ້ນສ່ວນອື່ນ, ບັນທຶກເປັນໄຟລ໌ ແລ້ວນຳເຂົ້າທີ່ນັ້ນ.

## post ໜ້າຕາແນວໃດ

```
post mymill
name ເຄື່ອງກັດຂອງຂ້ອຍ (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

ແຖວທີ່ເລີ່ມດ້ວຍ `//` ແລະ ແຖວຫວ່າງຖືກຂ້າມ. ດ້ານເທິງແມ່ນການຕັ້ງຄ່າ; ຈາກນັ້ນແມ່ນບລັອກ `on <event>` ໜຶ່ງອັນສຳລັບແຕ່ລະ event, ປິດດ້ວຍ `end`. event ທີ່ທ່ານບໍ່ໃສ່ຈະບໍ່ຂຽນຫຍັງ.

| ການຕັ້ງຄ່າ | ຄວາມໝາຍ |
|---|---|
| `post <id>` | id ຂອງ post: ຕົວອັກສອນ, ຕົວເລກ, `-` ແລະ `_` |
| `name <text>` | ສິ່ງທີ່ລາຍການ Control ສະແດງ |
| `extension <ext>` | ນາມສະກຸນໄຟລ໌: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … ໃນທຸກແຖວ `emit`, ຫຼື ບໍ່ມີ |
| `decimal-point yes` / `no` | `10.` ແທນ `10` (ຄອມເມັນບໍ່ເຄີຍມີຈຸດ) |
| `canned-cycles yes` / `no` | `no`: ຮູຖືກຂຽນເປັນການເຄື່ອນທີ່ G0/G1 ທີ່ມັນເປັນຕົວແທນ |
| `modal <group> <words>` | ຄຳຂອງກຸ່ມ (`modal motion G0 G1 G2 G3`) ທີ່ຖືກຂຽນແຕ່ເມື່ອມັນປ່ຽນ |

## Event

ພວກມັນເຮັດວຽກຕາມລຳດັບນີ້ສຳລັບໂປຣແກຣມ: `start`; ຈາກນັ້ນສຳລັບແຕ່ລະການດຳເນີນງານ `operation`, `tool-change` (ເມື່ອເຄື່ອງມືປ່ຽນ), `spindle` (ເມື່ອຄວາມໄວປ່ຽນ), `approach` (ການເຄື່ອນທີ່ຂຶ້ນໄປຈຸດທຳອິດ, ກ່ອນ rapid ທຳອິດ), `coolant-on`, ແລ້ວການເຄື່ອນທີ່ຂອງມັນເປັນ `rapid`, `feed` ແລະ `arc`, ແລະ ແຕ່ລະວົງຈອນສຳເລັດຮູບເປັນ `cycle-start`, `cycle-hole` ໜຶ່ງອັນຕໍ່ຮູ ແລະ `cycle-end`; ສຸດທ້າຍ `end`.

event ເພີ່ມເຕີມ ສຳລັບສິ່ງທີ່ເກີນສາມແກນ (post ທີ່ບໍ່ມີ event ຈະປະຕິເສດໂປຣແກຣມດັ່ງກ່າວ ແລະ ລະບຸ event ທີ່ມັນຂາດ):

| Event | ເມື່ອໃດ | ຕົວແປຂອງມັນ |
|---|---|---|
| `index` | ກ່ອນການດຳເນີນງານທີ່ທິດທາງເຄື່ອງມືຕ່າງຈາກຄັ້ງກ່ອນ, ແລະ ກ່ອນການດຳເນີນງານທຳອິດໃນເຄື່ອງທີ່ມີແກນໝຸນ | `rot.a`, `rot.b`, `rot.c` (ຕຳແໜ່ງທີ່ຈະໄປ; ວ່າງສຳລັບແກນທີ່ເຄື່ອງບໍ່ມີ), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | ການເຄື່ອນທີ່ຂອງການດຳເນີນງານທີ່ແກນໝຸນເຄື່ອນໃນຂະນະຕັດ | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (yes ເມື່ອ feed ຕ້ອງເປັນເວລາປີ້ນກັບ), `invf` (1/ນາທີ) |
| `rotary-end` | ຫຼັງການດຳເນີນງານດັ່ງກ່າວ | |
| `probe-move` | ການເຄື່ອນທີ່ທີ່ຢຸດເມື່ອ probe ແຕະ | `x`, `y`, `z`, `f`, `probe.n` (1 ຫາ 4), `probe.axis` (x, y ຫຼື z), `probe.k` (1, 2 ຫຼື 3) |
| `probe-set` | ຫຼັງການແຕະຂອງວົງຈອນ probing ໜຶ່ງ | `probe.kind` (`"z"`, `"x"`, `"y"` ຫຼື `centre`), `probe.action` (`set` ຫຼື `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | ການເຄື່ອນທີ່ເກຣວເທິງເຄື່ອງກຶງ | `x`, `z`, `thread.lead` |

ທຸກ event ມີ: `kin` (none, a, b, ac, bc), `rotary` ແລະ `tcp` (yes ຫຼື no, ຈາກເຄື່ອງໃນ Setup), `pivot.x`, `pivot.y`, `pivot.z`, `op.tilt` ແລະ `op.turn` ຂອງການດຳເນີນງານ, ແລະ ເທິງເຄື່ອງກຶງ `spin.mode` (css ຫຼື rpm), `spin.css`, `spin.max` ແລະ `tool.nose`. ຄຳຕົວອັກສອນທີ່ມີຄ່າວ່າງ, ເຊັ່ນ `A{rot.a}` ເທິງເຄື່ອງທີ່ບໍ່ມີແກນ A, ຖືກຕັດອອກຈາກແຖວ. ປຽບທຽບກັບ x, y ແລະ z ເປັນຂໍ້ຄວາມໃນເຄື່ອງໝາຍຄຳພາ (`if probe.kind == "z"`): ຖ້າບໍ່ມີ, ມັນເປັນພິກັດຂອງການເຄື່ອນທີ່.

ສອງແຖວເພີ່ມເຕີມທີ່ດ້ານເທິງຂອງ post ເຮັດໃຫ້ມັນເປັນ post ເຄື່ອງກຶງ: `machine lathe` (ມັນຂຽນແຕ່ X ແລະ Z, ແລະ ປະຕິເສດເສັ້ນທາງກັດ ຄືກັບ post ກັດປະຕິເສດເສັ້ນທາງກຶງ) ແລະ `lathe-x diameter` ຫຼື `lathe-x radius`.

ແຕ່ລະ event ສາມາດໃຊ້ຕົວແປຂອງປະເພດການເຄື່ອນທີ່ຂອງມັນ, ຂຽນເປັນ `{name}`: ໂປຣແກຣມ (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), ວັດຖຸດິບ (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), ເຄື່ອງມື (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ການດຳເນີນງານ (`op.name`, `op.type`), `rpm`, ຈຸດຂອງການເຄື່ອນທີ່ (`x`, `y`, `z`, `f`, ແລະ `moved`: true ເມື່ອແກນໃດໜຶ່ງປ່ຽນ), arc (`arc.g` 2 ຫຼື 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) ແລະ ຮູ (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). **Events and variables** ໃນ editor ສະແດງວ່າ event ໃດເຫັນຫຍັງ. ສະຖານະທີ່ທ່ານອ່ານ ແລະ ຕັ້ງໄດ້: `cool`, `offset`, ແລະ `at.x`, `at.y`, `at.z`, `at.f` (ຄ່າຂຽນຄັ້ງສຸດທ້າຍ).

## ຄຳສັ່ງ

| ຄຳສັ່ງ | ມັນເຮັດຫຍັງ |
|---|---|
| `raw TEXT` | ແຖວທີ່ຖືກພິມຕາມຕົວ (ບໍ່ມີໝາຍເລກແຖວ) |
| `comment TEXT` | `(TEXT)` ໂດຍຕັດຕົວອັກສອນທີ່ບໍ່ແມ່ນ ASCII ແລະ ວົງເລັບອອກ |
| `emit WORD WORD …` | ແຖວຂອງຄຳ; ຄຳທີ່ອອກມາເປັນຄ່າວ່າງຖືກຂ້າມ; ບໍ່ມີຄຳ, ບໍ່ມີແຖວ |
| `word WORD …` | ເພີ່ມຄຳໃສ່ແຖວທີ່ກຳລັງສ້າງ; `emit` ເປົ່າຈະປິດມັນ |
| `if EXPR` … `else` … `end` | ເງື່ອນໄຂ: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, ຖ້າບໍ່ດັ່ງນັ້ນ b) |
| `for tool in tools` … `end` | ໜຶ່ງຄັ້ງສຳລັບແຕ່ລະເຄື່ອງມືທີ່ໂປຣແກຣມໃຊ້ |
| `set NAME EXPR` | ຈື່ຄ່າ (`set offset tool.number`) |
| `reset NAME …` | ລືມຄຳ modal (ກຸ່ມ, ຕົວອັກສອນທີ່ຢູ່ເຊັ່ນ `Z`, ຫຼື `at.z`) |
| `do rapid X Y Z` | ແລ່ນ event `rapid` ສຳລັບຈຸດໜຶ່ງ |

ຄຳແມ່ນຂໍ້ຄວາມທີ່ພິມແລ້ວ ພ້ອມຊ່ອງ `{variable|filter}`. ຕົວກອງແມ່ນ `upper`, `lower`, `pad:N` (ເຕີມສູນ), `cut:N` (N ຕົວອັກສອນທຳອິດ), `safe` (ASCII ທີ່ປອດໄພສຳລັບຄອມເມັນ) ແລະ `int`. ຄຳທີ່ລົງທ້າຍດ້ວຍ `~` ເປັນ **modal**: ມັນຖືກຂຽນແຕ່ເມື່ອແຕກຕ່າງຈາກສິ່ງທີ່ຂຽນຄັ້ງສຸດທ້າຍ (`G1~`, `X{x}~`). ຄຳທີ່ລົງທ້າຍດ້ວຍ `~!` ຖືກຂຽນທຸກຄັ້ງ ແລະ ຍັງຈື່ໄວ້. ຊື່ທີ່ບໍ່ແມ່ນຕົວແປເປັນຂໍ້ຄວາມທຳມະດາ (`G81`, `mist`). ຕົວເລກຖືກປັດເປັນ 0.001 mm ແລະ ຂຽນໂດຍບໍ່ມີສູນທ້າຍ.

## post ເຮັດອັນໃດບໍ່ໄດ້

ມັນກຳນົດວິທີຂຽນການເຄື່ອນທີ່ເທົ່ານັ້ນ, ບໍ່ມີຫຍັງອື່ນ. ມັນບໍ່ສາມາດປ່ຽນເສັ້ນທາງເຄື່ອງມື, ຈັດລຽງການດຳເນີນງານ, ແບ່ງ arc, ເພີ່ມແກນ, ຮູ້ການເດີນທາງ ຫຼື ຈຸນລະສາດຂອງເຄື່ອງຈັກ, ຫຼື ຄິດໄລ່ເລກຄະນິດກັບພິກັດ (ບໍ່ມີ `+`). ຕຳແໜ່ງໝຸນເອງມາຈາກເຄື່ອງທີ່ອະທິບາຍໃນ Setup, ບໍ່ແມ່ນຈາກ post: post ສາມາດປ່ຽນເຄື່ອງໝາຍ ຫຼື ຕົວອັກສອນຂອງມັນ, ແຕ່ບໍ່ແມ່ນຈຸນລະສາດ. ວົງຈອນອາຍຸເຄື່ອງມື ແລະ subprogram ຍັງບໍ່ໄດ້ສ້າງ. ໄຟລ໌ post ຮູບແບບ `.cps` ຈາກໂປຣແກຣມອື່ນບໍ່ສາມາດໂຫຼດໄດ້: ນີ້ແມ່ນຮູບແບບທີ່ແຕກຕ່າງ ແລະ ງ່າຍກວ່າ.
