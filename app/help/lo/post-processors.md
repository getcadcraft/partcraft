ເສັ້ນທາງເຄື່ອງມືດຽວກັນຕ້ອງຖືກຂຽນແຕກຕ່າງກັນສຳລັບຕົວຄວບຄຸມຕ່າງກັນ: ມີເລກແຖວ ຫຼື ບໍ່ມີ, `M6` ຫຼື ການຢຸດຊົ່ວຄາວ, `G28` ຫຼື `G53`, `M30` ຫຼື `M2`. **ໂພສ** ແມ່ນຂໍ້ຄວາມສັ້ນທີ່ບອກວ່າຈະຂຽນແບບໃດ. ໂພສທັງສາມທີ່ມາພ້ອມກັບ PartCraft (ແບບ Fanuc, GRBL ແລະ LinuxCNC) ຖືກຂຽນໃນຮູບແບບນີ້, ດັ່ງນັ້ນໂພສຂອງທ່ານເອງສາມາດເລີ່ມຈາກການສຳເນົາໜຶ່ງໃນນັ້ນໄດ້.

ກ່ອນຕັດ ໃຫ້ກວດຜົນໃນໂປຣແກຣມຈຳລອງຂອງເຄື່ອງຂອງທ່ານເອງ, ແລະ ລອງແລ່ນໃນອາກາດເໜືອຊິ້ນວັດຖຸກ່ອນ. ໂພສທີ່ມາພ້ອມກັບໂປຣແກຣມຂຽນສິ່ງທີ່ມັນເຄີຍຂຽນກ່ອນຮູບແບບນີ້ມີ (ການທົດສອບປຽບທຽບຜົນເທື່ອລະໄບຕ໌ໃນຫຼາຍຮ້ອຍໂປຣແກຣມ), ແຕ່ບໍ່ມີຫຍັງຢູ່ບ່ອນນີ້ທີ່ໄດ້ຮັບການພິສູດໃນເຄື່ອງຂອງທ່ານ, ແລະ ໂພສທີ່ທ່ານປ່ຽນແປງແມ່ນຂອງທ່ານທີ່ຕ້ອງພິສູດເອງ.

## ສ້າງໂພສ

ໃນ ການຜະລິດ, ພາຍໃຕ້ **ໂພສ**:

- {{ui:ແກ້ໄຂໂພສ…}} ໃນຕົວຄວບຄຸມທີ່ມາພ້ອມ ຈະເປີດ **ສຳເນົາຂອງທ່ານເອງ** ຂອງມັນ. ຖ້າເປັນໂພສທີ່ທ່ານສ້າງເອງ ຈະເປີດໂພສນັ້ນ.
- {{ui:ໂພສໃໝ່…}} ເລີ່ມຈາກໂພສເປົ່ານ້ອຍໜຶ່ງທີ່ມີທຸກເຫດການຢູ່ໃນນັ້ນ.
- {{ui:ນຳເຂົ້າໄຟລ໌ໂພສ…}} ອ່ານໄຟລ໌ຂໍ້ຄວາມ `.cpost` (ໄຟລ໌ທີ່ທ່ານໄດ້ຈາກ **ບັນທຶກເປັນໄຟລ໌…** ໃນຕົວແກ້ໄຂ).

ຕົວແກ້ໄຂຈະສະແດງຂໍ້ຄວາມ, ແຖວທີ່ບອກວ່າອ່ານໄດ້ຫຼືບໍ່ (ແລະ ແຖວໃດຜິດ), ແລະ G-code ທີ່ໂພສຂຽນ ໃນຂະນະທີ່ທ່ານພິມ. **ພາກທົດລອງດ້ວຍ** ເລືອກໂປຣແກຣມຕົວຢ່າງນ້ອຍທີ່ແລ່ນທຸກເຫດການ, ຫຼື ໂປຣແກຣມຂອງຊິ້ນສ່ວນນີ້ເອງ. {{ui:ບັນທຶກ}} ຈະເກັບໂພສໄວ້ໃນໄຟລ໌ຂອງຊິ້ນສ່ວນ (ສູງສຸດ 20 ໂພສ) ແລະ ເລືອກມັນເປັນຕົວຄວບຄຸມ. ໂພສຈະຍ້າຍໄປກັບຊິ້ນສ່ວນ; ເພື່ອໃຊ້ໃນຊິ້ນສ່ວນອື່ນ ໃຫ້ບັນທຶກເປັນໄຟລ໌ ແລ້ວນຳເຂົ້າໃນຊິ້ນສ່ວນນັ້ນ.

## ໂພສໜ້າຕາແນວໃດ

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

ແຖວທີ່ເລີ່ມດ້ວຍ `//` ແລະ ແຖວວ່າງຈະຖືກຂ້າມ. ຢູ່ດ້ານເທິງແມ່ນການຕັ້ງຄ່າ; ຈາກນັ້ນແມ່ນບລັອກ `on <event>` ສຳລັບແຕ່ລະເຫດການ, ປິດດ້ວຍ `end`. ເຫດການທີ່ທ່ານບໍ່ໄດ້ໃສ່ຈະບໍ່ຂຽນຫຍັງ.

| ການຕັ້ງຄ່າ | ຄວາມໝາຍ |
|---|---|
| `post <id>` | ລະຫັດຂອງໂພສ: ຕົວອັກສອນ, ຕົວເລກ, `-` ແລະ `_` |
| `name <text>` | ສິ່ງທີ່ລາຍການຕົວຄວບຄຸມສະແດງ |
| `extension <ext>` | ນາມສະກຸນໄຟລ໌: nc, ngc, tap ... |
| `line-numbers 10` / `off` | `N10`, `N20` ... ໃນທຸກແຖວ `emit`, ຫຼື ບໍ່ມີເລີຍ |
| `decimal-point yes` / `no` | `10.` ແທນ `10` (ຄຳເຫັນບໍ່ມີຈຸດທົດສະນິຍົມ) |
| `canned-cycles yes` / `no` | `no`: ຮູຈະຖືກຂຽນເປັນການເຄື່ອນທີ່ G0/G1 ທີ່ມັນແທນ |
| `modal <group> <words>` | ຄຳຂອງກຸ່ມ (`modal motion G0 G1 G2 G3`) ທີ່ຂຽນພຽງເມື່ອມີການປ່ຽນແປງ |

## ເຫດການ

ພວກມັນເຮັດວຽກຕາມລຳດັບນີ້ສຳລັບໂປຣແກຣມ: `start`; ຈາກນັ້ນສຳລັບແຕ່ລະການດຳເນີນງານ `operation`, `tool-change` (ເມື່ອເຄື່ອງມືປ່ຽນ), `spindle` (ເມື່ອຄວາມໄວປ່ຽນ), `approach` (ການເຄື່ອນຂຶ້ນໄປຫາຈຸດທຳອິດ, ກ່ອນ rapid ທຳອິດ), `coolant-on`, ແລ້ວການເຄື່ອນທີ່ຂອງມັນເປັນ `rapid`, `feed` ແລະ `arc`, ແລະ ແຕ່ລະວົງຈອນສຳເລັດຮູບເປັນ `cycle-start`, `cycle-hole` ໜຶ່ງຄັ້ງຕໍ່ຮູ ແລະ `cycle-end`; ສຸດທ້າຍ `end`.

ແຕ່ລະເຫດການສາມາດໃຊ້ຕົວແປຂອງການເຄື່ອນທີ່ປະເພດຂອງມັນ, ຂຽນເປັນ `{name}`: ໂປຣແກຣມ (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), ວັດຖຸດິບ (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` ... `stock.maxz`), ເຄື່ອງມື (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), ການດຳເນີນງານ (`op.name`, `op.type`), `rpm`, ຈຸດຂອງການເຄື່ອນທີ່ (`x`, `y`, `z`, `f`, ແລະ `moved`: true ເມື່ອແກນໃດໜຶ່ງປ່ຽນ), ສ່ວນໂຄ້ງ (`arc.g` 2 ຫຼື 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) ແລະ ຮູ (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). ລາຍການ **ເຫດການ ແລະ ຕົວແປ** ໃນຕົວແກ້ໄຂສະແດງວ່າເຫດການໃດເຫັນຫຍັງ. ສະຖານະທີ່ອ່ານ ແລະ ຕັ້ງຄ່າໄດ້: `cool`, `offset`, ແລະ `at.x`, `at.y`, `at.z`, `at.f` (ຄ່າສຸດທ້າຍທີ່ຖືກຂຽນ).

## ຄຳສັ່ງ

| ຄຳສັ່ງ | ໜ້າທີ່ |
|---|---|
| `raw TEXT` | ແຖວທີ່ຂຽນຕາມທີ່ພິມ (ບໍ່ມີເລກແຖວ) |
| `comment TEXT` | `(TEXT)` ໂດຍຕັດອັກສອນທີ່ບໍ່ແມ່ນ ASCII ແລະ ວົງເລັບອອກ |
| `emit WORD WORD …` | ແຖວຂອງຄຳ; ຄຳທີ່ອອກມາວ່າງຈະຖືກຂ້າມ; ບໍ່ມີຄຳ ບໍ່ມີແຖວ |
| `word WORD …` | ເພີ່ມຄຳເຂົ້າໃນແຖວທີ່ກຳລັງສ້າງ; `emit` ເປົ່າຈະປິດແຖວ |
| `if EXPR` … `else` … `end` | ເງື່ອນໄຂ: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, ຖ້າບໍ່ມີແລ້ວ b) |
| `for tool in tools` … `end` | ເຮັດໜຶ່ງຄັ້ງສຳລັບເຄື່ອງມືແຕ່ລະອັນທີ່ໂປຣແກຣມໃຊ້ |
| `set NAME EXPR` | ຈື່ຄ່າໄວ້ (`set offset tool.number`) |
| `reset NAME …` | ລືມຄຳ modal (ກຸ່ມ, ຕົວອັກສອນທີ່ຢູ່ເຊັ່ນ `Z`, ຫຼື `at.z`) |
| `do rapid X Y Z` | ແລ່ນເຫດການ `rapid` ສຳລັບຈຸດໜຶ່ງ |

ຄຳໜຶ່ງແມ່ນຂໍ້ຄວາມທີ່ພິມໄວ້ທີ່ມີຊ່ອງ `{variable|filter}`. ຕົວກອງມີ `upper`, `lower`, `pad:N` (ເຕີມສູນ), `cut:N` (N ຕົວອັກສອນທຳອິດ), `safe` (ASCII ທີ່ປອດໄພສຳລັບຄຳເຫັນ) ແລະ `int`. ຄຳທີ່ລົງທ້າຍດ້ວຍ `~` ແມ່ນ **modal**: ຈະຖືກຂຽນພຽງເມື່ອມັນແຕກຕ່າງຈາກສິ່ງທີ່ຂຽນຄັ້ງສຸດທ້າຍ (`G1~`, `X{x}~`). ຄຳທີ່ລົງທ້າຍດ້ວຍ `~!` ຈະຖືກຂຽນທຸກຄັ້ງ ແລະ ຍັງຈື່ໄວ້. ຊື່ທີ່ບໍ່ແມ່ນຕົວແປຈະເປັນຂໍ້ຄວາມທຳມະດາ (`G81`, `mist`). ຕົວເລກຈະຖືກປັດເປັນ 0.001 mm ແລະ ຂຽນໂດຍບໍ່ມີສູນທ້າຍ.

## ໂພສເຮັດຫຍັງບໍ່ໄດ້

ມັນກຳນົດພຽງວ່າການເຄື່ອນທີ່ຈະຖືກຂຽນແນວໃດ, ບໍ່ມີຫຼາຍກວ່ານັ້ນ. ມັນບໍ່ສາມາດປ່ຽນເສັ້ນທາງເຄື່ອງມື, ຈັດລຳດັບການດຳເນີນງານ, ແບ່ງສ່ວນໂຄ້ງ, ເພີ່ມແກນ, ຮູ້ຂອບເຂດການເຄື່ອນທີ່ ຫຼື ກົນໄກການເຄື່ອນທີ່ຂອງເຄື່ອງຂອງທ່ານ, ຫຼື ຄິດໄລ່ເລກກັບພິກັດ (ບໍ່ມີ `+`). ການໂພບ, ວົງຈອນອາຍຸເຄື່ອງມື ແລະ ວົງຈອນໂປຣແກຣມຍ່ອຍ, ຜົນແກນທີ 4 ແລະ ທີ 5, ແລະ ລະຫັດເຄື່ອງກຶງ ຍັງບໍ່ໄດ້ສ້າງ. ໄຟລ໌ໂພສແບບ `.cps` ຈາກໂປຣແກຣມອື່ນບໍ່ສາມາດໂຫລດໄດ້: ນີ້ແມ່ນຮູບແບບທີ່ແຕກຕ່າງ ແລະ ງ່າຍກວ່າ.
