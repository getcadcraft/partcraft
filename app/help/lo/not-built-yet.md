PartCraft ແມ່ນການສ້າງເບື້ອງຕົ້ນ. ໜ້ານີ້ລະບຸສິ່ງທີ່ມັນຍັງບໍ່ເຮັດ ເພື່ອທ່ານຈະບໍ່ຕ້ອງຊອກຫາມັນ, ແລະ ສິ່ງທີ່ຕ້ອງເຮັດແທນໃນປັດຈຸບັນ. ບໍ່ມີສິ່ງໃດໃນນີ້ມີວັນທີກຳນົດ.

## ຕ້ອງການ kernel ທີ່ແນ່ນອນ

ການສ້າງນີ້ສ້າງທຸກຊິ້ນສ່ວນດ້ວຍ mesh kernel (ເບິ່ງ [ແບບ mesh kernel](topic:solid-kernels)). ທຸກຢ່າງດ້ານລຸ່ມຕ້ອງການ kernel ເລຂາຄະນິດທີ່ແນ່ນອນ, ເຊິ່ງການສ້າງນີ້ຍັງບໍ່ມີ. ຊິ້ນສ່ວນທີ່ບັນທຶກດ້ວຍຟີເຈີເຫຼົ່ານີ້ຍັງເປີດໄດ້: ຟີເຈີຢູ່ໃນປະຫວັດ, ໝາຍວ່າຍັງບໍ່ໄດ້ສ້າງ, ແລະ ຖືກເກັບໄວ້ເມື່ອທ່ານບັນທຶກ.

ບາງແຖວໃນຕາຕະລາງດ້ານລຸ່ມແນະນຳຟີເຈີໜຶ່ງເປັນທາງອ້ອມສຳລັບອີກຢ່າງ. ຄຳແນະນຳເຫຼົ່ານັ້ນໃຊ້ໄດ້ເມື່ອ kernel ທີ່ແນ່ນອນກັບມາ.
