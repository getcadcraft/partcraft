CraftScript ເປັນພາສາເມທຣິກທີ່ຖືກຂຽນໃຫ້ອ່ານຄ້າຍ MATLAB ດັ່ງນັ້ນໂຄ້ດຕົວເລກແບບດັ້ງເດີມສ່ວນໃຫຍ່ (ຕົວຢ່າງ ໂຄ້ດການປັບແຕ່ງໂຄງສ້າງ 88 ແຖວ) ສາມາດເຮັດວຽກໄດ້ດ້ວຍການແກ້ໄຂເລັກນ້ອຍເທົ່ານັ້ນ. ມັນເຮັດວຽກໃນ [ພື້ນທີ່ສະຄຣິບ](topic:craftscript) ແລະ ຈາກເສັ້ນຄຳສັ່ງ.

## ຄ່າ

| ປະເພດ | ຕົວຢ່າງ | ໝາຍເຫດ |
|---|---|---|
| ຕົວເລກ, ອາເຣ | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ທຸກຕົວເລກເປັນອາເຣ (ຂະໜາດ 1×1). ອາເຣຖືກເກັບແບບຖັນຕໍ່ຖັນ, ສູງສຸດ 8 ມິຕິ |
| ຕາມເງື່ອນໄຂ | `A > 2`, `true` | ອາເຣຄ່າ true/false; ໃຊ້ເປັນດັດຊະນີໄດ້ |
| ຂໍ້ຄວາມ | `'beam'`, `"beam"` | |
| ເມທຣິກກະຈາຍ | `sparse(i, j, v, n, n)` | ສຳລັບເມທຣິກຄວາມແຂງ |
| ເມຊ, ຟີລ໌ດ, ໂມເດວ | `hexGrid(…)`, `part()`, `load('part.stl')` | ສິ່ງທີ່ `show` ແຕ້ມ |
| ສະຕຣັກ | `s.E = 210e3` | ຟີລ໌ດທີ່ມີຊື່ |
| ເຊວ | `c = {1, 'two', [3 4]}` | ລາຍການຂອງຄ່າໃດກໍໄດ້ |
| ຕົວຈັບຟັງຊັນ | `f = @(x) x.^2` | |

## ອາເຣ ແລະ ການອ້າງດັດຊະນີ

- ຊ່ວງ: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- ການນັບດັດຊະນີເລີ່ມຈາກ 1: `A(2, 3)`, `v(end)`, `A(:, 1)` (ຖັນທັງໝົດ), `A(:)` (ທຸກຢ່າງເປັນຖັນດຽວ), `v(v > 0)` (ດັດຊະນີແບບເງື່ອນໄຂ).
- ການກຳນົດຄ່າເກີນທ້າຍຈະຂະຫຍາຍອາເຣ ເໝືອນໃນ MATLAB: `v(10) = 1`.

## ຕົວດຳເນີນການ

- `+ - * / \ ^` ເປັນການດຳເນີນການເມທຣິກ (`A \ b` ແກ້ສົມຜົນ); `.* ./ .^` ເຮັດວຽກເປັນອົງປະກອບໆ. `'` ເປັນການປ່ຽນຖ່າຍ.
- ການປຽບທຽບ `== ~= < <= > >=`; ຕາມເງື່ອນໄຂ `& | ~` (ເປັນອົງປະກອບໆ) ແລະ `&& ||` (ຢຸດທັນທີເມື່ອຮູ້ຜົນ).

## ການຄວບຄຸມລຳດັບ ແລະ ຟັງຊັນ

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ຟັງຊັນຖືກວາງໄວ້ໃນສະຄຣິບຫຼັງຄຳສັ່ງ, ຫຼື ໃນແທັບສະຄຣິບຂອງມັນເອງທີ່ຕັ້ງຊື່ຕາມຟັງຊັນ:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ການຄົ້ນຫາຊື່ເຮັດຕາມລຳດັບນີ້: ຕົວແປ, ສະຄຣິບໃນຊິ້ນສ່ວນນີ້ທີ່ມີຊື່ດັ່ງກ່າວ, ຟັງຊັນໃນຄັງ, ແລ້ວຟັງຊັນທີ່ມີມາໃນຕົວ.

## ການສະແດງຜົນ, ຄຳອະທິບາຍ, ຜົນອອກ

- ປະໂຫຍກທີ່ບໍ່ມີ `;` ຈະພິມຄ່າຂອງມັນ; `;` ເຮັດໃຫ້ມັນງຽບ.
- `%` ເລີ່ມຄຳອະທິບາຍ; `%{` ແລະ `%}` ທີ່ຢູ່ແຖວຂອງມັນເອງຈະໃສ່ຄຳອະທິບາຍໃຫ້ແຖວລະຫວ່າງສອງຕົວນັ້ນ.
- `disp(x)`, `fprintf('%g\n', x)` ແລະ `display(x)` ພິມອອກໄປທີ່ຄອນໂຊນ.

## ຂໍ້ຜິດພາດ ແລະ ຂີດຈຳກັດ

- ຂໍ້ຜິດພາດບອກວ່າມີຫຍັງຜິດດ້ວຍຖ້ອຍຄຳງ່າຍໆ ແລະ ບອກແຖວ (ພ້ອມລຳດັບການເອີ້ນຟັງຊັນ).
- ແຕ່ລະການຮັນມີ ງົບຂັ້ນຕອນ (ຕັ້ງໄດ້ໃນ Run options ຢູ່ແຜງ); ລູບທີ່ບໍ່ສິ້ນສຸດຈະຢຸດພ້ອມຂໍ້ຄວາມ, ຫຼື ກົດ [ຢຸດ](topic:craftscript).
- ອາເຣແຕ່ລະອັນເກັບໄດ້ສູງສຸດ 134 ລ້ານຄ່າ.

## ແຕກຕ່າງຈາກ MATLAB

- ຄຳສັ່ງແຜນທີ່ໃສ່ຕົວເລືອກຂອງມັນໄວ້ໃນການເອີ້ນ: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` ແລະ ຄຳສັ່ງທີ່ຄ້າຍຄືກັນ ຖືກຍອມຮັບ ແຕ່ບໍ່ເຮັດຫຍັງ.
- `input` ແລະ `keyboard` ບໍ່ຮອງຮັບ: ສະຄຣິບບໍ່ສາມາດຢຸດເພື່ອຖາມຄຳຖາມໄດ້.
- ບໍ່ມີຊຸດເຄື່ອງມືເສີມ; ສິ່ງທີ່ມີແມ່ນ [ຄັງການວິເຄາະ](topic:craftscript-library) ແລະ ຟັງຊັນທີ່ມີມາໃນຕົວ.
