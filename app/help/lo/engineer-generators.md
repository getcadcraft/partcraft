**ຕົວສ້າງ** ແມ່ນສະຄຣິບທີ່ກຳນົດຂະໜາດຊິ້ນສ່ວນຈາກຄວາມຕ້ອງການຂອງທ່ານ ແລະ ສ້າງມັນ. ຕົວສ້າງ heat exchanger ຮັບຄວາມຮ້ອນທີ່ຕ້ອງການຍ້າຍ, ສອງ flow ແລະ ອຸນຫະພູມຂອງມັນ, ຄວາມດັນ ແລະ ວັດສະດຸ; ມັນຄຳນວນວ່າແກນຕ້ອງໃຫຍ່ເທົ່າໃດ ແລະ ຝາໜາເທົ່າໃດ, ສ້າງມັນ, ແລະ ບອກຕົວເລກທີ່ມັນໃຊ້ ແລະ ມາຈາກໃສແຕ່ລະອັນ. ປ່ຽນ input ແລ້ວຊິ້ນສ່ວນຈະຕາມ.

ຜົນລັບແມ່ນ body ປົກກະຕິໃນຊິ້ນສ່ວນ: ມັນຢູ່ໃນລາຍການຄຸນສົມບັດ, ພິມໄດ້, ສົ່ງອອກໄດ້. ຕົວສ້າງເອງກໍຖືກເກັບໄວ້ໃນຊິ້ນສ່ວນເຊັ່ນກັນ, ດັ່ງນັ້ນໄຟລ໌ເປີດໄດ້ໃນຄອມພິວເຕີໃດກໍໄດ້ໂດຍບໍ່ຕ້ອງຕິດຕັ້ງຕົວສ້າງ, ແລະ **ການເປີດຊິ້ນສ່ວນບໍ່ເຄີຍເຮັດໃຫ້ສະຄຣິບເຮັດວຽກ**.

1. ເລືອກ workspace {{ui:Engineer}} ໃນຕົວສະຫຼັບ.

## ປ່ຽນມັນ

ປ່ຽນ input ໃດກໍໄດ້ ແລະ body ຈະຖືກສ້າງໃໝ່ບໍ່ດົນຫຼັງຈາກທ່ານຢຸດພິມ. ແຜງບອກວ່າໃນສາມສິ່ງນີ້ອັນໃດເປັນຈິງ:

- **Up to date**: body ກົງກັບສະຄຣິບ ແລະ input ຂອງມັນ.
- **The inputs changed**: body ໃນຊິ້ນສ່ວນມາຈາກ input ກ່ອນໜ້າ; ມັນກຳລັງຖືກສ້າງໃໝ່, ຫຼື ກົດ {{ui:Run}}.
- **Not run yet** ຫຼື **The last run failed**: ຂໍ້ຜິດພາດຂອງສະຄຣິບຈະສະແດງພ້ອມແຖວຂອງມັນ.

{{ui:Stop}} ຢຸດການເຮັດວຽກທີ່ໃຊ້ເວລາດົນເກີນໄປ. Undo ຍ້ອນກັບທີລະຂັ້ນ: ການເຮັດວຽກໜຶ່ງຄັ້ງແມ່ນໜຶ່ງຂັ້ນ, input ໜຶ່ງຄ່າແມ່ນໜຶ່ງຂັ້ນ.

## ແຜ່ນຂໍ້ມູນ

ທຸກຕົວເລກທີ່ຕົວສ້າງຄຳນວນໄດ້ຖືກລາຍການພ້ອມ **ຫົວໜ່ວຍ** ແລະ **ມາຈາກໃສ** (ສູດຕຳລາ, ມາດຕະຖານ, ແຜ່ນຂໍ້ມູນ). ບໍ່ມີຄ່າຄົງທີ່ທີ່ຖືກເຊື່ອງໄວ້. ແຜ່ນຂໍ້ມູນເປັນສ່ວນໜຶ່ງຂອງໄຟລ໌, ດັ່ງນັ້ນມັນຄືກັນໃນຄອມພິວເຕີເຄື່ອງຕໍ່ໄປ. [ຂໍ້ມູນສົ່ງອອກ](topic:data-out) ອະທິບາຍວິທີບັນທຶກມັນເປັນ JSON ຫຼື PDF.

## ການກວດ

ຕົວສ້າງສາມາດກວດຊິ້ນສ່ວນຂອງມັນກັບຂະບວນການພິມ: ຝາ ແລະ ຊ່ອງຫວ່າງທີ່ບາງກວ່າທີ່ຂະບວນການຮັບໄດ້, ຊິ້ນສ່ວນຫຼົມ, ຊ່ອງທີ່ກັກຜົງ ຫຼື ເຣຊິນ, ຮູທີ່ແຄບເກີນໄປທີ່ຈະໃຫ້ມັນຜ່ານໄດ້, ແລະ ສ່ວນຍື່ນທີ່ຕ້ອງການ support. ຜົນການກວດຢູ່ໃນແຜງ ແລະ ໃນລາຍການ {{ui:Problems}} (ປຸ່ມ ⚠), ແລະ ຖືກບັນທຶກກັບຊິ້ນສ່ວນ.

ຕົວເລກຂອງຂະບວນການແມ່ນຕົວເລກທົ່ວໄປທີ່ຄູ່ມືການອອກແບບສາທາລະນະໃຫ້ສຳລັບຂະບວນການໂດຍທົ່ວໄປ (FDM, SLA, SLS, metal powder bed). ພວກມັນ**ບໍ່ແມ່ນຂໍ້ມູນຈຳເພາະຂອງເຄື່ອງຂອງທ່ານ**: ປ່ຽນພວກມັນເປັນຕົວເລກຂອງໂຮງງານຂອງທ່ານກ່ອນພຶ່ງພາການກວດ. ການກວດເຮັດວຽກເທິງ grid ຂອງ voxel, ດັ່ງນັ້ນມັນຖືກຕ້ອງປະມານໜຶ່ງ voxel: ຝາຈະຖືກລາຍງານພຽງເມື່ອມັນບາງກວ່າຂີດຈຳກັດເກີນກວ່າໜຶ່ງ voxel.

## ການຄວບຄຸມການສົ່ງອອກ

ຕົວສ້າງ ແລະ ແຜ່ນຂໍ້ມູນຂອງ Engineer ມີປະກາດກ່ຽວກັບການຄວບຄຸມການສົ່ງອອກ ແລະ ການຄ່ຳບາດ. ອ່ານມັນໃນ [Engineer ແລະ ການຄວບຄຸມການສົ່ງອອກ](topic:engineer-export-notice); ມັນຢູ່ທ້າຍຂອງທຸກແຜ່ນຂໍ້ມູນເຊັ່ນກັນ.

## ຍັງບໍ່ໄດ້ສ້າງ

- Headers, ports ແລະ fittings ໃນແກນຂອງ heat exchanger: ມີແຕ່ແກນເທົ່ານັ້ນ.
- ເສັ້ນໂຄ້ງອຸນຫະພູມສຳລັບຄວາມແຂງແຮງຂອງວັດສະດຸ: ວັດສະດຸຢູ່ທີ່ອຸນຫະພູມຫ້ອງ.
- ການສູນເສຍຂອງ tee ແລະ ການແບ່ງ flow ລະຫວ່າງ outlets ໃນ manifold.
- ການເພີ່ມຕົວສ້າງຈາກ add-on directory ດ້ວຍການຄລິກດຽວ; ການເປີດໄຟລ໌ເພີ່ມໜຶ່ງອັນເຂົ້າບຣາວເຊີນີ້.
- ຕົວສ້າງສຳລັບແອັບອື່ນ.
