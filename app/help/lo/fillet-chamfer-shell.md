:::note
**ໃນເວີຊັນນີ້** PartCraft ສ້າງ fillet ແລະ chamfer ດ້ວຍ mesh kernel, ເທິງ **ຂອບເສັ້ນຊື່ລະຫວ່າງສອງໜ້າຮາບ** ເທົ່ານັ້ນ: ຂອບກ່ອງ ແລະຂອບເສັ້ນຊື່ຂອງ extrude ແລະ cut, ມຸມນອກ ຫຼືມຸມໃນ (ມຸມໃນຈະໄດ້ວັດຖຸເພີ່ມ). ຂອບມົນເຊັ່ນຂອບຮູ, ແລະລັດສະໝີທີ່ປ່ຽນຕາມຂອບ, ຍັງບໍ່ໄດ້ສ້າງ. ບ່ອນທີ່ຂອບມົນສອງອັນພົບກັນທີ່ມຸມ ການມົນຈະຖືກຕັດມຸມ (ພົບກັນເປັນຮອຍພັບຄົມ), ບໍ່ໄດ້ປະສານ. **Shell** ກໍເຮັດວຽກເຊັ່ນກັນ, ສ້າງໂດຍ mesh kernel: ມັນເປີດໄດ້ແຕ່ໜ້າຮາບ, ຝາທີ່ມີຄວາມໜາແຕກຕ່າງກັນຍັງບໍ່ໄດ້ສ້າງ, ແລະມັນຊ້າກັບຊິ້ນສ່ວນທີ່ມີຫຼາຍໜ້າກົມ. ເບິ່ງ [ສິ່ງທີ່ຍັງບໍ່ໄດ້ສ້າງ](topic:not-built-yet).
:::

{{ui:Fillet}} ມົນຂອບ, {{ui:Chamfer}} ລົບມຸມພວກມັນ ແລະ {{ui:Shell}} ເຈາະຊິ້ນສ່ວນເປັນຮູກາງ. ທັງສາມເຮັດວຽກກັບຂອບ ແລະໜ້າຂອງຕົວທຶບ ແລະຖືກສ້າງໂດຍ mesh kernel. ການມົນຂອງພວກມັນເປັນໜ້າຍ່ອຍເໝືອນໜ້າກົມທັງໝົດ (**Curves** ກຳນົດຄວາມລະອຽດ); ໜ້າກົມແມ່ນຊິລິນເດີທີ່ທ່ານສາມາດເລືອກ ແລະວັດໄດ້ (ເບິ່ງ [mesh kernel](topic:solid-kernels)).

## ມົນ ຫຼືລົບມຸມຂອບ

### ເລືອກຂອບກ່ອນ

1. ຄລິກຂອບຂອງຊິ້ນສ່ວນ. ທັງຂອບຈະເນັ້ນ, ແລະແຜງຂວາຈະບອກ **Edge**: ປະເພດຂອງມັນ (Straight, Circle or arc, Curve), ຄວາມຍາວ ແລະໜ້າທີ່ມັນຢູ່ລະຫວ່າງ.
2. ເພື່ອເພີ່ມຂອບ, ໃຫ້ {{key:Shift}}+ຄລິກພວກມັນ. ແຕ່ລະອັນຈະຖືກໝາຍ; {{key:Shift}}+ຄລິກຂອບທີ່ໝາຍແລ້ວເພື່ອເອົາມັນອອກ. ຫົວແຜງຈະນັບພວກມັນ ("4 edges") ແລະແຖບສະຖານະບອກວ່າ "4 edges picked. Fillet or Chamfer rounds them; Shift+click picks more, Esc clears."
3. ເລືອກ {{ui:Fillet}} ຫຼື {{ui:Chamfer}} ໃນແຖບເຄື່ອງມື, ຫຼືປຸ່ມດຽວກັນໃນແຜງຂວາ.

ຟີເຈີຖືກເພີ່ມດ້ວຍທຸກຂອບທີ່ເລືອກ: ມົນ 2 mm, ຫຼື chamfer 1 mm. ແຖບສະຖານະບອກ, ເຊັ່ນ: "Fillet1 added (4 edges). Change its size on the right; Pick edges changes which."

### ຫຼືເພີ່ມຟີເຈີກ່ອນ

1. ເມື່ອບໍ່ໄດ້ເລືອກຫຍັງ, ເລືອກ {{ui:Fillet}} ຫຼື {{ui:Chamfer}}.
2. PartCraft ຈະເຂົ້າສູ່ການເລືອກ: ຫົວແຜງຂວາຈະບອກ "Fillet1: picking", ຊິ້ນສ່ວນສະແດງຄືກັບກ່ອນ fillet (ແຜງຈະບອກແບບນັ້ນ), ແລະແຖບເຄື່ອງມືສະແດງ {{ui:Done}}.
3. ຄລິກແຕ່ລະຂອບເພື່ອເພີ່ມມັນ; ຄລິກມັນອີກຄັ້ງເພື່ອເອົາມັນອອກ. ແຖບສະຖານະນັບພວກມັນ.
4. ເລືອກ {{ui:Done}} (ຫຼື {{ui:Done picking}} ໃນແຜງ), ຫຼືກົດ {{key:Esc}} ຫຼື {{key:Enter}}.

### ການຕັ້ງຄ່າ

| ການຕັ້ງຄ່າ | Fillet | Chamfer |
|---|---|---|
| ຂະໜາດ | **Radius (mm)**, ຄ່າເລີ່ມຕົ້ນ 2 | **Distance (mm)** ຖອຍຈາກຂອບໄປທັງສອງໜ້າ, ຄ່າເລີ່ມຕົ້ນ 1 |
| **Edges** | ມີຈັກອັນ | ມີຈັກອັນ |

ລາຍຊື່ດ້ານລຸ່ມຕັ້ງຊື່ແຕ່ລະຂອບດ້ວຍສອງໜ້າທີ່ເຊື່ອມມັນ, ເຊັ່ນ "Edge 1: Extrude1 end face × Extrude1 side". **Remove** ເອົາອັນໜຶ່ງອອກ. {{ui:Pick edges}} ກັບໄປເລືອກ. ການດັບເບີ້ລຄລິກຟີເຈີໃນປະຫວັດກໍເຮັດແບບດຽວກັນ.

ຂອບຖືກຈື່ໄວ້ດ້ວຍສອງໜ້າທີ່ເຊື່ອມມັນ, ດັ່ງນັ້ນພວກມັນຍັງຢູ່ໃນຂອບທີ່ຖືກຕ້ອງເມື່ອທ່ານປ່ຽນມິຕິກ່ອນໜ້າໃນປະຫວັດ.

### ລັດສະໝີປ່ຽນແປງ ແລະປະເພດ chamfer

- **Variable radius** (fillet): ຍັງບໍ່ໄດ້ສ້າງໃນເວີຊັນນີ້ ("A fillet whose radius changes along the edge: not built yet (it needs an exact kernel). Give it one radius."). ເມື່ອມີ exact kernel: ຕິກມັນ ແລ້ວຕັ້ງ **End radius (mm)**. ລັດສະໝີຈະປ່ຽນເປັນເສັ້ນຊື່ຈາກ **Radius** ປາຍໜຶ່ງຂອງແຕ່ລະຂອບ ໄປຫາ **End radius** ອີກປາຍໜຶ່ງ; **Swap the ends** ປີ້ນມັນ.
- **Type** (chamfer): **Equal distance** (ໄລຍະເທົ່າກັນ), **Two distances** (ໄລຍະສອງ, ມີ **Second distance** ຢູ່ອີກໜ້າ) ຫຼື **Distance and angle** (ໄລຍະຢູ່ໜ້າໜຶ່ງ, ແລະມຸມລົບ **Angle (°)** ຕໍ່ໜ້ານັ້ນ). **Flip sides** ໃຫ້ໄລຍະທຳອິດຢູ່ອີກໜ້າ.

## ເຈາະຊິ້ນສ່ວນດ້ວຍ Shell

1. ຄລິກໜ້າຮາບທີ່ຈະປ່ອຍໃຫ້ເປີດ, ຕົວຢ່າງດ້ານເທິງຂອງກ່ອງ. ຫຼື {{key:Shift}}+ຄລິກຫຼາຍໜ້າ.
2. ເລືອກ {{ui:Shell}} ໃນແຖບເຄື່ອງມື, ຫຼື {{ui:Shell, opening this face}} ໃນແຜງຂອງໜ້ານັ້ນ.

ຊິ້ນສ່ວນຈະກາຍເປັນຝາໜາ 2 mm ໂດຍມີໜ້າທີ່ເລືອກເປີດຢູ່. ການຕັ້ງຄ່າ:

| ການຕັ້ງຄ່າ | ມັນເຮັດຫຍັງ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| **Wall (mm)** | ຄວາມໜາຂອງຝາ | 2 |
| **Walls grow outward (the faces stay inside)** | ຕິກແລ້ວ: ຝາຖືກເພີ່ມດ້ານນອກ, ດັ່ງນັ້ນດ້ານໃນຮັກສາຂະໜາດຂອງຊິ້ນສ່ວນ | ປິດ: ຝາໄປທາງໃນ ແລະດ້ານນອກຮັກສາຂະໜາດຂອງມັນ |
| **Open faces** | ມີກີ່ໜ້າທີ່ຖືກເອົາອອກ | |

ທາງໃນ, ຝາຈະໜາເທົ່າຄວາມໜາຝາຢ່າງແທ້ຈິງ: ມຸມນອກຍັງຄົມ, ມຸມໃນຈະມົນ (ລັດສະໝີ = ຝາ), ແລະຮູທະລຸຜ່ານຊິ້ນສ່ວນຈະໄດ້ທໍ່ຝາຢູ່ອ້ອມມັນ. ທາງນອກ, ຝາຈະຖືກເພີ່ມນອກຜິວເດີມ, ເຊິ່ງກາຍເປັນຮູກາງ, ແລະຂອບດ້ານນອກຈະມົນ. ໜ້າດ້ານໃນຈະຖືກຕັ້ງຊື່ຕາມໜ້າທີ່ພວກມັນຊົດເຊີຍ, ດັ່ງນັ້ນທ່ານສາມາດເລືອກພວກມັນໄດ້.

ມີແຕ່ໜ້າຮາບເທົ່ານັ້ນທີ່ເປີດໄດ້: ຖ້າເລືອກໜ້າໂຄ້ງ ຈະບອກວ່າ "Shell: ໃນເວີຊັນນີ້ມັນເປີດໄດ້ແຕ່ໜ້າຮາບເທົ່ານັ້ນ (mesh kernel ສ້າງມັນ)." Shell ຊ້າກັບຊິ້ນສ່ວນທີ່ມີຫຼາຍໜ້າກົມ (ຫຼາຍວິນາທີຕໍ່ລ້ານສາມຫຼ່ຽມ): ໃຫ້ໃຊ້ການຕັ້ງຄ່າ **Curves** ທີ່ຫຍາບກວ່າໃນຂະນະອອກແບບ.

{{ui:Pick faces}} ປ່ຽນໜ້າທີ່ເປີດ, ຄືກັບການເລືອກຂອບ. ລາຍຊື່ຕັ້ງຊື່ແຕ່ລະອັນ, ເຊັ່ນ "Face 1: Extrude1 end face". Shell ທີ່ບໍ່ມີໜ້າເປີດເລີຍບໍ່ໄດ້ຮັບອະນຸຍາດ: "ເລືອກໜ້າທີ່ຈະເອົາອອກ (ເປີດ), ແລ້ວ shell."

## ລຳດັບສຳຄັນ

ຟີເຈີຖືກສ້າງຈາກເທິງລົງລຸ່ມ. Fillet ທີ່ຢູ່ກ່ອນ shell ຈະຖືກ shell ພ້ອມຊິ້ນສ່ວນ, ດັ່ງນັ້ນດ້ານໃນຈະມີມຸມມົນເຊັ່ນກັນ. Fillet ທີ່ຢູ່ຫຼັງ shell ຈະມົນພຽງແຕ່ຂອບທີ່ທ່ານເລືອກ. ຍ້າຍຟີເຈີດ້ວຍ {{ui:Move up}} ແລະ {{ui:Move down}} (ເບິ່ງ [ປ່ຽນຊິ້ນສ່ວນຜ່ານປະຫວັດຂອງມັນ](topic:edit-history)).

Pattern ແລະ mirror ບໍ່ສາມາດສຳເນົາ fillet, chamfer ຫຼື shell ໄດ້: "Fillet1 changes the body's edges or walls; it cannot be copied. Copy the features that make solids (extrudes, revolves, holes, imports)." › "Fillet1 ປ່ຽນຂອບ ຫຼືຝາຂອງຕົວວັດຖຸ; ມັນບໍ່ສາມາດສຳເນົາໄດ້. ໃຫ້ສຳເນົາຟີເຈີທີ່ສ້າງຕົວທຶບ (extrude, revolve, hole, ການນຳເຂົ້າ)." ໃຫ້ຈັດຮູບແບບຮູ ຫຼື cut ກ່ອນ, ແລ້ວ fillet ທຸກຂອບຂອງສຳເນົາທັງໝົດໃນ fillet ດຽວ.

## ຂໍ້ຈຳກັດ

ໃນເວີຊັນນີ້ fillet ແລະ chamfer ເຮັດວຽກໄດ້ແຕ່ຂອບເສັ້ນຊື່ລະຫວ່າງສອງໜ້າຮາບ, ດ້ວຍລັດສະໝີດຽວ, ແລະການມົນທີ່ພົບກັນທີ່ມຸມຈະຖືກຕັດມຸມ. Shell ເປີດໄດ້ແຕ່ໜ້າຮາບ. ດ້ວຍ exact kernel, fillet ທີ່ປ່ຽນແປງຈະປ່ຽນເປັນເສັ້ນຊື່ຕາມແຕ່ລະຂອບ (ກົດດຽວຕໍ່ຟີເຈີ; ບໍ່ມີລັດສະໝີກຳນົດຢູ່ຈຸດຕາມຂອບ). Fillet ໜ້າ, fillet ມົນເຕັມ ແລະ shell ທີ່ມີຄວາມໜາຝາຕ່າງກັນຍັງບໍ່ໄດ້ສ້າງ.
