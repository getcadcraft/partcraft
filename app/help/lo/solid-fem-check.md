## ສິ່ງທີ່ທ່ານຈະເຮັດ

ກວດຊິ້ນສ່ວນແຂງໜຶ່ງອັນພາຍໃຕ້ແຮງ: ມັນເຄື່ອນໄປໃສ ແລະ ຄວາມເຄັ່ງສູງສຸດຢູ່ໃສ. ການຄຳນວນເປັນແບບເສັ້ນຊື່ ແລະ ຍືດຫຍຸ່ນ, ດັ່ງນັ້ນມັນເປັນເຄື່ອງຊ່ວຍກວດ; ວິສະວະກອນຂອງທ່ານຕ້ອງທົບທວນຜົນ.

## ຂັ້ນຕອນ

1. ເລືອກ {{ui:Settings}} › {{ui:Add-ons}} ແລ້ວເປີດ Solid FEM (ມັນປິດຢູ່ຈົນກວ່າທ່ານຈະເປີດ). ເປີດແຖບ Solid FEM ໃນແຖບດ້ານຂວາ.
2. ໃຕ້ {{ui:Material}} ໃຫ້ເລືອກວັດສະດຸ, ຫຼື {{ui:Custom}} ແລ້ວພິມອັດຕາສ່ວນ Poisson, ຄວາມໜາແໜ້ນ ແລະ ຄວາມເຄັ່ງຈຸດຄວາມຍຶດ.
3. ກົດ ເພີ່ມໜ້າທີ່ຍຶດໄວ້, ຄລິກໜ້າທີ່ຖືຢູ່ໃນມຸມມອງ 3D, ແລ້ວກົດ {{ui:Done picking}}.
4. ເພີ່ມແຮງດ້ວຍ ເພີ່ມແຮງ, ເພີ່ມແຮງດັນ ຫຼື ເພີ່ມແຮງໂນ້ມຖ່ວງ ແລ້ວເລືອກໜ້າຂອງມັນໃນວິທີດຽວກັນ.
5. ກົດ ແບ່ງຕາໜ່າງຊິ້ນສ່ວນ, ແລ້ວ {{ui:Solve}}. ເລືອກ {{ui:Natural frequencies}} ພາຍໃຕ້ {{ui:Study}} ກ່ອນ ຖ້າທ່ານຕ້ອງການຄວາມຖີ່.
6. ອ່ານ {{ui:Results}} ແລະ {{ui:Warnings}}, ແລ້ວກົດ ສະແດງເທິງໂມເດວ ເພື່ອແຕ້ມຄວາມເຄັ່ງ von Mises, ການເຄື່ອນຕົວ ຫຼື ຮູບແບບການສັ່ນ; ເອົາຜັງອອກ ຈະລຶບມັນອອກ.

## ໝາຍເຫດ

- ໜ້າເວັບຈະແກ້ສົມການສູງສຸດໄດ້ຈຳນວນ element ທີ່ກຳນົດໄວ້; ແຖບສະຖານະຈະບອກເມື່ອຂະໜາດ element ຂອງທ່ານລະອຽດເກີນໄປ.
- ຄວາມເຄັ່ງຢູ່ໜ້າທີ່ຍຶດໄວ້, ຈຸດແຮງ ແລະ ມຸມແຫຼມຈະເພີ່ມຂຶ້ນເມື່ອຕາໜ່າງລະອຽດຂຶ້ນ. ໃຫ້ປັບລະອຽດ ແລະ ປຽບທຽບກ່ອນທີ່ຈະເຊື່ອຄ່າສູງສຸດ.
- ທຸກການປ່ຽນແປງເປັນຂັ້ນຕອນ undo ໜຶ່ງ, ແລະ ການຕັ້ງຄ່າຈະຖືກບັນທຶກໄວ້ໃນໄຟລ໌ຊິ້ນສ່ວນ.
- ສຳລັບການສຶກສາການໄຫຼ ແລະ ການສຳຜັດ ເບິ່ງ [ກວດຄວາມເຄັ່ງ ແລະ ການໂກ່ງ](topic:simulation).
