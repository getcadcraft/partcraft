ຟີເຈີຖືກລາຍຊື່ໃນປະຫວັດຕາມລຳດັບທີ່ສ້າງ ແລະຖືກສ້າງຄືນຈາກເທິງລົງລຸ່ມ. ແຕ່ລະອັນຖືກຕັ້ງຊື່ຕາມປະເພດຂອງມັນພ້ອມເລກ: Sketch1, Extrude1, Revolve1, Hole1, LPattern1, CirPattern1, Mirror1, Fillet1, Chamfer1, Shell1, Imported1.

PartCraft ສ້າງທຸກຟີເຈີດ້ວຍ mesh kernel. Fillet ແລະ Chamfer ເຮັດວຽກກັບຂອບເສັ້ນຊື່ລະຫວ່າງສອງໜ້າຮາບ, ແລະ Shell ເປີດໜ້າຮາບ. ຕົວທຶບທີ່ນຳເຂົ້າຕ້ອງການ exact kernel, ເຊິ່ງເວີຊັນນີ້ບໍ່ມີ: ພວກມັນຍັງບໍ່ໄດ້ສ້າງ, ແລະພາກດ້ານລຸ່ມອະທິບາຍວ່າຊິ້ນສ່ວນທີ່ສ້າງໃນເວີຊັນກ່ອນໜ້າຈະເກັບພວກມັນໄວ້ແນວໃດ. ເບິ່ງ [mesh kernel](topic:solid-kernels) ແລະ [ສິ່ງທີ່ຍັງບໍ່ໄດ້ສ້າງ](topic:not-built-yet).

## Extrude ແລະ Cut

{{ui:Extrude}} ແລະ {{ui:Cut}} ສ້າງຟີເຈີດຽວກັນ, ເລີ່ມດ້ວຍການຕັ້ງຄ່າທີ່ແຕກຕ່າງກັນ.

| ການຕັ້ງຄ່າ | ທາງເລືອກ | Extrude ເລີ່ມທີ່ | Cut ເລີ່ມທີ່ |
|---|---|---|---|
| Operation | Boss (ເພີ່ມວັດຖຸ), Cut (ເອົາວັດຖຸອອກ), Intersect (ເກັບສ່ວນທີ່ທັບກັນ), New body (ຍັງບໍ່ໄດ້ສ້າງໃນເວີຊັນນີ້) | Boss | Cut |
| End | Blind (ຕາມຄວາມເລິກ), Mid-plane (ກາງລະນາບ, ສອງດ້ານ), Through all (ທະລຸທັງໝົດ) | Blind | Through all |
| Depth (mm) | ຫຼາຍກວ່າ 0, ເຖິງ 1,000,000 | 10 | 10 |
| Reverse direction | ປິດ / ເປີດ | ປິດ | ປິດ |

- ໂປຣໄຟລ໌: ທຸກວົງປິດຂອງເສັ້ນທຶບ, ວົງມົນ ແລະໂຄ້ງໃນພາບຮ່າງ. ວົງຢູ່ໃນວົງເປັນຮູ.
- Through all ໃຊ້ໄດ້ສະເພາະການຕັດ. ມັນທະລຸຕະຫຼອດຊິ້ນສ່ວນໄປທາງດ້ານທີ່ເລືອກ.
- ການຕັດເຂົ້າໄປໃນວັດຖຸ, ອອກຈາກດ້ານນອກຂອງລະນາບພາບຮ່າງ; Reverse ປີ້ນມັນ.

## Revolve ແລະ revolved cut

| ການຕັ້ງຄ່າ | ທາງເລືອກ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| Operation | Boss, Cut | Boss ({{ui:Revolve}}), Cut ({{ui:More}} › {{ui:Revolved cut}}) |
| Angle (°) | ຫຼາຍກວ່າ 0, ເຖິງ 360 | 360 |
| Axis | ເສັ້ນສູນກາງທຳອິດ, ເສັ້ນ ຫຼືເສັ້ນສູນກາງໃດໆຂອງພາບຮ່າງ, ຫຼືຟີເຈີແກນທີ່ຢູ່ໃນລະນາບຂອງພາບຮ່າງ | ເສັ້ນສູນກາງທຳອິດ |

- ໂປຣໄຟລ໌ຕ້ອງຢູ່ດ້ານດຽວຂອງແກນ. ມັນອາດຈະແຕະແກນໄດ້.
- ແກນຂອງ revolve ສາມາດໃຊ້ໂດຍ Circular pattern ແລະ joint ການປະກອບ.

## Hole

| ການຕັ້ງຄ່າ | ທາງເລືອກ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| Type | Simple (ທຳມະດາ), Counterbore (ຮູຂັ້ນ) | Simple |
| Diameter (mm) | ຫຼາຍກວ່າ 0 | 6 |
| Through all | ເປີດ / ປິດ | ເປີດ |
| Depth (mm) | ເມື່ອ Through all ປິດ | 10 |
| Counterbore ⌀ | ກວ້າງກວ່າຮູ | 11 |
| Counterbore depth | ຕື້ນກວ່າຮູຕາມຄວາມເລິກ | 6 |

- ຮູໜຶ່ງຢູ່ທຸກຈຸດທີ່ບໍ່ໄດ້ຕິດຢູ່ໃນພາບຮ່າງ (ຈຸດທີ່ສ້າງດ້ວຍເຄື່ອງມືຈຸດ). ແຜງຈະສະແດງຈຳນວນ.
- ຮູເຈາະຕັ້ງສາກກັບລະນາບພາບຮ່າງ, ເຂົ້າໄປໃນວັດຖຸ.
- ແກນຂອງແຕ່ລະຮູສາມາດໃຊ້ໂດຍ joint ການປະກອບ ("Hole1, hole 2").

## Fillet ແລະ Chamfer

ໃນເວີຊັນນີ້ mesh kernel ສ້າງພວກມັນເທິງຂອບເສັ້ນຊື່ລະຫວ່າງສອງໜ້າຮາບ (ມຸມນອກ ຫຼືມຸມໃນ), ດ້ວຍລັດສະໝີດຽວ. ຂອບມົນໂຄ້ງຈະບອກວ່າ "Fillet: ໃນເວີຊັນນີ້ມີແຕ່ຂອບເສັ້ນຊື່ລະຫວ່າງສອງໜ້າຮາບເທົ່ານັ້ນ (mesh kernel ສ້າງພວກມັນ). ໃຫ້ມົນ ຫຼືລົບມຸມຂອບໂຄ້ງໃນພາບຮ່າງ." ບ່ອນທີ່ຂອບມົນພົບກັນທີ່ມຸມ ພວກມັນຖືກຕັດມຸມ, ແລະຟີເຈີຈະເຕືອນ "Fillet ໂດຍ mesh kernel: ບ່ອນທີ່ຂອບມົນພົບກັນ ພວກມັນຖືກຕັດມຸມ, ບໍ່ໄດ້ປະສານ." ທຸກປະເພດຂອງ Chamfer ເຮັດວຽກໄດ້ (ໄລຍະເທົ່າກັນ, ສອງໄລຍະ, ໄລຍະ ແລະມຸມ, ພ້ອມ **Flip sides**). ເບິ່ງ [ມົນ, ລົບມຸມ ແລະເຈາະເປັນຮູກາງ](topic:fillet-chamfer-shell).

| ການຕັ້ງຄ່າ | ທາງເລືອກ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| Radius (mm) (Fillet) | ຫຼາຍກວ່າ 0 | 2 |
| Distance (mm) (Chamfer) | ຫຼາຍກວ່າ 0, ເທົ່າກັນທັງສອງໜ້າ | 1 |
| Edges | ຂອບທີ່ເລືອກ, ແຕ່ລະອັນຖືກລາຍຊື່ດ້ວຍສອງໜ້າທີ່ເຊື່ອມມັນ ("Extrude1 end face × Extrude1 side"), ພ້ອມ **Remove** | ຂອບທີ່ເລືອກຕອນເພີ່ມ |

- ເລືອກຂອບກ່ອນເລືອກປຸ່ມ (ໃຊ້ {{key:Shift}}+ຄລິກສຳລັບຫຼາຍອັນ), ຫຼືເລືອກມັນໂດຍບໍ່ມີຫຍັງຖືກເລືອກ ແລ້ວຄລິກຂອບພາຍຫຼັງ.
- {{ui:Pick edges}} (ຫຼືດັບເບີ້ລຄລິກຟີເຈີ) ປ່ຽນຂອບ.
- ຂອບຖືກຈື່ໄວ້ດ້ວຍສອງໜ້າທີ່ເຊື່ອມມັນ, ສະນັ້ນພວກມັນຢູ່ລອດເມື່ອປ່ຽນຂະໜາດກ່ອນໜ້າ.

## Shell

mesh kernel ສ້າງມັນ. ມີແຕ່ໜ້າຮາບເທົ່ານັ້ນທີ່ເປີດໄດ້ ("Shell: ໃນເວີຊັນນີ້ມັນເປີດໄດ້ແຕ່ໜ້າຮາບເທົ່ານັ້ນ (mesh kernel ສ້າງມັນ)."); ຝາທີ່ມີຄວາມໜາຕ່າງກັນຍັງບໍ່ໄດ້ສ້າງ. ເບິ່ງ [ມົນ, ລົບມຸມ ແລະເຈາະເປັນຮູກາງ](topic:fillet-chamfer-shell).

| ການຕັ້ງຄ່າ | ທາງເລືອກ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| Wall (mm) | ຫຼາຍກວ່າ 0 | 2 |
| Walls grow outward (the faces stay inside) | ປິດ: ຝາໄປທາງໃນ. ເປີດ: ຝາໄປທາງນອກ | ປິດ |
| Open faces | ໜ້າທີ່ຖືກເອົາອອກ, ຢ່າງໜ້ອຍໜຶ່ງ, ພ້ອມ **Remove** | ໜ້າທີ່ເລືອກຕອນເພີ່ມ |

## ຕົວທຶບທີ່ນຳເຂົ້າ

ສ້າງໂດຍການເປີດໄຟລ໌ STEP, STL, OBJ ຫຼື 3MF: ຕົວວັດຖຸຕັນທຶບຂອງສາມຫຼ່ຽມທີ່ບໍ່ມີປະຫວັດຂອງຕົນເອງ ([ເປີດໄຟລ໌ STEP](topic:import-step), [ເປີດ STL, OBJ ຫຼື 3MF](topic:open-meshes)). ມັນສະແດງໄຟລ໌ທີ່ມາຂອງມັນ ແລະສິ່ງທີ່ການນຳເຂົ້າແກ້ໄຂ; **Units in the file**, **Up in the file** ແລະ **Use it to** ຍັງແກ້ໄຂໄດ້. ຕົວທຶບ STEP ທີ່ນຳເຂົ້າໂດຍເວີຊັນເກົ່າທີ່ມີ exact kernel ຈະຢູ່ໃນປະຫວັດ ໝາຍວ່າຍັງບໍ່ໄດ້ສ້າງ; ເປີດໄຟລ໌ STEP ອີກຄັ້ງເພື່ອນຳມັນເຂົ້າມາເປັນສາມຫຼ່ຽມ.

| ການຕັ້ງຄ່າ | ທາງເລືອກ | ຄ່າເລີ່ມຕົ້ນ |
|---|---|---|
| Up in the file | Z up (CAD ສ່ວນຫຼາຍ), Y up | Z up |

ການຈັດລຽງຮູບແບບ ແລະ mirror ສາມາດສຳເນົາຕົວທຶບທີ່ນຳເຂົ້າໄດ້, ແຕ່ບໍ່ແມ່ນ fillet, chamfer ຫຼື shell.

## ການຕັ້ງຄ່າຊິ້ນສ່ວນ

ຄລິກບ່ອນຫວ່າງເພື່ອບໍ່ໃຫ້ມີຫຍັງຖືກເລືອກ. ແຜງຂວາສະແດງ **Part**:

- **Name**: ຊື່ຂອງຊິ້ນສ່ວນ, ໃຊ້ສຳລັບຊື່ໄຟລ໌ ແລະບລັອກຫົວເລື່ອງຂອງແບບແຕ້ມ (ສູງສຸດ 120 ຕົວອັກສອນ).
- **Curves**: ເບິ່ງຂ້າງລຸ່ມ.

### ຄວາມລະອຽດຂອງ Curves

mesh kernel ສ້າງຕົວທຶບເອງຈາກໜ້າຍ່ອຍຮາບ, ສະນັ້ນມຸມມອງ, STL, 3MF, STEP ແບບ faceted, ປະລິມາດ ແລະມຸມມອງແບບແຕ້ມທັງໝົດຕາມ **Curves**: ມີກີ່ໜ້າຍ່ອຍຕໍ່ຮອບເຕັມ.

| ການຕັ້ງຄ່າ | ໜ້າຍ່ອຍຕໍ່ຮອບ | ປະລິມາດຂອງຮູບກົມ |
|---|---|---|
| Coarse (32 per turn) | 32 | ປະມານ 0.64 % ຕ່ຳກວ່າຄ່າແທ້ |
| Normal (64 per turn) | 64 | ປະມານ 0.16 % ຕ່ຳກວ່າ (ຄ່າເລີ່ມຕົ້ນ) |
| Fine (128 per turn) | 128 | ປະມານ 0.04 % ຕ່ຳກວ່າ |
| Very fine (256 per turn) | 256 | ປະມານ 0.01 % ຕ່ຳກວ່າ |

Curves ທີ່ລະອຽດກວ່າໃຫ້ການສົ່ງອອກ ແລະມຸມມອງທີ່ລຽບກວ່າ, ແຕ່ການສ້າງຄືນຊ້າກວ່າ. ການຕັ້ງຄ່ານີ້ຖືກບັນທຶກໄວ້ໃນໄຟລ໌ຊິ້ນສ່ວນ.

## ຍັງບໍ່ໄດ້ສ້າງ

fillet ທີ່ລັດສະໝີປ່ຽນແປງ, fillet ແລະ chamfer ເທິງຂອບມົນ, shell ທີ່ເປີດໜ້າໂຄ້ງ, draft ເທິງໜ້າໂຄ້ງ, sweep, loft, rib, ຕົວທຶບ STEP ທີ່ມີໜ້າໂຄ້ງແທ້, ຕົວວັດຖຸໃໝ່, taper, "up to" ໜ້າ ຫຼືຈຸດຍອດ, ແລະການອ້າງອິງໃນໜ້າ ແລະຂອບຂອງຕົວທຶບ ຕ້ອງການ exact kernel, ເຊິ່ງເວີຊັນນີ້ບໍ່ມີ. ຍັງບໍ່ໄດ້ສ້າງເຊັ່ນກັນ: ຮູເກລຽວ (tapped) ແລະຮູຈົມ (countersunk). ເບິ່ງ [ສິ່ງທີ່ຍັງບໍ່ໄດ້ສ້າງ](topic:not-built-yet).
