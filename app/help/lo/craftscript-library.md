ຄັງການວິເຄາະແມ່ນຊຸດສະຄຣິບ, ແຕ່ລະອັນເປັນຟັງຊັນທີ່ທ່ານອ່ານຈາກເທິງລົງລຸ່ມໄດ້: ເມທຣິກຄວາມແຂງຖືກປະກອບແນວໃດ, ເງື່ອນໄຂຂອບເຂດຢູ່ໃສ, ຕົວແກ້ສົມຜົນໃດເຮັດວຽກ, ຜົນລັບຖືກຄຳນວນແນວໃດ. ບໍ່ມີຫຍັງຖືກເຊື່ອງໄວ້ໃນກ່ອງດຳ; ມີພຽງສ່ວນວົງໃນທີ່ເຮັດຊ້ຳໄວ (ເມທຣິກອົງປະກອບ, ຕົວແກ້ແບບກະຈາຍ, ການສ້າງເມຊ) ທີ່ຖືກສ້າງໄວ້ໃນຕົວ.

## ເລີ່ມດ້ວຍຕົວຢ່າງ

ກຸ່ມ **ຕົວຢ່າງ** ມີສະຄຣິບສັ້ນ 5 ອັນທີ່ໃຊ້ຄັງຕັ້ງແຕ່ຕົ້ນຈົນຈົບ. ກົດອັນໜຶ່ງ, ກົດ [ເປີດ (ອ່ານຢ່າງດຽວ)](topic:craftscript-library), ແລ້ວກົດ {{key:F5}}: ແຕ່ລະອັນຈະລ້າງມຸມມອງ, ສະແດງຜົນໃນພື້ນທີ່ແຕ້ມ ແລະ ແຜນທີ່ໃນໜ້າຈໍຍ່ອຍ.

| ຕົວຢ່າງ | ສະແດງຫຍັງ |
|---|---|
| ຄວາມເຄັ້ນຂອງຄານຍື່ນ | ແທ່ງເຫຼັກ 100 × 10 × 10 mm ພາຍໃຕ້ແຮງປາຍ 100 N: ຄວາມເຄັ້ນ von Mises ໃນແທ່ງທີ່ຖືກໂກ່ງ, ແລະ ການໂກ່ງປາຍທຽບກັບທິດສະດີຄານ ທີ່ຂະໜາດອົງປະກອບ 4 ຂະໜາດ (ມີແຜນທີ່) |
| ການປັບແຕ່ງໂຄງສ້າງ MBB | ການປັບແຕ່ງໂຄງສ້າງ 60 × 20 ແບບດັ້ງເດີມ: ການສ້າງຮູບແບບ, ຄວາມຍືດຫຍຸ່ນທີ່ຫຼຸດລົງ, ຜັງສຸດທ້າຍ (94 ຮອບການຄຳນວນ, ຄວາມຍືດຫຍຸ່ນ 203.19) |
| ຟີລ໌ດຂອງຕົວເກັບປະຈຸ | ແຜ່ນສອງອັນກວ້າງ 4 mm, ຫ່າງກັນ 1 mm: ຄວາມຕ່າງຟັງຊັນ ແລະ ສະໜາມ, ຄວາມຈຸໄຟຟ້າພ້ອມຜົນຂອບ ທຽບກັບຄ່າໃນອຸດົມຄະຕິ ແລະ ສູດຂອງ Palmer |
| ການໄຫຼໃນຊ່ອງ | ການໄຫຼ lattice Boltzmann ຜ່ານເສົາໃນຊ່ອງ: ຟີລ໌ດຄວາມໄວ ແລະ ປະຫວັດການລູ່ເຂົ້າ |
| ແມ່ເຫຼັກໄຟຟ້າ | ແກນເຫຼັກຮູບຕົວ C ທີ່ມີຊ່ອງວ່າງອາກາດ ແລະ ຂົດລວດ: ຄວາມໜາແໜ້ນຟລັກ, ສະໜາມໃນຊ່ອງວ່າງທຽບກັບສູດວົງຈອນແມ່ເຫຼັກ, ອິນດັກແທນ ແລະ ແຮງດຶງຂ້າມຊ່ອງວ່າງ. ອະທິບາຍໃນ [ສະໜາມແມ່ເຫຼັກ 2-D](topic:magnetic-fields-2d) |
| ແມ່ເຫຼັກຖາວອນ | ແກນດຽວກັນແຕ່ໃຊ້ແມ່ເຫຼັກຖາວອນແທນຂົດລວດ: ຈຸດເຮັດວຽກຂອງແມ່ເຫຼັກ, ສະໜາມໃນຊ່ອງວ່າງທຽບກັບວົງຈອນແມ່ເຫຼັກ, ຟລັກທີ່ຮົ່ວໄຫຼ, ແຮງດຶງ. ໃນ [ສະໜາມແມ່ເຫຼັກ 2-D](topic:magnetic-fields-2d#permanent-magnets) |

## ກຸ່ມ

| ກຸ່ມ | ຟັງຊັນ | ມັນເຮັດຫຍັງ |
|---|---|---|
| ການສ້າງເມຊ | `box_mesh`, `cylinder_mesh`, `voxel_mesh`, `tet_mesh`, `mesh_quality`, `nodes_at`, `face_nodes` | ກ່ອງ ແລະ ຊິລິນເດີເປັນເฮກຊາເຮດຣອນ, ລູກບາດ ຫຼື ເຕຕຣາເຮດຣອນ; ລູກບາດ ຫຼື ເຕຕຣາເຮດຣອນຂອງໂມເດວໃດກໍໄດ້ (ຊິ້ນສ່ວນ, ວັດຖຸ, STL ທີ່ໂຫຼດແລ້ວ); ປະລິມາດອົງປະກອບ ແລະ ຄຸນນະພາບ; ການເລືອກໂນດຢູ່ໜ້າຕັດ ຫຼື ໜ້າ |
| ຄວາມເຄັ້ນສະຖິດ | `static_voxel`, `static_tet` | ຄວາມເຄັ້ນສະຖິດເສັ້ນຊື່ເທິງລູກບາດ ຫຼື ເຕຕຣາເຮດຣອນ 10 ໂນດ: ການເຄື່ອນຕົວ, ຄວາມເຄັ້ນ, von Mises, ແຮງປະຕິກິລິຍາ |
| ໂຄງຖັກ | `frame3d` | ໂຄງຖັກ 3D ຂອງຄານ, ເສົາ ແລະ ຄ້ຳຢັນ ດ້ວຍວິທີຄວາມແຂງໂດຍກົງ: ການປົດປ່ອຍປາຍ, ຕົວຮອງຮັບ ແລະ ສະປຣິງ, ແຮງຕາມສະມາຊິກ; ການເຄື່ອນຕົວ, ແຮງປະຕິກິລິຍາ, ແຮງປາຍຂອງສະມາຊິກ. ການສົ່ງອອກ CraftScript ຂອງ {{ui:Export as CraftScript}} ໃນ DetailCraft ແລະ BimCraft ຂຽນໂມເດວທັງໝົດໃຫ້ມັນ. ເປັນເຄື່ອງຊ່ວຍວິເຄາະ, ບໍ່ແມ່ນການກວດສອບໂຄດ |
| ການສັ່ນ | `modal_tet` | ຄວາມຖີ່ທຳມະຊາດ ແລະ ຮູບແບບການສັ່ນ |
| ຄວາມຮ້ອນ | `heat_steady`, `heat_transient`, `heat_system` | ການນຳຄວາມຮ້ອນແບບຄົງທີ່ ແລະ ແບບຊົ່ວຄາວ ດ້ວຍອຸນຫະພູມຄົງທີ່, ການໃສ່ຄວາມຮ້ອນ, ການກຳເນີດ, ຟລັກ ແລະ ການພາ |
| ການປັບແຕ່ງໂຄງສ້າງ | `top88`, `top99`, `topopt3d` | ໂຄ້ດ 2-D 88 ແລະ 99 ແຖວທີ່ຖືກເຜີຍແຜ່, ແລະ ວິທີດຽວກັນໃນ 3-D ໃນລູກບາດ |
| ແມ່ເຫຼັກໄຟຟ້າ | `poisson2d`, `magnetostatic2d` | ໄຟຟ້າສະຖິດ 2-D (ຄວາມຕ່າງຟັງຊັນ, ສະໜາມ, ຄວາມຈຸ, ປະຈຸ) ແລະ ແມ່ເຫຼັກສະຖິດ (ເວກເຕີຕ່າງຟັງຊັນ, ຄວາມໜາແໜ້ນຟລັກ, ແມ່ເຫຼັກຖາວອນ) |
| ການໄຫຼຂອງຂອງເຫຼວ | `lbm2d`, `lbm3d` | ການໄຫຼ lattice Boltzmann: 2-D ຂຽນອອກໃນສະຄຣິບ, 3-D ໃຊ້ແກນການໄຫຼຂອງ PartCraft ເອງ |

ສ່ວນຫົວຂອງແຕ່ລະຟັງຊັນບອກອາກິວເມັນທີ່ແນ່ນອນ. ຫົວໜ່ວຍແມ່ນຂອງການສຶກສາໃນ PartCraft ຈົນກວ່າສ່ວນຫົວຈະບອກເປັນຢ່າງອື່ນ: ມິນລິແມັດ, ນິວຕັນ, ເມກາປາສກັນ, ໂຕນຕໍ່ລູກບາດມິນລິແມັດສຳລັບຄວາມໜາແໜ້ນ, ວັດ ແລະ ເຄວິນສຳລັບຄວາມຮ້ອນ. ຟັງຊັນໄຟຟ້າແມ່ເຫຼັກ ແລະ Lattice Boltzmann ເຮັດວຽກໃນຫົວໜ່ວຍໃດກໍໄດ້ທີ່ສອດຄ່ອງກັນ; ສ່ວນຫົວຂອງມັນບອກວິທີ.

## ວິທີການກວດສອບຄັງ

ສ່ວນຫົວຂອງແຕ່ລະຟັງຊັນຈົບດ້ວຍ **ການກວດສອບ**: ກໍລະນີນ້ອຍໆທີ່ຮູ້ຄຳຕອບ. ການທົດສອບຂອງ PartCraft ຮັນທຸກອັນ, ແລະ ບ່ອນທີ່ PartCraft ມີການສຶກສາຂອງຕົນເອງສຳລັບວຽກດຽວກັນ ຄຳຕອບຂອງສະຄຣິບຈະຖືກປຽບທຽບກັບການສຶກສານັ້ນໃນເມຊດຽວກັນ:

- ການໂກ່ງປາຍຂອງຄານຍື່ນທຽບກັບທິດສະດີຄານ (ພາຍໃນ 0.2 % ດ້ວຍລູກບາດ, 0.05 % ດ້ວຍເຕຕຣາເຮດຣອນ), ແລະ ທຽບກັບຕົວແກ້ຂອງພື້ນທີ່ **ການຈຳລອງ** ໃນເມຊດຽວກັນ (ຄືກັນເຖິງຫຼາຍຕຳແໜ່ງທົດສະນິຍົມ);
- ຄວາມຖີ່ທຳອິດຂອງຄານຍື່ນທຽບກັບທິດສະດີຄານ (ຕ່ຳກວ່າ 0.24 %, ຕາມທີ່ຄາດໄວ້ສຳລັບຄານສັ້ນ) ແລະ ທຽບກັບຕົວແກ້ໂໝດຂອງ **ການຈຳລອງ**;
- ຄວາມຮ້ອນ: ຝາຮາບແບນຕ່ຽງແຜ່ນທີ່ຖືກໃຫ້ຄວາມຮ້ອນແບບຖືກຕ້ອງທຸກປະການ, ວັດຖຸນ້ອຍທີ່ເຢັນລົງຕາມສູດ lumped-capacity, ອຸນຫະພູມຂອງແຜ່ນຄ່ອຍໆຫາຍໄປຕາມທິດສະດີ;
- ການປັບແຕ່ງໂຄງສ້າງ: `top88` ໄດ້ຜົນ 94 ຮອບ ແລະ ຄວາມຍືດຫຍຸ່ນ 203.1925 ຕາມເອກະສານ (ແລະ 218.8032 ດ້ວຍຕົວກອງຄວາມໜາແໜ້ນ); `topopt3d` ໄດ້ຄວາມຍືດຫຍຸ່ນດຽວກັນກັບພື້ນທີ່ **ການສ້າງ** ດ້ວຍການຕັ້ງຄ່າດຽວກັນ;
- ຄວາມຈຸຂອງຕົວເກັບປະຈຸ ແລະ ສະໜາມຂອງໂຊເລນອຍຍາວ ທຽບກັບຄ່າໃນຕຳລາ, ສະໜາມຂອງຊ່ອງວ່າງແມ່ເຫຼັກທຽບກັບສູດວົງຈອນແມ່ເຫຼັກ, ແລະ ແມ່ເຫຼັກຖາວອນທຽບກັບແມ່ເຫຼັກກົມໃນອາກາດ ແລະ ແມ່ເຫຼັກທີ່ປິດດ້ວຍເຫຼັກຮັບ;
- ການໄຫຼໃນຊ່ອງທຽບກັບໂປຣຟາຍພາຣາໂບລາທີ່ແນ່ນອນ.

## ອ່ານຟັງຊັນ

1. ເປີດແທັບ **ຄັງ** ຂອງແຜງສະຄຣິບ.
2. ກົດຟັງຊັນ. ສ່ວນຫົວຂອງມັນສະແດງ: ມັນຄຳນວນຫຍັງ, ວິທີການ, ຫົວໜ່ວຍ, ສົມມຸດຖານ ແລະ ຂີດຈຳກັດ, **ເອກະສານອ້າງອີງ** (ໜັງສື ຫຼື ບົດຄວາມ, ພ້ອມເລກສົມຜົນ) ແລະ **ການກວດສອບ** — ກໍລະນີນ້ອຍທີ່ຮູ້ຄຳຕອບ ທີ່ການທົດສອບຂອງ PartCraft ເອງຮັນ.
3. {{ui:Open (read-only)}} ເປີດສະຄຣິບທັງໝົດໃນແທັບທີ່ມີຂອບເສັ້ນປະ. ທ່ານສາມາດຮັນມັນ, ເລືອກ ແລະ ຮັນບາງສ່ວນຂອງມັນໄດ້, ແຕ່ບໍ່ສາມາດປ່ຽນແປງໄດ້.

## ປ່ຽນແປງຟັງຊັນ

ກົດ {{ui:Make a copy}} (ຫຼື **ສ້າງສຳເນົາເພື່ອແກ້ໄຂ** ທີ່ຢູ່ເໜືອແທັບອ່ານຢ່າງດຽວ). ສຳເນົາຈະເປັນສະຄຣິບໃນຊິ້ນສ່ວນຂອງທ່ານທີ່ມີຊື່ດຽວກັນ, ດັ່ງນັ້ນມັນຖືກບັນທຶກພ້ອມກັບຊິ້ນສ່ວນ, ແລະ **ທຸກການເອີ້ນຟັງຊັນນັ້ນຕອນນີ້ໃຊ້ສຳເນົາຂອງທ່ານ** — ຕົວແກ້ໄຂຈະບອກຢູ່ເໜືອສະຄຣິບ. ປ່ຽນຊື່ສຳເນົາເພື່ອເກັບທັງສອງໄວ້.

## ໃຊ້ຟັງຊັນ

ເອີ້ນຟັງຊັນຈາກຄັງໃນສະຄຣິບໃດກໍໄດ້ດ້ວຍຊື່ຂອງມັນ, ຄືກັບຟັງຊັນທີ່ມີມາໃນຕົວ:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

ຜົນລັບຖືກສົ່ງກັບເປັນຄ່າໃນພື້ນທີ່ເຮັດວຽກ; ພາບ ແລະ ຟີລ໌ດທີ່ມັນສະແດງຈະປາກົດໃນມຸມມອງ ແລະ ໜ້າຈໍຍ່ອຍ.

ຕົວຢ່າງການວິເຄາະສະຖິດຂອງຊິ້ນສ່ວນທີ່ເປີດຢູ່ ໃຊ້ພຽງບໍ່ເທົ່າໃດແຖວ:

```
v = voxel_mesh(part(), 2);                   % ລູກບາດ 2 mm
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % ຈັບດ້ານລຸ່ມ
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 500 N ລົງດ້ານເທິງ
r = static_voxel(v, 210000, 0.3, bc);       % ເຫຼັກ
```

`r` ເກັບການເຄື່ອນຕົວ, ຄວາມເຄັ້ນ ແລະ ແຮງປະຕິກິລິຍາ; ຄວາມເຄັ້ນ von Mises ຖືກແຕ້ມເທິງຊິ້ນສ່ວນທີ່ຖືກເຄື່ອນແລ້ວ. ສຳລັບຊິ້ນສ່ວນໂຄ້ງ ໃຊ້ `tet_mesh` ແລະ `static_tet`, ທີ່ສາມາດໂຫຼດ ແລະ ຈັບໜ້າທັງໝົດໄດ້ດ້ວຍ (`face_nodes`).

:::note
ຟັງຊັນໃນຄັງຖືກຂຽນດ້ວຍ CraftScript, ແລະ ສະຄຣິບ Lua ເອີ້ນພວກມັນຜ່ານ `cs` ຄືກັບຟັງຊັນທີ່ມີມາໃນຕົວ: `cs.static_tet(t, 200000, 0.3, bc)` (ເບິ່ງ [ສະຄຣິບ Lua](topic:craftscript-lua)). ແຕ່ລະຟັງຊັນແກ້ວັດສະດຸໜຶ່ງ ແລະ ກໍລະນີແຮງໜຶ່ງ; ສ່ວນຫົວຂອງມັນລະບຸສິ່ງອື່ນທີ່ບໍ່ໄດ້ຄອບຄຸມ.
:::
