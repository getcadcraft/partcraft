## ສິ່ງທີ່ທ່ານຈະເຮັດ

ສົ່ງ **ທຸກຂະໜາດຂອງຊິ້ນສ່ວນພ້ອມກັນ**: ໄຟລ໌ STEP, IFC ແລະ DWG ໜຶ່ງໄຟລ໌ ແລະ ຮູບໜຶ່ງຮູບສຳລັບແຕ່ລະຮູບແບບ, ຕາຕະລາງທີ່ບອກວ່າແຕ່ລະອັນແມ່ນຫຍັງ, ແລະ ລາຍການຄັງໜຶ່ງທີ່ວາງທຸກອັນໄວ້ໜ້າດຽວ.

ກ່ອນອື່ນ ທ່ານຕ້ອງມີຊິ້ນສ່ວນທີ່ມີ **ຮູບແບບ** (ເບິ່ງ [ຮູບແບບ ແລະ ຕາຕະລາງການອອກແບບ](topic:design-tables)). ຮູບແບບທີ່ປິດຄຸນສົມບັດໜຶ່ງ, ເຊັ່ນແຜ່ນທີ່ມີ ແລະ ບໍ່ມີຮູ, ຈະກາຍເປັນຕົວແປຂອງມັນເອງ.

## ຂັ້ນຕອນ

1. ເປີດຊິ້ນສ່ວນ. ໃນແທັບ {{ui:ພາລາມິເຕີ}}, ຊອກ **ຮູບແບບ**.
2. ຄລິກ {{ui:ຊຸດຕົວແປ…}}.
3. ໝາຍຮູບແບບທີ່ຈະສ້າງ (ທຸກອັນຖືກໝາຍໄວ້) ແລະ ໄຟລ໌ທີ່ຈະຂຽນ: STEP, IFC, DWG, ພາບຕົວຢ່າງ ແລະ ລາຍການຄັງ.
4. ຄລິກ {{ui:ສ້າງຊຸດ}}. ແຖວສະຖານະນັບຕົວແປທີ່ຖືກສ້າງ; ຊິ້ນສ່ວນຂອງທ່ານບໍ່ປ່ຽນ.
5. ໄຟລ໌ zip ໜຶ່ງຈະດາວໂຫຼດ: `<part> variants.zip`.

## ມີຫຍັງຢູ່ໃນ zip

| ໄຟລ໌ | ມັນແມ່ນຫຍັງ |
|---|---|
| `<name>.step` | ຮູບແບບເປັນຕົວທຶບ STEP. |
| `<name>.ifc` | IFC4, ອົງປະກອບໜຶ່ງທີ່ມີຕົວທຶບທີ່ສ້າງແລ້ວ ແລະ ພາລາມິເຕີຂອງຊິ້ນສ່ວນເປັນຄຸນສົມບັດ; ຄ່າແມ່ນຂອງຮູບແບບນັ້ນເອງ. |
| `<name>.dwg` | ມຸມມອງດ້ານໜ້າ, ດ້ານເທິງ, ດ້ານຂວາ ແລະ ໄອໂຊເມຕຣິກເປັນແຜ່ນແບບແຕ້ມຂະໜາດເຕັມ. |
| `<name>.svg` | ຮູບເສັ້ນໄອໂຊເມຕຣິກຂອງມັນ. |
| `variants.csv`, `variants.json` | ຕາຕະລາງພາລາມິເຕີ: id, ຊື່ ແລະ ຄ່າຂອງທຸກພາລາມິເຕີຂອງແຕ່ລະຕົວແປ, ຄຸນສົມບັດທີ່ມັນປິດ, ໄຟລ໌ຂອງມັນ, ບໍລິມາດ ແລະ ຂະໜາດຂອງມັນ. |
| `<part>.item.json` | ຊິ້ນສ່ວນເປັນລາຍການຄັງໜຶ່ງ ພ້ອມຕົວແປຂອງມັນ (ເບິ່ງດ້ານລຸ່ມ). |
| `README.txt` | ສິ່ງທີ່ຖືກສ້າງ, ໝາຍເຫດຂ້າງລຸ່ມ, ແລະ ສິ່ງທີ່ບໍ່ໄດ້ຖືກສ້າງ. |

ໄຟລ໌ຖືກຕັ້ງຊື່ຕາມຮູບແບບ. ຮູບແບບທີ່ສ້າງບໍ່ສຳເລັດ (ຄຸນສົມບັດທີ່ບໍ່ສາມາດສ້າງດ້ວຍຄ່າເຫຼົ່ານັ້ນ) ຈະຖືກຕັດອອກຈາກໄຟລ໌ ແລະ ຕາຕະລາງ, ຖືກລະບຸໄວ້ໃນ README ແລະ ໃນຂໍ້ຄວາມຫຼັງຈາກບັນທຶກ zip; ອັນອື່ນຍັງຖືກຂຽນຢູ່.

## ຄວນຮູ້

- **STEP** ຈະຖືກຕ້ອງແທ້ຈິງເມື່ອເຄີເນລທີ່ແທ້ຈິງເປີດຢູ່ໃນບິວດ໌ຂອງທ່ານ. ຖ້າບໍ່ມີ, STEP ຈະເປັນໜ້າ (ສາມຫຼ່ຽມຮາບ), ແລະ README ຈະບອກ.
- **DWG** ແມ່ນແຜ່ນແບບແຕ້ມ, ບໍ່ແມ່ນໂມເດວ 3D. ເສັ້ນຂອງມັນມາຈາກ mesh, ດັ່ງນັ້ນຂອບໂຄ້ງເປັນເສັ້ນສັ້ນຫຼາຍເສັ້ນ.
- **ລາຍການຄັງ** ມີຕົວທຶບໜຶ່ງ ແລະ ເນື້ອທີ່ພື້ນໜຶ່ງຕໍ່ຕົວແປ, ໃນແກນຂອງຄັງເອງ: Z ຊີ້ຂຶ້ນ, ດ້ານໜ້າຫັນໄປທາງ −Y, ແລະ ຈຸດວາງຢູ່ກາງດ້ານຫຼັງທີ່ດ້ານລຸ່ມ. ແຜນແມ່ນສີ່ແຈສາກຂອບເຂດຂອງແຕ່ລະຕົວແປ. ລາຍການຈຳກັດ 8 MB, ດັ່ງນັ້ນຕົວແປທີ່ໜັກຫຼາຍຈະກາຍເປັນກ່ອງທີ່ມີຂະໜາດດຽວກັນ ແລະ README ຈະບອກວ່າມີຈັກອັນ.
- ຮູບແບບທີ່ເຮັດວຽກຢູ່ຂອງຊິ້ນສ່ວນຈະເປັນຕົວແປເລີ່ມຕົ້ນຂອງລາຍການ.
- Ports (ຈຸດເຊື່ອມຕໍ່ສຳລັບທໍ່ ແລະ ທໍ່ລົມ) ບໍ່ຖືກຕັ້ງຈາກ PartCraft.

## ວາງຕົວແປໃນໜ້າຄັງ

ອັບໂຫຼດ `<part>.item.json` ທີ່ **ຄັງ › Upload** ໃນເວັບໄຊ. ເລືອກປະເພດ, ໃບອະນຸຍາດ ແລະ ແຖວເຄຣດິດຂອງທ່ານ, ແລ້ວມັນຈະກາຍເປັນລາຍການຄັງພ້ອມຕົວແປ. ໃນ BimCraft, ເວລາວາງມັນຈະຖາມວ່າຕົວແປໃດ, ແລະ ສະຫຼັບ (Swap) ຈະສະເໜີອັນອື່ນ. ໜ້າທີ່ຜູ້ເຂົ້າຊົມເລືອກຕົວເລືອກ, ເບິ່ງ 3D ແລະ ດາວໂຫຼດຕົວແປ ຕອນນີ້ເປັນ **ພາບຕົວຢ່າງສຳລັບພະນັກງານ**: ຍັງບໍ່ເປີດໃຫ້ສາທາລະນະ.

## ຈາກບັນທັດຄຳສັ່ງ

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` ລະບຸຮູບແບບ, `--formats` ເອົາຄ່າໃດກໍໄດ້ຈາກ `step`, `ifc`, `dwg`, `preview`, `--no-item` ບໍ່ລວມລາຍການຄັງ. ມັນຂຽນໂຟນເດີ, zip ຫຼື ທັງສອງ ແລະ ອອກດ້ວຍລະຫັດ 1 ເມື່ອຕົວແປໃດໜຶ່ງສ້າງບໍ່ໄດ້. ເບິ່ງ [ສະຄຣິບ ແລະ ບັນທັດຄຳສັ່ງ](topic:scripts-and-cli).
