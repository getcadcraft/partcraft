ເຄື່ອງມືວິສະວະກຳ (ຕົວສ້າງ, ຄັງວິສະວະກຳ, ການກວດສອບ ແລະ ໄຟລ໌ຂໍ້ມູນ) **ບໍ່ຕ້ອງການສິດ administrator** ແລະ **ບໍ່ຕ້ອງຕິດຕັ້ງ**. ມັນຂຽນພຽງສິ່ງທີ່ລະບຸໄວ້ທີ່ນີ້ເທົ່ານັ້ນ, ແລະ ບໍ່ຂຽນສິ່ງອື່ນ.

| ສິ່ງທີ່ | ບ່ອນທີ່ເກັບໄວ້ |
|---|---|
| ຊິ້ນສ່ວນຂອງທ່ານ, ພ້ອມຕົວທີ່ສ້າງຂຶ້ນ, ແຜ່ນຂໍ້ມູນ ແລະ ການກວດສອບ | ໄຟລ໌ຊິ້ນສ່ວນທີ່ທ່ານບັນທຶກ (`.partcraft.json`), ໃນບ່ອນທີ່ທ່ານບັນທຶກມັນ. |
| ຕົວສ້າງທີ່ທ່ານເປີດຈາກໄຟລ໌ | ໃນບ່ອນເກັບຂອງແອັບເອງ: local storage ຂອງເບຣົາເຊີໃນໜ້າເວັບ, ແລະ ໂຟນເດີ `data` ຂ້າງໂປຣແກຣມໃນ Studio ແບບພົກພາ. ສູງສຸດ 20. |
| ການຕັ້ງຄ່າ (ຂະໜາດ voxel ທີ່ທ່ານຕັ້ງ, ຈຳນວນເທຣດຂອງຕົວແກ້, ຮູບແບບໜ້າຈໍ) | ບ່ອນເກັບຂອງແອັບດຽວກັນ. |
| ແຜ່ນຂໍ້ມູນ, ຊ່ອງຂໍ້ມູນ, mesh | ພຽງບ່ອນທີ່ທ່ານບັນທຶກເທົ່ານັ້ນ: ການດາວໂຫຼດຈະໄປບ່ອນທີ່ທ່ານເລືອກ. |

ເຄື່ອງມືຈະ **ບໍ່ເຮັດການເອີ້ນເຄືອຂ່າຍດ້ວຍຕົວເອງ**: ຕົວສ້າງທີ່ມາພ້ອມແມ່ນໄຟລ໌ໃນໂຟນເດີຂອງແອັບເອງ, ຄັງ ແລະ ການກວດສອບເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ ໃນ worker ທີ່ເຂົ້າເຖິງເຄືອຂ່າຍບໍ່ໄດ້, ແລະ ຂໍ້ມູນວິສະວະກຳ (ຄຸນສົມບັດຂອງນ້ຳ ແລະ ອາກາດ, ວັດສະດຸ) ຢູ່ພາຍໃນແອັບ. ຕົວສ້າງທີ່ທ່ານເປີດຈາກໄຟລ໌ຖືກອ່ານໃນຄອມພິວເຕີຂອງທ່ານ ແລະ ບໍ່ໄປໃສອີກ.

## Windows zip ແບບພົກພາ ແລະ Linux

Studio ແບບພົກພາສຳລັບ Windows ເກັບການຕັ້ງຄ່າ, ແຄຊ ແລະ ສ່ວນເສີມຂອງມັນໄວ້ໃນໂຟນເດີ `data` ຂ້າງໂປຣແກຣມ. AppImage ຂອງ Linux ເກັບໄວ້ຂ້າງຕົວມັນເອງ ເມື່ອມີໄຟລ໌ຊື່ `portable` ຢູ່ຂ້າງມັນ; ຖ້າບໍ່ມີໄຟລ໌ນັ້ນ ມັນໃຊ້ໂຟນເດີບ້ານຂອງທ່ານ. ບໍ່ມີຮູບແບບພົກພາສຳລັບ Mac: ລະບົບບໍ່ໃຫ້ແອັບທີ່ດາວໂຫຼດມາຂຽນໄຟລ໌ຢູ່ຂ້າງຕົວມັນເອງ. ໝາຍເຫດພົກພາຂອງ shell ເອງ (ຄູ່ມື `Studio`) ລາຍການສິ່ງທີ່ໂປຣແກຣມຂຽນ.

## ການເຂົ້າເຖິງໂຮສ

ບໍ່ມີຫຍັງຢູ່ທີ່ນີ້ຮ້ອງຂໍການເຂົ້າເຖິງໂຮສ. ເຄື່ອງພິມ, ເຄື່ອງ serial ແລະ ອຸປະກອນ USB ແມ່ນແຍກຕ່າງຫາກ: ພວກມັນຖາມເມື່ອງານຕ້ອງການ, ຄັ້ງດຽວຕໍ່ອຸປະກອນ, ແລະ ບໍ່ມີຫຍັງໃນຕົວສ້າງ ຫຼື ການກວດສອບແຕະຕ້ອງພວກມັນ.
