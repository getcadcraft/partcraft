{{ui:Export}} ແລ້ວ {{ui:As}} {{ui:Interactive 3D file (HTML, opens offline)}} ຈະບັນທຶກໄຟລ໌ `.html` ໜຶ່ງໄຟລ໌. ສົ່ງທາງອີເມວ, ໃສ່ໃນ USB ຫຼື ໂຟນເດີແບ່ງປັນ: ມັນເປີດໄດ້ໃນບຣາວເຊີໃດກໍໄດ້ທີ່ຮອງຮັບ WebGL 2, ທັງໃນຄອມພິວເຕີ, ແທັບເລັດ ຫຼື ໂທລະສັບ.

ພາຍໃນໄຟລ໌:

- ລາກເພື່ອໝຸນໂມເດວ, ລາກຂວາ ຫຼື {{key:Shift}}+ລາກເພື່ອເລື່ອນມຸມມອງ, ລໍ້ເມົ້າ ຫຼື ບີບນິ້ວເພື່ອຊູມ.
- ຄລິກມຸມມອງໃນລາຍການ: ກ້ອງຈະເລື່ອນໄປບ່ອນນັ້ນ ແລະ ຊິ້ນສ່ວນຈະໃຊ້ຕຳແໜ່ງ, ລັກສະນະ, ການຕັດ ແລະ ແວ່ນຂະຫຍາຍຂອງມຸມມອງນັ້ນ.
- ຄລິກແຖວໃນລາຍການຊິ້ນສ່ວນເພື່ອໃຫ້ຊິ້ນສ່ວນຂອງມັນສະຫວ່າງຂຶ້ນ; ຄລິກຊິ້ນສ່ວນເພື່ອໃຫ້ແຖວຂອງມັນສະຫວ່າງຂຶ້ນ.
- ເມື່ອຄູ່ມືມີອະນິເມຊັນ ແຖບໃຕ້ໂມເດວຈະຫຼິ້ນ, ຢຸດຊົ່ວຄາວ ແລະ ລາກເລື່ອນໄປຕາມອະນິເມຊັນໄດ້.

ໄຟລ໌ນີ້ມີທຸກຢ່າງທີ່ມັນຕ້ອງການ (ໂມເດວ, ຕົວສະແດງຜົນ ແລະ three.js ພາຍໃຕ້ໃບອະນຸຍາດ MIT) ແລະ ປິດການຮ້ອງຂໍທຸກຢ່າງ: ມັນເຂົ້າອິນເຕີເນັດບໍ່ໄດ້, ບໍ່ມີບັນຊີ ແລະ ບໍ່ມີການຕິດຕາມ.

ການ 3D ແບບໂຕ້ຕອບຢູ່ໃນ PDF ບໍ່ມີໃຫ້ນຳໃຊ້: ບຣາວເຊີ ແລະ ຕົວອ່ານ PDF ສ່ວນໃຫຍ່ສະແດງບໍ່ໄດ້, ແລະ ຕົວອ່ານທີ່ສະແດງໄດ້ກໍປິດໄວ້ໂດຍຄ່າເລີ່ມຕົ້ນ. ໄຟລ໌ HTML ແມ່ນທາງເລືອກແບບໂຕ້ຕອບ.
