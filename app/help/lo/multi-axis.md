Manufacture ສາມາດຖືເຄື່ອງມືໃນມຸມໜຶ່ງ, ແລະ ມັນສາມາດເຄື່ອນແກນໝຸນໃນຂະນະທີ່ຕັດ. ສາມສິ່ງເຮັດມັນ, ຈາກງ່າຍທີ່ສຸດຂຶ້ນໄປ.

**ບໍ່ມີອັນໃດຢູ່ທີ່ນີ້ຖືກແລ່ນໃນເຄື່ອງຈັກ.** ເສັ້ນທາງຖືກກວດກັບເລຂາຄະນິດໂດຍການທົດສອບ ແລະ G-code ຖືກອ່ານກັບ, ແຕ່ post ທີ່ມາພ້ອມປະຕິບັດຕາມລະຫັດທີ່ບັນທຶກຂອງ control, ບໍ່ແມ່ນເຄື່ອງໃດໜຶ່ງທີ່ຢູ່ຕໍ່ໜ້າພວກເຮົາ. ພິສູດໂປຣແກຣມໃນ simulator ຂອງ control ຂອງທ່ານເອງ ແລະ ໃນອາກາດກ່ອນມັນຈະພົບໂລຫະ.

## ແກນໝຸນຂອງເຄື່ອງ

ໃນແຖບ **Setup**, {{ui:Rotary axes}} ບອກວ່າເຄື່ອງມີຫຍັງ:

| ທາງເລືອກ | ເຄື່ອງ |
|---|---|
| None (3 ແກນ) | ເຄື່ອງກັດທຳມະດາ. ການດຳເນີນງານໃດທີ່ຕ້ອງການເຄື່ອງມືອຽງຈະເຕືອນ, ແລະ post ຈະປະຕິເສດທີ່ຈະຂຽນມັນ. |
| A (ໝຸນຕາມ X) | ແກນໝຸນໜຶ່ງຕາມ X: ໂຕະແກນທີ 4 ຫຼື indexer. ເຄື່ອງມືອາດອຽງໃນຮາບ Y–Z ເທົ່ານັ້ນ. |
| B (ໝຸນຕາມ Y) | ແກນໝຸນໜຶ່ງຕາມ Y. ເຄື່ອງມືອາດອຽງໃນຮາບ X–Z ເທົ່ານັ້ນ. |
| A ແລະ C | ແກນອຽງຕາມ X ທີ່ຖືໂດຍ, ຫຼື ຖືສິ່ງ, ການໝຸນຕາມ Z: ໂຕະ trunnion, ຫຼື ຫົວ. |
| B ແລະ C | ຄືກັນກັບຂ້າງເທິງ ແຕ່ການອຽງຕາມ Y. |

ຈາກນັ້ນ:

- **Carried by**: {{ui:The table (the part turns)}} ຫຼື {{ui:The head (the tool turns)}}. ໂຕະໝຸນໃນທິດທາງກົງກັນຂ້າມເພື່ອນຳໜ້າດຽວກັນມາໃຕ້ເຄື່ອງມື, ດັ່ງນັ້ນເຄື່ອງໝາຍຂອງທຸກມຸມຂຶ້ນກັບຕົວເລືອກນີ້.
- **The control keeps the tool tip on the path (TCP)**: ເປີດ, X Y Z ໃນໂປຣແກຣມແມ່ນປາຍເຄື່ອງມືໃນພິກັດຂອງຊິ້ນສ່ວນເອງ ແລະ control ເຮັດສ່ວນທີ່ເຫຼືອ (post ແບບ Fanuc ແລະ LinuxCNC ທີ່ມາພ້ອມຂຽນ `G43.4` ສຳລັບຄວາມຍາວເຄື່ອງມື). ປິດ, ໃນເຄື່ອງແບບໂຕະ, PartCraft ຂຽນ X Y Z ຕາມທີ່ໂຕະທີ່ໝຸນນຳຊິ້ນສ່ວນ, ໂດຍຮອບ **ຈຸດສູນກາງການໝຸນ** ທີ່ທ່ານໃຫ້ (ໃນພິກັດການເຮັດວຽກ; 0, 0, 0 ເມື່ອ work origin ຢູ່ກາງ). ເຄື່ອງແບບຫົວຕ້ອງເປີດ TCP: ຖ້າບໍ່ມີ, ໂປຣແກຣມຈະຕ້ອງການຄວາມຍາວ pivot ຂອງເຄື່ອງ, ເຊິ່ງ PartCraft ບໍ່ຮູ້.
- **Tilt limit**: ແກນອຽງໄປໄດ້ໄກເທົ່າໃດ.

ເຄື່ອງຕ່າງກັນໃນວິທີທີ່ພວກມັນນັບວ່າເປັນບວກ. ຖ້າແກນໝຸນຜິດທາງໃນເຄື່ອງຂອງທ່ານ, ປ່ຽນເຄື່ອງໝາຍໃນສຳເນົາຂອງ post ([Post processors you can edit](topic:post-processors)).

## ເຄື່ອງມືອຽງສຳລັບການດຳເນີນງານທຳມະດາ

ທຸກການດຳເນີນງານກັດ (face, pocket, adaptive, contour, drill, chamfer, parallel, scallop, 3D rough, rest) ມີ **Tool tilt** ແລະ **Tilt towards**: ທິດທາງຂອງເຄື່ອງມືສຳລັບການດຳເນີນງານນັ້ນເທົ່ານັ້ນ, ວັດຈາກແກນເຄື່ອງມືຂອງ setup. ນີ້ແມ່ນການກັດ 3+2: ແກນໝຸນໄປຕຳແໜ່ງໜຶ່ງ ແລະ ຢູ່ທີ່ນັ້ນ ໃນຂະນະທີ່ສາມແກນຕັດ.

- ພິມມຸມສອງມຸມ, ຫຼື ກົດ {{ui:Tool square to a face}} ແລ້ວຄລິກໜ້າຮາບໜຶ່ງ: ເຄື່ອງມືຈະຊີ້ກົງໄປທີ່ມັນ.
- ເລືອກໜ້າ ແລະ ຂອບຂອງການດຳເນີນງານຕາມປົກກະຕິ. ສິ່ງທີ່ນັບວ່າເປັນພື້ນ ຫຼື ຮູ ຈະຖືກຕັດສິນຕາມເຄື່ອງມືທີ່ອຽງ.
- ວັດຖຸດິບສຳລັບທິດທາງນັ້ນແມ່ນກ່ອງທີ່ບັນຈຸວັດຖຸດິບທີ່ຖືກໝຸນ, ດັ່ງນັ້ນຄວາມສູງ ແລະ ໄລຍະຫ່າງປອດໄພຈາກດ້ານນັ້ນ.

ໃນ G-code, ກ່ອນການດຳເນີນງານ ເຄື່ອງມືຂຶ້ນ, ແກນໝຸນໝຸນ, ແລະ ເຄື່ອງມືລົງມາເທິງຈຸດທຳອິດ. ໃນເຄື່ອງແບບໂຕະທີ່ບໍ່ມີ TCP, arc ຢູ່ເປັນ arc ແລະ ວົງຈອນເຈາະສຳເລັດຮູບຢູ່ເປັນວົງຈອນ (ກອບທີ່ຂຽນຖືກໝຸນພຽງແຕ່ຕາມ Z). ເມື່ອມີ TCP ໃນຮາບອຽງ, arc ກາຍເປັນເສັ້ນສັ້ນ ແລະ ວົງຈອນກາຍເປັນການເຄື່ອນທີ່ທີ່ພວກມັນແທນ.

ການຈຳລອງວັດຖຸດິບເຮັດທິດທາງທີ່ອຽງ **ດ້ວຍຕົວມັນເອງ**: ມັນສະແດງສິ່ງທີ່ການດຳເນີນງານນັ້ນຕັດຈາກວັດຖຸດິບທັງໝົດທີ່ເຫັນຈາກດ້ານຂອງມັນ, ແລະ ພົບ gouge ຢູ່ທີ່ນັ້ນ, ແຕ່ການຕັດທີ່ເຮັດຈາກທິດທາງອື່ນຈະບໍ່ຖືກນຳມາ.

## ການຕົບແຕ່ງ 5 ແກນ

{{ui:More}} ໃນແຖບເຄື່ອງມື Manufacture ລາຍການການດຳເນີນງານນີ້ ແລະ ອັນຕໍ່ໄປຢູ່ເທິງສຸດຂອງແຖບ **Operations**.

{{ui:5-axis}} ແມ່ນ [ການຜ່ານຕົບແຕ່ງແບບຂະໜານ](topic:finish-3d) ດ້ວຍ **ball end mill ທີ່ອຽງໄປຕາມການເຄື່ອນທີ່**. ball ຕັດດ້ວຍໜ່ວຍກົມ, ແລະ ໜ່ວຍກົມແມ່ນຄືກັນບໍ່ວ່າເຄື່ອງມືຈະອຽງໄປທາງໃດກ່ຽວກັບຈຸດສູນກາງຂອງມັນ, ດັ່ງນັ້ນ ball ຕາມເສັ້ນທາງທີ່ການຜ່ານ 3 ແກນຈະໃຫ້ພອດີ ແລະ ມີພຽງທິດທາງຂອງເຄື່ອງມືທີ່ປ່ຽນ:

- **Towards the surface**: 1 = ຕັ້ງສາກກັບພື້ນຜິວ, 0 = ຕັ້ງຕົງ, ລະຫວ່າງນັ້ນແມ່ນຄ່າໃດກໍໄດ້.
- **Lean forward**: ອົງສາຕາມທິດທາງການຕັດ, ເພື່ອໃຫ້ຈຸດສູນກາງທີ່ຢູ່ນິ່ງຂອງ ball ບໍ່ແມ່ນສິ່ງທີ່ເຮັດການຕັດ.
- **Most tilt**: ເຄື່ອງມືບໍ່ເຄີຍອຽງໄກກວ່ານີ້ຈາກແກນຂອງ setup.

ບ່ອນທີ່ດ້າມຈັບຈະສຳຜັດກັບໂມເດວ, ການອຽງຖືກຕັດກັບຈົນກວ່າມັນຈະພົ້ນ, ແລະ ການດຳເນີນງານບອກວ່າມີກີ່ຈຸດ. ແຕ່ລະການຜ່ານຖືກເຂົ້າ ແລະ ອອກດ້ວຍການຍົກເສັ້ນຊື່.

## ການຕົບແຕ່ງດ້ວຍແກນໝຸນ (ແກນທີ 4)

{{ui:Rotary}} ແມ່ນສຳລັບຊິ້ນສ່ວນທີ່ຖືຕາມ **X ຂອງການເຮັດວຽກ** ເທິງແກນໝຸນ. ຊິ້ນສ່ວນໝຸນ ແລະ ball end mill, ທີ່ຊີ້ໄປທີ່ແກນສະເໝີ, ຕາມພື້ນຜິວຂອງມັນ:

- **Passes**: {{ui:Along the axis}} (ເສັ້ນຕາມ X, ຫ່າງກັນໜຶ່ງ stepover ຂອງການໝຸນ) ຫຼື {{ui:Round the part}} (ວົງ, ຫ່າງກັນໜຶ່ງ stepover ຂອງ X).
- **Axis at Y / Z**: ແກນຢູ່ໃສ. ວ່າງໝາຍຄວາມວ່າກາງຂອງວັດຖຸດິບ. ເທິງເຄື່ອງແບບໂຕະທີ່ບໍ່ມີ TCP ນີ້ຕ້ອງເປັນຈຸດສູນກາງການໝຸນໃນ Setup; ການດຳເນີນງານເຕືອນເມື່ອມັນບໍ່ແມ່ນ.
- **From / To X** ແລະ **From / To angle**: ສ່ວນຂອງຄວາມຍາວ ແລະ ຂອງການໝຸນທີ່ຈະຕັດ.

ຄວາມສູງຂອງ ball ເໜືອແກນໃນທຸກຈຸດແມ່ນການຕົກທີ່ແນ່ນອນຂອງໜ່ວຍກົມເທິງ mesh ຂອງຊິ້ນສ່ວນ, ຈາກດ້ານນັ້ນ.

## ຂີດຈຳກັດ

- ການຕົບແຕ່ງ 5 ແກນ ແລະ ແກນໝຸນຮັບ **ball end mill** ເທົ່ານັ້ນ. ບໍ່ມີການຕັດ swarf (ດ້ານຂອງເຄື່ອງມືເທິງກຳແພງທີ່ເປັນເສັ້ນຊື່), ບໍ່ມີ flow line ຕາມທິດທາງຂອງພື້ນຜິວເອງ, ບໍ່ມີການຫຍາບຫຼາຍແກນ ແລະ ບໍ່ມີການເລືອກມຸມອັດຕະໂນມັດເພື່ອຫຼີກການຊົນ.
- ເສັ້ນທາງ 5 ແກນ ແລະ ແກນໝຸນ **ບໍ່ຖືກແລ່ນຜ່ານການຈຳລອງວັດຖຸດິບ**, ເຊິ່ງເປັນ height map ແລະ ບໍ່ສາມາດຖືການຕັດທີ່ອຽງໄດ້.
- ດ້າມຈັບຖືກກວດໃນການຕົບແຕ່ງ 5 ແກນຕໍ່ກັບໂມເດວທີ່ເບິ່ງຈາກດ້ານເທິງ; holder, spindle ແລະ ຕົວເຄື່ອງເອງບໍ່ຖືກກວດທຸກບ່ອນ.
- ການຕົບແຕ່ງແກນໝຸນຕັດພຽງສິ່ງທີ່ເຄື່ອງມືເຫັນເມື່ອເບິ່ງແກນ.
- ການຕົບແຕ່ງ 5 ແກນໃຊ້ເວລາໜຶ່ງນາທີ ຫຼື ຫຼາຍກວ່ານັ້ນໃນການຄິດໄລ່ກັບຊິ້ນສ່ວນໃຫຍ່: ດ້າມຈັບຖືກກວດໃນທຸກຈຸດຂອງທຸກການຜ່ານ.
- ເມື່ອແກນໝຸນເຄື່ອນຮ່ວມກັບແກນເສັ້ນຊື່ ແລະ TCP ປິດ, post ທີ່ມາພ້ອມຂຽນ feed ເປັນເວລາປີ້ນກັບ (`G93`), ແລ້ວກັບໄປ `G94`.
- ລະຫັດ work plane ທີ່ອຽງ (`G68.2` ແລະ ອື່ນໆ) ບໍ່ຖືກຂຽນ, ແລະ ຂີດຈຳກັດ, ການບິດ ຫຼື ເຂດຊົນສະເພາະເຄື່ອງບໍ່ເປັນທີ່ຮູ້.
