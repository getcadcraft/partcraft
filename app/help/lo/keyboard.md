ປຸ່ມລັດຈະບໍ່ເຮັດວຽກໃນຂະນະທີ່ທ່ານກຳລັງພິມໃນກ່ອງໃນແຜງ, ຍົກເວັ້ນ {{key:Mod+S}} ແລະ {{key:Mod+O}} ທີ່ໃຊ້ໄດ້ສະເໝີ. ປຸ່ມຕົວອັກສອນໃຊ້ໄດ້ໂດຍບໍ່ຕ້ອງມີປຸ່ມຊ່ວຍ.

ໝາຍເຫດທົ່ວໄປກ່ຽວກັບປຸ່ມໃນບຣາວເຊີ ແລະ ແປ້ນພິມທີ່ບໍ່ມີປຸ່ມ function: [ປຸ່ມ, ເມົ້າ ແລະ ທຣັກແພດ](common:keys).

## ທຸກບ່ອນ

| ປຸ່ມ | ການກະທຳ |
|---|---|
| {{key:Mod+S}} | ບັນທຶກຊິ້ນສ່ວນ (ໃນການປະກອບ: ບັນທຶກການປະກອບ). ປິດພາບຮ່າງທີ່ເປີດຢູ່ກ່ອນ |
| {{key:Mod+O}} | ເປີດໄຟລ໌ຊິ້ນສ່ວນ ຫຼື ການປະກອບ (ຖາມກ່ອນຖ້າມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ) |
| {{key:Mod+Z}} | ຍ້ອນກັບ |
| {{key:Mod+Y}} ຫຼື {{key:Mod+Shift+Z}} | ເຮັດຊ້ຳ |
| {{key:F1}} | ເປີດ ຫຼື ປິດວິທີໃຊ້ນີ້ (ຫຼື {{ui:Help}} ໃນແຖບແອັບ). {{key:Esc}} ກໍ່ປິດໄດ້ເຊັ່ນກັນ. ໃນແລັບທັອບ ຫຼື ແປ້ນ Mac ຈຳນວນຫຼາຍ ໃຫ້ກົດ Fn ຄ້າງໄວ້ |
| {{key:Ctrl+Shift+F}} | ໂໝດໜ້າຈໍ: ປົກກະຕິ, ເຕັມຈໍ, ເຕັມຈໍໂດຍເຊື່ອງແຖບ. ໃນ Mac ໃຊ້ Control ເຊັ່ນກັນ, ບໍ່ແມ່ນ ⌘ |
| {{key:Esc}} | ອອກຈາກເຕັມຈໍ (ເມື່ອຢູ່ໃນໂໝດເຕັມຈໍ) |
| {{key:Mod+,}} | ການຕັ້ງຄ່າ, ລວມທັງແຖບ PartCraft (ເບິ່ງ [ການຕັ້ງຄ່າ PartCraft](topic:settings)) |

ໃນກ່ອງຕົວເລກຂອງແຜງ, {{key:Mod+Z}} ເປັນການຍ້ອນກັບຂໍ້ຄວາມຂອງບຣາວເຊີເອງ. ໃນກ່ອງຕົວເລກເທິງຂະໜາດພາບຮ່າງ, ມັນຍ້ອນກັບໃນ PartCraft.

## ສຳເນົາ, ວາງ ແລະ ສຳເນົາຊ້ຳ

ປຸ່ມເຫຼົ່ານີ້ເຮັດວຽກກັບສິ່ງທີ່ທ່ານກຳລັງເຮັດຢູ່: ຮູບຮ່າງທີ່ເລືອກໃນພາບຮ່າງທີ່ເປີດ, ຟີເຈີທີ່ເລືອກໃນປະຫວັດ, ຫຼື ຊິ້ນສ່ວນທີ່ເລືອກໃນການປະກອບ. ລາຍລະອຽດຢູ່ໃນ [ສຳເນົາ, ວາງ ແລະ ສຳເນົາຊ້ຳ](topic:copy-paste).

| ປຸ່ມ | ການກະທຳ |
|---|---|
| {{key:Mod+C}} | ສຳເນົາສ່ວນທີ່ເລືອກ |
| {{key:Mod+X}} | ຕັດ: ສຳເນົາ ແລ້ວລຶບ |
| {{key:Mod+V}} | ວາງ. ໃນພາບຮ່າງ ສຳເນົາຈະຕາມຕົວຊີ້, ໃຫ້ຄລິກບ່ອນທີ່ຕ້ອງການ |
| {{key:Mod+Shift+V}} | ວາງໃນຕຳແໜ່ງເດີມ: ພິກັດເດີມ (ໃນການປະກອບ, ບ່ອນເດີມ) |
| {{key:Mod+D}} | ສຳເນົາຊ້ຳ: ສຳເນົາ ແລະ ວາງໃນຂັ້ນຕອນດຽວ, ໂດຍບໍ່ແຕະຕ້ອງຄລິບບອດ |
| {{key:Mod+A}} | ເລືອກທັງໝົດ (ໃນພາບຮ່າງ) |
| {{key:Esc}} | ຍົກເລີກການເລືອກທັງໝົດ (ແລະ ຍົກເລີກການວາງທີ່ຕາມຕົວຊີ້) |

ໃນກ່ອງຕົວເລກ, ປຸ່ມເຫຼົ່ານີ້ສຳເນົາ ແລະ ວາງຂໍ້ຄວາມຕາມປົກກະຕິ. ຂໍ້ຄວາມທີ່ເລືອກໃນແຜງຈະຖືກສຳເນົາໂດຍບຣາວເຊີ.

## ໃນຊິ້ນສ່ວນ (ບໍ່ໄດ້ເປີດພາບຮ່າງ)

| ປຸ່ມ | ການກະທຳ |
|---|---|
| {{key:S}} | ສ້າງພາບຮ່າງເທິງໜ້າຮາບ ຫຼື ໜ້າແບນທີ່ເລືອກ; ຖ້າບໍ່ໄດ້ເລືອກ, ໃຫ້ເລືອກບ່ອນໂດຍການຄລິກ |
| {{key:F}} | ປັບຊິ້ນສ່ວນໃຫ້ພໍດີກັບມຸມມອງ |
| {{key:M}} | ວັດໄລຍະ, ໃນທຸກພື້ນທີ່ເຮັດວຽກ ແລະ ໃນການປະກອບ; {{key:Esc}} ລຶບຈຸດທີ່ເລືອກ, {{key:Esc}} ອີກຄັ້ງເພື່ອປິດ (ເບິ່ງ [ວັດໄລຍະທາງ, ມຸມ ແລະ ມວນ](topic:measure)) |
| {{key:X}} | ເປີດ ຫຼື ປິດມຸມມອງຕັດ, ໃນທຸກພື້ນທີ່ເຮັດວຽກ ແລະ ໃນການປະກອບ; {{key:Esc}} ປິດມັນ (ເບິ່ງ [ເບິ່ງພາຍໃນດ້ວຍມຸມມອງຕັດ](topic:section-view)) |
| {{key:Delete}} | ລຶບຟີເຈີທີ່ເລືອກ (ຖາມຖ້າມີຟີເຈີອື່ນໃຊ້ມັນຢູ່) |
| {{key:0}} … {{key:9}}, {{key:.}} | ເມື່ອເລືອກຟີເຈີ: ພິມຕົວເລກຫຼັກຂອງມັນ (ຄວາມເລິກຂອງ Extrude, ເສັ້ນຜ່າສູນກາງຂອງ Hole, ຈຳນວນຂອງ pattern, ລັດສະໝີຂອງ fillet …), ແລ້ວກົດ {{key:Enter}}. {{key:Esc}} ຮັກສາຄ່າເກົ່າໄວ້ |
| {{key:Backspace}} | ລຶບຟີເຈີທີ່ເລືອກ, ເມື່ອມີຟີເຈີຖືກເລືອກຢູ່ |
| {{key:Esc}} | ຢຸດການເລືອກໜ້າພາບຮ່າງ, ຫຼື ລຶບການເລືອກ (ລວມທັງຂອບ ຫຼື ໜ້າທີ່ເລືອກດ້ວຍ {{key:Shift}}) |

## ໃນມຸມມອງ 3D
