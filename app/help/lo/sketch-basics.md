ທຸກຊິ້ນສ່ວນແຂງເລີ່ມຈາກພາບຮ່າງ: ແບບແຕ້ມຮາບເທິງລະນາບ. ບົດນີ້ອະທິບາຍເຄື່ອງມືແຕ້ມ. ການກຳນົດພາບຮ່າງໃຫ້ຄົບດ້ວຍຄວາມສຳພັນ ແລະ ຂະໜາດ ຢູ່ໃນ [ກຳນົດພາບຮ່າງໃຫ້ຄົບ](topic:relations-dimensions).

## ເລີ່ມພາບຮ່າງ

ທ່ານສາມາດແຕ້ມພາບຮ່າງເທິງລະນາບຖານ ຫຼື ໜ້າຮາບໃດໆຂອງຊິ້ນສ່ວນ.

1. ເລືອກບ່ອນທີ່ຈະແຕ້ມ:
   - ລະນາບຖານ: ຄລິກ **ລະນາບໜ້າ**, **ລະນາບເທິງ** ຫຼື **ລະນາບຂວາ** ໃນ ປະຫວັດ, ຫຼື ຄລິກລະນາບໃນ ມຸມມອງ;
   - ໜ້າຮາບ: ຄລິກໜ້ານັ້ນໃນ ມຸມມອງ. ທັງໜ້າຈະຖືກໄຮໄລ້.
2. ເລືອກ {{ui:Sketch}} ໃນ ແຖບເຄື່ອງມື ຫຼື ກົດ {{key:S}}. (ເມື່ອເລືອກໜ້າແລ້ວ ທ່ານກໍສາມາດເລືອກ {{ui:Sketch on this face}} ໃນ ແຖບດ້ານຂວາ; ເມື່ອເລືອກລະນາບ, ໃຫ້ເລືອກ {{ui:Sketch on it}}.)

ມຸມມອງຈະຫັນໃຫ້ຕັ້ງສາກກັບລະນາບ, ເຄື່ອງມືພາບຮ່າງຈະປາກົດໃນ ແຖບເຄື່ອງມື, ແລະ ເຄື່ອງມື Line ຈະພ້ອມໃຊ້. ຖ້າກົດ {{ui:Sketch}} ໂດຍບໍ່ໄດ້ເລືອກຫຍັງ, ລະນາບຖານຈະສະແດງຂຶ້ນ ແລະ ແຖບສະຖານະຈະບອກວ່າ "ຄລິກລະນາບ ຫຼື ໜ້າຮາບເພື່ອແຕ້ມພາບຮ່າງ. Esc ເພື່ອຢຸດ."

:::note
ໜ້າໂຄ້ງບໍ່ສາມາດຖືພາບຮ່າງໄດ້: "ໜ້ານັ້ນໂຄ້ງ. ເລືອກໜ້າຮາບ ຫຼື ລະນາບເພື່ອແຕ້ມພາບຮ່າງ."
:::

**ພາບຮ່າງເທິງໜ້າຈະຕາມໜ້ານັ້ນ.** ຖ້າໜ້ານັ້ນຖືກສ້າງຈາກຂອບພາບຮ່າງ ຫຼື ປາຍຂອງ Extrude, ພາບຮ່າງໃໝ່ຈະຍ້າຍເມື່ອຟີເຈີປ່ຽນ (ຖ້າຂຸມເລິກຂຶ້ນ, ພາບຮ່າງທີ່ກົ້ນຂຸມກໍຈະຍ້າຍໄປນຳ). ຖ້າແຜງບອກວ່າໜ້າ "ຕຶງຢູ່ບ່ອນທີ່ເລືອກ", ພາບຮ່າງຈະຢູ່ຕຳແໜ່ງໜ້າປະຈຸບັນ.

## ເຄື່ອງມືແຕ້ມ

ແຕ່ລະເຄື່ອງມີປຸ່ມໃນແຖບເຄື່ອງມື ແລະ ປຸ່ມລັດ. ເລືອກປຸ່ມເດີມອີກຄັ້ງ, ກົດ {{key:S}}, ຫຼື ກົດ {{key:Esc}} ເພື່ອກັບໄປ Select.

| ເຄື່ອງມື | ປຸ່ມລັດ | ວິທີແຕ້ມ |
|---|---|---|
| {{ui:Line}} | {{key:L}} | ຄລິກຈຸດເລີ່ມ, ແລ້ວຄລິກແຕ່ລະຈຸດຕໍ່ໄປ. ເສັ້ນຈະຕໍ່ປາຍກັບປາຍ. ຈົບສາຍດ້ວຍ {{key:Esc}}, {{key:Enter}}, ຄລິກຂວາ ຫຼື ຄລິກສອງຄັ້ງ. ການຄລິກຈຸດທີ່ມີຢູ່ກໍຈົບເຊັ່ນກັນ |
| {{ui:Rectangle}} | {{key:R}} | ຄລິກມຸມໜຶ່ງ, ແລ້ວຄລິກມຸມກົງກັນຂ້າມ. ທ່ານຈະໄດ້ສີ່ເສັ້ນຕໍ່ກັນຢູ່ມຸມ, ສອງເສັ້ນແນວນອນ ແລະ ສອງເສັ້ນແນວຕັ້ງ |
| {{ui:Circle}} | {{key:C}} | ຄລິກຈຸດສູນກາງ, ແລ້ວຄລິກຈຸດໜຶ່ງເທິງວົງມົນ |
| {{ui:Arc}} | {{key:A}} | ຄລິກຈຸດສູນກາງ, ແລ້ວຈຸດເລີ່ມ, ແລ້ວຈຸດສິ້ນສຸດ. ເສັ້ນໂຄ້ງຈະໄປຕາມທິດທີ່ທ່ານເລື່ອນຕົວຊີ້ຮອບຈຸດສູນກາງ |
| {{ui:Point}} | {{key:P}} | ຄລິກ. ຈຸດດຽວໆໝາຍເຖິງຈຸດສູນກາງຂອງຮູສຳລັບ {{ui:Hole}} |
| {{ui:Centerline}} | {{key:N}} | ຄືເສັ້ນ, ແຕ່ແຕ້ມເທື່ອລະສ່ວນ. ແຕ້ມເປັນເສັ້ນປະ; ເປັນເລຂາຄະນິດການກໍ່ສ້າງ, ໃຊ້ເປັນແກນ Revolve ຫຼື ເສັ້ນອ້າງອີງ |
| {{ui:Fillet}} | {{key:F}} | ຄລິກມຸມທີ່ສອງເສັ້ນມາພົບກັນ, ພິມລັດສະໝີ, ກົດ {{key:Enter}} |
| {{ui:Spline}} | {{key:B}} | ຄລິກຈຸດທີ່ເສັ້ນໂຄ້ງຜ່ານ; {{key:Enter}} ເພື່ອຈົບ, ຄລິກຈຸດທຳອິດເພື່ອປິດ. ເບິ່ງ [ສະພລາຍ, ຕັດແຕ່ງ, ຊົດເຊີຍ ແລະ ເຄື່ອງມືພາບຮ່າງອື່ນໆ](topic:sketch-tools) |
| {{ui:Trim}} | {{key:T}} | ຄລິກສ່ວນຂອງເສັ້ນໂຄ້ງທີ່ຈະເອົາອອກ, ຈົນຮອດຈຸດຕັດກັນທີ່ໃກ້ທີ່ສຸດ |
| {{ui:Dimension}} | {{key:D}} | ເບິ່ງ [ກຳນົດພາບຮ່າງໃຫ້ຄົບ](topic:relations-dimensions) |

ໃນຂະນະແຕ້ມ, ກ່ອງນ້ອຍຂ້າງຕົວຊີ້ຈະສະແດງຄວາມຍາວ, ຂະໜາດ, ເສັ້ນຜ່າສູນກາງ ຫຼື ລັດສະໝີ.

### ພິມຂະໜາດຕອນແຕ້ມ

ຫຼັງຈາກຄລິກທຳອິດຂອງເສັ້ນ, ສີ່ແຈສາກ, ວົງມົນ ຫຼື ເສັ້ນໂຄ້ງ, ທ່ານສາມາດພິມຂະໜາດແທນການຄລິກໄດ້. ເມື່ອພິມຕົວເລກ ກ່ອງຈະເປີດຂ້າງຕົວຊີ້ ພ້ອມຕົວເລກນັ້ນ:

| ເຄື່ອງມື | ກ່ອງ ({{key:Tab}} ໄປກ່ອງຖັດໄປ) | ເກີດຫຍັງຂຶ້ນເມື່ອກົດ {{key:Enter}} |
|---|---|---|
| {{ui:Line}}, {{ui:Centerline}} | ຄວາມຍາວ, ແລ້ວ ມຸມ (°) ຈາກແກນ X ຂອງພາບຮ່າງ | ເສັ້ນຈະແຕ້ມຕາມຄວາມຍາວນັ້ນ, ໄປທາງຕົວຊີ້ ຫຼື ຕາມມຸມທີ່ພິມ; ສາຍຕໍ່ຈາກປາຍຂອງມັນ |
| {{ui:Rectangle}} | ຄວາມກວ້າງ, ແລ້ວ ຄວາມສູງ | ສີ່ແຈສາກຈະແຕ້ມຈາກມຸມທຳອິດໄປທາງຕົວຊີ້; ຂະໜາດທີ່ທ່ານບໍ່ໄດ້ພິມຈະມາຈາກຕົວຊີ້ |
| {{ui:Circle}} | ເສັ້ນຜ່າສູນກາງ | ວົງມົນຈະແຕ້ມດ້ວຍເສັ້ນຜ່າສູນກາງນັ້ນ |
| {{ui:Arc}} | ລັດສະໝີຫຼັງຈຸດສູນກາງ, ແລ້ວ ມຸມເສັ້ນໂຄ້ງ (°) ຫຼັງຈຸດເລີ່ມ | ຈຸດເລີ່ມຈະຢູ່ຫ່າງຈາກຈຸດສູນກາງໄປເທົ່າທີ່ກຳນົດ; ຈາກນັ້ນເສັ້ນໂຄ້ງຈະໝຸນໄປເທົ່ານັ້ນ, ໄປຕາມທິດທີ່ທ່ານເລື່ອນຕົວຊີ້ |

ຂະໜາດທີ່ທ່ານພິມແຕ່ລະອັນຈະກາຍເປັນ **ຂະໜາດຂັບເຄື່ອນ** ໃນຂັ້ນຕອນດຽວກັນ, ດັ່ງນັ້ນພາບຮ່າງຈະມີຂະໜາດຄົບ: {{key:Mod+Z}} ຈະເອົາຮູບຮ່າງ ແລະ ຂະໜາດຂອງມັນອອກພ້ອມກັນ. ການຄລິກແທນການກົດ {{key:Enter}} ຈະເກັບສິ່ງທີ່ທ່ານພິມໄວ້ ແລະ ເອົາສ່ວນທີ່ເຫຼືອຈາກການຄລິກ. {{key:Esc}} ປິດກ່ອງ ແລະ ກັບໄປຕົວຊີ້.

ປິດສິ່ງນີ້ໄດ້ໃນ {{ui:Settings}} › {{ui:PartCraft}} › **ກຳນົດຂະໜາດຕອນແຕ້ມ** ຖ້າທ່ານຕ້ອງການແຕ້ມດ້ວຍການຄລິກເທົ່ານັ້ນ. ເບິ່ງ [ການຕັ້ງຄ່າ PartCraft](topic:settings).

### ການດູດຕິດ

ການດູດຕິດຈະເພີ່ມຄວາມສຳພັນໃຫ້ທ່ານອັດຕະໂນມັດ, ເພື່ອໃຫ້ພາບຮ່າງຕິດກັນເມື່ອຍ້າຍ:

- ຢູ່ **ປາຍຈຸດ ຫຼື ຈຸດກຳເນີດ**, ຈະມີສີ່ຫຼ່ຽມນ້ອຍປາກົດ. ຈຸດໃໝ່ຈະທັບກັບຈຸດນັ້ນ.
- ຢູ່ **ເສັ້ນ, ວົງມົນ ຫຼື ເສັ້ນໂຄ້ງ**, ຈະມີເຄື່ອງໝາຍກາບາດປາກົດ. ຈຸດໃໝ່ຈະຖືກວາງເທິງເສັ້ນໂຄ້ງນັ້ນ.
- ເສັ້ນທີ່ຢູ່ໃນ 3 ອົງສາຈາກແນວນອນ ຫຼື ແນວຕັ້ງ ຈະດູດເຂົ້າໄປ ແລະ ໄດ້ຄວາມສຳພັນແນວນອນ ຫຼື ແນວຕັ້ງ. ປ້າຍຈະສະແດງ "H" ຫຼື "V".

ເພື່ອຫຼີກການດູດ, ໃຫ້ຊູມເຂົ້າ ເພື່ອຄລິກໃຫ້ຫ່າງຈາກຈຸດ ຫຼື ເສັ້ນໂຄ້ງຫຼາຍຂຶ້ນ.

## ປັດມຸມ

1. ກົດ {{key:F}} ຫຼື ເລືອກ {{ui:Fillet}}.
2. ຄລິກຈຸດມຸມທີ່ສອງເສັ້ນມາພົບກັນ.
3. ກ່ອງຈະເປີດພ້ອມລັດສະໝີທີ່ແນະນຳ. ພິມລັດສະໝີ ແລ້ວກົດ {{key:Enter}}.

ທັງສອງເສັ້ນຈະຖືກຕັດ ແລະ ເຊື່ອມດ້ວຍເສັ້ນໂຄ້ງສຳຜັດ ທີ່ມີຂະໜາດລັດສະໝີ. ຂໍ້ຄວາມທີ່ອາດເຫັນ: "Fillet ຕ້ອງການມຸມທີ່ມີສອງເສັ້ນພົບກັນພຽງສອງເສັ້ນເທົ່ານັ້ນ." ແລະ "ລັດສະໝີນີ້ໃຫຍ່ເກີນໄປສຳລັບເສັ້ນເຫຼົ່ານີ້."

:::tip
ການປັດມຸມພາບຮ່າງຈະປັດມຸມຂອງໂປຣໄຟລ໌, ດັ່ງນັ້ນ Extrude ຈະໄດ້ຂອບຕັ້ງທີ່ມົນ. ເພື່ອປັດຂອບຂອງຕົວຊິ້ນສ່ວນແຂງເອງ (ເຊັ່ນຂອບເທິງຂອງແຜ່ນ), ໃຫ້ໃຊ້ຟີເຈີ {{ui:Fillet}} ໃນຊິ້ນສ່ວນແທນ: ເບິ່ງ [ປັດ, ຕັດຂອບ ແລະ ເຈາະໄປເປັນກະປ໋ອງ](topic:fillet-chamfer-shell). ໃນພາບຮ່າງ, Fillet ຂອງແຖບເຄື່ອງມືແມ່ນເຄື່ອງມືພາບຮ່າງ; ໃນຊິ້ນສ່ວນ, ມັນເປັນຟີເຈີ.
:::

## ການກໍ່ສ້າງ

ເສັ້ນ, ວົງມົນ ແລະ ເສັ້ນໂຄ້ງການກໍ່ສ້າງເປັນເສັ້ນປະສີເທົາ. ມັນຊ່ວຍນຳທາງພາບຮ່າງ ແຕ່ບໍ່ແມ່ນສ່ວນໜຶ່ງຂອງໂປຣໄຟລ໌ທີ່ຖືກດຶງອອກ ຫຼື ໝຸນ.

1. ເລືອກເສັ້ນ, ວົງມົນ ຫຼື ເສັ້ນໂຄ້ງ.
2. ກົດ {{key:Q}} ຫຼື ເລືອກ {{ui:Construction}}. ກົດອີກຄັ້ງເພື່ອປ່ຽນກັບຄືນ.

## ເລືອກ, ລາກ ແລະ ລຶບ

ກົດ {{key:S}} (ຫຼື {{key:Esc}} ຈົນກວ່າບໍ່ມີເຄື່ອງມືໃດເຮັດວຽກ) ເພື່ອເລືອກ.

- ຄລິກຈຸດ, ເສັ້ນ, ວົງມົນ, ເສັ້ນໂຄ້ງ, ສັນຍາລັກຄວາມສຳພັນ ຫຼື ຂະໜາດ ເພື່ອເລືອກ. {{key:Shift}}+ຄລິກ ເພື່ອເພີ່ມ ຫຼື ເອົາອອກຈາກການເລືອກ. ໃນ Windows ແລະ Linux {{key:Ctrl}}+ຄລິກ ເຮັດໄດ້ຄືກັນ; ໃນ Mac ໃຊ້ ⌘+ຄລິກ.
- ລາກໃນບ່ອນຫວ່າງເພື່ອສ້າງກອບເລືອກ: ທຸກສິ່ງທີ່ຢູ່ພາຍໃນກອບຢ່າງຄົບຖ້ວນຈະຖືກເລືອກ.
- ລາກຈຸດ ຫຼື ເສັ້ນເພື່ອຍ້າຍ. ຕົວແກ້ສົມການຈະຮັກສາທຸກຄວາມສຳພັນ ແລະ ຂະໜາດໄວ້ຂະນະຍ້າຍ, ດັ່ງນັ້ນມີແຕ່ຮູບທີ່ບໍ່ຖືກຍຶດເທົ່ານັ້ນທີ່ຍ້າຍໄດ້. ລາກຂອບວົງມົນເພື່ອປ່ຽນລັດສະໝີ.
- ລາກຕົວເລກຂອງຂະໜາດເພື່ອຍ້າຍປ້າຍ.
- ກົດ {{key:Delete}} ຫຼື {{key:Backspace}}, ຫຼື ເລືອກ {{ui:Delete}} ໃນແຖບດ້ານຂວາ, ເພື່ອລຶບສິ່ງທີ່ເລືອກ. ການລຶບເລຂາຄະນິດຈະລຶບຄວາມສຳພັນທີ່ຢູ່ເທິງມັນນຳ.

## ຊູມ ແລະ ເລື່ອນໃນພາບຮ່າງ

- ໝຸນລໍ້ເພື່ອຊູມຢູ່ທີ່ຕົວຊີ້.
- ລາກດ້ວຍປຸ່ມກາງ ຫຼື ປຸ່ມຂວາເພື່ອເລື່ອນ.
- {{ui:Fit}} ໃນແຖບເຄື່ອງມື ຫຼື ແຖບດ້ານຂວາ ຈະປັບພາບຮ່າງໃຫ້ພໍດີກັບມຸມມອງ. ໃນພາບຮ່າງ ປຸ່ມ {{key:F}} ແມ່ນເຄື່ອງມື Fillet, ບໍ່ແມ່ນ Fit.

## ປິດພາບຮ່າງ

ເລືອກ {{ui:Exit}} ໃນແຖບເຄື່ອງມື ຫຼື {{ui:Exit sketch}} ໃນແຖບດ້ານຂວາ, ຫຼື ກົດ {{key:Esc}} ຈົນກວ່າພາບຮ່າງຈະປິດ. ແຕ່ລະ {{key:Esc}} ຈະຍົກເລີກສິ່ງທີ່ກຳລັງເຮັດກ່ອນ, ແລ້ວກັບໄປ Select, ແລ້ວລຶບການເລືອກ, ແລະ ຄັ້ງຕໍ່ໄປຈຶ່ງປິດພາບຮ່າງ.

ພາບຮ່າງຈະຍັງຖືກເລືອກຢູ່, ດັ່ງນັ້ນ {{ui:Extrude}} ຫຼື {{ui:Revolve}} ຕໍ່ໄປຈະໃຊ້ພາບຮ່າງນີ້.

## ໂປຣໄຟລ໌ທີ່ດີເປັນແນວໃດ

{{ui:Extrude}} ແລະ {{ui:Revolve}} ໃຊ້ **ທຸກວົງປິດ** ຂອງເສັ້ນ, ວົງມົນ, ເສັ້ນໂຄ້ງ ແລະ ສະພລາຍ (ທີ່ບໍ່ແມ່ນການກໍ່ສ້າງ) ຂອງພາບຮ່າງ. ວົງທີ່ຢູ່ໃນວົງອື່ນຈະກາຍເປັນຮູ.

- ທຸກປາຍຕ້ອງພົບກັບປາຍອື່ນພຽງໜຶ່ງປາຍເທົ່ານັ້ນ. "ໂປຣໄຟລ໌ເປີດຢູ່: ປາຍທີ່ (12.5, 40) ບໍ່ໄດ້ຕໍ່ກັບຫຍັງ." ຈະບອກບ່ອນນັ້ນ.
- ຈະບໍ່ມີສາມປາຍພົບກັນທີ່ຈຸດດຽວ: "ໂປຣໄຟລ໌ແຕກແຍກທີ່ (0, 20): ມີຫຼາຍກວ່າສອງປາຍພົບກັນຢູ່ນັ້ນ."
- ຈຸດ ແລະ ເລຂາຄະນິດການກໍ່ສ້າງຈະຖືກບໍ່ສົນໃຈໂດຍໂປຣໄຟລ໌.

ຕໍ່ໄປ: [ກຳນົດພາບຮ່າງໃຫ້ຄົບດ້ວຍຄວາມສຳພັນ ແລະ ຂະໜາດ](topic:relations-dimensions).

## ພາບຮ່າງຈາກຮູບຖ່າຍ

**Features › More › Sketch from a photo…** (ຫຼື ກຸ່ມ Sketch ໃນ ແຖບ Feature tree) ຈະຕິດຕາມຮູບຂອງຊິ້ນສ່ວນແບນລາບເທິງພື້ນທີ່ເຮັດງ່າຍ, ຄືຮູບຮ່າງ ແລະ ຮູຂອງມັນ, ຫຼື ຮູບແຕ້ມດ້ວຍປາກກາ ໃຫ້ເປັນພາບຮ່າງຂອງເສັ້ນ, ເສັ້ນໂຄ້ງ ແລະ ວົງມົນ. ບອກຄວາມຍາວໜຶ່ງຄ່າ (ຄວາມກວ້າງ, ຄວາມສູງ ຫຼື ດ້ານຍາວທີ່ສຸດ) ເພື່ອໃຫ້ພາບຮ່າງມີຂະໜາດຖືກຕ້ອງ, ກວດເບິ່ງສິ່ງທີ່ພົບໃນພາບຕົວຢ່າງ, ແລ້ວເລືອກ **ສ້າງພາບຮ່າງ**; ມັນຍັງສາມາດດຶງອອກເປັນຊິ້ນສ່ວນໄດ້ໃນຂັ້ນຕອນ undo ດຽວກັນ. ມັນຖືກຕິດຕາມໃນຄອມພິວເຕີເຄື່ອງນີ້. ລັດສະໝີມຸມຈະໄດ້ຄືນພາຍໃນປະມານ 5 %, ລາຍລະອຽດໜຶ່ງຫຼືສອງພິກເຊວຈະຫາຍໄປ, ແລະ ຮູບທີ່ຖ່າຍແບບອຽງ ຫຼື ມີເງາຕົກໃສ່ຊິ້ນສ່ວນຈະບໍ່ຖືກຢຽບໃຫ້ຊື່: ໃຫ້ຖ່າຍຊິ້ນສ່ວນໃຫ້ຕັ້ງສາກ ແລະ ມີແສງສະເໝີກັນ.
