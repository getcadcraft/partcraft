Lua ແມ່ນພາສາທີ່ສອງຂອງ [ພື້ນທີ່ສະຄຣິບ](topic:craftscript). ເລືອກ **Lua** ໃນກ່ອງພາສາເທິງຕົວແກ້ໄຂ (ໄຟລ໌ `.lua` ຈະເປີດເປັນ Lua ເອງ). Lua ແລະ CraftScript ໃຊ້ຕົວແປ ແລະ ຟັງຊັນທີ່ມີມາໃນຕົວຮ່ວມກັນ, ດັ່ງນັ້ນສະຄຣິບ Lua ສາມາດໃຊ້ສິ່ງທີ່ສະຄຣິບ CraftScript ສ້າງໄວ້, ແລະ ກັບກັນກໍໄດ້.

## ພື້ນຖານ

```
-- ທຸກຟັງຊັນທີ່ມີມາໃນຕົວຢູ່ໃນຕາຕະລາງ cs
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- ເລີ່ມຈາກ 1, ຄືກັບ CraftScript
print(K(1, 1), #K)             -- ໜຶ່ງອົງປະກອບ; ຈຳນວນອົງປະກອບ

-- ພື້ນທີ່ເຮັດວຽກ: ຕົວແປດຽວກັນທີ່ທຸກສະຄຣິບເຫັນ
ws.total = K(1, 1) * 2
print(ws.total)

-- ຫຼາຍຜົນຈາກຟັງຊັນດຽວ
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<ຊື່>(…)` ເອີ້ນຟັງຊັນທີ່ມີມາໃນຕົວໃດກໍໄດ້ ແລະ ສົ່ງຄືນຜົນທຳອິດ; `cs.call(ຊື່, n, …)` ສົ່ງຄືນ `n` ຜົນ.
- `cs.tensor({1, 2, 3})` ສ້າງແຖວ, `cs.tensor({{1, 2}, {3, 4}})` ສ້າງເມທຣິກ.
- ອາເຣ, ເມທຣິກກະຈາຍ, ເມຊ ແລະ ຟີລ໌ດ ເປັນຄ່າທີ່ມີວິທີການ: `t(i, j)` ຫຼື `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (ປ່ຽນຖ່າຍ), `t:totable()`. `+ - * / ^` ໝາຍເຖິງສິ່ງດຽວກັນກັບໃນ CraftScript (`*` ແມ່ນຜົນຄູນເມທຣິກ); `t:times(u)` ຄູນເປັນອົງປະກອບໆ.
- ຕົວເລກທີ່ເປັນອາເຣ 1×1 ຈະມາເປັນຕົວເລກ Lua ທຳມະດາ.
- `ws.name` ອ່ານ ແລະ ຂຽນພື້ນທີ່ເຮັດວຽກທີ່ໃຊ້ຮ່ວມກັນ. ຕົວແປທົ່ວໂລກທີ່ສະຄຣິບຂອງທ່ານປະໄວ້ກໍຈະໄປຢູ່ບ່ອນນັ້ນເມື່ອມັນຈົບ.
- `print(…)` ພິມໄປທີ່ຄອນໂຊນ; `cs.show(f)`, `cs.plot(y)` ແລະ ຟັງຊັນສະແດງອື່ນໆ ເຮັດວຽກຄືກັບໃນ CraftScript.

## ເອີ້ນຄັງການວິເຄາະ

ຟັງຊັນຂອງຄັງການວິເຄາະ (ແທັບ ຄັງ) ແລະ ຟັງຊັນ CraftScript ທີ່ສະຄຣິບຂອງຊິ້ນສ່ວນຂອງທ່ານກຳນົດ ກໍຖືກເອີ້ນຜ່ານ `cs` ເຊັ່ນກັນ:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- ສອງຜົນອອກ
```

ພວກມັນຖືກຄົ້ນພົບກ່ອນສະຄຣິບເລີ່ມ, ດັ່ງນັ້ນຕ້ອງຂຽນຊື່ໄວ້ໃນສະຄຣິບ: `cs.static_tet(` ຫຼື `cs.call('static_tet', …)`. ຊື່ທີ່ປະກອບຂຶ້ນໃນຂະນະທີ່ສະຄຣິບກຳລັງຮັນຈະເຂົ້າເຖິງໄດ້ແຕ່ຟັງຊັນທີ່ມີມາໃນຕົວເທົ່ານັ້ນ. ສະຕຣັກທີ່ສ້າງດ້ວຍ `cs.struct({ … })` ແມ່ນສະຕຣັກ CraftScript, ແລະ ລາຍການ Lua ຂອງພວກມັນ (`{ cs.struct(…), … }`) ແມ່ນເຊວ, ເຊິ່ງເປັນສິ່ງທີ່ການຕັ້ງຄ່າຂອງຄັງຕ້ອງການ. ຖ້າມີບາງຢ່າງຜິດພາດພາຍໃນຟັງຊັນຂອງຄັງ, ຂໍ້ຄວາມຈະບອກຊື່ຟັງຊັນ ແລະ ແຖວຂອງມັນ, ແລະ ຊີ້ໄປທີ່ແຖວຂອງທ່ານທີ່ເອີ້ນມັນ.

## ປິດໄວ້

ສະຄຣິບບໍ່ສາມາດເຂົ້າເຖິງໄຟລ໌, ເຄືອຂ່າຍ ຫຼື ໜ້າເວັບໄດ້: `io`, `os` (ຍົກເວັ້ນໂມງ), `require`, `dofile`, `loadfile` ແລະ `debug` ຖືກເອົາອອກ. ໃຊ້ Open ຂອງພື້ນທີ່ສະຄຣິບ ແລະ ຕົວແປເພື່ອນຳຂໍ້ມູນເຂົ້າມາ. ງົບຂັ້ນຕອນ ແລະ ປຸ່ມຢຸດເຮັດວຽກຄືກັບໃນ CraftScript.
