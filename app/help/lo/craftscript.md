**ຕົວຢ່າງ.** ການສະໜັບສະໜູນສະຄຣິບເປັນສິ່ງໃໝ່ໃນ PartCraft 0.3 ແລະ ຢູ່ໃນຂັ້ນຕົວຢ່າງ: ພາສາ, ຄັງ ແລະ ວິທີບັນທຶກສະຄຣິບອາດຈະປ່ຽນແປງ, ແລະ ສະຄຣິບທີ່ຂຽນໃນຕອນນີ້ອາດຕ້ອງແກ້ໄຂເລັກນ້ອຍໃນພາຍຫຼັງ. ບອກພວກເຮົາວ່າມີຫຍັງເສຍຫາຍ.

ພື້ນທີ່ສະຄຣິບຮັນການຄຳນວນຂອງທ່ານເອງຄຽງຂ້າງຊິ້ນສ່ວນ: ການບວກເລັກໆນ້ອຍໆ, ການວິເຄາະທັງໝົດ, ຫຼື ສະຄຣິບໃນ [ຄັງການວິເຄາະ](topic:craftscript-library). ສະຄຣິບຂຽນດ້ວຍ **CraftScript** (ພາສາເມທຣິກຄ້າຍ MATLAB, ເບິ່ງ [ພາສາ CraftScript](topic:craftscript-language)) ຫຼື ດ້ວຍ **Lua** (ເບິ່ງ [ສະຄຣິບໃນ Lua](topic:craftscript-lua)) ຫຼື ດ້ວຍ **Python** (ເບິ່ງ [ສະຄຣິບໃນ Python](topic:craftscript-python)).

ເລືອກ **ສະຄຣິບ** ໃນກ່ອງ **ພື້ນທີ່ເຮັດວຽກ** ທີ່ດ້ານຊ້າຍຂອງແຖບເຄື່ອງມື. ຊິ້ນສ່ວນຈະບໍ່ຖືກປ່ຽນແປງ. ແຜງເບື້ອງຂວາຈະກາຍເປັນແຜງສະຄຣິບ (ກວ້າງກວ່າປົກກະຕິ; ລາກຂອບຂອງມັນເພື່ອປ່ຽນຂະໜາດ, ຫຼື ຍ້າຍໄປຈໍທີສອງດ້ວຍເມນູ {{ui:⋯}} ຂອງມັນ, ເບິ່ງ [ຈັດແຈງແຜງ](common:arrange-panels)).

## ສະຄຣິບຂະນະສ້າງແບບ

ທ່ານບໍ່ຈຳເປັນຕ້ອງອອກຈາກພື້ນທີ່ອອກແບບເພື່ອຂຽນສະຄຣິບ. ໃນ Design, ແທັບ {{ui:Script}} ຂອງແຜງເບື້ອງຂວາມີຕົວແກ້ໄຂ, ຄອນໂຊນ, ຕົວແປ ແລະ ຄັງດຽວກັນ, ພ້ອມສະຄຣິບດຽວກັນ. ຕົ້ນໄມ້ຟີເຈີ ແລະ ມຸມມອງຍັງເຮັດວຽກຕໍ່ໄປ: ຄລິກຟີເຈີເພື່ອເລືອກມັນ, ດັບເບີ້ນຄລິກສະເກັດເພື່ອແກ້ໄຂມັນ, ໝຸນມຸມມອງ, ແລ້ວກັບໄປທີ່ແທັບ {{ui:Script}} ແລະ ກົດ {{key:F5}}.

ສິ່ງທີ່ສະຄຣິບ **ສະແດງ** (ເມຊ, ຟີລ໌ດ, ແຜນທີ່, ຕາຕະລາງ) ຈະບໍ່ຖືກແຕ້ມທັບໂມເດວຂອງທ່ານໃນ Design: ຄອນໂຊນຈະບອກແບບນັ້ນ, ແລະ ພື້ນທີ່ສະຄຣິບມີທັງໝົດນັ້ນເມື່ອທ່ານສະຫຼັບໄປ.

{{ui:Pop out}}, ຢູ່ຂ້າງ {{ui:Run}}, ຍ້າຍທັງແຜງໄປເປັນໜ້າຕ່າງຂອງມັນເອງ, ເຊັ່ນຢູ່ຈໍທີສອງ, ເພື່ອໃຫ້ຕົວແກ້ໄຂ ແລະ ມຸມມອງເຕັມຢູ່ຄຽງກັນ. {{ui:Put back}} ເອົາມັນກັບໄປເກາະອີກຄັ້ງ. ເບິ່ງ [ຈັດແຈງແຜງ](common:arrange-panels).

## ຮັນສະຄຣິບທຳອິດຂອງທ່ານ

1. ພິມໃນຕົວແກ້ໄຂ, ຕົວຢ່າງ:

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. ກົດ {{key:F5}} (ຫຼື {{ui:Run}}). ຄອນໂຊນທີ່ຢູ່ລຸ່ມຕົວແກ້ໄຂຈະສະແດງສິ່ງທີ່ສະຄຣິບພິມ, ແລະ "Done in … s". ແຜນທີ່ປາກົດໃນ **ໜ້າຈໍຍ່ອຍ** ຕາມລຸ່ມຂອງມຸມມອງ 3D.
3. ແຖວທີ່ບໍ່ມີ semicolon ຈະພິມຄ່າຂອງມັນ, ຄືກັບໃນ MATLAB: `a = 3` ພິມ `a = 3`; `a = 3;` ບໍ່ພິມຫຍັງ.
4. ເພື່ອຮັນພຽງບາງສ່ວນຂອງສະຄຣິບ, ເລືອກແຖວ ແລະ ກົດ {{key:Mod+Enter}} ({{ui:Selection}}). ຖ້າບໍ່ໄດ້ເລືອກຫຍັງ ມັນຈະຮັນແຖວທີ່ເຄີເຊີຢູ່.
5. ແຖວຢູ່ລຸ່ມສຸດຂອງຄອນໂຊນ (ຫຼັງ `>>`) ຮັນປະໂຫຍກໜຶ່ງໃນເວລາທີ່ທ່ານກົດ {{key:Enter}}. {{key:Up}} ແລະ {{key:Down}} ເອີ້ນແຖວທີ່ເຄີຍພິມກ່ອນໜ້າ.

## ຊອກຫາ, ພັບ ແລະ ເຕີມໃຫ້ສົມບູນ

- **ຊອກຫາ ແລະ ແທນທີ່.** ກົດ {{key:Mod+F}} (ຫຼື {{key:Mod+H}} ເພື່ອແທນທີ່ນຳ). ແຖບເປີດຂຶ້ນເໜືອໂຄ້ດ: ພິມສິ່ງທີ່ຈະຊອກຫາ; ຜົນທີ່ກົງກັນຈະສະຫວ່າງຂຶ້ນ ແລະ ຕົວນັບບອກວ່າທ່ານຢູ່ບ່ອນໃດ. ປຸ່ມຂ້າງກ່ອງຈະກົງຕົວພິມ (**Aa**), ຊອກຫາແຕ່ຄຳທັງໝົດ (**W**) ແລະ ໃຊ້ນິພົດປົກກະຕິ (**.\***; ໃນການແທນທີ່, `$1` ໃສ່ສິ່ງທີ່ກຸ່ມທຳອິດກົງກັນຄືນ). {{ui:Replace}} ແທນທີ່ການກົງກັນປັດຈຸບັນ, {{ui:All}} ແທນທີ່ທຸກການກົງກັນເປັນຂັ້ນຕອນດຽວຂອງ {{key:Mod+Z}}.
- **ການພັບ.** ກົດ ▾ ຂ້າງເລກແຖວ, ຫຼື ກົດ {{key:Mod+Shift+[}} ໂດຍມີເຄີເຊີຢູ່ແຖວ `function`, `if`, `for`, `while`, `switch` ຫຼື `try` (Lua: `function`, `do`, `if`, `repeat`), ເພື່ອເກັບແຖວພາຍໃນຂອງມັນໄວ້; ແຖວຈະບອກວ່າມີຈັກແຖວ. ▸ ຫຼື {{key:Mod+Shift+]}} ເປີດມັນອີກຄັ້ງ. ການພັບພຽງແຕ່ເຊື່ອງແຖວ: Run, Save, ການສຳເນົາ ແລະ ເລກແຖວທັງໝົດຍັງນັບທຸກແຖວຢູ່, ແລະ ການພິມໃນແຖວທີ່ພັບຈະເປີດມັນກ່ອນ.
- **ການເຕີມໃຫ້ສົມບູນ.** ພິມສອງຕົວອັກສອນຂອງຊື່, ຫຼື ກົດ {{key:Mod+Space}}: ລາຍການຈະສະແດງຕົວແປທີ່ທ່ານມີ, ຟັງຊັນຂອງພາສາ (ພ້ອມອາກິວເມັນ), ຄຳສຳຄັນ ແລະ ຊື່ທີ່ມີຢູ່ໃນສະຄຣິບແລ້ວ. ເລືອກດ້ວຍລູກສອນ ແລະ ກົດ {{key:Enter}} ຫຼື {{key:Tab}}.

## ເມື່ອມີບາງຢ່າງຜິດພາດ

- ຂໍ້ຜິດພາດບອກບັນຫາ ແລະ ແຖວຂອງມັນ: ແຖວຖືກໝາຍສີແດງໃນຕົວແກ້ໄຂ, ແລະ **Line n** ໃນຄອນໂຊນພາທ່ານໄປຫາມັນ.
- ລູບທີ່ບໍ່ສິ້ນສຸດ: ກົດ {{ui:Stop}} (ໃນແຖບເຄື່ອງມື ຫຼື ແຜງ). ສະຄຣິບຢຸດທັນທີ; ຕົວແປຈະຮັກສາຄ່າທີ່ມັນມີກ່ອນການຮັນນັ້ນ.
- ທຸກການຮັນຍັງມີ ງົບຂັ້ນຕອນ (2 ພັນລ້ານຂັ້ນຕອນຕາມຄ່າເລີ່ມຕົ້ນ; ປ່ຽນໄດ້ໃນ **Run options** ໃນແຜງ). ການຮັນທີ່ເກີນງົບຈະຢຸດພ້ອມຂໍ້ຄວາມ.

## ຕົວແປເດີນທາງຈາກສະຄຣິບໄປສະຄຣິບ

ທຸກຕົວແປລະດັບເທິງສຸດທີ່ສະຄຣິບສ້າງຈະໄປຢູ່ໃນແທັບ **ຕົວແປ** (ຊື່, ປະເພດ, ຂະໜາດ, ຄ່າຕ່ຳສຸດ ແລະ ສູງສຸດ) ແລະ ຢູ່ຕໍ່ໄປສຳລັບສະຄຣິບຕໍ່ໄປ, ໃນພາສາໃດກໍໄດ້. ນີ້ແມ່ນວິທີທີ່ສະຄຣິບໜຶ່ງສ້າງເມຊ, ອັນຕໍ່ໄປແກ້, ແລະ ອັນທີສາມສະແດງແຜນທີ່.

- ຄລິກຕົວແປເພື່ອສະແດງມັນ: ເມຊ, ຟີລ໌ດ ແລະ ໂມເດວໃນມຸມມອງ 3D, ອາເຣເປັນຕາຕະລາງ (ພ້ອມແຜນທີ່ເສັ້ນສຳລັບເວກເຕີ ຫຼື ແຜນທີ່ສີສຳລັບເມທຣິກ) ໃນໜ້າຈໍຍ່ອຍ.
- {{ui:Save as JSON}}, {{ui:Save as CSV}} (ຕາຕະລາງຕົວເລກ) ແລະ {{ui:Save as HDF5}} ດາວໂຫຼດມັນ; {{ui:Delete}} ເອົາມັນອອກ; {{ui:Clear all}} ລ້າງພື້ນທີ່ເຮັດວຽກ.
- ໝາຍ **ບັນທຶກຕົວແປພ້ອມຊິ້ນສ່ວນ** ເພື່ອເກັບມັນໄວ້ໃນໄຟລ໌ຊິ້ນສ່ວນ (ສູງສຸດ 32 MB; ອັນໃຫຍ່ກວ່ານັ້ນຈະຢູ່ສຳລັບການເຂົ້າໃຊ້ຄັ້ງນີ້ເທົ່ານັ້ນ). ເມື່ອທ່ານເປີດຊິ້ນສ່ວນແບບນັ້ນ, ແຜງຈະສະເໜີໃຫ້ໂຫຼດມັນ.

## ເມຊ, ຟີລ໌ດ ແລະ ແຜນທີ່

- `show(m)` ແຕ້ມເມຊ; `show(f)` ໃສ່ສີໃຫ້ຟີລ໌ດເທິງເມຊຂອງມັນພ້ອມແຖບສີ. ລາຍການ **ສະແດງ** ມຸມເທິງຊ້າຍຂອງມຸມມອງຊ່ອນ ({{ui:eye}}) ຫຼື ເອົາອອກແຕ່ລະລາຍການ, ແລະ ຊ່ອນ ຫຼື ສະແດງຊິ້ນສ່ວນເອງ. ຢູ່ໃຕ້ແຖບສີ, ພິມຊ່ວງ (**From**, **to**) ຫຼື ກົດ {{ui:Auto}}; ເວກເຕີ ຫຼື ຟີລ໌ດຄວາມເຄັ້ນຍັງໃຫ້ເລືອກອົງປະກອບທີ່ຈະສະແດງ.
- `show(f, 'deform', u, 'scale', 50)` ແຕ້ມເມຊທີ່ຖືກເຄື່ອນດ້ວຍຟີລ໌ດການເຄື່ອນຕົວ `u`, ຂະຫຍາຍ 50 ເທົ່າ (ຖ້າບໍ່ມີ `scale`, ປະມານ 8 % ຂອງຂະໜາດໂມເດວ).
- ຄລິກເມຊທີ່ສະແດງ: ໂນດທີ່ໃກ້ທີ່ສຸດ, ອົງປະກອບ ແລະ ຄ່າຟີລ໌ດຢູ່ບ່ອນນັ້ນຈະປາກົດໃນໜ້າຈໍຍ່ອຍ (**ທີ່ເລືອກ**).
- `plot`, `imagesc` ແລະ `table` ໃສ່ແຜນທີ່ເສັ້ນ, ແຜນທີ່ສີຂອງອາເຣ 2-D ຫຼື ຕາຕະລາງ ໃນໜ້າຈໍຍ່ອຍ. ແຜນທີ່ທີ່ມີ `'id'` (ຫຼື ຊື່) ດຽວກັບອັນກ່ອນໜ້າຈະແທນທີ່ມັນ, ດັ່ງນັ້ນລູບສາມາດອັບເດດແຜນທີ່ການລູ່ເຂົ້າໜຶ່ງອັນ; `'append', true` ເພີ່ມເສັ້ນໂຄ້ງເຂົ້າໃນແຜນທີ່. {{ui:Clear}} ລ້າງໜ້າຈໍຍ່ອຍ; ລູກສອນຈະພັບມັນເກັບໄວ້.
- ເມື່ອມີສອງແຜນທີ່ຂຶ້ນໄປ, {{ui:Side by side}} ສະແດງພວກມັນທັງໝົດພ້ອມກັນ (ຫົກອັນທີ່ໃໝ່ທີ່ສຸດ); ການຄລິກແທັບຂອງຕາຕະລາງ ຫຼື ຮູບຈະສະແດງອັນນັ້ນພຽງອັນດຽວອີກຄັ້ງ.
- ທຸກແຜນທີ່ມີ {{ui:PNG}}, {{ui:SVG}} ແລະ {{ui:CSV}} ຢູ່ລຸ່ມ. PNG ແລະ SVG ພິມມັນໃສ່ພື້ນຂາວດ້ວຍສີເອກະສານ ບໍ່ວ່າຈະເປັນຫຍັງຂອງຫົວຂໍ້ (PNG 1600 × 1000 ພິກເຊວ; SVG ຂະຫຍາຍໂດຍບໍ່ເບີ່ຍ); CSV ເກັບຕົວເລກຂອງມັນດ້ວຍທຸກຕຳແໜ່ງ: ຖັນໜຶ່ງຂອງ x ແລະ ຖັນຕໍ່ເສັ້ນໂຄ້ງເມື່ອເສັ້ນໂຄ້ງໃຊ້ x ຮ່ວມກັນ, ຖ້າບໍ່ດັ່ງນັ້ນ ໜຶ່ງແຖວຕໍ່ຈຸດພ້ອມຊື່ຂອງເສັ້ນໂຄ້ງ.
- {{key:F}} ຫຼື {{ui:Fit}} ພໍດີມຸມມອງກັບສິ່ງທີ່ສະແດງ.

## ໄຟລ໌

- {{ui:Open}} ໃນກຸ່ມ Script (ຫຼື ວາງໄຟລ໌ໃສ່ມຸມມອງ ຫຼື ແຜງ): ໄຟລ໌ `.craft`, `.lua` ແລະ `.py` ເປີດເປັນສະຄຣິບໃໝ່ (ພວກມັນບໍ່ຮັນ); ໄຟລ໌ຂໍ້ມູນ (STL, OBJ, CSV, JSON, NPY, HDF5) ໂຫຼດເຂົ້າໃນຕົວແປພາຍໃຕ້ຊື່ໄຟລ໌ຂອງມັນ.
- {{ui:Save}} ໃນກຸ່ມ Script ດາວໂຫຼດສະຄຣິບປັດຈຸບັນເປັນໄຟລ໌.
- {{ui:New}} ໃນກຸ່ມ Script (ຫຼື {{ui:+}} ຂ້າງແທັບ) ເລີ່ມສະຄຣິບອີກອັນໜຶ່ງ. ດັບເບີ້ນຄລິກແທັບເພື່ອປ່ຽນຊື່; {{ui:×}} ຂອງມັນເອົາອອກ (ທ່ານສາມາດຍົກເລີກສິ່ງນັ້ນໄດ້).

## ອ່ານພາລາມິເຕີຂອງຊິ້ນສ່ວນ

ສະຄຣິບອ່ານພາລາມິເຕີຂອງຊິ້ນສ່ວນ (ເບິ່ງ [ຂັບເຄື່ອນຊິ້ນສ່ວນດ້ວຍພາລາມິເຕີ](topic:parameters)) ດ້ວຍຊື່:

```
w = param('width');     % ຄ່າຂອງພາລາມິເຕີໜຶ່ງ, ເປັນມມ (ຫຼື ອົງສາ, ຫຼື ຕົວເລກທຳມະດາ)
p = params();           % ທັງໝົດ, ເປັນສະຕຣັກ: p.width, p.height
```

ໃນ Lua ແລະ Python ມັນແມ່ນ `cs.param('width')` ແລະ `cs.params()`. ສະຄຣິບອ່ານພາລາມິເຕີເທົ່ານັ້ນ: ປ່ຽນພວກມັນໃນແທັບ {{ui:Parameters}}. ພາຍໃຕ້ແທັບຂອງສະຄຣິບ, ແຖວໜຶ່ງລາຍຊື່ພາລາມິເຕີທີ່ມັນອ່ານດ້ວຍ `param('…')`, ແລະ ໝາຍຕົວໃດທີ່ຊິ້ນສ່ວນບໍ່ມີ; ແທັບ {{ui:Parameters}} ລາຍຊື່ສະຄຣິບຢູ່ໃຕ້ແຕ່ລະອັນ. ຊື່ທີ່ສ້າງຂຶ້ນໃນຂະນະທີ່ສະຄຣິບກຳລັງຮັນ, ເຊັ່ນ `param(name)`, ຈະບໍ່ຖືກລາຍຊື່.

## ສະຄຣິບຖືກບັນທຶກໄວ້ໃນຊິ້ນສ່ວນ

ທຸກສະຄຣິບໃນແທັບຖືກເກັບໄວ້ໃນຊິ້ນສ່ວນ, ດັ່ງນັ້ນ {{ui:Save}} ໃນກຸ່ມ File ບັນທຶກພວກມັນພ້ອມກັນ ແລະ ການປ່ຽນແປງຂອງພວກມັນສາມາດຍົກເລີກໄດ້. ການເປີດຊິ້ນສ່ວນ **ບໍ່ເຄີຍຮັນສະຄຣິບຂອງມັນ**: ຄອນໂຊນບອກວ່າມີຈັກອັນ, ແລະ ພວກມັນຮັນເມື່ອທ່ານກົດ Run ເທົ່ານັ້ນ. ຊິ້ນສ່ວນຈາກຄົນອື່ນສາມາດມີສະຄຣິບອັນໃດກໍໄດ້: ໃຫ້ອ່ານມັນກ່ອນຮັນ. ສະຄຣິບຮັນເບື້ອງຫຼັງໃນຄອມພິວເຕີນີ້ໂດຍບໍ່ມີການເຂົ້າເຖິງເຄືອຂ່າຍ ແລະ ບໍ່ສາມາດແຕະຕ້ອງໜ້າເວັບໄດ້.
