ການວິເຄາະໃນພື້ນທີ່ສະຄຣິບແມ່ນສະຄຣິບສັ້ນບໍ່ເທົ່າໃດອັນທີ່ສົ່ງຕົວແປໃຫ້ກັນແລະກັນ. ເລີ່ມຈາກຟັງຊັນ [ຄັງ](topic:craftscript-library) ທີ່ໃກ້ກັບສິ່ງທີ່ທ່ານຕ້ອງການ, ສ້າງສຳເນົາ ແລ້ວປ່ຽນແປງມັນ; ຫຼື ສ້າງຂຶ້ນມາເອງດັ່ງຂ້າງລຸ່ມ.

## 1. ເມຊ

```
model = part();                  % ຊິ້ນສ່ວນທີ່ທ່ານກຳລັງສ້າງແບບຈຳລອງ, ເປັນໂມເດວ
m = tetmesh(model, 4);           % ເຕຕຣາເຮດຣອນຂະໜາດປະມານ 4 mm
show(m)
```

ກວດສອບເມຊໃນມຸມມອງກ່ອນດຳເນີນຕໍ່: {{key:F}} ພໍດີກັບມັນ, ແລະ {{ui:eye}} ໃນ **ສະແດງ** ຊ່ອນຊິ້ນສ່ວນ.

## 2. ປະກອບ ແລະ ແກ້

ຂຽນລູບອົງປະກອບໃນສະຄຣິບ (ມັນອ່ານຄືກັບໃນປຶ້ມຕຳລາ), ແລະ ປ່ອຍໃຫ້ສ່ວນທີ່ໜັກໃຫ້ຟັງຊັນທີ່ມີມາໃນຕົວ: ເມທຣິກອົງປະກອບ, ການປະກອບແບບກະຈາຍຈາກສາມຕົວ, ແລະ ຕົວແກ້ gradient ແບບຄອນຈູເກດ ທີ່ມີຕົວປັບກ່ອນ. ຟັງຊັນໃນຄັງເຊັ່ນ `static_tet` (ເມື່ອຄັງມີມັນແລ້ວ) ເປັນຕົວຢ່າງທີ່ສົມບູນໃຫ້ຄັດລອກ.

## 3. ສະແດງຜົນ

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % ໜຶ່ງຄ່າຕໍ່ໂນດ
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- ຊ່ວງຂອງແຖບສີສາມາດພິມເຂົ້າໄປ ຫຼື ຕັ້ງກັບຄືນເປັນ {{ui:Auto}}.
- ກົດໃສ່ເມຊເພື່ອອ່ານຄ່າຢູ່ໂນດ.
- ແຜນທີ່ທີ່ຮັກສາ `'id'` ເດີມຈະຖືກອັບເດດໃນບ່ອນເດີມ, ດັ່ງນັ້ນໃຫ້ພິມ ແລະ ສະແດງແຜນທີ່ພາຍໃນລູບຂອງທ່ານເພື່ອເບິ່ງການລູ່ເຂົ້າ.

## 4. ກວດສອບ

ປຽບທຽບກັບສິ່ງທີ່ທ່ານຮູ້: ການໂກ່ງປາຍຂອງຄານຍື່ນທຽບກັບ PL³/3EI, ແຜ່ນທີ່ມີຮູທຽບກັບຄ່າປັດໄຈການເຂັ້ມຂຸ້ນຄວາມເຄັ້ນ, ແຮງປະຕິກິລິຍາທຽບກັບແຮງທີ່ໃສ່. ຂຽນການກວດສອບເປັນສະຄຣິບຂອງມັນເອງເພື່ອໃຫ້ມັນຮັນອີກຫຼັງທຸກການປ່ຽນແປງ:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. ເກັບໄວ້

- ແຕ່ລະຂັ້ນຕອນສາມາດເປັນແທັບສະຄຣິບຂອງມັນເອງ: ພວກມັນໃຊ້ຕົວແປຮ່ວມກັນ, ດັ່ງນັ້ນໃຫ້ຮັນທີ່ລະອັນຕາມລຳດັບ.
- ສະຄຣິບຖືກບັນທຶກໄວ້ໃນຊິ້ນສ່ວນ. ໃຫ້ໝາຍ **ບັນທຶກຕົວແປພ້ອມຊິ້ນສ່ວນ** ໃນແທັບຕົວແປເພື່ອເກັບຜົນລັບດ້ວຍ (ສູງສຸດ 32 MB).
- {{ui:Save}} ໃນກຸ່ມ Script ດາວໂຫຼດສະຄຣິບເພື່ອແບ່ງປັນ; {{ui:Open}} ນຳສະຄຣິບເຂົ້າມາ.
