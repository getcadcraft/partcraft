## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນ

ວິທີໃຫ້ຜູ້ຊ່ວຍ AI (ຫຼື ສະຄຣິບທີ່ທ່ານຂຽນເອງ) ເບິ່ງຊິ້ນສ່ວນທີ່ທ່ານເປີດຢູ່, ປ່ຽນພາລາມິເຕີຂອງມັນ, ຮັນສະຄຣິບ ແລະ ສົ່ງອອກມັນ, ແລະ ວິທີທີ່ທ່ານກຳນົດວ່າມັນສາມາດແຕະຕ້ອງຫຍັງໄດ້.

PartCraft **ບໍ່ມີ AI ຂອງຕົນເອງ** ແລະ ບໍ່ສົ່ງຫຍັງໄປບ່ອນໃດເລີຍ. ທ່ານນຳຜູ້ຊ່ວຍມາເອງ: ໂປຣແກຣມໃດກໍໄດ້ທີ່ຮອງຮັບ Model Context Protocol (MCP). PartCraft ພຽງແຕ່ໃຫ້ເຄື່ອງມືແກ່ມັນ ແລະ ທ່ານເປັນຜູ້ເລືອກວ່າຈະໃຫ້ເຄື່ອງມືໃດ.

## ເປີດໃຊ້

1. ເປີດ {{ui:ການຕັ້ງຄ່າ}} (ຮູບເຟືອງໃນແຖບແອັບ ຫຼື {{key:Mod+,}}) ແລ້ວໄປທີ່ແທັບ {{ui:PartCraft}}.
2. ພາຍໃຕ້ {{ui:ຜູ້ຊ່ວຍ}}, ໝາຍຖືກ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະ ສະຄຣິບໃຊ້ PartCraft**. ມັນປິດຢູ່ຈົນກວ່າທ່ານຈະເຮັດແບບນັ້ນ.
3. ເລືອກສິ່ງທີ່ມັນສາມາດເຮັດໄດ້. **ອ່ານ** ຖືກໝາຍໄວ້ຕັ້ງແຕ່ເລີ່ມ; ໝາຍອັນອື່ນພຽງເມື່ອທ່ານຕ້ອງການ.
4. ເພື່ອໃຫ້ມັນສົ່ງອອກ ແລະ ບັນທຶກເຂົ້າໂຟນເດີ, ເລືອກ {{ui:ເພີ່ມໂຟນເດີ…}} ພາຍໃຕ້ **ໂຟນເດີທີ່ມັນສາມາດໃຊ້ໄດ້** ແລ້ວເລືອກໂຟນເດີໃນກ່ອງໂຕ້ຕອບຂອງ Studio.

ຜູ້ຊ່ວຍເຊື່ອມຕໍ່ຜ່ານ **CadCraft Studio** ໃນຄອມພິວເຕີຂອງທ່ານ: Studio ຈະສະແດງທີ່ຢູ່ ແລະ ໂທເຄັນທີ່ຕ້ອງວາງໃສ່ຜູ້ຊ່ວຍ. ແທັບບຣາວເຊີບໍ່ສາມາດເປີດການເຊື່ອມຕໍ່ໃຫ້ຜູ້ຊ່ວຍໄດ້.

## ຜູ້ຊ່ວຍສາມາດຂໍຫຍັງໄດ້ແດ່

| ເຄື່ອງມື | ສິດ | ສິ່ງທີ່ມັນເຮັດ |
|---|---|---|
| `part_describe`, `features_list` | ອ່ານ | ຄຸນສົມບັດຕາມລຳດັບ ພ້ອມສິ່ງທີ່ສ້າງສຳເລັດ ແລະ ສິ່ງທີ່ລົ້ມເຫຼວ, ວັດສະດຸ, ບໍລິມາດ ແລະ ຂະໜາດຂອງຕົວທຶບ |
| `params_list` | ອ່ານ | ພາລາມິເຕີ ແລະ ທຸກຕົວເລກທີ່ສົມຜົນສາມາດຂັບເຄື່ອນໄດ້, ພ້ອມຄ່າຂອງພວກມັນ |
| `mass_properties` | ອ່ານ | ບໍລິມາດ, ເນື້ອທີ່, ຈຸດສູນກາງມວນ, ໂມເມັນເນຍ (inertia) ອ້ອມມັນ; ມວນເມື່ອຊິ້ນສ່ວນມີວັດສະດຸ |
| `param_set` | ແກ້ໄຂ | ຕັ້ງພາລາມິເຕີ ຫຼື ຕົວເລກຂອງຄຸນສົມບັດ ແລ້ວສ້າງໃໝ່. ເປັນຂັ້ນຕອນດຽວທີ່ທ່ານຍ້ອນກັບໄດ້ |
| `script_run` | ແກ້ໄຂ | ຮັນສະຄຣິບ CraftScript, Lua ຫຼື Python ໃນແບບດຽວກັນກັບພື້ນທີ່ເຮັດວຽກ {{ui:ສະຄຣິບ}}: ປິດສະໜິດ, ບໍ່ມີໄຟລ໌ ແລະ ບໍ່ມີເຄືອຂ່າຍ. ຊິ້ນສ່ວນຈະບໍ່ປ່ຽນ |
| `part_export` | ສົ່ງອອກ | STL, 3MF, STEP ຫຼື OpenUSD (.usdz, .usda, .usdc), ຕາມທີ່ {{ui:ໄຟລ໌}} › {{ui:ສົ່ງອອກ}} ຂຽນມັນ |
| `link_push` | ແກ້ໄຂ | ອັບເດດແບບທີ່ເຊື່ອມມາຈາກໂປຣແກຣມອື່ນ (ເບິ່ງ [ເກັບແບບ .3dm ໃຫ້ອັບເດດຢູ່ສະເໝີ](topic:live-3dm-link)) |
| `link_status` | ອ່ານ | ບອກວ່າແບບທີ່ເຊື່ອມຍັງຢູ່ບໍ່ ແລະ ອັບເດດຄັ້ງສຸດທ້າຍເມື່ອໃດ |
| `part_save` | ບັນທຶກ | {{ui:ບັນທຶກ}} ຂອງ PartCraft ເອງ |
| `illustrate_export` | ສົ່ງອອກ | ຄູ່ມືຈາກພື້ນທີ່ເຮັດວຽກ {{ui:ແຕ້ມຮູບປະກອບ}} ເປັນພາບເສັ້ນ PDF ຫຼື SVG ຂອງມຸມມອງ, ເປັນໄຟລ໌ 3D ແບບໂຕ້ຕອບ, ຫຼື ຄຳແນະນຳເປັນ PDF ຫຼື ໜ້າເວັບ, ຕາມທີ່ເມນູ {{ui:ສົ່ງອອກ}} ແລະ {{ui:ຄຳແນະນຳ}} ຂອງພື້ນທີ່ເຮັດວຽກຂຽນມັນ ([ຄູ່ມື](topic:illustrate)) |

## ທ່ານຄວບຄຸມຢູ່ສະເໝີ

- **ທຸກການປ່ຽນແປງແມ່ນໜຶ່ງຂັ້ນຕອນການຍ້ອນກັບ**, ມີປ້າຍຊື່ສຳລັບຜູ້ຊ່ວຍ, ເຊັ່ນ "Assistant: set l = 45". ກົດ {{key:Mod+Z}} ເພື່ອຍ້ອນກັບ.
- **ທ່ານຮູ້ເມື່ອມີການເຊື່ອມຕໍ່.** ປຸ່ມໃນແຖບແອັບຈະບອກຊື່ຜູ້ຊ່ວຍຕາບໃດທີ່ມັນເຊື່ອມຕໍ່ຢູ່. ກົດມັນເພື່ອເບິ່ງວ່າມັນເຮັດຫຍັງໄດ້ແດ່, ຫຼື ເພື່ອ **ຕັດການເຊື່ອມຕໍ່** ມັນ.
- **ກິດຈະກຳ.** {{ui:ການຕັ້ງຄ່າ}} › {{ui:PartCraft}} › {{ui:ຜູ້ຊ່ວຍ}} › {{ui:ກິດຈະກຳ}} ລາຍການທຸກການເອີ້ນ; {{ui:ບັນທຶກລາຍການ}} ເກັບສຳເນົາໄວ້.
- **ໂຟນເດີ.** ມັນອ່ານ ແລະ ຂຽນໄຟລ໌ພຽງໃນໂຟນເດີທີ່ທ່ານເພີ່ມເທົ່ານັ້ນ; {{ui:ລຶບອອກ}} ເອົາໂຟນເດີຄືນທັນທີ.

## ໂດຍບໍ່ຕ້ອງເປີດ PartCraft

ເຊີບເວີໄຟລ໌ CadCraft ສຳລັບຜູ້ຊ່ວຍ (`npx @getcadcraft/mcp`) ແລະ ຄຳສັ່ງ `cadcraft` ເປີດຊິ້ນສ່ວນ `.partcraft.json` ດ້ວຍໂຄດຂອງ PartCraft ເອງ ແລະ ເຄີເນລເມຊ, ໂດຍບໍ່ມີໜ້າຕ່າງ: ເຄື່ອງມືອ່ານແບບດຽວກັນ, ການຕັ້ງພາລາມິເຕີ, ສະຄຣິບ CraftScript, ການສົ່ງອອກ (ລວມ OpenUSD) ແລະ ການບັນທຶກ. `cadcraft convert bracket.partcraft.json bracket.stl` ສ້າງຊິ້ນສ່ວນ ແລະ ຂຽນມັນອອກຈາກບັນທັດຄຳສັ່ງ (command line). ຄູ່ມື (`.partcraft-manual.json`) ກໍສົ່ງອອກໄດ້ທີ່ນັ້ນເຊັ່ນກັນ: `illustrate_export`, ຫຼື `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (ເພີ່ມ `--instructions` ສຳລັບຄຳແນະນຳ).

## ຖ້າມີບາງຢ່າງບໍ່ເຮັດວຽກ

- **"needs the edit permission":** ໝາຍ **Edit** ພາຍໃຕ້ {{ui:ຜູ້ຊ່ວຍ}}, ແລ້ວຖາມອີກຄັ້ງ.
- **"driven by the equation":** ຕົວເລກນັ້ນຕາມພາລາມິເຕີ; ໃຫ້ຜູ້ຊ່ວຍຕັ້ງພາລາມິເຕີແທນ.
- **ການປ່ຽນແປງຂອງມັນຜິດ:** ກົດ {{key:Mod+Z}}.
