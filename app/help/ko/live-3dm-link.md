모델은 만드는 곳에서 계속 다듬고, 가공, 검토, 문서화는 여기서 합니다. 다른 프로그램에서 변경할 때마다 PartCraft에서 가져온 바디 하나가 교체되며, 그 뒤의 피처는 새 형상에 맞춰 다시 만들어집니다.

:::note
연결하려면 같은 컴퓨터에 **CadCraft Studio**가 필요합니다. 브라우저 탭으로는 연결할 수 없습니다. 인터넷으로는 아무것도 전송되지 않습니다. 스크립트는 이 컴퓨터의 자체 주소로 Studio와 토큰을 사용해 통신합니다.
:::

:::warning
이 연결은 스크립트의 파일 쓰기 기능과, 다른 프로그램을 대신하는 대체 프로그램으로 테스트되었습니다. 아직 Rhino나 Grasshopper 내부에서는 테스트하지 않았습니다. 그곳에서 실패하면 표시된 메시지를 알려 주십시오.
:::

## 설정하기

1. Studio에서 PartCraft를 엽니다. {{ui:설정}} › {{ui:PartCraft}} › {{ui:어시스턴트}}에서 **AI 어시스턴트와 스크립트가 PartCraft를 사용하도록 허용**을 체크한 다음 **편집**을 누르십시오.
2. Studio에서 {{ui:어시스턴트 연결}}을 선택하십시오. 아래에 붙여넣을 주소와 토큰이 표시됩니다.
3. 스크립트를 내려받으십시오: [cadcraft_link.py](https://getcadcraft.com/assets/link3dm/cadcraft_link.py).

## Rhino에서

1. Rhino의 스크립트 편집기에서 `cadcraft_link.py`를 실행하십시오(Rhino 8에서는 Python 3).
2. 처음에는 주소와 토큰을 붙여넣으십시오. 이 값은 홈 폴더의 `.cadcraft-link.json`에 저장되며, 모델에는 저장되지 않습니다. Studio는 시작할 때마다 새 토큰을 만들므로, 그때 스크립트가 다시 묻습니다.

중지하려면 스크립트를 다시 실행하십시오.

## Grasshopper에서

먼저 Rhino에서 스크립트를 한 번 실행하여 주소와 토큰을 저장하십시오.

1. Script 구성 요소(Python 3)를 추가하고 `cadcraft_link.py` 전체를 붙여넣으십시오.
2. 다음 입력을 지정하십시오: `G`(형상, 목록 접근), `N`(이름, 선택 사항), `On`(부울 토글), `Target`(선택 사항: `model` 또는 `part`, 두 앱이 모두 열려 있는 경우).
3. `On`을 true로 설정하십시오.

솔브할 때마다 `G`를 보내고, 이전에 구성 요소가 보냈던 것을 대체합니다.

## 작동 방식

- **바디 하나.** 모델에서 보이는 모든 것이 하나의 가져온 피처가 됩니다. [.3dm 파일 열기](topic:open-3dm-files)를 할 때와 같습니다.
- **닫혀야 합니다.** PartCraft는 작은 구멍과 평평한 열린 부분을 채우며, 다른 프로그램에 그 개수를 알려 줍니다. 모델이 여전히 닫히지 않으면 PartCraft는 이전 바디를 유지하고 상태 표시줄에 알립니다. 다음에 닫히는 변경이 생기면 갱신됩니다.
- **하던 작업을 마치십시오.** 스케치나 도면에서는 업데이트가 거부되었다가 다시 시도되며, 모델로 돌아오면 반영됩니다.
- **실행 취소.** 2초 이내의 업데이트는 실행 취소 한 단계로 묶입니다.
- **저장.** 파트 파일이 연결을 유지합니다. 다시 연 뒤 스크립트를 다시 실행하면 같은 피처가 갱신됩니다.

**단방향입니다.** 여기서의 변경은 다른 프로그램으로 돌아가지 않습니다.

## 문제가 생기면

- **"ModelCraft 또는 PartCraft 창에서 허용하지 않음":** 설정의 1단계를 수행하십시오.
- **"Studio가 토큰을 거부함":** Studio가 다시 시작되었습니다. 새 토큰을 복사한 다음 스크립트를 다시 실행하십시오. Grasshopper에서는 먼저 Rhino에서 실행하십시오.
- **"CadCraft Studio에 연결할 수 없음":** Studio가 실행 중이 아니거나 주소가 바뀌었습니다.
