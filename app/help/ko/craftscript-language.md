CraftScript는 MATLAB처럼 읽히도록 만든 행렬 언어이므로, 대부분의 고전적인 수치 계산 코드(예: 88줄짜리 위상 최적화 코드)를 조금만 고쳐도 실행할 수 있습니다. [스크립트 작업 공간](topic:craftscript)과 명령행에서 실행됩니다.

## 값

| 종류 | 예 | 설명 |
|---|---|---|
| 숫자, 배열 | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | 모든 숫자는 배열입니다(1×1 배열). 배열은 열 단위로 저장되며 최대 8차원까지 지원합니다 |
| 논리 | `A > 2`, `true` | 참/거짓 배열이며 인덱스로 사용할 수 있습니다 |
| 문자열 | `'beam'`, `"beam"` | |
| 희소 행렬 | `sparse(i, j, v, n, n)` | 강성 행렬용입니다 |
| 메시, 필드, 모델 | `hexGrid(…)`, `part()`, `load('part.stl')` | `show`가 그리는 대상입니다 |
| 구조체 | `s.E = 210e3` | 이름이 있는 필드입니다 |
| 셀 | `c = {1, 'two', [3 4]}` | 임의의 값들의 목록입니다 |
| 함수 핸들 | `f = @(x) x.^2` | |

## 배열과 인덱싱

- 범위: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`를 사용합니다.
- 인덱스는 1부터 시작합니다: `A(2, 3)`, `v(end)`, `A(:, 1)`(열 전체), `A(:)`(모든 원소를 한 열로), `v(v > 0)`(논리 인덱싱).
- MATLAB에서와 같이 끝을 넘어 대입하면 배열이 늘어납니다: `v(10) = 1`.

## 연산자

- `+ - * / \ ^`는 행렬 연산입니다(`A \ b`는 연립방정식을 풉니다). `.* ./ .^`는 원소별로 작동합니다. `'`는 전치를 합니다.
- 비교 연산자 `== ~= < <= > >=`, 논리 연산자 `& | ~`(원소별) 및 `&& ||`(단락 평가).

## 제어 흐름과 함수

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

함수는 명령 뒤의 스크립트에 쓰거나, 함수 이름을 딴 자체 스크립트 탭에 씁니다:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

이름은 다음 순서로 찾습니다: 변수, 이 파트에서 같은 이름을 가진 스크립트, 라이브러리 함수, 내장 함수.

## 에코, 주석, 출력

- `;` 없이 쓴 문장은 값을 출력하고, `;`을 붙이면 조용히 실행합니다.
- `%` 뒤는 주석입니다. `%{` 줄과 `%}` 줄 사이의 줄이 주석 처리됩니다. 두 줄은 각각 단독으로 써야 합니다.
- `disp(x)`, `fprintf('%g\n', x)`, `display(x)` 함수는 콘솔에 출력합니다.

## 오류와 제한

- 오류는 무엇이 잘못되었는지 쉬운 말로 알려 주고, 해당 줄과 함수 호출 순서를 보여 줍니다.
- 실행마다 단계 한도가 있습니다(패널의 실행 옵션에서 설정). 무한 루프는 메시지와 함께 멈추거나, 중지를 누르면 멈춥니다.
- 배열 하나에는 최대 134,000,000개의 값을 담을 수 있습니다.

## MATLAB 대비 차이점

- 그래프 명령은 옵션을 호출 안에 넣습니다: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` 등은 받아들이지만 아무 동작도 하지 않습니다.
- `input` 및 `keyboard`는 지원하지 않습니다. 스크립트가 멈추고 질문할 수 없습니다.
- 툴박스는 없습니다. 제공되는 것은 [해석 라이브러리](topic:craftscript-library)와 내장 함수뿐입니다.
