PartCraft는 사용자 컴퓨터에 있는 파일로 작업합니다. 파트를 업로드하는 일이 없으며, 계정이나 클라우드 저장소도 사용하지 않습니다. 클라우드 저장은 아직 사용할 수 없습니다.

## PartCraft가 여는 파일

| 파일 | 확장자 | 방법 |
|---|---|---|
| PartCraft 파트 | `.partcraft.json` | {{ui:열기}}, {{key:Mod+O}}, 또는 3D 뷰에 끌어다 놓기 |
| PartCraft 어셈블리 | `.partcraft-asm.json` | 동일합니다. PartCraft가 어느 종류인지 판별합니다 |
| STEP 솔리드 | `.step`, `.stp` | 솔리드 바디를 삼각형으로 읽습니다: [STEP 파일을 열어 이어서 작업하기](topic:import-step) |

STL, OBJ, 3MF 메시도 솔리드 바디로 열리며([STL, OBJ, 3MF 열기](topic:open-meshes)), `.3dm` 파일도 마찬가지입니다([.3dm 모델 열기](topic:open-3dm-files)). DXF, IGES 및 다른 프로그램의 고유 파트 파일은 열 수 없습니다([아직 만들지 않은 기능](topic:not-built-yet) 참고).

파일을 열 때의 규칙은 다음과 같습니다.

- 파트 또는 어셈블리 파일 이름은 `.json`으로 끝나야 하며, 파일 크기는 50 MB 미만이어야 합니다.
- 파일은 화면에 표시하기 전에 검사합니다. 손상되었거나 편집된 파일은 알기 쉬운 이유와 함께 거부됩니다. 예: "PartCraft 파일이 아닙니다."
- 더 새로운 PartCraft로 저장한 파일은 거부됩니다: "이 파일은 더 새로운 PartCraft (파일 버전 3)로 저장되었습니다. 이 버전은 2까지 읽습니다." 이전 버전의 파일은 열립니다.
- 화면의 파트에 저장하지 않은 변경 사항이 있으면 PartCraft가 먼저 묻습니다: {{ui:취소}}, {{ui:변경 사항 버리기}}, {{ui:먼저 저장}}.

## 저장

{{ui:저장}} 또는 {{key:Mod+S}}는 화면에 있는 내용을 저장합니다.

- 파트의 경우: `<파트 이름>.partcraft.json`. 전체 히스토리(스케치, 구속 관계, 치수, 피처, 롤백 위치), 도면 시트의 단면, 상세, GD&T 메모, 이전 빌드에서 가져온 STEP 솔리드의 전체 텍스트가 담깁니다. 이 버전에서 만들 수 없는 피처는 변경 없이 그대로 저장됩니다. 솔리드 자체는 저장하지 않으며, 파일을 열 때 PartCraft가 히스토리로부터 다시 생성합니다.
- 어셈블리의 경우: `<어셈블리 이름>.partcraft-asm.json`. **모든 파트가 파일 안에** 들어갑니다. 파일 하나에 어셈블리 전체가 담기므로 그 파일만 보내면 됩니다.

저장은 **다운로드**입니다. 브라우저가 파일을 다운로드 폴더에 넣거나, 위치를 묻도록 설정했다면 위치를 묻습니다. 다시 저장하면 새 다운로드가 만들어지며, 브라우저가 이전 파일을 덮어쓰지 않고 `Part1 (1).partcraft.json`처럼 이름을 붙일 수 있습니다. 파일 이름 변경과 이동은 {{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 원하는 대로 하십시오.

파트 이름에 들어 있는 글자, 숫자, 공백, `_`, `.`, `-` 이외의 문자는 파일 이름에서 `_`로 바뀝니다.

:::tip
대부분의 브라우저에는 다운로드할 때마다 저장 위치를 묻는 설정이 있습니다. 매번 "다른 이름으로 저장" 선택이 필요하면 켜 두십시오. Chrome과 Edge는 설정의 다운로드, Firefox는 일반의 파일 및 응용 프로그램, Safari는 일반의 파일 다운로드 위치에 있습니다.
:::

다운로드 파일이 저장되는 위치와 파일을 안전하게 보관하는 방법은 [파일이 저장되는 위치](common:your-files)를 참고하십시오.

## 내보내기

{{ui:내보내기}} 메뉴는 다른 형식으로 기록합니다. 각각 다운로드이며 파트 이름을 따라 이름이 붙습니다.

| 메뉴 항목 | 파일 | 담기는 내용 |
|---|---|---|
| {{ui:STL, 3D 프린팅용}} | `<이름>.stl` | 솔리드 삼각형의 바이너리 STL, 밀리미터 단위, **Z 위쪽** |
| {{ui:3MF, 3D 프린팅용}} | `<이름>.3mf` | 솔리드를 객체 하나로 담은 3MF, 밀리미터 단위, **Z 위쪽** |
| {{ui:STEP AP242 (정밀 솔리드)}} | `<이름>.step` | 이 버전에서는 아직 만들지 않았습니다(회색 표시). 정밀 커널이 필요합니다 |
| {{ui:STEP AP214 (정밀 솔리드)}} | `<이름>.step` | 이 버전에서는 아직 만들지 않았습니다(회색 표시) |
| {{ui:STEP (면 근사, 메시 커널)}} | `<이름>.step` | 메시의 평평한 면으로 이루어진 솔리드: **둥근 면은 작고 평평한 면 여러 개가 됩니다**. 밀리미터 단위, PartCraft 자체 축(Y 위쪽) 기준입니다. 이 버전에서 다른 CAD 프로그램용으로 쓰는 STEP입니다 |
| {{ui:스케치 또는 평면의 DXF}} | `<이름> - <스케치>.dxf` 또는 `<이름> - face.dxf` | DXF R12. 스케치의 경우: 스케치 자체 좌표의 선, 호, 원, 점이 PROFILE, CONSTRUCTION, POINTS 도면층에 담깁니다. 선택한 평면의 경우: 윤곽이 닫힌 폴리선으로 담깁니다(둥근 모서리는 면분할 상태) |
| {{ui:도면 (PDF): 뷰, 단면, 상세, GD&T}} | `<이름> - drawing.pdf` | A3 도면 시트: 뷰 3개, 등각 뷰, 설정한 경우 단면과 상세, 전체 크기, GD&T 기호, 표제란 |

:::note
{{ui:STEP AP242 (정밀 솔리드)}}와 {{ui:STEP AP214 (정밀 솔리드)}}는 이 버전에서 아직 만들지 않았습니다. {{ui:STEP (면 근사, 메시 커널)}}을 사용하십시오. 형상과 부피는 올바르지만 둥근 면이 모두 평평한 면 여러 개이므로, 다른 프로그램에서 구멍을 원통으로 선택할 수 없습니다. 이 점이 중요하면 먼저 **곡선** 설정을 더 세밀하게 하십시오.
:::

- 내보내기는 화면에 있는 파트를 대상으로 합니다. 어셈블리에서는 내보내기가 꺼져 있으며, 어셈블리 내보내기는 아직 없습니다.
- STL, 3MF, 면 근사 STEP, 면 DXF는 항상 면분할로 만들어집니다. **곡선** 설정(아무것도 선택하지 않았을 때 오른쪽 패널)이 한 바퀴당 32개에서 256개 사이로 세밀도를 정합니다. 매끄러운 출력을 위해 STL이나 3MF를 내보내기 전에 세밀 또는 매우 세밀을 선택하십시오.
- PDF 도면은 리더에 내장된 Helvetica 글꼴을 사용합니다. 이 글꼴로 표시할 수 없는 문자는 "?"로 인쇄됩니다.

단계별 설명: [인쇄용, STEP, DXF로 내보내기](topic:export-files), [도면 시트 만들기](topic:drawing-pdf).

## 저장하지 않은 작업

- PartCraft는 변경이 있을 때마다 잠시 후 열려 있는 파트나 어셈블리의 복구 사본을 이 브라우저에 보관합니다. 충돌이 나거나 탭을 닫아도 작업을 잃지 않으며, 다음에 PartCraft를 열면 "작업을 복구할까요?"라고 묻습니다. 이는 저장이 아닙니다. 작업을 보관하려면 파일로 저장하십시오. [저장하지 않은 작업 복구](common:recover)를 참고하십시오.
- 저장하지 않은 변경 사항이 있을 때 탭을 닫거나 새로 고치려고 하면 브라우저가 "사이트를 나가시겠습니까?"라고 묻습니다. 이는 브라우저 자체의 상자이며 PartCraft는 문구를 바꿀 수 없습니다.
- {{ui:새로 만들기}}, {{ui:열기}}, 어셈블리 닫기는 저장하지 않은 변경 사항을 버리기 전에 먼저 묻습니다.

## 온라인과 오프라인

모든 작업은 사용자 컴퓨터에서 이루어집니다. 메시 커널(WebAssembly 프로그램)은 앱과 함께 다운로드되어 형상을 로컬에서 생성하며, 파일은 디스크에서 읽고 디스크에 기록합니다. 네트워크로 전송되는 파트 데이터는 없습니다. [메시 커널](topic:solid-kernels)을 참고하십시오.

연결 없이 작업하려면 온라인 상태에서 PartCraft를 오프라인용으로 저장하십시오. 앱 바에서 {{ui:오프라인용 저장}}을 선택하고 "212개 중 40개 저장 중"처럼 진행되다가 **오프라인 사용 준비됨**으로 바뀔 때까지 기다립니다. 저장된 사본에는 3D 라이브러리와 메시 커널이 포함되므로, 이후에는 모델링, 저장, 모든 내보내기, 도면을 오프라인에서도 사용할 수 있습니다. **저장하지 못했습니다**라고 나오면 온라인 상태에서 클릭하여 다시 시도하십시오. **오프라인 사용 불가**는 이 브라우저 창이 사본을 보관할 수 없다는 뜻입니다(비공개 창과 일부 관리형 컴퓨터). 사본을 저장한 뒤 **오프라인 사용 준비됨**을 클릭하면 {{ui:다시 저장 (최신 버전 받기)}}와 {{ui:오프라인 사본 제거}}를 선택할 수 있습니다. 자세한 내용: [오프라인 작업](common:offline).

:::online
온라인 상태입니다. 오프라인용으로 저장하지 않았더라도 PartCraft를 불러온 뒤 상태 표시줄 칩에 "메시 커널"이라고 표시되면, 연결이 끊겨도 계속 작업할 수 있습니다. 다시 온라인이 될 때까지 페이지를 새로 고치지 마십시오.
:::

:::offline
오프라인 상태입니다. PartCraft가 이미 열려 있으면 계속 작업하십시오. 저장과 내보내기도 가능합니다. 앱 바에 **오프라인 사용 준비됨**이라고 표시되어 있으면 PartCraft를 연결 없이 처음부터 열 수도 있습니다. 그렇지 않으면 이 탭을 새로 고치지 마십시오.
:::

## 브라우저별 차이

- **다운로드.** 브라우저마다 다운로드 폴더와 묻는 방식이 다릅니다. 브라우저가 이 사이트의 파일 다운로드를 허용할지 물으면 허용하십시오. 그렇지 않으면 저장과 내보내기가 동작하지 않습니다.
- 파일을 뷰에 **끌어다 놓기**는 Chrome, Edge, Firefox, Safari에서 동작합니다.
- **휴대폰이나 태블릿의 파일.** iPhone과 iPad에서는 열기를 누르면 파일 앱이 나타나며, 저장한 파일은 파일 앱의 다운로드로 갑니다. Android에서는 다운로드 폴더로 갑니다.

파일에 담기는 내용은 브라우저나 운영 체제에 따라 다르지 않습니다.
