PartCraft는 컴퓨터의 파일로 작업합니다. 부품을 업로드하지 않으며, 계정이나 클라우드 저장소도 관여하지 않습니다. 클라우드 저장은 아직 사용할 수 없습니다.

## PartCraft가 여는 파일

| 파일 | 확장자 | 방법 |
|---|---|---|
| PartCraft 부품 | `.partcraft.json` | {{ui:열기}}, {{key:Mod+O}}, 또는 3D 뷰에 끌어다 놓기 |
| PartCraft 어셈블리 | `.partcraft-asm.json` | 같은 방법. PartCraft가 어떤 종류인지 스스로 확인합니다 |
| STEP 솔리드 | `.step`, `.stp` | 삼각형으로 읽은 솔리드 바디: [STEP 파일을 열고 이어서 작업하기](topic:import-step) |

STL, OBJ, 3MF 메시도 솔리드 바디로 열리며 ([STL, OBJ 또는 3MF 열기](topic:open-meshes)), `.3dm` 파일도 그렇습니다 ([.3dm 모델 열기](topic:open-3dm-files)). DXF, IGES 및 다른 프로그램의 고유 부품 파일은 열 수 없습니다 ([아직 만들지 않은 기능](topic:not-built-yet) 참조).

열 때의 규칙:

- 부품 또는 어셈블리 파일 이름은 `.json`으로 끝나야 하며, 파일은 50 MB 미만이어야 합니다.
- 파일은 무엇을 보여 주기 전에 검사됩니다. 손상되었거나 편집된 파일은 "PartCraft 파일이 아닙니다."와 같이 평이한 이유와 함께 거부됩니다.
- 최신 PartCraft에서 저장된 파일은 거부됩니다: "이 파일은 최신 PartCraft (파일 버전 3)에서 저장되었으며, 이 버전은 버전 2를 읽습니다." 이전 버전의 파일은 열립니다.
- 화면의 부품에 저장되지 않은 변경 사항이 있으면 PartCraft가 먼저 묻습니다: {{ui:취소}}, {{ui:변경 사항 버리기}} 또는 {{ui:먼저 저장}}.

## 저장

{{ui:저장}} 또는 {{key:Mod+S}}는 화면에 있는 내용을 저장합니다:

- 부품의 경우: `<부품 이름>.partcraft.json`에 전체 히스토리 (스케치, 관계, 치수, 피처, 롤백 위치), 도면 시트의 단면, 상세, GD&T 메모, 그리고 이전 빌드에서 가져온 STEP 솔리드의 전체 텍스트를 담습니다. 이 버전이 만들 수 없는 피처는 바뀌지 않은 채 다시 저장됩니다. 솔리드 자체는 저장되지 않으며, 파일을 열 때 PartCraft가 히스토리에서 다시 만듭니다.
- 어셈블리의 경우: `<어셈블리 이름>.partcraft-asm.json`에 **모든 부품**을 함께 담습니다. 파일 하나에 어셈블리 전체가 들어 있으므로 그 파일만 보내도 됩니다.

저장은 **다운로드**입니다. 브라우저가 파일을 다운로드 폴더에 넣거나, 위치를 묻도록 설정되어 있으면 저장 위치를 묻습니다. 다시 저장하면 새 다운로드가 만들어지며, 브라우저는 기존 파일을 바꾸지 않고 `Part1 (1).partcraft.json`처럼 이름을 붙일 수 있습니다. 파일 이름을 바꾸거나 옮기려면 {{pick:mac=Finder|windows=파일 탐색기|linux=사용 중인 파일 관리자}}에서 원하는 대로 하십시오.

부품 이름에서 글자, 숫자, 공백, `_`, `.`, `-`가 아닌 문자는 파일 이름에서 `_`로 바뀝니다.

:::tip
대부분의 브라우저에는 각 다운로드의 위치를 묻는 설정이 있습니다. 매번 "다른 이름으로 저장" 선택지를 원하면 켜십시오. Chrome과 Edge는 설정의 다운로드, Firefox는 일반 > 파일 및 애플리케이션, Safari는 일반 > 파일 다운로드 위치에 있습니다.
:::

다운로드 위치와 파일 보관에 대한 자세한 내용은 [파일이 있는 곳](common:your-files)을 참조하십시오.

## 내보내기

{{ui:내보내기}} 메뉴는 다른 형식으로 씁니다. 각 항목은 부품 이름을 따서 붙인 다운로드입니다.

| 메뉴 항목 | 파일 | 내용 |
|---|---|---|
| {{ui:STL, 3D 프린팅용}} | `<name>.stl` | 솔리드 삼각형의 바이너리 STL, 밀리미터, **Z 위쪽** |
| {{ui:3MF, 3D 프린팅용}} | `<name>.3mf` | 솔리드를 하나의 객체로 담은 3MF, 밀리미터, **Z 위쪽** |
| {{ui:STEP AP242 (정밀 솔리드)}} | `<name>.step` | 정밀 솔리드 하나, 밀리미터, Z 위쪽: 둥근 면은 참 원기둥, 원뿔, 구, 토러스. 다른 CAD 및 CAM 프로그램에 쓰는 STEP |
| {{ui:STEP AP214 (정밀 솔리드)}} | `<name>.step` | 이전 AP214 스키마로 된 같은 정밀 솔리드 |
| {{ui:STEP (면 근사, 메시 커널)}} | `<name>.step` | 메시에서 만든 평면 면으로 된 솔리드: **둥근 곡면은 많은 작은 평면 조각**. 밀리미터, PartCraft 자체 축 (Y 위쪽). 정밀 파일을 거부하는 프로그램용 |
| {{ui:스케치 또는 평면의 DXF}} | `<name> - <sketch>.dxf` 또는 `<name> - face.dxf` | DXF R12. 스케치: 스케치 고유 좌표의 선, 호, 원, 점을 PROFILE, CONSTRUCTION, POINTS 도면층에. 고른 평평한 면: 닫힌 폴리선으로 된 윤곽 (둥근 모서리는 그 면 조각) |
| {{ui:도면 (PDF): 뷰, 단면, 상세, GD&T}} | `<name> - drawing.pdf` | A3 도면 시트: 세 개의 뷰, 등각, 설정된 경우 단면과 상세, 전체 크기, GD&T 기호, 표제란 |

:::note
{{ui:STEP AP242 (정밀 솔리드)}}는 구멍, 돌출부, 모깎기, 원뿔, 구, 토러스를 참 곡면으로 씁니다. 따라서 다른 프로그램이 구멍을 원기둥으로 선택할 수 있으며, **곡선** 설정은 이를 바꾸지 않습니다. 스플라인 측면, 모델링된 나사산, 가져온 메시는 정밀 곡면이 없으므로 같은 솔리드 안에서 평면 면 조각으로 남으며, 상태 표시줄에 그 개수가 표시됩니다. {{ui:STEP (면 근사, 메시 커널)}}은 모든 둥근 면을 면 조각으로 씁니다.
:::

- 내보내기는 화면에 있는 부품의 것입니다. 어셈블리에서는 내보내기가 꺼져 있으며, 아직 어셈블리 내보내기는 없습니다.
- STL, 3MF, 면 근사 STEP, 면 DXF는 항상 면 조각으로 이루어집니다. **곡선** 설정 (아무것도 선택하지 않았을 때 오른쪽 패널)이 회전당 32에서 256 면까지 정밀도를 정합니다. 매끄러운 출력을 원하면 STL이나 3MF를 내보내기 전에 정밀 또는 매우 정밀을 선택하십시오.
- PDF 도면은 PDF 리더에 내장된 Helvetica 글꼴을 사용합니다. 표시할 수 없는 문자는 "?"로 인쇄됩니다.

단계별 안내: [인쇄, STEP, DXF용 내보내기](topic:export-files)와 [도면 시트 만들기](topic:drawing-pdf)를 참조하십시오.

## 저장되지 않은 작업

- PartCraft는 변경 후 잠시 뒤 이 브라우저에 열린 부품이나 어셈블리의 복구본을 보관합니다. 따라서 충돌이나 탭 닫힘에도 작업이 사라지지 않으며, 다음에 PartCraft를 열면 "작업을 복구할까요?"라고 묻습니다. 이는 저장이 아닙니다. 작업을 보관하려면 파일로 저장하십시오. [저장되지 않은 작업 복구](common:recover)를 참조하십시오.
- 저장되지 않은 변경 사항이 있는 상태에서 탭을 닫거나 새로 고치면 브라우저가 "사이트를 떠나시겠습니까?"라고 묻습니다. 이는 브라우저 자체의 대화상자이며, PartCraft는 그 문구를 바꿀 수 없습니다.
- {{ui:새로 만들기}}, {{ui:열기}}, 어셈블리 닫기는 저장되지 않은 변경 사항을 버리기 전에 묻습니다.

## 온라인과 오프라인

모든 것은 컴퓨터에서 일어납니다. 메시 커널 (WebAssembly 프로그램)은 앱과 함께 다운로드되어 로컬에서 형상을 만들고, 파일은 디스크에서 읽고 씁니다. 부품 데이터는 네트워크로 전송되지 않습니다. [메시 커널](topic:solid-kernels)을 참조하십시오.

연결이 전혀 없는 상태에서 작업하려면, 온라인일 때 PartCraft를 오프라인용으로 저장하십시오. 앱 막대에서 {{ui:오프라인용 저장}}을 선택하고, "저장 중 40/212"처럼 개수가 세어지는 동안 기다려 **오프라인 준비 완료**가 표시될 때까지 기다립니다. 저장된 복사본에는 3D 라이브러리와 메시 커널이 포함되므로, 이후 모델링, 저장, 모든 내보내기, 도면이 모두 오프라인에서 작동합니다. **저장할 수 없음**이 표시되면 온라인 상태에서 클릭하여 다시 시도하십시오. **오프라인 사용 불가**는 이 브라우저 창이 복사본을 보관할 수 없다는 뜻입니다 (비공개 창과 일부 관리되는 컴퓨터). 복사본이 저장된 상태에서 **오프라인 준비 완료**를 클릭하면 {{ui:다시 저장 (최신 버전 받기)}}와 {{ui:오프라인 사본 제거}} 항목이 표시됩니다. 자세한 내용은 [오프라인으로 작업하기](common:offline)를 참조하십시오.

:::online
온라인입니다. 오프라인용으로 저장하지 않더라도, PartCraft가 로드되고 상태 표시줄에 "메시 커널" 표시가 나타나면 연결이 끊겨도 계속 작업할 수 있습니다. 연결이 돌아올 때까지 페이지를 새로 고치지 마십시오.
:::

:::offline
오프라인 상태입니다. PartCraft가 이미 열려 있으면 계속 작업하십시오. 저장과 내보내기는 여전히 작동합니다. 앱 막대에 **오프라인 준비 완료**가 표시되어 있으면 PartCraft는 연결이 없어도 처음부터 열립니다. 그렇지 않으면 이 탭을 새로 고치지 마십시오.
:::

## 브라우저별 차이

- **다운로드.** 각 브라우저는 자체 다운로드 폴더와 묻는 방식이 있습니다. 브라우저가 이 사이트의 파일 다운로드를 허용할지 묻는다면 허용하십시오. 그렇지 않으면 저장과 내보내기가 작동하지 않습니다.
- **끌어서 놓기**로 파일을 뷰에 옮기는 것은 Chrome, Edge, Firefox, Safari에서 작동합니다.
- **휴대폰이나 태블릿의 파일.** iPhone과 iPad에서 열기를 누르면 파일 앱이 표시되며, 저장된 파일은 파일 앱의 다운로드에 들어갑니다. Android에서는 다운로드 폴더에 들어갑니다.

파일 내용은 브라우저나 운영체제에 따라 다르지 않습니다.
