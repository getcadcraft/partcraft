## 알아볼 내용

AI 어시스턴트(또는 직접 작성한 스크립트)가 열려 있는 파트를 살펴보고, 파라미터를 바꾸고, 스크립트를 실행하고 내보내게 하는 방법, 그리고 무엇을 건드릴 수 있을지 정하는 방법을 설명합니다.

PartCraft에는 **자체 AI가 없으며** 어디에도 아무것도 보내지 않습니다. 어시스턴트는 사용자가 직접 가져옵니다. 모델 컨텍스트 프로토콜(MCP)을 지원하는 프로그램이면 무엇이든 사용할 수 있습니다. PartCraft는 어시스턴트에게 도구만 제공하며, 어떤 도구를 줄지는 사용자가 고릅니다.

## 켜기

1. {{ui:설정}}(앱 바의 톱니바퀴 또는 {{key:Mod+,}})을 열고 {{ui:PartCraft}} 탭으로 이동합니다.
2. {{ui:어시스턴트}} 아래에서 **AI 어시스턴트와 스크립트가 PartCraft를 사용하도록 허용**을 체크합니다. 체크하기 전까지는 꺼져 있습니다.
3. 허용할 작업을 고릅니다. **읽기**는 처음부터 체크되어 있습니다. 나머지는 필요할 때만 체크합니다.
4. 어시스턴트가 폴더에 내보내고 저장하도록 하려면, **사용할 수 있는 폴더** 아래의 {{ui:폴더 추가…}} 항목을 고르고 Studio 대화상자에서 폴더를 선택합니다.

어시스턴트는 사용자 컴퓨터의 **CadCraft Studio**를 통해 연결됩니다. Studio가 어시스턴트에 붙여넣을 주소와 토큰을 표시합니다. 브라우저 탭으로는 어시스턴트 연결을 열 수 없습니다.

## 어시스턴트가 요청할 수 있는 작업

| 도구 | 권한 | 하는 일 |
|---|---|---|
| `part_describe`, `features_list` | 읽기 | 순서대로 나열된 피처와 빌드 성공 또는 실패 여부, 재질, 솔리드의 부피와 크기 |
| `params_list` | 읽기 | 파라미터와 방정식으로 조절할 수 있는 모든 숫자, 그리고 그 값 |
| `mass_properties` | 읽기 | 부피, 면적, 질량 중심, 그 중심에 대한 관성. 파트에 재질이 있으면 질량 |
| `param_set` | 편집 | 파라미터 또는 피처의 숫자를 설정하고 다시 빌드합니다. 실행 취소 한 단계 |
| `script_run` | 편집 | {{ui:스크립트}} 작업 공간과 같은 방식으로 CraftScript, Lua 또는 Python 스크립트를 실행합니다. 격리되어 있어 파일과 네트워크를 사용하지 않습니다. 파트는 바뀌지 않습니다 |
| `part_export` | 내보내기 | STL, 3MF, STEP 또는 OpenUSD(.usdz, .usda, .usdc)를 {{ui:파일}} › {{ui:내보내기}}가 쓰는 방식대로 내보냅니다 |
| `link_push` | 편집 | 다른 프로그램에서 연결된 모델을 업데이트합니다([.3dm 모델을 실시간으로 유지하기](topic:live-3dm-link) 참고) |
| `link_status` | 읽기 | 연결된 모델이 아직 있는지, 마지막으로 언제 업데이트되었는지 알려 줍니다 |
| `part_save` | 저장 | PartCraft 자체의 {{ui:저장}} |
| `illustrate_export` | 내보내기 | {{ui:일러스트레이트}} 작업 공간의 매뉴얼을 뷰의 PDF 또는 SVG 선 그림으로, 대화형 3D 파일로, 또는 지침을 PDF나 웹 페이지로 내보냅니다. 작업 공간의 {{ui:내보내기}} 및 {{ui:작업 지침}} 메뉴가 쓰는 방식과 같습니다([매뉴얼](topic:illustrate) 참고) |

:::note
이 빌드는 메시 커널을 사용합니다. 부피는 삼각형으로부터 계산되므로 실제 곡면 솔리드보다 약간 작으며, STEP은 정확한 곡면 대신 삼각형으로 된 면 근사 방식으로 저장됩니다.
:::

## 사용자가 통제합니다

- **모든 변경은 실행 취소 한 단계입니다.** 변경 내용에는 어시스턴트용 이름이 붙습니다(예: "Assistant: set l = 45"). {{key:Mod+Z}} 키를 누르면 되돌릴 수 있습니다.
- **연결 여부를 알 수 있습니다.** 연결되어 있는 동안 앱 바의 버튼에 어시스턴트 이름이 표시됩니다. 버튼을 클릭하면 허용된 작업을 보거나 **연결 해제**할 수 있습니다.
- **활동.** {{ui:설정}} › {{ui:PartCraft}} › {{ui:어시스턴트}} › {{ui:활동}}에서 모든 호출을 볼 수 있으며, {{ui:기록 저장}}을 누르면 복사본을 보관합니다.
- **폴더.** 어시스턴트는 사용자가 추가한 폴더에서만 파일을 읽고 쓸 수 있습니다. {{ui:제거}}를 누르면 해당 폴더가 즉시 제외됩니다.

## PartCraft를 열지 않고

CadCraft 파일 서버(`npx @getcadcraft/mcp`)와 `cadcraft` 명령줄은 창을 열지 않고도 PartCraft 자체 코드와 메시 커널로 `.partcraft.json` 파트를 엽니다. 어시스턴트의 읽기 도구, 파라미터 설정, CraftScript 스크립트, 내보내기(OpenUSD 포함), 저장을 같은 방식으로 제공합니다. 명령줄에서 `cadcraft convert bracket.partcraft.json bracket.stl` 명령을 실행하면 파트를 빌드하여 파일로 씁니다. 매뉴얼(`.partcraft-manual.json`)도 여기서 내보낼 수 있습니다: `illustrate_export`, 또는 `cadcraft convert linkage.partcraft-manual.json linkage.pdf` (지침을 내보내려면 `--instructions`를 추가합니다).

## 문제가 생겼을 때

- **"편집 권한이 필요합니다"** 메시지가 보이면: {{ui:어시스턴트}} 아래에서 **편집**을 체크한 다음 다시 요청합니다.
- **"방정식으로 구동됨"** 메시지가 보이면: 그 숫자는 파라미터를 따릅니다. 대신 파라미터를 설정하도록 어시스턴트에게 요청합니다.
- **변경이 잘못된 경우:** {{key:Mod+Z}} 키를 누릅니다.
