패널의 입력란에 입력하는 동안에는 키가 작동하지 않습니다. 단, {{key:Mod+S}} 및 {{key:Mod+O}}는 항상 작동합니다. 수정자 키 없이 누르는 글자 키는 작동합니다.

브라우저에서의 키 사용과 기능 키가 없는 키보드에 대한 일반적인 내용은 [키, 마우스, 트랙패드](common:keys)를 참고하십시오.

## 어디서나

| 키 | 동작 |
|---|---|
| {{key:Mod+S}} | 파트를 저장합니다(어셈블리에서는 어셈블리를 저장). 열려 있는 스케치는 먼저 닫습니다 |
| {{key:Mod+O}} | 파트 또는 어셈블리 파일을 엽니다(저장되지 않은 변경 사항이 있으면 먼저 묻습니다) |
| {{key:Mod+Z}} | 실행 취소 |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 다시 실행 |
| {{key:F1}} | 이 도움말을 열거나 닫습니다(앱 막대의 {{ui:도움말}}과 같음). {{key:Esc}}로도 닫을 수 있습니다. 많은 노트북과 Mac 키보드에서는 Fn 키를 누른 채로 누르십시오 |
| {{key:Ctrl+Shift+F}} | 화면 모드 전환: 일반, 전체 화면, 막대를 숨긴 전체 화면. Mac에서도 Control 키를 사용합니다(⌘ 아님) |
| {{key:Esc}} | 전체 화면 종료(전체 화면일 때) |
| {{key:Mod+,}} | {{ui:설정}} 열기, PartCraft 탭 포함([PartCraft 설정](topic:settings) 참고) |

패널의 숫자 입력란에서 {{key:Mod+Z}}는 브라우저의 텍스트 실행 취소입니다. 스케치 치수 위에 있는 숫자 입력란에서는 PartCraft에서 실행 취소합니다.

## 복사, 붙여넣기, 복제

이 키들은 현재 작업 중인 대상에 작동합니다. 열린 스케치에서는 선택한 형상, 기록에서는 선택한 피처, 어셈블리에서는 선택한 파트입니다. 자세한 내용은 [복사, 붙여넣기, 복제](topic:copy-paste)에서 확인하십시오.

| 키 | 동작 |
|---|---|
| {{key:Mod+C}} | 선택 항목을 복사합니다 |
| {{key:Mod+X}} | 잘라내기: 복사한 뒤 삭제합니다 |
| {{key:Mod+V}} | 붙여넣기. 스케치에서는 복사본이 포인터를 따라다닙니다. 놓을 위치를 클릭하십시오 |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 같은 좌표(어셈블리에서는 같은 위치) |
| {{key:Mod+D}} | 복제: 복사와 붙여넣기를 한 번에 하며, 클립보드는 그대로 둡니다 |
| {{key:Mod+A}} | 모두 선택(스케치에서) |
| {{key:Esc}} | 선택 해제(포인터를 따라가는 붙여넣기도 취소) |

숫자 입력란에서는 이 키들이 평소처럼 텍스트를 복사하고 붙여넣습니다. 패널에서 선택한 텍스트는 브라우저가 복사합니다.

## 파트에서(스케치가 열려 있지 않을 때)

| 키 | 동작 |
|---|---|
| {{key:S}} | 선택한 평면 또는 평평한 면에 스케치합니다. 아무것도 선택하지 않았으면 클릭해서 위치를 지정합니다 |
| {{key:F}} | 뷰에 파트를 맞춥니다 |
| {{key:M}} | 측정. 모든 작업 공간과 어셈블리에서 사용합니다. {{key:Esc}}는 선택을 지우고, 한 번 더 누르면 닫습니다([거리, 각도, 질량 측정](topic:measure) 참고) |
| {{key:X}} | 단면 뷰를 켜거나 끕니다. 모든 작업 공간과 어셈블리에서 사용합니다. {{key:Esc}}로 닫습니다([단면 뷰로 내부 보기](topic:section-view) 참고) |
| {{key:Delete}} | 선택한 피처를 삭제합니다(다른 곳에서 사용 중이면 묻습니다) |
| {{key:0}} … {{key:9}}, {{key:.}} | 피처를 선택한 상태에서 주요 숫자를 입력합니다(돌출 깊이, 구멍 지름, 패턴 개수, 필렛 반지름 등). 그다음 {{key:Enter}}. {{key:Esc}}를 누르면 기존 값을 유지합니다 |
| {{key:Backspace}} | 피처가 선택되어 있으면 선택한 피처를 삭제합니다 |
| {{key:Esc}} | 스케치 평면 선택을 중지하거나 선택을 해제합니다({{key:Shift}}로 고른 모서리나 면 포함) |

## 3D 뷰에서

먼저 뷰를 클릭해 키보드 초점을 두십시오.

| 키 | 동작 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 뷰를 15도 회전합니다 |
| {{key:Shift+Left}} 및 나머지 화살표 | 초점 이동 |
| {{key:Plus}} 또는 {{key:=}} | 확대 |
| {{key:Minus}} | 축소 |

| 마우스 | 동작 |
|---|---|
| 왼쪽 버튼으로 드래그 | 뷰 회전(궤도 회전) |
| 오른쪽 또는 가운데 버튼으로 드래그 | 초점 이동 |
| 왼쪽 버튼으로 드래그하는 동안 {{key:Shift}}, {{key:Ctrl}} 또는 ⌘ 누르기 | 초점 이동 |
| 휠 굴리기 | 포인터 위치에서 줌(몸에서 멀어지는 방향으로 굴리면 확대) |
| 트랙패드 두 손가락 스와이프 | 뷰 회전. {{key:Shift}} 키를 누르면 초점 이동. 핀치는 줌. [PartCraft 설정](topic:settings)의 **스크롤**에서 설정 |

[PartCraft 설정](topic:settings)에서 **뷰 회전: 가운데 버튼**을 켜면 가운데 버튼은 뷰를 회전하고, 가운데 또는 오른쪽 버튼과 함께 {{key:Shift}} 키를 누르면 초점 이동하며, 왼쪽 버튼은 선택만 합니다.
| 클릭 | 면(전체가 강조됨), 모서리 또는 평면 선택 |
| {{key:Shift}}+클릭(모서리 또는 면) | 여러 모서리 또는 면 모으기 |
| 빈 공간 클릭 | 선택 해제 |

## 브라우저가 가로챌 수 있는 단축키

- Safari에서 {{key:Mod+Y}}는 기록을 열 수 있습니다. 다시 실행은 {{key:Mod+Shift+Z}}를 사용하십시오.
- {{key:Mod+D}}는 브라우저의 책갈피 키입니다. 앱에 초점이 있으면 PartCraft가 사용하고, 입력란에 입력하는 동안에는 그대로 둡니다.
- {{key:F11}} 및 {{key:Mod+Plus}} / {{key:Mod+Minus}}는 PartCraft가 아니라 브라우저의 전체 화면과 페이지 확대/축소 키입니다. 전체 화면은 {{key:Ctrl+Shift+F}}를, 모델 확대/축소는 휠을 사용하십시오.
- 많은 노트북과 Mac에서는 기능 키에 Fn 키가 필요합니다. 도움말은 Fn+{{key:F1}}을 누르거나 {{ui:도움말}} 버튼을 사용하십시오.

터치와 트랙패드 제스처: [트랙패드, 터치, 작은 화면](topic:trackpad-and-touch).

## 이동 명령 위치

이동은 피처 그룹의 {{ui:더보기}} 메뉴에서 {{ui:바디 이동}}으로, ΔX, ΔY, ΔZ를 입력하는 {{ui:이동}} 상자에서, 그리고 파트의 {{ui:끌어서 이동}} 화살표로 사용할 수 있습니다.
