피처는 만든 순서대로 히스토리에 나열되며, 위에서 아래로 다시 만들어집니다. 각 피처는 종류에 따라 번호가 붙은 이름을 가집니다: Sketch1, Extrude1, Revolve1, Hole1, LPattern1, CirPattern1, Mirror1, Fillet1, Chamfer1, Shell1, Imported1.

PartCraft는 모든 피처를 메시 커널로 만듭니다. 필렛과 모따기는 평면 두 개 사이의 직선 모서리에서 동작하며, 쉘은 평면을 엽니다. 가져온 솔리드에는 정밀 커널이 필요하지만 이 버전에는 정밀 커널이 없으므로 아직 만들지 않습니다. 이전 빌드에서 만든 부품은 아래 해당 절의 설명대로 유지됩니다. [메시 커널](topic:solid-kernels)과 [아직 만들지 않은 기능](topic:not-built-yet)을 참조하십시오.

## 스케치

| 설정 | 참고 |
|---|---|
| 평면 | 정면, 상단 또는 우측 평면, 또는 평평한 면. 표시만 되며 바꿀 수 없음: 스케치를 옮기려면 새로 만드십시오 |
| 상태 | 완전 정의, 부분 정의 (남은 자유도 표시), 과도 정의, 또는 비어 있음 |
| 기하, 관계 | 곡선, 점, 관계의 개수 |
| 구동 치수 | 스케치의 모든 치수, 편집 가능 |

버튼: {{ui:스케치 편집}}, {{ui:DXF로 내보내기}}.

## 돌출과 잘라내기

{{ui:돌출}}과 {{ui:잘라내기}}는 시작 설정만 다른 같은 피처를 만듭니다.

| 설정 | 선택 항목 | 돌출의 시작값 | 잘라내기의 시작값 |
|---|---|---|---|
| 작업 | 보스 (재료 추가), 잘라내기 (재료 제거), 교차 (겹치는 부분 유지), 새 바디 (이 버전에서는 아직 만들지 않음) | 보스 | 잘라내기 |
| 끝 | 막힘 (지정 깊이), 중간면 (양방향), 모두 관통 | 막힘 | 모두 관통 |
| 깊이 (mm) | 0 초과, 최대 1,000,000 | 10 | 10 |
| 방향 반대로 | 끔 / 켬 | 끔 | 끔 |

- 프로파일: 스케치의 실선, 원, 호로 이루어진 모든 닫힌 루프. 루프 안의 루프는 구멍입니다.
- 모두 관통은 잘라내기에서만 동작합니다. 선택한 쪽으로 부품을 완전히 관통합니다.
- 잘라내기는 스케치 평면의 바깥쪽에서 재료 안으로 들어갑니다. 방향 반대로를 켜면 뒤집힙니다.

## 회전과 회전 절단

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 작업 | 보스, 잘라내기 | 보스 ({{ui:회전}}), 잘라내기 ({{ui:더보기}} › {{ui:회전 절단}}) |
| 각도 (°) | 0 초과, 최대 360 | 360 |
| 축 | 첫 번째 중심선, 스케치의 임의 선 또는 중심선, 또는 스케치 평면에 놓인 축 피처 | 첫 번째 중심선 |

- 프로파일은 축의 한쪽에 있어야 합니다. 축에 닿을 수는 있습니다.
- 회전의 축은 원형 패턴과 어셈블리 조인트에서 사용할 수 있습니다.

## 구멍

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 종류 | 단순, 카운터보어 | 단순 |
| 지름 (mm) | 0 초과 | 6 |
| 모두 관통 | 켬 / 끔 | 켬 |
| 깊이 (mm) | 모두 관통이 꺼져 있을 때 | 10 |
| 카운터보어 ⌀ | 구멍보다 넓음 | 11 |
| 카운터보어 깊이 | 막힌 구멍보다 얕음 | 6 |
| 방향 반대로 | 끔 / 켬 | 끔 |

- 스케치의 독립된 점마다 구멍 하나가 생깁니다 (점 도구로 만든 점). 패널에 개수가 표시됩니다.
- 구멍은 스케치 평면에 수직으로, 재료 안으로 뚫립니다.
- 각 구멍의 축은 어셈블리 조인트에서 사용할 수 있습니다 ("Hole1, 구멍 2").

## 선형 패턴

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 복사할 피처 | 그 위에 있는 모든 솔리드 피처 | 선택한 피처, 없으면 마지막 솔리드 피처 |
| 방향 | X 축, Y 축, Z 축; 이전 스케치의 선; 회전의 축; 선택한 모서리 | X 축 (또는 추가할 때 선택한 모서리) |
| 간격 (mm) | 임의의 숫자 | 20 |
| 개수 | 1부터 1000까지, 원본 포함 | 3 |
| 방향 반대로 | 끔 / 켬 | 끔 |

## 원형 패턴

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 복사할 피처 | 선형과 같음 | 선형과 같음 |
| 축 | 위의 방향과 같음 | 마지막 회전의 축, 없으면 Y 축 (또는 선택한 모서리) |
| 각도 (°) | 0 초과, 최대 360. 360이면 복사본을 모든 방향으로 같은 간격으로 배치하고, 그보다 작으면 그 각도에 걸쳐 펼칩니다 | 360 |
| 개수 | 1부터 1000까지, 원본 포함 | 6 |
| 방향 반대로 | 끔 / 켬 | 끔 |

## 대칭

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 대칭 | 지금까지 만든 전체 바디, 또는 선택한 피처 | 선택한 피처, 없으면 전체 바디 |
| 대칭 평면 | 정면, 상단 또는 우측 평면; 평평한 면 | 우측 평면, 또는 추가할 때 고른 평평한 면 |

## 필렛과 모따기

이 버전에서 메시 커널은 평면 두 개 사이의 직선 모서리 (바깥쪽 또는 안쪽 모서리)에, 반지름 하나로 필렛을 만듭니다. 둥근 모서리에서는 "필렛: 이 버전에서는 평면 두 개 사이의 직선 모서리만 지원합니다 (메시 커널이 만듭니다). 스케치에서 곡선 모서리를 둥글게 하거나 모따기하십시오."라고 표시됩니다. 둥근 모서리가 꼭짓점에서 만나면 맞대기 처리되며, 피처는 "메시 커널 필렛: 둥근 모서리가 만나는 곳은 블렌드되지 않고 맞대어집니다."라고 경고합니다. 모따기 유형 (같은 거리, 두 거리, 거리와 각도, 그리고 **면 뒤집기**)은 모두 동작합니다. [둥글리기, 모따기, 속 비우기](topic:fillet-chamfer-shell)를 참조하십시오.

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 반지름 (mm) (필렛) | 0 초과 | 2 |
| 거리 (mm) (모따기) | 0 초과, 양쪽 면에서 같음 | 1 |
| 모서리 | 선택한 모서리, 각각 연결된 두 면으로 표시 ("Extrude1 end face × Extrude1 side"), **제거** 포함 | 추가할 때 선택한 모서리 |

- 버튼을 누르기 전에 모서리를 먼저 선택하십시오 (여러 개는 {{key:Shift}}+클릭). 또는 아무것도 선택하지 않은 상태에서 버튼을 누른 뒤 모서리를 클릭하십시오.
- {{ui:모서리 선택}} (또는 피처를 두 번 클릭)으로 모서리를 바꿉니다.
- 모서리는 연결된 두 면으로 기억되므로, 앞선 크기를 바꿔도 유지됩니다.

## 쉘

메시 커널이 만듭니다. 평면만 열 수 있습니다 ("쉘: 이 버전에서는 평면만 열 수 있습니다 (메시 커널이 만듭니다)."). 두께가 다른 벽은 아직 만들지 않습니다. [둥글리기, 모따기, 속 비우기](topic:fillet-chamfer-shell)를 참조하십시오.

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 벽 (mm) | 0 초과 | 2 |
| 벽을 바깥으로 키우기 (면은 안쪽에 유지) | 끔: 벽이 안쪽으로 감. 켬: 벽이 바깥쪽으로 감 | 끔 |
| 열린 면 | 제거되는 면, 최소 하나, **제거** 포함 | 추가할 때 선택한 면 |

{{ui:면 선택}} 항목으로 열린 면을 바꿉니다.

## 가져온 솔리드

STEP, STL, OBJ 또는 3MF 파일을 열어 만듭니다. 자체 히스토리가 없는 삼각형 솔리드 바디입니다 ([STEP 파일 열기](topic:import-step), [STL, OBJ 또는 3MF 열기](topic:open-meshes)). 가져온 파일과 가져오기가 복구한 내용을 보여 주며, **파일의 단위**, **파일의 위쪽 방향**, **사용 목적**은 편집할 수 있습니다. 이전 빌드의 정밀 커널로 가져온 STEP 솔리드는 히스토리에 "아직 만들지 않음"으로 표시된 채 남으며, STEP 파일을 다시 열면 삼각형으로 가져옵니다.

| 설정 | 선택 항목 | 기본값 |
|---|---|---|
| 파일의 위쪽 방향 | Z 위쪽 (대부분의 CAD), Y 위쪽 | Z 위쪽 |

패턴과 대칭은 가져온 솔리드를 복사할 수 있지만, 필렛, 모따기, 쉘은 복사할 수 없습니다.

## 모든 피처의 공통 기능

피처 패널 하단의 버튼:

| 버튼 | 기능 |
|---|---|
| {{ui:억제}} / {{ui:억제 해제}} | 끄거나 켭니다. 꺼져 있는 동안 이를 필요로 하는 피처는 만들어지지 않습니다 |
| {{ui:여기까지 롤백}} | 이 피처 위의 피처만 만듭니다. 새 피처는 롤백 막대 위치에 추가됩니다 |
| {{ui:위로 이동}} / {{ui:아래로 이동}} | 사용하는 것이 아래로 내려가지 않을 때만 순서를 바꿉니다. 그렇지 않으면 흐리게 표시되며 이유가 나타납니다 |
| {{ui:삭제}} | 삭제하며, (확인 후) 이를 사용하는 모든 피처도 삭제합니다 |
| 이름 | 이름 변경 (최대 60자) |

스케치가 있는 피처는 **구동 치수**도 나열하며, 그 자리에서 편집할 수 있습니다.

## 히스토리의 상태

| 상태 | 표시 | 의미 |
|---|---|---|
| 만들어짐 | 보통 | 이상 없음 |
| 경고 | ⚠ | 만들어졌지만 확인할 것이 있음: "과도 정의: 관계 1개가 필요하지 않습니다." 또는 "이 작업 후 부품에 남은 것이 없습니다." |
| 오류 | ⚠ 오류, 빨간색 | 만들 수 없음; 메시지가 이유를 알려 줌 |
| 아직 만들지 않음 | ⚠ 아직 만들지 않음 | 실패했거나, 억제되었거나, 롤백된 피처가 필요하거나, 이 버전에 없는 정밀 커널이 필요함 ("스윕: 아직 만들지 않았습니다. …") |
| 억제됨 | 꺼짐 | 꺼져 있음 |
| 롤백됨 | 흐림, 롤백 막대 아래 | 앞으로 롤백할 때까지 만들어지지 않음 |

## 부품 설정

빈 공간을 클릭하여 아무것도 선택하지 않습니다. 오른쪽 패널에 **파트**가 표시됩니다:

- **이름**: 부품의 이름으로, 파일 이름과 도면 표제란에 사용됩니다 (최대 120자).
- **곡선**: 아래 참조.

### 곡선 해상도

메시 커널은 평면 면으로 솔리드를 직접 만듭니다. 따라서 뷰, STL, 3MF, 면 근사 STEP, 부피, 도면 뷰는 모두 **곡선**을 따릅니다. 이는 회전당 면의 개수입니다.

| 설정 | 회전당 면 | 둥근 형상의 부피 |
|---|---|---|
| 거칠게 (회전당 32) | 32 | 참값보다 약 0.64 % 작음 |
| 보통 (회전당 64) | 64 | 약 0.16 % 작음 (기본값) |
| 정밀 (회전당 128) | 128 | 약 0.04 % 작음 |
| 매우 정밀 (회전당 256) | 256 | 약 0.01 % 작음 |

곡선을 더 정밀하게 하면 내보내기와 뷰가 더 매끄러워지지만, 다시 만드는 속도는 느려집니다. 이 설정은 부품 파일에 저장됩니다.

## 아직 만들지 않은 기능

가변 반지름 필렛, 둥근 모서리의 필렛과 모따기, 곡면을 여는 쉘, 곡면의 구배, 스윕, 로프트, 리브, 정밀 곡면이 있는 STEP 솔리드, 새 바디, 테이퍼, 면이나 꼭짓점까지의 "까지" 끝, 솔리드의 면과 모서리에 대한 참조는 정밀 커널이 필요하며, 이 버전에는 정밀 커널이 없습니다. 탭 구멍과 카운터싱크 구멍도 아직 만들지 않습니다. [아직 만들지 않은 기능](topic:not-built-yet)을 참조하십시오.
