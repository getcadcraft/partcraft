엔지니어링 도구(생성기, 엔지니어링 라이브러리, 검사 및 데이터 파일)는 **관리자 권한**이나 **설치 프로그램**이 필요하지 않습니다. 도구는 아래에 나열된 항목만 기록하며, 그 밖의 것은 기록하지 않습니다.

| 항목 | 저장 위치 |
|---|---|
| 생성된 본체, 데이터 시트, 검사 결과를 포함한 파트 | 저장하는 파트 파일(`.partcraft.json`), 저장한 위치 |
| 파일에서 연 생성기 | 앱 자체 저장소: 웹 페이지에서는 브라우저의 로컬 스토리지, 휴대용 Studio에서는 프로그램 옆의 `data` 폴더. 최대 20개. |
| 설정(설정한 복셀 크기, 솔버 스레드 수, 레이아웃) | 같은 앱 저장소 |
| 데이터 시트, 필드, 메시 | 직접 저장한 경우에만 기록됩니다. 다운로드는 선택한 위치로 저장됩니다. |

도구는 자체적으로 네트워크 호출을 하지 않습니다. 포함된 생성기는 앱 자체 폴더의 파일이고, 라이브러리와 검사는 네트워크에 접근할 수 없는 작업자(worker)에서 사용자의 컴퓨터가 실행하며, 엔지니어링 데이터(물과 공기의 물성, 재료)는 앱 안에 들어 있습니다. 파일에서 연 생성기는 사용자의 컴퓨터에서 읽히며 외부로 전송되지 않습니다.

## 휴대용 Windows zip 및 Linux

Windows용 휴대용 Studio는 설정, 캐시, 애드온을 프로그램 옆의 `data` 폴더에 보관합니다. Linux AppImage는 `portable`이라는 이름의 파일이 옆에 있으면 자신의 옆에 보관하며, 그 파일이 없으면 홈 폴더를 사용합니다. Mac용 휴대용 형식은 없습니다. 시스템이 다운로드한 앱이 자신의 옆에 기록하지 못하게 막기 때문입니다. 셸 자체의 휴대용 안내(`Studio` 도움말)에 프로그램이 기록하는 항목이 나와 있습니다.

## 호스트 접근

여기서는 호스트 접근을 요청하지 않습니다. 프린터, 시리얼 장비, USB 장치는 별도로 취급됩니다. 작업에 필요할 때 장치마다 한 번씩 확인을 요청하며, 생성기와 검사는 이들에 접근하지 않습니다.
