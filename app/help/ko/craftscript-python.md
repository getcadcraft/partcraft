Python은 [스크립트 작업 공간](topic:craftscript)의 세 번째 언어입니다. 편집기 위의 언어 상자에서 **Python**을 선택하십시오(`.py` 파일은 자동으로 Python에서 열립니다). Python, Lua 및 CraftScript는 같은 변수와 같은 내장 함수를 공유하므로, Python 스크립트는 CraftScript 스크립트에서 만든 것을 사용할 수 있고 그 반대도 가능합니다.

방문 후 처음 Python을 실행하면 이 사이트에서 Python 자체(CPython 3.14, 약 7 MB)를 불러오며, 몇 초가 걸립니다. Python은 아직 {{ui:Save for offline}}의 일부가 아닙니다. 먼저 온라인 상태에서 Python 스크립트를 하나 실행하십시오.

## Python 격리

Python 스크립트는 CraftScript 및 Lua 스크립트와 마찬가지로 격리됩니다. 파트, 변수, 내장 함수에만 접근할 수 있으며 그 밖에는 접근할 수 없습니다. 실행할 때마다 자체 샌드박스에서 메모리상의 작은 파일 트리(표준 라이브러리와 실행이 끝나면 사라지는 `/tmp` 폴더)를 가진 새 Python이 시작됩니다. 브라우저와 명령행 모두에서 네트워크, 사용자의 파일, 페이지의 나머지 부분에 접근할 수 없습니다. 다른 사람이 만든 스크립트는 여전히 많은 시간이나 메모리를 사용할 수 있으며, 이 경우 {{ui:Stop}}로 종료합니다.

## 기본 사항

```
A = cs.magic(3)              # 모든 내장 함수는 cs.<name>
B = A @ A.T                  # @는 행렬 곱, .T는 전치
C = A * 2 + 1                # + - * / **는 numpy에서처럼 원소별 연산
print(A[0, 1], A[-1, -1])    # 0부터 시작; 음수는 끝에서부터 셈
row = A[1]                   # 행렬에 인덱스 하나를 쓰면 행
big = A[A > 4]               # 논리 마스크로 원소를 고름
A[0, 0] = -5                 # 배열에 대입
V, D = cs.call('eig', 2, A)  # 여러 결과: cs.call(name, 개수, …)
```

- 1 × 1 배열은 일반 숫자로 전달됩니다. 그 밖의 배열, 희소 행렬, 메시, 필드, 모델은 **Values**입니다.
- Value에는 `shape`(튜플), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()`(행 수), 그리고 원소 하나에 대한 `float()`, `int()`, `bool()`이 있습니다.
- 비교(`<`, `==`, …)는 numpy에서처럼 원소별로 작동하며, 논리 Value를 반환합니다.
- 내장 함수에 전달된 숫자 목록은 배열이 됩니다: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])`는 행렬을 만듭니다.
- dict는 구조체가 되고, 여러 종류가 섞인 목록은 셀이 되며, 다시 돌아갑니다.

스크립트가 만드는 모든 전역 변수(숫자, Value, dict, 목록 등)는 오류가 발생한 뒤에도 실행이 끝나면 **변수** 탭에 나타납니다. `_`로 시작하는 이름, 함수, 클래스, 모듈은 Python 안에 남습니다. `ws.name`은 변수를 직접 읽거나 설정하며, `ws_names()`는 이름을 나열합니다.

`print(…)`는 콘솔에 출력합니다. `display(…)`(또는 `cs.display`)는 CraftScript에서와 같이 메시, 필드 또는 그래프를 표시합니다.

## 해석 라이브러리 호출하기

라이브러리 함수는 내장 함수처럼 호출합니다: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. 스크립트에는 이름을 그대로 쓰십시오. PartCraft는 실행 전에 스크립트가 사용하는 라이브러리 함수를 찾습니다.

## 아직 없는 기능

- numpy, scipy 및 기타 패키지는 없습니다. Python 자체 표준 라이브러리(`math`, `json`, `itertools`, `decimal`, `statistics`…)만 있으며, 창, 터미널, 데이터베이스 부분(`tkinter`, `curses`, `sqlite3`)은 제외됩니다.
- 소켓 및 외부로 연결되는 그 밖의 모든 기능: 여기서 Python에는 네트워크가 없습니다.
- `time.sleep`은 즉시 반환합니다.
- 편집기의 접기 기능, 그리고 CraftScript 스크립트에서 Python 함수를 호출하는 기능.
- 실행은 1000줄마다 단계 한도와 중지를 확인합니다. 내장 함수 하나 안의 긴 계산은 먼저 끝납니다.
