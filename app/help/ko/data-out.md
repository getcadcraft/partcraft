{{ui:엔지니어}} 작업 공간에서, 또는 생성된 바디의 속성에서 **데이터 내보내기**를 여십시오:

| 버튼 | 파일 | 용도 |
|---|---|---|
| 데이터 시트 (JSON) | `.json` | 모든 입력, 모든 숫자와 그 단위 및 출처, 검사, 메시 지문. 정렬되어 있으며 시간 정보가 없으므로 같은 파트는 같은 파일을 만듭니다. |
| 데이터 시트 (PDF) | `.pdf` | 같은 내용을 종이 형식으로 담으며, 필요한 만큼 여러 쪽에 걸칩니다. |
| 필드 (.vti) | `.vti` | 점 격자 위의 부호 있는 거리(내부는 음수)와 내부 마스크로 표현한 파트: ParaView 및 VTK 기반 도구용 VTK 이미지 파일입니다. 생성기 입력의 복셀 크기로 바디의 표면에서 만들어지므로 시간이 조금 걸리며, 삼각형이 400,000개를 넘는 바디는 페이지에서 처리하기에 너무 큽니다. 이 경우에는 대신 스크립트(`field_bake`)에서 필드를 저장하십시오. |
| 레벨 셋 (.vdb) | `.vdb` | 같은 필드를 OpenVDB 레벨 셋으로 저장한 것: 표면 주위의 얇은 복셀 띠만 보존하는 희소 트리로, OpenVDB를 읽는 도구(렌더러, 시뮬레이션 및 3D 프로그램)용입니다. 복셀 크기와 단위는 생성기 값(밀리미터)을 따르며, 좁은 띠가 활성 부분이고 내부는 음수입니다. `.vti`와 같이 표면에서 만들어지며 삼각형 400,000개 제한도 같습니다. 1.5 GB를 넘는 파일은 거부됩니다(더 큰 복셀 크기를 사용하십시오). 파일은 OpenVDB 형식 224이며, OpenVDB 자체의 활성 값 패킹을 제외하면 압축되지 않으므로 모든 OpenVDB 리더가 열 수 있습니다. |
| 표면 (.vtu) | `.vtu` | 삼각형과 각 삼각형의 면적 및 법선. |
| 생성기 데이터 포함 3MF | `.3mf` | 슬라이서용 밀리미터 단위 메시이며, 생성기, 입력값, 그리고(구배 격자의 경우) 벽 범위가 파일 안에 메타데이터로 들어 있습니다. |

이 파일들에는 시계나 컴퓨터에서 가져온 내용이 없으므로, 두 파일을 바이트 단위로 비교할 수 있습니다. 바이트가 달라지면 파트가 달라진 것입니다.

## 아직 만들지 않은 기능

- 생성기 값과 다른 복셀 크기로 만든 필드의 `.vti` 또는 `.vdb`.
- `.vdb` 파일 읽어 들이기(쓰기만 구현되어 있습니다).
