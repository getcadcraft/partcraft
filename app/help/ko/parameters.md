**파라미터**는 이름이 붙은 숫자입니다. 예: `width = 120` 또는 `margin = bolt * 1.5`. 깊이, 구멍 지름, 패턴 개수 또는 스케치 치수를 파라미터에 연결하면, 파라미터를 바꿀 때 모두 한 번에 바뀝니다. 이렇게 하면 설계 의도가 머릿속이 아니라 파트 안에 남습니다.

## 파라미터 추가

1. 오른쪽 패널에서 {{ui:파라미터}} 탭을 클릭합니다.
2. **변수** 아래의 "name" 상자에 이름을 입력합니다. 예: `width`.
3. 다음 상자에 값을 입력합니다. 예: `120`. 그다음 {{key:Enter}} 키를 누르거나 {{ui:추가}} 버튼을 클릭합니다.

값은 숫자이거나 다른 파라미터의 식이 될 수 있습니다: `bolt * 1.5`, `width / 2 - 10`, `if(width > 100, 6, 4)`. **값** 열에는 계산된 결과가 표시됩니다. 이름은 문자 또는 `_`로 시작하며 문자, 숫자, `_`만 가질 수 있습니다. 함수와 단위의 이름(`sin`, `mm`, `pi`)은 거부되며, `a = b`이고 `b = a`인 것처럼 순환하는 식도 거부됩니다.

## 숫자를 파라미터에 연결하기

1. 기록에서 피처를 클릭합니다. 예: "Extrude1". 설정은 {{ui:속성}} 탭에 표시됩니다.
2. **깊이(mm)** 같은 숫자 상자에 `=` 기호와 식을 입력합니다: `=thick` 또는 `=width / 4`.
3. {{key:Enter}} 키를 누릅니다.

상자에는 결과가 표시되고, 라벨 옆에 **ƒ** 버튼이 나타납니다. 그 위에 마우스를 올리면 방정식이 보입니다. 스케치 치수도 같은 방식으로 작동합니다. 피처의 **스케치 치수** 목록과, 열린 스케치의 치수 상자 모두에서 가능합니다. 치수를 더블 클릭하고 `=width`를 입력한 뒤 {{key:Enter}} 키를 누르십시오.

연결할 수 있는 숫자는 다음과 같습니다. 돌출 깊이, 회전 각도, 구멍 지름, 깊이와 카운터보어 크기, 패턴 개수, 간격과 각도, 필렛 반지름, 모따기 거리, 셸 벽 두께, 모든 스케치 치수, 그리고 최신 피처의 크기(두 번째 깊이, 테이퍼, 카운터싱크, 기준면 거리, 구배 각도 등).

## 파라미터 바꾸기

{{ui:파라미터}} 탭의 **식** 열에 새 값이나 식을 입력하고 {{key:Enter}} 키를 누릅니다. 연결된 모든 것이 바뀌고 파트가 한 단계로 다시 만들어집니다. 되돌리기는 {{key:Mod+Z}} 키입니다.

반대 방향으로 숫자를 바꾸려면 [양방향 방정식](topic:equations-two-way)을 참조하십시오.

## 파라미터가 쓰이는 곳 보기

{{ui:파라미터}} 탭에서 각 파라미터 아래에는 그것을 사용하는 대상을 알려 주는 줄이 있습니다.

- 파라미터가 구동하는 숫자, 예: **Extrude1 깊이** 또는 **Sketch1 D2 (거리)**. 하나를 클릭하면 그 피처가 선택되고 속성이 표시됩니다.
- 다른 파라미터를 **거쳐** 구동하는 숫자, 예: `d = h + 2`이고 `h = w / 2`일 때 **Hole1 지름 (h, d를 거침)**.
- 식이 그것을 쓰는 **파라미터**, 그것을 설정하는 **구성**, 그것을 읽는 **스크립트**([CraftScript 작성과 실행](topic:craftscript) 참조).

"아직 사용되지 않음."은 아무것도 쓰지 않는다는 뜻이며, 묻지 않고 삭제해도 됩니다.

## 연결 해제, 이름 바꾸기, 삭제

- **숫자 연결 해제:** **ƒ** 버튼을 클릭하거나, **방정식** 목록에서 {{ui:연결 끊기}} 명령을 사용합니다. 현재 값을 유지하며, 더 이상 어떤 파라미터도 그 값을 바꾸지 않습니다.
- **파라미터 이름 바꾸기:** **이름** 상자에 새 이름을 입력합니다. 그 이름을 쓰는 모든 식이 다시 쓰입니다.
- **파라미터 삭제:** 행의 ×를 클릭합니다. 무언가 쓰고 있으면 PartCraft가 먼저 현재 값을 그 식에 기록할지 묻습니다.
- **피처 삭제**는 그 피처 숫자의 방정식을 없애며, 상태 표시줄에 어떤 것이 없어졌는지 알려 줍니다.

:::note
파라미터는 `.partcraft.json` 파일에 저장됩니다(파일 버전 3). 파라미터가 없는 파트는 이전과 똑같이 저장됩니다.
:::

## 식

| 입력 | 의미 |
|---|---|
| `120`, `12.5`, `1e3` | 숫자(밀리미터, 또는 각도면 도) |
| `2in`, `1ft`, `3"`, `1.5cm`, `0.2m` | 다른 단위의 길이, 밀리미터로 변환 |
| `30deg`, `0.5rad` | 각도, 도로 변환 |
| `+ - * / %` 및 `^` | 산술 연산. `^`는 거듭제곱, `-2^2`는 −4 |
| `sin cos tan asin acos atan atan2` | 도 단위의 삼각 함수 |
| `sqrt pow exp ln log abs sign` | 기타 함수 |
| `ceil floor int round(x, digits) min max` | 반올림과 한계 |
| `if(test, a, b)` 및 `< <= > >= == !=` | 선택. 예: `if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

이름은 대소문자를 구분합니다. `Width`, `width`: 서로 다른 두 파라미터입니다.
