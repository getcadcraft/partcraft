지오메트리 커널은 히스토리를 솔리드로 바꾸는 엔진입니다. 이 버전의 PartCraft에는 **메시 커널**(manifold-3d)이 하나 있습니다. 작은 WebAssembly 프로그램으로 사용자 컴퓨터에서 실행되며, 앱을 열면 곧바로 준비됩니다. 파트에 관한 어떤 내용도 외부로 전송되지 않습니다.

| | 메시 커널 |
|---|---|
| 둥근 형상 | 평평한 면분할. 파트 패널의 **곡선**으로 세밀도를 정합니다 |
| 부피와 면적 | 면분할된 솔리드 기준이며, 둥근 파트에서는 조금 작게 나옵니다 |
| 스케치, 돌출, 절단, 회전, 구멍, 패턴, 대칭, 기준 평면 | 지원 |
| 필렛과 모따기 | 평평한 면 사이의 직선 모서리에 적용합니다. 서로 만나는 라운드는 맞대어 접합합니다 |
| 쉘과 구배 | 쉘은 평평한 면을 열고(정확한 벽 두께), 구배는 평평한 면을 기울입니다 |
| 내보내기 | STL, 3MF, STEP (면 근사), 도면 PDF, DXF |
| 도면 뷰 | 면분할로 그리며, 단면 뷰도 포함합니다 |
| 면과 모서리 | 스케치에서 가져온 이름과 종류(평면, 원통, 원뿔, 구, 토러스, 직선, 원)를 가집니다. 시뮬레이션, 생성, 제조 작업 공간과 측정, 선택, 구멍 표가 이를 사용합니다 |

파트를 생성하는 동안 상태 표시줄 오른쪽 끝 근처의 칩에 **메시 커널**이라고 표시됩니다.

## 정밀 커널을 기다리는 기능

정밀(B-rep) 커널은 정확한 원, 원통, 원뿔을 유지하며, 임의의 모서리에 매끄러운 필렛을 만들 수 있습니다. 스윕, 로프트, 곡면, 판금, 리브, 여러 바디, STEP 가져오기, 정밀 STEP 내보내기가 이를 기반으로 합니다. PartCraft의 이전 랩 빌드는 이를 위해 OpenCascade를 사용했습니다. 그 라이선스(LGPL)는 이번 릴리스와 맞지 않습니다. 이번 릴리스에서는 모든 앱이 Apache-2.0이며 허용적 라이선스의 라이브러리만 사용하므로 포함하지 않았습니다. 일정은 정해져 있지 않습니다.

그때까지 해당 기능을 선택하면 **아직 만들지 않았습니다**라고 표시됩니다. 상태 표시줄에 이유가 나오고, 버튼 툴팁은 "아직 만들지 않았음 (정밀 커널 필요)"로 끝납니다. [아직 만들지 않은 기능](topic:not-built-yet)에 각 기능과 대안이 정리되어 있습니다.

이전 빌드에서 이런 기능으로 만든 파트도 여전히 열립니다. 해당 피처는 만들지 않은 상태로 표시되어 히스토리에 남고(가리키면 이유가 보입니다), 나머지 파트는 생성되며, 저장하면 변경 없이 그대로 유지됩니다.

## 둥근 면과 곡선

메시 커널은 원을 다각형으로 그립니다. 파트 패널의 **곡선**은 한 바퀴 원이 가지는 변의 수를 정합니다. 변이 많을수록 더 매끄럽게 보이고 측정값도 참값에 가까워지지만 생성에 시간이 더 걸립니다. {{ui:측정}}의 부피, 면적, 거리는 이 면분할된 솔리드 기준이므로, 구멍이나 보스는 둥근 형상의 값보다 조금 작게 나옵니다.

## 온라인과 오프라인

메시 커널은 앱 자체 다운로드에 포함되어 있습니다. 연결 없이 작업하려면 온라인 상태에서 PartCraft를 오프라인용으로 저장하십시오. 앱 바에서 {{ui:오프라인용 저장}}을 선택하고 **오프라인 사용 준비됨**이라고 표시될 때까지 기다립니다. 자세한 내용: [오프라인 작업](common:offline).
