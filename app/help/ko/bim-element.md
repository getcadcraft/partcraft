## 작업 내용

BimCraft 모델에서 가져온 파트를 건물 안의 제자리에서 작업하고, 새 형상을 다시 BimCraft로 보냅니다.

## 단계

1. BimCraft에서 요소를 선택하고 {{ui:파트 링크}} › {{ui:PartCraft에 보내기}}를 선택합니다. 파트가 새 파트로 열리며, 상태 표시줄에 BIM 요소라고 표시됩니다.
2. 요소 주변(3 m 이내)의 요소는 회색으로 그려집니다. 설계 기준으로만 사용하며, 선택하거나 변경할 수 없고 파트 파일에도 저장되지 않습니다.
3. 다른 파트와 같은 방식으로 자르기, 추가, 구멍 뚫기, 대칭 등의 작업을 합니다. 원점과 축은 요소 자체의 것이므로 파트는 원래 있던 위치로 돌아갑니다.
4. {{ui:파일}} › {{ui:내보내기}} › {{ui:BimCraft에 되돌려 저장}} 순서로 선택합니다. 상태 표시줄에 보낸 개정 번호가 표시됩니다.
5. BimCraft에서는 담당자가 수락할 때까지 요소가 변경된 것으로 표시됩니다.

## 확인할 내용

- 파트는 파일에 링크를 유지합니다. 나중에 열어도 상태 표시줄에 BIM 요소라고 계속 표시됩니다. 보낸 패키지를 브라우저가 가지고 있는 동안에는 회색 건물도 다시 나타납니다.
- 다시 되돌려 저장하면 개정 2, 3 등으로 번호가 올라갑니다. BimCraft는 가장 최신 개정을 보관합니다.

## 참고 사항

- 형상은 요소 자체의 축을 기준으로 밀리미터 단위의 메시로 되돌아갑니다. 피처는 PartCraft에 남습니다.
- BimCraft에서 가져오지 않은 파트에서는 {{ui:BimCraft에 되돌려 저장}} 명령을 사용해도 아무 일도 일어나지 않습니다.
- 아직 솔리드가 없는 파트는 보낼 내용이 없습니다.
- 두 앱을 같은 브라우저에서 모두 열어 두어야 합니다. 아무것도 업로드되지 않으며, 두 페이지가 요소를 서로 전달합니다.
