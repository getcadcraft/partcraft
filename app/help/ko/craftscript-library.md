해석 라이브러리는 위에서 아래로 읽을 수 있는 함수 형태의 스크립트 모음입니다. 강성 행렬을 어떻게 조립하는지, 경계 조건을 어디에 넣는지, 어떤 솔버를 실행하는지, 결과를 어떻게 계산하는지를 모두 볼 수 있습니다. 블랙박스로 숨겨진 부분은 없으며, 빠르게 반복되는 내부 루프(요소 행렬, 희소 솔버, 메시 생성)만 내장되어 있습니다.

## 예제로 시작하기

**예제** 그룹에는 라이브러리를 처음부터 끝까지 사용하는 짧은 스크립트 5개가 있습니다. 하나를 클릭한 다음 {{ui:Open (read-only)}} 버튼을 누르고, {{key:F5}} 키를 누르십시오. 각 예제는 보기를 지우고, 캔버스에 결과를 보여 주며, 보조 디스플레이에 그래프를 표시합니다.

| 예제 | 내용 |
|---|---|
| 외팔보 응력 | 100 N 끝단 하중을 받는 강재 막대(100 × 10 × 10 mm): 변형된 막대의 폰 미제스 응력, 그리고 네 가지 요소 크기에서 끝단 처짐을 보 이론과 비교(그래프로 표시) |
| MBB 보 위상 최적화 | 고전적인 60 × 20 위상 최적화: 설계가 만들어지는 과정, 컴플라이언스가 감소하는 과정, 최종 형상(반복 94회, 컴플라이언스 203.19) |
| 축전기 필드 | 폭 4 mm, 간격 1 mm의 두 판: 전위와 전기장, 프린지 효과를 포함한 정전 용량을 이상적인 값 및 Palmer 공식과 비교 |
| 채널 유동 | 채널 안의 기둥 주위 격자 볼츠만 유동: 속도장과 수렴 이력 |
| 전자석 | 공극과 코일이 있는 C자형 철심: 자속 밀도, 공극 내 자기장을 자기 회로 공식과 비교, 인덕턴스와 공극을 가로지르는 흡인력. [2차원 자기장](topic:magnetic-fields-2d)에서 단계별로 설명합니다 |
| 영구 자석 | 코일 대신 영구 자석을 넣은 같은 철심: 자석의 작동점, 자기 회로와 비교한 공극 내 자기장, 얼마나 많은 자속이 새는지, 흡인력. [2차원 자기장](topic:magnetic-fields-2d#permanent-magnets)에서 다룹니다 |

## 그룹

| 그룹 | 함수 | 기능 |
|---|---|---|
| 메시 생성 | `box_mesh`, `cylinder_mesh`, `voxel_mesh`, `tet_mesh`, `mesh_quality`, `nodes_at`, `face_nodes` | 상자와 원통을 육면체, 정육면체 또는 사면체로; 임의의 모델(파트, 바디, 불러온 STL)을 정육면체 또는 사면체로; 요소 부피와 품질; 평면이나 면 위의 절점 선택 |
| 정적 응력 | `static_voxel`, `static_tet` | 정육면체 또는 10절점 사면체의 선형 정적 응력: 변위, 응력, 폰 미제스, 반력 |
| 프레임 | `frame3d` | 직접 강성법으로 계산한 보, 기둥, 가새의 3D 프레임: 단부 해제, 지점과 스프링, 부재를 따라 작용하는 하중; 변위, 반력, 부재 단부력. DetailCraft 및 BimCraft의 {{ui:CraftScript 내보내기}}는 이를 위해 모델 전체를 작성합니다. 해석 보조 도구이며, 코드 검토 도구는 아닙니다 |
| 진동 | `modal_tet` | 고유 진동수와 모드 형상 |
| 열 | `heat_steady`, `heat_transient`, `heat_system` | 고정 온도, 열 입력, 열 발생, 열유속, 대류를 포함한 정상 및 비정상 열전도 |
| 위상 최적화 | `top88`, `top99`, `topopt3d` | 발표된 88줄 및 99줄 2차원 코드, 그리고 정육면체에 적용한 같은 방법의 3차원 버전 |
| 전자기학 | `poisson2d`, `magnetostatic2d` | 2차원 정전기학(전위, 전기장, 정전 용량, 전하) 및 자기정역학(벡터 퍼텐셜, 자속 밀도, 영구 자석) |
| 유체 흐름 | `lbm2d`, `lbm3d` | 격자 볼츠만 흐름: 2차원은 스크립트에 직접 작성되어 있고, 3차원은 PartCraft 자체 흐름 커널에서 실행합니다 |

모든 함수의 헤더에는 정확한 인수가 나와 있습니다. 헤더에 별도로 명시되지 않으면 단위는 PartCraft 해석의 단위를 따릅니다. 즉 밀리미터, 뉴턴, 메가파스칼, 밀도는 세제곱밀리미터당 톤, 열은 와트와 켈빈입니다. 전자기 함수와 격자 볼츠만 함수는 일관된 임의의 단위계에서 작동하며, 사용 방법은 각 헤더에 나와 있습니다.

## 라이브러리 검증 방법

각 함수의 헤더는 **검사**로 끝납니다. 정답이 알려진 작은 사례입니다. PartCraft의 테스트가 모든 검사를 실행하며, 같은 작업에 대해 PartCraft 자체의 해석 스터디가 있으면 스크립트의 결과를 같은 메시에서 그 스터디와 비교합니다:

- 외팔보 끝단 처짐을 보 이론과 비교(정육면체에서 0.2 % 이내, 사면체에서 0.05 % 이내), 그리고 같은 메시에서 **Simulation** 작업 공간의 솔버와 비교(여러 자리까지 일치).
- 외팔보의 첫 번째 고유 진동수를 보 이론과 비교(짧은 보에서 예상되는 대로 0.24 % 낮음), 그리고 **Simulation**의 모달 솔버와 비교.
- 열: 가열된 평면 벽은 정확히 일치하고, 작은 물체의 냉각은 집중 용량 공식과 일치하며, 슬래브의 온도가 이론대로 감소합니다.
- 위상 최적화: 논문과 같은 반복 94회 및 컴플라이언스 203.1925를 `top88`이 재현합니다(밀도 필터 적용 시 218.8032). `topopt3d`는 같은 설정에서 **Generative** 작업 공간과 같은 컴플라이언스에 도달합니다.
- 축전기의 정전 용량과 긴 솔레노이드의 자기장을 교과서 값과 비교하고, 전자석의 공극 자기장을 자기 회로 공식과 비교합니다. 영구 자석은 공기 중의 원형 자석, 그리고 철 키퍼로 닫힌 자석과 비교합니다.
- 채널 유동은 정확한 포물선 프로파일과 비교합니다.

## 함수 읽기

1. 스크립트 패널의 **라이브러리** 탭을 엽니다.
2. 함수를 클릭합니다. 헤더에는 계산 내용, 방법, 단위, 가정과 한계, **참고 문헌**(책 또는 논문, 식 번호 포함), 그리고 **검사**(정답이 알려진 작은 사례로, PartCraft 자체 테스트가 실행합니다)가 표시됩니다.
3. {{ui:Open (read-only)}} 기능은 전체 스크립트를 점선 테두리 탭에서 엽니다. 실행하거나 일부를 선택해 실행할 수 있지만 변경은 할 수 없습니다.

## 함수 변경하기

{{ui:Make a copy}}를 누르십시오(또는 읽기 전용 탭 위의 **편집용 사본 만들기**). 사본은 같은 이름으로 파트 안에 저장되는 스크립트이므로 파트와 함께 저장됩니다. 이후 **그 함수의 모든 호출은 이제 사본을 사용합니다**. 편집기는 스크립트 위에 이를 표시합니다. 둘 다 유지하려면 사본의 이름을 바꾸십시오.

## 함수 사용하기

내장 함수처럼 이름으로 모든 스크립트에서 라이브러리 함수를 호출합니다:

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

결과는 작업 공간에 값으로 반환되며, 표시되는 그래프와 필드는 보기와 보조 디스플레이에 나타납니다.

예를 들어 열린 파트의 정적 해석은 몇 줄이면 됩니다:

```
v = voxel_mesh(part(), 2);                   % 2 mm 정육면체
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % 아래면 고정
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 위쪽에 아래 방향으로 500 N
r = static_voxel(v, 210000, 0.3, bc);       % 강재
```

`r`에는 변위, 응력, 반력이 담깁니다. 폰 미제스 응력은 변형된 파트 위에 그려집니다. 곡면 파트에는 `tet_mesh` 및 `static_tet` 함수를 사용하십시오. 이 함수들은 면 전체에 하중을 가하고 고정할 수도 있습니다(`face_nodes`).

:::note
라이브러리 함수는 CraftScript 언어로 작성되어 있으며, Lua 스크립트는 내장 함수와 마찬가지로 `cs`를 통해 호출합니다: `cs.static_tet(t, 200000, 0.3, bc)` (참고: [Lua 스크립트](topic:craftscript-lua)). 각 함수는 재료 하나와 하중 사례 하나를 해석하며, 다루지 않는 항목은 헤더에 나와 있습니다.
:::
