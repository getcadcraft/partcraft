## 할 일

파트의 **모든 크기를 한 번에** 전달합니다. 구성마다 STEP, IFC, DWG 파일과 그림을 하나씩 만들고, 각 구성이 무엇인지 알려 주는 표를 만들며, 이 모두를 한 페이지에 담는 라이브러리 항목을 만듭니다.

먼저 **구성**이 있는 파트가 필요합니다([구성과 설계 표](topic:design-tables) 참고). 구멍이 있는 판과 없는 판처럼 피처를 끄는 구성은 각각 별도의 변형이 됩니다.

## 단계

1. 파트를 엽니다. {{ui:파라미터}} 탭에서 **구성**을 찾습니다.
2. {{ui:변형 팩…}} 버튼을 클릭합니다.
3. 빌드할 구성을 체크합니다(기본적으로 모두 체크되어 있습니다). 그리고 쓸 파일을 체크합니다: STEP, IFC, DWG, 미리 보기, 라이브러리 항목.
4. {{ui:팩 만들기}} 버튼을 클릭합니다. 상태 표시줄에 변형이 빌드되는 대로 개수가 표시되며, 파트는 바뀌지 않습니다.
5. zip 파일 하나가 다운로드됩니다: `<part> variants.zip`.

## zip 파일의 내용

| 파일 | 내용 |
|---|---|
| `<name>.step` | 구성을 STEP 솔리드로 저장한 파일입니다. |
| `<name>.ifc` | IFC4 형식이며, 빌드된 본체와 파트 파라미터를 속성으로 담은 요소 하나입니다. 값은 해당 구성 고유의 값입니다. |
| `<name>.dwg` | 정면, 상단, 우측, 등각 뷰를 실제 크기의 도면 시트로 담은 파일입니다. |
| `<name>.svg` | 구성의 등각 선 그림입니다. |
| `variants.csv`, `variants.json` | 파라미터 표입니다. 각 변형의 id, 이름, 모든 파라미터 값, 꺼지는 피처, 파일, 부피와 크기를 담습니다. |
| `<part>.item.json` | 파트를 변형이 포함된 하나의 라이브러리 항목으로 저장한 파일입니다(아래 참고). |
| `README.txt` | 만들어진 내용, 아래의 참고 사항, 빌드되지 않은 항목을 담습니다. |

파일 이름은 구성 이름을 따릅니다. 빌드에 실패한 구성(해당 값으로는 만들 수 없는 피처가 있는 경우)은 파일과 표에서 빠지며, README와 zip 저장 후 메시지에 나열됩니다. 나머지 구성은 그대로 저장됩니다.

## 알아두면 좋은 점

- **STEP**은 빌드에서 정확한 커널이 켜져 있을 때만 정확합니다. 그렇지 않으면 STEP은 면 근사 방식(평평한 삼각형)으로 저장되며, README에 이 사실이 적힙니다.
- **DWG**는 3D 모델이 아니라 도면 시트입니다. 선은 메시에서 만들어지므로 곡선 모서리는 여러 개의 짧은 선으로 표현됩니다.
- **라이브러리 항목**에는 변형마다 본체 하나와 바닥면 하나가 들어 있으며, 라이브러리의 축을 따릅니다. Z 축이 위, 정면은 −Y 방향, 삽입점은 바닥 뒤쪽의 가운데입니다. 평면도는 각 변형의 경계 사각형입니다. 항목 크기는 8 MB로 제한되므로, 매우 무거운 변형은 자체 크기를 가진 상자로 바뀌며 README에 그 개수가 적힙니다.
- 파트에서 현재 활성화된 구성이 항목의 기본 변형이 됩니다.
- 포트(배관과 덕트의 연결점)는 PartCraft에서 설정되지 않습니다.

## 라이브러리 페이지에 변형 올리기

사이트의 **라이브러리 › 업로드**에서 `<part>.item.json`을 업로드합니다. 분류, 라이선스, 출처 표시 문구를 선택하면 변형이 포함된 라이브러리 항목이 됩니다. BimCraft에서 배치하면 어떤 변형을 쓸지 묻고, 교체 기능에서 다른 변형을 고를 수 있습니다. 방문자가 옵션을 고르고 3D를 보고 변형을 내려받는 페이지는 현재 **직원 미리 보기**이며, 아직 일반에 공개되지 않았습니다.

## 명령줄에서

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only`는 구성을 지정하고, `--formats`는 `step`, `ifc`, `dwg`, `preview` 중 원하는 것을 지정합니다. `--no-item`은 라이브러리 항목을 제외합니다. 폴더, zip 또는 둘 다 쓰며, 변형을 빌드하지 못하면 종료 코드 1로 끝납니다. [스크립트와 명령줄](topic:scripts-and-cli)을 참고하십시오.
