PartCraft는 초기 빌드입니다. 이 페이지는 PartCraft가 아직 하지 않는 기능과 지금 대신 할 수 있는 방법을 나열하므로, 없는 기능을 찾느라 시간을 쓰지 않아도 됩니다. 여기 있는 항목 중 날짜가 정해진 것은 없습니다.

## 정밀 커널이 필요함

이 버전은 모든 파트를 메시 커널로 만듭니다([메시 커널](topic:solid-kernels) 참조). 아래 항목은 모두 정밀 지오메트리 커널이 필요하며, 이 버전에는 아직 없습니다. 이런 기능으로 저장한 파트도 열립니다. 피처는 기록에 남고 "만들지 않음"으로 표시되며, 저장할 때 유지됩니다.

| 아직 만들지 않음 | 지금 대신 |
|---|---|
| 둥근 모서리의 {{ui:필렛}} 및 {{ui:모따기}}, 모서리를 따라 반지름이 바뀌는 필렛, 만나는 지점에서 매끄럽게 섞인 라운드(메시 커널은 이를 맞댐으로 처리) | 평평한 면 사이의 직선 모서리에서는 필렛과 모따기가 작동합니다. 다른 모서리는 돌출 전에 스케치에서 둥글게 하십시오(스케치의 {{ui:필렛}}, {{key:F}}) |
| 곡면을 여는 {{ui:쉘}}, 두께가 다른 벽 | 평평한 면을 열고, 벽을 더 두껍게 해야 하면 돌출로 재료를 추가 |
| 곡면에 대한 {{ui:스윕}}, {{ui:로프트}}, {{ui:구배}}, 면, 다음 면 또는 꼭짓점까지 돌출, 테이퍼 돌출 | 돌출 또는 회전, 필요하면 단계별로. 측정한 깊이까지 돌출 |
| {{ui:리브}}, {{ui:베이스 플랜지}}, {{ui:모서리 플랜지}} 및 평판 패턴 | 판 또는 리브의 프로파일을 돌출 |
| 곡면: 파트 안으로 {{ui:형상}} 마무리, {{ui:패치}}, {{ui:곡면 로프트}}, {{ui:고든 곡면}}, {{ui:스티치}}, {{ui:두께 주기}}, {{ui:간격 띄우기 곡면}}, {{ui:곡면 연장}}, {{ui:곡면 자르기}} | 사용할 수 없음 |
| 여러 바디: {{ui:결합}}, {{ui:바디 이동}}, {{ui:바디 축척}}, {{ui:경로 패턴}}, 새 바디를 만드는 피처 | 솔리드 하나. 패턴과 대칭은 피처를 복사 |
| 정밀 커널로만 찾을 수 있는 면의 스케치, 평면, 축, 점(필렛으로 만든 면, 구멍 벽, 가져온 솔리드의 면) | 기준면, 그리고 돌출과 회전의 평평한 면에 스케치 |
| 생성 설계 결과를 파트로 열거나 파트에 추가(가져온 솔리드가 됨) | 결과를 STL 또는 STEP으로 다운로드 |
| 열린 STEP 파일의 곡면을 정밀 곡면으로 편집. 스플라인, 스윕, 회전 면의 정밀 STEP, 스플라인 측면, 모델링된 나사산. STL, OBJ, 3MF 바디와 어셈블리. 다른 파트 모델러용 STEP | {{ui:열기}}: STEP 파일을 삼각형으로 읽고, 파일의 평면, 원통, 원뿔, 구, 토러스를 내보내기용으로 유지([STEP 파일 열기](topic:import-step)). {{ui:내보내기}} › {{ui:STEP AP242 (정밀 솔리드)}}는 모든 해석적 면을 정확히 쓰고, 그 면들을 패싯으로 유지([내보내기](topic:export-files#for-other-cad-programs-step)). 다른 파트 모델러용 매크로는 계속 씁니다 |
| 정확한 호가 있는 도면 뷰 | 뷰와 단면 뷰는 패싯으로부터 그려집니다 |
| 정밀 부피, 면적, 거리 | {{ui:측정}} 명령은 패싯 솔리드의 값을 보여 주며, 둥근 파트에서는 약간 낮게 나옵니다. **곡선** 설정을 더 세밀하게 하면 더 가까워집니다 |

아래 표의 일부 행은 이 기능 중 하나를 다른 것의 해결책으로 제안합니다. 그 제안은 정밀 커널이 돌아온 뒤에 적용됩니다.

## 시뮬레이션과 생성 설계

| 아직 만들지 않음 | 지금 대신 |
|---|---|
| 항복, 큰 처짐, 파트 간 접촉, 피로를 다루는 비선형 해석 | 선형 정적 및 고유 진동수: [응력과 처짐 확인](topic:simulation) 참조. 안전율을 1보다 충분히 크게 유지 |
| 비선형 좌굴(불완전성, 좌굴 후, 스냅스루) | 여유를 둔 선형 좌굴 하중 계수: [열, 열응력, 좌굴](topic:thermal-and-buckling) 참조 |
| 면 사이의 복사(뷰 팩터), 접촉 저항, 온도에 따라 변하는 재료, 열응력의 관성(열 충격파) | 주변으로의 복사, 시간에 따른 정상 또는 준정적 열응력, 일정한 물성: [열, 열응력, 좌굴](topic:thermal-and-buckling) 참조 |
| 과도 열 해석과 열 하중 해석의 자동 세분화, 오차가 작은 곳의 메시를 거칠게 하기, 국소 값 목표(한 지점의 최대 응력) | 정적, 좌굴, 고유 진동수, 정상 열 해석의 **자동 세분화**(파트 전체 오차 기준): [응력과 처짐 확인](topic:simulation) 참조. 그렇지 않으면 요소 크기를 줄이십시오 |
| 베어링과 볼트 하중, 원격 힘, 모멘트, 스프링, 규정 변위 | 면의 힘과 압력, 중력. 고정 면과 마찰 없는 면 |
| 어셈블리 해석, 방향에 따라 달라지는 재료(인쇄 층, 복합재) | 파트 하나, 등방성 재료 하나 |
| 사면체 해석, 열전달, 생성 설계의 여러 솔버 스레드. 교차 출처 격리가 안 된 페이지의 스레드 | 복셀 해석, 좌굴, 시간에 따른 응력, 층류 흐름은 페이지가 허용하는 경우 스레드 사용: [PartCraft 설정](topic:settings) 참조 |
| 설계 정확도의 난류(Spalart–Allmaras 모델은 실험적으로 포함됨: 파이프 마찰 30~34 % 높음, 후향 계단 재부착 21~39 % 짧음. 계획: 벽 근처의 더 촘촘한 셀), 흐름의 열, 비정상(시간 정확) 흐름, 자유 표면, 비뉴턴 유체, 회전하는 파트 | 뉴턴 유체의 층류, 정상, 등온 흐름, 또는 정성적 패턴을 위한 실험적 난류 모델: [유동 시뮬레이션](topic:flow-simulation) 참조. 레이놀즈 수가 층류를 넘으면 패널이 경고 |
| 생성 설계의 응력 한계와 제조 규칙(오버행, 밀링 방향), 한 형상의 여러 재료 | 부피에 대한 가장 강한 형상. 시뮬레이션에서 결과 확인: [하중으로 형상 키우기](topic:generative-design) 참조 |
| 편집할 수 있는(매끄럽고 파라메트릭) 솔리드로서의 결과 | STL, 패싯 STEP, 또는 결과를 가져온 패싯 솔리드로 가진 파트 |
| 전기 기계 설계: 고정자 안에서 도는 회전자, 각도에 대한 토크, 포화되는 강재, 무릎점을 넘으면 세기를 잃는 자석, 와전류와 철·구리 손실. 3D 또는 곡면 메시의 자기장 | 분석 라이브러리의 격자에서 선형 2D 정자기: 코일, 철, 리코일 선의 영구 자석, 간극, 인덕턴스와 흡인력. [2D 자기장](topic:magnetic-fields-2d) 참조 |
