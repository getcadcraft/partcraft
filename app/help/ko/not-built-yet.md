PartCraft는 초기 빌드입니다. 이 페이지는 이 빌드가 아직 하지 않는 것을 나열하므로 찾느라 시간을 쓰지 않도록 하며, 오늘 대신 할 수 있는 방법도 알려 줍니다. 여기 있는 항목에는 날짜가 없습니다.

## 정확한 커널이 필요함

이 버전은 모든 파트를 메시 커널로 만듭니다([메시 커널](topic:solid-kernels) 참조). 아래의 모든 것은 정확한 기하 커널이 필요하며, 이 버전에는 아직 없습니다. 이런 기능으로 만든 파트도 열리기는 합니다. 특징은 이력에 남고 구현되지 않음으로 표시되며, 저장할 때 유지됩니다.

| 아직 구현되지 않음 | 오늘 대신 |
|---|---|
| 둥근 모서리의 {{ui:Fillet}}와 {{ui:Chamfer}}, 모서리를 따라 반지름이 변하는 필렛, 만나는 곳을 매끄럽게 섞은 라운드(메시 커널은 이것을 미터 맞춤으로 처리합니다) | 필렛과 모따기는 평면 사이의 직선 모서리에서 작동합니다. 다른 모서리는 돌출하기 전에 스케치에서 둥글게 하십시오({{ui:Fillet}}, 스케치에서, {{key:F}}) |
| 곡면을 열어 두는 {{ui:Shell}}, 벽 두께가 다른 셸 | 평면을 열어 두십시오. 벽이 더 두꺼워야 하는 곳은 돌출로 재료를 더하십시오 |
| 곡면에서의 {{ui:Sweep}}, {{ui:Loft}}, {{ui:Draft}}. 면, 다음 면 또는 꼭짓점까지의 돌출. 테이퍼 돌출 | 돌출 또는 회전, 필요하면 단계를 나누어서. 잰 깊이까지 돌출하십시오 |
| {{ui:Rib}}, {{ui:Base flange}}, {{ui:Edge flange}}와 평판 패턴 | 판이나 리브 단면을 돌출하십시오 |
| 표면: 파트 안으로 {{ui:Form}} 마무리, {{ui:Patch}}, {{ui:Loft surface}}, {{ui:Gordon surface}}, {{ui:Stitch}}, {{ui:Thicken}}, {{ui:Offset surface}}, {{ui:Extend surface}}, {{ui:Trim surface}} | 사용할 수 없음 |
| 여러 바디: {{ui:Combine}}, {{ui:Move body}}, {{ui:Scale body}}, {{ui:Path pattern}}, 새 바디를 만드는 특징 | 솔리드 하나. 패턴과 대칭은 특징을 복사합니다 |
| 정확한 커널만 찾을 수 있는 면의 스케치, 평면, 축, 점(필렛으로 만든 면, 구멍 벽, 가져온 솔리드의 면) | 기준 평면, 참조 평면, 돌출과 회전의 평면에 스케치하십시오 |
| 파트로 열거나 파트에 더한 생성 설계 결과(가져온 솔리드가 됨) | 결과를 STL 또는 STEP으로 내려받으십시오 |
| 열린 STEP 파일의 곡면을 정확한 표면으로 편집; STEP 파일의 스플라인, 스윕, 회전 면의 정확한 STEP; 스플라인 면, 모델링된 나사, STL / OBJ / 3MF 바디와 어셈블리; 다른 파트 모델러용 STEP | {{ui:Open}}은 STEP을 삼각형으로 읽고, 내보낼 때 파일의 평면, 원기둥, 원뿔, 구, 토러스를 유지합니다([STEP 파일 열기](topic:import-step)). {{ui:Export}} › {{ui:STEP AP242 (exact solid)}}는 모든 해석적 면을 정확하게 쓰고, 이를 패싯으로 유지합니다([내보내기](topic:export-files#for-other-cad-programs-step)). 다른 파트 모델러용 매크로는 여전히 씁니다 |
| 도면 뷰의 참 호 | 뷰와 단면 뷰는 패싯으로 그립니다 |
| 정확한 부피, 면적, 거리 | {{ui:Measure}}는 패싯 솔리드의 수치를 보여 주며, 둥근 부분에서는 약간 작습니다. 더 세밀한 **곡선** 설정이 값을 더 가깝게 만듭니다 |

아래 표 일부는 이 기능 중 하나를 다른 것의 우회로로 제안합니다. 그 제안은 정확한 커널이 돌아온 뒤에 적용됩니다.

## 특징

| 아직 구현되지 않음 | 오늘 대신 |
|---|---|
| 면 필렛, 완전 라운드 필렛, 모서리의 점에서 설정한 반지름의 필렛 | 일정 또는 선형 가변 {{ui:Fillet}}; 여러 필렛 특징 |
| 벽 두께가 다른 셸 | 하나의 {{ui:Shell}} 두께. 벽이 더 두꺼워야 하는 곳은 돌출로 재료를 더하십시오 |
| 자유 곡면(스플라인) 면의 구배 | {{ui:Draft}}는 평면, 원기둥, 원뿔 면에서 작동합니다 |
| 비틀림 스윕, 얇은 벽과 표면 스윕; 로프트 특징의 끝 접선; 안내 레일이 하나인 로프트; 스플라인 경로 | 방향이 고정되었거나 끝 배율이 있는 {{ui:Sweep}}; 안내 레일이 둘 이상인 로프트: [스윕, 로프트, 구배](topic:sweep-loft-draft) 참조 |
| 호나 스플라인에서 만든 리브; 스케치에 맞춰 사각으로 자란 리브(위 뷰에서); 리브의 구배; 한 스케치에서 여러 리브 | 리브의 평면에 있는 한 선 체인에서 만든 {{ui:Rib}}: [리브와 거셋](topic:rib) 참조 |
| 곡면까지 "까지", 굽은 면에서 멈추는 "다음까지" | 평면 또는 참조 평면까지 |
| 카운터드릴 구멍, 인치와 파이프 나사, 테이퍼 나사, 나사 끝의 런아웃, 모따기된 나사 시작 | 작은 깊이의 카운터보어. ISO 미터법과 사다리꼴 나사는 그려지거나 모델링된 것 모두: [축과 보어의 나사, 그린 것 또는 모델링된 것](topic:threads) 참조 |
| 얇은 특징 돌출 | 프로파일의 양쪽 벽을 모두 그리십시오 |
| 패턴 복사를 하나씩 건너뛰기, 채우기 패턴 | 별도의 특징을 쓰십시오. 곡선을 따른 패턴: {{ui:Path pattern}} |
| 패턴 복사, 대칭, 필렛, 모따기, 셸, 가져온 솔리드 복사 | 그것이 만들어진 스케치나 특징을 복사하거나 패턴을 만드십시오 |
| 형상의 특이점에서의 정확한(G1) 접선; 형상의 패치를 더 큰 면으로 합치기 | 형상의 Level을 올리십시오. 근사된 패치가 더 작아집니다. [Form으로 만든 자유 형상](topic:form-surfaces) 참조 |
| 한 특징에 떨어진 닫힌 조각 여러 개가 있는 형상; 형상 사이의 다리 | 형상 특징마다 닫힌 조각 하나. 결합하려면 {{ui:Join}}을 쓰십시오 |
| 뷰에서 표면 바디 고르기(트림과 패치 점 제외); 표면 필렛; 언트림; G2 패치; 굽은 이웃과 접하는 고든 곡면(평면과 평평한 면에 접하는 것은 구현됨) | 특징 패널에서 이름으로 고르십시오. 먼저 두께를 주고, 그다음 솔리드를 필렛하십시오 |
| 이력에 있는 바디 목록; 내보내기에서 숨겨진 바디 빼기 | 파트 패널의 바디 목록에서 이름을 바꾸고 숨기십시오. 바디를 만든 특징을 삭제하거나 억제하면 제외됩니다 |
| 원기둥과 원뿔을 해석적으로 유지하는 비균일 축척; 간격 띄우기 표면의 비균일 축척 | {{ui:Scale body}}는 곡면을 닫힌 B스플라인으로 만듭니다(0.0000004 mm 이내). 균일한 축척은 정확하게 유지됩니다 |
| 표면 바디 결합; 민코프스키 합 | 먼저 {{ui:Stitch}} 또는 {{ui:Thicken}}, 그다음 {{ui:Combine}} |
| 공차 해석: 모서리를 도는 스택업(2D 및 3D 벡터 루프), 기하에서 계산한 민감도, 다른 분포의 몬테카를로, 스케치 치수의 크기 공차, 재료 조건에 따른 보너스 공차 | 어셈블리의 {{ui:Stack-up}}: 한 방향, 최악의 경우와 RSS, 공차 직접 입력, 표제란의 일반 공차 또는 GD&T 틀에서 가져옴. [공차 스택업](topic:tolerance-stackup) 참조 |
| 네스팅: 절삭 순서와 리드인, 공유 모서리를 한 번만 절삭, 함께 두어야 하는 파트; 롤의 잔여분, 프로젝트 간 공유 소재 | 간격, 여백, 회전과 결을 갖춘 {{ui:Nest flat parts on sheets…}}: [평판 파트를 시트에 배치](topic:nest-flat-parts) 참조. 남은 판은 보관되어 먼저 쓰입니다: [자투리 보관과 재사용](topic:nest-offcuts) 참조. 절삭 계획은 절단기 자체 소프트웨어에서 하십시오 |
| 판금: 헴, 조그, 미터 및 윤곽 플랜지; 굽은 모서리나 굽은 베이스 플랜지 면의 플랜지; 스케치 굽힘; 모서리 마감; 성형 공구; 솔리드를 판금으로 변환; 절단이 있는 굽은 베이스 플랜지의 평판; 굽힘 표 | {{ui:Base flange}}(판 또는 굽은 단면), 판의 직선 모서리에 굽힘 릴리프가 있는 {{ui:Edge flange}}, K 인자가 있는 평판 패턴: [판금](topic:sheet-metal) 참조 |
| 어셈블리의 구배 해석; 파팅 라인 찾기; 벽 두께 해석 | 설계에서 파트의 {{ui:Draft analysis}}: [성형과 주조용 구배 확인](topic:draft-analysis) 참조. 어셈블리의 각 파트를 열어 확인하십시오 |

## 스케치

| 아직 구현되지 않음 | 오늘 대신 |
|---|---|
| 타원, 접선 호, 원뿔 곡선, 차수나 가중치가 정해진 스플라인(NURBS) | 스플라인(3차), 접선 관계가 있는 호와 원 |
| 스플라인 위의 점(관계), 곡률(G2) 관계 | 스플라인 자체의 점을 통과해야 하는 곳에 두십시오 |
| 나중의 변경을 따르는 스플라인의 오프셋 복사; 날카로운 스플라인 모서리가 있는 체인의 오프셋 | 변경 후 다시 간격 띄우기. 먼저 모서리를 둥글게 하십시오 |
| 원본에 연결된 채로 남는 패턴 복사; 곡선을 따른 패턴 | 변경 후 다시 패턴 |
| 자유 형상이나 기울어진 원형 모서리의 투영, 파트를 따라가는 투영 기하 | 직선과 평행한 원형 모서리를 투영한 뒤 치수를 기입하십시오 |
| 구동(참조) 치수 | 패널이나 파트 정보에서 크기를 읽으십시오 |
| 공선 관계 | 거리 0인 평행 |
| 다른 프로그램에 붙여넣기(시스템 클립보드) | DXF, STEP, STL 또는 3MF로 내보내십시오 |
| 호, 상대 또는 극좌표 입력 | 선과 원을 입력하고, 호는 호 도구로 그리십시오 |
| 포인터 없이 형상 선택 | 클릭이나 탭이 필요합니다 |

## 매개변수와 단위

| 아직 구현되지 않음 | 오늘 대신 |
|---|---|
| 재료를 바꾸는 구성; 특징을 끄는 CSV 설계 표 | 구성은 매개변수를 설정하고 특징을 켜고 끕니다: [구성과 설계 표](topic:design-tables) 참조. `partcraft variants`는 저장된 구성을 이름으로 변형 팩으로 만듭니다(꺼진 특징 포함): [구성에서 변형 팩 만들기](topic:variant-pack) 참조 |
| 가장 새로운 특징의 패널에 있는 수치 방정식(평면, 스윕, 구배 등) | 스크립트나 `partcraft set`으로 쓰십시오([스크립트와 명령행](topic:scripts-and-cli)) |
| 인치로 보이는 파트 | 크기는 밀리미터로 표시됩니다. 숫자 상자나 식에 `2in`을 입력하면 50.8이 됩니다 |

## 파일

| 아직 구현되지 않음 | 오늘 대신 |
|---|---|
| 가져온 STEP 솔리드 자체의 특징 편집(이력 없이 들어옴) | 자체 특징으로 재료를 더하거나 깎으십시오 |
| STEP에서 색, 이름, 어셈블리 구조, PMI 읽기 | 사용할 수 없음 |
| glTF, OBJ, IGES, Parasolid 내보내기; 3D 파트의 DWG(변형 팩만 DWG를 씁니다: 도면 시트) | 메시는 STL 또는 3MF, 솔리드는 STEP, 2D는 DXF |
| IGES, DXF 또는 다른 프로그램의 자체 파일 열기(`.3dm` 파일은 하나의 바디로 열림: [.3dm 모델을 솔리드 바디로 열기](topic:open-3dm-files)) | STEP을 요청하거나, 닫힌 STL, OBJ 또는 3MF 메시를 사용하십시오: [STL, OBJ 또는 3MF 열기](topic:open-meshes) |
| 내보낸 STEP의 어셈블리 구조(부품 이름이 있는 트리) | 어셈블리 STEP은 배치된 솔리드의 복합 하나입니다 |
| 브라우저 다운로드 없이 원하는 폴더에 저장 | 브라우저의 다운로드 설정에서 "저장 위치 묻기"를 켜십시오 |

| 과도 열해석과 열하중이 있는 연구의 자동 세분화; 오차가 작은 곳의 메시를 성기게 하기; 국소량(한 점의 최대 응력)을 목표로 하기 | 정적, 좌굴, 고유 진동수, 정상 열 연구에서 **자동으로 세분화**하며, 전체 파트의 오차 기준: [응력과 처짐 확인](topic:simulation) 참조. 그 밖에는 요소 크기를 줄이십시오 |
| 베어링과 볼트 하중, 원격 힘, 모멘트, 스프링, 규정된 변위 | 면의 힘과 압력, 중력; 고정 면과 마찰 없는 면 |
| 어셈블리의 시뮬레이션; 방향에 따라 달라지는 재료(인쇄 층, 복합재) | 파트 하나, 등방성 재료 하나 |
| 사면체 연구, 열 전달, 생성 설계를 위한 여러 해석 스레드; 교차 출처 격리되지 않은 페이지의 스레드 | 복셀 연구, 좌굴, 시간에 따른 응력, 층류는 페이지가 허용하는 곳에서 스레드를 사용합니다: [PartCraft 설정](topic:settings) 참조 |
| 설계 정확도를 갖춘 난류(Spalart–Allmaras 모델은 실험적으로 들어 있음: 관 마찰이 30~34 % 높고, 뒤쪽 계단 재부착이 21~39 % 짧음; 계획: 벽 근처의 더 세밀한 셀), 흐름의 열, 비정상(시간 정확) 흐름, 자유 표면, 비뉴턴 유체, 회전하는 파트 | 뉴턴 유체의 층류, 정상, 등온 흐름, 또는 정성적 패턴을 위한 실험적 난류 모델: [유체 흐름 시뮬레이션](topic:flow-simulation) 참조. 레이놀즈 수가 층류 범위를 넘으면 패널이 경고합니다 |
| 생성 설계의 응력 한계와 제조 규칙(오버행, 밀링 방향); 한 형상의 여러 재료 | 부피에 대한 가장 강한 형상. 해석에서 결과를 확인하십시오: [하중으로 형상 키우기](topic:generative-design) 참조 |

| 전기 기계 설계: 고정자 안에서 도는 회전자, 각도에 대한 토크, 포화되는 강재, 한계를 넘으면 세기를 잃는 자석, 와전류와 철심 및 구리 손실; 곡면 메시 위나 3D의 자기장 | 분석 라이브러리의 격자 위 선형 2D 정자기: 코일, 철심, 복귀선 위의 영구 자석, 간극, 인덕턴스, 인력: [2D 자기장](topic:magnetic-fields-2d) 참조 |
