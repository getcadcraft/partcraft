스크립트 작업 공간의 해석은 서로 변수를 넘겨주는 짧은 스크립트 몇 개로 이루어집니다. 필요한 것과 가까운 [해석 라이브러리](topic:craftscript-library) 함수에서 시작해 사본을 만들어 수정하거나, 아래처럼 단계별로 직접 만들 수 있습니다.

## 1. 메시

```
model = part();                  % 모델링 중인 파트를 모델로
m = tetmesh(model, 4);           % 약 4 mm 크기의 사면체
show(m)
```

계속하기 전에 보기에서 메시를 확인하십시오. {{key:F}} 키는 메시에 맞추고, **표시 중** 목록의 {{ui:눈 아이콘}}은 파트를 숨깁니다.

## 2. 조립과 풀이

요소 루프는 스크립트에 직접 작성하십시오(교과서처럼 읽힙니다). 무거운 계산은 내장 함수에 맡기십시오: 요소 행렬, 삼중항에서의 희소 조립, 전처리기를 사용하는 켤레 기울기 솔버. 라이브러리에 포함된 `static_tet` 같은 함수는 복사해 쓸 수 있는 완전한 예제입니다.

## 3. 결과 표시하기

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % 절점마다 값 하나
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- 범례의 범위는 직접 입력하거나 {{ui:Auto}}으로 되돌릴 수 있습니다.
- 메시를 클릭하면 절점의 값을 읽을 수 있습니다.
- 같은 `'id'`를 유지하는 그래프는 제자리에서 갱신되므로, 수렴을 지켜보려면 루프 안에서 출력하고 그래프를 그리십시오.

## 4. 검사하기

알고 있는 값과 비교하십시오: 외팔보 끝단 처짐을 PL³/3EI와 비교하고, 구멍이 있는 판을 응력 집중 계수와 비교하고, 반력을 하중과 비교합니다. 매 변경 후 다시 실행되도록 검사를 별도의 스크립트로 작성하십시오:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. 보관하기

- 각 단계는 자체 스크립트 탭으로 둘 수 있습니다. 탭들은 변수를 공유하므로 차례대로 실행하십시오.
- 스크립트는 파트 안에 저장됩니다. 결과도 함께 보관하려면 **변수** 탭에서 **파트와 함께 변수 저장**을 선택하십시오(최대 32 MB).
- 스크립트 그룹의 {{ui:Save}}은 스크립트를 공유할 수 있도록 내려받고, {{ui:Open}}는 스크립트를 가져옵니다.
