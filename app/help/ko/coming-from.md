SolidWorks에서 파트를 설계한다면 PartCraft의 개념 대부분이 익숙할 것입니다. Front, Top, Right 평면의 스케치, 구속 관계와 스마트 치수, 롤백 막대가 있는 피처 기록, 메이트로 배치하는 어셈블리가 그렇습니다. 이를 찾아가는 방법은 일부 다르며, 이 첫 빌드는 기능이 더 적습니다. 이 페이지는 익숙한 습관을 대응시키고 놀랄 만한 차이를 정리합니다.

## 습관 대응표

| 익숙한 방식 | PartCraft에서 |
|---|---|
| 왼쪽의 디자인 트리 | 왼쪽의 기록: 평면, 그다음 피처. 스케치는 그 스케치를 사용하는 피처 아래에 들여쓰기로 표시 |
| Front, Top, Right 평면 | 같은 세 개이며 원점을 지납니다. Front는 XY 평면, Top은 XZ, Right는 YZ입니다. Y는 위를 향합니다. |
| 평면이나 면에 스케치한 뒤 확인 모서리로 종료 | 선택된 평면이나 평평한 면에서 {{ui:스케치}} ({{key:S}}); 스케치가 닫힐 때까지 {{ui:종료}} 또는 {{key:Esc}} |
| 스마트 치수 | {{ui:치수}} ({{key:D}}). 항목 하나 또는 둘을 클릭한 다음 숫자를 놓을 위치를 클릭하십시오. 놓는 위치에 따라 수평, 수직, 정렬 치수가 정해집니다. |
| 속성 패널의 구속 관계 추가 | 항목을 선택한 다음 오른쪽 패널의 구속 관계 버튼(일치, 수평, 평행, 접선, 같음 등)을 사용하십시오 |
| 스케치 중 자동 구속 관계 | 스냅이 일치, 점-곡선 위, 수평, 수직 구속 관계를 자동으로 추가합니다 |
| 파란색 / 검은색 / 빨간색 스케치 색상 | 같은 의미입니다: 파란색은 정의 부족, 검은색은 완전 정의, 빨간색은 과잉 정의. 칩에는 남은 자유도가 표시됩니다. |
| 회전용 중심선 | {{ui:중심선}} ({{key:N}}). {{ui:회전}}은 다른 축을 고르지 않으면 첫 번째 중심선을 사용합니다. |
| 스케치 필렛 | 스케치에서 {{ui:필렛}} ({{key:F}}): 모서리를 클릭하고 반지름을 입력하십시오 |
| 작도 형상 전환 | {{ui:작도선}} ({{key:Q}}) |
| 돌출 보스 | {{ui:돌출}}: 블라인드, 중간 평면, 면 / 다음 / 꼭짓점까지, 면에서 오프셋, 두 번째 방향, 테이퍼, 하나의 윤곽(영역 선택) |
| 돌출 절단 | {{ui:절단}}: 처음에는 모두 관통이며, 포켓을 만들려면 블라인드로 바꾸십시오 |
| 회전 보스 / 절단 | {{ui:회전}} / {{ui:더보기}} › {{ui:회전 절단}} |
| 기준 평면 / 축 / 점 | {{ui:더보기}} › {{ui:평면}}, {{ui:축}}, {{ui:점}} ([기준 평면, 축 및 점](topic:reference-geometry) 참조) |
| 스윕 / 로프트 보스 또는 절단, 구배 | 평평한 면에서 {{ui:더보기}} › {{ui:구배}} ([스윕, 로프트 및 구배](topic:sweep-loft-draft) 참조). {{ui:스윕}}과 {{ui:로프트}}는 이 버전에서 아직 만들지 않았습니다(정확한 커널이 필요합니다) |

| 선형 / 원형 패턴, 대칭 | {{ui:선형}}, {{ui:원형}}, {{ui:대칭}} (피처 또는 바디 전체) |

| 쉘 | {{ui:쉘}}: 열 평평한 면을 클릭한 다음 버튼을 누르십시오. 벽 두께는 하나입니다. |

| 다시 만들기 | 모든 변경 후 자동으로 다시 만들어집니다. 다시 만들기 키는 없습니다. |
| 억제 / 억제 해제 | 오른쪽 패널의 {{ui:억제}} / {{ui:억제 해제}} |

| 모델을 더블클릭해 치수 편집 | 피처를 선택하십시오: 그 스케치의 치수가 오른쪽 패널에 나열됩니다 |
| 메이트: 일치, 동심, 거리, 각도 | {{ui:조인트}} ({{key:J}}): 각 파트의 평평한 면을 선택하십시오. 조인트가 면끼리 맞대게 합니다. 축에 대한 **중심 기준**은 동심과 같고, **오프셋**은 거리와, **각도**는 각도와 같습니다. |

| 우클릭 메뉴 | 없음. 오른쪽 드래그는 초점 이동입니다. 스케치에서는 우클릭으로 선 체인을 끝냅니다. |

## 혼동하기 쉬운 차이점

**스케치 전체가 프로파일입니다.** 돌출과 회전은 스케치의 닫힌 루프를 모두 사용합니다. 피처에 대해 스케치의 영역이나 윤곽을 하나만 고를 수 없습니다. 피처마다 스케치를 하나씩 사용하십시오.

**피처가 사용하는 스케치.** 피처는 방금 닫은 스케치나 기록에서 선택된 스케치를 사용합니다. 아무것도 선택하지 않으면 아직 어떤 피처도 사용하지 않은 가장 최근 스케치를 사용합니다. 잘못된 스케치가 선택되면 올바른 스케치를 선택한 다음 피처를 다시 선택하십시오.

**변경은 입력하는 즉시 적용됩니다.** 확인과 취소가 있는 피처 대화상자는 없습니다. 모든 숫자는 즉시 다시 만들어지며, 되돌리려면 {{key:Mod+Z}}를 사용합니다. 실행 취소 목록은 스케치 편집, 피처, 설정을 모두 포함합니다.

**과잉 정의는 조용히 남아 있도록 두지 않습니다.** 구동 치수(참조 치수)는 없습니다. 다른 구속 관계가 이미 고정하는 치수는 과잉 정의로 보고됩니다("이미 암시됨. 삭제하십시오."). 충돌하는 치수는 형상을 건드리지 않고 빨간색으로 바뀝니다. 하나를 삭제하거나 실행 취소하십시오.

**스윕과 로프트는 아직 만들지 않았습니다. 필렛, 모따기, 쉘, 구배에는 제한이 있습니다.** 이 버전의 PartCraft는 모든 파트를 메시 커널로 만들며, 상태 표시줄 칩에는 항상 "Mesh kernel"이라고 표시됩니다. 필렛과 모따기는 두 평평한 면 사이의 직선 모서리에서 작동하며, 라운드가 모서리에서 만나는 곳은 블렌드하지 않고 맞깎기로 처리합니다. 쉘은 열린 면을 지정해 만들 수 있으며, 구배는 평평한 면에서만 기울어집니다. 정확한 커널이 필요한 피처도 클릭은 되지만, 선택하면 "아직 만들지 않았습니다"라고 표시됩니다. [메시 커널](topic:solid-kernels)과 [아직 만들지 않은 기능](topic:not-built-yet)을 참조하십시오.

**같은 이름의 버튼 두 개.** 스케치에서 {{ui:필렛}} ({{key:F}})은 스케치 모서리를 둥글게 합니다. 파트에서는 피처 그룹의 {{ui:필렛}}이 솔리드 모서리를 둥글게 합니다(이 버전에서는 평평한 면 사이의 직선 모서리). 이 버전에는 스윕이나 로프트가 없습니다: [아직 만들지 않은 기능](topic:not-built-yet) 참조.

**구멍에는 독립 점이 필요합니다.** {{ui:구멍}}은 점 도구로 만든 점에 구멍을 뚫습니다. 원의 중심과 선의 끝은 해당하지 않습니다.

**모두 관통은 절단에만 사용합니다.** 보스에는 깊이가 필요합니다. "꼭짓점 / 면 / 다음까지" 끝 조건은 아직 없습니다.

**솔리드는 면으로 나뉩니다.** 메시 커널은 둥근 면을 평평한 면들로 만들므로, 뷰, 부피, STL, 3MF 내보내기는 모두 이 면들로 구성됩니다. 파트 패널의 **곡선**으로 더 세밀하게 만듭니다. 정확한 STEP 내보내기는 그렇지 않습니다. 둥근 면을 실제 곡면으로 씁니다.

**밀리미터만 사용합니다.** 아직 인치 설정이 없습니다. 인치 값은 입력할 때 25.4를 곱하십시오.

**Y가 위입니다.** Front 평면은 사용자를 향하고 Top은 파트를 내려다보며, 예상하신 대로입니다. 그러나 세계의 위쪽 축은 Y입니다. STL, 3MF, 정확한 STEP 내보내기는 Z가 위가 되도록 회전됩니다. 면으로 나뉜 STEP은 Y를 위로 유지합니다.

**메이트는 기하 쌍이 아니라 면입니다.** 조인트는 항상 면끼리 맞댄 두 평평한 면에서 시작합니다. 구멍에 들어가는 핀이라면, 구멍 주변의 평평한 면과 핀의 어깨를 선택한 다음, **중심 기준**을 구멍의 축과 핀의 회전 축으로 설정하십시오. 조인트가 닿지 않는 파트는 삽입된 위치에 그대로 있으며 끌 수 없습니다. 루프 안의 조인트는 풀리지 않습니다.

**저장은 다운로드입니다.** 계속 덮어쓰는 파일은 없습니다. 저장할 때마다 다운로드 폴더에 새 파일이 생깁니다. 먼저 파트 이름을 지정하고, 파일은 프로젝트 폴더에 보관하십시오.

**상황에 맞는 메뉴와 명령 관리자 탭은 없습니다.** 모든 기능은 도구 모음과 오른쪽 패널에 있으며, 도구 모음은 작업에 따라 바뀝니다. 스케치 도구는 스케치에서만, 어셈블리 도구는 어셈블리에서만 나타납니다.

**스케치 안에서는 키가 한 글자입니다.** {{key:L}}, {{key:R}}, {{key:C}}, {{key:A}}, {{key:P}}, {{key:N}}, {{key:F}}, {{key:D}}, {{key:Q}}, {{key:S}}는 수정자 없이 도구를 선택합니다. [키와 마우스](topic:keyboard)를 참조하십시오.
