PartCraft는 휠과 가운데 버튼이 있는 마우스를 위해 만들어졌지만, 제스처를 익히면 트랙패드도 잘 동작합니다. 터치 화면은 파트를 보고 간단한 스케치를 하는 데 쓸 수 있습니다.

## 트랙패드

:::mac
| 목적 | 방법 |
|---|---|
| 파트 회전 (3D) | 손가락 하나로 클릭하고 드래그합니다(세 손가락 드래그를 켰다면 세 손가락으로 드래그) |
| 초점 이동 (3D) | {{key:Shift}}(또는 ⌘)를 누른 채 클릭-드래그하거나, 두 손가락을 누른 채 클릭-드래그합니다(보조 클릭 드래그) |
| 스와이프로 파트 회전 | 두 손가락으로 스와이프합니다. {{key:Shift}}를 누르면 스와이프가 초점을 이동합니다. **스크롤**을 "자동 판단"(시작 값) 또는 "트랙패드"로 설정해야 합니다 |
| 확대/축소 (3D 및 스케치) | 핀치합니다. 확대/축소는 포인터 쪽으로 이루어집니다. **스크롤**을 "마우스 휠"로 설정하면 두 손가락 스크롤로도 확대/축소됩니다 |
| 우클릭 | 두 손가락으로 클릭하거나 {{key:Ctrl}}+클릭 |
| 스케치에서 초점 이동 | 두 손가락으로 스와이프("자동 판단" 또는 "트랙패드"), 또는 두 손가락을 누른 채 클릭-드래그. {{key:Shift}}+드래그는 스케치에서 초점을 이동하지 않습니다(선택 창을 그립니다) |
| 스케치에서 선택에 추가 | {{key:Shift}}+클릭 또는 ⌘+클릭 |

두 손가락 클릭이 동작하지 않으면 **시스템 설정**, **트랙패드**, **포인트 및 클릭**에서 보조 클릭을 켜십시오.
:::

:::windows linux
| 목적 | 방법 |
|---|---|
| 파트 회전 (3D) | 터치패드를 누르고(또는 탭한 뒤 길게 누르고) 드래그합니다 |
| 초점 이동 (3D) | {{key:Shift}} 또는 {{key:Ctrl}}을 누른 채 드래그하거나, 오른쪽 버튼 영역을 누른 채 드래그합니다 |
| 스와이프로 파트 회전 | 두 손가락으로 스와이프합니다. {{key:Shift}}를 누르면 스와이프가 초점을 이동합니다. **스크롤**을 "자동 판단" 또는 "트랙패드"로 설정해야 합니다 |
| 확대/축소 (3D 및 스케치) | 터치패드가 지원하면 핀치합니다. 확대/축소는 포인터 쪽으로 이루어집니다. **스크롤**을 "마우스 휠"로 설정하면 두 손가락 스크롤로 확대/축소됩니다 |
| 우클릭 | 두 손가락 탭, 또는 터치패드의 오른쪽 아래 모서리 |
| 스케치에서 초점 이동 | 두 손가락으로 스와이프("자동 판단" 또는 "트랙패드"), 또는 오른쪽 버튼 영역을 누른 채 드래그. {{key:Shift}}+드래그는 스케치에서 초점을 이동하지 않습니다 |
| 스케치에서 선택에 추가 | {{key:Shift}}+클릭 또는 {{key:Ctrl}}+클릭 |
:::

**스크롤**은 [PartCraft 설정](topic:settings)에 있습니다. "자동 판단"(기본)은 옆으로 또는 세밀하게 하는 스크롤을 트랙패드로 취급하고, "트랙패드"는 항상 트랙패드로 취급하며, "마우스 휠"은 절대 그렇게 취급하지 않습니다. 세 설정 모두에서 핀치는 확대/축소합니다.

뷰를 클릭한 뒤에는 방향키로 3D 뷰를 회전하고, {{key:Shift}}와 방향키로 초점을 이동합니다. 트랙패드에서 편리합니다. {{key:Plus}}와 {{key:Minus}}는 확대/축소합니다.

## 터치 화면

PartCraft는 터치 입력을 인식하므로 태블릿, 터치 노트북, 휴대폰에서 쓸 수 있지만 제약이 있습니다.

:::touch
**터치 키**

화면을 터치하면 뷰 오른쪽 아래에 손가락으로는 누를 수 없는 키가 있는 작은 막대가 나타납니다. 마우스를 쓰면 사라집니다.

- {{ui:Esc}}: Esc 키입니다. 시작한 작업을 취소하거나 한 단계 뒤로 가며, 키와 똑같이 동작합니다.
- {{ui:Add}}(스케치에서 선택 도구와 함께): 켜져 있는 동안 탭할 때마다 항목을 선택에 추가하거나 뺍니다. {{key:Shift}}+클릭과 같습니다. 다시 탭하면 한 번에 한 항목만 선택하는 방식으로 돌아갑니다.
- {{ui:Done}}(선 체인, 스플라인 또는 다각형을 그리는 동안): 우클릭과 같이 그리기를 끝냅니다.

손가락을 약 0.5초 동안 가만히 누르면 한 번 탭한 것과 같이 동작합니다. 그리기 도구에서는 그리던 것을 끝내고, 선택 도구에서는 손가락 아래의 항목을 선택에 추가하거나 뺍니다. 점과 선은 손가락으로 맞히기 어려우므로, PartCraft는 탭 주변을 클릭 주변보다 약 두 배 넓게 찾습니다.

**3D 뷰에서**

- 손가락 하나: 파트를 회전합니다.
- 두 손가락: 핀치로 확대/축소하고, 함께 움직이면 초점이 이동합니다.
- 탭: 면, 모서리 또는 평면을 선택합니다. 탭하기 전에는 포인터 강조 표시가 없습니다.

**스케치에서**

- 그리기 도구로 탭하여 각 점을 찍습니다. 시작점을 탭하고, 끝점을 탭합니다. 스냅은 손가락을 뗀 곳에서 적용됩니다.
- 두 손가락으로 핀치하여 확대/축소하고 초점을 이동합니다. 두 번째 손가락을 대면 첫 번째 손가락이 시작한 드래그가 취소됩니다.
- 선택 도구로 탭하면 선택합니다. 점이나 선을 드래그하면 이동하고, 빈 공간을 드래그하면 선택 창이 됩니다. 두 번째 탭은 {{ui:Add}}가 켜져 있지 않으면 선택을 바꿉니다(또는 두 번째 항목에서 손가락을 가만히 누르면 됩니다).
- 치수를 바꾸려면 오른쪽 패널에서 옆의 **편집**을 사용합니다.

**도면 시트에서**

기호를 탭하여 배치하고 선택하며, 기호를 드래그하여 옮깁니다. 핀치로 확대/축소하고, 두 손가락으로 초점을 이동하거나, 빈 종이 위를 한 손가락으로 드래그합니다. 두 번째 손가락을 대면 드래그하던 기호가 멈추고 원래 자리로 돌아갑니다.

**키보드가 필요한 것**

- 숫자 입력: 숫자 상자와 치수 입력란에서 화면 키보드가 나타납니다.
- 도구 단축키: 도구 모음을 사용하십시오.
:::

## 작은 화면과 휴대폰

- 1280픽셀 이상이면 도구 모음이 한 줄에 들어갑니다.
- 약 760~1100픽셀 사이에서는 옆 패널이 좁아집니다.
- 약 760픽셀 아래(휴대폰 또는 좁은 창)에서는 화면이 위에서 아래로 쌓입니다. 도구 모음(버튼을 더 보려면 옆으로 스와이프), 3D 뷰, 상태 표시줄, 그다음 속성 패널과 기록 순서입니다. 패널에 닿으려면 페이지를 스크롤하십시오.
- 메뉴({{ui:Export}}, {{ui:Views}})는 화면 너비 전체에 펼쳐집니다.

:::note
iPhone에서는 브라우저에 전체 화면 모드가 없습니다. {{key:Ctrl+Shift+F}}와 화면 모드 버튼은 일반 화면과 막대를 숨긴 화면 사이만 전환합니다.
:::

휴대폰은 파트를 열고 돌려 보고 정보를 확인하기에 충분합니다. 실제 모델링에는 더 큰 화면과 마우스 또는 트랙패드가 필요합니다.

## 브라우저

WebGL과 WebAssembly를 쓸 수 있는 한, 최신 Chrome, Edge, Firefox, Safari에서 PartCraft가 Windows, macOS, Linux, 태블릿, 휴대폰으로 동작합니다. [브라우저와 컴퓨터](common:browsers) 참고.
