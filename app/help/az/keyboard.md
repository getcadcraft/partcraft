Panelin qutusunda yazdığınız zaman düymələr işləmir, yalnız {{key:Mod+S}} və {{key:Mod+O}} istisnadır, onlar həmişə işləyir. Hərf düymələri dəyişdirici olmadan işləyir.

Brauzerdə və funksional düymələri olmayan klaviaturalarda düymələr haqqında ümumi qeydlər: [Düymələr, siçanlar və sensor panelləri](common:keys).

## Hər yerdə

| Düymə | Əməliyyat |
|---|---|
| {{key:Mod+S}} | Detalı saxla (yığımda: yığımı). Əvvəlcə açıq eskizi bağlayır |
| {{key:Mod+O}} | Detal və ya yığım faylını aç (saxlanmamış dəyişikliklər varsa əvvəlcə soruşur) |
| {{key:Mod+Z}} | {{ui:Geri qaytar}} |
| {{key:Mod+Y}} və ya {{key:Mod+Shift+Z}} | {{ui:Təkrarla}} |
| {{key:F1}} | Bu kömək səhifəsini aç və ya bağla (həmçinin tətbiq panelində {{ui:Kömək}}). {{key:Esc}} də bağlayır. Bir çox noutbuk və Mac klaviaturasında Fn düyməsini basılı saxlayın |
| {{key:Ctrl+Shift+F}} | Ekran rejimi: normal, tam ekran, panelləri gizlədilmiş tam ekran. Mac-da da Control, ⌘ deyil |
| {{key:Esc}} | Tam ekrandan çıx (tam ekranda olduqda) |
| {{key:Mod+,}} | {{ui:Parametrlər}}, PartCraft bölməsi daxil (bax: [PartCraft parametrləri](topic:settings)) |

Panelin rəqəm qutusunda {{key:Mod+Z}} brauzerin öz mətn geri qaytarmasıdır. Eskiz ölçüsünün üzərindəki rəqəm qutusunda isə PartCraft-da geri qaytarır.

## Kopyalama, yapışdırma və dublikat

Bunlar sizin işlədiyiniz yerə təsir edir: açıq eskizdə seçilmiş həndəsə, tarixçədə seçilmiş element və ya yığımda seçilmiş detal. Ətraflı: [Kopyalama, yapışdırma və dublikat](topic:copy-paste).

| Düymə | Əməliyyat |
|---|---|
| {{key:Mod+C}} | Seçimi kopyala |
| {{key:Mod+X}} | Kəs: əvvəl kopyala, sonra sil |
| {{key:Mod+V}} | Yapışdır. Eskizdə nüsxə göstərici ilə hərəkət edir: yerini klikləyin |
| {{key:Mod+Shift+V}} | Yerində yapışdır: eyni koordinatlarda (yığımda eyni yerdə) |
| {{key:Mod+D}} | Dublikat: bir addımda kopyala və yapışdır, buferə toxunmur |
| {{key:Mod+A}} | Hamısını seç (eskizdə) |
| {{key:Esc}} | Heç nə seçmə (və göstərici ilə hərəkət edən yapışdırmanı ləğv et) |

Rəqəm qutusunda bu düymələr mətni adi qaydada kopyalayır və yapışdırır. Paneldə seçilmiş mətn brauzer tərəfindən kopyalanır.

|---|---|

| {{key:F}} | Detalı görünüşə sığdır |
| {{key:M}} | Ölç, bütün iş sahələrində və yığımda; {{key:Esc}} seçimləri təmizləyir, yenidən {{key:Esc}} bağlayır (bax: [Məsafələri, bucaqları və kütləni ölç](topic:measure)) |
| {{key:X}} | Kəsik görünüşü açıq və ya bağlı, bütün iş sahələrində və yığımda; {{key:Esc}} bağlayır (bax: [Kəsik görünüşü ilə içəriyə bax](topic:section-view)) |
| {{key:Delete}} | Seçilmiş elementi sil (başqaları istifadə edirsə soruşur) |
| {{key:0}} … {{key:9}}, {{key:.}} | Element seçilmişkən: onun əsas rəqəmini yazın (ekstrüzyanın dərinliyi, deşiyin diametri, naxışın sayı, yuvarlaqlaşdırmanın radiusu …), sonra {{key:Enter}}. {{key:Esc}} köhnəsini saxlayır |
| {{key:Backspace}} | Seçilmiş elementi sil, əgər seçilibsə |
| {{key:Esc}} | Eskiz müstəvisini seçməyi dayandır və ya seçimi təmizlə ({{key:Shift}} ilə seçilmiş kənarlar və ya üzlər daxil) |

## 3D görünüşdə

Əvvəlcə görünüşün üzərinə klikləyin ki, klaviatura fokusu orada olsun.

| Düymə | Əməliyyat |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Görünüşü 15 dərəcə döndür |
| {{key:Shift+Left}} və digər oxlar | Sürüşdür |
| {{key:Plus}} və ya {{key:=}} | Miqyası artır |
| {{key:Minus}} | Miqyası azalt |

| Siçan | Əməliyyat |
|---|---|
| Sol düymə ilə sürüklə | Görünüşü fırlat (orbit) |
| Sağ və ya orta düymə ilə sürüklə | Sürüşdür |
| Sol düymə ilə sürüklərkən {{key:Shift}}, {{key:Ctrl}} və ya ⌘ basılı saxlayın | Sürüşdür |
| Təkəri fırladın | Göstərici yerində miqyas (sizdən uzağa fırladıqda böyüyür) |
| Sensor panelində iki barmaqla sürüşdürmə | Görünüşü döndür; {{key:Shift}} ilə sürüşdür. Sıxma miqyası dəyişdirir. [PartCraft parametrlərində](topic:settings) **Sürüşdürmə** ilə təyin olunur |

[PartCraft parametrlərində](topic:settings) **Görünüşün fırlanması: Orta düymə** seçilibsə, orta düymə görünüşü fırladır, {{key:Shift}} ilə orta düymə və ya sağ düymə sürüşdürür, sol düymə isə yalnız seçir.

| Klik | Üzü seç (tam işıqlanır), kənarı və ya müstəvini seç |
| {{key:Shift}}+klik kənar və ya üzdə | Bir neçə kənar və ya üz topla |
| Boş yerə klik | Seçimi təmizlə |

## Brauzerin ələ keçirə biləcəyi qısayollar

- Safari-də {{key:Mod+Y}} tarixçəni aça bilər: təkrarlamaq üçün {{key:Mod+Shift+Z}} istifadə edin.
- {{key:Mod+D}} brauzerin əlfəcin düyməsidir: PartCraft tətbiq fokusda olduqda onu götürür, qutuda yazdığınız zaman isə toxunmur.
- {{key:F11}} və {{key:Mod+Plus}} / {{key:Mod+Minus}} brauzerin tam ekran və səhifə miqyasıdır, PartCraft-ın deyil. Tam ekran üçün {{key:Ctrl+Shift+F}}, modeli miqyaslamaq üçün təkəri istifadə edin.
- Bir çox noutbuk və Mac-da funksional düymələr üçün Fn lazımdır: kömək üçün Fn+{{key:F1}} basın və ya {{ui:Kömək}} düyməsindən istifadə edin.

Toxunma və sensor panelinin jestləri: [Sensor paneli, toxunma və kiçik ekranlar](topic:trackpad-and-touch).

## Hərəkətin harada olduğu

Hərəkət **Elementlər** qrupunun {{ui:Daha çox}} menyusunda {{ui:Cismi köçür}} kimi, ΔX, ΔY və ΔZ yazdığınız {{ui:Hərəkət}} qutusunda və detal üzərində {{ui:Köçürmək üçün sürükləyin}} oxları kimi yerləşir.
