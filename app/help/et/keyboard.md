Klahvid ei tee midagi, kui kirjutad paneelis kasti, välja arvatud {{key:Mod+S}} ja {{key:Mod+O}}, mis töötavad alati. Tähtklahvid töötavad ilma muutjaklahvita.

Üldised märkused klahvide kohta brauseris ja klaviatuuridel ilma funktsiooniklahvideta: [Klahvid, hiired ja puuteplaadid](common:keys).

## Kõikjal

| Klahv | Toiming |
|---|---|
| {{key:Mod+S}} | Salvesta detail (koostes: koost). Sulgeb enne avatud visandi |
| {{key:Mod+O}} | Ava detaili- või koostefail (kui on salvestamata muudatusi, küsib enne) |
| {{key:Mod+Z}} | {{ui:Võta tagasi}} |
| {{key:Mod+Y}} või {{key:Mod+Shift+Z}} | {{ui:Tee uuesti}} |
| {{key:F1}} | Ava või sulge see abi (ka rakenduseribal {{ui:Abi}}). {{key:Esc}} sulgeb selle samuti. Paljudel sülearvutitel ja Maci klaviatuuridel hoia all Fn |
| {{key:Ctrl+Shift+F}} | Ekraanirežiim: tavaline, täisekraan, täisekraan peidetud ribadega. Mac-is Control, mitte ⌘ |
| {{key:Esc}} | Lahku täisekraanilt (kui oled täisekraanil) |
| {{key:Mod+,}} | {{ui:Sätted}}, sh PartCraft'i vahekaart (vt [PartCraft'i sätted](topic:settings)) |

Paneeli arvukastis on {{key:Mod+Z}} brauseri enda teksti tagasivõtmine. Visandi mõõdu kohal olevas arvukastis võtab see tagasi PartCraftis.

## Kopeerimine, kleepimine ja dubleerimine

Need toimivad selle järgi, millega parasjagu töötad: avatud visandi valitud geomeetria, ajaloos valitud element või koostes valitud detail. Üksikasjad: [Kopeerimine, kleepimine ja dubleerimine](topic:copy-paste).

| Klahv | Toiming |
|---|---|
| {{key:Mod+C}} | Kopeeri valik |
| {{key:Mod+X}} | Lõika: kopeeri ja kustuta |
| {{key:Mod+V}} | Kleebi. Visandis liigub koopia osutiga: kliki kohta, kuhu see läheb |
| {{key:Mod+Shift+V}} | Kleebi samasse kohta: samad koordinaadid (koostes samas asukohas) |
| {{key:Mod+D}} | Dubleeri: kopeeri ja kleebi ühe sammuga, lõikepuhver jääb puutumata |
| {{key:Mod+A}} | Vali kõik (visandis) |
| {{key:Esc}} | Tühista valik (ja katkesta osutiga liikuv kleepimine) |

Arvukastis kopeerivad ja kleebivad need klahvid teksti nagu tavaliselt. Paneelis valitud teksti kopeerib brauser.

## Detailil (visand pole avatud)

| Klahv | Toiming |
|---|---|
| {{key:S}} | Visand valitud tasandil või tasasel tahul; kui midagi pole valitud, vali koht klikkides |
| {{key:F}} | Sobita detail vaatesse |
| {{key:M}} | Mõõda igas tööruumis ja koostes; {{key:Esc}} tühjendab valimised, teine {{key:Esc}} sulgeb mõõtmise (vt [Mõõda kaugusi, nurki ja massi](topic:measure)) |
| {{key:X}} | Lõikevaade sisse või välja igas tööruumis ja koostes; {{key:Esc}} sulgeb selle (vt [Vaata lõikevaatega sisse](topic:section-view)) |
| {{key:Delete}} | Kustuta valitud element (küsib, kui teised seda kasutavad) |
| {{key:0}} … {{key:9}}, {{key:.}} | Elemendi valimisel: sisesta selle põhiarv (väljapressimise sügavus, augu läbimõõt, mustri arv, ümarduse raadius …) ja vajuta {{key:Enter}}. {{key:Esc}} jätab vana |
| {{key:Backspace}} | Kustuta valitud element, kui üks on valitud |
| {{key:Esc}} | Lõpeta visandi tasandi valimine või tühista valik (k.a {{key:Shift}}-ga valitud servad või tahud) |

| Hiir | Toiming |
|---|---|

## Otseteed, mida brauser võib enda jaoks võtta

- {{key:Mod+Y}} Safaris võib avada ajaloo: tee uuesti kasutamiseks {{key:Mod+Shift+Z}}.
- {{key:Mod+D}} on brauseri järjehoidja klahv: PartCraft võtab selle, kui rakendus on fookuses, ja jätab selle rahule, kui kirjutad kasti.
- {{key:F11}} ja {{key:Mod+Plus}} / {{key:Mod+Minus}} on brauseri täisekraan ja lehe suum, mitte PartCraft'i omad. Täisekraaniks kasuta {{key:Ctrl+Shift+F}}, mudeli suumimiseks ratast.
- Paljudel sülearvutitel ja Macidel vajavad funktsiooniklahvid klahvi Fn: abi jaoks vajuta Fn+{{key:F1}} või kasuta nuppu {{ui:Abi}}.

Puuteliigutused ja puuteplaat: [Puuteplaat, puudutus ja väikesed ekraanid](topic:trackpad-and-touch).

## Kus asub Teisalda

Teisalda asub elementide rühma menüüs {{ui:Veel}} nimega {{ui:Teisalda keha}}, kastis {{ui:Teisalda}}, kuhu kirjutad ΔX, ΔY ja ΔZ, ning detailil nooltena {{ui:Lohista teisaldamiseks}}.
