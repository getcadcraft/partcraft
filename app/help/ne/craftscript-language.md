CraftScript एउटा म्याट्रिक्स भाषा हो, जुन MATLAB जस्तै पढिने गरी लेखिएको छ, त्यसैले अधिकांश परम्परागत संख्यात्मक कोडहरू (जस्तै 88-लाइनको टोपोलजी अनुकूलन कोड) थोरै परिवर्तनसँग चल्छन्। यो [Script कार्यक्षेत्र](topic:craftscript) मा र कमाण्ड लाइनबाट चल्छ।

## मानहरू

| प्रकार | उदाहरण | टिप्पणी |
|---|---|---|
| संख्या, एरे | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | हरेक संख्या एउटा एरे हो (1×1 को)। एरेहरू स्तम्भ-स्तम्भ गरी भण्डारण हुन्छन्, 8 आयामसम्म |
| तार्किक | `A > 2`, `true` | true/false का एरेहरू; सूचकांकका रूपमा प्रयोग गर्न सकिन्छ |
| पाठ | `'beam'`, `"beam"` | |
| विरल म्याट्रिक्स | `sparse(i, j, v, n, n)` | कठोरता म्याट्रिक्सका लागि |
| जालो, क्षेत्र, मोडेल | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` ले के कोर्छ |
| स्ट्रक्ट | `s.E = 210e3` | नामित फिल्डहरू |
| सेल | `c = {1, 'two', [3 4]}` | जुनसुकै मानहरूको सूची |
| प्रकार्य ह्यान्डल | `f = @(x) x.^2` | |

## एरे र सूचीकरण

- दायरा: `1:5`, `0:0.1:1`। `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`।
- सूचीकरण 1 बाट सुरु हुन्छ: `A(2, 3)`, `v(end)`, `A(:, 1)` (एउटा पूरै स्तम्भ), `A(:)` (सबै एउटै स्तम्भका रूपमा), `v(v > 0)` (तार्किक सूचीकरण)।
- अन्त्यभन्दा बाहिर मान राख्दा MATLAB जस्तै एरे बढ्छ: `v(10) = 1`।

## अपरेटरहरू

- `+ - * / \ ^` म्याट्रिक्स क्रियाहरू हुन् (`A \ b` ले समाधान गर्छ); `.* ./ .^` ले तत्त्व-तत्त्वमा काम गर्छन्। `'` ले ट्रान्सपोज गर्छ।
- तुलनाहरू `== ~= < <= > >=`; तर्क `& | ~` (तत्त्व-तत्त्वमा) र `&& ||` (छोटो-सर्किट)।

## नियन्त्रण प्रवाह र प्रकार्यहरू

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

प्रकार्यहरू स्क्रिप्टमा आदेशहरूपछि राखिन्छन्, वा प्रकार्यकै नाम भएको आफ्नै स्क्रिप्ट ट्याबमा राखिन्छन्:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

नाम यस क्रममा खोजिन्छ: चर, यस भागमा त्यो नाम भएको स्क्रिप्ट, पुस्तकालय प्रकार्य, अनि अन्तर्निर्मित प्रकार्य।

## Echo, टिप्पणी, आउटपुट

- `;` नभएको कथनले यसको मान छाप्छ; `;` ले यसलाई चुप राख्छ।
- `%` ले टिप्पणी सुरु गर्छ; आफ्नै लाइनमा रहेका `%{` र `%}` ले तिनीहरूबीचका लाइनहरूलाई टिप्पणीमा राख्छन्।
- `disp(x)`, `fprintf('%g\n', x)` र `display(x)` ले कन्सोलमा छाप्छन्।

## त्रुटि र सीमाहरू

- त्रुटिहरूले के भयो सरल शब्दमा बताउँछन् र लाइन (र प्रकार्य कलहरूको शृंखला) दिन्छन्।
- हरेक रनको चरण बजेट हुन्छ (प्यानलमा Run options); अन्त नहुने लुप सन्देशसहित रोकिन्छ, वा रोक्नुहोस् थिच्नुहोस्।
- हरेक एरेले 134 million मानसम्म राख्न सक्छ।

## MATLAB जस्तो नभएको

- Plot आदेशहरूले आफ्ना विकल्पहरू कलभित्रै राख्छन्: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`। `figure`, `hold`, `axis`, `title(…)` र यस्तै अरू स्वीकार गरिन्छन्, तर तिनीहरूले केही गर्दैनन्।
- `input` र `keyboard` समर्थित छैनन्: स्क्रिप्ट प्रश्न सोध्न रोकिन सक्दैन।
- कुनै टुलबक्स छैनन्; [विश्लेषण पुस्तकालय](topic:craftscript-library) र अन्तर्निर्मित प्रकार्यहरू नै उपलब्ध छन्।
