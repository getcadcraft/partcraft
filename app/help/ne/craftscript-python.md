Python, [Script कार्यक्षेत्र](topic:craftscript) को तेस्रो भाषा हो। सम्पादकभन्दा माथिको भाषा बाकसमा **Python** छनौट गर्नुहोस् (`.py` फाइल आफैं Python मा खुल्छ)। Python, Lua र CraftScript ले उही चर र उही अन्तर्निर्मित प्रकार्यहरू साझा गर्छन्, त्यसैले Python स्क्रिप्टले CraftScript स्क्रिप्टले बनाएको कुरा प्रयोग गर्न सक्छ, र उल्टो पनि।

भ्रमणको पहिलो Python रनले यो साइटबाट Python आफैं (CPython 3.14, करिब 7 MB) लोड गर्छ, जसमा केही सेकेन्ड लाग्छ। Python अहिलेसम्म {{ui:Save for offline}} को भाग होइन: पहिले अनलाइन हुँदा एउटा Python स्क्रिप्ट चलाउनुहोस्।

## Python सिल गरिएको छ

Python स्क्रिप्टहरू CraftScript र Lua स्क्रिप्टजस्तै सिल गरिएका छन्: तिनीहरू भाग, चर र अन्तर्निर्मित प्रकार्यहरूमा मात्र पुग्छन्, अरू केही होइन। हरेक रन मेमोरीमा साना फाइल रूख भएको आफ्नै स्यान्डबक्समा नयाँ Python हो (यसको मानक पुस्तकालय र एउटा `/tmp` फोल्डर, जुन रनपछि हराउँछ)। यसले नेटवर्क, तपाईंका फाइल वा पृष्ठको बाँकी भागमा पुग्न सक्दैन, ब्राउजर र कमाण्ड लाइन दुवैमा। अरूको स्क्रिप्टले धेरै समय वा मेमोरी प्रयोग गर्न सक्छ: {{ui:Stop}} ले यसलाई अन्त्य गर्छ।

## आधारभूत कुराहरू

```
A = cs.magic(3)              # हरेक अन्तर्निर्मित प्रकार्य cs.<name> हो
B = A @ A.T                  # @ म्याट्रिक्स गुणन हो, .T ट्रान्सपोज
C = A * 2 + 1                # + - * / ** तत्त्व-तत्त्वमा हुन्छन्, numpy जस्तै
print(A[0, 1], A[-1, -1])    # 0 बाट सुरु; ऋणात्मकले अन्तबाट गन्छ
row = A[1]                   # म्याट्रिक्समा एउटा सूचकांक: एउटा पङ्क्ति
big = A[A > 4]               # तार्किक मास्कले तत्त्वहरू छान्छ
A[0, 0] = -5                 # एरेमा मान राख्दै
V, D = cs.call('eig', 2, A)  # धेरै नतिजा: cs.call(name, कति, …)
```

- 1 × 1 एरे सादा संख्याका रूपमा आउँछ; अरू एरे, विरल म्याट्रिक्स, जालो, क्षेत्र र मोडेलहरू **Values** हुन्।
- Value सँग `shape` (tuple), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (यसका पङ्क्तिहरू), र एउटा तत्त्वका लागि `float()`, `int()` र `bool()` छन्।
- तुलना (`<`, `==`, …) numpy जस्तै तत्त्व-तत्त्वमा हुन्छ: यसले तार्किक Value दिन्छ।
- अन्तर्निर्मित प्रकार्यलाई दिइएका संख्याका सूचीहरू एरे बन्छन्: `cs.sum([1, 2, 3])`। `cs.tensor([[1, 2], [3, 4]])` ले म्याट्रिक्स बनाउँछ।
- dict स्ट्रक्ट बन्छ, मिश्रित चीजहरूको सूची सेल बन्छ, र फेरि उल्टो।

तपाईंको स्क्रिप्टले बनाउने हरेक ग्लोबल (संख्या, Value, dict, सूची…) रन सक्दा **Variables** ट्याबमा पुग्छ, त्रुटि भए पनि। `_` बाट सुरु हुने नाम, प्रकार्य, क्लास र मोड्युल Python भित्रै रहन्छन्। `ws.name` ले चर सिधै पढ्छ वा सेट गर्छ, र `ws_names()` ले तिनीहरूको सूची दिन्छ।

`print(…)` ले कन्सोलमा लेख्छ। `display(…)` (वा `cs.display`) ले जालो, क्षेत्र वा प्लट देखाउँछ, CraftScript मा जस्तै।

## विश्लेषण पुस्तकालय कल गर्नुहोस्

पुस्तकालय प्रकार्यहरू अन्तर्निर्मित जस्तै कल गरिन्छन्: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`। स्क्रिप्टमा नाम जस्ताको तस्तै लेख्नुहोस्: PartCraft ले स्क्रिप्टले प्रयोग गर्ने पुस्तकालय प्रकार्यहरू चल्नुअघि नै खोज्छ।

## अहिलेसम्म नभएका कुराहरू

- numpy, scipy र अन्य प्याकेजहरू: यहाँ Python को आफ्नै मानक पुस्तकालय (`math`, `json`, `itertools`, `decimal`, `statistics`…) मात्र छ, यसका विन्डो, टर्मिनल र डाटाबेस भागहरू (`tkinter`, `curses`, `sqlite3`) बाहेक।
- सकेट र बाहिर पुग्ने अरू केही: यहाँ Python सँग नेटवर्क छैन।
- `time.sleep` ले तुरुन्तै फर्किन्छ।
- सम्पादकमा फोल्डिङ, र CraftScript स्क्रिप्टबाट Python प्रकार्य कल गर्ने।
- रनले हरेक 1000 लाइनमा निर्देशन बजेट र रोक्नुहोस् जाँच गर्छ; एउटा अन्तर्निर्मित प्रकार्यभित्रको लामो गणना पहिले सकिन्छ।
