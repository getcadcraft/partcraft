{{ui:Ekspor}}, lalu {{ui:Sebagai}} {{ui:File 3D interaktif (HTML, terbuka secara offline)}}, menyimpan satu file `.html`. Kirim lewat email, simpan di flashdisk atau folder bersama: file ini terbuka di peramban mana pun yang mendukung WebGL 2, di komputer, tablet, atau ponsel.

Di dalam file:

- Seret untuk memutar model, klik kanan lalu seret atau {{key:Shift}}+seret untuk menggeser, roda gulir atau cubit untuk zoom.
- Klik tampilan di daftar: kamera berpindah ke sana dan part mengambil posisi, tampilan visual, potongan, dan kaca pembesar tampilan tersebut.
- Klik baris daftar part untuk menyalakan part-nya; klik part untuk menyalakan barisnya.
- Jika manual memiliki animasi, bilah di bawah model memutarnya, menjedanya, dan menggeser ke bagian tertentu.

File ini memuat semua yang dibutuhkannya (model, penampil, dan three.js, di bawah lisensi MIT) dan melarang setiap permintaan: file tidak dapat mengakses internet, tidak memiliki akun, dan tidak melacak.

Model 3D interaktif di dalam PDF tidak disediakan: peramban dan sebagian besar pembaca PDF tidak dapat menampilkannya, dan pembaca yang bisa menampilkannya mematikannya secara default. File HTML adalah jawaban interaktifnya.
