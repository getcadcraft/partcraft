Pilih {{ui:Ekspor}} › {{ui:Paket USD (.usdz)}}.

- Di dalam part, file memuat solid part dengan material, volume, dan massanya.
- Di dalam rakitan, setiap part ditulis sekali dan setiap salinan ditempatkan sesuai posisi yang diberikan rakitan, sehingga file tetap kecil berapa pun jumlah salinannya.

PartCraft bekerja dalam milimeter dengan sumbu Y ke atas; file USD berada dalam meter dengan sumbu Z ke atas, seperti yang diharapkan kebanyakan program 3D.
