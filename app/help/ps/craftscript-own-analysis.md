په سکریپت کاري سیمه کې یو تحلیل یو څو لنډ سکریپتونه دي چې متغیرونه له یو بل سره لیږدوي. د [کتابتون](topic:craftscript-library) هغه دنده پیل کړئ چې ستاسو اړتیا ته نږدې وي، کاپي یې جوړه کړئ او بدلې یې کړئ؛ یا لاندې ډول له پیله جوړ کړئ.

## 1. یو مش

```
model = part();                  % هغه برخه چې ماډل کوئ، د ماډل په توګه
m = tetmesh(model, 4);           % څلور وجهې شاوخوا 4 mm پلنوالی
show(m)
```

مخکې له دې چې ادامه ورکړئ، مش په لید کې چک کړئ: {{key:F}} یې برابروي، د **ښودل شوي** په {{ui:سترګه}} برخه پټوي.

## 2. جوړول او حل

د عنصر حلقه په سکریپت کې ولیکئ (لکه درسي کتاب چې لولي)، او درنې برخې داخلي دندو ته پرېږدئ: د عنصر میټریکسونه، د درې ګونو څخه تنک جوړول، او د preconditioner سره conjugate gradient حل کوونکی. یوه کتابتون دنده لکه `static_tet` (کله چې کتابتون یې ولري) د کاپي کولو لپاره بشپړه بېلګه ده.

## 3. پایله وښایاست

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % په هر نوډ یو ارزښت
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- د legend حد کېدای شي ولیکل شي یا {{ui:اتوماتیک}} ته بیرته وګرځول شي.
- په مش کلیک وکړئ ترڅو د یوه نوډ ارزښتونه ولولئ.
- هغه پلات چې ورته `'id'` ساتي، په ځای کې تازه کېږي، نو په خپله حلقه کې چاپ او پلات وکړئ ترڅو یکجایېدل وګورئ.

## 4. یې چک کړئ

د یو څه سره پرتله کړئ چې پوهېږئ: د کانټیلیور سر ځړېدنه د PL³/3EI په مقابل کې، سوري پلېټ د هغه د فشار تمرکز فاکتور په مقابل کې، عکس العملونه د بارونو په مقابل کې. چک د خپل سکریپت په توګه ولیکئ ترڅو د هرې بدلون وروسته بیا وچلېږي:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. ساتل

- هر ګام کولی شي د خپل سکریپت ټب وي: دوی متغیرونه شریکوي، نو یو په بل پسې یې وچلوئ.
- سکریپتونه په برخه کې ساتل کېږي. په **متغیرونه** ټب کې **د برخې سره متغیرونه خوندي کول** غوره کړئ ترڅو پایلې هم وساتئ (تر 32 MB پورې).
- د سکریپت ګروپ کې {{ui:خوندي کول}} یو سکریپت ډاونلوډ کوي ترڅو شریک کړئ؛ {{ui:پرانیستل}} یې راوړي.
