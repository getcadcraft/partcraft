Python د [سکریپت کاري سیمې](topic:craftscript) دریمه ژبه ده. د مدیر پورته په ژبې ساحه کې **Python** وټاکئ (یوه `.py` فایل په خپله په Python کې پرانیستل کېږي). Python، Lua او CraftScript ورته متغیرونه او ورته داخلي دندې شریکوي، نو د Python سکریپت هغه څه کارولای شي چې د CraftScript سکریپت یې جوړ کړي، او برعکس.

لومړی Python چلښت په یوه لیدنه کې Python ځان (CPython 3.14، شاوخوا 7 MB) له دې سایټ څخه پورته کوي، چې څو ثانیې نیسي. Python لا د {{ui:افلاین لپاره خوندي کول}} برخه نه ده: لومړی د انټرنېټ پر مهال یو Python سکریپت وچلوئ.

## Python بند شوی دی

Python سکریپتونه د CraftScript او Lua سکریپتونو په څیر بند ساتل شوي دي: دوی برخې، متغیرونو او داخلي دندو ته رسېږي، او بل هېڅ نه. هر چلښت یوه تازه Python په خپل sandbox کې دی د حافظې کې د کوچني فایل ونې سره (د دې معیاري کتابتون او یو `/tmp` پوښ چې د چلښت وروسته ورک کېږي). دا شبکې، ستاسو فایلونو یا د پاڼې نورو برخو ته نشي رسېدلی، په براوزر او کمانډ کرښه دواړو کې. د بل چا سکریپت لاهم ډېر وخت یا حافظه کارولای شي: {{ui:ودرول}} یې پای ته رسوي.

## اساسات

```
A = cs.magic(3)              # هره داخلي دنده cs.<name> ده
B = A @ A.T                  # @ د میټریکس ضرب دی، .T ټرانسپوز
C = A * 2 + 1                # + - * / ** عنصر په عنصر دي، لکه numpy کې
print(A[0, 1], A[-1, -1])    # له 0 څخه؛ منفي له پای څخه شمېرل کېږي
row = A[1]                   # په میټریکس یو شاخص: یو قطار
big = A[A > 4]               # منطقي ماسک عنصرونه غوره کوي
A[0, 0] = -5                 # په سرۍ کې ارزښت ورکول
V, D = cs.call('eig', 2, A)  # څو پایلې: cs.call(name, څو، …)
```

- 1 × 1 سرۍ د ساده عدد په توګه راځي؛ نورې سرۍ، تنک میټریکسونه، مشونه، ساحې او ماډلونه **ارزښتونه** دي.
- یو Value لري `shape` (ټپل)، `T`، `type`، `numel()`، `copy()`، `tolist()`، `len()` (د هغه قطارونه)، او `float()`، `int()` او `bool()` د یو عنصر لپاره.
- پرتلې (`<`، `==`، …) عنصر په عنصر دي، لکه numpy کې: منطقي Value ورکوي.
- د عددونو لیستونه چې داخلي دندو ته لیږل کېږي سرۍ کېږي: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` یو میټریکس جوړوي.
- یو dict جوړښت کېږي او د مختلفو شیانو لیست حجره کېږي، او بیا بیرته.

هر عمومي شی چې ستاسو سکریپت جوړوي (یو عدد، یو Value، یو dict، یو لیست…) کله چې چلښت پای ته ورسېږي، حتی د تېروتنې وروسته هم، په **متغیرونه** ټب کې راځي. د `_` سره پیل شوي نومونه، دندې، ټولګي او ماډلونه په Python کې پاتې کېږي. `ws.name` یو متغیر مستقیم لولي یا ټاکي، او `ws_names()` یې لیست کوي.

`print(…)` کنسول ته لیکي. `display(…)` (یا `cs.display`) مش، ساحه یا پلات ښيي، لکه په CraftScript کې.

## د تحلیل کتابتون بلل

د کتابتون دندې لکه داخلي دندې بلل کېږي: `cs.box_mesh(20, 10, 10, 5, 'hex')`، `cs.call('modal_tet', 2, …)`. نوم په سکریپت کې همداسې ولیکئ لکه څنګه چې دی: PartCraft د سکریپت د چلېدو دمخه هغه د کتابتون دندې موندي چې سکریپت یې کاروي.

## لا نشته

- numpy، scipy او نور بستې: یوازې د Python خپل معیاري کتابتون (`math`، `json`، `itertools`، `decimal`، `statistics`…) دی، پرته له هغه کړکۍ، ترمینل او ډیټابیس برخو څخه (`tkinter`، `curses`، `sqlite3`).
- Sockets او هر څه چې بهر ته رسېږي: دلته Python شبکه نه لري.
- `time.sleep` سمدلاسه بېرته راګرځي.
- پټول (folding) په مدیر کې، او د CraftScript سکریپت څخه د Python دندې بلل.
- هر چلښت هر 1000 کرښو کې د لارښود بودجه او ودرول چک کوي؛ په یوه داخلي دنده کې اوږده محاسبه لومړی بشپړېږي.
