## به څه کوئ

**د یوې پرزې هر اندازه په یو ځل کې ورکړئ**: د هر ترتیب لپاره یو STEP، IFC او DWG فایل او یو انځور، یو جدول چې وایي هر یو څه دی، او د کتابتون یو توکی چې ټول په یوه پاڼه کې ږدي.

لومړی تاسو ته یوه پرزه د **ترتیبونو** سره ته اړتیا ده (وګورئ [ترتیبونه او د ډیزاین جدولونه](topic:design-tables)). هغه ترتیب چې یوه ځانګړتیا بندوي، لکه یو پلیټ د سورو سره او بې سورو، خپل متغیر کېږي.

## ګامونه

1. پرزه خلاص کړئ. د {{ui:Parameters}} ټب کې **ترتیبونه** ومومئ.
2. {{ui:Variant pack…}} کلیک کړئ.
3. هغه ترتیبونه نښه کړئ چې جوړ یې کړئ (ټول نښه دي) او هغه فایلونه: STEP، IFC، DWG، مخکتنه او د کتابتون توکی.
4. {{ui:Make the pack}} کلیک کړئ. د حالت کرښه متغیرونه شمېري څو چې جوړېږي؛ ستاسو پرزه نه بدلېږي.
5. یوه زپ ډاونلوډېږي: `<part> variants.zip`.

## په زپ کې څه دي

| فایل | څه دی |
|---|---|
| `<name>.step` | ترتیب د STEP جامد په توګه. |
| `<name>.ifc` | IFC4، یو عنصر چې جوړ شوی بدن او د پرزې پارامترونه د ملکیتونو په توګه لري؛ ارزښت د هماغه ترتیب خپل دی. |
| `<name>.dwg` | مخ، سر، ښي او آیسومیټریک لیدونه د نقشې پاڼې په توګه، په بشپړ اندازه. |
| `<name>.svg` | د هغه آیسومیټریک خطي انځور. |
| `variants.csv`، `variants.json` | د پارامترونو جدول: د هر متغیر ID، نوم او د هر پارامتر ارزښت، هغه ځانګړتیاوې چې بندوي، فایلونه، حجم او ابعاد. |
| `<part>.item.json` | پرزه د کتابتون یو توکی د خپلو متغیرونو سره (لاندې وګورئ). |
| `README.txt` | څه جوړ شو، لاندې یادښتونه، او هر هغه څه چې نه وو جوړ شوي. |

فایلونه د ترتیب په نوم نومول کېږي. هغه ترتیب چې نه جوړېږي (ځانګړتیا چې په هغو ارزښتونو نشي جوړېدای) له فایلونو او جدول څخه ایستل کېږي، په README کې او د زپ له خوندي کېدو وروسته په پیغام کې لیست کېږي؛ نور لاهم لیکل کېږي.

## ښه ده چې وپوهېږئ

- **STEP** دقیق دی کله چې دقیق کرنل ستاسو په جوړښت کې فعال وي. پرته له دې STEP فاسیټ شوی دی (مسطح مثلثونه) او README دا وايي.
- **DWG** د نقشې پاڼه ده، نه 3D ماډل. د هغې کرښې له مش راځي، نو منحني کنډه ډېرې لنډې کرښې دي.
- **د کتابتون توکی** په هر متغیر کې یو بدن او یو پلان لري، د کتابتون د خپلو محورونو پر بنسټ: Z پورته، مخ د −Y لور ته، او د داخلولو ټکی د شا منځ کې په ښکته اړخ. پلان د هر متغیر بند مستطیل دی. توکی تر 8 MB پورې محدود دی، نو ډېر دروند متغیر د خپل اندازې بکس کېږي او README وایي چې څو دي.
- د پرزې فعال ترتیب د توکي تلپاتې متغیر دی.
- پورټونه (د نل او د هوا نل د نښلولو ټکي) له PartCraft څخه نه ټاکل کېږي.

## متغیرونه په کتابتون کې د پاڼې په توګه ږدئ

`<part>.item.json` په سایټ کې **کتابتون › پورته کول** کې پورته کړئ. کټګوري، جواز او خپل د کریډیټ کرښه وټاکئ، او دا د متغیرونو سره د کتابتون یو توکی کېږي. په BimCraft کې، ایښودل پوښتي چې کوم متغیر، او Swap نور وړاندې کوي. هغه پاڼه چې لیدونکي اختیارونه غوره کوي، 3D وویني او متغیر ډاونلوډ کړي اوس **د کارکوونکو مخکتنه** ده: تراوسه عامه ته نه ده خلاصه.

## د کمانډ کرښې څخه

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` د ترتیبونو نومونه ټاکي، `--formats` کې هر یو له `step`، `ifc`، `dwg`، `preview`، `--no-item` د کتابتون توکی له منځه وړي. یوه فولډر، زپ یا دواړه لیکي او 1 کوډ سره وځي کله چې یو متغیر نشي جوړېدای. وګورئ [سکریپتونه او د کمانډ کرښه](topic:scripts-and-cli).
