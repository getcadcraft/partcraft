کله چې تاسو د پینل په یوه بکس کې لیکئ، کیلي هېڅ کار نه کوي، پرته له {{key:Mod+S}} او {{key:Mod+O}} څخه، چې تل کار کوي. د لیکونو کیلي د بدلوونکي کیلي پرته کار کوي.

د براؤزر او د فنکشن کیلیو نه لرونکو کیبورډونو په اړه عمومي یادښتونه: [کیلي، موږکونه او ټچ پیډونه](common:keys).

## هرځای

| کیلي | عمل |
|---|---|
| {{key:Mod+S}} | پرزه خوندي کول (په اسمبلي کې: اسمبلي). لومړی پرانیستل شوی سکېچ بندوي |
| {{key:Mod+O}} | د پرزې یا اسمبلي فایل پرانیستل (که خوندي نه شوي بدلونونه وي، لومړی پوښتنه کوي) |
| {{key:Mod+Z}} | بېرته کول |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | بیا کول |
| {{key:F1}} | دا مرسته پرانیستل یا بندول (همدارنګه د اپلیکیشن په بار کې {{ui:مرسته}}). {{key:Esc}} هم بندوي. په ډیرو لپټاپونو او Mac کیبورډونو کې، Fn ونیسئ |
| {{key:Ctrl+Shift+F}} | د سکرین حالت: عادي، بشپړ سکرین، یا بشپړ سکرین د بارونو پټولو سره. په Mac کې هم Control، نه ⌘ |
| {{key:Esc}} | د بشپړ سکرین څخه وتل (کله چې بشپړ سکرین وي) |
| {{key:Mod+,}} | {{ui:امستنې}}، پشمول د PartCraft ټب (وګورئ [د PartCraft امستنې](topic:settings)) |

د پینل د شمېرې په بکس کې، {{key:Mod+Z}} د براؤزر خپل د متن بېرته کول دی. د سکېچ د اندازې پر شمېرې بکس کې، دا په PartCraft کې بېرته کوي.

## کاپي، سرېښول او نقل

دا په هغه څه عمل کوي چې تاسو پرې کار کوئ: په پرانیستل شوي سکېچ کې ټاکل شوې جیومېټري، په تاریخچه کې ټاکل شوې ځانګړتیا، یا په اسمبلي کې ټاکل شوې پرزه. تفصیل په [کاپي، سرېښول او نقل](topic:copy-paste) کې دی.

| کیلي | عمل |
|---|---|
| {{key:Mod+C}} | ټاکل شوی کاپي کول |
| {{key:Mod+X}} | پرې کول: کاپي کول، بیا ړنګول |
| {{key:Mod+V}} | سرېښول. په سکېچ کې کاپي د پوینټر تعقیبوي: هغه ځای کلیک کړئ چیرې چې باید لاړ شي |
| {{key:Mod+Shift+V}} | په ځای کې سرېښول: ورته همغږي (په اسمبلي کې، ورته ځای) |
| {{key:Mod+D}} | نقل: کاپي او سرېښول په یو ګام کې، د کلیپبورډ پرېښودل |
| {{key:Mod+A}} | ټول ټاکل (په سکېچ کې) |
| {{key:Esc}} | هېڅ مه ټاکئ (او هغه سرېښول لغوه کړئ چې د پوینټر تعقیب کوي) |

د شمېرې په بکس کې، دې کیلیو متن په معمول ډول کاپي او سرېښي. په پینل کې ټاکل شوی متن د براؤزر لخوا کاپي کېږي.

## پر پرزه (هېڅ سکېچ نه وي پرانیستل شوی)

| کیلي | عمل |
|---|---|
| {{key:S}} | په ټاکل شوې سطحه یا هوار مخ کې سکېچ؛ که هېڅ ونه ټاکل شي، کلیک کولو سره ځای وټاکئ |
| {{key:F}} | پرزه په لید کې برابرول |
| {{key:M}} | اندازه کول، په هرې کاري ساحه او اسمبلي کې؛ {{key:Esc}} ټاکنې پاکوي، بیا {{key:Esc}} یې بندوي (وګورئ [واټنونه، زاویې او کتله اندازه کول](topic:measure)) |
| {{key:X}} | د برخې لید پرانیستل یا بندول، په هرې کاري ساحه او اسمبلي کې؛ {{key:Esc}} یې بندوي (وګورئ [د برخې لید سره دننه وګورئ](topic:section-view)) |
| {{key:Delete}} | ټاکل شوې ځانګړتیا ړنګول (که نور یې کاروي، پوښتنه کوي) |
| {{key:0}} … {{key:9}}، {{key:.}} | کله چې یوه ځانګړتیا ټاکل شوې وي: د هغې اصلي شمېره ولیکئ (د Extrude ژوروالی، د Hole قطر، د pattern شمېر، د fillet شعاع …)، بیا {{key:Enter}}. {{key:Esc}} زوړه شمېره ساتي |
| {{key:Backspace}} | ټاکل شوې ځانګړتیا ړنګول، کله چې یوه ټاکل شوې وي |
| {{key:Esc}} | د سکېچ سطحه ټاکل بندول، یا ټاکنه پاکول (په شمول د هغو څنډو یا مخونو چې {{key:Shift}} سره ټاکل شوي) |

## په 3D لید کې

لومړی په لید کې کلیک وکړئ ترڅو د کیبورډ تمرکز ولري.

| کیلي | عمل |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | لید 15 درجې وګرځوئ |
| {{key:Shift+Left}} او نور تیرونه | لید خوځول |
| {{key:Plus}} یا {{key:=}} | زوم زیاتول |
| {{key:Minus}} | زوم کمول |

| موږک | عمل |
|---|---|
| په کیڼه تڼۍ کش | لید چرخول (ګرځول) |
| په ښۍ یا منځنۍ تڼۍ کش | لید خوځول |
| {{key:Shift}}، {{key:Ctrl}} یا ⌘ ونیسئ کله چې په کیڼه تڼۍ کش کوئ | لید خوځول |
| د موږک څرخ وګرځوئ | د پوینټر پر ځای زوم (له تاسو لرې ځي = زوم زیاتوي) |
| په ټچ پیډ کې دوه ګوتو سوایپ | لید وګرځوئ؛ د {{key:Shift}} سره لید خوځوئ. پنچ زوم کوي. د [PartCraft امستنو](topic:settings) کې د **سکرول** له مخې ټاکل کېږي |

د [PartCraft امستنو](topic:settings) کې د **د لید ګرځول: منځنۍ تڼۍ** سره، منځنۍ تڼۍ لید ګرځوي، {{key:Shift}} له منځنۍ یا ښۍ تڼۍ سره لید خوځوي، او کیڼه تڼۍ یوازې ټاکي.
| کلیک | یو مخ ټاکئ (ټول رنګ کېږي)، یوه څنډه یا یوه سطحه |
| {{key:Shift}}+کلیک په څنډه یا مخ | ډېرې څنډې یا مخونه راټولول |
| په تشه ځای کلیک | ټاکنه پاکول |

## هغه شارټ کټونه چې براؤزر ممکن واخلي

- په Safari کې {{key:Mod+Y}} ممکن تاریخچه پرانیزي: د بیا کولو لپاره {{key:Mod+Shift+Z}} وکاروئ.
- {{key:Mod+D}} د براؤزر د بوکمارک کیلي ده: PartCraft هغه هغه وخت اخلي چې اپلیکیشن تمرکز ولري، او کله چې په بکس کې لیکئ، پرېږدي.
- {{key:F11}} او {{key:Mod+Plus}} / {{key:Mod+Minus}} د براؤزر بشپړ سکرین او د مخ زوم دي، نه د PartCraft. د بشپړ سکرین لپاره {{key:Ctrl+Shift+F}} وکاروئ او د ماډل لپاره د موږک څرخ.
- د ډېرو لپټاپونو او Mac کیبورډونو فنکشن کیلي Fn ته اړتیا لري: د مرستې لپاره Fn+{{key:F1}} وکېکاږئ، یا د {{ui:مرسته}} تڼۍ وکاروئ.

د ټچ او ټچ پیډ اشارې: [ټچ پیډ، ټچ او کوچني سکرینونه](topic:trackpad-and-touch).

## لېږدول چیرې دی
