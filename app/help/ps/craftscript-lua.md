Lua د [سکریپت کاري سیمې](topic:craftscript) دویمه ژبه ده. د مدیر پورته په ژبې ساحه کې **Lua** وټاکئ (یوه `.lua` فایل په خپله په Lua کې پرانیستل کېږي). Lua او CraftScript ورته متغیرونه او ورته داخلي دندې شریکوي، نو د Lua سکریپت هغه څه کارولای شي چې د CraftScript سکریپت یې جوړ کړي، او برعکس.

## اساسات

```
-- هره داخلي دنده د cs جدول کې ده
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- د 1 څخه پیلېږي، لکه CraftScript
print(K(1, 1), #K)             -- یو عنصر؛ د عنصرونو شمېر
-- کاري سیمه: ورته متغیرونه چې هر سکریپت ګوري
ws.total = K(1, 1) * 2
print(ws.total)
-- له یوې دندې څو پایلې
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` هره داخلي دنده بولي او لومړۍ پایله بېرته راګرځوي؛ `cs.call(name, n, …)` `n` پایلې بېرته راګرځوي.
- `cs.tensor({1, 2, 3})` یوه قطار جوړوي، `cs.tensor({{1, 2}, {3, 4}})` یو میټریکس.
- سرۍ، تنک میټریکسونه، مشونه او ساحې د میتودونو سره ارزښتونه دي: `t(i, j)` یا `t:get(i, j)`، `t:set(i, j, v)`، `t:shape()`، `#t`، `t:T()` (ټرانسپوز)، `t:totable()`. `+ - * / ^` هغه معنا لري چې په CraftScript کې یې لري (`*` د میټریکس ضرب دی)؛ `t:times(u)` عنصر په عنصر ضرب کوي.
- هغه عدد چې 1×1 سرۍ وي، د ساده Lua عدد په توګه راځي.
- `ws.name` شریکه کاري سیمه لولي او لیکي. هغه عمومي متغیرونه چې ستاسو سکریپت پریږدي، کله چې پای ته ورسېږي هم هلته راځي.
- `print(…)` کنسول ته لیکي؛ `cs.show(f)`، `cs.plot(y)` او نور ښودونکي دندې لکه په CraftScript کې کار کوي.

## د تحلیل کتابتون بلل

د تحلیل کتابتون دندې (د کتابتون ټب) او هغه CraftScript دندې چې د برخې خپل سکریپتونه یې تعریفوي، هم د `cs` له لارې لاسرسی کېږي:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- دوه پایلې
```

دا دندې د سکریپت له پیل دمخه موندل کېږي، نو نوم په سکریپت کې ولیکئ: `cs.static_tet(` یا `cs.call('static_tet', …)`. هغه نوم چې د سکریپت په چلښت کې جوړېږي، یوازې داخلي دندو ته رسېږي. هغه جوړښت چې د `cs.struct({ … })` په واسطه جوړ شوی، د CraftScript جوړښت دی، او د هغو Lua لیست (`{ cs.struct(…), … }`) یو حجره ده، چې د کتابتون امستنې یې غواړي. که د کتابتون دندې دننه ستونزه رامنځته شي، پیغام دندې نوم او کرښه ښيي، او ستاسو هغه کرښې ته اشاره کوي چې دا یې بللې.

## بند شوي

سکریپتونه فایلونو، شبکې یا پاڼې ته رسېدلی نشي: `io`، `os` (پرته له ساعت څخه)، `require`، `dofile`، `loadfile` او `debug` لرې شوي دي. د سکریپت کاري سیمې پرانیستل او متغیرونه وکاروئ ترڅو معلومات راولئ. د ګامونو بودجه او ودرول هم د CraftScript په شان کار کوي.
