تولیدونکی یو عادي سکریپټ دی ([CraftScript](topic:craftscript)، Lua یا Python) چې په سر کې یو څو تبصره کرښې لري. PartCraft تبصرې لولي او فورمه جوړوي؛ ستاسو سکریپټ ورودي د مخکې ټاکل شوو متغیرونو په توګه لولي.

## سرلیک

دا کرښې د تبصرې په توګه ولیکئ (CraftScript کې `%`، Lua کې `--`، Python کې `#`):

```
% @generator د تودوخې بدلون ورکوونکی
% @input mdot: kg/s = 0.2 [0.01 .. 10] "د ډله جریان"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "سطحه"
% @input solid: = true
% @input note: = "متن"
```

ورودی دا ډول ده: `name: unit = default`، بیا که غواړئ یوه لړۍ `[min .. max]` (شمېرې پکې ساتل کېږي)، د انتخابونو لیست `{a, b, c}` او په متنو کې یو لیبل. واحد یوازې د فورمې لپاره لیبل دی: **ارزښت په همدې واحد راځي**، نو هغه سکریپټ چې SI غواړي باید یې بدل کړي، او `to_si(value, 'kg/s', 'kg/s')` هم کتنه کوي چې واحد هغه څه معنا لري چې تاسو یې فکر کوئ. نوم د توریو، شمېرو او ټیټ خط څخه جوړ وي؛ `body`، `sheet` او `problems` ساتل شوي دي.

## سکریپټ څه پرېږدي

| متغیر | څه |
|---|---|
| `body` | **اړین.** د سطحې مش، عموماً له `[body, info] = to_body(field, h)` څخه. کله چې چلند پای ته ورسیږي، ترمیمېږي او کتنه کېږي. |
| `sheet` | اختیاري. یو ساختار: هره ساحه یو شمېره یا متن، یا ساختار چې `value`، `unit`، `ref` او `note` لري. دا د معلوماتو پاڼه جوړوي. |
| `problems` | اختیاري. د `mfg_check(field, 'sls', struct(), h)` څخه `problems` حجره، یا ستاسو خپلې ننوتې. دا کتنو او د ستونزو لیست ته ځي. |

## یوه بشپړه کوچنۍ بیلګه

```
% یو تش مکعب د دېوال سره.
% @generator تش مکعب
% @input side: mm = 12 [4 .. 40] "اړخ"
% @input wall: mm = 1.5 [0.5 .. 5] "دېوال"
% @input h: mm = 0.5 [0.25 .. 2] "د وکسل اندازه"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'د مش');
```

دا یو تړل شوی مکعب جوړوي، او کتنه یې د دننه تړل شوي ځای د پودر پروسې لپاره تېروتنه راپوروي. د وکسل اندازه `h` دې د تر ټولو نازک دېوال درېیمه برخه ونه شي: له شاوخوا درېو وکسلو کم دېوال باوري نه دی.

## ساحې

دا ساحې شتون لري: `field_sphere`، `field_box`، `field_capsule`، `field_cylinder`، `field_torus`، `field_revolve` (د پروفایل څخه د دوران جامد)، `tpms` (gyroid، Schwarz P او diamond سطحې، د حجرې اندازه او دېوال چې د برخې په اوږدو کې بدلېدای شي)، `lattice` او `lattice_beams`، `along` (ګرد کانال د لارې په اوږدو کې)، بولین عملیات `field_union`، `field_intersect`، `field_subtract`، نرم `field_blend`، او `field_offset`، `field_shell`، `field_move`، `field_rotate`، `field_scale`. `sample(f, points)` په ټکو کې نږدې فاصله ورکوي (منفي دننه)، `field_voxel` د حلونکو لپاره وکسلونه ورکوي. [ساحې](topic:fields) توضیح کوي چې دا څه دي.

د پوهېدو وړ حدونه: که د پاڼې دېوال له حجرې شاوخوا څلورمې برخې څخه ستر وي، کانالونه تړي؛ هغه ځانګړتیا چې له شاوخوا درېو وکسلو نازکه وي ټینګېدای شي؛ `along` ګرد مخروطونه نښلوي، نو که شعاع ژر بدله شي یو پړسوب پاتې کېږي (د پروفایل لپاره `field_revolve` وکاروئ).

## سکریپټ د تولیدونکي په توګه پرانیستل

په {{ui:Engineer}} کاري ساحه کې {{ui:Open}} کېکاږئ او دوسیه وټاکئ. هغه سکریپټ چې `@generator` یا `@input` کرښه نه لري رد کېږي: د ټاکلو لپاره به هېڅ نه وي. تولیدونکی په همدې براوزر کې ساتل کېږي (تر ۲۰ پورې) او {{ui:Remove}} یې ړنګوي. هغه بدن چې له دې څخه پیل شوی وي د سکریپټ کاپي لري، نو برخه له دې پورې نه تړل کېږي.

یوه دوسیه کېدای شي څو تولیدونکي هم ولري: JSON بنډل `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
