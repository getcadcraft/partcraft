ورته اوزار لاره باید د مختلفو کنټرولونو لپاره بېلې ولیکل شي: د کرښو شمېرې یا هېڅ، `M6` یا مکث، `G28` یا `G53`، `M30` یا `M2`. **پوست** لنډ متن دی چې وایې څنګه. د PartCraft درې بلټ‑ان پوستونه (Fanuc‑style، GRBL او LinuxCNC) په همدې بڼه لیکل شوي، نو ستاسو خپل پوست کیدای شي د یو له هغو د کاپي څخه پیل شي.

د پرې کولو دمخه د خپل ماشین خپل سمولاتور کې محصول وګورئ، او لومړی یې د خام توکو پورته په هوا کې وچلوئ. بلټ‑ان پوستونه هغه ولیکل چې دا بڼه له مخه نه وه شتون درلودونکې (ازموینې یې د سلګونو پروګرامونو په اړه بایټ په بایټ پرتله کوي)، خو دلته هېڅ شی ستاسو په ماشین کې ثابت شوی نه دی، او هغه پوست چې بدلوئ، د ثابتولو مسؤولیت ستاسو دی.

## یو جوړ کړئ

په Manufacture کې، د **Post** لاندې:

- په بلټ‑ان کنټرول کې {{ui:Edit post…}} ستاسو **خپل کاپي** پرانیزي. په خپل یو پوست کې دا همغه پوست پرانیزي.
- {{ui:New post…}} د یوه لنډ خالي پوست څخه پیل کوي چې ټولې پېښې په کې دي.
- {{ui:Import post file…}} د `.cpost` متن فایل لولي (هغه فایل چې د مدیر کې **په فایل کې خوندي کول…** څخه ترلاسه کوئ).

مدیر متن ښيي، یوه کرښه چې وايي آیا لوستل کېږي (او کومه کرښه غلطه ده)، او هغه G-code چې پوست یې لیکي، ستاسو د ټایپ کولو سره. **په دې سره مخکتنه** یو کوچنی نمونه پروګرام ټاکي چې ټولې پېښې چلوي، یا د دې برخې خپل پروګرام. {{ui:Save}} پوست د برخې په فایل کې ساتي (تر 20 پوستونو پورې) او کنټرول په توګه یې ټاکي. پوستونه له برخې سره ځي؛ د بلې برخې لپاره یې وکاروئ، فایل کې یې خوندي کړئ او هلته یې وارد کړئ.

## پوست څنګه ښکاري

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

هغه کرښې چې په `//` پیلېږي او خالي کرښې له پامه غورځول کېږي. په پیل کې امستنې راځي؛ بیا د هرې پېښې لپاره یو `on <event>` بلاک، چې په `end` بندېږي. هغه پېښه چې پرېږدئ هېڅ نه لیکي.

| امستنه | مانا |
|---|---|
| `post <id>` | د پوست پېژندنه: توري، عددونه، `-` او `_` |
| `name <text>` | هغه څه چې د کنټرول لیست ښيي |
| `extension <ext>` | د فایل توسیع: nc، ngc، tap … |
| `line-numbers 10` / `off` | `N10`، `N20` … په هره `emit` کرښه کې، یا هېڅ |
| `decimal-point yes` / `no` | `10.` د `10` پر ځای (تبصره هېڅکله نقطه نه لري) |
| `canned-cycles yes` / `no` | `no`: سوري د G0/G1 هغو حرکتونو په توګه لیکل کېږي چې استازیتوب یې کوي |
| `modal <group> <words>` | د یوې ډلې کلمې (`modal motion G0 G1 G2 G3`) چې یوازې هغه وخت لیکل کېږي کله چې بدلېږي |

## پېښې

دوی د پروګرام لپاره په دې ترتیب چلېږي: `start`؛ بیا د هرې عملیې لپاره `operation`، `tool-change` (کله چې اوزار بدلېږي)، `spindle` (کله چې سرعت بدلېږي)، `approach` (حرکت تر لومړي ټکي پورې، د لومړي `rapid` دمخه)، `coolant-on`، بیا د هغې حرکتونه د `rapid`، `feed` او `arc` په توګه، او هر canned cycle د `cycle-start` په توګه، لکه هر سوري لپاره یو `cycle-hole` او `cycle-end`؛ په پای کې `end`.

هره پېښه کیدای شي د خپل ډول حرکت متغیرات وکاروي، لیکل شوي `{name}`: د پروګرام (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`)، خام توکي (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`)، اوزار (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`)، عملیه (`op.name`, `op.type`)، `rpm`، د حرکت ټکی (`x`, `y`, `z`, `f`، او `moved`: true کله چې محور بدل شي)، کمانونه (`arc.g` 2 یا 3، `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) او سوري (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). د مدیر **Events and variables** لیست ښيي چې کومه پېښه کوم ګوري. حالت چې لوستل او ټاکل کېږي: `cool`, `offset`، او `at.x`, `at.y`, `at.z`, `at.f` (وروستي ارزښتونه چې لیکل شوي).

## بیانونه

| بیان | څه کوي |
|---|---|
| `raw TEXT` | یوه کرښه لکه څنګه چې ټایپ شوې (بې د کرښې شمېرې) |
| `comment TEXT` | `(TEXT)` د غیر ASCII توکو او قوسونو له لرې کولو سره |
| `emit WORD WORD …` | د کلمو کرښه؛ هغه کلمې چې خالي راځي پرېښودل کېږي؛ کلمې نه وي، کرښه نه وي |
| `word WORD …` | کلمې په جوړېدونکې کرښه کې اضافه کوي؛ یوازینی `emit` یې پای ته رسوي |
| `if EXPR` … `else` … `end` | شرطونه: `a == b`، `a != b`، `not a`، `a and b`، `a or b`، `a??b` (a، که نه b) |
| `for tool in tools` … `end` | د هر اوزار لپاره یو ځل چې پروګرام یې کاروي |
| `set NAME EXPR` | یو ارزښت یادوي (`set offset tool.number`) |
| `reset NAME …` | حالت کلمې هېروي (یوه ډله، د پته توری لکه `Z`، یا `at.z`) |
| `do rapid X Y Z` | د یوه ټکي لپاره `rapid` پېښه چلوي |

کلمه هغه ټایپ شوی متن دی چې `{variable|filter}` سوري لري. فلټرونه دا دي: `upper`، `lower`، `pad:N` (صفر ډکول)، `cut:N` (لومړي N توکي)، `safe` (تبصره‌خوندي ASCII) او `int`. کلمه چې په `~` پای ته رسي **modal** ده: یوازې هغه وخت لیکل کېږي کله چې د وروستي لیکل شوي څخه توپیر ولري (`G1~`، `X{x}~`). کلمه چې په `~!` پای ته رسي هر وخت لیکل کېږي او بیا هم یادېږي. نوم چې متغیر نه وي ساده متن دی (`G81`، `mist`). عددونه 0.001 mm ته ګرد کېږي او بې له وروستيو صفرونو لیکل کېږي.

## پوست څه نه شي کولی

دا یوازې ټاکي چې حرکتونه څنګه لیکل کېږي، نور هېڅ. نشي کولی د اوزار لاره بدله کړي، عملیې ترتیب کړي، کمان وېشي، محور زیات کړي، د ماشین ځای یا کینیمټیکس وپېژني، یا په همغږو حساب وکړي (`+` نشته). Probing، د اوزار ژوند او د فرعي پروګرام چرخې، د 4 مه او 5 مه محور محصول، او د لیت کوډونه جوړ شوي نه دي. د بل پروګرام `.cps` ډول پوست فایل نشي پورته کېدای: دا بل، ساده بڼه ده.
