ورته اوزار لاره باید د مختلفو کنټرولونو لپاره بېلې ولیکل شي: د کرښو شمېرې یا هېڅ، `M6` یا مکث، `G28` یا `G53`، `M30` یا `M2`. **پوست** هغه لنډ متن دی چې وایي څنګه. د PartCraft درې جوړ شوي پوستونه (Fanuc ډول، GRBL او LinuxCNC) په همدې فارمټ لیکل شوي، نو ستاسو خپل پوست کېدای شي د یوه کاپي څخه پیل شي.

مخکې له پرې کولو محصول د خپل ماشین په خپل سیمولیټر کې وګورئ، او لومړی یې په هوا کې د خام توکي پورته وچلوئ. جوړ شوي پوستونه هغه لیکي چې مخکې له دې فارمټ لیکل کېدل (ازمونې یې د ستون سلګونو پروګرامونو په بایټ-بایټ پرتله کوي)، مګر دلته هېڅ شی ستاسو په ماشین کې ثابت شوی نه دی، او هغه پوست چې تاسو یې بدلوئ ستاسو دی چې ثابت یې کړئ.

## یو جوړ کړئ

په تولید کې، لاندې **پوست**:

- {{ui:پوست سمول…}} په جوړ شوي کنټرول کې **ستاسو خپل کاپي** خلاصوي. په یو له خپلو پوستونو کې دا هغه پوست خلاصوي.
- {{ui:نوی پوست…}} د لنډ خالي پوست څخه پیلېږي چې هر پېښه پکې ده.
- {{ui:د پوست فایل واردول…}} د `.cpost` متني فایل لولي (فایل چې تاسو یې د مدیر څخه **په فایل کې وساتئ…** لاندې ترلاسه کوئ).

مدیر متن ښيي، یوه کرښه چې وایي آیا دا لولي (او کومه کرښه غلطه ده)، او هغه G-code چې پوست یې لیکي، کله چې تاسو ټایپ کوئ. **د ښودنې لاره** یو کوچنی نمونه پروګرام ټاکي چې هر پېښه چلوي، یا د دې برخې خپل پروګرام. {{ui:خوندي کول}} پوست د برخې په فایل کې ساتي (تر 20 پوستونو پورې) او هغه د کنټرول په توګه ټاکي. پوستونه د برخې سره سفر کوي؛ د بلې برخې لپاره یې وکاروئ، هغه د فایل په توګه وساتئ او بل ځای کې یې واردول کړئ.

## پوست څنګه ښکاري

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

هغه کرښې چې په `//` پیلېږي او خالي کرښې له پامه غورځول کېږي. په پیل کې امستنې راځي؛ بیا د هر **`on <event>`** بلاک د `end` سره تړل شوی. هغه پېښه چې پرېږدئ هېڅ نه لیکي.

| امستنه | معنا |
|---|---|
| `post <id>` | د پوست پیژندونکی: توري، شمېرې، `-` او `_` |
| `name <text>` | هغه څه چې د کنټرول لیست ښيي |
| `extension <ext>` | د فایل پسوند: nc، ngc، tap … |
| `line-numbers 10` / `off` | `N10`، `N20` … په هر `emit` کرښه، یا هېڅ |
| `decimal-point yes` / `no` | `10.` پرځای `10` (تبصرې هېڅکله ټکی نه لري) |
| `canned-cycles yes` / `no` | `no`: سوري د G0/G1 حرکتونو په توګه لیکل کېږي چې استازیتوب کوي |
| `modal <group> <words>` | د یوې ډلې کلمې (`modal motion G0 G1 G2 G3`) چې یوازې کله بدلېږي لیکل کېږي |

## پېښې

دوی د یوې برخې لپاره په دې ترتیب کې چلېږي: `start`؛ بیا د هر عملیات لپاره `operation`، `tool-change` (کله چې اوزار بدلېږي)، `spindle` (کله چې سرعت بدلېږي)، `approach` (حرکت لومړي ټکي ته، مخکې له لومړي چټک حرکت)، `coolant-on`، بیا د هغې حرکتونه د `rapid`، `feed` او `arc` په توګه، او هر ثابت سایکل د `cycle-start` په توګه، یو `cycle-hole` د هر سوری لپاره او `cycle-end`؛ په پای کې `end`.

د هغه څه لپاره چې له درې محورونو تېرېږي، نورې پېښې (پوست پرته له دې پېښې دا پروګرام رد کوي او نومونه یې کوي چې کومه پېښه نه لري):

| پېښه | کله | د هغې متغیرونه |
|---|---|---|
| `index` | مخکې له عملیات چې د اوزار لوری یې د تېرې څخه بېل وي، او مخکې له لومړي عملیات په ماشین کې د دوراني محورونو سره | `rot.a`، `rot.b`، `rot.c` (هغه ځایونه چې ورځو؛ خالي د هغه محور لپاره چې ماشین نه لري)، `first.x`، `first.y`، `first.z` |
| `rapid-rotary`، `feed-rotary` | حرکتونه د یوه عملیات چې دوراني محورونه یې حرکت کوي پرې کولو پر مهال | `x`، `y`، `z`، `rot.a`، `rot.b`، `rot.c`، `f`، `rot.moved`، `inverse` (هو کله چې تغذیه باید معکوس وخت وي)، `invf` (1/دقیقې) |
| `rotary-end` | وروسته له داسې عملیات | |
| `probe-move` | یو حرکت چې ودریږي کله چې سپړونکی ولوېږي | `x`، `y`، `z`، `f`، `probe.n` (1 تر 4)، `probe.axis` (x، y یا z)، `probe.k` (1، 2 یا 3) |
| `probe-set` | وروسته له لمس د یوې سپړنې چکر | `probe.kind` (`"z"`، `"x"`، `"y"` یا `centre`)، `probe.action` (`set` یا `measure`)، `probe.expect`، `probe.cx`، `probe.cy` |
| `thread` | د تار حرکت په خرادي ماشین کې | `x`، `z`، `thread.lead` |

په هر پېښه کې هم: `kin` (none، a، b، ac، bc)، `rotary` او `tcp` (yes یا no، له ماشین څخه په امستنه کې)، `pivot.x`، `pivot.y`، `pivot.z`، د عملیات `op.tilt` او `op.turn`، او په خرادي ماشین کې `spin.mode` (css یا rpm)، `spin.css`، `spin.max` او `tool.nose`. یو توری کلمه چې ارزښت یې خالي دی، لکه `A{rot.a}` په ماشین کې چې A محور نه لري، له کرښې څخه پاتې کېږي. د x، y او z سره د متن په توګه په متنو کې پرتله کړئ (`if probe.kind == "z"`): بې له دې، دوی د حرکت همغږي دي.

د پوست پیل کې دوه نورې کرښې یې د خرادي پوست جوړوي: `machine lathe` (دا یوازې X او Z لیکي، او د ماشینکاري لارو څخه انکار کوي لکه څنګه چې د ماشینکاري پوست د خرادي لارو څخه انکار کوي) او `lathe-x diameter` یا `lathe-x radius`.

هر پېښه کولی شي د خپل ډول د حرکت متغیرونه وکاروي، په `{name}` ډول لیکل شوي: د پروګرام (`name`، `program`، `setup.axis`، `setup.origin`، `setup.coolant`)، خام توکی (`stock.kind`، `stock.d`، `stock.sx`، `stock.sy`، `stock.sz`، `stock.minx` … `stock.maxz`)، اوزار (`tool.number`، `tool.desc`، `tool.kind`، `tool.d`، `tool.flutes`، `tool.fluteLen`)، عملیات (`op.name`، `op.type`)، `rpm`، د حرکت ټکی (`x`، `y`، `z`، `f`، او `moved`: ریښتیا کله چې محور بدل شي)، کمانونه (`arc.g` 2 یا 3، `arc.i`، `arc.j`، `arc.cx`، `arc.cy`) او سوري (`hole.x`، `hole.y`، `hole.z`، `hole.r`، `hole.q`، `hole.return`، `hole.first`، `cycle.kind`، `cycle.init`، `feed`). د مدیر **پېښې او متغیرونه** لیست ښيي چې کومه پېښه کوم ګوري. هغه حالت چې لوستل او ټاکل کېږي: `cool`، `offset`، او `at.x`، `at.y`، `at.z`، `at.f` (وروستي ارزښتونه لیکل شوي).

## جملې

| جمله | څه کوي |
|---|---|
| `raw TEXT` | یوه کرښه لکه څنګه چې ټایپ شوې (پرته له کرښې شمېرې) |
| `comment TEXT` | `(TEXT)` د غیر ASCII او قوسونو له لرې کولو سره |
| `emit WORD WORD …` | د کلمو کرښه؛ هغه کلمې چې خالي راځي له پامه غورځول کېږي؛ هېڅ کلمه نه، هېڅ کرښه نه |
| `word WORD …` | کلمې د جوړېدونکې کرښې ته زیاتوي؛ یو ساده `emit` کرښه پای ته رسوي |
| `if EXPR` … `else` … `end` | شرطونه: `a == b`، `a != b`، `not a`، `a and b`، `a or b`، `a??b` (a، که نه b) |
| `for tool in tools` … `end` | یو ځل د هرې اوزار لپاره چې پروګرام کاروي |
| `set NAME EXPR` | یو ارزښت یاد ساتي (`set offset tool.number`) |
| `reset NAME …` | ماډل کلمې هېروي (یوه ډله، د پته توری لکه `Z`، یا `at.z`) |
| `do rapid X Y Z` | د یوې ټکي لپاره `rapid` پېښه چلوي |

یوه کلمه متن دی چې د `{variable|filter}` سوري لري. فلټرونه دا دي: `upper`، `lower`، `pad:N` (صفر ډکول)، `cut:N` (لومړي N توري)، `safe` (تبصرې-خوندي ASCII) او `int`. کلمه چې په `~` ختمېږي **ماډل** ده: یوازې هغه وخت لیکل کېږي کله چې له وروستي لیکل شوي څخه توپیر ولري (`G1~`، `X{x}~`). کلمه چې په `~!` ختمېږي هر وخت لیکل کېږي او بیا هم یادېږي. هغه نوم چې متغیر نه وي ساده متن دی (`G81`، `mist`). شمېرې 0.001 mm ته ګرډ کېږي او بې له وروستي صفرونو لیکل کېږي.

## پوست څه نشي کولی

دا یوازې ټاکي چې حرکتونه څنګه لیکل کېږي، نور هېڅ نه. دا نشي کولی اوزار لاره بدله کړي، پېښې تقسیم کړي، کمان ووېشي، محور زیات کړي، ستاسو ماشین حدود یا کینیمټیک پیژني، یا په همغږیو حساب وکړي (`+` نشته). دورانې ځایونه له هغه ماشین څخه راځي چې په امستنه کې تشریح شوی، نه له پوست څخه: یو پوست کولی شي د دوی نښه یا توري بدل کړي، نه کینیمټیک. د اوزار ژوند او فرعي پروګرام سایکلونه شتون نه لري. د بل پروګرام `.cps` ډول پوست فایل نشي پورته کېدای: دا بل، ساده فارمټ دی.
