CraftScript یوه میټریکس ژبه ده چې د MATLAB په څیر لوستل کېږي، نو ډېری کلاسیک عددي کوډونه (د مثال په توګه د 88 کرښو توپولوژي اصلاح کوونکی کوډ) یوازې لږ بدلونونو سره چلېږي. دا په [سکریپت کاري سیمه](topic:craftscript) کې او د کمانډ کرښې څخه چلېږي.

## ارزښتونه

| ډول | بېلګه | یادونه |
|---|---|---|
| عدد، سرۍ | `a = 3`، `v = [1 2 3]`، `A = [1 2; 3 4]` | هر عدد یوه سرۍ ده (یوه 1×1 سرۍ). سرۍ ستون په ستون ذخیره کېږي، تر 8 ابعادو پورې |
| منطقي | `A > 2`، `true` | د true/false سرۍ؛ د شاخص په توګه کارېدای شي |
| متن | `'beam'`، `"beam"` | |
| تنک میټریکس | `sparse(i, j, v, n, n)` | د سختۍ میټریکسونو لپاره |
| مش، ساحه، ماډل | `hexGrid(…)`، `part()`، `load('part.stl')` | هغه څه چې `show` یې ښيي |
| جوړښت | `s.E = 210e3` | نومېدلې ساحې |
| حجره | `c = {1, 'two', [3 4]}` | د هر ډول ارزښتونو لیست |
| د دندې لاس | `f = @(x) x.^2` | |

## سرۍ او شاخص کول

- حدود: `1:5`، `0:0.1:1`. `linspace(a, b, n)`، `zeros(n, m)`، `ones`، `eye`، `rand`.
- شاخص کول له 1 څخه پیلېږي: `A(2, 3)`، `v(end)`، `A(:, 1)` (ټوله ستون)، `A(:)` (هرڅه د یوه ستون په توګه)، `v(v > 0)` (منطقي شاخص کول).
- د وروستي ځای څخه وروسته ارزښت ورکول سرۍ پراخوي، لکه په MATLAB کې: `v(10) = 1`.

## عملګرې

- `+ - * / \ ^` د میټریکس عملیات دي (`A \ b` حل کوي)؛ `.* ./ .^` عنصر په عنصر کار کوي. `'` ټرانسپوز کوي.
- پرتلې `== ~= < <= > >=`؛ منطق `& | ~` (عنصر په عنصر) او `&& ||` (لنډ لاره).

## د کنټرول جریان او دندې

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

دندې د سکریپت کې د خپلو امرونو وروسته، یا د دندې په نوم خپل سکریپت ټب کې ځای پرځای کېږي:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

نوم په دې ترتیب کې لټول کېږي: متغیر، د دې برخې هغه سکریپت چې په همدې نوم وي، د کتابتون دنده، بیا د داخلي دنده.

## Echo، تبصرې او پایله

- یو جمله چې `;` نه لري خپل ارزښت چاپوي؛ `;` یې چوپ ساتي.
- `%` تبصره پیلوي؛ `%{` او `%}` چې په خپلو کرښو کې وي، د دې دواړو ترمنځ کرښې تبصره کوي.
- `disp(x)`، `fprintf('%g\n', x)` او `display(x)` کنسول ته چاپ کوي.

## تېروتنې او حدونه

- تېروتنې په ساده ټکو ښيي چې څه ستونزه وه، او کرښه ښيي (او د دندو د بللو لړۍ هم).
- هر چلښت د ګامونو بودجه لري (د پینل د چلولو اختیارونه)؛ نه پای ته رسېدونکی حلقه په پیغام درېږي، یا {{ui:ودرول}} ته فشار ورکړئ.
- هره سرۍ تر 134 میلیونه ارزښتونو پورې ساتي.

## د MATLAB په څیر نه دي

- د پلات امرونه خپلې اختیارونه په بللو کې ږدي: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`، `hold`، `axis`، `title(…)` او ورته امرونه منل کېږي، خو هېڅ نه کوي.
- `input` او `keyboard` نه ملاتېږي: سکریپت نشي درېدای چې پوښتنه وکړي.
- د ځانګړو بستو (toolbox) نشته؛ یوازې [د تحلیل کتابتون](topic:craftscript-library) او داخلي دندې شته.
