Lua забони дуввуми [фазои скрипт](topic:craftscript) аст. **Lua**-ро дар қуттаи забон дар боло аз муҳаррир интихоб кунед (файли `.lua` худаш бо Lua кушода мешавад). Lua ва CraftScript тағйирёбандаҳо ва функсияҳои дарунсохти якхаларо истифода мебаранд, аз ин рӯ скрипти Lua метавонад он чиро, ки скрипти CraftScript сохтааст, истифода барад ва баръакс.

## Асосҳо

```
-- ҳар функсияи дарунсохт дар ҷадвали cs аст
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- аз 1, мисли CraftScript
print(K(1, 1), #K)             -- як унсур; шумораи унсурҳо

-- фазо: ҳамон тағйирёбандаҳо, ки ҳар скрипт мебинад
ws.total = K(1, 1) * 2
print(ws.total)

-- якчанд натиҷа аз як функсия
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` ҳар функсияи дарунсохтро даъват мекунад ва натиҷаи аввалинаашро бармегардонад; `cs.call(name, n, …)` `n` натиҷа бармегардонад.
- `cs.tensor({1, 2, 3})` сатр, `cs.tensor({{1, 2}, {3, 4}})` матритса месозад.
- Массивҳо, матритсаҳои сийрак, тӯрҳо ва майдонҳо арзишҳо бо усулҳо мебошанд: `t(i, j)` ё `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (транспонирование), `t:totable()`. `+ - * / ^` маънои худро мисли CraftScript доранд (`*` ҳосили матритсавӣ аст); `t:times(u)` поэлементӣ зарб мекунад.
- Ададе, ки массиви 1×1 аст, ҳамчун адади оддии Lua меояд.
- `ws.name` фазои муштаракро хонда ва навишта мегирад. Тағйирёбандаҳои глобалие, ки скрипт бақия мегузорад, низ ҳангоми анҷом ба он меафтанд.
- `print(…)` ба консол менависад; `cs.show(f)`, `cs.plot(y)` ва дигар функсияҳои намоиш мисли CraftScript кор мекунанд.

## Китобхонаи таҳлилро даъват кунед

Функсияҳои китобхонаи таҳлил (варақаи **Китобхона**) ва функсияҳои CraftScript, ки скриптҳои худи детали шумо муайян мекунанд, низ тавассути `cs` дастрасанд:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- ду натиҷа
```

Онҳо пеш аз оғози скрипт ёфта мешаванд, пас номро дар скрипт бинависед: `cs.static_tet(` ё `cs.call('static_tet', …)`. Номе, ки ҳангоми иҷрои скрипт сохта мешавад, танҳо ба функсияҳои дарунсохт мерасад. Структуре, ки бо `cs.struct({ … })` сохта мешавад, структураи CraftScript аст, ва рӯйхати Lua-и онҳо (`{ cs.struct(…), … }`) ячейка аст, ки танзимоти китобхона талаб мекунад. Агар дар дохили функсияи китобхона чизе хато кунад, паём номи функсия ва сатри онро мегӯяд ва сатри шуморо нишон медиҳад, ки онро даъват кардааст.

## Хомӯшшуда

Скриптҳо ба файлҳо, шабака ва саҳифа дастрасӣ надоранд: `io`, `os` (ба ғайр аз соат), `require`, `dofile`, `loadfile` ва `debug` хориҷ шудаанд. Барои ворид кардани маълумот аз **Кушодан**-и фазои скрипт ва тағйирёбандаҳо истифода баред. Буҷаи қадамҳо ва **Қатъ кардан** мисли CraftScript кор мекунанд.
