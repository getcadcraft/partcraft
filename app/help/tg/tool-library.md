Варақаи **Абзорҳо** дар Manufacture абзорҳои деталро нишон медиҳад. Дар зери **Китобхонаи абзорҳо** шумо метавонед абзорҳои худро берун аз як деталь нигоҳ доред:

- {{ui:Ин асбобро захира кардан}} абзори интихобшударо ба **Абзорҳои захирашудаи ман** илова мекунад; {{ui:Ҳамаи абзорҳои ин деталро захира кардан}} ҳамаашонро илова мекунад. Абзорҳои захирашудаи ман дар ин браузер нигоҳ дошта мешаванд ва барои ҳар деталь мавҷуданд. Абзори аллакай захирашуда (ҳамон навъ, андоза, канорҳо ва иваздиҳиҳо) дубора захира намешавад.
- {{ui:Ба ин деталь илова кардан}} абзори захирашудаи интихобшударо ба деталь мегузорад. Агар рақами T-и он аллакай аз абзори дигар дар деталь истифода шавад, ба рақами озоди навбатӣ мегирад ва панел онро мегӯяд. {{ui:Аз китобхонаи ман хориҷ кардан}} онро аз рӯйхати захирашуда тоза мекунад (на аз деталҳое, ки онро аллакай доранд).
- {{ui:Содироти абзорҳо…}} абзорҳои деталро ҳамчун файли `.json` менависад; {{ui:Воридоти абзорҳо…}} абзорҳои чунин файлро бо ҳамон қоидаҳо ба деталь илова мекунад (абзори аллакай мавҷуда партофта мешавад, рақами T-и банд ҷойивазкунӣ мешавад). Файл андоза, канорҳо, маводҳо ва иваздиҳиҳои фид ва суръатро, ки шумо нависедаед, дар бар мегирад; id надорад. Онро барои интиқоли абзорҳои дӯкон ба компютери дигар ё додан ба ҳамкор истифода баред.

Агар браузер китобхонаро нигоҳ надорад (захира хомӯш ё пур аст), захира ин гуфта мешавад ва **Содироти абзорҳо** роҳи нигоҳ доштани файл аст. Файл бояд китобхонаи абзорҳои PartCraft аз ин версия ё кӯҳна бошад, на бештар аз 500 абзор бо андозаҳои дуруст; ҳар чизи дигар бо сабаб рад карда мешавад.

Суръатҳои бурида ва чипҳо, ки бо абзор меоянд, нуқтаҳои оғоз мебошанд; [Сохтани роҳҳои ҳаракат ва G-code](topic:manufacture)-ро бинед.
