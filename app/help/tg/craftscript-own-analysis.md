Таҳлил дар фазои скрипт якчанд скрипти кӯтоҳ аст, ки тағйирёбандаҳоро ба ҳам медиҳанд. Аз функсияи [китобхона](topic:craftscript-library), ки ба чизи лозима наздик аст, оғоз кунед, нусха гиред ва тағйир диҳед; ё мисли зер якҷоя созед.

## 1. Тӯр

```
model = part();                  % детале, ки моделсозӣ мекунед, ҳамчун модел
m = tetmesh(model, 4);           % тетраэдрҳо тақрибан 4 mm бузург
show(m)
```

Пеш аз идома тӯрро дар намуд санҷед: {{key:F}} онро мувофиқ мекунад, {{ui:чашм}}-и дар **Намоишшуда** детални ро пинҳон мекунад.

## 2. Ҷамъ ва ҳал кунед

Ҳалқаи элементҳоро дар скрипт нависед (он мисли китоби дарсӣ хонда мешавад), ва қисмҳои вазнинро ба функсияҳои дарунсохт вогузоред: матритсаҳои элементҳо, ҷамъкунии сийрак аз сегонаҳо, ва ҳалкунандаи градиентии коньюгатӣ бо прекондитсионер. Функсияи китобхона мисли `static_tet` (вақте ки китобхона онро дорад) мисоли пурра барои нусхабардорист.

## 3. Натиҷаро нишон диҳед

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % як арзиш барои ҳар гиреҳ
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Қолдиқи ҳалкунанда', 'id', 'conv')
```

- Диапазони легенда метавонад дастӣ дохил карда шавад ё ба {{ui:Худкор}} баргардонда шавад.
- Барои хондани арзишҳо дар гиреҳ тӯрро клик кунед.
- Графике, ки ҳамон `'id'`-ро нигоҳ медорад, дар ҷояш навсозӣ мешавад, пас дар ҳалқаи худ чоп ва график кунед, то конвергенсияро бинед.

## 4. Санҷед

Бо чизе, ки медонед, муқоиса кунед: печиши нӯғи балкаи пешбаранда бо PL³/3EI, лавҳаи сӯрохдор бо коэффитсиенти консентратсияи фишораш, вокунишҳо бо борҳо. Санҷишро ҳамчун скрипти алоҳида нависед, то пас аз ҳар тағйир дубора иҷро шавад:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('нӯг %g mm, назарияи балка %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Нигоҳ доред

- Ҳар қадам метавонад варақаи скрипти худ дошта бошад: онҳо тағйирёбандаҳоро мубодила мекунанд, пас онҳоро пай дар пай иҷро кунед.
- Скриптҳо дар детал захира мешаванд. Барои нигоҳ доштани натиҷаҳо низ **Тағйирёбандаҳоро бо детал захира кардан**-ро дар варақаи **Тағйирёбандаҳо** интихоб кунед (то 32 MB).
- {{ui:Захира кардан}} дар гурӯҳи Скрипт скриптро барои мубодила зеркашӣ мекунад; {{ui:Кушодан}} онро ворид мекунад.
