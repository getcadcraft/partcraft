Python забони сеюми [фазои скрипт](topic:craftscript) аст. **Python**-ро дар қуттаи забон дар боло аз муҳаррир интихоб кунед (файли `.py` худаш бо Python кушода мешавад). Python, Lua ва CraftScript тағйирёбандаҳо ва функсияҳои дарунсохти якхаларо истифода мебаранд, аз ин рӯ скрипти Python метавонад он чиро, ки скрипти CraftScript сохтааст, истифода барад ва баръакс.

Аввалин иҷрои Python дар як боздид худи Python-ро (CPython 3.14, тақрибан 7 MB) аз ин сайт бор мекунад, ки чанд сония вақт мегирад. Python то ҳол дар {{ui:Захира барои офлайн}} нест: аввал як скрипти Python-ро дар ҳолати онлайн иҷро кунед.

## Python ҷудошуда аст

Скриптҳои Python мисли скриптҳои CraftScript ва Lua ҷудо шудаанд: онҳо ба детал, тағйирёбандаҳо ва функсияҳои дарунсохт мерасанд ва дигар чизро не. Ҳар иҷро Python-и нав аст дар қуттии худ бо дарахти хурди файлҳо дар хотира (китобхонаи стандартии он ва папкаи `/tmp`, ки пас аз иҷро нест мешавад). Он ба шабака, файлҳои шумо ва боқимондаи саҳифа дастрасӣ надорад, ҳам дар браузер ва ҳам дар хатти фармон. Скрипте аз шахси дигар бошад ҳам, метавонад вақт ё хотираи зиёд гирад: {{ui:Қатъ кардан}} онро хотима медиҳад.

## Асосҳо

```
A = cs.magic(3)              # ҳар функсияи дарунсохт cs.<name> аст
B = A @ A.T                  # @ ҳосили матритсавӣ, .T транспонирование
C = A * 2 + 1                # + - * / ** поэлементӣ, мисли numpy
print(A[0, 1], A[-1, -1])    # аз 0; манфӣ аз охир шумурда мешавад
row = A[1]                   # як индекс ба матритса: сатр
big = A[A > 4]               # ниқоби мантиқӣ унсурҳоро интихоб мекунад
A[0, 0] = -5                 # таъйин ба массив
V, D = cs.call('eig', 2, A)  # якчанд натиҷа: cs.call(name, чанд, …)
```

- Массиви 1 × 1 ҳамчун адади оддӣ меояд; массивҳои дигар, матритсаҳои сийрак, тӯрҳо, майдонҳо ва моделҳо **Арзишҳо** мебошанд.
- Арзиш `shape` (кортеж), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (сатрҳояш) дорад, ва `float()`, `int()` ва `bool()` барои як унсур.
- Муқоисаҳо (`<`, `==`, …) мисли numpy поэлементӣ мебошанд: арзиши мантиқӣ медиҳанд.
- Рӯйхати ададҳо, ки ба функсияи дарунсохт дода мешавад, массив мешавад: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` матритса месозад.
- Dict структура мешавад ва рӯйхати чизҳои аралаш ячейка, ва баръакс.

Ҳар глобале, ки скрипти шумо месозад (адад, Арзиш, dict, рӯйхат…), ҳангоми анҷоми иҷро ба варақаи **Тағйирёбандаҳо** меафтад, ҳатто пас аз хато. Номҳое, ки бо `_` оғоз мешаванд, функсияҳо, синфҳо ва модулҳо дар Python мемонанд. `ws.name` тағйирёбандаро бевосита мехонад ё таъйин мекунад, ва `ws_names()` онҳоро номбар мекунад.

`print(…)` ба консол менависад. `display(…)` (ё `cs.display`) тӯр, майдон ё графикро нишон медиҳад, мисли CraftScript.

## Китобхонаи таҳлилро даъват кунед

Функсияҳои китобхона мисли дарунсохт даъват мешаванд: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. Номро дар скрипт ҳамон тавр, ки ҳаст, нависед: PartCraft пеш аз иҷро функсияҳои китобхонаеро, ки скрипт истифода мебарад, меёбад.

## Ҳоло нест

- numpy, scipy ва дигар бастаҳо: танҳо китобхонаи стандартии худи Python (`math`, `json`, `itertools`, `decimal`, `statistics`…) ҳаст, бе қисмҳои тиреза, терминал ва пойгоҳи додаҳо (`tkinter`, `curses`, `sqlite3`).
- Сокетҳо ва ҳар чизи дигаре, ки ба беруна мерасад: Python дар ин ҷо шабака надорад.
- `time.sleep` фавран бармегардад.
- Пинҳон кардани блокҳо дар муҳаррир ва даъвати функсияи Python аз скрипти CraftScript.
- Иҷро буҷаи дастурҳо ва Қатъ кардан-ро ҳар 1000 сатр месанҷад; ҳисоби дароз дар дохили як функсияи дарунсохт аввал анҷом меёбад.
