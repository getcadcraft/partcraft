CraftScript — забони матритсавӣ, ки монанди MATLAB навишта шудааст, то ки аксари рамзҳои классикии ададӣ (масалан, рамзи оптимизатсияи топологияи 88-сатрӣ) бо тағйироти хурд кор кунанд. Он дар [фазои скрипт](topic:craftscript) ва аз хатти фармон кор мекунад.

## Арзишҳо

| Навъ | Мисол | Шарҳ |
|---|---|---|
| Адад, массив | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Ҳар адад массив аст (1×1). Массивҳо сутун-ба-сутун нигоҳ дошта мешаванд, то 8 андоза |
| Мантиқӣ | `A > 2`, `true` | Массивҳои дуруст/нодуруст; ҳамчун индекс истифода мешаванд |
| Матн | `'beam'`, `"beam"` | |
| Матритсаи сийрак | `sparse(i, j, v, n, n)` | Барои матритсаҳои сахтӣ |
| Тӯр, майдон, модел | `hexGrid(…)`, `part()`, `load('part.stl')` | Он чизе, ки `show` мекашад |
| Структура | `s.E = 210e3` | Майдонҳои номдор |
| Ячейка | `c = {1, 'two', [3 4]}` | Рӯйхати ҳар гуна арзишҳо |
| Дастаки функсия | `f = @(x) x.^2` | |

## Массивҳо ва индексатсия

- Диапазонҳо: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- Индексатсия аз 1 оғоз мешавад: `A(2, 3)`, `v(end)`, `A(:, 1)` (тамоми сутун), `A(:)` (ҳама ҳамчун як сутун), `v(v > 0)` (индексатсияи мантиқӣ).
- Таъйин кардан аз охир массивро калон мекунад, мисли MATLAB: `v(10) = 1`.

## Операторҳо

- `+ - * / \ ^` амалҳои матритсавӣ мебошанд (`A \ b` ҳал мекунад), `.* ./ .^` поэлементӣ кор мекунанд. `'` транспонир мекунад.
- Муқоисаҳо `== ~= < <= > >=`; мантиқ `& | ~` (поэлементӣ) ва `&& ||` (кӯтоҳшаванда).

## Идоракунии ҷараён ва функсияҳо

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Функсияҳо дар скрипт пас аз фармонҳояшон ҷойгир мешаванд, ё дар варақаи скрипти худ, ки ба номи функсия гузошта шудааст:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Ном ба ин тартиб ҷустуҷӯ карда мешавад: тағйирёбанда, скрипт дар ин детал бо ҳамин ном, функсияи китобхона, функсияи дарунсохт.

## Намоиш, шарҳҳо, натиҷа

- Фармони бе `;` арзиши худро чоп мекунад; `;` онро хомӯш нигоҳ медорад.
- `%` шарҳро оғоз мекунад; `%{` ва `%}` дар сатрҳои алоҳида сатрҳои байни онҳоро ба шарҳ мегиранд.
- `disp(x)`, `fprintf('%g\n', x)` ва `display(x)` ба консол чоп мекунанд.

## Хатогиҳо ва маҳдудиятҳо

- Хатогиҳо бо забони сода мегӯянд, ки чӣ хато шуд ва сатрро нишон медиҳанд (ва занҷири даъватҳои функсияҳоро).
- Ҳар иҷро буҷаи қадамҳо дорад (Танзимоти иҷро дар панел); ҳалқаи беохир бо паём қатъ мешавад, ё {{ui:Қатъ кардан}} фишор диҳед.
- Ҳар массив то 134 million арзиш дорад.

## Аз MATLAB фарқ

- Фармонҳои график параметрҳояшонро дар даъват мегузоранд: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` ва монанди инҳо қабул мешаванд, вале ҳеҷ кор намекунанд.
- `input` ва `keyboard` дастгирӣ намешаванд: скрипт наметавонад барои пурсиш қатъ шавад.
- Қуттиҳои асбобҳо нест; [китобхонаи таҳлил](topic:craftscript-library) ва функсияҳои дарунсохт ҳамин аст, ки мавҷуд аст.
