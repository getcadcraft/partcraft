Ҳамон траекторияро барои идоракунандаҳои гуногун гуногун навиштан лозим аст: рақамҳои сатр ё не, `M6` ё таваққуф, `G28` ё `G53`, `M30` ё `M2`. **Пост** матни кӯтоҳ аст, ки мегӯяд чӣ гуна. Постҳои дарунсохти PartCraft (Fanuc-style, GRBL ва LinuxCNC) дар ин формат навишта шудаанд, аз ин рӯ пости шахсии шумо метавонад аз нусхаи яке аз онҳо оғоз шавад.

Натиҷаро дар симулятори мошини худ пеш аз бурида санҷед ва аввал онро дар ҳаво, болои заготовка иҷро кунед. Постҳои дарунсохт ҳамон чизеро менависанд, ки пеш аз ин формат навишта мешуданд (санҷишҳо натиҷаи онҳоро дар садҳо барномаҳо байт ба байт муқоиса мекунанд), аммо ҳеҷ чиз аз ин ҷо дар мошини шумо собит нашудааст, ва постеро, ки тағйир медиҳед, исботи онро худатон бояд кунед.

## Яке созед

Дар Истеҳсол, зери **Пост**:

- {{ui:Таҳрири пост…}} дар идоракунандаи дарунсохт **нусхаи шахсии шуморо** мекушояд. Дар пости шахсии худатон он ҳамон постро мекушояд.
- {{ui:Пости нав…}} аз постҳои холии хурд, ки ҳамаи рӯйдодҳо дар он ҳастанд, оғоз мекунад.
- {{ui:Ворид кардани файли пост…}} файли матнии `.cpost`-ро мехонад (файле, ки аз **Захира ҳамчун файл…** дар таҳриргар мегиред).

Таҳриргар матнро нишон медиҳад, сатре, ки мегӯяд он мехонад ё не (ва кадом сатр нодуруст аст), ва G-кодеро, ки пост ҳангоми навиштан менависад. **Пешнамоиш бо** як барномаи намунавии хурдро интихоб мекунад, ки ҳамаи рӯйдодҳоро иҷро мекунад, ё барномаи ҳамин детали худатонро. {{ui:Захира кардан}} постро дар файли детал нигоҳ медорад (то 20 пост) ва онро ҳамчун идоракунанда интихоб мекунад. Постҳо бо детал мегарданд; барои истифодаи он дар детали дигар, онро ҳамчун файл захира кунед ва дар он ҷо ворид кунед.

## Пост чӣ гуна аст

```
post mymill
name My mill (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Program {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

Сатрҳое, ки бо `//` оғоз мешаванд, ва сатрҳои холӣ нодида гирифта мешаванд. Дар боло танзимот меоянд; сипас барои ҳар рӯйдод як блоки `on <event>`, ки бо `end` баста мешавад. Рӯйдоде, ки партофта мешавад, чизеро наменависад.

| Танзимот | Маъно |
|---|---|
| `post <id>` | Идентификатори пост: ҳарфҳо, рақамҳо, `-` ва `_` |
| `name <text>` | Он чизе, ки рӯйхати Control нишон медиҳад |
| `extension <ext>` | Пасванди файл: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … дар ҳар сатри `emit`, ё ҳеҷ |
| `decimal-point yes` / `no` | `10.` ба ҷои `10` (шарҳҳо ҳеҷ гоҳ нуқта надоранд) |
| `canned-cycles yes` / `no` | `no`: сӯрохҳо ҳамчун ҳаракатҳои G0/G1 навишта мешаванд, ки онҳоро ифода мекунанд |
| `modal <group> <words>` | Калимаҳои гурӯҳ (`modal motion G0 G1 G2 G3`), ки танҳо ҳангоми тағйир ёфтан навишта мешаванд |

## Рӯйдодҳо

Онҳо барои барнома ба ин тартиб иҷро мешаванд: `start`; сипас барои ҳар амалиёт `operation`, `tool-change` (ҳангоми иваз шудани асбоб), `spindle` (ҳангоми иваз шудани суръат), `approach` (ҳаракат то нуқтаи аввал, пеш аз аввалин rapid), `coolant-on`, пас ҳаракатҳояш ҳамчун `rapid`, `feed` ва `arc`, ва ҳар давраи қолабӣ ҳамчун `cycle-start`, як `cycle-hole` барои ҳар сӯрох ва `cycle-end`; дар охир `end`.

Ҳар рӯйдод метавонад миқдорҳои навъи ҳаракати худро истифода барад, ки ҳамчун `{name}` навишта мешаванд: барнома (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), заготовка (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), асбоб (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), амалиёт (`op.name`, `op.type`), `rpm`, нуқтаи ҳаракат (`x`, `y`, `z`, `f`, ва `moved`: true, вақте ки меҳвар тағйир ёфт), камонҳо (`arc.g` 2 ё 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) ва сӯрохҳо (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Рӯйхати **Рӯйдодҳо ва миқдорҳо** дар таҳриргар нишон медиҳад, ки кадом рӯйдод кадомро мебинад. Ҳолате, ки мехонед ва танзим мекунед: `cool`, `offset`, ва `at.x`, `at.y`, `at.z`, `at.f` (охирин арзишҳои навишташуда).

## Фармонҳо

| Фармон | Чӣ мекунад |
|---|---|
| `raw TEXT` | Сатре, ки дақиқ навишта шудааст (бе рақами сатр) |
| `comment TEXT` | `(TEXT)` бо ҳарфҳои ғайри ASCII ва қавсҳо бароварда шуда |
| `emit WORD WORD …` | Сатри калимаҳо; калимаҳои холӣ партофта мешаванд; калима набошад, сатр ҳам не |
| `word WORD …` | Калимаҳоро ба сатре, ки месозад, илова мекунад; `emit`-и холӣ онро тамом мекунад |
| `if EXPR` … `else` … `end` | Шартҳо: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, ё b) |
| `for tool in tools` … `end` | Барои ҳар асбобе, ки барнома истифода мебарад, як бор |
| `set NAME EXPR` | Арзишро нигоҳ медорад (`set offset tool.number`) |
| `reset NAME …` | Калимаҳои модалиро фаромӯш мекунад (гурӯҳ, ҳарфи нишонӣ мисли `Z`, ё `at.z`) |
| `do rapid X Y Z` | Рӯйдоди `rapid`-ро барои як нуқта иҷро мекунад |

Калима матни навишташуда бо сӯрохҳои `{variable|filter}` аст. Филтрҳо: `upper`, `lower`, `pad:N` (пур кардан бо сифр), `cut:N` (N аломати аввал), `safe` (ASCII-и бехатар барои шарҳ) ва `int`. Калимае, ки бо `~` тамом мешавад, **модалӣ** аст: он танҳо ҳангоме навишта мешавад, ки аз охирин навиштаашон фарқ кунад (`G1~`, `X{x}~`). Калимае, ки бо `~!` тамом мешавад, ҳар бор навишта мешавад ва ҳамчунон дар ёд дошта мешавад. Номе, ки миқдор нест, матни оддӣ аст (`G81`, `mist`). Рақамҳо то 0.001 mm дар давр карда мешаванд ва бе сифрҳои охир навишта мешаванд.

## Пост чиро карда наметавонад

Он танҳо тарзи навиштани ҳаракатҳоро муайян мекунад, ҳеҷ чизи дигар. Он траекторияро тағйир дода наметавонад, амалиётҳоро тартиб дода наметавонад, камонро тақсим намекунад, меҳвари нав илова намекунад, роҳи мошини шуморо ё кинематикаро намедонад, ё ҳисобҳо бо координатҳоро иҷро намекунад (`+` нест). Зондкунӣ, давраҳои умри асбоб ва зербарномаҳо, натиҷаи меҳвари 4-ум ва 5-ум ва кодҳои токарӣ сохта нашудаанд. Файли постии услуби `.cps` аз барномаи дигар бор карда намешавад: ин формати дигар ва содатар аст.
