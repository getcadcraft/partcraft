Ҳамон роҳи асбоб бояд барои назоратчиҳои гуногун гуногун навишта шавад: рақамҳои сатр ё набуданашон, `M6` ё таваққуф, `G28` ё `G53`, `M30` ё `M2`. **Пост** матни кӯтоҳест, ки мегӯяд чӣ тавр. Се постеи сохташудаи PartCraft (Fanuc-style, GRBL ва LinuxCNC) ба ин формат навишта шудаанд, пас пости шумо метавонад нусхаи яке аз онҳо бошад.

Натиҷаро дар симулятори мошини худатон пеш аз буридан санҷед ва аввал дар ҳаво боло аз заготовка иҷро кунед. Постҳои сохташуда ҳамон чизеро менависанд, ки пеш аз ин формат менавишт (санҷишҳо натиҷаи онҳоро байт ба байт бар садҳо барнома муқоиса мекунанд), аммо ҳеҷ чиз дар ин ҷо дар мошини шумо исбот нашудааст ва постеи тағйирёфта ба ӯҳдаи шумост, ки исбот кунад.

## Пост созед

Дар Истеҳсол, дар зери **Постпроцессор**:

- {{ui:Таҳрири пост…}} дар назоратчии сохташуда **нусхаи шахсии шуморо** мекушояд. Дар постеи худатон он постро мекушояд.
- {{ui:Пости нав…}} аз постеи холии хурд бо ҳар рӯйдод оғоз мекунад.
- {{ui:Ворид кардани файли пост…}} файли матнии `.cpost` (файлеро, ки аз **Захира ҳамчун файл…** дар муҳаррир мегиред) мехонад.

Муҳаррир матнро нишон медиҳад, сатре ки мегӯяд оё хонда мешавад (ва кадом сатр нодуруст аст), ва G-code-и ки пост менависад, ҳамон вақте ки менависед. **Пешнамоиш бо** барномаи намунаи хурдеро интихоб мекунад, ки ҳар рӯйдодро иҷро мекунад, ё барномаи ин қисмро. {{ui:Захира кардан}} постро дар файли қисм нигоҳ медорад (то 20 пост) ва онро ҳамчун назоратчӣ интихоб мекунад. Постҳо бо қисм ҳаракат мекунанд; барои истифода дар қисми дигар, онро ҳамчун файл захира кунед ва дар он ҷо ворид кунед.

## Пост чӣ гуна аст

```
post mymill
name Фрезаи ман (.nc)
extension nc
line-numbers off
decimal-point no
canned-cycles no
modal motion G0 G1 G2 G3

on start
  comment Барнома {program}: {name}
  emit G21 G90 G17
end

on tool-change
  emit T{tool.number} M6
end

on rapid
  if moved
    emit G0~ X{x}~ Y{y}~ Z{z}~
  end
end
```

Сатрҳое, ки бо `//` оғоз мешаванд ва сатрҳои холӣ нодида гирифта мешаванд. Дар боло танзимот меоянд; сипас як блоки `on <event>` барои ҳар рӯйдод, ки бо `end` баста мешавад. Рӯйдоде, ки шумо партофтед, ҳеҷ чиз намениваад.

| Танзим | Маъно |
|---|---|
| `post <id>` | Шиносаи пост: ҳарфҳо, рақамҳо, `-` ва `_` |
| `name <text>` | Он чи дар феҳристи назоратчӣ нишон дода мешавад |
| `extension <ext>` | Пасванди файл: nc, ngc, tap … |
| `line-numbers 10` / `off` | `N10`, `N20` … дар ҳар сатри `emit` ё ҳеҷ |
| `decimal-point yes` / `no` | `10.` ба ҷои `10` (шарҳҳо нуқтаро дар худ надоранд) |
| `canned-cycles yes` / `no` | `no`: сурохҳо ҳамчун ҳаракатҳои G0/G1, ки онҳоро ифода мекунанд, навишта мешаванд |
| `modal <group> <words>` | Калимаҳои гурӯҳ (`modal motion G0 G1 G2 G3`), ки танҳо вақте навишта мешаванд, ки тағйир ёбанд |

## Рӯйдодҳо

Онҳо барои барнома ба ин тартиб иҷро мешаванд: `start`; сипас барои ҳар амалиёт `operation`, `tool-change` (вақте асбоб иваз мешавад), `spindle` (вақте суръат иваз мешавад), `approach` (ҳаракат ба нуқтаи аввал, пеш аз аввалин тез), `coolant-on`, сипас ҳаракатҳояш ҳамчун `rapid`, `feed` ва `arc`, ва ҳар цикли тайёр ҳамчун `cycle-start`, як `cycle-hole` барои ҳар сурох ва `cycle-end`; дар охир `end`.

Рӯйдодҳои бештар, барои чизе, ки аз се меҳвар мегузарад (пост бе рӯйдод чунин барномаро рад мекунад ва рӯйдоди нокифояашро номбар мекунад):

| Рӯйдод | Кай | Тағйирёбандаҳояш |
|---|---|---|
| `index` | Пеш аз амалиёте, ки самти асбобаш аз охирин фарқ мекунад ва пеш аз аввалин амалиёт дар мошине бо меҳварҳои гардишӣ | `rot.a`, `rot.b`, `rot.c` (мавқеъҳо барои рафтан; холӣ барои меҳвари, ки мошин надорад), `first.x`, `first.y`, `first.z` |
| `rapid-rotary`, `feed-rotary` | Ҳаракатҳои амалиёте, ки меҳварҳои гардишиаш ҳангоми буридан ҳаракат мекунанд | `x`, `y`, `z`, `rot.a`, `rot.b`, `rot.c`, `f`, `rot.moved`, `inverse` (yes, вақте ки пешбарӣ бояд вақти баръакс бошад), `invf` (1/дақиқа) |
| `rotary-end` | Пас аз чунин амалиёт | |
| `probe-move` | Ҳаракате, ки вақте зонд мезанад, истода мешавад | `x`, `y`, `z`, `f`, `probe.n` (1 то 4), `probe.axis` (x, y ё z), `probe.k` (1, 2 ё 3) |
| `probe-set` | Пас аз ламсҳои як цикли зондкунӣ | `probe.kind` (`"z"`, `"x"`, `"y"` ё `centre`), `probe.action` (`set` ё `measure`), `probe.expect`, `probe.cx`, `probe.cy` |
| `thread` | Ҳаракати резбакунӣ дар токар | `x`, `z`, `thread.lead` |

Инчунин барои ҳар рӯйдод: `kin` (none, a, b, ac, bc), `rotary` ва `tcp` (yes ё no, аз мошин дар Танзим), `pivot.x`, `pivot.y`, `pivot.z`, `op.tilt` ва `op.turn` амалиёт ва дар токар `spin.mode` (css ё rpm), `spin.css`, `spin.max` ва `tool.nose`. Калимаи ҳарфӣ, ки арзишаш холӣ аст, масалан `A{rot.a}` дар мошине, ки меҳвари A надорад, аз сатр бароварда мешавад. Бо x, y ва z ҳамчун матн бо нақлҳо муқоиса кунед (`if probe.kind == "z"`): бе нақл онҳо координатаҳои ҳаракат ҳастанд.

Ду сатри дигар дар боло постро постеи токарӣ мекунанд: `machine lathe` (он танҳо X ва Z менависад ва роҳҳои фрезакуниро рад мекунад, чунон ки постеи фрезакунӣ роҳҳои токариро рад мекунад) ва `lathe-x diameter` ё `lathe-x radius`.

Ҳар рӯйдод метавонад тағйирёбандаҳои навъи ҳаракати худро истифода барад, ки ҳамчун `{name}` навишта мешаванд: барнома (`name`, `program`, `setup.axis`, `setup.origin`, `setup.coolant`), заготовка (`stock.kind`, `stock.d`, `stock.sx`, `stock.sy`, `stock.sz`, `stock.minx` … `stock.maxz`), асбоб (`tool.number`, `tool.desc`, `tool.kind`, `tool.d`, `tool.flutes`, `tool.fluteLen`), амалиёт (`op.name`, `op.type`), `rpm`, нуқтаи ҳаракат (`x`, `y`, `z`, `f` ва `moved`: true, вақте ки меҳвар тағйир ёфт), камонҳо (`arc.g` 2 ё 3, `arc.i`, `arc.j`, `arc.cx`, `arc.cy`) ва сурохҳо (`hole.x`, `hole.y`, `hole.z`, `hole.r`, `hole.q`, `hole.return`, `hole.first`, `cycle.kind`, `cycle.init`, `feed`). Феҳристи **Рӯйдодҳо ва тағйирёбандаҳо**-и муҳаррир нишон медиҳад, ки кадом рӯйдод чиро мебинад. Ҳолате, ки хондан ва танзим кардан мумкин аст: `cool`, `offset`, ва `at.x`, `at.y`, `at.z`, `at.f` (арзишҳои охирини навишташуда).

## Фармонҳо

| Фармон | Чӣ мекунад |
|---|---|
| `raw TEXT` | Сатре дақиқ, чунон ки навишта шудааст (бе рақами сатр) |
| `comment TEXT` | `(TEXT)` бо ASCII-и ғайриASCII ва қавсҳо бароварда шуда |
| `emit WORD WORD …` | Сатри калимаҳо; калимаҳое, ки холӣ мебароянд, партофта мешаванд; калима нест — сатр нест |
| `word WORD …` | Калимаҳоро ба сатре, ки сохта мешавад, илова мекунад; `emit`-и холӣ сатрро хатм мекунад |
| `if EXPR` … `else` … `end` | Шартҳо: `a == b`, `a != b`, `not a`, `a and b`, `a or b`, `a??b` (a, ва агар не, b) |
| `for tool in tools` … `end` | Барои ҳар асбобе, ки барнома истифода мебарад, як бор |
| `set NAME EXPR` | Арзишро ба ёд дорад (`set offset tool.number`) |
| `reset NAME …` | Калимаҳои модалиро фаромӯш мекунад (гурӯҳ, ҳарфи нишонӣ мисли `Z` ё `at.z`) |
| `do rapid X Y Z` | Рӯйдоди `rapid`-ро барои нуқта иҷро мекунад |

Калима матни навиштанӣ бо сӯрохиҳои `{variable|filter}` аст. Филтрҳо: `upper`, `lower`, `pad:N` (пур кардан бо сифр), `cut:N` (N аломати аввал), `safe` (ASCII-и бехатар барои шарҳ) ва `int`. Калима, ки бо `~` ба охир меояд, **модал** аст: танҳо вақте навишта мешавад, ки аз он чи охирин навишта шудааст фарқ кунад (`G1~`, `X{x}~`). Калима, ки бо `~!` ба охир меояд, ҳар бор навишта мешавад ва ҳамчунин ба ёд дошта мешавад. Ном, ки тағйирёбанда нест, матни оддӣ аст (`G81`, `mist`). Рақамҳо то 0.001 мм даврзада ва бе сифрҳои охирин навишта мешаванд.

## Пост чиро карда наметавонад

Он танҳо тарзи навиштани ҳаракатҳоро муайян мекунад, ҳеҷ чиз зиёд. Он роҳи асбобро тағйир дода наметавонад, амалиётҳоро тартиб дода наметавонад, камонро тақсим карда наметавонад, меҳвар илова карда наметавонад, роҳи мошини шумо ё кинематикаро намедонад, ё ҳисобкунӣ бо координатаҳо анҷом дода наметавонад (`+` нест). Мавқеъҳои гардишӣ аз мошине, ки дар Танзим тасвир шудааст, меоянд, на аз пост: пост метавонад аломат ё ҳарфҳои онҳоро тағйир диҳад, на кинематикаро. Циклҳои умри асбоб ва зерибарнома сохта нашудаанд. Файли `.cps`-и барномаи дигар бор карда намешавад: ин формати дигар, соддатар аст.
