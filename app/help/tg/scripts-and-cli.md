Моделсозии эҳтиёткорона бештар ба интизомнокӣ вобаста аст, на ба тугмачаҳо. Детале, ки ҳамчун матн навишта шудааст, метавонад хонда, баррасӣ, сатр ба сатр муқоиса ва бо скрипт аз нав сохта шавад. PartCraft ба ҳар ду самт кор мекунад: ҳар детал метавонад ҳамчун скрипт навишта шавад, ва скрипт деталро месозад.

## Дар барнома

Дар варақаи {{ui:Параметрҳо}}, дар зери **Скрипт**:

- {{ui:Захира кардан ҳамчун скрипт}} детали кушодаро ҳамчун `<name>.pcscript` зеркашӣ мекунад.
- {{ui:Кушодани скрипт}} аз файли `.pcscript` детал месозад. Хато бо рақами сатраш гузориш дода мешавад ва чизе иваз намешавад.

## Формати скрипт

```
pcscript 1
part "Bracket"
  resolution 64

param width = 120
  note Plate width
param thick = 8
param bolt = 8.5
param margin = bolt * 1.5

sketch Plate
  on top
  point a 0, 0
  point b 120, 0
  point c 120, 60
  point d 0, 60
  line bottom a b
  line right b c
  line top c d
  line left d a
  coincident a O
  horizontal bottom
  horizontal top
  vertical left
  vertical right
  distance bottom = width
  distance left 60

extrude Base
  sketch Plate
  depth = thick

sketch HoleCentres
  on face Base end
  point h1 12, 12
  hdistance O h1 = margin
  vdistance O h1 = margin

hole Bolts
  sketch HoleCentres
  d = bolt
  through
```

Қоидаҳо:

- Сатре, ки аз канори чап оғоз мешавад, фармонро оғоз мекунад: `pcscript`, `part`, `param`, навъи хусусият (`sketch`, `extrude`, `revolve`, `hole`, `lpattern`, `cpattern`, `mirror`, `fillet`, `chamfer`, `shell`, `import` ва навъҳои наве), ки номи худро пас аз он дорад, ё `rollback <feature>`.
- Сатрҳои фосилакдор танзимоти фармони боло мебошанд. Танзиме, ки танҳо меояд (`through`, `reverse`, `suppressed`), маънояш «ҳа» аст.
- Танзими рақамӣ ё рақам аст, ё `=` ва ифодае, ки муодила месозад: `depth = thick`.
- Дар эскиз: `on` ҳамворро номгузорӣ мекунад (`front`, `top`, `right`, `face Base end`, `face Revolve1 side l3`); геометрия чунин аст: `point <name> x, y`, `line <name> <point> <point>`, `circle <name> <centre> <radius>`, `arc <name> <centre> <start> <end>` (хилофи гардиши соат) ё `spline <name> fit|control <points>`; робитаҳо навъи худ ва номҳоеро доранд, ки онҳоро мепайванданд (`O` нуқтаи пайдоиш аст); андоза бо арзиши худ ё `= ифода` анҷом меёбад.
- Танзимоти ихтиёрии сатри геометрия ё робита дар қавсҳои чоргӯша дар охир, бо `;` ҷудо карда мешаванд: `[construction]`, `[side -1; label 5, 3]`.
- `#` шарҳро оғоз мекунад (дар оғози сатр ё пас аз фосила). Номҳои бо фосила дар дохили «» навишташуда.
- Шиносаҳои хусусият аз f1 ба тартиби навиштан шумурда мешаванд. Истинодҳои канор ва рӯро онҳо истифода мебаранд, масалан `edge f2.side:l3 f2.end [at 50, 0, 10]`.
- Танзимоте, ки формат барояшон калима надорад, бо `json` ва арзиш навишта мешаванд; онҳо ҳамон тавр хонда мешаванд.

Вақте ки аз барнома захира мешавад, скрипт ҳар танзимро дар бар мегирад, бинобар ин он ҳамон деталро мекушояд. Ҷисми STEP-и воридшуда аз барнома дар дохили скрипт навишта мешавад, ва аз хатти фармон ҳамчун файли алоҳидаи `.step` бо номе, ки `step-file` муайян мекунад.

## Абзори хатти фармон

Абзор дар компютере бо Node.js 24, аз нусхаи манбаи CadCraft иҷро мешавад: `node tools/partcraft-cli/partcraft.mjs <command>`. Ин абзори таҳиягар аст ва ҳамон модулҳоеро истифода мебарад, ки барнома. Деталҳо файлҳои `.partcraft.json` ё скриптҳои `.pcscript` мебошанд.

| Фармон | Чӣ мекунад |
|---|---|
| `info <part>` | Хусусиятҳо, параметрҳо, панели бозгашт, ҳаҷм ва андозаи ҷисми сохташуда |
| `params <part>` | Ҳар параметр ва муодила бо арзиши худ |
| `set <part> width=150 Base.depth==thick` | Пешбарӣ: тағйир додани параметрҳо, пайвастани рақамҳо (`==` ё ифода), гузоштани рақамҳои оддӣ |
| `drive <part> Base.depth=12` | Бозгашт: ҳалли параметре, ки рақами идорашавандаро пушти сар дорад (`--prefer width` яктоаш интихоб мекунад) |
| `build <part> --out x.step` | Менависад `.step`, `.stl`, `.3mf`, `.json`, `.pcscript` ё макрос (`.swb`) |
| `build <part> --table sizes.csv --out-dir sizes` | Як файл барои ҳар сатри ҷадвали тарроҳӣ |
| `variants <part> --out-dir d` ё `--zip f.zip` | Ҳар конфигуратсия ҳамчун STEP, IFC, DWG ва пешнамо, ҷадвали вариантҳо ва ашёи китобхона (`--only "A,B"`, `--formats step,ifc,dwg,preview`, `--no-item`); [Бастаи вариантҳоро созед](topic:variant-pack)-ро бинед |
| `script <in.pcscript> -o part.json` | Скриптро ба деталь табдил медиҳад |
| `to-script <part> -o part.pcscript` | Деталро ба скрипт табдил медиҳад |
| `rollback <part> [<feature>]`, `forward <part> [--end]` | Панели бозгаширо дар файл мекашад |
| `check <part> [--strict]` | Санҷиши интизомнокӣ (дар поён) |

`build` инчунин `--set name=value` (танҳо барои ин сохтан) ва `--upto <feature>`-ро қабул мекунад. Ҳар фармон `--json`-ро қабул мекунад. Рамзҳои хуруҷ: 0 — хуб, 1 — мушкилӣ ёфт шуд, 2 — фармон нодуруст навишта шудааст. Скрипт ҳеҷ гоҳ дар ҷои худаш навишта намешавад: барои захираи нусхаи тағйирёфта `-o`-ро диҳед.

## Санҷиш

`check` чизеро гузориш медиҳад, ки баъдтар тағйир додани детални мушкилро медиҳад:

| Ёфта | Ҳисоб мешавад ҳамчун |
|---|---|
| Эскизе, ки аз ҳад зиёд муайян шудааст (робитаҳои зиддиятнок ё такроршаванда) | хато |
| Хусусияте, ки сохта намешавад | хато |
| Параметр ё муодилае бо хато, ё параметрҳое, ки ба ҳамдигар истифода мешаванд | хато |
| Эскизе, ки кам муайян шудааст, бо дарачаҳои озодии худ | огоҳӣ |
| Рақамҳое, ки мустақиман ба хусусият ва андоза навишта шудаанд ва ягон параметр идора намекунад | огоҳӣ |
| Параметре, ки истифода намешавад | огоҳӣ |
| Хусусияти хомӯшшуда; панели бозгашт дар охир нест | огоҳӣ |

`--strict` ҳар огоҳиро хато месозад, то скрипти сохтан деталеро, ки пурра идора нашудааст, рад кунад.

:::note
Натиҷаи макроси `.swb` барои модельсози детале аст, ки аксари корхонаҳо истифода мебаранд: вақте дар он барнома иҷро шавад, детални дар он ҷо месозад. Он дар ин ҷо дар он барнома иҷро нашудааст (дар серверҳои мо дастрас нест), бинобар ин онро санҷида нашуда ҳисоб кунед.
:::
