## Чи кор мекунед

Ҳар андозаи деталро якбора **тақдим кунед**: як файли STEP, IFC ва DWG ва тасвир барои ҳар конфигурация, ҷадвале, ки мегӯяд ҳар кадом чист, ва ашёи китобхона, ки ҳамаи онҳоро дар як саҳифа мегузорад.

Аввал ба деталь **конфигурацияҳо** лозиманд (ниг. [Конфигурацияҳо ва ҷадвалҳои тарҳ](topic:design-tables)). Конфигурацияе, ки хусусиятро хомӯш мекунад, мисли лавҳа бо сӯрохиҳо ва бе онҳо, варианти алоҳидаи худро мегардад.

## Қадамҳо

1. Деталро кушоед. Дар варақаи {{ui:Parameters}} **Конфигурацияҳо**-ро ёбед.
2. {{ui:Variant pack…}}-ро пахш кунед.
3. Конфигурацияҳоеро, ки бояд сохта шаванд (ҳама ишорат шудаанд) ва файлҳоеро, ки навишта мешаванд, ишорат гузоред: STEP, IFC, DWG, пешнамо ва ашёи китобхона.
4. {{ui:Make the pack}}-ро пахш кунед. Сатри ҳолат вариантҳоро ҳангоми сохтан ҳисоб мекунад; деталатон тағйир намеёбад.
5. Як zip зеркашӣ мешавад: `<part> variants.zip`.

## Дар zip чи ҳаст

| Файл | Чист |
|---|---|
| `<name>.step` | Конфигурация ҳамчун ҷисми сахти STEP. |
| `<name>.ifc` | IFC4, як элемент бо ҷисми сохташуда ва параметрҳои деталь ҳамчун хусусиятҳо; қимат худи ҳамон конфигурация аст. |
| `<name>.dwg` | Намудҳои пеш, боло, рост ва изометрӣ ҳамчун варақи нақша дар андозаи пурра. |
| `<name>.svg` | Расми хатии изометрии он. |
| `variants.csv`, `variants.json` | Ҷадвали параметрҳо: id, ном ва қимати ҳар параметр барои ҳар вариант, хусусиятҳое, ки хомӯш мекунад, файлҳои он, ҳаҷм ва андозаи он. |
| `<part>.item.json` | Деталь ҳамчун як ашёи китобхона бо вариантҳояш (ниг. поён). |
| `README.txt` | Чи сохта шуд, ёддоштҳои поён ва он чи сохта нашуд. |

Файлҳо бо номи конфигурация гузошта мешаванд. Конфигурацияе, ки сохта нашавад (хусусияте, ки бо ин қиматҳо сохтан мумкин нест), аз файлҳо ва ҷадвал берун монда, дар README ва дар паёме пас аз захираи zip нишон дода мешавад; дигарҳо бошад навишта мешаванд.

## Донистани он фоиданок аст

- **STEP** дақиқ аст, вақте ки ядрои дақиқ дар версияи шумо фаъол аст. Бе он STEP бо секунҷаҳои ҳамвор меояд ва README инро мегӯяд.
- **DWG** варақи нақша аст, на модели 3D. Хатҳояш аз меш гирифта мешаванд, аз ин рӯ канори хамдор хатҳои кӯтоҳи зиёд мешавад.
- **Ашёи китобхона** барои ҳар вариант як ҷисм ва як пойгоҳ дорад, дар меҳварҳои худи китобхона: Z боло, пеш ба тарафи −Y, ва нуқтаи ворид шудан дар миёнаи қафо дар поён. Нақша росткунҷаи иҳотакунандаи ҳар вариант аст. Ашё то 8 MB маҳдуд аст, аз ин рӯ вариантҳои хеле вазнин ба қуттии ҳамон андоза табдил меёбанд ва README шумораашро мегӯяд.
- Конфигурацияи фаъоли деталь варианти пешфарзи ашё мешавад.
- Портҳо (нуқтаҳои пайвастшавӣ барои қубур ва канал) аз PartCraft танзим карда намешаванд.

## Вариантҳоро дар саҳифаи китобхона гузоред

`<part>.item.json`-ро дар сайт дар **Китобхона › Бор кардан** бор кунед. Категория, иҷозатнома ва сатри эътирофи худро интихоб кунед; он ашёи китобхона бо вариантҳояш мешавад. Дар BimCraft ҳангоми ҷойгир кардан он вариантро мепурсад ва **Иваз кардан** дигаронро пешниҳод мекунад. Саҳифае, ки меҳмонон вариантро интихоб мекунанд, 3D-ро мебинанд ва зеркашӣ мекунанд, ҳоло **пешнамои кормандон** аст: то ҳол барои ҷамоа кушода нест.

## Аз хати фармон

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only` конфигурацияҳоро номбар мекунад, `--formats` яке аз `step`, `ifc`, `dwg`, `preview`-ро, `--no-item` ашёи китобхонаро берун мегузорад. Он ё ҷузвдон, ё zip, ё ҳардуро менависад ва вақте ки вариант сохта нашуд, бо кодаи 1 хотима меёбад. Ниг. [Скриптҳо ва хати фармон](topic:scripts-and-cli).
