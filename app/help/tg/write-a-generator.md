Генератор скрипти оддӣ ([CraftScript](topic:craftscript), Lua ё Python) бо чанд сатри шарҳ дар боло аст. PartCraft сатрҳои шарҳро мехонад ва шаклро месозад; скрипти шумо вурудро ҳамчун тағйирёбандаҳои аллакай танзимшуда мехонад.

## Сарлавҳа

Инҳоро дар сатрҳои шарҳ гузоред (`%` дар CraftScript, `--` дар Lua, `#` дар Python):

```
% @generator Мубодилакунандаи гармӣ
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Ҷараёни массавӣ"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Сатҳ"
% @input solid: = true
% @input note: = "матн"
```

Вуруд чунин аст: `name: unit = default`, сипас ихтиёран диапазон `[min .. max]` (рақамҳо дар дохили он нигоҳ дошта мешаванд), рӯйхати интихобҳо `{a, b, c}` ва унвон дар дохили иқтибос. Воҳид танҳо барои шакл нишона аст: **қимат дар ҳамон воҳид меояд**, аз ин рӯ скрипте, ки SI мехоҳад, онро табдил медиҳад; `to_si(value, 'kg/s', 'kg/s')` низ месанҷад, ки воҳид ҳамон чизеро дорад, ки шумо фикр мекунед. Ном аз ҳарфҳо, рақамҳо ва хати поён иборат аст; `body`, `sheet` ва `problems` банд мебошанд.

## Он чизе, ки скрипт бармегузорад

| Тағйирёбанда | Чӣ |
|---|---|
| `body` | **Талаб мешавад.** Тӯри сатҳӣ, одатан аз `[body, info] = to_body(field, h)`. Ҳангоми анҷоми иҷро таъмир ва санҷида мешавад. |
| `sheet` | Ихтиёрӣ. Сохтор: ҳар майдон рақам ё матн, ё сохтор бо `value`, `unit`, `ref` ва `note`. Он варақи маълумот мегардад. |
| `problems` | Ихтиёрӣ. Ҳуҷайраи `problems` аз `mfg_check(field, 'sls', struct(), h)` ё сабтҳои худи шумо. Онҳо ба санҷишҳо ва рӯйхати Мушкилот мераванд. |

## Мисоли пурраи хурд

```
% Кубии холие, ки девор дорад.
% @generator Кубии холӣ
% @input side: mm = 12 [4 .. 40] "Канор"
% @input wall: mm = 1.5 [0.5 .. 5] "Девор"
% @input h: mm = 0.5 [0.25 .. 2] "Андозаи воксел"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'аз тӯр');
```

Ин кубии пӯшидаро месозад, ва санҷиш дохили пӯшидаашро барои раванди порошокӣ ҳамчун хато қайд мекунад. Андозаи воксели `h`-ро на бештар аз як сеяки тунуктарин деворе, ки мехоҳед, гузоред: агар девор аз тақрибан се воксел кам бошад, он боэътимод нест.

## Майдонҳо

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ҷисми инқилобӣ аз профил), `tpms` (сатҳҳои gyroid, Schwarz P ва diamond, бо андозаи ячейка ва девор, ки дар тамоми детал тағйир ёфта метавонанд), `lattice` ва `lattice_beams`, `along` (канали мудаввар дар роҳ), булевҳои `field_union`, `field_intersect`, `field_subtract`, ҳамвори `field_blend` ва `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` масофаи имзодорро дар нуқтаҳо медиҳад (дохили майдон манфӣ), `field_voxel` вокселҳоро барои ҳалкунандаҳо медиҳад. [Майдонҳо](topic:fields) маънои онҳоро шарҳ медиҳад.

Маҳдудиятҳое, ки донистан арзанда аст: агар девори варақ аз тақрибан як чоряки ячейка ғафстар бошад, каналҳо баста мешаванд; унсуре, ки аз тақрибан се воксел тунуктар аст, метавонад фишурда шавад; `along` конусҳои мудавварро пайваст мекунад, аз ин рӯ радиусе, ки зуд тағйир меёбад, варамро боқӣ мегузорад (барои профил `field_revolve`-ро истифода баред).

## Скрипти худро ҳамчун генератор кушоед

Дар фазои кории {{ui:Муҳандис}} ба {{ui:Кушодан}} пахш кунед ва файлро интихоб кунед. Скрипте, ки сатри `@generator` ё `@input` надорад, рад карда мешавад: зеро чизе барои танзим нест. Генератор дар ин браузер нигоҳ дошта мешавад (то 20 адад) ва {{ui:Хориҷ кардан}} онро аз байн мебарад. Ҷисме, ки аз он оғоз шудааст, нусхаи скриптро дар худ дорад, аз ин рӯ детал ба он вобаста нест.

Файл инчунин метавонад чанд генератор дошта бошад: бастаи JSON `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
