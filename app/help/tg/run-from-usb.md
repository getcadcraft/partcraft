Абзорҳои муҳандисӣ (генераторҳо, китобхонаи муҳандисӣ, санҷишҳо ва файлҳои маълумот) ба **ҳуқуқи администратор** ва **насбкунанда** ниёз надоранд. Онҳо танҳо он чизеро менависанд, ки дар ин ҷо рӯйхат шудааст, ва ҳеҷ чизи дигарро не.

| Чӣ | Дар куҷо нигоҳ дошта мешавад |
|---|---|
| Деталҳои шумо, бо ҷисмҳои сохташуда, варақҳои маълумот ва санҷишҳо | Файли детале, ки захира мекунед (`.partcraft.json`), дар ҷое ки онро захира мекунед. |
| Генераторҳое, ки аз файлҳо кушодаед | Дар захираи худи барнома: дар саҳифаи веб — захираи маҳаллии браузер, ва дар Studio-и портативӣ — ҷузвдони `data` дар паҳлӯи барнома. Ҳадди аксар 20. |
| Танзимот (андозаҳои воксел, ришташаҳои ҳалкунанда, тарҳбандӣ) | Ҳамон захираи барнома. |
| Варақҳои маълумот, майдонҳо, торҳо | Танҳо дар он ҷое ки захира мекунед: зеркашӣ ба ҷое меравад, ки интихоб мекунед. |

Абзорҳо **худашон ҳеҷ дархости шабакавӣ намефиристанд**: генераторҳое ки бо барнома меоянд, файлҳо дар ҷузвдони худи барнома ҳастанд; китобхона ва санҷишҳо дар компютери шумо дар коргар иҷро мешаванд, ки ба шабака дастрас шуда наметавонад; ва маълумоти муҳандисӣ (хосиятҳои об ва ҳаво, мавод) дар дохили барнома аст. Генераторе, ки аз файл кушода мешавад, дар компютери шумо хонда мешавад ва ба ҷое фиристода намешавад.

## Бойгонии zip-и портативии Windows ва Linux

Studio-и портативии Windows танзимот, захираҳо (кэш) ва иловаҳоро дар ҷузвдони `data` дар паҳлӯи барнома нигоҳ медорад. AppImage-и Linux онҳоро дар паҳлӯи худаш нигоҳ медорад, вақте ки файли `portable` дар кинораш ҳаст; бе ин файл, ҷузвдони хонагии шумо истифода мешавад. Шакли портативии Mac нест: система намемонад, ки барномаи зеркашидашуда дар паҳлӯи худаш нависад. Ёддоштҳои портативии худи қобиқ (роҳнамои `Studio`) рӯйхати чизҳоеро медиҳанд, ки барнома менависад.

## Дастрасӣ ба компютер

Ин ҷо ҳеҷ чиз дастрасӣ ба компютерро талаб намекунад. Чопгарҳо, дастгоҳҳои сериявӣ ва дастгоҳҳои USB ҷудо ҳастанд: вақте ки кор ба онҳо лозим мешавад, онҳо як маротиба барои ҳар дастгоҳ мепурсанд, ва генераторҳо ё санҷишҳо ба онҳо ҳеҷ дахл надоранд.
