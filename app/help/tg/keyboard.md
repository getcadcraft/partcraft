Тугмачаҳо ҳеҷ коре намекунанд, вақте ки шумо дар қуттии панел матн менависед, ба истиснои {{key:Mod+S}} ва {{key:Mod+O}}, ки ҳамеша кор мекунанд. Тугмачаҳои ҳарфӣ бе модификатор кор мекунанд.

Ёддоштҳои умумӣ дар бораи тугмачаҳо дар браузер ва дар клавиатураҳо бе тугмаҳои функсионалӣ: [Тугмачаҳо, мушукҳо ва тачпадҳо](common:keys).

## Ҳамаҷо

| Тугма | Амал |
|---|---|
| {{key:Mod+S}} | Захира кардани ҷузъ (дар маҷмӯа: маҷмӯа). Аввал эскизи кушодаро мепӯшонад |
| {{key:Mod+O}} | Кушодани файли ҷузъ ё маҷмӯа (аввал мепурсад, агар тағйироти захиранашуда бошад) |
| {{key:Mod+Z}} | Баргардондан |
| {{key:Mod+Y}} ё {{key:Mod+Shift+Z}} | Такрор кардан |
| {{key:F1}} | Кушодан ё пӯшидани ин роҳнамо (инчунин {{ui:Help}} дар панели барнома). {{key:Esc}} низ онро мепӯшонад. Дар бисёре аз ноутбукҳо ва клавиатураҳои Mac тугмаи Fn-ро нигоҳ доред |
| {{key:Ctrl+Shift+F}} | Режими экран: муқаррарӣ, экрани пурра, экрани пурра бо панелҳои пинҳоншуда. Дар Mac низ Control, на ⌘ |
| {{key:Esc}} | Аз экрани пурра баромадан (вақте ки дар экрани пурра ҳастед) |
| {{key:Mod+,}} | Танзимот, аз ҷумла бухтаи PartCraft (нигаред ба [Танзимоти PartCraft](topic:settings)) |

Дар қуттии рақами панел {{key:Mod+Z}} баргардондани матни худи браузер аст. Дар қуттии рақам дар болои андозаи эскиз, он дар PartCraft баргардонда мешавад.

## Нусха бардоштан, гузоштан ва дубора кардан

Онҳо ба чизе, ки шумо бо он кор мекунед, таъсир мекунанд: геометрияи интихобшуда дар эскизи кушода, хусусияти интихобшуда дар таърих ё ҷузъи интихобшуда дар маҷмӯа. Тафсилот дар [Нусха бардоштан, гузоштан ва дубора кардан](topic:copy-paste).

| Тугма | Амал |
|---|---|
| {{key:Mod+C}} | Нусхаи интихобро бардоштан |
| {{key:Mod+X}} | Буридан: нусха бардоштан, сипас нест кардан |
| {{key:Mod+V}} | Гузоштан. Дар эскиз нусха аз ишоргар пайравӣ мекунад: ҷое, ки бояд равад, клик кунед |
| {{key:Mod+Shift+V}} | Гузоштан дар ҷои худаш: ҳамон координатаҳо (дар маҷмӯа, ҳамон ҷой) |
| {{key:Mod+D}} | Дубора кардан: нусха бардоштан ва гузоштан дар як қадам, бе тағйир додани бофари муваққатӣ |
| {{key:Mod+A}} | Ҳамаро интихоб кардан (дар эскиз) |
| {{key:Esc}} | Ҳеҷ чизро интихоб накардан (ва гузоштани пайравикунандаро бекор кардан) |

Дар қуттии рақам ин тугмачаҳо матнро мисли маъмул нусха мебардоранд ва мегузоранд. Матни интихобшуда дар панел аз ҷониби браузер нусха бардошта мешавад.

Аввал дар намуд клик кунед, то фокуси тугмачаҳо дошта бошад.

| {{key:Plus}} ё {{key:=}} | Калонкунӣ |
| {{key:Minus}} | Хурдкунӣ |

| Мушук | Амал |
|---|---|
| Бо тугмаи чап кашидан | Намудро гардонед (орбита) |
| Бо тугмаи рост ё миёна кашидан | Ҷойивазкунӣ |
| {{key:Shift}}, {{key:Ctrl}} ё ⌘-ро нигоҳ дошта, бо тугмаи чап кашидан | Ҷойивазкунӣ |
| Чархро гардонед | Дар ишоргар калонкунӣ (аз шумо дур калонкунӣ мекунад) |
| Ду ангушт дар тачпад бо суръат гардонед | Намудро гардонед; бо {{key:Shift}} — ҷойивазкунӣ. Чимчимкунӣ калонкунӣ мекунад. Бо **Скроллинг** дар [Танзимоти PartCraft](topic:settings) муайян мешавад |

Бо **Гардондани намуд: тугмаи миёна** дар [Танзимоти PartCraft](topic:settings), тугмаи миёна намудро мегардонад, {{key:Shift}} бо тугмаи миёна ё тугмаи рост ҷойивазкунӣ мекунад ва тугмаи чап танҳо интихоб мекунад.
| Клик | Рӯро интихоб кунед (пурра ҷудо мешавад), қирра ё ҳавопаро |
| {{key:Shift}}+клик дар қирра ё рӯ | Якчанд қирра ё рӯро ҷамъ кунед |
| Клик дар фазои холӣ | Интихобро тоза кунед |

## Роҳҳои кӯтоҳе, ки браузер метавонад гирад

- {{key:Mod+Y}} дар Safari метавонад таърихро кушояд: барои такрор {{key:Mod+Shift+Z}}-ро истифода баред.
- {{key:Mod+D}} тугмаи хатбаракории браузер аст: PartCraft онро ҳангоми фокуси барнома мегирад ва ҳангоми терданатон дар қуттӣ онро тарк мекунад.
- {{key:F11}} ва {{key:Mod+Plus}} / {{key:Mod+Minus}} экрани пурраи браузер ва калонкунии саҳифа ҳастанд, на PartCraft. Барои экрани пурра {{key:Ctrl+Shift+F}}-ро ва барои модел чархро истифода баред.
- Тугмачаҳои функсионалӣ дар бисёре аз ноутбукҳо ва Mac тугмаи Fn-ро талаб мекунанд: барои роҳнамо Fn+{{key:F1}}-ро пахш кунед ё тугмаи {{ui:Help}}-ро истифода баред.

Жестҳои тачпад ва лама: [Тачпад, лама ва экранҳои хурд](topic:trackpad-and-touch).

## Дар куҷо Кӯчонидан ҷойгир аст

Кӯчонидан дар менюи {{ui:More}}-и гурӯҳи Хусусиятҳо ҳамчун {{ui:Кӯчонидани ҷисм}} ҷойгир аст, дар қуттии {{ui:Move}} (ки дар он ΔX, ΔY ва ΔZ менависед) ва ҳамчун тирҳои {{ui:Кашида кӯчонед}} дар ҷузъ.
