几何内核是把你的历史转换成实体的引擎。此版本的PartCraft有一个：**网格内核**（manifold-3d）。它作为一个小型WebAssembly程序在你的计算机上运行，应用打开片刻后即可使用。关于你零件的任何内容都不会发送到任何地方。

| | 网格内核 |
|---|---|
| 圆形 | 平面片。零件面板中的**曲线**决定其精细程度 |
| 体积和面积 | 按面片实体计算，圆形零件会略微偏小 |
| 草图、拉伸、切除、旋转、孔、阵列、镜像、参考平面 | 支持 |
| 圆角和倒角 | 用于平面之间的直边；相接的圆角做斜接 |
| 抽壳和拔模 | 抽壳打开平面（壁厚精确）；拔模使平面倾斜 |
| 导出 | STL、3MF、STEP（面片）、图纸PDF和DXF |
| 图纸视图 | 根据面片绘制，包括剖视图 |
| 面和边 | 带名称并按种类识别（平面、圆柱、圆锥、球、圆环；直线、圆），取自草图：仿真、生成式和加工工作空间、测量、拾取和孔表都会用到它们 |

在网格内核构建零件时，状态栏右端附近的标签显示**网格内核**。

## 哪些要等精确内核

精确（B-rep）内核保留真实的圆、圆柱和圆锥，并支持任意边上的光滑圆角；扫描、放样、曲面、钣金、筋、多个实体、STEP导入和精确STEP导出都建立在它之上。PartCraft早期的实验室版本用OpenCascade来实现这些。它的许可证（LGPL）不适合本次发布，因为这里每个应用都是Apache-2.0，并且只使用宽松许可证的库，所以没有包含它。此事没有日期。

在此之前，选择这些特征时会显示**尚未实现**：状态栏会给出原因，其按钮的工具提示以“尚未实现（需要精确内核）”结尾。[尚未实现的功能](topic:not-built-yet)逐项列出了它们以及可以改用的办法。

在早期版本中用它们制作的零件仍可打开。这些特征保留在历史中并标记为尚未实现（悬停可查看原因），零件的其余部分照常构建，保存时它们保持不变。

## 圆形表面和曲线

网格内核把圆绘制成多边形。零件面板中的**曲线**决定整圆有多少条边；边越多，外观越平滑，测量值越接近真实值，但构建时间越长。{{ui:测量}}得到的体积、面积和距离针对的是这个面片实体：对于孔或凸台，它们比圆形的真实值略小。

## 在线和离线

网格内核是应用自身下载的一部分。要在没有网络连接时工作，请在在线时将PartCraft保存为离线使用：选择应用栏中的{{ui:保存以供离线使用}}，并等待显示**离线可用**。详情：[离线工作](common:offline)。
