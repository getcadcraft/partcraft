**造型**工作空间用于创建有机形状。您编辑的是**控制网格**，即由角点、边和面组成的粗略网格。形状是该控制网格所控制的光滑曲面（其 Catmull–Clark 极限曲面），因此移动一个角点会使曲面在其周围平滑地弯曲。形状满意后，**表面处理**会将其作为*造型*特征添加到零件历史中，精确内核随后将其转换为真正的 B 样条曲面。之后您可以对其进行圆角处理、切割、与其他特征连接，并将其导出为 STEP。

在工具栏左侧的**工作空间**列表中选择**造型**。

## 创建控制网格

1. 在右侧面板中设置**尺寸**和**分段数**。分段数是每条边上划分的面数。
2. 点击工具栏中的{{ui:Box}}、{{ui:Quadball}}或{{ui:Plane}}。面板中还有**圆柱**、**圆环**和**按点击创建面**。

- **四边球**是一个经过拟合的长方体控制网格，其角点位于一个球面上。在这些角点之间，曲面略微位于球内：分段数为 2 时，体积约少 0.4 %。
- **平面**是开放的，因此它会成为曲面实体（见下文“设计中的曲面特征”）。
- **按点击创建面**：在顶部（地面）平面上或控制网格的角点上点击 4 个点，即可创建一个面。共享角点的面会相互连接。输入 3 个点后按{{key:Enter}}可创建三角形，或按{{key:Esc}}停止。

未完成的控制网格会随零件文件一起保存，因此您可以关闭文件，稍后再继续。

## 选择和移动

- 点击控制网格的角点、边或面。{{key:Shift}}+点击可添加或移除项目。{{key:Esc}}可清除选择。
- 选择对象的中央会出现操纵器。拖动箭头可沿该方向移动，拖动方块可在该平面内移动。按{{key:W}}进行移动，按{{key:E}}进行旋转，按{{key:R}}进行缩放，或使用面板中的按钮。工具栏中的{{ui:Gizmo}}可在这些模式之间切换。
- **柔和衰减**（mm）还会拖动该距离内的角点，并在该距离的边缘平滑地衰减至零。
- 每次拖动即为一步撤销：{{key:Ctrl+Z}}和{{key:Ctrl+Y}}照常工作。

## 修改控制网格

面板中的**修改**按钮作用于所选对象：

| 按钮 | 作用 |
|---|---|
| {{ui:Extrude}} | 所选面沿其法线方向按**拉伸距离**向外移动，并生成新的侧面。所选的开放边向外生成新面。 |
| {{ui:Edge loop}} / 插入边环 | 在所选边处，沿穿过该边的四边形面环中间进行分割。环越多，曲线越紧密。 |
| 插入点 | 在所选边的中点处添加一个角点。 |
| 细分 | 将每个所选面围绕其中心分割为四边形面。 |
| 桥接 | 用一组面的管状结构连接两个所选面，或连接两个开口（每个开口选择一条开放边）。两者的边数必须相同。 |
| 填充孔 | 用一个面封闭所选开放边所在的开口。 |
| 焊接 | 将所选角点合并为一个，位于其中点处。 |
| 展平 | 将所选角点移动到与其最贴合的平面上。 |
| 删除 | 删除所选面、边（两个面合并）或角点。 |

## 尖锐边、对称和显示

- {{ui:Crease}}使所选边变为尖锐。**折痕权重**为 10 时完全尖锐。较小的权重会在若干次细化步骤中保持尖锐，然后变得柔和，从而形成紧密的圆角而不是硬折。**取消折痕**可使其恢复光滑。**尖锐顶点**会固定一个角点，使曲面以一个尖点通过该处。
- **对称**会使控制网格沿 X、Y 或 Z = 0 镜像。它保留正侧，将其镜像，并将两半连接起来。此后，在任一侧进行的编辑都会在两侧同时生效。位于镜像平面上的角点仍保留在该平面上。
- {{ui:Display}}可在**平滑**（该特征最终的曲面）和**方块**（控制网格面本身）之间切换。
- **分析**：**斑马纹**会从当前视图中反射出条纹状光线。它们在光滑曲面上平滑地弯曲，在折痕处断开。**平均曲率**会将凸起区域显示为红色，凹陷区域显示为蓝色，平坦区域显示为白色。它是在显示的网格上使用余切公式测得的，因此只是参考，并非精确测量。

## 检查并完成

- **精确检查**会在精确内核中转换控制网格，而不更改您的零件。它会报告该控制网格生成了多少个 B 样条面片、其中多少个是精确的，以及结果是否为封闭的有效实体及其体积。
- {{ui:Finish}}会向历史记录添加一个*造型*特征，或更新您正在编辑的造型，并将您带回设计。封闭的控制网格会成为实体。其在设计面板中的**操作**可以是新建实体、合并、剪切或相交。开放的控制网格会成为曲面实体。
- 之后要修改造型，请在历史记录中选择它，然后点击**在造型中编辑**。编辑其控制网格时，已生成的实体会被隐藏。
- **放弃**会丢弃控制网格，而不改动历史记录。

## 哪些是精确的，哪些是近似的

控制网格的每个四边形面在需要时经过细化，成为一个双三次 B 样条面片。

- 当面的每个角点都是*正则*的（曲面内部有四条边相交，或在开放边或折痕处有三条边相交）时，面片与细分曲面**完全一致**。测试以 1e-9 mm 的精度验证这一点。
- 在**奇异点**处（三条、五条或更多边相交，三边形或五边形面的角点，或折痕的端点），不存在精确的多项式面片。在此处，面片采用该角点处的精确点和切平面，以及相邻的边曲线，因此各面片仍然无缝相接。在相交于该点的各边上，切线连续性是近似的。造型面板和该特征的面板会给出最大角度，通常小于 2°。在特征面板中提高**级别**会使这些面片更小、更精确。
- 尖锐的折痕是实体的真实边，因此您可以对其进行圆角处理。
- 每个面片都是独立的面，因此造型包含许多面，且面之间会绘制线条。

## 设计中的曲面特征

曲面命令位于设计的{{ui:More}}菜单中，列在各个特征之下。它们需要精确内核。曲面实体以蓝色半透明显示。在您加厚或缝合之前，它们不属于实体。

| 命令 | 作用 |
|---|---|
| 修补 | 填充一个闭合的边环。请先按住{{key:Shift}}并点击实体的边，或选择一个曲面实体以填充其开口。**相切(G1)**使修补与该曲面平滑相接。 |
| 放样曲面 | 通过每个草图中的一条曲线链（开放或闭合）生成曲面，按历史顺序排列。 |
| 缝合 | 沿共享边缝合曲面实体。如果它们闭合，结果为实体，并具有与其他特征相同的**操作**。 |
| 加厚 | 为曲面实体赋予厚度：沿其法线方向、反向，或两侧各一半。结果为实体。 |
| 偏移曲面 | 沿法线移动曲面实体的副本。原始曲面保留。 |
| 延伸曲面 | 将单面曲面延伸到您选择的边之外。 |
| 修剪曲面 | 在另一个曲面实体或实体与其相交处切割曲面实体。点击**在片段上选取点**以选择保留哪一片，或保留其余部分。 |

缝合、加厚、延伸和修剪会消耗其起始的曲面实体。之后的特征使用新生成的实体。

当前的限制：由多个独立闭合部分组成的造型无法转换为一个实体；规则区域不会合并为更大的曲面；另请参见[尚未实现的内容](topic:not-built-yet)。
