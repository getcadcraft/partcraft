参数是一个命名数值，例如 `width = 120` 或 `margin = bolt * 1.5`。将深度、孔直径、阵列数量或草图尺寸链接到参数后，修改参数即可一步改变所有这些值。这样即可将设计意图保存在零件中，而无需全靠记忆。

## 添加参数

1. 在右侧面板中，点击{{ui:参数}}选项卡。
2. 在**变量**下，于"名称"框中输入名称，例如 `width`。
3. 在下一个框中输入其值，例如 `120`，然后按 {{key:Enter}}（或点击{{ui:添加}}）。

值可以是数字，也可以是其他参数的表达式：`bolt * 1.5`、`width / 2 - 10`、`if(width > 100, 6, 4)`。**值**列显示计算结果。名称以字母或 `_` 开头，且仅包含字母、数字和 `_`；函数和单位的名称（`sin`、`mm`、`pi`）会被拒绝，循环引用（如 `a = b` 且 `b = a`）同样会被拒绝。

## 将数字链接到参数

1. 在历史记录中点击一个特征，例如 "Extrude1"。其设置会显示在{{ui:属性}}选项卡中。
2. 在数字框中（例如**深度 (mm)**）输入 `=` 和一个表达式：`=thick` 或 `=width / 4`。
3. 按 {{key:Enter}}。

数字框现在显示结果，并在其标签旁出现一个 **ƒ** 按钮。将鼠标指向它即可查看方程。草图尺寸的操作方式相同，既可在特征的**草图尺寸**列表中进行，也可在打开的草图的尺寸框中进行（双击尺寸，输入 `=width`，按 {{key:Enter}}）。

可链接的数字包括：拉伸深度、旋转角度、孔直径、深度和沉孔尺寸、阵列数量、间距和角度、圆角半径、倒角距离、抽壳壁厚、每个草图尺寸，以及较新特征的尺寸（第二深度、锥度、埋头孔、参考平面距离、拔模角度等）。

## 修改参数

在{{ui:参数}}选项卡的**表达式**列中输入新值或表达式，然后按 {{key:Enter}}。所有链接到它的内容都会改变，零件随之重建，作为一步完成：{{key:Mod+Z}} 可撤销此操作。

若要从另一端修改数字，见 [双向方程](topic:equations-two-way)。

## 查看参数的使用位置

在{{ui:参数}}选项卡中，每个参数下方都有一行说明其被哪些内容使用：

- 它所驱动的数字，例如 **Extrude1 depth** 或 **Sketch1 D2 (distance)**。点击其中一项可选中其特征并显示其属性；
- 它通过其他参数**间接**驱动的数字，例如当 `d = h + 2` 且 `h = w / 2` 时的 **Hole1 diameter (through h, d)**；
- 表达式中使用它的**参数**、设置它的**配置**，以及读取它的**脚本**（见 [编写和运行脚本](topic:craftscript)）。

"尚未使用。"表示没有任何内容使用它：可以直接删除，无需确认。

## 解除链接、重命名、删除

- **解除数字链接**：点击其 **ƒ** 按钮，或在**方程**列表中点击{{ui:解除关联}}。它保留当前值，不再受任何参数影响。
- **重命名参数**：在其**名称**框中输入新名称。所有使用它的表达式都会被改写。
- **删除参数**：点击其所在行的 ×。若有内容使用它，PartCraft 会先询问是否将其当前值写入这些表达式。
- **删除特征**会移除其数字的方程；状态栏会说明是哪些方程。

:::note
参数保存在 `.partcraft.json` 文件中（文件版本 3）。没有参数的零件保存方式与之前完全相同。
:::

## 表达式

| 写法 | 含义 |
|---|---|
| `120`、`12.5`、`1e3` | 数字（毫米；用于角度时为度） |
| `2in`、`1ft`、`3"`、`1.5cm`、`0.2m` | 其他单位的长度，换算为毫米 |
| `30deg`、`0.5rad` | 角度，换算为度 |
| `+ - * / %` 和 `^` | 算术运算；`^` 为幂，`-2^2` 为 −4 |
| `sin cos tan asin acos atan atan2` | 三角函数（以度为单位） |
| `sqrt pow exp ln log abs sign` | 其他函数 |
| `ceil floor int round(x, digits) min max` | 取整和极值 |
| `if(test, a, b)` 配合 `< <= > >= == !=` | 条件选择：`if(bolt >= 16, 6, 8)` |
| `pi` | 3.14159… |

名称区分大小写：`Width` 和 `width` 是两个参数。

另见 [配置和设计表](topic:design-tables) 和 [脚本和命令行](topic:scripts-and-cli)。
