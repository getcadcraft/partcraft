## 操作内容

一次性交付零件的**每种尺寸**：每个配置对应一个STEP、IFC和DWG文件以及一张图片；一张表格说明每个配置的含义；以及一个将所有配置放在同一页面上的库项目。

您需要先为零件设置**配置**（见[配置与设计表](topic:design-tables)）。关闭某个特征的配置（例如带孔与不带孔的板件）会成为独立的变体。

## 步骤

1. 打开零件。在{{ui:参数}}选项卡中找到**配置**。
2. 点击{{ui:变体包…}}。
3. 勾选要构建的配置（默认全选）以及要写出的文件：STEP、IFC、DWG、预览图和库项目。
4. 点击{{ui:生成变体包}}。状态栏会随变体的构建进行计数；零件不会被更改。
5. 将下载一个zip文件：`<part> variants.zip`。

## zip文件内容

| 文件 | 内容 |
|---|---|
| `<name>.step` | 该配置的STEP实体。 |
| `<name>.ifc` | IFC4，包含一个构件，内含已构建的实体，并将零件参数作为属性；属性值为该配置自身的值。 |
| `<name>.dwg` | 正视图、俯视图、右视图和等轴测视图，以原尺寸呈现在图纸上。 |
| `<name>.svg` | 该配置的等轴测线条图。 |
| `variants.csv`, `variants.json` | 参数表：每个变体的ID、名称以及每个参数的值、关闭的特征、其文件、体积和尺寸。 |
| `<part>.item.json` | 将零件及其变体作为一个库项目（见下文）。 |
| `README.txt` | 已生成的内容、下方的说明，以及未能构建的项目。 |

文件以配置命名。若某个配置构建失败（某个特征无法用这些值生成），则该配置会从文件和表格中剔除，列在README中，并在zip保存后的消息中提示；其余配置仍会写出。

## 注意事项

- 若构建版本启用了精确内核，**STEP**为精确格式。否则STEP为多面体（平面三角形），README会说明这一点。
- **DWG**是图纸，而不是三维模型。其线条来自网格，因此曲线边由许多短线段组成。
- **库项目**为每个变体包含一个实体和一个占地面积，使用库自身的坐标轴：Z轴朝上，正面朝向-Y，插入点位于底部后侧的中点。平面图为每个变体的外接矩形。项目大小上限为8 MB，因此体积过大的变体会被替换为同尺寸的方块，README会说明有多少个。
- 零件当前激活的配置即为项目的默认变体。
- 端口（管道和风管的连接点）不能在PartCraft中设置。

## 将变体放到库页面上

在网站的**库 › 上传**处上传`<part>.item.json`。选择其类别、许可证以及署名，它即成为带有变体的库项目。在BimCraft中放置该项目时会询问使用哪个变体，而"替换"会提供其他变体。供访客选择选项、查看三维模型并下载变体的页面目前为**员工预览**：尚未向公众开放。

## 命令行

```
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --out-dir plate-variants
node tools/partcraft-cli/partcraft.mjs variants plate.partcraft.json --only "Small,Large" --formats step,preview --zip plate.zip
```

`--only`用于指定配置名称，`--formats`可以是`step`、`ifc`、`dwg`、`preview`中的任意一个，`--no-item`表示不包含库项目。它会写出一个文件夹、一个zip，或两者，并在某个变体无法构建时以退出码1结束。见[脚本与命令行](topic:scripts-and-cli)。
