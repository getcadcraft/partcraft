这是 PartCraft 0.9 相对于 0.8.1 的变化。自由曲面现在可以闭合为实体，数千个零件的装配体仍然可用，Documents 库保存修订，而 Solid FEM 插件检查零件中的应力。每项都说明在哪里找到它。

## 0.9.1 新增

- **精确STEP导出。**{{ui:导出}} › {{ui:STEP AP242（精确实体）}}与{{ui:STEP AP214（精确实体）}}现已可用。孔、凸台、圆角、圆锥、球和环面以其真实曲面写出，边为真圆，因此其他 CAD 或 CAM 程序可以将孔识别为孔。样条侧面、建模螺纹与导入的网格仍在同一实体中保持为平面面片。参见[打印、STEP与DXF导出](topic:export-files#for-other-cad-programs-step)。
- **STEP 导入，精确STEP导出。**你打开的 STEP 文件保留其自身的平面、圆柱、圆锥、球和环面，因此{{ui:导出}} › {{ui:STEP AP242（精确实体）}}会将它们以真实曲面写回，而非面片：供应商的带螺栓孔的梁以原来的面输出，并加上你切入其中的部分。文件中的样条、扫掠与旋转面仍为面片，STL、OBJ 与 3MF 的实体也是如此。对于之前保存的零件，请重新打开其 STEP 文件。参见[打开STEP文件并在其上构建](topic:import-step)。
- **面片DXF中的真圆。**选择平面后，{{ui:导出}} › {{ui:草图或平面的DXF}}现在会将圆孔写为圆，并使用孔自身的圆心与半径，供激光、等离子或水刀切割台使用。其他圆边仍为面片。
- **车间用精确STEP。**在{{ui:制造}}中，{{ui:精确STEP（工件坐标）}}将零件写出，其原点位于装夹的工件原点，Z 沿刀具轴，即 G 代码所用的坐标。参见[生成刀路与G代码](topic:manufacture#exact-step-for-the-shop)。

## 新增

### 曲面与实体

- **面之间的圆角。**在{{ui:工作区}}框中选择{{ui:曲面}}，然后点击{{ui:面之间的圆角}}。选取一个实体的两个面，输入半径（以及{{ui:末端半径（mm，0 = 同起点）}}，用于沿边变化的半径）。结果行会说明该圆角与理想滚球之间的距离，无法适配的半径会被拒绝，并指明面。{{ui:同时对多条边圆角}}一步圆角多条边；勾选{{ui:角点（三条边相交处用球面片）}}，即可在三条圆角边相交处形成球形角。参见[自由曲面（NURBS）](topic:nurbs-surfaces)。
- **加厚为实体。**同一工作区中的{{ui:加厚为实体}}为曲面赋予厚度；{{ui:另一侧}}将其向另一方向增厚。折叠或自交处会被拒绝，并指明曲面与位置。
- **由曲面生成实体。**修剪后的曲面可用并集、差集与交集连接，并作为一个撤销步骤写入零件。STEP 将实体写为一个闭合壳，IGES 写为一个实体；两者读回后都为实体。若面未逐边配对，文件会得到分离的面，状态行会说明。实体也可以在节点编辑器中生成；参见[节点编辑器](topic:nodes)。
- **扫描中的环形圆角与变半径圆角。**将曲面拟合到扫描时，还会查找环形圆角（环面）以及沿较直边的变半径圆角，并列出其半径。仅在模拟扫描上测试过。

### 装配体、文档与链接

- **大型装配体。**副本零件共享一个网格，{{ui:视图}} › {{ui:轻量显示}}以盒体绘制，使视图保持流畅（对于非常大的装配体会自动开启；拾取与连接仍使用真实零件）。零件树显示前几行，其余部分由一个{{ui:显示其余 700 个}}按钮给出。装配文件最多可包含 50,000 个实例和 100,000 个连接。参见[构建装配体](topic:build-assembly)。
- **文档。**{{ui:文档（检出、检入、修订）}}位于**文件**组中，在项目文件夹上打开一个对话框：检出与检入、修订字母、状态（进行中、待审核、已发布、已废弃）、历史、使用位置与物料清单。参见[文档与修订（库）](topic:documents-walkthrough)。
- **实时Rhino链接。**一个脚本`cadcraft_link.py`监视 Rhino 或 Grasshopper 文档，仅将变化的内容推送到 PartCraft，导入的特征会在新形状上重建。该链接为单向，需要 Studio。参见[实时 .3dm 链接](topic:live-3dm-link)。
- **相互查看光标。**在共享会话中，每人的光标会显示其名字及其所选特征。参见[与他人实时协作](topic:work-live)。
- **车间。**在{{ui:设置}} › {{ui:插件}}中开启车间插件。在{{ui:制造}}中发布程序后，其选项卡可以{{ui:添加到车间作业队列}}或{{ui:另存为作业文件}}。它从不发送或启动机床。

### 分析与零件

- **Solid FEM 插件。**在{{ui:设置}} › {{ui:插件}}中开启{{ui:Solid FEM}}（默认关闭，直到你开启），右侧面板会出现{{ui:Solid FEM}}选项卡。{{ui:网格化零件}}，在三维视图中拾取固定面与载荷，{{ui:求解}}，并以{{ui:在模型上显示}}绘制位移、von Mises 应力或振型。参见[Solid FEM：应力检查](topic:solid-fem-check)。
- **草图圆弧，十种方法。**草图工具栏中{{ui:圆弧}}旁的箭头列出：三点、起点-圆心-端点、起点-圆心-角度、起点-圆心-长度、起点-端点-角度、起点-端点-方向、起点-端点-半径、圆心-起点-端点、圆心-起点-角度、圆心-起点-长度，以及延续。参见[用十种方法绘制圆弧](topic:sketch-arc-methods)。
- **英制钢型材。**焊接件可使用 976 种英制型材（UB、UC、PFC、EA、UEA、CHS、SHS、RHS）；输入如`305x165x40 UB`的尺寸。参见[结构构件](topic:structural-members)。

### 打印

- **打印阶段。**工具栏中的{{ui:打印阶段}}按钮（3D 打印插件，默认开启）将零件的实体放在虚线打印床上：{{ui:展开}}、旋转 90°、在打印床上排列、全部放入打印床、预览层，然后通过 USB、Klipper（Moonraker）、OctoPrint 或 PrusaLink 使用{{ui:发送到3D打印机}}。在你确认之前不会发送任何内容，零件也绝不会被更改。若要使用 STL 或 3MF 文件，参见[为3D打印准备零件](topic:print-3d)。
- **树脂打印。**插件位于{{ui:设置}} › {{ui:插件}}中，默认全部关闭，直到你开启：树脂切片器、曝光测试，以及文件格式 Elegoo GOO、SL1、Chitubox CBDDLP/CTB 与 Anycubic。切片在工作线程上运行，因此页面保持响应。

## 已知限制

- 精确 STEP 已在 OpenCascade 中回读（有效实体，体积与手算值相等）。它尚未在每个 CAD 或 CAM 程序中打开，装配体也不写为精确 STEP。
- 尚未在实际打印机上打印过任何内容。切片、G 代码与树脂文件由我们自己的程序或替代打印机回读；没有任何树脂格式在打印机上加载过，打印机尺寸与曝光只是起始值。
- Solid FEM 为线性、各向同性、弹性，每个零件一种材料，无接触、屈服或屈曲。固定面与尖角处的应力取决于网格。它是一种检查辅助工具，未经工程师审核。
- 大型装配体的计时来自无 GPU 的服务器；在那里，20,000 个零件的全细节帧仍需数秒。
- 圆角适用于成对的面；没有通用的顶点融合，也没有不相交的面之间的圆角。
- Rhino 链接从未在真实的 Rhino 或 Grasshopper 中运行。Documents 仅由两个程序在同一文件夹上试过，未由两人在网络共享上试过。
- 将曲面拟合到真实扫描尚未经过人工检查。除英语外的语言均为机器草稿。
- Windows 安装程序未经代码签名，macOS 磁盘映像未经公证。参见[故障排除](topic:troubleshooting)。

## 更早：0.8 与 0.8.1

这是 PartCraft 0.8 与 0.8.1 相对于 0.7 的变化。仿真可在你编辑时给出答案，并告诉你最先破坏的是什么；装配体可以进行运动研究；新的工作区使自由曲面与由物理决定的零件可以得到。0.8.1 为小型修复版本。

### 新增

**仿真**

- **编辑时更新。**在求解块中勾选{{ui:编辑时更新}}，你编辑时答案会随之更新。更改尺寸、载荷或材料，即刻显示用四倍大单元所做的快速答案；停顿约一秒后，研究自身的精细结果会替换它。结果会说明你正在查看哪一个。对钢悬臂梁而言，快速答案在挠度上与精细结果相差不到 1%，在应力上约为 4%。参见[检查应力与变形](topic:simulation#update-while-you-edit-live)。
- **最先破坏的是什么。**对静力或屈曲研究，**破坏分析**块中的{{ui:最先破坏的是什么？}}按比例放大荷载直至零件失效。它按从最危险到最不危险的顺序列出屈服的荷载系数（在应力峰值处有红色标记）与屈曲的荷载系数。系数小于 1 表示零件在当前荷载下已经失效，“问题”面板会显示错误。这些系数来自线性研究，因此其准确性与之相同。参见[检查应力与变形](topic:simulation#find-out-what-breaks-first-break-it)。
- **屈服与接触。**另外两种研究类型：非线性研究，其中材料沿直线至屈服应力再沿较平缓的斜率变化，并绘制塑性应变；以及接触研究，其中分离的部件相互推压（无摩擦）或保持粘结（粘结）。若某载荷步无法收敛，或部件相互侵入过深，会显示在“问题”面板中。摩擦、大滑移、大转动、大变形与疲劳未求解。参见[检查应力与变形](topic:simulation#yielding-and-contact-nonlinear-studies)。
- **CalculiX 输入文件。**{{ui:导出}} › {{ui:CalculiX 输入文件 (.inp)}}将研究保存为 CalculiX 格式（一个你需自行安装并运行的独立程序）；{{ui:导出}} › {{ui:CalculiX 结果 (.frd)}}将其结果文件读回同一网格。PartCraft 从不启动该程序，若保存输入文件之后零件已更改，它会说明。

**装配体**

- **运动研究。**{{ui:装配体}} › {{ui:运动}}在你给定的时间内驱动一个连接的值（匀速、缓动、正弦，或往返），在每一步按其连接与闭合环放置装配体，并报告哪些部件发生干涉以及它们靠得多近。{{ui:添加点}}绘制一点的位置、速度与加速度、连接的值以及间隙随时间的变化；{{ui:保存 CSV}}与{{ui:保存图}}将其写出。运行后，运行条中的“逐步查看运行”可将装配体移至任一步。研究的设置保存在装配文件中。速度与加速度由记录的位置计算，因此若尖峰读数偏低，请使用更多步。参见[检查装配体的干涉与运动](topic:check-assembly#a-motion-study)。

**由物理决定的曲面与零件**

- **曲面工作区。**在{{ui:工作区}}框中选择{{ui:曲面}}，可在零件旁使用 NURBS 曲线与曲面：{{ui:曲线}}、{{ui:放样}}、{{ui:扫掠}}、{{ui:匹配}}与{{ui:斑马纹}}，连续性（G0、G1 或 G2）在精确曲面上测量，比你要求的差的边会列在“问题”中并附有匹配修复。{{ui:光顺}}测量型线的拐点与曲率突变，并在你的公差内重建不光顺的部分。曲面保存在零件文件中，不改变零件的特征。参见[自由曲面（NURBS）](topic:nurbs-surfaces)。
- **工程师工作区。**在工作区切换器中选择{{ui:Engineer}}，选择一个生成器并点击{{ui:新建}}：脚本根据零件必须完成的功能（移动热量、流量、压力、材料、打印工艺）用教科书公式确定尺寸并构建零件，然后给出所用数值及其来源、制造检查以及供分析工具使用的文件。相同输入在任何计算机上得到相同零件。生成器保存在零件中，打开零件时从不运行脚本。参见[由物理决定的零件：生成器](topic:engineer-generators)与[编写生成器](topic:write-a-generator)。

**绘图与制造**

- **由照片生成草图。**{{ui:特征}} › {{ui:更多}} › {{ui:由照片生成草图…}}将平放在素色底面上的平面零件（轮廓与孔）或钢笔图画描成直线、圆弧与圆。你给定一个长度，检查预览并生成草图。参见[草图基础](topic:sketch-basics#a-sketch-from-a-photo)。
- **为打印缩放与分割。**{{ui:导出}} › {{ui:打印缩放（STL 或 3MF）…}}按各轴缩放，而不改变零件，例如按收缩余量。{{ui:导出}} › {{ui:打印分割（零件压缩包）…}}将超过打印床的零件切成编号的块，块之间用销、键、燕尾、销孔或磁铁槽连接。参见[三维打印](topic:print-3d)。
- **排入板材并生成G代码。**{{ui:导出}} › {{ui:嵌套板材转 G 代码}}读取嵌套的 DXF，并通过你选择的后处理器为每张板材生成一个程序：先孔与切口，然后轮廓。它不规划引入线、切割顺序或共享边。参见[在板材上排样平板零件](topic:nest-flat-parts#cut-the-sheets-g-code)。
- **更自动的图纸。**{{ui:图幅}} › {{ui:自动}}选择能容纳视图的最小 A 系列图幅，比例为不超过 1:1 的最大标准比例。{{ui:标注孔尺寸}}为每个孔标注中心线，每种尺寸一个引注，并从视图左下角给出位置。参见[绘制图纸](topic:drawing-pdf)。

**各应用通用**

- **语言。**应用提供 54 种语言。除英语外的语言均为机器草稿，直到母语者审读。
- **工具栏行数。**{{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}}可选择换行（同之前）、2 行或 1 行；放不下的工具栏横向滚动。PartCraft 的特征功能区将最常用的工具大号显示，并将变体收于分割按钮之后。
- **连接你的 AI。**Studio 是将你自己的助手连接到全部八个应用的中心，每个应用可设定只读、建议或编辑权限。连接的助手可以根据一句话（例如承受某荷载的支架）确定零件尺寸，展示其计算过程与所有检查，并构建它；它会报告未检查的内容（应力集中、疲劳、塑料蠕变）。参见[与 AI 助手一同使用 PartCraft](topic:use-with-ai-assistants)。
