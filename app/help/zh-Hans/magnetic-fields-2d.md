PartCraft 的分析库可以计算二维中线圈和铁芯的磁场：即沿长度方向截面相同的细长物体的截面，例如电磁铁、变压器铁芯、母线或电机的截面。本教程将运行分析库中的电磁铁示例，解读其输出，对其进行修改，演示如何建立自己的模型，然后再添加一个永磁体。

本教程使用脚本工作空间和[分析库](topic:craftscript-library)。学习本教程无需了解 CraftScript 语言；示例会说明每一行的作用。

## 建模内容

一个 C 形铁芯，外形尺寸为 100 × 80 mm，厚 20 mm，其右侧支腿中有一个 2 mm 的气隙。一个 100 匝、通过 10 A 电流（1000 安匝）的线圈缠绕在其左侧支腿上。所有结构都沿垂直于屏幕的方向延伸较长，因此结果为**每米深度**：对于实际磁体，请乘以实际深度。

分析库的 `magnetostatic2d` 在磁体周围空气盒中、以 1 mm 方格网格求解磁矢量势，然后由此计算磁通密度 **B**（单位为特斯拉）。

## 运行示例

1. 在工具栏左侧的**工作空间**框中选择**脚本**。
2. 打开脚本面板的**库**选项卡，然后依次选择**示例** › **电磁铁：磁场、气隙、电感**。
3. 点击 {{ui:打开（只读）}}，然后按 {{key:F5}}。

一两秒后，画布上会显示磁通密度，控制台会输出：

```
气隙中的 B 为 0.5427 T；磁路计算值为 0.5516 T（-1.6 %：边缘效应和漏磁）
电感为每米深度 0.1539 H；磁路计算值为 0.1103 H/m，未计入漏过气隙的磁通
储能 7.694 J/m；|B| 在窗口内角处达到峰值 1.97 T（实际钢材在此处会饱和）
跨气隙的吸力约为每米深度 2343 N（深 50 mm 时为 117.2 N）
```

画布下方的曲线图显示沿铁芯中线、从左到右的竖直磁通密度 B_y：左侧支腿约为 −0.55 T（磁通沿其向下流动），窗口内几乎为零，而右侧支腿及气隙处为 +0.55 T（磁通向上回流）。同一磁通穿过铁芯和气隙，因此两侧支腿与气隙处的数值几乎相同。

## 结果解读

- **气隙中的磁场**为 0.543 T。手工计算将铁芯视为一个磁路，B = μ0 N I / (g + l / μr)，其中 g 为气隙，l 为穿过铁芯的路径长度，μr 为铁的相对磁导率；得出 0.552 T。磁场略低于手工计算值，是因为磁通在气隙周围向外扩散（边缘效应），且有部分磁通直接穿过窗口形成短路（漏磁）。气隙更小或网格更细时，两者会更加接近。
- **100 匝线圈的电感**为每米深度 0.154 H，由磁场中储存的能量得出。磁路公式给出的数值较小（0.110 H/m），因为它只计入穿过气隙的磁通，而未计入漏过气隙的磁通。
- **闭合气隙的吸力**为 B² w / (2 μ0)，其中 w 为气隙面的宽度：约每米 2300 N，或深 50 mm 的磁体为 117 N。
- **1.97 T 的峰值**位于窗口的内角处，此处磁通急剧转向。模型将铁视为线性；实际的电工钢在约 1.5 至 2 T 时饱和，因此高于此值的数值应视为警告，而非结果。

:::note
分析库自身的测试会运行此示例，并在每次更改 PartCraft 时，将气隙磁场与磁路公式进行比对。该方法、参考文献及其他检验（长螺线管、带铁芯螺线管）均记录在 `magnetostatic2d` 的文件头中：请在库中点击它即可查看。
:::

## 修改设计

1. 点击只读脚本上方的 {{ui:制作副本}}。副本会随零件一同保存。
2. 修改顶部附近的一个数值，然后再次按 {{key:F5}}。可以尝试：
   - `g = 0.001;` — 气隙减半：气隙磁场几乎翻倍，吸力也随之翻倍（吸力与 B² 成正比）。
   - `mur = 200;` — 铁芯较差：更多的安匝消耗在铁中。
   - `N = 200;` — 匝数加倍：磁场加倍，电感增至四倍。
   - `h = 0.0005;` — 网格更细：结果更精确，耗时约为四倍。

每次运行都会替换画布。脚本生成的变量（如 `Bgap`、`L`、`F`）会保留在**变量**列表中，供自行计算时使用。

## 建立自己的模型

示例通过三个列表构建全部内容，每个方格对应一个值；对于沿网格以直线绘制的任意形状，都可以这样构建：

- **铁的位置：** `iron` 在铁芯内部的方格中为 true。示例由矩形构建它：`frame & ~window & ~gap` 表示“在框架内，不在窗口内，不在气隙内”。
- **磁导率：** `1 + (mur - 1) * iron` 在空气中为 1，在铁中为 `mur`。若有多种材料，可以以同样方式分别赋值。
- **电流：** `J` 为电流密度，单位为安培每平方米，垂直于屏幕向外为正，向内为负。线圈的两边符号相反；示例计算 `J0`，使其中一边携带 N I。

然后，`r = magnetostatic2d(m, permeability, J)` 进行求解。`r.B` 为每个方格中的磁通密度（两列，分别为 x 和 y），`r.Bmag` 为其大小，`r.energy` 为每米的储能。`plot(x, y)` 绘制一条曲线。

分析库以米为单位工作，而视图以毫米为单位，因此若直接显示磁场，其图形会缩小一千倍。示例在毫米单位的网格副本上显示它（`mm = quadGrid(…)`，然后 `show(field(mm, …))`）：请复制这两行。

默认情况下，盒子的边界会将磁场束缚在内：没有磁通从其穿出。请使盒子至少为磁体尺寸的两到三倍，以免挤压磁场。对于对称磁体，可以只建模其一半：`magnetostatic2d` 的文件头中说明了在对称线上应使用的边界条件。

## 永磁体

第二个示例为 **示例** › **铁芯中的永磁体：工作点、漏磁、吸力**，它与前一个铁芯相同，但去掉了线圈，并将左侧支腿中 10 mm 厚的一段替换为向上充磁的磁体。使用 {{key:F5}} 运行它。输出如下：

```
磁体工作点：B = 1.036 T，H = -124 kA/m（位于其回复线上：B = Br + μ0 μr H）
气隙中的 B 为 0.6778 T；无漏磁的磁路计算值为 0.9692 T（-30.1 %）
漏磁系数 1.53：离开磁体的磁通中，65 % 穿过两极面之间的气隙
跨气隙的吸力约为每米深度 3656 N（深 50 mm 时为 182.8 N）
```

- **工作点。** 磁体由其**剩磁** Br（被铁短路时保持的磁场：烧结钕铁硼磁体约为 1.2 T，铁氧体约为 0.4 T）和回复磁导率（约 1.05 和 1.1）描述。打开气隙会使其沿回复线下移：此处降至 1.04 T，其内部 H 的方向与 B 相反。
- **漏磁。** 不计漏磁的手工计算给出气隙中 0.97 T；模型给出 0.68 T。磁体在较短的长度上以强大的推力驱动其磁通，因此大量磁通直接穿过窗口回流，而不是穿过气隙。漏磁系数说明了其程度：此处为 1.53。若设置 `g = 0;`（闭合衔铁），磁体工作状态将与手工计算相差在 0.5% 以内。
- **自定义模型中的磁体。** 将磁体以 `struct('Br', Br)` 形式提供给 `magnetostatic2d`，其中 `Br` 每个方格一行，包含沿 x 和 y 方向的剩磁（单位为特斯拉，磁体之外为零），并在磁导率列表中为磁体方格赋予其回复磁导率：

  ```
  Brem = [zeros(numel(mag), 1), 1.2 * mag];     % mag 为 true 的方格中，向上 1.2 T
  r = magnetostatic2d(m, 1 + (mur - 1) * iron + 0.05 * mag, 0, struct(), struct('Br', Brem));
  ```

  对于按某一角度充磁的磁体，将 `Br·cos(angle)` 和 `Br·sin(angle)` 分别放入两列；对于向外充磁的环形磁体，则根据每个方格的位置计算其方向。`r.H` 给出每个方格中的磁场强度 H。

无论磁体受到多大驱动，模型都会使其保持在直线回复线上。实际磁体若被驱动超过其拐点（如大气隙、强线圈或高温），将永久损失部分强度；请对照厂商针对该牌号和温度给出的曲线检查工作点。

分析库的测试将磁体与两个手工计算结果进行比对：空气中的圆形磁体（其内部 B = Br / (1 + μr)）以及由铁衔铁闭合的磁体（磁路），两者误差均在 1% 以内。

## 尚未实现的功能

- **饱和。** 铁为线性：电流加倍，磁场即加倍，且无上限。
- **退磁。** 磁体保持在其直线回复线上（见上文）。
- **涡流**和**损耗**（铁损、铜损）。
- **运动部件和扭矩。** 不包括定子中转动的转子，也不包括扭矩随角度的变化。
- **圆形。** 网格由等大的方格构成，因此曲线轮廓会呈阶梯状。
- **三维。** 所有内容均为细长物体的截面。

电机设计（二维中的旋转转子、扭矩和损耗）正在考虑纳入后续版本。参见[尚未实现](topic:not-built-yet)。
