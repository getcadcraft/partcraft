PartCraft 与 SolidWorks 可双向交换零件，无需使用他人无法读取的文件格式：

- **导出：**一个宏（`.swb`，纯文本），由 SolidWorks 运行后逐个特征地自行构建零件，包括其草图、几何关系、尺寸、全局变量和方程。得到的是一个带实时特征树的原生零件，而非静态实体。
- **回传：**在 SolidWorks 中运行的宏会将零件的特征和方程写入一个 `.cadcraft-sw.json` 文件。在 PartCraft 中打开该文件的功能本版本尚未实现（需要精确内核）。

:::warning
以上功能尚未在 SolidWorks 中测试。SolidWorks 仅在带有许可证的 Windows 上运行，而 PartCraft 从未在其中运行过这些宏。这些宏依据 SolidWorks API 文档编写，并在此处进行了结构检查。可能会遇到问题，请予以反馈；宏写入的日志会指明哪一步失败。
:::

PartCraft 无法写入 `.sldprt` 文件，因为该格式是封闭的。获得原生零件的方法是使用宏。

## 将零件作为宏发送

1. 打开零件。
2. 选择{{ui:导出}}，然后选择{{ui:用于SolidWorks的宏（.swb）}}。PartCraft 将下载 `<part>.swb`，状态栏会显示其为“未使用精确内核写入”。
3. 对话框会显示宏将构建的特征、全局变量和方程的数量，并列出被省略的内容。本版本不会在其旁生成 STEP 文件：如需 STEP，请使用{{ui:导出}}，然后选择{{ui:STEP（面片，网格内核）}}。
4. 在 SolidWorks 中选择 **工具 > 宏 > 运行**，选择 `.swb` 文件并等待。它会基于默认零件模板新建一个零件，设置单位为毫米，并构建每个特征。
5. 完成时，消息会显示已完成的步骤数、失败的步骤数以及与 PartCraft 实体相符的数量。完整日志 `<part> macro log.txt` 会写在宏文件旁。

宏构建的内容：

| PartCraft | 在新零件中 |
|---|---|
| 草图位于前视、上视或右视基准面 | 位于该基准面上的草图，包含其直线、圆弧、圆、点、几何关系和尺寸（名称与 PartCraft 中相同，例如 `k7`） |
| 草图位于表面上 | 位于同一表面上的草图，通过其上的一点进行选择 |
| 草图位于固定基准面上 | 通过三点定义的参考基准面，以及位于其上的草图 |
| 拉伸、切除（给定深度、完全贯穿、中面、双向、拔模） | 凸台拉伸或切除拉伸 |
| 旋转、旋转切除 | 绕相同中心线旋转 |
| 孔（简单孔、沉头孔、埋头孔、攻丝孔） | 一个或两个切除，各带有自己的草图（攻丝孔按其底孔处理；不含螺纹） |
| 线性阵列、环形阵列、镜像 | 线性阵列、环形阵列、镜像（特征或实体） |
| 圆角、倒角、抽壳 | 对相同边和面进行圆角、倒角和抽壳，通过点选择 |
| 参数和方程 | 作用于重命名尺寸的全局变量和方程 |
| 被压缩的特征、回滚栏 | 以相同方式压缩；回滚栏位于相同位置 |

每个实体特征完成后，宏会将实体的体积和尺寸与 PartCraft 的进行比较。若二者不同，它会将该特征的方向反转一次并重新检查；若结果没有改善，则将其恢复，并在日志中写入“Check”。

### 省略的内容

对话框和宏的开头列出了所有未被转换的内容及原因。目前包括：导入的实体（请改为插入 STEP）、扫描、放样、拔模、参考轴和参考点、“直到”结束条件、仅拉伸部分轮廓，以及依赖上述内容的所有对象。样条将转换为通过其各点的曲线。本版本没有精确内核，因此位于表面上的草图以及通过选择边或面而生成的特征同样被省略。

## 发送命名 STEP

本版本尚未实现：{{ui:用于SolidWorks的STEP（具名，AP214）}}需要精确内核，选择该项时会提示“用于 SolidWorks 的 STEP：尚未实现。…”。若有精确内核，文件将包含零件名称、毫米单位和零件颜色，并使 Y 轴朝上，与 SolidWorks 显示零件的方式一致（普通的{{ui:STEP AP214（精确实体）}}导出则使 Z 轴朝上）。名称中的带重音字母会丢失重音，超出普通 ASCII 的其他字符会转换为 `_`。

## 回传零件

在 PartCraft 中打开该文件（第 3 步）本版本尚未实现：会提示“打开 SolidWorks 导出文件：尚未实现。…”。CadCraft 制图应用仍可打开该文件并获取其草图。

1. 选择{{ui:文件}} > {{ui:导出}} > {{ui:导出用于带回零件的宏（.swb）}}，下载 `CadCraftExport.swb`，并将其放在零件旁边。
2. 在 SolidWorks 中打开零件，选择 **工具 > 宏 > 运行**，然后选择 `CadCraftExport.swb`。它会在零件旁写入 `<part>.cadcraft-sw.json`，且不会更改零件本身。
3. 在 PartCraft 中选择{{ui:打开}}并选中该文件，或将其拖放到三维视图中。
4. 若有精确内核，PartCraft 会逐个特征地重建零件，并显示其执行的内容：例如“已从 SolidWorks 转入 5 个特征（共 5 个）（Flange.SLDPRT）”、未能转入的每个特征（“未转入：Sweep1（扫描）。”），以及体积是否与 SolidWorks 写入的体积一致。
5. 使用{{ui:保存}}将其保存为 PartCraft 零件。

草图位于基准面上时会放置在对应基准面上；若零件上存在对应的平整表面，则放置在该表面上（因此会跟随之后的编辑）；否则放置在固定基准面上。圆角、倒角和抽壳的边和面通过点来定位，并保留为命名引用。全局变量会成为参数（含空格的名称将以下划线代替空格：“Bolt count”变为 `Bolt_count`），方程则成为作用于相同尺寸的方程。不作任何猜测：没有对应项的内容会被列出。

CadCraft 制图应用可打开同一文件并获取其草图。

:::note
格式为 `cadcraft-sw-export` 第 1 版，为以毫米和度为单位的纯 JSON。来自较新宏的文件或无效文件会被拒绝，并说明原因。
:::
