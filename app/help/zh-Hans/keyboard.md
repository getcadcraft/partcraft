在面板的输入框中打字时，按键不起作用，但 {{key:Mod+S}} 和 {{key:Mod+O}} 始终有效。字母键无需配合修饰键即可使用。

关于浏览器中的按键以及没有功能键的键盘的通用说明：[按键、鼠标和触控板](common:keys)。

## 通用

| 按键 | 操作 |
|---|---|
| {{key:Mod+S}} | 保存零件（在装配体中则保存装配体）。若草图处于打开状态，先将其关闭 |
| {{key:Mod+O}} | 打开零件或装配体文件（若有未保存的更改，会先询问） |
| {{key:Mod+Z}} | 撤销 |
| {{key:Mod+Y}} 或 {{key:Mod+Shift+Z}} | 重做 |
| {{key:F1}} | 打开或关闭本帮助（应用栏中的 {{ui:帮助}} 同样可以）。{{key:Esc}} 也可关闭。在许多笔记本电脑和 Mac 键盘上，需按住 Fn |
| {{key:Ctrl+Shift+F}} | 屏幕模式：普通、全屏、隐藏工具栏的全屏。在 Mac 上也使用 Control，而非 ⌘ |
| {{key:Esc}} | 退出全屏（仅在全屏时） |
| {{key:Mod+,}} | 设置，包括 PartCraft 选项卡（见 [PartCraft 设置](topic:settings)） |

在面板的数值框中，{{key:Mod+Z}} 是浏览器自带的文本撤销。在草图标注上方的数值框中，它则在 PartCraft 中撤销。

## 复制、粘贴和创建副本

它们作用于当前正在编辑的内容：打开的草图中所选的几何图形、历史列表中所选的特征，或装配体中所选的零件。详情见[复制、粘贴和创建副本](topic:copy-paste)。

| 按键 | 操作 |
|---|---|
| {{key:Mod+C}} | 复制所选内容 |
| {{key:Mod+X}} | 剪切：先复制，再删除 |
| {{key:Mod+V}} | 粘贴。在草图中，副本会跟随指针：点击即可放置 |
| {{key:Mod+Shift+V}} | 原位粘贴：坐标相同（在装配体中则位置相同） |
| {{key:Mod+D}} | 创建副本：一步完成复制和粘贴，不改变剪贴板 |
| {{key:Mod+A}} | 全选（在草图中） |
| {{key:Esc}} | 取消选择（并取消跟随指针的粘贴） |

在数值框中，这些按键照常复制和粘贴文本。面板中所选的文本由浏览器复制。

## 在零件上（未打开草图）

| 按键 | 操作 |
|---|---|
| {{key:S}} | 在所选基准面或平面上创建草图；若未选择，则点击选择位置 |
| {{key:F}} | 将零件适合放入视图 |
| {{key:M}} | 测量，适用于所有工作空间和装配体；{{key:Esc}} 清除拾取，再按一次 {{key:Esc}} 关闭（见 [测量距离、角度和质量](topic:measure)） |
| {{key:X}} | 开启或关闭剖面视图，适用于所有工作空间和装配体；{{key:Esc}} 关闭（见 [使用剖面视图查看内部](topic:section-view)） |
| {{key:Delete}} | 删除所选特征（若其他特征正在使用，会先询问） |
| {{key:0}} … {{key:9}}、{{key:.}} | 选中特征时：输入其主要数值（拉伸的深度、孔的直径、阵列的数量、圆角的半径等），然后按 {{key:Enter}}。按 {{key:Esc}} 保留原值 |
| {{key:Backspace}} | 删除所选特征（需已选中特征） |
| {{key:Esc}} | 停止选择草图基准面，或清除选择（包括用 {{key:Shift}} 拾取的边或面） |

## 在三维视图中

先在视图中单击，使其获得键盘焦点。

| 按键 | 操作 |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 将视图旋转 15 度 |
| {{key:Shift+Left}} 及其他方向键 | 平移 |
| {{key:Plus}} 或 {{key:=}} | 放大 |
| {{key:Minus}} | 缩小 |

| 鼠标 | 操作 |
|---|---|
| 按住左键拖动 | 环绕（旋转）视图 |
| 按住右键或中键拖动 | 平移 |
| 按住 {{key:Shift}}、{{key:Ctrl}} 或 ⌘ 的同时按住左键拖动 | 平移 |
| 滚动滚轮 | 以指针位置为中心缩放（向远离的方向滚动为放大） |
| 触控板上双指滑动 | 旋转视图；配合 {{key:Shift}} 则平移。捏合缩放。由 [PartCraft 设置](topic:settings) 中的**滚动**决定 |

在 [PartCraft 设置](topic:settings) 中选择**视图旋转：中键**后，中键用于旋转视图，{{key:Shift}} 加中键或右键用于平移，左键仅用于拾取。
| 单击 | 拾取一个面（整个面会高亮）、一条边或一个平面 |
| {{key:Shift}}+单击边或面 | 拾取多条边或多个面 |
| 单击空白处 | 清除拾取 |

## 为圆角、倒角或抽壳选择边或面时

| 按键或鼠标 | 操作 |
|---|---|
| 单击边或面 | 添加该边或面；若已在选择中则移除 |
| {{key:Esc}} 或 {{key:Enter}} | 完成拾取（与 {{ui:完成}} 相同） |
| {{key:F}} | 适合窗口 |
| 方向键（视图已获得焦点时） | 旋转；配合 {{key:Shift}} 则平移 |

## 在图纸上

| 按键 | 操作 |
|---|---|
| {{key:F}} | 将图纸适合窗口 |
| {{key:Plus}} / {{key:Minus}} | 缩放（图纸获得焦点时） |
| {{key:Shift+Left}} 及其他方向键 | 平移（图纸获得焦点时） |
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | 将所选 GD&T 符号微移 1 mm |
| {{key:Delete}} 或 {{key:Backspace}} | 删除所选符号 |
| {{key:Esc}} | 停止放置符号；否则取消选择；否则返回模型 |

| 鼠标 | 操作 |
|---|---|
| 在视图上单击（已选择基准、特征控制框、表面处理或详图） | 在此处放置（自动吸附到最近的线） |
| 单击符号 | 选择它 |
| 拖动符号 | 移动它（引线保持指向其点） |
| 滚动滚轮 | 以指针位置为中心缩放 |
| 按住右键或中键拖动 | 平移 |

### 在数值框中

| 按键 | 操作 |
|---|---|
| {{key:Enter}} | 应用该值 |
| {{key:Esc}} | 关闭且不作修改 |

点击其他位置同样会应用该值。

## 在历史列表中

| 按键 | 操作 |
|---|---|
| {{key:Tab}} | 进入列表 |
| {{key:Up}} / {{key:Down}} | 在行之间移动 |
| {{key:Enter}} 或 {{key:Space}} | 选择该行 |
| {{key:Alt+Up}} / {{key:Alt+Down}} | 上移或下移所选特征（在历史记录允许的情况下） |
| {{key:F2}} | 在其所在行修改特征的主要数值；{{key:Enter}} 确认，{{key:Esc}} 保留原值 |

| 鼠标 | 操作 |
|---|---|
| 单击 | 选择基准面或特征 |
| 双击草图 | 打开它 |
| 双击特征的数值 | 在行内修改它 |

## 在装配体中

| 按键 | 操作 |
|---|---|
| {{key:J}} | 开始一个连接：然后在两个零件各单击一个平面 |
| {{key:F}} | 适合窗口 |
| {{key:Esc}} | 取消已开始的连接，或清除选择 |
| {{key:Delete}} | 移除所选零件或连接 |
| {{key:Backspace}} | 移除所选零件或连接 |
| {{key:Mod+Z}} / {{key:Mod+Y}} | 在装配体自身的列表中撤销和重做 |
| {{key:Mod+D}} | 创建所选零件的副本（相同零件，放在其他零件旁边） |
| {{key:Mod+C}}，然后 {{key:Mod+V}} 或 {{key:Mod+Shift+V}} | 复制零件，将其粘贴在其他零件旁边或相同位置 |

视图中的鼠标操作与上文三维视图相同。单击零件即可选中。在列表中双击零件即可编辑。

## 在脚本工作空间中

| 按键 | 操作 |
|---|---|
| {{key:F5}} | 运行脚本（在编辑器、面板或视图中均可） |
| {{key:Mod+Enter}} | 运行所选行，或光标所在的行 |
| {{key:Tab}} / {{key:Shift+Tab}} | 缩进 / 取消缩进所选行。若要用键盘离开编辑器，按 {{key:Esc}}，然后按 {{key:Tab}} |
| {{key:Mod+/}} | 将所选行注释掉，或取消注释 |
| {{key:Mod+F}} / {{key:Mod+H}} | 在脚本中查找 / 查找并替换；{{key:Enter}} 或 {{key:F3}} 跳到下一个匹配项，{{key:Shift+Enter}} 或 {{key:Shift+F3}} 跳到上一个，{{key:Esc}} 关闭 |
| {{key:Mod+Shift+[}} / {{key:Mod+Shift+]}} | 折叠 / 展开光标所在的代码块（函数、if、for、while 等直至 end） |
| {{key:Mod+Space}} | 列出正在输入的名称的补全项（输入两个字母后也会自动弹出）；{{key:Up}} / {{key:Down}} 选择，{{key:Enter}} 或 {{key:Tab}} 采用，{{key:Esc}} 关闭 |
| 控制台下方那一行中按 {{key:Enter}} | 运行该条语句；{{key:Up}} 和 {{key:Down}} 调出之前的语句 |
| {{key:F}} | 将视图适合窗口，显示脚本输出的内容 |

参见[编写和运行脚本](topic:craftscript)。

## 浏览器可能占用的快捷键

- {{key:Mod+Y}} 在 Safari 中可能打开历史记录：改用 {{key:Mod+Shift+Z}} 重做。
- {{key:Mod+D}} 是浏览器的书签快捷键：应用获得焦点时由 PartCraft 接管，在输入框中输入时则不做处理。
- {{key:F11}} 和 {{key:Mod+Plus}} / {{key:Mod+Minus}} 是浏览器的全屏和网页缩放，不属于 PartCraft。全屏请使用 {{key:Ctrl+Shift+F}}，模型缩放请使用滚轮。
- 许多笔记本电脑和 Mac 上的功能键需要按 Fn 键：按 Fn+{{key:F1}} 打开帮助，或使用 {{ui:帮助}} 按钮。

触摸和触控板手势：[触控板、触摸和小屏幕](topic:trackpad-and-touch)。

## “移动”命令的位置

“移动”位于“特征”组的 {{ui:更多}} 菜单中，名称为 {{ui:移动实体}}；也可在输入 ΔX、ΔY 和 ΔZ 的 {{ui:移动}} 框中使用；还可以用零件上的 {{ui:拖动移动}} 箭头。
