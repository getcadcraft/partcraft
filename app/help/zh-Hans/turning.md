制造工作空间为车床提供七项操作。它们适用于任何零件：切削的是零件绕毛坯中心旋转时所形成的**轮廓**，因此非圆形的零件会被车削至能够装夹它的圆形轮廓。

**这里的任何内容都未在车床上运行过。** 刀路由测试针对几何进行检查；两种车床后处理器遵循数控系统文档记载的代码。请先在数控系统自带的模拟器中验证程序，并在空中试切。

## 装夹设置

在**装夹**选项卡上：

- **刀具轴**为主轴轴线，即车床的 Z。零件正面位于 +Z；卡盘夹持另一端。
- **毛坯**：选择{{ui:圆柱}}，即棒料。其顶部偏移量即为端面车削去除的量。
- **工件原点**：毛坯顶部或模型顶部中心将 Z0 放在正面，这是常用位置。
- **数控系统**：{{ui:Fanuc式车床(.nc)}}或LinuxCNC车床(.ngc)。铣削后处理器会拒绝车削程序并说明原因。
- **最大主轴转速**：表面速度所保持的上限。

制造工具栏中的{{ui:更多}}会在**操作**选项卡顶部列出七项车削操作。你添加的第一项会自带其刀具：**车刀刀片**（刀尖圆弧、刀片角、切削刃角）或**切槽刀片**（宽度、角圆弧、可达深度）。在**刀具**选项卡中更改它们。进给以每转计，速度为表面速度（m/min），直径变化时由数控系统保持该速度；若要固定转速，请为刀具单独设定 rpm。

## 操作

| 操作 | 作用 |
|---|---|
| {{ui:面}} | 从棒料前端向下车至零件，每次一个切深，由外向内直至刚过中心。 |
| {{ui:粗车}} | 沿 Z 方向以**切削深度**间隔走刀，直至轮廓加上**留余量**；然后沿轮廓走一遍以去除台阶。两段台肩之间的凹谷由一次切削深度的插入进入。 |
| {{ui:表面处理}} | 沿轮廓走一刀，进给为刀具进给的一个分数。 |
| {{ui:切槽}} | 并排插入刀片，直至刀片能一次切入超过仍存留余量限值的部分：即车刀刀片够不到的槽。**从 / 至 Z**可缩小其范围。 |
| {{ui:切断}} | 在零件背面稍后处切断，至略过中心，并且若设定了啄钻则进行啄钻。 |
| {{ui:螺纹}} | 外螺纹：大径、螺距、长度、走刀次数。深度 0 表示 0.6134 × 螺距（60° 螺纹）。每次走刀切除的切屑面积相同；光刀道次重复最后一刀。 |
| {{ui:钻孔}} | 沿中心线钻至设定深度，可带啄钻。 |

## 刀具如何与零件保持距离

刀片按其所是的形状处理：其刀尖圆弧，以及其后的后刃，即一条直线，其角度为 180° 减去切削刃角与刀片角。该形状沿 Z 向逐点降至轮廓上，路径即为它停留的位置。因此：

- **刀尖圆弧已计入路径。** 后处理器不写`G41`或`G42`；坐标为刀具的编程点（刀尖圆弧所在方形的角）。
- 刀片**无法跟随比其后刃更陡的壁**。台肩之后的凹槽会被留下，精加工操作会说明有多少轮廓它无法到达。{{ui:切槽}}操作会处理这部分。
- 每次切削后沿 Z 跟踪毛坯，因此粗车不会切削空气，切槽会找出残留部分，且每项操作都会显示其切除的体积以及是否切入了零件。

## 限制

- **仅外圆车削**：无镗刀，无内沟槽或内螺纹，无端面沟槽。
- 一个主轴，零件夹在 −Z 处。无副主轴、无动力刀具、无 C 轴或 Y 轴、无中心架或尾座移动。
- 路径为直线移动：曲线为在公差内的短直线（无`G2`/`G3`），粗车与螺纹逐道写出（无`G71`或`G76`循环）。
- 螺纹为直线道次，末端为直线退刀；为螺纹设置退刀槽。螺纹不在毛坯中显示。
- 中心钻孔不改变毛坯模型。
- 刀架、刀塔与卡盘不做检查。设定在 Z 处停止，以使刀具远离卡爪。
- 进给与转速为初始值，与铣削相同。
