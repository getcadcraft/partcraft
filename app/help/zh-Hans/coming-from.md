如果你习惯在 SolidWorks 中设计零件，PartCraft 的大部分理念会很熟悉：草图位于前视、上视和右视基准面上，有关系和智能尺寸，带有回滚栏的特征历史，以及通过配合放置的装配体。访问它们的方式在某些地方有所不同，且此首个版本的功能较少。本页将对应你的使用习惯，并列出值得注意的差异。

## 使用习惯对照

| 习惯的操作 | 在 PartCraft 中的对应操作 |
|---|---|
| 左侧的设计树 | 左侧的历史记录：先是基准面，然后是特征，草图缩进显示在使用它们的特征下方 |
| 前视、上视和右视基准面 | 相同的三个基准面，经过原点。前视为 XY 平面，上视为 XZ 平面，右视为 YZ 平面；Y 轴向上 |
| 在基准面或面上绘制草图，然后使用确认角退出 | 在所选基准面或平面上使用{{ui:草图}}（{{key:S}}）；使用{{ui:退出}}或按{{key:Esc}}键，直至草图关闭 |
| 智能尺寸 | {{ui:标注}}（{{key:D}}）。点击一个或两个对象，然后选择数值的放置位置。放置的位置决定为水平、竖直还是对齐标注 |
| 在属性管理器中添加关系 | 选择对象，然后使用右侧面板中的关系按钮（重合、水平、平行、相切、相等等） |
| 绘制草图时的自动关系 | 捕捉会添加重合、点在曲线上、水平和竖直关系 |
| 草图颜色：蓝 / 黑 / 红 | 含义相同：蓝色为欠定义，黑色为完全定义，红色为过定义。状态标签会显示剩余的自由度 |
| 旋转用中心线 | {{ui:中心线}}（{{key:N}}）；除非你选择了其他轴，否则{{ui:旋转}}会使用第一条中心线 |
| 草图圆角 | 草图中的{{ui:圆角}}（{{key:F}}）：点击角点，然后输入半径 |
| 构造几何切换 | {{ui:构造}}（{{key:Q}}） |
| 拉伸凸台 | {{ui:拉伸}}：给定深度、中面对称、拉伸至面 / 下一面 / 顶点、从面偏移、第二方向、拔模、单一轮廓（拾取区域） |
| 拉伸切除 | {{ui:剪切}}：默认为贯穿全部；如需型腔，请切换为给定深度 |
| 旋转凸台 / 切除 | {{ui:旋转}} / {{ui:更多}} › {{ui:旋转切除}} |
| 参考平面 / 轴 / 点 | {{ui:更多}} › {{ui:平面}}、{{ui:轴}}、{{ui:点}}（参见[参考平面、轴和点](topic:reference-geometry)） |
| 扫描 / 放样凸台或切除，拔模 | 在平面上使用{{ui:更多}} › {{ui:拔模}}（参见[扫描、放样与拔模](topic:sweep-loft-draft)）。{{ui:扫掠}}和{{ui:放样}}在此版本中尚未实现（它们需要精确内核） |
| 孔向导 | 在每个独立的草图点上使用{{ui:孔}}：简单孔、沉孔、埋头孔（90° / 82°）或 ISO 公制攻丝孔 M2–M24，贯穿或给定深度 |
| 线性 / 圆周阵列、镜像 | {{ui:线性}}、{{ui:环形}}、{{ui:镜像}}（特征或整个实体） |
| 边上的圆角和倒角 | {{ui:圆角}} / {{ui:倒角}}：点击一条边，按{{key:Shift}}键+点击更多边，然后点击按钮。一个半径；可选等距、双距离或距离-角度倒角。在此版本中，仅支持两个平面之间的直边，并且在角点相交的圆角会进行斜接。如需对曲边进行圆角或倒角，请在草图中操作（草图中的{{ui:圆角}}，{{key:F}}） |
| 抽壳 | {{ui:抽壳}}：点击平面以开口，然后点击按钮。一个壁厚 |
| 打开 STEP 文件 | {{ui:打开}}：以三角面读取，作为可在其上构建的实体（参见[打开 STEP 文件](topic:import-step)） |
| 编辑特征，然后点击确定 | 点击特征；在右侧更改数值；输入时会即时重建。没有确定或取消：请使用{{key:Mod+Z}} |
| 编辑草图 | 在历史记录中双击草图 |
| 重建 | 每次更改后自动进行。没有重建快捷键 |
| 压缩 / 解除压缩 | 右侧面板中的{{ui:压缩}} / {{ui:取消压缩}} |
| 拖动回滚栏 | 在特征上使用{{ui:回滚到此处}}；点击“回滚栏 · 前滚”以返回 |
| 在设计树中拖动特征以重新排序 | {{ui:上移}} / {{ui:下移}}，或{{key:Alt+Up}} / {{key:Alt+Down}}；如果会破坏依赖关系，则会拒绝并说明原因 |
| 双击模型以编辑尺寸 | 选择特征：其草图的尺寸会列在右侧面板中 |
| 配合：重合、同心、距离、角度 | {{ui:连接}}（{{key:J}}）：在每个零件上拾取一个平面；连接会使它们面对面贴合。将**中心位于**设为某轴的效果类似同心；**偏移量**类似距离；**角度**类似角度 |
| 固定零部件 | 第一个零件为固定零件；{{ui:设为固定零件}}可更改它 |
| 插入零部件 | {{ui:添加副本}}或{{ui:创建副本}}（另一个副本），或{{ui:插入}}（从零件文件插入） |
| 在装配体中编辑零件 | {{ui:编辑零件}}，然后{{ui:返回}} |
| 干涉检测 | {{ui:干涉}} |
| 移动零部件以查看运动 | 拖动旋转或滑动连接的角度或偏移量滑块；{{ui:检查运动中是否有干涉}}会扫描它。没有连接的零件：**手动移动**（拖动箭头，或输入数值） |
| 测量 / 检查 | {{ui:视图}}，然后{{ui:测量}}（{{key:M}}）：距离、角度、半径、面积；{{ui:质量属性}} |
| 爆炸视图、物料清单 | 在未选中任何内容的装配体中，右侧面板中的**爆炸视图**和**物料清单** |
| 质量属性 | **零件**框：面片化实体的体积、表面积、尺寸（圆形零件的数值略偏小）。无质量：目前尚无材料 |
| 保存、另存为 STEP | {{ui:保存}}会下载 `.partcraft.json`；{{ui:导出}}提供 STL、3MF、精确 STEP（AP242 或 AP214）、面片化 STEP、DXF 以及 PDF 图纸 |
| 从零件生成工程图 | {{ui:图纸}}：自动生成一张 A3 图纸，包含三视图、等轴测视图、一个剖视图、一个详图、基准、特征控制框和表面粗糙度符号。仅标注总体尺寸 |
| 按住中键拖动以旋转 | 此处**左键拖动**可旋转。中键或右键拖动可平移。滚轮以指针位置为中心缩放 |
| 视图方向、正视于 | {{ui:视图}}菜单；对拾取的面、平面或草图使用{{ui:正对}} |
| 缩放至适合窗口（F） | {{key:F}}，或{{ui:适合}}（在草图中，{{key:F}}为圆角工具） |
| 右键菜单 | 无。右键拖动可平移；在草图中，右键点击可结束直线链 |

:::tip
如果你已习惯 SolidWorks 的操作方式，请在{{ui:设置}} › {{ui:PartCraft}} › {{ui:菜单、按键和鼠标}}中选择{{ui:特征树}}菜单样式：功能区包含“特征”“草图”“曲面”“评估”“图纸”“装配体”和“视图”选项卡，中键用于旋转，{{key:Shift}}加中键用于平移，左键仅用于拾取。参见[菜单、按键和鼠标](topic:menus-keys-and-mouse)。
:::

## 容易让人踩坑的差异

**整个草图即为轮廓。**拉伸和旋转会使用草图中的每个闭合环。你无法为特征选择草图中的某一个区域或某一条轮廓。请为每个特征使用一个草图。

**特征使用哪个草图。**特征会使用你刚刚退出的草图，或历史记录中选中的草图。未选中任何内容时，它会使用最新的、尚未被任何特征使用的草图。如果使用了错误的草图，请选中正确的草图，然后重新选择该特征。

**更改随输入即时生效。**没有带有确定和取消的特征对话框。每个数值都会立即重建，{{key:Mod+Z}}即为撤销途径。撤销列表同时涵盖草图编辑、特征和设置。

**过定义绝不会悄无声息地保留。**没有从动（参考）尺寸。已被其他关系确定的尺寸会被报告为过定义（“已隐含。请删除它。”）。冲突的尺寸不会改变几何图形，并显示为红色。删除其中一个，或撤销。

**扫掠和放样尚未实现；圆角、倒角、抽壳和拔模均有限制。**此版本的 PartCraft 使用网格内核构建每个零件；状态栏标签始终显示“Mesh kernel”。圆角和倒角适用于两个平面之间的直边，在角点相交的圆角会进行斜接，而非融合。抽壳仅作用于平面以进行开口，拔模仅对平面进行倾斜。需要精确内核的特征仍可点击，但选择后会提示“尚未实现”。参见[网格内核](topic:solid-kernels)和[尚未实现的功能](topic:not-built-yet)。

**两个名为圆角的按钮。**在草图中，{{ui:圆角}}（{{key:F}}）用于圆化草图角点。在零件上，“特征”组中的{{ui:圆角}}用于圆化实体边（在此版本中为平面之间的直边）。此版本中没有扫掠或放样：参见[尚未实现的功能](topic:not-built-yet)。

**孔需要独立的点。**{{ui:孔}}在使用点工具创建的点上进行钻孔。圆心和直线端点不计入。

**贯穿全部仅用于切除。**凸台需要指定深度。目前尚无“拉伸至顶点 / 曲面 / 下一面”的终止条件。

**实体是面片化的。**网格内核由平面小面构建圆形表面，因此视图、体积、STL 和 3MF 导出均由它们组成：零件面板中的**曲线**可使其更精细。精确 STEP 导出则不同：它会将圆形表面写为其真实曲面。

**仅使用毫米。**目前尚无英寸设置。输入英寸尺寸时，请乘以 25.4。

**Y 轴向上。**前视基准面朝向你，上视从上方俯视零件，正如你所预期，但世界的向上轴为 Y。STL、3MF 和精确 STEP 导出会转换为 Z 轴向上；面片化 STEP 保持 Y 轴向上。

**配合是面，而不是几何对。**连接始终从两个面对面贴合的平面开始。对于孔中的销，请拾取孔周围的平面和销的台肩，然后将**中心位于**设置为孔轴和销的旋转轴。未被连接触及的零件保持其插入位置；你无法拖动它们。回路中的连接不会被求解。

**保存即下载。**没有需要反复覆盖的文件。每次保存都会在你的下载文件夹中生成一个新文件。请先为零件命名，并将文件保存在项目文件夹中。

**没有右键菜单，也没有命令管理器选项卡。**所有功能都位于工具栏和右侧面板中，工具栏会随你的操作而变化：草图工具仅在草图中显示，装配体工具仅在装配体中显示。

**草图中的按键为单个字母。**{{key:L}}、{{key:R}}、{{key:C}}、{{key:A}}、{{key:P}}、{{key:N}}、{{key:F}}、{{key:D}}、{{key:Q}}和{{key:S}}无需修饰键即可选择工具。参见[按键与鼠标](topic:keyboard)。
