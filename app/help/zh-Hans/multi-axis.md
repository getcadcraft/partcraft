制造工作空间可以使刀具保持倾斜角度，并可在切削时运动旋转轴。以下三种方式按由简到繁排列。

**这里的任何内容都未在机床上运行过。** 刀路由测试针对几何进行检查，G 代码会被回读，但内置后处理器遵循的是数控系统文档记载的代码，而非我们面前的任何机床。请先在数控系统自带的模拟器中验证程序，并在空中切削后再切入金属。

## 机床的旋转轴

在**装夹**选项卡上，{{ui:旋转轴}}说明机床有哪些旋转轴：

| 选项 | 机床 |
|---|---|
| 无（3 轴） | 普通铣床。任何需要刀具倾斜的操作都会发出警告，后处理器拒绝写出。 |
| A（绕 X 旋转） | 沿 X 的一个旋转轴：第 4 轴工作台或分度头。刀具只能在 Y–Z 平面内倾斜。 |
| B（绕 Y 旋转） | 沿 Y 的一个旋转轴。刀具只能在 X–Z 平面内倾斜。 |
| A 与 C | 绕 X 的倾斜轴与绕 Z 的旋转轴相互承载：双摆工作台，或主轴头。 |
| B 与 C | 相同，但倾斜绕 Y。 |

然后：

- **承载方式**：{{ui:工作台（工件旋转）}}或{{ui:主轴头（刀具旋转）}}。工作台反向旋转，以将同一面带到刀具下方，因此每个角度的符号由此决定。
- **数控系统保持刀尖位于刀路上（TCP）**：开启时，程序中的 X Y Z 即为零件自身坐标系中的刀尖，其余由数控系统处理（内置 Fanuc 式与 LinuxCNC 后处理器为刀具长度写出 `G43.4`）。关闭时，在工作台式机床上，PartCraft 将 X Y Z 写为转动的工作台所带动的零件位置，围绕你给定的**旋转中心**（工件坐标系中；工件原点在中心时为 0, 0, 0）。摆头式机床必须开启 TCP：否则程序需要机床的枢轴长度，而 PartCraft 并不知道该值。
- **倾斜限位**：倾斜轴可以转动的最大角度。

各机床对“正方向”的定义不同。若某轴在你的机床上转动方向相反，请在后处理器的副本中改变符号（[可编辑的后处理器](topic:post-processors)）。

## 普通操作的倾斜刀具

每个铣削操作（面铣、型腔、自适应、轮廓、钻孔、倒角、平行、等残留高度、3D 粗加工、残料）都有**刀具倾斜**和**倾斜方向**：仅针对该操作的刀具方向，以装夹的刀具轴为基准度量。这就是 3+2 加工：旋转轴转到某一位置并保持不动，同时三轴进行切削。

- 输入两个角度，或按{{ui:使刀具垂直于某个面}}并点击一个平面：刀具将直指该面。
- 照常拾取该操作的面与边。何为底面或孔，依沿倾斜刀具的方向判断。
- 该方向的毛坯为容纳旋转后毛坯的长方体，因此从该侧看，高度与间隙是安全的。

在 G 代码中，操作开始前刀具抬起，旋转轴转动，然后刀具降到其第一点上方。在没有 TCP 的工作台式机床上，圆弧保持圆弧，固定钻孔循环保持循环（写出的坐标系仅绕 Z 旋转）。在倾斜平面上开启 TCP 时，圆弧变为短直线，循环变为其所代表的移动。

毛坯模拟**单独**运行倾斜方向：它显示该操作从其一侧所见的整个毛坯上切削掉的部分，并在那里发现过切，但其他方向的切削不会被带入。

## 5 轴精加工

制造工作空间工具栏中的{{ui:更多}}会在**操作**选项卡顶部列出本操作及下一项操作。

{{ui:5轴}}是[平行精加工道次](topic:finish-3d)，使用**边切削边倾斜的球头铣刀**。球头以球面切削，无论刀具绕其球心朝哪个方向倾斜，球面都相同，因此球头精确沿三轴道次给出的路径运动，只有刀具方向改变：

- **朝向曲面**：1 = 垂直于曲面，0 = 竖直，介于两者之间的任意值。
- **前倾**：沿切削方向的角度，使球的静止中心不参与切削。
- **最大倾斜**：刀具偏离装夹刀具轴的角度永不超过此值。

若刀柄会碰到模型，倾斜角会被减小直至不再碰撞，并且操作会说明有多少个点受此影响。每道次以直线抬刀进入和离开。

## 旋转精加工（第 4 轴）

{{ui:旋转}}用于零件沿**工件 X** 装夹在旋转轴上的情况。零件旋转，始终指向轴线的球头铣刀沿其表面走刀：

- **道次**：{{ui:沿轴向}}（沿 X 的直线，每条相隔一个旋转行距）或{{ui:绕零件一周}}（圆环，每个相隔一个 X 行距）。
- **轴位于 Y / Z**：轴的位置。留空表示毛坯中心。在没有 TCP 的工作台式机床上，这必须是装夹中设定的旋转中心；若不是，操作会发出警告。
- **自 / 至 X** 与 **自 / 至角度**：要切削的长度与旋转范围。

每点处球心在轴线以上的高度，是球体落在零件网格上的精确下落量（从该侧看）。

## 限制

- 5 轴与旋转精加工**仅**支持**球头铣刀**。不支持侧刃切削（沿直纹壁面的刀具侧面）、沿曲面自身方向的流线、多轴粗加工，也不支持为避免碰撞而自动选择倾斜角。
- 5 轴与旋转刀路**不经过毛坯模拟**，因为毛坯模拟是高度图，无法表示倾斜的切削。
- 5 轴精加工中，刀柄是对照从上方所见的模型进行检查的；刀柄座、主轴与机床本身均未在任何地方检查。
- 旋转精加工只切削刀具从轴线方向所能看到的部分。
- 大型零件上的 5 轴精加工需要一分钟或更长时间计算：每道次的每一点都要检查刀柄。
- 当旋转轴与直线轴同时运动且 TCP 关闭时，内置后处理器将进给写为反时间（`G93`），然后恢复为 `G94`。
- 不写出倾斜工作平面代码（如 `G68.2`），也不了解特定机床的限位、解绕或碰撞区域。
