在脚本工作空间中，一个分析就是若干个相互传递变量的简短脚本。可以从与你需要接近的[分析库](topic:craftscript-library)函数开始，制作副本并进行修改；也可以按照下面的步骤从头构建。

## 1. 网格

```
model = part();                  % 你正在建模的零件，作为模型
m = tetmesh(model, 4);           % 边长约 4 mm 的四面体
show(m)
```

继续之前，请在视图中检查网格：{{key:F}} 将其适合窗口显示，**已显示**列表中的{{ui:眼睛}}图标可隐藏零件。

## 2. 装配与求解

在脚本中编写单元循环（它读起来就像教科书），而将计算量大的部分交给内置函数：单元矩阵、由三元组进行的稀疏装配，以及带预条件子的共轭梯度求解器。像 `static_tet` 这样的库函数（待库提供后）是一个完整的示例，可供参考复制。

## 3. 显示结果

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % 每个节点一个值
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- 图例的范围可以手动输入，也可以恢复为{{ui:Auto}}。
- 点击网格可读取某节点处的值。
- 使用相同 `'id'` 的图会原地更新，因此可在循环中打印和绘图，观察其收敛过程。

## 4. 检查

与已知结果进行对比：悬臂梁自由端挠度与 PL³/3EI、带孔板与其应力集中系数、反力与荷载。将检查写成独立脚本，以便每次修改后都能重新运行：

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. 保存

- 每个步骤都可以是独立的脚本标签页：它们共享变量，因此请依次运行。
- 脚本保存在部件中。在**变量**选项卡中勾选**随部件保存变量**，即可同时保留结果（最大 32 MB）。
- 脚本组中的{{ui:保存}}会下载脚本以便共享；{{ui:打开}}则导入脚本。
