PartCraft 是为带滚轮和中键的鼠标设计的，但只要了解手势，触控板也能很好地使用；触摸屏适用于查看零件和简单的草图绘制。

## 触控板

:::mac
| 要做什么 | 操作方法 |
|---|---|
| 旋转零件（3D） | 用一根手指单击并拖动（若开启了三指拖移，则用三根手指拖动） |
| 平移（3D） | 按住{{key:Shift}}（或 ⌘）并单击拖动，或按住双指做辅助点按拖动 |
| 滑动旋转零件 | 用双指滑动；按住{{key:Shift}}时，滑动会平移。需要将**滚动**设为“自动判断”（默认）或“触控板” |
| 缩放（3D 和草图） | 捏合。缩放以指针为中心。若**滚动**设为“鼠标滚轮”，双指滚动也可缩放 |
| 右键单击 | 用双指单击，或{{key:Ctrl}}+单击 |
| 在草图中平移 | 用双指滑动（“自动判断”或“触控板”），或按住双指拖动。{{key:Shift}}+拖动在草图中不会平移（它会绘制选择窗口） |
| 在草图中添加到选择集 | {{key:Shift}}+单击或 ⌘+单击 |

若双指单击无效，请在“系统设置”的“触控板”中打开“辅助点按”。
:::

:::windows linux
| 要做什么 | 操作方法 |
|---|---|
| 旋转零件（3D） | 按下触控板（或轻触并按住）后拖动 |
| 平移（3D） | 按住{{key:Shift}}或{{key:Ctrl}}并拖动，或按住右键区域拖动 |
| 滑动旋转零件 | 用双指滑动；按住{{key:Shift}}时，滑动会平移。需要将**滚动**设为“自动判断”（默认）或“触控板” |
| 缩放（3D 和草图） | 触控板支持时可捏合。缩放以指针为中心。若**滚动**设为“鼠标滚轮”，双指滚动也可缩放 |
| 右键单击 | 双指轻触，或触控板右下角 |
| 在草图中平移 | 双指滑动（“自动判断”或“触控板”），或按住右键区域拖动。{{key:Shift}}+拖动在草图中不会平移 |
| 在草图中添加到选择集 | {{key:Shift}}+单击或{{key:Ctrl}}+单击 |
:::

**滚动**设置位于[PartCraft 设置](topic:settings)中：“自动判断”（默认）会将侧向或细微滚动视为触控板操作，“触控板”始终如此，“鼠标滚轮”从不如此。三种模式下，捏合都会缩放。

方向键在你于视图中单击之后可旋转 3D 视图，按住{{key:Shift}}加方向键可平移：适合在触控板上使用。{{key:Plus}}和{{key:Minus}}用于缩放。

## 触摸屏

PartCraft 支持触摸输入，因此平板、带触摸屏的笔记本和手机均可使用，但有一定限制。

:::touch
**触摸按键**

一旦触摸屏幕，视图右下角会出现一个小工具栏，其中包含手指无法提供的按键。使用鼠标时它会消失。

- {{ui:Esc}}：Esc 键。取消你已开始的操作或退回一步，效果与按键相同。
- {{ui:添加}}（草图中选择工具时）：开启后，每次轻触都会将一个项目加入选择集或将其移出，与{{key:Shift}}+单击相同。再次轻触可恢复为逐个选择。
- {{ui:完成}}（绘制直线链、样条曲线或多边形时）：完成绘制，与右键单击相同。

手指按住不动约半秒，效果与单次轻触相同：使用绘图工具时会结束当前绘制，使用选择工具时会将手指下的项目加入选择集或将其移出。点和线更容易用手指命中：PartCraft 在轻触点周围的查找范围约为单击时的两倍。

**在 3D 视图中**

- 单指：旋转零件。
- 双指：捏合缩放，并一起移动以平移。
- 轻触：选择面、边或平面。轻触之前没有悬停高亮。

**在草图中**

- 使用绘图工具时，轻触以放置每个点：先轻触起点，再轻触终点。吸附在抬起手指的位置发生。
- 双指捏合和平移。放下第二根手指会取消第一根手指开始的拖动。
- 要结束直线链，请轻触{{ui:完成}}、按住手指不动，或再次轻触工具栏中的{{ui:直线}}（或其他工具）。
- 使用选择工具时，轻触以选择；拖动点或线以移动它；在空白处拖动可绘制窗口。第二次轻触会替换选择集，除非{{ui:添加}}已开启（或你在第二个项目上按住手指不动）。
- 要修改尺寸，请使用右侧面板中它旁边的**编辑**。

**图纸**

轻触以放置和选择符号，拖动符号可移动它。捏合缩放，双指移动平移，或在空白图纸上用一根手指拖动。第二根手指会停止你正在拖动的符号，并使其复原。

**仍需键盘的操作**

- 输入数字：数字框和尺寸字段中会弹出屏幕键盘。
- 工具的键盘快捷键：请使用工具栏。
:::

## 小屏幕和手机

- 宽度为 1280 像素或更宽时，工具栏可在一行内显示。
- 宽度约在 760 至 1100 像素之间时，侧边面板会变窄。
- 宽度低于约 760 像素（手机或窄窗口）时，屏幕改为上下堆叠排列：工具栏（左右滑动可显示更多按钮）、3D 视图、状态栏，然后是属性面板和历史记录。滚动页面可访问各面板。
- 菜单（{{ui:导出}}、{{ui:视图}}）会横跨整个屏幕宽度打开。

:::note
在 iPhone 上，浏览器中没有全屏模式；{{key:Ctrl+Shift+F}}和屏幕模式按钮仅在正常模式与隐藏工具栏之间切换。
:::

手机适合打开零件、旋转它并检查其参数。实际建模需要更大的屏幕以及鼠标或触控板。

## 浏览器

当前版本的 Chrome、Edge、Firefox 和 Safari 可在 Windows、macOS 和 Linux 上运行 PartCraft，也可在平板和手机上运行，前提是支持 WebGL 和 WebAssembly。参见[浏览器与计算机](common:browsers)。
