特征按创建顺序列在历史记录中，并自上而下重建。每个特征以其类型加编号命名：Sketch1、Extrude1、Revolve1、Hole1、LPattern1、CirPattern1、Mirror1、Fillet1、Chamfer1、Shell1、Imported1。

PartCraft 使用网格内核构建所有特征。圆角和倒角作用于两个平面之间的直边，抽壳会打开平面。导入的实体需要精确内核，而本版本不具备该内核：它们尚未实现，下文的 "导入实体" 一节说明由早期版本生成的零件如何保留它们。参见 [网格内核](topic:solid-kernels) 和 [尚未实现的功能](topic:not-built-yet)。

## 草图

| 设置 | 说明 |
|---|---|
| 基准面 | 前视、上视或右视基准面，或平面。仅显示，不可更改：如需移动草图，请新建一个 |
| 状态 | 完全定义、欠定义（附自由度数）、过定义或空 |
| 几何、关系 | 曲线、点和关系的数量 |
| 驱动尺寸 | 草图的每个尺寸，可编辑 |

按钮：{{ui:编辑草图}}、{{ui:导出为DXF}}。

## 拉伸和切除

{{ui:Extrude}} 与 {{ui:Cut}} 生成相同的特征，只是起始设置不同。

| 设置 | 选项 | 拉伸起始值 | 切除起始值 |
|---|---|---|---|
| 操作 | 凸台（添加材料）、切除（去除材料）、相交（保留重叠部分）、新建实体（本版本尚未实现） | 凸台 | 切除 |
| 结束方式 | 盲孔（指定深度）、中面（双向）、贯穿全部 | 盲孔 | 贯穿全部 |
| 深度（mm） | 大于 0，最大为 1,000,000 | 10 | 10 |
| 反向 | 关 / 开 | 关 | 关 |

- 轮廓：草图中由实线、圆和圆弧构成的每个闭合环。环内的环为孔。
- 贯穿全部仅适用于切除。它沿所选一侧贯穿整个零件。
- 切除会进入材料内，远离草图平面的外侧；**反向** 会翻转此方向。

## 旋转与旋转切除

| 设置 | 选项 | 默认值 |
|---|---|---|
| 操作 | 凸台、切除 | 凸台（{{ui:Revolve}}），切除（{{ui:More}} › {{ui:Revolved cut}}） |
| 角度（°） | 大于 0，最大为 360 | 360 |
| 轴 | 第一条中心线，草图中的任一直线或中心线，或位于草图平面内的轴特征 | 第一条中心线 |

- 轮廓必须位于轴的同一侧。它可以与轴接触。
- 旋转的轴可用于环形阵列和装配体连接。

## 孔

| 设置 | 选项 | 默认值 |
|---|---|---|
| 类型 | 简单、沉孔 | 简单 |
| 直径（mm） | 大于 0 | 6 |
| 贯穿全部 | 开 / 关 | 开 |
| 深度（mm） | 贯穿全部关闭时 | 10 |
| 沉孔 ⌀ | 大于孔径 | 11 |
| 沉孔深度 | 浅于盲孔 | 6 |
| 反向 | 关 / 开 | 关 |

- 草图中的每个松散点（用点工具绘制的点）各生成一个孔。面板会显示数量。
- 孔垂直于草图平面钻入材料。
- 每个孔的轴可用于装配体连接（"Hole1, hole 2"）。

## 线性阵列

| 设置 | 选项 | 默认值 |
|---|---|---|
| 要复制的特征 | 其上方的任意实体特征 | 选中的特征，否则为最后一个实体特征 |
| 方向 | X 轴、Y 轴、Z 轴；较早草图中的一条直线；旋转的轴；所选的边 | X 轴（或添加时所选的边） |
| 间距（mm） | 任意数值 | 20 |
| 数量 | 1至1000，包括原件 | 3 |
| 反向 | 关 / 开 | 关 |

## 环形阵列

| 设置 | 选项 | 默认值 |
|---|---|---|
| 要复制的特征 | 同线性阵列 | 同线性阵列 |
| 轴 | 同上方的方向 | 最后一次旋转的轴，否则为 Y 轴（或所选的边） |
| 角度（°） | 大于 0，最大为 360。360 会将副本在整圈上均匀分布；小于 360 则将它们分布在该角度范围内 | 360 |
| 数量 | 1至1000，包括原件 | 6 |
| 反向 | 关 / 开 | 关 |

## 镜像

| 设置 | 选项 | 默认值 |
|---|---|---|
| 镜像 | 整个实体（至此已构建的部分），或所选特征 | 选中的特征，否则为整个实体 |
| 镜像平面 | 前视、上视或右视基准面；平面 | 右视基准面，或添加时所选的平面 |

## 圆角和倒角

在本版本中，网格内核在两个平面之间（外角或内角）的直边上以单一半径构建它们。圆形边会提示："Fillet: in this version only straight edges between two flat faces (the mesh kernel builds them). Round or bevel curved edges in the sketch."（圆角：本版本仅支持两个平面之间的直边（由网格内核构建）。请在草图中对弯曲的边进行圆角或倒角。）圆角在一个角相交时会斜接，并会警告 "Fillet by the mesh kernel: where rounded edges meet they are mitred, not blended."（网格内核圆角：圆角边相交处为斜接，而非融合。）倒角的所有类型（等距、两个距离、距离和角度，以及 **翻转侧面**）均可使用。参见 [圆角、倒角和抽壳](topic:fillet-chamfer-shell)。

| 设置 | 圆角 | 倒角 |
|---|---|---|
| 半径（mm）（圆角） | 大于 0 | 2 |
| 距离（mm）（倒角） | 大于 0，两个面上相同 | 1 |
| 边 | 所选的边，每条边以其连接的两个面列出（"Extrude1 end face × Extrude1 side"），并带有 **移除** | 添加时所选的边 |

- 点击按钮之前先选择边（选择多条时按住{{key:Shift}}并单击），或在未选择任何边时选择该命令，然后再单击各条边。
- {{ui:选择边}}（或双击该特征）可更改边。
- 边由其连接的两个面标识，因此在上游更改尺寸后仍然保留。

## 抽壳

网格内核构建抽壳。只能打开平面："Shell: in this version it opens flat faces only (the mesh kernel builds it)."（抽壳：本版本仅可打开平面（由网格内核构建）。）不同壁厚的壳体尚未实现。参见 [圆角、倒角和抽壳](topic:fillet-chamfer-shell)。

| 设置 | 选项 | 默认值 |
|---|---|---|
| 壁厚（mm） | 大于 0 | 2 |
| 壁向外生长（面保持在内部） | 关：壁向内；开：壁向外 | 关 |
| 打开的面 | 被移除的面，至少一个，附 **移除** | 添加时所选的面 |

{{ui:选择面}} 可更改打开的面。

## 导入实体

通过打开 STEP、STL、OBJ 或 3MF 文件生成：一个由三角形构成的实体，没有自身的历史记录（[打开 STEP 文件](topic:import-step)，[打开 STL、OBJ 或 3MF](topic:open-meshes)）。它会显示其来源文件以及导入时修复的内容；**文件中的单位**、**文件中的朝向** 和 **用途** 保持可编辑。由具有精确内核的较早版本导入的 STEP 实体会保留在历史记录中并标记为未实现；重新打开该 STEP 文件，即可将其作为三角形导入。

| 设置 | 选项 | 默认值 |
|---|---|---|
| 文件中的朝向 | Z 轴朝上（多数 CAD），Y 轴朝上 | Z 轴朝上 |

阵列和镜像可以复制导入的实体，但不能复制圆角、倒角或抽壳。

## 每个特征共有的内容

在每个特征面板的底部：

| 按钮 | 作用 |
|---|---|
| {{ui:压缩}} / {{ui:取消压缩}} | 关闭或开启。需要它的特征在其关闭时不会被构建 |
| {{ui:回滚到此处}} | 仅构建此特征上方的特征。新特征将添加到回滚栏处 |
| {{ui:上移}} / {{ui:下移}} | 重新排序，前提是其所用的内容不会因此位于其下方。否则按钮灰显并给出原因 |
| {{ui:删除}} | 删除该特征，并（经询问后）删除使用它的每个特征 |
| 名称 | 重命名（最多60个字符） |

有草图的特征还会列出 **草图尺寸**，可就地编辑。

## 历史记录中的状态

| 状态 | 显示为 | 含义 |
|---|---|---|
| 已构建 | 正常 | 一切正常 |
| 警告 | ⚠ | 已构建，但有需要检查的内容："过定义：有1个关系不需要。" 或 "此操作后零件已无剩余。" |
| 错误 | ⚠ 错误，红色 | 无法构建；消息说明原因 |
| 未构建 | ⚠ 未构建 | 所需的特征失败、被压缩或被回滚，或需要本版本不具备的精确内核（"扫描：尚未实现。……"） |
| 已压缩 | 关 | 已关闭 |
| 已回滚 | 灰显，位于回滚栏下方 | 在前滚之前不会构建 |

## 零件设置

单击空白处，使未选中任何对象。右侧面板会显示 **零件**：

- **名称**：零件的名称，用于文件名和图纸标题栏（最多120个字符）。
- **曲线**：见下文。

### 曲线精度

网格内核由平面面片自行构建实体，因此视图、STL、3MF、面片 STEP、体积和图纸视图均遵循 **曲线**：每整圈的面片数。

| 设置 | 每圈面片数 | 圆形形状的体积 |
|---|---|---|
| 粗略（每圈32） | 32 | 比真实值小约0.64 % |
| 普通（每圈64） | 64 | 比真实值小约0.16 %（默认） |
| 精细（每圈128） | 128 | 比真实值小约0.04 % |
| 非常精细（每圈256） | 256 | 比真实值小约0.01 % |

更精细的曲线会使导出和视图更平滑，但重建更慢。该设置保存在零件文件中。

## 尚未实现

变半径圆角、圆形边上的圆角和倒角、对弯曲面抽壳、弯曲面上的拔模、扫描、放样、筋、带精确弯曲面的 STEP 实体、新实体、锥度、"拉伸至"面或顶点，以及实体的面和边上的引用，都需要本版本不具备的精确内核。另外尚未实现：攻丝孔和埋头孔。参见 [尚未实现的功能](topic:not-built-yet)。
