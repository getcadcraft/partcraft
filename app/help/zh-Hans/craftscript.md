**预览。** 脚本功能是 PartCraft 0.3 的新增功能，目前为预览版：语言、库以及脚本的保存方式可能仍会更改，现在编写的脚本以后可能需要稍作修改。请告诉我们哪里出了问题。

脚本工作空间与零件并排运行你自己的计算：小型求和、完整分析，或[分析库](topic:craftscript-library)中的脚本。脚本可使用 **CraftScript**（一种与 MATLAB 非常相似的矩阵语言，见 [CraftScript 语言](topic:craftscript-language)）、**Lua**（见 [Lua 脚本](topic:craftscript-lua)）或 **Python**（见 [Python 脚本](topic:craftscript-python)）编写。

在工具栏左侧的**工作空间**框中选择**脚本**。零件不会被更改。右侧面板会变为脚本面板（比平时更宽；拖动其边缘可调整宽度，或通过其{{ui:⋯}}菜单将其移动到第二屏幕，见[排列面板](common:arrange-panels)）。

## 建模时编写脚本

编写脚本无需离开设计工作空间。在设计工作空间中，右侧面板的**脚本**选项卡包含相同的编辑器、控制台、变量和库，并使用相同的脚本。特征树和视图仍可正常使用：点击特征即可选中，双击草图即可编辑，旋转视图，然后回到**脚本**选项卡并按 {{key:F5}}。

脚本**显示**的内容（网格、场、图、表格）不会叠加绘制在设计中的模型上：控制台会说明这一点，切换到脚本工作空间后即可看到全部内容。

{{ui:弹出}}位于{{ui:运行}}旁边，可将整个面板移动到其自身的窗口中（例如放在第二屏幕上），使编辑器与完整视图并排显示。{{ui:放回}}则将其重新停靠。见[排列面板](common:arrange-panels)。

## 运行第一个脚本

1. 在编辑器中输入，例如：

   ```
   x = linspace(0, 2*pi, 50);
   y = sin(x);
   plot(x, y, 'title', 'A sine')
   disp(max(y))
   ```

2. 按 {{key:F5}}（或{{ui:运行}}）。编辑器下方的控制台会显示脚本打印的内容以及“Done in … s”。图会出现在三维视图底部的**子显示区**中。
3. 与 MATLAB 相同，不带分号的语句会打印其值：`a = 3` 会打印 `a = 3`；`a = 3;` 则不打印任何内容。
4. 若只运行脚本的一部分，请选中相应的行并按 {{key:Mod+Enter}}（{{ui:选区}}）。若未选中任何内容，则运行光标所在的行。
5. 控制台底部（`>>` 之后）的行会在你按 {{key:Enter}} 时运行一条语句。{{key:Up}} 和 {{key:Down}} 可调出之前输入的行。

## 查找、折叠和补全

- **查找和替换。**按 {{key:Mod+F}}（或按 {{key:Mod+H}} 同时替换）。代码上方会打开一个工具条：输入要查找的内容；匹配项会高亮显示，计数会指示你所在的位置。输入框旁的按钮用于区分大小写（**Aa**）、仅查找整个单词（**W**）以及使用正则表达式（**.\***；在替换内容中，`$1` 可放回第一个分组匹配的内容）。{{ui:替换}}替换当前匹配项，{{ui:全部}}将所有匹配项一次性替换，作为一步可用 {{key:Mod+Z}} 撤销。
- **折叠。**点击行号旁的 ▾，或在光标位于 `function`、`if`、`for`、`while`、`switch` 或 `try` 行（Lua：`function`、`do`、`if`、`repeat`）时按 {{key:Mod+Shift+[}}，即可将其内部行收起；该行会注明收起了多少行。▸ 或 {{key:Mod+Shift+]}} 可再次展开。折叠只是隐藏行：运行、保存、复制以及行号仍会计算每一行；在折叠行中输入内容会先将其展开。
- **补全。**输入名称的前两个字母，或按 {{key:Mod+Space}}：列表会显示你已有的变量、该语言的函数（带参数）、关键字以及脚本中已出现的名称。用方向键选择，然后按 {{key:Enter}} 或 {{key:Tab}}。

## 出现问题时

- 错误会指明问题及其所在行：该行在编辑器中以红色标记，控制台中的 **Line n** 可将你带到该行。
- 无限循环：按{{ui:停止}}（工具栏或面板）。脚本会立即停止；变量保留本次运行之前的值。
- 每次运行还有步数上限（默认为 20 亿步；可在面板中的**运行选项**下更改）。超过上限的运行会停止并给出提示。

## 变量在脚本之间传递

脚本创建的每个顶层变量都会进入**变量**选项卡（名称、类型、大小、最小值和最大值），并保留在其中供下一个脚本使用，无论使用哪种语言。这样，一个脚本划分网格，下一个脚本求解，第三个脚本绘图。

- 点击变量即可显示：网格、场和模型显示在三维视图中，数组以表格形式显示在子显示区中（向量另附折线图，矩阵另附色图）。
- {{ui:保存为JSON}}、{{ui:保存为CSV}}（数字表格）和{{ui:保存为HDF5}}可下载它；{{ui:删除}}将其移除；{{ui:全部清除}}会清空工作空间。
- 勾选**随部件保存变量**，即可将其保存在部件文件中（最大 32 MB；更大的仅在本次访问中保留）。打开此类部件时，面板会提供加载这些变量的选项。

## 网格、场和图

- `show(m)` 绘制网格；`show(f)` 在其网格上以图例着色显示场。视图左上角的**已显示**列表可以隐藏（{{ui:眼睛}}）或移除每一项，也可以隐藏或显示零件本身。在图例下方，可输入范围（**从**、**到**）或按{{ui:自动}}；向量场或应力场还可选择要显示的分量。
- `show(f, 'deform', u, 'scale', 50)` 绘制按位移场 `u` 移动后的网格，并放大 50 倍（不指定 `scale` 时，放大量约为模型尺寸的 8%）。
- 点击已显示的网格：最近的节点、单元及其处的场值会显示在子显示区中（**拾取**）。
- `plot`、`imagesc` 和 `table` 会在子显示区中显示折线图、二维数组的色图或表格。与之前某个图具有相同 `'id'`（或标题）的图会将其替换，因此循环可以更新同一个收敛图；`'append', true` 可向其中添加一条曲线。{{ui:清除}}会清空子显示区；箭头则将其收起。
- 当有两个或更多图时，{{ui:并排显示}}会同时显示所有图（最新的六个）；点击表格或图片的选项卡，则会再次只显示该项。
- 每个图下方都有{{ui:PNG}}、{{ui:SVG}}和{{ui:CSV}}。无论主题如何，PNG 和 SVG 都会以纸张配色在白色背景上输出（PNG 为 1600 × 1000 像素；SVG 缩放时不会模糊）；CSV 保存所有位数的数值：当各曲线共享 x 时，为一列 x 加每条曲线一列；否则每个点一行，并附曲线名称。
- {{key:F}} 或{{ui:适合}}使视图适合所显示的内容。

## 文件

- 脚本组中的{{ui:打开}}（或将文件拖放到视图或面板上）：`.craft`、`.lua` 和 `.py` 文件会作为新脚本打开（不会运行）；数据文件（STL、OBJ、CSV、JSON、NPY、HDF5）会以其文件名加载到变量中。
- 脚本组中的{{ui:保存}}会将当前脚本下载为文件。
- 脚本组中的{{ui:新建}}（或标签页旁的{{ui:+}}）可开始另一个脚本。双击标签页即可重命名；其{{ui:×}}会将其移除（此操作可撤销）。

## 读取部件参数

脚本通过名称读取部件的参数（见[用参数驱动部件](topic:parameters)）：

```
w = param('width');     % 单个参数的值，单位为 mm（或度，或纯数字）
p = params();           % 全部参数，以结构体形式返回：p.width、p.height
```

在 Lua 和 Python 中分别为 `cs.param('width')` 和 `cs.params()`。脚本只读取参数：请在{{ui:参数}}选项卡中更改它们。在脚本的标签页下，有一行会列出它通过 `param('…')` 读取的参数，并标记部件中不存在的参数；{{ui:参数}}选项卡会在每个参数下列出该脚本。运行时拼接出的名称（例如 `param(name)`）不会被列出。

## 脚本保存在部件中

标签页中的每个脚本都保存在部件中，因此文件组中的{{ui:保存}}会将它们一同保存，对其所做的更改也可以撤销。打开部件**绝不会运行其脚本**：控制台会说明其中包含多少个脚本，只有在你点击运行时才会运行。他人提供的部件可能包含任何脚本：运行之前请先阅读。脚本在本计算机上后台运行，无法访问网络，也无法操作页面。
