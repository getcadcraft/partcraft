PartCraft 是早期版本。本页列出它尚未实现的功能，以免你徒劳搜索，并说明目前应如何替代。这些功能均无确定日期。

## 需要精确内核

本版本使用网格内核构建所有零件（参见[网格内核](topic:solid-kernels)）。下列所有功能都需要精确几何内核，而本版本尚未具备。使用这些功能保存的零件仍可打开：特征保留在历史中，标记为尚未实现，保存时会被保留。

| 尚未实现 | 目前可行的替代做法 |
|---|---|
| {{ui:圆角}}与{{ui:倒角}}用于圆边；沿边变化半径的圆角；相交处平滑融合的圆角（网格内核会以斜接方式处理） | 圆角与倒角适用于平面之间的直边；其他角请在拉伸前在草图中倒圆（草图中的{{ui:圆角}}，{{key:F}}） |
| {{ui:抽壳}}开口于曲面；壁厚不同的壁 | 对平面开口；若某壁需要更厚，则用拉伸添加材料 |
| {{ui:扫掠}}、{{ui:放样}}、{{ui:拔模}}作用于曲面；拉伸至某个面、下一个面或某顶点；锥形拉伸 | 拉伸或旋转，必要时分步进行；拉伸至你测得的深度 |
| {{ui:加强筋}}、{{ui:基础法兰}}、{{ui:边法兰}}与展开平板 | 拉伸平板或筋的轮廓 |
| 曲面：将{{ui:造型}}完成为零件的一部分，{{ui:补面}}、{{ui:曲面放样}}、{{ui:Gordon曲面}}、{{ui:缝合}}、{{ui:加厚}}、{{ui:偏移曲面}}、{{ui:延伸曲面}}、{{ui:修剪曲面}} | 不可用 |
| 多实体：{{ui:合并}}、{{ui:移动实体}}、{{ui:缩放实体}}、{{ui:路径阵列}}，以及生成新实体的特征 | 一个实体；阵列与镜像复制特征 |
| 草图、基准面、基准轴与点位于只有精确内核才能找到的面上（由圆角生成的面、孔壁、导入实体的面） | 在基准面、参考平面以及拉伸和旋转的平面上绘制草图 |
| 作为零件打开或添加到零件中的生成式设计结果（它会变为导入的实体） | 将结果下载为 STL 或 STEP |
| 将打开的 STEP 文件的曲面作为精确曲面进行编辑；对 STEP 文件中的样条、扫掠和旋转面进行精确 STEP 输出，样条边，建模螺纹，STL / OBJ / 3MF 实体及装配体；其他零件建模软件的 STEP | {{ui:打开}}以三角面读取 STEP，并为导出保留文件中的平面、圆柱、圆锥、球和环面（[打开 STEP 文件](topic:import-step)）；{{ui:导出}} › {{ui:STEP AP242（精确实体）}}会精确写出每个解析面，并将其保留为面片（[导出](topic:export-files#for-other-cad-programs-step)）；其他零件建模软件的宏仍照常写出 |
| 工程图视图中的真圆弧 | 视图与剖视图由面片绘制 |
| 精确的体积、面积与距离 | {{ui:测量}}给出面片化实体的数值，对圆形零件略偏小；将**曲线**设置调得更细可使其更接近 |

下表中有些行建议以上某项功能作为其他问题的解决办法。这些建议在精确内核恢复后才适用。

## 草图

| 尚未实现 | 目前可行的替代做法 |
|---|---|
| 椭圆、相切圆弧、圆锥曲线、带设定阶数或权重的样条（NURBS） | 三次样条、圆弧与带相切约束的圆 |
| 样条上的点（约束）、曲率（G2）约束 | 将样条自身的点放在它必须经过的位置 |
| 随后续更改而变化的样条偏移复制；带尖角样条的链的偏移 | 更改后再次偏移；先倒圆该角 |
| 与原件保持关联的阵列副本；沿曲线的阵列 | 更改后重新阵列 |
| 投影自由形或倾斜的圆形边，随零件变化的投影几何 | 投影直线与平行的圆形边，然后标注尺寸 |
| 驱动（参考）尺寸 | 从面板或零件信息读取尺寸 |
| 共线约束 | 距离为 0 的平行约束 |
| 粘贴到其他程序（系统剪贴板） | 导出 DXF、STEP、STL 或 3MF |
| 键入圆弧、相对或极坐标 | 键入直线和圆；用圆弧工具绘制圆弧 |
| 无指针选择几何 | 需要单击或点触 |

| 轴承与螺栓载荷、远程力、力矩、弹簧、规定位移 | 面上的力与压力、重力；固定与无摩擦面 |
