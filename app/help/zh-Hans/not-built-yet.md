PartCraft 目前是早期版本。本页列出它尚未实现的功能，以免您去寻找，并说明目前可以采用的替代做法。这里的内容均没有确定的日期。

## 需要精确内核

本版本使用网格内核构建所有零件（见 [网格内核](topic:solid-kernels)）。以下所有内容都需要精确几何内核，而本版本尚不具备。使用这些功能保存的零件仍可打开：相关特征保留在历史记录中，标记为尚未实现，并在保存时保留。

| 尚未实现 | 当前替代做法 |
|---|---|
| 对曲边的{{ui:圆角}}和{{ui:倒角}}；沿边缘半径变化的圆角；在相交处平滑混合的圆角（网格内核会将其切成斜接） | 圆角和倒角仅适用于平面之间的直边；在拉伸前先在草图中对其他拐角做圆角（草图中的{{ui:圆角}}，{{key:F}}） |
| 对曲面开口的{{ui:抽壳}}；壁厚不同的抽壳 | 开放平面；若壁需要更厚，用拉伸增加材料 |
| 曲面上的{{ui:扫掠}}、{{ui:放样}}、{{ui:拔模}}；拉伸至某个面、下一个面或顶点；锥度拉伸 | 拉伸或旋转，必要时分步进行；拉伸到测量得到的深度 |
| {{ui:加强筋}}、{{ui:基础法兰}}、{{ui:边法兰}}和展开图 | 拉伸板件或加强筋的轮廓 |
| 曲面：将{{ui:造型}}完成为零件的一部分，{{ui:补面}}、{{ui:曲面放样}}、{{ui:Gordon曲面}}、{{ui:缝合}}、{{ui:加厚}}、{{ui:偏移曲面}}、{{ui:延伸曲面}}、{{ui:修剪曲面}} | 不可用 |
| 多个实体：{{ui:合并}}、{{ui:移动实体}}、{{ui:缩放实体}}、{{ui:路径阵列}}，以及生成新实体的特征 | 单一实体；阵列和镜像复制特征 |
| 草图、基准面、轴和点位于只有精确内核才能识别的面上（圆角生成的面、孔壁、导入实体的面） | 在基准面、参考平面以及拉伸和旋转的平面上绘制草图 |
| 将生成式设计结果作为零件打开或添加到零件中（它会成为导入的实体） | 将结果下载为 STL 或 STEP |
| 以精确曲面编辑已打开 STEP 文件的曲面；从 STEP 文件中精确读取样条、扫掠和旋转曲面，样条侧面，建模螺纹，STL / OBJ / 3MF 实体和装配体；面向其他零件建模软件的 STEP | {{ui:打开}}以三角面读取 STEP，并保留文件中的平面、圆柱、圆锥、球面和环面，用于导出（[打开 STEP 文件](topic:import-step)）；{{ui:导出}} › {{ui:STEP AP242（精确实体）}} 将每个解析面精确写出，并以面片形式保留（[导出](topic:export-files#for-other-cad-programs-step)）；其他零件建模软件的宏仍照常写出 |
| 图纸视图中的真圆弧 | 视图和剖视图由面片绘制 |
| 精确的体积、面积和距离 | {{ui:测量}}给出面片实体的数值，圆形部件的数值略小；将**曲线**设置得更精细可使其更接近 |

下面的表格中，有些行建议以其中某一功能作为其他问题的替代做法。这些建议仅在精确内核恢复后适用。

| 历史记录中的实体列表；导出时排除隐藏实体 | 在零件面板的实体列表中重命名和隐藏实体；删除或压缩生成某个实体的特征可将其排除 |
| 保持圆柱和圆锥为解析面的非均匀缩放；偏移曲面的非均匀缩放 | {{ui:缩放实体}}会将曲面转换为闭合的 B 样条（误差在 0.0000004 mm 以内）；均匀缩放保持精确 |
| 合并曲面实体；闵可夫斯基和 | 先{{ui:缝合}}或{{ui:加厚}}，再{{ui:合并}} |
| 公差分析：转角的公差累积（2D 和 3D 矢量环）、从几何计算的灵敏度、使用其他分布的蒙特卡洛法、草图尺寸的尺寸公差、来自材料状态的附加公差 | 装配体中的{{ui:公差累积}}：单方向、最坏情况和 RSS，手动输入公差，来自标题栏的一般公差或 GD&T 公差框：见 [公差累积](topic:tolerance-stackup) |
| 排版：切割顺序和切入路径、共享边只切一次、必须保持在一起的零件；卷料的余料、多个项目共享库存 | 使用{{ui:将平板零件排入板材…}}，设置间距、边距、旋转和纹理：见 [将平板零件排入板材](topic:nest-flat-parts)；剩余板材会被保留并优先使用：见 [保留并重用边角料](topic:nest-offcuts)；在切割机自带的软件中规划切割 |

| 装配体的{{ui:拔模分析}}；查找分型线；壁厚分析 | 在设计中对零件使用{{ui:拔模分析}}：见 [检查模塑和铸造的拔模](topic:draft-analysis)；打开装配体中的每个零件进行检查 |

## 草图

| 尚未实现 | 当前替代做法 |
|---|---|
| 椭圆、相切圆弧、圆锥曲线、带指定阶数或权重的样条（NURBS） | 样条（三次）、圆弧和圆，使用相切约束 |
| 样条上的点（约束）、曲率（G2）约束 | 将样条自身的点放在它必须经过的位置 |
| 随后续修改而更新的样条偏移副本；带尖角样条的链的偏移 | 修改后重新偏移；先将拐角做圆角 |
| 与原件保持关联的阵列副本；沿曲线的阵列 | 修改后重新阵列 |
| 投影自由形状或倾斜的圆形边，投影几何随零件更新 | 投影直线和平行的圆形边，然后标注尺寸 |
| 从动（参考）尺寸 | 从面板或零件信息中读取尺寸 |
| 共线约束 | 平行，距离为 0 |
| 粘贴到其他程序（系统剪贴板） | 导出 DXF、STEP、STL 或 3MF |
| 输入圆弧、相对坐标或极坐标 | 输入直线和圆；使用圆弧工具绘制圆弧 |
| 不使用指针选择几何体 | 需要点击或轻触 |

## 仿真与生成式设计

| 尚未实现 | 当前替代做法 |
|---|---|
| 非线性分析：屈服、大变形、零件间接触、疲劳 | 线性静力和固有频率：见 [检查应力和变形](topic:simulation)；安全系数应远大于 1 |
| 非线性屈曲（缺陷、后屈曲、跳跃屈曲） | 线性屈曲载荷系数，留有充足余量：见 [热、热应力和屈曲](topic:thermal-and-buckling) |
| 面与面之间的辐射（视角系数）、接触热阻、随温度变化的材料、热应力中的惯性（热冲击波） | 对周围环境的辐射、随时间的稳态或准静态热应力、常值材料属性：见 [热、热应力和屈曲](topic:thermal-and-buckling) |
| 瞬态热分析和带热载荷分析的自动细化；误差较小处使用更粗的网格；针对局部量的目标（某一点的峰值应力） | 对静力、屈曲、固有频率和稳态热分析，按整个零件的误差**自动细化**：见 [检查应力和变形](topic:simulation)；否则减小单元尺寸 |
| 轴承和螺栓载荷、远程力、力矩、弹簧、指定位移 | 面上的力和压力、重力；固定面和无摩擦面 |
| 装配体仿真；各向异性材料（打印层、复合材料） | 单一零件，单一各向同性材料 |
| 四面体分析、传热和生成式设计的多求解线程；页面未跨源隔离时的任何线程 | 体素分析、屈曲、随时间变化的应力和层流在页面允许的情况下使用线程：见 [PartCraft 设置](topic:settings) |
| 达到设计精度的湍流（Spalart–Allmaras 模型以实验形式提供：管道摩擦偏高30至34 %，后台阶再附着点偏短21至39 %；计划：壁面附近更细的网格）、流体中的传热、非定常（时间精确）流动、自由表面、非牛顿流体、旋转部件 | 牛顿流体的层流、稳态、等温流动，或用于定性模式的实验性湍流模型：见 [流体流动仿真](topic:flow-simulation)；雷诺数超过层流范围时，面板会发出警告 |
| 生成式设计中的应力限制和制造规则（悬垂、铣削方向）；同一形状中的多种材料 | 体积下刚度最大的形状；在仿真中检查结果：见 [根据载荷生成形状](topic:generative-design) |
| 可编辑的（光滑、参数化）实体形式的结果 | STL、面片 STEP，或将结果作为导入的面片实体放入零件 |
| 电机设计：转子在定子中旋转、转矩与角度关系、饱和钢材、过拐点后失去磁性的磁体、涡流以及铁损和铜损；三维磁场或曲面网格上的磁场 | 分析库中网格上的线性二维静磁场：线圈、铁芯、退磁曲线上的永磁体、气隙、电感和吸力：见 [二维磁场](topic:magnetic-fields-2d) |
