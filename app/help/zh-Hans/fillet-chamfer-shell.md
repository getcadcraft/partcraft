:::note
**在本版本中** PartCraft 使用网格内核构建圆角和倒角，且仅适用于**两个平面之间的直边**：盒子的边，以及拉伸和切除的直边，外角或内角均可（内角会增加材料）。圆形边（例如孔的边缘），以及沿边变化的半径，尚未实现。两条圆角边在一个角处相交时，圆角会斜接（相交成一条尖锐的折痕），而不会融合。**抽壳** 同样可用，由网格内核构建：仅可打开平面，不同壁厚的壳体尚未实现，并且在圆面很多的零件上速度较慢。参见 [尚未实现的功能](topic:not-built-yet)。
:::

{{ui:Fillet}} 对边进行圆角，{{ui:Chamfer}} 对边进行倒角，{{ui:Shell}} 将零件挖空。三者都作用于实体的边和面，并由网格内核构建。其圆角与其他圆形表面一样为面片（**曲线** 设置决定其精细程度）；圆形表面为可选取和测量的圆柱（参见 [网格内核](topic:solid-kernels)）。

## 圆角或倒角边

### 先选择边

1. 单击零件的一条边。整条边会高亮，右侧面板显示 **边**：其类型（直线、圆或圆弧、曲线）、长度以及它所在的两个面。
2. 要添加更多边，请按住{{key:Shift}}并单击。每条边都会被标记；按住{{key:Shift}}单击已标记的边可将其取消。面板标题会统计数量（"4条边"），状态栏显示 "已选择4条边。圆角或倒角将作用于它们；Shift+单击可继续选择，Esc清除。"
3. 在工具栏中选择 {{ui:Fillet}} 或 {{ui:Chamfer}}，或使用右侧面板中的相同按钮。

特征会以全部已选边添加：2 mm 圆角，或 1 mm 倒角。状态栏显示例如："已添加 Fillet1（4条边）。请在右侧更改其尺寸；选择边可更改所选的边。"

### 或先添加特征

1. 未选择任何边时，选择 {{ui:Fillet}} 或 {{ui:Chamfer}}。
2. PartCraft 进入选择模式：右侧面板标题显示 "Fillet1：选择中"，零件显示为圆角之前的状态（面板会说明这一点），工具栏显示 {{ui:完成}}。
3. 单击每条边以添加；再次单击即可取消。状态栏会统计数量。
4. 选择 {{ui:完成}}（或面板中的 {{ui:选择完成}}），或按{{key:Esc}}键或{{key:Enter}}键。

### 设置

| 设置 | 圆角 | 倒角 |
|---|---|---|
| 尺寸 | **半径（mm）**，默认2 | **距离（mm）**，从边在两个面上各退后的距离，默认1 |
| **边** | 数量 | 数量 |

下方列表会按连接的两个面给出每条边的名称，例如 "Edge 1: Extrude1 end face × Extrude1 side"。**移除** 可删除一条边。{{ui:选择边}} 会返回选择模式。在历史记录中双击该特征，效果相同。

边由它们所连接的两个面记住，因此当你更改历史记录中较早的尺寸时，它们仍保持在正确的边上。

### 变半径圆角和倒角类型

- **变半径**（圆角）：本版本尚未实现（"A fillet whose radius changes along the edge: not built yet (it needs an exact kernel). Give it one radius."，即沿边变化半径的圆角：尚未实现（需要精确内核）。请设置一个半径。）。在精确内核下：勾选它并设置 **终点半径（mm）**。半径沿每条边从一端的 **半径** 线性变化到另一端的 **终点半径**；**交换两端** 可将其反转。
- **类型**（倒角）：**等距**、**两个距离**（另一个面上的 **第二距离**）或 **距离和角度**（一个面上的距离，以及与该面成 **角度（°）** 的斜面）。**翻转侧面** 会将第一个距离放在另一个面上。

## 抽壳零件

1. 单击要保持打开的平面，例如盒子的顶面。或按住{{key:Shift}}并单击多个面。
2. 在工具栏中选择 {{ui:Shell}}，或在该面的面板中选择 {{ui:抽壳，打开此面}}。

零件会变为 2 mm 壁厚，所选面保持打开。设置如下：

| 设置 | 作用 | 默认值 |
|---|---|---|
| **壁厚（mm）** | 壁的厚度 | 2 |
| **壁向外生长（面保持在内部）** | 勾选：壁添加在外侧，因此内部保持零件的尺寸 | 关：壁向内生长，外部保持其尺寸 |
| **打开的面** | 被移除的面的数量 | |

向内时，壁的厚度正好为设定值：外角保持尖锐，内角呈圆角（半径等于壁厚），穿过零件的孔周围会得到一圈壁管。向外时，壁添加在原始表面之外，原始表面成为空腔，外边缘呈圆角。内表面以它们所偏移的面命名，因此你可以选取它们。

只能打开平面：选取弯曲面时会提示："Shell: in this version it opens flat faces only (the mesh kernel builds it)."（抽壳：本版本仅可打开平面（由网格内核构建）。）对于圆面很多的零件，抽壳较慢（每千个三角形需要数秒）：设计时请使用较粗的 **曲线** 设置。

{{ui:选择面}} 会以与选择边相同的方式更改打开的面。列表会命名每个面，例如 "Face 1: Extrude1 end face"。若没有打开的面，则不允许抽壳："请先选择要移除（打开）的面，再进行抽壳。"

## 顺序很重要

特征自上而下构建。在抽壳之前的圆角会随零件一起被抽壳，因此内部也会出现圆角。在抽壳之后的圆角只作用于你所选的边。使用 {{ui:上移}} 和 {{ui:下移}} 移动特征（参见 [通过历史记录修改零件](topic:edit-history)）。

阵列和镜像不能复制圆角、倒角或抽壳："Fillet1 changes the body's edges or walls; it cannot be copied. Copy the features that make solids (extrudes, revolves, holes, imports)."（Fillet1 会修改实体的边或壁，无法复制。请复制生成实体的特征（拉伸、旋转、孔、导入）。）请先阵列孔或切除，然后在一次圆角操作中对所有副本的边进行圆角。

## 失败时

| 提示 | 处理方法 |
|---|---|
| "A 5 mm round does not fit here (it is too big for a face next to one of the edges, or the edges meet in a corner the kernel cannot blend)."（5 mm 圆角在此处放不下（对于与某条边相邻的面而言过大，或各边相交于内核无法融合的角）。） | 使用较小的半径，或一次对较少的边进行圆角（使用多个圆角特征，最小的放在最后） |
| "An edge it rounds is gone: the edge between Extrude1 and Cut2."（它要圆角的边已不存在：Extrude1 与 Cut2 之间的边。） | 之前的更改移除了该边。请选择 {{ui:选择边}}，移除红色的边，然后选择新的边 |
| "The shell could not be made with this thickness (…)."（无法以此厚度抽壳（……）。） | 壁厚大于模型某个狭窄部分，或大于圆角半径。请使壁更薄，或使圆角大于壁厚 |
| "That face has no name the history can follow; pick another."（该面没有历史记录可追踪的名称；请选择其他面。） | 选择由特征生成的面（大多数面都是如此） |
| "Fillet: in this version only straight edges between two flat faces (the mesh kernel builds them). Round or bevel curved edges in the sketch."（同样适用于倒角）（圆角：本版本仅支持两个平面之间的直边（由网格内核构建）。请在草图中对弯曲的边进行圆角或倒角。） | 所选边为圆形，例如孔的边缘，或位于弯曲面上。请用 {{ui:选择边}} 将其移除，然后改为在草图中对该角进行圆角或倒角 |
| "A fillet whose radius changes along the edge: not built yet (it needs an exact kernel). Give it one radius."（沿边变化半径的圆角：尚未实现（需要精确内核）。请设置一个半径。） | 取消勾选 **变半径** |
| "Fillet by the mesh kernel: where rounded edges meet they are mitred, not blended."（网格内核圆角：圆角边相交处为斜接，而非融合。）（历史记录中显示 ⚠） | 这是警告而非错误：零件已构建。所选边在一个角处相交，圆角在那里相交成一条尖锐的折痕。请减少圆角的边，或接受该折痕 |
| "Shell: in this version it opens flat faces only (the mesh kernel builds it)."（抽壳：本版本仅可打开平面（由网格内核构建）。） | 打开的面是弯曲的。请用 {{ui:选择面}} 将其移除；只打开平面 |

## 限制

在本版本中，圆角和倒角仅适用于两个平面之间的直边，使用单一半径，并且在角处相交的圆角会斜接。抽壳仅可打开平面。在精确内核下，变半径圆角沿每条边线性变化（每个特征一条规律；不能在边上的各点设置半径）。面圆角、全圆圆角以及不同壁厚的壳体尚未实现。
