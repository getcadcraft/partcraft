装配体用于将零件组合在一起。在 PartCraft 中，**连接**负责定位零件：每个连接位于两个零件各自的一个平面上，并使两者面对面贴合。旋转连接允许一个零件转动，滑动连接允许其滑动，刚性连接则将其固定。

## 开始创建装配体

1. 创建一个带实体的零件（空零件无法放入装配体：“请先创建实体，然后再将其放入装配体。”）。
2. 在工具栏中选择{{ui:装配体}}。

状态栏会显示“已以 Part1 作为固定零件开始装配体。请插入更多零件（添加副本、插入，或编辑 › 创建副本），然后为它们添加连接。”左侧面板现在列出**零件**和**连接**，工具栏显示装配体工具。草图和特征工具会被隐藏。

第一个零件为**固定**零件：它永远不会移动，其余所有零件都相对于它定位。

## 插入零件

- {{ui:添加副本}}插入所选零件（或最后一个零件）的另一个副本。副本共享同一个零件：编辑它，所有副本都会随之变化。
- “编辑”组中的{{ui:创建副本}}（{{key:Mod+D}}）对所选零件执行相同的操作。{{key:Mod+C}}和{{key:Mod+V}}可复制零件，并将其粘贴到其他零件旁边，无论是在此装配体还是另一个装配体中；{{key:Mod+Shift+V}}则将其粘贴到相同位置。参见[复制、粘贴与创建副本](topic:copy-paste)。
- {{ui:插入}}从计算机上的 `.partcraft.json` 文件插入零件。该零件会被复制到装配体中。

新零件会出现在现有所有零件右侧 20 mm 处，并一直保持在该位置，直到连接将其定位。没有连接的零件也可以手动移动：输入数值或拖动箭头（参见[零件清单、爆炸视图和移动零件](topic:assembly-bom-explode)）。

## 连接两个零件

1. 选择{{ui:连接}}或按{{key:J}}键。右侧面板会显示**新建连接**。
2. 点击第一个零件上的一个平面。该面会高亮显示。
3. 点击第二个零件上的一个平面。

第二个零件会跳到位，使其面紧贴第一个零件的面并与之相对。连接会出现在**连接**下，例如“Revolute1”，右侧面板显示其设置。

- 如果两个面都由旋转生成，连接默认为**旋转**；否则为**刚性**。之后可以更改。
- 无法拾取曲面：“该面为曲面。请拾取平面（如需绕孔或旋转轴转动，请在之后的连接中选择它）。”
- 按{{key:Esc}}键可取消已开始的连接（或点击左侧列表中的一个零件）。

### 连接设置

| 设置项 | 作用 |
|---|---|
| **类型** | 下表中的一种连接 |
| **角度(°)** | 使第二个零件绕连接轴转动（与各面垂直） |
| **偏移量(mm)** | 使第二个零件沿轴线远离该面移动（负值则使其压入该面） |
| **沿 X**、**沿 Y**、**绕 X 倾斜**、**绕 Y 倾斜**、**沿槽**、**槽方向** | 其他取值，仅对使用它们的连接显示 |
| **中心位于**（每一侧） | 连接轴与面相交的位置：“面自身的原点”、旋转的轴（“Axis of Revolve1”）或某个孔的轴（“Hole1, hole 2”） |

连接允许移动的每个取值在其输入框下方都有拖动滑块；其他取值只需设置一次。

| 连接 | 可移动内容 | 仅需设置一次 |
|---|---|---|
| **刚性** | 无 | 角度、偏移量 |
| **旋转** | 角度（铰链） | 偏移量 |
| **滑动** | 偏移量（抽屉） | 角度 |
| **圆柱** | 角度和偏移量（滑动轴承中的轴） | |
| **平面** | 沿 X、沿面上的 Y 方向，以及角度（在桌面上滑动的零件） | |
| **球** | 角度（自转）以及绕连接中心的 X、Y 倾斜（球形关节） | |
| **销在槽中** | 沿槽和角度（直槽中的销） | 槽方向：槽相对于面的 X 轴的角度 |

面的 X 和 Y 与第一个零件的面相同；连接中心由**中心位于**设置。

“面自身的原点”是零件原点投影到该面上的位置，通常并非你希望零件对齐的位置。对于圆形零件和销，请将两侧的**中心位于**均设置为旋转轴或孔轴：此时轴线即对齐，类似于同心配合。

### 示例：两个法兰面对面用螺栓连接

1. 打开法兰零件（一个带有环形阵列孔的旋转特征）并选择{{ui:装配体}}。
2. 选择{{ui:添加副本}}。
3. 按{{key:J}}键，点击第一个法兰圆盘上的平面（螺栓孔的起始面），然后点击第二个法兰上的相同面。这些面由旋转生成，因此该连接为旋转连接。
4. 将两侧的**中心位于**均设置为“Axis of Revolve1”。两个法兰现在共享同一轴线。
5. 在**角度(°)**中输入`22.5`以对齐螺栓孔，或拖动滑块。

## 闭环：连杆机构

首尾相连成环的零件（四连杆机构、曲柄滑块机构、两侧均有支撑的框架）构成一个**回路**。PartCraft 会求解每个回路使其闭合：回路上的连接会取得使环闭合的数值，并尽量少地偏离原位置。

- 在回路上的连接中**设置或拖动**某个取值，回路的其余部分会随之跟随。对于四连杆机构，拖动曲柄的**角度**，连杆和摇杆会随之移动。你设置的取值会被保留；其他取值由它推算得出。
- 在列表中，仍可运动的回路上的连接显示为**蓝色**：仍可设置另一个取值。无法运动的回路（有支撑的框架）保持黑色。无法闭合的回路显示为**红色**。
- **零件**框会显示**回路**：已闭合的数量以及仍可运动的取值数量，例如“1 个已闭合；1 个取值仍可移动”。
- {{ui:检查运动中是否有干涉}}会逐步扫描回路上的一个连接，并使回路随之跟随（参见[检查装配体的干涉和运动](topic:check-assembly)）。

由平板叠放而成的平面连杆机构，其厚度必须一致：在环的两侧面对面连接的两个零件，在两个方向上都需要相同的堆叠高度。如果堆叠高度无法吻合，请使用连接的**偏移量**将零件抬起，否则回路无法闭合。

## 处理零件

点击视图或列表中的零件以选中它。右侧面板会显示其零件名称、副本数量、体积、连接，以及它是固定的、由连接确定的，还是“未连接：保持在放置的位置”。按钮如下：

- {{ui:编辑此零件}}（或工具栏中的{{ui:编辑零件}}，或在列表中双击该零件）：打开该零件进行编辑；
- {{ui:插入副本}}；
- {{ui:设为固定零件}}；
- {{ui:移除}}：同时删除其连接（会先询问）。

装配体至少保留一个零件：“装配体至少需保留一个零件。请改为关闭它。”

### 原位编辑零件

1. 选择一个零件并选择{{ui:编辑零件}}。该零件将连同其历史记录打开；标题显示“Bracket（在 Bracket 装配体中）”。
2. 像编辑其他零件一样进行修改。
3. 在工具栏中选择{{ui:返回}}。装配体随之更新：该零件的每个副本都会改变，由草图边生成的面上的连接会随之跟随。

将更改带回装配体是装配体撤销列表中的一步。

## 撤销、保存和关闭

- 装配体拥有独立的撤销列表：{{key:Mod+Z}}和{{key:Mod+Y}}作用于连接、插入和设置。
- {{ui:保存}}或{{key:Mod+S}}会下载 `<assembly name>.partcraft-asm.json`，其中包含每个零件。之后可使用{{ui:打开}}打开它。
- {{ui:关闭}}会关闭装配体，并返回你最初打开的零件。如果装配体尚未保存，会询问：{{ui:取消}}、{{ui:放弃装配体}}或{{ui:先保存}}。
- 要重命名装配体，请点击空白处使其未选中任何内容，然后在右侧面板中更改**名称**。

## 大型装配体

一个装配体可以容纳数千个少量零件的副本。同一零件的副本会被一起绘制，你转动的连接只会定位其后的零件，零件列表会显示前几行，并在其下方提供“显示更多”按钮（所选零件始终会列出）。

- 在转动或缩放视图时，超过约 300,000 个三角形的装配体会以每个零件一个方框的形式绘制，停止操作后片刻即会完整显示。
- {{ui:视图}} › {{ui:轻量显示}}可让方框始终显示。拾取零件和连接时仍使用实际零件。
- 转动速度还取决于你的显卡。PartCraft 所测得的数据已在版本说明中列出，并注明了测试所用的机器。

## 连接问题

- 没有任何连接触及的零件会被列为**自由**，面板会显示“Bracket2 未与固定零件连接，因此保持在放置的位置。”
- 无法闭合的回路（长度不够、限制阻止了连接、面的深度不一致）：“Revolute3 闭合的回路无法闭合：偏差 2.000 mm。请检查回路连接的面、偏移量和限制。”其连接会变为红色。
- 编辑零件后，如果连接所使用的面或轴已不存在：“该连接所使用的面已从 Bracket 中消失。”请移除该连接并重新创建。
