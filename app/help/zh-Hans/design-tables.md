**配置**是零件的一种尺寸：一组为其参数命名的数值。零件将其配置保存在自己的文件中，因此配置会随零件一起移动。**设计表**就是 CSV 文件形式的同一事物，每个配置占一行。

配置用于设置**参数**，因此请先添加参数（见[用参数驱动部件](topic:parameters)）。配置只保存为普通数字的参数；由其他参数计算得出的参数（例如 `area = w * d`）会自动随之变化。

## 保存配置

1. 在{{ui:参数}}选项卡中，为零件的某一尺寸设置参数。
2. 在**配置**下，输入名称（例如 `大号`），然后按{{ui:保存当前数值}}或 {{key:Enter}}。

新配置会标记为**当前**。之后更改参数，它会显示为**当前，之后已更改**，让你知道零件已与其不再一致。

## 切换、更新、重命名、删除

- {{ui:应用}}将参数设置为该配置的值，并重新生成零件。
- {{ui:更新}}将当前数值保存到该配置中。
- 要重命名，请在其输入框中键入新名称并按 {{key:Enter}}。
- {{ui:删除}}会移除该配置。参数保留其数值。

以上每项操作都是一步：{{key:Mod+Z}} 可撤销。若重命名参数，所有配置都会跟随新名称；若删除某个参数，它会从所有配置中移除。

## 在配置中开启和关闭特征

配置还会记录哪些特征被关闭，因此同一零件可以有带有**某项**和**不带某项**的版本：安装孔、倒角、凸台。

1. 关闭特征：在历史记录中点击该特征，然后在{{ui:属性}}中点击{{ui:压缩}}。
2. 照常保存配置，例如 `无孔`。其行会列出它所关闭的特征。
3. 重新开启该特征（{{ui:取消压缩}}），再保存另一个配置，例如 `有孔`。

一旦任一配置关闭了某个特征，应用某个配置时，会在一步之内连同其参数值一起，关闭其特征并开启**所有其他特征**。在任何配置中关闭特征之前保存的配置，视为“全部开启”。{{ui:更新}}会连同数值一起保存特征当前的状态。

若零件的配置关闭了特征，则会以较新的文件版本保存：较旧的 PartCraft 会提示该文件来自较新版本，而不会在不含这些特征的情况下将其打开。

:::note
CSV 设计表只包含参数值。将表导入到某个配置上会更改其数值，并保留其关闭的特征；命令行的 `--table` 只生成数值。
:::

零件文件会连同配置以及当前处于激活状态的配置一并保存。零件以保存时的数值打开。

## 导入或导出设计表

设计表是一个 CSV 文件，每个参数一列，每个配置一行：

```
name,width,thick,bolt
小,100,6,6.6
中,140,8,8.5
大,200,12,13
```

第一列可命名为 `name`、`config` 或 `configuration`；其他每一列都必须是零件某个参数的名称。单元格为数字，如需要可带单位（`8in`）。空单元格表示该行不包含该参数。

- {{ui:导入CSV}}会将每一行添加为一个配置。名称与现有配置相同的行会替换该配置。导入为一步操作。
- {{ui:导出CSV}}会将配置写出。若尚无配置，则写出一行当前数值，作为电子表格的起点。

电子表格会将以 `=`、`+`、`-` 或 `@` 开头的配置名称读取为公式，此类名称会以前导 `'` 写出。

## 一次生成所有尺寸

**配置**下的{{ui:变体包…}}会将所有配置（或选定的部分配置）一并生成为 STEP、IFC、DWG 文件及预览，打包在一个 zip 中，并附带其参数表：见[从配置制作变体包](topic:variant-pack)。

命令行工具会为 CSV 设计表的每一行生成一个文件：

```
node tools/partcraft-cli/partcraft.mjs build bracket.pcscript --table sizes.csv --out-dir sizes --format step
```

请先将配置导出为 CSV，然后用 `--table` 传入该文件。见[脚本与命令行](topic:scripts-and-cli)。以脚本形式保存的零件，会将其配置保存在 `configs json …` 行中。
