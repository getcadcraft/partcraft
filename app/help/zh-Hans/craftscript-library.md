分析库是一组脚本，每个脚本都是一个可以从头读到尾的函数：刚度矩阵如何装配、边界条件放在哪里、运行哪种求解器、结果如何计算。其中没有任何内容被藏在黑盒里；只有快速的内层循环（单元矩阵、稀疏求解器、网格划分）是内置的。

## 从示例开始

**示例**组包含五个简短脚本，它们端到端地使用分析库。点击其中一个，按{{ui:打开（只读）}}，然后按 {{key:F5}}：每个示例都会清空视图，在画布上显示结果，并在子显示区中显示图表。

| 示例 | 显示内容 |
|---|---|
| 悬臂梁应力 | 一根 100 × 10 × 10 mm 的钢棒，自由端承受 100 N 载荷：变形后钢棒上的 von Mises 应力，以及四种单元尺寸下自由端挠度与梁理论的对比（绘图） |
| MBB 梁拓扑优化 | 经典的 60 × 20 拓扑优化：设计形成过程、柔度下降过程以及最终布局（94 次迭代，柔度 203.19） |
| 电容器电场 | 两块宽 4 mm、相距 1 mm 的极板：电势和电场，以及考虑边缘效应的电容，与理想值及 Palmer 公式的对比 |
| 通道流动 | 格子玻尔兹曼方法模拟的通道中绕过立柱的流动：速度场和收敛历史 |
| 电磁铁 | 带气隙和线圈的 C 形铁芯：磁通密度、气隙中的磁场与磁路公式的对比、电感以及跨气隙的吸力。在[二维磁场](topic:magnetic-fields-2d)中有完整讲解 |
| 永磁体 | 相同铁芯，用永磁体代替线圈：永磁体的工作点、气隙中的磁场与磁路的对比、漏磁量以及吸力。见[二维磁场](topic:magnetic-fields-2d#permanent-magnets) |

## 分组

| 分组 | 函数 | 作用 |
|---|---|---|
| 网格划分 | `box_mesh`、`cylinder_mesh`、`voxel_mesh`、`tet_mesh`、`mesh_quality`、`nodes_at`、`face_nodes` | 将长方体和圆柱体划分为六面体、立方体或四面体；对任意模型（零件、实体、已加载的 STL）划分立方体或四面体；单元体积与质量；在平面或面上拾取节点 |
| 静应力 | `static_voxel`、`static_tet` | 立方体或 10 节点四面体上的线性静应力：位移、应力、von Mises 应力、反力 |
| 框架 | `frame3d` | 用直接刚度法计算由梁、柱和支撑组成的三维框架：端部释放、支座和弹簧、沿杆件的荷载；位移、反力、杆端内力。DetailCraft 和 BimCraft 的{{ui:导出为 CraftScript}}会为其写出整个模型。这是分析辅助工具，而非规范校核 |
| 振动 | `modal_tet` | 固有频率和振型 |
| 热 | `heat_steady`、`heat_transient`、`heat_system` | 具有固定温度、热输入、热生成、热流和对流的稳态与瞬态导热 |
| 拓扑优化 | `top88`、`top99`、`topopt3d` | 已发表的 88 行和 99 行二维代码，以及在立方体上以三维实现的同一方法 |
| 电磁学 | `poisson2d`、`magnetostatic2d` | 二维静电学（电势、电场、电容、电荷）和静磁学（矢量势、磁通密度、永磁体） |
| 流体流动 | `lbm2d`、`lbm3d` | 格子玻尔兹曼流动：二维完整写在脚本中，三维运行在 PartCraft 自有的流动内核上 |

每个函数的头部都给出其精确的参数。除非头部另有说明，单位与 PartCraft 研究所用的单位一致：毫米、牛顿、兆帕；密度用吨每立方毫米；热量用瓦和开尔文。电磁学和格子玻尔兹曼函数可使用任何一致的单位制，其头部会说明具体用法。

## 库如何检验

每个函数的头部都以**检查**结尾：一个答案已知的小算例。PartCraft 的测试会运行其中的每一个检查；若 PartCraft 对同一任务有自己的研究，则将脚本的结果与该研究在相同网格上的结果进行比较：

- 悬臂梁自由端挠度与梁理论的对比（立方体网格内 0.2 %，四面体网格内 0.05 %），以及与**仿真**工作空间的求解器在相同网格上的对比（结果完全一致，精确到很多位）；
- 悬臂梁一阶频率与梁理论的对比（低 0.24 %，对于短梁这是预期结果），以及与**仿真**的模态求解器的对比；
- 热：受热平面墙体（精确解）、小物体按集总热容公式冷却、平板温度按理论衰减；
- 拓扑优化：`top88` 复现了论文中的 94 次迭代和柔度 203.1925（使用密度过滤器时为 218.8032）；`topopt3d` 在相同设置下得到的柔度与**生成式**工作空间相同；
- 电容器的电容和长螺线管的磁场与教科书数值的对比，电磁铁气隙磁场与磁路公式的对比，以及永磁体与空气中圆形磁体、由铁质衔铁闭合的磁体的对比；
- 通道流动与精确抛物线剖面的对比。

## 阅读函数

1. 打开脚本面板的**库**选项卡。
2. 点击一个函数。其头部显示：它计算什么、所用方法、单位、假设和限制、**参考文献**（书籍或论文，附公式编号），以及**检查**——一个由 PartCraft 自身测试运行的、答案已知的小算例。
3. {{ui:打开（只读）}}会在一个带虚线边框的标签页中打开整个脚本。你可以运行它、选中并运行其中的部分，但不能修改。

## 修改函数

按{{ui:制作副本}}（或在只读标签页上方点击**制作副本以便编辑**）。副本是你部件中的一个脚本，名称相同，因此会随部件一起保存，并且**此后每次调用该函数都会使用你的副本**——编辑器会在脚本上方说明这一点。将副本重命名即可两者都保留。

## 使用函数

从任何脚本中，都可以像调用内置函数一样按名称调用库函数：

```
xPhys = top88(60, 20, 0.5, 3.0, 1.5, 1);
```

结果以值的形式返回到工作空间中；函数显示的图和场会出现在视图和子显示区中。

例如，对打开的零件进行静力分析只需几行：

```
v = voxel_mesh(part(), 2);                   % 2 毫米立方体
X = meshNodes(v);
bc = struct('fixed', nodes_at(v, 2, min(X(:, 2))));   % 固定底部
top = nodes_at(v, 2, max(X(:, 2)));
bc.loads = {struct('nodes', top, 'force', [0 -500 0])};   % 顶部向下 500 N
r = static_voxel(v, 210000, 0.3, bc);       % 钢
```

`r` 保存位移、应力和反力；von Mises 应力绘制在变形后的零件上。对于曲面零件，请使用 `tet_mesh` 和 `static_tet`，它们还可以对整个面施加荷载和约束（`face_nodes`）。

:::note
分析库中的函数用 CraftScript 编写，Lua 脚本通过 `cs` 像调用内置函数一样调用它们：`cs.static_tet(t, 200000, 0.3, bc)`（见 [Lua 脚本](topic:craftscript-lua)）。每个函数求解一种材料和一种荷载工况；函数头部列出了未涵盖的其他内容。
:::
