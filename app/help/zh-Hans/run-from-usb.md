工程工具（生成器、工程库、检查和数据文件）**无需管理员权限**，也**无需安装程序**。它们只写入此处列出的内容，不写入其他任何位置。

| 内容 | 保存位置 |
|---|---|
| 零件，包括其生成的实体、数据表和检查 | 保存时所选位置的零件文件（`.partcraft.json`）。 |
| 从文件打开的生成器 | 应用自身的存储：网页中为浏览器本地存储；便携版 Studio 中为程序旁的 `data` 文件夹。最多 20 个。 |
| 设置（已设定的体素尺寸、求解器线程数、布局） | 同一应用存储。 |
| 数据表、字段、网格 | 仅在保存时写入：下载内容保存到所选位置。 |

这些工具**不会自行发起任何网络请求**：随程序附带的生成器是应用自身文件夹中的文件；工程库和检查在计算机上的工作线程中运行，该线程无法访问网络；工程数据（水和空气的性质、材料）内置于应用中。从文件打开的生成器在计算机上读取，不会发送到任何地方。

## Windows 便携版压缩包与 Linux

Windows 便携版 Studio 将其设置、缓存和插件保存在程序旁的 `data` 文件夹中。Linux AppImage 在其旁边存在名为 `portable` 的文件时，同样将它们保存在其旁边；没有该文件时，则使用主目录。没有 Mac 便携版：系统会阻止从网上下载的应用写入自身所在的位置。程序本身的便携版说明（`Studio` 帮助）列出了程序写入的内容。

## 主机访问

此处的操作不请求主机访问权限。打印机、串口设备和 USB 设备是另外的：它们在作业需要时才请求访问，每个设备请求一次；生成器和检查都不会访问它们。
