屏幕分为五个部分：顶部的工具栏、左侧的历史、中间的三维视图、右侧的属性面板和底部的状态栏。它们之上是CadCraft应用栏。

## 应用栏

最顶部的细栏属于CadCraft网站，而不属于PartCraft本身。它显示应用名称和运行位置、版本菜单、**关于PartCraft**、屏幕模式按钮以及“图纸” / “模型”主题切换。

- **图纸**是浅色背景上的深色线条。**模型**是深色背景上的浅色线条。草图颜色随主题变化。
- {{ui:设置}}（齿轮图标，或{{key:Mod+,}}）有一个{{ui:PartCraft}}选项卡：哪个鼠标按键旋转视图、鼠标滚轮或触控板，以及绘制草图时的关系。参见[PartCraft设置](topic:settings)。
- 屏幕模式按钮或{{key:Ctrl+Shift+F}}依次切换普通、全屏，以及隐藏各栏的全屏。隐藏各栏后，将指针移到顶端（或在那里点按）即可调回。{{key:Esc}}回到普通模式。在Mac上这个键同样是{{key:Ctrl+Shift+F}}，而不是⌘。

## 工具栏

工具栏是分组的。它会随你正在做的事而变化，以便放在一行内：

| 组 | 按钮 | 显示时机 |
|---|---|---|
| 文件 | {{ui:新建}}、{{ui:打开}}、{{ui:保存}}、{{ui:导出}}（菜单） | 始终 |
| 草图 | {{ui:草图}} | 没有打开草图时 |
| 草图 | {{ui:退出}}、{{ui:直线}}、{{ui:矩形}}、{{ui:圆}}、{{ui:圆弧}}、{{ui:点}}、{{ui:中心线}}、{{ui:圆角}}、{{ui:标注}}、{{ui:构造}} | 仅在打开草图时 |
| 特征 | {{ui:拉伸}}、{{ui:切除}}、{{ui:旋转}}、{{ui:孔}}、{{ui:线性}}、{{ui:环形}}、{{ui:镜像}}、{{ui:圆角}}、{{ui:倒角}}、{{ui:抽壳}}、{{ui:更多}}（菜单：旋转切除、平面、轴、点、扫描、放样、拔模） | 在零件上，打开草图或图纸时不显示。圆角和倒角用于两个平面之间的直边；抽壳和拔模用于平面。扫描和放样在本版本中尚未实现（它们需要精确内核）；点击会给出说明 |
| 特征 | {{ui:完成}} | 仅在为圆角、倒角、抽壳或拔模拾取边或面时 |
| 图纸 | {{ui:图纸}} | 在零件上（零件有实体后可用） |
| 图纸 | {{ui:基准}}、{{ui:框格}}、{{ui:表面处理}}、{{ui:局部放大}}、{{ui:PDF}}、{{ui:返回}} | 仅在图纸上 |
| 装配体 | {{ui:装配体}} | 在零件上（零件有实体后可用） |
| 装配体 | {{ui:添加副本}}、{{ui:插入}}、{{ui:连接}}、{{ui:干涉}}、{{ui:编辑零件}}、{{ui:关闭}} | 仅在装配体中 |
| 装配体 | {{ui:返回}} | 从装配体中编辑零件时 |
| 编辑 | {{ui:撤销}}、{{ui:重做}}、{{ui:复制}}、{{ui:粘贴}}、{{ui:更多}}（菜单：剪切、复制、粘贴、原位粘贴、创建副本、删除、全选、取消选择） | 始终；每一项作用于你所在的草图、历史或装配体 |

将指针悬停在按钮上可以看到它的作用和快捷键。灰色的按钮当前无法使用：例如打开草图时的特征按钮，或装配体还没有两个零件时的{{ui:连接}}。

“编辑”组中的{{ui:更多}}菜单列出每个编辑操作及其快捷键。复制和粘贴作用于什么取决于你所在的位置；参见[复制、粘贴和创建副本](topic:copy-paste)。灰色项目的工具提示会说明它当前为何不能执行。

{{ui:导出}}菜单包含{{ui:STL，用于3D打印}}、{{ui:3MF，用于3D打印}}、{{ui:STEP AP242（精确实体）}}、{{ui:STEP AP214（精确实体）}}、{{ui:STEP（面片，网格内核）}}、{{ui:STEP AP214（面片，网格内核）}}、{{ui:草图或平面的DXF}}和{{ui:图纸（PDF）：视图、剖面、局部放大、几何公差}}。两个精确STEP项呈灰色：它们在本版本中尚未实现，请使用{{ui:STEP（面片，网格内核）}}。

## 历史（左侧）

左侧的面板是零件的特征历史，即PartCraft从上到下重新构建的列表。

- 标题是零件的名称（重命名之前为“零件1”）。
- **正面平面**、**顶面平面**和**右面平面**排在最前。点击其中一个可选择它；它会在视图中高亮显示。
- 其下是你按创建顺序排列的特征。特征所使用的草图缩进显示在该特征之下。
- 行右端的标志说明其状态：

| 标志 | 含义 |
|---|---|
| （无） | 已构建，且草图完全定义 |
| − | 欠定义的草图（仍可移动） |
| + | 过定义的草图 |
| ⚠ | 已构建，但有警告（悬停可阅读） |
| ⚠ 错误 | 特征失败。悬停可阅读原因，或点击它 |
| ⚠ 未生成 | 该特征依赖另一个已失败或已关闭的特征 |
| 关闭 | 已压缩 |

- 每个特征的名称后显示它的主要数值，例如拉伸的“25 mm”或孔的“Ø6.6 thru”。双击该数值，或在该行上按{{key:F2}}，即可就地更改。参见[更改尺寸](topic:change-sizes)。
- 点击特征可在右侧编辑它。双击草图可打开它。
- 回退时，列表中会出现一行**回滚条 · 向前滚动**。其下的特征呈灰色且未生成。
- 焦点在某一行时，{{key:Up}}和{{key:Down}}在行之间移动，{{key:Alt+Up}} / {{key:Alt+Down}}在历史允许的情况下移动特征本身。

在装配体中，同一面板改为列出**零件**（第一个标有“固定”）和**连接**。

### 零件信息

历史下方的**零件**框列出实体的**体积**、**表面积**、**尺寸（X × Y × Z）**、**通孔**、**实体**、**三角面**、**特征**数量以及有多少个**失败**。体积和面积针对的是由网格内核构建的面片实体，对圆形来说比真实值略小（参见[特征及其选项](topic:features#curves-resolution)）。

在装配体中，该框的标题为**装配体**：零件、实例、连接、未连接和干涉。

## 三维视图（中间）

视图显示实体、基准平面以及尚未被特征使用的草图。

零件为空时，基准平面完整绘制。零件有了实体后，它们退到后面：绘制得很淡，以免遮挡零件，点击会穿过它们作用到零件上。在你选择草图位置时（未选取任何内容时的{{ui:草图}}）以及在历史中选择某个平面时，它们会恢复完整显示。{{ui:视图}} › {{ui:基准平面}}可将它们完全隐藏；在你选择草图位置时它们仍会显示。PartCraft会记住这个选择。

- 拖动可旋转零件，右键拖动或中键拖动可平移，滚动滚轮在指针处缩放。详见[按键和鼠标](topic:keyboard)。
- 将指针悬停在面、边或平面上，它会亮起。点击即可拾取。面整体高亮，边整体绘制和拾取。按住{{key:Shift}}点击可收集多条边或多个面。它们会保持标记。
- 右上角的视图立方体随零件转动：点击面、边或角可从该方向观察，拖动可旋转，房子按钮返回起始视角。参见[视图立方体](topic:view-cube)。
- 选中的拉伸会在其端面上显示橙色箭头，旋转则在其转动末端显示弯曲箭头：拖动可更改深度或角度，也可在旁边的框中输入。参见[更改尺寸](topic:change-sizes#drag-it-in-the-view)。
- 零件为空时，标题为**开始一个零件**的框列出最初的几步。
- 将`.partcraft.json`或`.partcraft-asm.json`文件拖放到视图的任意位置即可打开。拖放到那里的`.step`、`.stp`、`.stl`、`.obj`、`.3mf`或`.3dm`文件会作为实体打开。

### 拾取边或面时

在没有拾取任何内容的情况下选择{{ui:圆角}}、{{ui:倒角}}或{{ui:抽壳}}后（或对此类特征选择{{ui:选择边}}），零件会显示为该特征之前的样子。点击边或面可添加或移除；它们的标记显示哪些已包含在内。{{ui:完成}}或{{key:Esc}}结束。参见[倒圆、倒角和抽壳](topic:fillet-chamfer-shell)。

### 在图纸上

{{ui:图纸}}用A3图纸取代三维视图。滚轮缩放，右键或中键拖动平移，{{key:F}}适合窗口。参见[制作图纸](topic:drawing-pdf)。

### 打开草图时

视图会转为正对草图平面，并在上面出现一个二维草图层。零件只显示此草图之前创建的特征。左上角的一条信息显示草图的状态标签（“完全定义”、“欠定义 · 3个自由度”等）及其名称，例如“拉伸1的一个面上的草图2”。

## 属性面板（右侧）

右侧的面板显示当前选中的内容，其标题给出名称：

- **零件**（未选择任何内容）：零件的**名称**和**曲线**设置。
- 平面：一个{{ui:在其上绘制草图}}按钮。
- **面**：它的种类（平面、带半径和轴线的圆柱面、圆锥面、球面或圆环面）、面积、由哪个特征生成，对于平面还有{{ui:在此面上绘制草图}}、{{ui:正对}}、{{ui:将面导出为DXF}}、{{ui:从此面拉伸}}、{{ui:切入此面}}和{{ui:在此打孔}}（参见[拉出或推入整个面](topic:extrude-and-cut#pull-or-push-a-whole-face)）。
- **边**：它的种类（直线、带圆心和半径的圆，或曲线）、长度，以及它所在的两个面（例如“拉伸1端面和拉伸1侧面”），带{{ui:圆角}}和{{ui:倒角}}按钮。
- 按住{{key:Shift}}拾取的多条边或多个面：数量，边带有{{ui:圆角}}和{{ui:倒角}}，以及{{ui:清除}}。
- 特征：它的数值和选项、其草图的尺寸，然后是{{ui:压缩}}、{{ui:回滚到此处}}、{{ui:上移}}、{{ui:下移}}、{{ui:删除}}及其**名称**。
- 已打开的草图：它的状态、可添加到所选内容的关系、关系和尺寸列表、**按坐标添加**，以及{{ui:退出草图}}、{{ui:适合}}和{{ui:导出为DXF}}。
- 在图纸上：剖面和局部放大的设置，或所选的几何公差符号。
- 在装配体中：装配体、所选零件或所选连接。

每个数字框在你按{{key:Enter}}或{{key:Tab}}或点击别处时生效。零件会立即重新构建；没有“确定”按钮。用{{key:Mod+Z}}返回。

## 状态栏（底部）

- 左侧是指针在草图中的坐标（仅在打开草图时）。
- 中间是消息：接下来该做什么，以及某项操作为何被拒绝。看起来没有反应时请看这里。
- 靠右是内核标签：在此版本中始终为“网格内核”。悬停可了解其含义。参见[网格内核](topic:solid-kernels)。
- 最右侧是一个标签：零件重建时显示“正在重建…”，一切正常时显示“已在…毫秒内重建”，否则显示“1个特征失败”。在装配体中它显示“已在…毫秒内放置完成”，或统计连接问题的数量。

另见[在Illustrate中开始一本手册](topic:illustrate)：用你的零件和装配体制作装配手册的工作空间。

## 在窄屏幕上

宽度不超过760像素时（例如手机），视图占满屏幕：工具栏变为可横向滚动的一行，面板从底部的栏中以面板页的形式打开。{{ui:工具}}隐藏工具栏，{{ui:移动}}把它放到底部。参见[触控板、触摸和小屏幕](topic:trackpad-and-touch)。
