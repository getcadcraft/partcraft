打开 {{ui:Settings}}：点击应用栏中的齿轮图标，或按 {{key:Mod+,}}。第一个选项卡 {{ui:PartCraft}} 包含仅属于本应用的设置；{{ui:General}} 包含所有 CadCraft 应用共享的设置（主题、工具栏、面板）。PartCraft 的设置仅在本应用中存在：在此更改后，本浏览器会记住它们。{{ui:Reset PartCraft settings}} 会将所有设置恢复为初始值。

## 旋转视图

- **左键**（初始设置）：按住左键拖动以旋转零件；按住右键或中键拖动以平移。
- **中键**：按下滚轮并拖动以旋转零件；按住 {{key:Shift}}（或 {{key:Ctrl}}，或 ⌘）并使用中键，或使用右键拖动，以平移。左键仅用于选择面、边和平面，因此轻微移动的点击不会旋转零件。许多 CAD 程序采用这种方式。

无论哪种方式，滚轮都以指针位置为中心缩放。在草图中，右键和中键仍照常平移。

## 滚动：鼠标滚轮或触控板

- **自动判断**（初始设置）：PartCraft 会监测滚动。触控板发出的横向或细微滚动会旋转零件；滚轮的整格滚动则会缩放。
- **鼠标滚轮**：滚动始终以指针为中心缩放。
- **触控板**：双指滑动以旋转零件，按住 {{key:Shift}} 并滑动以平移，捏合以缩放。在草图中，双指滑动可平移草图。

所有选项下，捏合均可缩放。如果"自动判断"对您的鼠标或触控板判断有误，请选择您实际使用的设备类型。更多内容参见[触控板、触摸与小屏幕](topic:trackpad-and-touch)。

## 草图：绘制时添加关系

**绘制时添加关系**（初始开启）：点击吸附到某点时，新点会与之重合；点击曲线时，点会位于该曲线上；接近水平或竖直绘制的直线会变为水平或竖直。参见[关系与尺寸](topic:relations-dimensions)。

关闭后，可以将几何图形放置在其他几何图形附近而不与之相连。指针仍会吸附到点和曲线，但不会建立连接：连续绘制的直线不会共享端点，因此拖动时可能会将它们分开。请在右侧面板中自行添加所需的关系。闭合轮廓在首尾相接时仍可拉伸。

:::note
该设置仅影响之后新绘制的内容。草图中已有的关系保持不变，圆角工具仍会生成其相切圆弧和半径。
:::

## 草图：绘制时标注尺寸

**绘制时标注尺寸**（初始开启）：绘制直线、矩形、圆或圆弧时，输入数字会填入指针旁的尺寸框（{{key:Tab}} 切换到下一个框），按 {{key:Enter}} 即可按该尺寸绘制图形，并为每个输入的尺寸添加驱动尺寸。关闭后，绘制时输入数字不起作用，图形只能通过点击绘制。参见[绘制时输入尺寸](topic:sketch-basics#type-the-size-as-you-draw)。

## 角落指示器

三维视图角落显示的内容：**视图立方体**（初始设置；位于右上角，点击面、边或角可从该方向观察，拖动可旋转视图，拖动其罗盘环可转动模型）、**坐标轴图标**（左下角一个小的 X、Y、Z 标记，随视图转动：X 为红色，Y 为绿色，Z 为蓝色）或**无**。绘制草图或在图纸上时，两者都不显示。参见[视图立方体](topic:view-cube)。

## 求解器线程

仿真求解器可使用的线程数。**自动**（初始设置）使用计算机逻辑处理器数减一（最多 16 个），以便求解时页面保持响应；也可以选择一个具体数字。大型体素研究、屈曲、随时间变化的应力和流动求解在多线程下速度更快（在我们的测试中，80,000 个立方体在 4 线程下约快 2 倍，在空闲计算机上可能更快）；约 20,000 个未知量以下的模型仍使用单线程，因为启动线程的开销超过其节省的时间。多线程求解与单线程的结果相同（仅舍入误差范围内：求和顺序不同）。每项研究的结果会在 **求解器** 下列出 **N 个线程** 或 **1 个线程** 及其原因。

线程要求页面处于**跨源隔离**状态（只有在此状态下，浏览器才允许工作线程共享内存）。实验室页面满足此条件；若不满足，设置中会说明（"此页面未跨源隔离，因此无论此处选择何种设置，求解器都只使用一个线程。"），且每次求解都只使用一个线程。其他功能与之前相同，结果也相同。

层流研究同样使用线程（在 54,000 个流体单元、4 线程下约快 2.5 倍，结果精确到最后一位相同）。二次四面体求解器和热传导在单线程下运行：在我们的测试计算机上，对其进行多线程化后反而更慢（它们的求解器受内存速度和一个无法拆分的步骤限制）。

### 在自有 Web 服务器上

若您从自己的服务器运行 PartCraft，它按原样即可工作。要使用求解器线程，请让服务器在发送 PartCraft 页面时附带以下两个响应头：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

在 Apache 上，于文件夹的 `.htaccess` 中（需要 mod_headers）：

```
Header set Cross-Origin-Opener-Policy "same-origin"
Header set Cross-Origin-Embedder-Policy "require-corp"
```

在 nginx 上，于提供 PartCraft 的 `location` 中：

```
add_header Cross-Origin-Opener-Policy "same-origin" always;
add_header Cross-Origin-Embedder-Policy "require-corp" always;
```

刷新页面后，设置 › 求解器线程 会提供 **自动**（使用计算机的处理器数）。第二个响应头会使浏览器拒绝页面从其他不允许该行为的站点加载的任何内容，对 PartCraft 本身而言这没有问题（它只从自己的文件夹加载所有内容）。
