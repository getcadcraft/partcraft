## Mba'e ikatu ereikuaa

Mba'eichapa pieza ojambue heta persona modelo ojapo jave. CadCraft Studio-pe Live TeamWork sesión oñepyrũ ha oñeʼẽ (Compartir, Unirse); ko ehechakuaa pieza ndive.

## Opa oiporu modelo-pe

Opa oiporu peteĩ elemento árbol-pe: boceto, extrusión, agujero, patrón, filete, parámetro. Nde ojambue ohechauka hoʼã; ambue persona ojambue ohupytýta peteĩ momento rire. Árbol ojapo hasy; sólido cada ventana-pe ojapo, PartCraft núcleo árbol mismo sólido cada ventana-pe ojapo.

- **Mokõi persona peteĩ elemento ojambue:** ambue ajuste (peteĩ profundidad, ambue fin condición) mokõi oguardá; ajuste mismo ojambuévaʼekue tapykue.
- **Boceto** árbol ojapo: mokõi persona peteĩ boceto ojambue jave, tapykue ojambue ganá. Eheka mavaʼe boceto ojapóta.
- **Elemento peteĩ ojeitýva jave** (extrusión oikoʼỹva boceto, agujero oikoʼỹva cara) ojeitýi, estado barra oñeʼẽ mba'ere.
- **Árbol ojapo jey** chequeado: mokõi persona peteĩ momento elemento ojapo jave, segundo jave ojeitýi.

## Ohechakuaa

Opavavépe sesión-pe peteĩ color oguereko. Ambue persona puntero flecha color-pe nombre ndive, cara ohechauka. Árbol-pe elemento elegí jave, nombre ohechauka.

Puntero, nombre ha elección sesión-pe ndaʼéi: archivo-pe ndoguardái ha ndoikói ningún persona deshacer-pe. Ohechauka ojepyrũ, lento conexión-pe jepe suave.

## Deshacer nde ojapo

{{key:Mod+Z}} nde última ojapo ojejapo ha ambue ndoikói. Ambue persona oiko jave, ndojejapói ha estado barra ohechauka máma.

## Navegador-gui oñeʼẽ

Persona Studio ndaiporíva ohecha QR-pe host código ndive, teléfono, tablet térã computadora red mbytépe. PartCraft navegador-pe oñepyrũ, host pieza oguejy ha ojapo host ojojoaʼỹ jave. Enlace invitación red ambue-pe ojoaʼỹ: host Team Cloud Plan plaza app-pe ohendu, ambue persona libre; enlace host sesión abierta jave ojapo.

## Sesión oñemoĩ jave

Host rehe pieza oguardá. Ambue persona copia ndoguardaʼỹ oguereko: guardá nde mba'eve rehe.

:::note
Ensamblaje sesión-pe ndojoaʼỹi: pieza ipahára ojeporu mokõi persona.
:::
