Tecla ndojapói panel-pe número caja-pe ñeñe'ẽ jave, excepto {{key:Mod+S}} ha {{key:Mod+O}}, ha'e kuri heta ojapo siempre. Letra tecla ojapo sin modificador.

Tecla ha mouse rehe ñe'ẽ general ha teclado función ndaipóri: [Teclas, mouse ha trackpad](common:keys).

## Opa ibápe

| Tecla | Mba'e ojapo |
|---|---|
| {{key:Mod+S}} | Guardar pieza (ensamblaje-pe: ensamblaje). Ojejuhu boceto abierto ántes |
| {{key:Mod+O}} | Abrir pieza térã ensamblaje archivo (ojapo pregunta ántes si oiko cambio ndoguardái) |
| {{key:Mod+Z}} | Deshacer |
| {{key:Mod+Y}} térã {{key:Mod+Shift+Z}} | Rehacer |
| {{key:F1}} | Abrir térã cerrar esta ayuda (ha {{ui:Help}} barra-pe). {{key:Esc}} ha'e cerrar avei. Heta notebook ha Mac teclado-pe, Fn pytyvõ |
| {{key:Ctrl+Shift+F}} | Pantalla modo: normal, pantalla completa, pantalla completa barra ocultáva. Mac-pe avei Control, ⌘ ndaha'éi |
| {{key:Esc}} | Pantalla completa-gui ijeity (pantalla completa-pe jave) |
| {{key:Mod+,}} | {{ui:Settings}}, PartCraft pestaña-pe avei (ver [PartCraft configuración](topic:settings)) |

Panel-pe número caja-pe, {{key:Mod+Z}} ha'e nave texto deshacer. Número caja boceto cota rehe jave, PartCraft-pe ojedeshace.

## Copiar, pegar ha duplicar

Ojapo oñeñandu hag̃ua: boceto abierto-pe selección geometría, historia-pe selección elemento, térã ensamblaje-pe selección pieza. Ha'e [Copiar, pegar ha duplicar](topic:copy-paste) rehe.

| Tecla | Mba'e ojapo |
|---|---|
| {{key:Mod+C}} | Copiar selección |
| {{key:Mod+X}} | Cortar: copiar, upéi eliminar |
| {{key:Mod+V}} | Pegar. Boceto-pe kópia puntero rapykue ho'a: clic upe ohóva |
| {{key:Mod+Shift+V}} | Pegar upe mismo lugar-pe: mismo coordenadas (ensamblaje-pe, mismo lugar) |
| {{key:Mod+D}} | Duplicar: copiar ha pegar peteĩ jave, portapapeles ndaipóri moñeñe'ẽ |
| {{key:Mod+A}} | Seleccionar todo (boceto-pe) |
| {{key:Esc}} | Ndaipóri selección (ha cancelar pegar puntero rapykue) |

Número caja-pe, ko teclas kópia ha pega texto ojapo oñeñandu. Panel-pe selección texto navegador ha'e kopia.

| {{key:Backspace}} | Eliminar elemento selección-pe, selección oiko jave |
| {{key:Esc}} | Ndaipóri boceto plano selección, térã selección ({{key:Shift}} rupive ojejapo borde térã cara rehe avei) |

## Navegador ojapo heta tecla

- Safari-pe {{key:Mod+Y}} historia ojehechauka: rehacer ojapo {{key:Mod+Shift+Z}}.
- {{key:Mod+D}} navegador marcador tecla: PartCraft ojeporavo app-pe, box-pe ojapo'ỹ.
- {{key:F11}} ha {{key:Mod+Plus}} / {{key:Mod+Minus}} navegador pantalla completa ha página zoom, PartCraft-pe ndaha'éi. Pantalla completa {{key:Ctrl+Shift+F}}, modelo zoom rueda rupive.
- Heta notebook ha Mac teclado función Fn ojapo: Fn+{{key:F1}} ayuda, térã {{ui:Help}} botón.

Tecla ha trackpad gesto: [Trackpad, touch ha pantalla chiquitu](topic:trackpad-and-touch).
