Python سومین زبان [فضای کار اسکریپت](topic:craftscript) است. **Python** را در جعبه‌ی زبان بالای ویرایشگر انتخاب کنید (فایل `.py` خودبه‌خود در Python باز می‌شود). Python، Lua و CraftScript متغیرها و توابع داخلی یکسانی دارند، پس یک اسکریپت Python می‌تواند از آنچه یک اسکریپت CraftScript ساخته استفاده کند، و برعکس.

نخستین اجرای Python در هر بازدید خود Python (CPython 3.14، حدود 7 MB) را از این سایت بار می‌کند که چند ثانیه طول می‌کشد. Python هنوز بخشی از {{ui:ذخیره برای استفاده آفلاین}} نیست: نخست یک اسکریپت Python را هنگام اتصال به اینترنت اجرا کنید.

## Python ایزوله است

اسکریپت‌های Python مانند اسکریپت‌های CraftScript و Lua ایزوله‌اند: فقط به قطعه، متغیرها و توابع داخلی دسترسی دارند و به چیز دیگری نه. هر اجرا یک Python تازه در محیط ایزوله‌ی خودش است با یک درخت فایل کوچک در حافظه (کتابخانه‌ی استاندارد آن و پوشه‌ی `/tmp` که پس از اجرا از بین می‌رود). در مرورگر و خط فرمان به یکسان نمی‌تواند به شبکه، فایل‌های شما یا بقیه‌ی صفحه دسترسی پیدا کند. اسکریپتی از دیگری همچنان ممکن است زمان یا حافظه‌ی زیادی مصرف کند: {{ui:توقف}} آن را پایان می‌دهد.

## اصول

```
A = cs.magic(3)              # هر تابع داخلی به‌صورت cs.<name> است
B = A @ A.T                  # @ ضرب ماتریسی است، .T ترانهاده
C = A * 2 + 1                # + - * / ** عنصر به عنصرند، همان‌طور که در numpy است
print(A[0, 1], A[-1, -1])    # از 0 شروع می‌شود؛ منفی از انتها می‌شمارد
row = A[1]                   # یک نمایه روی ماتریس: یک سطر
big = A[A > 4]               # یک ماسک منطقی عنصرها را انتخاب می‌کند
A[0, 0] = -5                 # انتساب به یک آرایه
V, D = cs.call('eig', 2, A)  # چند نتیجه: cs.call(name, تعداد، …)
```

- یک آرایه‌ی 1 × 1 به‌صورت یک عدد ساده دریافت می‌شود؛ آرایه‌های دیگر، ماتریس‌های تنک، مش‌ها، میدان‌ها و مدل‌ها **Values** هستند.
- یک Value دارای `shape` (یک توپل)، `T`، `type`، `numel()`، `copy()`، `tolist()`، `len()` (سطرهایش)، و `float()`، `int()` و `bool()` برای یک عنصر است.
- مقایسه‌ها (`<`، `==`، …) عنصر به عنصرند، همان‌طور که در numpy است: یک Value منطقی می‌دهند.
- فهرست‌های عددی که به یک تابع داخلی داده می‌شوند آرایه می‌شوند: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` یک ماتریس می‌سازد.
- یک dict ساختار می‌شود و فهرستی از چیزهای مختلط سلول، و برعکس.

هر متغیر سراسری که اسکریپتتان می‌سازد (یک عدد، یک Value، یک dict، یک فهرست…) هنگام پایان اجرا، حتی پس از خطا، به زبانه‌ی **متغیرها** می‌رود. نام‌هایی که با `_` شروع می‌شوند، توابع، کلاس‌ها و ماژول‌ها در Python می‌مانند. `ws.name` مستقیماً یک متغیر را می‌خواند یا تنظیم می‌کند، و `ws_names()` آن‌ها را فهرست می‌کند.

`print(…)` در کنسول می‌نویسد. `display(…)` (یا `cs.display`) یک مش، میدان یا نمودار را نشان می‌دهد، همان‌طور که در CraftScript.

## فراخوانی کتابخانه‌ی تحلیل

توابع کتابخانه مانند توابع داخلی فراخوانی می‌شوند: `cs.box_mesh(20, 10, 10, 5, 'hex')`، `cs.call('modal_tet', 2, …)`. نام را در اسکریپت همان‌طور که هست بنویسید: PartCraft پیش از اجرا توابع کتابخانه‌ای را که اسکریپت به کار می‌برد پیدا می‌کند.

## هنوز نیست

- numpy، scipy و بسته‌های دیگر: فقط کتابخانه‌ی استاندارد خود Python (`math`، `json`، `itertools`، `decimal`، `statistics`…) اینجاست، بدون بخش‌های پنجره، ترمینال و پایگاه‌داده‌اش (`tkinter`، `curses`، `sqlite3`).
- سوکت‌ها و هر چیز دیگری که به بیرون دسترسی پیدا کند: Python اینجا شبکه ندارد.
- `time.sleep` فوراً برمی‌گردد.
- جمع کردن (folding) در ویرایشگر، و فراخوانی یک تابع Python از یک اسکریپت CraftScript.
- هر 1000 خط، اجرا بودجه‌ی دستورها و توقف را بررسی می‌کند؛ محاسبه‌ی طولانی داخل یک تابع داخلی ابتدا تمام می‌شود.
