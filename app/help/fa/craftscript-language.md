CraftScript یک زبان ماتریسی است که طوری نوشته شده که مانند MATLAB خوانده شود، بنابراین بیشتر کدهای عددی کلاسیک (برای نمونه کد بهینه‌سازی توپولوژی 88 خطی) با تغییرات کوچکی اجرا می‌شوند. این زبان در [فضای کار اسکریپت](topic:craftscript) و از خط فرمان اجرا می‌شود.

## مقادیر

| نوع | مثال | توضیح |
|---|---|---|
| عدد، آرایه | `a = 3`، `v = [1 2 3]`، `A = [1 2; 3 4]` | هر عدد یک آرایه است (یک آرایه‌ی 1×1). آرایه‌ها ستون به ستون ذخیره می‌شوند و تا 8 بعد دارند |
| منطقی | `A > 2`، `true` | آرایه‌هایی از درست/نادرست؛ قابل استفاده به‌عنوان نمایه |
| متن | `'beam'`، `"beam"` | |
| ماتریس تنک | `sparse(i, j, v, n, n)` | برای ماتریس‌های سختی |
| مش، میدان، مدل | `hexGrid(…)`، `part()`، `load('part.stl')` | آنچه `show` رسم می‌کند |
| ساختار | `s.E = 210e3` | فیلدهای نام‌دار |
| سلول | `c = {1, 'two', [3 4]}` | فهرستی از هر مقدار |
| دستگیره‌ی تابع | `f = @(x) x.^2` | |

## آرایه‌ها و نمایه‌گذاری

- بازه‌ها: `1:5`، `0:0.1:1`. `linspace(a, b, n)`، `zeros(n, m)`، `ones`، `eye`، `rand`.
- نمایه‌گذاری از 1 شروع می‌شود: `A(2, 3)`، `v(end)`، `A(:, 1)` (یک ستون کامل)، `A(:)` (همه‌چیز به‌صورت یک ستون)، `v(v > 0)` (نمایه‌گذاری منطقی).
- انتساب بعد از پایان، آرایه را بزرگ می‌کند، مانند MATLAB: `v(10) = 1`.

## عملگرها

- `+ - * / \ ^` عملیات ماتریسی هستند (`A \ b` حل می‌کند)؛ `.* ./ .^` عنصر به عنصر کار می‌کنند. `'` ترانهاده می‌گیرد.
- مقایسه‌ها `== ~= < <= > >=`؛ منطق `& | ~` (عنصر به عنصر) و `&& ||` (اتصال کوتاه).

## جریان کنترل و توابع

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

توابع را پس از دستورهای یک اسکریپت یا در زبانه‌ای جداگانه با نامی برابر نام تابع قرار دهید:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

نام به این ترتیب جستجو می‌شود: یک متغیر، یک اسکریپت در این قطعه با همان نام، یک تابع کتابخانه، یک تابع داخلی.

## Echo، توضیح‌ها و خروجی

- دستوری که `;` ندارد مقدار خود را چاپ می‌کند؛ `;` آن را بی‌صدا نگه می‌دارد.
- `%` یک توضیح را شروع می‌کند؛ `%{` و `%}` در خط‌های جداگانه، خط‌های بین خودشان را به‌صورت توضیح درمی‌آورند.
- `disp(x)`، `fprintf('%g\n', x)` و `display(x)` در کنسول چاپ می‌کنند.

## خطاها و محدودیت‌ها

- خطاها با زبان ساده می‌گویند چه مشکلی پیش آمده و خط (و مسیر فراخوانی تابع‌ها) را نشان می‌دهند.
- هر اجرا بودجه‌ی گام دارد (گزینه‌های اجرا در پنل)؛ حلقه‌ی بی‌پایان با یک پیام متوقف می‌شود، یا توقف را فشار دهید.
- هر آرایه تا 134 میلیون مقدار دارد.

## تفاوت با MATLAB

- دستورهای رسم، گزینه‌های خود را در فراخوانی قرار می‌دهند: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`، `hold`، `axis`، `title(…)` و مانند آن‌ها پذیرفته می‌شوند و کاری انجام نمی‌دهند.
- `input` و `keyboard` پشتیبانی نمی‌شوند: اسکریپت نمی‌تواند برای پرسیدن پرسشی متوقف شود.
- جعبه‌ابزار وجود ندارد؛ آنچه هست [کتابخانه‌ی تحلیل](topic:craftscript-library) و توابع داخلی است.
