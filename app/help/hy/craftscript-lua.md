Lua-ն [Սցենարների աշխատանքային տարածքի](topic:craftscript) երկրորդ լեզուն է։ Ընտրեք **Lua**-ն խմբագրիչի վերևի լեզվի տուփում (`.lua` ֆայլը բացվում է Lua-ով ինքնուրույն)։ Lua-ն և CraftScript-ը կիսում են նույն փոփոխականները և նույն ներկառուցված ֆունկցիաները, ուստի Lua սցենարը կարող է օգտագործել CraftScript սցենարի ստեղծածը, և հակառակը։

## Հիմունքները

```
-- յուրաքանչյուր ներկառուցված ֆունկցիա `cs` աղյուսակում է
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1-ից սկսած, ինչպես CraftScript-ում
print(K(1, 1), #K)             -- տարր; տարրերի քանակը

-- աշխատանքային տարածքը՝ նույն փոփոխականները, որ տեսնում է ամեն սցենար
ws.total = K(1, 1) * 2
print(ws.total)

-- մի ֆունկցիայից մի քանի արդյունք
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)`-ը կանչում է ցանկացած ներկառուցված ֆունկցիա և վերադարձնում է իր առաջին արդյունքը; `cs.call(name, n, …)`-ը վերադարձնում է `n` արդյունք։
- `cs.tensor({1, 2, 3})`-ը սարքում է տող, `cs.tensor({{1, 2}, {3, 4}})`-ը՝ մատրից։
- Զանգվածները, նոսր մատրիցները, ցանցերը և դաշտերը արժեքներ են մեթոդներով․ `t(i, j)` կամ `t:get(i, j)`, `t:set(i, j, v)`, `t:shape()`, `#t`, `t:T()` (տրանսպոնում), `t:totable()`։ `+ - * / ^`-ը նշանակում են նույնը, ինչ CraftScript-ում (`*`-ը մատրիցային արտադրյալն է)․ `t:times(u)`-ը բազմապատկում է տարր առ տարր։
- 1×1 զանգվածը Lua-ին հասնում է որպես սովորական թիվ։
- `ws.name`-ը կարդում և գրում է ընդհանուր աշխատանքային տարածքը։ Գլոբալ փոփոխականները, որ սցենարը թողնում է, նույնպես այնտեղ են հայտնվում, երբ այն ավարտվում է։
- `print(…)`-ը գրում է կոնսոլ; `cs.show(f)`, `cs.plot(y)` և մյուս ցուցադրող ֆունկցիաները աշխատում են ինչպես CraftScript-ում։

## Կանչել վերլուծական գրադարանը

Վերլուծական գրադարանի ֆունկցիաները (**Գրադարան** ներդիրից) և ձեր դետալի սցենարների սահմանած CraftScript ֆունկցիաները նույնպես հասանելի են `cs`-ով՝

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- երկու արդյունք
```

Դրանք գտնվում են սցենարը սկսելուց առաջ, ուստի անունը գրեք սցենարում՝ `cs.static_tet(` կամ `cs.call('static_tet', …)`։ Աշխատանքի ընթացքում կառուցված անունը հասնում է միայն ներկառուցված ֆունկցիաներին։ `cs.struct({ … })`-ով կառուցված կառուցվածքը CraftScript կառուցվածք է, իսկ դրանց Lua ցանկը (`{ cs.struct(…), … }`) բջիջ է, ինչ գրադարանի կարգավորումները ակնկալում են։ Եթե գրադարանի ֆունկցիայի ներսում ինչ-որ բան սխալ է ընթանում, հաղորդագրությունը նշում է ֆունկցիան և նրա տողը և ցույց է տալիս ձեր տողը, որը այն կանչել է։

## Անջատված

Սցենարները չեն կարող հասնել ֆայլերին, ցանցին կամ էջին․ `io`-ն, `os`-ը (բացի ժամացույցից), `require`-ը, `dofile`-ը, `loadfile`-ը և `debug`-ը հեռացված են։ Տվյալներ բերելու համար օգտագործեք սցենարների աշխատանքային տարածքի **Բացել**-ը և փոփոխականները։ Քայլերի բյուջեն և {{ui:Կանգնեցնել}}-ը աշխատում են ինչպես CraftScript-ում։
