Python-ը [Սցենարների աշխատանքային տարածքի](topic:craftscript) երրորդ լեզուն է։ Ընտրեք **Python**-ը խմբագրիչի վերևի լեզվի տուփում (`.py` ֆայլը բացվում է Python-ով ինքնուրույն)։ Python-ը, Lua-ն և CraftScript-ը կիսում են նույն փոփոխականները և նույն ներկառուցված ֆունկցիաները, ուստի Python սցենարը կարող է օգտագործել CraftScript սցենարի ստեղծածը, և հակառակը։

Այցի ընթացքում առաջին Python գործարկումը բեռնում է Python-ն (CPython 3.14, մոտ 7 ՄԲ) այս կայքից, ինչը տևում է մի քանի վայրկյան։ Python-ը դեռ մաս չէ {{ui:Պահել անցանց}}-ին․ նախ գործարկեք մեկ Python սցենար առցանց։

## Python-ը փակված է

Python սցենարները փակված են CraftScript-ի և Lua սցենարների պես․ նրանք հասնում են դետալին, փոփոխականներին և ներկառուցված ֆունկցիաներին, և ոչ մի այլ բանի։ Յուրաքանչյուր գործարկում նոր Python է իր փակ միջավայրում՝ փոքր ֆայլային ծառով հիշողության մեջ (իր ստանդարտ գրադարանը և `/tmp` թղթապանակը, որը գործարկումից հետո անհետանում է)։ Այն չի կարող հասնել ցանցին, ձեր ֆայլերին կամ էջի մնացած մասին, և՛ բրաուզերում, և՛ հրամանի տողում։ Ուրիշի սցենարը դեռ կարող է շատ ժամանակ կամ հիշողություն սպառել․ {{ui:Կանգնեցնել}}-ը դադարեցնում է այն։

## Հիմունքները

```
A = cs.magic(3)              # յուրաքանչյուր ներկառուցված ֆունկցիա՝ cs.<անուն>
B = A @ A.T                  # @-ը մատրիցային արտադրյալն է, .T-ը՝ տրանսպոնումը
C = A * 2 + 1                # + - * / ** տարր առ տարր են, ինչպես numpy-ում
print(A[0, 1], A[-1, -1])    # 0-ից; բացասականը սկսվում է վերջից
row = A[1]                   # մեկ ինդեքս մատրիցի վրա՝ տող
big = A[A > 4]               # տրամաբանական դիմակը ընտրում է տարրերը
A[0, 0] = -5                 # վերագրում զանգվածի մեջ
V, D = cs.call('eig', 2, A)  # մի քանի արդյունք՝ cs.call(անուն, քանի, …)
```

- 1 × 1 զանգվածը հասնում է որպես սովորական թիվ; մյուս զանգվածները, նոսր մատրիցները, ցանցերը, դաշտերն ու մոդելները **Արժեքներ** են։
- Արժեքն ունի `shape` (տուպլ), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (իր տողերը), ինչպես նաև `float()`, `int()` և `bool()` մեկ տարրի համար։
- Համեմատումները (`<`, `==`, …) տարր առ տարր են, ինչպես numpy-ում․ դրանք տալիս են տրամաբանական Արժեք։
- Թվերի ցուցակները, որ փոխանցվում են ներկառուցված ֆունկցիային, դառնում են զանգվածներ՝ `cs.sum([1, 2, 3])`։ `cs.tensor([[1, 2], [3, 4]])`-ը սարքում է մատրից։
- Բառարանը (dict) դառնում է կառուցվածք, իսկ խառը ցանկը՝ բջիջ, և հակառակը։

Յուրաքանչյուր գլոբալ, որ ձեր սցենարը ստեղծում է (թիվ, Արժեք, բառարան, ցանկ…), հայտնվում է **Փոփոխականներ** ներդիրում գործարկումն ավարտվելուց հետո, նույնիսկ սխալից հետո։ `_`-ով սկսվող անունները, ֆունկցիաները, դասերը և մոդուլները մնում են Python-ում։ `ws.name`-ը կարդում կամ դնում է փոփոխական ուղղակիորեն, իսկ `ws_names()`-ը թվարկում է դրանք։

`print(…)`-ը գրում է կոնսոլ։ `display(…)`-ը (կամ `cs.display`) ցույց է տալիս ցանց, դաշտ կամ գրաֆիկ, ինչպես CraftScript-ում։

## Կանչել վերլուծական գրադարանը

Գրադարանի ֆունկցիաները կանչվում են ինչպես ներկառուցվածները՝ `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`։ Գրեք անունը սցենարում այնպես, ինչպես այն կա. PartCraft-ը գտնում է սցենարի օգտագործած գրադարանի ֆունկցիաները, նախքան այն գործարկելը։

## Դեռ չկա

- numpy, scipy և այլ փաթեթներ․ միայն Python-ի սեփական ստանդարտ գրադարանն է (`math`, `json`, `itertools`, `decimal`, `statistics`…), առանց դրա պատուհանների, տերմինալի և տվյալների բազայի մասերի (`tkinter`, `curses`, `sqlite3`)։
- Սոկետներ և ցանկացած այլ բան, որ դուրս կգա․ Python-ն այստեղ ցանց չունի։
- `time.sleep`-ը անմիջապես վերադառնում է։
- Ծալումը խմբագրիչում, և Python ֆունկցիայի կանչը CraftScript սցենարից։
- Գործարկումը ստուգում է հրահանգների բյուջեն և {{ui:Կանգնեցնել}}-ը յուրաքանչյուր 1000 տողը. մեկ ներկառուցված ֆունկցիայի ներսում երկար հաշվարկն նախ ավարտվում է։
