Վերլուծությունը Սցենարների աշխատանքային տարածքում մի քանի կարճ սցենար է, որոնք փոխանցում են փոփոխականներ միմյանց։ Սկսեք [գրադարանի](topic:craftscript-library) այն ֆունկցիայից, որը մոտ է ձեզ պետքին, պատճենեք և փոխեք այն; կամ կառուցեք վերլուծությունը ստորև ցույց տրված ձևով։

## 1. Ցանց

```
model = part();                  % դետալը, որ մոդելավորում եք, որպես մոդել
m = tetmesh(model, 4);           % քառանիստներ՝ մոտ 4 մմ չափով
show(m)
```

Ստուգեք ցանցը տեսքում, նախքան շարունակելը․ {{key:F}}-ը տեղավորում է այն, իսկ **Ցուցադրված** ցանկի {{ui:աչք}}-ը թաքցնում է դետալը։

## 2. Հավաքել և լուծել

Գրեք տարրերի ցիկլը սցենարում (այն կարդացվում է ինչպես դասագրքում), իսկ ծանր մասերը թողեք ներկառուցված ֆունկցիաներին․ տարրերի մատրիցներ, եռյակներից նոսր հավաքում և նախապայմանավորիչով համակցված գրադիենտների լուծիչ։ Գրադարանի ֆունկցիան, ինչպիսին `static_tet`-ն է (երբ գրադարանն այն ունենա), ամբողջական օրինակ է, որից պետք է պատճենել։

## 3. Ցույց տալ արդյունքը

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % մեկ արժեք յուրաքանչյուր հանգույցի համար
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- Լեգենդի միջակայքը կարող եք մուտքագրել կամ վերադարձնել {{ui:Ավտո}}-ին։
- Սեղմեք ցանցը՝ հանգույցի արժեքները կարդալու համար։
- Գրաֆիկը, որը պահում է նույն `'id'`-ն, թարմացվում է տեղում, ուստի տպեք և գծեք ձեր ցիկլի ներսում՝ զուգամիտությունը տեսնելու համար։

## 4. Ստուգել այն

Համեմատեք այն, ինչ գիտեք․ կոնսոլային ճառագայթի ծայրի շեղումը՝ PL³/3EI-ի հետ, անցքով սալի լարվածության կոնցենտրացիայի գործակիցը՝ իր դասագրքային արժեքի հետ, ռեակցիաները՝ բեռների հետ։ Գրեք ստուգումը որպես առանձին սցենար, որ այն նորից գործարկվի յուրաքանչյուր փոփոխությունից հետո՝

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. Պահել այն

- Յուրաքանչյուր քայլ կարող է լինել իր սեփական սցենարի ներդիրը․ նրանք կիսում են փոփոխականները, ուստի գործարկեք դրանք մեկը մյուսից հետո։
- Սցենարները պահվում են դետալի մեջ։ Նշեք **Պահել փոփոխականները դետալի հետ**-ը **Փոփոխականներ** ներդիրում, որ պահեք նաև արդյունքները (մինչև 32 ՄԲ)։
- {{ui:Պահել}}-ը Սցենար խմբում ներբեռնում է սցենարը՝ կիսվելու համար, {{ui:Բացել}}-ը բերում է մեկը։
