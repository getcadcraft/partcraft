CraftScript-ը մատրիցային լեզու է, որը գրված է այնպես, որ կարդացվի MATLAB-ի պես, ուստի թվային կոդերի մեծ մասը (օրինակ՝ 88 տողանի տոպոլոգիական օպտիմիզացիայի կոդը) աշխատում է փոքր փոփոխություններով։ Այն աշխատում է [Սցենարների աշխատանքային տարածքում](topic:craftscript) և հրամանի տողից։

## Արժեքներ

| Տեսակ | Օրինակ | Նշումներ |
|---|---|---|
| Թիվ, զանգված | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | Յուրաքանչյուր թիվ զանգված է (1×1)։ Զանգվածները պահվում են սյունակ առ սյունակ, մինչև 8 չափողականություն |
| Տրամաբանական | `A > 2`, `true` | Ճշմարիտ և կեղծ արժեքների զանգվածներ; օգտագործելի են որպես ինդեքսներ |
| Տեքստ | `'beam'`, `"beam"` | |
| Նոսր մատրից | `sparse(i, j, v, n, n)` | Կոշտության մատրիցների համար |
| Ցանց, դաշտ, մոդել | `hexGrid(…)`, `part()`, `load('part.stl')` | Այն, ինչ գծում է `show`-ը |
| Կառուցվածք | `s.E = 210e3` | Անվանված դաշտեր |
| Բջիջ | `c = {1, 'two', [3 4]}` | Ցանկ՝ ցանկացած արժեքներից |
| Ֆունկցիայի հղում | `f = @(x) x.^2` | |

## Զանգվածներ և ինդեքսավորում

- Միջակայքեր՝ `1:5`, `0:0.1:1`։ `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`։
- Ինդեքսավորումը սկսվում է 1-ից՝ `A(2, 3)`, `v(end)`, `A(:, 1)` (ամբողջ սյունակ), `A(:)` (ամեն ինչ մեկ սյունակով), `v(v > 0)` (տրամաբանական ինդեքսավորում)։
- Վերջից դուրս վերագրումը մեծացնում է զանգվածը, ինչպես MATLAB-ում՝ `v(10) = 1`։

## Օպերատորներ

- `+ - * / \ ^`-ը մատրիցային գործողություններ են (`A \ b`-ն լուծում է)․ `.* ./ .^`-ը աշխատում են տարր առ տարր։ `'`-ը տրանսպոնում է։
- Համեմատումներ՝ `== ~= < <= > >=`; տրամաբանություն՝ `& | ~` (տարր առ տարր) և `&& ||` (կարճ փակումով)։

## Կառավարման հոսք և ֆունկցիաներ

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

Ֆունկցիաները գրվում են սցենարում՝ իր հրամանների հետո, կամ իր անունն ունեցող առանձին սցենարի ներդիրում՝

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

Անունը փնտրվում է այս հերթականությամբ՝ փոփոխական, այս դետալում այդ անունով սցենար, գրադարանի ֆունկցիա, ներկառուցված ֆունկցիա։

## Արտածում, մեկնաբանություններ, ելք

- Առանց `;`-ի հրամանը արտածում է իր արժեքը․ `;`-ը այն պահում է լռության մեջ։
- `%`-ը սկսում է մեկնաբանություն․ `%{` և `%}` առանձին տողերում մեկնաբանում են դրանց միջև եղած տողերը։
- `disp(x)`, `fprintf('%g\n', x)` և `display(x)` արտածում են կոնսոլ։

## Սխալներ և սահմաններ

- Սխալները պարզ բառերով ասում են, թե ինչն է սխալ, և տալիս են տողը (և ֆունկցիաների կանչերի շղթան)։
- Յուրաքանչյուր գործարկում ունի քայլերի բյուջե (տե՛ս գործարկման ընտրանքները վահանակում)․ անվերջ ցիկլը կանգ է առնում հաղորդագրությամբ, կամ սեղմեք {{ui:Կանգնեցնել}}։
- Զանգվածները պահում են մինչև 134 միլիոն արժեք յուրաքանչյուրը։

## Այլ է, քան MATLAB-ում

- Գրաֆիկների հրամանները ընտրանքները դնում են կանչի մեջ՝ `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`։ `figure`, `hold`, `axis`, `title(…)` և նմանատիպ հրամանները ընդունվում են, բայց ոչինչ չեն անում։
- `input`-ը և `keyboard`-ը չեն աջակցվում․ սցենարը չի կարող կանգ առնել և հարց տալ։
- Տուլբոքսներ չկան․ [վերլուծական գրադարանը](topic:craftscript-library) և ներկառուցված ֆունկցիաներն են, որ կան։
