Գեներատորը սովորական սցենար է ([CraftScript](topic:craftscript), Lua կամ Python), որի սկզբում կան մի քանի մեկնաբանական տող։ PartCraft-ը կարդում է մեկնաբանությունները և կազմում ձևը։ Ձեր սցենարը մուտքերը կարդում է որպես արդեն սահմանված փոփոխականներ։

## Վերնագիրը

Սրանք դրեք մեկնաբանական տողերում (CraftScript-ում՝ `%`, Lua-ում՝ `--`, Python-ում՝ `#`)։

```
% @generator Ջերմափոխանակիչ
% @input mdot: kg/s = 0.2 [0.01 .. 10] "Զանգվածային հոսք"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "Մակերևույթ"
% @input solid: = true
% @input note: = "text"
```

Մուտքը սա է՝ `name: unit = default`, ապա ըստ ցանկության՝ միջակայք `[min .. max]` (թվերը դրա ներսում են պահվում), ընտրանքների ցանկ `{a, b, c}` և պիտակ չակերտների մեջ։ Միավորը միայն ձևի պիտակ է։ **Արժեքը գալիս է այդ միավորով**, ուստի սցենարը, որը ուզում է SI, պետք է փոխարկի այն․ իսկ `to_si(value, 'kg/s', 'kg/s')`-ը ստուգում է նաև, որ միավորը ճիշտ այն է, ինչ դուք եք մտածում։ Անունը բաղկացած է տառերից, թվերից և ընդգծումից․ `body`, `sheet` և `problems`-ը զբաղված են։

## Ինչ թողնում է սցենարը

| Փոփոխական | Ինչ է |
|---|---|
| `body` | **Պարտադիր է։** Մակերևույթային ցանց, սովորաբար `[body, info] = to_body(field, h)`-ից։ Աշխատանքի ավարտին այն շտկվում և ստուգվում է։ |
| `sheet` | Ըստ ցանկության։ Կառուցվածք, որի յուրաքանչյուր դաշտը թիվ կամ տեքստ է, կամ կառուցվածք՝ `value`, `unit`, `ref` և `note`-ով։ Այն դառնում է տվյալների թերթը։ |
| `problems` | Ըստ ցանկության։ `mfg_check(field, 'sls', struct(), h)`-ի `problems` բջիջը կամ ձեր սեփական գրառումները։ Դրանք գնում են ստուգումներին և Խնդիրների ցանկին։ |

## Փոքր ամբողջական օրինակ

```
% Պատով ներսից դատարկ խորանարդ։
% @generator Ներսից դատարկ խորանարդ
% @input side: mm = 12 [4 .. 40] "Կողմ"
% @input wall: mm = 1.5 [0.5 .. 5] "Պատ"
% @input h: mm = 0.5 [0.25 .. 2] "Վոքսելի չափ"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'ցանցի համար');
```

Այն կազմում է փակ տուփ, և ստուգումը դրա փակ ներսը հաշվում է որպես սխալ փոշու գործընթացի համար։ Վոքսելի չափ `h`-ը դարձրեք առավելագույնը այն ամենաբարակ պատի մեկ երրորդը, որը ուզում եք․ մոտ երեք վոքսելից ցածր պատը հուսալի չէ։

## Դաշտեր

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (պտտման մարմին պրոֆիլից), `tpms` (գիրոիդ, Շվարց P և դիամանդ մակերևույթներ, բջջի չափով և պատով, որոնք կարող են փոխվել ամբողջ մասի երկայնքով), `lattice` և `lattice_beams`, `along` (կլոր ալիք ուղու երկայնքով), բուլյան գործողությունները `field_union`, `field_intersect`, `field_subtract`, հարթեցնող `field_blend`, և `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`։ `sample(f, points)`-ը տալիս է կետերի ստորագրված հեռավորությունը (բացասական՝ ներսում), `field_voxel`-ը տալիս է վոքսելներ լուծիչների համար։ [Դաշտերը](topic:fields) բացատրում է, թե դրանք ինչ են։

Սահմանափակումներ, որոնք արժե իմանալ․ պատը, որը մոտ չորրորդ բջջի չափից հաստ է, փակում է ալիքները․ երեք վոքսելից մոտ բարակ մանրամասնը կարող է սեղմվել․ `along`-ը միացնում է կլոր կոներ, ուստի արագ փոփոխվող շառավիղը թողնում է ուռուցիկություն (պրոֆիլի համար օգտագործեք `field_revolve`)։

## Բացեք ձեր սցենարը որպես գեներատոր

{{ui:Engineer}} աշխատանքային տարածքում սեղմեք {{ui:Open}} և ընտրեք ֆայլը։ @generator կամ @input տող չունեցող սցենարը մերժվում է․ չկա, ինչ սահմանել։ Գեներատորը պահվում է այս դիտարկիչում (մինչև 20), և {{ui:Remove}}-ը հեռացնում է այն։ Դրանից սկսված մարմինը պարունակում է սցենարի պատճենը, ուստի մասը նրանից կախված չէ։

Ֆայլը կարող է պարունակել նաև մի քանի գեներատոր՝ JSON փաթեթի տեսքով․ `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`։
