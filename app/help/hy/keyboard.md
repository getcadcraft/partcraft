Ստեղները չեն աշխատում, երբ տեքստ եք մուտքագրում վահանակի դաշտում, բացի {{key:Mod+S}} և {{key:Mod+O}} ստեղներից, որոնք միշտ աշխատում են։ Տառային ստեղները աշխատում են առանց փոփոխիչի։

Ընդհանուր նշումներ բրաուզերի ստեղների և այն ստեղնաշարերի մասին, որոնք չունեն ֆունկցիոնալ ստեղներ՝ [Ստեղներ, մկնիկներ և թրեքփեդներ](common:keys)։

## Ամենուր

| Ստեղն | Գործողություն |
|---|---|
| {{key:Mod+S}} | Պահել մասը (հավաքվածքում՝ հավաքվածքը)։ Նախ փակում է բաց էսքիզը |
| {{key:Mod+O}} | Բացել մասի կամ հավաքվածքի ֆայլ (հարցնում է, եթե կան չպահված փոփոխություններ) |
| {{key:Mod+Z}} | Հետարկել |
| {{key:Mod+Y}} կամ {{key:Mod+Shift+Z}} | Կրկնել |
| {{key:F1}} | Բացել կամ փակել այս օգնությունը (նաև ծրագրի գործիքագոտու {{ui:Օգնություն}} կոճակը)։ {{key:Esc}}-ը նույնպես փակում է այն։ Շատ նոթբուքերի և Mac ստեղնաշարերի վրա պահեք Fn |
| {{key:Ctrl+Shift+F}} | Էկրանի ռեժիմ՝ սովորական, ամբողջ էկրան, ամբողջ էկրան՝ թաքցված գոտիներով։ Macում նույնպես՝ Control, ոչ ⌘ |
| {{key:Esc}} | Դուրս գալ ամբողջ էկրանից (երբ ամբողջ էկրանին է) |
| {{key:Mod+,}} | Կարգավորումներ, ներառյալ PartCraft ներդիրը (տե՛ս [PartCraft-ի կարգավորումներ](topic:settings)) |

Վահանակի թվային դաշտում {{key:Mod+Z}}-ը բրաուզերի սեփական տեքստի հետարկումն է։ Էսքիզի չափի վրայի թվային դաշտում այն հետարկում է PartCraft-ում։

## Պատճենում, տեղադրում և կրկնօրինակում

Դրանք գործում են այն վրա, ինչի հետ աշխատում եք՝ բաց էսքիզի ընտրված երկրաչափության, պատմության մեջ ընտրված գործողության կամ հավաքվածքում ընտրված մասի վրա։ Մանրամասները՝ [Պատճենում, տեղադրում և կրկնօրինակում](topic:copy-paste)։

| Ստեղն | Գործողություն |
|---|---|
| {{key:Mod+C}} | Պատճենել ընտրությունը |
| {{key:Mod+X}} | Կտրել՝ պատճենել, ապա ջնջել |
| {{key:Mod+V}} | Տեղադրել։ Էսքիզում պատճենը հետևում է նշիչին՝ սեղմեք, թե որտեղ տեղադրել |
| {{key:Mod+Shift+V}} | Տեղադրել նույն տեղում՝ նույն կոորդինատներով (հավաքվածքում՝ նույն տեղում) |
| {{key:Mod+D}} | Կրկնօրինակել՝ պատճենել և տեղադրել մեկ քայլով՝ առանց փոխելու սեղմատախտակը |
| {{key:Mod+A}} | Ընտրել բոլորը (էսքիզում) |
| {{key:Esc}} | Չընտրել ոչինչ (և չեղարկել նշիչին հետևող տեղադրումը) |

Թվային դաշտում այս ստեղները պատճենում և տեղադրում են տեքստ, ինչպես միշտ։ Վահանակի ընտրված տեքստը պատճենվում է բրաուզերի կողմից։

## Մասի վրա (էսքիզ բաց չէ)

| Ստեղն | Գործողություն |
|---|---|
| {{key:S}} | Էսքիզ ընտրված հարթության կամ հարթ նիստի վրա. եթե ոչինչ ընտրված չէ, ընտրեք տեղը սեղմելով |
| {{key:F}} | Տեղավորել մասը տեսքում |
| {{key:M}} | Չափել՝ բոլոր աշխատանքային տարածքներում և հավաքվածքում. {{key:Esc}}-ը մաքրում է ընտրությունները, {{key:Esc}}-ը կրկին փակում է այն (տե՛ս [Չափել հեռավորություններ, անկյուններ և զանգված](topic:measure)) |
| {{key:X}} | Կտրվածքի տեսքը միացնել կամ անջատել, բոլոր աշխատանքային տարածքներում և հավաքվածքում. {{key:Esc}}-ը փակում է այն (տե՛ս [Նայել ներս կտրվածքի տեսքով](topic:section-view)) |
| {{key:Delete}} | Ջնջել ընտրված գործողությունը (հարցնում է, եթե ուրիշներն են օգտագործում այն) |
| {{key:0}} … {{key:9}}, {{key:.}} | Երբ գործողությունն ընտրված է՝ մուտքագրեք դրա հիմնական թիվը (Արտամղման խորությունը, Անցքի տրամագիծը, օրինակի քանակը, եզրամշակման շառավիղը…), ապա {{key:Enter}}։ {{key:Esc}}-ը պահում է հին արժեքը |
| {{key:Backspace}} | Ջնջել ընտրված գործողությունը, եթե մեկը ընտրված է |
| {{key:Esc}} | Դադարեցնել էսքիզի հարթության ընտրումը կամ մաքրել ընտրությունը (ներառյալ {{key:Shift}}-ով ընտրված եզրերը կամ նիստերը) |

## 3D տեսքում

Նախ սեղմեք տեսքի վրա, որպեսզի ստեղնաշարի ֆոկուսը լինի դրա վրա։

| Ստեղն | Գործողություն |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | Պտտել տեսքը 15 աստիճանով |
| {{key:Shift+Left}} և մյուս սլաքները | Տեղաշարժ |
| {{key:Plus}} կամ {{key:=}} | Մեծացնել մասշտաբը |
| {{key:Minus}} | Փոքրացնել մասշտաբը |

| Մկնիկ | Գործողություն |
|---|---|
| Քաշել ձախ կոճակով | Պտտել (ուղեծրով) տեսքը |
| Քաշել աջ կամ միջին կոճակով | Տեղաշարժ |
| {{key:Shift}}, {{key:Ctrl}} կամ ⌘ պահած՝ ձախ կոճակով քաշելիս | Տեղաշարժ |
| Պտտել անիվը | Մասշտաբ նշիչի տեղում (ձեզնից հեռու պտտելը մեծացնում է) |
| Երկու մատով սահեցում թրեքփեդում | Պտտել տեսքը; {{key:Shift}}-ով՝ տեղաշարժ։ Մատների մերձեցումը՝ մասշտաբ։ Սահմանվում է [PartCraft-ի կարգավորումներում](topic:settings) **Սքրոլինգ**-ով |

[PartCraft-ի կարգավորումներում](topic:settings) **Տեսքի պտույտ՝ միջին կոճակ**-ով միջին կոճակը պտտում է տեսքը, {{key:Shift}}-ով միջին կոճակը կամ աջ կոճակը տեղաշարժում են, իսկ ձախ կոճակը միայն ընտրում է։
| Սեղմել | Ընտրել նիստ (այն ամբողջությամբ լուսավորվում է), եզր կամ հարթություն |
| {{key:Shift}}+սեղմում եզրի կամ նիստի վրա | Հավաքել մի քանի եզր կամ նիստ |
| Սեղմել դատարկ տարածքում | Մաքրել ընտրությունը |

## Եզրեր կամ նիստեր ընտրելիս՝ եզրամշակման, ֆասկի կամ թաղանթի համար

| Ստեղն կամ մկնիկ | Գործողություն |
|---|---|
| Սեղմել եզրի կամ նիստի վրա | Ավելացնել այն, կամ հանել, եթե արդեն կա |
| {{key:Esc}} կամ {{key:Enter}} | Ավարտել ընտրությունը (նույնն է, ինչ {{ui:Ավարտել}}) |
| {{key:F}} | Տեղավորել |
| Սլաք ստեղները, տեսքը ֆոկուսում | Պտտել; {{key:Shift}}-ով՝ տեղաշարժ |

## Դյուրանցումներ, որոնք կարող է վերցնել բրաուզերը

- {{key:Mod+Y}}-ը Safari-ում կարող է բացել պատմությունը. կրկնելու համար օգտագործեք {{key:Mod+Shift+Z}}։
- {{key:Mod+D}}-ն բրաուզերի էջանշանի ստեղնն է. PartCraft-ը այն վերցնում է, երբ հավելվածը ֆոկուսում է, և թողնում է այն անփոփոխ, երբ տառ եք մուտքագրում դաշտում։
- {{key:F11}}-ը և {{key:Mod+Plus}} / {{key:Mod+Minus}}-ը բրաուզերի ամբողջ էկրանի և էջի մասշտաբի ստեղներն են, ոչ թե PartCraft-ինը. ամբողջ էկրանի համար օգտագործեք {{key:Ctrl+Shift+F}}, իսկ մոդելի համար՝ անիվը։
- Շատ նոթբուքերի և Mac-երի ֆունկցիոնալ ստեղներին պետք է Fn. օգնության համար սեղմեք Fn+{{key:F1}}, կամ օգտագործեք {{ui:Օգնություն}} կոճակը։

Հպման և թրեքփեդի ժեստեր՝ [Թրեքփեդ, հպում և փոքր էկրաններ](topic:trackpad-and-touch)։

## Որտեղ է տեղափոխումը

Տեղափոխումը գտնվում է Գործողությունների խմբի {{ui:Ավելին}} ցանկում՝ որպես {{ui:Տեղափոխել մարմինը}}, {{ui:Տեղաշարժ}} արկղում, որտեղ մուտքագրում եք ΔX, ΔY և ΔZ, և որպես {{ui:Քաշել՝ տեղափոխելու համար}} սլաքներ մասի վրա։
