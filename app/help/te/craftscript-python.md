Python అనేది [స్క్రిప్ట్ వర్క్‌స్పేస్](topic:craftscript) యొక్క మూడవ భాష. ఎడిటర్ పైన ఉన్న భాష పెట్టెలో **Python** ను ఎంచుకోండి (`.py` ఫైల్ స్వయంగా Python లో తెరుచుకుంటుంది). Python, Lua మరియు CraftScript ఒకే వేరియబుల్స్ మరియు ఒకే అంతర్నిర్మిత ఫంక్షన్లను పంచుకుంటాయి, కాబట్టి Python స్క్రిప్ట్ CraftScript స్క్రిప్ట్ తయారుచేసిన దాన్ని ఉపయోగించగలదు, మరియు వైస్ వెర్సా.

ఒక సందర్శనలో మొదటి Python రన్ ఈ సైట్ నుండి Python ను స్వయంగా లోడ్ చేస్తుంది (CPython 3.14, సుమారు 7 MB), దీనికి కొన్ని సెకన్లు పడుతుంది. Python ఇంకా {{ui:ఆఫ్‌లైన్ కోసం సేవ్ చేయి}} లో భాగం కాదు: ముందుగా ఆన్‌లైన్‌లో ఒక Python స్క్రిప్ట్ నడపండి.

## Python సీల్ చేయబడింది

Python స్క్రిప్ట్‌లు CraftScript మరియు Lua స్క్రిప్ట్‌ల లాగా సీల్ చేయబడ్డాయి: అవి భాగం, వేరియబుల్స్ మరియు అంతర్నిర్మిత ఫంక్షన్లను చేరతాయి, మరేమీ కాదు. ప్రతి రన్ దాని స్వంత శాండ్‌బాక్స్‌లో, మెమరీలో చిన్న ఫైల్ ట్రీతో (దాని స్టాండర్డ్ లైబ్రరీ మరియు రన్ తర్వాత పోయే `/tmp` ఫోల్డర్) కొత్త Python. ఇది బ్రౌజర్‌లో మరియు కమాండ్ లైన్‌లో ఒకేలా, నెట్‌వర్క్, మీ ఫైళ్లు లేదా పేజీలోని మిగిలిన భాగాన్ని చేరలేదు. వేరొకరి స్క్రిప్ట్ ఇప్పటికీ చాలా సమయం లేదా మెమరీ వాడగలదు: {{ui:ఆపు}} దాన్ని ముగిస్తుంది.

## ముఖ్యాంశాలు

```
A = cs.magic(3)              # ప్రతి అంతర్నిర్మిత ఫంక్షన్ cs.<name>
B = A @ A.T                  # @ మ్యాట్రిక్స్ గుణకారం, .T ట్రాన్స్‌పోజ్
C = A * 2 + 1                # + - * / ** మూలకం వారీగా, numpy లాగా
print(A[0, 1], A[-1, -1])    # 0-ఆధారితం; ప్రతికూలం చివర నుండి లెక్కిస్తుంది
row = A[1]                   # మ్యాట్రిక్స్‌పై ఒక ఇండెక్స్: ఒక వరుస
big = A[A > 4]               # లాజికల్ మాస్క్ మూలకాలను ఎంచుకుంటుంది
A[0, 0] = -5                 # అర్రేలోకి విలువ ఇవ్వడం
V, D = cs.call('eig', 2, A)  # అనేక ఫలితాలు: cs.call(name, ఎన్ని, …)
```

- 1 × 1 అర్రే సాధారణ సంఖ్యగా వస్తుంది; ఇతర అర్రేలు, స్పార్స్ మ్యాట్రిక్స్‌లు, మెష్‌లు, ఫీల్డ్‌లు మరియు మోడల్‌లు **విలువలు**.
- ఒక విలువకు `shape` (ట్యూపుల్), `T`, `type`, `numel()`, `copy()`, `tolist()`, `len()` (దాని వరుసలు), మరియు ఒకే మూలకం కోసం `float()`, `int()` మరియు `bool()` ఉంటాయి.
- పోలికలు (`<`, `==`, …) numpy లో లాగా మూలకం వారీగా ఉంటాయి: అవి లాజికల్ విలువను ఇస్తాయి.
- అంతర్నిర్మిత ఫంక్షన్‌కు ఇచ్చిన సంఖ్యల జాబితాలు అర్రేలుగా మారతాయి: `cs.sum([1, 2, 3])`. `cs.tensor([[1, 2], [3, 4]])` ఒక మ్యాట్రిక్స్‌ను తయారు చేస్తుంది.
- ఒక dict స్ట్రక్ట్‌గా మారుతుంది, మరియు కలిపిన వస్తువుల జాబితా సెల్‌గా మారుతుంది, మరియు తిరిగి కూడా.

మీ స్క్రిప్ట్ చేసే ప్రతి గ్లోబల్ (ఒక సంఖ్య, ఒక విలువ, ఒక dict, ఒక జాబితా…) రన్ ముగిసినప్పుడు, లోపం తర్వాత కూడా, **వేరియబుల్స్** ట్యాబ్‌లో చేరుతుంది. `_` తో మొదలయ్యే పేర్లు, ఫంక్షన్లు, క్లాసులు మరియు మాడ్యూల్స్ Python లోనే ఉంటాయి. `ws.name` ఒక వేరియబుల్‌ను నేరుగా చదువుతుంది లేదా సెట్ చేస్తుంది, మరియు `ws_names()` వాటిని జాబితా చేస్తుంది.

`print(…)` కన్సోల్‌లో రాస్తుంది. `display(…)` (లేదా `cs.display`) CraftScript లో లాగా ఒక మెష్, ఫీల్డ్ లేదా ప్లాట్‌ను చూపుతుంది.

## విశ్లేషణ లైబ్రరీని కాల్ చేయండి

లైబ్రరీ ఫంక్షన్లు అంతర్నిర్మిత వాటిలాగానే కాల్ చేయబడతాయి: `cs.box_mesh(20, 10, 10, 5, 'hex')`, `cs.call('modal_tet', 2, …)`. పేరును స్క్రిప్ట్‌లో ఉన్నట్లే రాయండి: స్క్రిప్ట్ నడవడానికి ముందే PartCraft ఒక స్క్రిప్ట్ ఉపయోగించే లైబ్రరీ ఫంక్షన్లను కనుగొంటుంది.

## ఇంకా లేనివి

- numpy, scipy మరియు ఇతర ప్యాకేజీలు: Python యొక్క సొంత స్టాండర్డ్ లైబ్రరీ మాత్రమే ఇక్కడ ఉంది (`math`, `json`, `itertools`, `decimal`, `statistics`…), దాని విండో, టెర్మినల్ మరియు డేటాబేస్ భాగాలు (`tkinter`, `curses`, `sqlite3`) లేకుండా.
- సాకెట్లు మరియు బయటకు చేరే ఏదైనా: ఇక్కడ Python కు నెట్‌వర్క్ లేదు.
- `time.sleep` వెంటనే తిరిగి వస్తుంది.
- ఎడిటర్‌లో ఫోల్డింగ్, మరియు CraftScript స్క్రిప్ట్ నుండి Python ఫంక్షన్‌ను కాల్ చేయడం.
- ఒక రన్ ప్రతి 1000 లైన్లకు ఇన్‌స్ట్రక్షన్ బడ్జెట్ మరియు ఆపును తనిఖీ చేస్తుంది; ఒక అంతర్నిర్మిత ఫంక్షన్ లోపల దీర్ఘ లెక్క ముందుగా ముగుస్తుంది.
