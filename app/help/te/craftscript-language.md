CraftScript అనేది MATLAB లాగా చదవగలిగేలా రాయబడిన మ్యాట్రిక్స్ భాష, కాబట్టి చాలా క్లాసిక్ సంఖ్యాత్మక కోడ్‌లు (ఉదాహరణకు 88-లైన్ టోపాలజీ ఆప్టిమైజేషన్ కోడ్) చిన్న మార్పులతోనే నడుస్తాయి. ఇది [స్క్రిప్ట్ వర్క్‌స్పేస్](topic:craftscript) లో మరియు కమాండ్ లైన్ నుండి నడుస్తుంది.

## విలువలు

| రకం | ఉదాహరణ | గమనికలు |
|---|---|---|
| సంఖ్య, అర్రే | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ప్రతి సంఖ్య ఒక అర్రే (1×1 అర్రే). అర్రేలు కాలమ్ వారీగా, 8 డైమెన్షన్ల వరకు నిల్వ చేయబడతాయి |
| లాజికల్ | `A > 2`, `true` | నిజం/తప్పు అర్రేలు; ఇండెక్స్‌లుగా ఉపయోగించవచ్చు |
| పాఠ్యం | `'beam'`, `"beam"` | |
| స్పార్స్ మ్యాట్రిక్స్ | `sparse(i, j, v, n, n)` | స్టిఫ్‌నెస్ మ్యాట్రిక్స్‌ల కోసం |
| మెష్, ఫీల్డ్, మోడల్ | `hexGrid(…)`, `part()`, `load('part.stl')` | `show` గీసేది |
| స్ట్రక్ట్ | `s.E = 210e3` | పేరున్న ఫీల్డ్‌లు |
| సెల్ | `c = {1, 'two', [3 4]}` | ఏ విలువల జాబితా అయినా |
| ఫంక్షన్ హ్యాండిల్ | `f = @(x) x.^2` | |

## అర్రేలు మరియు ఇండెక్సింగ్

- పరిధులు: `1:5`, `0:0.1:1`. `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`.
- ఇండెక్సింగ్ 1 నుండి మొదలవుతుంది: `A(2, 3)`, `v(end)`, `A(:, 1)` (మొత్తం కాలమ్), `A(:)` (అన్నీ ఒకే కాలమ్‌గా), `v(v > 0)` (లాజికల్ ఇండెక్సింగ్).
- MATLAB లాగానే, చివరి దాటి విలువ ఇస్తే అర్రే పెరుగుతుంది: `v(10) = 1`.

## ఆపరేటర్లు

- `+ - * / \ ^` మ్యాట్రిక్స్ ఆపరేషన్లు (`A \ b` పరిష్కరిస్తుంది); `.* ./ .^` మూలకం వారీగా పనిచేస్తాయి. `'` ట్రాన్స్‌పోజ్ చేస్తుంది.
- పోలికలు `== ~= < <= > >=`; తర్కం `& | ~` (మూలకం వారీగా) మరియు `&& ||` (షార్ట్-సర్క్యూట్).

## నియంత్రణ ప్రవాహం మరియు ఫంక్షన్లు

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

ఫంక్షన్లు స్క్రిప్ట్‌లో దాని ఆదేశాల తర్వాత, లేదా ఫంక్షన్ పేరుతో ఉన్న వేరే స్క్రిప్ట్ ట్యాబ్‌లో ఉంటాయి:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

ఒక పేరును ఈ క్రమంలో వెతుకుతారు: వేరియబుల్, ఈ భాగంలో ఆ పేరుతో ఉన్న స్క్రిప్ట్, లైబ్రరీ ఫంక్షన్, అంతర్నిర్మిత ఫంక్షన్.

## Echo, వ్యాఖ్యలు, అవుట్‌పుట్

- `;` లేని స్టేట్‌మెంట్ దాని విలువను ప్రింట్ చేస్తుంది; `;` దాన్ని నిశ్శబ్దంగా ఉంచుతుంది.
- `%` వ్యాఖ్యను మొదలుపెడుతుంది; వేర్వేరు లైన్లలో ఉన్న `%{` మరియు `%}` వాటి మధ్య లైన్లను వ్యాఖ్యగా మారుస్తాయి.
- `disp(x)`, `fprintf('%g\n', x)` మరియు `display(x)` కన్సోల్‌లో ప్రింట్ చేస్తాయి.

## లోపాలు మరియు పరిమితులు

- లోపాలు ఏమి తప్పు జరిగిందో సాధారణ పదాలలో చెబుతాయి, మరియు లైన్ (మరియు ఫంక్షన్ కాల్‌ల గొలుసు) ఇస్తాయి.
- ప్రతి రన్‌కు స్టెప్ బడ్జెట్ ఉంటుంది (ప్యానెల్‌లోని రన్ ఎంపికలు); అంతులేని లూప్ ఒక సందేశంతో ఆగుతుంది, లేదా ఆపు నొక్కండి.
- ప్రతి అర్రేలో 134 మిలియన్ల విలువల వరకు ఉంటాయి.

## MATLAB లాగా కాదు

- ప్లాట్ ఆదేశాలు తమ ఎంపికలను కాల్‌లోనే ఉంచుతాయి: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`. `figure`, `hold`, `axis`, `title(…)` మరియు ఇలాంటివి ఆమోదించబడతాయి కానీ ఏమీ చేయవు.
- `input` మరియు `keyboard` మద్దతు ఇవ్వబడవు: స్క్రిప్ట్ ప్రశ్న అడగడానికి ఆగలేదు.
- టూల్‌బాక్స్‌లు లేవు; ఉన్నవి [విశ్లేషణ లైబ్రరీ](topic:craftscript-library) మరియు అంతర్నిర్మిత ఫంక్షన్లు మాత్రమే.
