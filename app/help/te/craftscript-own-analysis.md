స్క్రిప్ట్ వర్క్‌స్పేస్‌లో విశ్లేషణ అంటే ఒకదానికొకటి వేరియబుల్స్ అందించే కొన్ని చిన్న స్క్రిప్ట్‌లు. మీకు దగ్గరగా ఉన్న [లైబ్రరీ](topic:craftscript-library) ఫంక్షన్‌తో మొదలుపెట్టి, కాపీ చేసి మార్చండి; లేదా దిగువన చూపినట్లు ఒక్కొక్కటిగా నిర్మించండి.

## 1. ఒక మెష్

```
model = part();                  % మీరు మోడల్ చేస్తున్న భాగం, ఒక మోడల్‌గా
m = tetmesh(model, 4);           % సుమారు 4 mm అంతటా ఉన్న టెట్రాహెడ్రా
show(m)
```

ముందుకు వెళ్లే ముందు వ్యూలో మెష్‌ను తనిఖీ చేయండి: {{key:F}} దాన్ని సరిపెడుతుంది, **చూపబడినవి** లోని {{ui:కన్ను}} భాగాన్ని దాస్తుంది.

## 2. అసెంబుల్ చేసి పరిష్కరించండి

ఎలిమెంట్ లూప్‌ను స్క్రిప్ట్‌లో రాయండి (అది పాఠ్యపుస్తకం లాగా చదవబడుతుంది), మరియు బరువైన భాగాలను అంతర్నిర్మిత ఫంక్షన్లకు వదిలేయండి: ఎలిమెంట్ మ్యాట్రిక్స్‌లు, ట్రిపుల్స్ నుండి స్పార్స్ అసెంబ్లీ, మరియు ప్రీకండిషనర్‌తో కంజుగేట్ గ్రేడియంట్ సాల్వర్. `static_tet` వంటి లైబ్రరీ ఫంక్షన్ (లైబ్రరీలో ఉన్నప్పుడు) కాపీ చేయడానికి పూర్తి ఉదాహరణ.

## 3. ఫలితాన్ని చూపండి

```
f = field(m, vm, 'node', 'von Mises', 'MPa');  % ప్రతి నోడ్‌కు ఒక విలువ
show(f, 'deform', u, 'scale', 100)
plot(residuals, 'title', 'Solver residual', 'id', 'conv')
```

- లెజెండ్ పరిధిని టైప్ చేయవచ్చు లేదా {{ui:ఆటో}} కు తిరిగి సెట్ చేయవచ్చు.
- నోడ్ వద్ద విలువలు చదవడానికి మెష్‌పై క్లిక్ చేయండి.
- అదే `'id'` ఉంచే ప్లాట్ అక్కడే నవీకరించబడుతుంది, కాబట్టి అది కన్వర్జ్ అవుతుందో చూడడానికి మీ లూప్ లోపల ప్రింట్ మరియు ప్లాట్ చేయండి.

## 4. తనిఖీ చేయండి

మీకు తెలిసిన దానితో పోల్చండి: కాంటిలివర్ కొన విక్షేపం PL³/3EI తో, రంధ్రం ఉన్న ప్లేట్ దాని ఒత్తిడి కేంద్రీకరణ కారకంతో, ప్రతిచర్యలు లోడ్లతో. ప్రతి మార్పు తర్వాత అది మళ్లీ నడిచేలా తనిఖీని దాని స్వంత స్క్రిప్ట్‌గా రాయండి:

```
tip = max(abs(u(:)));
expected = P * L^3 / (3 * E * I);
fprintf('tip %g mm, beam theory %g mm (%.1f %%)\n', tip, expected, 100 * (tip / expected - 1))
```

## 5. దాన్ని ఉంచండి

- ప్రతి దశ దాని స్వంత స్క్రిప్ట్ ట్యాబ్ కావచ్చు: అవి వేరియబుల్స్ పంచుకుంటాయి, కాబట్టి వాటిని ఒకదాని తర్వాత ఒకటి నడపండి.
- స్క్రిప్ట్‌లు భాగంలో సేవ్ చేయబడతాయి. ఫలితాలను కూడా ఉంచడానికి **వేరియబుల్స్** ట్యాబ్‌లో **భాగంతో పాటు వేరియబుల్స్ సేవ్ చేయి** ను టిక్ చేయండి (32 MB వరకు).
- స్క్రిప్ట్ గ్రూప్‌లోని {{ui:సేవ్ చేయి}} ఒక స్క్రిప్ట్‌ను పంచుకోవడానికి డౌన్‌లోడ్ చేస్తుంది; {{ui:తెరువు}} ఒకదాన్ని తీసుకువస్తుంది.
