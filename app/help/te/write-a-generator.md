జనరేటర్ అనేది పైభాగంలో కొన్ని వ్యాఖ్య పంక్తులు ఉన్న ఒక సాధారణ స్క్రిప్ట్ ([CraftScript](topic:craftscript), Lua లేదా Python). PartCraft ఆ వ్యాఖ్యలను చదివి ఫారమ్‌ను తయారు చేస్తుంది; మీ స్క్రిప్ట్ ఇన్‌పుట్‌లను ఇప్పటికే సెట్ చేసిన వేరియబుల్స్‌గా చదువుతుంది.

## హెడర్

వీటిని వ్యాఖ్య పంక్తులలో ఉంచండి (CraftScript లో `%`, Lua లో `--`, Python లో `#`):

```
% @generator Heat exchanger
% @input mdot: kg/s = 0.2 [0.01 .. 10] "ద్రవ్య ప్రవాహం"
% @input kind: = gyroid {gyroid, schwarzp, diamond} "ఉపరితలం"
% @input solid: = true
% @input note: = "text"
```

ఒక ఇన్‌పుట్ `name: unit = default` రూపంలో ఉంటుంది, తర్వాత ఐచ్ఛికంగా పరిధి `[min .. max]` (సంఖ్యలు దాని లోపల ఉంటాయి), ఎంపికల జాబితా `{a, b, c}` మరియు కోట్‌ల మధ్య లేబుల్ ఉంటాయి. unit అనేది ఫారమ్ కోసం ఒక లేబుల్ మాత్రమే: **విలువ ఆ unit లోనే వస్తుంది**, కాబట్టి SI కావాల్సిన స్క్రిప్ట్ దాన్ని మార్చాలి. `to_si(value, 'kg/s', 'kg/s')` కూడా unit మీరు అనుకున్నదే అర్థమిస్తుందో లేదో తనిఖీ చేస్తుంది. పేరు అంటే అక్షరాలు, అంకెలు మరియు అండర్‌స్కోర్; `body`, `sheet` మరియు `problems` ఇప్పటికే ఉపయోగంలో ఉన్నాయి.

## స్క్రిప్ట్ ఏమి వదిలి వెళ్తుంది

| వేరియబుల్ | ఏమిటి |
|---|---|
| `body` | **తప్పనిసరి.** ఒక సర్ఫేస్ మెష్, సాధారణంగా `[body, info] = to_body(field, h)` నుండి. రన్ ముగిసినప్పుడు అది సరిచేయబడి తనిఖీ చేయబడుతుంది. |
| `sheet` | ఐచ్ఛికం. ప్రతి ఫీల్డ్ ఒక సంఖ్య లేదా టెక్స్ట్, లేదా `value`, `unit`, `ref` మరియు `note` కలిగిన స్ట్రక్ట్. ఇది డేటా షీట్ అవుతుంది. |
| `problems` | ఐచ్ఛికం. `mfg_check(field, 'sls', struct(), h)` నుండి వచ్చే `problems` సెల్, లేదా మీ స్వంత ఎంట్రీలు. అవి తనిఖీలకు మరియు సమస్యల జాబితాకు వెళ్తాయి. |

## ఒక చిన్న పూర్తి ఉదాహరణ

```
% గోడతో కూడిన బోలు క్యూబ్.
% @generator Hollow cube
% @input side: mm = 12 [4 .. 40] "భుజం"
% @input wall: mm = 1.5 [0.5 .. 5] "గోడ"
% @input h: mm = 0.5 [0.25 .. 2] "వోక్సెల్ పరిమాణం"
f = field_subtract(field_box([0 0 0], [side/2 side/2 side/2]), ...
                   field_box([0 0 0], [side/2-wall side/2-wall side/2-wall]));
fb = field_bake(f, h);
[body, info] = to_body(fb, h);
chk = mfg_check(fb, 'sls', struct(), h);
problems = chk.problems;
sheet = struct();
sheet.volume = struct('value', info.volume, 'unit', 'mm3', 'ref', 'మెష్ యొక్క');
```

ఇది మూసివున్న పెట్టెను తయారు చేస్తుంది, మరియు తనిఖీ దాని మూసివున్న లోపలిని పౌడర్ ప్రక్రియకు లోపంగా నివేదిస్తుంది. వోక్సెల్ పరిమాణం `h` ను మీరు కోరుకునే అత్యంత సన్నని గోడలో మూడో వంతు కంటే ఎక్కువ కాకుండా ఉంచండి: సుమారు మూడు వోక్సెల్స్ కంటే తక్కువ ఉంటే గోడ నమ్మదగినది కాదు.

## ఫీల్డ్‌లు

`field_sphere`, `field_box`, `field_capsule`, `field_cylinder`, `field_torus`, `field_revolve` (ఒక ప్రొఫైల్ నుండి భ్రమణ ఘనం), `tpms` (గైరాయిడ్, Schwarz P మరియు డైమండ్ సర్ఫేస్‌లు, సెల్ పరిమాణం మరియు గోడతో; భాగం అంతటా మారగలవు), `lattice` మరియు `lattice_beams`, `along` (మార్గం వెంట ఒక గుండ్రని ఛానల్), బూలియన్లు `field_union`, `field_intersect`, `field_subtract`, స్మూత్ `field_blend`, మరియు `field_offset`, `field_shell`, `field_move`, `field_rotate`, `field_scale`. `sample(f, points)` పాయింట్ల వద్ద సంతకం చేయబడిన దూరాన్ని ఇస్తుంది (లోపల ప్రతికూలం), `field_voxel` సాల్వర్‌ల కోసం వోక్సెల్‌లను ఇస్తుంది. [Fields](topic:fields) అవి ఏమిటో వివరిస్తుంది.

తెలుసుకోవలసిన పరిమితులు: సెల్ పరిమాణంలో సుమారు నాలుగో వంతు కంటే మందమైన షీట్ గోడ ఛానెల్‌లను మూసివేస్తుంది; మూడు వోక్సెల్స్ కంటే సన్నని ఫీచర్ పించ్ కావచ్చు; `along` గుండ్రని కోన్‌లను కలుపుతుంది, కాబట్టి వ్యాసార్థం వేగంగా మారితే ఉబ్బు ఏర్పడుతుంది (ప్రొఫైల్ కోసం `field_revolve` ఉపయోగించండి).

## స్క్రిప్ట్‌ను జనరేటర్‌గా తెరవండి

{{ui:Engineer}} వర్క్‌స్పేస్‌లో {{ui:Open}} పై క్లిక్ చేసి ఫైల్‌ను ఎంచుకోండి. `@generator` లేదా `@input` లైన్ లేని స్క్రిప్ట్ తిరస్కరించబడుతుంది, ఎందుకంటే సెట్ చేయడానికి ఏమీ ఉండదు. జనరేటర్ ఈ బ్రౌజర్‌లో ఉంచబడుతుంది (20 వరకు), మరియు {{ui:Remove}} దాన్ని తొలగిస్తుంది. దాని నుండి ప్రారంభించిన బాడీలో స్క్రిప్ట్ కాపీ ఉంటుంది, కాబట్టి పార్ట్ దానిపై ఆధారపడదు.

ఒక ఫైల్‌లో అనేక జనరేటర్‌లు కూడా ఉండవచ్చు: JSON బండిల్ `{"format": "cadcraft-generators", "version": 1, "generators": [{"title": "…", "text": "…"}]}`.
