Näppäimet eivät tee mitään, kun kirjoitetaan ruutuun paneelissa, paitsi {{key:Mod+S}} ja {{key:Mod+O}}, jotka toimivat aina. Kirjainnäppäimet toimivat ilman muokkausnäppäintä.

Yleisiä huomautuksia näppäimistä selaimessa ja näppäimistöillä, joissa ei ole toimintonäppäimiä: [Näppäimet, hiiret ja kosketuslevyt](common:keys).

## Kaikkialla

| Näppäin | Toiminto |
|---|---|
| {{key:Mod+S}} | Tallenna kappale (kokoonpanossa: kokoonpano). Sulkee ensin avoimen luonnoksen |
| {{key:Mod+O}} | Avaa kappale- tai kokoonpanotiedosto (kysyy ensin, jos tallentamattomia muutoksia on) |
| {{key:Mod+Z}} | Kumoa |
| {{key:Mod+Y}} tai {{key:Mod+Shift+Z}} | Tee uudelleen |
| {{key:F1}} | Avaa tai sulje tämä ohje (myös {{ui:Help}} sovelluspalkissa). {{key:Esc}} sulkee sen myös. Monilla kannettavilla ja Mac-näppäimistöillä pidetään Fn-näppäintä alhaalla |
| {{key:Ctrl+Shift+F}} | Näyttötila: normaali, koko näyttö, koko näyttö piilotetuilla palkeilla. Myös Control Macilla, ei ⌘ |
| {{key:Esc}} | Poistu koko näytöstä (kun koko näytössä) |
| {{key:Mod+,}} | Asetukset, mukaan lukien PartCraft-välilehti (katso [PartCraftin asetukset](topic:settings)) |

Paneelin numerokentässä {{key:Mod+Z}} on selaimen oma tekstin kumoaminen. Luonnosmitan päällä olevassa numerokentässä se kumoaa PartCraftissa.

## Kopiointi, liittäminen ja monistaminen

Ne toimivat siihen, missä ollaan työn touhussa: avoimen luonnoksen valittuun geometriaan, historian valittuun muotoelementtiin tai kokoonpanon valittuun osaan. Lisätietoja: [Kopiointi, liittäminen ja monistaminen](topic:copy-paste).

| Näppäin | Toiminto |
|---|---|
| {{key:Mod+C}} | Kopioi valinta |
| {{key:Mod+X}} | Leikkaa: kopioi ja poista |
| {{key:Mod+V}} | Liitä. Luonnoksessa kopio seuraa osoitinta: napsauta, mihin se menee |
| {{key:Mod+Shift+V}} | Liitä samaan paikkaan: samat koordinaatit (kokoonpanossa samaan paikkaan) |
| {{key:Mod+D}} | Monista: kopioi ja liitä yhdellä askeleella, leikepöytä jää rauhaan |
| {{key:Mod+A}} | Valitse kaikki (luonnoksessa) |
| {{key:Esc}} | Poista valinta (ja peruuta osoitinta seuraava liittäminen) |

Numerokentässä nämä näppäimet kopioivat ja liittävät tekstiä kuten tavallisesti. Paneelin valitun tekstin kopioi selain.

## Kappaleella (ei avointa luonnosta)

| Näppäin | Toiminto |
|---|---|
| {{key:S}} | Luonnos valitulle tasolle tai tasaiselle pinnalle. Jos mitään ei ole valittu, paikka valitaan napsauttamalla |
| {{key:F}} | Sovita kappale näkymään |
| {{key:M}} | Mittaa kaikissa työtiloissa ja kokoonpanossa. {{key:Esc}} tyhjentää valinnat, toinen {{key:Esc}} sulkee sen (katso [Mittaa etäisyydet, kulmat ja massa](topic:measure)) |
| {{key:X}} | Leikkausnäkymä päälle tai pois kaikissa työtiloissa ja kokoonpanossa. {{key:Esc}} sulkee sen (katso [Katso sisään leikkausnäkymällä](topic:section-view)) |
| {{key:Delete}} | Poista valittu muotoelementti (kysyy, jos muut käyttävät sitä) |
| {{key:0}} … {{key:9}}, {{key:.}} | Kun muotoelementti on valittu: kirjoita sen pääluku (pursotuksen syvyys, reiän halkaisija, kuvion määrä, pyöristyksen säde …) ja paina {{key:Enter}}. {{key:Esc}} säilyttää vanhan |
| {{key:Backspace}} | Poista valittu muotoelementti, kun sellainen on valittu |
| {{key:Esc}} | Lopeta luonnostason valinta tai tyhjennä valinta (mukaan lukien {{key:Shift}}-näppäimellä valitut reunat tai pinnat) |

| {{key:Plus}} tai {{key:=}} | Lähennä |
| {{key:Minus}} | Loitonna |

| Hiiri | Toiminto |
|---|---|
| Vedä vasemmalla painikkeella | Kierrä (kiertoradalla) näkymää |

| {{key:Shift}}, {{key:Ctrl}} tai ⌘ pidettynä vedettäessä vasemmalla painikkeella | Panoroi |
| Rullan pyöritys | Zoomaa osoittimen kohdalla (rullaa poispäin lähentää) |
| Kahden sormen pyyhkäisy kosketuslevyllä | Kierrä näkymää; {{key:Shift}}-näppäimen kanssa panoroi. Nipistys zoomaa. Asetetaan kohdassa **Vieritys** [PartCraftin asetuksissa](topic:settings) |

Kun **Näkymän kierto: keskipainike** on valittu [PartCraftin asetuksissa](topic:settings), keskipainike kiertää näkymää, {{key:Shift}} keskipainikkeen tai oikean painikkeen kanssa panoroi ja vasen painike vain valitsee.

## Kun valitset reunoja tai pintoja pyöristystä, viistämistä tai kuorta varten

| Näppäin tai hiiri | Toiminto |

| {{key:F}} | Sovita |

## Selaimen mahdollisesti käyttämät pikavalinnat

- Safarissa {{key:Mod+Y}} voi avata historian: käytä {{key:Mod+Shift+Z}} tehdäksesi uudelleen.
- {{key:Mod+D}} on selaimen kirjanmerkkinäppäin: PartCraft ottaa sen käyttöön, kun sovellus on fokuksessa, ja jättää sen rauhaan, kun tekstiä kirjoitetaan ruutuun.
- {{key:F11}} sekä {{key:Mod+Plus}} / {{key:Mod+Minus}} ovat selaimen koko näytön ja sivun zoomaus, eivät PartCraftin. Koko näytölle käytetään {{key:Ctrl+Shift+F}}-näppäintä ja mallin zoomaukseen rullaa.
- Monilla kannettavilla ja Macilla toimintonäppäimet vaativat Fn-näppäimen: paina Fn+{{key:F1}} ohjeelle tai käytä {{ui:Help}}-painiketta.

Kosketus- ja kosketuslevyeleet: [Kosketuslevy, kosketus ja pienet näytöt](topic:trackpad-and-touch).

## Missä Siirto sijaitsee

Siirto sijaitsee Muotoelementit-ryhmän {{ui:More}}-valikossa nimellä {{ui:Move body}}, {{ui:Move}}-ruudussa, johon kirjoitetaan ΔX, ΔY ja ΔZ, sekä kappaleella näkyvinä {{ui:Drag to move}}-nuolina.
