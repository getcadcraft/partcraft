Lua [اسکرپٹ ورک اسپیس](topic:craftscript) کی دوسری زبان ہے۔ ایڈیٹر کے اوپر زبان والے باکس میں **Lua** منتخب کریں (`.lua` فائل خود بخود Lua میں کھلتی ہے)۔ Lua اور CraftScript ایک ہی متغیرات اور ایک ہی بلٹ اِن فنکشنز کا اشتراک کرتے ہیں، اس لیے Lua اسکرپٹ وہ استعمال کر سکتا ہے جو CraftScript اسکرپٹ نے بنایا، اور اس کے برعکس بھی۔

## بنیادی باتیں

```
-- ہر بلٹ اِن فنکشن cs ٹیبل میں ہے
local K = cs.zeros(3, 3)
K:set(1, 1, 4)                 -- 1 سے شروع، CraftScript کی طرح
print(K(1, 1), #K)             -- ایک عنصر؛ عناصر کی تعداد

-- ورک اسپیس: وہی متغیرات جو ہر اسکرپٹ دیکھتا ہے
ws.total = K(1, 1) * 2
print(ws.total)

-- ایک فنکشن سے کئی نتائج
local V, D = cs.call('eig', 2, cs.tensor({{2, 1}, {1, 2}}))
```

- `cs.<name>(…)` کوئی بھی بلٹ اِن فنکشن کال کرتا ہے اور اس کا پہلا نتیجہ واپس کرتا ہے؛ `cs.call(name, n, …)` `n` نتائج واپس کرتا ہے۔
- `cs.tensor({1, 2, 3})` ایک قطار بناتا ہے، `cs.tensor({{1, 2}, {3, 4}})` ایک میٹرکس۔
- صفیں، اسپارس میٹرکس، میشز اور فیلڈز طریقوں والی قدریں ہیں: `t(i, j)` یا `t:get(i, j)`، `t:set(i, j, v)`، `t:shape()`، `#t`، `t:T()` (ٹرانسپوز)، `t:totable()`۔ `+ - * / ^` وہی معنی رکھتے ہیں جو CraftScript میں (`*` میٹرکس ضرب ہے)؛ `t:times(u)` عنصر بہ عنصر ضرب کرتا ہے۔
- وہ عدد جو 1×1 صف ہو، سادہ Lua عدد کے طور پر آتا ہے۔
- `ws.name` مشترکہ ورک اسپیس کو پڑھتا اور لکھتا ہے۔ آپ کے اسکرپٹ کے پیچھے رہ جانے والے گلوبل متغیرات بھی اس کے ختم ہونے پر وہاں پہنچ جاتے ہیں۔
- `print(…)` کنسول پر لکھتا ہے؛ `cs.show(f)`، `cs.plot(y)` اور دیگر ڈسپلے فنکشنز CraftScript کی طرح کام کرتے ہیں۔

## تجزیاتی لائبریری کو کال کریں

تجزیاتی لائبریری کے فنکشنز (لائبریری ٹیب) اور وہ CraftScript فنکشنز جو آپ کے پرزے کے اپنے اسکرپٹس بیان کرتے ہیں، وہ بھی `cs` کے ذریعے پہنچے جاتے ہیں:

```lua
local t = cs.box_mesh(100, 10, 10, 5, 'tet10')
local bc = cs.struct({ fixedFaces = 5, loads = { cs.struct({ face = 6, force = cs.tensor({ 0, -100, 0 }) }) } })
local r = cs.static_tet(t, 200000, 0.3, bc)
print(r.maxDisp)
local nodes, tris = cs.call('face_nodes', 2, t, 6)   -- دو آؤٹ پٹس
```

یہ اسکرپٹ شروع ہونے سے پہلے ڈھونڈ لیے جاتے ہیں، اس لیے نام اسکرپٹ میں اسی طرح لکھیں: `cs.static_tet(` یا `cs.call('static_tet', …)`۔ جو نام اسکرپٹ چلنے کے دوران بنایا جائے وہ صرف بلٹ اِن فنکشنز تک پہنچتا ہے۔ `cs.struct({ … })` سے بنایا گیا struct ایک CraftScript struct ہے، اور ان کی Lua فہرست (`{ cs.struct(…), … }`) ایک cell ہے، جس کی لائبریری کی ترتیبات توقع کرتی ہیں۔ اگر لائبریری فنکشن کے اندر کچھ غلط ہو جائے تو پیغام فنکشن اور اس کی لائن کا نام لیتا ہے، اور آپ کی اس لائن کی طرف اشارہ کرتا ہے جس نے اسے کال کیا۔

## بند ہے

اسکرپٹس فائلوں، نیٹ ورک یا صفحے تک نہیں پہنچ سکتے: `io`، `os` (گھڑی کے سوا)، `require`، `dofile`، `loadfile` اور `debug` ہٹا دیے گئے ہیں۔ ڈیٹا لانے کے لیے اسکرپٹ ورک اسپیس کا کھولیں اور متغیرات استعمال کریں۔ اسٹیپ بجٹ اور روکنا CraftScript کی طرح کام کرتے ہیں۔
