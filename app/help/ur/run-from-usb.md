انجینئرنگ ٹولز (جنریٹرز، انجینئرنگ لائبریری، جانچیں اور ڈیٹا فائلیں) کو **ایڈمنسٹریٹر حقوق** کی ضرورت **نہیں** اور **انسٹالر** کی بھی ضرورت نہیں۔ یہ صرف وہی لکھتے ہیں جو یہاں درج ہے، اور اس کے علاوہ کچھ نہیں۔

| کیا | کہاں محفوظ ہوتا ہے |
|---|---|
| آپ کے پارٹس، ان کی تیار شدہ باڈیز، ڈیٹا شیٹس اور جانچیں | وہ پارٹ فائل (`.partcraft.json`) جو آپ محفوظ کرتے ہیں، جہاں بھی آپ اسے محفوظ کریں۔ |
| وہ جنریٹرز جو آپ نے فائلوں سے کھولے | ایپ کا اپنا اسٹوریج: ویب صفحے میں براؤزر کا لوکل اسٹوریج، اور پورٹیبل Studio میں پروگرام کے ساتھ والا `data` فولڈر۔ زیادہ سے زیادہ 20۔ |
| ترتیبات (آپ کے سیٹ کردہ وائکسل سائز، سالور تھریڈز، لے آؤٹ) | وہی ایپ اسٹوریج۔ |
| ڈیٹا شیٹس، فیلڈز، میشز | صرف وہیں جہاں آپ انہیں محفوظ کریں: ڈاؤن لوڈ وہیں جاتا ہے جو آپ چنیں۔ |

ٹولز **اپنی طرف سے کوئی نیٹ ورک کال نہیں کرتے**: فراہم کردہ جنریٹرز ایپ کے اپنے فولڈر میں فائلیں ہیں، لائبریری اور جانچیں آپ کے کمپیوٹر پر ایک ورکر میں چلتی ہیں جو نیٹ ورک تک نہیں پہنچ سکتا، اور انجینئرنگ ڈیٹا (پانی اور ہوا کی خصوصیات، مواد) ایپ کے اندر ہے۔ فائل سے کھولا گیا جنریٹر آپ کے کمپیوٹر پر پڑھا جاتا ہے اور کہیں نہیں جاتا۔

## پورٹیبل ونڈوز زپ اور لینکس

پورٹیبل Studio برائے ونڈوز اپنی ترتیبات، کیش اور ایڈ آنز پروگرام کے ساتھ والے `data` فولڈر میں رکھتا ہے۔ Linux AppImage انہیں اپنے ساتھ رکھتا ہے جب اس کے ساتھ `portable` نامی فائل موجود ہو؛ اس فائل کے بغیر یہ آپ کے ہوم فولڈر کو استعمال کرتا ہے۔ macOS کی کوئی پورٹیبل شکل نہیں ہے: سسٹم ڈاؤن لوڈ کی گئی ایپ کو اپنے ساتھ لکھنے سے روکتا ہے۔ شیل کے اپنے پورٹیبل نوٹس (`Studio` مدد) میں درج ہے کہ پروگرام کیا لکھتا ہے۔

## ہوسٹ رسائی

یہاں کچھ بھی ہوسٹ رسائی نہیں مانگتا۔ پرنٹرز، سیریل مشینیں اور USB ڈیوائسز الگ ہیں: جب کوئی جاب انہیں درکار ہو تو وہ پوچھتی ہیں، ہر ڈیوائس کے لیے ایک بار، اور جنریٹرز یا جانچوں میں کچھ بھی انہیں نہیں چھوتا۔
