CraftScript ایک میٹرکس زبان ہے جو MATLAB جیسی پڑھی جاتی ہے، اس لیے زیادہ تر کلاسیکی عددی کوڈ (مثلاً 88 لائنوں والا ٹوپالوجی آپٹیمائزیشن کوڈ) تھوڑی سی تبدیلی کے ساتھ چل جاتے ہیں۔ یہ [اسکرپٹ ورک اسپیس](topic:craftscript) میں اور کمانڈ لائن سے چلتی ہے۔

## قدریں

| قسم | مثال | نوٹس |
|---|---|---|
| عدد، صف | `a = 3`, `v = [1 2 3]`, `A = [1 2; 3 4]` | ہر عدد ایک صف ہے (1×1 والی)۔ صفیں کالم بہ کالم محفوظ ہوتی ہیں، 8 ابعاد تک |
| لاجیکل | `A > 2`, `true` | true اور false کی صفیں؛ انڈیکس کے طور پر استعمال ہو سکتی ہیں |
| متن | `'beam'`, `"beam"` | |
| اسپارس میٹرکس | `sparse(i, j, v, n, n)` | سختی کے میٹرکس کے لیے |
| میش، فیلڈ، ماڈل | `hexGrid(…)`, `part()`, `load('part.stl')` | وہ جو `show` دکھاتا ہے |
| اسٹرکٹ | `s.E = 210e3` | نام والے فیلڈز |
| سیل | `c = {1, 'two', [3 4]}` | کسی بھی قدر کی فہرست |
| فنکشن ہینڈل | `f = @(x) x.^2` | |

## صفیں اور انڈیکسنگ

- رینجز: `1:5`, `0:0.1:1`۔ `linspace(a, b, n)`, `zeros(n, m)`, `ones`, `eye`, `rand`۔
- انڈیکسنگ 1 سے شروع ہوتی ہے: `A(2, 3)`, `v(end)`, `A(:, 1)` (پورا کالم), `A(:)` (سب کچھ ایک کالم میں), `v(v > 0)` (لاجیکل انڈیکسنگ)۔
- آخر سے آگے قدر دینے پر صف MATLAB کی طرح بڑھ جاتی ہے، جیسے `v(10) = 1`

## آپریٹرز

- `+ - * / \ ^` میٹرکس آپریشنز ہیں (`A \ b` حل کرتا ہے)؛ `.* ./ .^` عنصر بہ عنصر کام کرتے ہیں۔ `'` ٹرانسپوز کرتا ہے۔
- موازنے `== ~= < <= > >=`؛ منطق `& | ~` (عنصر بہ عنصر) اور `&& ||` (شارٹ سرکٹ)۔

## کنٹرول فلو اور فنکشنز

```
for k = 1:10
  if mod(k, 2) == 0
    continue
  elseif k > 7
    break
  end
end
while err > 1e-6, … end
switch kind
  case 'steel'
    E = 210e3;
  otherwise
    E = 70e3;
end
try
  x = A \ b;
catch e
  disp(e.message)
end
```

فنکشنز اسکرپٹ میں اس کے کمانڈز کے بعد رکھے جاتے ہیں، یا اپنے الگ اسکرپٹ ٹیب میں جن کا نام فنکشن کے نام پر ہوتا ہے:

```
function [k, m] = beam(E, I, L)
  k = 3 * E * I / L^3;
  m = 0;
end
```

نام اس ترتیب سے تلاش کیا جاتا ہے: متغیر، اس پرزے میں اسی نام کا اسکرپٹ، لائبریری فنکشن، پھر بلٹ اِن فنکشن۔

## Echo، تبصرے، آؤٹ پٹ

- `;` کے بغیر بیان اپنی قدر پرنٹ کرتا ہے؛ `;` اسے خاموش رکھتا ہے۔
- `%` تبصرہ شروع کرتا ہے؛ الگ سطروں پر `%{` اور `%}` ان کے درمیان کی سطروں کو تبصرہ بنا دیتے ہیں۔
- `disp(x)`, `fprintf('%g\n', x)` اور `display(x)` کنسول پر پرنٹ کرتے ہیں۔

## غلطیاں اور حدیں

- غلطیاں سادہ الفاظ میں بتاتی ہیں کہ کیا غلط ہوا، اور لائن (اور فنکشن کالز کی زنجیر) دیتی ہیں۔
- ہر رن کا ایک اسٹیپ بجٹ ہوتا ہے (**رن کے اختیارات** میں پینل پر)؛ لامتناہی لوپ ایک پیغام کے ساتھ رک جاتا ہے، یا {{ui:روکیں}} دبائیں۔
- ہر ایک میں 134 ملین قدریں تک صفیں رکھ سکتی ہیں۔

## MATLAB سے مختلف

- پلاٹ کمانڈز اپنے اختیارات کال کے اندر رکھتی ہیں: `plot(x, y, 'title', 'Error', 'xlabel', 'Step')`۔ `figure`، `hold`، `axis`، `title(…)` اور اس جیسے فنکشن قبول ہو جاتے ہیں، مگر کچھ نہیں کرتے۔
- `input` اور `keyboard` سپورٹ نہیں ہیں: اسکرپٹ سوال پوچھنے کے لیے رک نہیں سکتا۔
- کوئی ٹول باکس نہیں ہیں؛ جو کچھ ہے وہ [تجزیاتی لائبریری](topic:craftscript-library) اور بلٹ اِن فنکشنز ہیں۔
