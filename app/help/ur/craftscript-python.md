Python [اسکرپٹ ورک اسپیس](topic:craftscript) کی تیسری زبان ہے۔ ایڈیٹر کے اوپر زبان والے باکس میں **Python** منتخب کریں (`.py` فائل خود بخود Python میں کھلتی ہے)۔ Python، Lua اور CraftScript ایک ہی متغیرات اور ایک ہی بلٹ اِن فنکشنز کا اشتراک کرتے ہیں، اس لیے Python اسکرپٹ وہ استعمال کر سکتا ہے جو CraftScript اسکرپٹ نے بنایا، اور اس کے برعکس بھی۔

کسی ایک دورے میں Python کا پہلا رن اس سائٹ سے خود Python (CPython 3.14، تقریباً 7 MB) لوڈ کرتا ہے، جس میں چند سیکنڈ لگتے ہیں۔ Python ابھی {{ui:آف لائن کے لیے محفوظ کریں}} کا حصہ نہیں ہے: پہلے آن لائن رہتے ہوئے ایک Python اسکرپٹ چلائیں۔

## Python بند ہے

Python اسکرپٹس CraftScript اور Lua اسکرپٹس کی طرح بند ہوتے ہیں: وہ پرزے، متغیرات اور بلٹ اِن فنکشنز تک پہنچتے ہیں، اور کچھ نہیں۔ ہر رن اپنے سینڈ باکس میں ایک نیا Python ہے، جس کے پاس میموری میں ایک چھوٹا فائل ٹری ہے (اس کی معیاری لائبریری اور ایک `/tmp` فولڈر جو رن کے بعد ختم ہو جاتا ہے)۔ یہ نیٹ ورک، آپ کی فائلوں یا صفحے کے باقی حصے تک نہیں پہنچ سکتا، براؤزر میں اور کمانڈ لائن پر یکساں طور پر۔ کسی اور کا اسکرپٹ اب بھی بہت وقت یا میموری لے سکتا ہے: {{ui:روکیں}} اسے ختم کرتا ہے۔

## بنیادی باتیں

```
A = cs.magic(3)              # ہر بلٹ اِن فنکشن cs.<name> ہے
B = A @ A.T                  # @ میٹرکس ضرب ہے، .T ٹرانسپوز
C = A * 2 + 1                # + - * / ** عنصر بہ عنصر ہیں، numpy کی طرح
print(A[0, 1], A[-1, -1])    # 0 سے شروع؛ منفی آخر سے گنتا ہے
row = A[1]                   # میٹرکس پر ایک انڈیکس: ایک قطار
big = A[A > 4]               # لاجیکل ماسک عناصر چنتا ہے
A[0, 0] = -5                 # صف میں قدر دینا
V, D = cs.call('eig', 2, A)  # کئی نتائج: cs.call(name, کتنے, …)
```

- 1 × 1 صف سادہ عدد کے طور پر آتی ہے؛ باقی صفیں، اسپارس میٹرکس، میشز، فیلڈز اور ماڈلز **Values** ہیں۔
- ایک Value کے پاس `shape` (ٹپل)، `T`، `type`، `numel()`، `copy()`، `tolist()`، `len()` (اس کی قطاریں)، اور ایک عنصر کے لیے `float()`، `int()` اور `bool()` ہیں۔
- موازنے (`<`، `==`، …) numpy کی طرح عنصر بہ عنصر ہوتے ہیں: وہ ایک لاجیکل Value دیتے ہیں۔
- بلٹ اِن فنکشن کو دی گئی عددوں کی فہرستیں صفیں بن جاتی ہیں: `cs.sum([1, 2, 3])`۔ `cs.tensor([[1, 2], [3, 4]])` ایک میٹرکس بناتا ہے۔
- ڈکشنری ایک struct بن جاتی ہے اور مختلف چیزوں کی فہرست ایک cell، اور پھر واپس بھی۔

آپ کے اسکرپٹ کا ہر گلوبل (عدد، Value، ڈکشنری، فہرست…) رن ختم ہونے پر **متغیرات** ٹیب میں پہنچ جاتا ہے، غلطی کے بعد بھی۔ `_` سے شروع ہونے والے نام، فنکشنز، کلاسز اور ماڈیولز Python میں رہتے ہیں۔ `ws.name` ایک متغیر کو براہ راست پڑھتا یا سیٹ کرتا ہے، اور `ws_names()` انہیں فہرست کرتا ہے۔

`print(…)` کنسول پر لکھتا ہے۔ `display(…)` (یا `cs.display`) ایک میش، فیلڈ یا پلاٹ دکھاتا ہے، CraftScript کی طرح۔

## تجزیاتی لائبریری کو کال کریں

لائبریری فنکشنز بلٹ اِن فنکشنز کی طرح کال ہوتے ہیں: `cs.box_mesh(20, 10, 10, 5, 'hex')`، `cs.call('modal_tet', 2, …)`۔ نام اسکرپٹ میں جوں کا توں لکھیں: PartCraft چلنے سے پہلے وہ لائبریری فنکشنز ڈھونڈ لیتا ہے جو اسکرپٹ استعمال کرتا ہے۔

## ابھی موجود نہیں

- numpy، scipy اور دیگر پیکیجز: یہاں صرف Python کی اپنی معیاری لائبریری (`math`، `json`، `itertools`، `decimal`، `statistics`…) ہے، اس کے ونڈو، ٹرمینل اور ڈیٹا بیس والے حصوں کے بغیر (`tkinter`، `curses`، `sqlite3`)۔
- Sockets اور ہر وہ چیز جو باہر تک پہنچے: یہاں Python کا کوئی نیٹ ورک نہیں ہے۔
- `time.sleep` فوراً واپس آ جاتا ہے۔
- ایڈیٹر میں فولڈنگ، اور CraftScript اسکرپٹ سے Python فنکشن کال کرنا۔
- ایک رن ہر 1000 سطروں پر انسٹرکشن بجٹ اور {{ui:روکیں}} چیک کرتا ہے؛ کسی ایک بلٹ اِن فنکشن کے اندر لمبا حساب پہلے مکمل ہوتا ہے۔
