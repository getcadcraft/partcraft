پینل کے کسی باکس میں ٹائپ کرتے وقت کیز کچھ نہیں کرتیں، سوائے {{key:Mod+S}} اور {{key:Mod+O}} کے، جو ہمیشہ کام کرتی ہیں۔ حروف والی کیز ماڈیفائر کے بغیر کام کرتی ہیں۔

براؤزر میں کیز کے بارے میں، اور ان کی بورڈز پر جن میں فنکشن کیز نہیں ہوتیں، عمومی نوٹس: [کیز، ماؤس اور ٹریک پیڈ](common:keys)۔

## ہر جگہ

| کی | عمل |
|---|---|
| {{key:Mod+S}} | پارٹ محفوظ کریں (اسمبلی میں: اسمبلی)۔ پہلے کھلا اسکیچ بند کرتا ہے |
| {{key:Mod+O}} | پارٹ یا اسمبلی فائل کھولیں (اگر غیر محفوظ شدہ تبدیلیاں ہوں تو پہلے پوچھتا ہے) |
| {{key:Mod+Z}} | کالعدم کریں |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | دوبارہ کریں |
| {{key:F1}} | یہ مدد کھولیں یا بند کریں ({{ui:مدد}} کی طرح، ایپ بار میں بھی)۔ {{key:Esc}} بھی اسے بند کرتی ہے۔ بہت سے لیپ ٹاپ اور Mac کی بورڈز پر Fn دبائے رکھیں |
| {{key:Ctrl+Shift+F}} | اسکرین موڈ: عام، مکمل اسکرین، بارز چھپا کر مکمل اسکرین۔ Mac پر بھی Ctrl، ⌘ نہیں |
| {{key:Esc}} | مکمل اسکرین سے نکلیں (مکمل اسکرین میں ہوں تو) |
| {{key:Mod+,}} | {{ui:ترتیبات}}، بشمول PartCraft ٹیب (دیکھیں [PartCraft ترتیبات](topic:settings)) |

کسی پینل کے نمبر باکس میں {{key:Mod+Z}} براؤزر کا اپنا متن کالعدم کرنے کا عمل ہے۔ اسکیچ ڈائمینشن کے اوپر والے نمبر باکس میں یہ PartCraft میں کالعدم کرتا ہے۔

## کاپی، پیسٹ اور ڈپلیکیٹ

یہ اس پر عمل کرتی ہیں جس میں آپ کام کر رہے ہوں: کھلے اسکیچ میں منتخب جیومیٹری، ہسٹری میں منتخب فیچر، یا اسمبلی میں منتخب پارٹ۔ تفصیل: [کاپی، پیسٹ اور ڈپلیکیٹ](topic:copy-paste)۔

| کی | عمل |
|---|---|
| {{key:Mod+C}} | منتخب حصہ نقل کریں |
| {{key:Mod+X}} | کاٹیں: پہلے نقل کریں، پھر حذف کریں |
| {{key:Mod+V}} | چسپاں کریں۔ اسکیچ میں نقل پوائنٹر کے ساتھ چلتی ہے: جہاں جانا ہو وہاں کلک کریں |
| {{key:Mod+Shift+V}} | اسی جگہ چسپاں کریں: وہی کوآرڈینیٹس (اسمبلی میں، وہی جگہ) |
| {{key:Mod+D}} | ڈپلیکیٹ بنائیں: ایک مرحلے میں نقل اور چسپاں، کلپ بورڈ کو چھیڑے بغیر |
| {{key:Mod+A}} | سب منتخب کریں (اسکیچ میں) |
| {{key:Esc}} | انتخاب ختم کریں (اور پوائنٹر کے ساتھ چلنے والی چسپاں کو منسوخ کریں) |

نمبر باکس میں یہ کیز معمول کے مطابق متن نقل اور چسپاں کرتی ہیں۔ پینل میں منتخب متن براؤزر نقل کرتا ہے۔

## پارٹ پر (کوئی اسکیچ کھلا نہ ہو)

| کی | عمل |
|---|---|
| {{key:S}} | منتخب سطح یا ہموار رخ پر اسکیچ بنائیں؛ کچھ منتخب نہ ہو تو کلک کر کے جگہ چنیں |
| {{key:F}} | پارٹ کو ویو میں فٹ کریں |
| {{key:M}} | ناپیں، ہر ورک اسپیس اور اسمبلی میں؛ {{key:Esc}} منتخب اشیاء ہٹاتا ہے، {{key:Esc}} دوبارہ اسے بند کرتا ہے (دیکھیں [فاصلے، زاویے اور ماس ناپیں](topic:measure)) |
| {{key:X}} | سیکشن ویو آن یا آف، ہر ورک اسپیس اور اسمبلی میں؛ {{key:Esc}} اسے بند کرتا ہے (دیکھیں [سیکشن ویو سے اندر دیکھیں](topic:section-view)) |
| {{key:Delete}} | منتخب فیچر حذف کریں (اگر دوسرے اسے استعمال کر رہے ہوں تو پوچھتا ہے) |
| {{key:0}} … {{key:9}}، {{key:.}} | فیچر منتخب ہو تو اس کا بنیادی نمبر ٹائپ کریں (ایکسٹروڈ کی گہرائی، ہول کا قطر، پیٹرن کی گنتی، فلٹ کا رداس …)، پھر {{key:Enter}}۔ {{key:Esc}} پرانا نمبر رکھتا ہے |
| {{key:Backspace}} | منتخب فیچر حذف کریں، جب کوئی منتخب ہو |
| {{key:Esc}} | اسکیچ کی سطح چننا بند کریں، یا انتخاب ہٹائیں (بشمول {{key:Shift}} سے چنی گئی کناروں یا رخوں کے) |

## 3D ویو میں

پہلے ویو میں کلک کریں تاکہ اسے کی بورڈ فوکس ملے۔

| کی | عمل |
|---|---|
| {{key:Left}} {{key:Right}} {{key:Up}} {{key:Down}} | ویو کو 15 ڈگری گھمائیں |
| {{key:Shift+Left}} اور باقی تیر | پین کریں |
| {{key:Plus}} یا {{key:=}} | زوم ان |
| {{key:Minus}} | زوم آؤٹ |

| ماؤس | عمل |
|---|---|
| بائیں بٹن سے گھسیٹیں | ویو گھمائیں (آربٹ) |
| دائیں یا درمیانی بٹن سے گھسیٹیں | پین کریں |
| بائیں بٹن سے گھسیٹتے وقت {{key:Shift}}، {{key:Ctrl}} یا ⌘ دبا ہوا ہو | پین کریں |
| وہیل گھمائیں | پوائنٹر پر زوم (آپ سے دور جانے سے زوم ان ہوتا ہے) |
| ٹریک پیڈ پر دو انگلیوں سے سوائپ | ویو گھمائیں؛ {{key:Shift}} کے ساتھ پین کریں۔ پنچ سے زوم ہوتا ہے۔ [PartCraft ترتیبات](topic:settings) میں **اسکرولنگ** سے طے ہوتا ہے |

[PartCraft ترتیبات](topic:settings) میں **ویو گھمانا: درمیانی بٹن** ہونے پر درمیانی بٹن ویو گھماتا ہے، درمیانی یا دائیں بٹن کے ساتھ {{key:Shift}} پین کرتا ہے، اور بائیں بٹن سے صرف چنا جاتا ہے۔
| کلک | ایک رخ چنیں (پورا نمایاں ہوتا ہے)، ایک کنارہ یا سطح |
| {{key:Shift}}+کلک کنارے یا رخ پر | کئی کنارے یا رخ جمع کریں |
| خالی جگہ پر کلک | چناؤ ہٹائیں |

## وہ شارٹ کٹس جو براؤزر لے سکتا ہے

- Safari میں {{key:Mod+Y}} ہسٹری کھول سکتا ہے: دوبارہ کرنے کے لیے {{key:Mod+Shift+Z}} استعمال کریں۔
- {{key:Mod+D}} براؤزر کی بک مارک کی ہے: PartCraft اسے ایپ فوکس میں ہونے پر لیتا ہے، اور باکس میں ٹائپ کرتے وقت چھوڑ دیتا ہے۔
- {{key:F11}} اور {{key:Mod+Plus}} / {{key:Mod+Minus}} براؤزر کی مکمل اسکرین اور صفحے کا زوم ہیں، PartCraft کے نہیں۔ مکمل اسکرین کے لیے {{key:Ctrl+Shift+F}} اور ماڈل کے لیے وہیل استعمال کریں۔
- بہت سے لیپ ٹاپ اور Mac پر فنکشن کیز کے لیے Fn کی ضرورت ہوتی ہے: مدد کے لیے Fn+{{key:F1}} دبائیں، یا {{ui:مدد}} بٹن استعمال کریں۔

ٹچ اور ٹریک پیڈ کے اشارے: [ٹریک پیڈ، ٹچ اور چھوٹی اسکرینیں](topic:trackpad-and-touch)۔

## منتقلی کہاں ہے

منتقلی فیچرز گروپ کے {{ui:مزید}} مینو میں {{ui:جسم منتقل کریں}} کے طور پر ہے، اس {{ui:منتقلی}} باکس میں جہاں آپ ΔX، ΔY اور ΔZ ٹائپ کرتے ہیں، اور پارٹ پر {{ui:منتقل کرنے کے لیے گھسیٹیں}} تیروں کے طور پر۔
