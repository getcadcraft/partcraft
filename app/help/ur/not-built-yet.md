PartCraft ایک ابتدائی بلڈ ہے۔ یہ صفحہ بتاتا ہے کہ یہ کیا نہیں کرتا، تاکہ آپ اسے تلاش نہ کریں، اور آج اس کے بجائے کیا کریں۔ یہاں کسی چیز کی کوئی تاریخ نہیں ہے۔

## درست کرنل کی ضرورت

یہ ورژن ہر پرزہ mesh kernel سے بناتا ہے (دیکھیں [The mesh kernel](topic:solid-kernels))۔ نیچے کی ہر چیز ایک درست جیومیٹری کرنل مانگتی ہے، جو اس ورژن میں ابھی نہیں ہے۔ ان فیچرز والے محفوظ پرزے پھر بھی کھلتے ہیں: فیچرز ہسٹری میں رہتے ہیں، "ابھی تیار نہیں" کے نشان کے ساتھ، اور محفوظ کرتے وقت برقرار رہتے ہیں۔

| ابھی تیار نہیں | آج کے بجائے |
|---|---|
| گول کناروں پر {{ui:فلٹ}} اور {{ui:چیمفر}}؛ ایسے فلٹس جن کا رداس کنارے کے ساتھ بدلتا ہے؛ جہاں ملیں وہاں ہموار طور پر ملے ہوئے راؤنڈز (mesh kernel انھیں mitre کرتا ہے) | Fillet اور Chamfer سیدھے کناروں پر کام کرتے ہیں جو ہموار رخوں کے درمیان ہوں؛ باقی کونوں کو extrude سے پہلے خاکے میں گول کریں ({{ui:فلٹ}} خاکے میں، {{key:F}}) |
| کھلے منحنی رخوں پر {{ui:شیل}}؛ مختلف موٹائی کی دیواریں | کھلے ہموار رخ؛ جہاں دیوار موٹی ہونی ہو وہاں extrudes سے مواد شامل کریں |
| منحنی رخوں پر {{ui:سویپ}}، {{ui:لافٹ}}، {{ui:ڈرافٹ}}؛ کسی رخ، اگلے رخ یا کسی vertex تک extrude کرنا؛ ٹیپرڈ extrudes | Extrude یا revolve کریں، جہاں ضرورت ہو مرحلوں میں؛ جس گہرائی کی پیمائش کی ہو وہاں تک extrude کریں |
| {{ui:ریب}}، {{ui:بیس فلینج}}، {{ui:ایج فلینج}} اور flat patterns | پلیٹ یا ریب کا پروفائل extrude کریں |
| سطحیں: {{ui:فارم}} کو پرزے میں فنش کرنا، {{ui:پیچ}}، {{ui:سطح لافٹ}}، {{ui:گورڈن سطح}}، {{ui:اسٹچ}}، {{ui:موٹا کریں}}، {{ui:آفسیٹ سطح}}، {{ui:سطح بڑھائیں}}، {{ui:سطح ٹرم کریں}} | دستیاب نہیں |
| کئی باڈیز: {{ui:کمبائن}}، {{ui:جسم منتقل کریں}}، {{ui:جسم اسکیل کریں}}، {{ui:پاتھ پیٹرن}}، نئی باڈی بنانے والے فیچرز | ایک ٹھوس؛ پیٹرنز اور مرر فیچرز کاپی کرتے ہیں |
| رخوں پر خاکے، پلین، محور اور نقاط جنھیں صرف درست کرنل ڈھونڈ سکتا ہے (فلٹ سے بنا رخ، سوراخ کی دیوار، امپورٹ شدہ سالڈ کا رخ) | بنیادی پلینز، ریفرنس پلینز اور extrudes اور revolves کے ہموار رخوں پر خاکہ بنائیں |
| جنریٹو ڈیزائن کا نتیجہ بطور پرزہ کھولنا یا اس میں شامل کرنا (وہ امپورٹ شدہ سالڈ بن جاتا ہے) | نتیجہ STL یا STEP کے طور پر ڈاؤن لوڈ کریں |
| کھولی گئی STEP فائل کے منحنی رخوں کو درست سطحوں کے طور پر ایڈٹ کرنا؛ STEP فائل کے spline، swept اور revolved رخوں کا درست STEP؛ spline کنارے، ماڈل شدہ threads، STL / OBJ / 3MF باڈیز اور اسمبلیاں؛ دوسرے پارٹ ماڈلرز کے لیے STEP | {{ui:کھولیں}} STEP کو مثلثوں کے طور پر پڑھتا ہے اور فائل کے ہموار رخ، سلنڈرز، کونز، اسفیئرز اور ٹورائی ایکسپورٹ کے لیے رکھتا ہے ([STEP فائل کھولیں](topic:import-step))؛ {{ui:ایکسپورٹ}} › {{ui:STEP AP242 (ایکسیکٹ ٹھوس)}} ہر تحلیلی رخ کو درست لکھتا ہے اور انھیں facets کے طور پر رکھتا ہے ([ایکسپورٹ](topic:export-files#for-other-cad-programs-step))؛ دوسرے پارٹ ماڈلر کے لیے میکرو ابھی بھی لکھتا ہے |
| ڈرائنگ ویوز میں حقیقی قوسیں | ویوز اور سیکشن ویوز facets سے بنتے ہیں |
| درست حجم، رقبے اور فاصلے | {{ui:ناپیں}} faceted سالڈ کے عدد دیتا ہے، گول پرزوں پر تھوڑے کم؛ زیادہ باریک **Curves** سیٹنگ انھیں قریب لاتی ہے |

کچھ قطاریں نیچے کی جدولوں میں ان فیچرز میں سے کسی ایک کو کسی اور چیز کا حل بتاتی ہیں۔ وہ مشورے درست کرنل واپس آنے کے بعد لاگو ہوتے ہیں۔

## فیچرز

| ابھی تیار نہیں | آج کے بجائے |
|---|---|
| Face fillets، مکمل گول fillets، کنارے پر نقاط پر مقرر رداس والے fillets | مقررہ یا خطی متغیر {{ui:فلٹ}}؛ کئی fillet فیچرز |
| مختلف موٹائی کے Shells | ایک {{ui:شیل}} موٹائی؛ جہاں دیوار موٹی ہونی ہو وہاں extrudes سے مواد شامل کریں |
| Freeform (spline) رخوں پر ڈرافٹ | {{ui:ڈرافٹ}} ہموار، سلنڈری اور کونیکل رخوں پر کام کرتا ہے |
| Twisting sweeps، thin-wall اور surface sweeps؛ Loft فیچر پر end tangency؛ ایک گائیڈ ریل والا loft؛ spline paths | مقررہ سمت یا end scale کے ساتھ {{ui:سویپ}}؛ دو یا زیادہ گائیڈ ریلز والا loft: دیکھیں [Sweep، loft اور draft](topic:sweep-loft-draft) |
| قوسوں یا splines سے ریبز؛ خاکے کے مربع رخ پر اگائے گئے ریبز (اوپر والے ویو سے)؛ ریبز پر ڈرافٹ؛ ایک خاکے سے کئی ریبز | ریب کی اپنی پلین میں ایک زنجیر خطوط سے {{ui:ریب}}: دیکھیں [Ribs اور gussets](topic:rib) |
| منحنی رخ "تک"، منحنی رخ پر رکنے والا "اگلے تک" | ہموار رخ یا ریفرنس پلین تک |

| Thin-feature extrudes | پروفائل کی دونوں دیواریں بنائیں |
| پیٹرن کی کاپیاں ایک ایک کر کے چھوڑنا، fill patterns | الگ فیچرز استعمال کریں؛ کسی کرو کے ساتھ پیٹرنز: {{ui:پاتھ پیٹرن}} |
| پیٹرن کاپیاں، مرر، فلٹس، چیمفرز، شیلز اور امپورٹ شدہ سالڈز کی نقل | وہ خاکہ یا فیچر کاپی کریں جس پر وہ بنے ہیں، یا اسے پیٹرن کریں |
| فارم کے غیر معمولی نقاط پر درست (G1) tangency؛ فارم کے patches کو بڑے رخوں میں ملانا | فارم کا Level بڑھائیں: تخمینی patches چھوٹے ہو جاتے ہیں؛ دیکھیں [Form کے ساتھ آزاد شکلیں](topic:form-surfaces) |
| ایک فیچر میں کئی الگ بند ٹکڑوں سے بنی ایک فارم؛ فارمز کے درمیان پُل | ہر Form فیچر میں ایک بند ٹکڑا؛ انھیں {{ui:جوڑیں}} سے ملائیں |
| ویو میں surface باڈیز کو منتخب کرنا (trim اور patch کے نقاط کے علاوہ)؛ surface fillets؛ untrim؛ G2 patches؛ منحنی پڑوسیوں سے ملنے والے Gordon surfaces (مستوی اور ہموار رخوں سے ملنا بنایا گیا ہے) | فیچر کے پینل میں نام سے چنیں؛ پہلے موٹا کریں، پھر ٹھوس پر fillet کریں |
| ہسٹری میں باڈی کی فہرست؛ ایکسپورٹ سے چھپی ہوئی باڈیز کو باہر رکھنا | پرزے کے پینل کی باڈی فہرست میں نام بدلیں اور چھپائیں؛ باڈی بنانے والا فیچر حذف یا suppress کریں تاکہ وہ باہر رہے |
| سلنڈرز اور کونز کو تحلیلی رکھنے والا غیر یکساں اسکیل؛ offset surfaces کا غیر یکساں اسکیل | {{ui:جسم اسکیل کریں}} منحنی رخوں کو قریبی B-splines بناتا ہے (0.0000004 mm کے اندر)؛ یکساں اسکیل درست رہتا ہے |
| Surface باڈیز کو ملانا؛ Minkowski sums | پہلے {{ui:اسٹچ}} یا {{ui:موٹا کریں}}، پھر {{ui:کمبائن}} |
| Tolerance تجزیہ: کونے موڑنے والے stack-ups (2D اور 3D ویکٹر لوپس)، جیومیٹری سے نکالی گئی حساسیتیں، دوسری تقسیموں کے ساتھ Monte Carlo، خاکے کے ماپوں پر size tolerances، material condition سے bonus tolerance | اسمبلی میں {{ui:اسٹیک اپ}}: ایک سمت، worst case اور RSS، tolerances ٹائپ کر کے، ٹائٹل بلاک کی عمومی tolerance یا GD&T فریمز سے: دیکھیں [Tolerance stack-ups](topic:tolerance-stackup) |
| Nesting: کاٹنے کی ترتیب اور lead-ins، مشترک کناروں کو ایک بار کاٹنا، پرزے جو ساتھ رکھنے ہوں؛ رولز کے remnants، پراجیکٹس کے درمیان مشترک stock | spacing، margins، turns اور grain کے ساتھ {{ui:شیٹس پر فلیٹ پرزے نیسٹ کریں…}}: دیکھیں [شیٹس پر فلیٹ پرزے نیسٹ کریں](topic:nest-flat-parts)؛ بچے ہوئے پلیٹس محفوظ رہتے ہیں اور پہلے استعمال ہوتے ہیں: دیکھیں [Offcuts رکھیں اور دوبارہ استعمال کریں](topic:nest-offcuts)؛ کٹ کی منصوبہ بندی اپنے کٹر کے اپنے سافٹ ویئر میں کریں |
| Sheet metal: hems، jogs، miter اور contour flanges؛ منحنی کناروں پر یا مڑے ہوئے بیس فلینج کے رخوں پر flanges؛ خاکہ شدہ موڑ؛ corner closures؛ forming tools؛ سالڈ کو sheet metal میں بدلنا؛ کٹوں والا مڑا ہوا بیس فلینج؛ bend tables | {{ui:بیس فلینج}} (پلیٹ یا مڑا ہوا پروفائل)، سیدھے کناروں پر {{ui:ایج فلینج}} bend reliefs کے ساتھ، اور K-factor والا flat pattern: دیکھیں [Sheet metal](topic:sheet-metal) |
| اسمبلیوں پر Draft تجزیہ؛ parting line تلاش کرنا؛ دیوار کی موٹائی کا تجزیہ | ڈیزائن میں پرزے پر {{ui:ڈرافٹ تجزیہ}}: دیکھیں [مولڈنگ اور کاسٹنگ کے لیے draft جانچیں](topic:draft-analysis)؛ اسمبلی کا ہر پرزہ الگ کھول کر جانچیں |

## سمولیشن اور جنریٹو ڈیزائن

| ابھی تیار نہیں | آج کے بجائے |
|---|---|
| غیر خطی مطالعے: yielding، بڑے ڈیفلیکشن، پرزوں کے درمیان contact، fatigue | Linear static اور natural frequencies: دیکھیں [تناؤ اور ڈیفلیکشن جانچیں](topic:simulation)؛ safety factor 1 سے کافی اوپر رکھیں |
| غیر خطی buckling (imperfections، post-buckling، snap-through) | Linear buckling load factors کے ساتھ کافی margin: دیکھیں [حرارت، حرارتی تناؤ اور buckling](topic:thermal-and-buckling) |
| رخوں کے درمیان تابکاری (view factors)، contact resistance، درجۂ حرارت پر منحصر مواد، حرارتی تناؤ میں inertia (thermal shock waves) | ماحول تک تابکاری، وقت کے ساتھ steady یا quasi-static حرارتی تناؤ، مستقل خواص: دیکھیں [حرارت، حرارتی تناؤ اور buckling](topic:thermal-and-buckling) |
| Transient حرارت اور حرارتی بوجھ والے مطالعات کے لیے خودکار refinement؛ جہاں غلطی کم ہو وہاں میش کو موٹا کرنا؛ کسی مقامی مقدار پر ہدف (ایک نقطے پر چوٹی تناؤ) | **Refine automatically** جامد، buckling، natural-frequency اور steady حرارتی مطالعات کے لیے، پورے پرزے کی غلطی پر: دیکھیں [تناؤ اور ڈیفلیکشن جانچیں](topic:simulation)؛ ورنہ element size کم کریں |
| Bearing اور bolt کے لوڈز، remote forces، moments، springs، prescribed displacements | رخوں پر forces اور pressures، gravity؛ fixed اور frictionless رخ |
| اسمبلیوں کی سمولیشن؛ سمت کے لحاظ سے مختلف مواد (پرنٹ شدہ تہیں، composites) | ایک پرزہ، ایک isotropic مواد |
| Tetrahedral مطالعات، حرارتی منتقلی اور generative design کے لیے کئی solver threads؛ کسی ایسے صفحے پر threads جو cross-origin isolated نہ ہو | Voxel مطالعات، buckling، وقت کے ساتھ تناؤ اور laminar flow، جہاں صفحہ اجازت دے وہاں threads استعمال کرتے ہیں: دیکھیں [PartCraft سیٹنگز](topic:settings) |
| Turbulent flow، ڈیزائن درستگی کے ساتھ (Spalart–Allmaras ماڈل تجرباتی طور پر شامل ہے: پائپ فریکشن 30 تا 34 % زیادہ، backward-step reattachment 21 تا 39 % کم؛ منصوبہ: دیواروں کے قریب باریک خانے)، flow میں حرارت، unsteady (time-accurate) flow، آزاد سطحیں، non-Newtonian سیال، گھومتے پرزے | Laminar، steady، isothermal flow ایک Newtonian سیال کا، یا qualitative نمونوں کے لیے تجرباتی turbulent ماڈل: دیکھیں [سیال بہاؤ کی سمولیشن](topic:flow-simulation)؛ جب Reynolds number laminar سے آگے ہو تو پینل تنبیہ دیتا ہے |
| Generative design میں تناؤ کی حدیں اور مینوفیکچرنگ قواعد (overhangs، milling سمتیں)؛ ایک شکل میں کئی مواد | ایک حجم کے لیے سخت ترین شکل؛ نتیجہ Simulation میں جانچیں: دیکھیں [لوڈز سے شکل اگائیں](topic:generative-design) |
| ایک ایسا نتیجہ جو قابلِ ترمیم (ہموار، parametric) سالڈ ہو | STL، faceted STEP، یا نتیجہ بطور امپورٹ شدہ faceted سالڈ رکھنے والا پرزہ |
| برقی مشین ڈیزائن: stator میں گھومتا rotor، زاویے کے مقابل torque، سیچوریٹنگ اسٹیل، وہ مقناطیس جو اپنے knee سے آگے طاقت کھوئیں، eddy currents اور لوہے اور تانبے کا نقصان؛ 3-D یا منحنی میشز پر مقناطیسی میدان | تجزیاتی لائبریری میں گرڈ پر linear 2-D magnetostatics: کوائلز، لوہا، اپنی recoil لائن پر permanent magnets، گیپس، inductance اور pull: دیکھیں [2-D میں مقناطیسی میدان](topic:magnetic-fields-2d) |
